# Weekly prune

Run this once a week in the Memory Steward thread. Nothing is deleted until the founder says yes.

## Report (three lists only)

### 1. Learned

What became true this week that we did not have last week. One line each.

### 2. Promote to shared

Private notes that earned a permanent home (profile, decision, skill, rule). Quote the source bot and the proposed shared text.

### 3. Stale — propose delete

Facts, drafts, or rules that are old, duplicated, or contradicted. Show where they live. Wait.

## Cadence

- Same weekday. Same bot. Same three headings.
- After yes: delete the stale stores, write `always X, never Y` if a correction caused the delete.
- Standing goal remains: keep memory clean and current without being asked, but **still wait for yes on deletes** unless the founder just corrected that exact fact.

## Done when

The steward can point at: an updated Who-I-Am (if needed), new DECISIONS rows, new rules, and an empty “stale” list or a list awaiting yes.
