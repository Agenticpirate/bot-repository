    Grok Bot Skills vs Grok Bot Plugins

    A skill is a SKILL.md file: plain-text instructions, examples and guardrails that Grok Bot reads when a task matches. It changes how the agent works, not what it can connect to. There is no runtime, no install step beyond copying a folder, and nothing to keep updated.

    A plugin or MCP server is code. It adds capability: an API the agent can call, a database it can query, a tool it can execute. It needs credentials, a process to run, and version management.

    Most of the time the thing you actually want is a skill, because the model can already do the work and just needs the expert's method. Reach for a plugin when Grok Bot has to touch a system it has no access to. The two combine well: a skill can tell Grok Bot exactly how and when to use a plugin you already have installed.

    Use Your Skills Across AI Agents

    SKILL.md is an open format, so a skill is not locked to one agent. The same file you drop into your Grok Bot skill library for Grok Bot also loads in Claude Code, Cursor, Codex CLI, Gemini CLI, GitHub Copilot and 20+ other agents that read SKILL.md.

    That matters when you switch tools or work across a team that does not standardise on one agent. You buy the method once and keep it, instead of rebuilding prompts every time your stack changes. Skills that genuinely depend on one agent's file layout are marked as agent-specific on their listing, so you always know which one you are getting.

    How to install a skill in Grok Bot

    Skills load from your Grok Bot skill library

    1. Download the skill zip from Agensi and open the SKILL.md inside it.
    2. In Grok Bot, open the Bot you want to teach and go to Skills.
    3. Save a new skill and paste in the SKILL.md instructions, then keep the bundled reference files alongside it.
    4. Run the task once to confirm the Bot follows the saved method, then attach a routine if you want it to run on a schedule.
