# Vellum CLI

> The command line interface for interacting with Vellum.

The Vellum CLI is a command line interface for interacting with Vellum. It allows you to push and pull resources defined in both the Vellum application and the Vellum SDKs.

The push feature has different levels of support for different components and workflow types. See the [Push Feature Status](/developers/workflows-sdk/api-reference/push-feature-status) page for more details on current limitations and capabilities.

#### [Ping](/developers/workflows-sdk/api-reference/cli/ping)

Verify that the Vellum CLI is authenticated correctly

#### [Pull](/developers/workflows-sdk/api-reference/cli/pull)

Download resources from Vellum to your local environment

#### [Push](/developers/workflows-sdk/api-reference/cli/push)

Upload resources from your local environment to Vellum
