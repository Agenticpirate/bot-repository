# Skills Reference

Everything your assistant can do out of the box. One page per skill, same format throughout. Scan what you need, skip what you don't.

Each skill page covers:

- **What it does** — one sentence
- **Setup required** — what you need before first use
- **Permissions** — what access it needs
- **Common prompts** — things you can say to use it
- **Configuration** — options and settings
- **Tips & gotchas** — the stuff nobody tells you
