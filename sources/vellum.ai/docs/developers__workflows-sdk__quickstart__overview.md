# Quickstart Overview

> Learn how to define and run a Workflow in Vellum using the Workflows SDK or pull a Workflow from the Vellum UI.

## Prerequisites

Before getting started, make sure you have:

* Python 3.9+ installed ([download here](https://www.python.org/downloads/))
* A Vellum account ([sign up for free](https://app.vellum.ai/signup?f=wsdk\&utm_source=docs\&utm_medium=quickstart\&utm_campaign=sdk))
* Your `VELLUM_API_KEY` environment variable set

For detailed installation instructions including Python and `uv` setup, see our [Installation Guide](/developers/workflows-sdk/installation).
