FAQ

What are Claude Code skills?

Reusable instruction sets that teach your agent specific tasks. Install with a single command.

What are plugin marketplaces?

GitHub repositories that collect and distribute plugins. Each marketplace acts as a registry you can subscribe to for skills, MCP servers, commands, hooks, and agents.

What are MCP servers?

Protocol servers that extend your agent with tools, APIs, and integrations to external services.

What is a plugin?

A bundle of Claude Code extensions — skills, MCP servers, commands, hooks, or agents — packaged as one installable unit.

Skill vs. plugin vs. marketplace?

A skill is a single instruction set. A plugin bundles multiple skills, MCP servers, or commands. A marketplace is a GitHub repo that distributes many plugins under one registry.

How do I install something?

Copy the install command from any detail page and run it in your terminal. Most items install with a single command.

How is quality maintained?

Ranked by install count, GitHub stars, registry metadata, and usage, with policy checks for spam and off-topic listings.

Is this free?

Yes. Completely free and open. Browse and install anything at no cost.
