Frequently Asked Questions

What are Claude Code skills?
Claude Code skills are reusable system prompts that give AI coding agents specialized expertise. They work across Claude Code, Cursor, GitHub Copilot, Windsurf, and Cline. Install them with a single command to enhance code review, testing, frontend development, and more. Browse 8,886 skills →
How do I use Claude Code?
Install with npm install -g @anthropic-ai/claude-code, then run claude in any project. Read our tutorial or installation guide.
What Claude Code commands are available?
Claude Code supports slash commands like /install to add skills, /init to set up CLAUDE.md, and custom commands via plugins. See our slash commands guide and CLI reference.
What are MCP servers?
MCP (Model Context Protocol) servers extend AI coding agents with external tools -- databases, APIs, cloud services, and more. Browse 6,543 MCP servers or read the MCP guide.
What is agentic coding?
Agentic coding is when AI coding agents autonomously write, test, debug, and iterate on code. Unlike autocomplete, agents take multi-step actions across your entire project. Read our agentic coding guide.
