## 常见问题FAQ

### Q1: 如何在日历工具中搜索特定日期的事件？
A: 在日历工具中，您可以通过输入日期范围和关键词来搜索特定日期的事件。例如，输入“2023-12-01”和“会议”可以搜索2023年12月1日所有包含“会议”关键词的事件。

### Q2: 如果同步事件失败，我该如何处理？
A: 如果同步事件失败，首先检查网络连接是否稳定。如果网络正常，检查事件数据格式是否符合要求。如果问题依旧，请联系技术支持以获取进一步的帮助。

### Q3: 日历工具支持哪些类型的日历同步？
A: 日历工具支持与飞书Lark日历的同步，包括个人日历和共享日历。目前不支持与其他第三方日历服务的同步。

### Q4: 我能否在日历工具中设置事件提醒？
A: 目前日历工具不支持设置事件提醒功能。您需要在飞书Lark日历中手动设置事件提醒。

### Q5: 如果我需要查看多个日历的日程，应该如何操作？
A: 您可以在日历工具中指定多个日历ID，系统将列出这些日历的日程列表。确保在调用技能时提供所有相关日历的ID。

## 错误恢复流程
针对日历工具使用中可能遇到的常见问题,提供以下排查方案:

| 错误类型 | 原因分析 | 解决方案 |
|---------|---------|---------|
| API认证失败(401) | API密钥错误或过期 | 检查密钥配置,重新生成token |
| 接口限流(429) | 请求频率超出限制 | 降低调用频率,启用重试退避策略 |
| 响应超时(504) | 网络延迟或服务端负载过高 | 增加超时阈值,检查网络连接 |
| 文件不存在 | 路径错误或文件未创建 | 检查路径拼写,确认文件已生成 |
| 文件格式不支持 | 扩展名不在支持列表中 | 转换为支持的格式后重试 |
| 权限不足 | 当前用户无读写权限 | 检查文件权限,以管理员身份运行 |
| 命令执行失败 | 参数错误或环境依赖缺失 | 检查命令语法,确认依赖已安装 |
| 进程超时 | 命令执行时间过长 | 增加超时设置,优化命令参数 |
| 网络连接失败 | DNS解析失败或防火墙拦截 | 检查网络配置,确认代理设置 |
