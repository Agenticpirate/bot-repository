# 芝麻信用分 Skill

芝麻信用是蚂蚁集团的**商业信用评分**（350-950 分），用于支付宝
生态内的信用服务准入。它不是央行征信，但两者都值得维护。

## 分数构成（五维）

| 维度 | 大意 | 你能影响的部分 |
|------|------|----------------|
| 信用历史 | 花呗/借呗等按时还款记录 | 按时还款，别逾期 |
| 行为积累 | 支付宝生态使用深度 | 长期正常使用 |
| 资产证明 | 余额宝/理财等资产信息 | 如实完善，不必刻意堆 |
| 身份信息 | 实名/学历/职业等完善度 | 如实填写 |
| 人脉关系 | 生态内社交关联 | 权重低，不必经营 |

**有效提升 = 按时履约 + 信息如实完善 + 时间**。网上"快速提分
秘籍"（互转转账/买提分服务）基本无效或是骗局。

## 免押与信用权益场景

- **免押租赁**：充电宝/共享单车/租衣租物租数码，达标分数免押金
- **酒店**：信用住（先住后付免查房，见 `fliggy` skill）
- **出行**：部分城市先乘后付
- **签证便利**：部分国家签证材料简化（政策随时变，以官方为准）
- 使用逻辑：免押的本质是"违约成本从押金变成信用分"，
  租借物品照样要按约归还

## 常见误区澄清

1. **芝麻分 ≠ 央行征信**：银行房贷看的是央行征信报告，
   不看芝麻分；两套体系数据有部分互通但独立运行
2. **分数不是越高越有用**：主要是阶梯准入（如 550/600/650 档），
   过线即可享受对应权益
3. 逾期一次掉多少分没有公开公式，恢复靠持续履约，无捷径

## Agent 典型用法

1. **提分咨询**：给"有效动作 vs 无效偏方"清单，管理预期
2. **免押规划**：按用户分数列当前可用的免押场景
3. **误区答疑**：征信关系、逾期恢复按上文口径回答

## 本 skill 不做什么

- 不提供刷分、买分、洗白服务的渠道（均为骗局或违规）
- 分数规则为蚂蚁商业机密且动态调整，只讲已公开的构成逻辑
- 涉及央行征信异议处理，指路人民银行征信中心官方渠道
