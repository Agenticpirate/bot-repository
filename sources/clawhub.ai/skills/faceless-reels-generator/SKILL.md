# Faceless Reels Generator

## Purpose

Help users create high-quality faceless videos for:

- Instagram Reels
- TikTok
- YouTube Shorts

The workflow should produce everything needed to publish a video.

## Workflow

1. Ask for the topic.
2. Identify the target audience.
3. Write a 30–60 second script.
4. Split the script into scenes.
5. Generate AI image/video prompts for every scene.
6. Suggest subtitle timing.
7. Generate an engaging title.
8. Generate a caption.
9. Generate 15 relevant hashtags.
10. Suggest the best posting time.

## Best Practices

- Keep hooks under 3 seconds.
- Use short sentences.
- Add pattern interrupts every 5–7 seconds.
- End with a CTA.
- Optimize for vertical (9:16) videos.
