# AI无脸视频频道自动化系统

## 变现逻辑

无脸视频频道是2026年最热门的被动收入赛道之一，不需要露脸、
不需要真人出镜，只需要AI生成内容，靠流量分成和商单变现。

**赚钱方式**：
- B站创作激励（1000播放≈1-3元）
- YouTube AdSense（1000播放≈1-5美金）
- 抖音中视频计划
- 粉丝过万后接商单（500-5000元/条）
- 挂小黄车带货佣金

**适合赛道**：历史冷知识、悬疑故事、财经科普、书单推荐、
心理学、创业故事、科技资讯、产品评测等。

---

## 核心能力

### 1. 爆款选题挖掘

```python
# 流程示意
1. 用户提供赛道关键词（如"历史冷知识"）
2. WebSearch搜索该赛道近期高播放量视频
3. 分析爆款公式（开头钩子/信息密度/评论互动点）
4. 生成10-20个选题列表（含预估播放潜力评分）
5. 识别内容空白（用户感兴趣但没人做好的方向）
```

### 2. AI脚本生成

按平台特性和赛道风格生成专业脚本：

| 平台 | 时长 | 脚本风格 | 开头钩子要求 |
|------|------|---------|------------|
| 抖音 | 15-60秒 | 快节奏、强反转 | 前2秒必抓人 |
| B站 | 3-10分钟 | 深度+趣味+梗 | 前10秒定调 |
| YouTube | 8-20分钟 | 信息密度+叙事 | 前30秒价值承诺 |
| 小红书 | 1-3分钟 | 干货+种草 | 封面+前5秒 |

每个脚本包含：
- ✅ 抓人眼球的开头（3-5种钩子可选）
- ✅ 核心信息结构（起承转合）
- ✅ 画面/素材标注（[xxx画面]）
- ✅ 结尾引导互动（关注/点赞/评论）
- ✅ SEO标题和标签
- ✅ 封面标题文案

### 3. AI配音生成

支持多种风格声线，根据赛道自动匹配：

| 赛道 | 推荐声线 | 语速 | 语调 |
|------|---------|------|------|
| 历史/知识 | 沉稳男声 | 中速 | 平实叙述 |
| 悬疑故事 | 低沉男声 | 偏慢 | 悬疑感 |
| 财经科普 | 清晰女声 | 中速 | 专业 |
| 书单推荐 | 温暖女声 | 中速 | 亲和力 |
| 科技资讯 | 理性男声 | 偏快 | 干脆 |

### 4. 画面素材匹配

根据脚本内容自动匹配合适的画面：

- **免费图库**：Pexels / Pixabay / Unsplash 关键词构建
- **AI生成配图**：根据场景描述生成AI插画
- **信息图**：自动生成关键数据可视化图表
- **文本动画**：重点内容用文字卡片展示
- **背景音乐**：根据情绪推荐BGM（激昂/悬疑/温馨）

### 5. 字幕与包装

- 自动生成SRT字幕文件（中/英文）
- B站风格封面标题（大字+背景+边框）
- YouTube缩略图文字（大号sans-serif+对比色）
- 片头片尾模板（5秒统一品牌）

## 自进化学习系统（越用越好用、越用越高效）

本技能内置通用学习模块 `scripts/learner.py`。每次使用后自动复盘、积累经验，逐步提升输出质量与执行效率，无需人工维护。

### 记忆文件
`learned_patterns.json`（位于本技能目录）记录：操作总数、各能力使用频次、错误模式、用户偏好、改进建议。

### 使用后请调用（Bash）

```bash
# 记录一次成功使用（--capability 填本次主要能力名，如「简历优化」「比价」）
python scripts/learner.py record <本技能目录> --capability 简历优化
# 记录一次失败/异常
python scripts/learner.py record <本技能目录> --capability 简历优化 --fail --error 格式识别失败 --note "用户上传了非标准文件"
# 记录用户偏好（下次直接使用）
python scripts/learner.py prefer <本技能目录> --key 输出语言 --val 中文
# 查看累计洞察（高频能力 / 反复错误）
python scripts/learner.py insight <本技能目录>
# 自动复盘（错误≥3次 或 操作≥10次 时给出改进建议）
python scripts/learner.py reflect <本技能目录>
```

### 迭代规则
- **错误累计 ≥3 次** → 主动增加预检/兜底步骤，并将经验回写本 SKILL.md。
- **操作数 ≥10 次** → 分析高频能力优先打磨示例与质量，低频能力评估精简或合并。
- **重要用户偏好** → 写入 `learned_patterns.json`，下次调用直接采用，减少重复询问。

> 越用越懂你：第一次用是通用能力，第十次用已沉淀为你专属的最佳实践。
