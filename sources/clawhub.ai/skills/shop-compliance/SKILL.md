## 📋 功能概述

Shop-Compliance 面向电商平台上的中小商家，提供四大模块的快速合规筛查：

| 模块 | 检查什么 | 适用场景 |
|------|---------|---------|
| 📋 **商品上架** | 极限词审查、资质检查、描述真实性 | 上新商品前、被举报时 |
| 👥 **消费者权益** | 七天无理由退货、自动续费、投诉处理 | 开店初期、收到投诉时 |
| 🔐 **客户信息保护** | 信息共享、隐私面单、数据清理 | 店铺运营中、准备注销时 |
| 📢 **营销合规** | 直播话术、促销价格、短信营销 | 直播前、做大促前 |

## 🚀 快速开始

```bash
# 全量检查（推荐）
python3 scripts/shop-compliance-check.py --interactive

# 单模块检查
python3 scripts/shop-compliance-check.py -s listing
python3 scripts/shop-compliance-check.py -s consumer
python3 scripts/shop-compliance-check.py -s data
python3 scripts/shop-compliance-check.py -s marketing

# 输出报告
python3 scripts/shop-compliance-check.py -o report.md
python3 scripts/shop-compliance-check.py -o report.html -f html
```
