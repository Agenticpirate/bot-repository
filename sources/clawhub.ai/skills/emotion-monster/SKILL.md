# 🦋 情緒小怪獸（Emotion Monster）

## 名稱
emotion-monster

## 描述
情緒小怪獸，幫助 2-6 歲孩童認識與表達情緒的互動工具。透過情緒卡片、情緒日記、引導式問答，讓孩子學會用健康方式認識、理解、表達自己的情緒。

## 觸發關鍵字
情緒、心情、難過了、生氣了、害怕了、為什麼哭、情緒卡、情緒教育、情緒管理、孩子鬧脾氣、小孩生氣、小孩哭、情緒小怪獸、emotion、feeling

## 功能說明

### 1. 情緒卡片（emotion_cards.py）
展示 8 種基本情緒卡，每張卡用彩色 ASCII 藝術呈現，包含 Emoji、短句描述、情緒小怪獸角色。引導孩子「你現在像哪個小怪獸？」並提供幼兒能執行的健康建議。

### 2. 情緒日記（mood_diary.py）
每日情緒記錄工具，幫助孩子追蹤自己的情緒變化。包含互動式引導問答、本週統計、情緒趨勢文字視覺化、進步追蹤。數據保存在 `~/.bookshelf-plus/kids/mood_diary.json`。

### 3. 情緒教練（emotion_coach.py）
當孩子崩潰、大哭或生氣時的即時引導腳本。提供爸媽版引導語和給孩子聽的短語，分五步驟：命名情緒 → 接受情緒 → 深呼吸引導 → 表達引導 → 解決方案。

### 4. 情緒日曆（emotion_calendar.py）
月度情緒日曆，以 Emoji 呈現每天主要情緒，提供週末總結和彩色週月視圖。

## 核心概念
- 每種情緒對應一隻「小怪獸」角色，把情緒當朋友而非壞東西
- 「小怪獸跑出來了」= 情緒來了，這是正常的
- 語言全為繁體中文，適合 2-6 歲理解
- 零責怪、零羞辱、零惩罚暗示
