# 培训计划编排

> 输出为参考建议，最终排期由主理人确认后执行。

## 能力概述

根据培训通知模板，自动编排完整的培训计划，覆盖：

| 模块 | 核心内容 |
|------|---------|
| 基本信息 | 培训名称、届数、主题、组织机构 |
| 时间排期 | 日期选择、日程表生成、节假日冲突检查 |
| 讲师管理 | 讲师邀约、确认状态、课件提交跟踪 |
| 课程设计 | 模块划分、内容编排、课时分配 |
| 场地酒店 | 场地预订、住宿安排、交通指引 |
| 费用定价 | 收费标准、早鸟价、团队价、成本预估 |
| 筹备日程 | 倒计时甘特图、各阶段截止日期 |

## 输入

- **培训通知模板**：主办方提供的培训通知（含组织机构、时间地点、课程安排、费用等）
- **历史培训数据**：往期排期、讲师库、场地信息（可选）
- **自定义约束**：用户指定的特殊要求

【培训主题】XXX

【组织机构】
  - 主办：XXX
  - 承办：XXX
  - 协办：XXX
【培训对象】XXX
【培训目标】XXX
【培训方式】XXX
【收费标准】XXX元/人（团队价XXX元/人）
【课程安排】

  │   ├─ 09:00-12:00 模块一：XXX（主讲人：XXX）

### 筹备倒计时表

| 阶段 | 截止日 | 事项 | 负责人 | 状态 |
|------|--------|------|--------|------|
| T-60天 | MM-DD | 确定培训主题和日期 | 主理人 | ⏳ |
| T-45天 | MM-DD | 邀请讲师、确认课程 | 主理人 | ⏳ |
| T-30天 | MM-DD | 发布招生简章、开放报名 | 运营 | ⏳ |
| T-21天 | MM-DD | 场地酒店预订确认 | 行政 | ⏳ |
| T-14天 | MM-DD | 教材课件定稿 | 讲师 | ⏳ |
| T-7天 | MM-DD | 设备物料检查、学员确认 | 运营 | ⏳ |
| T-0天 | MM-DD | 培训执行 | 全员 | ⏳ |

## 工作流程

1. **解析培训通知**：提取时间、地点、课程、讲师、费用等关键信息
2. **时间排期检查**：核对节假日冲突、讲师档期、场地可用性
3. **生成课程表**：按天排布模块、主讲人、内容
4. **生成倒计时表**：从T-60到T-0的完整筹备日程
5. **输出计划书**：完整的培训计划 + 筹备甘特图

## 数据模型（培训记录）

每条培训记录包含：
- `id`：第X期
- `name`：培训名称
- `theme`：培训主题
- `date_start`：开始日期
- `date_end`：结束日期
- `location`：地点
- `organizers`：组织机构（主办/承办/协办）
- `target`：培训对象
- `fee`：收费标准
- `courses`：课程安排（数组，含时间/模块/讲师/内容）
- `lecturers`：讲师列表（含姓名/主题/确认状态/课件状态）
- `status`：筹备中/招生中/执行中/已结算/已归档
- `checklist`：筹备检查清单状态
