# 新闻联播政策摘报

## 概述

从新闻联播每日文字稿中提取宏观经济政策相关内容，生成结构化摘要报告。将新闻
按政策影响力分为三级：直接影响金融市场（降准降息、资本市场改革等）、重大产业
区域政策（新质生产力、区域战略等）、一般性政策参考（就业、民生等）。

## 工作流程

### 第一步：确定目标日期

询问或推断用户关心的新闻联播日期：

- "今天的新闻联播" → 当前日期
- "昨天的新闻联播" → 当前日期 - 1 天
- "最近一期的新闻联播" → 当前日期（或前一天，取决于是否已播出）
- 明确指定日期如 "8月1日的" → 解析为具体日期

新闻联播每晚 19:00 首播，若当前时间在 19:00 之前，当日内容通常尚未发布，
此时默认查询前一天的内容，并向用户说明。

### 第二步：获取新闻联播文字稿

同时尝试以下多个来源获取文字稿，选择一个内容最完整的：

1. **央视网官方**：使用 WebSearch 搜索 `新闻联播 文字稿 2026年X月X日`，
   优先选择 cctv.com 或 cctv.cn 域名的结果。
2. **新华网**：搜索 `新闻联播 主要内容 2026年X月X日 site:news.cn`
3. **人民网**：搜索 `新闻联播 摘要 2026年X月X日 site:people.com.cn`
4. 若以上来源均无完整文字稿，也可使用 `新闻联播 2026年X月X日 完整版 文字`
   进行宽泛搜索。

获取到链接后，用 WebFetch 抓取页面全文内容。

若当日文字稿暂未发布（通常次日早晨各大网站才会发布完整文字稿），告知用户
当前可获取的最新一期日期，询问是否查看该期内容。

### 第三步：解析与提取

将获取到的文字稿保存为临时文件（如 `C:\Users\mike\WorkBuddy\2026-08-02-16-21-00\.temp_xwlb.txt`），
然后使用解析脚本处理：

```bash
python "C:/Users/mike/.workbuddy/skills/xwlb-policy-extract/scripts/parse_xwlb.py" \
  "<临时文件路径>" \
  --date "YYYY-MM-DD"
```

脚本工作方式：
- 自动将文字稿拆分为单条新闻
- 与三级关键词库匹配，识别政策相关条目
- 按影响力分级（tier1/tier2/tier3）
- 合并相似条目，避免重复
- 输出结构化 Markdown 报告

若用户只需要 JSON 格式数据（用于后续处理），使用 `--format json` 参数。

### 第四步：呈现结果

将脚本输出的 Markdown 报告直接展示给用户。报告结构如下：

```
📺 新闻联播政策摘报 (YYYY-MM-DD)
> 总条数 / 政策条数统计

🎯 重点政策摘要
### 🔴 直接影响金融市场
  - 标题、关键词、内容预览
### 🟡 重大产业/区域政策
  - ...
### 🟢 一般性政策参考
  - ...

📋 其他要闻速览
1. 非政策类新闻标题列表
```

可在报告结尾补充简要总结（2-3 句话），概括当日政策信号的核心方向。

### 第五步：清理

删除临时文字稿文件。

## 关键词参考

解析脚本使用的完整关键词库位于 `references/macro_keywords.md`。
如需增删关键词（如添加新兴产业概念、新政策术语），直接编辑该文件
和脚本中对应的 `TIER1_KEYWORDS` / `TIER2_KEYWORDS` / `TIER3_KEYWORDS` 字典。

## 使用示例

**用户说：** "帮我看看今天新闻联播有什么重要的政策内容"

**执行：**
1. 确定日期 = 今日
2. WebSearch → 获取文字稿链接 → WebFetch 抓取全文
3. 运行 parse_xwlb.py 解析
4. 展示 Markdown 报告

---

**用户说：** "上周五的新闻联播有没有提到降息相关的？"

**执行：**
1. 确定日期 = 上周五的具体日期
2. WebSearch → WebFetch 获取文字稿
3. 运行 parse_xwlb.py 解析
4. 重点展示 tier1 中与"降息"、"货币政策"相关条目
