# 网文创作流水线（novel-writing-sop）

四阶段、文件编号化、可轻可重的中文网文生产流程。  
**卖点就三句：** 文件工程化长篇、5 章一批双视角质检、可执行去 AI 腔。  
**严禁抄袭**——学结构与爽点设计可以，照搬情节/设定不行。

## 什么时候用

- 用户说：写小说、写网文、写爽文、做大纲、续写、卡文、去 AI 味、分章写、长篇连载
- 平台向：番茄 / 起点 / 晋江 / 七猫
- 题材：男频/女频/玄幻/仙侠/古言/都市/科幻/系统流/重生穿越…

## 三模式（先选模式，再开工）

| 模式 | 适用 | 最少产出 | 门禁 |
|------|------|----------|------|
| **快速** | 先看效果、试文风 | 3 选题 + 迷你设定 + **第 1 章** | 字数≥2500，去 AI 腔速扫 |
| **标准** | 认真开书 | 选题 + **6 文档大纲** + 第 1 批 5 章 | 大纲确认后才批量写 |
| **量产** | 已有大纲，连载推进 | 每批 5 章 + 三审报告 | 编剧≥80 / 读者≥80 / 去AI≥38 |

默认：用户没说清楚 → **先走快速模式出第 1 章**，再问要不要升标准/量产。  
用户明确要完整长篇/工作室流程 → 标准或量产。

---

## 硬规则

1. **不抄袭**
2. **标准/量产：大纲先行**（6 文档完成前不批量写正文）
3. **快速模式可先写第 1 章**，但必须同步留下迷你设定，避免后崩
4. **5 章一批**（量产）：写完 → 编剧审 + 读者审 + 去 AI 腔 → 通过再下一批
5. **每章 ≥2500 字**（不含标题和「本章完」）
6. **钩子链不断**：章末悬念 → 下章开头衔接
7. **AI 高频词必删**：见 `references/去AI腔过滤指南.md`
8. **审核内嵌本技能**，不依赖外部 `novel-review` / `novel-reader-review` 技能

---

## 快速模式（5–15 分钟出活）

1. 只问 4 件事（能猜到的别反复问）：题材、男/女频、金手指、平台调性  
2. 给 **3 个选题**（书名约 15 字内 + ≤150 字简介 + 卖点）  
3. 用户选定或说「你定」→ 写 `1-选题.txt` 迷你版 + `2-核心设定.txt` 缩略版（800–1500 字即可）  
4. 直接写 `8-正文-第1章.txt`（≥2500）  
5. 章末自检：去 AI 腔速扫 + 钩子  
6. 问用户：继续快速写第 2 章，还是升级标准大纲

---

## 标准模式 = 四阶段完整 SOP

```
A 选题素材 → B 6文档大纲 → C 5章一批 → D 全书整合
```

### A. 选题

问清：题材/平台/金手指/参考作/目标字数。  
按 `references/01_选题与素材阶段.md` 出 3 案 → 写入：

- `1-选题.txt`
- `3-标签简介.txt`（6–8 标签 + 黄金简介）

### B. 6 文档大纲（逐个确认）

| # | 文档 | 参考模板 |
|---|------|----------|
| 1 | `2-核心设定.txt` | `templates/01_核心设定.md` + `02_人物群像.md` |
| 2 | `4-分卷大纲.txt` | `templates/03_主线剧情脉络.md` |
| 3 | `5-第X卷-剧情单元.txt` + `5-分章大纲.txt` | `templates/04_分卷细纲.md` |
| 4 | `6-节奏控制.txt` | `templates/05_系统与节奏控制.md` |
| 5 | `6-执行附录.txt` | `templates/06_执行附录.md` |

剧情单元习惯：5 章 = 1 单元。全书可按 5 卷规划，但允许用户改短。

### C. 量产循环（每批 5 章）

```
定位批次 N → 加载设定/大纲/上批钩子
→ 写/更新 5-第{N}-{N+4}章-分章大纲.txt
→ 逐章写 8-正文-第N章.txt（写一章核一字数）
→ 三审（本技能内嵌评分卡，见下）
→ 保存 7-批量核验-第{N}-{N+4}章.txt
→ 更新 6-执行附录.txt 伏笔/进度
→ 下一批
```

用户说「继续直到结束」：批次间可不打断确认，**三审不可省**。

### D. 整合

通读、统一称呼/时间线、回收伏笔、检查爽点与黄金三章、统一格式。  
详见 `references/04_整合阶段.md`。

---

## 内嵌三审评分卡（每批必做）

### 1) 编剧审（100，≥80）

| 维度 | 分 |
|------|----|
| 连贯性（大纲一致、衔接、逻辑） | 30 |
| 内容质量（人物/对话/描写） | 30 |
| 字数（≥2500、不注水） | 20 |
| 节奏（爽点、钩子、张弛） | 20 |

### 2) 读者审（100，≥80）

| 维度 | 分 |
|------|----|
| 故事连贯（5 章成小闭环） | 25 |
| 吸引力（悬念/可读） | 25 |
| 爽点密度（类型多样） | 25 |
| Bug（设定/人设/时间线） | 25 |

### 3) 去 AI 腔（50，≥38）

直接 / 干净 / 真实 / 动作化 / 具体 —— 各 10 分。  
必杀清单见 `references/去AI腔过滤指南.md`。

**速记禁用：** 值得注意的是、不是…而是…、就在此时/突然/忽然、不禁想到、心中一凛/倒吸凉气、身形一闪/快如闪电、非常/十分/极其、一排数据流、此刻他心中只有一个念头…  
**结构禁用：** 二元对立、否定列举、设问自答、排比堆砌、流水账转场、段末金句综合征。  
**格式：** 禁章节标题 `#` 前缀、禁 `——` 装饰线、禁 `*加粗*`；对白用「」。

任一不过 → 指出问题 → 改 → 重审（不静默死循环刷分）。

可用脚本做字数门禁：

```bash
python scripts/batch_review.py <项目目录> <起始章号>
```

## Agent 协作约定

- 被动触发：匹配写小说/网文/大纲/续写/去AI味等意图即加载
- 先快速出活，再问是否上完整大纲（除非用户点名标准/量产）
- 每阶段结束默认等确认；「继续直到结束」除外
- 主笔可用强创作模型；去 AI 腔可换视角重读，但仍在本技能内完成
- 详细 SOP 按需读 `references/`，不要一次全塞进上下文
