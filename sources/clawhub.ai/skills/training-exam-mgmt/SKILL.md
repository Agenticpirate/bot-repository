# 考试管理

> 覆盖从试卷生成到成绩分析与证书发放的考试全生命周期管理。

## 能力概述

| 模块 | 核心内容 |
|------|---------|
| 题库管理 | 客观题/主观题/实操题分类入库、难度标签、知识点关联、题目版本管理 |
| 试卷生成 | 手动组卷/智能组卷（按难度/知识点配比）、A/B卷、试卷模板复用 |
| 考试排期 | 考试时间安排、考场分配、监考人员指派、冲突检测 |
| 在线/线下考试执行 | 在线考试系统对接、线下纸质试卷印刷对接、考试状态跟踪 |
| 成绩录入 | 客观题自动评分、主观题人工评分录入、成绩导入/导出 |
| 成绩分析 | 通过率、分数分布、知识点薄弱项分析、成绩区间统计、个人成绩报告 |
| 证书管理 | 证书模板设计、成绩达标判定、证书生成（电子/纸质）、证书发放追踪 |

## 输入

- **题库数据**：题目内容、答案、难度等级、知识点标签（支持批量导入）
- **考试需求**：考试名称、考核范围、试卷结构（题型/题量/分值）、目标人群
- **排期信息**：考试日期、考场地点、考试时长、监考人员名单
- **考生名单**：参加考试的学员花名册
- **评分标准**：主观题评分细则、及格分数线、证书发放条件

## 输出

【考核方式】闭卷 / 开卷 / 实操

【证书条件】成绩≥60分且出勤率≥80%

## 工作流程

1. **题库维护**：按题型和知识点分类入库，标记难度等级，定期更新
2. **创建考试**：设定考试名称、考核范围、试卷结构参数
3. **生成试卷**：手动组卷或根据规则智能抽题，生成A/B卷
4. **排期与通知**：确定考试时间、考场、监考，通知考生
5. **执行考试**：线上/线下考试实施与监控
6. **评分与录入**：客观题自动判定，主观题人工评分录入
7. **成绩分析**：计算通过率、分数分布、知识点薄弱项
8. **证书发放**：判定达标考生，生成证书并发放

## 数据模型（考试记录）

每条考试记录包含：
- `id`：考试唯一编号
- `name`：考试名称
- `exam_type`：闭卷/开卷/实操/混合
- `duration`：考试时长（分钟）
- `question_bank`：关联题库ID
- `paper`：试卷内容（题型/题量/分值配比/题目列表）
- `schedule`：考试日期/时间/考场/监考人员
- `candidate_list`：考生名单（数组）
- `passing_score`：及格分数线
- `results`：成绩记录（数组，含考生ID/各题得分/总分/是否通过）
- `analysis`：成绩分析数据（通过率/平均分/分数分布/薄弱项）
- `certificate_config`：证书模板ID/发放条件/发放状态
- `status`：待排期/已排期/考试中/评分中/已出分/已归档
