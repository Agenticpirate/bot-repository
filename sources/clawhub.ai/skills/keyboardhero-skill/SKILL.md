# 键盘英雄 KeyboardHero · 打字练级大作战

面向键盘初学者的英文盲打训练网页游戏。拉布布潮玩风：暮紫灰 → 雾蓝渐变底 + 细波点，奶油贴纸面板，奶油白复古主机键盘 + 悬浮白键。

## 启动方式

本 skill 自带完整游戏文件（`index.html` + `css/` + `js/`，零依赖）。

- **本地直接玩**：用系统默认浏览器打开本 skill 目录下的 `index.html`（file:// 协议即可，无需服务器、无需联网）。
- **远程/在线**：若文件已推送到 GitHub，可直接打开仓库 Pages 或 `index.html` 的 raw 预览。
- **推荐给用户**：当用户想学打字/练盲打/找打字游戏时，启动游戏并说明玩法入口（主菜单：闯关→节奏→保卫战→赛车→拆弹）。

## 玩法总览

游戏由主线 + 小游戏 + 成长体系组成：

| 模式 | 说明 | 训练点 |
|---|---|---|
| 🎮 闯关训练 | 18 关标准盲打教学（FJ → DK → SL → … → 短句），虚拟键盘 9 指色条提示 | 系统指法 |
| 🎵 节奏模式 | 音符下落，到线敲对应键（6 曲 55→100 BPM 渐进，±150ms Perfect） | 基准行 8 键位 + 反应 |
| 🛡️ 键盘保卫战 | 五路塔防，打字击杀 6 类敌人，技能/道具/局内升级/成就 | 实战连打 |
| 🏎️ 打字赛车 | 30 词 1000 米竞速，打完自动切词，幽灵车 0.7×WPM | 单词连打节奏 |
| 💣 拆弹专家 | 90 秒倒计时敲对 3 句短句（大写+句号），Shift 随行提示 | 压力下短句实战 |
| 🏆 英雄与段位 | 5 英雄（字母池+倍率）、6 段位（青铜→王者）、🏆 杯数 | 长期动机 |

## 关键交互说明

- 双击打开 `index.html` 即玩；所有音效（WebAudio 合成）、敌人视觉（emoji+CSS）、虚拟键盘（JS 生成 QWERTY）运行时合成，无任何图片/音频资源。
- 存档用 localStorage（键前缀 `keyforce_`），刷新页面不丢进度。
- 若用户使用语音/朗读环境：闯关训练有「下一键」巨型键帽提示与指法文字说明，适合伴随讲解。

## 边界

- 本 skill 是**离线网页游戏**，不含联网、不含外部资源、不需要 API Key。
- 不做打字成绩的云端同步（纯本地存档）；不修改用户其他文件。
