# guaikei抖音数据流式接口

获取抖音公开数据的技能：关键词搜索、博主作品抓取、视频评论分析、实时热榜查询。一次最多获取 1 万条结构化数据，输出纯 JSON，可直接用于内容策划、竞品分析、舆情监控。

## 何时使用

| 场景 | 典型用户表达 |
|------|-------------|
| 关键词搜索 | "搜一下AI教程的抖音视频""找点赞最多的减肥视频""最近一周有什么火的短视频" |
| 博主作品抓取 | "看看这个博主的所有作品""抓取这个账号的主页数据""获取他最近50条视频" |
| 视频评论分析 | "这个视频的评论怎么说""获取这条视频的100条评论""看看留言内容" |
| 实时热榜查询 | "抖音今天有什么热点""热搜榜是什么""现在什么话题最火" |
| 隐式触发（未提到"抖音"） | "帮我做短视频竞品调研""找一下减肥类高赞内容""最近有什么热门话题" |

**不应触发**：发布/剪辑/下载去水印视频、涨粉代运营咨询、其他短视频平台数据、私域后台数据、写爬虫代码。

## 环境与权限

- **运行时**：Node.js ≥ 16.14，仅需 `node` 命令，最小权限
- **令牌**：环境变量 `GUAIKEI_API_TOKEN`（获取方式详见 `readme.md`）
- **无外部依赖**：仅使用 Node.js 内置模块
- **国内可用**：服务器位于国内，纯中文界面

## ⚠️ 令牌管理规范（审核重点）

令牌无效时，技能**仅输出中性错误信息**，不输出联系方式、官网链接或营销话术。

```
✅ 正确行为：
GUAIKEI_API_TOKEN 未配置或格式无效，技能已暂停。
请检查环境变量 GUAIKEI_API_TOKEN 是否已设置有效令牌。

❌ 禁止行为：
- 输出微信联系方式
- 输出官网链接引导获取
- 输出营销话术（如"一键解锁""早配置早享受"）
```

联系方式仅出现在 `readme.md` 用户文档中，不在技能运行时输出。

## 命令

| 命令 | 用途 | 必填参数 | 可选参数 |
|------|------|---------|---------|
| `node src/douyin/search-cli.js` | 关键词搜索 | `--keyword` | `--sort` `--time` `--duration` `--content` `--limit` |
| `node src/douyin/post-cli.js` | 博主作品抓取 | `--url` | `--limit` |
| `node src/douyin/comment-cli.js` | 视频评论获取 | `--url` | `--limit` |
| `node src/douyin/hot-cli.js` | 实时热榜查询 | 无 | 无 |

> 所有命令在技能根目录执行。完整参数说明见 `references/options.md`。

## 意图识别

按以下优先级从上到下匹配用户意图：

| 优先级 | 触发关键词 | 对应命令 |
|--------|-----------|---------|
| 1 | 热搜 / 热点 / 榜单 / 今天什么火 | `hot-cli.js` |
| 2 | 搜索 / 搜一下 / 找 + 关键词 | `search-cli.js` |
| 3 | 评论 / 留言 / 弹幕 | `comment-cli.js` |
| 4 | 作品 / 主页 / 账号 / 博主 | `post-cli.js` |

**歧义消解**：单独出现"视频"二字时，不默认归到 `post-cli`。
- 有"关键词"且无"评论" → `search`（用户想搜某个视频）
- 明确"这个视频的评论/留言" → `comment`
- 仅当"作品/主页/账号/博主"出现时才用 `post`

## 参数推断

| 用户说法 | 参数值 |
|---------|--------|
| 综合 / 默认 | `--sort 0` |
| 点赞最多 / 最火 / 爆款 | `--sort 1` |
| 最新 / 最近发布 | `--sort 2` |
| 全部 / 不限制 | `--time 0` |
| 一天 / 24小时 | `--time 1` |
| 一周 / 7天 | `--time 7` |
| 半年 | `--time 180` |
| 1分钟以下 | `--duration 1` |
| 1到5分钟 | `--duration 2` |
| 5分钟以上 | `--duration 3` |
| 视频 | `--content 1` |
| 图文 | `--content 2` |
| N条 / 前N条 | `--limit N` |

> 默认值：sort=0、time=0、duration=0、content=0、limit=10

## 输入输出规范

- **stdout**：纯 JSON 数据，便于程序直接解析消费
- **stderr**：日志与提示信息
- **退出码**：`0` = 成功（含空结果）、`1` = 运行错误、`3` = 令牌无效
- **数据上限**：单次最多 1 万条
- **日志归档**：自动保存到 `logs/` 目录，格式为 `时间戳_关键词_参数_类型.json`

## 错误处理

| 错误类型 | 处理方式 |
|---------|---------|
| 令牌无效（退出码 3） | 停止执行，输出中性错误提示，不重试 |
| API 次数超限 | 停止执行，向用户展示错误信息 |
| 网络超时 | 最多重试 3 次后停止 |
| 参数越界 | 立即报错，不自动调整参数 |
| 空结果 | 正常返回空数组，退出码 0 |

> 遇到错误时，立即向用户展示错误信息并询问是否调整参数。不要在收到 AUTH_ERROR 后继续重试。不要在用户未明确要求的情况下自动调整搜索条件。

## 示例

**1. 基础搜索**
```
用户：搜一下AI教程的抖音视频
命令：node src/douyin/search-cli.js --keyword "AI教程"
```

**2. 找爆款**
```
用户：找点赞最多的减肥视频，要20条
命令：node src/douyin/search-cli.js --keyword "减肥" --sort 1 --limit 20
```

**3. 时间+排序组合**
```
用户：近一周最火的短视频
命令：node src/douyin/search-cli.js --keyword "短视频" --time 7 --sort 1
```

**4. 博主作品抓取**
```
用户：看看这个博主的所有作品
命令：node src/douyin/post-cli.js --url "https://www.douyin.com/user/MS4wLjABxxx"
```

**5. 多步工作流：竞品分析**
```
用户：帮我分析一下这个竞品账号的内容策略
步骤1：node src/douyin/post-cli.js --url "https://www.douyin.com/user/MS4wLjABxxx" --limit 50
步骤2：取高赞视频URL，执行：
       node src/douyin/comment-cli.js --url "https://www.douyin.com/video/xxx" --limit 100
步骤3：汇总作品数据+评论数据，输出分析结论
```

**6. 热榜追踪**
```
用户：抖音今天有什么热点
命令：node src/douyin/hot-cli.js
```

## 限制

- 仅抓取抖音**公开数据**，不支持私密/隐藏内容
- 单次最多 1 万条
- 需配置有效令牌才能运行
- 数据仅限个人/团队内部使用，禁止违规分发
- 不支持发布、剪辑、下载去水印视频

## 安全与合规

- 仅使用 `node` 命令运行，最小权限
- 令牌通过环境变量传递，不落盘存储
- 令牌无效时仅输出中性错误，不输出联系方式或营销内容
- 抓取的是公开数据，合规使用
- 数据仅供内部使用，禁止违规分发
