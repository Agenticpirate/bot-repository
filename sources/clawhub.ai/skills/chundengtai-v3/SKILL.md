# chundengtai-v3

A股短线技术分析专家技能。触发：分析/诊断/选股A股代码/名称。核心能力：腾讯行情实时获取、V3百分位评分模型、三维定性框架、双卖出规则、仓位风控。

## 数据获取

### 腾讯实时行情（无需Token）

```bash
curl -s "https://qt.gtimg.cn/q=sh600143" | iconv -f GBK -t UTF-8
```

返回字段（`~`分隔，parts[]索引）：
- [1]名称 [3]现价 [4]开盘 [5]昨收 [7]最高 [8]最低
- [32]涨跌幅% [33]涨跌额 [34]成交量(手) [36]成交额
- [38]换手率% [39]PE [43]振幅% [44]流通市值(亿)
- [45]总市值(亿) [46]PB [47]量比
- [50]主力净流入(元)
- [62]5日动量 [63]10日动量 [65]20日动量 [66]60日动量

### 腾讯历史K线

```bash
curl -s "https://web.ifzq.gtimg.cn/appstock/app/fqkline/get?param=sh600143,day,,,60,qfq"
```

返回：`data['shXXXXXX']['qfqday']` 每行 [日期, 开, 收, 高, 低, 量]

## V3百分位评分模型

### 权重体系（满分85分 + 15分动态池）

| 因子 | 权重 | 计算 |
|:-----|-----:|:-----|
| range_pct（振幅百分位） | 20 | 今日振幅在近60日振幅中的百分位 |
| abs_ma5（距MA5偏离度） | 20 | abs(收盘/MA5 - 1) × 100，取百分位 |
| low_amp_cross（低振幅穿越） | 15 | MA5在布林中轨附近且价格站上MA5 |
| ma60_dist（距MA60距离） | 8 | (收盘/MA60 - 1) × 100，映射到百分位 |
| boll_pos（布林位置） | 8 | (收盘 - 下轨)/(上轨 - 下轨) × 100 |
| rsi_14（RSI） | 5 | RSI 40-65区间给分 |
| pct_chg（涨跌幅） | 3 | 当日涨跌幅百分位 |
| mom_20d/10d/5d | 2+2+2 | 各周期动量百分位 |

### 市场状态感知（三模式）

- V3_TREND（趋势）：MA5>MA10>MA20，且20日涨幅>5%
- V3_CHOP（震荡）：振幅<2%持续5日，或RSI在40-65波动
- V3_BEAR（下跌）：MA5<MA10<MA20，或20日跌幅>8%

权重动态调整：趋势模式动量因子权重↑，震荡模式布林位置↑，下跌模式现金偏好↑

### 动态池（15分）

每日从备选股中筛选前15%进入动态池。

## 三维定性框架

### 维度一：价格行为异常度（0-30分）
- 3日内涨幅>15%：+15分
- 5日内涨幅>20%：+10分
- 振幅>8%：+8分
- 量比>3：+5分
- 连续3日上涨：+5分
- 高点距今<10日：+3分

### 维度二：资金结构特征（0-30分）
- 主力净流入>0：+15分
- 主力净流入占比>10%：+10分
- 连续2日主力净流入：+8分
- 换手率>5%：+5分，换手率>10%：+8分

### 维度三：概念纯度（0-30分）
- 单一概念（<3只相关股）：+20分
- 主流概念（3-10只）：+15分
- 泛概念（>20只）：+5分
- 与龙头股联动>0.7：+10分

### 判断规则

| 概念股指数 | 判定 | 适用规则 |
|:-----------|:-----|:---------|
| >=40分 | 概念情绪驱动 | 隔日超短（场景A） |
| <40分 | 技术面驱动 | 主升浪（场景B） |

## 卖出规则

### 场景A：隔日超短（概念股）

适用：概念股指数>=40分

| 条件 | 操作 |
|:-----|:-----|
| 次日10:00前 | 必须卖出 |
| 盈利>+3% | 冲高即跑 |
| 盈利3%~5% | 清仓 |
| 盈利>+5% | 全清 |
| 亏损 | 割肉离场 |
| 收盘跌破10日线 | 次日开盘清仓 |

### 场景B：主升浪（技术股）

适用：概念股指数<40分

| 条件 | 操作 |
|:-----|:-----|
| 收盘不破5日线 | 继续持有 |
| 收盘跌破5日线 | 减仓50% |
| 收盘跌破10日线 | 全清 |
| 累计涨幅>50% | 全清 |
| 止损 | 收盘跌破买入价-3% |
