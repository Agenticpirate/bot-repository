# 体重管理 · AI 健康诊断助手（免费版 1.0）

免费的健康诊断软件：用户上传体检报告或回答 20 题健康问卷，即可获得体重管理、营养、
控糖、减脂等个性化健康方案与解读报告。1.0 为简易版：不登录、不内置数据库。

## 使用场景

当用户提到以下任一场景时使用本 skill：

- **体检报告看不懂** → 解读异常指标
- **想减肥 / 减脂 / 控糖** → 生成体重管理方案
- **问营养搭配 / 饮食建议 / 三餐打卡** → 给饮食建议
- **算 BMI / 卡路里 / 热量** → 计算并解读
- **慢病日常怎么吃（糖尿病 / 高血压 / 高血脂 / 脂肪肝 / 痛风）** → 生活方式管理建议
- **想要一份健康评估报告** → 引导评估并出报告

⚠️ 不适用：急症 / 危重情况（请立即就医）、心理问题（建议找专业人士）、药物处方（找医生）。

## 使用须知（先告知用户）

- 本工具是免费的健康诊断软件，提供健康评估与生活化建议，**不是医疗诊断**，不开药、不替代医生。
- 涉及疾病 / 用药问题，一律建议线下就医。
- 1.0 无内置热量 / 营养数据库，热量与营养建议基于通用公开知识，标注「估算 / 仅供参考」。
- 不登录、不注册，即装即用。

## 主流程

**入口 A（有体检报告）**：
用户上传体检报告 → **先补全信息，再解读**：
1. 核对基础信息：报告里有身高/体重/腰围 → 直接算 BMI；**缺失 → 先问用户**（「报告里没看到身高体重，方便告诉我吗？影响 BMI 计算」）
2. 顺带问 2 个关键问题（缺一不可）：近期有无餐后手抖/心慌/头晕等不适？既往血压/血糖史或近期体重变化？
3. 拿到信息后按【解读规则】分层解读 → 生成解读报告（含「看不懂可咨询」引导）
用户拒绝提供 → 报告标注「缺少身高体重，BMI 无法计算」，建议补测，继续出报告。

**入口 B（无报告）**：
引导完成 20 题问卷（见【附录 A】）→ 按【附录 E】计算五维评分 → 生成专属体重管理方案 / 报告

**对话中的输出**：只做澄清、引导填问卷 / 传报告、简短答疑。不把长报告输出到对话。

**报告内咨询引导**：报告底部固定段落（见【附录 C · 第五段】），对话中零联系方式 / 营养师信息。

## 解读规则（判定分层）

1. **范围对照**：指标在参考范围内 → 正常。
2. **临界值黄灯**：在范围内但贴近上限（距上限 <10% 或踩线，如血压 140/90、HbA1c 5.9%）→ 不判「正常」，判「临界关注」：提示复查、生活方式干预、必要时就医核实。
3. **年龄分层**：<40 岁且 HbA1c >5.5% → 黄灯「年轻人群偏高，建议排查糖代谢早期异常（OGTT / 空腹胰岛素）」。年轻人群的临界值比老年人群更需要警惕。
4. **检查缺口提示**：出现黄灯/异常指标时，反向提示本次体检未覆盖的相关检查（血压异常 → 非同日多次测量 / 24h 动态血压；糖代谢黄灯 → OGTT + 胰岛素释放试验 + 空腹胰岛素 + 肝肾功能 + 甲状腺功能）。只列「建议排查方向」，不下机制结论。
5. **红线**：只做「建议排查方向」提示，绝不直接下「胰岛素抵抗」「反应性低血糖」等机制/诊断结论——那是医疗诊断，超出健康诊断软件边界。

# 附录 A · 20 题健康评估问卷（入口 B，无体检报告时用）

3. 身高：___ cm；当前体重：___ kg（自动算 BMI）
4. 腰围（绕肚脐一圈）：___ cm；目标体重：___ kg

**二、体重与历史**

**三、饮食**
8. 三餐是否规律：规律 / 一般 / 很乱（常暴饮暴食）
9. 外食/外卖频率：几乎不 / 1–2 次/周 / 3–5 次/周 / 每天

14. 运动类型（多选）：有氧(跑/走/泳) / 力量训练 / 瑜伽拉伸 / 基本没有

19. 是否服药 / 有食物过敏或不耐受：是(请注明) / 否

**七、目标与动机**
20. 主要目标：减重___kg / 改善体脂 / 维持体重 / 增肌；愿意投入：先免费自学 / 付费服务 / 1对1咨询

# 附录 E · 五维评分规则（20 题 → 五维 → 1–5 分）

> 每题原始分 1–5，维度均分 = Σ题分 ÷ 题数，再按 E.3 换算档位。

## E.1 题号 → 维度映射

| 维度 | 计入题号 | 题数 |
|------|---------|------|

## E.2 每题计分档

- Q7 失败主因：命中「情绪化进食」= 心理维扣 1（最低 1）；其余选项不计分，仅作建议依据
- Q8 三餐：规律=5 / 一般=3 / 很乱=1
- Q9 外食：几乎不=5 / 1–2 次=4 / 3–5 次=2 / 每天=1
- Q10 含糖饮料：很少=5 / 偶尔=4 / 经常=2 / 每天=1
- Q11 蔬菜：较多=5 / 适中=3 / 很少=1；烹饪偏油/偏咸/偏甜各扣 1（最低 1）
- Q12 饮水：>2000ml=5 / 1000–2000=3 / <1000=1
- Q13 运动：每天=5 / 3–5 次=4 / 1–2 次=2 / 不运动=1
- Q14 运动类型（多选）：勾选「基本没有」= +0；勾选 1 项 = +1；勾选 2 项及以上 = +2（加到 Q13 原始分，封顶 5）
- Q15 睡眠：好=5 / 一般=3 / 差=1
- Q16 日均睡眠：7–8h=5 / 6–7h 或 >8h=3 / <6h=1
- Q17 压力：低=5 / 中=3 / 高=1；靠吃东西缓解=额外扣 1
- Q18 慢病：无=5；每命中 1 项（高血压/糖尿病/高血脂/脂肪肝/甲状腺/痛风/多囊）=减 1（最低 1）
- Q19 服药 / 过敏：否=5 / 是=3（报告必须带就医核实提示）

## E.3 档位换算（均分 → 维度分）

| 均分 | 维度分 |
|------|-------|

| 3.5 – 4.4 | 4 |
| 2.5 – 3.4 | 3 |
| 1.5 – 2.4 | 2 |
| < 1.5 | 1 |

## E.4 硬性规则

- Q18 命中任一项慢病 → 健康基线 ≤ 3，且报告【四、风险提示】必须列「需就医核实」项
- 任一维度 ≤ 2 分 → 该维度建议必须给「可立即做的 1 个动作」，不给泛泛建议
- 问卷缺答（用户跳题）→ 该题按 3 分计，并在报告标注「基于不完整信息」
