# 证券之星投资者互动 Skill

```bash
PYTHON=python3.12
IR=scripts/cli.py
```

通过自然语言查询上市公司投资者互动数据（董秘问答）和线索挖掘信号，数据来源证券之星。

## 适用场景

用户提到以下内容时触发本 Skill：

- **线索挖掘**："浦发银行有哪些投资信号"、"浦发银行的线索挖掘"、"平安银行最近有什么变化"
- **投资者互动**："看看浦发银行的董秘问答"、"投资者问了什么"、"董秘怎么回复的"
- **标签筛选**："浦发银行市值管理相关的问答"、"房地产风险的回复"、"有哪些标签可以筛选"
- **模糊搜索**："帮我查一下浦发银行"

## 核心约束

1. **数据真实性** — 禁止编造问答或信号数据，必须从真实 API/网页返回中提取
2. **覆盖范围** — 仅支持 A 股（6 位代码，自动补 sh/sz 前缀）
3. **查询限制** — 单次查询 1 只股票
4. **请求方式** — 使用 Python 脚本 `scripts/cli.py`（通过 `$PYTHON $IR` 调用），统一加 `--json` 参数
5. **输出格式** — 脚本输出 JSON，AI 负责组织语言呈现给用户，不直接输出 JSON 原文
6. **降级策略** — 线索挖掘返回空数据时（如茅台），自动降级提示用户使用 `qa` 命令查看原始问答

## 脚本命令

```bash
$PYTHON $IR signals <stock_code> --json        # 线索挖掘（主视图）
$PYTHON $IR qa <stock_code> --json              # 投资者互动原始问答
$PYTHON $IR qa <stock_code> --domain 公司治理 --tag 市值管理 --json  # 按领域+标签精确筛选
$PYTHON $IR qa <stock_code> --domain 公司治理 --json  # 仅按领域筛选
$PYTHON $IR qa <stock_code> --tag 市值管理 --json     # 仅按标签筛选（自动发现领域）
$PYTHON $IR tags <stock_code> --json            # 查看可用标签列表
$PYTHON $IR search <keyword> --json             # 模糊搜索股票
```

## 工作流

### 流程 0（前置）：模糊搜索股票

当用户输入中文名或模糊代码时，先调用 `search` 确认股票身份。

**步骤：**
1. 调用 `$PYTHON $IR search <keyword> --json`
2. 分析返回的候选列表：
   - 如果第一候选明显符合用户意图 → 直接取其代码，继续执行
   - 如果前几项都合理 → 把前 3 个候选简要列给用户确认
   - 如果无结果 → 告知用户未找到，建议更换关键词

### 流程 1：查询线索挖掘（默认推荐）

当用户问"XX有什么信号/线索/变化"时，优先使用 `signals`。

**步骤：**
1. 调用 `$PYTHON $IR signals <stock_code> --json`
2. 解析返回 JSON，检查 signals 列表是否为空
3. 若非空：按重要性排序展示（高→中→低），每个信号包含：
   - 线索名 + 类别 + 变化类别 + 边际变化总结
   - 时间线（最近变化点）
4. 若为空：提示用户该股票暂无结构化信号，建议用 `qa` 查看原始问答

**输出要点：**
```
📡 浦发银行 (600000) — 线索挖掘

【高重要性】
• 浦发转债转股进展（公司治理 / 阶段跃迁）
  最新：首次披露转股数据，股价已高于转股价
  时间：2025-05-29 → 2025-07-03

【中重要性】
• AI大模型与数智化转型（研发管线 / 策略态度转变）
  最新：DeepSeek千亿级大模型完成全栈国产化部署
  ...
```

### 流程 2：查看原始问答

当用户问"XX对YYY是怎么回复的"或需要查看具体问答详情时。

**步骤：**
1. 调用 `$PYTHON $IR qa <stock_code> --json`
2. 解析返回 JSON，提取问答列表
3. 按时间倒序展示（最新在前），每条包含：
   - 投资者提问内容
   - 董秘回复内容
   - 标签（领域分类）
   - 语义倾向（乐观/中性/谨慎）
   - 回复质量（内容详尽/模板套话/回避敏感问题）

### 流程 3：按标签或领域筛选问答

当用户明确指定标签或领域时。`--domain` 和 `--tag` 可独立使用，也可组合使用。

**三种筛选模式：**

| 模式 | 参数 | 示例 | 策略 |
|------|------|------|------|
| 精确筛选 | `--domain` + `--tag` | `--domain 公司治理 --tag 市值管理` | 服务端过滤，分页准确 |
| 按领域 | 仅 `--domain` | `--domain 公司治理` | 客户端过滤，分页基于全量数据 |
| 按标签 | 仅 `--tag` | `--tag 市值管理` | 自动发现所属领域后服务端过滤 |

**步骤：**
1. 根据用户意图选择参数组合，调用 `$PYTHON $IR qa <stock_code> [--domain 领域] [--tag 标签名] --json`
2. 展示筛选后的问答列表（输出含 `filter` 字段标注筛选条件）

**支持的领域（domain）：**
- `公司治理` — 公司治理（英文别名：`govern`）
- `风险提示` — 风险提示（英文别名：`risk`）
- `业务运营` — 业务运营（英文别名：`business`）
- `热点题材` — 热点题材（英文别名：`hot_topic`）
- `财务能力` — 财务能力（英文别名：`finance`）

### 流程 4：查看可用标签

当用户需要按标签筛选但不知道有哪些标签时，先用 `tags` 查看可用列表。

**步骤：**
1. 调用 `$PYTHON $IR tags <stock_code> --json`
2. 解析返回 JSON，按领域分组展示标签名称和问答条数
3. 用户选定标签后，用 `qa --domain <领域> --tag <标签名>` 筛选问答

**输出要点：**
```
🏷️ 600000 — 可用标签

【公司治理】
  • 市值管理 (3条)
  • 股东人数 (2条)

【风险提示】
  • 回避问询 (2条)

可用 qa --domain <领域> --tag <标签名> 筛选问答。
```

## 异常处理

| 异常 | 处理方式 |
|------|---------|
| 股票代码不存在 | 提示用户检查股票代码，建议用 search 搜索 |
| 网络超时 | 提示用户稍后重试 |
| 无搜索结果 | 提示用户更换关键词 |
| 线索为空 | 提示该股票暂无结构化信号，建议用 qa 查看原始问答 |
| 标签不存在 | 提示用户检查标签名称，建议用 tags 命令查看可用标签 |
