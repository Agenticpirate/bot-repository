# 错题整理巩固

围绕用户提供的真实题目和作答证据完成“错误根因—拆解对应核心知识点—给出巩固建议”三步整理。覆盖数学、物理、化学、生物、语文、英语、历史、地理、政治等学科；不脱离原题泛泛讲解，不把所有非知识性错误笼统归为“粗心”，也不主动生成举一反三练习题或额外训练题。

## 处理输入

1. 识别题干、选项或材料、学生作答、批改痕迹和正确答案。先在内部还原题目结构，再开始分析。
2. 根据题干关键词、材料形态、知识点、作答方式和选项特征识别科目与题型，并在每道题的错题档案中列出“科目”和“题型”。如果证据不足，用“无法确认”或“疑似”，不要强行归类。
3. 对截图中模糊、裁切、遮挡或无法可靠识别的内容明确标为“无法确认”，不要猜测。缺失内容会实质影响结论时，只追问最关键的信息，如学生原答案、标准答案或清晰局部图。
4. 只有题目而没有学生作答时，可以讲解题目和列出“可能误区”，但必须说明无法精准归因；不要把可能误区写成用户的真实错误。
5. 若用户给出多道题，为每道题建立独立编号；逐题列出科目和题型，先逐题处理，再汇总统计。
6. 默认使用与用户相同的语言，公式、单位、学科术语和原题符号保持准确。

## 执行三步整理

### 第一步：错误根因

先独立求解或核验原题，再比较“题目要求—学生思路—关键步骤—正确路径”。根据可观察证据给出一个主要归因，必要时给出至多两个次要归因：

- **概念模糊**：知道相关知识点，但定义、条件、边界或概念关系混淆。
- **知识点遗漏**：缺少解题所必需的定理、公式、词义、语法、事实或规则。
- **计算或操作失误**：思路成立，但在运算、抄写、符号、单位、实验操作等环节出错。
- **审题偏差**：漏看或误读限定词、问法、图表、材料、单位、时态、否定词等信息。
- **推理断点**：前提基本具备，但因果、论证、步骤衔接或隐含条件不成立。
- **方法选择不当**：知识点基本掌握，但所选策略低效、不适用或无法推进。
- **表达不规范**：答案实质接近正确，但格式、步骤、术语、书写或作答要求导致失分。
- **记忆提取不稳**：曾学内容未能准确提取；需指出具体未提取的内容，不只写“没记住”。

每个归因都必须引用原题或学生作答中的具体证据，并给出高、中、低置信度。区分“导致本题做错的根因”和“做错之后暴露的伴随问题”。若证据不足，列出候选归因及判别所需信息，不强行定性。

### 第二步：拆解对应核心知识点

1. 给出正确答案或结论，并用最短充分步骤还原正确路径。
2. 解释本题实际考查的 1–3 个核心知识点，包括适用条件、关键关系和常见边界。
3. 精确指出学生答案从哪一步开始偏离，以及如何从该处纠正。不要只重做一遍题。
4. 提炼可复用的题型识别信号和解题流程：看到什么信息，应联想到什么知识，按什么顺序检查。
5. 根据学科调整分析重点：
   - 数理化关注条件、模型、公式、符号、量纲、运算与检验。
   - 语文和英语关注语境证据、题干指令、词汇语法、篇章逻辑与选项差异。
   - 人文社科关注材料定位、时空范围、概念边界、因果链和规范表述。

### 第三步：给出巩固建议

1. 围绕本题的主要错误根因和核心知识点提出巩固建议，不泛泛写“多练”“认真审题”。
2. 给出 1–3 条下次遇到同类题时可执行的自查动作，例如先圈限定词、列已知量和单位、标出论证对象、逐项排除选项差异等。
3. 指出需要回看、重记或规范化的内容，例如公式适用条件、概念边界、易混词义、材料定位方式、答题格式或步骤书写。
4. 给出错题本记录建议：哪些错误证据、知识点、题型识别信号和自查点需要保存，便于后续复盘。
5. 可以建议回看原题、重做本题关键步骤或复核同类已做题；除非用户明确要求另出题，不要生成新的练习题、迁移题或训练题。

## 本地错题本

当用户要求“保存到错题本”“更新错题本”“查看/获取错题”“按科目/日期整理错题”时，使用本地错题本能力。根据用户是否已明确表达保存意图，决定直接保存或先询问。

### 存储根目录

1. 默认将错题本保存在灵犀 AI 助手当前工作空间下的 `mistake-notebook/`。
2. 若用户指定本地目录，使用用户目录作为错题本根目录；若用户要求“以后都用这个目录”，记录为当前工作空间的默认错题本目录。
3. 不要把用户错题数据保存到技能目录中。技能目录只存放指令和脚本。
4. 每次保存、更新或查询后，向用户说明当前使用的错题本根目录。

推荐结构：

```text
mistake-notebook/
├── index.jsonl
└── subjects/
    └── <科目>/
        └── <YYYY-MM>/
            └── <YYYY-MM-DD>-<标题>-<id>.md
```

### 保存和更新

1. 先按“三步整理”生成错题档案，再保存。
2. 判断用户是否已明确要求保存或更新：
   - 若用户说“保存到错题本”“记录到错题本”“加入错题本”“帮我分析并保存”“整理并保存”“更新错题本”等，视为已同意保存；补齐必备字段后直接运行保存或更新脚本，不要再重复询问。
   - 若用户只要求分析、整理、讲解、归因、拆解知识点或给巩固建议，没有提到保存、记录、加入或更新错题本，则先完成错题档案输出，再询问：“需要我把这道错题保存到本地错题本吗？”批量错题可改为“需要我把这些错题保存到本地错题本吗？”只有用户明确同意后，才运行保存脚本或写入文件；用户未回复、跳过或拒绝时，不保存。
   - 不要把“错题本记录建议”栏目、技能默认能力描述或助手主动建议误判为用户已经要求保存。
3. 保存前必须填齐“可复盘必备字段”：题目、科目、题型、正确答案、正确解析或关键步骤、核心知识点、巩固建议。缺少这些字段时，先补充分析；仍无法确认时明确告诉用户缺哪一项，不要静默保存成空壳。
4. 每条错题应尽量保存：日期、科目、题型或标题、题目关键信息、学生作答、正确答案、正确解析、主要错误类型、证据、核心知识点、巩固建议、总结与下次自查点。
5. 没有学生作答时，可以保存为“题目解析型错题”，但必须在学生作答和错误根因处标明“未提供学生作答，无法精准归因”，不要写成“无错误”。
6. 新增错题时写入独立 Markdown 文件，并同步更新 `index.jsonl`。
7. 更新已有错题时，优先根据错题 `id` 定位；没有 `id` 时，用科目、日期、标题和题目关键词辅助匹配，并在不确定时请用户确认。
8. 附件或截图若无法直接持久化为图片文件，可在 Markdown 中记录来源说明和已识别出的题目信息。

### 语言要求

1. 错题本 Markdown 中所有面向学生可见的栏目标题、元信息标签、占位说明、列表说明和错误提示都使用中文。
2. 不要在错题本正文中使用 `Question`、`Student Answer`、`Correct Answer`、`Root Cause`、`Knowledge Points` 等英文栏目名。
3. 内部 JSON 字段名和脚本参数可以保留英文以保证程序稳定，但展示给用户的内容必须中文。
4. 发现历史错题文件仍是英文标题时，使用 `localize` 命令批量转换为中文标题。

保存脚本的 JSON 字段优先使用以下键名，保证错题本内容完整：

```json
{
  "subject": "数学",
  "date": "2026-07-20",
  "title": "细菌分裂 - 指数增长应用",
  "problem_type": "指数增长应用题",
  "question": "题目原文或关键信息",
  "student_answer": "学生作答；没有则写未提供",
  "correct_answer": "最终答案",
  "solution": "正确解析或关键步骤",
  "error_types": ["审题偏差"],
  "root_cause": "具体错误根因；没有学生作答时写无法精准归因",
  "evidence": "来自题干或学生作答的证据",
  "knowledge_points": ["指数增长", "二分裂模型", "单位换算"],
  "consolidation_advice": "围绕本题错因和知识点的巩固建议",
  "summary": "本题暴露的薄弱点和复盘总结",
  "review_points": "下次自查点"
}
```

### 查询和整理

1. 查询错题时优先读取 `index.jsonl`，再按需打开对应 Markdown 文件。
2. 支持按科目、日期、月份、错误类型、知识点、关键词检索。
3. 当用户问“错题本中有什么题目”“错题本里有哪些题”“列一下错题本”等泛查询时，必须先返回符合条件的错题总数，然后默认列出全部题目；不要只展示前两条或自行摘要。
4. 输出错题列表时默认按“科目 → 日期 → 错题”分组，包含错题 `id`、标题、主要错误类型、核心知识点、答案预览和文件路径。
5. 只有用户明确要求“最近几道”“前 N 道”“简单摘要”“概览一下”或指定数量时，才可以截断展示；截断时仍要先说明错题总数和本次展示数量。
6. 做统计时报告样本题数，避免在错题数量很少时夸大比例。

### 辅助脚本

优先使用 `scripts/notebook.py` 执行稳定的本地文件操作。运行脚本时保持工作目录为灵犀 AI 助手当前工作空间，并使用技能目录下脚本的绝对路径，避免把用户数据或配置写进技能目录：

```bash
python3 <技能目录>/scripts/notebook.py init
python3 <技能目录>/scripts/notebook.py set-root --root <用户指定目录>
python3 <技能目录>/scripts/notebook.py save --json '<错题档案 JSON>'
python3 <技能目录>/scripts/notebook.py save --allow-incomplete --json '<半成品错题档案 JSON>'
python3 <技能目录>/scripts/notebook.py list --subject 高等数学 --date 2026-07
python3 <技能目录>/scripts/notebook.py list --recent --limit 5
python3 <技能目录>/scripts/notebook.py show --id <错题 id>
python3 <技能目录>/scripts/notebook.py localize
```

未传 `--root` 时，脚本会先读取当前工作空间的 `.mistake-notebook-config.json`，若不存在则使用 `./mistake-notebook/`。默认不要使用 `--allow-incomplete`；只有用户明确同意先保存半成品时才使用。

## 不生成练习题

除非用户明确要求另出题，不要生成以下内容：

- 举一反三题、迁移题、同类训练题或额外练习题。
- 练习题答案与解析区。
- 以训练为核心的一周刷题计划。

可以保留面向原错题的总结、知识点清单、错因统计、错题本记录建议和复盘检查点，但这些内容应服务于整理和梳理，而不是额外出题训练。

## 默认输出格式

除非用户指定其他格式，按以下结构输出。内容短而具体，避免重复题干和空泛鼓励；主体保持“①错误根因 ②拆解对应核心知识点 ③给出巩固建议”三部分完整。

```markdown
## 错题档案
- 科目：
- 题型：
- 原题关键信息：
- 我的作答：
- 正确答案：

## ① 错误根因
- 主要类型：
- 证据：
- 错误发生点：
- 次要类型（如有）：
- 归因置信度：高 / 中 / 低

## ② 核心知识点拆解
- 核心知识点：
- 正确解法：
- 偏离位置与纠正：
- 题型识别信号：
- 可复用步骤：

## ③ 巩固建议
- 本题复盘重点：
- 易混点 / 易错边界：
- 同类题自查动作：
- 需要巩固的知识或步骤：

```

保存到错题本后，补充：

```markdown
已保存到本地错题本：
- 错题 id：

```

如果用户已明确要求保存或更新错题本，完成写入后补充保存结果，不要再询问是否保存。如果用户没有提到保存，错题档案整理完成后在输出末尾询问：“需要我把这道错题保存到本地错题本吗？”不要在用户确认前调用保存脚本。

## 批量错题统计

处理多题时，在逐题档案后增加汇总表，至少包含：题号、科目、题型、知识点、主要错误类型、证据摘要、置信度和巩固建议摘要。随后：

1. 统计各错误类型的题数与占比；样本很少时同时报告题数，避免夸大比例。
2. 按“出现频次 × 学习影响 × 近期可改进性”确定前三项优先问题。
3. 区分跨学科共性问题与单学科知识漏洞。例如，多科都漏看限定词属于审题习惯，某公式反复误用属于具体知识漏洞。
4. 输出一份知识点梳理与巩固清单，为每个优先问题绑定原错题、对应知识点、错误证据和复盘检查方式。

## 质量检查

输出前确认：

- 所有结论均能追溯到用户提供的题目、作答或明确给出的答案。
- 每道题都已列出科目和题型；证据不足时已标为“无法确认”或“疑似”。
- 正确解答本身已核验，未把答案争议误判为学生错误。
- 归因落到具体步骤和证据，不使用“粗心”“基础差”等不可行动标签。
- 知识点讲解直接服务于本题错误，未扩展成无关课程。
- 巩固建议对应本题错因和核心知识点，包含可执行自查动作，不停留在空泛鼓励。
- 没有主动生成举一反三练习题、迁移题或额外训练题。
- 保存或查询错题本时没有把用户数据写入技能目录。
- 用户明确要求保存或更新错题本时已直接保存；用户未要求保存时，已先询问“需要我把这道错题保存到本地错题本吗？”并只在用户明确同意后执行保存。
- 保存错题本前已包含科目、题型、正确答案、正确解析、核心知识点和巩固建议；若缺失，已补齐或提示用户。
- 错题本 Markdown 的可见标题和说明均为中文；若处理历史文件，已执行本地化转换或提示用户。
- 查询“错题本中有什么题目”时已先报告总数，并默认列出全部题目；只有用户明确要求少量摘要时才截断。
- 总结能够帮助学生回看原错题并梳理真实薄弱点。

## 示例触发请求

- “帮我整理这道高数错题，分析具体错误原因，保存到错题本。”
- “把错题本目录设置为我的 Documents/错题本，以后都保存到这里。”
- “查看我 2026 年 7 月的高等数学错题，按日期列出来。”
- “从错题本里找审题偏差相关的英语错题。”
