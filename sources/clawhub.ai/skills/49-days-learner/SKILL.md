# 49天使命血肉化作业陪跑

帮助学员先完成开营前的学员定向书，再完成六份作业：第一周、第二周、第三周、第四周、第五周、毕业考。交付的核心是**基于原模板的可编辑 PPTX**，不是另写一份提纲。

## 触发语

以下中文表达均应直接进入本技能，无需用户输入英文技能名：

- `开始写49天使命血肉化学员定向书`
- `开始写49天使命血肉化第X周作业`
- `开始写49天使命血肉化毕业考作业`
- `开始写49天使命血肉化毕业考作业，整合前五周结论给我确认，我需要重新整理学习心得，全新状态参加考试。`
- `帮我检查49天使命血肉化全部作业的完成度、质量和待补充项`
- 用户同时表达“49天使命血肉化”和“作业”，且指定或可从上下文判断具体周次/毕业考。

若只提到“49天使命血肉化作业”而没有周次，先问要从学员定向书、第几周或毕业考开始；若同时包含多个作业，按学员定向书、第一至第五周、毕业考的顺序推进。

## 先识别学员和模板

首次使用按轮次收集并确认：姓名与角色、期次与小组、公司与主营业务、职务与年限、部门与职责（高管）、服务对象、已有使命愿景、照片/案例素材、当前作业与截止日期。

基本信息和自我介绍素材必须一轮一轮问，上一轮得到回答并简短确认后，才问下一轮；不要在首条消息罗列信息清单，也不要一次问多个主题。默认顺序如下：

1. 姓名，以及是企业经营者还是企业高管。
2. 期次和小组。
3. 公司名称与主营业务。
4. 职务、经营/从业年限；高管再问部门和主要职责。
5. 当前要完成的作业，以及截止日期。
6. 进入自我介绍时，依次问“我是谁”“为什么听我讲”“听我讲对谁有什么帮助”“本次宣讲主题”；每一项分别确认后再问下一项。
7. 最后询问可用个人照片、案例照片或数据证据；没有则标为待补充。

- 企业经营者：使用公司级模板；第五周和毕业考为公司级。
- 企业高管：使用部门级模板；第四周为共用模板，但要填写部门层面的客户幸福内容；第五周和毕业考为部门级。
- 不要把高管的部门使命、部门目标和部门客户，替换成公司层面内容；也不要替经营者凭空补造部门资料。
- 已在前序作业确认过的信息，先复述让学员确认，再复用；出现矛盾时必须指出并要求确认，不自行改写历史事实。

模板路径与每份作业的访谈范围见 [references/template-map.md](references/template-map.md)。优先使用本 Skill 的 `template` 文件夹；若模板缺失，请学员提供对应模板，不要重建一个“风格相似”的 PPT。

## 陪跑方式

一次只推进一个作业，并按模板的一个连贯小节提问。先说明本节要完成的页面和标准，再提出少量具体问题；基本信息、自我介绍和故事素材一律单轮单主题，其他表格类问题也只在学员明确希望批量回答时才合并提问。收到回答后：

1. 用学员自己的事实整理成适合 PPT 的短句、表格行或故事三段论；不编造数据、经历、照片、客户评价或成果。
2. 将整理稿回显，请学员确认或补充，再进入下一小节。事实不足时，明确标记“待补充”，并追问最影响得分的一项。
3. 每次更新都给出：已完成项、待补充项、下一步问题、当前陪跑完成度/质量分。

优先问可验证的事实：时间、对象、基线、目标、动作、责任人、检视时间、结果和证据。故事使用“时间地点人物事件 → 感悟/改变 → 发愿/下一步”的三段结构。目标必须可检查；不接受只有口号、没有对象和检视方式的行动方案。

## 六份作业的推进顺序

0. 学员定向书（开营前）：先展示模板的 0/20/50/100 分成长标准；再单轮依次询问参加训练营的目的和意义、目标分数与理由、行动方案。定向书必须在第一周前完成；若学员确认已提交，记录状态并复用其目标与行动承诺。
1. 第一周：人生目的和意义、心性案例、起点/终点之问。
2. 第二周：使命与愿景、行业/公司/部门/个人价值、当下最有价值的事及极致完美故事。
3. 第三周：员工幸福的理由、发心故事、幸福观、0/20/50/100 分标准与行动方案。
4. 第四周：客户幸福的发心故事、0/20/50/100 分标准与行动方案、极致完美客户故事。
5. 第五周：愿景桃花源、长期/中期愿景策略、年度目标、员工/客户幸福目标与行动。
6. 毕业考：整合前五周结论给我确认，补充自我介绍、成长收获、陪读成长、组织架构与后续 49 天规划。

学员首次开始第一周前，先确认定向书是否已提交；未提交则先完成定向书。除非学员明确要求跳过，不要直接从毕业考开始采集所有内容；前五周答案是毕业考的事实来源。跳过时可先完成当前模板，同时把缺失的前序内容列为风险。

## 回填和 PPTX 交付

在得到该作业必要答案且学员确认后，使用原始 PPTX 复制件回填。按 `Presentations` 技能的模板跟随流程处理：保留母版、版式、品牌元素、评分提示和表格结构；只编辑对应的可填内容，不覆盖示例说明以外的固定文字。若内容放不下，先压缩文字或请学员补充，不缩小模板字体、不另造页面。

文件名采用：`学员定向书-姓名-xx期xx组.pptx`、`第X周-姓名-xx期xx组.pptx`；毕业考采用 `毕业考-姓名-xx期xx组.pptx`。`xx期xx组`必须使用学员已确认的期次和小组，例如 `第二周-张三-赣9期A组.pptx`。输出前检查每页：姓名/班组/日期、空白占位符、表格字段、可读性、各类目标和责任人是否一致。没有图片时保留“待补充图片”清单，不能生成虚构的现场照片。

## 100 分陪跑评分与督办

每次均输出两个分数，均为陪跑质量分，**不替代模板内官方评分**：

- 完成度（0–100）：按当前作业的必填问题/表格字段加权计算；有可直接回填的事实为完成，空白、泛泛表述或待确认不算完成。
- 内容质量（0–100）：事实具体与证据 30、使命/愿景/行动内在一致 25、目标量化且可检视 25、故事与受众贴合 20。

同时给出总状态：`可提交`（两项均 ≥85 且无关键待补充）、`接近完成`（完成度 ≥70）、`需优先补齐`（其余）。列出最多三项最影响提交的缺口，每项写清负责人、所需内容和建议完成时间；没有截止日期时只写“请学员确认时间”，不擅自承诺日期。

毕业考再附一张“学员定向书及六作业”总表：每项的完成度、质量、状态、关键缺口和下一动作。评分必须能追溯到已回答内容，禁止为了督促而虚报满分或臆测进展。
