# 计量检测合规护栏 (Metrology Compliance Guard)

## 触发条件

当用户需要审核、发布、或生成以下内容时激活本技能：
- 检定证书 / 校准证书
- 检测报告 / 测试报告
- 计量授权申请书
- 计量标准考核文件
- 计量器具管理台账
- 实验室资质文件
- 对外宣传材料中涉及计量能力的描述

## 核心检查规则

### 一、证书/报告格式合规（依据JJF 1069-2012）

必须包含以下要素，缺少任一项即判定不合规：

| 序号 | 必需要素 | 说明 |
|------|----------|------|
| 1 | 证书/报告编号 | 唯一性编号，格式规范 |
| 2 | 委托单位信息 | 名称、地址 |
| 3 | 被检/校器具信息 | 名称、型号、编号、制造厂 |
| 4 | 检定/校准依据 | 引用的检定规程(JJG)或校准规范(JJF)编号及名称 |
| 5 | 环境条件 | 温度、湿度等 |
| 6 | 使用的计量标准器具 | 名称、编号、有效期 |
| 7 | 检定/校准结果 | 数据、结论 |
| 8 | 检定/校准日期 | 必须为实际执行日期 |
| 9 | 有效期（检定证书） | 检定证书必须注明有效期 |
| 10 | 检定员/校准员签名 | 须持有相应资质 |
| 11 | 核验员签名 | 不得与检定员为同一人 |
| 12 | 机构公章/检定专用章 | 必须加盖 |
| 13 | 机构名称及授权证书编号 | 法定计量检定机构必须标注 |

### 二、人员资质合规

- 检定员必须持有对应项目的《注册计量师》证书或《计量检定员证》
- 一级注册计量师：可开展所有等级计量标准器具的检定
- 二级注册计量师：可开展除最高计量标准器具以外的检定
- 核验人员资质不得低于检定人员
- **拦截规则**：证书中出现无资质人员签名 → 标记为【严重不合规】

### 三、计量标准器具合规

- 使用的计量标准必须在有效检定/校准期内
- 计量标准必须有有效的《计量标准考核证书》
- 量值溯源链必须完整（可追溯至国家基准）
- **拦截规则**：标准器具超期使用 → 标记为【严重不合规】

### 四、授权范围合规

- 检定项目必须在《计量授权》证书批准范围内
- 不得超范围开展检定/校准
- 授权区域限制（省级/市级/县级）
- **拦截规则**：超授权范围出具证书 → 标记为【严重不合规】

### 五、用语规范

| 不合规用语 | 合规替代 | 依据 |
|-----------|----------|------|
| "检测合格" | "检定合格" | 计量法第9条 |
| "精度" | "准确度等级"或"最大允许误差" | JJF 1001 |
| "误差为0" | 给出具体测量不确定度 | JJF 1059 |
| "永久有效" | 注明具体有效期 | 计量法实施细则 |
| "国家级" | 需有实际授权依据 | 广告法+计量法 |

### 六、宣传材料合规

- 不得使用"最准确""第一""唯一"等绝对化用语
- 不得虚假宣传资质范围
- 不得暗示或明示具有未获得的授权
- 引用资质必须真实、在有效期内
- **拦截规则**：绝对化用语/虚假资质 → 标记为【不合规】

## 输出格式

```
【计量合规审查报告】

文件类型：xxx
审查时间：xxx

✅ 合规项：x 项
⚠️ 警告项：x 项（建议修改但不强制）
❌ 不合规项：x 项（必须修改后方可发布）

--- 不合规详情 ---
[序号] 问题描述
  → 违反条款：xxx
  → 修改建议：xxx

--- 警告详情 ---
[序号] 问题描述
  → 建议：xxx

【结论】：通过 / 不通过（需修改后复审）
```

## 使用方式

用户提交待审核文本后，逐项对照上述规则进行检查，输出结构化审查报告。

对于严重不合规项（❌），必须明确拦截，建议不得发布。
对于警告项（⚠️），给出修改建议但不强制拦截。
