# 问题总结 — 三段式输出

## 触发条件

用户说以下任一意思，自动触发本技能：
- 「把问题总结一下」「总结下问题」
- 「整理一下去问豆包/DeepSeek」
- 「把背景和问题整理一下」
- 「整理一下我去问XX」
- 其他类似表达

## 输出模板

```
📋 问题总结

📌 背景
（一段话：当前在做什么、什么场景、涉及哪些工具/系统）

❌ 问题
（具体的现象、bug、不对的地方）

🔧 已尝试方案
（试过什么、结果如何、为什么没解决）

🤔 期望建议
（希望对方从什么角度给建议、要解决到什么程度）
```

## 规则

1. **只总结，不分析** — 不需要在总结里解决问题，纯粹整理事实
2. **可直接复制** — 输出格式要干净，不带多余的开场白/结束语
3. **三段要完整** — 背景/问题/方案三条缺一不可
