# HR谈心罗盘 (hr-talk-compass)

基于斯坦福《人生设计课》（Bill Burnett & Dave Evans）的设计思维方法论 + 教练式对话技术 + HRBP/OD 实践，帮助 HR 系统化地做好员工谈心与组织发展工作。

## 方法论来源

本 skill 的对话方法论直接源自 **卡兹克**（公众号「数字生命卡兹克」）《我把斯坦福最火的一门课，做成了Prompt来帮我设计人生》一文中公开的「人生设计师」Prompt（[原文链接](https://mp.weixin.qq.com/s/VDlBdkspV0SQNFJYLxOogQ)），其底层为斯坦福《人生设计课》（Bill Burnett & Dave Evans，含心流理论与积极心理学）。

本 skill 在该 Prompt 基础上做了 **HR 谈心 / OD 场景化改造**：版本分化（quick/deep/manager/review/follow-up）、模拟陪练、数据脱敏与升级边界、复盘结构化输出等。方法论骨架（仪表盘、重力问题、指南针、能量地图、锚问题、奥德赛计划、原型行动、失败免疫）保持与原文一致。

## 什么时候用这个 Skill

- 准备一场员工一对一谈心（保留、激励、辅导、职业困惑、流失预警）
- 想和 AI 模拟演练一场难谈的对话
- 谈完想复盘：员工真实状态如何？流失风险？组织层面有什么信号？
- 需要给业务主管一套他们自己能用的简化对话工具
- 定期把谈心沉淀为 OD 洞察（人才盘点、敬业度、组织诊断）

## 目录结构

```
hr-talk-compass/
├── SKILL.md                  ← 本文件（路由 + 总原则）
├── WORKFLOW.md               ← 完整工作流（必读，先读这个）
└── prompts/
    ├── quick-brief.md           ← 速用版：10分钟出谈心提纲（4-6核心问题）
    ├── deep-dialogue.md            ← 深度版：关键人才/高风险对话全流程（6-9个核心问题）
    ├── manager-toolkit.md         ← 主管版：给业务经理的简化对话工具
    ├── review-insights.md          ← 复盘版：谈后分析 + OD信号沉淀
    └── follow-up.md             ← 跟进版：两周后回访 + 风险重评（新增）
```

## 四个版本怎么选

| 场景 | 用哪个 | 输出 |
|------|--------|------|
| 明天就要谈，没时间准备 | quick-brief | 一页纸提纲（4-6核心问题+追问方向+边界提醒） |
| 关键人才、高流失风险、重要保留对话 | deep-dialogue | 全案：目标判断+提纲(6-9问)+模拟陪练+预案 |
| 给业务主管/一线经理赋能 | manager-toolkit | 他们能独立用的轻量对话框架 |
| 谈完了，要复盘和沉淀 | review-insights | 谈心分析报告 + OD信号 + 行动建议 |
| 两周后回访/跟进闭环 | follow-up | 跟进脚本 + 风险重评 + 决定去留走向 |

## 总原则（所有版本共享）

- **唤醒而非说服**：答案本来就在员工脑子里，提问只是把它唤醒（源自卡兹克原文的苏格拉底精神）。HR 的角色不是"让他留下"，而是"帮他看清自己"——看清了，留任是自然结果；看不清，留任也只是暂时的
- **员工视角**：所有对话设计从"员工此刻的人生阶段命题"出发，不从 HR 的 KPI 出发。帮员工看清人生规划的谈话，本身就是最好的留人动作——交差和留人可以是同一个动作的两面
- **事实 vs 推测**：HR 最容易犯的错误是把推测当事实（"他不加班 = 他不想留"）。所有版本都要帮 HR 做这个区分
- **教练点评**：允许（且应该）在提问过程中随时插话点评，指出 HR 的盲区和目标冲突——不客气，但温暖

## 核心方法论（所有版本共享的骨架）

1. **仪表盘**：健康/工作/娱乐/爱 四维 0-10 打分，先看人在哪（口径同卡兹克原文：健康含身体/情绪/心理三层，娱乐指纯粹为了快乐而做的事，爱是双向的）
2. **重力问题 vs 真问题**：分清"无法改变的现实"与"可动手设计的问题"，这是 HR 判断"这事公司能不能帮上忙"的关键动作
3. **指南针**：员工的工作观 + 人生观，与公司能提供的机会是否同向
4. **能量地图**：什么事在滋养他、什么事在消耗他，擅长 ≠ 热爱
5. **奥德赛计划**：三个都成立的五年版本（现路径延伸 / 现路径消失后的 Plan B / 不考虑钱和他人眼光的版本），帮员工打开可能性
6. **原型行动**：不做大决定，先做两周内可启动的低成本尝试

## HR 职业伦理红线（所有版本必须遵守）

1. 不窥探员工隐私，不用心理技巧操纵员工
2. 发现严重心理危机信号（抑郁、自伤倾向等）→ 转介专业资源（EAP/心理咨询），HR 不自己处理
3. AI 不替公司做承诺（晋升、调薪、转岗），也不教 HR 做超出授权的承诺
4. 所有建议符合中国劳动法常识，不教规避法律责任的操作
5. 谈心的目的不是"把员工劝回去"，而是帮双方看清最优解是否重合——不重合时，体面分开也是好的 OD 结果

## 数据脱敏与升级边界（所有版本必须执行，新增）

**数据卫生（谈前就要做）：**
- 一律用**员工代号**（P01/P02 或拼音缩写），不录入身份证号、手机号、邮箱、家庭住址、病历、体检报告、聊天记录截图、薪资明细等个人敏感信息
- 只给 AI 为完成这次分析**必要的去标识化信息**（岗位、司龄、绩效大致档位即可），不要整段粘贴原始记录
- 复盘报告归档时建议去标识化，代号映射表单独存放、与归档分开

**环境与场合：**
- 不要在**群聊 / 共享文档 / 多人可见频道**中用真实员工信息调用本 skill；研发、绩效、薪酬、健康类敏感内容只在私密一对一场景处理
- 产出物在发给任何非本人之前，人工再查一遍脱敏

**升级边界（遇到以下情况，停止 AI 分析，转人工流程）：**
| 场景 | 动作 | 话术示例 |
|------|------|---------|
| 心理危机（自伤/抑郁/重度焦虑） | 立即停止，转 EAP/心理热线，HR 不独自处理 | "这事我陪你，但我不是专业人员，我帮你对接更能帮到你的资源。" |
| 骚扰 / 歧视 / 霸凌投诉 | 转合规/法务/内部调查，不删证、不外传 | "谢谢你告诉我，这个情况有更合适的处理渠道，我会帮你转到对应的人。" |
| 劳动纠纷 / 裁员 / 竞业 / 工伤 / 严重违纪解除 | 转法务，不自行给出赔付或解除判断 | "涉及劳动权益，我不能拍板，我帮你约专门的同事给你准确口径。" |
| 超出本人授权范围的承诺 | 明确边界，不替公司答应 | "这个我没权限当场答应，我去了解清楚再回复你。" |
| 重大疾病 / 伤残 / 孕产假相关争议 | 转 HR 专岗 / 工会 / 法务，不点评健康或家庭决策 | "这件事涉及专业政策，我帮你对接对口同事，把你能拿到的都给你说清。" |

> 原则：AI 只辅助 HR 看清问题，**不替代法律咨询、不替代心理咨询、不替公司做承诺**。

## 使用流程

1. 先读 `WORKFLOW.md` 了解完整工作流
2. 按场景选一个 `prompts/*.md`，把内容整体发给 AI
3. 谈后把记录用 review-insights 复盘，产出归档（建议按员工+日期存档）
4. 每季度汇总多场 review-insights 复盘，让 AI 做横向 OD 分析

## 存档规范建议

```
HR谈心档案/
├── {员工代号}_{日期}_提纲.md        （quick-brief/deep-dialogue 产出）
├── {员工代号}_{日期}_复盘.md        （review-insights 产出）
└── _OD季度汇总_{YYYY}Q{n}.md        （横向分析）
```
