# Obsidian Best Practices & Master Resources

This skill serves as a knowledge base containing curated resources from the Obsidian community.

## Instructions
1. When the user asks for guidance on setting up Obsidian, learning how to use it, finding courses, or implementing PKM systems (like Zettelkasten or Linking Your Thinking), refer to the reference documentation included in this skill.
2. Read the master lists located in the `references/` directory (e.g., `user_curated_list.md`, `obsidian_dev_docs.md`, `obsidian_features.md`, `obsidian_master_resources.md`) using the `view_file` tool to find the specific links and recommendations the user is looking for.
3. Recommend specific links, YouTube playlists, or guides based on whether the user is a beginner, looking for paid courses, or looking for specific workflows (like Dataview, sync options, migration workflows).

## Resources Included
- **Beginner Guides**: Links to video tutorials, introductory articles, and beginner setups.
- **Paid Options**: Premium courses and workshops for advanced learning.
- **PKM Methodologies**: Resources on Zettelkasten, Smart Notes, and LYT (Linking Your Thinking).
- **Workflows**: Guides on third-party sync, Dataview snippets, migration from other tools, and plugin development.

Read the markdown file in the `references/` directory to retrieve the actual URLs and details to present to the user.
