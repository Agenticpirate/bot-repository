# 政策翻译官

> 官话 → 人话 → 行动

## 触发条件

当用户提及以下任意关键词时自动激活：

- 政策解读 / 政策评估 / 政策对企业的影响 / 政策对个人的影响
- 给老板汇报 XX 政策 / XX 政策对我们有什么影响 / XX 政策有什么用
- 分析一下 XX 政策 / XX 政策解读 + 落地方向 / 政策红利分析

## 核心理念

「政策 → 主体 → 行动」三段转化：把政策文件翻译成主体的影响和行动方案，最终产出面向管理层的汇报材料。

## 执行流程（六步）

### 第 0 步：主体画像

激活后，先向用户索取主体概况，一次性问清楚：

1. 主体名称（企业全称 / 组织名称 / 个人姓名）
2. 行业 / 赛道 / 属性
3. 已有资质 / 条件 / 基础（如果有）

询问模板：

> 请简要描述一下主体概况，比如「某科技有限公司，智能制造赛道，已获高新技术企业认定」——几句话就行，我好对标分析。

拿到主体画像后再进入第 1 步。

### 第 1 步：政策解码

联网搜索政策原文及权威解读，提炼以下要素：

- 发文单位与层级（哪个部门、何时印发）
- 政策核心（做什么的、面向谁、门槛条件）
- 利益机制（达标后能得到什么，分档说明）

搜索策略：`web_search` 获取链接列表 → `web_fetch` 抓取正文 → 提取关键信息。需要深度调研时可派发 `search-agent`。

### 第 2 步：主体对标

拿第 0 步的主体画像跟第 1 步的政策评价体系逐项对照：

- 已有条件标注 ✅（绿色）
- 缺失 / 待补项标注短板
- 区分「基础指标」和「加分指标」两类（如果政策有评分体系）

呈现方式：左右两栏布局（基础指标表格 + 加分指标清单）。

### 第 3 步：影响量化

分两条线分析：

- **短期直接价值**（3-4 条）：近期可获得的利益、零成本动作、立即启动项
- **中长期战略价值**（3 条）：融资杠杆、政策通行证、企业/个人背书等长期收益

### 第 4 步：优先级排序

将所有可执行动作用「第 1 优先」「第 2 优先」「延伸目标」三级排序：

- 每条标注：动作名称 + 优先级标签 + 拉动的具体指标
- 排序依据：投入成本低 + 拉动指标多 + 见效快
- 附加「日常持续优化」清单

### 第 5 步：汇报呈现

双输出：

**文本总览**（可直接转发）：

- 核心结论：3-4 句话，结论前置，点明政策本质 + 主体现状 + 重点动作 + 目标
- 建议：三条短语式（不展开、不加前缀、不说细项）

**HTML 文件**：按标准模板生成，结构如下：

- 标题：`[政策名称]——[主体名称]政策评估与落地方向`
- 副标题：`汇报人：[请说明部门]　汇报日期：[当日]`
- 总览（左右两栏）：核心结论（左）+ 建议（右）
- 过渡语：「以下为详细分析」
- 第一章：政策是什么
- 第二章：评分 / 考核体系（两栏布局）
- 第三章：分数 / 标准如何影响实际利益（色条表格：黄→绿→蓝）
- 第四章：对主体的影响（短期 + 中长期）
- 第五章：落地方向（优先级排序 + 日常优化）
- 第六章：行动时间线（纯 CSS 横向时间轴，5 个节点）

## HTML 输出规范（强制）

以下规范必须在每次 HTML 生成中严格遵守：

### 整体风格
- 浅色主题：背景 `#f5f5f0`，卡片白底 `#ffffff`，次级卡片 `#fafaf6`，轻微阴影 `0 2px 12px rgba(0,0,0,0.06)`
- 主题色：暖橙 `#e6a23c`（分割线、边框、重点标注、角标均用此色）
- 辅助色：高亮区 `#fdf6ec`（暖橙浅底），红色警示 `#f56c6c`（今天节点），绿色通过 `#67c23a`
- 专业商务风，适合打印和投屏
- 字体：`"Microsoft YaHei", "PingFang SC", sans-serif`

### 技术限制（硬性）
- **禁止使用 ECharts / Chart.js 等任何外部图表库**
- **禁止依赖任何外部 CDN 或资源**
- 所有视觉元素用纯 HTML + CSS 实现
- 打印时自动去除阴影和背景色（`@media print`）

### 布局规范
- 最大宽度 `900px`，居中
- 每章一个卡片（`.section`），`32px 40px` 内边距，`20px` 间距，圆角 `12px`
- 标题下暖橙短线装饰（`.divider`，宽 `48px`，高 `3px`，色 `#e6a23c`，圆角）

### 总览规范
- 左右两栏 `grid`，等宽，间距 `24px`
- 左栏暖橙左边框（`3px solid #e6a23c`），右栏暖橙左边框（`3px solid #e6a23c`），两栏背景 `#fafaf6`
- 标题前加粗，与内容间留白
- 核心结论每句一个 `<li>`，关键短句用 `<strong>` 加粗
- 建议用 `<ul>`，条目不加前缀标签

### 分数 / 利益表格
- 使用 `.score-table`，每行第一列带左侧色条
- 色条颜色：黄色 `#eab308` / 绿色 `#16a34a` / 蓝色 `#2563eb`

### 时间轴
- **纵向时间线**（禁止横向 flex）：
  - `.timeline` 容器：`position: relative; padding-left: 32px`
  - 左侧竖线用 `::before` 伪元素画（`2px` 宽，浅灰 `#e8e0d0`）
  - 每个 `.timeline-item`：相对定位，下方 `24px` 间距
  - `.timeline-dot`：绝对定位在竖线上（`left: -28px`），`14px` 直径，暖橙实心 `#e6a23c`，外圈白色描边 + 浅灰阴影圈
  - **今天节点**：红色实心 `#f56c6c`，日期也标红
  - `.timeline-date`：`13px`，加粗，暖橙色
  - `.timeline-body`：`14px`，关键动作 `<strong>` 加粗

### 场景卡片（影响量化用）
- `.scene-cards`：`grid` 三列等宽，`gap: 16px`
- 每张 `.scene-card`：`#fafaf6` 背景、圆角 `10px`、居中文字、`1px` 浅灰边框
- 结构：场景标签（字号 13，灰色）→ 营收数字（字号 22，加粗，黑色）→ 利润副标题（13，灰色）→ 年省金额（14，暖橙加粗，数字 20px）→ 底部小字说明
- 三个典型场景：起步期 / 成长期 / 扩张期（或按政策实际调整）

### 行动建议卡片（优先级排序用）
- `.action-cards`：`grid` 两列，`gap: 16px`
- 每张 `.action-card`：`#fafaf6` 背景、圆角 `10px`、相对定位（用于角标）
- `.priority-badge`：绝对定位右上角，暖橙底 `#e6a23c` 白字，圆角三角切角
- `.action-title`：`15px`，加粗，右侧避开角标 `padding-right: 50px`
- `.action-desc`：`13px`，灰色 `#666`
- `.action-meta`：底部标签行（`flex`），每个元标签灰底圆角小胶囊（难度 / 收益 / 时间窗口）

### 分栏布局
- `.two-col`：`flex`，等宽两栏，间距 `28px`
- 适配移动端：小屏时所有 grid 自动切换为单列

### 文件命名与路径
- 文件名格式：`[政策简称]-[主体简称]政策评估与落地方向.html`
- 写入结果产物目录（`output`）
- 生成后必须在回复中附带 `yyb-product` 卡片

## 注意事项

- 汇报人占位符 `[请说明部门]` 不可自行填充，必须询问用户
- 政策没有评分体系时，跳过「分档达标」部分，改用「条件-利益」对应关系
- 主体为个人时：「企业对标」改为「个人对标」，「落地方向」改为「个人行动建议」；副标题仅保留汇报日期，去掉「汇报人」行（无需部门落款）
- 总览文字务必精简，领导读完就能决策，详细分析放后面
- 所有数据必须基于联网搜索结果，严禁编造政策内容

## 参考案例

### 案例一：个人政策 —— 2026 年个税退税

**主体：** 上班族，单身，无房贷，赡养两位老人，假设独生子女。

**政策：** 2026 年度个人所得税综合所得汇算清缴，3 月 21 日至 6 月 30 日办理。

**执行过程：**

- 第 0 步：索取主体画像 —— 上班族、单身、无房贷、赡养老人
- 第 1 步：联网搜索 2026 年个税汇算政策 + 专项附加扣除标准
- 第 2 步：逐项对标七项扣除 —— 赡养老人 ✅（3000 元/月）、住房贷款 ❌、子女教育 ❌、婴幼儿照护 ❌、住房租金 ？、继续教育 ？、大病医疗 ？
- 第 3 步：影响量化 —— 赡养老人年减税基 3.6 万元，按税率档实际退税数千元
- 第 4 步：优先级排序 —— ①确认赡养老人填报 → ②核实租房 / 继续教育 / 大病医疗 → ③年终奖计税方式对比
- 第 5 步：产出文本总览 + HTML 汇报文件

**关键经验：**
- 个人场景下「落地方向」改为「个人行动建议」，「企业对标」改为「个人对标」
- 政策没有评分体系时，第三章改为「退税金额测算」场景对比表
- 待确认的扣除项标注「?」提示用户自查，不遗漏

### 案例二：企业政策（无评分体系）—— 2026 企业税收减免

**主体：** 某线上咨询公司，小微企业，增值税小规模纳税人，无特殊资质（非高新/非科小）。

**政策：** 2026 年度小微企业税收减免（企业所得税 5% + 增值税起征点 + 六税两费减半），财政部 税务总局公告 2023 年第 6/12 号、2026 年第 10 号。

**执行过程：**

- 第 0 步：索取主体画像 —— 小微企业、线上咨询、小规模纳税人、无特殊资质
- 第 1 步：联网搜索三项政策原文，提炼企业所得税 5%、增值税起征点 10 万/月、六税两费减半
- 第 2 步：认定匹配 —— 年应税所得 ✅、从业人数 ✅、资产总额 ✅、小规模纳税人 ✅（无评分体系，跳过「分档达标」）
- 第 3 步：场景卡片呈现 —— 起步期（年省 3 万）/ 成长期（年省 10.8 万）/ 扩张期（年省 16 万）
- 第 4 步：行动卡片 2×2 排列 —— ①控制开票节奏 → ②申报科小 → ③利润超 300 万规划 → ④年度重核认定
- 第 5 步：产出文本总览 + HTML，时间轴纵向可视化，今天节点标红

**关键经验：**
- 政策无评分/分档体系时，第三章改用场景卡片做节税测算，直观呈现"能省多少钱"
- 行动建议用卡片网格代替表格，角标优先级 + 元标签（难度 / 收益 / 时间窗口）一目了然
- 时间轴必须纵向，今天节点红色突出，禁止横向表格
- 无特殊资质的主体要明确标注「无」并聚焦基础通用政策
