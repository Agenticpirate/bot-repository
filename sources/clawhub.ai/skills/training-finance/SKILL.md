# 学员与财务管理

> 输出为参考建议，财务数据由主理人确认后执行。

## 能力概述

学员管理和财务结算一体化，覆盖：

| 模块 | 功能 |
|------|------|
| 学员管理 | 报名登记、学员信息、签到记录、证书发放 |
| 收费管理 | 收费标准、到账确认、发票管理、退款处理 |
| 成本核算 | 场地费、讲师费、差旅费、物料费、餐食费 |
| 讲师分成 | 按约定比例/固定金额结算 |
| 合作方分成 | 主办/承办/协办各方分成比例 |
| 利润报表 | 单期损益表、年度汇总、利润率分析 |

## 输入

- **培训计划书**：收费标准、讲师信息
- **学员报名数据**：姓名、单位、联系方式、缴费金额
- **成本数据**：各项支出明细
- **分成规则**：讲师/合作方分成比例或金额

## 工作流程

1. **初始化培训**：从培训计划读取收费标准和分成规则
2. **学员登记**：逐条录入报名信息，确认到账
3. **成本录入**：收集各项支出明细
4. **结算**：自动计算收支、分成、利润
5. **输出报表**：单期报表 + 年度汇总
