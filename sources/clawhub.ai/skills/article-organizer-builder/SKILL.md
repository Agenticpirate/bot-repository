# 文章收藏整理 Skill 构建器

本技能是一个**元技能**：它不直接整理文章，而是为用户**现场生成**一个全新的「文章收藏整理」Skill。用户可能想给自己的笔记库建一套自动收藏归档流程，也可能只是想要一个通用模板。

## 执行流程

1. **读取规范**：先完整读取 `references/builder-prompt.md`（通用构建规范，含 8 步构建流程、笔记模板、验收清单）。
2. **收集自定义信息**：按规范文末「自定义填充清单」逐项询问用户（用提问组件一次收集）：
   - 四个路径：笔记库根目录、源文章目录、收藏夹目录、归档目录；
   - 领域分类规则（主题分类 + 关键词）；
   - 分类 → 标签映射；
   - 笔记标题风格偏好。
   若用户不确定，给出合理默认值并标注，不要卡住流程。
3. **生成目标 skill**：在 `~/.workbuddy/skills/<用户主题相关的名字>/` 下按规范 8 步生成完整目录：`SKILL.md` + `scripts/scan.py` + `scripts/cleanup.py` + `references/classification.md`。规范中所有 `<尖括号>` 占位符必须替换为步骤 2 收集到的实际值。
4. **自检**：用规范中的「验收清单」逐项核对，缺项补齐再交付。
5. **交付**：告知用户生成的位置、目录结构、触发方式，以及验收清单核对结果。

## 注意

- 生成的目标 skill 是**全新独立的**，不得改动用户已有的其他 skill。
- 脚本只用 Python 标准库，不引入第三方依赖。
- 安全底线：生成脚本时必须保留「归档不删除、路径越界拒绝」逻辑。
