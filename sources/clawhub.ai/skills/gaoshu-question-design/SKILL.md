# 高等数学智能题库 · 题目设计技能

> 版本：1.0 ｜ 适用：高数智能题库扩展生产、省级培训出题教学、题库质量提升
> 定位：与 `gaoshu-questionbank-workflow`（批量生产流水线）互补——本技能回答"一道好题**怎么设计出来**"，流水线技能回答"设计好后**怎么入库**"。
> 来源：B74–B78 五个批次 200 题的实战沉淀（主库 3200 题，8 章全部 ≥90%）

---

## 一、何时使用本技能

- 用户要求"为第 X 章设计一批题 / 设计几道亮点题"
- 培训场景：教别人（老师/学生）如何出高质量高数题
- 生成脚本前的手工设计环节（流水线技能第③步之前的"想题"阶段）
- 审查他人出的题：用本技能的模式库与自检清单找问题

**核心原则**：
1. **先定答案，再编题面**——题目是"答案的倒推"，不是"题面的凑数"
2. **设计即避撞**——设计阶段就对照主库，不靠入库时去重兜底
3. **一道题只考一个核心考点**，其他都是陪衬
4. **陷阱要有教学意义**——陷阱对应真实的高频错误，不是为了难而难

## 二、题目设计工作流（七步）

### ① 定考点
- 从本章考点清单选 1 个核心考点 + 至多 1 个辅助考点
- 考点要有区分度：太基础（纯公式）或太偏（超纲）都不合格
- 参考章节完成率：薄弱章的题优先选高频考点（极限、中值定理、极坐标、特征方程等）

### ② 查重避让（设计前必做）
- 提取目标章全部现有题 q 文本到快照，**通读**
- 对候选考点，列出主库已有变体，确定"新意"在哪：
  - 换函数（x³sin2x → x³cos x）✅ 可
  - 换区域/换系数（圆域 → x²+y²≤2y）✅ 可
  - 同型结论变体（双中值：和→积→倒数）❌ **不可**（前 80 字符仍撞，B76 教训）
- 选择题固定开头（"下列…中收敛的是"）必须换措辞，否则误报重复

### ③ 数值倒推（先算答案）
- 心算/手算把答案先定下来，要求**干净**（整数、简单分数、π 的整数倍）
- 例：心形线 r=a(1+cosθ) 面积 → 3πa²/2；∫₀^πdx∫_x^π(sin y)/y dy → 2
- 答案不干净的题直接淘汰或改参数
- **设计陷阱数值**：干扰项用学生典型错误的结果（如极坐标忘乘 r 得到的值）

### ④ 编题面
- 题干一句话说清，条件齐全（区间、方向、侧、x>0 等一个不少）
- LaTeX 规范：`$…$` 内联，`\iint`/`\iiint`/`\oint` 用对，变量与主库风格一致
- 判断题：命题必须有"看似对实则错"或"看似错实则对"的教学点
- 选择题：4 个选项，干扰项 = 典型错误结论（计算错、忘条件、方向反）

### ⑤ 写 solution（评分梯度）
- 2-3 步，每步有明确得分点，分数和为 10（整数）
- 梯度逻辑：关键步骤分多（6 分），收尾步骤分少（2-4 分）
- 证明题：辅助函数构造 4-5 分 → 应用定理 3-4 分 → 结论 2 分
- 每步文本自含（不依赖上下文也能看懂）

### ⑥ 写 hints 与 common_errors
- hints 2-3 层递进：L1 概念提醒 → L2 方法提示 → L3 关键数值/结论
- common_errors 2 条：覆盖不同错误类型（conceptual/computational/procedural/strategy 至少两类）
- error 写学生视角的说法，reason 写正确解释

### ⑦ 标注元数据 + 自校验
- type/bloom/difficulty/thinking_type/tags/estimated_time/prerequisites/section/application 全填
- section 与主库现有分类完全一致（先查主库有哪些 section 名）
- 自校验：score 和=10；本章 type/bloom/diff 分布命中模板（见流水线技能第五节）

## 三、设计模式库（B74–B78 实战提炼）

### 模式 A：经典结论换壳
**思路**：保留经典题型骨架，替换函数/区域/系数，制造"熟悉又陌生"感。
- A1 换函数：x³sin 2x 高阶导 → x³cos x 莱布尼茨 y⁽⁵⁾(0)=-60
- A2 换区域：∬sin(x²+y²) 单位圆 → x²+y²≤2y（圆心不在原点，θ 范围变 [0,π]）
- A3 换参数：欧拉方程系数换组合 → 先验算特征方程根
- ⚠️ 限制：换壳后答案必须重算，不能沿用原答案

### 模式 B：隐藏的换序/换元
**思路**：给一个"直接积不动"的形式，逼学生换序/换元/换坐标系。
- B1 换序：∫₀^πdx∫_x^π(sin y)/y dy（sin y/y 对 y 不可积 → 换序后 ∫sin y=2）
- B2 极坐标化：x²+y²≤2x 化极坐标（陷阱：θ∈[-π/2,π/2] 而非 [0,2π]）
- B3 换元：∬_D x²/y² dxdy（xy=1,2 与 y=x,4x 区域 → 双换元）
- 设计要点：**换序/换元前后的形式都写进 solution**，评分点放在"识别需要换"这一关键认知上

### 模式 C：教学陷阱题（判断/选择）
**思路**：找学生"直觉会错"的命题，错因必须是真实高频错误。
- C1 第二类积分带定向：∬_Σ x dydz（球面外侧）= 4πR³/3 ≠ 0——直觉"x 是奇函数积分为 0"是错的（B78 亮点）
- C2 可导⇔可微（一元等价）vs 可导⇒连续（不反向）
- C3 y'=y^{1/3} 初值解不唯一（f 不满足利普希茨条件）
- C4 y'=y² 解在 x=1 爆破 → 最大存在区间 (-∞,1)
- 设计要点：判断题答案"正确/错误"都要能在 solution 里一句话讲清原理

### 模式 D：证明题的辅助函数库
**思路**：中值定理证明题 = 构造辅助函数 + 罗尔/拉格朗日/柯西/达布。
- D1 移项构造：证 f'≥1 ⇒ f≥x → g(x)=f(x)-x
- D2 乘积/指数因子：f'(ξ)+λf(ξ)=0 → e^{λx}f(x)
- D3 双展开消元：|f'(x)|≤M/2 → 在 x 处向两端泰勒展开，相减消 f(x)
- D4 达布衔接：f'(0)f'(1)>0 → 罗尔找 f'(η)=0，两端拉格朗日得 f'' 变号点，达布定理取 0（B78 亮点）
- D5 双曲辅助：y''-y=0 解空间 → u=y cosh x - y' sinh x 为常数（B78 亮点）
- D6 反证：f''≡0 ⇒ f 为一次函数，由端点条件矛盾（f 不恒 0 时 ∃f''(ξ)≠0）

### 模式 E：二维化/高维化一维定理
**思路**：把一维经典定理搬到二重/三重积分，考察概念迁移。
- E1 二维牛顿-莱布尼茨：∬∂²f/∂x∂y = f(1,1)-f(1,0)-f(0,1)+f(0,0)（B78 亮点）
- E2 富比尼乘积：∬f(x)f(y) = (∫f)²（B78 亮点）
- E3 换序定理证明（黎曼和，一致连续性）——L6 压轴（B78 亮点）
- E4 高斯公式/格林公式的证明与应用（散度定理、挖洞法 4π）

### 模式 F：应用场景封装
**思路**：纯数学结论套真实场景（无人机/金融/医学/电池/自动驾驶），不改变数学内核。
- F1 路径做功 = 第二类曲线积分（变力场）
- F2 药物浓度/半衰期 = 一阶线性/可分离方程
- F3 散热/扫描区域总功率 = 二重积分（密度函数）
- ⚠️ 限制：场景参数要现实（R=50m、100W/m² 级别），数值先算通

## 四、质量自检清单（每题）

**设计阶段**：
- [ ] 核心考点唯一、明确
- [ ] 答案已手算验证，数值干净
- [ ] 题面条件齐全（区间/方向/侧/定义域）
- [ ] 与主库 q[:80] 不重复（含变体措辞检查）
- [ ] solution 分数和=10 且每步有独立得分点
- [ ] hints 递进、common_errors 覆盖 ≥2 类错误

**批次阶段**（交给流水线技能）：
- [ ] 本章 type/bloom/diff 分布精确命中模板
- [ ] merge 去重 0、import --approved、verify 全绿

## 五、常见设计错误与对策

| 现象 | 原因 | 对策 |
|:-----|:-----|:-----|
| 答案丑陋（分数堆叠） | 没做数值倒推 | 先定答案再反推参数 |
| 双中值/同型题重复 | 结论变体仍撞前 80 字符 | 直接换模式（如换达布定理题） |
| 判断题直觉即对 | 命题没有教学陷阱 | 找"看似对实则错"的命题（第二类积分定向、唯一性条件） |
| 选择题干扰项无区分度 | 随便凑选项 | 干扰项用典型错误计算结果 |
| 证明题只写步骤不写构造 | 辅助函数凭空出现 | solution 里写清"为什么这么构造" |
| 应用场景脱离现实 | 参数随意 | 场景参数查真实量级 |
