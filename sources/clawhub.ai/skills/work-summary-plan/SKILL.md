# 工作内容分析与时间分配规划

自动化从有道云笔记中提取日常工作记录，分析工作内容分布，并生成未来时间分配规划报告的完整流程。

## 前置条件

用户需要提供两项信息（缺一不可，必须先收集）：

1. **有道云笔记个人Key** — 用于通过 MCP 连接有道云笔记
2. **日常工作取数规则** — 包括：
   - 工作笔记所在的文件夹/笔记本名称（如「日常工作」「周报」等）
   - 笔记标题的命名规则或关键词（如「本日工作」「本周工作」）
   - 覆盖的时间范围（如 2025年日誌 + 2026年周报）
   - 可选：工作的角色/岗位背景（如"财政预算管理一体化平台技术经理"），用于默认分类的适配

如果用户尚未提供这两项，先询问用户收集，不要猜测。

## 流程概览

```
用户提供Key+取数规则 → Step1: 连接有道云 → Step2: 搜索提取笔记 → Step3: 分类统计 → Step4: 生成分析报告 → Step5: 生成规划报告
```

## Step 1: 连接有道云笔记

使用有道云笔记 MCP 工具连接：
- 工具名：`mcp__youdao-note__*` 系列
- 用户需提供个人 Key 用于鉴权

验证连接成功后进入下一步。如果连接失败，提示用户检查 Key 是否正确。

## Step 2: 搜索和提取工作笔记

根据用户提供的取数规则：

1. **列出笔记**：使用 `mcp__youdao-note__listNotes` 获取笔记列表
2. **搜索笔记**：使用 `mcp__youdao-note__searchNotes` 按标题关键词搜索
3. **读取内容**：使用 `mcp__youdao-note__getNoteTextContent` 获取笔记正文

数据提取要点：
- 提取每条工作事项的简短描述
- 记录每条事项的日期/时间范围
- 保留原始笔记作为参考依据
- 用户可能用日誌（每日）或周报（每周）格式，两种都能处理

## Step 3: 工作内容分类

加载 `references/work_categories.md` 获取默认分类体系。

分类方法：
1. 将每条工作事项归类到对应的工作大类中
2. 统计每个类别的出现频次，转化为百分比
3. 按年度分别统计（如用户提供了两年数据）
4. 记录每个类别的典型工作内容举例（取2-3个）

**如果用户的角色不在默认分类中**，则根据角色特点调整分类。例如：
- 纯开发角色：可能去掉"团队管理""会议沟通"，增加"编码实现""代码评审"
- 产品经理：增加"原型设计""用户调研"，减少"开发发版"
- 调整后将新的分类体系告知用户确认

分类完成后展示分类结果给用户（表格形式），等待用户确认后再进入下一步。

## Step 4: 生成工作分布分析报告

加载 `references/report_spec.md` 获取报告模板和生成规范。

报告需包含：
1. **概览卡片**：分类数、样本数、总笔记数
2. **各年度饼图**：使用 Chart.js 的 doughnut 图
3. **年对比柱状图**：使用 Chart.js 的 bar 图
4. **分类明细表**：含占比、典型内容、变化趋势
5. **深度洞察分析**：基于数据的变化趋势解读、角色演进分析、风险提示
6. **优化建议**：基于数据发现的具体改进建议

报告模板参考：`assets/analysis_report_template.html`

生成后以 HTML 文件保存到当前工作目录，文件名为 `工作分析报告.html`。

## Step 5: 生成时间分配规划报告

基于 Step 4 的分析结果，生成未来时间分配规划报告。

报告需包含：
1. **当前 vs 建议时间分配对比**：饼图+雷达图
2. **四象限优先级矩阵**：重要紧急、重要不紧急、紧急不重要、不重要不紧急
3. **年度关键节点时间线**：按财政年度/自然年度周期划分，标注每阶段核心工作
4. **季度时间分配热力图**：各季度10项工作的投入力度
5. **具体行动建议**：分立即执行、近期推进、中长期规划三个层次
6. **优化效果预期表**

时间线需根据用户的行业/角色特点定制：
- 财政/政府类：按财政年度周期（Q3治理窗口、Q4年结、Q1规划、Q2交付）
- 互联网/产品类：按季度OKR周期
- 通用类：按自然年度四季划分

报告模板参考：`assets/planning_report_template.html`

生成后以 HTML 文件保存到当前工作目录，文件名为 `时间分配规划报告.html`。

## 完成

两个报告生成后，使用 `present_files` 展示给用户。同时将本次分析的核心数据（分类占比、关键发现）记录到工作目录的 `.workbuddy/memory/` 中。

## 约束

- 分类和统计数据必须基于真实提取的笔记内容，不可编造
- 所有百分比之和应为100%
- 报告中的深度洞察必须是数据驱动的，有变化幅度支撑
- 如果数据不足（样本少于10条），提醒用户增加数据后再分析
