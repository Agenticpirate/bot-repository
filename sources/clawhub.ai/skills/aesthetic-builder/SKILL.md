# 审美建造器

## 定位

本技能是**元技能系统（meta-skill-system）的下级母技能**，专门负责从任意审美概念出发，系统化填充9个交互维度（非正交），生成完整的审美系统Skill文件。

**与元技能系统（meta-skill-system）的关系**：本技能消费元技能系统的三轴执行框架（6大元操作、R1-R5校准、管线编排），将9维交互审美模型转化为可执行的审美生成管线。两者的分工边界：**元技能系统做事，审美建造器造美**。元技能系统消除的是工作流中的补偿性冗余，审美建造器创建的是有审美判断力的独立审美系统——前者去冗余，后者创价值，互不冲突。

**与Character Builder的关键差异**：Character Builder的12维是正交的（职业 × 身份 是一个有效的独立组合——医生×父亲和律师×父亲是两个不同的角色，但都是可独立成立的）。Aesthetic Builder的9维是**非线性的交互的**（色彩 × 材质 产生的是性质上不同于单独维度的新东西——金属暖色不是"金属的冷"加上"暖色调"的简单叠加，而是产生了"金属暖色"这个独立的新审美范畴）。这意味着：
- Character Builder可以逐维独立填充后组合验证，维度间的冲突是"一致性冲突"（农民不能同时是程序员）
- Aesthetic Builder必须在填充每个维度时就考虑它与其他维度的交互效应，维度间的冲突可能是"创意源"（低饱和色 + 粗糙材质 = 侘寂之美，这不是冲突，是创新）

**为什么需要9维交互审美模型**：单一的配色方案或材质选择不足以构成审美系统。真正的审美系统是9个维度之间的交互网络——一种材质在特定色彩和光线下的表现、一种节奏在特定空间布局中的流动、一种文化符号在特定情感基调下的诠释。本技能的价值在于系统化地覆盖9个维度及其交互，确保生成的审美系统具有内在一贯性和可执行性。

**核心理念**：审美 = 感知层坐标 × 情感层坐标 × 文化层坐标，但坐标之间的乘法不是正交乘积，而是化学反应的化合价——1+1可能等于完全不同的新事物。

## 双模式架构

本技能支持两种输入模式，由A0域的输入模式检测（ab-04）自动判定路由：

### Mode A：独立审美生成（Independent Aesthetic Generation）
- **输入**: 用户对审美系统的自然语言描述（"侘寂风格的日式茶室"、"赛博朋克霓虹美学"、"包豪斯极简办公空间"）
- **处理**: 按9维交互模型从零填充，维度填充时实时计算跨维交互效应
- **输出**: 独立完整的审美系统Skill文件
- **适用场景**: 品牌设计系统、UI视觉规范、艺术创作方向、空间设计指南

### Mode B：角色风格提取（Character Style Extraction）
- **输入**: 多个Character Builder生成的角色Skill文件
- **处理**: 从N个角色的躯体维(维5：外貌/体型/着装)、文化维(维6：审美理念/艺术偏好)中提取共享风格元素；从角色的时代/阶级/亚文化中反推审美参照系；对冲突风格进行协调或标注为"角色个性化差异"
- **输出**: 从角色数据中提取的共享审美系统 + 每个角色的个性化风格变体
- **适用场景**: 已有角色库需要统一视觉风格、为角色阵容设计共享美学、IP视觉一致性管理

### 路由逻辑
1. 检测输入是否包含角色Skill文件引用
2. 包含且≥2个角色 → Mode B，消费角色数据提取审美
3. 不包含或仅1个角色 → Mode A，独立生成
4. 混合输入 → Mode A为主，角色数据作为审美参数的约束和参考

### 双模式不互斥
Mode A生成的审美系统可以作为后续角色生成的风格约束——注入到Character Builder的躯体维和文化维中。Mode B提取的审美系统可以与Mode A合并——角色提供的"已有审美偏好"作为锚点，独立生成填充"未表达的审美维度"。

### 关键设计注意
Mode B的维度交互计算尤其重要：多个角色的躯体维可能暗示不同的材质偏好（金属vs织物），这些差异本身构成了审美系统的张力。Mode B不应简单取平均——应保留这种张力，标注为"系统中的审美两极"，这本身就是有价值的审美系统特征。

### 与Character Builder的分工
单角色的审美风格用Character Builder的躯体维(维5)和文化维(维6)就能完整定义——一个人的着装/外貌/审美偏好自包含于其12维数据中。当你拥有≥2个角色需要共享统一的视觉/审美语言，或者需要从群体中提取风格系统作为品牌/IP的审美规范时，才需要本技能。本技能是风格协调器，不是替代品。

## 审美9维模型

```
第一层：感知层（Perceptual Layer）——审美系统的"表面"，直接可感知的物理属性
  维1 色彩维（Color）：色相/明度/饱和度、色调温度（暖/冷/中性）、色彩调和关系（互补/类似/三角/分裂互补）、对比度、色彩数量约束
  维2 形态维（Form）：形状（几何/有机/抽象）、比例系统（黄金分割/三分法/模数化）、线条特性（曲/直/折/流）、体量感（轻盈/厚重/锐利/圆润）
  维3 材质维（Material）：质感（光滑/粗糙/哑光/亮光）、密度感（轻/重/浮/实）、透明度（不透明/半透明/透明）、触觉暗示（温/冷/软/硬/柔/刚）
  维4 空间维（Spatial）：构图（对称/不对称/放射/网格/自由）、留白与负空间策略、深度层次（前景/中景/远景）、尺度关系（宏大/亲密/中性）

第二层：情感层（Emotional Layer）——审美系统的"感受"，作用于观者的情感
  维5 情感基调（Emotional Tone）：整体氛围（宁静/活跃/庄严/欢快/神秘/温暖/冷峻）、情感效价（积极/消极/中性/混合）、唤醒度（高/中/低）、情感精确描述（不止于"悲伤"，而是"秋日黄昏的怅然"）
  维6 节奏维（Rhythm）：视觉节奏（重复/渐变/突变/交替）、节奏速度（快/慢/变速）、图案密度（密集/稀疏/有密有疏）、视觉流动线（引导视线在画面中的移动路径）

第三层：文化层（Cultural Layer）——审美系统的"出处"和"意义"
  维7 文化引用（Cultural Reference）：风格时期（文艺复兴/巴洛克/现代主义/后现代等）、艺术运动（印象派/包豪斯/波普/极简等）、文化传统（东方/西方/非洲/伊斯兰/印度等具体传统）、跨文化融合标注
  维8 符号维（Symbolic）：视觉隐喻（用什么物象表达什么概念）、原型意象（母性/英雄/智者/阴影等）、符号体系（具象符号/抽象符号/文化特定符号）、可读性（符号含义是否对目标观众可解读）
  维9 语境维（Contextual）：媒介载体（印刷/屏幕/空间/装置/数字/混合）、目标观众（年龄/文化背景/审美素养/期待）、功能目的（传达/说服/装饰/纪念/挑衅/沉浸）、时代场域（当代/复古/未来/永恒）

维度交互示例（非线性交互是一等处理对象）：
- 色彩×材质：暖色+金属 = 铜质暖感（不同于暖色在哑光纸上的感受）；冷色+玻璃 = 冰透感（不同于冷色在粗糙石面上的感受）
- 形态×情感：圆润曲线+宁静基调 = 安抚感；锋利折线+活跃基调 = 动感张力
- 材质×空间：粗糙纹理+大量留白 = 孤独与质感并存；光滑表面+密集构图 = 未来科技感
- 文化引用×色彩：印象派光影理解+柔和互补色 = 致敬莫奈的色彩策略；包豪斯+高对比黑白红 = 德式现代主义审美
- 情感基调×节奏：沉静+慢节奏 = 禅意；亢奋+变速节奏 = 都市霓虹感
```

交互矩阵（第一性交互对，共9维间的36对交互）的优先级如下：

| 优先级 | 交互对 | 原因 |
|--------|--------|------|
| P0 必处理 | 色彩×材质 | 材质决定色彩的实际呈现效果，是感知层内最强交互 |
| P0 必处理 | 形态×情感基调 | 形态直接唤起情感反应，是跨层最强单向交互 |
| P0 必处理 | 空间×节奏 | 空间布局决定视觉流动，节奏在其中展开 |
| P1 优先处理 | 色彩×情感基调 | 色彩心理学——色相和饱和度直接影响情感效价 |
| P1 优先处理 | 材质×空间 | 材质在空间中的分布影响深度感和层次感 |
| P1 优先处理 | 文化引用×符号 | 文化引用提供符号体系的解码密钥 |
| P2 标准处理 | 其余30对交互 | 按域间流程自然覆盖 |

## 核心能力

### 审美需求解析
从用户输入中提取审美概念的初始线索，判断哪些维度已有隐含信息、哪些需要主动询问、哪些可以自动推导。与Character Builder的差异：还需识别用户输入中隐含的维度交互暗示（如"温暖的金属感"隐含了色彩×材质的交互需求）。

### 9维交互填充
按三层结构（感知层→情感层→文化层）逐层填充每个维度，**同时**追踪维度间的交互效应。每个维度填充时不是独立完成，而是与已填充维度进行交互检查：这个色彩在这个材质上的实际效果是什么？这个形态在这个情感基调下的观感是什么？P0和P1交互对必处理。

### 跨维度交互映射
专门处理维度组合产生的涌现属性——即单独维度不存在的、仅在交互中产生的新审美范畴。这是Aesthetic Builder区别于其他Builder的核心能力。

### 审美Skill组装与输出
将填充完成的9维审美系统组装为标准的审美Skill文件，包含SKILL.md + references/的完整三层结构。

## 三层结构

```
第一层：审美技能清单 + 依赖拓扑   →  references/aesthetic-catalog.md
第二层：审美方法论要求清单        →  references/aesthetic-requirements.md
第三层：审美范本库              →  references/exemplars.md
```

## 使用规则

### 执行流程
1. **首次加载**：读取 `references/aesthetic-catalog.md`，获取域分类、依赖拓扑、元操作映射提示
2. **按需深入**：确认目标审美生成任务后，读取 `references/aesthetic-requirements.md` 获取各维度的填充槽位和约束
3. **独立执行**：本技能仅依赖元技能系统的执行框架，不依赖其他领域技能

### 事实纪律
1. 色彩命名和色相描述需基于可验证的色彩理论（NCS/Munsell/Pantone/PCCS等体系），不确定的标注"待验证"
2. 文化引用必须指向真实存在的风格时期/艺术运动/文化传统，不可编造不存在的艺术流派
3. 符号体系的解读必须基于该文化内部的符号学传统，不可仅凭外观臆断其文化含义
4. 材质和工艺描述必须基于物理可实现性（除非标注"概念性/数字材质"）
5. 9维之间不得有逻辑冲突，但允许有"创意张力"——冲突标注为"张力"并说明设计意图
6. 维度不可跳过——空缺维度必须标注"未定义"并说明原因
7. 交互对处理必须显式标注（P0/P1/P2优先级处理结果），不可隐含处理
8. 审美Skill输出格式必须符合元技能系统接口规范

### 扩展能力
9. **提示词导出**：可将本技能的SKILL.md与references目录下所有文件内容合并为单一提示词文件，用于不支持skill目录格式的工具
10. **完整合并版**：references/aesthetic-builder-prompt.md 为完整合并版提示词文件，包含SKILL.md与所有references文件内容

## 执行框架

本技能消费以下元技能系统组件：

- **三轴判定（M4-09）**：判定审美生成请求的复杂度、内容类型、创新需求
- **领域校准（M4-10）**：R1信息密度→色彩/文化引用的准确度要求，R2创造性→风格新颖度与创新需求，R3交互性→用户参与迭代的程度，R4规范性→维度严格度与交互对强制处理级别，R5迭代性→审美细化轮次
- **6大元操作**：S感知=搜索色彩理论/材质特性/文化风格信息，C认知=分析维度交互效应/风格一致性，A行动=填充维度内容/设计交互对，O组织=组装审美Skill，I交互=用户确认关键审美决策，G守护=9维完整性校验/交互对处理验证
- **管线编排（M4-07/M4-08）**：感知层三域(A1)可并行填充（但需共享交互上下文），情感层(A2)和文化层(A3)可与感知层并行启动——因为三层之间是交互关系而非严格顺序依赖，但情感层需部分感知层输入，文化层需部分情感层输入

## 域概览

按审美生成流程组织，共6域21种任务：

| 域 | 任务数 | 典型任务 |
|----|--------|---------|
| A0 审美需求解析域 | 4 | 输入模式检测、审美需求解析、维度交互填充策略（含交互对优先级）、执行顺序确定 |
| A1 感知层域 | 5 | 色彩设计、形态与几何设计、材质与质感设计、空间构图设计、感知层校验（含层内交互） |
| A2 情感层域 | 3 | 情感基调定义、节奏与图案设计、情感层校验 |
| A3 文化层域 | 4 | 文化引用映射、符号体系设计、语境适配、文化层校验 |
| A4 跨维交互域 | 3 | 跨维度交互映射、协同增强、张力（对比）设计 |
| A5 整合输出域 | 3 | 9维完整性校验、审美Skill组装、审美Skill输出 |

**域间逻辑流**：A0 → A1/A2/A3（三层可并行启动但需交互上下文共享） → A4（跨维交互映射） → A5

完整清单见 `references/aesthetic-catalog.md`。

## 与执行框架的接口

### Step 0 三轴判定
审美生成任务默认为：复杂度=中等（9维+交互对）、内容类型=结构化（9维框架+交互矩阵）、创新需求=通常需要创新（审美价值依赖新颖性）。

### Step 1 领域校准
基于审美类型推导R1-R5参数：
- **写实审美**（品牌设计/UI设计/空间设计）：R1高/R2中/R3高/R4高/R5中 → S和G权重高，交互对强制处理
- **艺术审美**（纯艺术/概念设计/个人风格）：R1中/R2极高/R3低/R4低/R5高 → A和C权重高，C偏发散，交互对允许创意偏离
- **文化审美**（传统风格/地域风格/民族风格）：R1高/R2低/R3中/R4高/R5低 → S和G权重高，文化引用的准确性优先
- **实验审美**（前卫/跨界/混合媒介）：R1低/R2极高/R3中/R4低/R5极高 → C偏发散，交互对是主要创新源

### Step 2-4 管线编排与执行
三层(A1/A2/A3)可并行启动——每个层的域内任务串行（如A1: ab-10→ab-11→ab-12→ab-13→ab-14），但三层之间可同时开始填充。A4跨维交互在所有层完成后执行。A5整合在A4完成后执行。

关键差异：不同于Character Builder的"A1→A2→A3严格串行"（因为实体层不完成无法确定社会层），Aesthetic Builder的三层可以并行启动——因为感知层的一个色彩选择不需要等文化层完成才能进行，但各层内的交互上下文需要在A4阶段汇合处理。

## 降级模式

当依赖的外部能力不可用时，按以下降级策略执行：

| 缺失能力 | 降级模式 | 影响范围 | 说明 |
|---------|---------|---------|------|
| 网络搜索（色彩数据/文化引用） | 基于内置知识填充，标注"未网络验证" | ab-10, ab-30 | 色彩精确值和文化遗产细节可能不够准确 |

## 事实纪律

1. 仅使用确知的色彩理论、材质科学、艺术史事实和可验证的文化知识，不得编造数据或引用
2. 文化引用中涉及的艺术运动、风格时期、文化传统必须确知真实存在，不确定的标注"待验证"
3. 符号体系的解读必须基于该文化的内部符号学传统，不可仅凭外观臆断——若不确定，标注"推测性解读"
4. 材质描述必须基于物理可实现性，数字/虚拟材质需标注"数字材质"
5. 色彩交互效果的描述需基于已知的色彩调和理论和材质反射原理
6. 维度交互效应的判断需显式标注推导链路（如"色彩×材质→金属暖色：因为金属表面高反射率×暖色调光→产生温润的金属光泽"）
7. 审美判断不可避免有主观成分，主观判断需标注"主观判断"以区别于客观事实
8. 生成的审美Skill中的创新风格需标注是"基于已知风格的融合"还是"原创风格"
