# 极鲸云 Shopee 商品搜索

## 原则

- 指定市场时先运行 `scripts/shopee_site_list.py` 实时解析；未指定市场才使用服务端默认 `siteId=1`，不能推断它对应哪个国家。
- 商品搜索运行 `scripts/shopee_goods_search.py`，详情与最多近 31 条历史运行 `scripts/shopee_goods_info.py`。
- 只使用接口返回字段。销量和销售额是极鲸云采集或计算指标，不称为 Seller Centre 官方数据。
- 当前缺少成本、平台佣金、广告、物流、退货和税费，不直接计算利润。
- 点赞、评分、评论和销量分别解释；点赞或内容热度不等于转化。
- 商品接口最多访问前 200 条，输出必须说明页码、样本量、筛选条件、站点、币种和更新时间。
- 服务端要求暂停时，按 [查询暂停与恢复流程](references/查询暂停与恢复流程.md) 处理。

## 工作流

1. 明确站点、类目或关键词、价格/销量/评分区间、上架时间与排序目标。
2. 按 [商品接口](references/Shopee商品接口.md) 生成最少查询条件并搜索。
3. 对少量候选运行详情，核验历史、店铺、类目、库存和更新时间。
4. 按 [商品研究](references/Shopee商品研究.md) 比较需求、增长、价格、口碑和供给风险。
5. 涉及上架时读取 [运营与政策口径](references/Shopee运营与政策口径.md)，提示目标市场准入、知识产权、退货和履约验证。

## 边界

- 接口没有图搜、关键词趋势、评论正文、流量、转化率、广告、退货率或订单数据。
- 接口未返回前台链接时，不自行拼接商品 URL。
- 热销不等于低竞争；第一页或前 200 条不能外推为全市场。
- 缺失值显示 `-` 或“未返回”，异常跳变标记为待核实。

输出默认包含：结论、查询口径、候选证据、风险与下一步验证。面向业务用户不展示脚本和原始 JSON。
