# AliWay v1.0.1 — 阿里味战略文档写作术

## 核心理念

阿里味的本质不是词汇堆砌，是**思维方式**。真正的阿里 P10 文档有三个特征：
1. **从"道"出发** — 先讲为什么存在，再讲怎么做
2. **使命驱动** — 一切选择都指向一个比商业更大的意义
3. **组织穿透** — 文档即管理工具，读完要让人知道"我该做什么、不做什么、做不到会怎样"

---

## 第一步：选择文档框架

**不要每次都用同一个框架。** 根据文档目的，从以下四种框架中选择最合适的一种。框架决定叙事结构、语气重心和读者期待。

### 框架 A：战略判断型（适合：方向选择、赛道判断、架构决策）

核心问题：我们应该往哪走？为什么？

```
标题：[使命金句] — [方向定义]
开篇：升维定位（"这不是X，是Y"）
一、终局判断 — 行业终局是什么形态，能活几家
二、窗口研判 — 为什么是现在，错过代价多大
三、我们的牌 — 手上有什么，缺什么，独特性在哪
四、战略选择 — 押注什么，明确不做什么
五、路线节奏 — 分阶段打穿，每阶段验收标准
六、风险护栏 — 最怕什么，怎么对冲
七、衡量标准 — 指标体系，对结果负责
```

语气重心：**笃定感 + 取舍魄力**。"这不是商量，是战略选择。"

### 框架 B：组织动员型（适合：团队大会、季度 kick-off、变革启动）

核心问题：为什么每个人都必须动起来？

```
标题：[行动号召] — [紧迫性]
开篇：灵魂追问（3个直击要害的问题）
一、见自己 — 我们是谁，基因和宿命
二、见天地 — 时代变革，不变就会被替代
三、见众生 — 我们服务的人需要什么
四、使命重定义 — 一句话讲清存在意义
五、核心抓手 — 资源往哪倾斜
六、组织机制 — 谁 own、怎么考核、做不到怎么办
七、收尾 — 回归使命，燃起斗志
```

语气重心：**使命感 + 紧迫感**。"此时此刻，非我莫属。"

### 框架 C：复盘反思型（适合：项目复盘、失败分析、季度回顾）

核心问题：我们学到了什么？下次怎么做得更好？

```
标题：[核心教训] — [反思主题]
开篇：先亮结果（好的坏的都摊开）
一、初心回溯 — 当初为什么做这件事
二、过程还原 — 关键节点发生了什么
三、剥洋葱 — 表面原因 vs 根因
四、教训沉淀 — 哪些是偶然的，哪些是结构性的
五、改进承诺 — 具体行动，责任人，时间点
六、组织收获 — 这次失败/成功沉淀了什么组织能力
```

语气重心：**诚实感 + 担当感**。"任何人的错都是我的错。"

### 框架 D：愿景布道型（适合：新方向宣讲、使命升级、文化传递）

核心问题：我们要把世界变成什么样？

```
标题：[愿景描述] — [时间跨度]
开篇：从一个具体场景/故事开始
一、今天的世界 — 现状是什么，痛点在哪
二、明天的世界 — 我们想让它变成什么样
三、为什么是我们 — 基因、积累、独特优势
四、道 — 信念和第一性原理
五、路径 — 从今天到明天怎么走
六、号召 — 这件事值得一生投入
```

语气重心：**感染力 + 画面感**。"梦想不足以让你到达远方，但到达远方的人一定有梦想。"

### 混合使用原则

- 四种框架可以混合元素，但**主框架只选一个**，确保叙事主线清晰
- 判断标准：读者读完后的第一反应应该是什么？
  - "我知道该往哪走了" → 框架 A
  - "我必须动起来了" → 框架 B
  - "我明白哪里做错了" → 框架 C
  - "我被点燃了" → 框架 D

## 四层内容架构：道法术器

不管选哪个框架，内容组织都遵循"道法术器"四层递进。但不同框架对四层的权重不同：

| 框架 | 道（Why） | 法（What） | 术（How） | 器（Measure） |
|------|-----------|-----------|-----------|--------------|
| A 战略判断 | ●●○ | ●●● | ●●○ | ●●● |
| B 组织动员 | ●●● | ●●○ | ●○○ | ●●○ |
| C 复盘反思 | ●○○ | ●●○ | ●●● | ●●● |
| D 愿景布道 | ●●● | ●●○ | ●○○ | ●○○ |

### 道（Why）— 第一性原理
- 从事物本质推导出不可违背的底层规律
- 不从竞品分析推导，从对世界的理解推导
- 每条原理用一句话表述，能指导所有后续决策

### 法（What）— 战略选择与取舍
- **做什么** — 三个以内核心抓手，按优先级
- **不做什么** — 同样重要，每项说清底层逻辑
- 取舍标准：是否指向使命，是否形成结构性壁垒

### 术（How）— 路线图与节奏
- 分阶段，每阶段有明确验收标准
- 验收标准可量化、可验证（不是"做了什么"，是"达到什么效果"）
- 资源分配要有具体比例

### 器（Measure）— 指标与考核
- 领先指标（方向对不对）、滞后指标（结果好不好）、健康指标（方法对不对）
- 指标不是用来看的，是用来考核的
- 带时间维度（6个月目标、12个月目标）

## 阿里味修辞术

### 核心心法：阿里味不是贴标签，是思维方式的自然流露

错误示范（贴标签）：
> 我们要拉通各个模块的底层逻辑，形成闭环的顶层设计。

正确示范（思维方式）：
> 这三个模块今天是散装的——各自独立演进，没有形成统一系统。散装的能力不叫生态，叫资源浪费。

### 六脉神剑正确用法

不是口号式引用，是融入论证逻辑：

| 价值观 | 错误用法 | 正确用法 |
|--------|---------|---------|
| 客户第一 | "我们要客户第一" | "客户第一——这里的客户是 BP，他们的生产环境不能用来试错" |
| 因为信任所以简单 | "因为信任所以简单" | "我把这个判断给到你们，你们拿结果来验证。因为信任所以简单——但信任不是放羊" |
| 唯一不变的是变化 | "唯一不变的是变化" | "过去做的 feature 不是白做——价值没变，载体变了。拥抱变化不是口号，是行为" |
| 今天最好的表现是明天最低的要求 | "今天最好的表现是明天最低的要求" | "做到了是及格，做不到复盘，反复做不到——组织会帮你做调整" |
| 此时此刻非我莫属 | "此时此刻非我莫属" | "不是因为我们最强——是因为牌面在此刻最完整，而窗口不等人" |
| 认真生活快乐工作 | "认真生活快乐工作" | "我们不是要大家卖命——是要大家把笑脸带回家，把智慧带回公司" |

### 高频修辞模式

1. **追问式开篇** — 上来就问 2-3 个问题，逼读者自己想，不给舒适区
2. **类比降维** — 用日常概念让抽象战略具象化（操作系统、蒸汽机、翻译官、蜡烛与火芯）
3. **对偶否定** — "不是X，是Y"制造张力（"不是技术升级，是生产关系变革"）
4. **量化锚定** — 所有判断带数字（"18个月"、"60%工程力量"）
5. **组织压力** — "组织会帮你做选择"、"变不了的人，组织会帮你做调整"
6. **格局对比** — "P7 的定位 vs P10 的定位"
7. **先破后立** — 先否定旧认知，再建立新认知（"旧战场的仗已经打完了"）
8. **土话点睛** — 在论证的关键转折处，用一句阿里土话收束，形成记忆锚点
9. **故事切入** — 不是每次都追问开篇，也可以从一个具体场景/故事开始
10. **自我否定** — 先承认自己之前做得不够，再讲新方向，增强可信度

### 语气特征

- **审视感** — 从上往下看，不是平级讨论
- **笃定感** — 不用"可能"、"也许"、"建议考虑"，用"必须"、"不商量"、"这是战略选择"
- **责任感** — 所有判断都带"对结果负责"的兜底
- **使命感** — 让人觉得做的不是项目，是改变一代人命运的事业
- **人味** — 不是冰冷的分析报告，要有真情实感，偶尔露出"管理者也是人"的一面

## 开篇手法库（避免千篇一律）

每次写文档，从以下开篇手法中选择，**不要总用同一种**：

### 1. 追问式（适合战略判断型）
> 我先问三个问题，你们自己想一想：[问题1]？[问题2]？[问题3]？想清楚这三个问题，后面所有选择都是自然的。

### 2. 否定式（适合变革启动型）
> 这不是一份技术方案。这不是一次架构升级。这是[真正定义]。如果你读完只觉得"又是一次XX"，说明我没讲清楚。

### 3. 场景式（适合愿景布道型）
> 想象一下：三年后的某个早晨，一个数据工程师打开电脑，[描绘未来场景]。这不是科幻——这是我们正在建的东西。

### 4. 数据式（适合复盘反思型）
> [关键数字]。这个数字说明了什么？说明了[洞察]。更重要的是它没说明的：[被忽视的真相]。

### 5. 故事式（适合文化传递型）
> [年份]年，[具体人]做了一个[具体决定]。当时所有人都觉得[反对意见]。[结果]。这件事教会我们：[教训]。

### 6. 坦白式（适合复盘/转型型）
> 有些话不好听，但必须说。过去一年我们做了很多事，但诚实讲——[核心问题]。今天不是来表功的，是来照镜子的。

### 7. 时间倒推式（适合紧迫型）
> [X]个月。这是我们从"定义规则的人"变成"追赶规则的人"之间的距离。时间不等人。

## 阿里土话 102 式素材库

以下土话按使用场景分类。写作时从中选取 3-5 句自然融入论证，**切忌堆砌**——一段话里出现超过两句土话就是在表演，不是在思考。

### 使命与梦想
- **此时此刻，非我莫属。** — 用于号召承担，表达舍我其谁的气概
- **心有多大，舞台就有多大。** — 用于鼓励格局拉升
- **今天最好的表现是明天最低的要求。** — 用于设定标准，传递持续进化的期望
- **梦想不足以让你到达远方，但到达远方的人一定有梦想。** — 用于区分空想和行动
- **定位"有什么，要什么，放弃什么"** — 用于战略取舍的核心三问
- **蹲下来是为了跳得更高。** — 用于解释短期退让的战略意图

### 执行与落地
- **想不等于做，做不等于做到，做到不等于得到。** — 用于强调从想法到结果的全链路
- **一流 idea 三流实施不如一流实施三流 idea。** — 用于强调执行力大于创意
- **马上做，做精彩。** — 用于消灭拖延，追求卓越
- **没有过程的结果是垃圾，没有结果的过程是放屁。** — 用于强调过程和结果缺一不可
- **做发动机，不要做飞轮。** — 用于要求主动驱动而非被动响应
- **不要事情找你，是你找事情。** — 用于要求 owner 意识
- **机会太多，只能抓一个。** — 用于要求聚焦

### 取舍与战略
- **与其等待与能力匹配的机会，不如培养与机会匹配的能力。** — 用于鼓励能力建设
- **100 米赛跑没有时间看你的对手，唯一办法是盯着终点拼命跑。** — 用于去除竞品焦虑
- **当你只需要一根针时，千万不要去磨铁棒。** — 用于警示过度建设
- **今日因，明日果。** — 用于强调当下决策的长远影响
- **不要纠缠于"长期"和"短期"，"长期"已经成为现在不做事情的借口。** — 用于打破拖延借口

### 压力与韧性
- **今天很残酷，明天更残酷，后天很美好，但绝大部分人死在明天晚上。** — 用于描述坚持到底的重要性
- **不难，要你干嘛？** — 用于激励面对困难
- **永远不要跟别人比幸运，要比谁更有毅力。** — 用于强调长期主义
- **SO TMD WHAT！** — 用于表达面对挫折的豪气（谨慎使用）
- **不怕输才会赢。** — 用于鼓励冒险
- **你感觉不舒服的时候，就是成长的时候。** — 用于安抚变革中的不适
- **生命在于折腾，不在折腾中崩溃，就在折腾中涅磐。** — 用于鼓励变革和探索

### 自我认知与反思
- **看不出问题就是最大的问题。** — 用于警示盲目乐观
- **自己觉得有，别人感觉不到你有，你就是没有。** — 用于提醒价值需要外部验证
- **最大的错误就是停在原地不动，就是不犯错误。** — 用于反对求稳心态
- **Back To Basic。** — 用于面对混乱时回归本质
- **乐于揪头发，勇于照镜子。** — 用于自我反思（揪头发=站高看远，照镜子=审视自我）
- **别把沙子放大成绊脚石。** — 用于保持判断力，不被小事干扰

### 团队与协作
- **1.1×1.1×……≈3，0.9×0.9×……≈1/3。** — 用于说明每个人多做一点的复利效应
- **分享是学习他姥姥。** — 用于鼓励知识沉淀（教别人是最好的学习）
- **不要害怕把自己的弱项暴露给他人。** — 用于建设信任文化
- **不要让自己的队友失败。** — 用于强调团队责任
- **己所欲，施于人。** — 用于比"己所不欲勿施于人"更积极的协作观

### 管理与组织
- **任何人的错都是我的错。** — 用于管理者担当
- **错误的决定比没有决定要好。** — 用于要求决断力
- **重复等于强调。** — 用于管理沟通
- **开会不能总讲和气，越和气就越微妙。** — 用于鼓励真实讨论
- **No surprise 原则。** — 用于绩效管理（结果不应让人吃惊）
- **团队的成长是管理者最大的成功。** — 用于重定义管理者价值
- **你刚来可以抱怨手下是混蛋，过了一年你还在抱怨，那你才是混蛋。** — 用于管理者担责
- **管理者要学会自己舔伤口，舔完自己的还要去舔别人的。** — 用于管理者的韧性要求

## 绝对禁忌

1. **禁止空洞口号** — 每句阿里味的话后面必须跟具体论证或行动
2. **禁止纯技术视角** — 永远回到"为谁创造什么价值"
3. **禁止面面俱到** — 取舍是格局，砍比加更难
4. **禁止模糊表述** — 所有判断要有数字、有时间、有验收标准
5. **禁止自卖自夸** — "牌好不等于赢"比"我们最强"更有说服力
6. **禁止框架雷同** — 不要每篇文档都用"见自己见天地见众生"，根据目的选框架
7. **禁止土话堆砌** — 一段话超过两句土话就是表演。土话是点睛之笔，不是主菜

## 质量检查清单

写完后自检：

- [ ] 读完是否知道"我们为什么存在"？（使命感）
- [ ] 读完是否知道"时代在发生什么级别的变革"？（格局）
- [ ] 读完是否知道"我该做什么、不做什么"？（取舍清晰度）
- [ ] 读完是否知道"做不到会怎样"？（组织压力）
- [ ] 读完是否觉得"这件事值得我拿职业生命来赌"？（使命驱动）
- [ ] 阿里味是自然融入论证还是贴在表面？（修辞质量）
- [ ] 有没有至少一处让人脊背发凉的判断？（战略穿透力）
- [ ] 这篇文档的框架和上次写的是否不同？（多样性）
- [ ] 土话使用是否克制（全文不超过 5-8 句）？（节制感）
- [ ] 开篇手法是否和上次不一样？（新鲜感）
