# 简历面试助手

## 能力概览

本技能提供从简历撰写到 offer 选择的全流程求职辅助能力：

| 能力模块 | 覆盖内容 |
|---------|---------|
| 简历诊断 | 简历结构评分、内容质量评估、格式合规检查 |
| 简历优化 | STAR法则改写、量化成果、关键词植入、一页纸排版 |
| 面试准备 | 行为面试STAR故事库、技术面试知识点梳理、HR面试模拟 |
| 面试复盘 | 面试录音转录分析、回答质量评估、改进建议 |
| 求职策略 | 行业薪资基准、岗位匹配度分析、谈薪话术、Offer比较矩阵 |
| 英文简历 | 中英文双语简历、英文Cover Letter、LinkedIn优化 |

## 使用方式

### 简历诊断与优化

用户提供简历内容（粘贴文字或上传文件）后：

1. **结构评估**：检查简历模块完整性（个人信息、教育背景、工作经历、项目经验、技能标签）
2. **内容诊断**：识别"描述空洞"问题（如"负责XX工作"→改为"通过XX方法，实现XX结果，提升XX%"）
3. **关键词优化**：根据目标岗位JD植入行业关键词，提高简历筛选通过率
4. **格式检查**：确认一页纸原则、字体统一、时间线连贯

### 模拟面试

用户提供目标岗位和公司后：

1. **行为面试**：使用 STAR 方法模拟常见问题（"请分享一个你带领团队解决困难项目的经历"）
2. **技术面试**：根据岗位生成针对性技术问题（后端/前端/算法/产品/运维等）
3. **HR面试**：模拟职业规划、离职原因、薪资期望等软性问题
4. **回答评价**：从"清晰度/结构化/量化程度/匹配度"四个维度评分并给出改进建议

### 求职策略

1. **行业薪资调研**：通过 WebSearch 获取目标行业/城市的薪资基准数据
2. **岗位匹配分析**：对比用户简历与目标JD，量化匹配度，列出差距项
3. **谈薪话术生成**：根据面试进展和用户预期，生成有理有据的谈薪话术
4. **Offer比较**：多Offer多维矩阵对比（薪资/职级/成长/文化/地点）

## 自进化学习系统（越用越好用、越用越高效）

本技能内置通用学习模块 `scripts/learner.py`。每次使用后自动复盘、积累经验，逐步提升输出质量与执行效率，无需人工维护。

### 记忆文件
`learned_patterns.json`（位于本技能目录）记录：操作总数、各能力使用频次、错误模式、用户偏好、改进建议。

### 使用后请调用（Bash）

```bash
# 记录一次成功使用（--capability 填本次主要能力名，如「简历优化」「比价」）
python scripts/learner.py record <本技能目录> --capability 简历优化
# 记录一次失败/异常
python scripts/learner.py record <本技能目录> --capability 简历优化 --fail --error 格式识别失败 --note "用户上传了非标准文件"
# 记录用户偏好（下次直接使用）
python scripts/learner.py prefer <本技能目录> --key 输出语言 --val 中文
# 查看累计洞察（高频能力 / 反复错误）
python scripts/learner.py insight <本技能目录>
# 自动复盘（错误≥3次 或 操作≥10次 时给出改进建议）
python scripts/learner.py reflect <本技能目录>
```

### 迭代规则
- **错误累计 ≥3 次** → 主动增加预检/兜底步骤，并将经验回写本 SKILL.md。
- **操作数 ≥10 次** → 分析高频能力优先打磨示例与质量，低频能力评估精简或合并。
- **重要用户偏好** → 写入 `learned_patterns.json`，下次调用直接采用，减少重复询问。

> 越用越懂你：第一次用是通用能力，第十次用已沉淀为你专属的最佳实践。
