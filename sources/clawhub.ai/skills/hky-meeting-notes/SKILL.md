# 养老与传承会谈纪要整理自动生成 Skill

## 定位

专为「养老规划 + 财富传承」场景设计的会谈纪要整理生成器。它把零散的沟通材料，变成后续能直接产出风险评估报告的"原料库"。

与通用会谈纪要整理不同，本 Skill 强制按**五板块信息矩阵**归位，并显式标注"信息缺口"——因为养老与传承方案的质量，取决于信息完整度。凡会谈未提及的，用"虚线框 / 信息确认点"留白，而不是编造。

默认完成：

- 画家庭架构草图（含未确认的虚线框）。
- 把信息归位到五个板块（健康 / 财务 / 房产居住 / 家庭关系 / 现有保障）。
- 区分事实、顾问说明、推断、待确认。
- 初判显性风险信号。
- 输出信息缺口清单（下次要补什么）。
- 输出客户画像、明确需求、主要顾虑。
- 给下一步动作和可直接发送的微信跟进消息。
- 标注"不要再说的话"（红线）。

## WorkBuddy 兼容规则

在 WorkBuddy 或其他 Agent 中使用时，不假设有私有素材库或本机记忆；只使用用户本轮材料。信息不足时列出缺口和可先做的动作，不编真实案例、客户原话、后台路径或确定性结论。涉及保险、医疗、法律、监管、信托的事实，标注需要人工核验。对外成品（要发给客户的）必须脱敏、改口风；过程信息（缺口、推断、客户阶段）只留在内部纪要，不进入对外消息。

## 适用场景

- 首次需求访谈（收集信息为主）。
- 二次深度沟通（信息校准，本 Skill 也可用于更新已有纪要）。
- 回访沟通（家庭结构/资产变化记录）。
- 任何需要把养老与传承客户沟通沉淀成"报告原料"的场合。

## 输入

用户可提供任意一种或多种：

- 通话 / 面谈录音转写。
- 微信聊天记录。
- 现场手记 / 零散要点。
- 客户填好的信息收集清单。

如果目的不清，先问：

- 这份纪要给谁看：自己 / 团队 / 客户。
- 这次沟通处在哪个阶段：首次访谈 / 二次沟通 / 回访。
- 会后最重要的下一步是什么。

## 处理流程

### 1. 会议识别卡

```markdown
【会议识别卡】
- 场景：首次访谈 / 二次沟通 / 回访
- 纪要受众：自己 / 团队 / 客户
- 客户阶段：刚建立联系 / 识别需求 / 比较方案 / 接近成交 / 成交后
- 信息完整度：低（<40%）/ 中（40-70%）/ 高（>70%）
- 是否需要脱敏：
```

### 2. 家庭架构草图（含虚线框）

用文字或 ASCII 画出家庭结构，未确认的角色/关系用"虚线框 [待确认]"标注。

```markdown
[客户] —— 婚况：[已婚/离异/丧偶/未领证，待确认]
   │
   ├── 子女：[姓名/年龄/状态；特殊需要子女需标"需终身照护，照护等级待确认"]
   ├── 父母：[在世/已故，年龄与健康状况待确认]
   └── 其他经济支柱：[无 / 伴侣 / 其他，待确认]

[虚线框：生父/继父母/未领证伴侣是否承担经济或监护责任 —— 待确认]
```

### 4. 区分事实、顾问说明、推断、待确认

- **客户明确说过**：原文要点，不演绎。
- **顾问明确说明过**：已讲的概念、比喻、边界（如"这是风险评估，不是方案"）。
- **推断**：从上下文推的（如"客户回避生父话题，可能关系紧张"），必须写依据。
- **待确认**：会谈没提的，全部列缺口，不补。

### 5. 风险信号初判

基于已有信息，初判显性风险（不打分，只列信号）：

- 本人为唯一经济支柱 → 倒下即断供。
- 特殊需要子女无长期照护资金安排。
- 无遗嘱/意定监护 → 传承与监护真空。
- 医疗险缺口 / 重疾裸奔。
- 养老金替代率不足。

### 6. 客户画像 / 明确需求 / 主要顾虑

- 身份与场景。
- 当前阶段与最关心的问题。
- 明确说出的需求。
- 主要顾虑（区分"顾虑=没想清楚"与"异议=明确反对"）。

### 7. 下一步动作 + 跟进消息 + 不要再说的话

下一步用表格（动作 / 负责人 / 截止 / 状态）。跟进消息要像微信不像报告。不要再说的话列红线。

## 输出结构

```markdown

## 1. 本次沟通摘要
## 2. 会议识别卡
## 3. 家庭架构草图（虚线框 = 待确认）
## 4. 五板块信息矩阵
## 5. 事实 / 顾问说明 / 推断 / 待确认
## 6. 风险信号初判
## 7. 客户画像
## 8. 明确需求
## 9. 主要顾虑
## 10. 信息缺口清单（下次必补）
## 11. 下一步动作
## 12. 可直接发送的跟进消息
## 13. 不要再说的话
```

## 质量标准

- 信息按五板块归位，不遗漏板块。
- 凡没提到的写"待确认"，不编。
- 风险信号能回溯到原始材料。
- 会谈纪要整理能直接喂给"标准化风险报告生成 Skill"。
- 跟进消息口语化。

## 退回规则

- 原文没有的信息写"待确认"，不补。
- 未脱敏真实客户资料，先要求脱敏再处理对外版。
- 用户要求写恐吓式跟进消息，拒绝并改成低压力提醒。
- 用户要求伪造客户意向，拒绝。
