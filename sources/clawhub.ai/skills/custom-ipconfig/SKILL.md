# 本机公网 IP 与归属地查询

通过公共接口查询当前设备的公网 IP 地址、归属地、城市、运营商、经纬度等网络信息。无需 API 密钥，纯免费公共接口，支持 Agent 自主调用。

## 触发条件（满足任意一条）

- 用户询问：我的IP、本机IP、公网IP、网络地址
- 用户询问：我现在网络在哪、IP归属地、网络运营商
- 用户提问：当前网络信息、查看本机网络状态
- 用户需要排查网络、代理、翻墙、节点地区信息

## 参数说明

本技能**无需用户输入任何参数**，直接自动获取当前设备出口公网IP。
如果用户指定了某个IP，则查询用户指定IP；无参数默认查询本机。

## 接口调用规范

接口地址：`http://ip-api.com/json/`
（备选 `https://ipapi.co/json/` 有 Cloudflare 反爬限制，优先用 ip-api.com）

请求方式：GET
请求头：无
密钥：无需

## 返回数据字段说明（ip-api.com）

- **query**：公网IP地址
- **country**：国家
- **regionName**：省份/地区
- **city**：城市
- **lat / lon**：经纬度
- **org**：网络运营商/机房机构
- **isp**：互联网服务提供商
- **timezone**：时区

## Agent 执行流程（强制）

1. 识别用户需要查询IP/网络归属地意图
2. 调用 `http://ip-api.com/json/` 获取完整网络信息
3. 捕获异常：超时/失败返回「当前无法获取公网IP信息，请检查网络连接」
4. 整理成简洁中文结构化结果输出，禁止直接输出原始JSON

## 固定输出格式（必须遵守）

```text
【当前设备公网网络信息】
🌐 公网IP：xxx.xxx.xxx.xxx
📍 归属地：国家 / 省份 / 城市
🏢 运营商：网络服务商
🌍 经纬度：纬度, 经度
⏰ 时区：当前时区
```

## 约束规则

- 单次对话最多调用一次接口，避免频繁请求
- 禁止泄露、记录、上传用户隐私IP数据，仅对话展示
- 若检测到是代理/VPN出口IP，正常如实播报即可
