# Skill 4：成本估算

## 功能概述

对架构设计方案进行成本估算，覆盖算力消耗、云服务成本、带宽、存储等维度，输出多方案的成本对比分析。

## 输入与输出

| 项目 | 内容 |
|------|------|
| **输入** | 架构设计方案（来自Skill 2）、风险评估结果（来自Skill 3） |
| **输出** | 成本估算报告（含成本分解、多方案对比、月度/年度成本预测） |

## 执行流程

### Step 1：成本维度识别

从以下维度系统性估算成本：

| 成本类别 | 子项 | 估算依据 |
|---------|------|---------|
| **计算资源** | 应用服务器、AI推理服务器、批处理服务器 | 服务器规格×数量×单价 |
| **存储资源** | 数据库存储、对象存储、文件存储、备份存储 | 存储量×单价×冗余系数 |
| **网络资源** | 公网带宽、内部网络、CDN | 带宽需求×单价 |
| **AI/LLM费用** | LLM API调用、模型训练/微调、向量数据库 | 调用量×单价（或自部署成本）|
| **中间件** | 消息队列、缓存、搜索引擎、API网关 | 节点数量×单价 |
| **运维成本** | 监控、日志、告警、容器编排 | 节点数量×单价 |
| **人力成本** | 开发团队、运维团队 | 团队规模×平均薪资（可选）|
| **第三方服务** | 短信、邮件、认证、地图等 | 按调用量或订阅计费 |

### Step 2：成本估算方法

#### 2.1 基于规模的估算

对于每个组件，根据用户规模和性能要求估算：

```markdown
### 计算资源估算

| 组件 | 规格 | 节点数 | 月单价 | 月度小计 |
|------|------|--------|--------|---------|
| API服务 | 8C16G | 3 | ¥800 | ¥2,400 |
| 业务服务 | 8C16G | 5 | ¥800 | ¥4,000 |
| AI推理服务 | 16C32G + GPU | 2 | ¥3,000 | ¥6,000 |
| **合计** | | **10** | | **¥12,400** |
```

#### 2.2 基于用量的估算

对于按量计费的服务（LLM API、短信等）：

```markdown
### LLM API费用估算

| 模型 | 预估月调用量 | 单价 | 月费用 |
|------|------------|------|--------|
| GPT-4o | 1,000,000 tokens | ¥0.15/1K tokens | ¥150 |
| 文本嵌入 | 5,000,000 tokens | ¥0.02/1K tokens | ¥100 |
| **合计** | | | **¥250** |
```

#### 2.3 参考定价数据源

在估算云服务成本时，建议通过联网搜索获取最新定价（使用search_web和fetch_web工具）：

- **国内云**：阿里云、腾讯云、华为云
- **国际云**：AWS、Azure、GCP
- **AI服务**：OpenAI、Claude、国产大模型

> **注意**：标注估算日期和来源，提示用户实际价格可能变动

### Step 3：多方案成本对比

对关键成本差异点，提供多方案对比：

```markdown
### 方案成本对比

| 成本项 | 方案A：自建机房 | 方案B：公有云 | 方案C：混合云 |
|--------|--------------|-------------|-------------|
| 初始投入 | ¥500,000 | ¥0 | ¥200,000 |
| 月度运营 | ¥30,000 | ¥45,000 | ¥35,000 |
| 12个月总成本 | ¥860,000 | ¥540,000 | ¥620,000 |
| 弹性扩展能力 | ⭐⭐ | ⭐⭐⭐⭐⭐ | ⭐⭐⭐⭐ |
| 运维复杂度 | ⭐⭐⭐⭐⭐ | ⭐⭐ | ⭐⭐⭐ |

**推荐方案**：方案B（公有云）
**理由**：总成本最低、弹性最好，适合快速增长的业务
```

### Step 4：成本敏感度分析

识别对总成本影响最大的因素：

```markdown
### 成本敏感度分析

| 成本驱动因素 | 占比 | 变化10%影响总成本 | 控制建议 |
|------------|------|-----------------|---------|
| AI推理服务器 | 35% | +3.5% | 优先使用模型量化/蒸馏降低算力需求 |
| 数据库存储 | 25% | +2.5% | 实施冷热数据分层存储策略 |
| LLM API调用 | 20% | +2.0% | 使用缓存减少重复API调用 |
| 网络带宽 | 15% | +1.5% | 使用CDN和图片压缩 |
| 其他 | 5% | +0.5% | — |
```

## 成本优化原则

1. **预留实例 vs 按需实例**：稳定负载用预留实例可节省30-50%
2. **自动伸缩**：根据负载动态调节资源，避免过度配置
3. **冷热数据分离**：热数据用高速存储，冷数据用低成本归档存储
4. **缓存策略**：合理使用缓存减少后端计算和存储压力
5. **异步/批处理**：非实时任务用异步批处理降低计算峰值
6. **选用性价比模型**：对于非关键推理，可选择量化后的轻量模型
