# 情绪调节微练习

微型化的情绪干预技术，每个练习 5-15 分钟，基于 CBT、DBT 和正念疗法的实证研究。

## 使用场景

- 情绪突然涌上来，需要快速平复
- 睡前太兴奋或焦虑，需要放松
- 工作/学习中感到压力突然增大
- 与他人发生冲突后需要冷静
- 经前综合征（PMS）情绪波动
- 想要建立日常情绪健康习惯

---

## 技术一：STOP 急救法（4-6分钟）

基于 DBT 的核心技术，用于情绪即将失控的紧急情况。

```
S - Stop（停）
    停下手头的事情，不要加重情况

T - Take a breath（呼吸）
    做3次深呼吸，每次呼吸注意胸腔和腹部的起伏

O - Observe（观察）
    观察身体：心跳加快？肩膀紧绷？
    观察情绪：我正在生气/害怕/难过？
    观察想法：我脑海里有什么念头？

P - Proceed mindfully（行动）
    问自己：我真正想要的是什么？
    这个行动会帮我接近还是远离目标？
```

**关键提示：** 停下来不是放弃，而是给自己一个选择的空间。

---

## 技术二：呼吸方块（5-8分钟）

最快速有效的自主神经调节方法。

```
第一步：鼻吸，数5秒
    用鼻子慢慢吸气，感觉腹部随之鼓起

第二步：呏住，数4秒
    轻轻闭气，保持自然

第三步：口呼，数6秒
    用嘴唇轻轻吐气，仿佛在吹凉一杯热茶

重复：3-5个循环
```

**备选：** 如果数秒感觉不舒服，可以换成 4-7-8 呼吸：吸气4秒，呏住7秒，呼出8秒。

## 技术三：五感镜子（5分钟）

基于正念的地铢技术（Grounding），将注意力从内心拉回当下。

```
看到5个东西：
    例如：桌面的纹理、窗外的云、手机的颜色

听到4种声音：
    例如：空调风声、车流声、自己的呼吸声

触摸到3种质感：
    例如：上衣的纹理、桌面的冰凉、手机的光滑

闻到2种气味：
    例如：咖啡的香、手洗液的味道

尝到1种味道：
    例如：喝一口水、含一颗糖
```

**原理：** 当情绪过载时，大脑的「战或逃」系统被激活。五感镜子通过调动感官资源重新连接大脑皮层，恢复理性思考能力。

## 技术四：认知重构（CBT框架，10分钟）

检查并挑战导致情绪恶化的自动化思维。

```
第一步：识别自动思维
    我脑海里刚才出现了什么念头？
    例：「我完全弄砸了」「他们肯定觉得我很差劲」

第二步：标注认知偏差
    这是哪种认知偏差？
    ● 非黑即白（「完全」「从不」）
    ● 心理读心术（「他们肯定觉得……」）
    ● 灾难化（「太糟了，全完了」）
    ● 以偏概全（「总是」「每次都是」）
    ● 应该陈述（「我应该更好」）

第三步：提出中立思维
    如果朋友告诉我这个想法，我会怎么开导他？
    有什么证据支持/反驳这个想法？
    是否有其他解释可能？

第四步：生成平衡思维
    用更实际、更温和的方式重新表述。
    例：「虽然这次表现不如预期，但这是一次学习机会。很多人都会经历类似的情况」
```

## 技术五：幸福储蓄缺口（每日维护，3分钟）

基于积极心理学，每天做一次，增加情绪韧性。

```
今天发生的三件小事：
1. _______________
2. _______________
3. _______________

其中最让我感到温暖/满足的一件：
_______________

我想对自己说的一句话：
_______________
```

**作用：** 大脑有「注意偏误」，习惯性关注危险而忽略安全。每天主动记录小确幸，可以重新训练大脑的注意系统。

---

## 技术选择指南

| 情况 | 推荐技术 | 时长 |
|-------|----------|------|
| 情绪快要爆发 | STOP 急救法 | 4-6 分钟 |
| 心跳加快、手发抖 | 呼吸方块 | 5-8 分钟 |
| 感觉脱离现实、发呆 | 五感镜子 | 5 分钟 |
| 一直想乱七八糟的事 | 认知重构 | 10 分钟 |
| 想建立日常习惯 | 幸福储蓄 | 3 分钟 |

---

## 温馨提示

1. 这些技术需要练习才能在紧急时刻发挥作用——建议在平静时先尝试几次。
2. 没有一种技术对所有人都有效，可以一个个尝试，找到最适合自己的。
3. 如果情绪持续低落超过两周，或影响到日常生活，建议寻求专业心理咨询师的帮助。
