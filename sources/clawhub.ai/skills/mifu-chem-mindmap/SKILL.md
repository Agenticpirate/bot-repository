# 米赋化学知识体系思维导图 Skill

## 概述

本Skill与 `mifu-chemistry-lesson-prep` 配合使用：备课教案中的"转化网络设计"模块只呈现价态轴主干，本Skill负责产出**完整知识体系三层思维导图**（参考"铝及其重要化合物｜三层思维导图招贴本"形态），作为教案附件、课堂投屏素材和学生招贴打印件。

**核心保证：内容完整（7维度清单）+ 方程式正确（自动守恒校验）+ 展现形式合理（招贴本式HTML，零依赖可打印）——通过"数据→渲染→校验"流水线实现，不允许手写HTML直接交付。**

## 三层定位（与备课skill的关系）

```
mifu-chemistry-lesson-prep（备课框架）
  └─ 教案模块2.2 转化网络设计
       ├─ 价态轴主干（教案内保留，供课上"空骨架补边"）
       └─ ★完整知识体系思维导图（本Skill产出，作为附件引用）
            ├─ coach用：备课校对+课堂投屏
            └─ 学生用：A3/A0招贴打印+复习挂墙
```

**铁律：教案2.2的文字部分保留空骨架策略（米赋手写原则），思维导图是"验收对照答案"，不替代学生手绘。**

## 流水线（三步，顺序不可颠倒）

```
Step1 数据层：mindmap-data.json（唯一事实源，树形结构+方程式清单）
Step2 渲染层：mindmap_tools.py render → 招贴本式HTML（零外部依赖，可打印）
Step3 校验层：mindmap_tools.py validate → 方程式守恒校验+7维度完整度检查
```

**交付标准：validate全绿（0错误）才允许交付；任何方程式修改必须改JSON后重新渲染，禁止直接改HTML。**

## Step1 数据层：JSON Schema（详见 references/01-structure-standard.md）

```json
{
  "meta": {"module": "模块名", "element": "元素符号", "theme": "主题式包装", "grade_region": "上海高考", "textbook": "沪科技版", "version": "v1.0", "date": "2026-09-10"},
  "valence_axis": {"states": [{"v": -2, "species": ["H₂S", "FeS"]}], "special": "归中/歧化标注"},
  "branches": [
    {"id": 1, "title": "一级分支（物质类别）", "color": "blue", "sections": [
      {"title": "二级维度（物理性质/化学性质/制备/检验/用途）", "nodes": [
        {"text": "三级节点描述", "eq": "化学方程式（可空）", "tag": "常考/易错/可推（可空）"}
      ]}
    ]}
  ],
  "equations_bank": ["全部方程式平铺清单——校验对象"]
}
```

## Step2 渲染层：招贴本设计规范（详见 references/02-design-spec.md）

- **布局**：中心主题横幅（含价态轴SVG）+ 一级分支卡片网格（每行2卡，6分支=3行）
- **层级视觉**：一级分支=彩色粗边框卡片+编号；二级维度=灰底小节标题；三级节点=条目行，方程式用等宽字体+浅色底纹块内嵌
- **标签体系**：`常考`红标签 / `易错`黄标签 / `可推`绿标签（对应"记和推分开"方法论）
- **零依赖**：纯HTML+CSS+内联SVG，无CDN、无JS依赖（file://预览可靠），A3/A0打印友好
- **中文字体**：PingFang SC / Hiragino Sans GB fallback链

## Step3 校验层：三重校验（详见 references/03-verification.md）

| 校验 | 内容 | 实现方式 |
|------|------|---------|
| V1 方程式守恒 | 每条方程式原子守恒（自动解析化学式统计元素） | `mindmap_tools.py validate`（脚本内置解析器） |
| V2 完整度7维度 | 价态轴/物理性质/化学性质方程式/制备/检验/用途/污染治理 逐分支对照 | 脚本输出统计+人工对照清单 |
| V3 渲染检查 | HTML生成成功+节点/方程式数量与JSON一致+无占位符残留 | 脚本自检输出 |

**人工兜底（脚本无法覆盖，必须做）：** ①条件与现象标注（点燃/催化剂/⇌/↑↓符号）②沪科技版教材范围核对（不超纲）③与教案方程式银行一致性对照。

## 使用流程（AI教练标准动作）

### 输入
- 模块名（如：硫及其重要化合物）+ 教案方程式银行（从备课教案复制）
- 知识库参考源：IMA「上海-高考-化学」→ 一轮复习复习讲义（考点目录=完整度对照骨架）+ 上海教材（沪科技版范围）+ 教辅资料
- 形态参考：三层思维导图招贴本（铝样例）

### 执行步骤
1. **建骨架**：从一轮复习讲义考点目录提取一级分支（物质类别），映射7维度到二级section
2. **填数据**：写mindmap-data.json——方程式银行优先（与教案一致），再补讲义/教材中的其他方程式与知识点；每条方程式立即在脑中过守恒
3. **渲染**：`python3 scripts/mindmap_tools.py render <data.json> <out.html>`
4. **校验**：`python3 scripts/mindmap_tools.py validate <data.json>` → 全绿
5. **人工三查**：条件现象标注/教材超纲核对/教案一致性
6. **交付**：HTML投屏+打印；教案2.2模块补一行引用："完整知识体系思维导图见附件xxx.html（validate已通过）"

## 适用边界

- ✅ 化学元素化合物模块（S/Cl/N/Na/Fe/Al等）的知识体系图
- ✅ 原理模块（氧化还原/电离水解/平衡）可复用三层结构，但价态轴维度换成"概念轴"
- ❌ 不做动态交互仿真（那是chem-viz的活）
- ❌ 不替代学生手绘（米赋强制手写原则）
