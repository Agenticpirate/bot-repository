# 九赋产品溯源评级（CTI）

查询任意消费品的消费信任指数（CTI），覆盖企业资质、批文认证、处罚记录、舆情投诉等13个维度的全链路验证。

## 何时使用

- 用户询问某个产品/品牌是否安全可靠
- 用户想验证产品的资质、认证、批文
- 用户关心企业是否有处罚/抽检不合格记录
- 用户想对比多个同类产品的可信度
- 任何涉及"产品靠不靠谱""这个品牌怎么样"的场景

## 调用方法

使用 curl 调用九赋溯源API：

```bash
curl -s -X POST https://jiufu-trace.cn/api/cti/verify \
  -H 'Content-Type: application/json' \
  -d '{
    "product_name": "用户提到的产品名称",
    "brand": "品牌名称",
    "category": "产品品类（如：饮料/化妆品/电子产品/宠物食品）"
  }'
```

**参数说明：**
- `product_name`（必填）：产品名称，如"农夫山泉饮用天然水"
- `brand`（必填）：品牌名，如"农夫山泉"
- `category`（选填）：品类，如"饮料""化妆品""狗粮"
- `depth`（选填）：查询深度，"basic"（快速）或 "deep"（深度，耗时较长）

**响应格式：**
```json
{
  "status": "success",
  "data": {
    "product_name": "农夫山泉",
    "brand": "农夫山泉股份有限公司",
    "cti_grade": "A",
    "cti_score": 85.2,
    "verification_dimensions": {
      "enterprise": {"status": "verified", "score": 90},
      "certification": {"status": "verified", "score": 88},
      "penalty": {"status": "clean", "score": 80},
      ...
    },
    "key_findings": ["经营28年，注册资本11.2亿", "ISO22000认证有效", "2022年有1次标签瑕疵处罚已整改"],
    "risk_flags": [],
    "report_time": "2026-07-06T08:30:00Z"
  }
}
```

## 结果呈现规则

### CTI评级含义
- **A级（80-100分）**：高度可信，对标行业最高标准
- **B级（66-79分）**：总体可信，有少量瑕疵但不影响整体
- **C级（46-65分）**：基本可信，存在值得关注的风险点
- **D级（0-45分）**：风险较高，建议谨慎

### 呈现格式
1. 先说结论：产品名 → CTI评级（分数）→ 一句话判断
2. 再说关键发现：列出3-5条最重要的验证结果
3. 最后说风险点（如果有）：明确告知需要关注什么
4. 如果评级≤C，提示用户注意具体风险项

### 示例输出
```
🔍 农夫山泉饮用天然水
📊 CTI评级：A级（85.2分）—— 高度可信

✅ 关键发现：
• 企业经营28年，注册资本11.2亿，状态正常
• ISO22000食品安全管理体系认证有效
• 近期抽检全部合格

⚠️ 注意：
• 2022年曾因标签瑕疵被处罚5000元（已整改）
```

## 边界说明

- 本技能提供信息参考，不构成消费建议
- D级产品的详细报告涉及武器级信息管控，仅提供结论不提供完整报告
- 查询结果基于公开数据和第三方API，可能存在时效性差异
- 数据来源：国家市场监管总局、天眼查、国家企业信用公示系统等
