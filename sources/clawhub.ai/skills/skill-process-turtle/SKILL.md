# 过程乌龟图工具

## 任务目标
- 本Skill用于:根据流程描述自动生成专业级流程可视化图表
- 能力包含:多模板支持(乌龟图/泳道图/流程图/时间线)、节点关系定义、SVG/PNG导出
- 触发条件:用户请求"画流程图"、"生成乌龟图"、"可视化XX流程"、"导出流程图"

## 前置准备
- 依赖包:cairosvg==2.7.1 (用于PNG导出，如仅需SVG可省略)
- 工作区:脚本在Skill目录内运行，用户文件使用 `./` 相对路径

## 操作步骤

### 1. 需求解析与配置生成
分析用户描述的流程，生成JSON配置：

```json
{
  "title": "流程标题",
  "template": "turtle|swimlane|flowchart|timeline",
  "nodes": [
    {"id": "唯一标识", "name": "节点名称", "type": "process|decision|start|end", "category": "分类(如man/machine/method等)"},
    {"id": "唯一标识", "name": "节点名称", "type": "process", "category": "分类"}
  ],
  "edges": [
    {"from": "起始节点ID", "to": "目标节点ID", "label": "关系说明(可选)"}
  ]
}
```

### 2. 脚本调用生成图表
```bash
python scripts/process_turtle.py --config <配置文件.json> --type <模板类型> --output <输出文件名> --format <svg|png>
```

### 3. 参数说明

| 参数 | 必填 | 说明 | 可选值 |
|------|------|------|--------|
| --config | 是 | JSON配置文件路径 | 有效的.json文件路径 |
| --type | 否 | 覆盖配置中的template字段 | turtle/swimlane/flowchart/timeline |
| --output | 否 | 输出文件名(不含扩展名) | 默认使用配置中的title |
| --format | 否 | 输出格式 | svg(默认)/png |

### 4. 输出说明
- SVG文件:矢量图形，可直接用于报告和网页
- PNG文件:位图格式，适合PPT和文档插入
- 默认保存路径:当前工作目录

## 模板类型说明

### turtle (乌龟图/5M1E)
人(Man)、机(Machine)、法(Method)、料(Material)、测(Measurement)、环(Environment)六维度分析

### swimlane (泳道图)
横向分区展示不同责任部门或阶段的流程

### flowchart (标准流程图)
线性流程，含开始/结束节点、判断分支

### timeline (时间线图)
按时间顺序展示里程碑和关键节点

## 使用示例

### 示例1: 质量管理乌龟图
- 场景/输入:用户描述"质量管理流程，包含5M1E各环节：人是操作员培训，机器是检测设备，方法是SOP，材料是来料检验，测量是数据记录，环境是车间温湿度控制"
- 预期产出:5M1E乌龟图SVG，中心为"质量管理"，六个分支展示各维度
- 关键要点:category字段对应5M1E分类，edges定义输出关系

### 示例2: 订单处理泳道图
- 场景/输入:"订单处理流程：销售接单→仓库配货→物流发货→客户签收，涉及销售部、仓储部、物流部"
- 预期产出:泳道图，三个横向泳道展示各部门职责和流程流转
- 关键要点:nodes的category对应泳道名称，edges定义跨部门流转

### 示例3: 简单线性流程图
- 场景/输入:"项目立项流程：需求收集→方案评审→立项审批→合同签订→项目启动"
- 预期产出:标准流程图，从开始到结束的线性流程
- 关键要点:首节点type为start，末节点type为end，判断节点type为decision

## 注意事项
- JSON配置中id必须唯一，建议使用数字或简短字符串
- edges中from/to必须对应nodes中存在的id
- category字段用于模板布局，非必填但影响显示效果
- 导出PNG需要安装cairosvg，未安装时仅生成SVG
