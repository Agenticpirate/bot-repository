# 食药化妆品广告合规护栏 (food-drug-cosmetics-ad-guard)

## 一、它是什么

食药 / 化妆品广告合规护栏是一个**事前实时拦截器**：在药品、医疗器械、保健食品、特殊医学用途配方食品、化妆品的广告文案、产品详情页、直播话术、对外宣传发布前，自动检测其中与**广告法及食药妆专门监管规定**相关的危险表述，按风险分级（high / medium / low）输出命中项与整改建议，供 Agent 主动调用，避免违规文案对外发布。

与事后深度审查（如广告合规审计）不同，护栏是**高频、轻量、嵌入创作流**的事前拦截：文案一写就查，边写边改。

## 二、覆盖的 6 类红线

| 类别 | 风险 | 代表表述 | 主要依据 |
|---|---|---|---|
| 药品 / 医疗器械广告禁止内容 | high | 保证治愈、根治、治愈率、比其他药品更有效 | 广告法第16条 |
| 保健食品广告禁止内容 | high | 保证功效、涉及疾病预防、与药品比较、代言人推荐 | 广告法第18条 |
| 化妆品广告禁止内容（医疗作用暗示） | high | 治疗功效、消炎、抗炎、杀菌、药用 | 化妆品监督管理条例第43条 |
| 疾病治疗宣称违规（非药品滥用医疗用语） | high | 治疗糖尿病 / 高血压 / 癌症、消炎杀菌、抗感染 | 广告法第17条 |
| 处方药违规发布 | high | 处方药大众媒介、面向公众、无处方可购 | 广告法第15条 |
| 功效断言与绝对化用语 | high | 最佳疗效、100%有效、最高安全、国家级 | 广告法第9条 + 第16/18条 |

## 三、检测能力边界（重要）

- ✅ **适合检测**：表述级红线——功效断言保证、治愈率/有效率、疾病治疗宣称、医疗作用暗示、绝对化用语等**可被关键词识别**的危险表述。
- ⚠️ **不适合检测**：是否取得广告审查批准文件、广告主资质、特殊化妆品注册证、功效宣称评价报告等技术/资质状态——这些是**行政许可状态**，关键词抓不到，应归深度审查（check/audit）。
- ⚠️ **子串匹配的固有局限**：对否定句（如“本产品不具有治疗功效”）可能误命中，命中后请结合上下文判断；免责条款已覆盖误报情形。

## 四、适用场景

- 药品 / 医疗器械 / 保健食品 / 化妆品 品牌的**广告文案、详情页、直播话术、种草笔记**发布前自检。
- 电商平台**商品标题与描述**的食药妆合规预检。
- 市场 / 合规 / 法务人员在对外物料审批流中的**高频拦截**环节。

## 五、调用方式（供 Agent 参考）

```bash
# 检测一段广告文案
python3 scripts/guard.py --text "本品保证治愈，根治高血压，100%有效，最佳疗效" --format json

# 从标准输入读取（适合管道 / Agent 调用）
echo "化妆品具有消炎杀菌的治疗功效" | python3 scripts/guard.py --stdin

# 列出违规类别
python3 scripts/guard.py --list-categories
```

## 八、与深度检查的关系

- **护栏（本工具）**：日常高频拦截，边写边查。
- **深度检查 / 审计（如广告合规审计 skill）**：正式对外发布前的全面体检，含资质审查、功效评价报告、广告审查批准文件等行政许可状态核查。

两者互补：护栏兜底高频红线，深度检查兜底系统性合规。
