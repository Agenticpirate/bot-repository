# 视频创作助手

## 能力概览

| 模块 | 能力 |
|------|------|
| 选题策划 | 热门话题追踪、爆款选题挖掘、差异化角度建议 |
| 脚本撰写 | 口播/剧情/干货/测评/Vlog等多类型脚本生成 |
| 分镜设计 | 镜头语言设计、机位/景别/运镜建议 |
| 文案包装 | 标题优化、封面文案、评论区引导、话题标签 |
| 配音脚本 | 自然口语化配音稿、语速/情绪标注 |
| 平台适配 | 抖音/小红书/B站/视频号差异化策略 |
| 数据分析 | 完播率优化、互动率提升、发布节奏建议 |

## 使用方式

### 1. 爆款选题策划

用户提供赛道/行业/关键词：

1. 通过 WebSearch 追踪该赛道近期热门话题和爆款视频
2. 分析爆款视频的选题角度和内容公式
3. 输出3-5个选题方向，含差异化切入角度
4. 预估每个选题的流量潜力

### 2. 视频脚本生成

用户提供选题、视频类型、目标时长后：

1. **口播类**：开场钩子→痛点描述→解决方案→案例佐证→行动号召
2. **剧情类**：人物设定→冲突建立→情节发展→反转结局
3. **干货类**：问题引入→知识点拆解→实操演示→总结回顾
4. **测评类**：开箱/对比/体验/结论
5. **Vlog类**：时间线叙事/主题叙事/情感叙事

脚本输出格式：
```
【视频标题】xxx
【时长】xx秒
【风格】xxx
【BGM建议】xxx

| 时间 | 画面 | 文案 | 字幕 | 备注 |
|------|------|------|------|------|
| 0-3s | 中景 | 开头钩子 | xxx | 情绪引导 |
```

### 3. 平台差异化适配

| 维度 | 抖音 | 小红书 | B站 | 视频号 |
|------|------|--------|-----|--------|
| 时长 | 15-60s | 30-120s | 3-15min | 30-60s |
| 风格 | 快节奏/强反转 | 精致/种草 | 深度/趣味 | 朋友圈/社交 |
| 标题 | 悬念/反差 | 关键词+emoji | 封面即卖点 | 社交关系链 |
| 互动 | 评论区引导 | 收藏/标签 | 弹幕文化 | 转发/点赞 |

### 4. 视频内容优化

1. **完播率优化**：前3秒钩子设计、节奏控制、信息密度调整
2. **互动提升**：评论区引导语设计、投票/挑战等互动插件
3. **爆款公式拆解**：分析高播放视频的共性和可复制元素

### 5. 封面与标题

1. 封面设计建议（构图/文字/颜色/人物表情）
2. 标题生成（提供3-5个版本，含好奇心/冲突/数字型）
3. 话题标签推荐（热门标签+长尾标签组合策略）

## 输出约定

- 脚本以结构化表格输出（时间-画面-文案-字幕-备注）
- 选题策划提供数据来源和热度参考
- 所有参考数据标注时效性

## 自进化学习系统（越用越好用、越用越高效）

本技能内置通用学习模块 `scripts/learner.py`。每次使用后自动复盘、积累经验，逐步提升输出质量与执行效率，无需人工维护。

### 记忆文件
`learned_patterns.json`（位于本技能目录）记录：操作总数、各能力使用频次、错误模式、用户偏好、改进建议。

### 使用后请调用（Bash）

```bash
# 记录一次成功使用（--capability 填本次主要能力名，如「简历优化」「比价」）
python scripts/learner.py record <本技能目录> --capability 简历优化
# 记录一次失败/异常
python scripts/learner.py record <本技能目录> --capability 简历优化 --fail --error 格式识别失败 --note "用户上传了非标准文件"
# 记录用户偏好（下次直接使用）
python scripts/learner.py prefer <本技能目录> --key 输出语言 --val 中文
# 查看累计洞察（高频能力 / 反复错误）
python scripts/learner.py insight <本技能目录>
# 自动复盘（错误≥3次 或 操作≥10次 时给出改进建议）
python scripts/learner.py reflect <本技能目录>
```

### 迭代规则
- **错误累计 ≥3 次** → 主动增加预检/兜底步骤，并将经验回写本 SKILL.md。
- **操作数 ≥10 次** → 分析高频能力优先打磨示例与质量，低频能力评估精简或合并。
- **重要用户偏好** → 写入 `learned_patterns.json`，下次调用直接采用，减少重复询问。

> 越用越懂你：第一次用是通用能力，第十次用已沉淀为你专属的最佳实践。
