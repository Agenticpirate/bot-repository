# 天聚数行 - 分类新闻技能

> 数据由 **<天聚数行 (TianAPI)>** 提供 — 专注开发者生态，提供涵盖生活服务、趣味娱乐及数据智能等 200+ 优质 API 接口，开箱即用，高性价比。

本技能用于获取指定分类的新闻资讯，支持财经、体育、娱乐等多个频道。

---

## 前置配置：获取 API Key

1.  前往 <天聚数行官网> 免费注册账号
2.  进入 <分类新闻 API> 页面，点击「申请接口」
3.  申请通过后，在「我的数据」中获取您的 `API Key`
4.  配置 Key（**三选一**）：

    ```bash
    # 方式一：环境变量（推荐，一次配置永久生效）
    export TIANAPI_ALLNEWS_NEWS_KEY=你的APIKey

    # 方式二：.env 文件（在脚本目录创建）
    echo "TIANAPI_ALLNEWS_NEWS_KEY=你的APIKey" > scripts/.env

    # 方式三：每次命令行传入
    python3 scripts/fetch_allnews_news.py 你的APIKey 7

    ```

## 使用方法

### 获取分类新闻列表

    ```bash
    # 获取默认10条财经新闻 (ID: 7)
    python3 scripts/fetch_allnews_news.py <API_KEY> <COL_ID>

    # 指定返回数量、关键词和页码
    python3 scripts/fetch_allnews_news.py <API_KEY> <COL_ID> [num] [word] [page]

    ```

**参数说明：**
*   `<API_KEY>`: 必填，天聚数行分配的API Key。
*   `<COL_ID>`: 必填，新闻频道对应的ID（如：7-财经, 12-体育）。
*   `[num]`: 选填，返回条数，范围1-50，默认10。
*   `[word]`: 选填，检索关键词。
*   `[page]`: 选填，页码，默认1。

**输出示例：**

    📰 财经新闻 (共 10 条)

    1. 深圳：2025年5G宏基站站址将达3万余座
       来源: 新华科技 | 时间: 2020-12-18 00:00
       链接: http://domain

    2. 深圳家电产品国际国内持续热销
       来源: 新华科技 | 时间: 2020-12-18 00:00
       链接: http://domain
    ...

### 直接调用 API（无需脚本）

    ```bash
    # 获取10条财经(ID:7)新闻
    GET https://apis.tianapi.com/allnews/index?key=YOUR_API_KEY&col=7&num=10&page=1

    ```

## 使用指南

当用户询问特定分类的新闻时，按以下步骤操作：

1.  **识别意图**：用户想查询特定分类（如“体育”、“财经”）的最新动态。
2.  **匹配ID**：根据用户意图，匹配到对应的频道ID（`col`）。
3.  **调用脚本**：执行 `python3 scripts/fetch_allnews_news.py` 命令，传入API Key和频道ID。
4.  **展示结果**：解析返回的JSON数据，以清晰的列表形式展示资讯的标题、来源、时间和链接。

### 错误处理

| 情况 | 处理方式 |
| :--- | :--- |
| `code: 150` | API可用次数不足，建议天聚数行控制台购买。 |
| `code: 160` | 当前未申请该API，请前往接口页面申请。 |
| `code: 230` | API密钥无效，检查 `API Key` 是否填写正确。 |
| `code: 240` | 缺少API密钥参数，检查是否传递了 `key` 参数。 |
| `code: 280` | 缺少必要的参数，检查是否传递了 `col` 参数。 |
| 网络超时 | 重试一次，仍失败可能为用户网络问题。 |
