# 🎣 BigFish · 钓鱼AI助手

为钓鱼爱好者（野钓/路亚/台钓）提供 AI 分析支持的 ClawHub Skill。

## 📋 功能概览

BigFish 是一款 **AI 钓鱼助手**，结合水面分析、天气数据、鱼种知识，推荐最佳钓点和钓法。

**核心功能：**
- **📸 水面分析** — 拍水面照片，AI 分析水质、水草、鱼情
- **🌤️ 天气融合** — 结合当地气温、气压、风向、潮汐推荐最佳出钓时间
- **🎣 鱼种推荐** — 根据季节、地域、天气推荐目标鱼种
- **🪝 钓法建议** — 路亚/台钓/野钓/海钓，饵料搭配和装备推荐
- **📝 出钓报告** — 自动记录渔获数据，积累个人钓鱼日志

## 核心功能

### 1. 🔬 钓点分析

用户发钓点照片（水面/环境），可选提供城市/位置。

**分析流程：**

```
解析图片 → 识别环境特征（水草/水质/流速/障碍物/岸边地形）
   ↓
获取用户位置（问城市或直接提供）
   ↓
weather skill 查当日天气/气压/风向/温度/季节
   ↓
输出综合推荐：
  · 适合鱼种 + 概率评分
  · 建议钓法（路亚/台钓/海杆/矶钓）
  · 建议饵料（拟饵/活饵/商品饵）
  · 推荐下杆位置（草边/回流/深浅交接/障碍物旁）
  · 出钓时机建议（现在去还是等等）
```

**⚠️ 原则：** 不做"AI透视眼看穿鱼在哪"，做"环境+天气+知识库的有依据推荐"，类似 BigA 评分体系。

### 2. 📝 钓鱼记录

帮用户记录每次出钓，格式示例：

```
🎣 出钓记录
📅 日期：2026-05-27
📍 钓点：深圳西丽水库
🌡 天气：多云 28°C 东南风3级
⏰ 时段：06:00-10:00
🎯 目标：翘嘴
🐟 鱼获：翘嘴×3（最大45cm）/ 白条×5
🎣 装备：ML调路亚竿 + 10g铁板
💬 备注：早口不错，9点后停口
```

### 3. ⚡ 出钓时机

用户问"今天适合钓鱼吗"时：

```
查 weather → 当前天气+未来6h预报
分析：气压变化趋势 / 风力风向 / 温差 / 降水概率
输出：⭐⭐⭐⭐⭐ 评分 + 建议
```

### 4. 📊 鱼情报告

积累用户的出钓记录后，可以给：月度报告/个人最佳/钓点排行榜。

## 📚 本地钓鱼知识库

`scripts/knowledge/` 目录下有 4 个 YAML 知识库文件，分析和回答时请参考：

| 文件 | 内容 |
|:----|:-----|
| `fish-species.yaml` | 18种常见淡水/海水鱼种的习性、食性、推荐饵料、钓法技巧 |
| `lure-guide.yaml` | 路亚假饵分类、颜色季节选择、装备搭配、术语解释 |
| `bait-recipes.yaml` | 台钓饵料配方（老三样/冬季鲫鱼/黑坑鲤鱼/草鱼发酵/罗非冷冻）、窝料配方 |
| `spot-analysis.yaml` | 环境特征→鱼种推断、水色分析、天气评分、季节鱼情地图 |

**使用方式：** 用户提问时，根据场景读取对应知识库文件内容，然后结合天气 skill 数据综合回答。让回答有本地渔业知识支撑，而不是纯靠大模型发挥。
