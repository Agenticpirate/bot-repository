# phonebridge · WorkBuddy PhoneBridge 手机数据桥

一个免费教程库：**各种手机 × 各种应用**的数据导出方法，全部免 root、只讲自己的设备自己的账号。

## 数据来源（按优先级）

1. **在线站点**（完整版，多页 SEO）：https://b1f884fbf01f443d9e99f3d71dad32c6.gz4.agentos-app.net
   - `brand/<品牌>.html`：各品牌开启 USB 调试教程（含品牌特有坑与 FAQ）
   - `app/<应用>.html`：各应用数据导出教程（元宝/微信/ADB）
   - `about.html` / `legal.html`：安全隐私与版权声明
2. **本地数据**（随包提供）：`js/data.js` 含全部品牌/应用结构化数据；若电脑配了 phone-mirror 连接器，可读取 `~/PhoneMirror/` 已导入的手机数据。

## 执行步骤

1. 确认用户的**手机品牌**（未说则让用户选：小米/红米、华为/荣耀、OPPO/一加、vivo/iQOO、三星、其他）
2. 从站点对应品牌页（或 data.js）取该品牌步骤，按用户需求输出：
   - 开启开发者模式路径
   - 打开 USB 调试路径
   - 品牌特有坑（如小米需「USB 调试（安全设置）」+ 登录小米账号；三星需装 USB 驱动）
3. 用户想导出某应用数据（元宝 / 微信 / ADB 抓屏）→ 给对应应用页步骤
4. 输出要求：**小白友好**——用「点哪 → 点哪 → 点哪」路径条，不用黑话；结尾附「卡住了」FAQ；提示先备份数据

## 使用示例

- 用户：「红米 K80 Pro 怎么连电脑传数据？」→ 输出开发者模式 → USB 调试 →（抓屏需安全设置）三步
- 用户：「元宝 AI 聊天记录怎么导出？」→ 网页版导出两种方式 + 官方转为文档
- 用户：「我想备份微信聊天记录」→ 微信电脑版备份与迁移步骤
