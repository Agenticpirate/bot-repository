# Horoscope Skill

星座运势、性格分析、配对查询工具，集成 ohmanda API 和 taibu MCP。

## 功能

### 1. 每日运势查询

调用 ohmanda API 获取实时运势数据。

**使用方式：**
```bash
python scripts/daily_horoscope.py <星座名>
```

**支持输入：**
- 英文：`aries`, `leo`, `pisces`
- 中文：`白羊座`, `狮子座`, `双鱼座`
- 别名：`白羊`, `狮子`, `双鱼`

**输出格式：**
```
♌ 狮子座今日运势（2026-07-29）

Cutting corners won't get you very far, dearest Leo...
```

### 2. 星座性格分析

读取本地 `data/personalities.json` 获取性格详解。

**使用方式：**
```bash
python scripts/zodiac_sign.py <日期>
```

**支持日期格式：**
- `3-15`, `7/29`
- `1990-05-15`, `1990/05/15`
- `12月25日`

**输出格式：**
```
♓ 🐟 双鱼座

📅 日期范围：2/19 - 3/20
🔥 元素：水象 | 性质：变动
🪐 守护星：海王星

🔢 幸运数字：3, 9, 12, 15, 18
🎨 幸运颜色：淡紫色, 海蓝色
💎 幸运宝石：海蓝宝石
📅 幸运日：周四
```

### 3. 星座配对

读取本地 `data/compatibility.json` 获取配对分析。

**使用方式：**
```bash
python scripts/compatibility.py <星座1> <星座2>
```

**输出格式：**
```
♈ × ♌ 白羊座 × 狮子座

契合度：⭐⭐⭐⭐⭐⭐⭐⭐☆☆ (8/10)

火象组合，激情满满，互相理解

✅ 优势：
  • 互相理解
  • 共同冒险
  • 坦诚沟通
  • 充满活力

⚠️ 冲突：
  • 都不让步
  • 竞争意识强
  • 容易争吵
  • 缺乏耐心

💡 建议：
需要一个人先学会退让，给彼此空间，避免正面冲突
```

### 4. 中国传统命理（taibu MCP）

taibu 提供 15 个命理工具，通过 MCP 协议调用：

| 工具 | 功能 | 示例提问 |
|------|------|----------|
| `bazi` | 八字排盘 | "我是1990年5月15日15点生，请帮我排盘" |
| `ziwei` | 紫微斗数 | "我是农历1990年4月初八生，请排紫微盘" |
| `ziwei_horoscope` | 紫微运限 | "帮我看看2026年的紫微运限" |
| `liuyao` | 六爻占卜 | "我想占卜今年的事业运" |
| `meihua` | 梅花易数 | "用梅花易数看这次合作能不能成" |
| `tarot` | 塔罗抽牌 | "请为我抽一张塔罗牌，关于近期的爱情运势" |
| `almanac` | 黄历查询 | "今天的黄历怎么样？适合求婚吗？" |
| `astrology` | 西方占星 | "帮我看一下这段时间的占星流运重点" |
| `qimen` | 奇门遁甲 | "用奇门看一下今天谈合作是否顺利" |

**调用方式：**
在对话中直接提问，牛牛会自动调用 taibu MCP 工具。

## 数据文件

| 文件 | 内容 |
|------|------|
| `data/zodiac_info.json` | 12 星座基础信息（符号、元素、守护星、幸运数字等） |
| `data/personalities.json` | 12 星座性格详解（核心特质、优缺点、职业、恋爱等） |
| `data/compatibility.json` | 10 种元素组合配对（火火、火土、火风等） |

## 错误处理

如果 ohmanda API 不可用：
1. 告知用户 API 暂时不可用
2. 建议用户稍后重试
3. 可以用 LLM 知识生成运势（需明确告知是 AI 生成，非实时数据）

## 使用示例

**用户：** "帮我查一下狮子座今天的运势"
**牛牛：** 调用 `daily_horoscope.py`，返回运势内容

**用户：** "白羊座和狮子座配不配？"
**牛牛：** 调用 `compatibility.py`，返回配对分析

**用户：** "我是1990年5月15日生，什么星座？"
**牛牛：** 调用 `zodiac_sign.py`，返回星座信息

**用户：** "帮我排个八字"
**牛牛：** 调用 taibu bazi 工具
