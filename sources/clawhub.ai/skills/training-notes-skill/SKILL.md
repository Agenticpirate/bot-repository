# 培训纪要结构化（training-notes-skill）

> 基于官方「腾讯会议 Skill（tmeet）」二创 · 赛事主题「让开会更简单」

培训会议动辄一小时起步，转写稿几千字，新人根本看不进去。本 Skill 把转写稿重构成**可速读的章节手册 + 可自测的题库**，让一次培训产生可复用的知识资产。

## 一、能力边界

- 单向依赖 **腾讯会议 Skill（tmeet）**：拉取培训会议的录制/智能纪要/转写。
- 本地模式：`training_minutes.py` 直接处理本地转写/纪要素材，零依赖。

## 二、触发场景

- 用户说「把这场产品培训整理成手册」
- 用户说「根据培训转写生成自测题」
- 用户说「培训材料结构化，方便新人看」

## 三、标准工作流

1. 通过 tmeet 拉取培训会议的智能纪要 / 转写。
2. 按原始议程或语义切分**章节**。
3. 每章提炼**要点**（关键概念、操作步骤、易错点）。
4. 基于要点生成 **2-3 道自测题**（选择题/简答题），便于培训后检验。
5. 组装为带目录的培训手册（Markdown）。

## 四、与 tmeet 的对接指令（给 Agent）

- 拉取转写：`tmeet 录制管理 列表/转写 <会议ID>`
- 拉取纪要：`tmeet 录制管理 智能纪要 <会议ID>`

> 若环境未安装 tmeet，直接读取用户提供的转写/纪要文件，走本地模式。

## 五、输出结构（培训手册）

```markdown
# {培训主题} 培训手册
## 目录
## 第一章 {章节名}
### 要点
- ...
### 自测题
1. （简答）...
## 第二章 ...
```

## 六、示例

> 用户：把这场后端规范培训转写做成手册，附自测题。
>
> 助手：拉取 tmeet 转写 → 切 3 章 → 每章要点 + 2 题 → 输出《后端规范培训手册》。

## 七、注意事项与局限

- 自测题为**基于要点的启发式生成**，用于复习引导，非标准考卷；正式考核请人工审校。
- 章节切分依赖纪要中的标题/议程信号；纯流水转写时按时间或话题段落近似切分。
- 涉及内部资料请注意权限与合规。
