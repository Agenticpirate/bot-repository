## 除法取余规则

- 除以8取余数，余1~7对应先天数
- **余0 → 作8**（整除时视为余8）
- 除以6取动爻，**余0 → 作6**

## 标准解读流程

### 第一步：确认起卦信息

| 输入形式 | 对应起卦法 |
|---------|-----------|
| 农历年月日时 | 时间起卦法 |
| 两个数字 | 数字起卦法 |
| 汉字/文字 | 字画起卦法 |
| 已有卦象（如"地天泰"） | 直接解读 |
| 姓名+出生时间 | 命卦流程（读 `birth_chart.md`） |

> ⚠️ 旺相分析需要知道当前农历月份。

### 第二步：时间起卦法

```
年支数 = 地支序数（子1 丑2 寅3 卯4 辰5 巳6 午7 未8 申9 酉10 戌11 亥12）
上卦  = (年支数 + 月 + 日) ÷ 8 → 取余数（余0作8）
下卦  = (年支数 + 月 + 日 + 时辰数) ÷ 8 → 取余数（余0作8）
动爻  = (年支数 + 月 + 日 + 时辰数) ÷ 6 → 取余数（余0作6）
```

> ⚠️ 下卦与动爻都用**年+月+日+时辰**的**总和**，不是上卦数加时辰

**时辰数**：子1 丑2 寅3 卯4 辰5 巳6 午7 未8 申9 酉10 戌11 亥12

**输出格式**：
```
【起卦】年支X + 月X + 日X + 时辰X = 总和X
        上卦 ÷ 8 → 余X → X卦
        下卦 ÷ 8 → 余X → X卦
        动爻 ÷ 6 → 余X → 第X爻
【主卦】䷊ 地天泰
【变卦】䷋ 天地否
```

### 第二步附：多种起卦方法

梅花易数以"观象"立宗，除时间法外，另有五种常用起卦法，适用于不同场景。

#### 1. 数字起卦法
**触发**：用户提供两个数字（可任意指定，如年龄、门牌、手机尾号等）
```
上卦  = 数字1 ÷ 8 → 取余数（余0作8）
下卦  = 数字2 ÷ 8 → 取余数（余0作8）
动爻  = (数字1 + 数字2) ÷ 6 → 取余数（余0作6）
```
**输出格式**：
```
【数字起卦】数字1=X，数字2=Y，总和=X+Y
上卦：X÷8余→X卦
下卦：Y÷8余→Y卦
动爻：(X+Y)÷6余→第X爻动
```

#### 2. 字画起卦法
**触发**：用户提供一个或多个汉字（单字/词语/句子均可）
```
总笔画 = 上汉字总笔画 + 下汉字总笔画（如两个字，上字为上卦，下字为下卦）
       = 第一个字的笔画数（主卦上卦）
       + 第二个字的笔画数（主卦下卦）
       + [若有更多字则累计]
上卦  = 主卦上卦笔画数 ÷ 8 → 取余数
下卦  = 主卦下卦笔画数 ÷ 8 → 取余数
动爻  = 总笔画 ÷ 6 → 取余数
```
**笔画数说明**：以康熙字典笔画为准。常见字笔画：
- 单笔划：横1、竖2、撇3、点4、折5（乙）
- 示例："测"字17画，"字"6画 → 上卦17÷8余1→乾，下卦6÷8余6→坎

#### 3. 方位起卦法
**触发**：用户描述方位（如"看东方"、"西北角"）
```
上卦  = 方位先天数 ÷ 8 → 取余数（余0作8）
        方位先天数：乾9 兑4 离3 震4 巽5 坎6 艮7 坤2
下卦  = 时辰数 ÷ 8 → 取余数（余0作8）
动爻  = (方位先天数 + 时辰数) ÷ 6 → 取余数
```
**方位先天数（文王后天方位数）**：
```
  离南（3）
坤西南（2）  兑西（4）
  巽东南（5）  乾西北（9）
  坎北（6）
  震东（4）  艮东北（7）  坤（2）
```

#### 4. 来人方位起卦法
**触发**：来人进门时，心中默记其方位和时间
```
上卦  = 来人方位先天数 ÷ 8 → 取余数
下卦  = 年支数 + 月 + 日 + 时辰数（总和） ÷ 8 → 取余数
动爻  = (上卦方位数 + 下卦总和) ÷ 6 → 取余数
```

#### 5. 物象起卦法
**触发**：用户看到某物（如鸟叫、玻璃破碎、行人衣着颜色等）
```
上卦  = 物象所属先天数 ÷ 8 → 取余数
        物象归类：乾为圆/马/金玉；兑为少女/羊/口舌；
        离为火/雉/目；震为雷/龙/足；巽为风/鸡/股；
        坎为水/猪/耳；艮为山/狗/手；坤为地/牛/腹
下卦  = 时间总数 ÷ 8 → 取余数
动爻  = (物象数 + 时间数) ÷ 6 → 取余数
```

#### 6. 声音起卦法
**触发**：用户听到声音（汽车喇叭、门铃、鸟鸣等）
```
上卦  = 声音数（如次数或持续秒数）÷ 8 → 取余数
下卦  = 时间总数 ÷ 8 → 取余数
动爻  = (声音数 + 时间数) ÷ 6 → 取余数
```

#### 起卦方法汇总

| 起卦法 | 上卦来源 | 下卦来源 | 动爻来源 | 触发词 |
|-------|---------|---------|---------|--------|
| 时间法 | 年+月+日÷8 | 年+月+日+时÷8 | 总和÷6 | "起卦" "算一卦" |
| 数字法 | 数字1÷8 | 数字2÷8 | 两数÷6 | "数字起卦" "数字算" |
| 字画法 | 上字笔画÷8 | 下字笔画÷8 | 总笔画÷6 | "字画起卦" "这个字" |
| 方位法 | 方位先天数÷8 | 时辰数÷8 | 两数÷6 | "方位起卦" "看这个方位" |
| 来人法 | 来人方位÷8 | 时间总和÷8 | 两数÷6 | "来人起卦" |
| 物象法 | 物象分类÷8 | 时间总数÷8 | 两数÷6 | "物象起卦" "看到X" |
| 声音法 | 声音数÷8 | 时间总数÷8 | 两数÷6 | "声音起卦" "听到" |

> 💡 **选法原则**：时间法最通用；数字法适合指定问题；字画法适合文字相关；方位法适合风水环境；来人/物象/声音法适合现场感应。选择后统一走标准解读流程（第三步至第七步）。

> 💡 **近事取近期（1-10日），远事取远期（1-6月），终身大事看年运**

#### 维度二：卦气旺衰定应期

| 卦气状态 | 应期倾向 | 说明 |
|---------|---------|------|

| 卦气平和 | 应期中和 | 正常周期内应验 |

#### 维度三：卦象组合定细节

| 卦象特征 | 应期提示 |
|---------|---------|

| 体卦当令 | 近期应验 |
| 用卦休囚 | 事情迟缓 |

1. **先看动爻数**（取周期）
2. **再看卦气旺衰**（定早晚）
3. **最后看变卦生克**（定吉凶应期）
