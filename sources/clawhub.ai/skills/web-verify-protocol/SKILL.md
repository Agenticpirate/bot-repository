# 三轮联网搜索验证协议

## Purpose

让"AI 联网搜出来的数据"达到可发布、可引用的可信度。核心机制：
单次搜索只能抓住约 70% 的错误，第二轮到 90%，三轮独立验证接近 100%。
这不是建议，是**结构性门槛**——不满足就禁止输出。

## When to Use

- 文章/公众号要引用具体数字（营收、出货量、市占率、价格）
- 用户提供爆料/新闻要点，需要联网核实真伪
- 商业分析、研报拆解要区分可信来源
- 任何"AI 出数据"的任务，用户强调"数据要可靠"
- 信息图、PPT、公开分享中的关键数据点

## 核心流程

### Phase 0: 信源分级（Pass 1 — Source Grading）

动手搜索前，先明确信源等级标准：

| 级 | 示例 | 可靠性 | 规则 |
|----|------|--------|------|
| S | 公司官网公告、招股书、监管文件、央媒首发（新华社/中新社）、政府白皮书 | 最高 | 可作主要来源 |
| A | 证券时报/中证报/上证报/第一财经、IDC/高工等权威第三方 | 高 | 必须与至少 1 个 S 或 A 交叉验证 |
| B | 36Kr/虎嗅/界面/凤凰科技/甲子光年/每经 | 中 | 必须与至少 1 个 S 或 A 交叉验证 |
| C | 自媒体号/头条/公众号/小红书/微博 | 低 | 永不作唯一来源；须 S 或 A 独立确认 |

### Phase 1: 三轮硬性核实（STRUCTURAL GATE）

#### Round 1 — 新角度搜索，S 级升级（最少 3 次 WebSearch）

目标不是复查已找到的，而是找**更好的来源**。

硬性下限：
- 至少 3 次独立 WebSearch，每次不同角度
- 至少 1 次针对 S 级来源（公司公告/新华社/政府文件/gov.cn）
- 结果：所有数据点达到 S 或 A 级；卡在 B 级的标记 ⚠️ 未验证

R1 能抓住：媒体转述错误、指标不准、公司归属错误、过时数据当最新。

#### Round 2 — 独立交叉验证（最少 3 次 WebSearch）

拿 R1 验证过的数据，找**第二个独立来源**确认或反驳。

硬性下限：
- 至少 3 次独立 WebSearch
- 至少 1 次针对事实争议（"[claim] + 核实" 或 "[claim] + correction"）
- 结果：每个商业指标至少 2 个独立 S/A 来源确认；单源指标标注"单源确认，待交叉验证"

R2 能抓住：媒体互相引用的连锁错误、老数据被当新的、区域数据被当成全国。

#### Round 3 — 叙事数字审查（最少 2 次 WebSearch）

只针对"讲故事的数字"：百分比提升、X 倍、前后对比、最高级、任何"太整齐"的数字。

硬性下限：
- 至少 2 次独立 WebSearch
- 每次针对数据表里**具体某一个**叙事数字（不是泛泛的选题搜索）
- 结果：每个叙事说法有 S 或 A 来源；来自 B/C 的要么换成 S 级替代、要么明确标注来源并标 ⚠️

R3 能抓住：B 级白皮书/分析报告里被 S 级公司/政府数据打脸的夸张数字。

### Phase 2: ⛔ 阻塞门 — 输出前必须打印核实报告

**在写任何输出文件之前**，必须在对话中打印以下报告（这是用户验证"三轮真的跑了"的唯一方式）：

```
══════════ 三轮核实报告 ══════════
R1 S级升级: {N}次搜索, {M}个数据点从B升到S/A, {K}个仍为⚠️单源
R2 交叉验证: {N}次搜索, {M}个指标≥2源确认, {K}处修正
R3 叙事审查: {N}次搜索, {M}个叙事数字审查, {K}个替换/降级
结论: ✅ 通过 / ❌ 需补充{R1/R2/R3}
═══════════════════════════════
```

任一轮次数不足，或 R3 有未解决的叙事说法 → **门未通过**，补齐再验。

### Phase 3: 输出最终验证版

门通过后，交付的文件是**最终验证版**，不是草稿。数据点标注来源级别。

## 冲突解决规则（Pass 3）

1. 同数据多来源冲突 → S > A > B > C，公司自己的公告优先于媒体转述
2. 新旧冲突 → 新报道通常修正旧错误，用新的
3. 双方都可信但数据不同 → 用高级别来源 + 加注："注：另有报道称[不同数据]，本文以[来源]为准"
4. 无法解决 → 降级为"据XX报道"并显式标注 ⚠️

## 触发重新核实的红旗

- 任何最高级说法（"全球首次""唯一""最大"）没有 S 级来源
- 过于整齐的整数（100、1000、10000），常是四舍五入或估算
- 数据来源是"业内人士""据透露"且无具名
- 两个 B 级媒体对同一数据差异明显
- 需要访问非公开数据才能得到的统计（如精确的竞品出货量）

## 适用场景扩展

| 场景 | 怎么用 |
|------|--------|
| 公众号文章引用数字 | 三轮核实后再写，防止"据XX报道"翻车 |
| 爆料核实 | 用户给要点 → R1 查证 → R2 找矛盾 → R3 审叙事 |
| 研报拆解 | 每页数据标注 S/A/B/C，关键指标双源确认 |
| 信息图/公开分享 | 只有 A 级以上的数据才能上图表 |
| 连麦内容提炼 | 金句和数字先过核实再发 |
