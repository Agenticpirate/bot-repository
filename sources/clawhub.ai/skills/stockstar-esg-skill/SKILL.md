# 证券之星 ESG 评级 Skill

```bash
PYTHON=python3.12
ESG=scripts/cli.py
```

通过自然语言查询上市公司 ESG 评级数据，数据来源证券之星，覆盖妙盈科技、华证指数、商道融绿三家机构。

## 适用场景

用户提到以下内容时触发本 Skill：

- **ESG 评级查询**："查一下XX的ESG评级"、"XX的ESG评分"、"XX的绿色金融评级"
- **ESG 详细评分**："XX的ESG详细数据"、"环境评分"、"社会责任评分"、"治理评分"
- **多股对比**："对比XX和YY的ESG"、"这几只股票ESG对比"
- **评级列表（辅助）**："华证评级最高的股票"、"妙盈评级列表"

## 核心约束

1. **数据真实性** — 禁止编造 ESG 评级数据，必须从真实的 API/网页返回中提取
2. **覆盖范围** — 同时支持 A 股（6位代码）和港股（5位代码）
3. **查询限制** — 单次查询 1 只股票，对比不超过 5 只，列表每页 20 条
4. **请求方式** — 使用 Python 脚本 `scripts/cli.py`（通过 `$PYTHON $ESG` 调用），统一加 `--json` 参数获取 JSON 输出
5. **输出格式** — 脚本输出 JSON，AI 负责组织语言呈现给用户，不直接输出 JSON 原文
6. **统一字段集** — 三家机构 JSON 输出返回 6 个相同字段（rate + date + E/S/G 评分），空字符串 `""` 表示不提供；detail 文本模式额外展示 E/S/G 评级字母和行业排名（仅华证有值）

## 脚本命令

优先调用 Python 脚本获取数据，统一加 `--json`：

```bash
$PYTHON $ESG search <keyword> --json           # 模糊搜索股票
$PYTHON $ESG query <stock_code> --json         # 个股综合评级
$PYTHON $ESG detail <stock_code> --json        # 个股详细评分
$PYTHON $ESG compare <code1> <code2> [code3...] --json # 多股对比
$PYTHON $ESG list --provider chindices --page 1 --json       # 评级列表（辅助功能）
```

脚本返回 JSON 后，AI 按场景组织语言，不要把整段 JSON 原样输出给用户。

## 工作流

### 流程 0（前置）：模糊搜索股票

当用户输入中文名或模糊代码时，先调用 `search` 确认股票身份。

**步骤：**
1. 调用 `$PYTHON $ESG search <keyword> --json`
2. 分析返回的候选列表：
   - 如果第一候选明显符合用户意图 → 直接取其代码，继续执行 query
   - 如果前几项都合理 → 把前 3 个候选简要列给用户确认
   - 如果无结果 → 告知用户未找到，建议更换关键词

**示例：**
```
用户：查一下腾讯的ESG
→ search "腾讯" → 候选：腾讯控股(00700)、腾讯音乐(TME)
→ 前 3 候选列给用户选择 → 用户选 00700 → query 00700
```

### 流程 1：查询单个股票 ESG 评级

```
用户输入 → 识别股票代码/名称 → 调用详情页 API → 解析数据 → 结构化输出
```

**步骤：**
1. 调用 `$PYTHON $ESG query <stock_code> --json`
2. 解析返回 JSON，提取每家机构的 rate（等级）和 date（日期）
3. 用中文向用户总结，至少展示：股票名称/代码、三家机构的 ESG 等级 + 日期

**输出要点：**
```
📊 贵州茅台 (600519) — ESG 评级
- 妙盈科技: A（2025-06-30）
- 华证指数: AAA（2026-04-30）
- 商道融绿: A（2026-03-15）
```

### 流程 2：查看个股 ESG 详细评分

**步骤：**
1. 调用 `$PYTHON $ESG detail <stock_code> --json`
2. 解析返回 JSON，三家机构字段集一致，按字段值有无判断可用性
3. 按机构分组展示

**输出要点：**
三家机构 JSON 返回相同的 6 个字段。AI 按以下规则读取：
- `rate` / `date` — 均有值，必展示
- `e_score` / `s_score` / `g_score` — 有值展示评分，空字符串跳过
优先总结关键发现（如"治理(G)评分最高"）。

### 流程 3：对比多只股票

**步骤：**
1. 调用 `$PYTHON $ESG compare <code1> <code2> [code3...] --json`
2. 解析返回 JSON，按股票分组对比
3. 以对比表格风格输出，避免混成一段

**输出格式示例：**
```
ESG 评级对比

| 股票 | 妙盈 | 华证 | 商道融绿 |
|------|------|------|---------|
| 贵州茅台 | A    | AAA  | A       |
| 五粮液  | BBB  | A    | A-      |
```

### 流程 4（辅助）：浏览评级列表

仅当用户明确要求按机构查看评级列表时使用，不主动推荐。

**步骤：**
1. 判断用户指定的评级机构（妙盈/华证/商道融绿），映射英文名：`miotech`/`chindices`/`syntaogf`
2. 调用 `$PYTHON $ESG list --provider <英文名> --page <N> --json`
3. 解析返回 JSON，列表形式展示股票名称、代码、ESG 等级
4. 提示用户可通过 `--page 2` 查看下一页

## 异常处理

| 异常 | 处理方式 |
|------|---------|
| 股票代码不存在 | 页面返回 404 或内容异常，提示用户检查股票代码 |
| 网络超时 | 提示用户稍后重试 |
| 无搜索结果 | 提示用户更换关键词或检查股票代码 |
| 超过对比数量 | 提示用户每次最多对比 5 只股票 |
