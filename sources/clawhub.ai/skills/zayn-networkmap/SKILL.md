# NETWORKMAP() 公开关系研究

建立有证据的行业关系，不追求无边界的公司数量，不把公开同场关系升级为销售判断。

## 确认范围

研究前先检查用户提供或已连接的 Obsidian、Excel、CSV、邮件、聊天、询价、报价、订单、付款、发货、售后、历史报告和人工备注。优先复用强证据，再补充公开检索。

确认以下输入：

1. 研究模式：行业与展会、行业与协会、公司与近期活动
2. 明确的行业和产品边界
3. 国家、地区或目标市场
4. 时间范围
5. 目标实体的唯一身份；公司模式下包括官网、别名和本地语言名称
6. 期望结果数量，以及需要完整目录还是高价值公开子集
7. 需要识别的参与角色和用户已有资料

用户未指定时，公司近期活动默认覆盖过去 24 个月；周期性展会默认覆盖最近两个已完成或已正式公布的相关届次；首轮只研究 5 至 10 个高价值展会或组织。活动不是每年举办时，按实际届次处理，不机械套用 24 个月。

## 消除跨行业歧义

公司可能横跨多个明显不同的行业时，依次依据真实业务记录与人工判断、客户记录和沟通材料、公司官网产品及解决方案、公司官方新闻与活动、其他可信公开资料判断。不得仅凭公司名称、搜索摘要、行业标签或模型常识确定行业。

如果行业选择会明显改变展会、协会或活动结果，在扩展研究前停止，并提供二至四个最相关选项。每个选项说明行业名称、关联依据、包含范围和明确排除的相邻业务；推荐一个选项并说明理由，但等待用户最终确认。

仅当用户已明确行业、产品或业务范围足够清晰，或真实业务记录能证明范围且没有实质歧义时直接继续。结果开头仍要声明采用的行业口径和排除范围。不得用“综合科技”“综合 IT”等宽泛标签绕过确认，不得混合公司的全部业务。

## 执行研究模式

### 行业与展会

识别目标行业和地区内较有影响力的展会，并核对最近两个相关届次。使用主办方权威性、连续举办情况、公开规模、行业覆盖和业内引用等公开指标解释影响力，不依赖模型印象。

记录展会名称、地区、届次、日期、行业相关性、影响力依据、参展公司及明确角色、来源与访问日期、名单完整度、未确认事项和访问限制。

### 行业与协会

识别主要协会或行业组织，说明覆盖地区、行业定位、相关性和影响力依据。优先使用协会官方会员目录确认会员，并记录会员对应年份或访问日期。

不得因公司出现在协会新闻、合作内容或活动页面而推断会员身份。没有官方会员目录或其他足够强的证据时标记待核验。

### 公司与近期活动

查找目标公司参加的展会、会议、峰会、论坛、赞助或其他行业活动，记录活动名称、日期、地点、类型、目标公司角色与证据，以及同场公司的名称、角色和关系证据。

严格区分参展商、赞助商、演讲者、合作伙伴、获奖者、普通参会者和仅被提及者。证据不能确定角色时标记“角色未确认”，不得笼统写成“参加活动”。

## 使用证据

按以下等级判断来源：

1. A 级：展会官方参展商目录、协会官方会员目录、活动官方议程、官方参会公司目录或官方演讲者页面；可确认明确关系和角色
2. B 级：公司官网新闻、公司或主办方官方社交账号、主办方正式公告；可确认参与，但必须准确记录角色
3. C 级：官方展馆地图、官方会议手册或 PDF、官方赞助商或合作伙伴页面；用于辅助确认身份、角色和届次
4. D 级：媒体报道、第三方活动汇总页、LinkedIn 帖子和搜索摘要；仅作线索，没有更强证据时标记待核验
5. E 级：模型推测、行业相似性和无来源常识；不得进入确认名单

打开原始页面核对实体、日期、届次和角色，不把搜索摘要作为最终证据。研究非英语市场时，组合当地语言、英语、法定名称、品牌名和常见转写提高召回，但最终证据仍须满足上述标准。

若官方来源需要登录、网页脚本无法访问或只公开部分名单，如实说明。不得绕过访问限制，不承诺完整抓取。证据缺失的字段可留空或标记未确认；与人工判断冲突时保留双方信息并提示复核，不覆盖原始材料。

## 标记名单完整度

每份公司名单只能使用以下一种标签：

1. `完整官方目录`：有充分依据覆盖该届次或目录的全部公开对象
2. `官方公开子集`：来源官方，但只公开部分对象
3. `多来源重建名单`：合并多个证据来源，不保证完整
4. `搜索发现线索`：仅供后续核验，不是确认名单

不得把搜索到的公司描述为全部参展商或全部会员。

## 输出结果

先给简洁结论和本次行业边界，再给证据表。证据表使用以下字段：

| 字段 | 内容 |
| --- | --- |
| 实体名称 | 官方名称；必要时保留当地语言名称 |
| 实体类型 | 展会、协会、活动或公司 |
| 关系类型 | 参展、会员、赞助、演讲、合作或其他明确角色 |
| 行业口径 | 本次确认的行业范围 |
| 地区 | 国家、地区或城市 |
| 届次或日期 | 年份；能确认时记录具体日期 |
| 证据来源 | 原始页面标题和链接 |
| 来源等级 | A、B、C、D 或 E |
| 名单完整度 | 使用规定标签 |
| 状态 | 已确认、待核验、存在冲突或未确认 |
| 备注 | 限制、排除项和必要解释 |

明确区分事实、合理判断和待核验线索。所有来源记录访问日期。同场出现、会员或参展身份只代表公开关系，不代表采购意愿、客户价值或销售优先级。

## 停止研究

遇到以下情况时先确认或停止：

1. 行业口径过宽或存在多个合理方向
2. 公司身份不唯一
3. 地区会实质改变结果但用户未指定
4. 时间范围会实质改变结果且默认值不适用
5. 只能找到搜索摘要或低强度线索
6. 用户要求完整名单但来源仅公开部分对象
7. 查询范围明显偏离最初目标

停止时说明已经确认的范围、缺失信息、访问或证据限制，以及继续研究所需的最小补充。不要为填满字段而无限扩展查询。
