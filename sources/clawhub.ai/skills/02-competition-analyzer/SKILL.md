# 竞品深度分析器

> 产品开发全链路 Skill #2 · 知己知彼，找到你的差异化空间

## 功能

系统化扫描和分析竞品，帮你找到产品的差异化定位和竞争壁垒。

## 核心工作流

### Step 1：竞品扫描

搜索并列出至少 5 个竞品，分三类：
- **直接竞品**：解决同样问题、面向同样人群
- **间接竞品**：解决同样问题但不同人群/方式
- **潜在竞品**：可能进入这个赛道的玩家

**输出**：竞品全景地图

### Step 2：竞品多维拆解

对每个竞品，按以下维度分析：

| 维度 | 说明 |
|------|------|
| 产品定位 | 一句话说清楚这个产品 |
| 目标用户 | 核心用户画像 |
| 核心功能 | 主要功能列表 |
| 定价策略 | 免费/付费/订阅/按量 |
| 用户规模 | 估算的 MAU/DAU |
| 技术方案 | 自研/外包/开源 |
| 数据壁垒 | 是否有独特数据资产 |
| 核心优势 | 用户为什么选它 |
| 核心弱点 | 用户为什么吐槽它 |

### Step 3：差异化定位

基于竞品分析，找出你的差异化空间：

1. **竞品覆盖不足**：竞品没做好的功能
2. **竞品价格空白**：价格带的空白区间
3. **竞品用户盲区**：竞品忽视的用户群
4. **技术代差**：能否用新技术降维打击

**输出**：差异化定位矩阵（竞品 vs 你）

### Step 4：壁垒评估

评估各竞品的可复制性：
- 功能壁垒：1-3个月可复制
- 数据壁垒：6-12个月可复制
- 品牌壁垒：12-24个月可复制
- 网络效应：24个月以上不可复制

**输出**：竞争壁垒分级报告

## 输出格式

- 最终交付物：Markdown 竞品分析报告
- 命名规范：`{产品名}-竞品分析报告.md`

## 硬约束

1. 至少分析 5 个竞品，不能少于 3 个
2. 每个竞品的信息必须标注来源
3. 如果竞品定价信息不公开，注明"估算"
4. 不能只说竞品缺点，也要客观分析竞品优势
5. 差异化定位必须有数据支撑
