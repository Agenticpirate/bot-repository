# Activity Planner - 活动策划方案生成器

## Overview

根据活动基本信息，自动生成结构完整、可落地执行的活动策划方案。覆盖从策略定位到效果评估的全流程，输出为专业 HTML 报告。

## Workflow

### Step 1: 信息收集

主动向用户收集以下活动要素（未提供的逐项询问，已提供的不重复问）：

| 要素 | 说明 | 必填 |
|------|------|------|
| 活动类型 | 新品发布/年会/快闪店/促销/社群活动/展会参展/其他 | 是 |
| 活动目标 | 品牌曝光/获客转化/用户激活/客户答谢/销售促进 | 是 |
| 目标人群 | 人群画像（年龄、职业、兴趣等） | 是 |
| 预算范围 | 总预算区间 | 是 |
| 活动时间 | 具体日期或时间段 | 是 |
| 活动地点 | 线上/线下（城市+场地类型） | 是 |
| 参与人数 | 预计参与规模 | 否 |
| 品牌调性 | 专业/活泼/高端/亲民/科技感等 | 否 |
| 特殊要求 | 其他约束条件 | 否 |

询问技巧：一次性列出所有缺失要素，不要逐条追问。用户给出部分信息时，对缺失的必填项进行一次性补问。

### Step 2: 策略定位

基于收集到的信息，完成策略分析：

1. **活动定位**：明确活动在品牌/业务中的角色（拉新？促活？转化？品牌建设？）
2. **核心目标量化**：将模糊目标转化为可量化指标（如：获客200人、曝光10万+、转化率15%）
3. **受众洞察**：分析目标人群的决策动机和参与驱动力
4. **竞品/同类参考**：简要分析同类活动的常见做法和可差异化点

### Step 3: 创意概念

生成活动主题和创意方向：

1. **活动主题**：提供 2-3 个主题方向供选择，每个主题包含：
   - 主题名称（简短有记忆点）
   - 主题阐释（一句话说明核心理念）
   - 适合理由（为什么适合这个活动）
2. **视觉方向建议**：色彩、风格、关键视觉元素的方向描述
3. **互动创意**：2-3 个能增强参与感的互动环节设计

### Step 4: 方案生成

生成完整的活动策划方案，包含以下模块：

#### 4.1 活动概述
- 活动名称、主题、时间、地点、规模、目标

#### 4.2 活动流程设计
- 活动前（预热期）：时间线、动作、渠道
- 活动中（执行期）：详细流程时间表（精确到分钟），包含每个环节的负责人、时长、内容
- 活动后（延续期）：跟进动作、内容二次传播

#### 4.3 预算分配
- 参照 `references/budget_guide.md` 中的预算分配比例
- 按类别列出预算明细（场地、物料、人员、宣传、餐饮、杂项、机动）
- 提供预算总表

#### 4.4 宣传推广计划
- 预热期：渠道选择、内容规划、节奏安排
- 活动期：现场传播设计（拍照点、话题、直播等）
- 延续期：内容二次利用、用户UGC引导

#### 4.5 物料文案生成

针对活动全生命周期生成可直接使用的文案内容，参照 `references/copywriting_templates.md` 中的模板。

- **邀请函文案**：正式版 + 轻松版，适配邮件/微信/短信三种渠道
- **预热海报文案**：主标题 + 副标题 + 行动号召，提供 3 版供选择
- **社交媒体文案**：
  - 朋友圈/微信群：预热期3条、活动当天2条、延续期2条，每条含文案+配图建议
  - 公众号推文：标题3选1 + 正文结构框架 + 引导关注话术
  - 小红书/抖音：种草文案 + 话题标签组合
- **现场物料文案**：签到板文字、展板内容、易拉宝文案、导视牌文字
- **短视频脚本**：预热短视频脚本（15-30秒）+ 活动回顾脚本（30-60秒），含分镜描述
- **话术脚本**：参照 `references/script_templates.md`，包含以下场景
  - 邀约话术：电话邀约、微信邀约、邮件邀约（含跟进催访话术）
  - 现场话术：主持串词、签到引导话术、体验引导话术、销售转化话术
  - 客服话术：常见问题应答（FAQ 5-8条）、投诉处理话术
  - 活动后话术：感谢回访话术、满意度调查话术、二次转化话术

文案要求：
- 每条文案标注适用渠道和发布时间节点
- 话术脚本标注使用场景和使用人
- 文案风格与品牌调性保持一致
- 提供 A/B 测试备选方案（关键文案提供2版）

#### 4.6 推广过程监控

设计推广过程的实时监控和动态优化机制，参照 `references/promotion_monitor.md`。

- **监控指标体系**：
  - 曝光层：各渠道展示量、触达人数、CPM
  - 互动层：点击率、互动率、转发量、CPE
  - 转化层：报名人数、留资数、到店数、CPL/CPA
  - 每个指标设定目标值和预警阈值
- **数据回收频率**：
  - 预热期：每日回收，输出每日推广日报
  - 活动当天：每2小时回收一次关键数据
  - 延续期：每日回收转化数据
- **动态优化策略**：
  - 预算调拨规则：某渠道 CPA 低于均值 30% 则追加 20% 预算，高于均值 50% 则暂停
  - 内容优化规则：CTR 低于 1% 的素材 24 小时内替换
  - 节奏调整规则：预热第3天报名率不足目标 40% 则启动应急推广
- **每日推广日报模板**：包含各渠道数据、目标达成率、异常预警、次日优化建议
- **推广复盘报告模板**：活动结束后输出渠道效果对比、ROI 分析、优化建议

#### 4.7 人员分工
- 核心角色及职责（总协调、内容、设计、场务、宣传等）
- 人员需求清单

#### 4.8 风险预案
- 识别 3-5 个主要风险点
- 每个风险对应的预防措施和应急方案

#### 4.9 效果评估
- 量化 KPI 指标（参与人数、曝光量、转化率、满意度等）
- 数据回收方式
- 复盘时间节点

### Step 5: 输出方案

将完整方案输出为 HTML 文件，使用 `assets/plan_template.html` 作为基础模板。

输出要求：
- 文件保存到用户当前工作目录
- 文件名格式：`活动策划方案_活动名称_日期.html`
- HTML 包含目录导航、响应式布局、打印友好样式
- 预算表格用 HTML table 呈现
- 流程时间表用可视化时间线呈现
- 话术脚本用代码块或引用块呈现，标注使用场景
- 物料文案按渠道分区呈现，标注发布时间节点
- 推广监控用数据表格+预警色块呈现

## Notes

- 预算分配参照 `references/budget_guide.md`，根据实际预算规模调整比例
- 不同活动类型的策划要点参照 `references/activity_framework.md`
- 文案和话术模板参照 `references/copywriting_templates.md` 和 `references/script_templates.md`
- 推广监控指标和优化策略参照 `references/promotion_monitor.md`
- 方案必须可落地，避免空泛描述，每个环节给出具体动作和时间
- 话术和文案必须可直接复制使用，不留占位符（除非确实需要用户填写具体信息）
- 推广监控指标的目标值和预警阈值必须具体，不能泛泛而谈
- 如果用户预算极低（5000元以下），侧重低成本创意和线上传播，话术以微信/社群为主
- 如果用户预算充足（10万以上），增加专业制作、媒体投放等模块，话术增加媒体接待话术
- 方案生成后主动询问是否需要调整某个模块
