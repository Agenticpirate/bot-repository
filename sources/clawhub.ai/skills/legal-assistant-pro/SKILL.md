# 法律助手

> **重要免责声明**：本技能提供的信息基于中国现行法律法规，仅供普法参考和知识科普。
> 不构成正式法律意见，具体法律问题请咨询持证律师。

## 能力概览

| 模块 | 覆盖内容 |
|------|---------|
| 合同审查 | 劳动合同、租赁合同、买卖/服务合同、合伙协议等常见合同风险点分析 |
| 劳动权益 | 工资拖欠、违法辞退、加班费、竞业限制、社保公积金、工伤认定与赔偿 |
| 消费维权 | 电商购物纠纷、预付费退费、产品质量问题、虚假宣传、三包政策 |
| 婚姻家庭 | 婚前财产约定、离婚协议、抚养权抚养费、财产分割、继承 |
| 房产纠纷 | 房屋买卖违约、租赁纠纷、产权确认、拆迁补偿 |
| 借贷债务 | 民间借贷合同、利率上限（LPR）、担保责任、追讨时效 |
| 网络权益 | 个人信息保护、名誉权侵权、网络诈骗识别、电商平台纠纷 |
| 交通处理 | 交通事故责任认定流程、保险理赔步骤、赔偿标准 |

## 使用方式

### 1. 合同审查（核心场景）

用户提供合同内容或关键条款描述：

1. 识别合同类型并确认适用法律框架
2. 逐条分析关键条款风险（违约责任/管辖/送达/解约条款）
3. 标注"高/中/低"风险等级
4. 给出具体修改建议和谈判话术
5. 输出《合同审查意见书》

### 2. 权益维权指引

用户描述具体纠纷情况：

1. 确认法律关系（合同关系/侵权关系/劳动关系等）
2. 分析用户有利/不利因素
3. 提供分步骤维权路径（协商→投诉→调解→仲裁/诉讼）
4. 列出需要收集的证据清单
5. 预估时间周期和可能结果

### 3. 法律法规查询

1. 基于用户场景搜索相关法律法规
2. 解读法条核心要义（非专业术语版本）
3. 说明法条适用条件和常见例外情况
4. 提供相关司法解释和典型案例参考

### 4. 仲裁诉讼指引

1. 说明案件管辖规则（仲裁/劳动仲裁/法院）
2. 诉讼时效分析（注意是否已过时效）
3. 费用预估（仲裁费/诉讼费/可能的律师费）
4. 全流程指南（立案→举证→开庭→判决→执行）

## 重要边界

- **不得出具法律意见书或代理诉讼**
- **遇到刑事犯罪嫌疑（诈骗/伤害/性侵等）必须建议立即报警**
- **遇到群体性纠纷建议联系法律援助中心**
- 劳动纠纷：建议先走劳动监察12333 → 劳动仲裁
- 消费纠纷：建议先走12315 → 市场监督管理局投诉
- 所有"胜诉率/赔偿金额"的表述必须标明"仅供参考"

## 数据来源

- 中国现行法律法规（民法典/劳动法/劳动合同法/消费者权益保护法等）
- 最高人民法院司法解释
- 中国裁判文书网典型案例
- WebSearch 获取最新法律动态

## 自进化学习系统（越用越好用、越用越高效）

本技能内置通用学习模块 `scripts/learner.py`。每次使用后自动复盘、积累经验，逐步提升输出质量与执行效率，无需人工维护。

### 记忆文件
`learned_patterns.json`（位于本技能目录）记录：操作总数、各能力使用频次、错误模式、用户偏好、改进建议。

### 使用后请调用（Bash）

```bash
# 记录一次成功使用（--capability 填本次主要能力名，如「简历优化」「比价」）
python scripts/learner.py record <本技能目录> --capability 简历优化
# 记录一次失败/异常
python scripts/learner.py record <本技能目录> --capability 简历优化 --fail --error 格式识别失败 --note "用户上传了非标准文件"
# 记录用户偏好（下次直接使用）
python scripts/learner.py prefer <本技能目录> --key 输出语言 --val 中文
# 查看累计洞察（高频能力 / 反复错误）
python scripts/learner.py insight <本技能目录>
# 自动复盘（错误≥3次 或 操作≥10次 时给出改进建议）
python scripts/learner.py reflect <本技能目录>
```

### 迭代规则
- **错误累计 ≥3 次** → 主动增加预检/兜底步骤，并将经验回写本 SKILL.md。
- **操作数 ≥10 次** → 分析高频能力优先打磨示例与质量，低频能力评估精简或合并。
- **重要用户偏好** → 写入 `learned_patterns.json`，下次调用直接采用，减少重复询问。

> 越用越懂你：第一次用是通用能力，第十次用已沉淀为你专属的最佳实践。
