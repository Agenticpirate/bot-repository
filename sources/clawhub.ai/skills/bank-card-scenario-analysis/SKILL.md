# 银行卡场景化策略分析

## 核心分析框架

### 1. 场景筛选（值不值得做）

- 市场规模与增速
- 客群画像（年龄、性别、收入、城市线级）
- 消费频率与客单价
- 与银行现有客群的重叠度

### 2. 借记 vs 信用 × 守存量 vs 挖新客 四象限

| 维度 | 评估要素 |
|------|----------|
| 获客成本 | 借记低（零门槛）/ 信用高（需征信审批） |
| 权益成本 | 银联兜底 vs 银行自建 |
| 授信风险 | 借记无 / 信用有不良风险 |
| 合规难度 | 场景相关监管要求 |

**决策逻辑：**
- 借记×挖新客 = 甜点（零风险、沉淀AUM、低成本获客）
- 借记×守存量 = 次优（提粘性但无增量）
- 信用×守存量 = 陪跑（需测ARPU达标再开展）
- 信用×挖新客 = 不建议（征信弱客群坏账+获客双高）

### 3. 权益组合策略

**三层权益模型：**
1. **银联兜底层**：卡组织现成权益（保险、商户优惠、体检等），零增量成本
2. **银行特色层**：本地IP、区域商户、自建生态，差异化壁垒
3. **场景创新层**：联名、公益、社交裂变，拉新促活

### 4. 竞品对比维度

- 卡组织（银联/双品牌）
- 年费规则
- 核心跨境/场景优惠
- 境外/场景返现
- 专属权益
- 客群定位

### 5. 输出格式：一页纸

每个场景浓缩为一页纸，包含：
- 市场一句话
- 四象限推荐结论（★评级）
- 目标客群3类
- 权益组合（银联+特色）
- 差异化切入点2-3条
