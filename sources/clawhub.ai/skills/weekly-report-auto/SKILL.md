# 周报自动汇总技能执行规则

## 触发指令

用户输入：生成周报、汇总本周日报、整理本周工作、输出周总结、出本周工作总结，自动触发本技能。

## 文件读取规则（适配纯MD日报）

1. 固定读取路径：C:\Users\zsj\Desktop\WorkBuddyFile\第*周（如第一周、第二周、第三周、第四周等；日报均存放在对应周文件夹内，需递归扫描子目录）
2. **仅读取后缀为 .md 的 Markdown 日报文件，忽略所有 txt、docx、其他格式文件**
3. 自动扫描目录下全部MD文件，**只筛选本周日期创建/修改的日报**，自动过滤所有上周及过期旧日报
4. 完整读取所有本周MD日报全文，整合零散工作内容，**禁止逐条机械罗列单日流水账、禁止按天数罗列**

## 内容整理规范

1. 去重精简：合并本周每日重复工作内容，剔除无效琐碎记录、无意义细碎日常，只保留核心有效内容，**不按日期堆砌、不单日逐一介绍**，全局统一汇总整理。
2. 固定三分类 + **强制内部分点展示（核心修改）**
   全文内容只拆分为三大板块，**每个板块内部按具体事项清晰分1、2、3点罗列**：
   - 实操工作板块：将本周所有落地工作、业务操作、问题排查、进度对接、优化调整等内容，**按工作事项归类分点整理**，相同工作合并为一条，提炼成果、进度与现存问题。
   - 知识点学习板块：将本周所有学习的专业知识、技术要点、实操技巧、业务认知，**按知识点条目分点整理**（例如第一点CPU相关、第二点GPU相关、第三点系统配置等），逐条清晰呈现学习收获与掌握情况。
   - 个人反思板块：将所学的知识点和实操内容有什么值得改进的地方或者不足之处指出来，以便于下一步计划确定与实施。
3. 排版规则：**大模块为段落标题，模块内部严格分点展示**，结构清晰、事项分明，不杂乱、不流水。
4. 固定输出模块：全文只保留两大板块：**本周工作总结、下周工作计划**，无多余冗余模块。
5. 重点聚焦：弱化琐碎小事，突出核心工作进度、工作价值、成果收获、问题反思与知识沉淀。

## 文风硬性要求

1. 严禁使用首先、其次、最后、综上所述、总体而言等AI模板句式
2. 采用普通员工真实工作总结口吻，平实自然、接地气、无生硬机器感
3. 不虚构、不夸大、不编造内容，所有总结严格基于本地MD日报真实内容生成
4. **大模块标题段落化，内部内容条目化，事项清晰、分类明确**

## 输出结构

1. 本周工作总结
   整合本周全部工作与学习内容，分为三大类别、内部逐条分点展示：
   （1）实操工作汇总：合并本周所有落地工作事项，分点罗列核心工作内容、完成进度、工作成果、现存问题与优化方向，不区分日期、不重复堆砌。
   （2）知识点学习汇总：整合本周所有学习积累，分点罗列掌握的技术知识点、业务知识、实操技巧、认知提升，每条对应一个完整知识点维度，清晰规整。
   （3）个人反思部分：整合本周的每天日报的反思内容，以便于下一步计划确定与实施。
2. 下周工作计划
   结合本周未完成实操工作、常规业务推进需求，搭配本周知识点薄弱项、学习提升需求，**分点制定落地可行的下周工作安排与学习提升计划**。
