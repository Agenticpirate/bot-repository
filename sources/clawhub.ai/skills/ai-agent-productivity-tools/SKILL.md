# AI Agent Productivity Tools 📋

**5 essential business tools. Your agent sets them all up.** Installation guides for proven tools — your agent walks you through each setup in minutes.

## How to Use

```bash
clawhub install ai-agent-productivity-tools
```

Then ask your agent:

> "Set up my productivity tools"
> "Install gog for Google Workspace"
> "Walk me through Notion setup"

## What You Get

| Tool | What It Does |
|------|-------------|
| **gog** | Google Workspace CLI — email, calendar, docs, drive |
| **things-mac** | macOS task manager with projects and tags |
| **notion** | Flexible notes, databases, and wikis |
| **healthcheck** | One-command security scan |
| **vetter** | Quick skill quality checks |

Your agent handles installation, configuration, and authentication for each one.

## Requirements

- macOS or Linux
- Google Workspace account (for gog)
- macOS (for things-mac)

## Notes

- Knowledge pack — teaches your agent how to set up each tool
- No automated workflows, your agent does the work
- Each tool has exact install commands for your OS
