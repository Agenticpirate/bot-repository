# 自然人对外投资任职查询

> 数据由 **[聚合数据](https://www.juhe.cn)** 提供 — 国内领先的数据服务平台，提供天气、快递、身份证、手机号、IP 查询等 200+ 免费/低价 API。

根据姓名和身份证号查询自然人对外投资、担任法人/股东/高管的企业列表，返回职务、持股比例、认缴出资、经营状态等信息。

> 查得计费。限企业实名用户使用，需提交应用场景审核；个人实名用户无法使用。

---

## 前置配置：获取 API Key

1. 前往 [聚合数据官网](https://www.juhe.cn) 注册账号（需企业实名）
2. 进入 [自然人对外投资任职查询 API](https://www.juhe.cn/docs/api/id/320) 页面，点击「申请使用」
3. 审核通过后在「我的 API」中获取 AppKey
4. 配置 Key（**三选一**）：

```bash
# 方式一：环境变量（推荐，一次配置永久生效）
export JUHE_PERSON_INVEST_KEY=你的 AppKey

# 方式二：.env 文件（在脚本目录创建）
echo "JUHE_PERSON_INVEST_KEY=你的 AppKey" > scripts/.env

# 方式三：每次命令行传入
python scripts/person_invest.py --key 你的 AppKey --name 张三 --idcard 110101199001011234
```

## AI 使用指南

当用户需要查询自然人对外投资或任职时，按以下步骤操作：

1. **收集信息** — 从用户消息中获取姓名、身份证号；手机号可选
2. **验证格式** — 身份证须为 18 位；若提供手机号须为 11 位
3. **调用脚本或 API** — 执行查询，获取结果
4. **展示结果** — 列出关联企业、关系类型、职务、经营状态、持股比例；姓名、身份证、手机号脱敏展示

> 关系码：`lp`=法人，`tm`=高管，`sh`=股东。展示给用户时请转成中文。

### 请求参数

| 参数 | 必填 | 说明 |
|------|------|------|
| `name` | 是 | 姓名 |
| `idcard` | 是 | 身份证号码 |
| `mobile` | 否 | 手机号 |
| `key` | 是 | 聚合数据 AppKey |

### 返回字段说明

| 字段 | 含义 | 示例 |
|------|------|------|
| `orderid` | 流水号 | JH3201230401100134642483UG |
| `data[].orgName` | 企业名称 | 洛阳市福悦实业有限公司 |
| `data[].pName` | 查询人姓名 | 王晓民 |
| `data[].legalPersonName` | 企业法人姓名 | 王晓民 |
| `data[].relationship` | 与企业关系 | `lp` 法人 / `tm` 高管 / `sh` 股东 |
| `data[].typeJoin` | 职务 | 执行董事、监事、董事长、总经理 |
| `data[].estiblishTime` | 企业注册时间 | 2004-07-07 |
| `data[].regStatus` | 经营状态 | 存续 / 吊销 / 注销 等 |
| `data[].companyOrgType` | 企业类型 | 有限责任公司(自然人投资或控股) |
| `data[].creditCode` | 统一社会信用代码 | 91410381764873573E |
| `data[].industry` | 所属行业 | 食品制造业 |
| `data[].regNumber` | 注册号 | 410381000005409 |
| `data[].regCapital` | 注册资本 | 1000万人民币 |
| `data[].regCapitalCurrency` | 注册币种 | 人民币 |
| `data[].subscriptAmt` | 认缴出资额 | 900.0万人民币 |
| `data[].investDate` | 认缴出资时间 | YYYY-MM-DD |
| `data[].fundedRatio` | 认缴出资比例 | 90.0% |
| `data[].base` | 企业所在省份 | 河南省 |

> 注意：接口返回字段名为 `estiblishTime`（拼写如此），不是 `establishTime`。

### 错误处理

| 情况 | 处理方式 |
|------|----------|
| `error_code` 10001/10002 | API Key 无效，引导用户至 [聚合数据](https://www.juhe.cn/docs/api/id/320) 重新申请 |
| `error_code` 10012 | 当日调用次数已用尽，建议升级套餐 |
| `error_code` 232001 | 网络超时，稍后重试 |
| `error_code` 232002 | 参数为空，检查姓名和身份证号 |
| `error_code` 232003 | 姓名格式错误 |
| `error_code` 232004 | 身份证格式错误 |
| `error_code` 232005 | 手机号格式错误 |
| `error_code` 232006 | 查询无数据，告知未找到对外投资或任职记录 |
| `error_code` 232008 | 查询失败，告知稍后重试 |
| 网络超时 | 重试一次，仍失败则告知网络问题 |

- **物流快递**：100+ 快递公司实时追踪
- **金融数据**：汇率、股票、黄金价格

企业实名注册并审核通过后即可使用本接口。
