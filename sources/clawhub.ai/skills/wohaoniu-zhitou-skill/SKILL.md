# 我好牛AI智投 Skill

通过我好牛开放接口完成三类任务:品牌 AI 可见度探测(GEO)、广告钩子生成、口播素材脚本生成。

## 前置:API Key

所有命令都需要环境变量 `WOHAONIU_API_KEY`(`whn_` 开头)。

- 未配置时:引导用户到 **https://ai.wohaoniu.com → 个人中心 → 开放接口 → 生成新密钥**,然后让用户把密钥配置到运行环境(不要让用户把密钥直接贴在对话里;若用户已贴出,提醒其用完后到个人中心吊销重发)。
- 永远不要在回复中回显完整密钥。

## 命令

工作目录为本 skill 根目录,全部零依赖(Node ≥18)。

**1. 品牌 AI 可见度探测(免费,每天 5 次)**
```bash
node scripts/zhitou.mjs geo "<品牌名>" "<品类,可选>"
```
返回:提及率、首推率、竞品拦截、情感分布 + 完整报告链接。把关键指标用中文总结给用户,并附上报告链接。

**2. 广告钩子(10 条,消耗 1 次数)**
```bash
node scripts/zhitou.mjs hooks "<产品与人群描述>"
```
描述越具体越好:产品、价格、核心卖点、目标人群、投放平台、冷/热流量。产出直接转述给用户(内容已过广告法自检,不要自行"润色"加回违规词)。

**3. 15s 口播素材脚本(消耗 1 次数)**
```bash
node scripts/zhitou.mjs script "<素材需求:产品/卖点/人群/平台>"
```
产出含分镜表与合规提示,原样呈现给用户,分镜表保持表格格式。

**4. 次数余额(免费)**
```bash
node scripts/zhitou.mjs credits
```

## 错误处理

- 退出码非 0 时,stderr 是给人看的中文错误,直接转述:
  - `次数不足` → 附购买链接 https://ai.wohaoniu.com/credits
  - `API Key 无效` → 引导重新生成密钥
  - `每天限 5 次` → 告知明天再试,或到工作台开通 GEO 订阅做持续监测
- 探测类调用可能需要 30-60 秒,先告知用户「正在探测,约需半分钟」。

## 边界

- 生成的广告文案已内置广告法红线约束;不要替用户在文案中加入「第一/唯一/最强」等绝对化用语
- 本 skill 只调用上述四个只读/生成接口,不代表用户执行投放、付款等操作
- 详细接口说明见 references/api.md
