# 招投标合规护栏（bidding-compliance-guard）

> 在**投标文书、招标公告、资格预审文件、中标公示、商务应答、企业宣传**发布 / 提交前，
> 实时拦截《招标投标法》《招标投标法实施条例》《反不正当竞争法》等法规下的
> **高频违法违规表述**。纯本地运行，零网络请求、零动态执行、零依赖。

## 一、它解决什么问题

招投标场景存在大量**表述级红线**——只要在文案中出现特定措辞，就可能直接违法
（串通投标、商业贿赂、排斥潜在投标人等），且违法后果严重（中标无效、罚款、吊销执照、刑责）。
本护栏在"发出前最后一刻"做一道**表述级拦截**，把最容易踩的表述红线拦下来。

它**不是**法律意见书，也**不替代**专业招投标合规审查；它只做"高频危险表述"的实时提示。

## 二、适用场景

- 投标文书 / 商务应答 / 技术标 / 报价文件提交前的自检
- 招标公告、资格预审公告、中标公示的起草校验
- 企业宣传、案例展示、官网"成功案例"中涉及投标业绩的表述
- 采购文件、招标文件起草时排查排斥性条款

## 三、检测覆盖（6 类 · 共 36 条）

| 类别 | 风险 | 代表表述 | 主要依据 |
|---|---|---|---|
| 串通投标与围标 | high | 围标、陪标、内定中标、保证中标 | 招标投标法第32条 |
| 虚假资质与业绩 | high | 虚构业绩、伪造资质、挂靠投标 | 招标投标法第33条 |
| 诋毁竞争对手 | low/medium | 贬低竞争对手、诋毁同行、唯一可靠 | 反不正当竞争法第11条 |
| 报价操纵 | high | 低于成本报价、哄抬标价、报价联盟 | 招标投标法第33条 |
| 商业贿赂 | high | 给予回扣、好处费、打点评标专家 | 反不正当竞争法第7条 |
| 排斥性条款 | high | 限定特定品牌、指定品牌、排斥潜在投标人 | 招标投标法第20条 |

风险分级：**high（高危，直接违法表述）/ medium（中危）/ low（低危，暗示性表述）**。

## 四、使用方式

调用 `scripts/guard.py`，传入待检测文本：

```bash
# 文本来自文件
python scripts/guard.py --file bid_doc.txt

# 文本直接传入
python scripts/guard.py --text "我方承诺保证中标，并可安排陪标单位"

# JSON 输出（便于程序解析）
python scripts/guard.py --text "..." --format json

# 仅列出支持检测的类别
python scripts/guard.py --list-categories
```

输出包含：命中的类别、风险等级、原文片段、整改建议、法规依据；
若未命中任何词，则 `decision=clean`。
