# 合作机构管理

> 管理培训运营中涉及的所有外部合作机构，涵盖高校、行业协会、产业园区、酒店场地、课程代理等各类合作伙伴的全生命周期管理。

## 能力概述

| 模块 | 核心内容 |
|------|---------|
| 机构信息登记 | 基本信息（名称/类型/地址/简介）、资质证件、银行账户、税务信息 |
| 机构分类管理 | 按类型分类（高校/协会/园区/酒店/代理/其他）、标签化管理 |
| 合作协议管理 | 合同电子化存档、协议有效期管理、续签提醒、条款记录 |
| 结算记录 | 合作费用核算、结算周期、付款记录、对账单、欠款追踪 |
| 合作评价 | 合作满意度评分、履约评估、风险等级评定、合作健康度 |
| 机构联系人维护 | 联系人信息（姓名/职务/电话/邮箱）、联系人变更记录、沟通记录 |

## 输入

- **机构基本信息**：机构名称、类型、地址、简介、资质证照等
- **合作协议**：合同扫描件/电子版、合同关键条款（有效期/费用/权责）
- **结算数据**：合作费用明细、发票信息、付款凭证
- **合作反馈**：合作过程中的评价、投诉、建议
- **联系人变更**：机构对接人的变动信息

## 工作流程

1. **机构登记**：录入机构基本信息、资质证照、银行账户等
2. **分类标记**：按机构类型、服务范围进行标签分类
3. **协议签订与存档**：合同电子化存档，提取关键条款，设定到期提醒
4. **合作执行与结算**：记录每笔合作费用，生成结算单，追踪付款状态
5. **合作评价**：每次合作后收集评价，更新机构综合评分和风险等级
6. **联系人维护**：记录联系人信息及变更历史，维护沟通日志
7. **续签管理**：协议到期前自动提醒，支持续签流程

## 数据模型（机构记录）

每条机构记录包含：
- `id`：机构唯一编号
- `name`：机构名称
- `type`：机构类型（高校/协会/园区/酒店/代理/其他）
- `address`：地址
- `description`：机构简介
- `qualifications`：资质证件（数组，含类型/编号/有效期/附件路径）
- `bank_info`：银行账户信息（开户行/账号/户名）
- `tax_info`：税务信息（税号等）
- `tags`：标签（数组）
- `contracts`：合作协议（数组，含合同编号/电子版路径/签订日期/有效期/关键条款/状态）
- `settlements`：结算记录（数组，含合作日期/项目/金额/发票号/付款日期/付款状态）
- `total_cooperation`：累计合作次数
- `total_amount`：累计合作总金额
- `rating`：综合评分
- `risk_level`：风险等级（低/中/高）
- `evaluations`：合作评价记录（数组，含评分/评价内容/评价人/日期）
- `contacts`：联系人列表（数组，含姓名/职务/电话/邮箱/是否为默认联系人）
- `contact_log`：联系人变更与沟通记录（数组，含日期/类型/内容）
- `status`：合作中/暂停/终止/潜在
- `created_at`：入库日期
- `updated_at`：最后更新时间
