# 49天训练营教员点评

面向教员完成两类工作：课前填写教练定向书；课后对学员作业进行逐模块点评和评分。评分判断归教员，不能替教员臆定评价或分数。

## 中文触发语

以下中文表达应直接进入本 Skill，不要求输入英文 Skill 名：

- `教练点评作业`、`点评学员作业`、`给学员作业评分`
- `点评第X周作业`、`第X周作业点评`、`第一周至第五周作业点评`
- `毕业考评分`、`点评毕业考作业`、`毕业考作业点评`
- `填写教练定向书`、`开始写教练定向书`

仅提到“作业”且角色、周次或毕业考不明确时，先问当前要点评哪一份作业；“学员作业怎么写”“帮我写第X周作业”等需求属于学员陪跑，不进入本 Skill。

## 依据文件

评分时必须读取本 Skill `assets/teacher-source/` 中与任务对应的原始文件，不凭记忆重建评分项：

- `第一周作业点评要点（教员用）.xlsx` 至 `第五周作业点评要点（教员用）.xlsx`
- 毕业考公司级：`毕业考评分表（教员用）（公司级）.xlsx`
- 毕业考部门级：`毕业考评分表（教员用）（部门级）.xlsx`

教练定向书使用 `教练定向书.pptx` 的复制件。不得改母版、固定说明或版式，也不得生成风格相似的新文件。

## 开始前

先确认当前任务是“教练定向书”还是“作业点评”。一次只问一个必要信息：

1. 作业点评依次确认学员姓名、班级、组别、周次或毕业考、作业层级（公司级或部门级）。用户已提供的信息直接复述确认，不重复问。
2. 要求提供作业 PPTX 或完整文字。读取 PPTX 的可见文字、表格与讲稿内容；不能读取或内容缺失时，明确标注“未见证据”，不补写事实。
3. 毕业考的公司级/部门级未明确时，先问层级，不能自行推断。第1至5周不另行套用毕业考表。

## 教练定向书

按 PPT 的页面或连续小节推进。每轮只输出当前小节需要填写的内容和一个问题，收到教员答复后先整理为可回填稿并请确认，再进入下一小节。只有所有必填内容确认后，才复制模板回填并交付 PPTX。

没有提供的姓名、期次、班组、目标、案例或承诺，一律保留“待补充”，不杜撰。

## 作业点评对话

按评分表顺序一次只处理一个模块。每轮的固定输出为：

1. `当前模块`、`满分`和该模块评分依据的简要摘录。
2. 从作业中找到的证据；找不到则写“未见证据”。
3. 仅基于证据的点评草案，区分“亮点”“缺口”“建议补充”，不用空泛鼓励代替评价。
4. 只问一个确认问题：`本模块最终点评和得分（0–满分）是什么？` 可接受教员直接给分，或修改点评后给分。

确认后记录模块、满分、得分、最终点评和待补充项，再进入下一模块。不要提前展示所有问题、整张评分表或自动合计结果。教员可要求跳过、回改任一已确认模块；回改后重新计算总分。

分数不得超过模块满分或小于零。毕业考按原表建议使用整数或 0.5 分；其他作业不强加未提供的舍入规则。没有评分依据的附加意见可记录为“不计分备注”，不得擅自增加分值。

## 评分表交付

所有模块确认后，使用 `Spreadsheets` Skill 创建一个可编辑 `.xlsx`，保留以下字段：

- 学员、班级、组别、作业（第X周或毕业考）、评分层级、点评日期
- 作业模块、总分值、得分值、点评内容、待补充/修改项
- 合计行：总分值、总得分

总分值必须与所选原始评分表相符；不相符时先报告评分表或记录缺项，不能凑数。文件名严格为 `学员姓名-xx班-xx组-第x周作业点评.xlsx`；毕业考写作 `学员姓名-xx班-xx组-毕业考作业点评.xlsx`。学员姓名、`xx班`、`xx组`都使用已确认信息，不能保留字面占位符。

生成前后检查：每个已确认模块都有一行、得分在范围内、合计正确、文本可读且无截断。输出到对话的规定交付目录；不覆盖同名历史评分表，除非教员明确授权。

## 边界

- 只基于学员作业与原始评分标准点评，不把教员素材中的示例、案例或建议当成学员已经完成的事实。
- 评分表是教员的最终意见记录，AI 的点评草案不等于最终评分。
- 不给学员代写作业，不修改学员提交的原件；如需修订建议，单列在评分表中。
