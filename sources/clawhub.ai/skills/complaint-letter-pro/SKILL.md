# 投诉维权文书专家

## 为什么需要本技能

普通人遇到消费纠纷最常犯的错误：
- ❌ 投诉写得情绪化 → 被对方无视
- ❌ 说不清法律依据 → 维权无力
- ❌ 诉求不明确 → 来回扯皮
- ❌ 不知道找哪个部门 → 投诉无门

一个**逻辑清晰、依据充分、诉求明确**的投诉函，维权成功率提高3倍以上。

## 核心能力

### 1. 消费维权投诉函

覆盖场景：网购商品质量问题、商家拒绝退款、虚假宣传、价格欺诈、三包纠纷

**自动生成的文书包含**：
```

📋 投诉函结构
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

2️⃣ 法律依据
```

## 使用流程

### 生成投诉函

```
输入："我在淘宝买了台洗衣机，用了3天就不转了，
商家让我自己找维修，我要求退款他们不同意"

输出：
1️⃣ 完整投诉函（含事实+法律依据+诉求）
2️⃣ 送达渠道建议（厂家→平台→12315按顺序）
3️⃣ 需要收集的证据清单
4️⃣ 预计处理流程和时间
```

### 需要用户提供的关键信息

| 信息 | 说明 |
|------|------|
| 纠纷类型 | 网购/物流/外卖/劳动/物业等 |
| 涉及金额 | 精确到元 |
| 时间线 | 什么时候买的/什么时候出问题的 |
| 证据情况 | 有截图/录音/聊天记录吗 |
| 对方态度 | 是否已经沟通过 |

### 投诉信写作原则

```
✅ DO
- 事实清晰：时间/地点/人物/经过
- 证据具体：订单号/发票号/聊天截图
- 诉求明确：具体要什么/多少钱
- 依据充分：引用相关法规条款
- 语气理性：不用骂人/威胁/情绪化表达

❌ DON'T
- 长篇大论情绪发泄
- 威胁"我要曝光你"（要有具体措施）
- 诉求模糊（"给我一个说法"）
- 没有证据支撑
```
