# 九三学社社情民意信息写作

## 概述

本技能用于撰写九三学社社情民意信息。社情民意信息是民主党派成员通过政协等渠道反映社会情况、群众意愿和对策建议的重要参政议政形式。产出须严格遵循九三学社官方格式规范，内容须有数据案例支撑、逻辑严谨、建议务实。

## 写作流程

### 第一步：明确信息类型与主题

社情民意信息分为两类：

1. **单纯反映问题类**：结构为"存在的问题 → 分析原因"
2. **问题+对策建议类**：结构为"存在的问题 → 解决建议"（更常见，推荐使用）

确认用户要写的信息类型和主题后，据此确定整体结构。

### 第二步：遵循格式规范

完整格式规范详见 `references/writing_guide.md`，核心要点：

- **标题**：方正小标宋简体，二号，居中
- **作者标注**：格式为"某某某（九三学社社员、社会职务）反映："，三号黑体
- **摘要**：标题下方写摘要，200-300字，概述核心内容；摘要后空一行再写正文
- **正文**：小标题用楷体，正文主体用仿宋体，均为三号；正文字数控制在2500字以内
- **行距**：段前0行、段后0行，固定值29磅
- **页边距**：上3.7cm、下3.5cm、左2.8cm、右2.6cm

### 第三步：撰写内容

#### 标题

标题须简明扼要，点明核心问题或建议方向。宜采用对仗式或提炼式表述。

#### 摘要

200-300字，包含：作者身份信息、问题概述、主要建议要点。一段成文，不加小标题。

#### 正文结构（问题+对策建议类）

**第一部分：存在的问题**

- 2-4个问题，每个问题以"一是""二是""三是"等序号引导
- 每个问题须引用具体数据或案例佐证
- 数据案例须注明来源（角标尾注形式，正文末尾列明）
- 审慎使用AI工具，避免编造数据，所有数据须可溯源

**第二部分：解决问题的建议**

- 对应问题逐一提出建议，以"一是""二是"等序号引导
- 每条建议须有具体操作路径和责任主体（如"XX部门牵头""XX部委出台"）
- 建议须务实可操作，避免空泛口号

#### 尾注

正文末尾以"[1] [2] [3]..."形式列出所有数据及案例来源，格式为：来源机构/媒体，文献标题，日期。

### 第四步：质量检查

完成初稿后逐项检查：

- [ ] 格式是否符合规范（字体、字号、行距、页边距）
- [ ] 摘要是否在200-300字之间
- [ ] 正文是否在2500字以内
- [ ] 每个问题是否有数据或案例佐证
- [ ] 数据来源是否标注完整
- [ ] 建议是否有明确的责任主体和操作路径
- [ ] 是否存在AI编造的不可溯源数据
- [ ] 作者标注格式是否正确

## 范文参考

完整范文详见 `references/sample.md`，该范文为"警惕全国各地盲目开展算力招商"的社情民意信息，展示了标准格式、摘要写法、问题与建议结构、数据引用及尾注格式。

## 注意事项

- 所有引用数据必须真实可查，禁止使用AI"幻觉"编造数据
- 社会职务只写主要职务，人大代表/政协委员身份可前置
- 正文语言须正式严谨，符合党政机关公文风格
- 问题部分重在"有理有据"，建议部分重在"务实可行"
- 用户偏好开篇对仗、各部分逻辑呼应、结尾凝练有力的修辞风格
- 如需分段输出，按用户指定的各部分字数要求撰写
