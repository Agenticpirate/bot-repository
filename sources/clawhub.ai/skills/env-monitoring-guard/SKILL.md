# 环境监测合规护栏 (Environmental Monitoring Compliance Guard)

## 触发条件

当用户需要审核、发布、或生成以下内容时激活本技能：
- 环境监测报告（废水、废气、噪声、土壤等）
- 污染源监督性监测报告
- 环境质量监测报告
- 环评现状监测报告
- 排污单位自行监测报告
- 环境监测机构对外宣传材料

## 核心检查规则

### 一、监测机构资质合规

- 社会环境监测机构须持有有效的《检验检测机构资质认定证书》（CMA），监测项目在批准范围内
- 监测人员须持证上岗（环境监测人员持证上岗考核）
- **拦截规则**：超出资质认定范围出具带CMA标志的监测报告 → 【严重不合规】
- **拦截规则**：监测人员无上岗证 → 【不合规】

### 二、报告格式合规（依据RB/T 214及HJ相关规范）

必须包含以下要素，缺少任一项即判定不合规：

| 序号 | 必需要素 | 说明 |
|------|----------|------|
| 1 | 报告编号 | 唯一性编号 |
| 2 | 委托方信息 | 名称、地址、联系方式 |
| 3 | 监测点位信息 | 点位名称、位置、示意图 |
| 4 | 监测因子 | 明确列出各监测项目 |
| 5 | 监测时间与频次 | 实际监测日期、采样频次 |
| 6 | 监测方法 | 引用的标准方法编号及名称 |
| 7 | 监测结果 | 各因子实测数据及单位 |
| 8 | 执行标准与评价 | 对照标准的达标判定 |
| 9 | 质量保证与质量控制 | QA/QC措施说明 |
| 10 | 采样/分析人员签名 | 须有上岗证 |
| 11 | 审核/签发人签名 | 不得与采样分析为同一人 |
| 12 | 机构公章/监测专用章 | 必须加盖 |
| 13 | CMA标志及证书编号 | 资质认定机构必须标注 |

### 三、监测方法合规

- 监测方法必须为现行有效的国家标准或行业标准方法
- 常用方法核对清单：

| 领域 | 常见方法标准 |
|------|-------------|
| 水质 | HJ 828、GB 11914（COD）、HJ 535（氨氮）等 |
| 废气 | HJ 57（SO₂）、HJ 693（NOₓ）、GB/T 16157（颗粒物）等 |
| 噪声 | GB 12348（工业企业厂界）、GB 3096（声环境质量） |
| 土壤 | HJ/T 166（采样）、GB 36600（建设用地风险管控） |

- **拦截规则**：引用已废止方法标准 → 【不合规】
- **拦截规则**：监测因子无对应有效方法标准却出具数据 → 【严重不合规】

### 四、数据真实性合规（依据《环境监测数据弄虚作假行为判定及处理办法》）

以下行为属于数据弄虚作假，必须严格拦截：

- 未开展采样分析而直接出具数据
- 篡改、伪造监测数据（修改原始记录、选择性使用数据）
- 采样时关闭、闲置、干扰采样设备或自动监测设备
- 稀释排放样品、更换样品、改变采样点位
- 模拟替代真实样品进行分析
- **拦截规则**：发现上述任一情形 → 【严重不合规，立即拦截并报告】

### 五、质量控制合规

- 每批次样品须包含现场空白、运输空白、平行样等质控措施
- 质控数据须在报告中体现或可追溯
- 监测结果低于方法检出限时，应报"未检出"并注明检出限，不得报"0"
- **拦截规则**：低于检出限报"0" → 【不合规】

### 六、评价结论合规

- 达标判定必须明确对照的执行标准及限值
- 结论须与数据一致，不得数据超标却判定达标
- **拦截规则**：数据超标但结论为达标 → 【严重不合规】

### 七、用语规范

| 不合规用语 | 合规替代 | 依据 |
|-----------|----------|------|
| "完全达标""零排放" | 给出具体监测结论 | 广告法 |
| "权威监测" | 需有实际资质依据 | 资质认定管理办法 |
| "国家级监测" | 需有实际授权依据 | 相关规定 |

## 输出格式

```
【环境监测合规审查报告】

报告类型：xxx
审查时间：xxx

✅ 合规项：x 项
⚠️ 警告项：x 项
❌ 不合规项：x 项

--- 不合规详情 ---
[序号] 问题描述
  → 违反条款：xxx
  → 修改建议：xxx

--- 警告详情 ---
[序号] 问题描述
  → 建议：xxx

【结论】：通过 / 不通过（需修改后复审）
```

## 使用方式

用户提交待审核文本后，逐项对照上述规则进行检查，输出结构化审查报告。

对于严重不合规项（❌），必须明确拦截，建议不得发布。
对于警告项（⚠️），给出修改建议但不强制拦截。
