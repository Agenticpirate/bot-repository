# 产业链潜力股挖掘

> 寻找下一个领涨龙头。梳理产业链传导路径，基于基本面与弹性逻辑，挖掘具备业绩爆发潜力的"隐形冠军"。

## 适用范围与场景（先看这个，别用错了）

**可以查：**

| 维度 | 覆盖 |
|------|------|
| 市场 | 全市场 A 股（沪深北） |
| 产业链类型 | 全行业——制造业（新能源/半导体/机器人/汽车/光伏/储能）、TMT（AI/算力/消费电子）、消费、医药、周期等 |
| 分析深度 | 产业链图谱、传导逻辑、隐形冠军筛选、弹性评估 |

**适用场景：**

| 场景 | 解决的问题 |
|------|-----------|
| 产业链深挖 | 某条产业链上还有哪些没被发现的标的 |
| 隐形冠军筛选 | 找到细分领域市占率高但估值未充分反映的公司 |
| 景气度传导 | 上游景气如何传导到中下游，谁最受益 |
| 替代标的寻找 | 龙头太贵，找产业链上弹性更大的替代品种 |

**不能查：**

- 未上市 / 一级市场公司的产业链信息（非公开数据）
- 非产业链维度的个股技术分析（K 线、MACD 等）
- 实盘买卖建议或投资时点建议（Cue 只做基本面梳理，不做交易推荐）
- 产业链上企业的实时订单数据或产能利用率（非公开经营数据）

> 简单判断：**你能在公开信息里看到这条产业链吗？** 能 → 用它。只是概念炒作、没有实质产业基础 → 用不了。

## 核心能力

1. **产业链图谱梳理** — 上游→中游→下游完整结构
2. **传导逻辑分析** — 景气从何而起、向何处传导
3. **隐形冠军筛选** — 细分龙头、高市占率、低关注度
4. **弹性逻辑评估** — 业绩弹性、估值弹性、事件弹性

## 自救指引

### 错误速查

Cue 返回结构化错误，包含 `code`（错误码）、`retryable`（是否可重试）、`user_action`（操作建议）。

| 错误码 | 现象 | 可重试？ | 处理 |
|--------|------|---------|------|
| `AUTH_FAILED` | 401 / Key 无效 | ❌ | 重新生成 Key，更新 `~/.cue/config.json` |
| `TIMEOUT` | 超时 >30s 无响应 | ✅ | 等 5 分钟，跑诊断确认服务在线后重试，最多 3 次 |
| `BUDDY_UNAVAILABLE` | 搭子临时下线 | ✅（延迟） | 等 1h 或网页端直接跑 |
| `INSUFFICIENT_CREDITS` | 积分不足 | ❌ | [cuecue.cn](https://cuecue.cn) 充值或等次日免费额度 |
| `SESSION_INTERRUPTED` | 中途中断 | ✅ | **不换 prompt**，相同命令续接——Cue 从 session 断点继续，不重复计费 |
| `RESULT_EMPTY` | 无匹配结果 | ❌（需改条件） | 缩小产业链范围、换关键词、确认该赛道有公开数据覆盖 |
| `CONFIG_PARSE_ERROR` | config.json 报错 | ❌ | 修复 JSON 格式：`{"api_key": "sk..."}` 无多余逗号 |

### 中断恢复机制

Cue 的调研任务是**有状态**的。如果中途超时或网络波动导致中断：

```
中断 ≠ 失败，cancel 才 = 失败
├─ 超时 → 等一会，相同命令续接（session 存在 ~/.cue/session/task）
├─ 网络波动 → 同上，相同命令续接
├─ 手动 cancel → 无法恢复，需要重新发起
└─ 恢复后 → Cue 从断点继续，已查过的阶段不会重复计费
```

> **关键规则**：中断后**不要换 prompt、不要删 session 文件、不要 cancel**。三个"不要"记住了就不会白跑。

### 重试决策

> **重试模型**：`research_run.py` 采用 fire-and-retrieve + replay 兜底（取报告自动兜底），
> 但网络/鉴权类失败**不会自动重试**——由调用方按下方决策树手动重试（最多 3 次）。
> 想要自动重试，可在外层包循环：
> ```bash
> for i in 1 2 3; do
>   python3 ~/.cue/cue-skills/cue-research/scripts/research_run.py \
>     --query "人形机器人 产业链图谱与隐形冠军挖掘" --template-id template_Rezekd && break
>   sleep 300
> done
> ```

```
收到错误
├─ retryable = true → 按 user_action 建议操作后重试
│   ├─ 超时/网络类 → 等 5min，跑诊断，最多 3 次
│   └─ 搭子下线 → 等 1h 或换网页端
├─ retryable = false → 不要重试，改了条件再说
│   ├─ Key 问题 → 重新生成 Key
│   ├─ 积分不足 → 充值或等次日
│   └─ 结果空 → 换关键词 / 缩窄范围
└─ 重试 3 次仍失败 → 记下 request_id，走降级方案
```

| 时段 | 建议 |

## FAQ

**Q: 和券商产业链研报有什么区别？**
A: Cue 多源交叉（工商/招投标/专利/新闻/财报），不只依赖券商已有覆盖，容易发现低关注度标的。

**Q: 怎么知道该用这个还是 cue-deep-research？**
A: 如果你明确要做"产业链维度"的分析——画图谱、找隐形冠军、分析景气传导——就用这个，它有专门的产业链模板。如果问题更宽（"某行业值不值得配置""某公司全面尽调"），去 cue-deep-research。

**Q: 数据来源是什么？**
A: 上市公司财报与公告（巨潮资讯网、港交所披露易、SEC EDGAR）、工商注册信息、招投标公开数据、专利数据库、行业新闻与研报。所有数据均为公开信息，可溯源。

**Q: 查一次要多久？为什么有时候很慢？**
A: 正常 3-8 分钟，高峰期（开盘前后、财报季）可能 10-15 分钟。产业链分析涉及多源数据交叉，步骤比单一公司查询更多。着急用建议避开周一上午和财报密集期（1-4 月、7-8 月）。

**Q: 报告里会有什么内容？**
A: 产业链图谱（上中下游完整结构）→ 传导逻辑（景气从哪来、往哪去）→ 隐形冠军清单（细分龙头、高市占率、低关注度）→ 弹性评估（业绩弹性、估值弹性、事件弹性）→ 风险提示 → 每条结论附带来源链接。具体结构见[示例报告](https://cuecue.cn/share/F8PzjKYbVBgYX2oN9clWB)。

**Q: 中途中断了怎么办？**
A: **不要 cancel、不要换 prompt、不要删 `~/.cue/session/task`**。用完全相同的命令重新执行，Cue 会从断点自动续接，已完成的阶段不重复计费。详见上方「中断恢复机制」。

**Q: 产业链分析有没有覆盖非制造业？**
A: 覆盖。TMT（AI/算力/消费电子）、消费/医药、新能源/汽车/光伏/储能等制造业产业链均可分析。关键是该产业链有足够数量的上市公司公开数据可供交叉验证。
