# 极鲸云 SHEIN 类目搜索

仅使用极鲸云实时返回的数据搜索和分析 SHEIN 类目。独立返回经类目路径和层级验证的可信 ID，不根据名称猜测类目 ID，不编造类目、指标、链接或市场结论。

## 执行流程

1. 先读取 [SHEIN 类目搜索](references/SHEIN类目搜索.md)，按其中的业务口径、分析方法和输出要求执行。
2. 读取 [SHEIN 类目搜索接口](references/SHEIN类目搜索接口.md)，只选取用户请求所需的查询参数。
3. 未指定站点时使用 `siteId=1`（站点列表名称“全部”，当前映射 `us`，不是跨国家聚合）；明确美国站时使用 `siteId=2`。指定其他国家或地区时，先运行 `python3 scripts/shein_site_list.py --country "国家或地区名"`，只采用唯一精确匹配的站点 ID。
4. 用户请求热销类目、蓝海类目或类目机会榜单时，再读取 [SHEIN 类目榜单查询预设](references/SHEIN类目榜单预设.md)，每次只采用一个最符合意图的主预设。
5. 从本 Skill 根目录运行 `python3 scripts/shein_category_search.py --param "名称=值"`。需要多个条件时重复传入 `--param`。
6. 用返回的完整类目路径、层级和父类目核验 `catId`。名称相近或路径不唯一时列出候选并请用户确认，不自行选择。
7. 检查返回结构、命中总数、当前页、样本量和更新时间。`total` 是精确命中数，但最多只能分页访问前 10000 条；超过时缩小筛选范围。需要完整结果时逐页查询，未完成分页时明确说明仅为样本。
8. 按参考文档分析数据并输出中文业务结论。对每个返回非空 `linkUrl` 的类目，将类目名称或完整路径写成可点击链接。

## 复用登录态

- 先直接运行类目搜索脚本。脚本通过 `scripts/geekbi_auth.py` 优先读取所有极鲸云 Skills 共用的系统用户配置登录态；已有有效登录态时不得再次要求登录。
- 仅在脚本返回 `actionRequired` 或退出码 `2` 时读取并执行 [查询暂停与恢复流程](references/查询暂停与恢复流程.md)。向用户展示服务端中文提示和有效跳转链接，然后暂停查询；用户完成操作并回复继续后，原样重跑同一命令。
- 退出码 `1` 时仅展示错误输出中的一级中文 `msg`。不得展示访问令牌、设备码、请求头、原始错误 JSON 或异常栈。

## 资源路由

- 执行任何类目搜索、类目 ID 查询或类目分析时，读取 `references/SHEIN类目搜索.md`。
- 组装查询参数、选择排序字段或解释返回字段时，读取 `references/SHEIN类目搜索接口.md`。
- 处理类目榜单请求时，读取 `references/SHEIN类目榜单预设.md`。
- 仅在服务端要求用户操作时，读取 `references/查询暂停与恢复流程.md`。

若环境尚未安装依赖，运行 `python3 -m pip install -r requirements.txt` 后再执行查询脚本。
