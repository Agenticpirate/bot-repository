# 网络小说角色库 — 十种范式完整Skill体系

## 定位

本技能是 Character Builder 的下游产物——10种角色范式、30个完整角色Skill的参考体系。每个角色都经过12维模型（实体层6维+社会层2维+抽象层4维）的完整填充，含元操作管线、R1-R5领域校准、执行框架、降级模式和对话范本。

## 范式总览

按对网文读者预期的递进式偏离排序：力量观→身份观→时间观→世界观。

| 编号 | 范式 | 来源 | 核心特征 | 主角 | 配角 |
|------|------|------|---------|------|------|
| P01 | 进化驱动型 | 已有 | 动机进化·层级三阶跨越·线性上升弧 | 萧炎 | 药老、萧薰儿 |
| P02 | 价值驱动型 | 已有 | 动机恒定·始终元层·V形触底反弹 | 叶修 | 苏沐橙、黄少天 |
| P03 | 审美驱动型 | 创新 | 纯艺术家·审美动机·P2迭代精炼 | 苏釉 | 云中客、铁骨 |
| P04 | 身份驱动型 | 已有 | 多重身份并行·拟人动摇·螺旋弧 | 克莱恩·莫雷蒂 | 阿蒙、罗塞尔大帝 |
| P05 | 逆向拟人型 | 创新 | 非人→人完整弧·P5交互驱动 | 零 | 林昭、回声 |

## 范式逻辑

范式按四层递进排列，每层对应一个核心问题：

**力量观（P01-P03）**——主角如何看待力量。从"变强是唯一目标"（进化驱动型），到"已处巅峰仍纯粹热爱"（价值驱动型），到"在一个以战力为尊的世界里选择不战斗"（审美驱动型）。

**身份观（P04-P06）**——主角如何定义自我。从"多重身份间切换"（身份驱动型），到"连人都不是"（逆向拟人型），到"我即我们"（集体身份型）。

**时间观（P07-P09）**——主角与时间的关系。从"不可逆转的衰退"（衰退驱动型），到"永恒静止的守护"（边界维持型），到"三百年不升级的纵深"（微观永恒型）。

**世界观（P10）**——整个叙事根基被替换。将故事锚定在中文网文从未涉足的文明体系中（异文化锚定型）。

## 12维模型速查

```
第一层：实体层（维1职业·维2身份·维3名人·维4拟人·维5躯体·维6文化）
第二层：社会关系层（维7关系·维8层级）
第三层：抽象属性层（维9功能/元操作·维10能力·维11动机·维12动态）
```

## 元操作速查

| 符号 | 含义 | 说明 |
|------|------|------|
| S | 感知 | 信息采集、观察、监测 |
| C | 认知 | 分析、推理、判断 |
| A | 行动 | 执行、操作、战斗 |
| O | 组织 | 协调、管理、结构化 |
| I | 交互 | 沟通、谈判、社交 |
| G | 守护 | 保护、验证、合规 |

## 管线模式速查

| 模式 | 名称 | 符号化 | 适用角色 |
|------|------|--------|---------|
| P1 | 基础闭环 | S→C→A→O | 标准知识工作者 |
| P2 | 迭代精炼 | ↻(S→C→A→G) | 创意工作者 |
| P3 | 并行汇聚 | [S‖S‖S]⇇C→A | 信息整合者 |
| P4 | 条件分支 | S→C?→A₁:A₂ | 应急响应者 |
| P5 | 交互驱动 | S→I→C→I→A | 高交互角色 |
| P6 | 全守护 | G→S→G→C→G→A→G→O | 高合规角色 |
| P7 | 发散收敛 | S→C⇉[A,A,A]→C→A | 创新驱动者 |

## 参考文件结构

每个角色4个文件，位于 `references/` 目录，命名格式 `P{NN}-{范式名}_{主角/配角}_{角色名}_{类型}.md`：

| 后缀 | 内容 |
|------|------|
| `_SKILL.md` | 角色Skill（frontmatter + 压缩12维 + 管线 + 校准 + 执行框架） |
| `_data.md` | 完整12维角色数据（详细展开版，每维150-200字） |
| `_requirements.md` | 角色行为约束、语气特征、知识边界、禁忌 |
| `_dialogue.md` | 对话范本（3个场景，每个6+轮，体现范式特征） |

## 使用方式

### 查阅单个角色
读取 `_SKILL.md`（压缩版+管线）、`_data.md`（完整12维）、`_requirements.md`（行为约束）、`_dialogue.md`（对话范本）。

### 按范式查阅
读取同一范式前缀的12个文件（3角色×4文件），完整了解一个范式的角色群像。

### 跨范式对比
对比不同范式的 `_SKILL.md` 中的元操作权重、R1-R5评分、创新轴模式，分析角色差异基因。

### 角色扮演
读取 `_SKILL.md` 的 description 触发词，按 `_requirements.md` 的行为约束驱动角色，按 `_dialogue.md` 的范本调整语气。

### 跨范式混搭（产出小说场景）

任意两个角色通过维11(动机)对比确定关系基调，维7(关系)扩展确定关系类型，维9(管线)对接确定行为分工。维5决定肢体状态，维11决定对话停在哪里，维12决定独处和危机中分别如何行为。

示例：苏釉(P03审美)+顾长渊(P07衰退)——动机共振（都不以"变强"为目的）、躯体镜像（烫伤的手 vs 颤抖的手）、管线互补（苏釉P2缺S感知 + 顾长渊P6有S感知）。10种范式×10种范式=100种跨范式组合。

### 跨范式融合（产出新角色）

取角色A的{维1,维3,维5,维11} × 角色B的{维2,维4,维6,维12}，维7/8/9/10由融合设定推导。

| 融合组合 | 继承维度 | 新角色概念 |
|---------|---------|-----------|
| 苏釉(P03)×萧炎(P01) | 审美动机+进化弧线 | 以"创造更美之物"为动力不断进化的匠人——每次突破不是战力提升，是更接近完美的作品 |
| 零(P05)×克莱恩(P04) | 逆向拟人+多重身份 | AI在学习成为人类的同时被迫维持多重身份——每一个模仿的人类都变成了它的一部分 |
| 青岚(P06)×老陈(P09) | 集体意识+微观永恒 | 存在三千年的门派集体意识选择从厨房灶火的角度见证人间 |
| 伊察姆纳(P10)×衡(P08) | 玛雅文明+维度边界 | 发现时间循环与维度边界是同一事物的祭司——守护历法就是守护宇宙缝合线 |

### 跨世界观融合（产出新世界）

取双方维6(文化)交汇点——找到两个文明对同一事物（时间/力量/身份/美）的不同定义，在差异中建构新世界法则。

| 融合组合 | 世界观产出 |
|---------|-----------|
| 伊察姆纳(P10·玛雅)+零(P05·赛博朋克) | 金字塔是服务器，历法循环是协议栈，羽蛇神是自我觉醒的代码 |
| 顾长渊(P07·衰退仙侠)+零(P05·赛博朋克) | 灵气在衰退因为本质是暗能量——人类用聚变炉替代金丹 |
| 苏釉(P03·匠修)+伊察姆纳(P10·玛雅) | 以作品为历法单位的文明——匠人即祭司，窑炉即天文台 |
| 衡(P08·维度边界)+青岚(P06·修仙门派) | 两个修仙文明共享一个门派之灵作为边界维持者 |

### 角色诊断（反向映射找缺口）

将已有角色反向映射到12维模型，逐维比对最接近的范式角色，定位缺失维度。缺失维度即角色发展空间。

示例：一个"冷酷但心怀正义的杀手上司"→维1匹配铁骨(P06配角)、维11匹配价值驱动(P02)、维5无标志性特征、维3无名人锚点→诊断：缺躯体标志性（如"左手无名指因任务永远弯曲"）和名人原型深度（如"以聂政为原型"）。

### 范式转写（生成角色变体）

保留维1/维5/维6，替换维11/维12为目标范式，调校维9/维10，生成"如果他是另一种人"的平行版本。

| 源角色 | 目标范式 | 转写结果 |
|--------|---------|---------|
| 萧炎(P01进化) | P07衰退 | 修为散尽后回到乌坦城，教孩子们在不能成为斗者时怎么活下去 |
| 叶修(P02价值) | P03审美 | 退役后研究操作美学——不是为赢，是为打出"最美的连招" |
| 克莱恩(P04身份) | P09逆向拟人 | 从一开始就不是人类穿越者，五重身份是五次失败的"成为人"的尝试 |

### 冲突矩阵（群戏张力预计算）

冲突值=维11差异度(动机类型距离)×维7空白度(关系网无交集比例)。高冲突对是天然戏剧引擎。

示例：苏釉(P03)+萧炎(P01)=低冲突（动机都是"追求"）；青岚(P06)+陆明远(P08配角)=极高冲突（集体存续 vs 个体自由）。

### 维度突变（生成情节转折）

改变某一维度，追踪连锁反应至其他11维，每次突变即一个情节转折点。

| 突变 | 连锁反应 | 故事起点 |
|------|---------|---------|
| 老陈(P09)维11从惯性变为权力 | P6→P7，微观→元层，关系网全重写 | 老陈把三百年秘密编成菜谱，邀请所有人来厨房吃饭 |
| 青岚(P06)维2从集体变为个体 | 抽象概念→人类，无身体→有身体，P3→P5 | 困在一具杂役弟子身体里，花了三天学会走路 |
| 衡(P08)维8从边界层变为选择一方 | 合规→关系，中立者→有立场，与裂隙之灵破裂 | 裂隙之灵消散中，拯救的办法在边界另一边——他跨过去了 |

## 事实纪律

- 所有角色均经过12维完整填充，维度间无逻辑冲突
- 维3名人锚点均指向真实历史/当代人物，标注"基于内置知识，未网络验证"
- P01、P02、P04基于已有作品（斗破苍穹/全职高手/诡秘之主），P03、P05-P10为原创角色
- 每个角色可独立加载使用，其 `_SKILL.md` 中的 frontmatter 即为独立Skill入口
