# 史诗级韭菜每日投研 Skill

## 概述

本 Skill 将 IMA 知识库「胖胖的龙龙的知识库」中的投资研究与复盘体系抽象为自动化投研笔记生成工具。

**核心理念：「反者道之动」** — 反常之处即机会所在。寻找史诗级极端事件中的不对称机会。

**数据优先级：通达信（TDX）> westock-data > 互联网数据。两者矛盾时以 TDX 为准。**

输出文件：`E:\文件\workbody\a stock\史诗级韭菜投研笔记_YYYY-MM-DD.md`
双写到 IMA 知识库「胖胖的龙龙的知识库」→「每日总结」→「宏观和微观」文件夹。

---

## 投资哲学框架（来自知识库）

本 Skill 的判断逻辑基于以下投资哲学：

### 1. 「反者道之动」
反常之处即机会所在。当大多数人在恐惧或贪婪时，反向思考。
- 猪肉史诗级低价 → 猪周期反转机会
- 黄金史诗级跳水 → 避险资产错杀
- 板块集体恐慌抛售 → 错杀优质标的

### 2. 「常识即力量」
违背常识的地方孕育巨大机会或风险。
- 所有人都看好的方向 → 警惕过度拥挤交易
- 超出常理的价格 → 寻找背后逻辑

### 3. 「价值投资四要素」
- **买股票 = 买公司**：关注企业本身，不沉迷于K线
- **市场不可预测**：不对短期走势做确定性判断
- **安全边际**：以低于内在价值的价格买入
- **市场服务于你**：利用市场波动，不被市场利用

### 4. 「不亏钱法则」
- 亏损 50% 需要 100% 才能回本
- 保本 > 收益
- 当看不清楚时，减少仓位

### 5. 「均值回归」
- 所有极端现象终将消退
- 极端低估时买入，极端高估时卖出
- 耐心等待回归，不追涨杀跌

## 执行流程

### 第一步：交易日判断

**在执行任何数据获取前，必须先判断目标日期是否为A股交易日。**

判断方法（按优先级）：
1. **尝试获取上证指数行情**：调用 TDX 查询上证指数（code: "000001", setcode: 1）。如果返回正常行情 → 是交易日
2. **备用方法**：调用 westock-data 查询上证指数，如果失败则为非交易日
3. **日期判断**：周六/周日 → 直接判定为非交易日

**非交易日处理**：
- 非交易日直接退出，不生成文件
- 如果用户在非交易日手动触发：提示"YYYY-MM-DD 为非交易日，无行情数据"

**确定复盘日期**：默认为当日。用户指定日期时使用指定日期。

### 第二步：获取 A 股行情数据

#### 2.1 七大指数行情

使用 `mcp__tdx-connector__tdx_quotes`：

| 指数 | setcode | code |
|------|---------|------|
| 上证指数 | 1 | 000001 |
| 深证成指 | 0 | 399001 |
| 创业板指 | 0 | 399006 |
| 科创50 | 1 | 000688 |
| 上证50 | 1 | 000016 |
| 沪深300 | 1 | 000300 |
| 中证500 | 1 | 000905 |

参数：`{code, setcode, hasCalcInfo: 1, hasExtInfo: 1, hasHQInfo: 1}`

提取：收盘点位、涨跌幅、成交额（万元→亿元）、量比、换手率。

#### 2.2 涨跌停统计

调用 `mcp__tdx-connector__tdx_screener`：
- 涨停：`{message: "涨停", rang: "AG", pageSize: 200, pageNo: 1}`
- 跌停：`{message: "跌停", rang: "AG", pageSize: 200, pageNo: 1}`

统计总数（TDX total 字段），记录连板天数。

#### 2.3 成交额 TOP10

调用 `mcp__tdx-connector__tdx_screener`：`{message: "成交额 从大到小 前10名", rang: "AG", pageSize: 10}`

#### 2.4 板块轮动

调用 westock-data 获取板块涨跌排行：
```
node "<westock-data-path>/scripts/index.js" sector ranking --limit 30
node "<westock-data-path>/scripts/index.js" sector ranking --asc --limit 10
```

提取领涨/领跌板块 TOP5，以及资金流向方向。

### 第三步：识别「史诗级」信号

这是本 Skill 的核心差异化步骤。基于投资哲学，主动扫描以下四类异常信号：

#### 3.1 极端估值信号
- 搜索近期板块/个股估值是否处于历史极低（10年PE分位<10%）或极高（>90%）
- 可用 westock-data 或 TDX 查询行业PE/PB数据

#### 3.2 价格极端信号
- 指数单日涨跌幅 > 3% → 标记为异常波动
- 板块单日涨跌幅 > 5% → 标记为极端轮动
- 成交额同比放大/缩小 > 30% → 标记为量能异常

#### 3.3 背离常识信号
- 基本面消息利好但价格下跌 → 警惕出货
- 基本面利空但价格坚挺 → 可能是最后一跌或主力护盘
- 大众情绪极端一致时 → 反向思考

#### 3.4 资金异常信号
- 北向资金连续3日净流入/流出 > 100亿
- 主力资金单日净流入/流出 > 500亿
- 板块资金连续5日同向流动

### 第四步：检索 IMA 知识库历史

调用 `mcp__ima-mcp__search_knowledge` 搜索「胖胖的龙龙的知识库」中与当日热点板块/个股相关的历史笔记。

搜索关键词示例：
- 如果当日领涨板块是"CPO、通信设备" → 搜索"CPO"、"通信"、"易中天"
- 如果当日领跌板块是"猪肉、黄金" → 搜索"猪肉"、"黄金"、"史诗级"

> **注意**：IMA 搜索功能需要 ima-mcp 连接器已连接。如未连接，跳过此步，在笔记中标注「IMA未连接，历史笔记未检索」。

从搜索结果中提取：
- 该板块/个股的历史判断与操作建议
- 之前的买点/卖点记录
- 之前的估值判断是否准确

### 第五步：生成投研笔记

按照模板格式生成 Markdown 笔记文件，保存到：
```
E:\文件\workbody\a stock\史诗级韭菜投研笔记_YYYY-MM-DD.md
```

笔记包含 6 大板块（详见 references/template.md）：

1. **今日市场速览** — 指数/成交额/涨跌家数/情绪定性
2. **板块轮动观察** — 领涨领跌/资金流向/持续性判断
3. **史诗级信号预警 🔍** — 识别到的异常信号+机会/风险分析
4. **核心标的追踪** — 持仓股/关注股表现+买卖点重估
5. **跨境联动** — 美股/港股/商品对A股传导
6. **操作计划** — 明日策略/仓位建议/具体买卖点

### 第六步：写入 IMA 知识库

将生成的笔记内容同步到 IMA 知识库：
1. 使用 ima-skills（notes 子模块）的 `import_doc` 接口创建笔记
2. 笔记标题：`史诗级韭菜投研笔记_YYYY-MM-DD`
3. 笔记内容：Markdown 正文
4. 目标文件夹：`每日总结/宏观和微观`
5. 使用 `add_knowledge` 将笔记关联到「胖胖的龙龙的知识库」

**IMA 写入失败处理**：
- 如果 ima-skills 凭证未配置：仅生成本地 MD 文件，提示用户手动上传
- 如果 API 调用报错：记录错误日志，确保本地文件已生成

## 重要约定

### 数据优先级

| 优先级 | 来源 | 适用场景 |
|--------|------|---------|
| 1（最高） | TDX 通达信 | 指数行情、涨跌停统计、成交额排行 |
| 2 | westock-data | 板块排行、财务数据 |

IMA 知识库同步：胖胖的龙龙的知识库 → 每日总结 → 宏观和微观

## 故障处理

### TDX 工具不可用

如果 `mcp__tdx-connector` 未连接或调用失败：
1. 立即通知用户"通达信（TDX）接口不可用，将使用 westock-data 作为主数据源"
2. 在生成的笔记中标注 `(westock-data数据，TDX未连接)`
3. 继续完成投研笔记生成，不能因 TDX 不可用而中断

### IMA 连接器不可用

如果 `mcp__ima-mcp` 未连接：
1. 跳过第四步（历史笔记检索）和第六步（IMA写入）
2. 在笔记开头标注「IMA未连接：未检索历史笔记、未同步到知识库」
3. 仅生成本地 MD 文件

### ima-skills 凭证缺失

如果 ima-skills 的 OpenAPI 凭证未配置：
1. 跳过第六步（IMA写入），仅生成本地 MD 文件
2. 提示用户配置凭证以获得完整功能
3. 不影响第一~四步执行

### 非交易日

同第一步判断逻辑，非交易日直接退出。
