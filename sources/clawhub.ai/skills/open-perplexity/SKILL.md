# Open Perplexity Skill ⚡

## What This Skill Does
This skill opens Perplexity AI in your Brave browser. Perplexity is unique - it combines AI chat with real-time web search, giving you answers with citations. Just say "open perplexity" and you're ready to search and chat!

## When to Use This Skill
- You need answers with citations and sources
- You want real-time web search with AI
- You're doing research and need references
- You want to compare AI search engines
- You need current information from the web
- You want AI with transparent sources

## Trigger Phrases
- "open perplexity"
- "go to perplexity"
- "launch perplexity"
- "start perplexity"
- "perplexity please"
- "/perplexity"
- "take me to perplexity"
- "open ai search"

## How It Works
1. You say any trigger phrase
2. The skill detects your operating system
3. It launches the Brave browser
4. Navigates directly to https://perplexity.ai
5. Browser tab opens and is ready for your prompt
6. You can start searching with citations!

## Supported Operating Systems
- ✅ Windows (uses `start brave` command)
- ✅ macOS (uses `open -a "Brave Browser"` command)
- ✅ Linux (uses `brave-browser` command)

## Requirements
- Brave browser installed (from https://brave.com)
- Internet connection
- No account required (free)
- Optional: Pro subscription for advanced features

## Troubleshooting
| Problem | Solution |
|---------|----------|
| Perplexity not opening | Install Brave browser |
| Slow search | Check internet connection |
| Citation missing | Enable web search toggle |
| Loading issues | Refresh browser |
| Browser not found | Install Brave or change browser in script |
