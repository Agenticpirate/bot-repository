# 离线 HTML 演示稿生成器

当输出应该是一个可分享的演示稿，但 PDF 或幻灯片文件又太死板时，就用这个技能。

默认输出是一个本地单文件 HTML，内嵌 CSS，不依赖外部资源。

## 工作流

1. 评估源材料。
   - 这份演示稿是给什么用的？
   - 谁会看？
   - 想让读者改变什么判断或理解？

2. 先产出文案优先的大纲。
   - 标题。
   - 叙事主线。
   - 6 到 12 页。
   - 每页只放一个主张。

3. 构建单文件 HTML。
   - 内嵌 CSS。
   - 避免外部字体、CDN、远程图片和在线脚本。
   - 保证在普通笔记本屏幕上仍然好读。

4. 离线验证。
   - 本地打开文件。
   - 检查所有页面是否渲染。
   - 检查文本有没有溢出。
   - 检查断网后是否仍可用。

## 页面规则

- 一页只做一件事。
- 标题要具体。
- 能用数据、例子或对比就别空说。
- 不要加说明书式的“如何使用这个演示稿”。
- 优先用干净静态布局，不要依赖脆弱动画。

## 输出

主输出：

```text
deck.html
README.md
```

可选输出：

```text
source-notes.md
review-checklist.md
```

## 安全

公共模板里不要放私有客户名、内部编号、账号标识或保密截图。
