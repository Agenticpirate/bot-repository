# Title Contribution Checker - 标题贡献度检查

## 功能说明

判断论文标题是否清晰传达了研究的核心理念和价值。

## 检查标准

### 1. 回答"研究了什么？"
标题应该明确回答这个问题，而不是只描述一个宽泛的主题。

### 2. 包含研究焦点
标题应包含具体的研究变量、对象或方法。

### 3. 识别无贡献标题
以下类型标题缺乏研究贡献：
- 只描述研究主题
- 使用过于宽泛的术语
- 缺乏具体研究问题

## 示例

### ❌ 差标题（无贡献）
```
Social Media Use
```
分析：只描述了研究主题，没有传达任何具体研究内容或贡献。

### ✅ 好标题（有贡献）
```
Social Media Use Predicts Sleep Quality Through Emotional Regulation
```
分析：清晰传达了研究变量（社交媒体使用、睡眠质量、情绪调节）和它们之间的关系。

### ❌ 问题标题
```
A Study on Social Media
```
分析：使用了"Study on"这种无意义的词，且没有说明具体研究什么。

### ✅ 优化后
```
The Impact of Social Media on Adolescent Mental Health: A Longitudinal Study
```

## 判断标准

**高贡献度标题特征**：
- 包含具体的研究变量
- 暗示了研究发现或关系
- 使用了精确的术语

**低贡献度标题特征**：
- 只有宽泛的主题词
- 使用"Study on"、"Research on"等无意义词
- 缺乏具体研究内容

## 输出格式

检查后请提供：
1. **贡献度评估**：高/中/低
2. **分析**：标题传达了什么研究内容
3. **问题**：如果有问题，指出具体问题
4. **建议**：如果需要优化，提供修改建议
