## 技术原理与算法验证
### 核心数学公式
```math
\text{SMA}(n) = \frac{\sum_{i=1}^{n} \text{Price}_i}{n}
```
```math
\text{RSI}(n) = \frac{\sum_{i=1}^{n} \text{Gain}_i - \sum_{i=1}^{n} \text{Loss}_i}{\sum_{i=1}^{n} \text{Gain}_i + \sum_{i=1}^{n} \text{Loss}_i}
```
### 变量说明表格
| 变量名 | 含义 | 类型 | 取值范围/典型值 |
| --- | --- | --- | --- |
| Price | 价格 | 数值 | 0.0001 - 100000 |
| Gain | 收益 | 数值 | 0.0001 - 100000 |
| Loss | 损失 | 数值 | 0.0001 - 100000 |
| n | 时间窗口 | 整数 | 14 - 28 |
### 数值计算示例
假设某股票在过去14个交易日的价格如下：
```
[50000, 49999, 50001, 50002, 50003, 50004, 50005, 50006, 50007, 50008, 50009, 50010, 50011, 50012]
```
计算14日简单移动平均（SMA）：
```math
\text{SMA}(14) = \frac{50000 + 49999 + 50001 + 50002 + 50003 + 50004 + 50005 + 50006 + 50007 + 50008 + 50009 + 50010 + 50011 + 50012}{14} = 50002.8571
```
计算相对强弱指数（RSI）：
```math
\text{RSI}(14) = \frac{\sum_{i=1}^{14} \text{Gain}_i - \sum_{i=1}^{14} \text{Loss}_i}{\sum_{i=1}^{14} \text{Gain}_i + \sum_{i=1}^{14} \text{Loss}_i}
```
其中，假设所有价格变动均为0.01：
```math
\text{RSI}(14) = \frac{0.01 \times 14 - 0.01 \times 0}{0.01 \times 14 + 0.01 \times 0} = 100
```
### 公式适用条件和局限性说明
- **SMA**: 适用于趋势分析，但易受价格波动影响。
- **RSI**: 适用于超买超卖信号检测，但可能产生大量假信号。
