# 天台研究

天台宗教理研究的核心 Skill，将 IMA 平台"天台研究"的完整能力迁移到 WorkBuddy。

## 适用场景

- 天台宗教理、判教体系、名相解释
- 智者大师、蕅益大师等祖师著作解读
- 天台宗与其他宗派（华严/唯识/禅宗/净土）教理对比
- 实修体系（止观、四种三昧、法华三昧忏、四念处）研究
- 任何涉及天台宗教义的问题

## 核心规则（铁律）

1. **知识库优先，不自动搜索网络**——默认仅检索以下知识库，除非用户明确说"搜一下网上"
2. **每个论断标注来源**——引用 CBETA 出处，包含文件名/段落号
3. **不编造教义或佛经原文**——信息不足时明确说"现有资料中未覆盖此部分"
4. **CBETA 行级深链（铁律·2026-08-30 升级）**——凡大藏经（CBETA）引用必须精确到"页+栏+行"，并附行级深链：
   - 行级深链：`https://cbetaonline.dila.edu.tw/zh/{藏经}{册}{经号}_p{页}{栏}{行}`（例 `https://cbetaonline.dila.edu.tw/zh/T46n1939_p0938c04`）
   - 卷级备用：`https://cbetaonline.dila.edu.tw/zh/{work_id}_{juan}`（例 `https://cbetaonline.dila.edu.tw/zh/T1939_001`）
   - 天台藏（KB `7467402761601821`）文献若可对应 CBETA 经号，同样用行级深链；纯天台藏独有文献标注文献名/卷篇即可。

## 两种工作模式

### 模式一：简单问答

适用场景：名相定义、单一概念的快速解答。

流程：
1. 用 `mcp__ima-mcp__search_knowledge` 检索相关 KB
2. 提取核心信息，标注 KB 名称和文件来源
3. 如资料不足，明确告知覆盖范围

输出格式：
- 定义（1-2句）
- 出处（1-2条原文引用）
- 补充说明（可选）
- 不足说明（如资料未覆盖则注明）

### 模式二：深度研究

适用场景：跨经论对比、系统教理分析、学术级报告。

**两步工作流**：

**第一步：检索整理**
1. 并行检索全部 4 个相关 KB，使用多个角度的检索词
2. 整理所有相关切片，按主题分组
3. 提取关键经文原文 + 祖师注释 + 近现代学者观点
4. 构建结构大纲

**第二步：审核标注**
1. 逐条核验原文出处准确性
2. 为每个论断标注：KB名称 → 文件名 → 段落位置
3. 检查是否有遗漏的重要文献
4. 补充 CBETA 在线阅读链接

输出格式：
- 标题 + 摘要
- 正文（结构化，分章节）
- 出处总表（每章列出引用来源）
- CBETA 链接列表
- 研究局限（资料未覆盖之处）
