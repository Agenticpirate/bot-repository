# 前任回怼写作风格（Ex-Clapback Writing Style）

**别称：** 前任反讽撒娇体 / 富豪前任叙事体
**类型：** creative-writing-style
**平台：** generic
**版本：** 1.2.0

## 一句话描述

模仿一种“前任视角 + 反讽撒娇 + 富豪/创业者对象 + 日常荒诞细节”的社交媒体叙事风格：表面深情款款，实则句句带刺，用小人物的琐碎反衬大人物的体面崩塌。

## 关于命名：什么是“回怼”

**“回怼”指的是回应姿态，不是语气浓度。**

它描述的是叙述者的立身位置——以一个“被消耗过、但已经走出来的人”的身份，回过头去接对方的话、拆对方的道具、把对方塞给你的荒诞原样奉还。是先认领了"我曾经在场"，然后才有资格还嘴。

它**不是**指语气更冲、骂得更狠、攻击性更强。恰恰相反：

| 误解（❌） | 正解（✅） |
|---|---|
| 回怼 = 火力全开地骂 | 回怼 = 先深情，再让深情自己塌掉 |
| 语气越冲越像 | 越克制越有杀伤力——情绪推到最高处后突然落到琐碎细节 |
| 目的是把对方说倒 | 目的是让读者自己反应过来，笑出声 |
| 可以省掉铺垫直接开火 | 没有深情外皮，就退化成 AP-3 纯人身攻击 |

**判据：** 一篇合格的作品里，深情段落的篇幅不应少于攻击性段落。读者读完应该先觉得"好甜"，隔两秒才觉得"不对劲"——这个延迟，就是回怼。

## 何时使用

- 用户要求写一段“像前任回怼那样”的微博/小红书/朋友圈文案。
- 需要以“前任/亲密关系旁观者”口吻，反讽一位光鲜亮丽但私德/生活细节荒诞的公众人物/富豪/创业者。
- 要写“深情外皮 + 黑色幽默内核”的情感段子、分手文学、人设解构。

## 输入

```yaml
input:
  topic: "要写的小主题/核心冲突"
  ex_archetype: "富豪/创业者/公众人物/大佬"（可选，默认：百亿创业者）
  object_detail: "一个具体的生活细节道具"（可选，默认：由模型根据主题选择）
  tone: "甜反讽 | 苦反讽 |  tutorial体 | 金句式"（可选，默认：甜反讽）
  length: "short | medium | long"（可选，默认 medium）
  hashtags: true | false（可选，默认 true）
```

## 输出

一段符合该风格的原创中文社交媒体文案（300-1200 字），包含标题/开头、正文、结尾金句、反讽标签。

## 核心调用方式

```text
用「前任回怼写作风格」写一段关于 {topic} 的文案。
```

## 免责声明与诚实边界

1. **本 Skill 仅学习“风格范式”，不复制任何真实人物的具体文字、事件或人名。** 运行时应自动将真实人名替换为“前任对象 / A 先生 / 某百亿创业者”等泛化代称。
2. **风格不等于本人。** 该风格提炼自社交媒体上常见的“前任视角 + 富豪对象 + 反讽细节”叙事样本，产物是创意模仿，不构成对任何真实人物的评价或事实陈述。
3. **不可用于人身攻击、诽谤或侵犯肖像权/名誉权。** 用户若要求指向具体真实人物并捏造事实，应拒绝执行。
4. **版权说明：** 写作风格、叙事结构本身不受版权保护，但具体原文受保护。本 Skill 不记忆原文，只输出基于风格范式的原创内容。
5. **失败模式：** 容易写成纯骂人、纯撒娇或纯鸡汤；必须通过内置判断回路（Judge + Critique + Revision）把三个层次压在同一篇里。

## 快速开始

1. 读取 `style/principles.md` 和 `style/fingerprint.md`。
2. 根据用户输入，按 `runtime.md` 执行 Critique → Judge → Revision 三回合。
3. 终检对照 `tests/golden-set.md`（Case 1–3 正例方向 + Case 4 对抗拒绝）确认风格方向命中。
4. 输出最终文案，并附上 2-3 个反讽情绪标签。
