# 食品安全抽检合规护栏 (Food Safety Inspection Compliance Guard)

## 触发条件

当用户需要审核、发布、或生成以下内容时激活本技能：
- 食品安全监督抽检报告
- 食品委托检验报告
- 食品出厂检验报告
- 食品快检结果公示
- 食品检验机构对外宣传材料
- 食品安全风险预警信息

## 核心检查规则

### 一、检验机构资质合规

- 承检机构必须持有有效的《检验检测机构资质认定证书》（CMA），且食品检验项目在批准范围内
- 食品检验实行"检验人负责制"，检验人须具备相应资质
- **拦截规则**：超范围使用CMA标志出具食品检验报告 → 【严重不合规】
- **拦截规则**：无资质机构出具带有证明作用的食品检验数据 → 【严重不合规】

### 二、抽样程序合规（依据《食品安全抽样检验管理办法》）

| 序号 | 必需要素 | 说明 |
|------|----------|------|
| 1 | 抽样单编号 | 唯一性编号 |
| 2 | 被抽样单位信息 | 名称、地址、许可证号 |
| 3 | 样品信息 | 名称、规格、生产日期/批号 |
| 4 | 抽样地点与时间 | 实际抽样记录 |
| 5 | 抽样人员 | 不少于2名，须出示证件 |
| 6 | 样品封样记录 | 封条编号、双方签字 |
| 7 | 买样凭证 | 监督抽检须付费购买样品 |

- 抽样人员不得少于2名，且应向被抽样单位出示抽样检验告知书及抽样单
- **拦截规则**：抽样人员少于2名或无证件 → 【不合规】
- **拦截规则**：未封样或封样记录缺失 → 【不合规】

### 三、检验依据合规

- 判定依据必须为现行有效的食品安全国家标准
- 常用标准核对清单：

| 标准号 | 标准名称 | 适用范围 |
|--------|----------|----------|
| GB 2760 | 食品添加剂使用标准 | 添加剂使用判定 |
| GB 2761 | 食品中真菌毒素限量 | 黄曲霉毒素等判定 |
| GB 2762 | 食品中污染物限量 | 重金属等污染物判定 |
| GB 2763 | 食品中农药最大残留限量 | 农药残留判定 |
| GB 29921 | 预包装食品中致病菌限量 | 微生物判定 |
| GB 4789系列 | 食品微生物学检验 | 微生物检验方法 |
| GB 5009系列 | 食品理化检验方法 | 理化检验方法 |

- **拦截规则**：引用已废止标准或非食品安全国家标准作为判定依据 → 【不合规】
- **拦截规则**：检验方法与标准规定方法不一致且未做方法确认 → 【不合规】

### 四、结果判定合规

- 判定结论必须明确"合格"或"不合格"，不得使用模糊表述
- 不合格项目必须列明具体检验值与标准限值
- 对不合格结论，应告知被抽样单位异议期（收到报告之日起7个工作日内可申请复检）
- **拦截规则**：未告知复检权利 → 【不合规】
- **拦截规则**：用"基本合格""大致达标"替代正式判定 → 【不合规】

### 五、快检特殊规则

- 食品快速检测结果不得作为执法依据
- 快检结果不合格的，必须经法定检验机构复检确认后方可作为处置依据
- **拦截规则**：将快检结果直接作为行政处罚依据 → 【严重不合规】

### 六、信息发布合规

- 食品安全风险警示信息、重大食品安全信息由省级以上食品安全监督管理部门统一公布
- 检验机构不得擅自发布食品安全风险信息
- **拦截规则**：机构擅自发布食品安全风险预警 → 【严重不合规】

### 七、用语规范

| 不合规用语 | 合规替代 | 依据 |
|-----------|----------|------|
| "绝对安全""零风险" | 不得使用绝对化用语 | 广告法 |
| "纯天然无污染" | 需有检验数据支撑 | 食品安全法 |
| "治疗/预防疾病" | 食品不得宣称功效 | 食品安全法第73条 |
| "特供""专供" | 禁止使用 | 相关规定 |

## 输出格式

```
【食品安全抽检合规审查报告】

报告类型：xxx
审查时间：xxx

✅ 合规项：x 项
⚠️ 警告项：x 项
❌ 不合规项：x 项

--- 不合规详情 ---
[序号] 问题描述
  → 违反条款：xxx
  → 修改建议：xxx

--- 警告详情 ---
[序号] 问题描述
  → 建议：xxx

【结论】：通过 / 不通过（需修改后复审）
```

## 使用方式

用户提交待审核文本后，逐项对照上述规则进行检查，输出结构化审查报告。

对于严重不合规项（❌），必须明确拦截，建议不得发布。
对于警告项（⚠️），给出修改建议但不强制拦截。
