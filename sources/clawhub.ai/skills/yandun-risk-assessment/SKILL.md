# 研盾 · 风险评估 (yandun-risk-assessment)
> **⚠️ 数据来源与限制（重要披露）：**
> 本Skill为课程教学演示：五维风险评分基于输入参数与**内置演示评分规则**计算（教学简化版），输出为示例性风险评估，并标注「演示评分」。
> 评分结果不构成真实投顾风控结论，不构成投资建议。



## 功能
1. **五维风险评估** — 基本面/技术面/舆情/流动性/尾部风险综合评估
2. **量化指标计算** — 最大回撤、年化波动率、Beta、VaR(95%/99%)
3. **风险等级评定** — 低/中低/中/中高/高 五级风险评级
4. **风险预警** — 标记超阈值的风险信号

## 五维评估框架
| 维度 | 评估内容 | 数据来源 |
|------|---------|---------|
| 基本面风险 | 业绩不确定性、财务健康度、商誉减值 | 财报数据 |
| 技术面风险 | 趋势破位风险、顶部形态、量价背离 | K线+指标 |
| 舆情风险 | 负面新闻、监管关注、品牌危机 | 新闻舆情 |
| 流动性风险 | 成交量变化、换手率、大股东减持 | 交易数据 |
| 尾部风险 | 地缘政治、宏观突变、行业黑天鹅 | 宏观数据 |

## 调用方式
```bash
python3 {baseDir}/scripts/assess_risk.py [--codes sh600519,sz300750] [--output json|text]
```
