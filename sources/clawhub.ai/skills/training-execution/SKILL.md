# 培训执行跟踪

> 输出为参考建议，现场执行由主理人或现场负责人确认。

## 能力概述

培训现场执行的全流程跟踪工具，覆盖：

| 模块 | 功能 |
|------|------|
| 课程执行 | 每模块是否按时启动/结束、讲师出勤、内容完成度 |
| 学员考勤 | 每日签到/签退、出勤率统计、缺勤提醒 |
| 物料管理 | 物料发放记录、剩余库存、补货提醒 |
| 考评测试 | 试卷发放、成绩登记、证书资格确认 |
| 现场日志 | 问题记录、应急处理、学员反馈收集 |

## 输入

- **培训计划书**：课程安排、讲师名单
- **学员花名册**：报名学员信息
- **物料清单**：需发放的物料种类和数量

## 输出

### 每日执行日志

```
📋 第X天执行日志（MM月DD日）

【课程执行】
├─ 09:00-12:00 模块一：XXX — 主讲人：XXX — ✅按计划完成
├─ 13:30-16:30 模块二：XXX — 主讲人：XXX — ✅按计划完成
└─ 17:30-20:00 分组共研 — ⚠️超时15分钟

【学员考勤】
├─ 应到：XX人
├─ 实到：XX人
├─ 出勤率：XX%
└─ 缺勤：XXX（已联系）

【物料发放】
├─ 学员手册：XX本 ✅已发
├─ 工具包：XX套 ✅已发
└─ 证书：待发

【现场问题】
├─ ⚠️ 下午投影故障，5分钟后恢复
└─ ✅ 无其他异常
```

### 培训总结报告

```
📊 第X期研修班执行总结

【总体出勤率】XX%
【课程完成率】XX%（X/X模块按计划完成）
【考评情况】参加XX人，通过XX人，通过率XX%
【学员满意度】（如有收集）
【物料使用】XX%使用率
【问题汇总】X个问题，X个已解决
【经验沉淀】可复用的改进点
```

## 工作流程

1. **初始化**：加载培训计划和学员花名册
2. **每日执行**：记录课程执行、学员出勤、物料发放
3. **问题登记**：记录现场问题和处理结果
4. **考评管理**：组织测试、登记成绩
5. **生成总结**：培训结束后输出执行总结报告
