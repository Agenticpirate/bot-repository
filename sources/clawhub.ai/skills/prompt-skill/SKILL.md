# 楚歌提示词生成器 Skill

> 基于楚歌AIGC公众号的美学提示词方法论
> 一句话输入 → 完整可用的 GPT-image2 提示词输出

## 何时触发

- 用户说「楚歌 / chuge / 写个提示词 / 生成一张[海报/人像/封面] / 做提示词 / 美学提示词 / prompt me」
- 用户给出一句画面需求、想生成图片，且未指定其他模型
- **边界**：仅用于 GPT-image2 图像生成；不用于 Midjourney / DALL·E / 视频 / 3D / UI；不适合纯文案生成（必须有"生成图片"意图）

## 工作流程

```
用户一句话描述需求
   ↓
1. 识别意图 → 用「风格选择表」匹配最贴合的风格编号（可给 1-2 个候选）
2. 读取模板 → 打开 references/templates.md，定位该编号的完整提示词模板
3. 参数填空 → 从需求提取 主题 / 比例 / 文字 / 色彩 / 用途
             缺失关键项（主题、比例）时简短追问，其余用合理默认
4. 色彩分配 → 默认用「五角色色彩法」自动分配（用户指定则尊重）
5. 质检 → 套用「负面清单」过滤（见下）
6. 输出 → 中文提示词 + 英文提示词 + 一句使用说明
```

## 五角色色彩法（自动分配）

对所有提示词自动应用五角色色彩分配法：

| 角色 | 占比 | 生成逻辑 |
|------|------|----------|
| 底色 | 最大面积 | 从主题提取高明度/洁净色 |
| 主体色 | 中等 | 主题材质/情绪温度 |
| 强调色 | 极小 | 高饱和高能点，只 1-2 处 |
| 结构色 | 线框/阴影 | 中低明度结构色 |
| 信息色 | 文字层 | 高对比白色/浅色 |

**默认过滤清单（必须规避）：** ❌浑浊　❌陈旧　❌灰脏　❌烟灰　❌复古泛黄

## 排版与文风规则

- 第一眼：大标题/大字 → 主体 → 细节注释
- 字号梯度：主标题极大 > 副标题大 > 辅助文字小 > 微型注释极小
- 上方保留大面积呼吸空间（上面空下面实）
- 文字要像"从画面里长出来的"，不是贴上去的
- 用楚歌标志性写法：用"像……"打比方引导 AI 理解感觉；先感性（感觉/情绪）再理性（结构/参数）；破折号 + 排比制造节奏；末尾用 `——————` 分隔参数填空

## 增强能力（双语 / 混搭 / 迭代）

- **双语输出**：中文版供用户校对阅读，英文版用于实际喂给 GPT-image2（英文遵循度通常更好）。翻译时保持结构一致，仅切换语言，不要增删要素。
- **风格混搭**：用户要求"A + B 结合"时，保留两个风格的签名元素，以一个为主、另一个点缀，避免元素互相打架；必要时向用户确认主从。
- **迭代优化**：用户对成图不满意时，询问"想调整哪一维（构图 / 色彩 / 文字 / 主体 / 情绪）"，仅改该维度并重生成，不整体推翻。
