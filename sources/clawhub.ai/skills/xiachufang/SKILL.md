# 下厨房菜谱与家常烹饪 Skill

下厨房是中国最大的 UGC 菜谱社区，同一道菜常有几百个版本——
**会筛菜谱比会做菜更先决**。本 skill 教 agent 用社区信号选出
靠谱版本，并把菜谱转成可执行的做饭计划。

## 怎么筛出靠谱菜谱（社区信号解读）

1. **"做过"数是金标准**：几千人"做过"的版本经过了大规模复现
   验证，优先级高于标题花哨的新菜谱
2. **看"做过"作品图**：普通用户复现图接近你的真实产出；
   如果作者图精美但复现图翻车率高，说明菜谱写得不可复现
3. **看差评关键词**：翻"做过"里的吐槽（太咸/时间不对/比例有问题），
   常能提前拿到修正参数
4. 同菜多版本对比：新手选步骤图完整、用料克数明确的版本，
   避开"盐适量、火候看感觉"型菜谱

## 菜谱 → 做饭计划（agent 核心价值）

1. **购物清单合并**：多道菜的用料去重合并，按超市动线分组
   （蔬菜/肉禽/调料/冷冻）
2. **备菜时间线倒排**：按"耗时最长的先动手 + 灶台占用不冲突"
   排任务，例：先炖汤（40 分钟无人值守）→ 腌肉 → 切配 → 快炒收尾
3. **份量换算**：菜谱人份 ≠ 你的人数时按比例换算，但**调味料
   不等比放大**（盐建议先按 70% 放，尝后补）
4. 厨具替换：没有烤箱/空气炸锅时给平底锅等价方案，并提示口感差异

## 新手概念速查

| 术语 | 意思与要点 |
|------|-----------|
| 焯水 | 沸水快烫去腥去涩；绿叶菜加几滴油保色，肉类冷水下锅 |
| 上浆/挂糊 | 淀粉蛋清裹肉保嫩；浆是薄层，糊是厚层（炸物） |
| 收汁 | 大火蒸发汤汁变稠；有糖的酱汁最后收，早收易糊 |
| 炝锅/爆香 | 冷油下葱姜蒜小火出香再下主料，油温过高会苦 |
| 断生 | 刚熟的临界点；蔬菜断生即出锅，余温会继续加热 |

## 失败复盘框架

用户报"这道菜失败了"时按序排查：**盐（调味比例）→ 火（火候与
锅温）→ 时（每步时长）→ 料（食材新鲜度与替换）**，
定位后给下次的具体修正参数，而不是空泛的"多练"。

## Agent 典型用法

1. **今晚吃什么**：按冰箱现有食材反推可做菜谱，给购物补差清单
2. **宴客规划**：N 道菜的购物清单合并 + 备菜时间线倒排 +
   灶台调度（哪道先做能保温）
3. **菜谱翻译**："适量/少许"型菜谱补上具体克数区间与判断标准
4. **失败诊断**：按复盘框架定位翻车原因，给修正参数

## 本 skill 不做什么

- 不提供爬取下厨房数据的方法；筛选方法基于公开可见的社区信号
- 涉及食品安全一律从严：肉禽蛋熟透、隔夜菜冷藏与复热标准
  不做妥协性建议
- 特殊饮食（婴幼儿/孕期/慢性病）建议咨询专业人士，本 skill
  只做常规家常烹饪
