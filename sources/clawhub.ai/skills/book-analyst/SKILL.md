# 图书智能解读系统 v1.1

## 概述

以专业图书分析专家的角色，对指定图书进行系统、深入且实用的解读分析，产出帮助读者快速把握核心内容、获取实践指导、并顺着"书脉"延伸阅读的解读报告。

v1.1 相对 v1.0 的新增能力：
1. **线头梳理**：每份报告末尾附 2-4 本同类图书推荐，逐本标注与本书的关联"线头"类型与阅读顺序
2. **评分量规校准**：📚🎯⚡ 三档评分按可对照的量规给出，并附一句理由
3. **引文真实性规则**：所有引用带来源状态标注，杜绝伪引文
4. **交付自查清单**：报告交付前逐项自查
5. **mermaid 思维导图**：第 7 节思维导图用 mermaid 语法输出
6. **HTML 可视化报告**：默认双格式交付（Markdown + 单文件 HTML）

## 触发场景

- 用户提供书名，要求解读、分析、拆解该书
- 用户提供图书的章节文本、笔记、摘录或 PDF 内容
- 用户要求生成读书报告、书籍精华、阅读指南
- 用户询问"读完这本书还可以读什么 / 同类书有哪些"（线头梳理单独触发时，输出同类图书推荐清单即可）

## 版本与文件结构

```
book-analyst/
├── SKILL.md                # 本文件：流程与触发
└── references/
    └── report-spec.md      # 输出规范权威来源（必读）
```

**每次产出报告前，必须完整读取 references/report-spec.md**，以其为准执行：13 节输出模板、评分量规、引文真实性细则、交付自查清单、mermaid 导图规范、HTML 报告规范、线头梳理方法。本文件与 report-spec.md 冲突时，以 report-spec.md 为准。

## 工作流程

### 第一步：确认分析对象与材料

- 判断**书籍类型**：实用类 / 学术类 / 文学类 / 传记类，据此微调各节侧重点（如实用书加重行动指南，学术书加重论证与批判，文学书加重主题与人物，传记书加重脉络与启示）
- 材料判定：
  - 用户提供了文本材料（PDF、章节文本、笔记、摘录）→ 以材料为唯一事实来源，先完成文本读取与章节文本抽取
  - 仅有书名 → 基于该书公开公认的内容分析，全程遵守引文真实性规则（详见 report-spec.md 第四节）

### 第二步：执行 13 维分析

按顺序完成：基础信息 → 内容框架 → 核心观点（3-5 论点+证据+创新见解）→ 关键概念 → 精彩片段（带来源状态）→ 三层应用价值 → **mermaid 思维导图** → 批判性思考 → 行动指南 → 阅读建议 → 核心问答 → 延伸思考 → **同类图书推荐（线头梳理）**。

各节的具体写法、格式与硬性要求以 report-spec.md 为准。

### 第三步：双格式交付

1. 生成 **Markdown 完整报告**：严格对照 report-spec.md 的 13 节模板与自查清单
2. 生成 **HTML 可视化报告**：同一内容的单文件渲染版（结构规范见 report-spec.md 第七节）
3. 文件命名：`<书名>-解读报告.md` 与 `<书名>-解读报告.html`
4. 用 present_files 同时呈现两个文件（HTML 在前，md 在后）

## 质量红线（速查）

1. **不编造**：禁止伪造引文措辞、页码、章节标题；禁止推荐不存在的书目
2. **来源状态**：每条引用/推荐要么标注 [原文]/[大意]，要么有明确依据
3. **评分可解释**：三个评分必须对应量规档位并附一句理由
4. **交付前自查**：逐项过 report-spec.md 第六节自查清单，不通过不发
