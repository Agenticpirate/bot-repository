# Demo Ingest Skill

This is a demo skill created to illustrate the complete workflow of content ingestion:
from creation and processing to publishing into the resource center (ClawHub).

## Purpose

- Demonstrate skill structure
- Test the ingest workflow
- Serve as a reference for skill creation
