## 核心原则

1. **不污染cheat-on-content**：所有大赛相关产出在 `demo/` 下，不修改cheat-on-content的skill/rubric/state
2. **每个demo独立**：`demo/<NN>-<name>/` 下包含完整申报材料
3. **预测调用cheat-on-content**：打分预测时读取 `rubric_notes.md` 和 `starter-rubrics/` 的评分体系
4. **引导式互动**：每个阶段产出后展示给用户，等用户确认/修改后再进入下一阶段
5. **序号自动递增**：从01开始，新建demo时读取 `state.md` 取最大序号+1
6. **数据分离**：隐私数据（demo进度、经验、账号上下文）存 `state.md`，本文件只含工作流模板

## 引导式互动流程（8阶段）

### 阶段0：Onboarding — 介绍规则

**触发条件**：用户首次触发trae-hot，或说"开始新demo"、"规则是什么"

**动作**：
1. 读取 `state.md` 获取当前进度
2. 展示上方开场白
3. 如果用户是第一次，引导浏览大赛官网置顶帖了解完整规则
4. 询问：要做新选题还是继续已有demo

**产出**：无文件，纯对话引导

---

### 阶段1：选题 — 确定方向

**触发条件**：用户说"做新选题"、"新demo"、"我想做一个xxx"

**动作**：
1. 和用户讨论选题方向，确认：
   - 赛道（四选一 + 可选社会公益）
   - 产品形态（App/小程序/网站/系统/硬件）
   - 想解决什么痛点
   - 目标用户是谁
2. 帮用户做选题合规检查（见下方清单）
3. 探讨产品设计：核心功能、差异化、价值主张
4. 用户确认后，读取 `state.md` 取最大序号+1，创建目录 `demo/<NN>-<name>/`
5. 产出 `选题.md`，更新 `state.md`

**产出**：`demo/<NN>-<name>/选题.md`

**选题.md模板**：
```markdown
# <NN> - <Demo名称>

## 基本信息
- 赛道：生活娱乐/学习工作/社会服务/硬件交互
- 附加赛道：社会公益（可选）
- 产品形态：App/小程序/网站/系统/硬件

## 创意描述
- 想解决什么问题
- 灵感来源
- 一句话概括产品

## 目标用户
- 核心用户群体
- 使用场景
- 当前痛点

## 价值主张
- 商业价值/效率提升/社会价值（选1-2个角度）

## 差异化
- 和已有方案的区别
```

**确认后才进入阶段2**

---

### 阶段2：报名帖

**触发条件**：选题确认后，或用户说"写报名帖"

**动作**：
1. 基于选题.md，按报名帖模板起草 `报名帖.md`
2. 展示给用户，等待反馈
3. 用户可要求修改任何部分（标题、标签、正文、措辞）
4. 用户确认后，提醒：**"请在TRAE社区报名专区发布，并上传HTML文件"**

**产出**：`demo/<NN>-<name>/报名帖.md`

**报名帖模板**：
```markdown
# 报名帖

**【标题】** 【赛道名称】Demo名称

**【标签】** 赛道标签（+ 社会公益，如有）

**【正文】**

**1. 创意名称 + 创意介绍**
- 想解决什么问题
- 为什么会想到做这个
- 大概是什么产品

**2. 目标用户及痛点**
- 面向哪些用户
- 在什么场景下使用
- 当前痛点

**3. 价值与意义**
- 商业价值/效率提升/社会价值

**4. 必须附带**
- HTML文件上传
```

> 字数≥100字。HTML文件在阶段3生成。

**确认后才进入阶段3**

---

### 阶段3：HTML产品介绍页

**触发条件**：报名帖确认后，或用户说"做HTML"、"产品页"

**动作**：
1. 基于选题和报名帖内容，用TRAE生成单HTML产品介绍页
2. 要求：
   - 精美UI设计（根据产品调性选择风格）
   - 展示核心功能（痛点→方案→价值的故事线）
   - 响应式布局（桌面+平板+手机）
   - 包含交互元素（动画、hover效果等）
   - 纯单文件，可直接在浏览器打开
3. 保存为 `产品介绍页.html`
4. 提醒用户：**"这个HTML文件需要上传到报名帖作为附件"**

**产出**：`demo/<NN>-<name>/产品介绍页.html`

**确认后才进入阶段4**

---

### 阶段4：初赛深化设计

**触发条件**：用户反馈"报名通过了"、"报名初审过了"、"可以做初赛了"

**前提检查**：确认报名帖已审核通过。初赛作品有效的前提是报名审核已通过，否则不进入评审。

**动作**：
1. 恭喜用户通过报名
2. 结合初赛官方要求，和用户讨论如何深化demo：
   - 初赛评审4维度：创新性、实用性、完成度、技术实现
   - 初赛帖要求：Demo简介 + 创作思路 + 体验地址（三选一） + TRAE实践过程（≥3截图+≥3 Session ID）
   - 是否需要增加功能、优化UI、补充交互
3. **C/S架构桌面端应用处理**：不需要提交源码或安装包。只需确保交互式HTML产品介绍页质量过关，打包zip上传即可。
4. 如果需要部署在线体验链接，帮用户部署
5. 用户确认demo就绪后进入阶段5

**产出**：深化后的demo（可能是更新HTML或新增代码文件）

**确认后才进入阶段5**

---

### 阶段5：初赛帖

**触发条件**：初赛demo就绪，或用户说"写初赛帖"

**动作**：
1. 按初赛帖模板起草 `初赛帖.md`
2. 展示给用户，**明确提醒用户确认或提出修改意见**
3. 提醒用户准备：
   - ≥3张TRAE开发过程截图（放到 `素材/` 目录）
   - ≥3个关键对话Session ID（双击TRAE对话即可复制）
   - **报名帖URL**：提示用户把报名帖链接发过来，填入初赛帖底部的"附：报名帖链接"
4. **⚠️ 用户确认初赛帖草稿后，必须进入阶段5B（模拟评委打分）！** 不可跳过直接发布。
5. 阶段5B打分完成后，展示优化建议，提醒用户修改初赛帖。用户确认最终版后，提醒发布。
6. **重要提醒**：

```
📢 初赛帖发布前，确认以下事项：

✅ 截图（≥3张）已放入demo目录
✅ Session ID（≥3个）已填入
✅ 报名帖URL已填入初赛帖底部

📢 初赛帖发布后，要做三件事：

1️⃣ 在初赛专区发帖：https://forum.trae.cn/c/38-category/40-category/40

2️⃣ 抖音发布视频，带话题 #vibecoding大赏 #traeai创造力大赛
   并 @TRAE @抖音科技
   （人气分 = 点赞+评论×2+收藏+转发，点赞≥500才入榜）

3️⃣ 申领5W流量券！填写问卷：
   https://bytedance.larkoffice.com/share/base/form/shrcnzp18Sdf6XQxm8wGPPXDt4b
   ⏰ 每个初赛作品都可以申领一次！名额有限，先到先得！

4️⃣ 发帖后，把初赛帖链接发回来，我帮你记录到回收文档里
```

**产出**：`demo/<NN>-<name>/初赛帖.md`

**初赛帖模板**：
```markdown
# 初赛帖

**【标题】** 【赛道名称】+ Demo名称（示例：【学习工作赛道】+ LiveBuddy数字人直播伴侣）

**【标签】** 主赛道标签（生活娱乐/学习工作/社会服务/硬件交互 四选一）+ 附加赛题可加选 社会公益

**【正文】**

**0. 先和大家打个招呼吧 👋**

你是谁：用一句话介绍你的职业/身份（如：13年IT高级工程师 / 大三学生 / 独立开发者……）；

你是怎么用TRAE把Demo做出来的：说说你和TRAE「配合」的真实感受。比如：是怎么把脑子里的想法一句句讲给它听的？哪一步让你觉得「原来这么简单」？它帮你跨过了哪个原本以为搞不定的坎？

**1. Demo简介**
- 是什么
- 面向谁
- 主要功能（2-3个，配截图）

**2. Demo创作思路**
- 灵感来源
- 想解决的问题
- 为什么做这个方向

**3. Demo体验地址**
- 部署链接 / 交互式HTML文件Zip / 演示视频链接（三选一）

**4. TRAE实践过程**
- 开发流程描述
- 关键步骤截图（≥3张）
- 关键对话Session ID（≥3个，**必须完整显示，不可省略或缩写**。格式为 `数字:hash_后缀hash.后缀hash.后缀hash`，末尾的 `_xxxx...` 后缀不可省略，必须完整粘贴）
- 附上通过的报名帖链接
```

**确认后才进入阶段5B**

### 阶段5B：模拟评委打分 ⭐

**触发条件**：阶段5完成，用户说"准备发版"、"模拟打分"、"评委打分"，或用户确认初赛帖准备发布时

**动作**：
1. 基于初赛帖和HTML产品页，启动7位独立人格评委进行模拟评审
2. 每位评委按4维度打分（每维度10分）+ 给出通过/不通过 + 点评意见
3. 汇总7位评委总分，取平均分，给出综合评审结论
4. 产出 `模拟评委打分.md`，展示给用户
5. 根据评委意见，提示用户需要在哪些方面优化
6. 用户优化后再次确认，提醒发布
7. **发布后，提醒用户把初赛帖链接发回来，记录到回收文档**

### Session ID获取方法

在TRAE对话中，**双击对话即可复制Session ID**。初赛帖需附≥3个关键任务的Session ID，用于证明作品由TRAE开发完成。

**⚠️ 完整格式（3段都不能丢！）**：Session ID 由三段用 `:` 拼接而成，**任何一段都不能截断！** 完整格式：

```
数字:hash_后缀hash.后缀hash.后缀hash:客户端元数据.0.1.21.no_sid.no_ppe.T(时间戳)
```

例如：
```
你的数字ID:hash_你的hash1.你的hash2.你的hash3:TRAE Work CN.0.1.xx.no_sid.no_ppe.T(时间戳)
```

**绝不能拆分！** 常见错误：
- ❌ 错误：只保留前两段 `数字:hash_后缀`（漏掉客户端元数据+时间戳）
- ❌ 错误：以为 `_xxxx...` 后缀是边界就停
- ❌ 错误：以为 `数字:hash` 之后是固定格式可以省略
- ✅ 正确：原样整行粘贴，不做任何拆分、缩写、删减

**如何避免出错**：用户提供的 session.txt 文件（每行一条完整 Session ID）→ **整行原样粘贴**到初赛帖中，不要做"看起来已经够长"的截断判断。

### 重要FAQ

- **多个创意都过了报名，初赛能都提交吗？** 可以提交多个对应的Demo，但晋级复赛只取同账号下得分最高的1个作品。
