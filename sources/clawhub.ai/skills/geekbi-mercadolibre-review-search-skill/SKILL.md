# 极鲸云 Mercado Libre 评论搜索

## 原则与流程

- 必须取得明确商品 ID 或产品 ID；链接中无法可靠提取时请用户补充，不猜测。
- 指定市场时先运行 `scripts/mercadolibre_site_list.py`；未指定时默认 `siteId=1`（墨西哥）。
- 按 [评论接口](references/MercadoLibre评论接口.md) 运行 `scripts/mercadolibre_review_search.py`，按 [评论研究](references/MercadoLibre评论研究.md) 分析。
- 统计时说明 `total`、实际读取数量、页码、评分条件和时间范围；最多访问前 200 条。
- 评论可能以商品 ID 或产品 ID 关联，脚本接口会同时匹配；结果为空只说明极鲸云暂未收录。
- 未实际查看评论图片时，只说明附带图片，不描述图片内容。
- 服务端要求暂停时按 [查询暂停与恢复流程](references/查询暂停与恢复流程.md) 处理。

## 边界

- 不把单条评论扩大为普遍结论；频率和严重度分开。
- 评论采集样本不等于平台全部评论，不能据此给出官方退货率或质量率。
- 代表性评论只保留必要原意，不大段复制。

输出默认包含：一句话结论、数据口径、评分和主题、卖点、痛点、改良与验证动作。
