# KT 合同审查专家 Skill

> ⚠️ **阅读前必读：能力范围**
> 
> 本 skill 是基于 用户的 25 份真实合同修改经验提炼的合同审查工具。  
> **不能替代专业法律意见**，仅供合同初稿审查和方向性建议使用。
> 
> 涉及重大商业决策时，请咨询专业律师。

---

## 这是什么

基于 用户 25 份真实合同修改经验（截至 2026-08-19），自动识别合同中的高风险条款，按 资深合同顾问 的修改习惯给出**修改方向**和**典型改法**。

**核心特点：**
- 📚 100 条修改习惯（#1-#220）+ 34 条新追加（#187-#220）
- 🎯 7 大修改原则（过错责任、双向约束、催告程序、责任上限等）
- 📋 案例驱动（每条习惯都有真实合同出处）

---

## 适用场景

**适合：**
- ✅ 房地产/建设工程类合同审查
- ✅ 销售/采购/施工/安装合同审查
- ✅ 合作类合同审查（景区、设备投放、运营合作）
- ✅ 政府/事业单位合作合同审查
- ✅ 起草新合同前参考 资深合同顾问 的修改风格

**不适合：**
- ❌ 金融/股权/并购类合同（建议用 `china-contract-review`）
- ❌ 劳动人事类合同（建议用 `labor-contract-review`）
- ❌ 涉外合同（建议用 `legal-document-assistant`）

## 执行流程

### 第一步：识别合同类型与立场

```python
# 自动识别
合同类型 = detect_type(contract_text)  # 房地产/建设工程/合作类
立场 = determine_position(contract_text)  # 资深合同顾问 是甲方/乙方
```

### 第二步：按 7 大原则扫描

```python
risks = []
risks += check_principle_1(text)  # 过错责任
risks += check_principle_2(text)  # 双向约束
risks += check_principle_3(text)  # 催告程序
risks += check_principle_4(text)  # 责任上限
risks += check_principle_5(text)  # 甲方免责
risks += check_principle_6(text)  # 紧急补偿
risks += check_principle_7(text)  # 格式规范
```

### 第三步：按 34 条具体习惯细查

```python
for habit in habits_187_to_220:
    matches = habit.pattern.search(text)
    if matches:
        risks.append(habit.report(matches))
```

### 第四步：输出风险评估

按 `高/中/低` 风险等级输出，每条标注：
- 条款位置（编号）
- 原文
- 修改建议
- 法律依据（如适用）

## 核心修改原则（7 大方向）

| # | 原则 | 说明 | 典型场景 |
|---|------|------|---------|
| ① | **过错责任原则** | 把乙方全责改为"乙方在过错范围内承担" | 几乎所有责任条款 |
| ② | **双向约束** | 原版只约束乙方，同步加甲方对等义务 | 营收造假、设备干扰、协助义务 |
| ③ | **7 日催告** | 解约前给 7 日补救期 | 所有解约条款 |
| ④ | **责任上限** | 累计赔偿不超过 12 个月已支付分成 | 违约责任、赔偿条款 |
| ⑤ | **甲方免责** | 非乙方原因导致的不担责 | 设备故障、行政处罚 |
| ⑥ | **紧急补偿** | 甲方单方免责改为补偿合理损失 | 紧急情形、政府原因 |
| ⑦ | **格式规范** | 统一用语、编号、空白格式 | 全文 |

## 34 条新追加习惯（#187-#220）

### A. 责任分配类（7 条）

| # | 习惯名 | 一句话总结 |
|---|--------|----------|
| 187 | 过错责任原则统一贯彻 | "全部由乙方承担" → "乙方在过错范围内承担" |
| 188 | 双向约束条款 | 乙方造假要赔，甲方干扰后台也要赔 |
| 191 | 甲方原因免责条款 | 因甲方原因导致的，乙方不担责 |
| 196 | 消防责任范围缩窄 | 乙方只对设备部分负责，不扩大到场地整体 |
| 208 | 保险投保资料配合义务 | 甲方资料延误导致乙方无法投保，甲方要赔 |
| 209 | 审批手续抗辩权 | 被行政查处≠乙方违约，可抗辩 |
| 210 | 知识产权素材瑕疵责任 | 素材本身瑕疵由甲方担责 |

### B. 催告+程序类（5 条）

| # | 习惯名 | 一句话总结 |
|---|--------|----------|
| 189 | 7 日书面催告程序 | 解约前必须先发书面催告 |
| 197 | 图纸审查默示同意 | 甲方 7 工作日未表态视为同意 |
| 202 | 紧急抢修豁免通知前置 | 紧急抢修免甲方书面同意 |
| 214 | 接收确认表催告程序 | 5 日催告后才视为已交付 |
| 215 | 维修催告程序 | 书面催告后仍不修才可解约 |

### C. 赔偿与上限类（4 条）

| # | 习惯名 | 一句话总结 |
|---|--------|----------|
| 190 | 累计赔偿责任上限 | 不超过 12 个月已付分成 |
| 199 | 逾期付款违约金上限 | 不超过逾期金额的 20% |
| 200 | 赔偿范围排除间接/商誉 | 限直接经济损失 |
| 218 | 责任上限与具体上限关系 | 多重上限以较低者为准 |

### D. 风险隔离类（4 条）

| # | 习惯名 | 一句话总结 |
|---|--------|----------|
| 192 | 紧急情形补偿机制 | 甲方单方免责 → 改为补偿合理损失 |
| 194 | 甲方电力/场地义务量化 | 未提前通知断电要赔 |
| 198 | 政府原因举证倒置 | 甲方必须提供政府批文 |
| 205 | 物品清理双向免责 | 不可抗力/甲方原因乙方不担责 |

### E. 退出与补偿类（4 条）

| # | 习惯名 | 一句话总结 |
|---|--------|----------|
| 193 | 优先续约权 | 乙方享有同等条件下优先续约权 |
| 211 | 改造后退出权 | 新点位不满足基本要求乙方可退出 |
| 212 | 设备调整提前通知期 | 至少提前 15 工作日 |
| 219 | 终止补偿协商机制 | 金额由双方协商确定 |

### F. 数据/技术类（4 条）

| 206 | 数据后台双向保护 | 甲方不得干扰后台，否则赔乙方损失 |
| 213 | 抗辩+赔偿反制条款 | 乙方可抗辩+反诉 |
| 220 | 不可抗力定义程序化 | 通知+证明+持续期+结算 |

## 案例应用：文旅中国·智能设备合作协议

**背景：**
- 乙方：某智能设备运营公司（资深合同顾问 是乙方）
- 甲方：某景区运营方
- 类型：智能终端设备投放合作

**7 大重点保护条款：**

1. **5.1.2** 甲方原因断电/封闭 → 收益减免 + 损失赔偿
2. **5.1.4** 设备损毁 → 乙方主要风险，但甲方过错要赔
3. **5.1.11** 紧急情形 → 收益减免 + 终止要补偿乙方
4. **5.2.5** 消防责任 → 仅乙方设备部分
5. **7.2** 数据查阅 → 仅限核对账目，终止后仍有效
6. **10.4 + 10.10** 累计赔偿上限 12 个月分成
7. **3.3 双向约束** 甲方干扰后台要赔
