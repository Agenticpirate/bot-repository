# 公文优化（Gongwen Optimize）

## Overview

本 skill 把"公文优化"方法化、可复用化。它**不按文体套模板**，而提供一套"意图驱动 + 通用结构规则"
的诊断—改写—解析工作流，适用于党政机关、企事业单位各类公文的润色与完善。

贯穿所有场景的真正规律只有四条（与文体无关）：
1. **意图驱动**——先弄清作者写这段话到底想达成什么、希望对方产生什么改变，再动手。
2. **标题有价值**——独立成文/章节必须有"金句"式标题，而不是"关于XX的汇报"这种平铺直叙。
3. **层次与逻辑可优化**——总-分-总、拆维度、分情形、排比；同一逻辑层级的并列项必须对仗。
4. **表达价值密度可提升**——用领域标准术语把模糊处写透、单薄处写厚，去口语、强化动词、嵌政策热词。

触发信号（命中即调用）：用户给出一段原文并出现"优化""润色""完善""修改""改改""帮我提升"
"丰富细节""看看这函/汇报/请示/案例/讲话/发言"等；或粘贴公文草稿要求改进。

不触发：纯格式排版（转 docx/套红头）请走 `format-official-docx`；新建空白公文模板而非优化已有草稿。

**两条不可逾越的红线（针对"内容"，最优先于一切润色）**：
1. **不臆造内容（分清"禁添"与"可丰富"）**：意图识别是为了"判断这段话要实现什么目的"，
   绝不是让你乱加东西；但"优化"的核心价值恰恰是用领域知识把内容**写厚、写透**。
   - **严禁凭空添加**：原文没有的**具体硬数据/成效数字/专有事实**（如原文未提的投资额、覆盖率、
     未发生的成效）一律不得编造；**真实姓名/职务**不得编造。
   - **▸ 讲话稿/发言稿例外（文种结构，非臆造）**：当其明确为"讲话/发言/致辞/表态"形态时，
     应补全标准发言结构——开场（"尊敬的\[对方称呼\]：""大家上午/下午好！"）+ 结尾
     （"各位领导、同志们""谢谢大家！"）。具体人名/职务用**占位符**代填
     （如 `[您的职务]` `[您的姓名]` `[XX主席]`），**不得编造真实姓名职务**；若用户已给明称谓则直接用。
   - **允许且鼓励"丰富"**（尤其当用户要求"完善/丰富细节"时，或优化对象为讲话稿/申报材料时）：
     * **起势/背景铺垫句**：用"近期，我单位（我区）紧抓…机遇，扎实推进…"等公文标准开篇立住基调
       ——以"我单位/我区"为行文主语，属报告惯例，**非新增收件人**。
     * **领域标准场景与成效展开**：基于项目类型，用新基建/数字政府等领域**标准术语**具象化
       "这个平台/项目能干什么、达到什么效果"（如"一网监管平台"→可视可管可控、保障低空物流文旅
       场景安全；"城市大脑"→打破数据壁垒、一网统管、态势感知预警预测协同处置）。
     * **政策热词 / 政治站位拔高**：如"基层减负增效""一网统管""智慧中枢""高质量发展的重要一环"
       "肩负…重大使命"，提升政务高度（讲话稿尤需）。
   - 一句话：**不编真实姓名职务与硬数据，但要用标准术语、占位符结构、对仗金词把模糊处讲透、把单薄处写厚。**
2. **默认不落盘**：优化结果默认在对话中直接输出；不生成 .md 文件，除非用户明确要求保存或导出。

## 核心方法论（通用，优先于文体）

> 无论来的是什么文体，都走下面这套通用流程。文体差异（复函/汇报/讲话…）只影响"策略侧重"，
> 不改变通用规则本身。具体"某意图类型要额外注意什么"以及语气、结构模板、词例见文末**附录 A–D**。

### 第一步：提取意图（最高优先级，决定一切）
**核心纪律：先搞清楚"作者为什么写这段话、想让对方做什么、期望对方产生什么改变"，再动手优化。**
脱离意图的润色只是文字游戏；只有锚定意图，后续诊断与改写才有针对性。

**意图四问（先做判断，不产出任何新增文字）**：
1. **作者真实目的**：写这段话究竟想达成什么结果？——不是字面文种，而是背后的沟通意图
   （例如"拒绝但不得罪""让领导知情""帮领导做分情形决策""展示工作成效""评优挣政绩"
   "发言致辞争取支持"）。
2. **文本逻辑主线**：这段话内在是按什么维度组织的？（如"挖存量/拓增量/抓项目"三维度、
   "背景—做法—成效"三段式、"欢迎—成绩—诉求"讲话三段式）。识别主线，优化时才不破坏原结构。
3. **接收方角色（以原文明示为准）**：对方是拍板人 / 协同方 / 评审方 / 外部受众？原文未点明则不臆造。
4. **期望改变**：希望对方读完后产生什么认知 / 态度 / 行动变化？

并补充一项：**丰富程度需求**——用户是否要求"完善/丰富细节"？若是，则改写须主动展开领域标准场景与成效。

**隐藏战略张力（来自通用润色方法论）**：若草稿隐含"风险 vs 机会""拒绝 vs 合作""审慎 vs 支持"
"短期动作 vs 长期设计"等战略张力，改写前用一句话点明（如"底层逻辑似乎是…"），帮助用户判断改写是否对准目标；
若意图明显，则只在内部使用、直接给成品。

**将意图归类为下表的"意图类型"，用于第三步选择策略侧重**（注意：意图类型只决定"额外侧重"，
通用规则对所有类型一律适用）：

| 意图类型 | 典型场景 | 额外策略侧重 | 附录提示 |
|---|---|---|---|
| 拒绝/设边界 | 无法满足平级/上级请求 | 讲客观风险 + 给替代配合，不得罪对方 | A / C |
| 汇报进展 | 让上级/读者知情、展示成效 | 结构化、突出结果、结论前置、**丰富场景与成效** | A / B |
| 请示/求授权 | 要领导拍板、给资源 | 委婉、给选择余地、结论先行 | A / B |
| 研判/参谋 | 帮决策者在信息不对称下做分情形判断 | 判断清晰、分情形、给可操作建议 | A / B |
| 申报/展示 | 评优、挣政绩、经验交流 | 政务高度、对仗、摘要、框架 | A / C |
| 商洽/协调 | 平级协作、商请配合 | 尊重、共赢、明确诉求 | A / C |
| 说服/争取 | 要资源、要政策支持 | 利益驱动、数据支撑、路径可行、建设性诉求 | A / B / C |
| 发言/致辞 | 调研座谈、大会发言、表态 | 标准结构 + 政治站位 + 排比气势 + 建设性诉求 | A / B / C |

### 第二步：通用诊断框架（不分文体）
诊断须**围绕第一步识别的意图与逻辑主线**展开——重点找"哪些表达偏离或削弱了意图"，而非单纯挑语病。
从五个通用维度审视草稿（可先肯定优点再指出不足，保持建设性）：

1. **意图锚定**：哪些表述偏离或削弱了意图？例如拒绝时只说"不行"却没给理由/留余地；
   向上级提诉求太直白、缺建设性与逻辑支撑；汇报时亮点淹没在长句里。
2. **层次与逻辑**（最关键的结构维度）：
   - 是否总-分-总、有一条清晰主线？
   - **同一逻辑层的并列项是否对仗平行？**（领起句字数、结构、词性是否一致）
   - 长段是否塞了多维内容，需拆维度？（如"创新点"挤一段 → 拆模式/协同/技术）
   - 有无阶段混淆？如"预期效果"与"实际成效"前后重叠、"目标"与"成效"不分。
   - **层次要素是否混杂**（来自通用润色方法论）：背景/事实/对方诉求/判断/措施/成效/风险/下一步
     是否各归其位？尤其注意：**企业诉求不得混同为政府决策**、宣传口号不得混同为工作成效、
     技术细节不得混同为战略结论。
3. **标题价值**：独立成文或独立章节是否需要标题？现有标题是否平铺直叙
   （如"关于XX的汇报""XX情况报告"）？应凝练为"金句+实题"式有价值标题。
4. **表达质量**：有无口语词、冗余、动词力度弱、错别字、病句、重复用词过多？
5. **红线检查**：有无臆造收件人/真实姓名职务/硬数据？讲话稿是否误把占位符写成真名？

### 第三步：七条通用优化规则（本 skill 主体，不分文体）
按第一步意图，逐条套用以下通用规则。**这些规则对所有文体一律适用**，文体差异仅作额外侧重提示（附录）。

**规则1 · 意图锚定改写**：所有版本与每处改动都必须服务于第一步识别的意图与逻辑主线。
凡对意图无益甚至削弱的表达，一律优化；改写后自检"这处改动让意图更清晰了吗"。

**规则2 · 标题凝练（拒绝平铺直叙）**：当原文是独立成文、独立章节或一大段汇报时，必须给出有价值标题。
- **主标题（成文/大章）**："金句主标题 + 实题副标题"范式，主标题点精神、不写"关于XX"。
  - 模式A 动宾对仗：`聚焦增值赋能 打造智办标杆`
  - 模式B 抢抓X+谋划Y：`抢抓低空经济新赛道 前瞻谋划产业布局`
  - 模式C 破解X+实现Y：`破解政策壁垒 实现秒懂秒配`
  - 模式D 数字概括：`三个聚力` / `向存量要增量、向生态要动能、向项目要后劲`
  - 副标题写实：`——某地区依托政务智能辅助工具构建政务服务新生态`
- **小标题（同级并列）**：领起句同结构（2+2 / 四字 / 六字动词短语），可嵌引号金词，
  使审阅者一眼见气势（详见规则3）。
- 注意：若原文仅为正文片段/要点罗列、用户未要求成篇，则不强行加主标题，仅优化小标题与表达。

**规则3 · 同层必对仗（同一层次要对仗）**：在逻辑树上**同一父节点下的并列项，领起句必须平行对仗**。
- 判定同级：它们是同一个层级、并列关系（如"一是/二是/三是""第一/第二/第三"的兄弟节点）。
- 要求：领起句**同字数、同词性、同句式**；最好形成对仗金句。
- 反例（不平行）：`一是关于低空经济领域项目谋划情况` / `二是谋划人工智能赋能基层应用` /
  `三是基层治理，这块是正在谋划城市大脑的项目`（第三点口语、三句结构不一）。
- 正例（平行对仗）：`一是抢抓"低空经济"新赛道，前瞻谋划产业布局` /
  `二是聚焦"人工智能+"，赋能基层办公数字化转型` / `三是深化"智慧治理"，高标准谋划"城市大脑"项目`。
- 若原文某并列项缺领起句，应补齐使结构平行（如补`三是紧盯重大项目，蓄积长远发展后劲`）。
- 进阶：相邻小标题避免重复同一词（除非刻意）；用"存量/生态/项目""基础/资源/人才""现状/机遇/路径"
  等递进词链替代重复词。

**规则4 · 层次与逻辑重构**：让结构更清晰、有气势。
- **总-分-总 / 主线检查**：确保有一条贯穿主线，结尾回扣。
- **层次要素归位**（来自通用润色方法论）：把混杂的内容拆回其应有层次——
  背景（为何其事）、事实（已知/已完成）、对方诉求（不使其成为政府承诺）、判断（作者观点）、
  措施（已采取行动）、成效（已交付变化）、风险/约束（需谨慎处）、下一步（谁做什么）。
- **拆维度**：一段塞多维内容 → 拆为并列维度，各配小标题。如"创新点"拆为
  `模式创新 / 协同创新 / 技术创新`；成绩归纳成`三个聚力`（聚力科普教育 / 聚力技能提升 / 聚力才智下沉）。
- **分情形**：两种情景并列 → 明确为`情形一 / 情形二`或`若以…为主 / 若以…为主`，让决策框架清晰。
- **排比"三个X"**：对并列要点提炼概括词（如"三个聚力""三种能力"），既便于口头听记又有气势，
  记忆点强（讲话、汇报尤需）。
- **阶段分离**：把"预期/目标"与"实际/成效"分开，避免前后重叠；事前研判/事中汇报/事后总结各归其位。
- **长句拆链**：因果链不清的长句（如"欢迎落地→申请专项债→谋划项目→产业带动"塞一句）→ 理清动作顺序。

**规则5 · 价值密度提升（把内容写厚、写透）**：
- **触发**：用户要求"完善/丰富细节"，或对象为讲话稿/申报材料时，**主动展开**。
- **展开方式**：补**应用场景**（具体能干什么）+ **预期成效**（达到什么效果），并用领域标准术语具象化。
  - 低空"一网监管平台" → `实现低空飞行活动可视、可管、可控，为低空物流、文旅观光等场景落地提供安全监管保障`；
  - 办公系统"引入AI大模型" → `开发智能公文起草、政策知识检索、会议自动摘要及数据智能分析等功能，切实减轻基层干部案头负担`；
  - "城市大脑" → `打破部门数据壁垒，汇聚多维治理数据，打造集态势感知、预警预测、协同处置于一体的智慧治理中枢，推动基层治理"一网统管"`。
- **起势铺垫句**：立住基调，如`近期，我单位紧抓新基建发展机遇，立足实际，扎实推进重点领域项目谋划工作。`
  （以"我单位/我区"为主语，非收件人，属允许丰富）。
- **强化动词**：增`聚焦、深化、抢抓、精准摸排、力促、打通、涵养`等公文常用动词，措施更有力度。
- **去口语转公文语**：`福利→优惠`、`想了解→咨询`、`希望可以快速落地→希望加快落地进程`、
  `包装成→谋划为`、`这块是→规范表述`、`秒变→具备…能力`（生动比喻可保留但纳入对仗框架）。
- **嵌入政策热词 / 金词**：`基层减负增效、一网统管、智慧中枢、人工智能+、国字号、动能、后劲、闭环`，
  提升政务高度。
- 注意：展开用**标准功能描述与政策热词**，**不编造原文没有的专有数据或已发生的成效数字**；
  不要把" tentative 计划"说成"已确认项目"，不替代作者的实质立场。

**规则6 · 红线守门**：改写全程守两条红线——（a）不臆造收件人/真实姓名职务/硬数据；
（b）讲话稿可补全标准结构但用占位符、默认不落盘（详见 Overview）。若原文明示称谓/标题抬头，则保留并用对应敬语。

**规则7 · 多版本输出**：按**使用场景/语域**区分（如"书面报告 / 会议发言 / PPT简报 / 微信工作群"），
每版注明"何时选此版"。版本区分的是**场景与语感**，不是"替作者补称谓"（见红线⑥）。
- **公文规范版**（书面报告、正式留痕：结构严谨、动词有力、对仗工整、细节丰富）
- **精简干练版**（PPT展示、口头简报：直击重点、数据/结果导向更强、不展开细节）
- **讲话稿结构版**（发言/致辞：补全称谓问候+结尾致谢占位符、政治站位拔高、成绩排比、建设性诉求；见附录-C）
- 当要求"丰富细节"时，公文规范版应**主动展开场景与成效**（规则5），精简版保留骨架不展开。
- **版本数量偏好**（吸收自通用润色方法论）：若草稿使用场景单一，默认给 1 个推荐版；
  若明显有不同用途（如微信稿 vs 正式报告、会议稿 vs 纪要），给 2–3 版并各标场景；
  会议/座谈情况报告默认给"正式报告版 + 简报/新闻稿版"两版；讲话/发言默认给完整稿 + 简短"改进逻辑"说明。

### 第四步：解析关键修改点
列出 3–5 条核心修改点并解释"为什么这样改"，且**每条都点明它如何服务于第一步识别的意图与逻辑主线**，
例如：凝练有价值标题、同层对仗、拆维度、分情形、排比"三个X"、丰富应用场景与预期成效、加起势铺垫句、
补全发言结构、政治站位拔高、诉求建设性表达、化解生硬感、强调双向风险、结尾留余地、补全病句、规范称呼、
减少重复用词、强化动作感、去口语、层次要素归位。让用户理解方法、举一反三。

## 附录 A：意图类型 → 策略提示（文体差异精华，降级为参考）

> 通用规则（规则1–7）已覆盖绝大多数优化。下方仅列出"某意图类型要**额外**注意什么"，作为补充侧重。
> 这些不是独立原则，而是在通用规则之上叠加的关注点。

- **拒绝/设边界**：化解生硬感（客观表述替代训诫式）；强调双向风险（为对方着想"怕你出丑"+
  为大局着想"怕冲击主业/安全"）；结尾留余地（给替代配合，不甩锅）。
- **汇报/请示/研判**：结论前置、突出成效；补全病句、规范称呼简称（自规局→资规局、谋化→谋划）；
  请示委婉且给选择余地；研判分情形、给可操作建议。
  ⚠️ 第一人称文种差异：讲话稿/发言稿**保留"我/我们/我区"**自然第一人称；仅书面报告、上行公文、案例申报
  倾向客观时才弱化"我们"为"本地区/单位"。判断依据：原文是否以"讲话/发言"形态呈现。
- **商洽/协调（平行文）**：尊重平等、共赢表述、明确诉求；保留"贵部/贵单位"等平行敬语
  （仅当原文已示平行关系）；避免指令式或推诿式措辞。
- **申报/展示**：额外做主标题金句+【摘要】+小标题对仗+成效框架化（量/质/面）+长段拆维度；
  对仗化时复查错字与事实，避免把 typo 一并升华。
- **发言/致辞**：补全标准结构（占位符代真名，不编真名）；政治站位拔高（静态描述→使命化大局化）；
  成绩/要点排比化（"三个X"+对仗金词，便于听记有气势）；向上级提希望时诉求建设性表达（问题归因工作拓展、
  金词对仗、补区情逻辑支撑）；结尾加号召力表态语。

## 附录 B：语气矩阵（Tone Matrix，吸收自通用润色方法论）

按"意图 + 接收方"选择语气基调（与意图类型配合使用，不替代通用规则）：

| 场景 | 语气基调 | 关键措辞倾向 |
|---|---|---|
| 工作汇报（上行） | 平实、 factual、行动-结果导向 | "现将…报告如下""妥否，请指示""呈领导审示" |
| 讲话/发言 | 有温度、有节奏、可记忆、有仪式感 | 标准称谓问候、欢迎致谢、"借此机会"、号召力结尾 |
| 向上请示 | 恭敬、客观、有理有据 | 客观约束、给选择余地、结论先行 |
| 平级商洽 | 客气、非指令、协作共赢 | "建议贵单位协调研究""商请配合"，避免推诿 |
| 风险提醒 | 专业、审慎、有据 | 点名风险不指责、附核实步骤、事实与判断分离 |
| 宣传/案例 | 拔高且叙事，但仍以事实为支撑 | 主标题金句、对仗小标题、强叙事包装 |
| 处理措施/成效 | 无口号，用可追溯的动作、数字、标准、结果 | 去宣传语，标题扛结构，措施+成效分列 |

红线：避免过度承诺；若给支持，须指明可控范围（选址建议、信息共享、现场协调、材料提供、政策解释）。

## 附录 C：文体结构模板参考（吸收自通用润色方法论，仅作参考，不强制）

> 以下为常见文体的"推荐骨架"，用于快速对齐结构。**通用规则（规则1–7）始终优先**；
> 当原文场景明确匹配某模板时，可参照其骨架，但不得为套模板而破坏意图或臆造内容。

- **复函 / 平行协调**：`贵部《…》收悉。经研究，现答复如下：` → ①系统/事项定位与职责边界 →
  ②客观约束与风险（兼顾对方成效与己方主业/安全）→ ③结论 + 替代协作路径。`此复。`
- **上行汇报 / 微信请示**：`[称谓]您好，关于…情况汇报如下：` → 时间+主持+会议/事项名+"明确如下安排" →
  一机制/进展、二牵头/责任、三下一步/需领导知晓 → `妥否，请指示。` 请示事项以附注形式放文末。
- **书面报告**：`关于…的报告` → 主持+会议/事项 → 一建立机制、二加快选址、三推进签约（四字小标题）→ `特此报告。`
- **处理措施与成效**（去宣传语）：`一、处理措施`（动作标题：谁在何地基于何需做了何定）→
  `二、处理成效`（交付成效：完成时间/点位数量/运行状态；实效：解决了何盲区/短板）。措施与成效分列，保留技术细节与数量。
- **讲话 / 座谈发言**：标题 + `（[您的职务][您的姓名]）` → 开场称谓问候欢迎致谢 → 定位（本地/单位在大局中的意义）
  → 工作基础与成绩（2–4 个对仗分组，如"三个聚力"）→ 形势与需要 → 诉求/希望（建设性、归因工作拓展、金词对仗、补区情支撑）
  → 结尾表态致谢。`谢谢大家！`
- **会议 / 座谈情况报告**：开头（时间+规范称谓顺序+主持+会议方+议题+"情况报告如下"）→
  一节 项目/事项基本情况与对方诉求（明示"企业诉求/对方请求"，不混为政府承诺）→
  二节 会议决定/下一步（平行小标题 + 责任主体）。默认给"正式报告版 + 简报/新闻稿版"两版。
- **短要点 / PPT**：`底层逻辑：`（3–6 字链，如存量-增量-项目）→ 版本一 正式书面（对仗小标题+每点一句）
  → 版本二 精简PPT（短标题+结果导向）→ `主要改进：`（仅列关键 craft 变化）。
- **项目谋划 / 新基建进展**：起势句（抢抓机遇、立足实际）→ 每点 `领域定位+当前进展+谋划项目+应用场景+预期成效`
  → 收尾/下一步（细化内容、投资估算、实施路径、场景、资金/规划报送路线）。丰富场景与成效，状态动词准确（已报送/正协调/正谋划/拟探索）。
- **案例申报 / 经验交流**：主标题（主题+方法+结果，非仅工具名）+ 副标题 → 【摘要】（痛点+回应+机制+可量化结果+价值）
  → 一总体情况（背景需求/痛点/目标）→ 二主要做法（数据基础/流程融合/队伍保障）→ 三成效（效率/质量/营商）
  → 四创新与推广（模式/协同/技术/机制创新 + 可复制性）。

## 附录 D：词例升级表（吸收自通用润色方法论 + 本技能实战）

把"口语/生硬/宣传腔"替换为对应公文语。以下为**模式**而非逐字模板，按语境取意：

| 原表述（弱） | 升级方向（强） | 说明 |
|---|---|---|
| "福利" | "优惠" | 公文偏好"优惠" |
| "想了解" | "咨询" | 去口语 |
| "希望可以快速落地" | "希望加快落地进程" | 更正式 |
| "包装成" | "谋划为 / 统筹谋划为 / 协调建设" | 去功利口语 |
| "这块是…" | 规范表述（去口语领起） | 第三点尤忌 |
| "秒变" | "具备…能力 / 快速掌握" | 生动比喻可保留但纳入对仗 |
| 生硬拒绝"不能提供" | "暂不具备…条件" + 替代支持 | 客观约束替代硬否定 |
| 技术限制 | 风险逻辑："影响对方成效 + 冲击己方主业/安全" | 双向风险 |

| "人手不足是突出问题" | "随着工作拓展，专职力量短缺、基层组织体系尚需完善等问题日益凸显" | 建设性归因 |

| 平淡标题"企业情况" | "项目基本情况与企业诉求" | 有价值标题 |
| 不平标"下一步" | "明确责任、加快推进落实" | 行动-结果导向 |
| 相邻重复词 | 递进词链（存量/生态/项目；基础/资源/人才） | 避免相邻重复 |
