# 猪肉分割技术规程

## 任务目标

本技能依据 [GB/T 40466-2021相关要求摘编](references/pork-butcher-procedures.md)指导猪肉分割加工，涵盖术语定义、原料要求、分割车间要求、分割方式、分割程序及要求、标识包装贮存运输等完整流程。

## 前置准备

- 原料来源：片猪肉应符合 [GB/T 9959.1-2019相关要求](references/gbt_9959_1_2019_raw_carcass.md)（带皮片猪肉、去皮片猪肉或分体）
- 设备工具：手持式切割设备、锯骨设备、刀具、案板等
- 人员资质：具备分割操作基础知识

## 执行流程

### 第一步：确认分割方式

根据原料状态选择分割方式：

- **热分割**：屠宰后未经冷却的鲜片猪肉，分割至入预冷库时间不应超过45min
- **冷分割**：冷却猪肉（中心温度7℃以下）或解冻猪肉（-2℃～4℃），分割加工时间不超过1h

### 第二步：执行分段操作

从第5～6肋骨间胸椎处垂直中线下锯，前腿部位为**前段**；从腰椎与荐椎连接部下锯，后腿部位为**后段**；中间部位为**中段**。

- 六分体：前段+中段+后段
- 八分体：六分体+沿中段脊椎骨下4cm～6cm肋骨处平行脊骨锯下的大排和带骨中方

### 第三步：前段分割

1. **分前排、颈背肌肉（Ⅰ号肉）**：修去胸腔内淋巴结、大血管和肥膘；自排骨与前腿肌肉中间肌膜处下刀，刀锋靠肩胛骨底面前进，分割带颈背肌肉的前排；再沿腓脊骨剔下颈背肌肉
2. **扒膘**：沿肌膜分开部分肥膘，分割出带皮或不带皮肥膘
3. **剔前腿骨、肩胛骨（扇骨）**：分割前腿骨和前腿肌肉（Ⅱ号肉）；沿肩胛骨边缘分割，取下肩胛骨和月牙骨（脆骨边）

### 第四步：中段分割

1. **锯大排**：从脊椎骨下约4cm～6cm肋骨处平行脊骨方向锯断
2. **分大排肌肉（Ⅲ号肉）和小里脊**：沿脊骨剔下大排肌肉和带脂里脊
3. **剔脊骨、分肋排**：剔下脊骨后锯分肋排；扒去肋排腩肉得五花肉

### 第五步：后段分割

1. **扒膘**：割开腿筋，沿膘肉结合部扒去内侧肥膘
2. **剔尾骨、叉骨**：从髋关节处沿叉骨与尾骨分离，剔下尾骨和叉骨
3. **剔后腿骨**：分离股四头肌（元宝肉），剔下后腿骨，剩余为后腿肌肉（Ⅳ号肉）

### 第六步：皮膘分割与修整

- **皮膘分割**：分离猪皮和肥膘，修去淤血、淋巴结、猪毛等杂质
- **修整**：按膘厚、带脂或等级要求修整，修去表面淤血、碎肉、淋巴结、骨渣、猪毛等

### 第七步：标识、包装、贮存、运输

| 环节  | 要求                                       |
| --- | ---------------------------------------- |
| 标识  | 符合[NY/T 3383-2020](references/nyt_3383_2020_packaging_labeling.md)，储运标志符合[GB/T 191-2025](references/gbt_191_2025_handling_marks.md)、[GB/T 6388-1986](references/gbt_6388_1986_shipping_marks.md) |
| 包装  | 按品种、级别包装；包装间温度10℃～12℃；冷却肉包装滞留时间不宜超过30min |
| 贮存  | 冷却肉0℃～4℃；冷冻肉≤-18℃；避免与有毒有害物品混合贮存          |
| 运输  | 符合[GB/T 20575-2019相关要求](references/gbt_20575_2019_transport.md) |

## 使用示例

- **场景/输入**：帮我按照标准流程进行猪肉热分割操作
  
  - **预期产出**：完成从片猪肉到六分体或八分体的分段，并完成前段、中段、后段各部位分割
  - **关键要点**：热分割从屠宰到入预冷库不超过45分钟；分段位置为第5～6肋骨间和腰椎与荐椎连接处

- **场景/输入**：冷分割操作中大排和里脊怎么分离
  
  - **预期产出**：完成大排肌肉（Ⅲ号肉）和小里脊的分离
  - **关键要点**：先从脊椎骨下4cm～6cm处锯断大排，再沿脊骨剔下大排肌肉和带脂里脊

## 质量约束

- 分割车间温度：预冷间/冷却间0℃～4℃，分割剔骨间12℃以下
- 分割时间：热分割≤45min，冷分割≤1h
- 产品表面：不得有淤血、碎肉、淋巴结、骨渣、猪毛及其他杂质
- 异物检测：分割后入库前进行金属等异物检查
- 包装滞留：冷却肉包装间温度10℃～12℃，滞留时间不宜超过30min
