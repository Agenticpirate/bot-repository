## 父方法：回译派「反思回译法」10 阶段（必读，版权归属悦迅翻译）

```
① 术语提取 → ② 网络核验 → ③ 术语统一
                              ↓
⑥ 终稿修订 ← ⑤ 反思润色 ← ④ 批量直译
                              ↓
                           ⭐ ⑦ 盲回译质检
                              ↓
⑩ 合规检查 ← ⑨ 交付门禁 ← ⑧ 诊断修复
```

| # | 阶段 | 核心动作 | 模型要求 |
|---|------|---------|---------|
| ① | 术语提取 | 结构化输出专有名词/术语 | 结构化生成强 |
| ② | 网络核验 | 联网检索权威译例 | 联网搜索型 |
| ③ | 术语统一 | 整合术语表（JSON） | 结构化整理 |
| ④ | 批量直译 | 全文初稿 | 专业翻译模型（模型 A） |
| ⑤ | 反思润色 | 约束化润色、句式优化 | 推理强模型（模型 B，≠A） |
| ⑥ | 终稿修订 | 整合终稿、排版 | 综合通用模型（B 或 C） |
| ⭐⑦ | **盲回译质检** | 终稿反向回译源语、逐句对照 | **独立隔离模型（模型 C，≠A,B）** |
| ⑧ | 诊断修复 | 定位/修复语义缺陷 | 精准修改模型（≠C） |
| ⑨ | 交付门禁 | 人工复核缺陷清单 | 人工主导 |
| ⑩ | 合规检查 | 法律/格式/地域用语校验 | 行业知识库 |

### 两条不可突破铁律（原文继承）
- **铁律 1**：盲回译仅用于定稿后语义校验。❌ 不在初稿上筛；❌ 不跳过终稿修订直接拿直译稿回译。
- **铁律 2**：直译与回译必须不同模型。❌ 模型 A 既直译又回译 → 同模型"自我掩饰"；⚠️ 单模型环境必须标注"未跨模型校验，需加强人工复核"。

### 模型编排硬性标准
| 任务 | 必须用 | 不能用 |
|------|--------|--------|
| 直译 | 专业翻译模型 | 推理型（慢） |
| 反思润色 | 推理强模型 | 与直译同模型 |
| 盲回译 | 独立翻译模型 | 与直译/润色同模型 |
| 诊断修复 | 精准修改模型 | 与回译同模型（避免裁判兼修改） |

### 三角色（三 Agent 架构）
- **直译官（①–⑥）**：批量产出，不求完美但求高效。
- **质检官（⑦–⑧）**：独立视角，只找问题（盲回译 + 诊断修复）。
- **终控官（⑨–⑩）**：缺陷清零、门禁放行、合规兜底（人工 + AI）。

## ⭐ 越南语翻译实战要点（悦迅 15 年踩坑沉淀，加固①的"检查字典"）

中越是特殊一对：同属孤立语、同为声调语言、基本 SVO、汉越词重叠 25%–70% → 语义层回译信号干净；但语用/形态层极易"假一致"漏检。以下每一条都来自真实错译案例：

| 维度 | 中→越典型坑 | 越→中典型坑 | 真实示例 |
|------|------------|------------|---------|
| **汉越词陷阱** | 过度汉越化显生硬书面；混淆近义汉越词 | 误把汉越词当纯越词理解 | học sinh=中小学生，sinh viên=大学生；把"学生"全译 sinh viên 是错 |
| **定语后置** | 中文前置语序残留（*xe đỏ lớn* 应为 xe đỏ lớn? 注意多层定语顺序） | 回译中文自动前置，错误被"修复"吞掉 | hoa đỏ（红花）；"红色的花"译 hoa màu đỏ 累赘 |
| **称呼体系** | 一个"你"对应 anh/chị/em/cậu/mày/bạn 至少五种，依辈分/关系/熟悉度 | 回译统一成"你/我"，立场完全漏检 | 对年长男客户用 anh，对平辈女友用 bạn；误用 ông（老者/敬语）会冒犯 |
| **量词** | 中文"个"泛用 → 越语强制细分 | 漏掉量词或用错 | sách→quyển，动物→con，车辆用具→chiếc，绝不滥 cái |
| **虚词语气** | rồi/thì/mà/nhé/nhỉ/nha/vậy/đấy 是语气灵魂 | 回译易丢情感色彩 | "你吃吧"→bạn ăn đi nhé（nhé 表亲昵提议）；漏 nhé 变命令 |
| **文化负载词** | 应保留越语原生名 | 直译失真 | 粽子 bánh chưng(方)/bánh tét(圆)、Tết(春节)、áo dài(奥黛)、phở(河粉) 保留原生名 |
| **时间副词** | đã/đang/sẽ/rồi/từng/vừa 承担时态 | 回译中文能否还原"了/正在/将" | "他吃了"→anh ấy đã ăn；漏 đã 变"他吃" |
| **声调** | 声调标错意思全变 | — | rắn(蛇) vs răn(劝告)、má(妈妈) vs mà(但是) |
| **方言** | 北 v↔南 d、北 r↔中南部 gi、北 x↔中南部 s | 跨方言需主动调整或加注 | 南部"吃" ăn vs 部分南部发音；正式文本以河内音为准 |

> 越语知识内化提示：越语无形态变化、无"的"字结构（定语靠后置或 của 短语）、约六成词汇源于古汉语但语义已漂移。

## ⭐ 中越实战案例：回译"修复错误"（最阴险漏检，加固②要治的）

**案例 A — 称呼立场被回译修复**
- 原文：「他是一位老师」（中性第三人称）
- 初译（错）：`Ông ấy là một giáo viên` — `Ông` 是尊称"先生/老者"，误加了敬语色彩
- 盲回译：`他是一位老师` ✅ 与原文一字不差 → 判"一致"放行
- **结果**：越文在目标语里其实不对（冒犯性/立场错），却被回译"认证"为正确
- **加固②解法**：目标语母语自检（"假设没见过原文，这段越语自然吗？"）→ 发现 ông 不当；或中越专项清单"称呼体系"逐条核对 → 抓出

**案例 B — 定语前置被回译修复**
- 原文：「那家大的红店」
- 初译（错）：`cửa hàng đỏ lớn đó`（语序混乱，且定语位置不对）
- 盲回译：`那家大的红店` ✅ 中文回译自动顺成合理语序 → 放行
- **结果**：越文语序错误被结构对称性抹平
- **加固②解法**：专项清单"定语位置"核对 + 目标语自检

**结论**：这是回译的**内在、不可根除**局限（逆否命题不成立）。中越因结构太像比英中更严重——**绝不可只靠单通盲回译**，必须叠加固①②。

## 加固①：中越专项检查清单（补回译漏检，强制逐条核对）
```
请对照源文与初译，专项核查以下中越易错点，仅列出"回译无法发现"的差异：
1. 代词立场：越文代词(anh/chị/tôi/em/bạn)是否与源文人际关系同一立场？
2. 量词：cái/con/quyển/cuốn… 是否选对类别？
3. 定语位置：修饰语是否后置？有无残留中文前置语序？
4. 被动：bị/được 的受损/受益色彩是否一致？是否该用主动？
5. 时态虚词：đã/đang/sẽ 与源文时体是否匹配？
6. 语气词：à/ư/nhé 等情感色彩是否丢失或误加？
7. 文化负载词：bánh chưng/Tết/áo dài/phở 等是否保留越语原生名？
8. 汉越词：是否过度汉越化？近义汉越词是否混淆？
```

## 加固②：假一致"回译修复错误"应对（叠在铁律 1/2 之上）
铁律 2（异模型）已缓解（模型 C 无 A 偏置，更可能如实翻回"歪的源文"），但未根除。应对（按可靠性）：
| 机制 | 可靠性 |
|---|---|
| 目标语母语自检（不译回源语，直接问"假设你是没见过原文的越语母语者，这段话自然/语法对吗"） | 高 |
| 参考-free QE 模型（CometKiwi 类，目标语空间打分，不经过回译） | 高 |
| 中越专项清单（即加固①，语言学硬核核对） | 高 |
| 异模型回译（=铁律 2，已强制） | 高（缓解） |
| 正向一致性（翻第三语言 Z 再翻回 y'，目标语内比 y 与 y'） | 中 |
| 回译"直译模式"（低温度+强约束"逐词逆译、勿润色"） | 中（增噪声） |
| 高危人工兜底（合同/金额/称谓，对应阶段 ⑨ 交付门禁） | 最高 |

## 加固③：可选回译前接地信号（DUAL-REFLECT 式）
在 ⑤ 反思前加一步"初译回译→过程评估"，把差异作为 ⑤ 的锚点，提升反思定位精度。**不替代铁律 1 的终稿盲回译门禁**（回译用两次：可选 mid 接地 + 终稿门禁）。

## 落地 Prompt 模板（对齐回译派阶段编号，越南语特化）

**① 术语提取**（结构化强模型）
```
从以下原文提取所有专有名词与关键术语，输出 JSON：
{ "terms": [ { "src": "原文词", "type": "人名/地名/机构/品牌/术语/缩略语/文化词", "hint": "可能越语译法" } ] }
源文：{src}
```

**② 网络核验**（联网搜索型，越语权威源优先）
```
对以下术语逐条联网检索权威越语/中文对应译法，优先 VietnamNet/VnExpress/Tuổi Trẻ/Thanh Niên/Zing/维基越语版/机构官网，多源交叉验证：
{terms}
输出：| 源文词 | 定名 | 来源链接 | 置信度 | 备注(保留越语原文/暂译) |
```

**③ 术语统一**（结构化整理）→ 输出术语表 JSON `{glossary:[{src,vi,zh,note}]}`

**④ 批量直译**（模型 A）
```
将以下中文译为越南语，遵守术语表与越南语规范（定语后置、量词细分、称呼依关系选 anh/chị/em/bạn…）：
术语表：{glossary}
源文：{src}
```

**⑤ 反思润色**（模型 B，≠A；可选先跑加固③接地）
```
你是悦迅翻译资深越汉译审。对照中越专项清单（称呼/量词/定语/被动/时态/语气/文化词/汉越词）逐条核对以下初译，
指出偏差与取舍，给出润色版：
初译：{vn}  源文：{src}  术语表：{glossary}
```

**⑥ 终稿修订** → 整合初译与润色，输出定稿（直译版+意译版+语体变体版，每版≤50字设计意图）。

**⭐⑦ 盲回译质检**（模型 C，独立隔离，≠A,B；铁律 1：仅对终稿）
```
将以下越南语终稿反向翻译回中文，严格逐词逆译、不要润色改写（铁律 2：你与直译模型不同）：
{vn_final}
```

**⑧ 诊断修复**（精准修改模型，≠C）
```
对比 A(原中文) 与 B(盲回译中文)，定位致命/重大语义缺陷并修复越文终稿：
A：{src}  B：{back}  终稿：{vn_final}
```

**⑨ 交付门禁**（人工主导）+ **⑩ 合规检查**（行业知识库）
```
人工复核缺陷清单并清零；AI 校验越南语法律条款/地域用语（北 vs 南）/格式合规，输出"待确认"项须明确告知用户，不得静默修正。
```

## 适配用户架构（悦迅翻译 / 4 Agent 蜂群 / NVIDIA 中转站）
- **回译派三 Agent 映射**：直译官(①–⑥)→规划 Agent + 翻译 Agent；质检官(⑦–⑧)→校验 Agent（盲回译 + 诊断）；终控官(⑨–⑩)→人工 + 合规 Agent。
- **NVIDIA 中转站 auto 路由**：④直译/⑤反思/⑦盲回译分走不同模型别名。⚠️ 铁律 2 要求 ⑦≠④⑤——`auto` 随机选最快可能撞同模型，建议 ⑦ 显式指定与 ④ 不同的模型。
- **单模型回退**：必须字幕标注"未跨模型校验，需加强人工复核"（铁律 2 妥协）。
- **越南语翻译子代理**：其 step3 反思即加固①清单，可作直译官 ⑤ 的强化人格（知识接地，规避朴素盲反思）。
