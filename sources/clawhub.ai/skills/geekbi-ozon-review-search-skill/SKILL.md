# 极鲸云 Ozon 评论搜索

- 必须先取得明确 `goodsId`，不从不可靠文本猜测。
- 未指定站点时默认俄罗斯站 `siteId=1`；指定其他市场时先运行 `ozon_site_list.py`，再按 [评论接口](references/Ozon评论接口.md) 查询。
- 按 [评论研究](references/Ozon评论研究.md) 分析评分、主题、规格、优缺点、媒体和卖家回复。
- 报告总数、完整筛选摘要、实际读取数、页码、评分条件和时间范围；最多访问前 200 条。
- 仅评分评论仍参与统计；未查看媒体时不描述内容。
- 暂停按 [查询暂停与恢复流程](references/查询暂停与恢复流程.md)。
