# 艾略特波浪：有比例约束的群体心理循环

## R — 原文 (Reading)

> "艾略特波浪理论认为，市场遵循一种五浪上涨、三浪下跌的八浪循环；各浪之间的比例与回撤位常符合菲波纳奇数列。"
> "调整浪绝不会以五浪结构的形式出现，只能以三浪结构出现（三角形例外）。"
> "第 4 浪绝不可与第 1 浪的价位有重叠——在股市中是铁律。"
> "交替规则：不要指望同一类型的调整形态连续出现。"
>
> — 约翰·墨菲，第十三章 艾略特波浪理论

---

## I — 方法论骨架 (Interpretation)

波浪理论把市场看作有节律的群体心理循环，核心不是"数浪猜涨跌"而是**用比例与规则约束数浪**：

1. **八浪循环**：五浪推动（1-2-3-4-5）+ 三浪调整（a-b-c）；更大层级上这套结构可嵌套。
2. **菲波纳奇比例约束**（g12）：回撤位常用 38.2%/50%/61.8%，目标位常用 1.618 等倍数——这是数浪的"标尺"。
3. **核心数浪规则**：
   - 调整浪必为三浪（p46）：看到五浪下跌说明调整未完，不是新推动。
   - 第 4 浪不进入第 1 浪价格区（p47，股市铁律，期货稍放宽）。
   - 熊市通常不跌破前牛市第 4 浪底（p48）——经验性下跌支撑下限。
   - 交替规则（p49）：2 浪简单则 4 浪复杂，反之亦然，排除"重复上一回"。
4. **延长**：某一推动浪异常拉长（常是 3 浪），其余两浪相对简单。
5. **须协同其它工具**（p50 / ce29）：看不清形态时不可强套，应结合趋势线、均线、形态综合研判。

## A1 — 书中的应用 (Past Application)

### 案例 1：科得角海滩海浪的"三节拍"（概念导入）
- **问题**：波浪理论是否凭空臆造？
- **方法论的使用**：作者以海滩观察海浪"冲锋—退落—再冲锋"的自然韵律，类比五浪推动的群体心理节律。
- **结论**：波浪是市场（自然）节律的映射，非主观发明。
- **结果**：作为概念导入实例（c16）。

### 案例 2：黄金市场的波浪分析"表现最好"
- **问题**：波浪理论在哪些市场最有效？
- **方法论的使用**：作者指出黄金是有清晰趋势节律的市场，波浪划分与历史走势吻合度极高。
- **结论**：波浪理论在群体参与广泛、趋势清晰的市场尤为有效。
- **结果**：验证理论适用性（c17）。

### 案例 3：1980–81 商品顶部受旧顶制约
- **问题**：长周期波浪如何判别空间？
- **方法论的使用**：1980–81 商品顶部始终未超约 1974 年旧顶，暗合大循环浪对新一轮顶部的制约。
- **结论**：长周期波浪有"老顶"空间约束。
- **结果**：实例支持大循环浪框架（c18）。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?
1. 问"帮我数一下现在是第几浪 / 这波是延长浪吗"。
2. 问"菲波纳奇 0.618 回撤位在哪里、目标怎么算"。
3. 问"五浪走完了后面该走什么浪"。
4. 困惑"同一个走势能数出好几种浪，怎么定"。

### 语言信号
- "数浪、艾略特、五浪三浪、延长浪"
- "菲波纳奇、0.382/0.5/0.618、浪 1-5、调整浪、1.618 目标"

### 与相邻 skill 的区分
- 与 `time-cycles` 的区别：波浪按"形态+比例"数，周期按"时间窗口+波峰左右移"判，二者互补但不可混淆。
- 与 `reversal-patterns` 的区别：头肩/双顶是价格形态，波浪是层级循环结构。

## E — 可执行步骤 (Execution)

1. **定层级与方向**：先由长周期图确定当前处于更大浪级的哪一阶段。
   - 完成标准：明确是推动浪还是调整浪环境。
2. **按规则数浪**：用 5-3 结构、4 浪不重叠、调整必三浪等约束划浪。
   - 完成标准：浪形满足基本规则，无明显违规。
3. **用菲波纳奇测位**：在浪间标 38.2%/50%/61.8% 回撤与目标位。
   - 完成标准：给出关键回撤/目标价格区。
4. **应用交替/延长**：用交替规则排除重复形态，识别延长浪。
   - 完成标准：推断下一浪形态与规模。
5. **协同验证**：与趋势线突破、均线、形态、背离交叉确认，不孤立用浪。
   - 完成标准：至少一项独立信号支持数浪结论。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill
- 用户问"商品有个 28 天周期快到底了" → 转 time-cycles。
- 用户问"头肩顶颈线跌破是不是反转" → 转 reversal-patterns。

### 作者在书中警告的失败模式
- **菲波纳奇时间事后拟合**（ce28）：时间目标选择余地太多，常事后才肯定，事前不可证伪。
- **不可死搬硬套**（ce29）：强行给不清朗走势加波浪=自我证实偏差，须与其它工具协同。
- **个股/清淡期货效果差**（ce30）：理论依赖广泛群体参与，小品种/低成交量市场形态失真。
- **商品新牛市不超旧顶**（ce31）：勿把股市式"生长螺线"套到商品上。

### 作者的盲点 / 时代局限
- 1986 年无计算机自动数浪；但"形态+比例+多工具验证"的约束原则仍适用。

### 容易混淆的邻近方法论
- 波浪（形态比例）vs 周期（时间窗口）：二者都讲节律，但波浪重结构、周期重时点，混用易误判（见 time-cycles B）。
