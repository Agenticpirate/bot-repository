# 口碑（阿里本地生活）档案与指引 Skill

口碑是阿里的到店业务品牌（2015 年与蚂蚁重启的合资品牌，
对标美团到店）。经历多轮组织调整后，**独立 App 已停止运营，
到店业务并入高德地图**（"高德扫街榜"等形态）与支付宝生态——
搜"口碑怎么不见了"的用户需要的是这份迁移地图。

## 入口变迁地图（用户侧）

| 原口碑功能 | 现在去哪 |
|------------|----------|
| 到店团购/套餐 | **高德地图**内本地生活入口、支付宝生活频道 |
| 外卖 | 饿了么（见 `ele` skill） |
| 门店会员卡/储值 | 支付宝卡包/商家小程序 |
| 评价体系 | 高德评价与榜单体系承接 |

## 商家侧迁移要点

- 原口碑店铺资产（评价/会员/储值）随业务并入分批迁移，
  以商家后台官方通知为准
- 新开到店业务：阿里系入口现在主要谈**高德**（流量入口）+
  **支付宝**（交易与会员）组合
- 多平台策略：到店流量大盘在美团/大众点评（见 `dazhong` skill）
  与抖音到店，阿里系是补充渠道——按客群分布配置资源

## 行业格局理解（写作/分析素材）

口碑的兴衰是"组织战 vs 产品战"的典型案例：阿里到店业务
多次重组（口碑→本地生活公司→并入高德），反映其对美团的
追赶策略从对标复制转向"用高德的出行流量做到店"的差异化路径。

## Agent 典型用法

1. 用户找口碑 App/功能 → 按迁移地图指路
2. 商家咨询阿里系到店渠道 → 高德+支付宝组合与多平台配比建议
3. 本地生活行业分析 → 用格局演变素材

## 本 skill 不做什么

- 组织与产品持续调整中，具体入口以高德/支付宝当前版本为准
- 不编造未公开的业务数据
