# 自如租房决策 Skill

自如是中国最大的长租公寓运营商（链家系）。标准化装修与服务省心，
但**真实成本高于标价**且合同条款专业性强，本 skill 帮你算清账、
避开坑。

## 真实成本计算（标价之外）

```
月度真实成本 = 月租金
            + 服务费（年费制，约为年租金的 10% 上下，按月分摊）
            + 网费/智能设备费（部分房源）
            + 电费（公寓类房源可能是商电，单价高于民电）
```

**附零依赖计算器**（`scripts/cost_calc.py`，纯本地计算）：

```bash
python3 scripts/cost_calc.py 5000 --service-rate 10 --commercial --compare 4300
# → 真实月成本 5642 元(比标价高 12.9%)，比普租(含中介费年摊)每月多 984 元
```

- 对比普租：同地段自如整租通常贵 10%-20%，买的是标准化装修、
  管家维修与不被随意涨租/赶人——值不值取决于你对省心的定价
- **签约前必问**：电价是民电还是商电、服务费包含哪些次数的保洁

## 签约避坑清单

1. **付款方式甄别**："月付"若走第三方金融产品即为**租金贷**——
   人搬走贷款还在的风险源头。选月付时确认合同主体与资金流向，
   页面出现"分期""信用付"字样要警觉
2. **空气质量**：新装修房源（自如历史上有甲醛争议并已建立空气
   检测标准）——入住前索要检测报告，首次配置房源可要求空置期
   或自行复检（CMA 资质机构）
3. **条款细读**：提前退租违约金（常为一个月租金+服务费不退比例）、
   换租规则、转租是否允许
4. 拍照留证：入住当天全屋拍照（含家电读数、已有损耗），
   退租扣费争议的核心证据

## 退租扣费争议处理

保洁费/维修费扣押金是高频争议。路径：管家协商（出示入住照片）→
自如客服投诉 → 12315/当地住建部门租赁纠纷渠道。日常损耗
（正常使用磨损）依法不应由租客承担。

## Agent 典型用法

1. **真实成本对比**：把自如报价换算成含费月成本，与同地段普租对比
2. **合同审查**：按避坑清单逐条检查用户合同截图/条款描述
3. **争议指导**：按证据与路径给维权步骤
4. **产品线选型**：按预算/独居合租偏好/通勤给整租/友家/自如寓建议

## 本 skill 不做什么

- 价格与服务费率因城市房源而异，以签约页实际展示为准
- 空气质量问题涉及健康，一律建议 CMA 机构实测，不做安全背书
- 不提供逃避违约金的方法，只主张依法不该扣的不被扣
