# 师资管理

> 本 Skill 聚焦讲师资源库的建设与长期运营管理，区别于"培训计划编排"中的讲师邀约环节，前者管"人"的长期档案，后者管"事"的临时调度。

## 能力概述

| 模块 | 核心内容 |
|------|---------|
| 讲师信息登记 | 姓名、性别、出生年月、学历、工作单位、职务职称、联系方式、照片 |
| 资质审核 | 资质证件上传与审核（教师资格证、职业资格证、行业认证等）、审核状态追踪 |
| 授课领域分类 | 按专业领域、课程类型（理论/实操/案例研讨等）、适合对象分级 |
| 授课记录 | 历次授课时间、课程名称、参训单位、学员人数、满意度评分 |
| 评价评级 | 学员/主办方评价收集、综合评级（初级/中级/高级/特级讲师）、晋升记录 |
| 课酬标准 | 不同级别/领域对应的课酬费率、差旅补贴标准、结算周期、历史调薪记录 |
| 档期管理 | 讲师可授课时间段标记、冲突检测、忙闲日历预览 |

## 输入

- **讲师基础信息**：姓名、学历、工作单位、职称、联系方式等
- **资质证明文件**：证件扫描件、证书照片、从业证明等（接收 PDF/图片）
- **授课记录与评价**：往期培训中的讲师表现数据、学员评价反馈
- **课酬与档期查询**：用户发起的课酬标准查询或档期可用性询问
- **评级调整请求**：基于累计授课量和评价的综合晋升申请

## 输出

### 讲师档案卡片

```
【讲师姓名】XXX
【级别】特级讲师 | 高级讲师 | 中级讲师 | 初级讲师
【授课领域】XX管理 / XX技术 / XX实务（多标签）
【累计授课】XX场 / XX学时 / XX人次
【综合评分】X.X / 5.0（满意度）
【课酬标准】XXX元/学时（税前）
【档期状态】🟢 可约 / 🟡 需确认 / 🔴 已满
【最近授课】YYYY年MM月DD日 — 《课程名称》（主办方：XXX）
```

### 师资库报表

- **讲师花名册**：全量讲师清单（含级别、领域、档期状态）
- **授课统计**：按年度/季度统计讲师授课量和评分趋势
- **课酬核算表**：各讲师课酬汇总、待结算明细

## 工作流程

1. **登记/导入讲师信息**：录入或批量导入讲师基础档案
2. **资质审核与归档**：验证资质证件真实性，标记审核通过/待补充/不通过
3. **授课领域分类**：根据讲师专业背景和授课经验，进行领域标签分配
4. **记录授课数据**：每次培训后归档授课记录、满意度评价
5. **综合评级维护**：根据累计授课量、评价结果动态调整讲师评级
6. **课酬标准管理**：设定/调整各等级讲师课酬费率，记录调薪历史
7. **档期维护与查询**：更新讲师忙闲日历，档期冲突检测与预警

## 数据模型（讲师记录）

每条讲师记录包含：
- `id`：讲师唯一编号
- `name`：姓名
- `gender`：性别
- `birth_date`：出生年月
- `education`：最高学历
- `employer`：工作单位
- `title`：职务/职称
- `contact`：联系方式（手机/邮箱）
- `photo`：照片路径
- `certifications`：资质证件列表（类型/编号/审核状态/附件路径）
- `domains`：授课领域标签（数组）
- `level`：讲师评级（初级/中级/高级/特级）
- `course_records`：授课记录（数组，含日期/课程/主办方/人数/评分）
- `rating_avg`：综合平均评分
- `fee_standard`：课酬标准（元/学时）
- `fee_history`：课酬调整历史（数组，含日期/调整前/调整后/原因）
- `schedule`：档期日历（数组，含日期段/状态/备注）
- `status`：可用/暂停/冻结/已离职
- `created_at`：入库日期
- `updated_at`：最后更新时间
