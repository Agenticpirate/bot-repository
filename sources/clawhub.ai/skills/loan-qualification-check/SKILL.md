## Quick Start

### 第一步：配置环境变量

```bash

```

```bash

```

注册成功后会获得用户Key，请妥善保存。

### 第三步：资质评估

**基础评估：**
```bash

  --age 30 --income 15000 --credit good \
  --loan-type consumer --city 北京
```

**完整评估（含资产信息）：**
```bash
python3 {baseDir}/scripts/loan_check.py check \
  --age 35 --income 25000 --credit excellent \
  --loan-type business --city 上海 \
  --has-house --fund --social-security \
  --work-years 8 --loan-amount 100
```

**输出Markdown格式并保存：**
```bash
python3 {baseDir}/scripts/loan_check.py check \
  --age 30 --income 15000 --credit good \
  --loan-type consumer --format markdown -o report.md
```

## 常见问题 FAQ

**Q1: 评估结果准确吗？和银行实际审批差多少？**
A: 评估基于42款产品的公开准入条件和常见审批逻辑，准确率约80%。最终审批还受银行政策变动、客户细节资质、当前额度紧张度等因素影响，建议作为参考依据，不作为最终承诺。

**Q2: 征信等级怎么判断？**
A: 
- excellent：无逾期，查询少，负债低，有多种信用记录
- good：偶尔1-2次30天内逾期，查询正常，负债适中
- fair：有多次逾期或查询多，负债较高，有小贷记录
- poor：90天以上逾期、当前逾期、呆账、被执行人等

**Q3: 常见拒件原因有哪些？怎么应对？**
A: Top 5拒件原因：
1. **征信差**（逾期多/查询多/负债高）→ 建议养征信3-6个月再申请
2. **收入不足** → 增加共同借款人或提供更多资产证明
3. **职业行业限制** → 换匹配的产品，部分银行对特定行业有专项产品
4. **资料造假** → 必须真实，一旦发现直接拒贷且上黑名单
5. **小额贷款过多** → 结清小贷，降低查询频率

**Q4: 支持哪些城市？**
A: 产品库为全国主流银行产品，大部分全国可做。部分城市可能有本地化产品差异，建议结合当地实际情况调整。

**Q5: 批量评估支持多少条数据？**
A: 理论上无上限，建议单次不超过1000条以保证速度。按实际评估人次扣点。
