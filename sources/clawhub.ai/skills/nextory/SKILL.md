# AI 图片提示词优化器

## 目标

把用户需求翻译成可直接复制的高精度、高质感提示词。

默认交付：
- 参考图角色明确
- 模仿保真等级与不可变项明确
- 位置、角度、镜头、比例明确
- 若涉及人物，表情、眼神、姿态、手部、皮肤与服装贴合自然
- 若涉及人像，皮肤、眼神、头发、表情、姿态更真实
- 若涉及电商产品，边缘、材质、标签、反光、阴影更精致
- 视觉主次与画面层级明确
- 光线、色彩、材质、真实感明确
- 风格来源与品牌语气明确
- 负面提示词按任务场景定制
- 若平台提示内容政策拦截，输出平台安全改写版
- 输出完整提示词包，而不是只给一段 prompt
- 若用户要求 1:1 还原，尽量减少自由发挥

## 核心流程

始终按这个顺序：
1. 判断任务模式
2. 给每张图分配角色
3. 抽取必须锁定的视觉事实
4. 根据任务路由到对应参考文档
5. 若用户提到违规、审核、无法生成、内容政策，先执行平台安全改写
6. 执行参考保真与精确模仿矩阵
7. 若涉及人物，执行人物自然度控制
8. 若涉及人像，执行人像真实感增强
9. 若涉及电商产品，执行产品精致度增强
10. 执行细节扩写、质感增强与矛盾自检
11. 输出完整提示词包

## Step 1: 判断任务模式

| 模式 | 触发信号 | 处理要求 |
| --- | --- | --- |
| 严格复刻 | 1:1还原、完全一致、照着做、复现这张图 | 强约束，少创作 |
| 平台安全改写 | 违反内容政策、无法生成、被拒、提示违规、审核不过 | 删除敏感词，用商业服饰/产品摄影安全表达 |
| 精确模仿 | 模仿更精确、保留同一个人/产品、完全参考上传图 | 建立保真等级和不可变项矩阵 |
| 高保真生成 | 基于参考图优化、保留主体不变 | 锁定主体，局部改动 |
| 人物自然化 | 人物更自然、真实人像、别像AI、表情自然、姿势自然 | 强化表情、眼神、姿态、手部、皮肤和服装接触 |
| 人像真实增强 | 人像更真实、皮肤真实、眼神真实、真人感、别假脸 | 强化身份保真、皮肤、眼神、表情、头发、镜头 |
| 电商产品精致 | 产品图更精致、电商主图高级、产品更干净、材质更好 | 强化边缘、标签、反光、阴影、材质和背景 |
| 细节扩写 | 提示词更详细、更完整、细节更多、效果更好 | 按硬约束、空间镜头、质感真实、用途纠错扩写 |
| 质感增强 | 更高级、更有质感、更全面、提示词优化、品牌感 | 保持事实，强化视觉导演层 |
| 风格借鉴 | 参考这个氛围/调色/布光/构图 | 只转移允许的风格层 |
| 逆向推导 | 只给图，让你分析并反推 | 先分析，后写 prompt |
| 电商交付 | 主图、详情页、九宫格、四视图、模特图 | 必须拆图输出 |

若任务同时命中多个模式，优先级为：
`安全合规 > 严格复刻/精确模仿 > 电商交付 > 人像真实增强/人物自然化 > 电商产品精致 > 高保真生成 > 细节扩写/质感增强 > 风格借鉴`。

如果用户明确说生成失败或提示内容政策，优先级改为：
`平台安全改写 > 安全合规 > 参考保真 > 人物自然 > 质感增强`。

## Step 2: 给参考图分配角色

不要把多张图混成“参考图”，必须明确角色：
- 主体/模特参考：锁定脸型、五官、发型、肤色、妆容、体态、气质
- 服装/面料参考：锁定款式、版型、颜色、纹理、褶皱、面料反光
- 产品参考：锁定结构、比例、材质、logo、颜色、边角细节
- 姿势/构图参考：锁定站姿、手势、裁切、视角、景别
- 场景参考：锁定背景、道具、空间关系、景深
- 风格参考：锁定布光、色调、胶片感、品牌视觉、情绪

若用户说“完全参考上传模特风格”，默认锁定：
- 脸部识别特征
- 发型与妆感
- 年龄气质与整体穿搭方向

## Step 3: 必须抽取的信息

所有任务至少补齐这 18 组信息：
1. 主体是谁
2. 保留什么不变
3. 改什么
4. 产品位置
5. 产品角度
6. 人物与产品关系
7. 镜头与构图
8. 视觉主次关系
9. 光线系统
10. 色彩系统
11. 材质系统
12. 真实感细节
13. 风格来源
14. 禁止变化项
15. 参考图保真等级
16. 不可变项与允许变化项
17. 若为人物：表情、眼神、姿态、手部、皮肤自然度
18. 输出用途与模型平台
19. 是否需要平台安全词版本
20. 若为人像：皮肤、眼神、头发、镜头与真实光影
21. 若为产品：边缘、标签、材质、反光、阴影、背景

如果用户没有提供全部信息，先做合理假设并写入【假设 / 待确认】；只有缺失信息会决定方向时才提问。

如果是电商任务，还要额外补齐：
- 交付格式：主图 / 详情页 / 九宫格 / 四视图 / 模特图
- 销售渠道：平台白底 / 品牌官网 / 社媒广告 / 海外独立站
- 品牌语气：轻奢 / 法式 / 运动 / 极简 / 买手店风
- 是否成组输出：单张 / 4张 / 8张 / 9张
- 是否预留文案区

## Step 4: 位置与角度写法

禁止只写“放好看点”“角度高级一点”，必须写成可执行句子：
- `产品位于画面中央偏右，占画面约 20%，处于前景`
- `产品为正面 3/4 视角，向左旋转约 30°`
- `镜头略微俯拍，镜头高度高于产品 10-15 cm`
- `包包挂在模特左肩，包体落在左髋骨位置`

更完整词库：`references/spatial-control.md`

## Step 5: 平台安全改写

用户说 `违反内容政策 / 无法生成 / 生成失败 / 提示违规 / 审核不过 / policy` 时，必须读取 `references/policy-safe-generation.md`。

平台安全改写规则：
- 最终 prompt、English Prompt、负面提示词、Add-on 中都不要出现高风险词
- 不要在负面提示词里写敏感词；很多平台会直接拦截
- 用商业服饰、电商目录、专业模特、完整覆盖、版型展示、面料结构替代敏感表达
- 优先输出“安全可生成版”，再提供“更保真但风险更高的词”作为内部说明，不要让用户直接复制风险词

贴身服饰类默认安全表达：
- `商业服饰目录摄影`
- `贴身服饰产品参考`
- `结构化上装`
- `高腰贴身下装`
- `完整覆盖的服装版型`
- `专业时装模特`
- `端正自然站姿`
- `重点展示剪裁、面料、结构和穿着效果`

如果平台仍拒绝，按顺序降敏：
1. 产品平铺图
2. 隐形模特图
3. 加外搭但保留版型
4. 纯色棚拍/电商白底
5. 删除所有人体敏感词，只保留服饰产品语言

## Step 6: 参考保真与精确模仿

用户说 `模仿更精确 / 1:1 / 完全参考 / 保留同一个人 / 保留同一个产品 / 照着图做` 时，必须读取 `references/reference-fidelity-system.md`。

所有带参考图的任务都要输出：
- `参考图角色矩阵`
- `保真等级`：L1 风格借鉴 / L2 局部高保真 / L3 严格复刻 / L4 电商一致性
- `不可变项`
- `允许变化项`
- `复刻风险`

写 prompt 时必须把“像”拆成具体锁定项：
- 人物：脸型、五官比例、发型、肤色、妆感、体态、气质
- 产品：结构、比例、颜色、材质、logo位置、边角、标签区域
- 服装：版型、领口、肩带、腰头、腿口、缝线、透明度、褶皱
- 场景：空间布局、道具位置、景深、光源方向、裁切

默认不要新增参考图中没有的：
- logo
- 文字
- 花纹
- 首饰
- 配件
- 复杂背景道具

## Step 7: 人物自然度控制

涉及 `人物 / 人像 / 模特 / 上身图 / 穿搭 / 内衣模特 / lifestyle model` 时，必须读取 `references/natural-human-system.md`。

人物自然度必须补齐：
- 成年人物语境
- 表情：轻微自然表情，不夸张
- 眼神：视线目标、眼神光方向
- 姿态：重心、肩颈、脊柱、支撑点
- 手部：动作、接触点、手指弯曲状态
- 皮肤：毛孔、细纹、肤色变化、非塑料感
- 服装接触：褶皱、张力、接触阴影、肩带/腰头位置

如果手部不是画面重点，优先降低手部复杂度，不要设计复杂交叠动作。

## Step 8: 人像真实感增强

用户说 `人像更真实 / 真人感 / 皮肤真实 / 眼神真实 / 别假脸 / 人物像真人` 时，必须读取 `references/portrait-realism-system.md`。

人像提示词必须补齐：
- 身份保真：脸型、眉眼比例、鼻梁、唇形、发型、肤色、肩颈线条
- 皮肤真实：轻微毛孔、自然肤色变化、鼻翼/眼下/嘴角细微阴影
- 眼神真实：视线目标、眼神光来源、双眼高光方向一致
- 表情真实：轻微表情、自然不对称、避免用力微笑
- 姿态真实：身体重心、肩线、手臂与身体距离
- 手部真实：动作简单、手指自然微弯、不遮挡产品
- 头发真实：发丝边缘、少量碎发、受光方向一致

人像类 English Prompt 不要只写 `realistic portrait`，必须写具体的皮肤、眼神、姿态和镜头控制。

## Step 9: 电商产品精致度增强

用户说 `产品图更精致 / 电商图更高级 / 主图更干净 / 材质更好 / 产品更真实 / 详情页更精致` 时，必须读取 `references/ecommerce-product-polish-system.md`。

电商产品提示词必须补齐：
- 产品一致性：轮廓、比例、颜色、材质、logo/标签区域、关键结构
- 产品角度：正面、3/4、侧面、背面、微距细节
- 镜头角度：平视、轻微俯拍、微距近景
- 边缘质量：轮廓清晰、无光晕、自然分离、无粘贴感
- 光线阴影：主光方向、补光、接触阴影、反光控制
- 材质细节：玻璃、金属、皮革、塑料、纸盒、布料等专属描述
- 背景留白：平台白底、品牌官网、社媒广告分别处理

如果用户只说“产品高级点”，不要只加风格词；默认输出平台白底主图和品牌官网主图两个版本。

## Step 10: 细节扩写层

用户说 `更详细 / 更完整 / 细节更多 / 效果更好 / 提示词完善` 时，必须读取 `references/prompt-detail-expansion-system.md`。

扩写时按信息密度分配：
- 35% 硬约束：主体、参考图、不可变项、禁止变化项
- 20% 空间镜头：位置、比例、视角、景别、焦距、画幅
- 25% 质感真实：光线、色彩、材质、皮肤/表面/阴影细节
- 10% 风格用途：品牌语气、商业用途、交付格式
- 10% 纠错约束：负面词、复跑建议、局部修复位置

扩写要让提示词更可执行，而不是更堆砌。

## Step 11: 质感增强层

所有最终提示词都要做一次质感增强。用户说“更高级 / 更有质感 / 更全面 / 品牌感 / 去 AI 感”时，必须读取 `references/prompt-quality-system.md`。

质感增强不是堆形容词，而是补齐 6 个层次：
1. 视觉焦点：主体或产品为什么先被看见
2. 画面层级：前景、中景、背景如何分工
3. 光线逻辑：主光、补光、轮廓光、阴影方向是否一致
4. 色彩关系：主色、辅助色、点缀色和饱和度是否克制
5. 材质触感：布料、皮肤、金属、玻璃、塑料、纸张如何反光或吸光
6. 真实瑕疵：保留轻微纹理、自然褶皱、合理阴影、非塑料皮肤

提示词最后必须通过质量门槛：
- 是否有一个清楚的视觉中心
- 是否能看出镜头从哪里拍
- 是否有可执行的光线方向
- 是否有 2-4 个具体材质细节
- 是否没有互相冲突的角度、风格或主体约束
- 若是人物，是否通过人物自然度自检
- 若是人像，是否通过人像真实感自检
- 若是产品，是否通过产品精致度自检

## Step 12: 风格与品牌语气层

### 普通风格参考

默认只迁移：
- 布光
- 调色
- 氛围
- 构图语言

默认不迁移：
- 具体人物身份
- 产品结构
- 服装版型
- 品牌 logo
- 可识别文字

### 品牌语气层

用户说 `轻奢 / 法式 / 运动 / 极简 / 买手店风 / 品牌感` 时：
- 先读取 `references/brand-tone-map.md`
- 再读取 `references/prompt-quality-system.md`
- 选择 `1 个主语气 + 最多 1 个辅助语气`
- 输出时拆成色板、布光、构图、材质重点、道具密度、文案区

## Step 13: 内衣 / 贴身服饰专项规则

涉及 `贴身服饰 / 家居服 / 塑身服 / 男士贴身下装 / bodysuit / fitted apparel` 时：
- 内部可以理解用户品类，但最终交给生图模型的提示词要优先使用 `references/policy-safe-generation.md` 的平台安全表达
- 默认使用 `专业时装模特 + 商业服饰目录摄影 + 完整覆盖的服装版型`
- 避免在最终提示词和负面词中出现容易触发平台审核的敏感词
- 必须写清版型、材质、贴合关系、覆盖度、透明度

先判断品类归属：
- 女款贴身服饰 / 连体服：`professional fashion model` / `fitted apparel`
- 男士贴身下装 / 背心 / 家居服：`professional male fashion model` / `fitted base layer`
- 中性家居服：`professional fashion model` / `lounge apparel`

如果是男士内裤/背心类，要强调：
- 腰头
- 裆部支撑
- 腿口包裹
- 棉感 / 莫代尔 / 罗纹
- 运动或居家气质

详细规则：`references/lingerie-guide.md`

## Step 14: 电商固定交付格式

如果用户明确要：
- 主图
- 模特图
- 四视图
- 详情页
- 九宫格

必须读取 `references/ecommerce-deliverables.md`，并拆成多张图输出。

最终输出至少包含：
- `交付类型`
- `总视觉方向`
- `品牌语气层`
- `每张图的角色`
- `每张图的空间与角度蓝图`
- `每张图的中文提示词`
- `每张图的 English Prompt`

不要只给一条总 prompt。

## Step 15: Prompt 写作原则

用户要求 `更完善 / 效果更好 / 可直接复制 / 给完整提示词包 / ao` 时，读取 `references/prompt-output-package.md`。

优先使用自然语言长句，顺序：
```text
[主体与参考关系]
[保真等级与不可变项]
[必须保持不变的内容]
[位置与角度]
[姿势/交互]
[人物自然度控制，如适用]
[视觉主次与画面层级]
[场景与背景]
[布光与色彩]
[材质与真实细节]
[风格来源]
[画幅/镜头/画质]
```

必须做到：
- 先写硬约束，再写风格修饰词
- 把“参考谁”写清楚，不要只写“参考图”
- 把“像什么”改成“具体长什么样”
- 把“自然”拆成表情、眼神、重心、手部、皮肤、服装接触
- 把“高级”拆成光线、色板、材质、留白、镜头和道具密度
- 中文提示词负责完整决策，英文提示词负责模型可执行表达，不能机械直译
- 用户指定了位置、角度、比例、风格时，不要被更泛的词覆盖

必须避免：
- 空泛词堆砌：`masterpiece`、`best quality`、`ultra detailed`
- 弱约束：`similar`、`inspired`、`cool`、`nice`
- 冲突约束：例如同时要求 `top-down` 和 `eye-level`
- 未经授权修改主体：换脸、换年龄、换品牌、换 logo

## 标准输出格式

## 失败保护

如果用户要求“1:1 完全一致”，但存在以下高风险项，要在提示词后补一句提醒：
- 复杂文字排版
- 具体商标/小字
- 手指与首饰复杂交互
- 透明材质 + 高频反射
- 蕾丝镂空、网纱半透明、极细肩带、连体内衣高贴合区域
- 多人物拥挤构图
- 超复杂背景中的遮挡关系

## Quick Rules

- 用户说 `ao`，默认启用本 skill
- 用户说 `更完善 / 效果更好 / 直接可用`，默认输出完整提示词包
- 用户说 `更详细 / 细节更多 / 提示词更完整`，默认启用细节扩写系统
- 用户说 `人像更真实 / 真人感 / 皮肤真实 / 眼神真实 / 别假脸`，默认启用人像真实感系统
- 用户说 `产品图更精致 / 电商图更高级 / 主图更干净 / 材质更好`，默认启用电商产品精致度系统
- 用户说 `违反内容政策 / 生成不了 / 提示违规 / policy / 审核不过`，默认启用平台安全改写，不在最终 prompt 和负面词里输出敏感词
- 用户说 `更有质感 / 更高级 / 更全面`，默认启用质感增强层
- 用户说 `模仿更精确 / 完全参考 / 保留同一个人 / 保留同一个产品`，默认启用参考保真系统
- 用户说 `人物更自然 / 别像AI / 姿势自然 / 表情自然`，默认启用人物自然度系统
- 用户说 `1:1还原`，默认进入严格复刻
- 用户说 `产品位置` 或 `产品角度`，必须量化
- 用户说 `主图 / 详情页 / 九宫格 / 四视图 / 模特图`，默认拆成固定帧位输出
- 用户说 `轻奢 / 法式 / 运动 / 极简 / 买手店风`，默认映射成品牌语气层
- 能明确的就不要模糊，能量化的就不要空泛
