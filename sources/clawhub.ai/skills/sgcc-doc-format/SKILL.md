# 国家电网规范格式 Word 排版

把收到的 Word 文档（.docx）按辉总确认的 12 条国网规范规则重新排版，生成新文件，
并通过飞书消息把成品发回给用户。

## 触发条件

用户发来 Word 文档（docx 附件）并说"调成规范格式" / "按国网格式排版" 等。

## 12 条规范速查

| 元素 | 字体 | 字号 | 加粗 | 对齐 | 缩进 | 行距 | 备注 |
|---|---|---|---|---|---|---|---|
| 主标题 | 方正小标宋_GBK | 二号(22) | 否 | 居中 | 无 | 28磅 | 样式正文，段前后0 |
| 副标题 | 方正楷体_GBK | 三号(16) | 是 | 居中 | 无 | 28磅 | 样式正文，段前后0 |
| 目录标题 | 方正黑体_GBK | 二号(22) | 否 | 居中 | 无 | 28磅 | 样式正文，段前后0 |
| 目录内容 | 与各级标题一致 | 四号(14) | 随标题 | 左 | 无 | 28磅 | 可点击跳转（TOC域） |
| 一级标题 | 方正黑体_GBK | 三号(16) | 否 | 左 | 2字符 | 28磅 | 样式标题1，序号"一、" |
| 二级标题 | 方正楷体_GBK | 三号(16) | 是 | 左 | 2字符 | 28磅 | 样式标题2，序号"（一）" |
| 三级标题 | 方正仿宋_GBK | 三号(16) | 是 | 左 | 2字符 | 28磅 | 样式标题3，序号"1." |
| 四级标题 | 方正仿宋_GBK | 三号(16) | 否 | 左 | 2字符 | 28磅 | 样式标题4，序号"（1）" |
| 正文 | 方正仿宋_GBK | 三号(16) | 否 | 左 | 2字符 | 28磅 | 样式正文 |
| 页码 | 方正仿宋_GBK | 四号(14) | 否 | 居中 | - | - | "-1-"样式，从正文开始编号，封面目录无页码 |
| 表格表头 | 方正黑体_GBK | 四号(14) | 否 | - | - | 20磅 | 表格整体居中 |
| 表格其他 | 方正仿宋_GBK | 四号(14) | 否 | - | - | 20磅 | 表格整体居中 |
| 引号 | - | - | - | - | - | - | 英文双引号改为中文引号"" |

## 处理流程

1. 保存用户发来的 docx 到工作目录（如 `~/.openclaw/workspace/tmp/`）
2. 运行脚本：

   ```bash
   python3 ~/.openclaw/workspace/skills/sgcc-doc-format/scripts/format_sgcc.py 输入.docx 输出.docx
   ```

   参数说明：
   - `输入.docx`：必填
   - `输出.docx`：可选，默认 `输入_规范格式.docx`
   - `--no-auto-toc`：可选，不自动插入目录域（默认自动插入）

3. 检查脚本输出的识别报告（主标题/副标题/标题统计/表格数），如有异常向用户说明
4. 用飞书消息把输出文件发给用户（MEDIA 附件方式），并附简短说明

## 识别规则（重要）

- **主标题**：正文区域之前的第一个居中段落；无居中段则取第一个非空段
- **副标题**：主标题之后第一个居中段落（可能不存在）
- **目录标题**：文本恰为"目录"的段落
- **标题级别**：优先按 Word 样式（Heading 1-4）识别；否则按编号规则：
  - `一、` → 一级；`（一）` → 二级；`1.` → 三级；`（1）` → 四级
- **正文起始**：目录标题之后的第一个标题段
- 封面/目录区域的其他段落（如落款、日期）保持原样不动

## 目录与页码说明

- 文档已有"目录"标题 → 清理旧目录条目，插入可点击 TOC 域（`TOC \o "1-4" \h \z \u`）
- 文档无"目录"标题 → 自动在正文前插入"目录"标题 + TOC 域
- 已设置 `updateFields`，Word 打开时自动刷新目录；若未刷新，提示用户全选按 F9
- 正文前自动插入分节符：封面/目录节无页码，正文节页码从 1 开始，格式 `-1-`

## 注意事项

- 字体只写入字体名，本机无需安装方正字体；用户端 Word 需装有对应字体才能正确显示
- 只处理 .docx；.doc 老格式需先另存为 .docx
- 引号替换按段落成对处理（奇数个引号时最后一个保持英文引号并提示）
- 处理前保留原文件，输出为新文件，不覆盖
