# 美团爆单操盘手

为本地生活商家设计一套能在美团"比价场"里活下来的团购产品体系，从调研到上线把单量做爆。核心方法论来自真实项目实战（深圳车公庙中医诊所美团团购方案），不是通用营销理论。

## 何时使用

- 新店要在美团上线团购，不知道项目怎么选、怎么定价
- 存量店铺团单销量差，需要诊断重构
- 商户要参加平台大促（双11/年货节），需要折扣规划
- 只问某个单点问题（如"神券分摊规则"）→ 直接查 `references/marketing-tools.md`

## 核心心法（先建立判断框架）

1. **美团是比价场，不是理念展示场**。用户列表页只看"项目名+时长+价格"三件事，先赢在比价，再用到店服务讲理念。
2. **占便宜 > 真便宜**。团购价/正价的折扣深度心智锚点是 5-6.5 折，8 折的"体验价"没有点击欲望，还会让正价显得虚高。
3. **折扣只动团购价，永不动正价**。正价是划线锚点，动了就失去所有大促的让利空间。
4. **弱搜索品类不做线上引流款**。用户在美团搜的是"推拿/正骨/艾灸"这类即时消费词，不会搜"体检报告解读"这类延迟消费词——后者只能做"桥梁品"（到店后转化）。
5. **新店获客第一理由就是占便宜 + 时长不吃亏**。同期价格要比片区验证过的低价带更低或持平，时长要 ≥ 片区主流。

## 五步工作流

### 第一步：片区竞对调研（数据是一切的前提）

用 WebSearch 调研商家所在位置 3km 内同类店铺的线上项目。**必须拿到真实数据，没有数据的定价是拍脑袋。**

- 按品类分组搜索（如推拿正骨/针灸/艾灸/头疗睡眠/美容项目各自成组）
- 每个竞对项目记录六字段：**项目名称、时长、正价、团购价、销量/评价数、特色服务内容**
- 特别留意"已售数量"——已售几百单的低价品 = 片区被验证过的引流钩子
- 模板见 `assets/competitor-research-template.md`

调研完成后输出"价格带分布"结论：每个品类的低价带（引流线）、主流带（常规线）、高端带（利润线）分别是多少。

### 第二步：四层产品架构 + 桥梁品

| 层级 | 定位 | 定价逻辑 | 备注 |
|---|---|---|---|
| 引流层 | 拉爆销量、进搜索流量 | 对标片区验证过的低价带，持平或更低；时长 ≥ 片区主流 | 即时消费品类才配做引流款；主推品可设每日限量制造紧迫感 |
| 常规层 | 走量+口碑 | 贴片区头部竞对团购价 ±10% | 时长口径不能输竞对 |
| 盈利层 | 差异化赚钱 | 卡在市场锚点的中间空白带 | 独有/强差异化项目放这里 |
| 高客单层 | 大促主力、锁客 | 单次价 × 次数 × 0.85 左右的次卡形态 | 优先挂平台次卡产品（资金监管、随时可退，打掉"办卡怕跑路"顾虑） |
| 桥梁品 | 到店转化中间件 | 线上挂名做信任背书但不投流；到店后低价加购或高客单直接送 | 弱搜索品类专属位置，核心作用是挖需求、对症升单 |

每层项目数量建议：引流 2 个、常规 3-4 个、盈利 2-3 个、高客单 2-3 个。超过 15 个 SKU 会稀释主推权重。

### 第三步：定价与折扣纵深建模

**团购价必须卡在神券档位线上**（如 98/198/228/368 这类整数心理位），券一挂就能用。

极端叠券到手价测算公式：

```
极端到手价 = 团购价 − 平台券商家分摊（见 marketing-tools.md 分摊表）− 新客立减
合格标准 = 极端到手价下毛利仍为正 → 全年任何大促都不用临时改价
```

引流款建议只报普通神券（商家分摊仅 ¥3），不报膨胀档，避免低价品被券打穿。

项目命名公式：**【人群/痛点】+ 通俗项目名 + 时长**。用客户搜的词（"痛症针灸"而不是"元气针"），禁生造概念词。

### 第四步：活动玩法规划

读 `references/marketing-tools.md`（含神会员/神券分摊规则表、商家自设工具清单、全年大促日历）。要点：

- 神会员必报——不报名的店用户照样能用券（平台全出），但拿不到神券流量标签，等于白送竞对截客
- 按商户类目核对工具开放性：医疗类目下秒杀/直播/次卡等可能受限，需与 BD 逐项确认
- 结合当前月份排大促节奏（双11疗程卡主场、12月年货节、1-2月春节不打烊等）

### 第五步：冷启动 SOP + 方案输出

上线 30 天打法（销量冷启动、评价关键词、首图详情、限购限量兜底）+ 合规红线检查（读 `references/compliance.md`）。

最终方案输出为 HTML 报告，结构骨架直接取 `assets/html-report-skeleton.html`，必须包含：竞对数据全景表、价格带可视化、四层架构图、逐 SKU 卡片（含对标依据）、折扣纵深测算表、活动日历、冷启动计划、上线确认清单。

## 弱项应对（方案必备章节）

商户必有弱项（无医保、位置偏、品牌新、无停车场……）。原则：**不补短板，绕开打**。

1. 界定弱项影响的客群，明确"主动让出"哪部分客
2. 找到弱项不影响决策的主攻客群（如无医保 → 主攻自费场景客群）
3. 用别信任要素替代（资质公示、医师团队、流程透明、独家差异化服务）
4. 若弱项是价格类，用引流款激进定价对冲心理落差

## 上线前必核清单（输出给商户确认）

- 划线正价的真实性（虚高正价是平台重点打击对象，也是合规风险）
- 成本口径与毛利底线（每个 SKU 的极端到手价毛利测算）
- 每日限量/限购参数
- 资质公示项（营业执照/许可证/医师资质）
- 桥梁品的线上挂名策略
- 医疗等特殊类目与 BD 确认工具开放性
