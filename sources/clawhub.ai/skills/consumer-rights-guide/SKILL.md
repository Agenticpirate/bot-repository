# consumer-rights-guide
> 消费维权全流程指引：从证据整理到投诉举报的完整SOP。当用户需要维权、投诉、举报时使用，可独立于 import-product-investigator 被触发。

## 触发场景

当用户有以下需求时使用本技能：
- "我要投诉" / "帮我写投诉材料" / "怎么维权"
- 购买到问题产品（假货、违规、虚假宣传）后不知道怎么投诉
- 药店/商家拒绝退货退款，想要下一步行动方案
- 想知道退一赔三怎么操作
- **联动触发**：import-product-investigator 调查结论为违规/空壳/三无时，建议用户说"消费者维权"进入本 skill

## 前置确认

开始维权指引前，快速确认以下关键信息：

| 问题 | 目的 |
|------|------|
| 在哪里买的？（线下药店 / 线上电商 / 医生推荐） | 决定投诉渠道优先级 |
| 有购买凭证吗？（小票/发票/订单截图） | 凭证是维权基础，没有则先解决凭证问题 |
| 产品问题是什么？（无资质 / 虚假宣传 / GACC暂停 / 无批号） | 决定投诉理由和法律依据 |
| 购买金额是多少？ | 决定赔偿计算方式 |

**如用户无法提供任何凭证**：指引用户先联系商家/平台补开凭证，再继续维权流程。

## 第一阶段：证据整理（1小时内完成）

### 目标
整理所有证据，建立完整证据链。证据越完整，投诉成功率越高。

### 截图保存说明

本 skill 涉及截图时，按以下方式操作：

1. **使用浏览器截图**（适用于在线购买链接、产品详情页）：
   - `browser(action=screenshot)` 或 `browser(action=open)` + `browser(action=screenshot)`
   - 保存到：`~/.qclaw/workspace/证据包_YYYY-MM-DD/`
   - 命名格式：`01_购买页面_商品名.png`、`02_NMPA查询_商品名.png`

2. **用户上传图片**（适用于产品包装照片、购买小票、GACC截图等）：
   - 请用户直接在对话中发送图片
   - AI 收到后保存到：`~/.qclaw/workspace/证据包_YYYY-MM-DD/`
   - 命名格式：`03_产品包装_正面_商品名.jpg`、`04_购买小票_商品名.jpg`

3. **证据包目录结构**（最终输出）：

```
~/.qclaw/workspace/证据包_YYYY-MM-DD/
├── 01_购买凭证/
│   ├── 购买小票.jpg
│   └── 支付记录.png
├── 02_产品包装/
│   ├── 正面.jpg
│   ├── 背面.jpg
│   └── 成分表.jpg
├── 03_查询证据/
│   ├── GACC查询截图.png
│   ├── NMPA查询截图.png
│   └── 境外企业查询截图.png
├── 04_商家沟通（如有）/
│   └── 沟通记录.png
└── 证据清单.md    ← 自动生成
```

### 必做清单

**1. 购买凭证**
- 保存小票/发票原件（拍照 + 电子扫描）
- 记录：购买时间、购买地点、商家名称
- 如有支付记录（微信/支付宝/银行卡），截图保存

**2. 产品包装**
- 拍照：正面、背面、成分表、标签（所有文字清晰可读）
- 特别拍摄：注册号、出口商名称、原产地标注
- 如已开封，保留包装盒和内包装

**3. 医生处方（如有）**
- 保留医生开具的纸质外采处方原件
- 记录：医生姓名、科室、医院名称

**4. 查询证据**（来源于 import-product-investigator 调查报告）
- GACC查询截图（显示注册号和状态）
- NMPA查询截图（显示无保健食品批号）
- 境外企业查无实体记录（如有）
- 商家销售页面截图（如在线购买）

**5. 其他证据**
- 与商家沟通的聊天记录截图
- 商家拒绝退货的录音（如有）

## 第二阶段：渠道选择与投诉执行

### 原则
先本地（药店）再平台，先行政再法律。

### 渠道一：购买地点现场交涉（当天）

**适用场景**：在线下药店/门店购买，希望快速解决。

**目标**：退货退款，必要时争取三倍赔偿。

**操作步骤**：
1. 携带购买凭证和产品，前往购买地点
2. 向店员/店长说明情况，态度坚定但保持礼貌
3. 出示核心证据（GACC暂停截图、NMPA无批号截图）
4. 提出诉求：退货 + 三倍赔偿

**参考话术**：
> "您好，我在贵店购买了[产品名称]，经查询发现以下问题：[简述1-2个核心发现]。根据《消费者权益保护法》第55条，我要求退货并三倍赔偿。"

**录音提示**：全程录音，开口时说"本次谈话将被录音"。

**可能结果**：
- ✅ 同意退货+三倍赔偿 → 签署和解协议（见第三阶段模板）
- ⚠️ 同意退货但拒绝赔偿 → 接受退货，保留追诉权
- ❌ 拒绝退货 → 保留录音，转向渠道二

---

### 渠道二：12315平台投诉（当天）

**适用场景**：现场交涉未果，或在线购买，或需要正式投诉记录。

**操作步骤**：
1. 微信搜索"12315"小程序，或访问 https://www.12315.cn/
2. 选择"我要投诉"，填写：
   - 被投诉方：商家名称、地址、统一社会信用代码
   - 投诉问题类型：进口食品无合法资质 / 虚假宣传 / GACC暂停进口仍在销售
   - 诉求：退货退款 + 三倍赔偿
3. 上传购买凭证和产品照片
4. 提交后记录投诉编号

**投诉文本模板**：

```
投诉对象：[商家名称]
统一社会信用代码：[填入，企查查可查]

投诉内容：
本人于[购买日期]在[商家名称]购买了[产品名称]，经查询发现以下问题：

1. 该产品标注的境外生产企业GACC注册号为[XXX]，状态为"暂停进口"，但产品仍在市场销售，违反《食品安全法》第92条；
2. 该产品未取得国家市场监管总局保健食品注册（NMPA查询结果为"无匹配数据"），但以保健食品身份销售，违反《食品安全法》；
3. 产品包装标注出口商为[XXX]，经查询在当地政府公司注册数据库中无记录，涉嫌虚假标注。

诉求：依据《消费者权益保护法》第55条，要求退货退款并三倍赔偿，共计[金额×4]元。

证据已上传。
```

---

### 渠道三：12360海关热线（当天或次日）

**适用场景**：GACC状态为"暂停进口"或"取消"，需要海关介入。

**操作步骤**：
1. 拨打12360（部分地区需加区号），或微信搜索"海关12360"
2. 说明情况：某产品GACC注册号已被暂停但仍在销售
3. 提供：产品名称、GACC注册号、购买渠道、销售平台链接
4. 记录工单号

**投诉文本模板**：

```
本人发现以下进口食品涉嫌违规：

产品名称：[产品名称]
GACC注册号：[XXX]
境外生产企业：[名称]
购买渠道：[线下药店/电商平台]

经海关总署进口食品境外生产企业注册信息查询系统查询，GACC注册号[XXX]状态为"暂停进口"，但该产品仍在市场销售。

请海关部门核查该产品是否属于违规销售。
```

### 渠道四：医院投诉（如有医生推荐）

**适用场景**：医生违规推荐无资质产品。

**操作步骤**：
1. 向医院医务科提交书面投诉（附医生处方复印件）
2. 说明：医生推荐的具体产品名称、品牌，超出了诊疗范围
3. 同时拨打12320（卫健委热线）投诉

## 第三阶段：和解谈判

### 原则
优先接受和解，但协议内容必须有书面记录。

### 和解协议模板

```
和解协议

甲方（消费者）：[姓名]
乙方（商家）：[商家名称]

一、乙方同意退还甲方购买款项人民币[金额]元，于[日期]前支付至甲方账户（[支付方式/账号]）。

二、乙方同意赔偿甲方人民币[金额]元，于[日期]前支付。

三、甲方收到上述款项后，不再就本次购买行为向乙方主张任何权利。

四、本协议一式两份，甲乙双方各执一份，具有同等法律效力。

甲方签字：____________    乙方签字：____________
日期：____________         日期：____________
```

**注意**：
- 所有金额白纸黑字写明
- 口头承诺无效
- 签署前拍照留档
- 建议现场签署，如对方要求带走签署则保留沟通记录

## 第四阶段：升级路径

### 渠道五：人民法院起诉

**适用场景**：投诉渠道均无果，金额较大（建议500元以上考虑）。

**操作步骤**：
1. 准备证据包（按第一阶段清单）
2. 在"人民法院在线服务"小程序或当地法院立案
3. 起诉案由：买卖合同纠纷 + 消费者权益保护
4. 诉讼请求：退货退款 + 三倍惩罚性赔偿

**成本估算**：
- 诉讼费：50元（金额1万以下）
- 律师费：可不请律师，消费者权益纠纷可自行起诉
- 耗时：2-6个月

**简化起诉状模板**：

```
民事起诉状

原告：[姓名]，身份证号：[填入]，联系电话：[填入]
被告：[商家名称]，统一社会信用代码：[填入]

诉讼请求：
1. 判令被告退还购买款人民币[金额]元
2. 判令被告支付惩罚性赔偿金人民币[金额×3]元
3. 诉讼费由被告承担

事实与理由：
[简述购买经过和违规发现，200字以内]

此致
[商家所在地基层人民法院]

起诉人（签名）：____________
日期：____________
```

## 赔偿计算速查

| 购买金额 | 三倍赔偿金额 | 合计 | 说明 |
|---------|------------|------|------|
| ≤ 500元 | 500元（最低赔偿额） | 退款+500 | 保底500元 |
| 368元 | 1,104元 | 退款368 + 赔偿1,104 = 1,472元 | 实际案例 |
| 500元 | 1,500元 | 退款500 + 赔偿1,500 = 2,000元 | - |
| > 500元 | 购买金额 × 3 | 退款 + 购买金额 × 3 | 标准计算 |

## 注意事项

1. **证据先行**：没有凭证先补凭证，证据越完整越好
2. **投诉不收费**：12315、12360均为免费渠道，不会要求转账
3. **录音合法**：与商家的沟通录音在维权场景下可作为证据使用
4. **先易后难**：先现场交涉（最快），再12315，再12360，最后考虑起诉
5. **保留追诉权**：即使当场接受退货未获赔偿，仍可在1年内通过12315追诉
6. **保护隐私**：所有证据仅用于维权，不对外传播
