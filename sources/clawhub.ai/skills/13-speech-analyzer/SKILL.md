# 口头表达分析器

> 产品开发全链路 Skill #13 · 用数据说话，用20个维度量化你的表达质量

## 功能

基于音频文件，进行 20 维度口头表达分析，输出结构化分析报告。

## 分析框架

### 标准层（15 维度）

| 组 | 维度 | 说明 |
|----|------|------|
| 基础指标 | 口癖分析 | 核心口癖和延伸词密度统计 |
| 基础指标 | 语速分析 | 平均语速、变异系数、稳定性 |
| 基础指标 | 声学特征 | 音高、音量动态范围、清晰度 |
| 基础指标 | 停顿分析 | 短/中/长/超长停顿分布 |
| 时间维度 | 口癖热力图 | 每10分钟口癖密度变化 |
| 时间维度 | 每10分钟指标 | 细粒度时间序列 |
| 时间维度 | 最佳/最差表现 | 自动标记表现窗口 |
| 内容维度 | 话题结构 | 按话题拆解表现差异 |
| 内容维度 | 互动分析 | 说话人占比和模式 |
| 诊断改善 | 执行摘要 | 综合评分和评级 |
| 诊断改善 | 诊断 | 核心问题定位 |
| 诊断改善 | 改善建议 | 分级改进方案 |
| 诊断改善 | 跨场对比 | 多场次趋势追踪 |

### 深度层（5 维度）

| 维度 | 说明 |
|------|------|
| 表达结构分析 | 句子类型、逻辑连接词、句子长度分布 |
| 内容质量分析 | 词汇丰富度、具象vs抽象比例 |
| 收尾困难分析 | 收尾质量、重复率、语法完整性 |
| 认知负荷分析 | 各时段认知负荷变化 |
| 即兴表达原理 | 即兴表达质量评估 |

## 输出格式

- 最终交付物：Markdown 分析报告
- 可选项：Web 可视化报告

1. 分析必须基于实际音频数据
2. 所有评分必须有计算公式
3. 改善建议必须可执行
