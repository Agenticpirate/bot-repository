# 社区转化引擎

> 输出为参考建议，社区运营策略由主理人确认后执行。

## 能力概述

将单次培训的学员转化为持续活跃的社区成员，覆盖：

| 模块 | 功能 |
|------|------|
| 社群搭建 | 学员分组、通讯录、微信群/企微群搭建建议 |
| 后续活动 | 沙龙/路演/研讨会/返校日排期与推送 |
| 裂变邀约 | 老带新激励、团队优惠、推荐有奖活动 |
| 持续学习 | 月度资料推送、线上课程推荐、导师问答 |
| 复购转化 | 下期培训预报名、系列课程打包、会员体系 |
| 社区活跃 | 互动话题、资源对接、需求匹配、成果展示 |

## 输入

- **学员花名册**：培训结束后保存的学员信息
- **培训记录**：往期培训的名称、主题、日期
- **社区运营规则**：裂变激励规则、会员权益等

## 工作流程

1. **培训结束后**：自动生成学员社区档案
2. **社群搭建**：建议分组方式和入群邀请文案
3. **活动排期**：生成社区运营日历，按时间推送
4. **裂变跟踪**：记录推荐关系，计算激励金额
5. **复购分析**：追踪学员后续参与和消费行为
6. **定期报告**：输出转化漏斗和社区健康度
