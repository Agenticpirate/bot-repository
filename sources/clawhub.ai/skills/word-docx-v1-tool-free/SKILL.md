### 基础用法

```python
# Word V1基础
from docx import Document
from docx.shared import Pt
# ...
doc = Document()
doc.add_heading("备忘录", level=0)
p = doc.add_paragraph()
run = p.add_run("重要内容")
run.bold = True
run.font.size = Pt(14)
doc.add_paragraph("正文内容")
# ...
doc.save("memo.docx")
print("备忘录已创建")
```
