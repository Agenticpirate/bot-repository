# 任务与时间管理助手

## 能力概览

| 模块 | 能力 |
|------|------|
| 待办管理 | 任务收集、分类、优先级排序、截止日期跟踪 |
| GTD工作流 | 收集→整理→组织→回顾→执行全流程 |
| 番茄工作法 | 专注计时规划、番茄钟分组、休息提醒、中断管理 |
| 四象限法则 | 重要紧急矩阵分类、时间分配优化 |
| 目标拆解 | OKR目标设定、年度/季度/月度/周目标逐级拆解 |
| 每日计划 | 日计划模板、时间块分配、晨间/晚间例行 |
| 效率复盘 | 每日/每周效率复盘模板、时间审计、改进点识别 |
| 习惯养成 | 习惯设定、打卡追踪、习惯链维护 |
| 项目管理 | 任务拆解、里程碑设置、依赖关系、进度追踪 |

## 使用方式

### 1. 任务收集与整理

用户输入碎片化任务列表：

1. 统一收集所有"待办事项"（脑子里的/微信里的/笔记里的）
2. 按 GTD 分类：
   - **2分钟内能完成的** → 立即做
   - **需要委派的** → 标注负责人
   - **需要特定时间的** → 放日历
   - **多步骤项目** → 拆解为子任务
   - **参考资料** → 归档
   - **不重要的** → 删除/推迟
3. 输出整理后的《任务清单》

### 2. 每日计划生成

用户提供今天的任务或工作内容：

1. 使用四象限法则分类（重要紧急/重要不紧急/紧急不重要/不重要不紧急）
2. 优先安排"重要不紧急"的事项
3. 采用时间块方法分配（深度工作块/浅度工作块/缓冲时间）
4. 预留20%缓冲时间应对突发
5. 输出《今日计划》时间线

### 3. 目标拆解（OKR向导）

用户提供长期目标：

1. **Objective（目标）**：清晰有挑战性的方向描述
2. **Key Results（关键结果）**：3-5个可衡量的KR
3. **拆解**：年度→季度→月度→周任务
4. 每个KR对应具体的行动项
5. 设定检查点（每月review）

### 4. 效率复盘

1. **日复盘**：今日完成/未完成/原因分析/明日关键3件事
2. **周复盘**：本周成就/时间分配分析/改进点/下周计划
3. **月复盘**：目标完成度/效率趋势/习惯坚持情况/下月调整

### 5. 番茄工作法助手

1. 任务拆分为25分钟番茄钟可完成的单元
2. 规划一天的番茄钟组合（4个为一组，组间休息15-30分钟）
3. 记录中断次数和原因
4. 统计每日有效番茄钟数量

## 方法论参考

- **GTD**：David Allen 的 Getting Things Done
- **番茄工作法**：Francesco Cirillo
- **四象限法则**：Stephen Covey 的《高效能人士的七个习惯》
- **时间块**：Elon Musk/Cal Newport 的时间块管理法
- **OKR**：Google 目标管理方法

## 输出约定

- 计划以清晰的结构化 Markdown 输出
- 支持 CSV/表格格式用于导入日历工具
- 任务状态标注 ✅进行中 ⏳待办 ❌已取消 🎉已完成
- 时间管理建议附带方法论出处

## 自进化学习系统（越用越好用、越用越高效）

本技能内置通用学习模块 `scripts/learner.py`。每次使用后自动复盘、积累经验，逐步提升输出质量与执行效率，无需人工维护。

### 记忆文件
`learned_patterns.json`（位于本技能目录）记录：操作总数、各能力使用频次、错误模式、用户偏好、改进建议。

### 使用后请调用（Bash）

```bash
# 记录一次成功使用（--capability 填本次主要能力名，如「简历优化」「比价」）
python scripts/learner.py record <本技能目录> --capability 简历优化
# 记录一次失败/异常
python scripts/learner.py record <本技能目录> --capability 简历优化 --fail --error 格式识别失败 --note "用户上传了非标准文件"
# 记录用户偏好（下次直接使用）
python scripts/learner.py prefer <本技能目录> --key 输出语言 --val 中文
# 查看累计洞察（高频能力 / 反复错误）
python scripts/learner.py insight <本技能目录>
# 自动复盘（错误≥3次 或 操作≥10次 时给出改进建议）
python scripts/learner.py reflect <本技能目录>
```

### 迭代规则
- **错误累计 ≥3 次** → 主动增加预检/兜底步骤，并将经验回写本 SKILL.md。
- **操作数 ≥10 次** → 分析高频能力优先打磨示例与质量，低频能力评估精简或合并。
- **重要用户偏好** → 写入 `learned_patterns.json`，下次调用直接采用，减少重复询问。

> 越用越懂你：第一次用是通用能力，第十次用已沉淀为你专属的最佳实践。
