# 资金管理：交易生存的底线工程

## R — 原文 (Reading)

> "在任何成功的期货交易模式中，都必须考虑价格预测、时机抉择和资金管理三个方面，缺一不可。"
> "一笔交易中获利的潜力至少须 3 倍于可能的亏损，我们才能够付诸实施。"（报偿—风险比 ≥ 3:1）
> "绝不要追加保证金，别把活钱扔进死头寸里去。"
> "最成功的交易商也只能在 40% 的交易中获利。"（长期靠赔率而非胜率）
>
> — 约翰·墨菲，第十六章 资金管理

---

## I — 方法论骨架 (Interpretation)

资金管理决定"投多少钱、亏多少就停"，是生存优先的底线工程。成功交易三要素（预测/时机/资金）缺一则全盘失效（p63）。核心限额与纪律：

1. **总资本限额**：投入市场资金 ≤ 总资本 50%，余额留储备（p64）。
2. **单市场限额**：单市场 ≤ 总资本 10%–15%（p65）。
3. **单市场亏损限额**：单市场最大亏损 ≤ 总资本 5%（p66）——这是倒推仓位与止损距离的核心出发点。
4. **群类限额**：同一群类（如贵金属）≤ 总资本 20%–25%（p67），因同群类常同向、分散无效。
5. **始终设止损**（p68 / ce38）：开仓即挂，把亏损锁死在计划内；止损太近被洗、太远亏大，须按波动率与支撑位设。
6. **报偿—风险比 ≥ 3:1**（p69 / ce40）：胜率本就低（约 40%），须靠少数大赢覆盖多数小亏，未达不动。
7. **让利润奔跑、限亏损**（p70）：截断亏损、让盈利增长。
8. **复合头寸**（p71 / g17）：分跟势头寸（远止损图大利）与交易头寸（短线了结锁利），化解"预先/当场/伺后"两难。
9. **金字塔加码**（p76 / g17）：后层<前层、只顺盈加、绝不加亏损、止损移至保本。
10. **绝不加保证金**（p73 / ce42）：亏损头寸证明判断有误，再加钱摊平只会越陷越深。
11. **分散勿过**（p75 / ce41）：在 4–6 个不相干市场持有，过度分散使少数盈利被大量小亏抵消。
12. **保守生存**（p72 / ce44）：长期保守最可取；盈利后膨胀加注（资本顶峰扩注）时机最糟。

## A1 — 书中的应用 (Past Application)

### 案例 1：黄金交易者 300→500 的报偿—风险比
- **问题**：如何判断是否值得入场？
- **方法论的使用**：交易者在 300 介入、290 止损（风险 10），目标 500（利润 200），R:R ≈ 20:1，远高于 3:1 门槛。
- **结论**：先算 R:R 再决定，未达 3:1 不动。
- **结果**：符合资金管理入场条件（c26）。

### 案例 2：作者从研究转做资金管理
- **问题**：为何资金管理是交易核心？
- **方法论的使用**：作者从大经纪公司技术分析研究转做资金管理实务，格外重视把分析转为可执行头寸与风险管理。
- **结论**：分析再好，落不到仓位与止损上仍会亏。
- **结果**：奠定全书"资金管理优先"的取向（c27）。

## E — 可执行步骤 (Execution)

1. **定风险额度**：单市场最大亏损 ≤ 总资本 5%，反推可承受合约数与止损距离。
   - 完成标准：明确单笔最大亏损金额与合约数。
2. **算 R:R**：用目标位与止损位算报偿—风险比，≥3:1 才入场。
   - 完成标准：R:R 达标，否则放弃。
3. **设限额**：总投入 ≤50%、单市场 ≤10–15%、群类 ≤20–25%。
   - 完成标准：仓位在各限额内。
4. **开仓即挂止损**：按支撑位/波动率设，不裸奔。
   - 完成标准：止损单已挂，距离合理。
5. **用复合头寸+金字塔**：分笔建仓，盈利后递减加码、止损移至保本。
   - 完成标准：顺盈加码、绝不加亏损头寸。
6. **不加保证金、优先平亏损**：死头寸认错离场，保留盈利仓奔跑。
   - 完成标准：不摊平、不补保证金。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill
- 用户问"突破点/入场时机怎么选" → 转 trading-tactics-checklist。
- 用户问"市场情绪是不是太一致了" → 转 oscillators-contrarian。

### 作者在书中警告的失败模式
- **杠杆强平**（ce04）：高杠杆下小幅逆向即触发追加保证金，资金不足被迫在底部/顶部平仓。
- **止损两难**（ce38）：太近被洗、太远亏大，须按波动率与支撑位设，无万能值。
- **限额失守**（ce39）：超限集中，单次/单群类失败即重创或爆仓。
- **低赔率必亏**（ce40）：不满足 3:1 长期数学期望为负。
- **分散过犹不及**（ce41）：超过 4–6 个不相干市场，少数盈利被大量小亏抵消。
- **加保证金死头寸**（ce42）：亏损头寸加钱摊平只扩大损失。
- **顶峰扩注**（ce44）：盈利后膨胀加注，回撤杀伤最大。

### 作者的盲点 / 时代局限
- 1986 年无组合期权/波动率曲面等现代风控；但"限额+止损+3:1+保守生存"的骨架仍普适。

### 容易混淆的邻近方法论
- 资金管理（仓位/风险）vs 交易策略（择时/入场）：先有策略信号，再用本 skill 定"下多少注"（见 trading-tactics-checklist B）。
