# 台灣／淘寶手機配件市場 Skill

## 目的

將台灣購物網與淘寶的手機配件資訊整理成可驗證、可比較、可執行的新品與商業決策資料。優先研究台灣市場，淘寶作為新品雷達、供應鏈與價格基準。只處理手機配件，不處理手機、平板、筆電、智慧手錶或其他主機本體。

## 執行流程

1. **界定範圍。** 確認市場（台灣優先、淘寶其次）、更新週期、手機型號與品類。預設優先追蹤極輕薄手機殼、MagSafe／Qi2 磁吸配件；若使用者指定其他配件，保留同樣的排除規則。
2. **建立搜尋詞組。** 以「品類詞＋材料詞＋功能詞＋機型詞＋新品／源頭詞」組合搜尋。台灣使用繁體中文，淘寶使用簡體中文；不要只搜尋「手機配件」。
3. **蒐集多平台樣本。** 台灣優先檢查品牌官方頁、momo、PChome、Yahoo 購物、蝦皮與其他主要通路；淘寶檢查商品搜尋、海外頁、天貓或可辨識的店鋪。每個品類至少取得多個平台樣本，避免用單一店鋪代表市場。
4. **記錄證據。** 為每項商品保存商品名稱、平台、網址、抓取日期、原價、促銷價、幣別、平台換算值、主要材質、實測或標示厚度／重量、磁吸／充電規格、手機型號、店鋪或品牌、是否新品、供應商資訊與資料可信度。
5. **排除與覆核。** 排除手機、平板、筆電、手錶本體；排除只提供圖片、沒有型號或規格、重複鋪貨或無法確認是配件的結果。對「超薄、真芳綸、強磁、軍規、Qi2」等宣稱標記為待驗證，不把標題當成測試證據。
6. **比較價格。** 將價格分為台灣標價、台灣促銷成交價、淘寶人民幣頁面價格與估計台灣到手成本。到手成本至少考慮商品、跨境運費、集運、稅費、平台／金流費與退貨摩擦；若缺資料，明確標示未計入，不自行補造數字。
7. **分析材料與結構。** 對手機殼分辨 PC、TPU、PC＋TPU、矽膠、芳綸／Kevlar、碳纖維與表面紋理；對 MagSafe 配件分辨磁環、線圈／屏蔽、PC／ABS、鋁合金、TPU／矽膠、皮革／織物與電池模組。分開討論薄度、吸震、耐刮、抗黃、磁吸、無線充電、散熱與耐用度。
8. **產生商業結論。** 說明台灣的現貨、售後、規格信任與品牌溢價，以及淘寶的供應鏈效率、款式長尾、快速開模與價格梯度。不要把淘寶低價直接等同於同規格低成本。
9. **如需創業規劃。** 先建立成本假設，再規劃庫存、補貨門檻、零售價、批發價、團購價與貢獻毛利。將假設和實際報價分開，對未確認的物流、平台費率、退貨率與稅務列為待補資料。
10. **如需行銷。** 以問題認知、產品證明、信任建立與轉換收口設計 30 天內容。文案可主張可驗證的厚度、重量、材質與相容性，不宣稱「絕對不摔壞」「永久不黃」或未測試的安全／認證結果。
11. **如需供應商搜尋。** 優先找「源頭工廠、厂家、OEM、ODM、定制、小批量、工厂直销」組合，但把這些詞視為搜尋詞，不視為工廠證明。要求樣品、材料與結構資料、實測數據、MOQ、交期、瑕疵率、售後、平台保障與合規文件。
12. **週期更新。** 每週更新只報告新增、價格顯著變化、規格改版、供應商狀態變動與代表性競品；合併重複商品，保留首次發現日與最近檢查日期。每月可加上價格帶、材料分布、熱銷機型與 SKU 淘汰建議。

## 必備輸出欄位

| 欄位 | 要求 |
|---|---|
| 品類／子類 | 例如極輕薄手機殼、磁吸卡包、Qi2 行動電源 |
| 平台／品牌／店鋪 | 區分台灣與淘寶；能確認時記錄官方或工廠身份 |
| 商品與型號 | 保留完整名稱與適用手機型號 |
| 價格 | 原價、促銷價、幣別、抓取日期；不可混用標價與到手價 |
| 材質／結構 | 只記錄頁面明示或樣品驗證內容 |
| 規格 | 厚度、重量、容量、功率、磁吸／充電協議等 |
| 競爭觀察 | 台灣服務優勢、淘寶供應鏈優勢、同質商品差異 |
| 風險與覆核 | 未驗證宣稱、跨境成本、電池與售後風險 |
| 網址與來源 | 提供可直接開啟的來源網址 |

## 品質原則

使用者若要「目前」「新品」「價格」等時間敏感資訊，必須以當日或指定日期的頁面為準並記錄日期。搜尋結果摘要只能用來發現來源，不足以支持重要價格或規格結論；應開啟來源頁核對。資料不完整時，標記「待驗證」而非補猜。對充電器、無線充電器與行動電源，必須另外記錄額定容量、輸入／輸出、發熱、電池與安全文件，不因商品標題寫 Qi2 或 MagSafe 就視為已認證。

## 預設報告結構

先給執行摘要，再給新品與價格表，接著比較材料／規格、台灣與淘寶競爭優勢、供應商或選品建議、風險與下一步，最後附上來源與搜尋日期。若使用者要求週期任務，確認時區與執行時間，並避免建立重複任務。
