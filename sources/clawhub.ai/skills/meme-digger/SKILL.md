# Meme Digger — 网络梗考古与科普（刨根问底版）

梗的答案不在任何单一平台：起源往往在贴吧/论坛，走红靠 B 站/微博，二次创作散落各平台，**真正的线索常常藏在评论区里**（高赞评论是用户集体认知，评论里的名字/作品/梗图是发散搜索的起点）。本 skill 采用"**分文件收集 → 发散深挖 → 最终整合**"的刨根问底工作法，绝不编造出处，区分事实与网络传闻。

**脚本位置**：所有 `scripts/...` 路径相对本 skill 目录（即 SKILL.md 所在目录）。调用前先解析 skill 目录（Claude Code 可用 `${CLAUDE_SKILL_DIR}`；pi 等其它 agent 定位到 SKILL.md 所在目录即可），再以 `python <skill_dir>/scripts/xxx.py` 执行，不要在其它工作目录直接写相对路径。

## 工作区结构（每个梗一个目录）

在**当前工作目录**下创建 `meme-research/<梗名-slug>/`，所有调查产物分文件存放：

```
meme-research/<梗名>/
├── 00-计划.md               # 立项：关键词变体、假设、待查问题清单
├── 01-b站搜索.md             # B站搜索结果 + 候选视频详情
├── 02-b站评论区.md           # 评论区挖掘（高赞评论/线索/评论图片URL）
├── 03-贴吧.md                # 贴吧帖子与吧内讨论
├── 04-发散线索.md            # 从评论/视频中提取的线索 → 发散搜索的记录
├── 05-梗图.md                # 梗图图鉴：本地图/出处/含义/使用场景
├── images/                   # 下载到本地的梗图文件 + manifest.txt
├── 06-来源考证.md            # 每条关键论断的证据链与可信度评级
├── 报告-<梗名>.md            # 最终整合：文字说明 + 梗图 + 来源介绍
└── <梗名>-百科.html          # 第9步生成的单文件 Meme 百科页（最终交付物）
```

## 工作流程

### 第 1 步：立项（先想清楚再动手）

创建 `00-计划.md`，写清：
- **关键词变体**：原名 / 拼音缩写 / 英文名 / 表情包关键词 / 话题标签 / 近义梗（例："典" → `典`、`典中典`、`太典了`）。
- **待查问题清单**：它是什么？什么时候出现的？谁发明的？怎么火的？现在怎么用？衍生了什么？
- **假设**：先写下自己的初判（多义词时列多个义项），之后逐条验证或推翻。

### 第 2 步：B 站搜索（主通道）

```bash
python "scripts/bili_search.py" "<关键词>" --limit 10
```

- 对候选视频逐一取详情（发布时间 = 时间线证据）：

```bash
python "scripts/bili_video.py" "<bvid>"
```

- 把结果整理进 `01-b站搜索.md`。标记出"考古/科普/盘点"向视频（标题含科普/考古/溯源/梗百科/盘点）。

### 第 3 步：评论区深挖（本版核心，免登录）

对 **2-5 个关键视频** 挖掘评论区：

```bash
python "scripts/bili_comments.py" "<bvid>" --pages 3 --top 50 --min-like 20 --out "meme-research/<梗名>/02-b站评论区.md"
```

- 同时生成 `02-b站评论区.images.txt`（评论里的梗图 URL 清单）。
- **读评论看什么**：
  1. 高赞评论 = 大众对该梗的集体认知/用法示例。
  2. 评论里出现的**专有名词** = 发散线索（人名、up主、作品名、平台、事件、其他梗名）。
  3. 评论区吵什么 = 该梗的争议点。
- 把线索（含来源评论）登记到 `04-发散线索.md`。

### 第 4 步：贴吧采集（需 cookie，见下）

```bash
python "scripts/tieba_search.py" "<关键词>"
```

- **cookie 配置（B站 + 贴吧统一管理）**：复制 `config/cookies.json.example` 为 `config/cookies.json` 并填写，**推荐用配置向导**（自动验证 cookie 是否有效）：

```bash
python "scripts/config_cookies.py"                    # 交互式：粘贴 B站/贴吧 Cookie，自动验证后写入
python "scripts/config_cookies.py" --status           # 查看当前配置与有效性
python "scripts/config_cookies.py" --bili-cookie "..." --tieba-cookie "..."   # 命令行方式
```

- 获取方式：登录对应站点 → F12 → Network → 刷新 → 复制请求头的 Cookie 整段。
- B站 cookie 用于提升稳定性（评论/搜索默认免登录即可，有 cookie 更稳）；贴吧 cookie **必需**（否则 403 安全验证）。
- 贴吧价值：**起源考据**（最早帖子）、讨论语境、吧内黑话。
- 无 cookie 时降级：web_search `site:tieba.baidu.com <关键词>`（工具可用时）→ web_fetch 吧页 → 或明确告知用户"贴吧侧缺失"。

### 第 5 步：发散式搜索（刨根问底的引擎）

把 `04-发散线索.md` 里登记的**每一条线索**作为新关键词，回到第 2-4 步循环搜索（通常 2-3 轮）：

- 人名/up主 → 搜其代表作、最早作品
- 作品名 → 搜其起源、主创
- 平台/事件 → 搜时间节点
- 其他梗名 → 搜其与主梗的关系

每轮把新发现追加进 `04-发散线索.md`（标注：线索 → 搜了什么 → 找到了什么 → 新线索）。**收敛条件**：连续一轮没有产生新线索，或待查问题清单全部有答案。

### 第 6 步：梗图收集（一次性完整图鉴，v1.1）

**一次运行收集所有图源**，自动完成相关性分档、去重、生成候选清单：

```bash
python "scripts/collect_gallery.py" "<梗名>" \
  --variants "<变体1,变体2,...>" \
  --out "meme-research/<梗名>" --limit 60
```

- **图源与分档**（T1 直接联系最强 → T6 尽力而为）：

| 级 | 源 | 直接联系保证 |
|---|---|---|
| T1 | B站代表视频封面 | 视频标题含梗 |
| T2 | B站高赞评论配图 | 评论含梗词/反应词 |
| T3 | B站二创/表情包/合集/整活视频封面 | 查询=梗名+二创词（**二创检索通道**） |
| T4 | 百度图片（表情包/梗图/二创 查询） | 查询词相关，内容需人工复核 |
| T5 | 贴吧帖子首楼图（需 cookie） | 帖子标题含梗；风控验证页自动降级 |
| T6 | 斗图啦 | 尽力而为，失败静默 |

- **二创梗图**：T3/T4 显式按 "二创/整活/表情包/梗图/合集/抽象" 检索，覆盖二创梗图通道。
- **自动去重**：URL 归一化 + 下载后 sha256 内容去重。
- **产出**：`images/`（编号图片 + manifest.json）+ `05-梗图.md` 候选清单（出处/评分/上下文），人工复核后定稿。
- **预览**：先 `--no-download` 看候选，再正式下载；单源不可用时自动降级不中断。
- 旧版定向挖掘（bili_memes）仍可单独使用：`python "scripts/bili_memes.py" "<bvid>" --pages 2 --min-like 20 --download N --out ...`

**人工复核（强制，不变）**：每张梗图定稿前确认：① 图片内容与梗主题相关（看上下文/原图佐证）；② 记录出处；③ 标注含义与使用场景。**拿不准的图一律不收**，宁可少收。

### 第 7 步：来源考证

在 `06-来源考证.md` 里为**每条关键论断**建立证据链：

| 论断 | 证据(链接/引用) | 可信度 |
|---|---|---|
| 起源 | ... | 确凿/网友考证/待考证 |

- 至少 **2 个独立信源**一致才写"确认"。
- 严格区分：确凿证据（原始链接/时间戳）vs 网友考证 vs 流传说法。
- 找不到出处 → 明确写"待考证"，不编造。

### 第 8 步：最终整合

读取所有分文件，整合成 `报告-<梗名>.md`（模板见下）。要点：
- **先给结论**：一句话概括放最前。
- **证据链**：每条论断后标注来源（BV 链接/帖子链接/平台）。
- **时间线精确到月**，给时间点不给"大概"。
- **梗图入报告**：正文相关处引用本地梗图（`![图](images/xxx.jpg)`），并标注含义。
- **来源介绍**：除链接外，一句话说明每个来源是什么（哪个 up 主、什么立场、辟谣还是玩梗）。
- 末尾附"仍不确定"清单。

### 第 9 步：生成 Meme 百科 HTML（最终交付）

```bash
python "scripts/make_report.py" "meme-research/<梗名>" --out "meme-research/<梗名>/<梗名>-百科.html" [--title 自定义标题]
```

- **单文件自包含**：内联 CSS + 图片 base64 内嵌，字体走 CDN（Poppins/Inter）+ 系统回退，可离线阅读核心内容。
- **百科页固定模板**（`templates/encyclopedia.css` 控制样式，遵循用户级 `house-style` 技能：极简纸质·米白+橙·章节红分割线·低多边形/粒子 hero·reduced-motion）→ 各章节（起源/时间线/含义/例句/梗图图鉴/衍生/数据/信源/注意事项）→ 页脚。
- 梗图图鉴自动渲染为网格画廊，时间线自动渲染为列表，信源渲染为可点击链接。
- 每次调查只生成 **一个 HTML 文件**，即最终交付物。

## 输出模板（报告-<梗名>.md）

```markdown
# 「<梗名>」是什么梗？

## 一句话概括
<谁、什么时候、因为什么、怎么火的，30 字内>

## 起源与出处
- <最早的出处/原型，标注信源>
- <多条说法并存时：说法A（来源1）、说法B（来源2），注明主流观点>

## 走红时间线
- YYYY-MM：<事件>（信源）

## 含义与用法
- 原义 / 引申义 / 当下主流用法；使用场景与语气

## 经典例句 / 句式
> "例句"

## 梗图图鉴
![梗图1](images/xxx.jpg)
<这张图是什么、梗在哪、常用场景>
![梗图2](images/yyy.jpg)
...

## 衍生与相关梗
- <衍生梗>：<一句话>（信源）

## 数据佐证
- B站代表视频：<标题>（<bvid>）播放<X>，发布于<日期>
- 贴吧/评论热度：<若有>

## 信源列表（含来源介绍）
1. <平台> <作者>：<标题>（<一句话说明该来源的性质>）<链接>

## 注意事项
- 争议/敏感：<若有>
- 待考证：<明确列出未能证实的内容>
```

## 质量标准（写完自查）

- [ ] 每个关键论断带信源，链接可点开
- [ ] 事实与传闻分开标注
- [ ] 有时间线（尽量精确到月）
- [ ] 有例句，读者能立刻学会用
- [ ] 梗图有出处与含义说明
- [ ] 信源列表包含"来源介绍"（作者/立场）
- [ ] "待考证"项明确列出，没有编造

## 边界与安全

- 不传播谣言与恶意抹黑；涉及争议内容只陈述"网络说法"并标注风险。
- 涉及低俗/违规梗：正常科普可以，不教唆、不美化、不过度展开。
- 引用遵守"简短引用 + 链接"，不整段复制他人文案。
- **梗图版权**：只下载保存用于分析，报告中保留原图 URL 与出处；不声称拥有版权。
- 用户问的梗若带明显攻击/引战意图，先温和澄清意图再科普。

## 故障排查

| 现象 | 处理 |
|---|---|
| bili_search 解析 0 条 | 风控/改版 → web_fetch 打开搜索页；加 --page 2；稍后重试 |
| bili_comments code≠0 或无评论 | 视频被删/限流 → 换 bvid；评论关闭 → 跳过该视频 |
| 贴吧 403 安全验证 | 配置 config/cookies.json（第 4 步）或走降级路径 |
| web_search/web_fetch 不可用 | 提示 Ollama web search 未启动；B站三件套脚本不依赖它 |
| 梗太新搜不到 | 告知"尚未形成稳定记录"，给已确认部分 + 观察建议 |
| 下载的图打不开 | 部分图片 URL 需 Referer（脚本已带）；重试或换源 |

## 脚本与配置

- `scripts/bili_search.py <关键词> [--page N] [--limit N]` — B站搜索（免登录）
- `scripts/bili_video.py <bvid> [--cover]` — 视频详情（免登录；--cover 输出封面 URL）
- `scripts/bili_comments.py <bvid> [--pages N] [--top N] [--min-like N] [--out 文件] [--root <rpid>]` — 评论区深挖（免登录，附带图片URL清单）
- `scripts/collect_gallery.py <梗名> [--variants a,b,c] [--out 目录] [--limit N] [--no-download]` — **一次性完整图鉴收集**（T1-T6 多源 + 二创检索 + 去重 + 自动 05-梗图.md）
- `scripts/bili_memes.py <bvid...> [--pages N] [--min-like N] [--download N] [--out 目录]` — 单视频定向梗图挖掘（旧版）
- `scripts/bili_dl.py <url...>|--from <清单文件> --out <目录>` — 图片下载（去重）
- `scripts/tieba_search.py <关键词>` — 贴吧搜索（需 cookie）
- `scripts/config_cookies.py` — **B站+贴吧 cookie 配置向导**（验证后写入 config/cookies.json）
- `scripts/make_report.py <工作目录> --out <输出.html> [--title 自定义标题]` — 生成单文件 Meme 百科 HTML
- `scripts/common.py` — 共享模块（UA / cookie 加载 / 重试抓取），所有脚本依赖
- `config/cookies.json` — 统一 cookie 配置（bilibili + tieba 两个条目），由 config_cookies.py 写入
- `templates/encyclopedia.css` — 百科页固定模板样式（make_report.py 自动引用）
- 全部仅用 Python 标准库，无需安装依赖。
