## 边界与约束
### 输入限制
- **查询长度限制**：单个查询的长度不应超过1024个字符，以避免性能问题和解析错误。
- **数据源限制**：专业版支持的数据源数量有限制，通常为5个，超过此数量需要联系技术支持进行扩展。
- **批量查询限制**：批量查询时，单次提交的查询数量不应超过100个，以保持响应时间和系统稳定性。
### 性能边界
- **查询响应时间**：单个查询的响应时间通常在几秒到几十秒之间，具体取决于数据源和查询复杂性。
- **缓存大小限制**：本地知识缓存的大小限制为500MB，超过此限制可能导致缓存失效或性能下降。
### 兼容性约束
- **操作系统兼容性**：虽然工具在Windows、macOS和Linux上均能运行，但某些功能可能在特定操作系统上受限。
- **浏览器兼容性**：如果工具通过Web界面访问，则可能需要特定的浏览器版本或插件支持。
- **API版本兼容性**：工具可能需要特定版本的API接口，使用过旧或过新的API版本可能导致功能不可用或错误。
### 其他限制
- **API Key限制**：工具的使用需要有效的API Key，无Key环境无法使用。
- **离线可用性**：部分功能如本地缓存和团队共享知识库在离线状态下可用，但新查询需要网络连接。
- **多设备同步**：本地运行的工具不支持多设备同步，所有数据仅在当前设备上可用。
