# 电商运营助手

## 能力概览

本技能覆盖电商运营五大核心模块：

| 模块 | 能力 |
|------|------|
| 选品分析 | 市场趋势洞察、品类分析、竞品选品策略、热销品特征提炼 |
| 商品优化 | 标题撰写（核心词+属性词+场景词）、主图文案、详情页结构、SKU命名 |
| 流量运营 | 搜索排名因子分析、直通车/千川/巨量引擎策略、自然流量优化 |
| 活动策划 | 平台大促（618/双11/双12）策划、店铺自播活动、优惠券/满减策略 |
| 数据客服 | 差评回复模板、客户投诉处理、客服话术库、退货退款分析 |

## 使用方式

### 1. 选品分析

用户提供品类关键词后：

1. 通过 WebSearch 获取平台热搜词、趋势品类数据
2. 分析品类竞争格局（头部品牌集中度、价格带分布）
3. 提炼成功商品的核心要素（标题公式、定价策略、视觉风格）
4. 输出《选品分析报告》：市场容量/竞争强度/利润空间/切入建议

### 2. 商品标题与详情优化

1. 分析用户提供的商品信息，提取核心卖点
2. 生成多版本标题（综合排序版/销量转化版/搜索流量版）
3. 设计详情页内容结构：痛点→解决方案→产品优势→信任背书→行动召唤
4. 输出优化对比和预期效果

### 3. 竞品分析

1. 用户提供竞品链接或关键词
2. 分析竞品的定价策略、标题结构、评价反馈、促销节奏
3. 输出《竞品拆解报告》：优势/劣势/机会点/行动建议

### 4. 活动策划

1. 根据平台和节日节点，输出活动方案框架
2. 设计优惠策略（满减梯度、优惠券组合、限时秒杀）
3. 预估 ROI 和库存备货建议
4. 输出完整活动执行 SOP

### 5. 客服与评价管理

1. 生成差评回复模板（区分物流/质量/描述不符等类型）
2. 编写客服标准话术（售前咨询/售后处理/催付/回访）
3. 分析评价数据，提炼产品改进方向

## 平台差异注意事项

- **淘宝/天猫**：重视搜索权重、直通车、万相台
- **拼多多**：重视价格力、活动资源位、多多搜索
- **抖音电商**：重视内容质量、直播间转化、达人合作
- **京东**：重视自营权重、精准通、星级评分

## 输出约定

- 所有分析报告输出为结构化Markdown，含数据来源和置信度标注
- 标题/文案输出提供2-3个版本供选择
- 涉及费用估算时标注"预估仅供参考"

## 自进化学习系统（越用越好用、越用越高效）

本技能内置通用学习模块 `scripts/learner.py`。每次使用后自动复盘、积累经验，逐步提升输出质量与执行效率，无需人工维护。

### 记忆文件
`learned_patterns.json`（位于本技能目录）记录：操作总数、各能力使用频次、错误模式、用户偏好、改进建议。

### 使用后请调用（Bash）

```bash
# 记录一次成功使用（--capability 填本次主要能力名，如「简历优化」「比价」）
python scripts/learner.py record <本技能目录> --capability 简历优化
# 记录一次失败/异常
python scripts/learner.py record <本技能目录> --capability 简历优化 --fail --error 格式识别失败 --note "用户上传了非标准文件"
# 记录用户偏好（下次直接使用）
python scripts/learner.py prefer <本技能目录> --key 输出语言 --val 中文
# 查看累计洞察（高频能力 / 反复错误）
python scripts/learner.py insight <本技能目录>
# 自动复盘（错误≥3次 或 操作≥10次 时给出改进建议）
python scripts/learner.py reflect <本技能目录>
```

### 迭代规则
- **错误累计 ≥3 次** → 主动增加预检/兜底步骤，并将经验回写本 SKILL.md。
- **操作数 ≥10 次** → 分析高频能力优先打磨示例与质量，低频能力评估精简或合并。
- **重要用户偏好** → 写入 `learned_patterns.json`，下次调用直接采用，减少重复询问。

> 越用越懂你：第一次用是通用能力，第十次用已沉淀为你专属的最佳实践。
