# TARGET_CUSTOMER_PROFILE() 目标客户画像

Display Name：`TARGET_CUSTOMER_PROFILE()`  
Chinese Name：目标客户画像  
Project：WorkFn  
Version：v1.0.0

## 参数与最低运行条件

必需：产品/服务、目标市场、我方能力、客户开发目标。建议：市场机会结论、历史订单/询价、成交客户特征、价格带、交付、付款、认证和售后限制。

市场、产品与我方能力明确后才生成正式画像；缺少历史证据时允许输出低置信度假设，但必须标为待验证。

## 流程

1. 从强证据中提取已成交或高质量询价客户的共同特征。
2. 将候选客户区分为分销型、项目型、技术方案型、维修翻新型和终端采购型。
3. 对每类说明购买场景、价值来源、官网/产品线/规模信号及不匹配原因。
4. 给出优先、次优和排除类型，不用“经销商”“集成商”等单一宽泛标签结束判断。
5. 输出可直接交给搜索策略和公司筛选的明确条件。

## 输出

输出优先客户类型、次优类型、典型采购场景、共同特征、官网关键词、品牌/产品线特征、规模与能力特征、高匹配信号、低匹配信号、排除条件和待确认问题。

## 边界与协作

本 Skill 建立“应寻找什么样的客户”，不整理单个既有客户的历史事实；后者使用 `zayn-customer-profile`。上游接 `zayn-market-opportunity`；下游接 `zayn-search-strategy` 和 `zayn-company-screening`。
