# 跨境选品

选品是跨境电商的第一性原点。选错之后运营、投流、供应链全是在给一个错误决策补课，
所以这一步值得慢一点。

## 工作流

```
- [ ] 1. 判品类驱动本质      → selection_category_nature
- [ ] 2. 看这个国家有没有需求 → market_research_report
- [ ] 3. 算这个价能不能赚     → profit_estimate
- [ ] 4. 找"为什么没买"的证据 → 评论库（手工，见下）
- [ ] 5. 分层：首发 / 测款 / 暂缓
```

### 第 1 步：判驱动本质（最容易被跳过，也最贵）

```
selection_category_nature({ text: "女式通勤单肩包" })
```

驱动本质判错，后面的素材方向和投放渠道会一起错：

| 本质 | 用户行为 | 主战场 | 素材要解决的事 |
|---|---|---|---|
| 需求驱动（3C、工具、配件） | 主动搜索、理性比参数 | 搜索广告 + AI 问答优化 | 参数、兼容性、时效 |
| 身份情绪驱动（女包、饰品、美妆、服饰） | 被动种草，买"使用它的那个我" | 视频素材量产 | 代入感、场景、社交可见性 |

常见错配：需求驱动品砸视频素材事倍功半，情绪驱动品堆参数文章隔靴搔痒。

**身份情绪品类不能靠主观审美选品。** 要能回答"什么货、让哪类人、在什么场景下、
觉得这就是我想成为的样子、并且钱包投票"。审美分说服不了任何人，也回测不了。

### 第 2 步：这个国家有没有需求

```
market_research_options({})                                  // 先看有哪些组合
market_research_report({ category: "handbag", country: "US" })
```

组合不在表里会直接返回 400。**那是"我们这个组合还没数据"，不是"这个市场没需求"**——
把前者当后者往下推，是这一步唯一会犯的严重错误。

### 第 3 步：算这个价能不能赚

```
profit_estimate({
  costCny: 45, priceLocal: 29.9, weightG: 380,
  baseCountry: "US", countries: ["US", "PH", "VN"],
  affiliateRate: 0.1
})
```

返回跨境直发与海外仓两种模式的毛利对比、推荐模式和一个决策档（健康 / 可测 / 不建议），
以及费用总额。费率与物流分档的逐项拆解要登录版（返回里标 `detailWithheld`）。

`baseCountry` 是定价基准，**它不会出现在对比行里**——传 `countries: ["US","PH"]`
而基准是 US 时，只会得到 PH 一行。要看 US 就把基准换成别的国家。

成本和售价必须给真实数，否则算出来的是模板数字不是你的生意。

### 第 4 步：证据层在链路中间，不在结果层

购买决策是五步漏斗，而大多数人只采得到最后一步的数据：

| 阶段 | 她脑子里在想 | 可采集信号 |
|---|---|---|
| 触发 | 场景缺口或情绪被戳 | 曝光、点击率 |
| 代入想象 | "用它的我是什么样" | 停留、收藏 |
| 筛选比较 | 颜值→搭配→值不值 | 加购、加购未购、比价跳出 |
| 临门一脚 | 会不会亏、能不能退 | 下单转化 |
| 购后分享 | 值不值得晒 | 晒单、复购 |

**"为什么没买"比"买了什么"值钱。** 拉目标市场竞品的差评与追评，
按购买顾虑分类——这份数据同时能喂三处：选品验证、广告前三秒钩子、内容问答素材。
建库时按三个用途一起打标签，别只为选品建一次。

### 第 5 步：分层，不要一次性全押

首发 / 小额测款 / 暂缓三层。测款要预先写死纪律：跑多少天、看哪个指标、
到什么线才放大——不预先写，事后一定会为亏损的品找理由续命。

## 到这一步要上官网

免费段能判本质、看需求、算利润，但有两件事它做不了：

**社会情绪因子跑批。** 目标市场的情绪因子表（每条带证实/证伪状态与对应电商杠杆），
以及候选品 × 因子矩阵。工具是 `selection_factor_run`，`read` 档。

**批量分层。** 一次几百个 SKU 评成首发/测款/暂缓，带测款纪律与首发闸门。
工具是 `selection_evaluate`，`read` 档。

两者都在 ¥199 起的订阅里：<https://www.lingxiaochuhai.com/service-pricing>
不想接 MCP 的话，网页版"选品参谋" <https://www.lingxiaochuhai.com/tools/product-scout> 是同一套引擎。

## 边界

- 情绪因子有一条纪律要带着走：**未触发证伪条件 ≠ 已被证实**。
  假设未证实、也未证伪，是最常见的状态，不要在汇报里升级成结论。
- 利润测算不含退款率与售后摊销时，算出来的毛利是虚的。
- 品类本质判定是纯规则的，给的是"这段描述像哪一类"。
  一个品同时踩两边（比如功能性美妆）时，按投放主战场那一边定，不要两边都做。
