# 电商生图

生图便宜到一张几毛之后，瓶颈就不在"能不能出图"，而在**出的是不是能上架的图**。
主图、场景图、模特图、白底图要解决的是四件不同的事，用同一条提示词批量出，
结果是四张都不能用。

领霄的其他 skill 粘个 URL 就能匿名试用，**生图不行**：它扣的是"你自己的"生图余额、
出的图落在你名下，没有身份就只能记到共用账号上——所以匿名调用会被直接拒，
不会静默记到别人头上。这是刻意的，不是限制你。

先在 <https://www.lingxiaochuhai.com/app/membership?from=mcp-trial> 领 key，再粘配置：

```json
{ "mcpServers": { "lingxiao": {
  "url": "https://www.lingxiaochuhai.com/mcp",
  "headers": { "x-api-key": "<你的 key>" } } } }
```

**这个 skill 会真花钱**：出图按张扣你自己的生图余额，画质档约 ¥1/张、快档约 ¥0.25/张。
其余工具不花钱。

## 出图前先看一眼余额

```
image_models({})
```

返回可用模型、每张单价、**你自己的**余额，以及按余额每个模型还能出几张。
单价差 4 倍，而余额不够时生图会直接失败——先看一眼比撞一次 402 划算。

## 出图

```
image_generate({
  prompt: "...",
  modelId: "<从 image_models 里选>",
  portrait: true,
  refId: "BAG-001",
  confirm: true
})
```

**必须带 `confirm: true` 才真执行**，不带只返回报价和余额。
一次只出一张，要多张就调多次——每张单独过一次余额校验，
不会出现"批量出 10 张、扣到第 7 张余额空了"的半成品状态。

`refId` 填 SKU，会写进生图流水，事后对得上账。

两个行为要先知道，免得当成 bug：

- 指定模型出图失败时会**自动降级**到下一个通道，返回里 `billing.downgraded` 会标出来。
  按画质档下单却拿到快档的图，就是这个原因，扣费也按实际那档，不会多收。
  要保证一批图画质一致，传 `strictModel: true`，宁可失败也不降级。
- **参考图只有火山通道吃**，其他通道会如实把 `referenceApplied` 标成 false，
  不假装锁上了人物。

## 四类图，四种提示词结构

| 用途 | 要解决的事 | 提示词重点 | 常见废图原因 |
|---|---|---|---|
| 白底图 | 过平台审核 | 纯白背景、无阴影投射、产品占画面 85% | 生成了带渐变的"接近白" |
| 主图 | 三秒内被点 | 单一主体、强对比、留出角标位 | 元素太多，缩略图上糊成一团 |
| 场景图 | 让人代入 | 使用中的动作 + 环境线索 + 光源方向 | 只有产品摆在桌上，没有人和场景 |
| 模特图 | 建立尺寸感与身份感 | 人物特征 + 姿态 + 与产品的相对尺寸 | 手指与产品比例失真 |

提示词按这个顺序写，效果比堆形容词稳：

```
主体是什么 → 材质与颜色 → 摄影角度与景别 → 光线 → 背景 → 画幅
```

英文提示词效果更好。**光线单独写一句**，这是 AI 图看起来假的头号原因：
真实商品摄影有明确的主光方向和柔和的补光，不写就会得到一张四面平光的塑料感图。

## 什么时候不该用 AI 生图

**上架主图涉及真实材质细节时用实拍。** 布料纹理、金属拉丝、屏幕显示内容，
AI 生成的会在评论区变成"和图片不符"，那笔退货成本远高于省下的拍摄费。

AI 生图的成本优势在**量**：需要几十上百张场景变体做投流素材时，
它比实拍便宜一到两个量级。单款几张精修图，实拍反而更省事。

## 边界

- 出图失败不扣费；降级出图按实际那档扣。返回里的 `billing` 是准的，以它对账。
