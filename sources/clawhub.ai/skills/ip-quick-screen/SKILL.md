# IP快速筛查（尽调初筛）

面向技术尽调场景的轻量级IP快速筛查工具。**不做深度P2I评估**，做**快速筛查→风险预警**。

## 核心能力

1. **专利组合概览**：输入企业名称/专利号列表，输出专利数量、技术领域分布、法律状态概览
2. **专利质量初筛**：基于公开指标（引用次数、专利族大小、剩余保护期、同族国家数等）做快速评分
3. **技术领域识别**：自动识别专利所属技术领域（IPC分类），输出技术布局热力图
4. **风险预警**：识别失效/即将失效/被引异常/诉讼关联等风险信号

## 数据源

使用免费公开数据源，无需认证：
- **USPTO PatentsView API**（美国专利结构化数据，免费开放）
- **Google Patents 公开搜索**
- **Lens.org 公开API**（非商业使用免费）

## 工作流程

### 第1步：解析输入
- 如果用户输入的是**企业名称**，搜索该企业名下的专利
- 如果用户输入的是**专利号列表**，直接查询这些专利的详情
- 如果用户输入的是**URL链接**，提取链接中的专利信息

### 第2步：查询专利数据
- 使用 USPTO PatentsView API 查询专利信息
- 使用 Google Patents 补充查询
- 收集以下字段：专利号、标题、摘要、IPC分类、引用次数、法律状态、申请日、公开日、专利权人

### 第3步：分析处理
1. **专利组合概览**：
   - 统计专利总数
   - 按技术领域（IPC大类）分组统计
   - 按法律状态分组统计（有效/失效/审查中）
   
2. **专利质量初筛**（基于公开指标，不输出具体估值数字）：
   - 引用次数分析：被引次数排名
   - 专利族大小：同族专利数量
   - 剩余保护期：从申请日起20年，计算剩余年限
   - 同族国家数：覆盖的国家数量
   - 综合标记：高/中/一般 三个等级的参考标记

3. **技术领域识别**：
   - 按IPC分类统计技术领域分布
   - 识别主要技术方向
   - 生成技术分布概览

4. **风险预警**：
   - 已失效专利
   - 即将到期专利（剩余保护期<3年）
   - 被引异常（过高或过低）
   - 法律状态异常
   - 诉讼关联标记（如涉及PTAB、诉讼等）

### 第4步：输出报告
输出格式化的IP概览报告，包含：
- 企业IP概览报告（专利数、技术领域、法律状态分布）
- 专利质量初筛参考（基于引用/族大小/保护期等公开指标，不输出具体估值数字）
- 技术领域分布概览
- 风险预警清单

## 边界情况处理

- **企业名称未找到专利**：返回"未查询到该企业相关专利，请确认企业名称是否正确"
- **专利号格式错误**：提示支持的专利号格式（US+数字、CN+数字等）
- **API请求失败**：尝试备用数据源，如果全部失败则返回错误提示
- **数据量过大**：如果专利数量超过100件，展示前100件的概览并提示"更多专利可通过具体专利号查询"
- **无风险信号**：明确告知"未发现明显风险信号"

## 重要限制说明

- **不做**：专利价值量化评估、技术特征光谱分析、P2I评分
- **不做**：输出具体估值数字或评分数字
- **定位**：快速筛查工具，用于决定是否需要找专业机构做深度评估
- 数据可能存在延迟，仅供参考，不构成法律意见

## 变更记录

### v1.0.1（2026-07-13）
- **修复**：修复了"被引异常偏高"检测中的运算符优先级错误。原代码 `qs.get("citedby_count", 0) or 0 >= 100` 因缺少括号导致任何非零被引数都被判定为异常，修正为 `(qs.get("citedby_count", 0) or 0) >= 100`。
- **增强**：改进了同族专利统计功能。`_get_patent_family_info` 函数现在不仅返回 `family_id`，还通过二次查询统计每个专利族的实际成员数量，使 `family_size` 字段能反映真实的同族专利规模。此修复使专利质量评分中的"高"等级判定更加准确（之前 `family_size` 固定为1，条件从未满足）。
