# 供应商档案整理技能

## 任务目标
- 本技能用于：帮助供应商管理人员将杂乱的供应商资料（Word/PDF/Excel）整理为结构化的质量管理档案
- 核心能力：多格式文件解析、信息提取、结构化汇总、Markdown/SVG 图表生成
- 触发条件：用户提供供应商资料并要求整理建档（如"整理供应商资料""生成供应商档案""供应商信息归档"）

## 输出格式

| 格式 | 说明 |
|------|------|
| **Markdown** | 默认输出，可导出为任意格式 |
| **Word/PDF** | 可选输出，含 SVG 图片版组织架构图 |

> 默认输出 Markdown；用户明确要求 Word 或 PDF 时，按需生成。

## 工作流程

### 步骤一：接收用户资料
1. 确认用户提供的文件格式（Word/PDF/Excel）
2. 记录文件路径

### 步骤二：解析文件内容
- **Word 文件 (.docx/.doc)**：读取文本、标题、表格
- **PDF 文件**：提取文本，识别表格结构
- **Excel 文件 (.xlsx/.xls)**：读取工作表、表格数据

### 步骤三：确认输出模板（交互必做）
**询问用户**：
> "您是否有自定义的供应商档案模板（Markdown 格式）？如果有，请提供。如果没有，我将使用默认模板。"

### 步骤四：提取关键信息
| 信息类别 | 提取内容 |
|----------|----------|
| 基本信息 | 供应商名称、地址、统一社会信用代码、成立时间 |
| 联系方式 | 联系人、电话、邮箱、网址 |
| 产品/服务范围 | 主要产品、年产能、主要客户 |
| 质量认证 | ISO 9001、IATF 16949、ISO 13485 等（含证书编号） |
| 品质组织架构 | 品质负责人、人员配置、分工权限 |
| 质量能力 | CTQ 工序、设备产能、不合格品管理 |
| 三检体系 | IQC/IPQC/FQC 的标准、设备、人员 |
| 质量数据 | 投诉率、不合格率、风险评级 |
| 合作记录 | 首次合作时间、最近审核日期、审核结果 |
| 提升规划 | 品质目标、改善措施、复盘计划 |

### 步骤五：生成 SVG 组织架构图
调用脚本生成 SVG 图表：

```bash
python scripts/generate_org_chart.py \
    --supplier "供应商名称" \
    --org_data '{"品质负责人":{"name":"张总","team":["IQC组长-李工","IPQC组长-王工","FQC组长-赵工"]}}' \
    --output assets/org_chart.svg
```

**SVG 图表说明**：
- 使用 Python 生成矢量 SVG 图
- 嵌入 Markdown 时转换为 base64 图片或直接引用 SVG 文件
- 图表风格：简洁扁平，层级清晰

### 步骤六：生成文档
**Markdown 格式**（默认）：
- 文件命名：`{供应商名称}_供应商质量管理档案.md`
- 组织结构图以 SVG 或 base64 图片形式嵌入
- 保存至当前目录 `./`

**Word/PDF 格式**（可选）：
- 用户明确要求时生成
- 调用脚本转换或使用 python-docx 直接生成
- 组织结构图以图片形式嵌入文档
- 文件命名：`{供应商名称}_供应商质量管理档案.docx`

## 能力边界

### 输入格式支持
| 格式 | 支持程度 | 说明 |
|------|---------|------|
| WORD (.docx) | 完整支持 | 可提取表格和段落 |
| Excel (.xlsx) | 支持 | 需用户指定关键列 |
| PDF（文本型） | 支持 | 可提取文本 |
| PDF（扫描型） | 有限支持 | 需先 OCR 或手动录入 |
| 纯文本/Markdown | 完整支持 | 直接读取 |

### 最低信息要求
生成基本档案至少需要：
- 供应商名称
- 主要产品/服务
- 一种联系方式

### 不支持的功能
- 自动从互联网搜索供应商信息
- 多供应商横向对比分析（需分别生成后手动对比）
- 供应商绩效评分（需用户提供评分维度和标准）

## 异常处理

### 脚本执行失败
- 若 `python-docx` 未安装：提示安装命令或提供纯 Markdown 输出作为替代
- 若 `PIL/Pillow` 未安装：SVG 生成失败时，提供文本版组织架构描述
- 若 Python 环境不可用：提供手动整理指导，仅输出 Markdown 格式

### 输入格式问题
- 若用户提供扫描版 PDF：提示先使用 OCR 处理，或提供关键信息手工录入
- 若信息不完整：生成部分档案并标注"待填写"字段
- 若 Excel 列名不规范：列出识别到的列名让用户确认映射关系

### 输出格式问题
- 若 Word 格式排版不理想：同时提供 Markdown 原文件供手动调整
- 若 SVG 图过大：提供缩放建议或分页处理
