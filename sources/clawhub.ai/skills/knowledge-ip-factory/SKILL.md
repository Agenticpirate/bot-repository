# 知识IP工坊

知识IP全链路打造技能。将「用户调研 → 知识体系梳理 → 定位与差异化 → 竞品分析 → 内容矩阵规划 → 课程大纲设计 → 变现路径规划」整合为一条流水线，帮专业人士把隐性知识转化为可交付的知识产品。

## 参考资源

本技能在 `references/` 目录下提供了完整的模板和案例库，执行各阶段时应主动查阅：

| 阶段 | 参考文件 | 何时使用 |
|------|---------|---------|
| 阶段零 | — | 用户调研以对话引导为主 |
| 阶段一 | `references/知识树图谱模板.md` | 输出知识树时参考格式和示例 |
| 阶段二 | `references/定位一句话模板库.md`、`references/竞品IP分析模板.md`、`references/成功案例集.md` | 定位时参考模板库，竞品分析时使用采集表和四象限 |
| 阶段三 | — | 内容矩阵按平台特性直接规划 |
| 阶段四 | `references/课程大纲模板.md` | 设计课程时使用四层结构模板 |
| 阶段五 | — | 变现路径按五层阶梯直接规划 |

## 触发条件

当用户表达以下意图时触发本技能：
- "帮我打造知识IP""我想做知识付费""怎么把我的经验变现"
- "帮我梳理知识体系""帮我做课程大纲""规划内容矩阵"
- "我的专业是XX，怎么定位""帮我找到差异化方向"
- 涉及知识体系搭建、课程设计、IP定位、内容规划

## 工作流程

### 阶段零：用户调研（前置环节）

在开始知识体系梳理之前，先帮用户明确"为谁打造IP"。定位不能凭空做，需要先了解目标用户。

1. **引导用户描述目标用户画像：**
   - 你想服务什么样的人？（年龄、职业、收入、场景）
   - 他们目前最大的痛点是什么？（具体到某个场景下的某个问题）
   - 他们为了解决问题已经尝试过什么？为什么没解决？
   - 他们愿意为解决问题付多少钱？

2. **输出目标用户画像卡片：**
   ```
   👤 目标用户：{一句话描述}
   📌 核心痛点：{最痛的1-3个点}
   🔧 已尝试方案：{他们已经试过什么}
   ❌ 为什么没解决：{现有方案的问题}
   💰 付费意愿：{愿意花多少钱解决}
   ```

3. 如果用户自己也不清楚目标用户是谁，可以先跳过此阶段，在后续阶段中逐步收敛。但**完成阶段二定位后，必须回头补上用户画像**，确保定位是基于真实需求而非自我想象。

### 阶段一：知识体系梳理

1. 引导用户明确自己的专业领域和核心经验
2. 将用户的知识资产结构化，按以下维度梳理：
   - 核心知识域（硬技能/方法论）
   - 经验案例库（真实项目/解决问题）
   - 独特观点（行业洞察/个人判断）
   - 资源网络（人脉/工具/信息源）
3. **参照 `references/知识树图谱模板.md`** 输出知识树图谱，标注每个分支的深度和可产品化程度（✅高/⚠️中/❌低）

### 阶段二：定位与差异化

1. 搜索该领域的竞争格局和热门IP，分析市场空白
2. **使用 `references/竞品IP分析模板.md`** 中的采集表和四象限模型，帮用户完成竞品分析
3. 按以下维度帮用户找到差异化定位：
   - 人群细分（服务谁？越窄越强）
   - 问题聚焦（解决什么具体问题？）
   - 方法独特性（你的方法论有什么不同？）
   - 表达风格（专业严谨/接地气/数据驱动/故事型）
4. **参照 `references/定位一句话模板库.md`** 中的10个行业示范和检验标准，输出定位一句话
5. **参照 `references/成功案例集.md`** 中的真实案例，帮助用户理解如何将定位落地

### 阶段三：内容矩阵规划

按平台特性规划内容矩阵：

**公众号/知乎（深度内容）：**
- 定位：建立专业信任，输出行业洞察
- 内容类型：深度文章、案例分析、方法论拆解
- 发布频率：每周1-2篇
- 目标：积累精准粉丝，建立专家形象

**小红书/抖音（流量内容）：**
- 定位：扩大影响力，触达泛人群
- 内容类型：知识卡片、行业揭秘、趋势解读
- 发布频率：每周3-5条
- 目标：破圈传播，引流到私域

**视频号/B站（信任内容）：**
- 定位：展示人格魅力，建立情感连接
- 内容类型：直播答疑、实战演示、学员案例
- 发布频率：每周1-2次
- 目标：转化付费用户

**播客/社群（粘性内容）：**
- 定位：深度连接，持续激活
- 内容类型：行业对话、学员分享、内部答疑
- 发布频率：每周1次
- 目标：提升复购和转介绍

### 阶段四：课程大纲设计

**使用 `references/课程大纲模板.md`** 中的四层课程结构：

```
试听课（免费/9.9元）→ 入门课（99-199元）→ 进阶课（399-999元）→ 大师课（1999-4999元）
```

1. 基于知识体系，提取可教学的模块
2. 按四层结构设计课程体系：
   - **试听课**（30-45min）：解决一个具体小问题，给学员"原来如此"的顿悟感，建立信任
   - **入门课**（5-7节，每节20-30min）：完整方法论框架，带练1-2个核心动作，让学员快速看到效果
   - **进阶课**（12-15节+4次直播）：系统掌握，大量案例+实操项目，能独立操作
   - **大师课**（1-3个月）：高级技巧+1v1辅导+实战项目+资源对接，达到行业前20%水平
3. 每节课内部遵循五段式教学逻辑：痛点引入→认知重构→方法论→实操演练→进阶路径
4. 输出完整课程大纲，含模块名称、学习目标、课时安排、目标学员画像

### 阶段五：变现路径规划

1. 根据用户的知识资产和影响力阶段，推荐变现路径：
   - 引流品：免费内容（文章/短视频/直播）
   - 低价品：9.9-99元（小报童/知识星球/训练营）
   - 中价品：199-999元（录播课/社群/咨询服务）
   - 高价品：1000-5000元（训练营/1v1咨询/私教）
   - 旗舰品：5000+元（年度私董会/企业内训/出版）
2. 输出分阶段变现路径图，标注每个阶段的里程碑、冷启动策略和收入预估（含假设条件：粉丝量/转化率/客单价）
3. 补充私域承接建议：朋友圈运营、社群SOP、转介绍机制

### 阶段六：输出交付

1. 汇总所有产出，以清晰结构呈现
2. 包含：用户画像、知识树、定位一句话、竞品分析证据表、内容矩阵表、课程大纲（四层结构）、变现路径图
3. 提供下一步行动建议

## 注意事项

- 知识IP打造需要用户真实专业积累，不凭空编造经验
- 定位建议仅供参考，最终方向需结合用户实际情况调整
- 课程大纲为框架性建议，具体内容需用户自行填充
- 变现预估基于行业平均水平，附带假设条件（粉丝量/转化率/客单价），**不代表保证收益**，实际收入因执行力、流量等因素差异较大
- 如果用户未提供专业领域，主动询问以精准服务
- 本技能依赖联网搜索进行竞品分析，建议在支持搜索的环境中运行以获得更准确的市场数据
