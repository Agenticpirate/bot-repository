# 类人 AI 数字员工配置

> **一句话定位**：通用 AI 助手最大的痛不是"不会答"，而是"不像人"——没记性、不主动、不会用工具、人设飘。
> 本技能把"类人效果"拆成**四件套**，给一套可复制的**诊断 → 搭建 → 维护**流程，既能自用，也能拿去对客户交付赚钱。

## 我们的优势（凭什么交付得出"类人"）

- **超强大脑**：底层跑强模型，推理 / 记忆 / 多工具调度是真能干活，不是花架子——复杂需求接得住。
- **类人程度高**：四件套打磨过的人感：记得住你、会主动、工具用对、人设稳，聊起来不像机器人。
- **可复制交付**：方法论 + 模板 + 诊断表，企业单与个人单同一套能力，规模化的边际成本低。
- **双线通用**：同一套四件套既给 SMB 搭"数字员工"，也给个人 / 家长 / 学生搭"数字助理 / 数字老师 / 儿童 AI 老师"。
- **透明可观测**：配好的 AI 状态 / 任务 / 全局一眼可见（健康看板），不黑箱——客户买得安心，也是转化杀手锏。
- **安全可控**：只做防御加固（防注入 / 防越权 / 异常熔断 / 审计留痕，见 `10`），不碰主动攻击；配出的数字人"既像人、又守规矩"，区别于裸模型。
- **认知内核升级（v2.0）**：在四件套之外补上"会复盘、会规划、会代谢"——反思自省闭环、显式规划推理、记忆巩固遗忘，让数字员工从"像人地做"进化到"像人地想"，对标 2026 前沿（Reflexion / Tree-of-Thoughts / Anthropic Dreaming）。

## 我们提出的理念（交付权威的来源）

> 不是只会配，我们有自己的方法论主张——这是客户愿意信、敢把单交给我们的根。

- **AIzaoAI（AI 造 AI）沟通方法论**：我们提出"用 AI 给客户造 AI"的沟通框架（见 `06`）——以活样板代替 PPT、以可验证标准代替自夸，让客户亲眼看到"配好的样子"。这是我们对"AI 原生世界怎么卖服务"的方法论沉淀。
- **AI 世界治理理念**：我们提出一套面向 AI 数字人的治理主张——**可控**（角色一致、边界清晰、不越权）、**可防**（防注入 / 防越权 / 异常熔断，且只做防御、不做主动攻击）、**可验**（时间戳 + 指纹 + 哈希全链路，见 `07`）、**透明**（健康 / 任务 / 全局可观测，见 `08`）——贯穿到每一单交付与合规（PIPL / GDPR）。让我们配出的数字人"既像人、又守规矩"，区别于裸模型。

> 表述口径：对外用"我们提出 / 主张"，不用"全球首创 / 最"等绝对词——权威靠可验证的交付，不靠夸大。

## 类人效果四件套（核心方法论）

通用 AI 配出"人感"，本质就四件事，缺一个就露馅：

### 1. 长期记忆（Long-term Memory）
- **分层**：用户级（跨项目偏好/习惯）`~/.workbuddy/MEMORY.md`、项目级（长期事实 + 每日日志）`项目/.workbuddy/memory/`、会话级（当前上下文）。
- **机制**：任务完成后自动写回记忆文件 / 结构化库；启动与按需检索注入。
- **关键反模式**：每次会话从零、只存不改 → 永远长不大。

### 2. 主动执行（Proactive Execution）
- 不止应答，能判断"该不该主动做"：定时任务、状态巡检、到点提醒、异常预警。
- **边界**：主动 ≠ 越权。必须预设授权范围 + 高危动作二次确认。

### 3. 多工具调用（Tool Use）
- 给 AI 接上真实动作：读/写文件、发消息/邮件、查日历/会议、搜索/抓取、跑脚本/调 API。
- **原则**：能工具化的别靠嘴说；工具要最小权限 + 敏感操作二次确认。

### 4. 角色一致（Consistent Persona）
- 用 `SOUL.md`（我是谁）+ `IDENTITY.md`（标识）+ `USER.md`（关于人类）固化身份/语气/职责边界。
- 不串角色、不飘人设，是"像人"的底座。

## 认知内核四件套（v2.0 三件套 + v2.1 持续进化 · 让"类人"名副其实）

四件套解决"像人地做"（记得住、会动手、能干活、人设稳），但还差"像人地想"与"像人地长进"——原四件套没有**元认知**：不复盘、不规划、不代谢、不进化。v2.0 补上认知内核三件套（反思/规划/巩固），v2.1 再补**持续进化**，与四件套并列，构成完整的类人认知体系：

### ① 反思自省（Reflection）
做完回头想：评估结果 → 写反思笔记 → 修正并写回记忆。对标 Reflexion + Anthropic 双 Agent 互评。详见 `references/35-反思自省.md`。

### ② 规划推理（Planning / System 2）
先想清楚再干：拆子目标 → 路径评估（ToT / MCTS）→ 执行编排 → 失败重规划。对标 System 2 / Tree-of-Thoughts。详见 `references/36-规划推理.md`。

### ③ 遗忘巩固（Consolidation）
睡一觉消化记忆：编码 → 离线巩固（去重/关联/提炼 SOP）→ 提取并按遗忘曲线衰减。把 `32` 的遗忘衰减升级为实能力，对标 Anthropic 2026-05 Dreaming。详见 `references/37-遗忘巩固.md`。

### ④ 持续进化（Lifelong Self-Evolution）
干一单、强一点：训(学重点)→战(实战)→省(复盘)→化(固化成技能/记忆)，闭环回灌。把"会从经验里长进"文档化——这是比静态配置更类人的真差异点，对标 Anthropic 2026「learned behavior」/ Letta 持续人格。详见 `references/38-持续进化.md`。

> **v2.3 强化（落实 D4）**：反思（`35` §10）与进化（`38`）嵌入**自主反思闭环**——空闲窗口 / 定时自动自省、写回记忆、规划改进、回灌飞轮，无需人催；异步限频、可审计、不擅改人设。设计层规格与路线图见 `40` §D1–D4。

> 四件套(做) + 认知内核四件套(想/长进) 咬合：反思结论写回记忆、规划读记忆调工具、巩固把反思教训固化进程序性记忆、进化把可复用经验升级为跨任务资产——形成"想—做—代谢—长进"的生命闭环，正是 2026 年人脑级 Agent 的核心特征。

## 使用示例

**场景**：给一个电商客服配"类人数字员工"。

- **记忆**：建 `MEMORY.md` 记客户偏好（退货政策、常用话术、黑话），每次会话后自动写回。
- **角色**：`SOUL.md` 定"专业但不啰嗦、先共情后解决"，不串成销售。
- **工具**：接订单查询 API + 退款工单创建接口，最小权限。
- **主动**：每天 9:00 跑未结工单巡检，超 24h 自动提醒负责人。

**效果**：客户问"我那单啥进度" → AI 直接查到并回复，不用重复说明；半夜新工单 → 次日 9:00 主动播报。这就是"像人"。

## 配套工具（拿来即用）

本技能包附带 6 个可直接运行的工具（`tools/`）：

| 工具 | 用途 | 运行 |
|------|------|------|
| `tools/id_verify.py` | 加密 ID 来源认证：签发 / 验证 / 吊销 Ed25519 凭证（见 `17`） | `python tools/id_verify.py genkey --dir ./keys` 等 |
| `tools/ai_bench.py` | AI 身份智力测试：评测电池出分 + 对标等级 + 哈希留证（见 `16`） | `python tools/ai_bench.py demo` / `ollama --model qwen2.5:7b` |
| `tools/trace.py` | 全链路追溯：时间戳 + SHA-256 留证 / 校验（见 `07`） | `python tools/trace.py stamp <文件> --out stamp.json` |
| `tools/license_code.py` | 同意授权码：L0–L3 四层码生成 / 校验 / 吊销（见 `14`） | `python tools/license_code.py gen L1 --cid X --caps 1,3,5` |
| `tools/config_pack.py` | 一键配置包生成：标准配置包目录（见 `31`） | `python tools/config_pack.py gen --name 小张 --role 电商客服 --out ./pack` |
| `tools/eval_smoke.py` | 本地离线评测冒烟（D1）：对配置做八维接线检查，输出评分卡，无 API 依赖（见 `40` §D1） | `python tools/eval_smoke.py demo` / `python tools/eval_smoke.py <config_dir>` |

> 5 个工具均已实测跑通：加密 ID 签发→验证→吊销；评测出报告（综合分+对标+哈希留证）；追溯 stamp→check 校验一致；授权码 gen→valid→revoke→revoked；配置包生成完整目录。私钥仅签发用、永不进发布包（`18`）；授权码密钥走环境变量 `WB_LIC_KEY`，不落明文。

## 交付物定义（两层，先分清）

> 常被问"你们交付物是插件吗"——**不是传统插件**。我们有两层交付物：

**① 对外发布物 = Skill 技能包（本包）**
- 形态：可安装进 WorkBuddy / Claude Code 等平台的**技能包**（类插件，但不是传统插件——它不提供独立功能，而是给 AI 代理装上"怎么配类人数字员工"的方法论与流程）。
- 本质：**方法论 + 诊断表 + 模板 + SOP + 知识库**（53 文件），是**生产线 / 生产资料**，不是最终产品。
- 给谁：数字员工配置师 / 同行 / 想自建的人。定价见市场（一次性或订阅）。

**② 对客户交付物 = 数字员工配置资产（服务）**
- 形态：标准配置包（角色三件套 + 记忆骨架 + 工具清单 + 主动规则 + 加密 ID，见 `31`）+ 文档 + 培训 + 售后。
- 本质：一键装到任意大模型（`31`），跑起来就是客户自己的**类人数字员工**，是**产品**。
- 给谁：企业（数字员工）/ 个人（数字助理 / 老师 / 儿童 AI 老师）。定价见 `02` / `08` / `24`。

> 一句话：**Skill 包是"造数字人的生产线"，数字员工配置资产是"生产线造出来的产品"——两个都卖，别混。**

## 能力边界

- 本技能给**方法论 + 配置模板 + 诊断表**，不含某平台的专属对接代码（各平台 API 各异，需另行对接）。
- 不替你写业务系统；不接管核心权限账号。
- 记忆质量取决于你**喂得勤不勤**——"不写回"等于没记忆。
- 角色漂移需定期校正，不是一劳永逸。

## 红线（对外交付必守）

- 不碰客户核心代码 / 密钥；不越权执行。
- 数据不出门优先本地推理；云端 API 任务需评估合规。
- 对外署名一律用品牌**注册老炮**，与委托人身份隔离（沿用既有红线）。

**信任与生态层（交付即带身份与可追溯）**：每单成交发放「客户 ID + 通行证」，交付物打时间戳 + 数字指纹 + 哈希，形成全链路可追溯；授权作展示用例的客户享费用减免（见 `02` 展示用例激励、`04` 阶段 2 / 4.5、`07` 交付可信与全链路可追溯）。数字人能力**版本化、可升版**（见 `13`），升版即持续收费接口，与月费、转介绍构成复利三层。客户对数字人的**控制权以「同意授权码」实现**——四层码（绑定/能力/操作/熔断）让客户用最简单方法控 AI，且现实+AI 双世界深度绑定（见 `14`）。对外沟通采用「AI 造 AI」叙事（活样板即说服力），话术框架见 `06`；治理理念与权威定位见 `09`。造出来的数字人还纳入**生态运营**——AI 挑战 / 组队接单 / 客户社群（见 `15`），把一次性交付变「搭建 + 月费 + 升版 + 生态」四层复利，且持续在场即最强信任锚。此外，每个交付数字人签发**加密 ID 凭证**（带数字签名），并提供公开验证入口，任何人可验"是否注册老炮出品"、戳穿冒用——出处防伪即最强权威锚（见 `17`）。每单交付前用**权威基准评测电池**给数字人客观打分、映射对标等级（助教/讲师/副教授/教授，类比非职称），评测即定价锚也是最强信任证明（见 `16`）；升版（`13`）重测刷新、活动（`15`）榜单即评测排名。方法资产分公开层/私密层，获利引擎（专有调参）绝不进发布包（见 `18`）；同时我们在 AI 世界打造 IP 与生态，让造出的数字人带可验证身份被生态认知与认可（见 `19`）。交付覆盖**售前/售中/售后全周期服务**（见 `20`）；客户可**自助喂料**扩容知识库（见 `21`）、用**微信/支付宝/谷歌一键绑定**本人（见 `22`）；跑出类人效果**硬件要求低、成本低**（见 `23`）；客户亦可**一次性买断**解锁全部能力并自行改造（见 `24`），配置支持**多语言交付**（见 `25`）——把"像人、便宜、好改、能出海"一次说清。谈单摆**证据墙**（脱敏案例 + 评测分 + 可验真，见 `26`）；已有 AI 的客户走**旧改新升级**（体检→改造→重测，见 `27`）；培训 + 认证把客户变成**代理**（转介返点更高、组队优先，见 `28`）——客户越多，帮我们卖的人也越多。交付附**客户引导手册**（`29`：三步上手 / 喂料 / 日常用法 / FAQ，不设版权壁垒、客户可自由修改、附免责声明）；客户不满意可**退款，但数字员工须销毁**（配置 + 数据，见 `11`）——保障客户，也守住"退款不白用"。业务运行靠**四端口体系**（交付/付费/咨询/投诉建议，见 `30`），客户在哪都能进来、办哪件事走哪个口；配好的数字 AI 支持**一键配置到任意大模型**（WorkBuddy/Claude/Cursor/Coze/Dify/元器/本地 Ollama，换模型不换人格，见 `31`）；记忆按**四层架构**持久化（工作/情景/语义/程序性，对标记忆层实缺口，见 `32`）——平台只给 Bot，我们给可迁移的类人资产。

## FAQ（反模式专节）

**Q1：为什么我的 AI 每次都像失忆？**
没配"写回"机制——只注入不沉淀。补上任务完成后的记忆写回，它才长记性。

**Q2：主动执行会不会乱来？**
会，如果没边界。必须设授权白名单 + 高危动作二次确认，主动≠越权。

**Q3：工具接得越多越好？**
不是。最小权限原则，接一个管一个边界；冗余工具只增风险。

**Q4：角色卡写一遍就行？**
会漂移。人设要定期校正（维护阶段），否则聊久了就串味。

**Q5：本地推理还是云端 API？**
敏感数据本地优先，重活走云端，按合规与成本选，不硬绑。

**Q6：这套能直接卖钱？**
能。三阶段交付 + 月费续费，定价见 `references/02-报价与交付.md`，续费是复利引擎。
