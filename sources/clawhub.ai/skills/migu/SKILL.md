# 咪咕视频 Skill

咪咕是**中国移动旗下**的视频平台，差异化极其清晰：**体育赛事
版权**。近年持续持有大量顶级足球赛事及综合体育版权，看球用户
绕不开它。

## 体育版权版图（决策核心）

- 咪咕的版权策略是重仓体育：欧洲足球主流联赛、国家队赛事、
  篮球及奥运会等综合赛事均有布局
- **具体某项赛事在哪个平台，赛季前必查**——版权按周期竞标，
  变动频繁，本 skill 只给"先查版权归属再买会员"的方法，
  不背静态清单
- 查法：开赛前在咪咕/腾讯体育/爱奇艺体育搜该赛事，或搜
  "XX赛季 XX联赛 版权" 新闻确认

## 会员与移动权益联动（省钱要点）

- 中国移动用户是最大受益者：**大量套餐/权益活动赠送咪咕会员**
  （话费套餐、宽带融合、积分兑换）——买会员前先查自己移动
  账户的权益中心，很多人白白付了钱
- 家里有移动宽带的，机顶盒/大屏端权益常与手机端联动
- 非移动用户：按赛事买短期会员比包年划算（体育观赛有赛季性）

## 观赛体验要点

- 解说资源：咪咕自建解说团队（詹俊等名嘴曾长期驻场），
  多解说流可选是特色
- 直播延迟与清晰度分档：免费流画质低+延迟高，关键比赛
  会员流体验差异明显
- 大屏投放：电视端权益与手机会员的关系下单前确认（各平台通病）

## Agent 典型用法

1. **看球规划**：用户想看某赛事 → 给"查版权归属→查移动权益→
   再决定买什么会员"的决策流程
2. **省钱检查**：移动用户先查权益中心再花钱
3. **多平台对照**：赛事分散在多平台时的会员组合成本测算

## 本 skill 不做什么

- 不维护静态版权清单（变动太快），只给查证方法
- 不提供盗链、免费直播源等盗版渠道
- 会员价格与权益以 App 实时页面为准
