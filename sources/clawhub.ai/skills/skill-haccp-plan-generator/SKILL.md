# HACCP 计划表生成器

## 任务目标

- 本 Skill 用于：根据用户提供的生产流程，自动生成符合 Codex/GB 标准的 HACCP 危害分析与关键控制点计划表
- 能力包含：危害分析、CCP 识别、关键限值设定、监控/纠偏/验证措施制定、Excel 导出
- 触发条件：用户说"生成 HACCP"、"帮我分析生产流程"、"创建食品安全计划"或类似表达

## 前置准备

- **必需信息**：产品名称 + 生产流程（从原料到成品的完整工序列表）
- **可选信息**：产品规格、储存条件、设备参数、目标消费群体等
- **缺失处理**：凡使用通用描述或默认值的内容，必须在输出中标注 `[待确认]` 或 `[默认值]`

## 操作步骤

### 第一步：信息收集

当用户提供信息后，先确认是否满足最小信息集：

| 必需项 | 确认内容 |
|--------|---------|
| 产品名称 | 具体食品名称，如"蛋黄酥"、"巴氏杀菌乳" |
| 生产流程 | 至少包含主要工序，如"原料验收→配料→加工→包装→出厂" |

若信息不足，按以下方式追问：

- 缺少产品名称：询问"请告诉我这是什么产品？"
- 缺少流程：询问"请描述一下从原料到成品的完整生产工序"

### 第二步：流程解析与危害分析

1. **解析流程**：将用户描述的流程拆解为独立工序
2. **识别危害**：对每道工序分析三类危害
   - 生物性：细菌、病毒、寄生虫
   - 化学性：农残、添加剂、金属异物
   - 物理性：异物、玻璃碎屑
3. **评估风险**：结合产品特性判断危害显著性（是否需要控制）

> 详见 [references/haccp-knowledge.md](references/haccp-knowledge.md) 中的"危害分析指南"

### 第三步：确定关键控制点（CCP）

判断标准（决策树）：

```
该工序是否存在显著危害？
├── 否 → 不是 CCP，记录为受控工序
└── 是 → 后续问题是否有控制措施？
          ├── 否 → 不是 CCP（需重新评估工艺）
          └── 是 → 该控制措施是否可以监控？
                    ├── 否 → 不是 CCP（需增设控制点）
                    └── 是 → 确定为 CCP
```

常见 CCP 参考（按产品类型）：

| 产品类型 | 常见 CCP |
|---------|---------|
| 肉制品 | 原料验收、冷却、腌制、加热 |
| 乳制品 | 巴氏杀菌、冷链储存 |
| 烘焙食品 | 烘烤冷却、金属检测 |
| 水产品 | 冷冻、解冻、蒸煮 |

### 第四步：设定关键限值

关键限值（CL）示例：

| 监控对象 | 关键限值示例 | 来源 |
|---------|-------------|------|
| 温度 | 加热中心温度 ≥75℃ | Codex 标准 |
| 时间 | 解冻时间 ≤12h（4℃以下） | 行业实践 |
| 浓度 | 消毒剂余氯 50-100ppm | 设备参数 |
| 感官 | 无异味、颜色正常 | 感官指标 |

**注意**：关键限值必须可测量、可监控、可验证

### 第五步：生成 HACCP 计划表

按以下 11 列格式输出：

| NO | 过程名称 | 危害类型 | 关键限值 | 控制措施 | 监控对象 | 监控方法 | 监控频率 | 监控人员 | 纠偏行动 | 验证 | 记录 |
|----|---------|---------|---------|---------|---------|---------|---------|---------|---------|------|------|

- **NO**：序号（参考工艺流程顺序）
- **过程名称**：工序名称，可包含工序编号
- **危害类型**：生物/化学/物理危害描述
- **关键限值**：量化指标，如"温度≥75℃"
- **控制措施**：预防该危害的具体方法
- **监控对象/方法/频率/人员**：监控四要素
- **纠偏行动**：失控时的纠正措施
- **验证**：确认 CCP 有效的验证活动
- **记录**：需保存的记录文件名称

### 第六步：标注缺失信息

凡使用以下内容时，必须标注：

| 场景 | 标注方式 | 示例 |
|------|---------|------|
| 行业通用值 | `[默认值]` | 冷藏温度≤4℃ `[默认值]` |
| 需用户确认 | `[待确认]` | 金属检出限 `[待确认]` |
| 未提供信息 | `[未提供]` | 目标消费群体 `[未提供]` |

### 第七步：导出（可选）

如需导出为 Excel 文件：

```bash
python scripts/export_haccp.py --product "产品名称" --data '{"ccps": [...]}'
```

导出后的文件保存为 `HACCP计划表_产品名称_YYYYMMDD.xlsx`

## 使用示例

### 示例 1：简单产品

**用户输入**：
```
帮我为蛋黄酥生成 HACCP 计划表
流程：原料验收→冷冻储存→解冻→配料→制馅→包馅→成型→烘烤→冷却→包装→金属检测→出厂
```

**输出**：
```
已生成 HACCP 计划表（蛋黄酥），共识别 3 个关键控制点：

| NO | 过程名称 | 关键限值 | 纠偏行动 |
|----|---------|---------|---------|
| 7  | 烘烤 | 中心温度≥75℃ | 延长烘烤时间或报废 |
| 10 | 金属检测 | Fe≥1.5mm | 隔离复查产品 |
| 2  | 冷冻储存 | ≤-18℃ | 调整温控或隔离评估 |

⚠️ 以下参数使用了默认值，请在实施前确认：
- 解冻温度/时间限制 [默认值：≤4℃/≤12h]
- 冷却时间限制 [默认值：2h内降至21℃]
```

### 示例 2：补充信息后

**用户输入**：
```
产品：巴氏杀菌乳 250ml 利乐包
流程：原料验收→过滤→均质→巴氏杀菌→冷却→灌装→冷藏储存→出货
储存条件：2-6℃冷链，保质期7天
消费群体：普通消费者
```

**输出**：
完整 HACCP 计划表，CCP 包括原料验收（菌落总数）、巴氏杀菌（致病菌）、冷链储存（温度控制）

## 注意事项

1. **信息不足时**：先收集信息，不盲目生成不完整表格
2. **缺失标注**：默认值和待确认项必须明确标注，不隐藏
3. **行业差异**：关键限值需结合企业实际和行业标准调整
4. **验证记录**：生成的记录文件名称供参考，需配套实际表单
5. **仅生成框架**：本 Skill 生成初稿，企业需内部评审后方可实施
