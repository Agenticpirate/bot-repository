## 使用场景

### 场景 1: 绘制流程图

使用 Mermaid 语法快速绘制业务流程图

```bash
graph TD
  A[开始] --> B{条件判断}
  B -->|是| C[处理A]
  B -->|否| D[处理B]
  C --> E[结束]
  D --> E
```

### 场景 2: 生成架构图

使用 Graphviz 绘制系统架构图

```bash
from graphviz import Digraph
dot = Digraph()
dot.node("A", "API网关")
dot.node("B", "业务服务")
dot.edge("A", "B")
dot.render("arch", format="png")
```
