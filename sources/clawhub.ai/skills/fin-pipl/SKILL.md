## 📋 功能概述

Fin-PIPL 针对金融行业四大业务场景，提供定制化合规检查：

| 场景 | 重点检查项 | 适用机构 |
|------|-----------|---------|
| 🏦 **银行业务** | 开户告知同意、信贷信息处理、征信查询、信用卡营销、账户信息共享 | 商业银行、消金公司 |
| 📈 **证券/基金** | 适当性管理、交易信息保护、投资者信息共享、智能投顾合规 | 券商、基金公司 |
| 🏥 **保险业务** | 核保健康信息收集、理赔调查、再保险信息共享、保险营销推荐 | 保险公司、保险中介 |
| 💳 **支付业务** | 交易信息收集、风控信息使用、商户信息处理、支付标记化 | 支付机构、第三方支付 |

## 🚀 快速开始

```bash
# 交互式检查（推荐）
python3 scripts/fin-pipl-check.py --interactive

# 指定场景
python3 scripts/fin-pipl-check.py --scenario banking
python3 scripts/fin-pipl-check.py --scenario securities
python3 scripts/fin-pipl-check.py --scenario insurance
python3 scripts/fin-pipl-check.py --scenario payment

# 输出报告
python3 scripts/fin-pipl-check.py --scenario banking --output report.md
python3 scripts/fin-pipl-check.py --scenario banking --output report.json --format json
python3 scripts/fin-pipl-check.py --scenario banking --output report.html --format html
```

## 🔍 检查项概览（20+项）

### 银行业务（8项）
1. 开户告知同意 — 线上/线下开户的 PIPL 告知同意完整性
2. 信贷信息处理 — 贷款审批、贷后管理的信息使用合规
3. 征信查询报送 — 征信授权、查询用途、异议处理
4. 信用卡营销 — 账单、分期、联名卡营销中的个人信息使用
5. 账户信息共享 — 集团内共享、第三方合作的告知与授权
6. 个人金融信息分级 — JR/T 0197 的 C3/C2/C1 分类
7. 自动化决策 — 授信模型、评分卡的用户拒绝权
8. 数据留存与删除 — 账户注销后的个人信息删除

### 证券/基金业务（6项）
1. 适当性管理 — KYC 信息收集范围与目的
2. 交易信息保护 — 委托、成交、持仓信息的保护
3. 投资者信息共享 — 登记结算、托管银行的数据传输
4. 智能投顾合规 — 算法推荐、自动化投资建议的告知
5. 营销推介合规 — 基金销售中的个人信息使用与隐私政策
6. 跨境投资数据 — 沪深港通、QDII 等场景的数据出境

### 保险业务（6项）
1. 核保健康信息 — 投保环节健康告知信息的收集范围
2. 理赔调查 — 理赔时第三方调查的信息授权
3. 再保险共享 — 再保险安排中个人信息的跨境与第三方传输
4. 保险营销推荐 — 保单到期提醒、交叉销售的信息使用
5. 健康数据分级 — 体检报告、病历等敏感个人信息保护
6. 受益人信息处理 — 受益人个人信息的收集与保护

### 支付业务（5项）
1. 交易信息收集 — 支付信息的最小必要原则
2. 风控信息使用 — 反欺诈、反洗钱中的信息处理
3. 商户信息处理 — 收单业务中的商户个人信息保护
4. 支付标记化 — Tokenization 技术的合规使用
5. 账户信息保护 — 支付账户与绑定银行卡信息保护
