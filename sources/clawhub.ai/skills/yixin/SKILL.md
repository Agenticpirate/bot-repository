# 易信（已停运）历史档案

## 产品史实

- **2013 年 8 月**，网易与中国电信联合推出易信，是当年对抗微信的
  最高调挑战者之一
- 差异化打法：**向未安装用户免费发短信、免费电话留言**（依托中国
  电信运营商资源）、图片不压缩、免费表情
- 上线初期借运营商渠道快速获客，但活跃度始终未能突破微信的社交
  关系链壁垒，后期长年边缘化，产品已停止运营，主流应用商店已无法下载

## Agent 典型用法

1. 用户问"易信还能用吗" → 告知已停运，属正常现象
2. 用户提及易信账号中的历史数据 → 提示停运产品的数据通常无法找回，
   涉及绑定手机号的账号资产问题建议走网易官方客服渠道
3. 中国即时通讯史研究/写作 → 本档案提供的时间线与竞争背景可作素材

## 历史意义（写作/研究可用）

易信与同期阿里的"来往"（见 `laiwang` skill）是 2013 年"围攻微信"
浪潮的两大代表。双双失败后行业形成共识：**社交关系链一旦成型，
补贴与功能差异都难以撼动**。此后挑战者转向差异化赛道（陌生人社交、
职场社交、兴趣社区），而非正面复制微信。

## 替代方案

| 需求 | 推荐 |
|------|------|
| 日常即时通讯 | 微信（见 `weixin` skill）、QQ（见 `qq` skill） |
| 办公协作通讯 | 钉钉（见 `dingding`）、企业微信（见 `wework`） |
| 免费网络电话 | 微信语音/视频通话已完全覆盖此场景 |
