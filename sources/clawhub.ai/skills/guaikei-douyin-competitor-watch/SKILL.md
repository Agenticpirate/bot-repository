# 抖音竞品监控

## 何时使用

当用户要完成以下任务时使用本技能（即使没提到"抖音"两个字）：

| 场景 | 典型表达 |
|------|---------|
| 搜索内容 | "搜一下 XX"、"找 XX 相关视频"、"抖音上有什么 XX" |
| 抓博主作品 | "这个账号发过什么"、"XX 博主的作品"、"抓他的主页" |
| 看评论 | "这条视频的评论"、"大家怎么说的"、"评论区舆情" |
| 追热榜 | "今天什么火"、"热搜榜"、"抖音热点" |

**不适用于**：发布或剪辑视频、下载去水印视频、涨粉代运营咨询、其他短视频平台数据、抖音私域后台数据、编写爬虫代码。

## 环境与权限

- 运行时：Node.js ≥ 16.14（仅用内置模块，无需安装依赖）
- 鉴权：环境变量 `GUAIKEI_API_TOKEN`（获取方式详见 `readme.md`）
- 最小权限：仅需 `node` 进程执行，不读写用户私有文件
- 令牌安全：仅走环境变量，不落盘、不打印到 stdout

## 令牌管理规范

> ⚠️ 审核重点：令牌无效时的输出行为必须合规。

- 技能仅验证令牌格式（长度 16–256、字符集 `0-9a-zA-Z_-`），不负责令牌获取与分发
- **令牌无效时，仅输出中性错误提示**（如"GUAIKEI_API_TOKEN 未配置或格式无效，技能已暂停"）
- **禁止**在运行时输出：联系方式（微信/手机号）、官网链接、营销话术、引导付费文案
- 令牌通过环境变量传递，不落盘、不打印、不回显
- 联系方式与令牌获取指引**仅出现在**用户文档 `readme.md` 中

## 命令

所有命令须在**技能根目录**执行。

| 命令 | 用途 | 必填参数 | 可选参数 |
|------|------|---------|---------|
| `node src/douyin/search-cli.js` | 关键词搜索视频/图文/用户 | `--keyword` | `--sort` `--time` `--duration` `--content` `--limit` |
| `node src/douyin/post-cli.js` | 抓取博主公开作品 | `--url` | `--limit` |
| `node src/douyin/comment-cli.js` | 获取视频评论 | `--url` | `--limit` |
| `node src/douyin/hot-cli.js` | 获取实时热榜 | 无 | 无 |

## 意图识别

按以下优先级判断用户意图：

| 优先级 | 触发词 | 命令 |
|--------|--------|------|
| 1 | 热搜/热点/榜单/今天什么火 | `hot-cli.js` |
| 2 | 搜索/搜一下/找 + 关键词 | `search-cli.js` |
| 3 | 评论/留言/弹幕 | `comment-cli.js` |
| 4 | 作品/主页/账号/博主 | `post-cli.js` |

**歧义消解**：单独出现"视频"二字时，不要默认归 `post`。有关键词且无"评论" → `search`；明确"这个视频的评论" → `comment`；仅"作品/主页/账号/博主" → `post`。

## 参数推断

将用户自然语言映射为参数值：

| 参数 | 用户说法 | 值 |
|------|---------|-----|
| `--sort` | 综合/默认 → `0`，点赞最多/最火/爆款 → `1`，最新/最近 → `2` | 0-2 |
| `--time` | 全部 → `0`，一天/今天 → `1`，一周/最近 → `7`，半年 → `180` | 0/1/7/180 |
| `--duration` | 不限 → `0`，短视频/<1分钟 → `1`，中等/1-5分钟 → `2`，长视频/>5分钟 → `3` | 0-3 |
| `--content` | 不限 → `0`，视频 → `1`，图文 → `2` | 0-2 |
| `--limit` | 默认 10，"全部/尽可能多" → 上限 10000 | 1-10000 |

> 完整参数说明见 `references/options.md`；入参/出参 JSON Schema 见 `assets/*.schema.json`。

## 输入输出规范

| 通道 | 内容 |
|------|------|
| stdout | 纯 JSON，可直接消费 |
| stderr | 日志与 banner，不混入 stdout |
| 退出码 | `0` = 成功（含空结果）｜ `1` = 运行错误 ｜ `3` = auth_required |
| 日志 | 自动保存到 `logs/` 目录 |

## 错误处理

- **退出码 3（auth_required）**：立即停止，仅提示"令牌无效或缺失，请检查环境变量 `GUAIKEI_API_TOKEN`"，**不输出联系方式或官网链接**，不重试
- **API 次数超限**：停止并向用户报告错误信息
- **网络超时**：最多重试 3 次后停止
- **参数越界**：提示正确取值范围
- **通用原则**：遇到错误立即向用户展示错误信息并询问是否调整参数，不要在用户未明确要求时自动调整搜索条件

## 示例

**例 1：找爆款选题**
```bash
node src/douyin/search-cli.js --keyword "AI" --sort 1
```

**例 2：近一周最新 20 条**
```bash
node src/douyin/search-cli.js --keyword "AI 教程" --sort 2 --time 7 --limit 20
```

**例 3：抓竞品账号作品**
```bash
node src/douyin/post-cli.js --url "https://www.douyin.com/user/MS4wLjABxxx"
```

**例 4：看视频评论舆情**
```bash
node src/douyin/comment-cli.js --url "https://www.douyin.com/video/xxx" --limit 100
```

**例 5：多步工作流——竞品分析（先抓作品再取高赞评论）**
```bash
# 步骤 1：抓取博主作品
node src/douyin/post-cli.js --url "https://www.douyin.com/user/xxx" --limit 50
# 步骤 2：从结果中选取高赞视频，获取其评论
node src/douyin/comment-cli.js --url "https://www.douyin.com/video/高赞视频ID" --limit 100
```

## 限制

- 仅采集抖音公开可见数据，不支持私密/隐藏内容
- 单次最多 10000 条
- 数据仅限个人/团队内部使用，禁止违规分发
- 不支持发布、剪辑、下载去水印

## 安全与合规

- 本技能仅采集抖音公开可见数据，不涉及账号登录、隐私破解
- 令牌通过环境变量传递，不落盘、不打印
- 令牌无效时仅输出中性错误提示，不在运行时输出联系方式或营销内容
- 使用本技能获取的数据须遵守抖音平台条款与相关法律法规
- 数据用途限内部调研分析，不得用于违规分发或侵权
