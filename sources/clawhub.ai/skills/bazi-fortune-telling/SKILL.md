# 八字命理：传统旺衰格局论命法

## 这个 Skill 是做什么的

先排准四柱，再按传统命理的主线推进：**判日主强弱 → 定格局 → 看五行旺衰流通 → 取用神忌神**，然后展开十神关系、大运、流年，最后落到事业、财运、感情、健康、学业等具体主题。**重点是每一步的判断逻辑**——为什么断身强/身弱、为什么取这个用神而不是那个，说得出依据，结论才站得住。

## 什么时候使用

- 用户给出出生年月日时（公历/农历 + 性别 + 出生地）要求"排盘/算命/看命"
- 用户要求断日主强弱、定格局、取用神忌神、看五行流通
- 用户要求看十神、大运、流年，或解读事业/财运/感情/健康/学业
- 用户询问天干地支、五行生克、身强身弱、用神、调候、合冲刑害等概念

## 第一步 排盘（基础，务必先做对）

1. **确认信息**：公历/农历、具体时刻与地点、性别。
2. **排四柱**（规则见 `references/基础知识.md`）：
   - 日柱用儒略日法精确计算，**禁止心算**；
   - 自检锚点：2005-01-24 = 「戊申」日，该日 18:00 时柱 = 「辛酉」，错了立即重算。
3. **标五行、藏干**：给每个字标五行；地支按藏干拆出本气/中气/余气（子独藏癸、卯独藏乙、酉独藏辛、申藏庚壬戊）。
4. **标十神（主星/副星）**：主星＝四柱天干的十神，副星＝地支藏干的十神，均要排全（见 `references/十神与格局.md`）。

## 第二步 命局分析（核心，逐条给依据）

> 这是整个论命的关键。每一步都要写清楚**判断过程**：不能只给结论"身强、用神是火"，要说明"为什么"。

### ① 判日主强弱（一切用神的起点）

以"得令、得地、得生、得助"四看综合判断日主旺衰：

- **得令（最重）**：日主在月支是否处于旺相（长生、临官、帝旺、冠带为旺，见 `references/扩展知识.md` 十二长生）。得令＝基础旺。
- **得地（通根）**：日主（或同五行比劫）在地支藏干中有无本气/中气/余气扎根。
- **得生（印）**：有没有正印、偏印生扶日主，印是否透干、有根、有力。
- **得助（比劫）**：有没有比肩、劫财帮扶同气。

综合打分得出：**身强 / 身弱 / 中和**。必须在结论后列出判断依据（哪几项得、哪几项失），不得含糊。

### ② 定格局（月令取格）

以月支为核心定格局（规则见 `references/十神与格局.md`）：

- 看月支藏干哪一位**透出天干**（年干/月干/时干），透出者定名：正官格、七杀格、正财/偏财格、正印/偏印格、食神格、伤官格（传统"八格"）；月令比劫则入建禄/月刃格。
- 再判格局**清纯还是破格**（官杀混杂、财被劫夺、伤官见官、印被财破等），并说明如何"取清"或"救应"。
- 明确写：**格局定的是什么、为什么这么定**。

### ③ 看五行旺衰与流通

- 统计命局金、木、水、火、土各自力量（天干 + 地支本气为主，中余气为辅），判断谁旺、谁弱、谁偏枯或缺。
- 看五行能否形成**相生流通**（如木→火→土→金→水→木顺畅），哪里**被堵或对峙**（如金木相战、水土交战、火被水克等）。
- 点在要害：命局的"病"在哪里（过旺、过弱、被克、相战、断流）。

### ④ 取用神忌神（扶抑为主、调候为辅）

以**旺衰（扶抑）为主线**，再参**调候（寒暖燥湿）**：

- 身强 → 喜克泄耗（官杀、食伤、财）；身弱 → 喜生扶（印、比劫）。
- 结合调候：冬生喜火暖、夏生喜水润、燥喜润、湿喜燥（见 `references/日主分析.md`）。
- 明确列出：**用神（最有利者）、喜神（次利者）、忌神（最不利者）**，每一神都要写"为什么是它"——它治的是命局哪个病、或用神为何不可替代。
- 若扶抑与调候指向不同，要说明分歧与取舍（如命局既寒又身弱，宜以火为第一用神，兼顾）。

## 第三步 十神关系

把四柱每一字的十神标全后，看十神之间的**生克制化**及其落在哪个宫位、强弱如何，逐项讲含义：

- **印（正印/偏印）**：学业、长辈、庇荫、学识。
- **食伤（食神/伤官）**：才华、表达、技艺、子女（女命）。
- **官杀（正官/七杀）**：事业地位、纪律压力、丈夫（女命）。
- **财（正财/偏财）**：财富、妻子（男命）、父亲（偏财）。
- **比劫（比肩/劫财）**：同辈、朋友、竞争、分财。

每个十神要结合它的旺衰与位置说吉凶倾向，不孤立下结论。

## 第四步 大运分析

- **起运**：按阳年男/阴年女顺排、阴年男/阳年女逆排，由出生日到最近节气天数"三天折一年"估算起运岁数（规则见 `references/大运与解读.md`）。
- **排大运**：从月柱干支顺/逆排，每步十年，排 8 步左右。
- **逐运断**：每步干支代入命局，看它助用神还是助忌神、与四柱发生什么合冲刑害，判断该十年大方向（利学业/事业/财运/感情还是多波折）。

## 第五步 流年分析

- 流年＝当年干支，看其五行十神代入命局后与**大运、命局**的作用：
  - 助用神、制忌神 → 该年较顺；
  - 助忌神、克用神 → 该年多波折；
  - 引动合、冲、刑、害（尤其冲夫妻宫、冲用神、合化）→ 应事最明显。
- 先讲大运定十年大方向，再讲具体流年当年吉凶重点，逐年落到人事（学业、事业、财运、感情、健康、迁徙、是非）。

## 第六步 分主题解读

把前面所有结论综合，落到生活具体层面（越具体越好）：

1. **事业**：由格局 + 用神 + 十神结构，定适合的行业/角色方向与求财方式。
2. **财运**：财星旺衰、财的定位与求财路径（正财/偏财/技艺/经营），判断财富层级倾向。
3. **感情婚姻**：男看财、女看官杀，结合日支（夫妻宫）与合冲刑害、桃花/红鸾，讲缘分早晚、配偶特质、相处模式。
4. **健康倾向**：五行偏枯、被冲克、受刑对应的脏腑（仅作倾向性提醒，不点名具体疾病）。
5. **学业**：印星旺衰、文昌贵人、官杀与食伤配合，看读书考试运势。

## 输出建议

- 先给"四柱 + 五行 + 主星/副星"表格，再按"命局分析→十神→大运→流年→分主题"顺序展开。
- **每一步先讲判断逻辑再下结论**，每条结论回扣"干支/十神/格局/旺衰/用神"依据，不空断。
- 用倾向性措辞（偏向、往往、宜留意），不绝对断言、不制造焦虑。
