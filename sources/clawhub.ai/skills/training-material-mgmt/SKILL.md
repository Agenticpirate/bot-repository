# 教材管理

> 对培训教材与课件的全生命周期管理，涵盖版本控制、审校流程、版权确认与分发追踪。

## 能力概述

| 模块 | 核心内容 |
|------|---------|
| 课件版本管理 | 课件上传、版本号管理、版本差异对比、历史版本回溯、版本锁定 |
| 教材归档 | 教材入库、分类存储（按课程/领域/年份）、电子化存档、备份管理 |
| 课件审校流程 | 提交审校→初审→复审→定稿发布、审校意见记录、审校人指派 |
| 版权确认 | 版权声明登记、授权文件归档、版权有效期跟踪、使用限制标注 |
| 教材分发管理 | 分发范围设置（学员/讲师/内部）、分发记录追踪、下载权限控制 |
| 更新记录追踪 | 更新日志、变更内容摘要、更新通知推送、版本发布计划 |

## 输入

- **课件文件**：PPT/PDF/Word/视频等课件源文件
- **教材资料**：讲义、案例集、习题集、参考资料等
- **审校要求**：审校人员指派、审校截止日期、审校标准
- **版权信息**：版权归属方、授权范围、授权期限、使用限制说明
- **分发需求**：分发对象、分发方式、分发时间要求

## 工作流程

1. **教材入库**：上传课件/教材文件，填写元数据（课程、领域、版本号）
2. **版本登记**：自动或手动分配版本号，记录更新摘要
3. **版权确认**：登记版权归属和授权信息，标记版权状态
4. **审校流转**：分配审校人→初审（意见记录）→修订→复审→定稿发布
5. **教材归档**：定稿教材按分类规则存入教材库
6. **分发管理**：设定分发范围和权限，记录分发日志
7. **更新追溯**：维护版本更新日志，支持版本回溯比对

## 数据模型（教材记录）

每条教材记录包含：
- `id`：教材唯一编号
- `name`：教材名称
- `type`：课件/讲义/案例集/习题集/参考资料
- `course_id`：关联课程ID
- `file_path`：源文件存储路径
- `file_format`：文件格式（PPT/PDF/Word/视频等）
- `version`：当前版本号（如 v1.0、v2.0）
- `version_history`：版本历史（数组，含版本号/日期/更新摘要/文件路径）
- `copyright`：版权信息（归属方/授权范围/有效期/限制说明/授权文件路径）
- `review_status`：审校状态（待提交/初审中/需修订/复审中/已定稿）
- `review_records`：审校记录（数组，含审校人/轮次/意见/结论/日期）
- `distribution`：分发配置（分发范围/权限设置/分发链接）
- `distribute_log`：分发日志（数组，含分发对象/时间/方式/次数）
- `change_log`：更新日志（数组，含版本/日期/变更摘要/变更人）
- `status`：草稿/审校中/已定稿/已归档/已废弃
- `created_at`：入库日期
- `updated_at`：最后更新时间
