# 体彩筛选 Skill

体育彩票号码分析与数据参考工具。覆盖乐透数字型、竞猜型全部玩法，提供号码查询、条件筛选、走势图分析、历史数据统计全链路功能。

> ⚠️ **合规声明**：本工具仅供数据分析与学习研究使用，**不提供任何投注建议，不承诺中奖概率，不用于实际博彩行为**。所有输出内容均基于统计学原理，彩票开奖结果具有完全随机性，任何分析方法均无法预测开奖结果。请遵守《彩票管理条例》及相关法律法规，理性对待。

## 三、功能模块

### 3.1 历史数据查询

用户通过自然语言查询开奖数据，支持多种查询维度。

**查询方式**：

| 方式 | 说明 | 示例 |
|------|------|------|
| 按彩种查询 | 指定彩种的历史记录 | "查大乐透最近20期" |
| 按期号查询 | 指定期号结果 | "查大乐透第25001期" |
| 按日期查询 | 指定日期结果 | "查2026年6月开奖" |
| 多期对比 | 多期数据对比 | "对比近10期号码" |
| 历史同期 | 历年同期对比 | "历年同期开奖数据" |

**输出指标**：期号、开奖号码、和值、跨度、奇偶比、大小比、012路、奖池金额、中奖注数。

### 3.2 数据分析

对历史数据进行多维度统计分析，输出结构化报告。提供 `lottery_filter.py csv`（频率统计）和 `lottery_missing.py`（遗漏深度分析）两个命令行工具。

**分析维度**：

| 维度 | 说明 | 工具 |
|------|------|------|
| 号码频率 | 各号码出现次数排名 | `lottery_filter.py csv` |
| 遗漏分析 | 当前遗漏/最大遗漏/平均遗漏 | `lottery_missing.py` |
| 冷热分布 | 热号(≤5期)/温号(6-15期)/冷号(≥16期) | `lottery_missing.py` |
| 回补信号 | 遗漏超均值+标准差 → 关注反弹 | `lottery_missing.py` |
| 遗漏分布 | 冷/温/热各区数量+比例 | `lottery_missing.py` |
| 和值走势 | 均值/标准差/极值/区间分布 | — |
| 跨度走势 | 大/中/小跨度占比 | — |

### 3.3 条件筛选

支持对全部数字彩进行多条件组合过滤。用户以自然语言输入条件，AI 自动解析验证并生成满足条件的号码。提供 `lottery_kill.py` 进行多策略杀号缩减号码池。

**筛选条件速查**：

| 条件 | 适用彩种 | 说明 |
|------|---------|------|
| 奇偶比 | 全部数字彩 | 奇偶号码数量比 |
| 大小比 | 全部数字彩 | 大小号数量比 |
| 质合比 | 大乐透/排列3/5/七星彩 | 质数合数比 |
| 和值范围 | 全部数字彩 | 号码总和区间 |
| 跨度范围 | 全部数字彩 | 最大-最小值区间 |
| 连号 | 全部数字彩 | 相邻连续号码组数 |
| 重号 | 全部数字彩 | 与上期重复个数 |
| 冷热号 | 全部数字彩 | 冷/热号出现个数 |
| AC值 | 大乐透 | 复杂度指标范围 |
| 012路 | 全部数字彩 | 除3余数分布 |
| 定位 | 排列3/5/七星彩 | 每位号码范围 |
| 振幅 | 排列3/5/七星彩 | 同位置差值 |
| 区位分布 | 大乐透 | 一/二/三区出号数 |
| 尾数 | 大乐透/排列5 | 个位数分布 |
| 赔率 | 竞彩 | 赔率范围过滤 |
| 凯利指数 | 竞彩 | 投注价值过滤 |

**执行流程**：

```
用户输入条件 → 解析条件类型与适用彩种 → 验证条件自洽性
→ 生成号码池 → 逐条件过滤 → 统计满足注数 → 输出 TOP 参考
```

### 3.4 号码参考

根据用户偏好或默认设置，生成符合条件的号码组合。提供 `lottery_dan.py`（多策略定胆）和 `lottery_bet_gen.py`（复式全组合生成）两个辅助工具。

**参考逻辑**：
1. 彩种识别与条件收集
2. 候选号码池生成（随机/加权）
3. 条件过滤引擎逐层过滤
4. 遗漏值/冷热号加权排序
5. 按需输出指定注数

**输出模式**：

| 模式 | 说明 | 输出内容 |
|------|------|---------|
| 单式参考 | 符合条件的单注号码列表 | N注号码+条件说明 |
| 胆拖参考 | 指定胆码+拖码 | 胆码+拖码+组合注数 |
| 复式参考 | 指定号码池的全组合 | 号码池+注数+金额 |
| 杀号过滤 | 从号码池中剔除无效号码 | 原始池→剩余池+缩减率 |
| 综合参考 | 合并多策略胆码 | 热号/冷号/邻号/近期高频+综合 |

**输出格式**：

```
参考一：03 08 15 22 31 + 05 10   参考二：06 11 19 25 33 + 02 07
参考三：01 09 17 28 30 + 04 11

分析：奇偶比 3:2 | 大小比 2:3 | 和值 70-90 | 跨度 20-30
投注建议：单式5注，合计10元
```

### 3.5 号码核验

提供 `lottery_compare.py` 核对自选号码与官方开奖结果是否一致，精确到奖级。

| 彩种 | 核验方式 | 奖级识别 |
|------|---------|---------|
| 大乐透 | 前区5个+后区2个匹配 | 7个奖级(一等~七等) |
| 排列3 | 直选/组选3/组选6自动识别 | 按命中精度输出 |
| 排列5 | 5位精确匹配 | 全对=中奖 |
| 七星彩 | 7位精确匹配 | 全部一致=中奖 |

支持按指定期号核验或遍历全部历史数据。

### 3.6 概率计算

提供 `lottery_probability.py` 计算各彩种各奖级的精确中奖概率。

| 彩种 | 计算内容 |
|------|---------|
| 大乐透 | 7个奖级分别的概率 + 整体中奖率 |
| 排列3 | 直选/组选3/组选6 分别概率 |
| 排列5 | 直选概率 |
| 七星彩 | 一等奖~六等奖分别概率 |

### 3.7 数据管理

| 工具 | 功能 |
|------|------|
| `lottery_merge.py` | 合并多个CSV文件、去重、排序（混合彩种自动识别） |
| `lottery_report.py` | 生成 HTML 综合分析报告（频率/和值/跨度/冷热统计） |
| `validate_csv.py` | 校验 CSV 格式是否符合规范 |
| `generate_data.py` | 生成示例开奖数据（按实际开奖日） |
| `fetch_data.py` | 在线拉取历史数据（三源自动降级到本地生成） |

### 3.8 走势图

以文本/表格形式生成 9 种走势图，支持 10/20/30/50/100 期及历史同期周期。

**走势图类型**：

| # | 类型 | 适用彩种 | 核心内容 |
|---|------|---------|---------|
| 1 | 号码综合走势 | 全部数字彩 | 每期号码+和值+跨度+奇偶+大小+012路 |
| 2 | 和值走势 | 全部数字彩 | 和值变化曲线+区间分布+均值统计 |
| 3 | 跨度走势 | 全部数字彩 | 跨度变化+大/中/小占比 |
| 4 | 定位走势 | 排列3/5/七星彩 | 每位号码分布+振幅 |
| 5 | 冷热走势 | 全部数字彩 | 频率+遗漏+冷热状态+趋势 |
| 6 | 奇偶/大小形态 | 全部数字彩 | 形态比例变化+趋势 |
| 7 | 遗漏走势 | 全部数字彩 | 各号码遗漏值曲线+极值提示 |
| 8 | 区位分布 | 大乐透 | 三区出号分布+断区分析 |
| 9 | 后区走势 | 大乐透 | 后区号码+跨度+奇偶搭配 |

**走势图综合分析报告**：

综合多种走势图，输出结构化的分析结论，包含：和值/跨度趋势判断、冷热号分布与回补提示、区位参考、后区搭配建议、综合号码池参考。

### 3.9 完整工作流示例

以下展示从数据输入到分析到输出的全链路操作：

#### 示例：大乐透下期号码参考

```bash
# Step 1: 查看走势图（近10期综合走势）
python3 scripts/lottery_charts.py examples/dlt_sample.csv --type comprehensive --periods 10

# Step 2: 遗漏分析（冷热号 + 回补信号）
python3 scripts/lottery_missing.py examples/dlt_sample.csv --top 5

# Step 3: 定胆参考（多策略综合）
python3 scripts/lottery_dan.py examples/dlt_sample.csv --count 3

# Step 4: 杀号过滤（尾数 + 区间 + 分区）
python3 scripts/lottery_kill.py --pool 01-35 --kill-tail 0,1 --sections 5

# Step 5: 条件生成（奇偶3:2 + 和值80-110）
python3 scripts/lottery_filter.py generate --oe 3:2 --sum 80-110 --count 5

# Step 6: 概率说明
python3 scripts/lottery_probability.py --lottery 大乐透

# Step 7: 生成报告
python3 scripts/lottery_report.py examples/dlt_sample.csv -o report.html
```

#### 示例：排列3形态分析

```bash
# 定位走势
python3 scripts/lottery_charts.py examples/pl3_sample.csv --lottery 排列3 --type position --pos 0 --pos-name 百位

# 遗漏分析
python3 scripts/lottery_missing.py examples/pl3_sample.csv --lottery 排列3

# 形态生成（奇奇奇）
python3 scripts/lottery_filter.py generate --lottery 排列3 --oe-shape 奇奇奇 --count 5

# 定位复式
python3 scripts/lottery_bet_gen.py --lottery 排列3 --front "0,2,4,6,8/1,3,5,7,9/0,2,4,6,8"
```

#### 示例：历史数据管理

```bash
# 校验 CSV 格式
python3 scripts/validate_csv.py examples/dlt_sample.csv

# 合并多个 CSV
python3 scripts/lottery_merge.py csv1.csv csv2.csv -o merged.csv

# 核对自选号码是否中奖
python3 scripts/lottery_compare.py "05 12 19 26 33 + 03 10" -d examples/dlt_sample.csv
```

## 四、数据流

### 4.1 数据源说明

本工具**不内置实时抓取功能**，依赖用户提供或预先加载的开奖数据。

### 4.2 缓存策略

| 层级 | 说明 | 有效期 |
|------|------|--------|
| 会话缓存 | 用户当前对话中已提供的数据 | 会话结束 |
| 持久化缓存 | 用户可维护的 CSV 文件（见 4.3） | 文件更新 |

**策略说明**：
- 同一会话内重复查询同彩种不重复请求用户提供数据
- 用户可主动刷新数据：`更新大乐透数据到最新XX期`
- 数据格式遵循 4.3 节定义

### 4.3 CSV 格式定义

#### 乐透数字型 CSV

```csv
彩种,期号,开奖日期,号码1,号码2,号码3,号码4,号码5,号码6,号码7,奖池(亿),销量(亿)
大乐透,25001,2026-01-03,05,12,19,26,33,03,10,9.62,2.85
排列3,26158,2026-06-17,1,5,8,,,,
排列5,26158,2026-06-17,1,5,8,3,9,,
七星彩,26001,2026-01-02,3,8,1,5,9,2,6,,
```

**字段说明**：
- `彩种`：大乐透 / 排列3 / 排列5 / 七星彩
- `期号`：5-6 位数字
- `开奖日期`：YYYY-MM-DD
- `号码1~号码5`：前区（大乐透）/ 数字彩依次排列
- `号码6~号码7`：后区（大乐透）/ 第6-7位（七星彩）；数字彩该列为空
- `奖池(亿)` / `销量(亿)`：仅大乐透

#### 竞彩 CSV

```csv
彩种,日期,编号,主队,客队,主胜赔,平赔,客胜赔,让球,让球主胜,让球客胜,比分
竞彩足球,2026-06-17,001,主队A,客队B,1.85,3.40,3.75,0.5,1.60,2.20,2-0
```

**字段说明**：
- `让球`：让球数（负值为客让）
- `让球主胜/客胜`：让球后胜平负赔率
- `比分`：最终赛果

### 4.4 处理流程

```
[用户输入] → [自然语言解析] → [意图识别]
    ├─ 查询意图 → CSV 数据源 → 统计分析引擎 → 结果格式化 → 输出
    ├─ 筛选意图 → 条件解析器 → 条件验证 → 号码生成引擎 → 输出
    ├─ 走势意图 → 走势图引擎 → 图表示例生成 → 统计注释 → 输出
    ├─ 统计输出意图 → 加权随机发生器 → 条件过滤器 → 排序 → 输出
    └─ 走势意图 → 走势图引擎 → 图表示例生成 → 统计注释 → 输出
```

### 8.4 号码计算规则

**组合注数公式**：

| 类型 | 公式 |
|------|------|
| 前区复式 | C(n, 5)，n 为前区选号数 |
| 后区复式 | C(n, 2)，n 为后区选号数 |
| 双区复式 | C(n₁, 5) × C(n₂, 2) |
| 前区胆拖 | C(m, 5-k)，m 为拖码数，k 为胆码数 |
| 后区胆拖 | C(m, 2-k)，m 为拖码数，k 为胆码数 |

**概率计算**：

| 奖级 | 大乐透条件 | 概率 |
|------|-----------|------|
| 一等奖 | 5+2 | 1/21,425,712 |
| 二等奖 | 5+1 | 1/1,071,286 |
| 三等奖 | 5+0 / 4+2 | 1/476,127 |
| 四等奖 | 4+1 | 1/39,678 |
| 五等奖 | 4+0 / 3+2 | 1/6,613 |
| 六等奖 | 3+1 / 2+2 | 1/1,082 |
| 七等奖 | 3+0 / 2+1 / 1+2 / 0+2 | 1/55 |

### 8.5 输出格式保证

所有 CLI 脚本输出格式一致，固定为以下模板：

| 场景 | 输出结构 | 示例 |
|------|---------|------|
| 号码分析 | 彩种 → 号码 → 各维度指标逐行 | `前区: [5,12,19,26,33]` → `奇偶比: 3:2` → `和值: 95` |
| 号码参考 | `参考N: 号码` 格式，前缀固定 | `参考1: 03 08 15 22 31 + 05 10` |
| 组合注数 | 数量 + 金额 + 追加金额 | `注数: 18注  金额: 36元 (追加54元)` |
| 遗漏分析 | 冷号表+热号表+回补信号+分布 | 表格分隔，TOP N 可配置 |
| 杀号 | 原始池→各策略杀号明细→剩余池→缩减率 | 逐策略列出杀除号码 |
| 走势图 | 表头+分隔线+每期一行 | ASCII 表格，列宽固定 |

### 8.6 输入验证流

```
用户输入 → 格式校验 → 彩种识别 → 范围验证 → 条件自洽性检查 → 执行 → 输出
  ├─ 号码格式错误 → 提示正确格式 "05 12 19 26 33 + 03 10"
  ├─ 号码超范围 → 提示彩种号码范围（大乐透前区01-35 后区01-12）
  ├─ 条件自相矛盾 → 提示矛盾原因并建议放宽条件
  └─ 数据不足 → 提示当前数据量并输出基于已有数据的分析
```

### 8.7 可靠性设计

| 场景 | 处理方式 |
|------|---------|
| CSV 缺少字段 | 仅处理可用字段，缺失字段提示日志 |
| 号码类型不匹配 | validate_csv.py 自动校验类型和范围 |
| 竞彩/数字彩混排 | lottery_merge.py 自动识别彩种字段差异 |
| 无数据 | 输出引导模板，提示用户提供数据 |
| 条件无满足结果 | 提示"当前条件无满足组合"，给出当前数据分布帮助用户放宽 |
| 注数过多 | 超过 `--max` 限制时只统计不生成明细，避免输出爆炸 |

### 8.8 术语表

| 术语 | 英文 | 说明 |
|------|------|------|
| 彩种 | Lottery Type | 体育彩票的具体种类（大乐透、排列3等） |

| 奇偶比 | Odd/Even Ratio | 奇数号码与偶数号码的数量比 |

| 质合比 | Prime/Composite Ratio | 质数与合数的数量比 |

| 单注 | Single Bet | 基本投注单位（2元） |
| 追加 | Additional Bet | 大乐透+1元追加投注（浮动奖+80%） |
| 杀号 | Number Killing | 通过策略排除不可能出现的号码 |
| 回补信号 | Rebound Signal | 遗漏值超过均值+标准差，可能回调 |
| 振幅 | Amplitude | 同位置相邻两期的号码差值 |
