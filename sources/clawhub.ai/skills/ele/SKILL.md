# 饿了么 Skill

饿了么是阿里本地生活旗下外卖平台，与美团外卖构成双寡头。
本 skill 覆盖用户侧省钱决策与商家侧运营基础。

## 用户侧：点外卖的省钱决策逻辑

优惠叠加顺序（同类只能选一，异类可叠加）：

```
店铺满减/折扣  →  店铺券/商品券  →  平台红包  →  会员红包
（店铺承担）      （店铺承担）      （平台承担）   （会员权益）
```

- **吃货豆/超级吃货卡（会员体系）**：高频用户（月 ≥ 8 单）通常回本，
  低频用户先领免费红包再决定，不要看到会员就买
- **凑满减陷阱**：为凑满减多点 10 元菜实际优惠 5 元是负收益，
  按"实付/实际想吃的东西"算才是真价格
- **时段红包**：下午茶/夜宵时段常有大额平台券，非饭点需求可等时段
- **比价习惯**：同店铺美团/饿了么价格与券力度常不同，大额订单两边
  都看一眼（各平台独立定价与补贴）

## 履约规则速查

- **准时宝**：付费/会员赠送的超时赔付服务，按超时时长阶梯赔红包——
  雨雪天、高峰期下单前看一眼是否可加
- **超时/餐损处理**：App 内"订单-申请售后"通道，餐洒/错漏拍照留证，
  平台介入通常按责赔付
- 骑手申请"报备"（商家出餐慢等）会顺延承诺时间，此时超时赔付
  按顺延后时间算

## 商家侧运营基础

- **入驻**：营业执照+食品经营许可证是硬门槛，入驻免费，
  抽佣按品类/配送模式不同（自配送费率低于平台配送）
- **排名逻辑**（方法论层面）：转化率、复购率、评分、出餐时效都
  进权重——刷单提排名是封店高危操作，做好出餐速度和差评响应
  是性价比最高的优化
- **开放平台**：open.shop.ele.me 面向商家系统对接（订单回流 ERP、
  门店管理），需要签约商家身份，个人开发者无公开 API
- **蜂鸟配送**：即时配送开放能力，电商/零售同城配可接入

## Agent 典型用法

1. **下单省钱助手**：用户报订单构成 → 按叠加逻辑算最优组合，
   提醒凑单陷阱
2. **会员划算性测算**：`月单量 × 单均红包 vs 会员费`，给买/不买建议
3. **售后指导**：超时/餐损场景给出申请路径与举证要点
4. **商家咨询**：入驻材料清单、佣金结构解读、排名优化优先级排序

## 本 skill 不做什么

- 具体佣金费率、会员价格、红包面额随城市与活动变化，一律以 App
  实时展示为准，不报死数字
- 不提供刷单、刷好评、薅羊毛漏洞等违规方法
- 外卖 CPS 推广（返利）另有生态，此处不展开
