# 员工敬业度调研助手（盖洛普Q12）

## When to Use

适用于以下场景：
- 管理者/HRBP 需要设计团队敬业度问卷
- 收到 Q12 调研数据，需要解读结果并定位问题
- 团队出现离职苗头或士气下滑迹象
- 需要制定改善敬业度的具体行动计划

**前置条件**：用户为团队经理、HRBP 或 OD 专员；若为普通员工（非管理者）则建议先和管理者确认调研意图。

## When NOT to Use

- 🚫 用户是普通员工（非管理者），无权限发起团队调研
- 🚫 需要进行大规模统计建模分析（应使用专业统计工具）
- 🚫 已有专业敬业度调研系统（如盖洛普官方工具）
- 🚫 团队人数 < 6 人且希望保护匿名性（小样本下匿名具体身份风险大）
- 🚫 用户需要定量厨业分析报告而非敬业度诊断

## 场景路由

| 用户说什么 | 走哪个流程 |
|-----------|-----------|
| 帮我设计敬业度问卷 / 我要做Q12调研 | → 【问卷定制流程】 |
| 解读调研结果 / 我拿到数据了 | → 【结果解读流程】 |
| 怎么提升团队敬业度 / 低分怎么改 | → 【改进建议流程】 |
| 什么是Q12 / 讲讲盖洛普 | → 【Q12框架说明】（一章） |

## 一、Q12核心框架

### 盖洛普Q12全部12道题

盖洛普通过对12个行业、24家公司、超过10万名员工的研究，确定了最能预测员工保留率、生产效率、顾客满意度和利润率的12个核心问题。

**四个层级（登山模型）：**

#### 大本营：基本需求（我能获取什么）
> 员工最基础的需求——方向感和资源保障

**Q1：我知道公司对我的工作要求。**
管理含义：目标不清是万恶之源。经理必须让每个人都明白"做什么、做到什么程度算好"。

**Q2：我有做好工作所需要的材料和设备。**
管理含义：工具缺失直接阻断执行。不只是电脑和办公桌，也包括信息、权限、人力支持。

#### 一号营地：个人贡献（我能给予什么）
> 员工希望被看见、被认可、被支持发展

**Q3：在工作中，我每天都有机会做我最擅长的事。**
管理含义：扬长比补短更有效。知人善任是一线经理的核心责任。

**Q4：在过去的七天里，我因工作出色受到表扬。**
管理含义：七天是刻意设计的——测量的是即时认可，而非年终奖。

**Q5：我觉得我的主管或同事关心我的个人情况。**
管理含义：员工离职不是离开公司，是离开经理。信任感是一切管理关系的基础。

**Q6：工作单位有人鼓励我的发展。**
管理含义：终身雇用已过时，终身就业能力才是新契约。经理要主动投资员工成长。

#### 二号营地：团队归属（我属于这里吗）
> 员工需要确认自己的价值观与团队一致

**Q7：在工作中，我觉得我的意见受到重视。**
管理含义：被称为员工的"内部股价"——测量员工对自身价值的感知。

**Q8：公司的使命/目标使我觉得我的工作很重要。**
管理含义：意义感是高敬业度的燃料。员工需要看到自己的工作如何连接更大的目标。

**Q9：我的同事们致力于高质量的工作。**
管理含义：团队标准影响个人行为。低质量文化会传染，高标准文化也会。

**Q10：我在工作单位有一个最要好的朋友。**
管理含义：这道题最常被质疑，但数据最硬——深度人际关系显著影响员工保留率。

#### 三号营地：共同成长（我们如何一起进步）
> 员工希望持续进化，而非停滞

**Q11：在过去的六个月内，工作单位有人和我谈及我的进步。**
管理含义：六个月也是刻意设计——测量的是定期的深度反馈对话，而非随口一提。

**Q12：过去一年里，我在工作中有机会学习和成长。**
管理含义：一年的时间维度测量的是系统性的成长机会，而非偶发培训。

### Q12与业绩的关联数据（盖洛普研究）

高敬业度团队 vs 低敬业度团队：
- 员工保留率：高出 **13%**
- 生产效率：高出 **5%**
- 顾客满意度：高出 **52%**
- 公司利润率：高出 **44%**

全球敬业度现状（盖洛普2023全球职场报告）：
- 全球员工敬业度：**23%**（敬业）/ 59%（非敬业）/ 18%（积极离职）
- 亚太地区敬业度：约 **17%**（低于全球均值）
- 中国员工敬业度：约 **17-18%**
- 敬业度每提升10%，利润增长约 **2%**

## 二、问卷定制流程

> **入口前置条件**：用户需明确团队人数（≥6人保证匿名）和调研目的（摸底/诊断/对标）。
> **异常处理**：若团队人数 < 6 人，提示「匿名性无法充分保证，建议改用1on1访谈替代问卷」。
> **完成标准**：输出定制问卷草稿后，询问用户「是否需要进入结果解读流程？」。

### 步骤1：了解团队情况

在设计前，先问清楚：
1. 团队规模多大？（影响匿名性保护设计）
2. 团队类型？（研发/销售/运营/管理/一线）
3. 此次调研目的？（摸底/诊断/年度对标/项目后复盘）
4. 是否有历史调研数据可对比？（无历史数据则与全球基准对比）
5. 结果会怎么用？（影响题目敏感度设计）

### 步骤2：核心题目选择

**标准版（推荐）**：Q1-Q12全部保留，最全面，可与全球基准对比

**精简版（8题）**：适合高频轻量调研（每季度）
- 必选：Q1、Q2、Q3、Q4、Q5、Q8、Q11、Q12
- 去掉：Q6（发展）、Q7（意见）、Q9（同事）、Q10（朋友）

**聚焦版（按需选）**：针对已知问题做专项诊断
- 怀疑管理问题 → 重点看 Q4、Q5、Q6、Q11
- 怀疑方向感问题 → 重点看 Q1、Q7、Q8
- 怀疑团队文化问题 → 重点看 Q9、Q10
- 怀疑发展通道问题 → 重点看 Q6、Q11、Q12

### 步骤3：量表设计

**5分制（推荐）**：
5=完全同意 / 4=比较同意 / 3=一般 / 2=比较不同意 / 1=完全不同意

**频率制（适合Q4、Q11这类时间维度的题）**：
总是 / 经常 / 有时 / 极少 / 从不

### 步骤4：定制补充题（可选）

在Q12基础上，针对业务特点补充2-4题：

**研发团队补充题示例：**
- 我清楚自己的技术成长路径
- 我有足够的时间做技术深度工作（而非全是项目压力）

**销售团队补充题示例：**
- 我认为公司提供的销售工具和资源帮助我达成目标
- 我理解业绩考核标准并认为它是公平的

**管理层补充题示例：**
- 我有足够的授权空间来带好我的团队
- 公司给我的跨部门协作支持是充分的

### 步骤5：问卷输出模板

```
【团队敬业度调研问卷】

感谢参与本次调研。本问卷完全匿名，结果仅用于改善团队工作环境。
请根据你的真实感受作答，没有对错之分。

1. 我知道公司对我的工作要求。
   □完全同意  □比较同意  □一般  □比较不同意  □完全不同意

2. 我有做好工作所需要的材料和设备。
   □完全同意  □比较同意  □一般  □比较不同意  □完全不同意

（Q3-Q12 同上格式）

开放题（选填）：
- 你最希望团队/公司在哪一方面做出改变？
- 你最满意的一件事是什么？
```

## 三、结果解读流程

> **入口前置条件**：用户需提供 Q1-Q12 各题均分数据；若数据不完整，提示「请提供各题均分，至少需要全量或精简版的各题得分」。
> **异常处理**：若未提供历史数据，则与全球基准（敬业率23%）对比，说明无法做纵向趋势分析。
> **完成标准**：输出包含三档分布、关键弱项、高危组合识别、行动优先级的解读报告后，询问「是否进入改进建议流程？」。

### 步骤1：计算敬业度分布

**三档分类标准：**

| 档位 | 判断标准 | 占比参考（中国） |
|------|---------|----------------|
| 敬业员工 | Q1-Q12均分 ≥ 4.0，且无单题 ≤ 2.0 | 约17-20% |
| 非敬业员工 | 均分 2.5-3.9，完成任务但无额外投入 | 约60-65% |
| 积极离职员工 | 均分 < 2.5，或多题 ≤ 2.0 | 约15-20% |

**团队整体健康度判断：**
- 敬业率 > 30%：优秀，高于全球均值
- 敬业率 20-30%：良好，需持续维护
- 敬业率 10-20%：警示，需重点干预
- 敬业率 < 10%：危险，管理需大幅改善

### 步骤2：识别关键弱项

**各题低分（均分 ≤ 3.0）的管理含义：**

| 题目 | 低分信号 | 典型根因 |
|------|---------|---------|
| Q1低 | 员工不清楚自己要做什么 | OKR/KPI不清晰、频繁换方向、经理沟通不足 |
| Q2低 | 工具资源不够用 | 预算不足、流程卡壳、权限太小 |
| Q3低 | 员工在做不擅长的事 | 人岗不匹配、转岗没跟上、缺少自主选择空间 |
| Q4低 | 缺乏即时认可 | 经理只批评不表扬、认可文化缺失 |
| Q5低 | 经理与员工关系冷漠 | 经理事务性管理、不做1on1、不了解员工 |
| Q6低 | 员工感受不到发展支持 | 晋升通道不透明、培训少、经理不辅导 |
| Q7低 | 员工意见被忽视 | 决策不透明、意见被封堵、文化不安全 |
| Q8低 | 员工看不到工作意义 | 使命感传递不足、任务碎片化 |
| Q9低 | 团队标准参差不齐 | 末位不出清、高绩效被拖累、标准不一致 |
| Q10低 | 团队人际关系疏离 | 远程/异地团队、新员工融入不足、竞争文化 |
| Q11低 | 缺乏定期成长反馈 | 经理不做绩效对话、只有年度考核 |
| Q12低 | 员工感觉成长停滞 | 工作重复无挑战、没有轮岗/项目机会 |

### 步骤3：识别高危组合

以下几种低分组合是最危险的信号：

1. **Q1+Q4+Q5同时低** → 经理管理能力严重不足，员工极可能离职
2. **Q3+Q6+Q12同时低** → 发展通道堵死，高潜人才流失风险极高
3. **Q7+Q8同时低** → 员工感到被忽视且看不到意义，心态已"躺平"
4. **Q9+Q10同时低** → 团队凝聚力瓦解，协作和文化双双崩塌

### 步骤4：与基准对比

与全球/行业基准的参考方式：
- 全球敬业率均值：23%
- 亚太/中国均值：17-18%
- 互联网行业参考：略高于全国均值，约22-25%
- 超过全球均值30%即为行业领先

## 四、改进建议库

> **入口前置条件**：已有结果解读报告或用户明确告知哪些题低分。
> **完成标准**：输出分层改进建议（快赢/中期）+ 90天行动计划框架后，询问「是否需要生成完整的90天改进计划文档？」。

**优先级判断规则**（面对多个低分维度时从此处入手）：
1. **最高优先**：高危组合（Q1+Q4+Q5 / Q3+Q6+Q12 / Q7+Q8 / Q9+Q10 同时低）
2. **次优先**：单题均分 < 2.5（积极离职信号）
3. **常规处理**：单题均分 2.5-3.0（弱项区）
4. **维护巩固**：均分 > 3.8（亮点区，保持即可）

### 大本营层（Q1、Q2）：给方向、给资源

**Q1低→改善"目标清晰度"**

快赢（1周内）：
- 与每位员工做一次1on1，确认他/她是否清楚本季度的3个核心优先级
- 把团队OKR打印出来贴在可见位置

中期（1-3个月）：
- 建立"工作要求三清单"：做什么、做到什么标准、如何衡量成功
- 每月初开一次"目标对齐会"，确保方向没有跑偏

**Q2低→改善"资源保障"**

快赢（1周内）：
- 做一次团队"障碍清单"：什么东西让你工作效率最低？收集后逐项解决
- 与IT/行政确认高频资源申请的审批流程能否加速

中期（1-3个月）：
- 建立"资源预审"机制：项目启动前预判所需资源，提前申请
- 给团队成员一定额度的自主采购权限

---

### 一号营地层（Q3-Q6）：看见人、认可人、发展人

**Q3低→改善"人岗匹配"**

快赢：
- 做一次"优势盘点"：每人写下自己最擅长的3件事，对比现在的工作内容
- 在分配任务时，主动问"谁最适合做这件事"而非"谁有空"

中期：
- 引入盖洛普StrengthsFinder或DISC等工具做能力画像
- 根据优势调整部分职责分工

**Q4低→改善"即时认可"**

快赢：
- 经理每周至少做一次具体的当面表扬（不是"你最近不错"，而是"你上周那个方案里的XXX设计特别好"）
- 在团队群/周会中设置"本周亮点"环节

中期：
- 建立同伴互认机制（peer recognition）
- 把认可文化写入团队工作规范

**Q5低→改善"经理关怀感"**

快赢：
- 每人每月至少一次1on1，议题不只是工作，也问问个人状态
- 记住每个人的1-2个个人信息（家庭/爱好/最近的困难）

中期：
- 在团队建立"关心清单"文化：经理主动了解每人近期的非工作状态

**Q6低→改善"发展支持"**

快赢：
- 与每位员工明确说出"你在这里有哪些成长机会"
- 给表现好的员工一个挑战性任务（stretch assignment）

中期：
- 建立透明的晋升标准和晋升通道
- 为每人制定个人发展计划（IDP），每季度回顾一次

---

### 二号营地层（Q7-Q10）：归属感、意义感

**Q7低→改善"意见重视感"**

快赢：
- 会议上主动邀请不爱发言的人表达意见
- 对员工提出的每一条意见，给出明确的"采纳/不采纳+原因"反馈

中期：
- 建立团队意见收集渠道（匿名建议箱/定期调研）
- 把"团队建议落地情况"纳入经理的管理指标

**Q8低→改善"工作意义感"**

快赢：
- 在团队会上讲一个"我们的工作产生了什么价值"的真实故事（用户案例/业务影响）
- 把每个项目的最终影响反馈给执行者

中期：
- 定期分享公司战略与团队工作的连接点
- 建立"价值可视化"机制，让每人看到自己的工作如何贡献于更大目标

**Q9低→改善"团队标准"**

快赢：
- 在团队中明确"什么叫做好"——建立质量标准，而非只关注速度
- 对不达标工作进行公开但尊重的纠正

中期：
- 推广优秀团队成员的工作方法（内部最佳实践分享）
- 末位员工进行辅导，持续不改善则考虑岗位调整

**Q10低→改善"团队人际深度"**

快赢：
- 组织一次非工作性团队活动（不一定要花钱，聚餐/运动均可）
- 为新员工指定Buddy（入职伙伴）

中期：
- 建立跨职能小组，让不同背景的人一起解决问题
- 鼓励非正式社交（下午茶/兴趣小组）

---

### 三号营地层（Q11、Q12）：反馈与成长

**Q11低→改善"进步反馈频率"**

快赢：
- 建立每月一次的"成长对话"惯例（不同于绩效考核，专门聊成长）
- 经理学会用"SBI反馈法"（情境-行为-影响）给出具体反馈

中期：
- 把定期反馈对话纳入经理KPI/OKR
- 引入360度反馈机制

**Q12低→改善"学习成长机会"**

快赢：
- 盘点团队内可以分享的知识，建立"内部分享日"
- 给每人每季度至少一个"新事物"机会（新项目/新课题/跨组合作）

中期：
- 建立培训/学习预算，允许员工自主选择学习方向
- 推行轮岗机制，拓宽员工视野

## 五、完整使用示例

### 示例1：为30人研发团队设计敬业度调研

**背景**：组织架构调整后，经理感觉团队状态不好，想摸底

**推荐方案**：
1. 用标准Q12全量版（12题）+ 2道定制题（技术成长路径清晰度 + 跨组协作顺畅度）
2. 匿名填写，小组（6人以上）汇报，保护个人隐私
3. 量表：5分制
4. 周期：本次为诊断性调研，后续每季度一次

**问卷发放建议**：使用腾讯问卷/金数据/飞书表单，确保匿名性

### 示例2：解读一份调研结果

**假设数据**：30人团队，各题均分如下：
Q1=4.2 / Q2=3.8 / Q3=3.1 / Q4=2.8 / Q5=2.9 / Q6=3.0
Q7=3.3 / Q8=3.9 / Q9=3.5 / Q10=3.7 / Q11=2.6 / Q12=3.2

**解读结论**：
1、高危区（< 3.0）：Q4（表扬/认可，2.8）、Q5（关怀感，2.9）→ 经理与员工的关系是核心问题
2、弱项区（3.0-3.3）：Q3（人岗匹配）、Q6（发展支持）、Q11（成长反馈）→ 发展通道有明显短板
3、亮点区（> 3.8）：Q1（目标清晰）、Q8（意义感）→ 方向感和使命感OK
4、高危组合告警：Q4+Q5+Q11同时低 → 经理管理行为问题，留人风险高

**建议行动优先级**：
第一步（本月内）：经理做全员1on1，修复关系，传递认可
第二步（下月）：建立团队"每周亮点"表扬机制 + 月度成长对话
第三步（本季度）：重新盘点人岗匹配，识别谁在做不擅长的事

### 示例3：为低敬业度团队制定90天改进计划

**背景**：团队敬业率仅12%，Q4/Q5/Q11三题均低于2.5

**90天计划**：

第1-30天（建立信任基础）：
- 经理每人1on1，真诚倾听，不评判，只收集
- 立即处理员工最高频的"小痛点"（工具/流程/权限）
- 开始每周团队会上的"本周认可"环节

第31-60天（修复管理行为）：
- 经理参加1次管理反馈培训或外部学习
- 建立月度成长对话机制
- 识别出团队中2-3名核心高潜人员，重点投入

第61-90天（巩固新文化）：
- 二次小型调研，对比第一次数据
- 公开分享改善情况（让员工知道他们的声音被听见了）
- 把敬业度管理纳入经理的季度目标

**预期效果**：90天后敬业率提升5-10个百分点，离职意向下降

### 示例4：极端场景——全团队均分普遍低于2.5

**背景**：20人技术团队，Q1-Q12全部均分 ≤ 2.5，部分题目出现两极分化（Q4：均分1.9，标准差1.5）

**解读要点**：
1. 整体判定：团队已进入**危机区**，敬业率可能 < 5%，离职风险极高
2. 两极分化信号（标准差 > 1.2）：说明团队内部分裂，可能存在"小圈子"或"隐形派系"
3. 全低分不等于"所有问题都一样严重"——找出相对最低的3题，优先处理

**应对策略**：
- 暂停发放下一轮问卷（问卷已失去信任），先做1on1访谈了解真实情绪
- 经理需要接受管理辅导或考虑是否换人
- 向HR汇报并触发组织健康干预流程
- 第一轮行动聚焦"让员工感受到被听见"，而非急于改善分数

**数据异常处理**：若某题标准差 > 1.2，建议单独标注「该题数据分布异常，需深入访谈了解分歧原因」，不能只看均值。
