# 证券之星-基金评级 Skill

```bash
PYTHON=python3.12
FUND=scripts/cli.py
```

通过自然语言查询公募基金评级数据，数据来源证券之星，覆盖上海证券、国泰海通、银河证券、招商证券、晨星、济安金信、天相投顾七家评级机构。

## 适用场景

用户提到以下内容时触发本 Skill：

- **基金评级查询**："查一下XX基金的评级"、"XX基金几星"、"XX基金评级如何"
- **基金评分详情**："XX基金的晨星评级"、"XX基金的上海证券评级"

## 核心约束

1. **数据真实性** — 禁止编造评级数据，必须从证券之星真实页面返回中提取
2. **查询方式** — 支持基金代码（6 位数字）或基金名称查询，名称支持精确匹配和子串匹配；若匹配多只基金则返回列表让用户确认
3. **缓存机制** — 首次查询约需 3 秒并行下载全量评级数据，后续查询秒回
4. **请求方式** — 使用 Python 脚本 `scripts/cli.py`（通过 `$PYTHON $FUND` 调用），统一加 `--json` 参数获取 JSON 输出
5. **输出格式** — 脚本输出 JSON，AI 负责组织语言呈现给用户，不直接输出 JSON 原文
6. **评级格式** — 每家机构输出数字评级（1-5）、文字评级（一星~五星）、星级图案（★~★★★★★）

## 脚本命令

```bash
$PYTHON $FUND query <fund_code_or_name> --json    # 查询基金评级（支持代码或名称）
```

脚本返回 JSON 后，AI 按场景组织语言，不要把整段 JSON 原样输出给用户。

## 工作流

### 流程 1：查询基金评级

**步骤：**
1. 调用 `$PYTHON $FUND query <fund_code_or_name> --json`（支持基金代码或名称）
2. 解析返回 JSON，提取每家机构的评级信息
3. 用中文向用户总结，展示基金名称、代码、七家机构的星级评级

**输出要点：**
七家机构 JSON 返回的字段：
- `fund_name` / `fund_code` — 基金名称和代码
- `ratings.{机构名}.status` — 评级状态（"rated" 已评级 / "unrated" 未评级）
- `ratings.{机构名}.rating` — 数字评级（1-5）
- `ratings.{机构名}.rating_text` — 文字评级（一星~五星）
- `ratings.{机构名}.rating_stars` — 星级图案（★~★★★★★）
- `ratings.{机构名}.rating_date` — 评级日期

## 异常处理

| 异常 | 处理方式 |
|------|---------|
| 基金代码/名称不存在 | 返回 "未找到该基金的评级数据" |
| 基金名称匹配多只基金 | 返回基金列表，引导用户使用基金代码查询 |
| 首次查询 | 提示 "正在初始化数据，请稍候..." |
| 缓存更新 | 自动检测评级日期变化，静默更新 |
