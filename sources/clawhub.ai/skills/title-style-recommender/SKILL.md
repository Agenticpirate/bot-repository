# Title Style Recommendation - 标题风格推荐

## 功能说明

根据研究类型和内容，推荐最合适的标题表达方式。

## 研究类型与推荐模板

### 1. 概念研究 / 理论框架

**特征**：发展或验证理论框架、概念模型

**推荐模板**：

```
The X: Conceptual Framework and Supporting Evidence
```

```
Development and Validation of a Conceptual Framework for X
```

```
X: A Theoretical Model of Y
```

**示例**：
```
Self-Determination Theory: A Framework for Understanding Intrinsic Motivation
The Technology Acceptance Model:扩展与应用
```

### 2. 实证研究 / 变量关系

**特征**：检验变量间关系、干预效果

**推荐模板**：

```
X Improves Y
```

```
X Predicts Y Through Z
```

```
The Effect of X on Y: A [研究设计] Study
```

**示例**：
```
Exercise Improves Cognitive Function in Older Adults
Social Media Use Predicts Sleep Quality Through Emotional Regulation
The Effect of Mindfulness Training on Stress Reduction: A Randomized Controlled Trial
```

### 3. 探究性研究 / 验证性研究

**特征**：探索性问题、验证假设

**推荐模板**：

```
Does X Work?
```

```
Can X Reduce Y?
```

```
What is the Role of X in Y?
```

**示例**：
```
Does Social Media Use Cause Depression in Adolescents?
Can Cognitive Behavioral Therapy Reduce Test Anxiety?
What is the Relationship Between Sleep and Academic Performance?
```

### 4. 方法论研究

**特征**：开发或验证测量工具、方法

**推荐模板**：

```
Development and Validation of [测量工具]
```

```
A New Method for [测量/分析] X
```

```
Testing the Reliability and Validity of [工具]
```

**示例**：
```
Development and Validation of the Social Media Addiction Scale
A New Method for Analyzing Big Data in Healthcare
```

### 5. 综述 / 元分析

**特征**：综合已有研究

**推荐模板**：

```
A Meta-Analytic Review of X
```

```
X: A Systematic Review of the Literature
```

```
The Effects of X on Y: A Comprehensive Review
```

**示例**：
```
Social Media and Mental Health: A Meta-Analytic Review
Exercise and Depression: A Systematic Review of Randomized Controlled Trials
```

### 6. 纵向/追踪研究

**特征**：随时间变化的研究

**推荐模板**：

```
X Predicts Y Over Time: A [时间] Follow-Up Study
```

```
The Long-Term Effects of X on Y
```

**示例**：
```
Childhood Adversity Predicts Adult Depression: A 20-Year Follow-Up Study
The Long-Term Effects of Early Childhood Education on Adult Outcomes
```

## 选择建议

| 研究类型 | 推荐结构 | 原因 |
|---------|---------|------|
| 理论构建 | 概念型 | 强调理论贡献 |
| 实证检验 | 关系型/发现型 | 突出研究发现 |
| 探索发现 | 问题型 | 突出研究问题 |
| 方法创新 | 方法型 | 突出方法学贡献 |
| 文献综合 | 综述型 | 明确研究性质 |

## 输出格式

请提供：
1. **研究类型判断**：根据内容判断属于哪类研究
2. **推荐模板**：提供2-3个可用的标题模板
3. **示例标题**：根据用户研究内容生成示例
4. **注意事项**：该类型标题的特殊要求
