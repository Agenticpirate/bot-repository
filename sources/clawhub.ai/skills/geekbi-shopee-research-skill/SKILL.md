# 极鲸云 Shopee 数据分析与市场调研

## 总体原则

- 将本 Skill 作为 Shopee 数据研究的统一入口，按用户问题路由商品、店铺和类目能力。
- 只使用极鲸云真实返回的数据。区分原始字段、可复算指标与经营判断。
- 默认使用简体中文和绝对日期；保留站点、币种、筛选条件、分页范围、样本量和更新时间。
- `daySold`、`monthSold`、`totalSales` 等是极鲸云采集或计算指标，不称为 Shopee Seller Centre 官方数据；`0`、缺失值和异常跳变先标为待核实。
- 当前数据没有成本、平台佣金、达人佣金、广告费、履约费、退货率和税费，不能直接给出利润结论。
- 面向用户使用中文业务名称，不展示脚本命令、英文参数或原始 JSON；开发对接或故障排查除外。
- 服务端因登录或可恢复条件要求暂停时，按 [查询暂停与恢复流程](references/查询暂停与恢复流程.md) 处理。

## 执行流程

1. 明确决策问题、目标站点、商品或类目边界、时间口径和硬性条件。指定市场时先运行 `scripts/shopee_site_list.py` 实时解析；未指定市场才使用服务端默认 `siteId=1`，不能推断它对应哪个国家。
2. 只读取当前主能力对应文档，生成最小必要条件。
3. 商品搜索运行 `scripts/shopee_goods_search.py`；已有商品 ID 时运行 `scripts/shopee_goods_info.py` 获取详情、最多近 31 条历史和关联店铺。
4. 店铺详情运行 `scripts/shopee_mall_info.py`。研究该店商品时，把店铺 ID 作为商品关键词搜索，并只保留 `mallId` 完全相同的结果。
5. 类目从 `parentCatId=0` 开始运行 `scripts/shopee_category_list.py` 逐层下钻；用 `scripts/shopee_category_info.py` 核验父链，再把可信 `catId` 交给商品搜索。
6. 检查响应、站点、币种、分页、缺失字段、更新时间和可比性。商品接口最多访问前 200 条；未覆盖全部命中时明确称为样本。
7. 输出结论、口径、证据、风险与下一步验证。简单查询保持简洁。

## Shopee 特有口径

- `goodsId`、`mallId` 是数据中的商品与店铺标识；接口没有提供商品或店铺前台链接时，不自行拼接 URL。
- `likedCount`、评分、评论数和销量是不同信号；点赞或内容热度不等于订单转化，不能据单一字段判断爆品。
- `isCross` 是采集数据中的跨境标记；缺失时不猜本土或跨境，且不能代替卖家资质判断。
- 当前数据没有自然/广告流量、搜索量、转化率、退货率、订单和评论正文，不能包装成完整竞争度或消费者洞察。
- 热销商品不等于低竞争；Shopee 选品还需验证供货、跨境准入、履约、退货风险、知识产权和类目资质。
- 涉及实际上架或推广前，核验目标站点最新禁售/限售、商品信息、履约、评价和内容政策。

## 输出要求

默认顺序：一句话结论；数据口径；关键证据；机会与风险；下一步验证。

每次写清“第几页/前 N 条/总命中上限”和数据更新时间。接口未返回链接时只展示商品名与 ID，不输出猜测链接。缺失字段显示 `-` 或“未返回”，不得用估算填充。
