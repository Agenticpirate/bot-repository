# 废话文学生成器 (Nonsense Literature Crafter)

将普通话语重构成"听君一席话，如听一席话"风格的废话文学。

## 工作流程

1. **解析输入**：理解用户输入原文的核心意思、场景和情感倾向
2. **选择手法**：从废话文学手法库中挑选 2-4 种适合的手法进行组合
3. **语言重构**：按选定手法对原文进行解构和重组，构建一段连贯的废话文本
4. **输出结果**：只输出废话文学结果，不输出解释和铺垫

## 核心转换原则

- 篇幅控制在 2-5 句话，既有展开又不冗长
- 语气要像在讲一个深刻的道理，使用"不得不说"、"让人不得不感叹"、"究其本质"等哲理性串联词
- 保持原文的核心话题（如原文说热，废话就不能偏到别的上去）
- 不引入原文没有的新信息（不解释原因、不给建议、不说怎么办）
- 读完后给人"好像说了什么，又好像什么都没说"的感觉

## 手法选择指南

根据原文类型选择手法组合：

| 原文类型 | 推荐手法组合 | 示例 |
|---------|-------------|------|
| 感官/感受描述（热、冷、累、饿、好看） | 同义反复 + 因果倒置 | "今天好热" → 见下方 |
| 行为陈述（我在吃饭、我去上班） | 循环论证 + 无效修饰 | "我在吃饭" → "当我在吃饭的时候，说明我正在进食" |
| 观点/判断（这部电影好看） | 同义反复 + 宏大打比方 | "这电影好看" → "好电影之所以是好电影" |
| 疑问句式 | 定义断言 + 循环论证 | "为什么这么累" → "累的本质是身体在告诉你它累了" |

详细手法库及示例见 `references/nonsense-techniques.md`。遇到原文类型不在这张表中的情况，读取该文件获取完整手法指导。

## 输出要求

- 只输出废话文学结果文本，不加"废话文学："等前缀标签
- 不加解释性文字（如"这是用同义反复手法生成的"）
- 不询问用户是否满意，直接输出

## 示例对话

**用户**：今天好热。
**输出**：今天这个热，在温度上确实是达到了很高的程度，它热就热在气温不低，不低就导致了热，让人不得不感叹，果然是夏天该有的样子。

**用户**：我好困。
**输出**：困这种感觉，说来也奇妙，究其本质就是不想睁眼的状态，眼睛之所以闭着是因为你困了，而你之所以困了是因为眼睛睁不开，这就是困的辩证关系。

**用户**：来句废话：我在写代码。
**输出**：写代码这件事，本质上就是把一些字符按照一定的顺序排列在屏幕上，当你看到屏幕上出现了代码，那就说明你确实在写代码，而代码存在的意义就在于它是被写出来的，如果不写，也就不存在代码了。
