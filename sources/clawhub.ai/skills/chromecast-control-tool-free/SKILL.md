## 场景介绍
### 场景一：投屏在线视频
将在线视频投屏到电视上观看.
```bash
# 发现设备
catt scan
# ...
# 投屏YouTube视频
catt cast "https://www.youtube.com/watch?v=dQw4w9WgXcQ"
# ...
# 指定设备投屏
catt -d "Living Room" cast "https://www.youtube.com/watch?v=dQw4w9WgXcQ"
```
### 场景二：投屏本地文件
将本地视频或音频文件投屏到电视.
```bash
# 投屏本地视频文件
catt cast "./movie.mp4"
# ...
# 投屏本地音频文件
catt cast "./music.mp3"
# ...
# 投屏本地图片
catt cast "./photo.jpg"
```
### 场景三：播放控制
控制当前投屏内容的播放.
```bash
# 暂停播放
catt pause
# ...
# 继续播放
catt play
# ...
# 停止播放
catt stop
# ...
# 快进30秒
catt seek 30
# ...
# 快退30秒
catt seek -30
# ...
# 跳转到指定位置（秒）
catt seek 120
# ...
# 调整音量（0-100）
catt volume 50
# ...
# 音量增加
catt volumeup
# ...
# 音量减小
catt volumedown
# ...
# 静音
catt volumemute
```

2. **设备名称**：使用易读的设备名称，便于多设备区分
3. **视频格式**：推荐使用MP4格式，兼容性优秀

## 边界与约束
### 输入限制
- **设备发现**：技能仅支持在同一局域网内的Chromecast设备发现，不支持跨网络或远程设备。
- **视频格式**：对于本地视频投屏，技能仅支持MP4、MKV、AVI等常见视频格式，不支持其他格式如MOV、WMV等。
- **文件大小**：对于本地文件投屏，单个文件大小限制取决于Chromecast设备的存储空间和网络带宽。
- **URL限制**：在线视频投屏支持YouTube、Bilibili等主流视频网站，但对于某些需要额外配置或代理的网站可能不支持。
### 性能边界
- **并发控制**：技能不支持同时控制多个Chromecast设备，每次操作只能针对一个设备。
- **响应时间**：技能的响应时间受限于网络延迟和Chromecast设备的处理速度，对于复杂的操作可能需要较长时间。
### 兼容性约束
- **操作系统**：技能在Windows、macOS和Linux操作系统上运行，但不支持其他操作系统。
- **Python版本**：技能要求Python版本为3.7及以上，不支持更早的版本。
- **Chromecast设备**：技能支持所有版本的Chromecast设备，但某些功能可能因设备型号而有所不同。
### 其他限制
- **免费版功能限制**：免费版不支持播放队列、高级音频编解码与均衡器调节等功能。
- **网络稳定性**：技能对网络稳定性要求较高，网络不稳定可能导致操作失败或延迟。

## 错误管理机制
针对投屏控制免费版使用中可能遇到的常见问题,提供以下排查方案:

| 错误类型 | 原因分析 | 解决方案 |
|---------|---------|---------|
| API认证失败(401) | API密钥错误或过期 | 检查密钥配置,重新生成token |
| 接口限流(429) | 请求频率超出限制 | 降低调用频率,启用重试退避策略 |
| 响应超时(504) | 网络延迟或服务端负载过高 | 增加超时阈值,检查网络连接 |
| 文件不存在 | 路径错误或文件未创建 | 检查路径拼写,确认文件已生成 |
| 文件格式不支持 | 扩展名不在支持列表中 | 转换为支持的格式后重试 |
| 权限不足 | 当前用户无读写权限 | 检查文件权限,以管理员身份运行 |
| 命令执行失败 | 参数错误或环境依赖缺失 | 检查命令语法,确认依赖已安装 |
| 进程超时 | 命令执行时间过长 | 增加超时设置,优化命令参数 |
| 网络连接失败 | DNS解析失败或防火墙拦截 | 检查网络配置,确认代理设置 |

### 投屏控制免费版通用排查步骤

1. **检查输入参数**: 确认所有必填参数已提供且格式正确
2. **查看日志输出**: 定位具体错误行和异常类型
3. **验证环境配置**: 确认依赖库版本和运行环境满足要求
4. **逐步调试**: 缩小问题范围,隔离故障模块
