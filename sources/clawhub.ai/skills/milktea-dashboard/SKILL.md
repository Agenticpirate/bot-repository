# 奶茶运营看板 Skill

## 概述

奶茶店运营数据看板，自动生成 **日报/周报**、**原材料库存预警**、**销售趋势分析**。通过绑定店铺数据源，AI 在每个营业周期末自动产出结构化运营报告，并主动推送原材料补货提醒。

## 适用场景

- 每日/每周闭店后自动生成运营报告
- 原材料库存低于安全水位时主动预警
- 销售趋势异常（暴增/暴跌）自动提醒
- 新品/爆品分析，指导备货和营销

## 前置依赖

| 项目 | 说明 |
|------|------|
| 数据源 | 店铺 POS / ERP API 或本地 CSV/JSON 数据文件 |
| 定时任务 | OpenClaw cron 定时触发日报/周报 |
| 推送渠道 | 支持 OpenClaw message 的渠道（电报/微信/QQ/站内） |

## 数据格式约定

### 销售数据 (sales.json)

```json
[
  {
    "date": "2026-07-28",
    "items": [
      {"name": "珍珠奶茶", "qty": 58, "price": 15, "cost": 5},
      {"name": "杨枝甘露", "qty": 32, "price": 22, "cost": 8}
    ],
    "total_revenue": 1560.0,
    "total_cost": 480.0,
    "order_count": 72
  }
]
```

### 原材料库存 (inventory.json)

```json
[
  {
    "name": "珍珠",
    "unit": "kg",
    "stock": 5.0,
    "safe_level": 10.0,
    "daily_consumption_avg": 3.5,
    "lead_time_days": 2,
    "expiry_days": 7,
    "purchase_date": "2026-07-25"
  }
]
```

### 店铺配置 (shop_config.json)

```json
{
  "shop_name": "茶语时光 · 中山路店",
  "operating_hours": "10:00-22:00",
  "cost_center": ["原料", "包装", "人工", "水电", "房租"],
  "alert_channels": ["lightclawbot"],
  "report_recipient": "100025544027",
  "week_start_day": 1
}
```

## 工作流

### 1. 日报生成

**触发方式**：每日 23:30 cron 定时任务

**执行流程**：
1. 读取当日 sales.json 和 inventory.json
2. 计算关键指标：
   - 当日营收、成本、毛利、毛利率
   - 客单价 = 营收 / 订单数
   - 单品销量 TOP 5
   - 销量环比昨日变化
3. 检查原材料库存水位
4. 生成结构化日报 Markdown

**输出示例**：

```
📊 茶语时光 · 中山路店 | 日报 2026-07-28
━━━━━━━━━━━━━━━━━━━━━━━━━
📈 经营概览
  营收: 1560.00 (↑12.3% vs 昨日)
  成本: 480.00 (毛利率 69.2%)
  订单: 72 单
  客单价: 21.67

🥤 热销 TOP 5
  1. 珍珠奶茶    58杯  870  37.2%
  2. 杨枝甘露    32杯  704  30.1%
  3. 柠檬绿茶    28杯  364  15.6%
  4. 芋泥波波    21杯  315  13.5%
  5. 芒果冰沙     9杯   81   3.5%

⚠️ 原材料预警
  🔴 珍珠: 库存 5.0kg < 安全库存 10.0kg (预计1.4天后耗尽, 补货需2天)
  🟡 鲜奶: 库存 12L < 安全库存 20L (预计3天后耗尽)
  ✅ 其他原料库存正常

💡 运营建议
  - 珍珠库存告急，建议今晚下单补货
  - 杨枝甘露销量环比上升28%，可适量增加备料
```

### 2. 周报生成

**触发方式**：每周一 09:00 cron 定时任务

**执行流程**：
1. 聚合过去7天 sales.json 数据
2. 计算周度指标：
   - 周营收、成本、毛利、毛利率
   - 日均营收、日均订单
   - 环比上周变化
   - 单品总销量和排名变化
   - 每日趋势
3. 原材料周消耗统计
4. 生成周报 Markdown

### 3. 原材料预警（独立触发）

**触发方式**：
- 日报/周报生成时自动检查
- 通过 cron 定时单独检查（每2小时）
- 销售产生时实时检查（可选）

**预警级别**：

| 级别 | 条件 | 动作 |
|------|------|------|
| 紧急 | stock < safe_level | 立即推送 + 建议采购量 |
| 注意 | stock < safe_level x 1.5 | 日报/周报中提示 |
| 正常 | stock >= safe_level x 1.5 | 无动作 |

**自动采购建议算法**：
建议采购量 = (safe_level - stock) + daily_consumption_avg x lead_time_days

### 4. 趋势异常检测

日报/周报生成时自动检测异常：
- 销量骤降：单品日销量 < 近7天日均 x 0.5
- 销量飙升：单品日销量 > 近7天日均 x 2.0
- 毛利率异常：毛利率 < 55% 或 > 85%
- 库存加速消耗：日消耗 > 近7天日均 x 1.5

## 部署步骤

### Step 1: 准备数据文件

将 sales.json、inventory.json、shop_config.json 放在 workspace 约定路径。

### Step 2: 设置定时任务

```bash
# 日报 - 每日 23:30
openclaw cron add --name "奶茶日报" \
  --schedule "cron:30 23 * * *" \
  --tz "Asia/Shanghai" \
  --agentTurn "生成奶茶运营日报" \
  --announce

# 周报 - 每周一 09:00
openclaw cron add --name "奶茶周报" \
  --schedule "cron:0 9 * * 1" \
  --tz "Asia/Shanghai" \
  --agentTurn "生成奶茶运营周报" \
  --announce

# 库存检查 - 每2小时营业时段
openclaw cron add --name "奶茶库存检查" \
  --schedule "cron:0 10-22/2 * * *" \
  --tz "Asia/Shanghai" \
  --agentTurn "检查奶茶店原材料库存预警" \
  --announce
```

### Step 3: 使用指令

```
生成奶茶运营日报
生成奶茶运营周报
检查奶茶店原材料库存预警
手动更新库存数据
```

## 扩展方向

- 多店对比：多个店铺数据源生成对比看板
- 可视化图表：用 canvas 或 diagram-maker 生成营收趋势图
- 采购单自动生成：预警触发后自动生成采购清单
- 天气关联分析：结合天气 API 分析天气影响
- 员工排班优化：根据客流量预测排班
- 会员数据分析：结合会员系统分析复购率

## 数据安全

- 店铺数据文件仅存储在本地 workspace，不外传
- 预警推送通过 OpenClaw message 加密通道
- 不涉及第三方数据上传
