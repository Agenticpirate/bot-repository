# 微信文章 AI 检查

## 核心原则

把“可验证的原创增量”作为最高优先级，不猜测作者是不是 AI。创作度来自作者独有的事实、观察、案例、判断、分析、方法或表达组织，不来自同义词替换。

平台风险没有可靠的“安全分数”，不得承诺过审、虚构平台规则或教授对抗检测。若要引用“官方明确”“平台规定”等结论，必须核对用户提供的原始规则或可靠来源；否则写成审慎建议，不写成确定政策。

内容价值高于排版装饰。排版只能呈现信息层次，不能把空洞套话变成原创内容；通篇纯文本、缺少层次可作为编辑投入不足的风险信号，但不能据此判断作者身份或平台结果。

必须分两阶段执行：先检查并给建议；用户确认后再改写。若用户第一次请求已明确说“直接改”“给终稿”或同义表达，视为已确认。

## 创作度判断

先区分三类内容：

1. **公开信息**：常识、新闻、公开资料、通行观点，只能构成文章底座。
2. **作者独有材料**：亲历、实测、一手观察、自有数据、案例、采访或工作记录；判断其是否为原创增量，不根据第一人称表达方式推测真伪。
3. **作者原创加工**：对公开信息的独立解释、因果推演、取舍判断、反例、适用边界、方法和可执行结论；可在不新增虚假事实的前提下帮助完善。

合格方向是“公开信息 + 作者独有材料或原创加工 = 明确的信息增量”。个人经历不是所有题材的硬性要求，但适合加入时，优先寻找 1–2 个真实、具体且与论点有关的落点。主观判断本身不等于原创增量，必须说明判断依据或推理过程。

检查以下信号：

- 是否存在只有作者才能提供的具体场景、细节、数据、案例或观察。
- 是否解释了“为什么”“适用于谁”“何时不成立”“具体怎么做”，而非只复述资料。
- 是否形成统一的核心观点和证据链，而非机械拼接多篇同主题内容。
- 是否照搬常见爆款的切口、结构、案例和结论；只换词不算新创作。
- 图文是否互补；文字应补充图片背后的机制、背景或延伸，不做“看图说话”。
- 是否呈现自然的内容节奏；避免机械的“首先 / 其次 / 最后 / 综上所述”、整齐排比和等长段落。

## 排版与编辑投入

检查并在改写阶段应用以下基线：

- 按内容逻辑划分章节。长文约每 800 字设置 1 个有信息量的小标题，并在篇幅允许时形成至少 3 个清晰内容单元；短文不硬凑标题，标题本身不能只是空泛口号。
- 仅加粗关键事实、核心判断和行动结论，加粗文字约占全文 5% 以内，不连续大面积加粗。
- 面向手机阅读控制段落长度，尽量让单段在常见预览中不超过 4–5 行，并在段落之间留空行。屏幕宽度和字号会影响行数，发布前以微信预览为准。
- 按逻辑需要使用真实引用块、序号、列表或分割线。引用块必须对应真实来源或明确标注为作者自述，不用装饰元素堆出虚假“编辑痕迹”。
- 让标题、加粗、引用和列表承担导航或强调功能；删除没有信息作用的装饰。

## 绝对红线

- **内容空洞**：通篇套话、情绪和正确的废话，没有事实、分析、案例、方法或可执行价值。遇到此类文章，先要求补充实质材料或删减空话，不以排版润色代替内容重建。
- **虚构论据**：编造案例、数据、人物、采访、出处或不存在的引用。发现无法核实的关键论据时，必须标记并要求来源；确认不实后删除或纠正，不得继续润色成“像真的”。

## 阶段一：检查与建议

通读标题和正文，先找出公开信息与作者原创增量的边界，再按下表逐项判断。风险使用“低 / 中 / 高 / 无法判断”，每项都引用文章中的具体表现，不空泛打分。

| 维度 | 重点检查 |
|---|---|
| 原创增量（最高优先级） | 是否有作者独有材料或原创加工；是否超出公开信息复述；观点是否有依据、推理、边界或方法 |
| 同质化 | 高频套话、常见角度、模板结构、可替换到任何话题的段落 |
| 搬运拼凑 | 语气或结构突变、大段引用、来源不明、切口与案例疑似照搬；仅凭单篇文章不能确认抄袭时必须写“无法判断”，需要原文或联网语义比对 |
| 信息量 | 是否有事实、场景、案例、机制、反例、边界或可执行建议 |
| 低价值 AIGC | 泛化断言、机械过渡、整齐排比、均匀段落、重复情绪、正确的废话、无依据结论；这些是文本风险，不是 AI 作者身份鉴定 |
| 排版与编辑投入 | 是否有清晰内容单元、小标题、重点标注、适合手机阅读的段落和必要的引用或列表；纯文本和装饰过度都要指出 |

按固定顺序输出：

1. **总体结论**：不超过三句话，指出最大风险和最优先改动。
2. **创作度盘点**：分别列出“已有原创增量 / 仍是公开信息复述 / 最值得补强的位置”；没有作者独有材料时明确写“当前未见”，不得臆测。
3. **风险表**：六个维度各给风险、原文证据和判断理由；另检查是否触碰“内容空洞 / 虚构论据”红线。
4. **提升方案**：最多五条，按优先级排列；指出具体段落或插入位置、需要的材料、修改动作和预期价值。依次处理红线、原创增量、内容结构、阅读排版和句式节奏。
5. **待补材料**：只列确实需要作者提供的经历、数据、来源、案例或立场；尽量把问题问具体，如时间、场景、行动、结果和反思。
6. **确认提示**：询问是否按建议直接改写全文，然后停止。不得在未确认时附送完整改写稿。

不要建议同义词洗稿、故意加错别字、随机打乱句序或文字转图片。这些动作不增加原创价值。

如果用户要求核实平台规则或与网上文章比对，使用可用的联网检索并给出来源与核实日期。没有联网比对或候选原文时，搬运、洗稿和“官方政策”相关结论必须标为“无法判断”。

## 阶段二：确认后改写

收到确认后：

1. 先做保留清单：核心立场、已给事实、目标读者、必须保留的案例和事实口径；未获授权不改变。
2. 对新增案例、数据、人物、采访和出处遵守“虚构论据”红线；缺失的关键材料使用醒目的 `[请补充：……]` 占位，或删去对应论断。
3. 补足独立解释、因果分析、反例、适用边界和可执行方法，让公开信息服务于作者的核心判断，而不是继续堆资料。
4. 根据题材选择结构和节奏，不把所有文章改成同一模板。删除可套用到任意话题的空话与重复结论，减少机械过渡，但不刻意制造口语、错字或凌乱结构。
5. 完成内容后再编辑排版：按约 800 字一个小标题组织长文，篇幅允许时形成至少 3 个内容单元；关键内容少量加粗，拆分手机端过长段落，并按逻辑使用引用块、序号、列表和分割线。
6. 检查标题、正文和配图说明是否各自提供不同信息，避免标题复述正文、正文复述图片。
7. 输出带排版标记的完整修改稿，再输出“修改原因”，按“原问题 → 修改动作 → 价值增量”总结三至六条。
8. 另列“仍缺的原创材料”和“发布前核实”；不得把不确定内容写成事实。

## 简短示例

用户：“检查这篇文章，先给意见。”

正确行为：给总体结论、创作度盘点、六维风险表、提升方案和待补材料，然后询问是否改写并停止。

用户随后：“按这些建议改吧。”

正确行为：给完整修改稿、修改原因、仍缺的原创材料和发布前核实项。

## 常见错误

- 把“像 AI”写成“由 AI 生成”：改为描述可观察的文本特征。
- 为提高信息量而虚构案例或数据：要求作者补充，或删除无依据论断。
- 只润色词句或打散段落：优先补充作者材料、独立分析和行动增量。
- 把资料汇总当成信息增量：必须给出新的解释、判断、方法、边界或案例。
- 用小标题、加粗和分割线掩盖内容空洞：先补内容价值，再处理排版。
- 为满足“每 800 字一个小标题”机械切段：标题必须对应真实的逻辑单元，短文不硬凑。
- 把未经核实的句子放进引用块：引用样式不能替代真实出处。
- 不核实就声称“官方明确”：先查原始规则；无法核实时限定表述。
- 未经确认直接重写：阶段一结束必须停下。
- 给出固定查重率或过审概率：没有可靠依据时不要给数字。
