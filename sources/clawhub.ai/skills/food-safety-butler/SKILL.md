## 三、详细使用方法

### 3.1 如何触发

**说人话就能触发**，例如：
- "明天市场监管局来查，后厨墩布池有点堵"
- "新店厨房布局图帮我审一下，怕过不了"
- "顾客吃到头发了，怎么处理合法？"
- "我们 1200 家店，做个集团食安体系体检"

| 触发场景 | 触发词示例 | 走哪层 |
|---|---|---|
| 日常自查 / 办证 | 食安检查、迎检、办证、后厨布局、健康证、食品经营许可证 | v1 |
| 单店合规审计 | HACCP、GB 31654、食安审计、差距分析、ATP、温度记录 | v2 |
| 集团体系 / 舆情 / 飞行检查 | 集团食安审计、合规体系升级、客诉溯源、飞行检查、供应商准入、舆情风险 | v3 |

> 判定原则：含"全集团 / 全国 / 体系 / 千店"等聚合字眼 → 走集团版；仅单店数据 → 走 Pro 审计；日常自查 / 办证 → 走 v1。

### 3.2 两种输入方式

**方式 A：自然语言（推荐，零门槛）**
直接描述场景即可，系统自动映射到对应字段，缺失项标注"未提供 / N/A"，不臆造。

**方式 B：结构化 JSON（精确审计用）**
适合已有测温 / ATP / 台账系统的门店导出数据，粘贴即可出报告。

### 3.3 分场景使用流程

**场景 A — 日常自查（红黄绿）**
1. 说明场景（如"今天市场监管局要来"）。
2. 系统按六维度（人员 / 食材 / 加工 / 环境 / 消毒 / 公示）扫描。
3. 输出 🟢安全区 / 🟡预警区 / 🔴危险区 三色清单 + 专家建议。

**场景 B — 办证 & 后厨布局**
1. 提交新店厨房平面 / 设备 / 动线图，或描述业态（热食 / 冷食 / 饮品）。
2. 系统按"核名 → 报图 → 装修 → 现场核查 → 领证"四步导航，对照水池 / 墙面地面 / 三防 / 专间要点给整改。
3. 输出流程图 + 布局合规要点 + 常见驳回→整改 + 迎检话术。

**场景 C — Pro 单店审计（HACCP + GB 31654）**
1. 粘贴温度 / ATP / 健康证 / 溯源 JSON。
2. 系统应用 HACCP 七大原理，逐项比对 GB 31654-2021 条款，做微生物风险评估。
3. 输出四段式报告：审计结论 / 详细发现表（含条款号）/ CAPA 纠正措施 / HACCP 计划摘要。

**场景 D — 集团风控体检**
1. 粘贴集团级 JSON（门店总数、成熟度、违规史、数字化覆盖、供应商黑白名单、溯源率）。
2. 系统做成熟度评级、系统性风险识别、风险传导测算、HACCP 落地审核、客诉溯源。
3. 输出五段式《集团食安中心通报》：成熟度报告 / 系统性风险表 / HACCP 审计 / 突发事件预案 / 集团执行指令。

**场景 E — 客诉 / 打假应对**
1. 描述事件（如"顾客吃到头发""职业打假人上门"）。
2. 系统给接待话术、赔偿边界（《食安法》第 148 条）、证据固定清单、对内动作。

### 3.4 输出样例（从业者视角片段）

> **🟡 预警区**：墩布池堵塞——易污水倒灌、滋生细菌。立即疏通，检查期间确保地面干燥。
> **🟢 安全区**：主动亮出晨检本、进货台账、员工口罩佩戴。
> **💡 专家建议**：检查员先看公示栏再查后厨，安排专人陪走指定路线，别乱开无关柜门。

（集团版则输出五段式《食安中心通报》：成熟度报告 / 系统性风险表 / HACCP 审计 / 突发事件预案 / 集团执行指令。）

## 五、注意事项（必读）

### 5.1 红线（严禁）
- **绝不**教伪造健康证、篡改保质期、隐瞒实情、伪造台账等违规动作。
- 所有整改可**合法落地**，目标是"过检 + 避罚"，不是钻空子。

### 5.2 地域差异
- 各地对专间面积、水池数量、布局细节要求不同，须以**属地市场监管所（食药所）**口径为准。
- 本 Skill 采用行业通用底线（冷藏 ≤8℃、冷冻 ≤-12℃、烹饪 ≥70℃、热藏 ≥60℃、ATP <200 RLU），若标签 / 属地更严从其规定。

### 5.3 使用边界
- **能做的**：把法规变成可执行的清单、流程、话术、差距报告与执行指令。
- **不能做的**：替代官方行政检查、出具法律意见、替你做行政决策。
- **不虚构**：本 Skill 专注食安合规 / HACCP / 集团风控，**不含**订单处理、员工排班、菜品管理等运营系统功能。

### 5.4 免责声明
本 Skill 提供合规建议与差距分析，**不能替代官方监管部门的行政检查**，不承担因用户实际经营或违规操作导致的任何法律责任。
