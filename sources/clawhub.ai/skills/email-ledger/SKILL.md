# 报备邮件台账登记工具

将 .eml 邮件文件（zip压缩包或目录）自动解析为标准报备邮件台账 Excel，一键完成登记。支持基于现有台账模板追加新记录、自动去重。

## 适用场景

- 用户发送了报备邮件的 zip 压缩包，要求整理登记
- 用户要求按报备邮件台账字段完成邮件登记
- 用户需要将多封 .eml 邮件批量整理为台账
- 用户提供了现有台账 xlsx，要求追加新邮件记录
- 用户提到"报备台账"、"邮件台账"、"报备登记"、"整理邮件"等关键词

## 核心工作流

### Step 1：确认输入

用户通常会随消息发送邮件附件（zip压缩包），有时还会提供现有台账模板。

识别以下输入：
- **邮件文件**：zip压缩包或包含 .eml 文件的目录路径（必填）
- **台账模板**：现有的 .xlsx 台账文件（可选，用于追加记录或保持格式一致）

> 如果用户同时发送了 zip 和 xlsx 文件，xlsx 视为已有台账，新解析的记录将追加到其中（按邮件主题去重）。

### Step 2：运行解析脚本

```bash
python3 <skill_dir>/scripts/parse_emails.py \
  --input '<邮件zip或目录路径>' \
  --output '<输出xlsx路径>' \
  [--template '<已有台账xlsx路径>']
```

参数说明：
- `--input / -i`：必填，邮件zip压缩包或包含eml文件的目录
- `--output / -o`：必填，输出的Excel台账路径
- `--template / -t`：可选，已有台账xlsx。提供时，脚本会读取其中的记录，将新解析结果追加（按邮件主题去重），保留原有格式

脚本会自动完成：
1. 解压zip并扫描所有 .eml 文件
2. 逐封解析：提取发送时间、发件人、主题、收件人、抄送人
3. 智能分类报备类型（14种类型自动识别）
4. 提取供应商/渠道名称
5. 生成主要事由摘要（200字内）
6. 识别审批人
7. 如有模板，合并去重后输出
8. 按时间排序，生成格式化Excel台账（首行冻结、自动筛选、待补充标黄）

### Step 3：上传并提供下载

使用 uploader 技能上传生成的 xlsx 文件：

```bash
python3 <uploader_skill_dir>/scripts/upload_media.py '<输出xlsx路径>'
```

将返回的 downloadUrl 提供给用户。

### Step 4：结果汇报

向用户汇报：
- 共解析邮件数量
- 报备类型分布统计
- 如有模板，说明合并情况（新增N条、已有N条）
- 如有待补充项（供应商名称/审批人无法自动识别），提醒用户（Excel中已标黄）

## 台账字段

| 字段 | 说明 | 提取方式 |
|------|------|----------|
| 发送时间 | 邮件发送时间 | 邮件Date头 |
| 发件人 | 姓名(邮箱前缀) | 邮件From头 |
| 邮件主题 | 完整主题 | 邮件Subject头 |
| 收件人 | 姓名(邮箱前缀)列表 | 邮件To头 |
| 抄送人 | 姓名(邮箱前缀)列表 | 邮件Cc头 |
| 报备类型 | 智能分类 | 主题+正文关键词匹配 |
| 供应商/渠道 | 供应商或渠道 | 场地类→渠道，其他→供应商 |
| 供应商/渠道名称 | 具体公司/场地名 | 主题+正文正则提取 |
| 主要事由 | 200字内摘要 | 正文核心内容 |
| 审批人 | 审批负责人 | 主题/正文/收件人推断 |

## 报备类型

脚本支持以下 14 种报备类型的自动识别：

- 商务结果报备
- 阳光承诺书免签申请
- 指定供应商申请
- 新增简易供应商/阳光承诺书特批
- 白名单申请
- 授权自采申请
- 费用变更报备
- 特殊入库报备
- 供应商新增审批
- 审批类报备
- 采购方式报备
- 采购申请
- 一般报备
- 其他报备

## 去重规则

当提供已有台账模板时，按 **邮件主题 + 发送时间** 进行去重：
- 主题完全相同且发送时间一致的邮件视为重复，不重复录入
- 新记录追加到已有记录之后
- 最终按发送时间统一排序

## 标黄提示

以下情况会在 Excel 中标黄，提示用户人工补充：
- 供应商/渠道名称无法从邮件中自动提取 → 显示"（需补充）"并标黄
- 审批人无法从邮件中自动推断 → 显示"（需补充）"并标黄

## 注意事项

- 解析仅提取邮件正文主内容，自动去除原始邮件引用（-----原始邮件-----）和签名部分
- 如果邮件主题模式有新增，可在脚本的 `CATEGORY_PATTERNS` 列表中添加匹配规则
- 输出文件默认命名：`报备邮件台账_已登记.xlsx`，保存在 workspace 目录
- 如用户未指定输出路径，使用默认路径并告知用户
