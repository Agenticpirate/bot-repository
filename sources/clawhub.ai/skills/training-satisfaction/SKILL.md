# 培训满意度管理

> 输出为参考建议，具体整改措施由主理人确认后推进执行。

## 能力概述

培训满意度全链路管理，从问卷设计到改进闭环的全流程覆盖：

| 模块 | 核心内容 |
|------|---------|
| 问卷设计 | 多维评价体系（课程内容/讲师授课/组织服务/场地设施）、题型配置（评分/单选/多选/开放式）、NPS评分题嵌入 |
| 发放回收 | 问卷自动发放（邮件/系统消息/二维码）、回收进度跟踪、催填提醒、匿名保障 |
| 统计分析 | 自动汇总评分、NPS计算与等级评定、词云生成、改进建议聚类、优秀/待改进项识别 |
| 趋势追踪 | 历史满意度趋势曲线、各维度对比分析、同期对比、异常波动预警 |
| 改进闭环 | 问题项识别→责任人指派→整改方案→整改验证→满意度复测 |

## 输入

- **培训记录信息**：培训名称、期次、日期、讲师、课程内容等
- **参训学员名单**：学员姓名、联系方式、部门
- **问卷配置要求**：评价维度、题型偏好、评分量表标准（如1-5分/1-10分）
- **历史满意度数据**：往期满意度评分、历史NPS趋势、改进项完成情况

## 工作流程

1. **问卷设计**：根据培训类型配置评价维度和题型，嵌入NPS评分题，生成问卷模板
2. **问卷发放与回收**：培训结束后自动/手动发放，跟踪回收率，定时催填
3. **数据汇总分析**：回收截止后自动统计，计算各维度均分和NPS，生成词云与聚类分析
4. **报告生成**：输出满意度分析报告（含评分、NPS、词云、改进建议）
5. **改进闭环管理**：识别关键问题→指派责任人→制定整改方案→跟踪执行→复测验证
6. **趋势存档**：将本期数据归入历史趋势库，更新满意度变化曲线

## 数据模型（满意度记录）

每条满意度调查记录包含：
- `id`：调查唯一ID
- `training_session_id`：关联培训期次ID
- `training_name`：培训名称
- `survey_date`：调查时间范围
- `total_trainees`：参训总人数
- `responses`：回收答卷数
- `response_rate`：回收率
- `dimensions`：各维度评分（数组）
  - `name`：维度名称（课程/讲师/组织/场地）
  - `avg_score`：平均分
  - `nps`：NPS评分
  - `rating`：等级评定
- `overall_score`：综合评分
- `overall_nps`：综合NPS
- `wordcloud_hot`：正面高频词
- `wordcloud_cold`：待改进高频词
- `improvements`：改进项（数组）
  - `issue`：问题描述
  - `source_dimension`：来源维度
  - `assignee`：责任人
  - `action`：整改措施
  - `deadline`：整改截止日期
  - `status`：待处理/整改中/已验证
  - `verified_date`：验证日期
- `trend_data`：历史趋势数据引用
