# 供应商信息整理技能

根据用户提供的供应商资料（WORD/PDF/Excel），提取关键信息并结构化整理为质量管理档案。支持 Markdown 输出，可调用 Python 脚本生成 SVG 组织架构图和 Word 文档。

## 触发条件

当用户提到以下关键词时激活本技能：
- 供应商档案、供应商信息整理
- 供应商管理、合格供方名录
- 来料质量管理、供应商审核准备
- 整理供应商资料、生成供应商档案

## 能力边界

### 输入格式支持
| 格式 | 支持程度 | 说明 |
|------|---------|------|
| WORD (.docx) | 完整支持 | 可提取表格和段落 |
| Excel (.xlsx) | 支持 | 需用户指定关键列 |
| PDF（文本型） | 支持 | 可提取文本 |
| PDF（扫描型） | 有限支持 | 需先 OCR 或手动录入 |
| 纯文本/Markdown | 完整支持 | 直接读取 |

### 最低信息要求
生成基本档案至少需要：
- 供应商名称
- 主要产品/服务
- 一种联系方式

### 不支持的功能
- 自动从互联网搜索供应商信息
- 多供应商横向对比分析（需分别生成后手动对比）
- 供应商绩效评分（需用户提供评分维度和标准）

## 执行流程

### 阶段 1：信息提取
根据用户提供的资料类型选择提取方法：
- WORD/Markdown：直接读取，重点提取表格中的关键字段
- Excel：识别关键列（供应商名称、产品、联系人、认证等）
- PDF：提取文本后人工复核关键信息

### 阶段 2：信息结构化
按以下模板整理供应商档案：

1. **基本信息**：名称、地址、统一社会信用代码、成立时间
2. **联系方式**：联系人、电话、邮箱、网址
3. **产品/服务范围**：主要产品、年产能、主要客户
4. **质量认证**：ISO 9001、IATF 16949、ISO 13485 等
5. **组织架构**（可选）：若有数据可调用 `scripts/generate_org_chart.py` 生成 SVG
6. **合作记录**（可选）：首次合作时间、最近审核日期、审核结果

### 阶段 3：档案生成
1. 生成 Markdown 格式档案
2. 若用户需要 Word 格式：调用 `scripts/convert_to_docx.py` 转换为 .docx
3. 若用户提供组织架构数据：调用 `scripts/generate_org_chart.py` 生成 SVG 图

### 阶段 4：质量检查
- [ ] 所有"[需补充]"字段是否已标注
- [ ] 联系方式格式是否统一
- [ ] 若生成了 SVG 图，是否已嵌入文档
- [ ] 认证编号格式是否正确（如 ISO 9001:2015）

## 异常处理

### 脚本执行失败
- 若 `python-docx` 未安装：提示安装命令或提供纯 Markdown 输出作为替代
- 若 `PIL/Pillow` 未安装：SVG 生成失败时，提供文本版组织架构描述
- 若 Python 环境不可用：提供手动整理指导，仅输出 Markdown 格式

### 输入格式问题
- 若用户提供扫描版 PDF：提示先使用 OCR 处理，或提供关键信息手工录入
- 若信息不完整：生成部分档案并标注"[需补充]"字段
- 若 Excel 列名不规范：列出识别到的列名让用户确认映射关系

### 输出格式问题
- 若 Word 格式排版不理想：同时提供 Markdown 原文件供手动调整
- 若 SVG 图过大：提供缩放建议或分页处理
