# 多平台内容检测&安全改写

## 概述

对任意中文文本执行三维一体的合规检查，输出结构化的检查报告 + 可直接发布的合规版本。三个维度独立运行，覆盖从法律合规到内容质量的全链路。

## 触发条件

### 主动触发（用户明确提出检查请求）

当用户提出以下类型请求时触发：
- "帮我检查这段内容/文案"
- "这段文字有没有违反广告法"
- "帮我去AI味"
- "这个文案能发到小红书/抖音/微信公众号吗"
- "审一下这篇稿子"
- "检查内容合规性"
- "这段文字有没有问题"
- 任何涉及内容审查、广告法、平台规范、AI痕迹检测的请求

### 不自动触发

用户在对话中粘贴一段文字但未明确说明要"检查/审稿/合规"时，**不自动触发本技能**。

如果用户粘贴的内容疑似需要审查，可简短回复一句确认：
> "你刚才贴的是一段文案，需要我帮你做一次合规检查吗？（输入 /内容检查 启动）"

等待用户确认后再进入检查流程。

## 工作流程

### 第一步：接收内容并识别检查范围

接收用户提供的文本内容，识别以下信息（如有不确定项，先向用户确认再继续）：

1. **待检查文本**：用户粘贴的文本（本技能不主动读取用户本地文件；如用户指定文件路径，需用户明确确认后读取）
2. **目标平台**（辅助推断）：从文本风格和内容辅助推断可能的目标平台（如种草文案→小红书/抖音；长文→微信公众号/知乎；短文→微博/百家号）；如无法推断则询问用户或默认检查全部平台通用红线
3. **特殊品类**（辅助推断）：从文本内容辅助判断是否涉及医疗、金融、食品、教育、母婴等特殊品类；如涉及则加载对应品类限制
4. **检查深度**：默认完整检查（三维度全检 + 实时搜索），如用户只要求某一维度可简化

### 第二步：加载参考文档

执行以下文件读取：

1. `references/ad-law-checklist.md` — 广告法合规检查清单
2. `references/platform-rules.md` — 各主流平台内容规范
3. `references/anti-ai-checklist.md` — 去AI化检查清单
4. `references/platform-format-guide.md` — 各平台发布格式指南

四个文档作为**基础规则基线**加载，检查时逐项对照。其中格式指南在第七步生成发布版本时使用。

> **重要**：参考文档是静态基线，但广告法条款、平台政策、敏感词库会随政策更新和执法实践动态变化。因此第三步必须执行实时联网搜索，将最新规则叠加到基线之上，确保检查依据不过时。

### 第三步：实时联网搜索最新规则（动态更新层）

**此步骤为强制执行步骤，不可跳过。** 目的是获取参考文档编写日之后的新增/变更规则，弥补静态文档的时效缺口。

#### 3.1 搜索最新广告法动态

使用 WebSearch 工具执行以下搜索（可并行）：

1. **新增禁用词/敏感词**：搜索 `广告法 违禁词 最新 [当前年份]` 和 `广告法 新增 禁用词 敏感词 [当前年份]`
2. **最新执法案例**：搜索 `广告法 处罚案例 [当前年份]` 和 `市监局 广告处罚 通报 [当前年份]`
3. **新增法规/规范性文件**：搜索 `广告法 修订 [当前年份]` 和 `互联网广告管理办法 最新 [当前年份]`
4. **行业专项治理**：搜索 `市监局 专项整治 广告 [当前年份]` 和 `平台经济 广告监管 [当前年份]`

对搜索结果执行：
- 提取新增的违禁词/敏感词，补充到绝对化用语和虚假宣传检查清单
- 提取新增的特殊品类限制
- 提取最新的执法口径变化（如某些表述以前允许但现在开始处罚）
- 如果有新的法规修订，更新检查标准

#### 3.2 搜索目标平台最新政策

根据用户指定的目标平台（如未指定则搜索主流平台通用更新）：

1. **平台内容规范更新**：搜索 `[平台名] 内容规范 更新 [当前年份]`（如 `小红书 内容规范 更新 2026`）
2. **平台处罚公告**：搜索 `[平台名] 违规处罚 封禁 限流 [当前年份]`
3. **平台敏感词更新**：搜索 `[平台名] 敏感词 违禁词 最新 [当前年份]`
4. **平台新功能/规则变化**：搜索 `[平台名] 规则变化 新规 [当前年份]`

对搜索结果执行：
- 提取平台新增的禁止内容类型
- 提取平台新增的敏感词/违禁词
- 提取平台审核标准的变化
- 标注平台近期重点打击的违规行为类型

#### 3.3 搜索行业/品类专项监管（如文本涉及特殊品类）

如果文本涉及医疗、金融、食品、教育、母婴等特殊品类：

1. 搜索 `[品类] 广告监管 最新规定 [当前年份]`（如 `医疗广告 监管 最新 2026`）
2. 搜索 `[品类] 违禁词 敏感词 [当前年份]`
3. 搜索 `[品类] 处罚案例 通报 [当前年份]`

#### 3.4 搜索最新敏感词/政治敏感内容

1. 搜索 `网络 敏感词 违禁词 最新 [当前年份]`
2. 搜索 `网信办 内容监管 新规 [当前年份]`
3. 搜索 `网络信息内容生态治理规定 最新 [当前年份]`

#### 3.5 汇总动态更新

将搜索到的新增/变更规则汇总为**动态补充清单**，格式如下：

```
## 本次检查动态更新（[搜索日期]）

### 新增违禁词（广告法）
- [新词1]：来源 [搜索结果出处]
- [新词2]：来源 [搜索结果出处]

### 平台规则变更
- [平台名]：[变更内容] — 来源 [出处]

### 特殊品类新增限制（如适用）
- [品类]：[新增限制] — 来源 [出处]

### 新增敏感词
- [敏感词1]：来源 [搜索结果出处]
```

此动态补充清单与静态参考文档**合并后**执行后续检查步骤。检查时以"静态基线 + 动态更新"的并集为准，如有冲突以动态更新（最新信息）为准。

### 第四步：广告法合规检查

加载 `references/ad-law-checklist.md` + 第三步动态更新清单，对文本逐项扫描：

#### 4.1 绝对化用语扫描
- 扫描静态清单和动态搜索结果中所有禁用词（最高级类、唯一性类、权威认证类、绝对化承诺类、领先超越类、诱导紧迫类、搜索新增词）
- 逐句标注命中的违禁词及其所在位置
- 标注严重等级：违法（绝对化用语属法定违禁）

#### 4.2 虚假宣传检查
- 检查是否有虚构的效果描述
- 检查是否有无法验证的数据
- 检查是否有虚构背书
- 检查是否有无法兑现的承诺
- 结合动态搜索的最新执法案例，检查是否有新增的虚假宣传认定标准

#### 4.3 比较广告检查
- 检查是否直接贬低其他品牌
- 检查是否有不公正对比
- 检查是否有选择性对比

#### 4.4 特殊品类限制检查（如适用）
- 根据文本内容判断是否涉及特殊品类
- 按对应品类规则检查（医疗/金融/食品/教育/房地产/烟酒/母婴）
- 检查是否有违规功效宣称或收益承诺
- 结合动态搜索的最新品类监管要求，补充新增限制项

#### 4.5 诱导性内容检查
- 检查是否有焦虑营销
- 检查是否有误导性表述
- 检查是否有低俗/不当内容
- 检查未成年人保护违规

### 第五步：平台合规检查

加载 `references/platform-rules.md` + 第三步动态更新清单，根据用户指定的目标平台（或全部平台）检查：

#### 5.1 通用红线检查
- 检查是否违反所有平台共禁内容（含动态搜索新增的共禁项）
- 检查商业推广内容是否需要报备/标注
- 检查是否有导流到外部平台的行为
- 检查是否有虚假体验或编造案例

#### 5.2 平台特有检查
- 根据目标平台，检查对应平台的特有规则
- 叠加动态搜索到的平台最新规则变更和新增敏感词
- 如未指定平台，检查文本是否适合在主流平台通用发布
- 标注哪些平台可能有风险及具体风险点

#### 5.3 平台适配建议
- 根据文本风格，建议最适合的发布平台
- 指出文本在哪些平台可能被限流或审核不通过
- 给出针对目标平台的修改建议

### 第六步：去AI化检查

加载 `references/anti-ai-checklist.md`，对文本进行四维度扫描：

#### 6.1 词汇维度
- 扫描所有禁用的高频AI词汇（13个子类）
- 标注命中词汇及类别
- 特别关注：意义膨胀词、推销式语言、物化客户词汇、伪权威表达

#### 6.2 句式维度
- 检查系动词回避
- 检查否定并列
- 检查三元组滥用
- 检查虚假范围
- 检查同义词循环
- 检查过度限定
- 检查填充短语
- 检查被动语态隐藏主体
- 检查尾随否定片段

#### 6.3 结构维度
- 检查首段是否为完整段落
- 检查结构性标记词
- 检查段落长度均匀性
- 检查结尾是否总结升华
- 检查"挑战与展望"公式段落
- 检查内联标题列表
- 检查加粗过度
- 检查破折号滥用（硬性约束：最终版本不含破折号）
- 检查emoji
- 检查标题后重复阐述段落
- 检查变更叙事式写作

#### 6.4 灵魂维度
- 检查是否有观点和立场
- 检查节奏变化
- 检查是否承认复杂性
- 检查是否具体而非空泛
- 检查对话式残留
- 检查谄媚语气
- 检查知识截止声明
- 检查通用积极结论

#### 6.5 检测判断原则
- 寻找AI特征的**集群**，而非孤立特征
- 一个破折号不算什么；破折号+三元组+意义膨胀+"结论"部分就是AI铁证
- 不误报：完美语法、正式词汇、弯引号等单独出现不是AI痕迹
- 保留人类写作的迹象：具体细节、混合感受、年代感引用、句子长度变化

### 第七步：生成可直接发布的合规版本

在检查基础上，生成去AI味+合规修正+平台格式适配后的**可直接发布版本**。用户拿到这个版本后，无需二次修改，直接复制粘贴到目标平台即可发布。

#### 7.1 内容修正
1. 修正所有广告法违禁词
2. 修正所有平台合规问题
3. 去除所有AI写作痕迹
4. 保留核心信息完整
5. 维持原有语气和风格
6. 注入灵魂（观点、节奏、具体性）

#### 7.2 平台格式适配

加载 `references/platform-format-guide.md`，根据第一步识别的目标平台，对修改后的内容执行格式适配：

- **标题**：按平台字数限制优化标题（小红书≤20字、微博≤140字含正文、公众号建议≤30字）
- **段落**：按平台阅读习惯调整段落长度和间距
- **emoji/排版**：小红书/抖音适合适度emoji和短段落；公众号适合分段+加粗重点；知乎适合长段落+专业排版
- **话题标签**：按平台规则添加合适的话题标签（小红书末尾3-5个、微博正文内嵌、抖音末尾3-5个）
- **字数控制**：按平台最佳字数范围调整内容长度
- **特殊格式**：如抖音/快手需拆分为视频口播脚本格式（含分镜提示）；小红书需笔记封面标题+正文结构

#### 7.3 改写原则
- 替换而非删除：用自然的替代方案替换问题片段
- 保留信息量：如果原文有五段，改写也有五段
- 信任读者：直接陈述事实，跳过软化和辩解
- 变化节奏：混合句子长度，两项优于三项
- 具体而非空泛：用数据和案例替代模糊主张

#### 7.4 最终版本自检

生成后对最终版本执行一次快速自检：
- [ ] 广告法违禁词已全部替换
- [ ] 平台敏感词已规避
- [ ] AI痕迹已清除
- [ ] 字数在平台最佳范围内
- [ ] 标题符合平台字数限制
- [ ] 话题标签格式正确
- [ ] 排版符合平台阅读习惯
- [ ] 核心信息无丢失

#### 输出规则

1. 报告必须包含全部三个维度的检查结果，即使某维度无问题也要标注"通过"
2. 违规项用表格清晰呈现，包含原文片段和修改建议
3. **可直接发布版本必须是完整文本**，不是片段，用户拿到后可直接复制到目标平台发布
4. 发布版本须按平台格式指南适配：标题字数、正文排版、标签格式、emoji使用等
5. 发布版本用代码块包裹，方便用户一键复制
6. 质量评分只针对去AI化维度，按1-10分五维度评分
7. 如用户只要求检查某一维度（如只查广告法），可简化其他维度为"用户未要求，跳过"
8. 如无任何问题，明确告知"检查通过，未发现合规风险或AI痕迹"，并直接输出版本（仅做格式适配，不做内容修改）
9. 如用户需要多平台发布，为每个平台生成独立的适配版本

## 关键约束

### 检查红线
1. 广告法绝对化用语属法定违禁，必须100%检出
2. 平台通用红线内容必须100%检出
3. AI痕迹检测须对照完整清单逐项扫描，不得跳过
4. 修改版本须保留原文核心信息，不得丢失信息量
5. **实时搜索为强制步骤**：每次检查必须执行第三步联网搜索，不得跳过或用缓存数据替代
6. **动态优先原则**：当静态参考文档与实时搜索结果冲突时，以最新搜索结果为准

### 搜索策略
1. 优先搜索当前年份的最新信息，保证时效性
2. 每个搜索维度至少执行2-3条搜索查询，确保覆盖面
3. 搜索结果只提取与本次检查文本相关的更新，避免信息过载
4. 如搜索无法访问或无结果，在报告中标注"实时搜索未获取到更新，仅基于静态基线检查"
5. 提取的新增违禁词/敏感词须标注来源，便于追溯

### 判断原则
1. 广告法：有疑必报，宁严勿松
2. 平台合规：按目标平台实际规则判断，标注风险等级
3. AI检测：寻找特征集群而非孤立特征，避免误报
4. **时效性判断**：对于搜索到的新规，如生效日期在检查文本发布日期之前，则适用；如尚未生效则标注"预警：即将生效"

### 适用范围
1. 适用于所有中文文本类型：文章、文案、社交媒体帖子、商品描述等
2. 不限于特定品牌或行业，通用型检查
3. 特殊品类检查在文本涉及对应品类时自动激活
4. 如文本为英文，仍可检查AI痕迹（英文AI模式），但广告法和平台规则以中文平台为准
