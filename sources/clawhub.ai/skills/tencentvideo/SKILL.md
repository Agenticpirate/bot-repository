# 腾讯视频（别名入口）

完整使用指南在本团队的 **`qqlive`** 主技能中（腾讯视频客户端历史
名称即 QQLive），本入口保留最常用速查。

## 速查卡

| 项目 | 要点 |
|------|------|
| VIP vs SVIP | **手机/平板/电脑 VIP 权益不含电视端**；投电视看全屏内容需 SVIP（含极光 TV） |
| 投屏限制 | 非 SVIP 投屏常被限清晰度或直接拦截，这是最高频的用户困惑 |
| 内容格局 | 腾讯/爱奇艺/优酷/芒果各有独播，为剧开会员前先确认平台归属 |
| 自动续费 | 首充优惠普遍绑定自动续费，开通后记得按需关闭 |

## Agent 典型用法

1. 用户问"为什么投不了电视/投屏模糊" → 十有八九是 VIP/SVIP
   权益差异，见速查卡
2. "这部剧在哪个平台" → 先查独播归属再建议开哪家会员
3. 完整的会员选择、下载限制、排障 → 用 `qqlive` 主技能

## 边界

- 会员价格与权益调整频繁，以购买页实时说明为准
- 不提供破解 VIP、去广告、盗版资源渠道
