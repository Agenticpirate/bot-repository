# 研技 · K线数据采集 (yanji-kline-data)
> **⚠️ 数据来源与限制（重要披露）：**
> 本Skill优先从新浪财经实时获取K线数据（网络可用时）；网络不可用或接口受限时自动回退到**内置模拟K线数据**（课程教学演示用），输出会标注「模拟数据」。
> 模拟数据仅用于演示分析流程，不反映真实行情。



## 功能
1. **实时行情报价** — 从新浪财经获取当日开盘/收盘/最高/最低/成交量（网络可用时）
2. **均线估算** — 基于当前价计算MA5/MA10/MA20/MA60演示估算值（明确标注为估算，非历史均线）
3. **网络不可用兜底** — 接口失败时输出明确提示「数据获取失败」或演示估算值

> 说明：本Skill提供实时报价与均线演示估算，不提供历史K线序列；多周期（周/月/60分钟）历史K线不在当前脚本能力范围内。

## 数据源
| 数据类型 | 来源 | 说明 |
|---------|------|------|
| 实时行情 | 新浪财经 | `hq.sinajs.cn` 实时接口（网络可用时） |
| 均线估算 | 脚本内计算 | 基于当前价的演示估算值（非真实历史均线） |

## 调用方式
```bash
python3 {baseDir}/scripts/fetch_kline.py [--code sh600519] [--period daily|weekly|monthly] [--days 60] [--output json|text]
```
