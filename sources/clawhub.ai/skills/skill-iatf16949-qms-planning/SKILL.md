# IATF16949质量管理体系策划

## 任务目标

- **本Skill用于**:帮助汽车行业企业或相关机构规划、建立和优化符合IATF16949标准的质量管理体系
- **核心能力**:标准解读 | 策划流程 | 文件模板 | 过程分析 | 审核支持 | 最佳实践
- **触发条件**:体系建设需求 | 认证准备 | 过程优化 | 审核策划 | 标准差距分析

## 核心能力模块

### 1. IATF16949标准解读与应用

IATF16949:2016是汽车行业质量管理体系标准，结合ISO9001:2015框架与汽车行业特殊要求。

**十大核心条款**:
- 第4章 组织环境（内外部因素、利益相关方）
- 第5章 领导力（质量方针、职责权限）
- 第6章 策划（风险与机遇、质量目标）
- 第7章 支持（资源、能力、意识、沟通）
- 第8章 运行（策划、控制、不合格输出）
- 第9章 绩效评价（监视测量、分析评价）
- 第10章 改进（不符合处理、持续改进）

**汽车行业特殊要求**:
- 产品安全相关过程控制
- 过程方法应用（乌龟图）
- 顾客特殊要求（CSR）整合
- 精益制造与浪费消除
- 供应链管理要求

详细内容见 [references/standard-interpretation.md](references/standard-interpretation.md)

### 2. 体系策划流程

**标准流程**:

```
┌─────────────────────────────────────────────────────────┐
│  1. 初始评估                                              │
│     - 确定范围与边界                                      │
│     - 识别内外部环境因素                                  │
│     - 利益相关方分析                                      │
├─────────────────────────────────────────────────────────┤
│  2. 标准差距分析                                          │
│     - 对标IATF16949各条款                                 │
│     - 识别现有体系差距                                    │
│     - 差距优先级排序                                      │
├─────────────────────────────────────────────────────────┤
│  3. 体系策划                                              │
│     - 确定过程架构（乌龟图）                              │
│     - 编写体系文件清单                                    │
│     - 资源配置与职责分配                                  │
├─────────────────────────────────────────────────────────┤
│  4. 体系建立                                              │
│     - 编写质量手册                                        │
│     - 编制程序文件                                        │
│     - 完善作业指导书                                      │
├─────────────────────────────────────────────────────────┤
│  5. 体系运行与优化                                        │
│     - 试运行与问题收集                                    │
│     - 内审与管理评审                                      │
│     - 持续改进                                            │
└─────────────────────────────────────────────────────────┘
```

**智能体职责分工**:
- 流程指导与答疑：由智能体通过对话提供指导
- 文件编制支持：智能体引导用户基于模板填充内容
- 工具应用指导：智能体解释并指导使用

### 5. 内部审核与管理评审

**内部审核策划流程**:

```
审核策划 → 审核准备 → 审核实施 → 审核报告 → 跟踪验证
```

**关键要素**:
- 审核方案制定（基于风险）
- 审核员能力要求
- 审核检查表编制
- 不符合项跟踪闭环

## 使用示例

### 示例1: 新建体系策划
- **场景**:企业首次建立IATF16949体系
- **流程**:
  1. 智能体引导进行初始评估
  2. 基于模板编制质量手册
  3. 对照差距分析完善程序文件
  4. 策划内部审核方案
- **产出**:完整的体系文件架构与核心文件初稿

### 示例2: 认证准备
- **场景**:企业已运行体系，准备第三方认证审核
- **流程**:
  1. 进行管理体系差距分析
  2. 策划并实施内部审核
  3. 准备管理评审输入
  4. 优化体系文件与过程控制
- **产出**:审核准备清单与改进建议

### 示例3: 过程优化
- **场景**:企业需优化特定过程（如来料检验）
- **流程**:
  1. 应用乌龟图分析过程输入输出
  2. 使用FMEA识别潜在风险
  3. 制定防错措施
  4. 建立SPC控制图
- **产出**:过程优化方案与控制计划
