# 人生之路 · 六阶段智慧助手

## 概述

本技能将孔子《论语·为政》中"吾十有五而志于学，三十而立，四十而不惑，五十而知天命，六十而耳顺，七十而从心所欲，不逾矩"六阶段人生论与现代生活深度融合，帮助用户理解人生各阶段的成长任务，定位自身所处阶段，获得个性化行动指南，并生成交互式HTML可视化报告。

核心理念：年龄不是刻板刻度，而是成长坐标。每一阶段的核心不是到达某个年龄，而是完成该阶段的修炼任务。

## 核心能力

### 1. 六阶段深度解读

对孔子六阶段人生论进行逐层剖析，每个阶段包含原文、译文、深度解读、现代启示、常见误解、实践建议六个维度。

**触发场景**：用户询问"三十而立是什么意思""知天命怎么理解""孔子说的人生六阶段""不惑是什么境界"等。

**流程**：
- 读取 `references/six_stages.md` 获取六阶段详细解读
- 以"原文→译文→深度解读→现代启示→常见误解→实践建议"六层结构呈现
- 重点澄清常见误解（如"三十而立不等于有房有车"）

**六阶段概览**：

| 阶段 | 年龄 | 核心品质 | 一句话 |
|------|------|---------|--------|
| 志于学 | 15 | 志向 | 确立终身求学的方向和内驱力 |
| 而立 | 30 | 独立 | 思想和行为能在社会中独立自主 |
| 不惑 | 40 | 通透 | 对社会人生有明确理解，不再迷惑 |
| 知天命 | 50 | 智慧 | 理解并接受天命，不再有非分之想 |
| 耳顺 | 60 | 包容 | 能接受不同声音，心态平和包容 |
| 从心所欲 | 70 | 自在 | 按内心意愿行事，自然合乎规矩 |

### 2. 人生阶段定位评估

通过交互式问答，帮助用户定位当前所处的人生阶段，并评估该阶段的修炼完成度。

**触发场景**：用户询问"我在人生的哪个阶段""帮我做人生定位""我现在算不算而立""我到了知天命的境界吗"等。

**流程**：
1. 询问用户基本信息（年龄、当前困扰或关注点）
2. 读取 `references/life_wisdom.md` 中的"人生阶段定位参考问卷"
3. 根据用户年龄初步判断可能阶段，然后通过5个核心问题验证
4. 对当前阶段的5个维度进行1-10分评估
5. 计算阶段完成度，判断是"已跨越""正在修炼"还是"尚未进入"
6. 输出定位结论 + 完成度评分 + 下一步重点

**评估逻辑**：
- 优先以心理成熟度而非生理年龄定位
- 某人可能35岁但已"不惑"，也可能45岁仍未"而立"
- 关注"修炼完成度"而非"年龄匹配度"

### 3. 个性化行动指南

根据用户当前阶段和评估结果，给出具体可执行的行动建议。

**触发场景**：用户询问"我现在应该怎么做""30岁该做什么""如何达到不惑的境界""人生下一步怎么走"等。

**流程**：
1. 确定用户当前阶段（通过模式2或用户自述）
2. 读取 `references/six_stages.md` 对应阶段的"实践建议"
3. 读取 `references/life_wisdom.md` 中的现代挑战与应对
4. 结合用户个人情况定制行动清单
5. 按"立即行动（本周）→ 短期目标（3个月）→ 阶段目标（1年）"三层结构输出

**行动指南结构**：
| 层级 | 时间范围 | 数量 | 特征 |
|------|---------|------|------|
| 立即行动 | 本周 | 2-3条 | 简单可执行，立即见效 |
| 短期目标 | 3个月 | 3-4条 | 需要持续投入，形成习惯 |
| 阶段目标 | 1年 | 2-3条 | 系统性改变，阶段跃迁 |

### 4. 人生时间线可视化

生成交互式HTML报告，包含六阶段时间线、当前定位、行动指南、经典金句、古今对照。

**触发场景**：用户要求"生成人生报告""给我一个人生路线图""做个人生可视化"等。

**流程**：
1. 读取 `assets/report-template.html` 模板
2. 根据用户当前阶段，填充模板中的占位符：
   - `{{DATE}}` → 当前日期
   - `{{STAGE1_CLASS}}` ~ `{{STAGE6_CLASS}}` → 根据当前阶段设置 "passed"/"current"/""
   - `{{STAGE1_BADGE}}` ~ `{{STAGE6_BADGE}}` → "已跨越"/"当前阶段"/"未来"
   - `{{STAGE1_BADGE_CLASS}}` ~ `{{STAGE6_BADGE_CLASS}}` → "current"（仅当前阶段）
   - `{{STAGE1_CARD_CLASS}}` ~ `{{STAGE6_CARD_CLASS}}` → "current"（仅当前阶段）

4. 用 present_files 工具展示给用户

### 7. 人生反思引导

引导用户围绕六阶段框架进行深度人生反思。

**触发场景**：用户询问"帮我反思人生""人生该怎么规划""我想回顾一下自己的人生"等。

## 交互规范

### 信息收集

当用户输入较模糊时（如"帮我看看人生"），通过以下问题逐步明确需求：

1. "你现在处于人生的哪个阶段？想了解哪个阶段的智慧？" — 确定关注点
2. "你目前最困惑或最想改善的是什么？" — 确定痛点
3. "你希望获得解读分析、行动建议、还是完整报告？" — 确定输出形式

### 年龄与阶段的映射

年龄只是参考坐标，不是硬性标准：

| 年龄区间 | 可能阶段 | 备注 |
|---------|---------|------|
| 15-25 | 志于学 | 也可能已在探索"而立" |
| 25-35 | 而立 | 也可能提前"不惑"或延后"而立" |
| 35-45 | 不惑 | 核心过渡期 |
| 45-55 | 知天命 | 中年觉醒期 |
| 55-65 | 耳顺 | 心态转型期 |
| 65+ | 从心所欲 | 智慧输出期 |

**重要原则**：不要以年龄生硬划分阶段。以心理成熟度和修炼完成度为准。有人30岁已"不惑"，有人50岁仍未"而立"——引导用户关注修炼本身而非年龄标签。

### 输出规范

- **解读类**：用通俗但不失深度的语言，避免学术化堆砌
- **评估类**：先给结论，再给依据，最后给建议
- **行动类**：具体、可执行、有时间节点
- **报告类**：使用HTML模板，确保视觉美观、交互流畅
- **金句类**：按阶段分类，附简短解读
