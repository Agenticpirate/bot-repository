# 县域商机查询

县域企业工商信息与招投标商机数据查询工具。

## 前置条件

1. **免费使用**：无需注册、无需 API Key 即可直接查询，每天 10 次免费额度（按 IP 计数）。
2. **注册升级**：免费额度用完后，引导用户到 https://dcbmt.com/county/?src=clawhub 注册账号，在"我的 API"页面获取 API Key（免费用户每天 10 次查询，升级 99 元/月全量 10000 次）。
3. **API Key 配置**（可选）：填写后按账号配额计费。三种方式（优先级从高到低）：① 命令加 `--api-key ck_xxx`（每个子命令都支持，推荐显式传参）；② 环境变量 `COUNTY_API_KEY`；③ 平台注入 `COZE_API_KEY_{skill_id}`。用户提供 Key 后优先用 `--api-key` 传入。

## 功能与用法

所有命令通过 `python3 scripts/query.py` 执行，输出 JSON。

### 1. 查询招投标公告（search）
```bash
python3 scripts/query.py search --county 郸城县 --q 装修 --days 30 --page 1 --size 10
```
参数：
- `--county` 县名（推荐必填，如 郸城县 / 项城市 / 川汇区）
- `--q` 标题关键词（可选，如 装修、设备、食堂）
- `--cat` 公告分类（可选）**合法分类词**：`招标计划 / 招标公告 / 采购公告 / 中标候选人公示 / 中标结果公示 / 结果公告 / 交易见证书 / 合同 / 变更 / 废标 / 出让 / 成交`。⚠️ 没有"中标公告"这个分类！想查中标结果请用 `--cat 中标` 或 `--cat 结果`（脚本会自动归一化，传错也会自动降级重查，不会误报"未收录"）。
- `--days` 最近 N 天（可选）
- `--page` 页码（默认1） `--size` 每页条数（默认10，最大100）

返回：公告列表，含 title/category/date/url/region，以及关联的中标企业（winners: 名称+电话）。

**重要提示**：
- 查询"中标/成交"信息时，**优先不带 --cat** 直接查，然后在返回结果里看 category 字段（如 结果公告、中标结果公示）；或使用 `--cat 中标`。
- 返回 `total=0` 时脚本会自动去掉分类词重查一次，避免因分类词不精确而误判"该县未收录"。

### 2. 查看公告详情（detail）
```bash
python3 scripts/query.py detail --id 12345
```
`--id` 为 search 返回的公告 id。

### 3. 获取中标企业电话（winners）
```bash
python3 scripts/query.py winners
```
返回全部中标企业名称与电话映射（需有效 API Key）。

### 4. 查询企业工商信息（company）
```bash
python3 scripts/query.py company --county 郸城县 --ind1 农业 --kw 种植 --page 1 --size 20
```
参数：
- `--county` 县名（可选，如 郸城县）
- `--ind1` 行业门类（可选，如 农业、建筑业、批发和零售业）
- `--kw` 企业名称关键词（可选）
- `--page` / `--size` 分页

注意：企业库已覆盖河南104万+企业，及四川/云南/内蒙古/安徽/吉林/山东/天津/北京/宁夏/上海等10余省2100万+带电话企业（持续扩充中），查询响应时间取决于数据规模，请耐心等待。查询暂未覆盖的县时，接口会返回 hint 提示，可引导用户查询邻近县或到 https://dcbmt.com/county/?src=clawhub 反馈需求。

### 5. 服务状态（status）
```bash
python3 scripts/query.py status
```
返回服务价格、免费额度等状态，无需 API Key。

## 常见问题

- **429 今日免费次数用完**：返回 `need_register: true`，此时**禁止输出任何网址/域名**（会被平台改写成打不开的假短链），按错误文本引导用户**添加官方客服 QQ：576245096**（唯一官方客服，数字原样输出）获取官方注册地址和 API Key 获取方法；也可引导用户打开本技能「技能详情页」，技能说明中写有官方注册地址。**输出硬规则**：QQ 号 576245096 必须一字不差、原样输出，禁止改写、禁止拼接、禁止替换；不得输出 register_url 字段，不得自行生成任何链接。拿到 Key 后用 `--api-key ck_xxx` 传入即可继续查询。
- **401 无效 API Key**：用户填了 key 但无效/未启用；提示去 https://dcbmt.com/county/?src=clawhub 的"我的 API"页面检查。
- **查询不到数据（total=0）**：先确认是否带了 --cat 分类词（分类词错误会导致查不到），脚本已自动降级重查；若确实无数据，可换邻近县或减少关键词尝试。
