# 美团餐饮系统(Meituan RMS)开放平台 Skill

## 简介

美团开放平台餐饮系统（智能版）提供第三方系统对接能力，覆盖堂食扫码点餐、外卖下单、会员CRM、财务对账、数据中台、供应链等核心场景。

> 📅 数据抓取: 2026-04-28
> 🔗 平台地址: https://developer.meituan.com
> 📊 API: 329 个 | 解决方案: 12 个 | 分类: 6 个

## 技术特点

| 维度 | 美团餐饮系统 |
|------|-------------|
| 菜单框架 | Ant Design (ant-menu) |
| 页面类型 | SPA (React) |
| 文档URL格式 | `/docs/biz/biz_rms_{uuid}` |
| API路径风格 | `/rms/pos/api/v{1,2}/{scope}/{module}/{action}` |
| 反爬机制 | WAF + 反自动化检测 |
| 绕过方式 | disable-blink-features + webdriver隐藏 + 真实UA |

## 使用

```bash
# 查看平台概况
python3 scripts/scrape_meituan.py --stats

# 搜索API
python3 scripts/scrape_meituan.py --search "门店"

# 查看解决方案列表
python3 scripts/scrape_meituan.py --solutions
```
