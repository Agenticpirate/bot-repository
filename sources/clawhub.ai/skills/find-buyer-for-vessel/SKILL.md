# 租赁-卖家找买家

为 ShippingClaw/OpenClaw 执行卖家找买家工作流。调用脚本获取真实求购数据，不要猜测买家需求、公司或联系方式。不要采集、返回或展示会员类型及会员积分。

## 必需输入

收集以下三项后查询：

- 船舶类型。
- 实际载重或容量及单位；未注明单位的“吨”按 DWT。
- 实际船龄；支持“8年”“2018年建造”和“新船”。

可选输入：船旗、内贸/外贸。内贸/外贸不参与匹配，仅在卖家主动提供时写入需求记录。

## 查询

```bash
python scripts/find_buyer.py search \
  --vessel-type "<船型>" \
  --capacity "<数值及单位>" \
  --age "<实际船龄、建造年份或新船>" \
  --flag "<可选船旗>" \
  --trade-scope "<可选内贸或外贸>" \
  --user-id "<当前登录卖家用户ID>"
```

测试阶段用户 ID 为空时添加 `--skip-demand-sync`。

默认展示匹配分最高的前10条，字段顺序为：匹配分、可点击编号、求购船型、需求载重吨/容量、船龄要求、船旗要求、买家公司、需求状态、更新时间。

- 将编号渲染为 `[编号](detail_url)`；支持结构化交互时绑定 `detail_action`。
- 仅展示脚本返回的结果。
- `manual_confirmation_fields` 非空时明确标注对应字段需人工确认。

## 匹配与评分

- 船型允许同义名称和同一类别的相近船型；完全一致得分高于相近类型。无法识别或仅为“其他船”的记录排除。
- 容量只在相同单位间比较。DWT/载重吨统一，万吨可换算；TEU、BHP、GRT、CBM、PAX 不得互转。
- 卖家实际载重落在买家需求区间内得满分；区间边界外最多放宽20%，越接近得分越高。
- 卖家船龄落在买家要求区间内得满分；区间边界外最多放宽3年。“不限”接受任意船龄；卖家是新船时，买家船龄条件必须包含0年。
- 卖家填写船旗时，只保留船旗完全一致的需求；买家要求“不限”不视为完全一致。卖家未填写船旗时不筛选。
- 内贸/外贸不参与匹配，因为数据源没有该字段。
- 已成交、已关闭、已下架、过期或失效记录直接排除。
- 基础权重：船型35、载重/容量35、船龄25、船旗5。未填写船旗时，将权重按比例分配给其余项目。
- 最终按总分降序、容量误差、船龄误差和更新时间排序。
- 列表和详情缓存12小时。若数据源请求失败，可返回尚在本地的过期缓存并明确标注 `stale`。

## 详情

点击搜索结果中的站内链接或执行：

```bash
python scripts/find_buyer.py detail --solid "<solid>"
```

展示买家需求详情和公开可见联系方式，不返回原始网站链接，也不展示会员类型或会员积分。付费、遮罩或登录后可见字段留空；不得登录、支付、绕过限制或推断联系方式。

部署时设置 `SELLER_BUYER_PUBLIC_URL` 为用户浏览器可访问的服务地址；本机默认 `http://127.0.0.1:8768`。

## 需求同步

一次完整查询完成后同步卖家找买家需求。用户 ID 为空时跳过；后台接口未配置或提交失败时进入本地待处理队列。接口字段见 [references/backend-api.md](references/backend-api.md)。

## 服务

```bash
uvicorn scripts.service:app --host 0.0.0.0 --port 8768
```

接口为 `GET /health`、`POST /search`、`GET /purchase/{solid}`（JSON）和 `GET /purchase/{solid}/view`（站内详情）。
