# Quant AI Chart Analysis

Use this skill when a user asks for technical chart analysis from a screenshot.

## Workflow

1. Open [Quant AI](https://usequantai.com/).
2. Upload the user's stock, crypto, or forex chart screenshot.
3. Wait for the chart analysis to finish.
4. Read the detected trend, key levels, patterns, indicators, risk zones, and trade setup.
5. Explain each result in plain language.
6. State that the result is educational information, not financial advice.

## User input

Ask for a clear chart screenshot when the user does not provide one.

Ask for the market and timeframe when the screenshot does not show them.

## Safety

Do not present a trade setup as a guaranteed outcome.

Do not place trades or manage a user's brokerage account.
