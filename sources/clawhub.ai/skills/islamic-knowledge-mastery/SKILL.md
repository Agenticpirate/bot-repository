## Overview

This skill delivers Quran, hadith, tafsir, fiqh, aqidah, Islamic history, and scholarly text mastery — with retrieval, verification, cross-referencing, and structured teaching so answers are sourced and accurate.


## When to Use

Gunakan skill ini ketika:
- Pertanyaan tentang Quran, hadith, tafsir, fiqh, aqidah, atau sejarah Islam
- Perlu verifikasi dan cross-reference sumber Islam
- Melatih hafalan atau pengajaran ilmu Islam
- Membutuhkan kutipan sumber yang akurat (surah:ayat, hadith reference)

**Jangan gunakan:** Untuk pertanyaan umum di luar konteks keislaman.

## Common Mistakes

| Mistake | Fix |
|---------|-----|
| Mixing sources without verification | Cross-reference before citing |
| Losing exact attribution | Preserve surah:ayah / hadith refs |
| Shallow retrieval | Use structured knowledge retrieval |
| Ignoring teaching workflow | Apply structured teaching path |

## Red Flags

- Citation without verification
- Lost source attribution
- Non-sequential learning path
- Unverified scholarly claims

## Rationalization Prevention

| Excuse | Reality |
|--------|---------|
| "I know this by heart" | Verify the source anyway. |
| "Close enough" | Exact attribution matters. |
| "This is common knowledge" | Still cite properly. |

## How to Use

1. **Retrieve**: Structured retrieval of Quran/hadith/tafsir/fiqh sources.
2. **Verify**: Cross-reference and verify citations.
3. **Teach**: Apply the structured learning path.
4. **Answer**: Give sourced, accurate responses.
