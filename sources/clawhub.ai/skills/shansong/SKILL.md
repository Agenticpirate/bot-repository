# 闪送同城急送 Skill

闪送的核心差异化是**1 对 1 专人直送**：接单后不拼单、不中转，
取件后直奔收件地——为"急"和"贵重"付溢价。

## 同城配送选型表

| 平台 | 模式 | 适合 |
|------|------|------|
| **闪送** | 1对1专人直送，不拼单 | 急件/贵重/易损（合同、证件、蛋糕、鲜花） |
| 达达/美团跑腿 | 顺路拼单为主 | 普通物品，价格敏感（见 `dada` skill） |
| 顺丰同城 | 半专送，品牌背书 | 商务件，对时效与形象都有要求 |
| 货拉拉/快狗 | 车辆运输 | 大件、批量 |

判断口诀：**耽误不起 → 闪送；差几块钱无所谓但不急 → 拼单平台**。

## 计费与时效

- 计费 = 起步价（含起步距离）+ 超距费 + 重量附加 + 时段/天气加价，
  下单页实时报价为准
- 时效预期：同城 10 公里内通常 1 小时上下门到门，但恶劣天气/
  高峰期会延长——给用户做时间规划时留 30% 余量
- 远距离（30km+）先比较闪送与同城快递次日达的成本差

## 贵重/敏感物品要点

1. **保价**：贵重物品必买保价，未保价按运费倍数赔付上限很低
2. **拍照留证**：交接时拍物品状态与包装
3. **禁寄**：现金、危险品、活体（规则内除外）、违禁品——
   代购处方药等灰色需求一律拒绝
4. 文件证件类建议信封密封并要求送达拍照回执

## Agent 典型用法

1. **选平台**：按物品价值/紧急度/距离给平台建议与成本估算框架
2. **时间规划**：倒排取送时间（如"下午 3 点前必须送达"→ 何时下单）
3. **风险控制**：贵重物品的保价+留证清单
4. **纠纷处理**：延误/损坏的索赔路径（App 客服→保价理赔）

## 本 skill 不做什么

- 价格随城市/时段/天气浮动，以下单页实时报价为准
- 不提供绕过禁寄清单的方法
- 骑手端（接单/奖励机制）不在本 skill 覆盖范围
