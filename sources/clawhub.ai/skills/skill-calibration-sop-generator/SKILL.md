# 校准作业指导书生成器

## 概述

本技能用于辅助生成计量/校准领域的作业指导书（SOP）。根据用户提供的设备信息，自动匹配适用标准，补充校准参数、允差要求、环境条件和操作步骤，输出结构化的指导书文档。

## 能力边界

**本技能能够**：
- 根据设备类型推荐适用的校准规范（JJG/JJF）
- 补充常见计量器具的校准点设置建议
- 提供标准规定的允差/判定依据参考
- 生成符合计量行业规范的文档结构

**本技能不能**：
- 替代专业计量工程师的判断
- 保证标准引用的绝对准确性（需人工核对）
- 处理特种设备或强检目录内的器具

## 工作流程

### 步骤1：收集设备信息

引导用户提供以下基本参数：

| 参数 | 说明 | 示例 |
|------|------|------|
| 设备名称 | 被校准器具名称 | 工业铂热电阻 |
| 型号/规格 | 设备型号 | Pt100, -200~500℃ |
| 准确度等级 | 精度等级 | AA/A/B/C级 |
| 测量范围 | 量程范围 | 0~500℃ |
| 设备编号 | 内部编号（可选） | SB-2024-001 |

### 步骤2：识别设备类型并推荐标准

根据设备名称和类型，识别其所属类别：

| 类别 | 常见设备 | 适用标准示例 |
|------|----------|--------------|
| 温度 | 热电偶、热电阻、温度计、温控仪 | JJG 667, JJG 229, JJF 1076 |
| 压力 | 压力表、数字压力计、压力变送器 | JJG 49, JJG 875, JJF 1323 |
| 力学 | 砝码、台秤、天平、硬度计 | JJG 99, JJG 13, JJG 1036 |
| 电气 | 万用表、钳形表、兆欧表、耐压仪 | JJG 315, JJG 366, JJG 622 |
| 长度 | 卡尺、千分尺、百分表、量块 | JJG 30, JJG 21, JJG 146 |
| 流量 | 流量计、水表、煤气表 | JJG 257, JJG 162 |

**标准推荐原则**：
- 首选国家计量检定规程（JJG）
- 次选国家计量技术规范（JJF）
- 涉及进口设备时参考国际建议（OIML R）
- 行业专用设备参考部门校准规范

### 步骤3：补充校准技术参数

根据推荐的标准，补充以下技术参数：

#### 3.1 校准点设置

根据量程和精度等级建议校准点：

```python
# 典型校准点设置原则
校准点数量: 5~7个（均匀分布或关键点集中）
优先点位: 量程的20%, 40%, 60%, 80%, 100%
特殊点位: 零点、满量程、常用点
```

#### 3.2 允差/判定依据

根据准确度等级提供允差参考：

```
铂热电阻（JJG 229-2010）允差参考：
- AA级: ±(0.10+0.0017|t|) ℃
- A级: ±(0.15+0.002|t|) ℃  
- B级: ±(0.30+0.005|t|) ℃
- C级: ±(0.60+0.010|t|) ℃
```

#### 3.3 环境条件

标准规定的校准环境：

| 项目 | 常规要求 | 精密要求 |
|------|----------|----------|
| 温度 | 20±5℃ | 20±2℃ |
| 湿度 | ≤85%RH | 40%~60%RH |
| 其他 | 无剧烈振动、无腐蚀性气体 | 屏蔽、恒温恒湿 |

#### 3.4 标准器要求

推荐使用的标准器：

```
温度类: 二等标准铂电阻温度计、标准热电偶、
        精密温度测量系统
压力类: 0.05级标准压力表、活塞式压力计
力学类: E2等级标准砝码、标准力传感器
电气类: 0.01级标准源、标准电阻箱
```

### 步骤4：生成指导书

调用脚本生成指导书文档：

```bash
python scripts/doc_generator.py \
  --device "工业铂热电阻" \
  --range "0~500℃" \
  --grade "A级" \
  --standard "JJG 229-2010" \
  --output "./校准作业指导书_铂热电阻.md"
```

## 使用示例

### 示例1：温度仪表

**用户输入**：
> 我要校准一台工业铂热电阻，型号Pt100，测量范围0~500℃，准确度A级

**技能响应**：
1. 识别设备类型 → 温度仪表/热电阻
2. 推荐标准 → JJG 229-2010《工作用铂热电阻》
3. 补充参数 → 校准点、允差、环境要求
4. 生成指导书

**生成结果预览**：
```markdown
# 校准作业指导书

## 1. 基本信息
- 设备名称：工业铂热电阻
- 型号规格：Pt100
- 测量范围：0~500℃
- 准确度等级：A级

## 2. 校准依据
JJG 229-2010《工作用铂热电阻》

## 3. 校准条件
- 环境温度：(20±2)℃
- 相对湿度：40%~60%RH
- 标准器：二等标准铂电阻温度计

## 4. 校准点设置
0℃, 100℃, 200℃, 300℃, 400℃, 500℃

## 5. 判定依据
A級允差: ±(0.15+0.002|t|) ℃

...（完整内容见生成的文档）
```

**用户输入**：

### 示例3：电气仪表

2. 推荐标准 → JJG 315-2023《直流数字式电流表》
3. 补充参数 → 校准点、允差、环境要求

## 注意事项

1. **标准核对**：生成后请核对推荐的标准编号是否与实际适用版本一致
2. **允差确认**：允差值仅供参考，最终以现行有效标准为准
3. **模板调整**：可根据单位内部规范调整模板内容
4. **特殊设备**：非标设备或特殊校准方法需人工补充相关内容
5. **版本追溯**：建议在文档中标注校准依据的版本号和发布日期
