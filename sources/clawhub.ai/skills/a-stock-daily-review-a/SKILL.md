# A股每日复盘 Skill

## 概述

每个A股交易日收盘后，自动生成一份完整的每日复盘 Markdown 文件，保存到 `E:/文件/workbody/A股每日复盘_YYYY-MM-DD.md`。

**数据优先级：通达信（TDX）> westock-data > 互联网数据。两者矛盾时以 TDX 为准。**

---

## 执行流程

### 第一步：判断是否为交易日

**在执行任何数据获取前，必须先判断目标日期是否为A股交易日。**

判断方法（按优先级）：
1. **尝试获取上证指数行情**：调用 `mcp__tdx-connector__tdx_quotes` 查询上证指数（code: "000001", setcode: 1）。如果返回正常行情数据 → 是交易日；如果返回错误、空数据或休市标志 → 非交易日
2. **备用方法**：调用 westock-data 查询上证指数，如果失败则为非交易日
3. **日期判断**：如果当天为周六或周日 → 直接判定为非交易日，无需调用接口

**非交易日处理**：
- 如果在 Automation 定时触发场景下遇到非交易日：**直接退出，不生成文件，不发送通知**
- 如果用户在非交易日手动触发：提示用户"YYYY-MM-DD 为非交易日，无行情数据"，询问是否复盘最近一个交易日

**确定复盘日期**：
- Automation 定时触发（15:30）：复盘日期为**当日**（已在交易时间内判断过为交易日）
- 用户在交易时间内（9:30~15:00）手动触发：复盘日期为**当日**
- 用户收盘后手动触发：复盘日期为**当日**
- 用户指定日期：使用指定日期（仍需判断是否为交易日）

目标文件路径：`E:/文件/workbody/A股每日复盘_YYYY-MM-DD.md`

### 第二步：读取复盘模板

读取参考模板获取格式和板块结构：

```
E:/文件/workbody/A股每日复盘_2026-07-02.md
```

如果上述文件不存在，读取任意已有的复盘文件作为格式参考。

模板固定包含 7 大板块：
1. 今日市场概况
2. 核心涨跌停统计
3. 板块轮动与热点主线
4. 全A成交额 TOP20
5. 涨停核心标的 TOP20（含涨停原因揭秘）
6. 跌停核心标的 TOP20（含跌停原因揭秘）
7. 消息面与明日策略

### 第三步：获取 TDX 权威数据（必须首先执行）

使用 `mcp__tdx-connector` 工具获取以下数据，**所有数据以 TDX 返回值为主**：

#### 3.1 七大指数行情

| 指数 | setcode | code |
|------|---------|------|
| 上证指数 | 1 | 000001 |
| 深证成指 | 0 | 399001 |
| 创业板指 | 0 | 399006 |
| 科创50 | 1 | 000688 |
| 上证50 | 1 | 000016 |
| 沪深300 | 1 | 000300 |
| 中证500 | 1 | 000905 |

调用 `mcp__tdx-connector__tdx_quotes`，参数：`{code, setcode, hasCalcInfo: 1, hasExtInfo: 1, hasHQInfo: 1}`

从返回结果中提取：
- 收盘点位（`close` 或 `current`）
- 涨跌幅（`changePCT` 或 `pchgPct`）
- 成交额（`amount` 或 `volume`，单位通常为万元，需转换为亿元）
- 量比、换手率等辅助指标

#### 3.2 涨跌停统计

调用 `mcp__tdx-connector__tdx_screener`：
- 涨停：`{message: "涨停", rang: "AG", pageSize: 200, pageNo: 1}`
- 跌停：`{message: "跌停", rang: "AG", pageSize: 200, pageNo: 1}`

统计返回结果的总数（TDX 的 total 字段），并记录连板天数。

#### 3.3 全A成交额 TOP20

调用 `mcp__tdx-connector__tdx_screener`：
- `{message: "成交额 从大到小 前20名", rang: "AG", pageSize: 20}`

如上述自然语言查询效果不佳，改用排序参数直接获取。

#### 3.4 涨停/跌停核心标的详情

对 TOP20 涨停股和跌停股，逐只调用 `mcp__tdx-connector__tdx_quotes` 获取详细信息，并调用 `mcp__tdx-connector__tdx_api_data` 获取涨停/跌停原因（如有）。

涨停原因揭秘调用方式：
```
mcp__tdx-connector__tdx_api_data
{code: <股票代码>, setcode: <0或1>, entry: "TdxSharePCCW.tdxsj_lhbd_lhbzl", mode: "branch-date-period", date: "YYYYMMDD", branch: "0", period: "1"}
```

---

### 第四步：交叉验证（westock-data + 互联网）

#### 4.1 板块涨跌排行

调用 westock-data 获取板块数据：
```
node "<westock-data-path>/scripts/index.js" sector ranking --limit 50
node "<westock-data-path>/scripts/index.js" sector ranking --asc --limit 30
```

将结果与 TDX 指数数据对比，如有矛盾以 TDX 为准，在文件中标注 `(TDX校验)`。

#### 4.2 互联网数据补充

使用 `WebSearch` 搜索当日复盘文章，关键词：
- `A股 YYYY年M月D日 收盘复盘 涨跌家数 北向资金`
- `YYYY年M月D日 A股板块涨跌 领涨 领跌`

使用 `WebFetch` 抓取百度百家号、同花顺、东方财富等复盘文章，提取：
- 涨跌家数（上涨/下跌/平盘）
- 北向资金净流入/流出金额
- 市场情绪描述
- 催化消息详情

**北向资金说明**：TDX 接口暂不支持全市场北向资金汇总，此字段以互联网数据为准，并在文件中标注 `(互联网数据，TDX暂不支持)`。

---

### 第五步：生成复盘文件

按照模板格式，将所有数据填入，生成完整 Markdown 文件，保存到：
```
E:/文件/workbody/A股每日复盘_YYYY-MM-DD.md
```

文件末尾新增 `## 数据校验说明` 章节，列出：
- TDX 校验通过的数据项
- 与互联网数据存在矛盾的数据项及修正说明
- 数据局限性说明（如北向资金、涨跌家数的来源）

---

### 第六步：输出复盘摘要

文件生成后，向用户输出：
1. 复盘文件已保存的路径
2. 今日市场核心结论（3~5 条要点）
3. 新手操作建议（针对不熟悉A股的用户）
4. 主要数据校验结果（如有修正，重点说明）

## 重要约定

### 数据优先级

| 优先级 | 来源 | 适用场景 |
|--------|------|---------|
| 1（最高） | TDX 通达信 | 指数行情、涨跌停统计、成交额排行 |
| 2 | westock-data | 板块排行、个股财务数据 |
| 3 | 互联网数据 | 消息面、北向资金、涨跌家数 |

### 文件命名规范

```
A股每日复盘_YYYY-MM-DD.md
```

示例：`A股每日复盘_2026-07-02.md`

### 输出路径

固定输出到：`E:/文件/workbody/`

### 针对新手的特别说明

当用户说"我刚开始做投资/不熟悉A股行情"时，在复盘文件的 `## 新手入门操作建议（明日策略）` 章节中，必须包含：
- 当前建议仓位（□成仓）
- 可关注方向（不超过3个）
- 需回避风险（不超过3个）
- 具体操作纪律（不追高、不抄底、分批建仓等）

## 故障处理

### TDX 工具不可用

如果 `mcp__tdx-connector` 未连接或调用失败：
1. 立即通知用户"通达信（TDX）接口不可用，将使用 westock-data 作为主数据源"
2. 在生成的复盘文件中标注 `(westock-data数据，TDX未连接)`
3. 继续完成复盘生成，不能因 TDX 不可用而中断

### 模板文件不存在

如果 `E:/文件/workbody/` 下没有历史复盘文件：
1. 使用内置默认模板（见 `references/template.md`）
2. 通知用户"未找到历史复盘模板，使用默认格式生成"

### 非交易日

如果目标日期为非交易日（周末或节假日）：
1. 提示用户"YYYY-MM-DD 为非交易日，无行情数据"
2. 询问用户是否复盘最近一个交易日
3. 不生成空文件
