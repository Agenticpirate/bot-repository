# 链家买房/租房决策 Skill

链家是贝壳找房体系内最大的直营中介品牌，以"真房源"机制（真实存在/
真实在售/真实价格）著称。本 skill 帮你把房源页信息读透、把交易
流程的坑排掉。

## 房源页信息怎么读（买二手房）

- **挂牌价 ≠ 成交价**：挂牌普遍留砍价空间。看小区近期**成交记录**
  （链家 App 内小区页→成交）才是真实价格锚点，重点看近 3 个月
  同户型成交单价
- **关键字段核对**：房本年限（满二/满五影响税费巨大）、抵押状态、
  户口情况、是否唯一住房——这四项直接问经纪人并要求写进合同
- **带看话术过滤**："业主诚心卖""马上要涨"是常规话术；
  "近期有客户出价 X 被拒"要求出示记录，多数是逼定手段
- 同小区多套对比：单价差通常来自楼层/朝向/装修/税费差，把税费
  折进总价再比才公平

## 税费构成速算（二手房大头）

| 税种 | 规则要点 |
|------|----------|
| 增值税及附加 | 房本**满 2 年**免征（普宅），不满 2 年约 5.3% |
| 个税 | **满五唯一**免征；否则常见 1% 或差额 20% |
| 契税 | 首套/二套与面积挡位不同，约 1%-3% |
| 中介费 | 链家二手房常见 2%-2.7%（可谈，大额房款务必谈） |

具体税率随政策与城市调整频繁，**签约前以当地不动产登记中心与
链家交易顾问出具的税费试算单为准**，本表只用于理解构成。

## 交易流程与资金安全节点

签约 → 网签 → （买方贷款审批）→ 缴税过户 → 物业交割 → 放款结清

- **资金监管是底线**：首付款走银行/住建部门资金监管账户，
  不直接转给业主个人
- 网签前查封/抵押核验，过户当日拿到回执再释放尾款节点
- 物业交割别省：水电燃气物业费结清+户口迁出约定违约金写进合同

## 租房避坑

- 中介费：链家租房常见月租金的 50%-100%（各城市不同，可谈）
- 合同细节：提前退租违约条款、维修责任归属、押金退还时限
  三处最容易埋雷，签前逐条确认
- "押一付一"若由第三方金融公司放款（租金贷）务必弄清，
  避免人走贷还在

## Agent 典型用法

1. **房源分析**：用户贴房源信息 → 按字段核对清单提问题、
   按成交价锚点判断挂牌水分
2. **税费估算**：给定房本年限/唯一性/首套二套 → 按构成表列
   应缴项与大致比例，并提示以官方试算为准
3. **流程陪跑**：按交易阶段提示当前节点的核验事项与资金安全动作
4. **租房合同审查**：对照避坑清单逐条检查用户的合同条款

## 本 skill 不做什么

- 不预测房价涨跌，不提供投资建议
- 税率/贷款政策随城市与时间变化大，所有数字仅为理解构成用，
  决策以官方与合同文本为准
- 不提供绕过限购/做低合同价避税的方法（违法且有交易风险）
