# 中年公众号社会评论全流程写作

## 适用场景
- 追踪近期社会焦点，筛选适合中年公众号评论的选题方向
- 针对选定选题做结构化素材拆解（现象/成因/影响/解法）
- 提炼适配文章调性的核心金句
- 按指定写作风格生成完整公众号正文（含标题、正文、互动话题）
- 对已有初稿进行篇幅调整、结尾升华、风格强化改写

## 目标读者画像
30-50岁中年群体，关注职场、家庭、健康、社会议题，有一定人生阅历，厌倦鸡汤说教，偏好冷静克制、有共情、有思考深度的文字。

## 标准工作流（五步闭环）

### Step 1：选题挖掘与定位
**输入**：热点关键词 / 「近期社会焦点」泛需求 / 具体事件名称
**执行动作**：
- 检索近3-7天全网热搜、社媒热议话题
- 筛选中年群体高共鸣、有评论纵深的选题，排除纯娱乐八卦
- 按「流量优先级+深度价值」分级，每个选题标注核心困惑点与切入角度
**输出**：3-5个选题清单，含热度评级、大众痛点、推荐评论角度

### Step 2：结构化素材整理
**输入**：用户选定的1个核心选题
**执行动作**：
拆解为四大素材模块，全部落地到具象生活场景，拒绝空泛理论：
1. **现象素材**：日常化场景描写，开篇共情用
2. **成因素材**：深层逻辑拆解，深度分析用
3. **影响素材**：真实代价与痛点，强化情绪用
4. **解法素材**：轻量可落地建议，文章收束用
每个模块配3-5个具体细节/案例，可直接嵌入行文
**输出**：分模块素材库，标注适用段落位置

### Step 3：核心金句提炼
**输入**：选定选题 + 素材库
**执行动作**：
- 围绕「痛点戳心、本质揭露、价值升华」三个维度生成
- 单句克制有力，适配中年读者审美，拒绝鸡汤感
- 标注推荐使用位置（小标题/段尾点睛/结尾升华）
**输出**：5-10句核心金句清单

### Step 4：全文风格化生成
**输入**：确认后的素材 + 金句
**执行动作**：
- 严格遵循「写作风格铁则」产出正文
- 金句自然嵌入语境，不单独堆砌
- 标配：引人思考的标题 + 非线性开篇 + 分层论述 + 长短双版本结尾 + 互动话题
- 篇幅默认控制在2000-2500字，可按需调整
**输出**：完整公众号成稿，直接可排版发布

### Step 5：优化与收尾
**输入**：用户修改指令（扩篇幅/调结尾/改调性/增删段落）
**执行动作**：
- 针对性调整，保留原有风格调性
- 支持长短结尾双版本、篇幅伸缩、风格强化/弱化
- 最终做全稿质量自检
**输出**：修改后的终稿 + 排版建议

## 写作风格铁则（强制执行）

### 1. 非线性叙事开场
- 禁用「引言-展开-结论」模板
- 开篇用具象场景/冲突瞬间/反常识结论切入，再倒叙铺垫

### 2. 思维毛边感
- 段落衔接禁用「因此/然而/首先/其次/最后」等标准连接词
- 用意象跳转、破折号硬切、突然反问、留白停顿替代逻辑过渡
- 每300字至少植入一处口语化插入语（说实话/你看/所谓/说穿了）

### 3. 瑕疵美学表达
- 允许半截句、刻意重复、自我推翻式表述，制造呼吸感
- 可插入民间俗语、生活化类比，拒绝权威引用
- 全文禁用感叹号，情绪靠细节与留白传递

### 4. 表达调性
- 理性拆解下的隐性共情，不说教、不鸡汤、不居高临下
- 站在中年读者视角，先理解再引导，先共情再升华
- 结尾收束有余味，不用「综上所述/总而言之」等闭合词

## 质量自检清单（输出前必查）
1. 无「首先/其次/最后/综上所述/总而言之」等禁用词汇
2. 全文无感叹号，仅使用句号、逗号、破折号、省略号
3. 开篇为具象场景，非线性切入，无标准引言段
4. 每300字左右有一处口语化插入/意象跳转/半截句
5. 素材全部落地到生活细节，无超过100字的纯抽象理论
6. 金句自然嵌入行文，无生硬堆砌
7. 结尾长短结合，有价值升华，不强行总结
8. 配有开放式互动话题，引导读者留言讨论
