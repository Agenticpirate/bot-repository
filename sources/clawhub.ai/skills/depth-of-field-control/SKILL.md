# 景深控制三法则

## R — 原文 (Reading)

> "当某一物体聚焦清晰时，从该物体前面的某一段距离到其后面的某一段距离内的所有景物也都是相当清晰的。焦点相当清晰的这段从前到后的距离就叫做景深...孔径越小（f值越大），景深越大...焦点越远，景深越大...镜头的焦距越短，景深越大。"
>
> — 美国纽约摄影学院，第三章

---

## I — 方法论骨架 (Interpretation)

景深不是技术参数而是创造性手段——不同的景深选择传达不同的信息。控制景深有三大因素：第一，孔径（f值），f值越大（孔径越小）景深越大，f值越小（孔径越大）景深越小，这是最直接的控制手段。第二，聚焦距离，焦点越远景深越大，所以拍远处风光天然景深大，拍近处微距天然景深极小。第三，镜头焦距，焦距越短（广角）景深越大，焦距越长（长焦）景深越小。三个因素可以组合使用：要最大景深就用广角+小光圈+对远处聚焦（配合超焦距技术可从前景延伸到无穷远）；要最小景深就用长焦+大光圈+靠近被摄体。

## A1 — 书中的应用 (Past Application)

### 案例 1: 中国象棋棋子景深实验
- **问题**: 直观展示孔径对景深的控制效果
- **方法论的使用**: 所有照片聚焦在"马"上，只改变孔径：f/2时只有"马"清晰；f/8时"兵"和"车"进入清晰范围；f/16时四个棋子都相当清晰。
- **结论**: 孔径是控制景深最直接的手段
- **结果**: 经典教学演示

### 案例 2: 职业摄影师的景深选择
- **问题**: 如何用景深隔离主体或保留环境
- **方法论的使用**: 查尔斯·穆尔用大孔径浅景深将女性从热闹场面中拉出，注意力固定在面孔上。苏珊·麦卡特尼用足够景深保留充分背景加强主题。弗雷德·莱昂用小孔径最大景深+高视点拍摄旧金山湾，海鸥突然出现产生强烈的比例和距离感。
- **结论**: 景深选择直接服务于主题表达
- **结果**: 证明了景深是创造性手段

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行：

1. **确定景深目标**
   - 完成标准: 明确用户需要浅景深（隔离主体）还是大景深（全景清晰）

2. **调整孔径（最直接手段）**
   - 完成标准: 浅景深→建议f/1.4-f/2.8；大景深→建议f/8-f/16
   - 注意: 需同步调整快门速度保持曝光量（互易律）

3. **调整焦距和距离（辅助手段）**
   - 完成标准: 浅景深→建议用长焦+靠近被摄体；大景深→建议用广角+对远处聚焦
   - 判停条件: 若手机拍摄→解释手机镜头焦距极短导致天然景深大，建议用人像模式或靠近被摄体

4. **高级技术：超焦距（风光摄影）**
   - 完成标准: 若用户需要从前景到无穷远都清晰，介绍超焦距设置方法
   - 方法: 设最小孔径→将无穷远标志对准景深标尺右边的f值数字

## B — 边界 (Boundary)

### 不要在以下情况使用此 skill
- 曝光量计算问题 → 应调用 exposure-dual-control
- 聚焦不清晰（对焦失误）→ 是聚焦技术问题，不是景深问题
- 数码后期虚化（人像模式算法虚化）→ 本 skill 关注光学景深

### 作者在书中警告的失败模式
- "头上长树"——大景深使背景进入焦点，背景干扰物与主体融合
- 微距摄影清晰范围极小，距离变化不到1/4英寸就会失去清晰焦点

### 作者的盲点 / 时代局限
- 数码时代手机/计算摄影可通过算法模拟浅景深，不完全依赖光学景深
- 未涉及数码传感器的裁切系数对等效焦距和景深的影响
