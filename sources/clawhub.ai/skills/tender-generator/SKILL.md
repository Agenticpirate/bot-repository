# 专业标书生成器 V3 (Tender Generator Pro)

通过对话式交互收集项目信息，自动填充模板生成全套规范化投标文档。

## 🚀 核心能力

| 能力 | 说明 |
|------|------|
| 对话式信息采集 | 渐进式提问，每次1-2个问题 |
| 智能信息提取 | 从文本/文档自动提取关键信息 |
| 多行业模板 | 默认/IT/建筑/服务行业模板 |
| 专业文档样式 | 页眉页脚、统一字体、专业排版 |
| 合规自检 | 扫描未填充占位符和关键信息缺失 |
| 批量生成 | 支持一次生成多个项目 |
| 信息校验 | 自动校验格式一致性 |
| 一键打包 | 生成带时间戳的zip压缩包 |

## 📋 工作流程

### 步骤 1: 初始化与模板选择

1. 问候用户，确认生成意图
2. 三级模板决策：
   - **优先级1**：用户指定模板（如"用IT行业模板"）
   - **优先级2**：用户上传模板压缩包
   - **优先级3**：列出可用模板，让用户选择
3. 检查模板完整性，缺失文档自动补全
4. 展示选定模板清单，请求用户确认

**可用模板**：
```
templates/
├── default/      # 默认通用模板
├── it/           # IT行业模板
├── construction/ # 建筑工程模板
└── service/      # 服务行业模板
```

### 步骤 2: 信息收集

遵循"渐进式提问"原则，每次1-2个问题。

**必填信息**：

| 类别 | 字段 | 占位符 |
|------|------|--------|
| 项目 | 项目名称 | `{{project_name}}` |
| 项目 | 项目编号 | `{{tender_number}}` |
| 公司 | 公司全称 | `{{company_name}}` |
| 公司 | 统一社会信用代码 | `{{credit_code}}` |
| 公司 | 授权代表 | `{{authorized_rep}}` |
| 财务 | 总报价 | `{{total_price}}` |

**选填信息**：
- 招标人、截止日期、地址、法定代表人
- 银行信息、联系电话、报价明细等

**智能萃取**：如果用户粘贴大段文字或上传文档，自动提取信息并整理成清单供确认。

### 步骤 3: 信息确认与锁定

生成《信息确认单》，汇总所有已收集信息，请求用户最终确认。

### 步骤 4: 执行文件生成

1. 加载模板文档
2. 替换占位符
3. 添加专业样式（页眉页脚）
4. 处理技术文档

### 步骤 5: 合规自检

- 检查未填充占位符
- 校验关键信息完整性
- 验证格式一致性
- 生成《待补充材料清单》

### 步骤 6: 打包交付

1. 生成带时间戳的zip包
2. 报告生成结果
3. 提示需手动替换的材料

## 🛠️ 使用方式

### 方式一：对话引导（推荐）

直接说："帮我生成一套标书"，系统引导完成全流程。

### 方式二：命令行快速生成

```bash
# 基本用法
python3 scripts/generate_bid.py --info info.json --output ./output

# 指定模板
python3 scripts/generate_bid.py --info info.json --template it --output ./output

# 使用技术文档
python3 scripts/generate_bid.py --info info.json --tma TMA.docx --output ./output
```

### 方式三：交互式收集

```bash
python3 scripts/generate_bid.py --interactive
```

### 方式四：从文档提取信息

```bash
# 从文本提取
python3 scripts/generate_bid.py --extract project.txt --output info.json

# 从Word文档提取
python3 scripts/generate_bid.py --extract proposal.docx --output info.json
```

### 方式五：校验信息

```bash
python3 scripts/generate_bid.py --info info.json --validate
```

## 📁 模板结构

每个模板文件夹包含：

| 序号 | 文件名 | 必填 | 说明 |
|------|--------|------|------|
| 1 | `00-封面.docx` | 是 | 项目封面 |
| 2 | `01-承诺书.docx` | 是 | 投标承诺书 |
| 3 | `02-资质文件.docx` | 是 | 资质能力证明 |
| 4 | `03-报价明细.docx` | 是 | 报价单 |
| 5 | `04-偏离说明.docx` | 是 | 技术/商务偏离表 |
| 6 | `05-技术方案.docx` | 是 | 技术实施方案 |
| 7 | `06-业绩材料.docx` | 否 | 过往业绩证明 |
| 8 | `07-审计报告.docx` | 否 | 财务审计报告 |

## ⚠️ 核心约束

- **数据不可变**：严禁修改用户提供的具体数据
- **对话驱动**：所有信息收集必须在对话框内完成
- **隐私保护**：敏感信息不记录到公开日志
- **专业风格**：统一字体、专业排版、页眉页脚
