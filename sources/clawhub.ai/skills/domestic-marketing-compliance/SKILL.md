# 国内营销文案合规指南

## 加载须知

当用户要求撰写国内营销文案（公众号推文、抖音脚本、小红书笔记、电商详情页、直播话术、广告文案等）时，必须加载本 skill。按平台分类处理，不可混用规则。

**配合使用：** 同时加载 `marketing-copy-generation` skill 获取生成方法论（打动人心、渠道融合、突出价值、去AI味等11条原则）。本 skill 负责合规避坑，marketing-copy-generation 负责怎么写好。两 skill 配套使用，缺一不可。

## 一、广告法全平台通用红线（绝对禁止）

所有平台（抖音、小红书、快手、微信、视频号）均适用，触发即封号/罚款。

### 1.1 绝对化/极限用语

**"最"字系：** 最、最佳、最具、最爱、最赚、最优、最优秀、最好、最大、最高、最高级、最高档、最奢侈、最低、最低价、最底、最便宜、最流行、最受欢迎、最时尚、最聚拢、最符合、最舒适、最先、最先进、最新、最新科技、最新科学、最前沿。

**"一"字系：** 第一、中国第一、全网第一、销量第一、排名第一、唯一、第一品牌、NO.1、TOP.1、独一无二、全国第一、全球第一、仅此一次、仅此一款、最后一波、一天（仅限一天）、一流、首个、首选、首款、首家、独家配方（无专利证明）、填补国内空白。

**"级/极"字系：** 国家级（相关单位颁发除外）、全球级、宇宙级、世界级、顶级（顶尖/尖端）、顶级工艺、顶级享受、高级、极品、极佳（绝佳/绝对）、终极、极致、致极、极具、完美、至尊、至臻、臻品、巅峰、问鼎、之王、王者、缔造者、统领。

**虚假/夸大系：** 史无前例、前无古人、永久、万能、祖传、特效、无敌、纯天然（需证明）、100%、百分百、零风险、无毒副作用、无依赖、绝无仅有、空前绝后、绝版。

### 1.2 权威性/国家形象引用

禁止：国家领导人推荐、国家XX机关推荐/专供/特供、国宴专用、人民大会堂、军队/武警专供。

禁止：质量免检、无需国家质量检测、免抽检、国家免检。

禁止：人民币图样（央行批准除外）、违规使用"中国驰名商标"、"老字号"（无授权）。

### 1.3 迷信/封建/不良导向

禁止：带来好运气、增强第六感、化解小人、增加事业运、招财进宝、健康富贵、提升运气、有助事业、护身、平衡正负能量、转富招福、逢凶化吉、时来运转、旺人、旺财、镇宅、消灾、挡灾、助吉避凶、转运、水逆、算命、看相、风水、龙脉、神仙保佑、显灵、超度。

禁止：屌丝、绿茶婊、渣男/女（视语境降权）、暴富、躺赚、不劳而获。

### 1.4 医疗/功效类（普通商品严禁）

**治疗承诺：** 治疗、治愈、治愈率、根除、抗炎、消炎、活血、祛瘀、止咳、解毒、疗效、防治、防癌、抗癌、肿瘤、增高、益智、复活、再生。

**药用混淆：** 处方、复方、中药、中草药、改善内分泌、补肾、壮阳、荷尔蒙、抗生素、激素、药妆（中国法规已禁用此词）。

**绝对效果承诺：** 不反弹、无效退款、无副作用、一针见效、根治、彻底康复、永不复发、包治百病、安全无风险。

### 1.5 通用替换词表

| 原词（违禁） | 建议替换 |
|:---|:---|
| 第一、No.1、Top1 | 头部、领跑、佼佼者、前列、首要 |
| 唯一、独家 | 特色、少有、匠心、差异化 |
| 最（最好、最佳、最强） | 较、理想、出色、优选、宝藏 |
| 顶级、顶尖、极品 | 高端、资深、精选、高阶 |
| 完美 | 理想、圆满、精致、令人满意 |
| 万能 | 多功能、全能、多用途 |
| 永久 | 长久、耐用、持久 |
| 治疗/治愈 | 改善、缓解、修护、调节 |
| 根除/根治 | 帮助减少、逐步改善 |
| 减肥/瘦身/溶脂 | 减脂、管理身材、轻盈、体态管理 |
| 美白（无特证） | 提亮、去黄、光泽 |
| 祛斑（无特证） | 淡斑、匀净肤色、对抗暗沉 |
| 杀菌/消毒 | 清洁、净澈、去污 |
| 秒杀/抢光 | 限时、惊喜价、手慢无、福利价 |
| 赚钱/暴富 | 收获、变现、创收 |
| 0风险/稳赚/保本 | 稳健、低波动（需加风险提示） |

## 二、微信生态风控（分级阻断）

微信审核三层次：封号级红线 → 降权折叠词 → 行业特供词。

### 2.1 封号级红线（强制拒绝生成）

时政红线、色情低俗、欺诈黑产、绝对违禁品（电子烟/特效药/仿真枪等）。

### 2.2 降权折叠词

**诱导分享：** 不转不是中国人、转疯了、必转、转发后一生平安。替换：欢迎分享给有需要的朋友。

**诱导关注：** 关注后看答案、回复XX获取、点击领取红包。替换：更多内容详见...

**标题党：** 震惊、刚刚曝光、惊天内幕、紧急通知（非官方）、速看马上删。替换：量化信息式标题，如"XX研究显示：XX成分或有助于缓解XX症状"。

**营销垃圾词（密度控制）：** 代理、加盟、招商、爆款、躺赚、暴利、微商。同一篇文中出现超5次可能降权，用"合作伙伴"、"事业机会"替换。

### 2.3 AI生成内容标注（2025新规）

AI生成文章如未标注"由AI生成"且涉及虚假信息，账号将被重罚。建议默认在末尾添加："*本文部分内容由 AI 辅助生成*"。

## 三、抖音规则

### 3.1 诱导互动（重灾区）

**违规：** "扣666"、"扣1"、"公屏打出想要"、"点赞到XX万发货"、"截屏抽奖"、"送福利"（无明确规则）。

**替换：** "喜欢的粉丝宝宝点点关注"、"想参与的在评论区互动一下"。

### 3.2 抖音专用替换表达

| 违禁词 | 安全替换 |
|:---|:---|
| 随时结束 | 卖完就结束 |
| 仅此一次 | 今天只安排了这一次 |
| 马上涨价 | 卖完就恢复日常价 |
| 最后一次/波 | 卖完就结束了 |
| 全网/全球/独家 | 我们的（搭配手势）、非常少见 |
| 秒杀 | 秒一个、炸一个 |
| 抢/抢爆 | 拼手速、没抢到就没有了 |
| 不会再便宜了 | 这个价我尽力了 |
| 万人疯抢 | 很多宝宝都在买、断货好久了 |
| 奢侈/奢华 | 小资、品质、精致 |
| 100%/纯 | 纯...（留白）、选它没错 |
| 祛黑头/祛痘 | 叠词法（痘痘）、清洁毛孔 |
| 美白 | 提亮、光泽、近音法（米白） |
| 增强免疫力 | 防御外界不良因素的那个力 |

### 3.3 演戏/剧本违规

禁止：工厂倒闭、老板跑了、离婚卖货、破产清算、身患重病、孤儿等卖惨剧本。

### 3.4 导流红线

禁止引导到微信/站外。禁止：微信、VX、二维码、主页有联系方式、私信。拼音/变体也会被ASR识别。

### 3.5 直播行为规范

禁止：挂机直播、抽烟喝酒、着装暴露、展示纹身、未成年人单独出镜。

## 四、小红书规则

### 4.1 反黑话机制

小红书能识别拼音/谐音/变体，且会判定为**恶意规避**，处罚更重。

**禁止：** VX、绿泡泡、多少米、多少Q、马内、jg、m感肌、敏敏肌、蹲（暗示私信）。

**正确做法：** 直接说"价格"、"多少钱"、"预算"。

### 4.2 站外导流（红线）

任何变体都无法绕过系统检测。建议引导在平台内成交。

### 4.3 美妆医美（重灾区）

**无特证不得宣传：** 美白→提亮、祛斑→淡斑、防晒→物理遮蔽。

**禁止医疗术语：** 抗炎/消炎→舒缓/修护/改善泛红。活血、排毒→净澈。

**禁止速效承诺：** 一洗白、XX天见效、永不褪色。

**禁止伪科学：** 换脸、回春、逆龄、量子护肤、激活细胞。

**塑形类：** 溶脂/吸脂/燃烧脂肪→身体管理/控卡/轻盈/体态管理。

### 4.4 食品保健

禁止：治疗便秘、通便、增强免疫力、防癌抗癌、助眠、治疗失眠。

替换：膳食纤维丰富、帮肠道做运动、补充营养、强健体魄、睡前好物、享受宁静夜晚。

### 4.5 水晶珠宝

禁止：招财、化解小人、转运、旺财。

允许：寓意美好、寄托希望、好心情。仅保留文化寓意。

### 4.6 社区氛围

禁止炫富、焦虑营销、低俗展示（密集恐惧/分泌物/伤口特写等）。

## 五、小红书文案撰写方法论

### 5.1 核心定位与受众

小红书主要群体以年轻女性为主。内容风格需：
- 贴近年轻女性喜好和习惯
- 语言活泼、有亲和力
- 注重情感共鸣
- 生活方式分享为主，避免过度商业化和广告化语言

### 5.2 内容撰写框架

**核心公式：痛点冲突 × 解决方案 × 社交货币**

案例模板：
- 标题：\"毛孔粗大十年，美容师表姐教我这样解决\"
- 内容：左脸vs右脸对比实验（原相机拍摄）
- 钩子：\"评论区发照片免费分析肤质\"

### 5.3 四大原则

1. **真实性优先：** 小红书极度重视真实体验分享。内容要贴近用户真实生活和体验，分享真实使用感受。禁止过度夸大宣传。
2. **生活指引式写作：** 以经验分享的方式为用户解决具体生活问题，进行场景化描述。可以是通用问题，也可以是细分场景问题，都容易获得推荐流量。
3. **长尾关键词：** 每篇内容自然嵌入3-5个长尾关键词，提高搜索和推荐效果。
4. **情绪共鸣：** 适当加入情绪内容，引起用户情感共鸣。

### 5.4 标签规范

- 每篇笔记不超过 **5个标签**，超过会被判定滥用降权
- 优先使用广泛传播的热门标签，增加推荐概率
- 可搭配小众精准标签，增加被目标用户发现的概率

### 5.5 标题创作体系

**标题三板斧自查清单：**
1. 是否绑定具体人群（学生党/新手妈妈/打工人）
2. 是否给出明确利益（省1万/多睡2小时/5分钟搞定）
3. 是否制造认知冲突（竟被/才发现/千万别）

**长效爆款标题结构：**

**美妆个护类：**
- 数字悬念+效果可视化：\"28天换头计划！塌鼻梁→妈生鼻的修容地图\"（公式：时间+身体部位对比+专业术语包装）
- 数据+稀缺词：\"被追问800次的伪素颜密码！油痘肌的早八作弊器\"（\"作弊器\"\"密码\"类词标题点击率高22%）
- 社交认证+精准人群：\"被闺蜜追着问链接的3支口红！黄黑皮亲妈显白到发光\"
- 反常识挑战+结果背书：\"不运动不节食！吃瘦18斤的食谱竟被健身教练偷学\"（\"竟被XX偷学\"类比均值高47%）
- 禁止式引导：\"千万别学这个睫毛画法！怕你被误会做了角蛋白\"

**母婴育儿类：**
- 身份认同+避坑指南：\"高敏感宝宝妈妈必看！这5个哄睡神器让我多活2年\"（用\"多活X年\"替代\"省心\"）
- 家庭冲突+结果逆袭：\"婆婆说我毁了孩子！语言迟缓干预半年后打脸现场\"
- 紧急预警+权威背书：\"儿保医生拦下我的辅食碗！这些网红产品竟会贫血\"

**家居好物类：**
- 低价高质+社交货币：\"被邻居误认豪宅的客厅！其实全是1688同源厂\"（\"误认\"制造反差+\"同源厂\"暗示性价比）
- 神器种草+使用场景：\"南方回南天保命指南！这7个神器让蟑螂连夜搬家\"

**知识干货类：**
- 行业黑话+利益承诺：\"新媒体人速存！把信息差变成摇钱树的18个野路子\"（\"野路子\"收藏率高65%）
- 失败经验+数据支撑：\"烧光50万才明白！小白开咖啡馆必看的7个生死线\"（损失敏感度是获得的2倍）
- 资源福利+紧迫感：\"限时删！留学生都在抢的50G论文神器安装包\"

### 5.6 敏感词替换（小红书特供）

| 违禁词 | 替换方案 |
|:---|:---|
| 史上最全 | 保姆级 |
| 永久有效 | 亲测三年 |
| 绝对 | 90%人不知道 |
| 医疗相关词（治疗等） | 养护方案 |
| 教育提分相关 | 学习思路 |

### 5.7 黄金法则

1. **绑定具体人群**（学生党/新手妈妈/打工人/油痘肌）
2. **制造认知冲突**（\"千万别\"\"竟然\"\"才发现\"）
3. **量化利益点**（省1万/快30分钟/多睡2小时）
4. **去AI味，像真人分享**——避免模板化、过于完美的句式堆砌

## 六、行业特供规则

### 6.1 金融

禁止：保本、无风险、稳赚不赔、100%收益。必须加风险提示。

### 6.2 房产

禁止：收益稳健、保证升值、即买即收租、XX分钟可达车站/机场、学区房承诺。

### 6.3 教育培训

禁止：记忆效率提升百倍、7天记住永不忘、通过率XX%、高分王者、命题专家联手。

### 6.4 药品/医疗器械

禁止：安全无毒副作用、无效退款、当天见效、治愈率XX%、彻底治愈、显著改善。必须标注"请按药品说明书或者在药师指导下购买和使用"。

## 七、使用流程

1. 用户要求撰写文案时，先确认目标平台（公众号/抖音/小红书/全平台）
2. 按对应平台的规则审核内容
3. 逐条检查：绝对化用语、医疗功效、迷信、导流诱导、行业特供词
4. 使用替换词表进行修改
5. 输出最终文案
