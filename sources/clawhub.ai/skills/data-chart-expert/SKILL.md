# 数据图表解析

## 任务目标

将用户粘贴的原始数据转换为可执行的图表方案和可直接用于论文、报告的客观文字。默认交付图表推荐、标题与图例文案、数据解读三部分；只有用户明确要求实际绘图时，才使用当前可用工具生成图表文件，同时保留三部分文字结果。

## 工作流程

1. 识别研究对象、指标、单位、分组、时间或顺序变量、样本量，以及用户希望回答的问题。
2. 将 Markdown 表格、CSV、制表符、空格分隔或从电子表格复制的内容还原为行列清楚的数据表。
3. 检查缺失值、重复项、单位混用、百分比与小数混用、类别是否互斥、时间顺序和合计关系。不要静默修正原始数据。
4. 计算支持解读所需的派生量，包括最大值、最小值、排序、绝对差、相对变化率、百分比的百分点差，以及时间序列的起止变化和转折点。
5. 根据数据结构和研究问题选择一种首选图表；只有备选图表能回答不同问题时才补充一个备选方案。
6. 生成完整标题、轴标题、单位、图例与图注，并按“事实—比较—结论”的顺序撰写解读。
7. 复核所有数字、计算口径和结论强度，确保文字能够由输入数据直接支持。

## 数据理解与校验

- 保留原始数据的行列含义，不自行删除异常值、补齐缺失值、合并类别或取平均值。
- 不自行创建复合类别或合并多个原始选项。只有用户明确要求，或研究问题明确需要且类别含义允许时才计算合并值，并将其标注为“分析性合并”，不得替代原始分类结论。
- 单位或表头缺失但仍可分析时，使用 `【待确认：指标/单位】` 标记，并基于明确写出的假设继续输出。
- 只有纯数字且完全无法判断行列含义时，先用“第1列”“第2组”等中性名称描述；若不同解释会改变图表类型或结论，只询问一个最关键的问题。
- 时间标签可无歧义排序时按时间顺序处理，并在数据说明中注明；无法确认顺序时保持用户原顺序。
- 将百分比值之间的差写成“百分点”，例如 60% 与 45% 相差 15 个百分点；只有明确基准时才写相对增长率。
- 计算相对变化率时使用 `(比较值 - 基准值) / 基准值 × 100%`，明确指出基准；基准为 0 时不计算百分比变化。
- 用户同时提供样本量和百分比时，不把可能经过四舍五入的百分比反推为精确人数。只有能确认百分比由精确计数得到，或用户明确要求估算时才换算人数；无法确认时使用“约”并说明换算口径。
- 派生结果的精度与原始数据相称，避免用过多小数制造虚假精确性。

## 图表选择规则

| 数据结构与目的 | 首选图表 | 使用要点 |
| --- | --- | --- |
| 连续时间、年级、阶段或其他有序序列，重点观察变化趋势 | 折线图 | 横轴使用有序变量，纵轴使用指标；多组数据使用多条线和清楚图例 |
| 离散类别、实验组与对照组、多个对象之间比较数值高低 | 柱状图 | 单系列用普通柱状图，多组并列比较用分组柱状图，构成比较可用堆叠柱状图 |
| 单一时点的整体构成，各类别互斥、非负且合计约为 100% | 饼图 | 类别控制在 6 个以内，按占比排序并直接标注类别与百分比 |

同时遵守以下限制：

- 不对无序类别使用折线图，以免暗示不存在的连续关系。
- 不用多个饼图承担精确组间比较；此时改用分组或堆叠柱状图。
- 构成项不互斥、含负值、合计明显不等于整体或类别过多时，不推荐饼图。
- 类别名称较长或类别较多时，推荐横向柱状图；保持“柱状图”这一主类型。
- 柱状图数值轴原则上从 0 开始；若必须截断坐标轴，明确披露，避免夸大差异。
- 避免 3D、双纵轴、装饰性渐变和过多颜色。让颜色服务于分组，保证文字、数据标签和图例易读。

## 分析与结论规则

- 先报告可核验的数值事实，再解释趋势或差异，不使用“明显”“大幅”“优势突出”等无量化依据的词。
- 趋势分析至少覆盖起点、终点、总体方向、峰值或谷值，以及存在时的转折或波动；不要只写“总体上升/下降”。
- 对比分析指出比较对象、具体数值、绝对差，并在基准明确且有意义时给出相对差。
- 优先比较用户给出的原始类别，不增加未经请求的类别合计、重新分组或衍生排名结论。
- 处理实验组与对照组时，说明处理方向和效应大小；将结论限定为“在本实验条件与观测范围内”。
- 只有用户提供统计检验结果，或数据足以完成并确实完成了合适的统计检验时，才使用“统计显著”“显著差异”。否则使用“数值上更高/更低”并说明尚不能判断统计显著性。
- 只有重复观测或原始样本数据足够时才计算均值、标准差、置信区间或进行显著性检验；不要从单个汇总值虚构离散程度、样本量、误差线或 p 值。
- 不把相关关系写成因果关系。调研数据默认只描述本次样本，不自动外推到总体；实验设计不足以支持因果时使用“结果支持/提示”，不要写“证明”。
- 数据质量或设计限制会实质影响结论时，在结果末尾用一句话指出具体限制，不添加与当前数据无关的通用免责声明。

## 标题、图例与图注

- 使用“研究对象 + 指标 + 分组或时间范围”的信息型标题，例如“2021—2025年某校高一年级数学平均成绩变化”。
- 在轴标题中写出变量名和单位，例如“年份”“平均成绩（分）”；饼图无需坐标轴。
- 图例只保留真正需要区分的系列，并写明颜色或线型对应的组别，不重复已经由横轴表达的信息。
- 图注解释缩写、样本范围、统计量和必要口径。没有来源、样本量或误差定义时不要自行补写。
- 让可复制的图表说明包含研究对象、比较范围、关键趋势和主要差异，但不要在图注中重复整段讨论。

## 固定输出格式

除非用户指定其他格式，严格输出以下三部分：

### ① 推荐适配图表样式

写明：

- `推荐图表：` 图表主类型与必要子类型。
- `推荐理由：` 数据结构与研究问题为什么适合该图表。
- `绘制方案：` 横轴、纵轴、单位、系列或图例、排序方式和数据标签。
- `数据说明：` 仅在存在假设、缺失、异常或口径风险时添加。

### ② 完整图表标题 + 图例描述文案

按以下字段提供：

- `图表标题：`
- `横轴：` 与 `纵轴：`，饼图则省略。
- `图例描述：`
- `图注（可直接复制）：` 用一段完整、客观、简洁的文字描述图表内容。

### ③ 数据趋势、对比差异与实验结论

先用要点列出关键趋势和对比，再给出 `结果表述（可直接用于论文/报告）：`。结果表述使用一段连贯文字，包含必要的具体数值、比较基准、结论边界和确有必要的限制。

## 实际绘图

用户明确要求生成图表图片或电子表格内图表时：

1. 使用当前环境可用的电子表格或绘图工具，保留一份可追溯的原始数据表。
2. 按本技能推荐的编码、单位、排序和样式绘图，不以美化为由修改数据。
3. 检查标题、轴标签、图例、中文字体和数据标签是否清晰，避免标签重叠或裁切。
4. 交付生成文件，并继续输出固定的三部分文字说明。

## 典型调用示例

- “粘贴这份用户调研数据，推荐合适图表类型，撰写图表描述文字，分析数据差异。”
- “分析以下实验对比原始数据，生成柱状图文字解读，提炼可直接放进论文结果部分的有效结论。”
- “根据这份历年成绩统计数据分析变化趋势，写一段标准图表说明文本。”
