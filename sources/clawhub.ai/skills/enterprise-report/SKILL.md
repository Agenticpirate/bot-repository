# 中国企业尽职调查报告生成

## 概述

通过聚合多个公开企业信息平台的搜索数据，生成一份结构化HTML企业尽职调查报告。报告涵盖工商登记、股权穿透、实际控制人、司法风险、经营状态、关联企业等12个核心板块。

## 工作流程

### 第一步：多源并行搜索

使用 WebSearch 工具，分批次搜索以下信息，每次可并行发起多个独立搜索：

**第1批 — 基础工商信息（并行搜索）：**
- 使用 `query_keyword_groups` 同时搜索：
  - `"{企业名称} 工商信息"`
  - `"{企业名称} 企查查"`
  - `"{企业名称} 天眼查 股东"`
  - `"{企业名称} 爱企查"`
  - `"{企业名称} 启信宝"`

**第2批 — 风险与司法信息（并行搜索）：**
- 使用 `query_keyword_groups` 同时搜索：
  - `"{企业名称} 司法案件"`
  - `"{企业名称} 行政处罚 经营异常 失信"`
  - `"{企业名称} 裁判文书"`
  - `"{企业名称} 开庭公告 立案信息"`

**第3批 — 关联方与层级穿透（并行搜索）：**
- 搜索母公司/股东：`"{母公司名称} 企业信息 股东 法定代表人"`
- 搜索实际控制人：`"{法定代表人姓名} 关联企业 任职 限制高消费"`
- 搜索关联体系：`"{疑似品牌/体系名称} {法定代表人姓名} 关联企业"`
- 搜索裁判文书：`""{企业名称}" 判决书 诉讼 法院 案件"` (使用精确匹配)

### 第二步：数据整理与报告结构

从搜索结果中提取关键数据，按以下结构组织。详细数据采集清单见 `references/data-sources.md`。

报告12个板块：
1. **工商登记基本信息** — 企业名称、统一社会信用代码、法定代表人、注册资本（实缴/认缴）、成立日期、经营状态、企业类型、行业、注册地址、登记机关、参保人数、纳税人资质
2. **经营范围** — 主营业务许可项目、经营范围变更历史
3. **股东及股权结构** — 股权穿透图（法人/自然人→母公司→目标公司）、母公司基本信息
4. **实际控制人与最终受益人** — 控制人姓名、任职企业数量、关联体系、个人风险记录
5. **主要管理人员** — 董监高姓名、职务、关联企业数、个人风险标签
6. **联系方式与公开信息** — 电话、邮箱、官网、备案
7. **风险全景分析** — 自身风险、关联风险、司法风险、执行风险、法定代表人风险
8. **历史变更记录** — 名称、法定代表人、注册资本、地址、经营范围、主要人员变更次数及关键信息
9. **分支机构与对外投资** — 分公司数、对外投资数、控股企业数
10. **行政许可与年报** — 行政许可数量、年报公示连续性
11. **综合评价与建议** — 风险评级（法律合规/信用/经营稳定性/年报合规性四个维度）、优势与风险要点、总体结论
12. **数据来源与声明** — 逐一标注信息来源、免责声明

### 第三步：生成HTML报告

使用 `assets/report-template.html` 作为模板，替换其中的占位内容：

报告中需要填充的关键元素：
- 企业名称（含英文翻译）
- 报告日期
- 各类风险数字统计卡片
- 股权穿透 SVG 或 CSS 图表
- 评分进度条（法律合规风险/信用风险/经营稳定性/年报合规性）
- 优势与风险要点列表
- 总体结论

**样式规范：**
- 背景 `#f5f6f8`，卡片白色 `#fff`
- 主色调 `#1e5fb4`（蓝色）
- 风险色 `#d32f2f`（红色）、警告色 `#e67e22`（橙色）、安全色 `#27ae60`（绿色）
- 字体优先使用系统字体栈：`-apple-system, BlinkMacSystemFont, "Segoe UI", "PingFang SC", "Microsoft YaHei"`
- 风险评级进度条宽度根据严重程度设置（低0-30%、中30-60%、高60-100%）

### 第四步：风险评级规则

| 风险维度 | 低风险 | 中风险 | 高风险 |
|---------|-------|-------|-------|
| 自身风险条数 | 0-5 | 6-20 | >20 |
| 关联风险条数 | 0-10 | 11-50 | >50 |
| 司法案件数 | 0-3 | 4-15 | >15 |
| 法定代表人限高 | 0 | 1-3 | >3 |
| 母公司是否失信 | 否 | — | 是 |

根据以上维度综合评定，输出总体风险评级和建议。
