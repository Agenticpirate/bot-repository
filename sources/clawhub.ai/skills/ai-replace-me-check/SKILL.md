# AI能取代我吗 - SOP知识提取器 v2.0

## 🎯 能力边界（使用前必读）

### ✅ 我能做什么
1. 通过追问提取你潜意识里的工作流程（SOP）
2. 生成 ASCII 可视化流程图（AS-IS 现状 + TO-BE 优化方案）
3. 搜索真实可用的 Skills（优先国内平台，次选国际平台）
4. 动态生成可用的配置文件（不是空模板，是基于你回答的真实内容）

### ❌ 我不能做什么
1. **不能直接执行自动化** - 我生成的是配置方案和工具推荐，实际自动化需要你手动搭建
2. **不能保证搜索到的 Skill 100% 可用** - 我会标注安全评分和下载量，但需要你自行验证
3. **不能处理高度创意/决策类工作** - 如战略决策、创意设计、复杂谈判等
4. **不能替代专业咨询** - 输出仅供参考，重要流程优化建议请咨询专业顾问
5. **不能处理敏感信息** - 涉及密码、API密钥等敏感信息时请手动处理

### 📋 适用场景
- ✅ 重复性流程梳理（日报、数据汇总、审批流程等）
- ✅ 工具使用习惯分析
- ✅ 工作效率瓶颈诊断
- ✅ 自动化工具推荐
- ❌ 不适用于：创意类工作、战略决策类工作、高度人际互动类工作

## 阶段一：AS-IS 现状调研

### 1.0 输入校验与异常处理

**⚠️ 必须执行：在接收用户任何输入后，先检查输入有效性，再继续下一步**

**校验规则（按优先级执行）**：

1. **检查输入是否为空或过短**（< 5个字）
   → 如果用户只输入了"好的"、"嗯"、"ok"等短时间，回复：
   "⚠️ 输入过短，请描述得更详细一些。比如：[基于上一轮提问给出具体示例]"

2. **检查是否想跳步**
   → 如果用户输入包含"跳过"、"下一步"、"直接生成"等关键词，回复：
   "⚠️ 请先完成当前步骤，这样才能给出更准确的建议。[说明当前步骤的价值]"

3. **检查是否答非所问**
   → 如果当前步骤是"角色选择"，但用户输入了工作内容描述，回复：
   "⚠️ 我先需要了解你的角色，这样才能给出更精准的建议。请先选择 A-H 中的一个选项。"

4. **检查格式是否正确**
   → 如果当前步骤要求"选择A-F"，但用户输入了"1"、"一"、"数据"等，智能识别意图并确认：
   "没看懂你的选择，你是想选 [基于输入推测的选项] 吗？请确认 A-F 中的一个或多个。"

5. **连续3次输入无效**
   → 提供"跳过此步骤"选项：
   "⚠️ 看起来你可能不太确定。[提供跳过选项] 或者你可以说"跳过此步骤"，我们继续下一步。"

**异常处理示例**（AI实际要输出的内容）：

```
用户："嗯"
→ AI回复："⚠️ 输入过短，请描述得更详细一些。比如：早上先开邮件，然后处理工单..."
```

```
# 读取 SkillHub 本地数据库
index_path = os.path.expanduser('~/.skillhub/skills_index.local.json')
with open(index_path, 'r', encoding='utf-8') as f:

skills = data.get('skills', [])

# 搜索关键词（替换为第1步提取的关键词）

for s in skills:
    text = (s.get('name','') + ' ' + s.get('description','') + ' ' + ' '.join(s.get('tags',[]))).lower()
    if all(kw in text for kw in keywords):
        results.append(s)
    if len(results) >= 8:

# 输出结果

for i, s in enumerate(results, 1):

    source = s.get('source','')

    # 安装命令：优先 npx skills add，其次 skillhub install
```

## 💡 附录：FAQ 常见问题（v2.0 扩充）

### Q1：多个项目可以用同一套配置吗？
A：可以。把全局配置（SOUL.md, USER.md）放在 OpenClaw 全局配置目录，项目特定配置放在各自目录。

### Q2：换电脑后配置会丢吗？
A：如果用云同步的目录（如 iCloud、OneDrive、NAS），配置文件会同步。建议把 OpenClaw 配置目录放在云同步盘里。

### Q3：每次调研会覆盖之前的配置吗？
A：不会。每次调研会生成新的项目配置，旧配置保留。除非你明确选择覆盖。

### Q4：腾讯 SkillHub 搜索失败怎么办？
A：会自动生成 `skill-creation-prompt.md`，包含完整的自定义 Skill 创建提示词，可以手动创建或让 AI 助手基于提示词生成。

### Q5：不知道 OpenClaw 配置目录在哪里？
A：直接问 OpenClaw「我的配置文件存在哪里？」，它会告诉你具体路径。

### Q6：生成的配置文件可以直接用吗？还是只是模板？
A：**可以直接使用**。v2.0 优化了配置文件生成逻辑，会根据你的实际回答填充 60%-80% 的内容。你只需要补充少量个性化内容（如 API 密钥、具体权限等）。

### Q7：搜索 Skills 时为什么使用 SkillHub？
A：SkillHub 是腾讯的 Skills 平台，包含 12,891 个真实 Skills，访问速度快，中文支持好。

### Q8：如果我填错了怎么办？会不会一路错下去？
A：v2.0 增加了输入校验和异常处理。如果你输入的内容明显有问题（如选角色时输入了"123"），我会提示你重新输入。每个阶段结束也有确认环节，可以及时纠正。

### Q9：这个技能和"AI能取代我吗"有什么关系？
A：通过梳理你的 SOP，你会发现哪些工作是重复性的（可能被 AI/自动化取代），哪些工作需要创造性/人际互动（难以被取代）。我会基于你的工作流程给出具体的自动化建议。

### Q10：输出有哪些文件？每个文件是干什么的？
A：详见上方的"输出清单"部分。简单说：
- `SOUL.md` = 你的工作价值观和行为准则
- `USER.md` = 你的偏好和习惯
- `AGENTS.md` = 自动化规则配置
- `TOOLS.md` = 工具连接信息
- `HEARTBEAT.md` = 定时任务配置
- `IDENTITY.md` = 身份和边界定义

### Q11：如果我的工作很特殊，列表里没有怎么办？
A：选 G（自定义），然后描述你的工作。我会基于你的描述生成定制化方案。

### Q12：生成的 ASCII 图看起来有点乱，能换成图片吗？
A：ASCII 图是为了在纯文本环境下也能正常显示。如果你需要更美观的图表，可以：
1. 复制 ASCII 图到支持 Mermaid 的工具（如 Notion、飞书文档）自动转换
2. 在阶段四生成的 `summary.html` 中包含 Mermaid 可视化图表

### Q13： Skills 搜索结果是真实的吗？还是模拟的？
A：**必须是真实的**。我会通过 SkillHub 本地 JSON 数据库（含 12,891 个真实 Skills）按关键词搜索，然后展示搜索结果。如果本地数据库未安装，会提示用户先安装 SkillHub CLI。

### Q14：这个技能需要联网吗？
A：阶段一和阶段二（调研和可视化）不需要联网。阶段三（搜索 Skills）需要联网。如果你无法联网，我会跳过真实搜索，直接生成自定义 Skill 创建提示词。

### Q15：我对隐私比较敏感，这个技能会上传我的数据吗？
A：不会。所有调研数据都只保存在你的本地会话中，不会上传到任何服务器。搜索 Skills 时只会发送关键词（如"数据自动化"），不会发送你的个人信息。

## 🚫 反模式与常见错误（新增）

### ❌ 不要这样做

#### 1. 输入阶段
```
❌ 错误：用户输入"不知道"、"忘了"
→ 正确：提供示例引导，如"比如你早上一般先做什么？打开电脑后第一个动作是什么？"

❌ 错误：用户想跳过某个步骤
→ 正确：说明该步骤的必要性，提供"稍后补充"选项，但不建议跳过

❌ 错误：用户输入过于简短（<5个字）
→ 正确：提示"请描述得更详细一些，比如..."
```

#### 2. 搜索阶段
```
❌ 错误：搜索失败后直接生成占位符
→ 正确：必须展示真实搜索过程，失败则生成 skill-creation-prompt.md

❌ 错误：只搜一个平台就放弃
→ 正确：SkillHub 搜索失败才生成提示词

❌ 错误：推荐安全评分<4.5的Skill
→ 正确：只推荐安全评分>4.5且下载量>500的Skill
```

#### 3. 生成配置文件阶段
```
❌ 错误：生成空模板让用户自己填
→ 正确：基于用户回答动态填充60%-80%内容

❌ 错误：使用占位符如`[工具A]`、`[步骤1]`
→ 正确：必须填写真实搜索到的Skill名称或用户提到的工具名

❌ 错误：生成的SOUL.md是通用模板
→ 正确：基于用户痛点、工作价值观、沟通风格生成个性化内容
```
