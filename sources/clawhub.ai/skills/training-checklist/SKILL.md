# 筹备检查清单

> 输出为参考建议，最终筹备状态由主理人确认。

## 能力概述

对培训筹备全流程进行逐项检查、状态跟踪和自动提醒。覆盖：

| 阶段 | 检查项 |
|------|--------|
| 策划期（T-60） | 培训主题、日期、组织机构、预算 |
| 讲师期（T-45） | 讲师邀约、课程大纲、课件进度 |
| 招生期（T-30） | 招生简章、海报设计、公众号发布、报名渠道 |
| 准备期（T-21） | 场地合同、酒店预订、设备清单、教材印刷 |
| 冲刺期（T-7） | 物料打包、学员确认、食宿安排、交通指引 |
| 执行期（T-0） | 签到、课程执行、考评、证书 |

## 输入

- **培训计划书**：包含时间、地点、课程、讲师、费用等信息
- **往期检查清单**（可选）：历史培训的检查项可作为参考


## 标准检查清单（可扩展）

### 策划期
- [ ] 培训主题和名称确定
- [ ] 培训日期确定（含节假日检查）
- [ ] 组织机构确认（主办/承办/协办）
- [ ] 预算方案制定
- [ ] 培训对象和招生目标确定

### 讲师期
- [ ] 讲师名单确定
- [ ] 讲师邀约确认（确认函）
- [ ] 讲师课件大纲提交
- [ ] 讲师课件定稿
- [ ] 讲师差旅安排

### 招生期
- [ ] 招生简章定稿
- [ ] 海报/宣传物料设计完成
- [ ] 公众号文章发布
- [ ] 报名渠道搭建（表单/缴费入口）
- [ ] 招生渠道推送（社群/朋友圈/合作方）

### 准备期
- [ ] 场地合同签署
- [ ] 酒店客房预订
- [ ] 设备清单确认（投影/音响/录播/直播）
- [ ] 教材/教辅资料印刷或制作
- [ ] 学员手册/工具包准备
- [ ] 证书/考评材料准备
- [ ] 食宿安排确认

### 冲刺期
- [ ] 现场物料打包（指引牌/胸牌/签到表/易拉宝）
- [ ] 学员名单确认（实际到场）
- [ ] 交通指引发送
- [ ] 应急预案准备

### 执行期
- [ ] 学员签到
- [ ] 课程执行跟踪
- [ ] 物料发放
- [ ] 考评测试组织
- [ ] 证书发放

## 工作流程

1. **加载培训计划**：读取培训计划书中的关键信息
2. **生成检查清单**：根据培训规模和类型，自动生成标准检查项
3. **逐项检查**：用户逐项确认状态，更新至✅/⚠️/❌
4. **自动提醒**：接近截止日期仍未完成的项自动提醒
5. **周度小结**：每周固定时间输出进度报告
