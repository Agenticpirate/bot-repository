## 核心理念

**知乎回答** = 选题(40%) × 开头钩子(30%) × 内容质量(20%) × 互动引导(10%)

两轨并行，互相引流：热点社会话题先写回答蹭流量，再改编盐言短篇投稿变现。

- "帮我选个适合写的话题"

按优先级排序：
1. **AI/人工智能** — GPT、大模型、AI编程工具、AI行业动态

### 选题评分公式

```
推荐度 = 热度 × 匹配度 / (竞争度 + 1)
```

### 选题优先级速查

| 条件 | 行动 |
|------|------|
| 热度 > 300万 + 匹配度 > 0.7 | 🔥 立即写，抢窗口期 |
| 热度 100-300万 + 匹配度 > 0.7 | ✅ 可以写，稳定流量 |
| 热度 > 300万 + 匹配度 0.3-0.7 | 🤔 找角度，需要动脑 |
| 匹配度 < 0.3 | ❌ 不适合，别硬写 |

## Step A3: 竞品分析

分析维度：
1. **问题核心**：用户真正在关心什么？争议点在哪？

## Step A4: 爆款写作

### 开头钩子（知乎信息流只展示前40-60字）

| 类型 | 模板 | 适用场景 |
|------|------|---------|
| 🔄 反转 | "你以为XXX？完全错了。" | 纠正常见误解 |
| 📊 数据 | "看过300+XX后，我发现90%都..." | 有数据积累的话题 |
| 📖 故事 | "X年前，我还是XX。现在我已经..." | 个人经历分享 |
| 💬 共鸣 | "这种感觉你一定有过：..." | 普遍痛点/经历 |
| ⚡ 冲突 | "有人说XX。作为一个XXX，我想说..." | 争议性话题 |

### 正文结构

```markdown
【开头钩子】3-5句，制造悬念或共鸣（‼️最关键）
【核心观点】1-2句亮明立场
【背景铺垫】这个问题为什么重要
【展开分析】3-5个分点，观点→论据→小结
【深度洞察】1-2个别人没说过的角度
【实操建议】可落地的行动指南（可选）
【结尾引导】金句总结 + 互动引导
```

### 写作风格要求

**✅ 做到：**
- 有观点有态度，不骑墙
- 用案例代替理论，用数字代替形容词
- 段落短（手机3-4行），节奏快
- 语气像在跟朋友聊天，不是写论文
- 加入具体细节增加真实感

**❌ 避免：**
- "首先...其次...最后..."的作文体
- 空洞的行业黑话（赋能、抓手、底层逻辑...）
- 没有观点的信息搬运
- 过度谦虚
- AI味（"在这个充满变化的时代"、"众所周知"）
- 营销感强的软广

### 个人标签自然融入

- 南京信息工程大学 CS 本科大三
- AI 研究方向，有实际项目经验
- 懂 Python、软件开发、自动化
- 有 A 股投资经验

⚠️ 不要生硬植入，只有在相关时才自然提及。

### 互动引导

每篇只用1-2个引导：
- 点赞："觉得有用的话，点个赞让更多人看到 🔼"
- 评论："你怎么看？评论区聊聊 👇"
- 关注："我会持续分享AI/编程干货，关注不迷路"
- 收藏："干货较多，建议先⭐收藏再看"

## B2: 盐言短篇写作引擎

### B2.1 盐言故事的黄金结构

盐言和普通小说的本质区别：**读者先看免费部分（3-5段），再决定付不付费。**

```
┌─────────────────────────────────────┐
│ 开头5段（免费试读）← 最关键！       │
│ 段1: 知乎体提问 → 制造悬念          │
│ 段2: 反常信息 → 打破预期            │
│ 段3: 人物出场 → 建立认同            │
│ 段4: 冲突升级 → 钩住继续            │
│ 段5: 🔒付费点 → "后来我才知道..."   │
├─────────────────────────────────────┤
│ 正文（付费部分）                     │
│ 每800-1200字一个反转/小高潮          │
│ 对话驱动（70%对话 + 30%描写）        │
│ 最后200字必须有情感暴击              │
└─────────────────────────────────────┘
```

### B2.2 开头五段模板

**模板一：知乎提问体（最经典）**
```
你们班上有没有那种看起来平平无奇，实际上有着隐藏身份的男生？

我跟陈屿同班三年，一直觉得他就是个普通理工男。

直到那天我亲眼看见，校门口停的那辆劳斯莱斯上，走下来给他开车门的人，是我爸公司的CEO。
```
→ 品类：网恋掉马 / 校园甜宠

**模板二：反常识陈述体**
```
谁说女生一定要温柔懂事？

我这个人天生反骨，受不了委屈。

男朋友妈妈第一次见面就让我洗碗，我洗了。

然后我把碗全部放进洗碗机，转头对他妈说了句：阿姨，时代变了。
```
→ 品类：大女主爽文

**模板三：暗恋错过体**
```
你有没有喜欢一个人，喜欢到连自己都骗？

我喜欢周循六年。

从高一到大三，从同桌到朋友圈的点赞之交。

直到他结婚那天，我在婚礼上喝醉了，室友翻我手机，发现备忘录里写了378条"想对他说的话"。
```
→ 品类：青春火葬场

**模板四：热搜改编体**
```
前几天热搜上那个"快递员被逼下跪"的事你们都看了吧。

没人知道，那个快递员的女儿，是我们学校年级第一。

也没人知道，三天后那个逼他下跪的女人，收到了一个让她当场崩溃的包裹。
```
→ 品类：热点改编

### B2.3 反转密度检查

盐言爆款的共同点：**反转间隔不超过1200字**。

标准节奏：
```
0-800字   → 建立日常 + 第一个小疑问
800-1600字 → 第一次反转（信息差揭露）
1600-2400字 → 第二次反转（身份/关系反转）
2400-3200字 → 小高潮（冲突爆发）
3200-4000字 → 第三次反转（真相/动机反转）
4000-5000字 → 情感暴击结局
```

### B2.4 对话驱动原则

盐言爆款70%是对话。对比：

❌ 描写驱动（不要这么写）：
> 林小满走进教室的时候，所有人都转过头看她。她的头发被雨淋湿了，校服也湿透了，样子很狼狈。但她的眼神很坚定，一步一步走到讲台前。

✅ 对话驱动（要这么写）：
> "那是谁啊？淋成这样。"
> "不知道，转校生吧。"
> "笑死，第一天就迟到，还是这副鬼样子。"
> 她没理，走到讲台前，开口第一句话就让全班安静了：
> "我叫林小满。你们班原来的第一名，以后是我的了。"

### B2.5 知乎体特征

盐言故事之所以叫"盐言"，因为它从知乎问答演变而来。保留知乎体特征可以大幅提高过稿率：

- ✅ 第一人称"我"叙事
- ✅ 口语化、接地气的语言
- ✅ 用"你"直接呼唤读者
- ✅ 每段短（2-4句），手机屏幕友好
- ✅ 段与段之间有空行，呼吸感强
- ✅ 开头有"提问感"
- ❌ 传统小说式的第三人称全知视角（过稿率大幅下降）
- ❌ 大段景物/心理描写

## B3: 七种品类写作模板

### 品类 1：校园甜宠

**人设公式**：普通女主 × 隐藏身份男主（学霸/校霸/转校生/青梅竹马）

**冲突公式**：
- 误会 → 冷战 → 男主暗中帮忙 → 真相揭露 → 甜
- 或：契约关系 → 假装情侣 → 慢慢认真 → 被告白

**反转元素**：
- 男主真实身份揭露
- "我以为他不喜欢我" → "他其实偷偷喜欢我三年"
- 某个物品/事件揭开真相（备忘录/日记/聊天记录）

**情感暴击**：男主说出一个细节证明一直在关注女主

---

### 品类 2：青春火葬场

**人设公式**：暗恋者女主 × 被暗恋的男主（有女朋友/已婚/高不可攀）

**冲突公式**：
- 暗恋 → 卑微付出 → 心碎时刻 → 女主离开 → 男主后悔 → 追妻火葬场

**反转元素**：
- 男主其实也在暗恋女主但各种原因不能表达
- 女主离开后男主的崩溃（通过第三方视角）
- 时间的残酷感（"三年后"跳转）

**情感暴击**：女主放下的那个瞬间，读者心碎。男主发现来不及了的瞬间，读者又心碎一次。

---

### 品类 3：双男主

**人设公式**：互补型双男主（阳光×冷傲 / 温柔×霸道 / 学霸×学渣）

**冲突公式**：
- 初期对立 → 被迫相处 → 逐渐了解 → 感情萌芽 → 外力阻挠 → 选择

**反转元素**：
- 一方早有预谋（原来他很早就注意到对方了）
- 某个意外事件让关系质变
- "我以为他讨厌我" → "他其实一直在保护我"

**情感暴击**：表白场景，或者被迫分离的场景。

---

### 品类 4：热点改编 ⭐⭐⭐⭐⭐

**核心原则**：
- ⚠️ 必须改编加工，不能直接抄袭真实事件
- ⚠️ 必须符合社会主义核心价值观
- ✅ 取其情感内核，架空人物和细节

**改编流程**：
```
热搜事件 → 提取情感内核(愤怒/同情/感动/震惊)
         → 架空人物（换名字、换职业、换地点）
         → 构建新冲突（保留情感，重写情节）
         → 增加反转（现实没有的戏剧性）
         → 情感暴击结局
```

**案例**：
- 社会事件"快递员被逼下跪"→ 情感内核"底层劳动者尊严"→ 改编成"快递员的女儿暗中复仇"（悬疑反转向）
- 情感事件"订婚变卦"→ 情感内核"被辜负的真心"→ 改编成"女主反手曝光全部真相"（大女主爽文向）

---

### 品类 5：网恋掉马 ⭐⭐⭐⭐⭐

**人设公式**：隐藏身份的一方 × 不知情的另一方

**经典套路**：
- 游戏中认识 → 线下意外相遇 → 掉马 → 尴尬/甜
- 社交App匹配 → 聊了半年 → 发现是死对头/老板/前男友
- 匿名帮助 → 对方感谢 → 见面发现是熟人

**反转元素**：
- 掉马瞬间的巨大反差（身份反差、性格反差）
- "网络中的他" vs "现实中的他"的差距
- 对方是否早就知道身份？

**情感暴击**：掉马后的第一句话。

---

### 品类 6：大女主爽文

**人设公式**：有能力的女主 × 小看她的人（渣男/势利眼/绿茶）

**冲突公式**：
- 被轻视 → 被陷害 → 不动声色布局 → 反击 → 对方崩溃

**反转元素**：
- 女主隐藏的实力/身份揭露
- 女主早已看穿一切，只是不想计较
- 渣男发现自己被骗的瞬间

**情感暴击**：女主云淡风轻地说出真相的那一刻。

---

### 品类 7：虐文

**人设公式**：付出型女主 × 后知后觉型男主

**冲突公式**：
- 深爱 → 付出一切 → 被伤害 → 心死离开 → 男主发现真相 → 追悔莫及

**反转元素**：
- 女主离开的真正原因
- 男主的视角切换（前文是女主视角，结尾切到男主视角）
- 某个秘密被揭开

**情感暴击**：女主说"我不爱你了"的那一刻。男主发现女主为他做过什么的那一刻。

## B4: 完整写作流程

### 触发语
- "写一篇盐言短篇：[品类/主题]"
- "从今天的热榜找个适合改编的话题，写盐言短篇"
- "帮我写一篇网恋掉马的短篇"

### 执行步骤

```
Step B4.1: 选题 → 确定品类 + 情感内核
Step B4.2: 大纲 → 人设 + 冲突 + 反转节点 + 结局
Step B4.3: 开头 → 用知乎体提问或反常识陈述开头
Step B4.4: 正文 → 分段写作，每800字检查反转密度
Step B4.5: 结尾 → 情感暴击 + 开放式/反转式收尾
Step B4.6: 包装 → 知乎体标题 + 话题标签推荐
Step B4.7: 存档 → ~/Documents/notes/盐言/
```

### 字数控制

| 档位 | 字数 | 反转数 | 适用投稿 |
|------|------|--------|---------|
| 微型 | 1500-3000字 | 1-2次 | 社区故事 |
| 短篇 | 3000-5000字 | 2-3次 | ⭐ 盐言主流 |
| 标准 | 5000-8000字 | 3-5次 | ⭐ 盐言主流 |
| 中篇 | 8000-15000字 | 5-8次 | 专栏签约 |

**建议从5000字标准短篇开始练手。**

## B5: 投稿策略

### B5.1 投稿前检查清单

- [ ] 开头5段能否让读者产生"必须付费继续看"的冲动？
- [ ] 反转密度够不够（≤1200字一个反转）？
- [ ] 对话占比是否≥60%？
- [ ] 是否有知乎体特征（第一人称、口语化、短段落）？
- [ ] 结尾是否有情感暴击？
- [ ] 是否踩了敏感雷区（政策、价值观）？
- [ ] 标题是否有"问题感"？

### B5.2 标题包装

盐言标题最好有"知乎提问感"：

| 一般标题 | 知乎体标题 ✅ |
|---------|------------|
| 我和陈屿的爱情故事 | 你们班上有没有那种，看起来普通但藏着大秘密的人？ |
| 网恋对象是霸总 | 网恋半年的对象，见面那天开了一辆劳斯莱斯，我转头就跑 |
| 我不爱他了 | 你有没有喜欢一个人，喜欢到连自己都骗？ |

### B5.3 话题标签推荐

- 根据品类选择5-8个相关话题
- 优先选热度中等的（太热门的话题竞争激烈）
- 举例：网恋掉马 → #网恋 #恋爱 #反转 #你经历过网恋吗 #掉马

### B5.4 冷启动联动

用知乎回答给盐言作品引流：
1. 在"有没有网恋故事推荐"类问题下写回答
2. 回答末尾自然植入："其实我自己也写过一篇类似的，在盐言专栏"
3. 用自己的经历/观点获取赞同，顺便推广作品

## B6: 热点改编双轨工作流

这是最高效的策略：**一个热点，两份产出。**

```
        ┌──────────────┐
        │  今日热榜     │
        │  tophub抓取  │
        └──────┬───────┘
               │
        ┌──────▼───────┐
        │  筛选情感类   │
        │  社会话题     │
        │  (非技术/科学) │
        └──────┬───────┘
               │
      ┌────────┴────────┐
      ▼                 ▼
┌──────────┐    ┌──────────────┐
│ 轨道A    │    │ 轨道B        │
│ 知乎回答 │    │ 盐言短篇     │
│          │    │              │
│ 观点分析 │    │ 故事改编     │
│ 评论视角 │    │ 架空创作     │
│ 涨粉引流 │    │ 投稿变现     │
│          │    │              │
│ 回答末尾 │◄───│ 植入盐言作品 │
│ 引流到   │    │              │
│ 盐言专栏 │    │              │
└──────────┘    └──────────────┘
```

### 触发语
- "看看今天热榜有什么适合改编的话题"
- "双轨处理：[话题]"

### 筛选标准

适合改编成盐言短篇的热点特征：
- ✅ 涉及情感关系（恋爱、婚姻、家庭、友情）
- ✅ 有"受害者"和"施害者"的对立
- ✅ 网友有强烈的情绪反应（愤怒、同情、感动）
- ✅ 有未解之谜/悬念感
- ❌ 纯科技/经济/政策类
- ❌ 纯科普类
- ❌ 体育赛事

# 核心知识库速查

## 知乎爆款公式
1. 开头3秒定生死（前40字必须有钩子）
2. 立场鲜明，有态度的回答更容易被记住
3. 信息密度高，每段都有新信息
4. 具象化，用"3天"代替"几天"
5. 节奏起伏，分析+共鸣交替
6. 反常识洞察，提供没想到的角度
7. 行动指引，结尾告诉读者可以做什么

## 盐言爆款公式
1. **开头5段定付费** — 免费部分就是你的销售页
2. **知乎体提问开头** — "你们有没有遇到过…"
3. **1200字反转律** — 每800-1200字一个新信息或反转
4. **70%对话驱动** — 用对话推进剧情，不用描写
5. **第一人称"我"** — 代入感最强的叙事视角
6. **情感暴击收尾** — 最后200字让读者破防
7. **短段落呼吸感** — 每段2-4句，手机友好
