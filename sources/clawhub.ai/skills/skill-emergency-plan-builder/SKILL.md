# 应急方案编制助手

## 任务目标

- 本 Skill 用于：辅助用户快速构建规范化、可执行的应急方案文件
- 能力包含：方案框架设计、模板匹配、内容填充指导、方案管理建议
- 触发条件：用户提及"应急预案"、"应急方案"、"突发事件处置"、"应急演练"、"灾害应对"等场景

## 前置准备

- 无特殊依赖，直接使用智能体能力进行方案编制
- 用户需明确应急场景类型（如自然灾害、事故灾难、公共卫生事件、社会安全事件等）

## 操作步骤

### 步骤一：明确应急场景

1. 确认应急事件类型：
   - 自然灾害类（地震、洪水、台风、泥石流等）
   - 事故灾难类（火灾、爆炸、危化品泄漏、交通事故等）
   - 公共卫生类（传染病疫情、食品安全事故等）
   - 社会安全类（恐怖袭击、群体性事件、网络安全事件等）

2. 收集基础信息：
   - 事发地点与范围
   - 涉及人员与规模
   - 潜在危害程度
   - 现有资源条件

### 步骤二：选择方案模板

根据应急场景类型，从 [references/emergency-plan-template.md](references/emergency-plan-template.md) 中选择对应的标准模板结构。模板包含以下核心模块：

| 模块 | 说明 |
|------|------|
| 总则 | 编制目的、依据、适用范围、原则 |
| 组织体系 | 指挥机构、职责分工、联系方式 |
| 预防与预警 | 风险监测、预警分级、预警响应 |
| 应急响应 | 响应分级、响应程序、处置措施 |
| 后期处置 | 善后处理、恢复重建、总结评估 |
| 保障措施 | 通信保障、物资保障、资金保障 |

### 步骤三：结构化填充内容

#### 3.1 总则部分

- **编制目的**：阐明本方案要解决的核心问题
- **编制依据**：引用相关法律法规、标准规范
- **适用范围**：明确方案适用的场景和边界
- **工作原则**：如"以人为本、快速响应"等

#### 3.2 组织体系

- **指挥机构**：明确总指挥、现场指挥角色
- **职责分工**：使用表格清晰列出各部门/岗位职责

| 角色 | 主要职责 | 联系方式 |
|------|----------|----------|
| 总指挥 | 统一指挥、决策重大事项 | - |
| 现场指挥 | 现场处置协调 | - |
| 信息联络组 | 信息收集与上报 | - |
| 抢险救援组 | 现场救援行动 | - |
| 医疗救护组 | 伤员救治 | - |
| 后勤保障组 | 物资保障 | - |

#### 3.3 预防与预警

- **风险监测**：建立日常监测机制
- **预警分级**：建议采用四级分类（红/橙/黄/蓝）
- **预警响应**：明确各级别的启动条件和措施

#### 3.4 应急响应

- **响应分级**：与预警级别对应
- **响应程序**：按时间线描述处置流程
  1. 发现报告（X分钟内）
  2. 启动响应（X分钟内）
  3. 现场处置（持续）
  4. 响应终止（条件达成后）

#### 3.5 后期处置

- 善后处理工作清单
- 损失评估与统计
- 恢复重建计划
- 经验总结与改进

### 步骤四：方案优化与完善

1. **完整性检查**：确保每个模块都有实质内容
2. **可操作性验证**：检查每项措施是否具体可执行
3. **责任明确性**：确认每项任务有明确的负责主体
4. **时效性检查**：确保时间节点和期限合理
5. **联络畅通性**：核实所有联系方式有效

### 步骤五：方案管理与更新

- **版本控制**：记录方案版本和修订日期
- **定期评审**：建议每年至少评审一次
- **动态更新**：根据演练和实际事件经验及时修订
- **存档管理**：重要版本应留档保存

## 使用示例

### 示例一：编制火灾应急预案

- 场景/输入：用户需要为办公楼编制火灾应急预案
- 预期产出：完整的火灾应急方案文档，包含组织体系、疏散流程、灭火措施等
- 关键要点：
  1. 明确建筑结构和消防设施布局
  2. 确定疏散路线和集合点
  3. 区分不同楼层、不同区域的处置措施

### 示例二：完善传染病防控方案

- 场景/输入：用户在已有公共卫生预案基础上，需要补充新冠类传染病应对措施
- 预期产出：补充完善的传染病防控专项方案
- 关键要点：
  1. 疫情监测与预警机制
  2. 隔离救治流程
  3. 密接人员追踪管理
  4. 物资储备与调配

### 示例三：制定应急演练计划

- 场景/输入：用户需要设计一场地震应急演练脚本
- 预期产出：包含演练场景、角色分配、时间节点、评估标准的演练方案
- 关键要点：
  1. 模拟真实的灾害情景
  2. 明确每个参与者的动作指令
  3. 设置观察点和评估指标

## 注意事项

- 方案编制应遵循"简明扼要、可操作性强"的原则，避免过度冗长
- 涉及生命安全的措施必须具体明确，确保非专业人员也能执行
- 定期根据实际情况演练和修订方案，保持时效性
- 重要方案应经过相关部门审核后发布实施
