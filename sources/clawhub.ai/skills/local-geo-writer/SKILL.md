## Quick Start

### 第一步：配置环境变量

```bash
export GEO_USER_KEY="你的DeepSeek API Key"
# 可选：自定义API地址
export DEEPSEEK_BASE_URL="https://api.deepseek.com/v1"
```

### 第二步：生成文章

**单篇生成：**
```bash
python {baseDir}/scripts/geo_writer.py single \
  "汉中鑫诚助贷" "助贷" "汉中" \
  "经营贷,房产抵押" service 2000
```

**批量生成（5篇不同类型）：**
```bash
python {baseDir}/scripts/geo_writer.py batch \
  "汉中老王装修" "装修" "汉中" \
  5 "装修公司,家装设计" 1500
```

**SEO质量检测：**
```bash
python {baseDir}/scripts/geo_writer.py check \
  article.md "汉中助贷" "汉中"
```

**关键词建议：**
```bash
python {baseDir}/scripts/geo_writer.py keywords "装修" "汉中"
```

## 常见问题 FAQ

**Q1: 生成的文章是原创的吗？会查重吗？**
A: AI生成的文章有一定原创性，但建议发布前做适当修改和人工润色，加入真实案例和数据，既提高原创度也增加可信度。

**Q2: 生成的文章能上百度首页吗？**
A: GEO优化的文章更容易被搜索引擎抓取和推荐，但排名还受很多因素影响（网站权重、域名年龄、外链、竞争度等）。好内容是基础，再配合其他SEO手段效果更好。

**Q3: AI搜索优化（GEO）和传统SEO有什么区别？**
A: 传统SEO针对搜索引擎排名，GEO针对AI搜索引擎的推荐。两者有重叠但侧重点不同：GEO更看重E-E-A-T、结构化数据、问题覆盖率、权威性等。建议两者都做。

**Q4: 支持哪些城市？关键词库只有汉中的吗？**
A: 内置汉中的10大行业关键词，但任何城市都能使用。其他城市会自动生成通用的本地关键词模板，你也可以在生成时通过关键词参数自定义。

**Q5: 批量生成的文章会不会重复？**
A: 批量生成时每篇选择不同的文章类型和侧重点，内容不会重复。但建议生成后人工过一遍，适当加入本地特色信息。

**Q6: 一篇文章生成需要多久？**
A: 根据文章长度，一般1-3分钟。批量生成按篇数累计。建议用合理的字数（1500-2000字），兼顾质量和速度。
