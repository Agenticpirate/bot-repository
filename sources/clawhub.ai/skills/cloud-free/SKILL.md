## 核心能力（免费版）

### 1. 快速服务选型

按设备组合推荐优选云存储服务：

| 你的设备 | 优选选择 | 原因 |
|---------|---------|------|
| iPhone + Mac | iCloud | 原生集成，无缝 |
| Android + Chrome | Google Drive | Gmail自带，自动照片备份 |
| Windows PC | OneDrive | Windows内置，Office集成 |
| 混合设备 | Dropbox | 各平台表现一致 |

选型原则：原生集成优先，避免跨平台兼容性损耗。

### 2. 常见困惑澄清

| 你以为的 | 实际发生的 |
|---------|-----------|
| "我从手机删除后笔记本上也没了" | 同步按设计工作——一个文件，处处一致 |
| "iCloud满了但手机还有空间" | 手机存储 ≠ iCloud存储 |
| "我的照片到处都是重复的" | 多个服务备份同一相机卷 |
| "我付了3个云服务的钱" | 选一个主服务，取消其余 |

## 使用流程

1. **识别用户设备组合**：询问或推断用户主要设备（iPhone+Mac / Android+Chrome / Windows PC / 混合）。
2. **推荐主服务**：按快速服务选型表给出优选选择与原因。
3. **澄清困惑**：若用户描述同步异常或空间困惑，对照常见困惑澄清表解释。
4. **建议整合**：若用户付费多个服务，建议选一个主服务并取消其余。

**结果处理**: 执行完成后,查看输出结果确认操作状态。成功时输出包含处理摘要和结果数据;失败时根据错误信息排查问题,参考错误处理章节获取恢复步骤。

## 常见问题

### Q1：免费版能帮我清理存储吗？
免费版仅识别存储满的原因（如照片占用、重复备份）。付费版提供4步清理流程的详细步骤。

### Q2：iCloud满了但手机还有空间，怎么回事？
手机存储与iCloud存储是两个独立配额。手机本地存储充足不代表iCloud云端配额充足。

### Q3：应该选哪个云存储服务？
按设备组合选：iPhone+Mac用iCloud，Android+Chrome用Google Drive，Windows PC用OneDrive，混合设备用Dropbox。

### Q4：3-2-1备份规则是什么？
3份副本、2种不同介质、1份异地。详细评估与建议为付费版专享。

### Q5：如何升级到付费版？
参考 `cloud` 付费版SKILL.md，解锁存储满4步清理、3-2-1备份策略、文件分享方法、安全基础审查等能力。
