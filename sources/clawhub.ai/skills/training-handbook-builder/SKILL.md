# Training Handbook Builder

本技能用于生成专业级培训手册Word文档，适合打印印制分发给培训人员。

## 适用场景

- 高校/政企培训手册制作
- 操作指南与工作手册生成
- 白皮书与指导文件排版
  任何需要"封面+目录+页码+正文+附录"完整文档结构且适合打印的场景

## 核心能力

1. **最新内容研究**：通过WebSearch/WebFetch检索截至当前日期的最新政策、案例和技术动态
2. **结构化内容设计**：按"背景政策→技术基础→全场景应用→标杆案例→工具速查→安全合规→领导力转型→行动规划→FAQ"九大模块组织
3. **专业Word排版**：使用python-docx生成含封面、自动目录域代码、页码、彩色表格、重点提示框、实践案例标注的打印级文档

## 执行流程

### 第一步：需求确认与内容研究

1. 确认手册主题、目标受众、覆盖场景范围
2. 使用WebSearch检索最新政策文件、行业报告、实践案例（搜索时注意使用当前年份）
3. 使用WebFetch深入获取关键网页的详细内容
4. 整理研究成果，形成内容素材库

### 第二步：结构设计

按以下通用结构设计手册章节（可根据主题调整）：

- **封面页**：标题、副标题、版本信息、政策依据
- **目录页**：Word域代码自动生成（用户打开后右键更新域即可）
- **第一章 时代背景与政策框架**：行业趋势、国家政策、标准体系
- **第二章 核心概念与技术基础**：关键概念对照表、技术架构、主流工具
- **第三章 全场景应用详解**：按目标受众的核心工作场景逐一展开
- **第四章 标杆案例深度解析**：2-3个典型案例，含建设模式、关键启示
- **第五章 实用工具速查手册**：工具全景表、选型参考、决策矩阵
- **第六章 安全与合规保障**：挑战分析、合规要求、实操清单
- **第七章 领导力转型与组织变革**：角色转型、能力模型、变革路径
- **第八章 行动规划与实施路线**：30天速赢计划、半年路线图、评估指标
- **第九章 常见问题与答疑**：认知层面+实操层面FAQ
- **附录**：政策文件索引、学习资源、术语表

### 第三步：Word文档生成

使用 `scripts/generate_handbook.py` 脚本生成Word文档。该脚本封装了完整的排版逻辑：

**运行方式：**
```bash
# 确保已安装python-docx
C:\Users\admin\.workbuddy\binaries\python\versions\3.13.12\python.exe -m pip install python-docx --target C:\Users\admin\.workbuddy\binaries\python\envs\default\Lib\site-packages

# 执行生成脚本（需要根据具体主题修改content部分）
C:\Users\admin\.workbuddy\binaries\python\envs\default\Scripts\python.exe scripts/generate_handbook.py
```

**脚本核心功能模块：**

| 函数 | 用途 |
|------|------|
| `add_cover_page(doc)` | 添加封面页（标题+版本+政策依据+分页符） |
| `add_toc_placeholder(doc)` | 添加自动目录域代码（Word打开后更新域即可生成目录） |
| `add_tip(doc, text)` | 添加红色重点提示框（楷体加粗） |
| `add_case(doc, title, content)` | 添加绿色实践案例标注（黑体标题+楷体正文） |
| `add_table(doc, headers, rows, col_widths)` | 添加彩色表格（深蓝表头+交替行背景） |
| `add_numbered_item(doc, number, title, content)` | 添加编号条目（蓝色标题+宋体正文） |
| `add_page_number(doc)` | 添加页脚页码（居中） |

**排版规格：**
- 页面：A4纸，上下边距2.5cm，左右边距2.8cm（适合打印）
- 正文：宋体12pt，行距1.5倍
- 一级标题：黑体22pt深蓝色(#1A3C6E)
- 二级标题：黑体16pt蓝色(#2B579A)
- 三级标题：黑体14pt浅蓝(#3A6BA5)
- 表头：白字深蓝背景(#1A3C6E)，交替行浅蓝(#EBF5FB)/白色
- 重点提示：楷体红色(#C0392B)
- 实践案例：楷体深灰(#2C3E50)

**自定义内容的方法：**

1. 复制 `scripts/generate_handbook.py` 到工作目录
2. 修改 `content` 部分——替换章节标题和正文内容为主题相关素材
3. 保留所有排版函数（`add_cover_page`、`add_toc_placeholder`、`add_table`等）不变
4. 修改 `output_path` 变量指定输出文件名
5. 执行脚本生成Word文档

### 第四步：验证与交付

1. 确认文件生成成功（检查文件大小>50KB通常表示内容完整）
2. 提醒用户：打开Word后右键目录页→"更新域"→"更新整个目录"即可生成带页码的完整目录
3. 使用present_files工具交付文档

## 关键注意事项

- **内容时效性**：使用WebSearch时务必搜索当前年份的最新信息，确保手册内容不过时
- **政策准确性**：引用政策文件时需核实文号、发布日期和发布机构，不可臆造
- **中文字体设置**：python-docx默认不支持中文，必须通过XML方式设置 `w:eastAsia` 属性
- **目录生成**：python-docx无法直接生成可视化目录，使用Word域代码（TOC field）让用户打开后一键更新
- **页码生成**：同样使用Word域代码（PAGE field），非硬编码数字
- **表格颜色**：通过XML的 `w:shd` 元素设置单元格背景色
- **分页控制**：每章结尾使用 `doc.add_page_break()` 确保章节从新页开始
