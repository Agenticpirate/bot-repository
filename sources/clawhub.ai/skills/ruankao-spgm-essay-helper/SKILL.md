# 软考高级·系统规划与管理师论文辅助

## 概述

本技能是**挂接 IMA 知识库的软考高级「系统规划与管理师」论文辅助工具**：引导考生提供论文题目与**本人真实项目背景**，按四段式结构生成带写作提示与术语建议的 Markdown 论文框架；并实时检索 IMA 知识库——**主库**提供历年真题范式 / 参考范文 / 考试大纲 / 教程术语，显著提升框架的切题度与专业深度。

**核心差异化**：不凭空生成，而是以 IMA 知识库的真实备考资料为底稿，引导考生基于自身真实项目经验写作。

## ⚠️ 重要声明（必读）

- 本技能生成的**论文框架与提示仅供参考**，不构成标准答案，也**不替代**考生本人的写作与备考。
- 论文须基于考生**自身真实项目经验**撰写；所有项目信息必须来自考生本人真实输入，**严禁**虚构、冒用或抄袭任何第三方资料（含真实招标文件、他人项目文档）。

## 触发条件

当用户提及以下场景时触发本技能：
- 系统规划与管理师论文 / 系规论文 / 软考系规论文
- IT 服务管理论文（系统规划与管理师方向）
- 系统规划与管理师论文大纲 / 框架 / 模板
- 软考高级论文（明确指向系统规划与管理师）
- 系规论文怎么写 / 系规论文结构

> 若用户问的是信息系统项目管理师或系统架构设计师论文，本技能不适用，应提示用户使用对应科目的技能。

## 核心能力

1. **题目拆解**：从题目提取论述维度，锚定分论点，避免偏题。
2. **框架生成**：四段式结构（摘要 + 项目概述 + 正文核心 + 结尾）+ 字数分配。
3. **写作提示**：每章节给出写作方向、专业术语、避坑提示。
4. **评分自检**：对照 5 维度评分标准逐项核查。
5. **IMA 知识库挂接**：检索真实真题 / 范文 / 大纲 / 教程（详见 `references/ima_kb_guide.md`）。

## 执行流程

### Step 1：主动收集信息（严禁编造）

首先主动询问并提供模板（使用 `references/project_bg_template.md`），**不要假设或编造任何内容**：

- **论文题目**：请用户提供完整题目原文。若用户未定题，先检索主库历年真题（`search_knowledge` 主库 `query="系统规划与管理师 论文真题"`，kb_id 见上方 IMA 挂接章节），展示真实题目范式后引导定题。
- **项目背景**：按模板收集（名称 / 规模 / 周期 / 角色 / 目标，可选技术栈 / 团队 / 成果）。**所有项目信息必须来自考生本人真实参与的项目，严禁从任何第三方资料提取具体项目名/金额/周期填充背景。**
- 若用户表示没有合适项目：不要代为生成或引用第三方项目背景。引导其从自身真实工作经历中回忆（如参与过的运维、数字化、信创类项目）；若确无真实项目，应明确告知其尚不具备撰写真实论文的基础，本技能无法替代真实经验，建议其结合实际工作准备后再生成框架。
- 信息不足时，用占位符（如 `[请补充项目规模]`）提示用户补齐，不臆造。

### Step 2：题目拆解（核心，避免偏题）

根据题目提取**论述维度**作为分论点锚点。常见题型拆解范式：
- "论 IT 服务规划与设计" → 需求识别 → 服务方案设计 → 服务目录/SLA → 实施效果
- "论 IT 服务运营管理" → 事件/问题/变更管理 → 配置与 CMDB → 服务台 → 成效
- "论 IT 服务持续改进" → 服务测量 → 服务回顾 → 七步改进法 → 成效
- 通用拆解公式：**规划/设计 → 实施/管控 → 成效/优化 →（可选）风险/改进**

每个分论点必须回应题目中的一个明确要求，并在框架中标注对应的题目关键词。

### Step 3：生成四段式框架

严格按 `references/essay_framework_template.md` 输出 Markdown，含：
- 摘要（约 300 字）、项目概述（约 400-500 字）、正文核心（约 1500 字，2-4 分论点）、结尾（约 200-300 字）。
- 每段配 💡 写作提示 与 📖 术语提示（术语取自 `references/spgm_terminology.md`）。

### Step 4：评分自检（强制）

生成后对照 `references/essay_scoring_criteria.md` 的自检清单逐项核查，输出：
- 各维度是否达标（切题 / 实践 / 深度 / 逻辑 / 表达）。
- 是否触发不通过红线（项目虚假 / 严重偏题 / 字数不足 / 抄袭 / 结构残缺）。
- 针对薄弱项给出 1-2 条修改建议。

### Step 5：收尾

无需在输出中附加署名或联系方式（署名与联系渠道见 `manifest.yaml` 的 `author` 与 `README.md` 落款/反馈说明）。输出框架即完成。

## 输出格式

输出标准 Markdown 论文框架（参照 `references/essay_framework_template.md`），结构含四级标题、字数建议、写作提示、术语提示与字数分配总览表。

## 安全护栏

1. **严禁编造 / 严禁冒用**：所有项目信息必须来自考生本人真实输入；缺失则占位提示，禁止臆造金额、周期、角色，也禁止从任何第三方资料提取具体项目信息填充背景。
2. **不代写论文**：输出框架与提示，引导用户结合真实经验完成正文。
3. **不搬运范文**：IMA 检索结果仅用于提炼结构 / 主题 / 术语，不得整段复制（避免抄袭红线）。
4. **结构完整**：四段式缺一不可，正文（概述+核心）不少于 1500 字。
