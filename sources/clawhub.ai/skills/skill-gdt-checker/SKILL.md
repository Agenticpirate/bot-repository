# GD&T 标注检查技能

## 一、角色定位（给谁用）

本技能服务于需要审核机械图纸上 **GD&T（Geometric Dimensioning and Tolerancing，几何尺寸与公差）标注** 是否完整、合规的工程师：

- **设计工程师**：在出图前/评审中自查 GD&T 标注是否齐全、基准体系是否合理。
- **工艺工程师**：评估图纸标注是否可制造、可测量，避免标注与工艺/检具冲突。
- **质量工程师 / 尺寸工程师**：在来图转化、供应商图纸评审、首件检验（FAI）前审核标注合规性。

**岗位画像（典型）**：用户拿到一张带几何公差标注的 2D 图纸（或 3D 数模转出的 2D 视图），担心"有没有漏标、基准标得对不对、符号用错没"。用户要的是一张**对照式的检查表 + 一份问题清单**，能逐条打勾并定位问题，而不是一段 GD&T 理论讲解。

> 本技能基于领域知识（ASME Y14.5、GB/T 1182 等几何公差标准）做**标注层面的合规性检查**，不替代 CAD 软件自动几何检查，也不替代实际三坐标测量。

## 二、使用场景（工作环节 / 触发条件 / 手头材料）

| 场景 | 触发条件 | 用户手头通常有的材料 |
|------|----------|----------------------|
| 出图前自查 | 设计完成待评审，确认 GD&T 无缺漏 | 2D 图纸（GD&T 标注）、3D 数模 |
| 图纸评审 / 会签 | 跨职能审图，验证标注合规 | 图纸 PDF/图片、标注说明 |
| 来图转化 | 客户/供应商图纸转为内部图纸 | 客户图纸、内部转化稿 |
| 供应商图纸评审 | 审核供应商提交图纸的标注合理性 | 供应商图纸、技术要求 |
| 首件检验前 | FAI 前确认图纸标注可检、无歧义 | 图纸、检验规划 |

**激活触发词**：GD&T 检查、几何公差、形位公差、基准体系、位置度、轮廓度、符号检查、图纸标注合规、标注缺漏、基准参考框、MMC/LMC、公差叠加前标注核对。

## 三、解决的问题（业务痛点，非动作）

1. **标注缺漏**：该标几何公差的地方没标（如配合面无平面度/位置度），或功能关键特征无基准引用。
2. **基准体系错**：基准选择不当、基准顺序混乱、基准参考框（Datum Feature Simulator）与实际装配基准不匹配。
3. **符号误用**：修饰符号（Ⓜ MMC、Ⓒ CMM、Ⓛ LMC、○ 直径、继续延伸线等）用错或漏用，导致含义歧义。
4. **标注自相矛盾**：理论正确尺寸（TED）缺失、基准与尺寸链不闭环、公差与功能要求不匹配。
5. **可检性不足**：标注无法用现有量具/三坐标实现，或缺少测量基准定义。

## 四、能力边界（能做 / 不做 / 输入要求）

**能做**：
- 按检查表逐项核对图纸 GD&T 标注的完整性与合规性。
- 指出缺漏项、基准体系问题、符号误用，并给出"为什么错 / 怎么改"的要点。
- 生成 **GD&T 检查表 + 问题清单**（纯文字版 .txt + Markdown .md）。

**不做**：
- 不替代 CAD/公差分析软件做自动几何校验或三维拟合。
- 不替代三坐标（CMM）实际测量，只做标注层面合规判断。
- 不替代设计决策（是否采用某基准/公差最终由设计责任人定）。
- 不编造标准号/具体公差数值；不确定的标准条款标「待企业补充」。

**输入要求**：
- 至少提供：图纸的 GD&T 标注信息（可文字描述、截图或 PDF），以及该特征的功能/装配要求（用于判断是否需要某公差）。
- 缺关键信息（如不知道哪个是装配基准）时，标「待确认」并追问 1–2 点，不臆造基准。

## 五、交互与角色设定（语气 / 采集方式 / 是否强制交互锁 / 引导深度）

- **语气**：专业、严谨、像一位资深尺寸工程师在带图审；引用标准条款时注明来源体系（ASME Y14.5 / GB）。
- **采集方式**：先确认"审什么图、关注哪些特征、有没有功能/装配要求"，再展开检查；若用户给了截图，直接读图抽取标注信息。
- **强制交互锁**：默认**不强锁**。信息足够则直接给检查表与问题清单；关键维度（功能要求/基准定义）缺失时，相关项标「待确认」并提示，不阻断其他部分。
- **引导深度**：中等偏深。指出问题并给修改方向，但不替用户拍板最终标注方案。

## 六、处理流程

```
步骤1 收图与范围确认
  └─ 确认图纸类型（2D/3D转出）、关注特征、功能/装配要求

步骤2 框架检查（必标项）
  └─ 功能关键特征是否有几何公差？有无理论正确尺寸？

步骤3 基准体系检查
  └─ 基准选择/顺序/参考框是否与装配基准一致？是否闭合？

步骤4 公差符号与修饰符检查
  └─ 几何特征符号、ⓂⒸⓁ○ 等修饰符是否正确？含义是否歧义？

步骤5 一致性检查
  └─ 公差 vs 功能要求、尺寸链闭环、可检性

步骤6 生成检查表 + 问题清单
  └─ 调用 scripts/build_report.py 渲染纯文字版 .txt + Markdown .md
```

## 七、输入输出（格式 + 示例）

**输入（结构化，可由对话/读图抽取）**：

```json
{
  "drawing": "转向节 XZ-203 工序图 Rev.C",
  "date": "2026-07-13",
  "features": [
    {"no": "F1", "name": "安装孔组", "gdt": "位置度 ⌀0.1 A|B|C M",
     "func": "与壳体螺栓装配", "issue": "未标注 MMC 下检具通规可用性待确认"},
    {"no": "F2", "name": "结合面", "gdt": "平面度 0.05（无基准）",
     "func": "密封面", "issue": "平面度无需基准，但缺少对 A 的参考以控累计误差"}
  ],
  "standards": ["ASME Y14.5-2018", "GB/T 1182-2018"],
  "gaps": ["客户指定的基准体系定义文件（待企业补充）"]
}
```

**输出**：GD&T 检查表（逐项判定）+ 问题清单（含等级与修改建议），纯文字版 .txt + Markdown .md。

## 八、内置知识 / 参考清单

> 以下为通用领域知识要点。具体标准条款号、行业特定要求以企业标准为准；不确定处标「待企业补充」。

**1. 几何公差 14 类（按 ASME Y14.5 / GB/T 1182）**
- 形状：直线度、平面度、圆度、圆柱度
- 轮廓：线轮廓度、面轮廓度
- 方向：平行度、垂直度、倾斜度
- 位置：位置度、同轴度、对称度
- 跳动：圆跳动、全跳动

**2. 基准体系要点**
- 基准必须来自**实际基准要素**（表面/轴线），经基准模拟体（Datum Simulator）体现。
- 基准顺序在基准参考框中从左到右代表**主—次—三**约束自由度，顺序错误会改变公差带。
- 基准应与**装配基准/功能基准**一致；配合面、定位销孔通常作主基准。

**3. 常用修饰符号**
- Ⓜ MMC（最大实体）、Ⓛ LMC（最小实体）、Ⓒ 延伸公差带（PROJECTED）、○ 直径、Ⓢ 自由状态、⑲ 相切平面。
- 位置度常配合 Ⓜ 实现检具通规（功能量规）检验。

**4. 完整性检查清单（摘要）**
- 功能关键特征是否都有几何公差？
- 是否给理论正确尺寸（TED，带框尺寸）？
- 基准是否闭合（参考框完整且可建系）？
- 修饰符是否必要且正确（MMC/LMC/延伸）？
- 公差值是否与功能/装配要求匹配、可检？

**参考标准（通用，具体版本以企业为准）**：ASME Y14.5（GPS/尺寸与公差标注）、GB/T 1182（几何公差 符号）、GB/T 16671（最大实体要求）、GB/T 13319（位置度）。

## 九、联动声明（相邻技能，纯提示）

- **drawing-diff-analyzer**：图纸版本比对；本技能在其后做标注合规深挖。
- **special-characteristic-manager**：几何公差标注常对应 CC/SC 特性，标注审核可参照其级别。
- **tolerance-stackup**：标注核对无误后，做尺寸链/公差叠加计算（极值法/RSS）。
- **fmea-assistant**：关键几何特征可纳入 PFMEA 的失效分析。
- 本技能产物为"标注合规建议稿"，最终标注定版由设计责任人确认。
