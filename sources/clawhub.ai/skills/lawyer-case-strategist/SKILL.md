# 律师全案攻防实战推演 v3.0

> 头像：`assets/avatar.png`
> 适用领域：民商事诉讼（全领域通用，含合同纠纷、建工纠纷、借贷纠纷、公司纠纷、侵权纠纷等）
> 方法论根基：邹碧华《要件审判九步法》（人民法院出版社2020纪念版新注 / 法律出版社2010初版）

## 一、定位

本技能是律师的全案攻防推演系统，将法官的"要件审判九步法"思维地图，转化为律师从接案到复盘全生命周期的办案工作流。核心是**用法官的脑、走律师的路**——以裁判者视角预判案件走向，以当事人视角构建攻防方案。

**与其他技能分工**：本技能是"案件分析师 + 攻防策略师"（怎么赢）。裁判者版技能 `adjudicator-trial-guide` 是"审判管理师"（怎么审），两者互补。

## 二、激活条件

满足以下任一条件时，应激活本技能：

1. 用户提出民商事案件分析、案情梳理、诉讼策略请求
2. 用户提出"要不要接这个案子"、"这个案子能不能赢"
3. 用户需要构建请求权基础、检索抗辩、梳理争点
4. 用户需要核验起诉状/答辩状/代理词/上诉状的逻辑一致性
5. 用户需要庭审前的攻防预演、质证准备
6. 用户需要裁判结果预判、备选方案
7. 用户提出"九步法"、"要件分析"、"八个一致"、"举证责任分配"等专业术语

## 三、六个阶段（Phase 0-5）

每个阶段有"准入条件 → 任务清单 → 产出物 → 退出条件"四要素，确保工作流可追溯、可复用。

### Phase 0：案件初筛（要不要接？）

**核心问题**：这个案子值不值得接？风险敞口多大？

**任务清单**：
1. 客户背景与诉求确认
2. 案由识别（合同纠纷/建工纠纷/借贷纠纷/公司纠纷/侵权纠纷/物权纠纷等）
3. 时效核查（诉讼时效、除斥期间）
4. 管辖与受理可行性
5. 证据初评（核心证据是否在己方手中）
6. 客户预期管理（胜诉概率区间、时间成本、费用预估）
7. 利益冲突检索

**产出物**：接案评估卡（见 `assets/01-接案评估卡模板.md`）

**退出条件**：形成"接/不接/有条件接"三选一决策

### Phase 1：诉请构建（怎么告？/怎么应？）

**核心问题**：请求权基础是什么？抗辩空间在哪里？

**任务清单**：
1. 固定权利请求（明确原告诉求/被告答辩立场）
2. 检索请求权基础规范（民法典及相关司法解释、特别法条文）
3. 识别抗辩权基础规范（时效抗辩/质量抗辩/付款条件抗辩/担保抗辩等）
4. 拆分构成要件（每一项基础规范的要件逐项列出）
5. 分配举证责任（按法律规范要件分类说）
6. 识别请求权竞合场景（适用选择性合并理论）

**产出物**：请求权基础分析报告（见 `assets/02-请求权基础分析报告模板.md`）

**退出条件**：请求权基础规范与抗辩基础规范已锁定，构成要件已拆分

### Phase 2：攻防推演（九步法系统分析）

**核心问题**：攻防全景长什么样？关键节点在哪？

**任务清单**（九步法递进）：
1. **第一步 固定权利请求** → 攻防目标锁定
2. **第二步 确定权利请求基础规范** → 进攻武器库
3. **第三步 确定抗辩权基础规范** → 防御武器库
4. **第四步 基础规范构成要件分析** → 攻防颗粒度
5. **第五步 诉讼主张的检索** → 己方主张清单
6. **第六步 争点整理** → 真假争点/攻防争点分类
7. **第七步 要件事实证明** → 证据链与举证责任分配
8. **第八步 事实认定** → 证据三性预判
9. **第九步 要件归入并作出裁判** → 裁判走向预判

**产出物**：九步法攻防全景图（见 `assets/03-九步法攻防全景图模板.md`）

**退出条件**：每一步均有明确结论，全景图完整闭环

**深度参考**：详见 `references/九步法理论体系详解.md`、`references/请求权抗辩基础备考表.md`、`references/借贷合同纠纷全流程运用解析.md`

### Phase 3：文书核验（八个一致审计）

**核心问题**：法律文书逻辑自洽吗？经得起上诉审/再审审查吗？

**任务清单**（"八个一致"逐项审查）：
1. 诉讼请求与诉讼主张一致
2. 诉讼请求与事实理由一致
3. 诉讼请求与法律依据一致
4. 诉讼请求与举证质证一致
5. 事实认定与证据采信一致
6. 事实认定与裁判说理一致
7. 裁判说理与裁判主文一致
8. 裁判主文与诉讼请求一致

**深度参考**：`references/裁判文书八个一致深度解析.md`（含"四个不固定"根源诊断、检查方法、核验技巧速查表）

**产出物**：八个一致核验清单（见 `assets/04-八个一致核验清单模板.md`）

**退出条件**：八个一致全部通过（或遗留风险已明确标注）

### Phase 4：庭审预演（争点+证据+质证）

**核心问题**：庭审怎么打？法官会怎么问？对方会怎么抗？

**任务清单**：
1. 争点表整理（与Phase 2第六步衔接）
2. 证据三性预判（真实性/合法性/关联性+证明力）
3. 质证提纲准备（对每项对方证据的质证意见）
4. 法庭发问预演（法官可能发问 + 我方应对）
5. 释明信号识别（参见 `references/法官释明与心证公开信号解读.md`）
6. 辩论提纲（按争点分组组织）
7. 庭审风险预案

**深度参考**：`references/法官释明与价值观深度解析.md`（法官释明的法理基础、典型话术、心证公开的边界）

**产出物**：庭审应对手册（见 `assets/05-庭审应对手册模板.md`）

**退出条件**：每个争点均有攻防预案 + 质证提纲 + 风险预案

### Phase 5：策略复盘（裁判预判+备选方案）

**核心问题**：法官大概率怎么判？最坏情况如何应对？

**任务清单**：
1. 裁判结果预判（按"支持/部分支持/驳回"三档分析）
2. 关键变量识别（哪些事实/证据/法律观点改变会影响判决）
3. 敏感性分析（在不同假设下的判决走向）
4. 备选方案（Plan A/B/C，含调解空间）
5. 上诉/再审预案
6. 执行预案

**产出物**：裁判预判与备选方案（见 `assets/06-裁判预判与备选方案模板.md`）

**退出条件**：形成"主推方案 + 备选方案 + 风险预警"完整输出

## 四、核心方法论：要件审判九步法

底层逻辑是**演绎推理（三段论）**：
- 前四步：确立大前提（找法析法）—— 固定请求 → 锁定规范 → 锁定抗辩 → 拆分要件
- 中间三步：确立小前提（主张争点证明）—— 检索主张 → 整理争点 → 证明要件事实
- 第八步：事实认定
- 第九步：要件归入 → 结论（涵摄归入）

**关键概念速查**：
- **要件**：法律规范构成要件 / 要件事实（与规范对应的主要事实）
- **请求权基础规范**：支持原告诉求的法律条文
- **抗辩权基础规范**：被告抗辩依据的法条
- **抗辩 vs 否认**：抗辩产生新法律效果且基础事实可并存；否认仅否定原因事实
- **主张责任**：当事人须对有利要件事实提出主张，否则败诉风险
- **举证责任**：法律规范要件分类说（权利发生/妨碍/消灭要件由主张方负担）
- **争点**：以要件为基本元素的争议点
- **主张共通原则**：一方未提出的要件事实，对方提出后可视为已主张
- **八个一致**：裁判文书逻辑自洽的八项审查标准
- **选择性合并理论**：请求权竞合时合并主张，法院择一裁判

**详细论述**：见 `references/九步法理论体系详解.md`

## 五、五大核心理念

1. **介入前移**：Phase 0 即介入，避免"事后救火"
2. **动态迭代**：六阶段不是单向流水线，每个阶段输出可反哺前置阶段
3. **双向攻防**：原告视角与被告视角并行分析
4. **法官视角贯穿**：每个阶段都问"法官会怎么看"
5. **产出复用**：每阶段产出物可作为下一案的方法论资产

## 六、典型案由与请求权基础示例

> 以下以建工纠纷为例展示九步法的运用方式，方法论可迁移至所有民商事案由。

| 案由 | 主要请求权基础规范 | 常见抗辩 |
|---|---|---|
| 工程款支付纠纷 | 《民法典》第793条、《建工解释（一）》第43条 | 付款条件未成就、时效抗辩 |
| 实际施工人主张 | 《建工解释（一）》第43条 | 合同相对性、转包合法性 |
| 工程价款优先受偿权 | 《民法典》第807条 | 行使期限、范围抗辩 |
| 工程质量纠纷 | 《民法典》第793、802条、《建筑法》 | 质量责任划分、修复费用合理性 |
| 工期延误纠纷 | 《民法典》第590条 | 不可抗力、合同约定违约金 |
| 造价鉴定争议 | 《建工解释（一）》第30-32条 | 鉴定程序、鉴定结论质证 |
| 保证金返还纠纷 | 《建工解释（一）》第17条 | 保修期未届满、缺陷责任 |

**其他常见民商事案由**：民间借贷纠纷、买卖合同纠纷、股权转让纠纷、合伙协议纠纷、保证合同纠纷、租赁合同纠纷等，均可按同一方法论展开分析。

**备考表全文**：见 `references/请求权抗辩基础备考表.md`

## 七、常见实务疑难问题示例

> 以建工领域为例，展示九步法如何破解疑难问题。其他领域的疑难问题可按同一思路分析。

- **借名施工/挂靠**：实际施工人认定标准、内部责任划分
- **连环分包/转包**：合同效力、付款责任穿透
- **背靠背条款**：效力认定、付款条件抗辩
- **以房抵债**：与建工款优先受偿权冲突
- **造价司法鉴定**：启动条件、鉴定机构选择、重新鉴定
- **黑白合同/备案合同**：以哪份为准
- **优先受偿权行使期限**：起算点、除斥期间

**典型案例深度解析**：见 `references/借贷合同纠纷全流程运用解析.md`（以借贷为例完整演示九步法运用，方法论可迁移至所有民商事案件）

## 八、与裁判者版技能的分工

| 维度 | 律师版（本技能） | 裁判者版（adjudicator-trial-guide） |
|---|---|---|
| 视角 | 攻防策略/代理方案 | 审判思路/庭审管理 |
| 核心问题 | "怎么赢" | "怎么审" |
| 释明 | 如何利用法官释明信号 | 如何正确行使释明权 |
| 文书 | 核验起诉状/代理词质量 | 核验裁判文书质量 |
| 释明边界 | 提示法官未释明可能上诉 | 不得替代当事人选择诉讼路径、不得偏向一方 |
| 价值观 | 最大化当事人利益 | 居中裁判 |

## 九、📦 导出交付

本技能支持将任意阶段产出物（Markdown格式）一键转为规范排版的DOCX文档：

```bash
python scripts/markdown_to_docx.py <output_dir> [output_dir2 ...]
```

支持：
- 单文件转换：`.md` → `.docx`
- 批量转换：递归扫描目录
- 批量打包：自动ZIP打包

DOCX样式：A4 / 宋体（正文）/ 黑体（一级标题）/ 1.5倍行距 / 标准页码

## 十一、给使用者的提醒

1. **方法论是中性的**：九步法既可进攻也可防御，关键看站在哪一方
2. **请求权基础决定天花板**：所有策略都要回到请求权基础规范
3. **举证责任分配是风向标**：决定谁先举证、谁先败诉
4. **八个一致是底线**：任何一个不一致都可能被对方抓住
5. **法官释明是信号**：律师要学会读懂、适时利用，但不可滥用
6. **裁判预判不是赌博**：是基于要件事实+证据+法律适用的概率分析
