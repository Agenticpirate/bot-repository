# 大藏经CBETA2026

大藏经 CBETA2026 简体版检索核心 Skill。以 IMA 订阅知识库「大藏经CBETA2026简体版」为唯一数据源，提供精准的经论原文检索与引文核验。

## 为什么单独封装这个 Skill？

很多用户看到「天台研究」Skill 时不知道其中包含大藏经通用检索能力。大藏经是**跨宗派的基础设施**——无论修学天台、净土、禅宗还是唯识，查经论原文都离不开它。这个 Skill 把大藏经检索能力**显式暴露出来**，让不熟悉天台研究的用户也能直接使用。

## 适用场景

- 佛经原文检索（经号、卷数、品名、段落）
- 经论名相解释与出处核对
- 律藏 / 论藏条文查询
- 跨经论对比（同一名相在不同部类中的表述）
- CBETA 在线链接生成
- 任何需要「这句佛经原文到底在哪」的问题
- 教学研究中的引文核验（讲稿 / 论文 / 复讲的经文准确性审核）

## 核心规则（铁律）

1. **唯一数据源：大藏经CBETA2026简体版（订阅知识库）**——KB ID `7466305749789975`
2. **知识库优先，不自动搜索网络**——默认仅检索该知识库，除非用户明确说"搜一下网上"
3. **每个论断标注来源**——引用 CBETA 标准格式：典籍名（CBETA 编号, 卷数/页码/栏位）
4. **德山棒原则——不编造佛经原文**——信息不足时明确说"现有资料中未覆盖此部分"，绝不拼凑
5. **CBETA 行级深链（铁律·2026-08-30 升级）**——引用必须精确到"页+栏+行"，并附行级深链：
   - 行级深链（精确到行）：`https://cbetaonline.dila.edu.tw/zh/{藏经}{册}{经号}_p{页}{栏}{行}`
     - 例：大正藏第46册1939经·页938·下栏·第4行 → `https://cbetaonline.dila.edu.tw/zh/T46n1939_p0938c04`
     - linehead 结构：T=藏经(大正T/卍续X/嘉兴A…)、46=册、1939=经号、p0938=页、c=栏(a上/b中/c下)、04=行
   - 卷级备用链（无栏行信息时）：`https://cbetaonline.dila.edu.tw/zh/{work_id}_{juan}`（例 `https://cbetaonline.dila.edu.tw/zh/T1939_001`）
   - 凡定位到页栏行，必须用行级深链；仅卷/页级才用卷级链。

## 两种工作模式

### 模式一：简单问答

适用场景：名相定义、单一概念的快速解答、"这句话出自哪里"。

流程：
1. 用 `mcp__ima-mcp__search_knowledge` 检索 KB `7466305749789975`
2. 提取核心信息，标注 CBETA 出处
3. 如资料不足，明确告知覆盖范围

输出格式：
- **答案**（1-3句，直击要点）
- **出处**（CBETA 标准格式：典籍名 Txx, no. xxxx, 卷x / 页x / 栏x）
- **原文引用**（关键经文原文 1-2 条）
- **不足说明**（如资料未覆盖则注明）

### 模式二：深度研究

适用场景：跨经论文献对比、系统性教理分析、学术级报告、复讲审核。

**两步工作流**：

**第一步：检索整理**
1. 使用多组检索词并行搜索（繁简体都要试）
2. 整理所有相关切片，按主题/典籍分类
3. 提取关键经文原文 + 古代注释 + 近现代学者观点
4. 构建结构大纲

**第二步：审核标注**
1. 逐条核验 CBETA 出处准确性（经号/卷/页/栏）
2. 为每个论断标注：典籍名 → CBETA编号 → 卷页栏 → 原文位置
3. 检查是否有遗漏的重要平行文本
4. 补充 CBETA 在线阅读链接

输出格式：
- 标题 + 摘要（200字内）
- 正文（结构化分章节，每章含论述+引文）
- **出处总表**（每条论断一行，含 CBETA 完整定位）
- CBETA 在线链接列表
- 研究局限（资料未覆盖之处）

## 检索策略

**必检 KB**：
- `7466305749789975`（大藏经CBETA2026简体版）——**唯一必检**

**检索词技巧**：
- 使用**繁体中文**检索（如"止觀""圓教""一念三千"）效果显著优于简体
- 至少 2-3 组同义检索词覆盖不同表述（如："一念三千"/"一念三千界"/"三千诸法"）
- 经号检索用标准格式（如"T09"/"T46"/"T12"）
- 人名+关键词组合（如"智者大师 止观"、"蕅益大师 净土"）
