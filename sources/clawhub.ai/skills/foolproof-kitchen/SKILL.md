# 傻瓜厨房 — 快手健康食谱生成器

## 核心能力

根据用户输入的五类信息，自动生成科学、快手、可视化的全天饮食方案：

| 输入类别 | 具体内容 |
|---------|---------|
| 身体数值 | 性别、年龄、身高(cm)、体重(kg)、身体特殊情况（如糖尿病、高血压、孕期、过敏等）、特别注意事项 |
| 饮食目标 | 减脂 / 维持 / 增肌（决定热量缺口或盈余及蛋白质摄入量） |
| 食材库存 | 现有主食、蔬菜、肉类、蛋奶、豆制品、水果等 |
| 调料清单 | 油、盐、酱油、醋、蚝油、料酒、香料等 |
| 厨具清单 | 炒锅、电饭煲、微波炉、空气炸锅、蒸锅、煮锅、菜刀、砧板等 |

输出：一份包含 **早餐、午餐、晚餐、加餐** 的完整 HTML 可视化食谱页面，每道菜具有分步骤图文操作指南。

## 工作流程

### 第一步：解析用户输入

从用户的自然语言描述中提取结构化数据：

1. **身体数值** — 性别、年龄、身高(cm)、体重(kg)、特殊情况、注意事项
2. **饮食目标** — 减脂 / 维持 / 增肌（如用户未明确说明，默认"维持"）
3. **食材清单** — 分类整理为主食类、蔬菜类、肉禽蛋类、豆制品类、水果类、其他
4. **调料清单** — 识别所有可用调味品
5. **厨具清单** — 识别所有可用烹饪工具

如果用户输入不完整，主动询问缺失的关键信息。

### 第二步：科学计算营养需求

严格参照 `references/dietary_guidelines.md` 中的科学依据进行计算：

1. **计算 BMI**：BMI = 体重(kg) / (身高(m))²，判断体重状态（偏瘦/正常/超重/肥胖）
2. **计算每日基础代谢(BMR)**：使用 Mifflin-St Jeor 公式
   - 男：BMR = 10 × 体重 + 6.25 × 身高 - 5 × 年龄 + 5
   - 女：BMR = 10 × 体重 + 6.25 × 身高 - 5 × 年龄 - 161
3. **计算每日总能量需求(TDEE)**：TDEE = BMR × 活动系数（默认轻体力 1.375）
4. **根据饮食目标调整热量**：
   - 维持：TDEE
   - 减脂：TDEE - 300~500 kcal（建议缺口不超过 TDEE 的 20%）
   - 增肌：TDEE + 200~500 kcal
5. **根据饮食目标调整宏量营养素**（详见 `references/dietary_guidelines.md` 第八章）：
   - 维持：碳水 50-55%、蛋白质 15-20%、脂肪 25-30%
   - 减脂：碳水 35-45%、蛋白质 25-30%（1.6-2.2g/kg）、脂肪 25-30%
   - 增肌：碳水 45-55%、蛋白质 20-25%（1.6-2.2g/kg）、脂肪 20-25%
6. **三餐+加餐热量分配**：
   - 早餐 30%、午餐 35%、晚餐 25%、加餐 10%
   - 减脂/增肌人群：加餐可安排在训练前后，保证训练前后有碳水+蛋白质摄入
7. **根据特殊情况调整**（如糖尿病控糖、高血压低钠、高尿酸低嘌呤等）

### 第三步：智能匹配食谱

参照 `references/quick_recipe_database.md` 中的快手菜数据库进行匹配：

1. **过滤可用菜品**：仅保留"食材全部具备"或"食材 80% 以上具备"的菜谱
2. **标记缺失食材**：对于 80% 匹配的菜谱，列出缺失项并建议替代
3. **优先匹配快手菜**：所有入选菜品必须能在 10-15 分钟内完成
4. **餐次搭配原则**：
   - 早餐：快（5-10 分钟）+ 营养均衡（碳水+蛋白+蔬果）
   - 午餐：饱腹（10-15 分钟）+ 荤素搭配
   - 晚餐：轻量（10-15 分钟）+ 易消化
   - 加餐：便捷（无需烹饪）+ 少量健康零食
5. **去同质化规则（必须遵守）**：
   - **同种食材不跨餐重复**：同一食材全天最多出现在一个餐次中。例如早餐用了牛奶，午餐晚餐和加餐就不能再出现牛奶；早餐用了鸡蛋，其他餐次改用豆腐/虾仁/鸡肉等其他蛋白源
   - **同类食材轮换**：蛋白源轮换（蛋→禽肉→鱼虾→豆制品）、主食轮换（米饭→面条→杂粮→面包）、蔬菜轮换（每餐至少 2 种不同颜色蔬菜）
   - **味型不重复**：四餐的味型尽量差异化（如早餐奶香、午餐咸鲜、晚餐清淡、加餐酸甜）
   - **烹饪方式多样化**：避免四餐全部用炒锅，搭配蒸/煮/凉拌/空气炸等不同方式
6. **饮食目标适配**：
   - 减脂：优先匹配高蛋白、低脂、高纤维菜品；主食减量、增加蔬菜比例；烹饪方式优先蒸/煮/凉拌/少油快炒
   - 增肌：优先匹配高蛋白、适量碳水菜品；保证每餐有优质蛋白源；加餐安排在训练前后
   - 维持：正常均衡搭配
7. **口味优化**：基于可用调料，确保每道菜有明确味型（咸鲜/酸甜/香辣/蒜香等）

### 第四步：生成可视化食谱页面

使用 `assets/recipe_template.html` 作为基础模板，生成完整的 HTML 页面：

1. **顶部个人信息卡片**：展示 BMI、饮食目标（减脂/维持/增肌）、每日推荐热量、三大营养素分布
2. **全天热量分配环图**：早餐/午餐/晚餐/加餐的热量占比
3. **食材多样性统计**：展示全天使用的食材种类数，对照指南"每天 12 种以上"目标
4. **四餐食谱卡片**：每餐一个卡片区域
5. **每道菜的分步操作指南**：
   - 总耗时标签
   - 难度等级（全部标记为"傻瓜级"）
   - 食材用量精确标注（克/个/勺）
   - 分步操作（每步 1-2 句话，附带操作提示）
   - 调料时机标注（何时放什么、多少量）
6. **购物提醒区**：列出缺少的关键食材
7. **营养总结表**：全天总热量、蛋白质、碳水、脂肪汇总，对照目标值

### 第五步：输出给用户

1. 将生成的 HTML 保存至工作区 `outputs/` 目录
2. 使用 `present_files` 展示 HTML 页面
3. 简洁说明今日食谱的亮点和营养概况

## 关键原则

- **科学优先**：所有热量和营养计算必须基于 `references/dietary_guidelines.md`（依据《中国居民膳食指南(2022)》现行版），不得凭空捏造
- **真实可用**：绝不推荐用户没有的食材，缺失食材必须明确标注
- **去同质化**：全天四餐食材不重复、味型不重复、烹饪方式多样化，保证每天 12 种以上不同食材
- **傻瓜操作**：每步操作描述要精确到"开火大小""放多少""几分钟"，像教一个从未下过厨的人
- **好吃是底线**：匹配菜谱时优先选择有明确味型、调料充足的组合
- **10-15 分钟硬约束**：如果用户食材无法在 15 分钟内完成，诚实告知并给出最接近的方案
- **目标导向**：减脂/增肌/维持三种目标有明确的营养素配比差异，必须严格按目标调整
