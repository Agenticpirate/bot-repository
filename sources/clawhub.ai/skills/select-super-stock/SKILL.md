# A 股单股研究助手

真实性修复版 v1.4.0。此技能只研究用户明确指定的一只 A 股，输出来源、交易日与技术观察；不是“超级股票”推荐器。

## 使用

```bash
python3 scripts/stock_analyzer.py --symbol 600938
```

`--date YYYY-MM-DD` 只接受已完成交易日；`--json` 输出结构化结果；`--timeout` 限制整个联网采集过程。脚本使用 AKShare 的新浪日线为首选、东方财富为备用，不安装依赖、不改代理、不读取凭据、不发消息。

退出码 0 表示已取得可校验日线观察；2 表示数据不可用，停止所有行情结论。它没有缓存：非交易时也只拉取带交易日期的历史日线，不把旧报告伪装成实时数据。

## 约束

- 输入仅限沪深北 A 股 6 位代码。港股、美股、基金及指数不在本版范围，明确写“未覆盖”。
- 没有准确交易日、前一交易日、OHLCV、足够历史长度或数据源时，写“不可用/证据不足”；不以 0、N/A、示例或模型记忆补值。
- 只列可由日线计算的事实：收盘价、单日变化、MA20/60/250（历史足够时）、RSI14、52 周区间位置。调整方式和来源必须随输出写明。
- 技术观察不是质量判断、估值结论、基本面验证、相似公司比较或收益预测。不得把“均线之上”“低位”称作买点、击球区或推荐。
- ROE、股息率、财报、行业周期、新闻、股东结构及港美股数据不由脚本提供。只有获得独立、带日期的可核验来源后，才可补充，并要单独标明来源/口径/时间。
- 不自动调用交易、持仓管理、下单、发帖或其他技能。真实账户行为需要单独明确授权。

## 输出

报告按以下顺序：数据口径 → 已核验日线观察 → 技术研究备注 → 未覆盖/缺失项 → 风险提示。区分观察与推断，不评分、不排名、不输出仓位或交易策略。

用于 Discord 时保留“数据日期、采集时间、来源、调整方式、非实时日线”五项。末尾写“仅供学习与信息参考，不构成投资建议”。
