# 检测报告合规护栏 (Inspection Report Compliance Guard)

## 触发条件

当用户需要审核、发布、或生成以下内容时激活本技能：
- 产品质量检测报告
- 委托检验报告
- 监督抽查检验报告
- 型式试验报告
- 出厂检验报告
- 第三方检测报告
- 检验检测机构对外宣传材料

## 核心检查规则

### 一、报告格式合规（依据RB/T 214-2017）

必须包含以下要素，缺少任一项即判定不合规：

| 序号 | 必需要素 | 说明 |
|------|----------|------|
| 1 | 报告编号 | 唯一性编号 |
| 2 | 委托方信息 | 名称、地址、联系方式 |
| 3 | 样品信息 | 名称、规格型号、数量、状态 |
| 4 | 检测依据 | 引用的标准编号及名称（GB/GB/T/行标） |
| 5 | 检测项目 | 明确列出各检测项目 |
| 6 | 检测结果 | 各项目的实测数据 |
| 7 | 单项判定 | 每项的合格/不合格判定 |
| 8 | 综合结论 | 整体判定结论 |
| 9 | 检测日期 | 实际检测日期 |
| 10 | 报告日期 | 报告签发日期 |
| 11 | 检测人员签名 | 须有上岗证 |
| 12 | 审核人员签名 | 不得与检测人员为同一人 |
| 13 | 批准人签名 | 授权签字人 |
| 14 | 机构公章/检验检测专用章 | 必须加盖 |
| 15 | CMA标志及证书编号 | 资质认定机构必须标注 |

### 二、资质合规

- 检测机构必须持有有效的《检验检测机构资质认定证书》（CMA）
- 检测项目必须在资质认定批准范围内
- 不得超范围出具带CMA标志的报告
- **拦截规则**：超范围使用CMA标志 → 【严重不合规】

### 三、标准引用合规

- 引用的检测标准必须为现行有效版本
- 已废止标准不得作为检测依据
- 标准变更时须确认新方法适用性
- **拦截规则**：引用已废止标准 → 【不合规】

### 四、数据与结论合规

- 检测数据必须与原始记录一致
- 判定结论必须有明确依据（标准条款）
- 不得出具"参考""仅供参考"等模糊结论替代正式判定
- 测量不确定度应在适用时给出
- **拦截规则**：无依据判定 → 【不合规】

### 五、用语规范

| 不合规用语 | 合规替代 | 依据 |
|-----------|----------|------|
| "产品质量最好" | 不得使用绝对化用语 | 广告法 |
| "100%合格" | 给出具体检测结论 | RB/T 214 |
| "国家级检测" | 需有实际资质依据 | 资质认定管理办法 |
| "免检产品" | 已取消免检制度 | 产品质量法 |
| "中国名牌" | 已取消评选 | 相关规定 |

### 六、CMA使用规范

- CMA标志必须按规定格式使用
- 证书编号必须与资质认定证书一致
- 不得转让、出租、出借资质认定证书
- 分包项目必须注明分包方及其资质
- **拦截规则**：CMA标志格式错误/证书编号不符 → 【严重不合规】

### 七、委托检验特殊要求

- 委托检验须注明"仅对来样负责"（适用时）
- 样品信息由委托方提供时须注明
- 不得将委托检验结果用于产品质量监督抽查
- 委托方不得要求修改检测数据

## 输出格式

```
【检测报告合规审查报告】

报告类型：xxx
审查时间：xxx

✅ 合规项：x 项
⚠️ 警告项：x 项
❌ 不合规项：x 项

--- 不合规详情 ---
[序号] 问题描述
  → 违反条款：xxx
  → 修改建议：xxx

--- 警告详情 ---
[序号] 问题描述
  → 建议：xxx

【结论】：通过 / 不通过（需修改后复审）
```

## 使用方式

用户提交待审核文本后，逐项对照上述规则进行检查，输出结构化审查报告。

对于严重不合规项（❌），必须明确拦截，建议不得发布。
对于警告项（⚠️），给出修改建议但不强制拦截。
