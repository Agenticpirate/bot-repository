# 未成年人保护合规护栏 (minor-protection-guard)

## 概述

**minor-protection-guard** 是面向网络产品、游戏、直播、社交、教育场景的"事前拦截"工具：在文案、功能说明、用户协议、运营话术**发布前**，实时检测 6 类未成年人保护高频违规表述，按 high / medium / low 分级给出整改建议。

它与 **ai-persona-guard**（AI 拟人化互动中的未成年人保护）形成互补——后者覆盖 AI 虚拟互动场景，本工具覆盖产品 / 平台通用合规；二者可叠加使用，构建更完整的未成年人保护护栏网。

本工具定位为 **Guard（护栏）**：轻量、前置、零延迟，不替代深度合规审计。如需正式合规审计，建议结合专业法律服务。

## 标准背景

依据均为**全文公开**的法律法规与监管文件：

- 《中华人民共和国未成年人保护法》（2021年6月1日施行）"网络保护"专章
- 《未成年人网络保护条例》（2024年1月1日施行，全文公开）
- 国家新闻出版署《关于防止未成年人沉迷网络游戏的通知》（2019年11月1日施行，2021年8月进一步收紧至每周最多3小时）
- 《中华人民共和国个人信息保护法》第三十一条（不满十四周岁未成年人个人信息需监护人同意）

## 与 ai-persona-guard 的关系

| 工具 | 覆盖场景 | 侧重点 |
|---|---|---|
| minor-protection-guard | 通用网络产品 / 游戏 / 直播 / 社交 / 教育 | 实名、青少年模式、防沉迷、消费限制、儿童信息同意、不良信息过滤 |
| ai-persona-guard | AI 拟人化互动（虚拟恋人、情感陪伴等） | 未成年人防沉迷、内容安全红线、用户权益与防诱导 |

**建议**：面向未成年人的 AI 互动产品，同时叠加两者；通用产品至少使用本工具。

## 快速开始

```bash
# 检测一段文本（文本格式，默认）
python scripts/guard.py --text "本游戏无需实名认证，未成年人可全天游戏，可无限充值"

# 以 JSON 格式输出（便于 Agent / 程序消费）
python scripts/guard.py --text "无青少年模式，不区分成年未成年" --format json

# 从标准输入读取
echo "收集儿童信息无需家长同意" | python scripts/guard.py --stdin

# 列出全部检测类别
python scripts/guard.py --list-categories
```

**无任何第三方依赖、无网络请求、无外部进程调用**，下载即可运行。

## Agent 调用

当生成或审核涉及未成年人的产品文案、功能说明、用户协议、运营话术时，Agent 应主动调用本工具做前置拦截：

```python
import subprocess, json

def check_minor_protection(text: str) -> dict:
    out = subprocess.run(
        ["python", "scripts/guard.py", "--text", text, "--format", "json"],
        capture_output=True, text=True, cwd="<skill_dir>"
    )
    return json.loads(out.stdout)

report = check_minor_protection(user_text)
if report["level"] != "clean":
    # 把 findings 中的 suggestion 反馈给用户，要求修改后再发布
    ...
```

- 命中 `high` → 必须修改后才能发布
- 命中 `medium` → 强烈建议修改
- `clean` → 通过前置拦截

## 检测范围

| 类别 | 风险 | 典型违规表述 |
|---|---|---|
| 未落实实名认证 | high | 无需实名认证、游客模式无限制、no age verification |
| 未提供未成年人模式/青少年模式 | high / medium | 无青少年模式、不区分成年未成年、no minor mode |
| 游戏未落实防沉迷/无时长限制 | high | 无游戏时长限制、未成年人可全天游戏、no playtime limit |
| 诱导未成年人消费/打赏 | high | 未成年人可无限充值、诱导未成年人打赏、no spending limit |
| 收集儿童个人信息未取得监护人同意 | high | 收集儿童信息无需家长同意、默认收集未成年人信息 |
| 向未成年人推送不良信息 | medium | 向未成年人推送不良内容、无不良信息过滤、未处置网络欺凌 |

每条命中均返回：`term`（命中词）、`category`（类别）、`risk`（风险）、`suggestion`（整改建议）、`basis`（法规依据）、`start`/`end`（位置）。

## 安全与隐私

- **纯本地运行**：所有检测在本地完成，文本不会离开本机，不发任何网络请求。

- **无副作用**：只读输入文本，不写文件、不修改系统、不调用外部进程。
- **透明可审**：所有规则为 `scripts/rules/terms.py` 中的声明式词表，逻辑完全可读、可审计。
