# 管理体系整合系统

## 任务目标
- 本Skill用于:企业多管理体系整合优化，避免重复工作，提升管理效率
- 能力包含:体系录入、要素映射、兼容性分析、文件生成
- 触发条件:用户表达整合多个管理体系、管理体系融合优化、建立统一管理体系等意图

## 预置管理体系标准

系统预置以下主流ISO管理体系框架，智能体基于这些框架进行映射和分析：

| 体系 | 标准号 | 核心要素 |
|------|--------|----------|
| 质量管理 | ISO 9001:2015 | 组织环境、领导力、策划、支持、运行、绩效评价、持续改进 |
| 环境管理 | ISO 14001:2015 | 组织环境、领导力、策划、支持、运行、绩效评价、持续改进 |
| 职业健康安全 | ISO 45001:2018 | 组织环境、领导力、策划、支持、运行、绩效评价、改进 |
| 信息安全管理 | ISO 27001:2022 | 组织环境、领导力、策划、支持、信息安全风险评估、信息安全处置、绩效评价、改进 |
| 食品安全管理 | ISO 22000:2018 | 前提方案、HACCP计划、PRP、OPRP、CCP、应急准备响应 |
| 能源管理 | ISO 50001:2018 | 领导力、策划、支持、运行、绩效评价、改进 |

## 管理体系结构模板

当用户录入管理体系时，按以下结构提取信息：

```yaml
体系名称: <体系名称>
标准号: <对应ISO标准号>
版本: <版本信息>
核心要素:
  - 要素名称: <要素1>
    子要素: [<子要素列表>]
    要求描述: <核心要求概述>
  - 要素名称: <要素2>
    ...
  ...
特有条款: <该体系特有的关键要求>
```

## 操作流程

### 流程一：管理体系录入

1. **收集信息**
   - 用户描述管理体系（可以是现有制度、ISO标准、企业内部标准）
   - 识别体系类型，对应预置框架或新建

2. **结构化提取**
   - 解析出核心要素、子要素、关键要求
   - 识别与其他体系的对应关系
   - 输出结构化的体系数据

3. **存储确认**
   - 在会话中展示录入结果
   - 确认无误后进入下一阶段

### 流程二：要素映射

1. **映射类型**
   - **等同映射**: 不同体系中的完全相同要求
   - **包含映射**: 一个要素包含另一个要素的要求
   - **交叉映射**: 部分重叠，需整合处理
   - **独立映射**: 某一体系独有，无对应要素

2. **映射操作**
   - 用户指定要建立映射的两个体系
   - 智能体识别并列出可映射的要素对
   - 用户确认或调整映射关系
   - 输出映射关系表

3. **映射关系表格式**
   ```markdown
   | 体系A要素 | 映射类型 | 体系B要素 | 整合策略 |
   |-----------|----------|-----------|----------|
   | 4.1理解组织环境 | 等同 | 4.1组织环境 | 合并 |
   | 6.1风险与机遇 | 包含 | 6.1危险源辨识 | 扩展 |
   | 8.1运行策划 | 交叉 | 8.1文件控制 | 整合 |
   ```

### 流程三：兼容性分析

1. **分析维度**
   - 重叠度分析: 统计各体系间的重叠要素数量与比例
   - 差异点识别: 列出各体系独有要求
   - 冲突检测: 识别可能存在矛盾的要求
   - 整合优化空间: 评估整合后的效率提升

2. **输出报告结构**
   ```markdown
   # 管理体系兼容性分析报告
   
   ## 一、分析概要
   - 分析体系: [体系列表]
   - 总体重叠率: XX%
   - 可整合要素: XX个
   - 冲突要素: XX个
   
   ## 二、重叠要素清单
   [详细列表]
   
   ## 三、差异要素清单
   [各体系独有要素]
   
   ## 四、潜在冲突点
   [冲突描述与建议]
   
   ## 五、整合优化建议
   [可操作的整合方案]
   ```

3. **分析执行**
   - 调用兼容性分析流程
   - 生成完整报告
   - 列出关键的整合优化建议

### 流程四：体系文件生成

1. **生成类型**
   - **整合手册**: 统一的管理体系手册
   - **程序文件清单**: 整合后的程序文件列表
   - **要素对照表**: 各要素在不同体系中的对应关系
   - **差异分析表**: 各体系差异及处理方式

2. **生成流程**
   - 用户指定生成目标（如"生成整合管理手册"）
   - 确认涵盖的体系范围和整合策略
   - 生成Markdown格式文件
   - 提供文件下载或保存建议

3. **整合管理手册模板**
   ```markdown
   # [组织名称] 整合管理体系手册
   
   ## 1. 目的与范围
   ## 2. 引用标准
   ## 3. 术语与定义
   ## 4. 组织环境
   ## 5. 领导力
   ## 6. 策划
   ## 7. 支持
   ## 8. 运行
   ## 9. 绩效评价
   ## 10. 改进
   ## 附录A: 要素对照表
   ## 附录B: 体系差异说明
   ```

## 使用示例

### 示例1：基础整合需求
- **场景**: 用户有ISO 9001和ISO 14001两套体系，希望整合
- **操作**:
  1. 分别录入两个体系
  2. 建立要素映射
  3. 执行兼容性分析
  4. 生成整合管理手册
- **关键点**: 两个体系结构高度相似(均基于PDCA)，映射和整合相对简单

### 示例2：多体系整合
- **场景**: 企业需同时运行质量、环境、职业健康安全、信息安全四个体系
- **操作**:
  1. 批量录入四个体系
  2. 生成多体系映射矩阵
  3. 执行兼容性分析，识别重叠和差异
  4. 生成整合优化方案
- **关键点**: 优先处理高重叠要素，独有要素单独处理

### 示例3：新增体系整合
- **场景**: 企业已有质量管理体系，现需新增ISO 27001信息安全体系
- **操作**:
  1. 加载现有质量管理体系数据
  2. 录入信息安全体系
  3. 执行兼容性分析
  4. 生成整合方案，最大限度复用现有文件
- **关键点**: 分析与现有体系的交叉部分，设计复用策略
