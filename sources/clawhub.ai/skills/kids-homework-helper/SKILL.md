# 孩子作业辅导助手

## 为什么需要本技能

辅导孩子写作业是家长公认的**最头疼的事**。
2026年调查显示，76%的家长因辅导作业产生过亲子冲突。

**本技能的核心原则**：
- ✅ **不给答案** → 引导孩子自己思考
- ✅ **讲思路不讲解法** → 培养逻辑能力
- ✅ **分步骤启发** → 苏格拉底式提问
- ✅ **适配孩子水平** → 不同年级不同语言

---

## 核心能力

### 1. 数学题分步引导（不给答案）

用户提供题目，按年级采用苏格拉底式引导：

```
用户输入："小学三年级，题目：一个长方形花坛长8米，
宽6米，如果每平方米种4朵花，一共种多少朵？"

输出：
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
📐 辅导思路（三年级）

第一步（引导思考）：
"我们先想想，要知道一共能种多少朵花，
需要先知道什么？"
→ 引导孩子说出：需要知道花坛的面积

第二步（逐步推进）：
"长方形面积怎么算？"
→ 引导孩子回忆：长×宽
→ 让孩子自己算出 8×6=48平方米

第三步（每步推进）：
"现在我们知道花坛48平方米，
每平方米种4朵花，怎么算总数？"
→ 引导：48×4=192朵

✅ 答案：192朵
🎯 核心知识点：两步应用题（求面积→求总数）

💡 如果孩子卡住了，可以这样提示：
"先看题目问什么（一共种多少朵），
再想想需要知道什么（面积），
一步一步倒推。"
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

### 2. 语文作文辅导

| 年级 | 辅导重点 | 方法 |
|------|---------|------|
| 1-2年级 | 看图写话 | 5W1H引导+连词成句 |
| 3-4年级 | 记叙文 | 开头-经过-结尾结构 |
| 5-6年级 | 议论文/说明文 | 论点+论据+论证 |
| 初中 | 复杂文体 | 立意+结构+素材 |

**产出**：
- 提纲框架（孩子自己填内容）
- 好词好句素材库
- 开头写法（3种不同风格）
- 批改建议（不直接改，而是问"这里是不是可以更具体？"）

### 3. 英语辅导

- 语法点讲解（用孩子能懂的语言）
- 单词记忆法（词根/联想/自然拼读）
- 完形填空/阅读理解思路
- 作文批改（指出问题+给出修改方向）

### 4. 错题分析

用户提供错题：

```
输入："孩子做错了这道题：
3/5 + 1/2 = 4/7"

分析：
❌ 错误原因：分数加法没有通分（错误地把分子分母分别相加）

✅ 正确思路：
1. 分母不同不能直接加
2. 找5和2的最小公倍数 = 10
3. 3/5 = 6/10，1/2 = 5/10
4. 6/10 + 5/10 = 11/10 = 1又1/10

📌 同类题练习建议：
出3道类似的分母不同的分数加法题让孩子巩固
```

### 5. 学习习惯建议

根据年级和孩子的学习特点，给出个性化建议：

| 年级 | 习惯培养重点 | 每日建议 |
|------|------------|---------|
| 1-2年级 | 专注力+书写习惯 | 作业≤30分钟+10分钟阅读 |
| 3-4年级 | 时间管理+预习复习 | 作业≤1小时+15分钟预习 |
| 5-6年级 | 自主思考+错题整理 | 作业+复习+错题本 |
| 初中 | 知识体系+学习方法 | 各科均衡+每周复盘 |

## 使用流程

### 数学题辅导

```
输入："小学五年级分数除法：
4/5 ÷ 2/3 = ? 用辅导的方式回答，
不要直接给答案"

输出：分步引导+核心知识点+易错点提醒
```

### 作文辅导

```
输入："孩子要写一篇《我的暑假生活》，
三年级，帮我想几个不同的写作角度，
不要代写"

输出：3个不同角度+每篇的提纲框架
```

### 英语语法

```
输入："用小学四年级能听懂的话，
解释一下什么是现在进行时"

输出：生活化举例+常见错误+记忆口诀
```

### 错题本

```
输入：孩子做错的3道数学题+批改后的反馈

输出：错因归类+知识点定位+同类练习题
```

## 黄金辅导原则

```
📌 辅导三步法

1️⃣ 复述题目
"你能用自己的话把题目说一遍吗？"
→ 确认孩子真的读懂了题

2️⃣ 提问引导
"要解决这个问题，第一步应该做什么？"
→ 引导孩子自己找解题路径

3️⃣ 举一反三
"如果把题目中的XX改成XX，答案会变吗？"
→ 检验是否真正理解

⚠️ 重要提醒：
- 不要直接给答案 → 依赖AI给答案是错的
- 不要替孩子做题 → 作业是孩子的
- 如果孩子累了 → 停下来明天再继续
```

## 自进化学习系统（越用越好用、越用越高效）

本技能内置通用学习模块 `scripts/learner.py`。每次使用后自动复盘、积累经验，逐步提升输出质量与执行效率，无需人工维护。

### 记忆文件
`learned_patterns.json`（位于本技能目录）记录：操作总数、各能力使用频次、错误模式、用户偏好、改进建议。

### 使用后请调用（Bash）

```bash
# 记录一次成功使用（--capability 填本次主要能力名，如「简历优化」「比价」）
python scripts/learner.py record <本技能目录> --capability 简历优化
# 记录一次失败/异常
python scripts/learner.py record <本技能目录> --capability 简历优化 --fail --error 格式识别失败 --note "用户上传了非标准文件"
# 记录用户偏好（下次直接使用）
python scripts/learner.py prefer <本技能目录> --key 输出语言 --val 中文
# 查看累计洞察（高频能力 / 反复错误）
python scripts/learner.py insight <本技能目录>
# 自动复盘（错误≥3次 或 操作≥10次 时给出改进建议）
python scripts/learner.py reflect <本技能目录>
```

### 迭代规则
- **错误累计 ≥3 次** → 主动增加预检/兜底步骤，并将经验回写本 SKILL.md。
- **操作数 ≥10 次** → 分析高频能力优先打磨示例与质量，低频能力评估精简或合并。
- **重要用户偏好** → 写入 `learned_patterns.json`，下次调用直接采用，减少重复询问。

> 越用越懂你：第一次用是通用能力，第十次用已沉淀为你专属的最佳实践。
