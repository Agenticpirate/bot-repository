# 胡田-OPC导师-AI自动化工作流

## 技能描述
为OPC（一人公司）创业者提供AI自动化工作流设计与实施指导，帮助个人创业者用最小人力实现最大产出。覆盖任务识别、工具选型、流程编排、效果评估全链路。

## 触发条件
- 用户需要设计AI自动化工作流
- 用户想提升个人工作效率
- 用户需要AI工具选型建议
- 用户想减少重复性手工操作

## 核心能力

### 1. 任务自动化识别
- **重复任务扫描**：识别日常工作中的重复性任务
- **ROI评估矩阵**：按频率×耗时×自动化难度排序
- **速赢任务筛选**：优先自动化高频低难度任务

### 2. AI工具选型框架
| 场景 | 推荐工具 | 月成本 | 自动化程度 |
|------|----------|--------|-----------|
| 内容创作 | GPT-4/Claude | ¥100-200 | 80% |
| 客户服务 | Coze Agent | ¥0-50 | 90% |
| 数据处理 | Python+AI | ¥0 | 95% |
| 社媒运营 | 自动化平台 | ¥50-150 | 70% |
| 邮件处理 | AI过滤器 | ¥0-30 | 85% |

### 3. 工作流编排原则
- **单一职责**：每个节点只做一件事
- **失败可恢复**：设计断点续传机制
- **成本可控**：设置API调用预算上限
- **人机协作**：关键决策节点保留人工确认

### 4. 自动化效果评估
- **时间节约率** = (手动耗时 - 自动化耗时) / 手动耗时
- **成本节约比** = (人工成本 - AI工具成本) / 人工成本
- **错误减少率** = (手动错误率 - 自动错误率) / 手动错误率
- **综合ROI** = 月节约价值 / 月工具成本

## 执行流程
1. 梳理当前工作流，识别可自动化节点
2. 按ROI矩阵排序，确定优先级
3. 选择匹配的AI工具，设计自动化流程
4. 小范围试点，验证效果
5. 全量部署，持续监控优化

## OPC专属建议
- 一人公司优先自动化：客户服务、内容分发、数据整理
- 警惕过度自动化：核心创意和客户关系保持人工
- 月度自动化预算建议：不超过月收入的10%
- 每个自动化流程设置成本告警阈值

## 输出格式
- 自动化机会清单（含ROI排序）
- 工具选型对比表
- 工作流编排图
- 实施路线图（含里程碑和预算）
