# 影视解说一键生成 Skill

## 功能概述

根据用户提供的「电影/剧名」「视频时长」「解说风格」三个核心参数，自动生成完整的一站式影视解说制作方案，包含四大板块输出。

## 触发条件

当用户提及以下关键词或意图时应触发本 Skill：

- "影视解说"、"电影解说"、"解说文案"、"解说脚本"
- "一键生成解说"、"自动出文案"、"分段字幕"
- "BGM 推荐"、"剪辑提示"、"镜头建议"
- 用户要求为某部电影/剧集制作解说视频
- 关键词组合：电影名 + 时长/风格 中的任意两个

## 输入参数

接收用户提供的以下参数：

| 参数 | 必填 | 说明 | 示例 |
|------|------|------|------|
| 电影/剧名 | 是 | 要解说的影视作品名称 | 《肖申克的救赎》 |
| 时长 | 是 | 解说视频目标时长 | 1分钟 / 3分钟 / 10分钟 |
| 风格 | 是 | 解说呈现风格 | 搞笑 / 深度 / 悬疑催泪 |

其他可选补充信息（由用户可选提供）：
- 核心看点：用户希望突出的重点
- 目标平台：抖音 / B站 / 小红书 / YouTube
- 特殊要求：是否要吐槽向、是否要剧透等

## 工作流

### Step 1：理解作品基本信息

先根据电影/剧名，确定以下基础信息以供后续内容生成使用：
- 作品类型（电影 / 剧集）
- 核心剧情梗概（3-5 句话概括主线）
- 主要角色及关系
- 知名程度 / 观众画像

如果 AI 对所述作品不熟悉，应坦诚告知并建议用户提供剧情概要。此时仍然根据用户提供的信息和 Skill 中的模板生成高质量内容。

### Step 2：根据风格确定解说策略

参考 `references/风格模板.md`，根据用户选择的风格加载对应的模板策略：

- **搞笑风格**：吐槽 + 夸张对比 + 网络热梗 + 碎片化笑点
- **深度风格**：主题挖掘 + 人物剖析 + 社会隐喻 + 哲思金句
- **悬疑催泪风格**：情绪递进 + 悬念保留 + 情感共鸣 + 反转节奏

### Step 3：生成完整文案

文案结构按视频时长分为三级：

**1 分钟文案结构：**
- 黄金 3 秒开场钩子 → 核心事件快剪 → 高潮片段 → 神转折/金句结尾
- 总字数约 250-350 字

**3 分钟文案结构：**
- 5-10 秒钩子 → 背景速览 → 核心冲突 → 2-3 个关键情节 → 高潮反转 → 主题升华
- 总字数约 800-1200 字

**10 分钟文案结构：**
- 15 秒引入 → 片头引入 → 完整剧情四段式（起承转合）→ 细节深度分析 → 主题总结
- 总字数约 2500-3500 字

### Step 4：生成分段字幕

将文案按镜头/段落拆分为字幕片段，每条字幕：

- **1 分钟**：6-10 条字幕
- **3 分钟**：15-25 条字幕
- **10 分钟**：40-60 条字幕

每条字幕格式：
```
[时间戳] 字幕内容 | 建议画面 | 情绪/语气
示例：
[00:00-00:05] 注意看，这个男人叫小帅 | 电影男主角特写，慢镜头 | 旁白平静，悬念铺垫
```

### Step 5：推荐热门 BGM

参考 `references/BGM推荐.md`，根据风格和场景推荐 2-5 首 BGM。

推荐格式：
```
场景：开场 / 中期叙事 / 高潮 / 结尾
曲名：XXX
风格：XXX
推荐理由：XXX
```

### Step 6：提供镜头剪辑提示

参考 `references/镜头剪辑提示.md`，按时间线提供剪辑建议。

格式示例：
```
00:00-00:05 | 特写+慢镜头 | 配合旁白"注意看" | 淡入开场
00:05-00:30 | 快节奏交叉剪辑 | 配合剧情介绍 | 抖动转场
```

## 输出格式模板

最终输出应整合为结构化内容，推荐以下交付格式：

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━
🎬 《电影名》| {时长} | 风格：{风格}
━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【完整文案】
（完整解说文案，不分段）

【分段字幕】
1. [00:00-00:05] 字幕内容 | 画面描述 | 情绪
2. ...

【BGM 推荐】
🎵 开场：BGM1
🎵 中段：BGM2
🎵 高潮：BGM3
🎵 结尾：BGM4

【剪辑提示】
| 时间区间 | 镜头类型 | 剪辑手法 | 备注 |
|----------|----------|----------|------|
```

## 质量控制要点

1. **版权规避**：文案中避免直接大段引用原片台词，使用间接转述
2. **钩子强度**：每个视频前 3 秒必须包含一个让观众暂停滑走的钩子
3. **节奏控制**：1 分钟视频每段不超过 15 秒；3 分钟每段不超过 30 秒
4. **风格一致**：全片文案语气、BGM 调性、剪辑风格需统一
5. **信息密度**：解说不是复述剧情，要提供观点、解读或情绪价值
