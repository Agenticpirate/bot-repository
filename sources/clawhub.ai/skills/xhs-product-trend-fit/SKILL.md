# xhs-product-trend-fit

## 功能描述

用户在**宣传一款商品到小红书之前**，想知道：我的商品对应什么方向，在小红书上有没有热度？有没有爆款笔记可以参考？应该怎么宣传？

skill 输入商品信息（**图片必填** + 介绍文字），自动完成：

1. 识别商品关联的品类/风格/场景方向（LLM 子会话，图片读不了自动退化用文字）
2. 用 3~6 个候选搜索词逐个搜索小红书，判断该方向近 **2 周**的热度趋势
3. 重新组织为 **1 个明确的「宣传方向」**（不是搜索词），由 2~4 篇真实爆款笔记（赞≥100）支撑
4. 对支撑该方向的爆款笔记逐个深入拉取（封面图、标题、正文、互动数、评论区信号）做分析
5. 输出 **HTML 报告**：商品方向 + 按方向的热度趋势判断 + 素材参考（爆款笔记详解 + 分维度爆款分析）

## 前置条件

- **wc3-chrome 扩展 + Relay 服务已启动**（Extension Relay HTTP API 端口 3459），Chrome 已登录小红书更稳
- **本地 pipeline 服务运行中**（子会话经 `wc3-code.mjs` 代跑，端口 3460）
- Node.js >= 22（使用原生 fetch / import.meta.dirname）

## 使用方式

```bash
node skill.mjs [input.json 路径]
# 或：node skill.mjs  （自动读 CWD 下 input.json；无 input.json 时用默认值）
```

**input.json 入参**：

| 字段 | 必填 | 说明 |
|------|------|------|
| `product_image` | 是 | 商品图片本地路径（用于方向识别；子会话读不了图会自动退化用文字，不阻塞流程） |
| `product_desc` | 是 | 商品介绍文字，建议含品类/材质/风格/适用场景/目标人群 |
| `report_path` | 否 | HTML 报告输出路径，默认 `<output_dir>/小红书商品宣传分析报告_<日期>.html` |
| `output_dir` | 否 | 产出 res.json / data.md 的目录，默认 `process.cwd()` |
| `output_files.result` | 否 | res.json 文件名，默认 `res.json` |
| `output_files.data` | 否 | data.md 文件名，默认 `data.md` |

示例：

```json
{
  "product_image": "/path/to/product.jpg",
  "product_desc": "日式原木风餐桌，白橡木实木，侘寂/北欧极简，配藤编餐椅和云朵藤编吊灯",
  "output_dir": "/tmp/my-run"
}
```

## 输出格式

- **HTML 报告**（`report_path`）：① 商品方向（品类/风格/场景 + 识别依据，含商品图片直接展示）② 热度趋势判断（按宣传方向：高/中/低/无 + 累计口径证据——近 2 周点赞累计≥1000、素材参考收藏累计≥1000 独立成行）③ 素材参考（爆款笔记最多 3 篇：2 篇近 14 天 + 1 篇近 6 个月，每篇含标题/作者/粉丝/点赞收藏评论真实数据/封面图/**爆款分析**——从粉丝基础、标题钩子、首图、内容结构、抓用户什么点拆解为什么爆）
- **res.json**（`output_dir`）：`{ status, summary, direction, heat, report_path }`
- **data.md**（`output_dir`）：报告数据明细版（含候选词逐词近 2 周热度统计，可代码验证）

stdout 只输出一行 JSON 摘要 `{ status, summary, output_dir }`，其余日志走 stderr。

## 注意事项

- 热度窗口是**近 2 周（14 天）**：note_id 前 8 位 = hex 编码 Unix 时间戳，解码发布日期判断时效
- 热度证据按**累计口径**：点赞累计≥1000、收藏累计≥1000 各自独立成行（趋势按累加算，不是单帖门槛）
- 素材参考**最多 3 篇**：2 篇近 14 天新爆款 + 1 篇近 6 个月历史爆款，超过 6 个月（180 天）忽略；头部最高赞也只统计近 6 个月内
- 素材参考必须走「搜索结果页点卡片进详情」模式，不独立打开 explore 详情页（会落推荐流拿不到目标内容）
- 搜索词之间串行、间隔 >= 4s，避免触发验证码墙
- 所有数据仅取搜索结果页与笔记详情弹层**公开可见**信息，不抓取登录后才可见的他人数据
