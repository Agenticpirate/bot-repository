# Skill: merge-inventory（入库单合并汇总）

## 触发条件
用户上传入库单 Excel 文件，要求将表1（入库单据格式）转换为标准汇总表（表2格式）。

## 核心转换规则（基于真实样例）

### 表1 → 表2 识别逻辑

**表1 特征：** 多行杂乱布局，含表头公司名（成都金山化学试剂有限公司）、仓库、单据编号、审核人等信息。

**识别方法：** 扫描所有行，找 `col[1] == '序号'` 的行作为数据块起点。

### 列索引映射（0基）

| 表头字段 | col 索引 | 表2列名 |
|---|---|---|
| 序号 | 1 | 序号 |
| 存货编码 | 5 | 存货编码 |
| 存货名称 | 12 | 存货名称 |
| 规格 | 16 | 规格 |
| 单位 | 19 | 单位 |
| 数量 | 20 | 数量 |
| 单价 | 25 | 单价 |
| 含税金额 | 29 | 含税金额 |
| 批次号 | 33 | 批次号 |
| 客户送货日期 | 36 | 客户送货日期 |
| 客户送货单号 | 39 | 客户送货单号 |
| 供应商送货日期 | 43 | 供应商送货日期 |
| 供应商送货单号 | 45 | 供应商送货单号 |

### 数据块识别

1. 表头行：`col[1] == '序号'`，记录为数据块起始
2. 数据行：序号值为数字，依次读取 col[5,12,16,19,20,25,29,33,36,39,43,45]
3. 合计行：序号值为 `'合计'`，此行 col[16]='大写'，col[29]=含税金额合计数
4. 块结束：遇到下一块表头行或行空时结束

### 多单据合并

- 同一文件内多个入库单 → 纵向合并，块间插入空行分隔
- 各块内序号独立（从1重新编号），合计行单独一行
- 所有列保持13列标准格式

### 多 Sheet 支持

- 文件含多个 sheet（如 InStore, InStore_1...）时，**自动遍历所有 sheet**，每个 sheet 视为一个独立入库单块
- 单 sheet 文件只处理该 sheet
- 可通过 `sheet='sheet名'` 参数指定只处理某个 sheet

### 可选过滤

- **过滤占位行**：若用户要求，可删除 `存货编码 == '71000064'` 且 `含税金额 == 0` 的行（食堂采购专用占位行）

### 输出格式

| 字段 | 要求 |
|---|---|
| 字体 | Arial |
| 表头 | 粗体，浅蓝背景(#D9E1F2)，水平垂直居中 |
| 合计行 | 粗体，浅黄背景(#FFF2CC) |
| 普通数据行 | 白色背景 |
| 边框 | 所有单元格细边框 |
| 列宽 | 自动（内容自适应，max=30） |
| 冻结 | 首行冻结（freeze_panes='A2'） |
| 行号 | 从1开始，连续编号 |
| 空值 | 显示为空字符串，不显示NaN |

## 执行流程

1. **读取文件**：`pd.read_excel(input_file, header=None)` 逐行扫描
2. **解析块**：循环扫描，提取每个「表头→数据→合计」块
3. **过滤**（如需要）：删除占位行
4. **合并**：`pd.concat(blocks, ignore_index=False)` + 空行插入
5. **写入**：`openpyxl.Workbook()` 创建标准化Excel，应用样式
6. **输出**：保存到用户指定路径或 `merged_output.xlsx`

- "入库单汇总"

## 输入输出

- **输入**：入库单 Excel（.xlsx），路径由用户提供
- **输出**：标准化汇总 Excel（.xlsx），文件名默认 `merged_output.xlsx`（可指定）

## 技术要求

- Python 3，依赖：pandas, openpyxl
- 处理多个单据时，各块间用空行分隔
- 不使用公式，纯数据写入
- 空单元格写入 `None`，Excel中显示为空，不显示NaN
