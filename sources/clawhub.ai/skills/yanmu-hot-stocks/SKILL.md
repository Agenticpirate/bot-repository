# 研木 · 热门股票推荐 (yanmu-hot-stocks)

> **⚠️ 数据来源与限制（重要披露）：**
> 本Skill为课程教学演示而设计：**不联网获取实时热门股票**，统一返回**内置示例标的列表**（覆盖A股/港股/美股各3只教学示例标的），并在输出中标注为示例数据。
> 所有输出仅用于课程教学演示，不构成任何投资建议。

## 功能
根据用户选择的市场类型（A股/港股/美股），返回该市场3只教学示例标的（公司名+股票代码），供用户练习选择研究标的。

## 工作流程

### 1. 用户选择市场
让用户从以下三个市场中选择：
- **A股** — 上海/深圳交易所
- **港股** — 香港交易所
- **美股** — 纽约交易所/纳斯达克

### 2. 调用脚本获取示例标的
使用 `exec` 工具运行 Python 脚本，脚本从内置示例标的库中返回对应市场的标的列表。

```bash
python3 {baseDir}/scripts/fetch_hot_stocks.py --market <a-share|hk|us>
```

### 3. 展示结果给用户
脚本返回格式化的示例标的列表，包括：
- 公司中文名称
- 股票代码（含交易所后缀）
- 简要描述（行业/教学示例说明）

### 4. 用户确认
让用户从列表中选择，或输入自定义股票代码。

## 数据来源说明（重要）
- 本Skill**不联网、不调用任何财经数据接口**（如新浪财经、东方财富、Yahoo Finance 等均不访问）。
- 返回的标的来自**内置静态示例库**，仅用于课程教学演示，不代表当前市场热门股票。
- 脚本中保留的联网获取函数（`try_fetch_from_sina` / `try_fetch_from_yahoo`）当前**恒返回 None，不会执行**，仅作为课程讲解代码结构的示例。
- 请勿将输出当作实时行情或投资参考。

## 输出格式
```
📊 【热门股票推荐 · {{市场名}}】

1. 🥇 公司名 (代码) — 简要说明
2. 🥈 公司名 (代码) — 简要说明
3. 🥉 公司名 (代码) — 简要说明

📌 输入序号或股票代码选择研究标的（或输入 `自定义` 手动输入代码）：
```

## 调用说明
本Skill由研木智能体自动调用，用户无需手动触发。
