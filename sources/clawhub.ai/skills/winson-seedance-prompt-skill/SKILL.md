## 一、核心哲学

### 1.1 双铁律

> **铁律一：技能不是知识库的翻译，是创意到提示词的转化引擎。**
> **铁律二：公式服务于表达，不是表达服务于公式。**

一个把即梦官方手册抄一遍的文档是说明书；一个能帮创作者把脑中一句话想法，转化为即梦2.5可直接"发车"的完整提示词的文档，才是技能。

区别在于：前者教你"怎么写"，后者帮你"写出来"。

### 1.2 三个底层认知

| 认知 | 说明 |
|------|------|
| **创意先行** | 创作者的核心资产是想法，不是提示词技术。技能的价值是让想法快速落地，而不是让创作者变成提示词工程师。 |
| **场景路由** | 不同创作意图需要不同的提示词结构。叙事用时间轴、人物用七维公式、编辑用修改公式——选对场景，公式才有用。 |
| **防崩坏是底线** | 即梦2.5能力强大但有边界。好的提示词不仅告诉AI"做什么"，还要明确"不做什么"，防止角色变形、穿模、风格漂移。 |

### 1.3 视觉语言 DNA（铁幕·Iron）

本 SKILL 生成的提示词遵循以下结构基因：

| 维度 | 规范 | 作用 |
|------|------|------|
| 结构化分段 | 用【】划分模块，用时间轴切分镜 | 可读性 |
| 素材显式引用 | @图片1、@视频1 明确标注 | 精准性 |
| 正反双向描述 | 写要什么 + 写不要什么 | 防崩坏 |
| 全局收束 | 结尾再次强调全局要素 | 一致性 |

## 二、即梦 2.5 能力边界（你需要知道能做什么）

### 2.1 参数规格速查

| 维度 | 规格 |
|------|------|
| 生成时长 | [4, 30]s（97-721帧），超长视频模式支持 30-180s |
| 参考视频 | 最多10个，所有视频总时长≤30s |
| 参考音频 | 最多10段，所有音频总时长≤30s |
| 参考图片 | 最多30张4K分辨率以内 |
| 输出分辨率 | 480p、720p |
| 仅传音频 | 支持（2.0不支持，2.5新增） |

### 2.2 四大模式选择

| 模式 | 什么时候用 | 核心能力 |
|------|------|------|
| **全能参考** | 多素材混合创作（图+视频+音频） | 综合参考，最灵活 |
| **智能编辑**（新） | 对已有视频做局部修改 | 文字描述编辑，无需标注 |
| **超长视频**（新） | 一次性生成30-180秒长片 | 无需分段延长，直接出长片 |
| **首尾帧** | 控制视频开头和结尾画面 | 精准控制起止帧 |

### 2.3 素材输入建议

| 场景 | 建议 |
|------|------|
| 主体音视频 | 1-5主体效果较好；5-10s时长；超过5主体建议单视图 |
| 主体图 | 1-8主体效果较好；9-12主体可尝试但需抽卡 |
| 视频编辑 | 20s以内效果较好 |
| 参考图编辑 | 1-5张效果较好 |

## 三、创意→提示词转化流程（核心引擎）

> 这是本 SKILL 的核心。不是教你背公式，而是帮你把脑中的想法变成可发车的提示词。

### Phase 1：意图解码

**目标**：理解创作者想表达什么，而非简单地问"你要什么"。

创作者的表达通常有以下形态，你需要识别并补全：

| 创作者说的 | 真实意图 | 你需要补全的 |
|------|------|------|
| "一只猫在雨中走路" | 一个有氛围感的场景 | 情绪基调、镜头语言、环境细节、声音设计 |
| "我想讲一个母亲收养流浪猫的故事" | 一个叙事短片 | 分镜结构、时间轴、角色设计、情感弧线 |
| "把这个视频里的鲸鱼换成龙" | 一个编辑操作 | 修改对象、变化描述、生效时序 |
| "20秒的赛博朋克摩托车追逐" | 一个风格化短片 | 视觉风格、镜头语言、动作设计、禁止项 |
| "把我的白模渲染成香水广告" | 一个白模渲染 | 渲染材质、光照设计、场景参考、时间轴 |

**检验标准**：你能用一句话概括"创作者想表达的核心情感/故事/画面"。

### Phase 2：模式路由

根据意图解码结果，选择对应的提示词场景：

| 创作意图 | 路由到 | 生成时长 |
|------|------|------|
| 单场景/单镜头表达 | 4.1 基础提示词 | 4-30s |
| 以人物为核心的表达 | 4.2 真人人物 | 4-30s |
| 多镜头叙事/电影感短片 | 4.3 30秒长视频 | 30s |
| 超长叙事/Vlog/完整故事 | 4.4 超长视频 | 30-180s |
| 在已有视频上续写/延长 | 4.5 视频延长 | 延长4-30s |
| 修改已有视频的局部元素 | 4.6 智能编辑/高级编辑 | 编辑 |
| 把白模动画渲染成成片 | 4.7 白模渲染 | 4-30s |

**检验标准**：已确定使用哪个公式，并明确了生成时长和画幅比例。

### Phase 3：创意展开

**目标**：把创作者的一句话想法，展开为完整的提示词结构骨架。

这是最关键的一步。你不是在"套公式"，而是在"帮创作者把想法说清楚"。

**展开方法**：

1. **定基调**：这个创意的核心情绪是什么？（温暖治愈/冷峻压迫/梦幻浪漫/紧张刺激...）
2. **定主体**：画面核心是谁/什么？需要什么参考素材？
3. **定场景**：发生在哪里？环境细节是什么？
4. **定时间线**：如果是叙事，故事怎么推进？分几个时间段？
5. **定镜头**：用什么机位/运镜最能传达这个情绪？
6. **定声音**：需要什么音效/环境音/BGM？还是不要BGM？
7. **定禁止项**：什么元素绝对不能出现？（防止AI自由发挥跑偏）

**检验标准**：你已经有了完整的七维度骨架，每个维度至少有一句具体描述。

### Phase 4：公式填充

根据 Phase 2 路由到的场景，调用第四章的对应公式，将 Phase 3 的骨架填入公式结构。

**填充原则**：
- 素材引用要显式：@图片1、@视频1 按上传顺序标注
- 时间轴要连续：不允许出现时间断裂
- 正反双向：每个分镜既写"要什么"也写"不要什么"
- 全局收束：结尾必须再次强调全局要素

**检验标准**：提示词已按公式结构完整组装，每个模块都有具体内容。

### Phase 5：防崩坏校验

即梦2.5能力强大，但以下问题最常出现。在输出前逐项检查：

| 检查项 | 常见问题 | 防范写法 |
|------|------|------|
| 角色一致性 | 人物外观在中途变化 | 结尾强调"角色外观、服饰及比例全程保持一致" |
| 穿模变形 | 物体扭曲、肢体穿模 | 加"禁止角色变形、比例错误""禁止物体凭空出现" |
| 风格漂移 | 风格在中途变化 | 全局补充中强调"整体风格保持一致" |
| 无关元素 | 出现字幕、BGM | 加"不要字幕""不要bgm"或结尾"全程无字幕，无背景音乐" |
| 时间断裂 | 分镜之间不衔接 | 加"禁止生硬切镜""保持时间、空间、人物位置及光照连续" |
| 克隆人 | 背景人物长得一样 | 加"禁止背景出现长相相同的克隆人" |
| **版权IP** | 提示词涉及已知动漫/影视/游戏角色，平台拒绝生成 | 提取IP的精神内核（如"力大无穷的少年""可变形机甲"），替换为原创设定，加"禁止出现任何已知IP角色外观或标志性元素" |

**检验标准**：提示词中已包含至少一条反向描述（禁止项），角色一致性有全局强调，无版权IP风险。

### Phase 6：输出可发车提示词

**输出格式**：
- 直接输出完整的提示词文本，创作者可复制粘贴到即梦2.5中使用
- 如有需要，附上1-2句"使用建议"（建议时长、画幅、模式选择）
- 不要输出公式解释，只输出最终提示词

**检验标准**：创作者拿到提示词后，无需二次修改即可直接粘贴到即梦发车。

## 四、七大场景公式库（工具箱）

> 以下公式由 Phase 4 调用。每个公式包含：公式定义 → 各模块详解 → 模板 → 关键要点。

### 4.1 基础提示词公式

**适用**：单场景/单镜头的创意表达，4-30秒。

```
完整提示词 = 【素材描述】+【一句话概述】+【具体情节描述】+【全局补充（结尾）】
```

| 模块 | 写什么 | 举例 |
|------|------|------|
| 素材描述 | 素材编号（按上传顺序）+ 具体用途。没有参考素材可忽略 | @图片1为场景参考，@图片2为人物参考 |
| 一句话概述 | 主体 + 地点 + 事件 + 题材/风格 + 特殊运镜 | 写实自然纪录片风格，清晨薄雾中，湿地芦苇荡里一只丹顶鹤展翅起舞 |
| 具体情节描述 | 分时间轴写。每个时间段：正向描述（画面+运镜+动作+音效）+ 反向描述（不要什么） | 0s-3s：丹顶鹤静立浅水中，缓慢展开双翼...3s-8s：轻盈跳跃，双脚点水溅起水花... |
| 全局补充 | 再次强调贯穿始终的要素：机位+环境+声音/氛围+光影。以及全局不要的元素 | 低机位，轻微手持感，景深自然。自然环境音，水流声、鹤鸣声。整体宁静空灵唯美 |

**关键要点**：
- 素材@清楚是第一位——告诉AI每个素材分别是什么用途
- 一句话概述定调，后续所有描述都服务于这个基调
- 时间轴必须连续，不允许跳跃

### 4.2 真人人物公式

**适用**：以人物为核心的表达，避免AI感和"双胞胎脸"。

```
人物 = [年龄/种族] + [肤色/皮肤质感] + [面部细节特征] + [眼神/灵魂] + [发型/发色] + [服装/服装质感] + [体型/情绪/气质] + [其他要求]
```

| 维度 | 细分公式 | 举例 |
|------|------|------|
| 年龄/种族 | [具体岁数] + [国籍/人种] + [风格形容词] + [脸型名词] | 22岁东亚女性，清冷古典的骨相脸 |
| 肤色/皮肤质感 | [冷暖色调] + [具体肤色名词] + [皮肤质感形容词] + 保留真实的微细毛孔与肌肤纹理 | 冷调白皙肤色，透出细腻的温润质感，保留真实的微细毛孔与肌肤纹理 |
| 面部细节特征 | [眼型] + [眉骨] + [鼻梁] + [唇形] + [下颌线]（至少3-4点） | 细长的桃花眼，鼻梁小巧挺直，唇部丰润且嘴角带浅笑，下颌线柔和 |
| 眼神/灵魂 | [眼神形容词] + [目光传达的信息/比喻] + [透出的底层情绪] | 眼神深情含情脉脉，眼底仿佛有一汪春水，透着深深的眷恋与不舍 |
| 发型/发色 | [具体发色] + [头发状态/质感] + [具体发型名词] + [环境互动补充] | 乌黑发丝绾成古典低盘发，几缕碎发垂落脸颊，随微风轻拂 |
| 服装/服装质感 | [版型/剪裁] + [颜色] + [具体服装名词] + [布料材质/新旧状态] + [穿着方式/细节] | 极简素白色交领古装，带有柔软光泽的素雅真丝，衣襟微微散开 |
| 体型/情绪/气质 | [骨架/肩部] + [构图/镜头要求] + [人物动作/视线] + [整体氛围词] | 身姿纤细，双肩削瘦，特写构图眼神直视镜头，散发出温柔婉约的古典浪漫气质 |

**关键要点**：
- "保留真实的微细毛孔与肌肤纹理"是去AI感的核心后缀，不可省略
- 眼神决定情感——不要只写"好看的眼睛"，要写"目光传达的信息"
- 服装质感从侧面烘托人物特性（真丝=优雅，做旧皮夹克=硬核）
- 如整体提示词已包含构图/镜头/动作描写，体型维度可去除构图和动作部分

### 4.3 30秒长视频公式

**适用**：多镜头叙事、电影感短片，30秒。

```
完整提示词 = 【全局设定】+【时间戳剧本分镜】
```

**全局设定包含**：

| 模块 | 写什么 |
|------|------|
| 基础环境与质感 | 场景环境 + 物理真实感要求（如"冰雪融水的折射必须符合真实光学规律"） |
| 视觉风格 | 风格定义 + 色调 + 画质要求 |
| 镜头语言 | 全局镜头策略（如"一镜到底无人机推进""蒙太奇剪辑+物理无缝转场"） |
| 主体造型 | 角色外观（可调用4.2真人人物公式） |
| 表演核心 | 重点展现什么（如"一击必杀的速度感""极度克制下的情感暗涌"） |
| 禁止项 | 明确禁止的元素（如"禁止3D油腻感""禁止武打拖泥带水""禁止字幕"） |

**时间戳剧本分镜格式**：

```
[时间段] 镜头标题（转场方式）
动作/物理指令：具体的画面内容、运镜、动作
镜头潜台词：这个镜头要传达的视觉张力/情感/意境
```

**关键要点**：
- 全局设定的"禁止项"是防崩坏的第一道防线，必须写
- 每个分镜的"镜头潜台词"是给AI的意图说明，帮助AI理解"为什么这样拍"
- 转场方式要在分镜标题中明确标注（如"相似物转场""遮罩转场""水墨转场"）
- 时间戳必须连续，不允许出现时间空隙

### 4.4 超长视频公式

**适用**：30-180秒的完整故事/Vlog/叙事短片。

```
完整提示词 = 【全局参数】+【素材描述】+【一句话概述】+【具体情节描述】+【全局补充（结尾）】
```

| 模块 | 与基础公式的区别 |
|------|------|
| 全局参数 | 新增模块。因超长视频时间长，开头需再次强调：生成几分钟、画幅比例多少 |
| 素材描述 | 同基础公式，但更关键——超长视频素材多，必须把每个@图片/@视频的用途标清楚 |
| 一句话概述 | 同基础公式 |
| 具体情节描述 | 同基础公式，分时间轴/故事线写。超长视频可以按"段落"而非"秒"来分 |
| 全局补充 | 同基础公式 |

**模板示例**：
```
全程3分钟，@图片1猫咪打工vlog，视频比例16:9，以橘猫为主角当服务员的一天，
它从起床刷牙洗脸，骑电动车到街边小店，清晨上班擦桌签到，迎客引座递菜单，
场景参考@图6-10，餐厅整体参考@图11，他小心送餐到客户@图片2345的桌子上，
午休偷啃小鱼干打盹，傍晚收小鱼干小费、收拾桌面，最后打烊蜷在窗边休息，
骑电动车，回到房间参考@图12，洗漱，吃饭，睡觉。
全程无字幕，无背景音乐
```

**关键要点**：
- 超长视频的核心是"把素材@清楚 + 故事描述清楚"，不需要像30秒长视频那样写逐秒分镜
- 可以用自然语言按故事线描述，不强制要求时间戳格式
- 全局参数放在最开头，让AI先建立整体框架
- 全局禁止项（无字幕、无BGM）放结尾再次强调

### 4.5 视频延长公式

**适用**：在已有视频（≤30秒）上续写/延长，单次延长4-30秒。

**延长提示词模板**：
```
参考@视频1的内容，延长视频Xs向后延长。
要求延长自然、动作衔接流畅，禁止生硬切镜、禁止物体凭空出现。
[描述延长部分的画面内容]
```

**进阶：带转场的延长**：
```
参考@视频1的内容，延长视频Xs延长续写。
要求需要在切镜处使用"[转场名称]"转场（禁止生硬切镜、禁止物体凭空出现）。
镜头A展示[当前画面]，[转场描述]；
随后镜头拉开显现出下一个场景：[新画面]。
要求必须自然切换场景。
```

**"套娃式"延长规则**：
- 原视频需≤30秒才能使用延长功能
- 单次延长4-30秒
- 延长后的视频如仍≤30秒，可再次延长
- 极限：30秒原视频 + 30秒延长 = 60秒

### 4.5.1 九种转场技法库

> 当延长或长视频需要场景切换时，从这里选择合适的转场技法。

| 转场 | 是什么 | 适用场景 | 提示词写法 |
|------|------|------|------|
| **叠化** | 画面A缓慢变透明，画面B逐渐显现，有2秒重叠交融 | 柔和过渡、时间流逝、回忆闪回 | 需要在切镜处使用"叠化"转场（禁止生硬切镜、禁止物体凭空出现）。镜头A[描述A]画面缓慢变透明；同时镜头B[描述B]逐渐显现，两个画面产生2秒的重叠交融。要求必须自然切换场景 |
| **白闪/黑闪** | 画面瞬间闪白或闪黑一下，然后切到下一个画面 | 配合重音（鼓点、枪声、快门声），卡点视频、混剪、紧张刺激氛围 | 需要在切镜处使用"白闪/黑闪"转场（禁止生硬切镜、禁止物体凭空出现）。画面瞬间爆发强烈的白光（或瞬间陷入全黑）一闪而过，紧接着极速切入下一个画面，带有强烈的视觉冲击感。要求必须自然切换场景 |
| **擦除** | 画面B像推拉门一样，把画面A从某方向"推走"或"擦掉" | 复古风格（如《星球大战》），或明显的地点转移 | 需要在切镜处使用"擦除"转场（禁止生硬切镜、禁止物体凭空出现）。画面B像推拉门一样，从左侧（或右侧/上下）平滑推进，将画面A完全覆盖/擦掉。要求必须自然切换场景 |
| **遮罩转场** | 镜头向前推进，被一个物体完全遮挡导致画面变黑，下一个镜头从变黑状态拉开已是新场景 | 空间跨越。如穿过镜子来到奇幻世界、纸飞过盖住镜头后是另一个场景 | 需要在切镜处使用"遮罩转场"转场（禁止生硬切镜、禁止物体凭空出现）。镜头向前推进，被画面中的[某物体，如：一棵大树/人物背影]完全遮挡导致全屏变黑，随后镜头穿过黑暗，直接拉开显现出下一个全新的场景。要求必须自然切换场景 |
| **相似物转场** | 前一个镜头的最后一帧和后一个镜头的第一帧形状/轮廓/颜色极其相似 | 蒙太奇手法。如天上的圆月→杯子里的圆形咖啡拉花 | 需要在切镜处使用"相似物转场"转场（禁止生硬切镜、禁止物体凭空出现）。利用形状或色彩的相似性进行无缝过渡。例如：上一个镜头的最后一帧是[圆形物A]，镜头推进，[物A]无缝化为下一个镜头中同样圆形的[物B]。要求必须自然切换场景 |
| **动作转场** | 镜头在A场景猛地向左（或上下）甩动，画面模糊；B场景顺着同样力道甩入定格 | 动感极强，适合动作片、跑酷、旅行Vlog，"瞬间转移"的速度感 | 需要在切镜处使用"动作转场"转场（禁止生硬切镜、禁止物体凭空出现）。利用镜头的极速运动进行衔接。镜头在A场景猛烈向左（或右）甩动，画面产生强烈的运动模糊；随后B场景顺着相同的甩动方向和力度，从模糊中切入并定格。要求必须自然切换场景 |
| **动态接力转场** | 借助人物动作衔接。A镜头人物向上跳起（跳出画框），B镜头人物正好从画框上方落入 | 换装视频（"踢鞋换装""响指换装"）、主角跨地区旅行拼接 | 需要在切镜处使用"动态接力转场"转场（禁止生硬切镜、禁止物体凭空出现）。借助人物的连贯动作进行场景切换。例如：人物在A场景向上跳起脱离画框，紧接着在B场景中，该人物保持下落的姿势从画框上方落入画面。要求必须自然切换场景 |
| **拉近/拉远转场** | 镜头无限放大A场景的某个细节（瞳孔、锁孔），放大到极致时细节变成B场景全貌；或反过来拉远 | 极其宏大的叙事或微观视角切换，科幻片，"世界中有世界"的套娃概念 | 需要在切镜处使用"拉近/拉远转场"转场（禁止生硬切镜、禁止物体凭空出现）。镜头极致放大A场景中的某个细节（如：人物瞳孔），当瞳孔占据整个屏幕时，画面在瞳孔内部无缝展开，变成B场景的宏大全貌。要求必须自然切换场景 |
| **水墨转场** | 画面像一滴浓墨滴入水中一样晕染、扩散开来，前一画面随墨迹蔓延逐渐消失，同时在墨迹中浮现下一画面 | 极具东方美学和诗意，古风汉服展示、人文风光（江南水乡）、历史纪录片、回忆 | 需要在切镜处使用"水墨转场"转场（禁止生硬切镜、禁止物体凭空出现）。画面A像被滴入清水中的浓墨一样迅速晕染、扩散，随着墨迹的蔓延，画面A逐渐消失，画面B从散开的墨迹中逐渐浮现出来。要求必须自然切换场景 |

### 4.6 智能编辑与高级编辑公式

**适用**：对已有视频做局部修改、元素替换、元素增删。

**智能编辑公式**（文字描述编辑）：
```
[具体修改对象/什么东西] + [动作与变化描述] + [生效时序]
```

**高级编辑/视频编辑公式**（带标注工具）：
```
[标注工具与方位] + [具体修改对象/什么东西] + [动作与变化描述] + [生效时序]
```

| 模块 | 写什么 | 举例 |
|------|------|------|
| 标注工具与方位 | 用什么工具画的 + AI应关注里面还是外面 | 将红框内、沿着红色箭头指向的区域、地标点处、红线左侧 |
| 具体修改对象 | 在该区域内具体想改什么 | 男生的牛仔裤、画面背景的枯树、女主角手里的咖啡杯 |
| 动作与变化描述 | 要变成什么样，或添加/消除什么 | 替换为深黑色西装裤、变成樱花树、从画面中无痕消除并补全背景、增加一道闪电 |
| 生效时序 | 一直存在还是特定秒数才变化 | 全片（15秒）统一修改保持一致、仅在第5-8秒期间发生变化、从第3秒起逐渐显现 |

**必填词汇**：编辑视频里的xx、增加/加上、删除/去掉、修改/替换/改成

**模板示例**：
```
在整体视频的0-8秒，全部修改。把视频中的鲸鱼修改为一条白色的龙。去掉bgm。
```
```
把整个视频0-5秒，全部视频。白色的背景，都变成绿幕背景。去掉声音，保持静音。
```

### 4.7 白模渲染公式

**适用**：将白模动画视频渲染成最终成片。

**两种粒度**：

**粗颗粒度**（整体描述）：
```
将[视频1]的白模动画渲染成最终成片。
[整体场景描述 + 角色描述 + 动作描述 + 时间轴故事线]
[渲染风格 + 材质要求 + 光照要求]
[禁止项]
```

**细颗粒度**（逐秒/逐段描述）：
```
将[视频1]的白模动画渲染成最终成片。
0-Xs：[段落标题]
[场景渲染描述：色调、材质、光照、景深]
背景场景使用[图X]的[环境]。
[角色/物体渲染描述：材质、反射、细节]
X-Ys：[段落标题]
[同上结构]
...
整体采用[风格]，保持[材质表现]全程一致。
整体采用[光照技术]，[画质要求]。
```

**关键要点**：
- 必须明确"将白模动画渲染成最终成片"这个指令开头
- 材质描述要具体：玻璃用"透明高折射玻璃材质"，金属用"拉丝银材质"，液体用"真实流体折射效果"
- 全程一致性是白模渲染的核心——材质、光照、色彩表现必须全程一致
- 可以参考@图片做场景/配色参考

## 五、常见陷阱与避坑指南

| 陷阱 | 表现 | 后果 | 修正 |
|------|------|------|------|
| **素材不标注** | 上传了5张图但提示词里没@引用 | AI不知道哪张图是什么用途，输出混乱 | 每个素材必须@引用并说明用途 |
| **人物写太简单** | 只写"一个漂亮女生" | AI感重，人物像双胞胎，缺乏辨识度 | 用4.2真人人物七维公式，尤其"保留微细毛孔与肌肤纹理" |
| **只写正向不写反向** | 只写要什么，不写不要什么 | 出现字幕、BGM、克隆人、风格漂移 | 每个场景必须有禁止项，结尾全局再强调一次 |
| **时间轴断裂** | 分镜之间有时间空隙或跳跃 | 画面不连贯，动作衔接生硬 | 时间戳必须连续，加"禁止生硬切镜" |
| **转场不指定** | 想要场景切换但不告诉AI用什么转场 | 硬切，破坏画面连贯性 | 明确指定转场类型，用4.5.1九种转场技法库 |
| **全局设定缺禁止项** | 30秒长视频的全局设定没写禁止项 | 风格漂移、肢体穿模、3D油腻感 | 全局设定必须有"禁止项"模块 |
| **编辑不写时序** | 只说"把裤子换成黑色"不写哪段时间 | 全片修改或修改错时段 | 必须写生效时序：全片统一 / 特定秒数 |
| **白模不写材质** | 只说"渲染成香水广告"不写材质细节 | 渲染效果不理想，与原视频偏差大 | 逐段写明材质：玻璃折射、金属反射、流体光学 |
| **超长视频写太细** | 180秒视频写逐秒分镜 | 提示词过长，AI抓不住重点 | 超长视频按故事线/段落写，不强制逐秒 |
| **延长不带转场** | 延长视频时不指定转场方式 | 新旧段落硬切，不自然 | 延长时指定转场类型，或至少写"延长自然、动作衔接流畅" |
| **版权IP直接写** | 提示词直接写"葫芦娃""变形金刚"等已知IP | 平台拒绝生成，提示词无法发车 | 提取IP精神内核替换为原创设定，加"禁止出现任何已知IP角色外观或标志性元素" |

## 八、执行原则

1. **创意先行，公式服务于表达**：先理解创作者想表达什么，再选公式。不要让创作者适应公式，让公式适应创意。
2. **一句话也能发车**：创作者只给一句话，你要帮他展开为完整提示词。不要反问"你想要什么风格"，而是根据创意意图主动补全。
3. **素材@清楚是第一铁律**：无论什么场景，素材引用必须显式标注（@图片1、@视频1），并说明每个素材的用途。
4. **正反双向是底线**：好的提示词不仅告诉AI"做什么"，还要明确"不做什么"。每个提示词必须有禁止项。
5. **全局收束是保险栓**：结尾必须再次强调全局要素（风格一致、角色一致、不要字幕/BGM等），防止AI中途漂移。
6. **转场要指定**：场景切换时，必须从九种转场技法库中选择并明确指定，不要让AI自由发挥。
7. **输出即发车**：最终输出的提示词必须可直接使用，不附公式解释，不附冗余说明。
8. **去AI感是人物核心**：生成真人人物时，"保留真实的微细毛孔与肌肤纹理"是去AI感的核心后缀，不可省略。
9. **版权IP要转化**（实战新增）：创作者提到已知IP角色时，不要直接写进提示词。提取IP的精神内核（能力特征、美学风格），替换为原创设定，并加"禁止出现任何已知IP角色外观或标志性元素"。
