## 排错指南
### 问题1: 选题捕手返回的选题时效性差
**现象**: 选题与当前热点不符，评分偏低
**原因**: 热搜API不可用，已降级为LLM知识库生成
**解决**:
1. 检查 `HOT_SEARCH_API_KEY` 环境变量是否配置
2. 确认热搜API服务是否在线（可手动调用测试）
3. 配置国内热搜API（微博热搜/百度热搜/新榜API）替代
4. 降级模式下选题基于近期趋势推测，建议结合实际热搜验证
### 问题2: 标题钩子工厂生成的标题字数超标
**现象**: 小红书标题超过20字限制
**原因**: LLM生成时未严格遵守平台字数限制
**解决**:
1. 检查word_limit字段是否正确返回平台限制值
2. 标题已自动截断至平台最大字数，但可能丢失部分信息
3. 建议在topic描述中加入字数提示，如"20字以内"
4. 手动微调截断后的标题，保留核心关键词
### 问题3: 爆款预言机评分与实际表现差异大
**现象**: 预测高分内容表现一般，低分内容反而爆款
**原因**: 预测基于历史爆款规律和LLM分析，无法保证100%准确
**解决**:
1. 预测结果仅供参考，不作为发布决策的唯一依据
2. 评分>80的内容爆款概率较高，评分<60建议优化
3. 结合账号权重、发布时机、平台算法等多因素综合判断
4. 不同LLM模型评分可能差异较大，建议使用同一模型保持一致性
### 问题4: 短剧生产管道在第10步角色画面生成失败
**现象**: 管道执行到"角色画面生成"步骤时报错
**原因**: 图像生成API（InstantID/FLUX/Kling）不可用或配额耗尽
**解决**:
1. 检查 IMAGE_API_KEY 环境变量是否配置
2. 确认图像生成API配额是否充足
3. 尝试切换style_track：real_person→anime（使用FLUX引擎，成本更低）
4. 尝试切换scene_id：scene_7(Kling)→scene_6(FLUX标准画质)
5. 查看drama_assets/{project_id}/episodes/{chapter}.json确认失败步骤的错误信息
### 问题5: 四层TTS全部降级到L4 Edge-TTS
**现象**: tts_engine_used为edge_tts，tts_fallback_chain显示L1-L3全部失败
**原因**: CosyVoice2 API Key未配置或网络不通；本地GPU环境不可用
**解决**:
1. L4 Edge-TTS为免费方案，可正常使用但配音质量略低
2. 如需高质量配音，配置 TTS_API_KEY 启用L1 CosyVoice2
3. 如有GPU环境，部署L2 Fish-Speech或L3 GPT-SoVITS本地引擎
4. 检查网络连接，确认CosyVoice2云端API可达
## 能力限制说明
### 内容创作类限制
- **平台覆盖**: 选题捕手和标题工厂仅支持国内4平台（小红书/抖音/微博/知乎），不支持B站/快手/头条号/海外平台
- **语言限制**: 仅支持中文内容创作，不支持英文/其他语种标题生成和内容预测
- **内容长度**: 爆款预言机要求内容50-10000字，过短无法有效预测，过长自动截断
- **竞争度精度**: 竞争度基于平台搜索结果数估算，可能不完全反映实际竞争程度
- **评分主观性**: 选题5维评分和标题4维打分基于LLM判断，不同模型评分可能差异较大
### 短剧制作类限制
- **单次管道超时**: 25步管道执行超时上限60分钟，复杂章节可能超时
- **同一book_id不可并行生成**: 生成锁机制限制同一book_id同时只能有一个生成任务
- **真人剧成本较高**: real_person风格使用InstantID，成本约45元/分钟；动漫FLUX仅约14元/分钟
- **竖屏固定输出**: 本Plug输出为竖屏短剧(9:16)，不支持横屏电影级长片制作
- **本地GPU TTS需GPU环境**: L2 Fish-Speech和L3 GPT-SoVITS需本地GPU，无GPU只能用L1(需Key)或L4(免费)
### 不适用场景
- 海外平台内容创作（Twitter/Reddit/YouTube/Instagram/TikTok国际版）
- B2B行业选题（侧重消费品/生活方式类）
- 学术论文标题和新闻采编选题（需专业判断非爆款导向）
- 实时直播短剧演出（本Plug为离线AI生成）
- 横屏院线级长片制作
- 纯文字小说续写创作（本Plug短剧功能为视频生成非文字创作）
- 实时性要求<100ms的场景
- 需要完全离线运行的场景
## 热门问题
### Q1: Plug中的技能可以单独使用吗？
A: 可以，Plug中的每个技能都是独立的，可以单独调用。组合使用时效果更佳，选题→标题→预测形成数据驱动的创作决策链。
### Q2: 选题捕手的热搜API不可用会影响什么？
A: 热搜API不可用时降级为LLM基于知识库生成选题，选题的时效性会降低（可能不是最新热点），但选题分析和评分功能不受影响。建议配置国内热搜API提升时效性。
### Q3: 短剧爆款生产线的成本如何控制？
A: 动漫风格FLUX标准画质(scene_6)成本最低约14元/分钟，真人剧(scene_8)约45元/分钟。TTS使用L4 Edge-TTS免费方案可省去TTS API费用。建议预算有限时选择anime+FLUX+Edge-TTS组合。
### Q4: 爆款预言机的预测准确率如何？
A: 预测基于历史爆款规律和LLM分析，评分>80的内容爆款概率较高。准确率受平台算法变化、发布时机、账号权重等多因素影响，预测结果仅供参考，不保证100%准确。
### Q5: 支持自定义工作流程吗？
A: 支持。可在Agent对话中指定执行特定技能或自定义技能执行顺序。例如只执行选题→标题两步，跳过预测和短剧制作。

# AI内容创作工作站
> 选题到爆款全链路，4个AI技能组成的内容创作流水线：选题捕手聚合热点、标题钩子工厂生成标题、爆款预言机预测潜力、短剧爆款生产线自动出片
## 能力矩阵
本Plug将内容创作拆解为4个可独立调用又可串联执行的阶段，每个阶段由一个专业技能负责，形成从灵感发现到成片发布的完整工作流。
### 包含技能
| 技能 | slug | 领域 | 核心能力 | 质量分 |
|:-----|:-----|:-----|:-----|:-----|
| 选题捕手 | `topic-hunter` | Automation | 4大平台热点聚合 + 5维趋势评分 + 差异化选题建议 | 4.7/5.0 |
| 标题钩子工厂 | `title-hook-factory` | Automation | 6大钩子公式 + 3-5个标题候选 + 4维量化打分 + 多平台字数控制 | 4.9/5.0 |
| 爆款预言机 | `viral-prophet` | Automation | 6维潜力评分 + 5大爆款要素分析 + 竞品对比 + 优化建议 | 4.9/5.0 |
| 短剧爆款生产线 | `drama-hit-producer` | Automation | 25步全自动管道 + 双轨风格 + 四层TTS + 质量闭环 | 4.8/5.0 |
### 技能间协同关系
```
topic-hunter (选题) ──输出选题──> title-hook-factory (标题)
                                        │
                                        ├──输出标题+内容──> viral-prophet (预测)
                                        │                        │
                                        │                   预测通过
                                        │                        │
                    drama-hit-producer (短剧制作) <──小说章节────┘
```
- **topic-hunter** 为创作起点，输出高潜选题和差异化切入角度
- **title-hook-factory** 接收选题，生成多平台适配的爆款标题和钩子段落
- **viral-prophet** 对标题+内容进行发布前预测，评分通过后进入发布或制作环节
- **drama-hit-producer** 接收小说章节，25步管道自动生成竖屏短剧并多平台发布

## 应用场景
### 场景1 自媒体日更选题与标题生成
自媒体创作者每日需要产出3-5条内容，面临"不知道写什么"和"标题不够吸引人"两大痛点。
- **Step 1**: 调用 topic-hunter，传入 platforms=["xiaohongshu","douyin"] + category="科技"，获取10个高潜选题 + 5维评分 + 蓝海机会点
- **Step 2**: 选择评分最高的选题，调用 title-hook-factory，传入 topic + platform="xiaohongshu"，获取5个标题候选 + 4维打分 + 钩子段落
- **Step 3**: 撰写正文后调用 viral-prophet，传入 content + platform，获取6维潜力评分和优化建议，评分>80直接发布
### 场景2 MCN机构批量短剧生产
MCN机构需要将签约小说IP快速转化为竖屏短剧，在抖音/快手/B站多平台分发。
- **Step 1**: 调用 drama-hit-producer，传入 book_id + chapter_number + style_track="anime" + platforms=["douyin","kuaishou","bilibili"]
- **Step 2**: 25步管道自动执行：章节获取→事件图谱→角色工坊→TTS匹配→剧本转换→导演规划→分镜生成→配音→画面生成→视频合成→字幕→质量监督→多平台发布
- **Step 3**: 质量评分为C/D级时自动重做（最大2次），重做后仍不达标触发人工裁决
### 场景3 内容运营团队选题决策
内容运营团队需要数据支撑选题决策，避免拍脑袋。
- **Step 1**: 调用 topic-hunter，传入 platforms=["weibo","zhihu"] + keyword="AI编程" + time_range="30d"，获取趋势上升的选题 + 增长率 + 入场时机建议
- **Step 2**: 对已有内容草稿调用 viral-prophet 进行竞品对比，传入 content + competitor_contents，获取优势/差距分析和差异化建议

### 全链路工作流
#
### Step 1: 选题阶段（topic-hunter）
- **输入**: platforms（目标平台数组）+ category（内容分类）+ user_interests（可选）
- **处理**: 聚合小红书/抖音/微博/知乎4大平台热点，5维趋势评分（热度30%+增长趋势25%+竞争度20%+变现潜力15%+可持续性10%）
- **输出**: 按评分排序的选题列表，每个选题含差异化切入角度建议和蓝海标记
- **降级**: 热搜API不可用时降级为LLM基于知识库生成选题
#
### Step 2: 标题阶段（title-hook-factory）
- **输入**: topic（选题）+ platform（目标平台）+ hook_type（钩子公式，默认auto）
- **处理**: 基于6大钩子公式（痛点共鸣/好奇悬念/数字权威/对比反差/情感共鸣/紧迫感稀缺）生成3-5个标题候选，4维打分（钩子匹配度30%+情感强度25%+关键词覆盖25%+吸引力20%）
- **输出**: 标题候选列表 + best_title + 钩子段落（50-200字开篇）
- **字数控制**: 小红书20字内/抖音15字内/公众号30字内/微博30字内
#
### Step 3: 预测阶段（viral-prophet）
- **输入**: content（内容全文）+ platform + competitor_contents（可选）
- **处理**: 6维潜力评分（钩子吸引力20%+情绪强度20%+价值密度20%+结构清晰度15%+节奏控制15%+CTA转化10%）+ 5大爆款要素分析 + 竞品对比
- **输出**: 爆款概率分级 + 优化建议（按优先级排序）+ 发布时机建议
- **分级**: 高(>80)/中高(70-79)/中(60-69)/低(<60)
#
### Step 4: 短剧制作阶段（drama-hit-producer，可选）
- **输入**: book_id + chapter_number + style_track（real_person/anime）+ platforms
- **处理**: 25步管道全自动执行，双轨风格切换（真人剧InstantID/动漫FLUX/Kling），四层TTS降级链（CosyVoice2→Fish-Speech→GPT-SoVITS→Edge-TTS）
- **输出**: 竖屏短剧视频URL + 质量评级 + 多平台发布结果
- **质量闭环**: A/B/C/D四级评分 + R1-R4红线检查，C/D级自动重做
### 单技能调用
每个技能均可独立调用，无需执行全链路。调用时在Agent对话中直接描述对应需求即可触发。

## 常见问题解答 (FAQ)
### Q1: 如何配置API Key？
A: 在Agent环境变量中配置相应的API Key，例如 `LLM_API_KEY`、`HOT_SEARCH_API_KEY`、`TTS_API_KEY`、`IMAGE_API_KEY` 和 `VIDEO_API_KEY`。
### Q2: 如何使用短剧制作功能？
A: 调用 `drama-hit-producer` 技能，传入 `book_id`、`chapter_number`、`style_track`（选择 `real_person` 或 `anime`）和 `platforms`（目标平台数组）。
### Q3: 如何自定义工作流程？
A: 在Agent对话中指定执行特定技能或自定义技能执行顺序。例如，只执行选题和标题生成，可以使用 `execute_workflow` 并指定 `workflow` 参数为 `topic_only | title_only`。
### Q4: 如何处理API配额限制？
A: 如果API配额耗尽，可以尝试切换到备用API或等待配额恢复。在配置文件中设置备用API的参数，并在API调用失败时自动切换。
### Q5: 如何处理内容违规问题？
A: 短剧生产线包含内容审核步骤，自动过滤敏感词和违规内容。如果生成的内容被标记为违规，可以手动检查并修改内容，或者联系客服寻求帮助。
## 异常恢复流程
针对AI内容创作工作站使用中可能遇到的常见问题,提供以下排查方案:
| 错误类型 | 原因分析 | 解决方案 |
|---------|---------|---------|
| API认证失败(401) | API密钥错误或过期 | 检查密钥配置,重新生成token |

| 文件不存在 | 路径错误或文件未创建 | 检查路径拼写,确认文件已生成 |
| 文件格式不支持 | 扩展名不在支持列表中 | 转换为支持的格式后重试 |
| 权限不足 | 当前用户无读写权限 | 检查文件权限,以管理员身份运行 |
| 命令执行失败 | 参数错误或环境依赖缺失 | 检查命令语法,确认依赖已安装 |
| 进程超时 | 命令执行时间过长 | 增加超时设置,优化命令参数 |
| 网络连接失败 | DNS解析失败或防火墙拦截 | 检查网络配置,确认代理设置 |
