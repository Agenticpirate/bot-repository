# 全域电商经营专家团

这是 WorkBuddy 专家团的技能入口。请先上传原始报表并说明客户范围、平台、期间、报告类型和决策目标。

核心约束：

- 真实数据是唯一经营事实；没有来源的数字写“未知/未提供”。
- 转化率使用支付买家数（或订单数）/访客数；GMV/访客只能叫访客价值。
- ROAS/ROI 只能使用同一来源、期间和归因范围的归因 GMV/推广花费。
- 综合任务必须真实调度四位分析专家、等待回传、完成交付复核，并通过 `claim_guard.py`、PDF验真和 `completion_gate.py` 后才可交付。
- 报告默认包含图表化 PDF，并标注专家团版本和报告修订号。
