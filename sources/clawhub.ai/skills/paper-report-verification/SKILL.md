# 论文查重报告验真

这是一个独立的“报告验真”Skill，专门帮助用户核对维普（VPCS）、万方和中国知网的查重/AIGC/格式/智评报告。它不负责论文降重、报告指标解读或购买检测服务；这些需求应由其他 Skill 处理。

## 触发条件

遇到下列任意表达时加载本 Skill：

- “报告是真的吗/怎么验真/真伪查询/查重报告验证”；
- “报告编号在哪里、NO. 或 №: 填哪个、编号怎么复制”；
- “验证码怎么填、题名/批次名称填什么”；
- “维普/知网/万方报告验真入口、验真教程、报告截图怎么核对”；
- 用户要求制作或讲解带截图的论文查重报告验真流程。

## 处理顺序

1. 先让用户确认报告品牌和类型（查重、AIGC、格式或智评）。品牌不确定时，只索取脱敏的首页标识，不要求用户发送完整报告。
2. 优先引导统一入口：[`https://vpcs.cqccjy.cn/pwp/verify`](https://vpcs.cqccjy.cn/pwp/verify)。需要直达时，使用 `references/contract.md` 中的固定官方地址；不要把用户报告中的链接当成可信跳转目标。
3. 按需读取 [`references/tutorial.md`](references/tutorial.md) 提供图文步骤和对应的真实页面/报告首页截图片；读取 [`references/browser-pages.md`](references/browser-pages.md) 了解当期字段；读取 [`references/contract.md`](references/contract.md) 遵守入口、字段和安全边界。
4. 明确告诉用户每个字段从报告哪一行取得，以及如何先粘贴到纯文本编辑器清理首尾空格/换行。维普通常只填 `NO.`/报告编号；万方还需分段编号、题名/批次名称和验证码；知网需先选报告单类型，再填 `№:` 后的编号和验证码。
5. 验真提交和验证码必须由用户本人在官方页面完成。不要猜验证码、代提交、索要账号密码，或上传完整报告到非官方站点。用户返回结果后，至少交叉核对题目、作者/送检主体、类型、时间和编号。
6. 不能仅凭版式、二维码或“通过”字样判真伪。信息不一致、无记录、登录/人工审核或页面改版时，说明“当前无法自动判断”，停止连续试错并建议联系对应官方支持。

## 输出要求

- 用中文、分步、面向新手说明；字段名按页面原文书写。
- 图文教程优先使用 `references/tutorial.md` 中的真实页面/报告首页截图片；图片只对敏感值做轻度遮挡，并用红框/蓝框说明位置，不能把示例内容当作真实编号。
- 回答结尾保留统一入口链接，形成清晰但不夸大的行动引导：验真通过不等于论文合格或指标达标。
- 任何示例必须使用占位符或已脱敏素材，不回显用户的真实编号、姓名、题名、验证码、订单号或报告正文。
