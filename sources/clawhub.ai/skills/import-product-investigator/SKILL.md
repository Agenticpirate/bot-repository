# import-product-investigator
> 通过公开信息平台,完整溯源进口产品的供应链,识别资质问题、虚假标注和消费欺诈风险,并给出合适结论与建议。

## 触发场景与路由规则

> **核心原则：先看图片，再决定走哪个 skill。**
> 图片触发规则仅适用于"发送产品图片"场景；纯文字描述/产品名/链接等均走原有文字触发规则。

### 第一层：图片自动识别路由

**操作方式：** 读取图片，提取所有可见文字和视觉元素，按以下信号判断。

#### 触发本技能（进口产品）的图片信号

| 信号类型 | 识别依据 | 说明 |
|---------|---------|------|
| 🌍 外文正文 | 标签正文含英/日/韩/法/德等外文（品牌名除外） | 外文占比高为强信号 |
| 📍 原产地标注 | 标 注 "原产国:XX"、"ORIGIN:XX"、"MADE IN XX" | 强信号 |
| 🏢 境外企业名 | 包装印有境外公司名称（非国内地址） | 强信号 |
| 📋 进口经销商 | 标注"进口商:XX"、"代理商:XX"（国内公司名） | 强信号 |
| 🔢 GACC注册号 | 标注格式 CN+字母+数字（如 CNZL15042401240001） | 直接触发 |
| 🏷️ 溯源码/防伪标 | 含二维码+涂层数字、"跨境溯源"、"防伪验证"字样 | 强信号 |
| 🇳🇿🇦🇺🇺🇸 等国别标识 | 包装含新西兰/澳大利亚/美国/日本等国旗/标识 | 辅助信号 |
| 🔒 无CCC标志 | 家用电器/3C品类产品但无CCC标志（可能为跨境进口豁免） | 辅助信号 |

**判断规则：**
- 满足 **≥1个强信号** → 直接触发本 skill
- 无强信号但有 **≥2个辅助信号** → 触发本 skill
- 图片仅含中文、无境外信息 → **触发国产商品核查**（`domestic-product-investigator` skill）

#### 触发国产商品核查的图片信号

| 信号类型 | 识别依据 |
|---------|---------|
| 🇨🇳 纯中文包装 | 标签正文全部或绝大部分为中文 |
| 🏭 国内制造商 | 标注"制造商:XXX"且为国内公司/国内地址 |
| ✅ CCC/GB标志 | 包装含CCC标志、GB标准号 |
| 📞 国内联系方式 | 400/800电话、国内网站 |
| 🇫🇷🇩🇪 纯外文无进口信息 | 纯外文包装但无任何国内进口商/经销商信息 → 疑似水货，**升级触发本 skill** |

#### 路由决策流程

```
用户发送产品图片
        ↓
提取文字+视觉元素
        ↓
┌─ 有外文正文 ──→ ┐
├─ 有"MADE IN XX" ─┤
├─ 有境外企业名 ───┤──→ 触发 import-product-investigator
├─ 有GACC注册号 ──┤
├─ 有跨境溯源码 ───┤
└─ 有"进口商/代理商"─┘
        ↓（均无）
┌─ 纯中文+国内制造商 ─→ 触发 domestic-product-investigator
├─ 纯外文无国内信息 ─→ 触发 import-product-investigator（水货/无正规进口）
└─ 无法判断 ─────────→ 询问用户："这是进口产品还是国产产品？"
```

### 第二层：文字触发规则（无图片时）

当用户无图片、只有文字描述时，使用以下规则：

#### 触发本技能（进口产品）的文字信号

- "核实/验证/查一下这个进口产品"
- "查一下这个产品" + 提及"跨境"、"保税"、"海外直邮"
- "看看是不是正规进口"、"是不是真的原装进口"
- "帮父母查一下他们买的XX保健品"（默认进口导向）
- 提及 GACC注册号、境外企业名、溯源码

#### 触发国产商品核查的文字信号

- "查一下这个国产产品"、"核实一下这个国产品牌"
- "查一下CCC认证"、"查一下这个产品有没有3C"
- 明确提及国内制造商名称+国内地址

### 场景对照表

| 场景 | 触发条件 | 目标 skill |
|------|---------|-----------|
| 场景A:核实产品 | 用户说"核实一下这个产品" + 图片 | 按图片路由 |
| 场景B:质疑产品 | 用户质疑"是不是假洋牌/虚假进口" | 直接触发本 skill |
| 场景C:购买后发现问题 | 用户买了进口产品后发现异常 | 直接触发本 skill |
| 场景D:供应链调查 | 用户调查境外供应链 | 直接触发本 skill |
| 场景E:国产产品核实 | 用户明确说"查一下国产/国内产品" | domestic-product-investigator |

**注意:** 当无法从图片判断进口/国产时，主动询问用户，不自行猜测。

## 置信度等级说明(全局)

每一步调查完成后,需标注本步的置信度:

| 置信度 | 含义 | 说明 |
|--------|------|------|
| ✅ 已核实 | 信息完整、可交叉验证 | 结果可直接用于结论 |
| 🟡 部分可查 | 信息部分获取,存在缺口 | 结论需降级处理 |
| 🔴 查无结果 | 在所有可用渠道均无法查到 | 本身是重要发现,单独标注 |
| ⚠️ 存疑 | 查询结果与包装标注不一致 | 需进一步核查或标注为风险点 |

## 证据来源独立性分级(核心原则)

调查结论的可信度,不取决于"查到了多少条信息",而取决于**这些信息来自谁、来源是否相互独立**。一条低可信来源的陈述,无论出现多少次,都不能当作正面证据累加。

### 三级来源

| 等级 | 来源类型 | 示例 | 证明力 |
|------|---------|------|--------|
| 🟢 独立第三方硬证 | 与商品销售无利益关联的官方/权威机构 | 海关清关记录(单一窗口)、品牌方官方验证、GACC 官方状态、当地政府公司注册库 | 高,可直接作结论依据 |
| 🟡 半独立/自证来源 | 平台或商家自行录入、可操纵的数据 | 跨境防伪溯源平台(商家自填、平台不核验)、电商商品页参数、品牌官网自称 | 中低,仅作参考,不可单独背书 |
| 🔴 商品自述 | 包装上印刷的信息(品牌、成分、经销商、批号) | 瓶身标签、中文标贴 | 仅排除低级假,不能证明正品 |

### 铁律

1. **同源性排除**:若"平台说正品"和"平台说首查记录"来自同一个低可信平台,二者是同一来源,不能互相加成。用低可信来源给自己背书 = 无效。
2. **溯源平台"首查时间/首查人"不能作为正品加分项**:它证明的只是"这个码在某个时间被第一次扫描",不是"商品是真品"。假货商家可自己生成码、自己录入、自己先扫一次,同样产生首查记录;且首查人甚至可能不是买家本人(进口商入库时扫)。
3. **平台"正品"声明 ≠ 海关背书**:315 曾曝光多起跨境溯源平台"商家自填、平台不核验"案例。平台显示"正品"仅说明标签真实生成、码未被批量复制,不能证明海关清关或商品真伪。
4. **包装自述不构成铁证**:高仿可完美复制包装印刷、成分表、批号、甚至真实经销商名。包装过关 = "没发现假的证据",≠ "证明真"。

> 应用:综合评估时,只对 🟢 级来源计为正向硬证;🟡 级来源仅用于"未发现矛盾",不得加分;🔴 级来源用于排除低级假,不得加分。

## Step 1: 包装信息提取

从产品包装照片或描述中提取以下关键字段:

| 字段 | 示例 | 用途 |
|------|------|------|
| 产品名称 | 同唯安®叶酸复合营养片 | 品牌核查 |
| 品牌商 | 同唯安(陕西)医学科技有限公司 | 企业查证 |
| 原产地 | 新西兰 | 核查真实性 |
| 境外生产企业 | Oranutrition Limited | GACC注册查证 |
| GACC注册号 | CNZL15042401240001 | 海关注册状态 |
| 出口商 | Tovian Limited, Mississauga, Canada | 境外实体查证 |
| 国内经销商/代理商 | XX国际贸易有限公司 | 经销商资质核查 |
| 认证标志 | RMP/GMP/HACCP | 真实性核查 |
| 批号/有效期 | U411076 / 2027-11-04 | 购买凭证关联 |

**操作**:要求用户拍照产品包装(正反面、成分表、标签),或引导用户提供已知信息。

**用户上传图片时**:立即保存到证据包目录(见"证据包自动生成"章节),无需等待后续步骤。

**提前终止条件**:如用户无法提供任何包装信息,且无法从购买链接等渠道补充,终止调查并告知需补充信息。

**本步置信度:** ✅ 已核实 / 🟡 部分可查 / 🔴 查无结果 / ⚠️ 存疑
**置信度说明:** (一句话说明提取到的信息完整度)

### 包装真实性辅助判断技巧(非必须,但能提升判断质量)

- **成分表比对**:将包装成分表与已知正品配方比对。配方明显异常(如软骨素剂量远低于标准版、出现陌生成分)是造假线索;与正品一致则支撑包装真实(但仍可被高仿复制)。
- **包装经销商(品牌方)核查**:包装印的境外品牌方/经销商(如 Move Free 印 "RB Health US"),应核查其是否为真实实体且与品牌归属匹配(如 RB Health US = Reckitt 美国健康部门,Schiff/Move Free 确属 Reckitt)。真实匹配可排除"印虚假经销商"的低级假特征,但高仿同样可抄真实名,不构成硬证。
- **视觉判断上限提醒**:仅凭包装图片判断"非假货"可信度上限为"中等"(~50-60%)。高仿印刷可乱真,图片看不到材质/瓶盖工艺/防伪暗记/内容物。包装过关 = "没发现假的证据",≠ "证明真"。

| 数据源 | 网址 | 查询内容 |
|--------|------|---------|
| **市场监管总局特殊食品信息查询** | https://bjzx.samr.gov.cn/sscxquery/ | 保健食品注册、特殊食品经营备案 |

- 商标注册在第3类(日化用品)却卖食品 → 品牌混淆

**提前终止条件**:如在天眼查/企查查查到企业经营范围不含食品相关,且商标类别不符 → 可跳过 Step 6 国内资质进一步核查,直接作为风险点记录。

**查询时**:立即 browser 截图保存(见"证据包自动生成"章节)。

**本步置信度:** ✅ 已核实 / 🟡 部分可查 / 🔴 查无结果 / ⚠️ 存疑

## Step 3: 海关注册查证(GACC)

**查询地址**:https://ciferquery.singlewindow.cn/

**查询方式**:输入 GACC 注册号(格式:CN+字母+数字,如 CNZL15042401240001)

**状态解读**:

| 状态 | 含义 | 风险等级 |
|------|------|---------|
| **正常** | 已注册,可进口 | ✅ 低 |
| **暂停进口** | 被海关暂停,正在调查或违规 | 🔴 高 |
| **取消** | 已注销,不得进口 | 🔴 高 |
| **撤销** | 已撤销,注册失效 | 🔴 高 |

**提前终止条件**:
- GACC 状态为"暂停"或"取消" → 无论后续结果如何,均可提前给出违规/三无结论
- GACC 状态为"正常" → **不得提前结束**,须继续 Step 4/5/6 核查境外实体、经销商资质及产品批号;GACC 正常仅证明境外工厂有进口资质,不证明商品真伪

**查询时**:立即 browser 截图保存 GACC 状态页面。

**本步置信度:** ✅ 已核实 / 🟡 部分可查 / 🔴 查无结果 / ⚠️ 存疑
**置信度说明:** (一句话说明注册状态及是否与包装标注一致)

## Step 5: 国内经销商核查

> **为什么重要**:进口产品的国内经销商承担加贴中文标签、执行产品召回、提供售后服务的法律责任。若经销商无资质,产品的国内流通本身就不合规。此环节与 Step 4 并行,先查境外实体再查国内经销商,形成完整供应链链。

### 5.1 食品经营许可证

**查询地址**:国家企业信用信息公示系统 https://www.gsxt.gov.cn/ → 输入企业名称

|--------|---------|------|

| 查无该企业 | 🔴 无资质销售 | |
| 有企业但经营范围不含食品/保健食品 | 🔴 超范围经营 | |
| 企业已注销/吊销 | 🔴 不得经营 | |

### 5.2 报关单与检验检疫证明

**操作**:向商家索要报关单和检验检疫证明(国家法规要求销售商留存),核对以下内容:

| 核查项 | 判断标准 | 风险 |
|--------|---------|------|

| 收货人/申报单位 | 报关单收货人 vs 实际销售商 | 不符 → 🟡 授权链存疑 |
| 进口日期 | 核实产品是否在有效期内 | 已过期 → 🔴 |

### 5.3 授权链验证

| 核查项 | 判断标准 | 风险 |

| 报关单收货人 ≠ 实际销售的经销商(多层转手)| 🟡 授权链断档 | |
| 无法提供报关单 | 🟡 无法核实货证一致性 | |

## Step 7: 跨境溯源码 / 防伪溯源平台核查

跨境电商产品常贴有"跨境贸易电子商务进口商品防伪溯源码"(多为二维码 + 涂层下数字码)。扫码或输入码后跳转到第三方溯源平台。本节规范此类平台的核查方法,**重点防范把平台数据误当正品证据**。

### 7.1 查询方式

- 优先**扫码**(手机扫瓶身二维码)获取正确跳转链接与查询入口
- 浏览器直查常因 SSRF 策略限制失败(需 IP 直连);可改用 `curl` 直接请求接口,或解码二维码得到跳转域名
- **查询键要用对**:标签上通常有两组数字--一组是展示码(如 12 位明码),一组是涂层下刮开的**验证数字**(也是 12 位左右)。**正确查询键是涂层下那组**,用错会导致两平台都显示"无效"
- 不同口岸平台码制不同(如宁波口岸为 13 位,第三方平台 12 位)。码制不符→"无效"属正常,不代表假,可能是清关口岸不同

### 7.2 溯源平台主体核实(用备案号反查,别搜公司名)

- 从平台页面/二维码跳转参数提取 **ICP 备案号**(如 粤ICP备2023131442号)
- **正确做法:用备案号反查主体**(站长工具、icplishi 等),而非用公司名搜索--公司名常被近似冒用(如"晨必达/卓必达/雾必达"一堆近似名),搜名字会查错主体
- 备案主体真实存在 ≠ 商品正品:平台只是 SaaS 服务商,数据由商家自填 → 主体核实结果交给 **7.6 溯源平台可信度评估** 给出最终评级

### 7.3 溯源结果的解读(严禁误读)

| 平台显示 | 正确解读 | 错误解读(禁止) |
|---------|---------|----------------|
| "正品" | 标签真实生成、码未被批量复制 | ❌ 当作海关正品背书 |
| "首查时间 2026-05-29" | 该码于该日首次被扫 | ❌ 当作"买家本人首查、排除掉包" |
| 物流信息(启运国/进口港) | 商家录入的物流描述 | ❌ 当作海关清关记录 |

### 7.4 批号 LOT vs 促销/防伪码

- **LOT / 生产批号**(如 T25E075):生产追溯码,**公开渠道无法直接在线验证**。验证路径只有两条硬路:1 品牌方客服(提供 LOT,后台查生产日期/真伪);2 海关清关单比对(单一窗口,身份证号,清关单列批号)
- **促销/积分防伪码**(部分品牌瓶身另有可刮开码):如 Schiff/Move Free 官网代码验证系统,验的是促销码有效性,不是 LOT 批号,二者勿混
- 批号本身可被仿印,单独不构成正品铁证,需配合包装物证 + 独立验证

### 7.5 本步结论定位

- 溯源平台"正品" + 首查记录 → **不得计入正向可信度**
- 仅当溯源码能对应到**海关清关记录**(单一窗口)时,才升为 🟢 级硬证
- 本步价值:确认标签真实、辅助定位正确查验入口(哪个口岸/平台),以及为后续品牌方/海关验证提供批号

**本步置信度标注说明(与全局定义对应):**

| 本步标注 | 对应全局置信度 | 本步中的具体含义 |
|---------|-------------|----------------|
| ✅ 已核实 | ✅ 已核实 | 溯源码能直连海关清关记录,码状态可交叉验证 |
| 🟡 部分可查 | 🟡 部分可查 | 能在平台上查到结果,但数据来自商家自填,无海关硬证 |
| 🔴 查无 | 🔴 查无结果 | 码在平台上无效,且无法通过其他口岸/平台对应到海关记录 |
| ⚠️ 存疑 | ⚠️ 存疑 | 溯源平台主体存疑(空壳/被曝光/跨平台查无) |

### 7.6 溯源平台可信度评估(关键:有码必评平台)

查到溯源结果后,**必须单独对溯源平台本身做可信度判定**--只查码不评平台,等于把商家的自证当证据。按以下五维给平台定级(高 / 中 / 低 / 存疑):

| 维度 | 高可信信号 | 低可信 / 存疑信号 |
|------|-----------|------------------|
| 运营主体 | ICP 备案真实 + 工商可查到公司 + 有实际业务 | 备案查无主体 / 主体为空壳 / 近似名冒用(晨必达/卓必达/雾必达) |
| 数据性质 | 直连海关/官方数据库,数据不可商家篡改 | 商家自填、平台不核验(第三方 SaaS) |
| 官方背书 | 海关/政府口岸平台(宁波口岸、单一窗口) | 纯商业第三方溯源 SaaS |
| 曝光记录 | 无 315/消协负面 | 曾被 315 或消协曝光"虚假溯源/自填不核验" |
| 跨平台一致性 | 同一码在官方口岸平台也能查到 | 仅在该第三方"正品",官方口岸查无 |
| 许可资质 | 主体持 ICP 经营许可证(B25) + 等保备案 + 可证明直连海关系统 | 仅有 ICP 备案/营业执照,无 ICP 经营许可证,更无海关对接(典型第三方 SaaS) |

**评级结论:**
- **高**:海关/政府官方平台、直连清关数据 → 平台数据可升为 🟢 级硬证
- **中**:真实运营的第三方 SaaS,但数据商家自填 → 仅证明标签真实生成、码未被复制,不得背书正品
- **低 / 存疑**:主体查无、空壳、曾被曝光、跨平台查无 → 平台数据作废,可信度归零

**许可资质核查清单(先破 myth,再分层查):**

> **Myth-buster:不存在"防伪/溯源资质牌照"。** 防伪技术产品生产许可证已于 2019 年 9 月取消(国发〔2019〕19号),2022 年《产品防伪监督管理办法》修订再删除相关要求。任何平台拿"防伪资质"当背书都是话术,不予采信。溯源平台也不是特许行业,无专门牌照。

按以下四层核查平台主体持有什么证(查得越全,平台可信度越高):

| 层级 | 查什么 | 查询入口 | 判读 |
|------|--------|----------|------|
| 基础(必须) | ICP 备案号、公安联网备案、营业执照+经营异常/处罚 | beian.miit.gov.cn / www.beian.gov.cn / gsxt.gov.cn / creditchina.gov.cn | 缺任一项即存疑;看经营范围是否含软件/信息技术/防伪服务,是否被列入经营异常或处罚 |
| 增强(经营性应有) | **ICP 经营许可证(B25)**、等保备案(二级/三级)、软著/专利 | dxzhgl.miit.gov.cn / 市级以上公安 / 企查查·天眼查 | 溯源 SaaS 向商家收费属经营性,**必须有 ICP 经营许可证**;仅备案无许可证 = 合规缺口 |
| 行业自证(非强制) | 中国防伪行业协会会员、ISO 27001/27701 | 协会官网 / 认证机构 | 加分项,非必需 |
| 最强背书 | 直连海关跨境进口统一版系统 | 宁波口岸 / 单一窗口 | 真官方溯源是海关系统本身,非商业平台;商业平台声称"海关溯源"须能证明系统对接,否则冒用 |

**核查要点:**
- 备案号反查出的主体,要回 dxzhgl.miit.gov.cn 核它**自己**有没有 ICP 经营许可证--很多平台把备案挂在商家域名下"借壳",真实运营主体可能无证。
- "有 ICP 备案" ≠ "有 ICP 经营许可证":备案是域名登记(非经营性也需),许可证才是有偿服务的经营凭证。
- 主体有证 ≠ 商品正品:仍只证明平台合法运营,数据是否商家自填要看"数据性质"维度。

**铁律:**
1. **平台可信度 ≠ 商品可信度**:即便平台高可信(官方海关),它只证明清关链路,仍需结合包装/批号判定商品。
2. **平台低可信时,其"正品"声明直接作废**,不得计入任何正向证据;调查必须转向独立验证(品牌方客服 / 海关清关单),不得停在"平台说正品"。
3. **跨平台查无是强预警**:若该码在官方口岸平台查不到,而只在某个 obscure 第三方显示"正品",极大概率清关口岸不符或平台数据不可信,必须标注并存疑。

**越权声明识别(平台说了不该它说的话):**

溯源平台能证明的事情是有限的:
- ✅ **它能证明**:这个码是真实的、没被批量复制、是它系统生成的
- ❌ **它不能证明**:这个商品是正品、海关真的清关过、品牌方授权过

当一个商业溯源平台(如晨必达这类 SaaS)在结果页上写"正品验证通过"或"海关溯源",它就是在**越权声明**--因为它没有海关系统的数据权限,它只有商家自己录入的数据。

| 声明内容 | 谁有权说 | 商业平台说了就是越权 |
|---------|---------|------------------|
| "此码真实,未被复制" | 溯源平台自己 | ✅ 合规声明 |
| "此商品已通过海关清关" | 海关官方系统(单一窗口/口岸平台) | ❌ 越权(除非能证明直连海关) |
| "此商品为正品" | 品牌方/海关(基于真品供应链) | ❌ 越权(平台只知商家录入,不知真假) |
| "此商品经 XXX 检测认证" | 第三方检测机构 | ❌ 越权(除非能提供机构背书链接) |

**实操例子:**
- 晨必达平台返回"正品" → 越权声明,数据来自商家自填,平台不核验
- 宁波口岸平台返回"已清关" → 官方系统,合规声明
- 茅台官网验真返回"正品" → 品牌方自有系统,合规声明

**平台信用替代指标(国家不发牌时,看这些判断可信度):**

既然没有"防伪溯源牌照"这种准入门槛,判断可信度要看平台自己建构信用的信号--不是看它有什么证,而是看它的**机制、动机、历史、能力**。

| 指标 | 看什么 | 高可信信号 | 低可信信号 |
|------|--------|-----------|-----------|
| 1 码机制 | 码本身是否防造假 | 预涂层刮码 + 随机生成 + 绑定批次/效期 | 明码印刷 + 顺序号 + 无商品绑定 |
| 2 数据防篡改 | 数据存在哪 | 区块链存证 + 多方节点 | 中心化数据库,平台可随时改 |
| 3 背书来源 | 谁为数据负责 | 品牌方/电商平台自建,或官方系统 | 独立第三方 SaaS,无权威背书 |
| 4 历史行为 | 过往记录 | 运营 3 年以上,无重大投诉/曝光 | 刚上线,或被 315/媒体曝光过 |
| 5 利益动机 | 谁给它钱 | 收消费者验证费(依赖信任) | 收品牌方服务费(利益冲突,可能放水) |
| 6 跨平台验证 | 能否交叉印证 | 同码在官方/品牌方平台也能查到 | 仅该平台"正品",官方查无 |

**综合判断示例:**
- **晨必达**:明码 + 中心化数据库 + 第三方 SaaS + 收商家钱 + 刚运营几年 → 🟡 中可信(只证码真,不证正品)
- **茅台官网验真**:品牌方自建 + 绑定生产批次 + 官方背书 → 🟢 高可信
- **某个被 315 曝光过的平台**:声称海关背书但无直连 + 被曝光"商家自填不核验" → 🔴 低可信

**实操链路:**
看到溯源码 → 扫码 → 看返回页面写什么 → 如果写"正品/海关清关" → 查平台是否有权说这话:
- 有直连证明 → 采信
- 无直连证明 → 越权声明,降权 → 转向六项替代指标判断平台信用 → 综合评级(高/中/低) → 决定是否采信其"码真"

## 信息不完整时的替代路径

### 情况A:用户只知道产品名,不知道GACC注册号

**替代查询路径**:
1. 通过天眼查/企查查查到品牌商 → 查看其对外投资的境外子公司名称
2. 用产品名+"GACC注册号"或"境外生产企业注册"搜索
3. 打开购买链接,查看产品详情页是否标注GACC注册号

**流程变更**:Step 1 → Step 2 → **Step 2.5 GACC反推(可选)** → Step 3

### 情况B:用户无法提供包装照片,只有购买链接

**替代查询路径**:打开购买链接,截图产品参数页,提取品牌、产地、境外生产企业名称、国内经销商名称、认证标志;详情页无GACC号则通过情况A反推。

### 情况C:用户只知道品牌名,不知道产品具体名称

**替代查询路径**:以品牌名为核心查天眼查/企查查判断资质 → 电商平台搜索具体型号 → 优先查NMPA + 特殊食品备案。

### 情况D:用户无法提供任何包装信息

**替代路径**:用"品牌名+骗/假/违规"搜索预判 → 直接查NMPA判断是否可疑 → 明确告知用户需补充哪些信息。

### 情况E:用户无法提供报关单

**替代路径**:
- 在电商平台商品详情页查找"进口海关单"或"检验检疫证明"展示入口
- 若电商平台无此信息 → 标注为"无法核实货证一致性(报关单缺失)",降级置信度,继续其他步骤

**信息缺口告知模板**:
> 要完成完整调查,还需要以下信息之一:GACC注册号(格式CN+字母+数字)、境外生产企业名称、国内经销商名称、产品购买链接、报关单(可向商家索要)。请您帮忙补充任意一项,调查即可继续。

## 合适结论 + 建议

### 结论定性(5级)

| 结论 | 描述 | 建议方向 |
|------|------|---------|
| ✅ **合规产品** | 所有资质齐全,GACC正常,境外企业可查证,国内经销商资质合规 | 无需行动 |
| 🟡 **存疑产品** | 部分信息无法核实,但无明确违规证据 | 谨慎使用,索要证明 |
| 🔴 **违规产品** | GACC暂停/取消,或无保健食品注册,或经销商无资质 | 停止使用 |
| ⚠️ **空壳公司产品** | 境外出口商在当地政府数据库查无记录 | 停止使用 |
| ⚠️ **三无产品** | 无资质、无合法进口渠道、无真实境外来源 | 立即停止 |
| 💀 **假冒产品** | 伪造GACC注册号、仿冒境外品牌、伪造证照 | 立即停止,举报 |

### 结论有效期说明

- **静态信息**(企业注册号、商标类别):相对稳定
- **动态信息**(GACC注册状态、公司注册状态):随时可能变化
- **建议**:在报告开头标注"本报告查询时间为 YYYY-MM-DD",提示用户结论具有时效性

### 结论与预期不符时的处理

- **用户坚信是假货,但实际合规** → 如实告知,说明依据,提示可向商家索要完整资质证明
- **用户希望维权,但证据链不足以支持投诉** → 如实告知证据缺口,建议补充证据后再投诉

### 建议(根据结论决定)

| 结论 | 建议内容 |
|------|---------|
| ✅ 合规产品 | 无需任何行动 |
| 🟡 存疑产品 | 保留购买凭证,向商家索要完整资质证明文件(报关单、检验检疫证明) |
| 🔴 违规产品 | 保留证据 → 停止使用 |
| ⚠️ 空壳公司产品 | 保留证据 → 停止使用 |
| ⚠️ 三无产品 | **立即停止服用** → 保留证据 |
| 💀 假冒产品 | **立即停止使用** → 向市场监管部门举报 |

## 综合可信度分层评估

每步用 ✅/🟡/🔴/⚠️ 标注后,还需给出一个**数值化综合可信度(非假货概率)**,避免把不同来源混为一谈虚高评分。

### 分层基准

| 证据组合 | 非假货可信度 |
|---------|------------|
| 仅包装图片(视觉过关) | 中(~50-60%) |
| 包装 + 低可信溯源平台"正品/首查" | 中(~50-60%,平台数据不计分) |
| 包装 + 包装经销商(品牌方)核查真实 + 链路自洽 | 中(~60-70%) |
| 以上 + 品牌方批号验证通过 | 高(~85-90%) |
| 以上 + 海关清关单比对一致 | 很高(~90%+) |

### 铁律

1. **视觉包装判断上限是"中等"**:高仿可乱真,图片看不到材质/瓶盖工艺/防伪暗记/内容物,纯包装无法排除高仿。
2. **低可信平台数据不加分**:见"证据来源独立性分级"。
3. **"无矛盾" ≠ "真实"**:链路信息自洽只是没发现破绽,不是正向证明。
4. **综合可信度 = 最强独立硬证决定上限**:没有 🟢 级硬证(品牌方/海关),综合可信度封顶在"中等",无论包装多完美。

### 输出要求

最终报告必须明确写出综合可信度的**数值区间 + 依据分层**,例如:
> 综合非假货可信度:中等(~65%)。依据:包装过关 + 经销商 RB Health US 真实匹配 + 链路自洽;但无品牌方/海关独立硬证,高仿风险未排除。

## 注意事项

1. **信息来源优先顺序**:用户提供的包装信息 > 政府官方数据库 > 新闻报道 > 第三方平台
2. **每个事实性断言必须注明来源**,不推断,只陈述可查证的内容
3. **空壳公司判定**:当地政府数据库无记录 + 地址为民用住宅 = 高概率空壳
4. **GACC"暂停进口"是最强的违规信号**:说明海关已在调查该企业
5. **经销商资质是容易被忽视的环节**:进口产品包装上的"代理商"信息 ≠ 有国内经营资质,务必核查
6. **报关单是关键证据**:向商家索要时,若对方拒绝或拖延,是重要警示信号
7. **保护用户隐私**:调查报告仅用于用户个人维权,不对外传播
8. **证据完整性**:截图优于描述,购买小票是最重要的实物证据
9. **证据包全程随查随存**:每步查询完成后立即截图保存,结论出来证据包即ready
