## Core Rules

1. **真实可信原则**：基于用户提供的信息生成，不虚构公司情况
2. **合规性原则**：不包含年龄、性别、婚育、地域等歧视性表述
3. **吸引力原则**：突出岗位亮点和成长空间，吸引目标候选人
4. **清晰原则**：结构分层、重点突出，便于候选人快速阅读
5. **差异化原则**：不同平台用不同话术，适配各平台用户特征

## Usage

### 基础用法 - 生成JD
```bash
jd_generator.py "产品经理"
```

### 指定风格
```bash
jd_generator.py "高级Python开发工程师" --style startup --industry "人工智能" --salary "25-40K" --location "北京"
```

### 6大风格可选
- `boss` - BOSS直聘风格（简洁直接、突出薪资、口语化）
- `liepin` - 猎聘风格（专业正式、职业发展导向）
- `lagou` - 拉勾网风格（互联网味、技术导向）
- `campus` - 校园招聘风格（成长导向、培训体系）
- `official` - 官方正式风格（国企/上市公司规范风格）
- `startup` - 创业公司风格（激情、期权、扁平管理）

### 岗位深度分析
```bash
jd_generator.py "AI算法工程师" --analyze --industry "大模型"
```

输出包含：岗位核心价值、关键能力模型、市场薪资参考、招聘难点分析、考核指标建议、理想人才画像

### 多渠道一键生成
```bash
jd_generator.py "前端开发工程师" --multi-channel --level "高级" --salary "20-35K"
```

一键生成BOSS直聘+猎聘+拉勾3个版本

## Parameters

| 参数 | 说明 | 必填 |
|------|------|------|
| job_title | 岗位名称 | ✅ |
| --industry/-i | 所属行业 | ❌ |
| --company-size/-s | 公司规模 | ❌ |
| --level/-l | 岗位级别（初/中/高/专家） | ❌ |
| --salary | 薪资范围 | ❌ |
| --location | 工作地点 | ❌ |
| --requirements/-r | 核心任职要求 | ❌ |
| --highlights | 岗位亮点 | ❌ |
| --style | JD风格（默认boss） | ❌ |
| --analyze | 岗位深度分析模式 | ❌ |
| --multi-channel | 多渠道一键生成 | ❌ |
| --json | JSON格式输出 | ❌ |
