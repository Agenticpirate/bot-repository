# 成果转化方案生成

## Overview

整合「交易模式决策矩阵」与「41个科技成果转化典型案例库」，为一项技术或成果制定完整转化方案。核心流程：收集技术信息 → 检索相似案例 → 10维度决策矩阵评分 → 输出推荐模式与条款清单 → 对标案例库给出参照。

## 使用流程（Workflow）

### Step 1: 收集技术基本信息

向用户确认以下信息（缺失项可先合理假设并标注）：

| 信息项 | 说明 | 示例 |
|--------|------|------|
| 技术领域 | 环保/生物医药/新材料/信息技术等 | 医疗器械 |
| 技术成熟度 TRL | 1-9级（1-3原理验证，4-6实验室/中试，7-9产业化） | TRL 6 |
| 所有权情况 | 职务发明/横向项目/共有 | 职务发明，权属清晰 |
| 主体身份 | 高校/科研院所/医院/企业/个人 | 高校教授团队 |
| 市场预期 | 规模、增速、竞品 | 预计3年市场规模10亿 |
| 团队意愿 | 是否愿意创业/深度参与 | 愿意参与但不牵头创业 |
| 合作方情况 | 意向企业、其诉求 | 有医疗器械企业洽谈 |
| 金额期望 | 一次性vs长期收益偏好 | 期望快速变现 |

### Step 2: 检索案例库中的相似案例（必做）

**必须先加载 `references/case_library_guide.md` 了解案例库字段与检索方式**，然后从案例库（`references/case_library.json`，41个案例）中检索与用户技术场景相似或同领域的案例，作为方案参考。

检索方式（Python）：

```python
import json
with open('references/case_library.json', encoding='utf-8') as f:
    cases = json.load(f)

# 示例1：按技术领域/主题检索（如"医工结合"）
similar = [c for c in cases if '医工' in c.get('topic_name','') or '生物医药' in json.dumps(c.get('tags',[]))]

# 示例2：按转化模式检索（作价入股案例）
equity = [c for c in cases if c.get('category') == '作价入股' or '作价入股' in c.get('tags',[])]

# 示例3：按主体类型（高校）
univ = [c for c in cases if c.get('organization_type') == '高校']

# 示例4：全文关键词
kw = [c for c in cases if '概念验证' in json.dumps(c, ensure_ascii=False)]
```

或使用命令行检索脚本（已包含在 `scripts/` 中）：

```bash
python scripts/search_cases.py --keyword "作价入股"
python scripts/search_cases.py --type 高校
python scripts/search_cases.py --library 全国
```

**选择 2-4 个最相似的案例**，在最终方案中列出：案例编号、单位、转化模式、关键数据（金额/股权/许可费）、可借鉴做法。

### Step 3: 三选一决策树

```
用户有可转化的技术 →
├── 想保留所有权 + 长期收益？ → 许可 (License)
├── 想一次性变现 + 彻底退出？ → 转让 (Assignment)
└── 想深度参与 + 分享成长红利？ → 作价入股 (Equity)
```

结合 Step 2 检索到的相似案例实际选择，辅助判断。

### Step 4: 10维度决策矩阵评分

对每个交易模式在以下 10 个维度上打分（1-5 分），加权后比较。结合用户信息和案例库案例给出评分依据。

| 决策维度 | 权重 | 许可 | 转让 | 入股 | 说明 |
|---------|:---:|:---:|:---:|:---:|------|
| 短期现金流 | 15% | 3(入门费+分成) | 5(一次性大额) | 1(无现金) | 评分高=钱快 |
| 长期收益天花板 | 15% | 4(持续的) | 1(一次性) | 5(股权增值) | 评分高=潜力大 |
| 风险暴露 | 10% | 3(对方不商业化=0) | 5(钱到手了) | 1(公司可能失败) | 评分高=风险低 |
| 控制权保留 | 10% | 4(可限制范围) | 1(完全失去) | 3(有董事席位) | 评分高=控制强 |
| 退出便利性 | 5% | 3 | 5 | 1(锁定期) | 评分高=容易退出 |
| 税务效率 | 10% | 3(增值税免) | 4(所得税≤500万免) | 2(递延纳税) | 评分高=税低 |
| 运营负担 | 5% | 2(需监控履约) | 5(一次了事) | 1(需参与经营) | 评分高=省心 |
| 合作方意愿 | 15% | 3 | 2(买断压力大) | 4(共担风险) | 评分高=对方想要 |
| 技术阶段适配 | 10% | 4(各阶段均适合) | 3(成熟技术最佳) | 2(早期技术好) | TRL<5偏入股，TRL>7偏许可 |
| 团队意愿 | 5% | {打分} | {打分} | {打分} | 核心团队偏好 |

**加权总分 = Σ(维度评分 × 权重)**

输出三模式加权得分对比表，推荐得分最高者，并说明与所选相似案例的模式一致性。

### Step 5: 典型场景速查（辅助判断）

| 场景 | 推荐模式 | 理由 |
|------|:---:|------|
| 教授不想创业，技术已成熟 | **许可** | 保留所有权 + 稳定提成 |
| 企业战略调整，剥离非核心 IP | **转让** | 快速回笼资金 |
| 颠覆性技术，市场未验证 | **作价入股** | 分享未来成长，但眼下不值钱 |
| 跨国技术输出 | **许可** | FTO 风险可控，分批许可 |
| 创始人即将退休 | **转让** | 一次性退出，不留后事 |
| 高校横向合作项目成果 | **共有+许可** | 权属清晰化，避免后续纠纷 |
| 技术依赖持续迭代 | **许可+改进回授** | 双方各自迭代，互相许可改进 |

### Step 6: 输出转化方案文档

方案文档包含以下部分：

1. **技术概况**：技术领域、TRL、权属、主体
2. **推荐转化模式**：决策矩阵得分表 + 推荐结论 + 理由
3. **参考案例对标**：2-4个案例库相似案例（编号/单位/模式/数据/启示）
4. **条款清单**（按推荐模式选择对应模板，见下方）
5. **税收影响速算**（见下方）
6. **操作步骤建议**：下一步做什么（评估、谈判、签约、登记）

## 谈判条款清单模板

### 通用核心条款
- [ ] 交易标的（专利号/技术秘密范围）
- [ ] 地域范围（中国/亚洲/全球）
- [ ] 期限（年数/专利到期）
- [ ] 对价（金额 + 支付方式 + 时间节点）
- [ ] 独占性（独占/排他/普通许可）
- [ ] 技术交接与培训安排
- [ ] 验收标准

### 许可模式特有
- [ ] 入门费 + 销售提成比例
- [ ] 最低年费（防对方不商用）
- [ ] 改进技术归属 vs 回授条款
- [ ] 分许可权
- [ ] 终止与撤回条件

### 转让模式特有
- [ ] 一次性转让费
- [ ] 转让后发明人署名权保留
- [ ] 有无回购条款
- [ ] 买方是否承担年费

### 入股模式特有
- [ ] 技术估值方法与依据
- [ ] 股权比例
- [ ] 董事会席位
- [ ] 优先清算权
- [ ] 反稀释条款
- [ ] 退出机制（IPO/并购/回购）
- [ ] 竞业禁止

## 税收影响速算

| 模式 | 增值税 | 企业所得税 | 个人（发明人）所得税 |
|------|:---:|------|------|
| 技术许可 | **免** | 正常25%（高企15%） | 工资薪金/劳务报酬 |
| 技术转让 | **免** | ≤500万**免**，超出减半 | 奖励给个人的，减按50%计入当月工资 |
| 作价入股 | 免 | 递延至转让股权时 | 递延至转让股权时 |
