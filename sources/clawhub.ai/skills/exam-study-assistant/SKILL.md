# 考试学习助手

## 能力概览

| 模块 | 能力 |
|------|------|
| 学习计划 | 长期/中期/短期学习计划、每日学习安排、倒推式计划 |
| 知识总结 | 教材/笔记内容结构化提炼、知识点串联、概念对比 |
| 思维导图 | 章节/整书知识框架、可导出为思维导图格式 |
| 记忆规划 | 艾宾浩斯遗忘曲线复习安排、间隔重复提醒 |
| 错题整理 | 错题归因分析、弱项识别、针对性练习建议 |
| 题库练习 | 选择题/填空题/简答题/论述题生成、真题风格适配 |
| 考前冲刺 | 高频考点梳理、模拟测试、考试技巧、心态调整 |
| 多科协调 | 多科目时间分配策略、交叉学习建议 |

## 使用方式

### 1. 学习计划制定

用户提供考试名称、距离考试天数、每日可用时间：

1. 采用**倒推法**：从考试日期倒推，分割为阶段
2. 设计三阶段计划：
   - **基础阶段**：教材通读+知识框架搭建（50%时间）
   - **强化阶段**：刷题+错题整理+专题突破（30%时间）
   - **冲刺阶段**：全真模拟+高频考点回顾（20%时间）
3. 考虑艾宾浩斯遗忘曲线安排复习节点
4. 输出《全周期学习计划表》

### 2. 知识点总结与思维导图

用户提供教材内容或知识点列表：

1. 提取核心概念和关键定义
2. 构建知识层级（章→节→知识点→子知识点）
3. 识别概念间的关联关系（因果/对比/包含/递进）
4. 标注重点/难点/高频考点
5. 输出两种格式：
   - Markdown层级大纲
   - 可导入思维导图工具的格式（如Markdown列表）

### 3. 错题分析与弱项诊断

用户提供错题内容：

1. **归因分析**：知识盲区/理解偏差/粗心大意/审题错误
2. **知识定位**：错误关联到具体的知识点/章节
3. **规律挖掘**：是否在特定题型/知识点上反复出错
4. **针对性方案**：推荐复习材料+专项练习+记忆策略

### 4. 模拟试题生成

用户提供科目、题型、难度、数量：

1. 根据考试大纲和历年真题风格生成模拟题
2. 选择题等客观题附带解析（正确/错误选项都解析）
3. 主观题提供评分标准和参考答案要点
4. 标注题目所考察的知识点

### 5. 记忆曲线复习规划

1. 根据艾宾浩斯遗忘曲线设计复习节点：
   - 第1次复习：学习后1小时
   - 第2次复习：学习后1天
   - 第3次复习：学习后3天
   - 第4次复习：学习后7天
   - 第5次复习：学习后15天
   - 第6次复习：学习后30天
2. 每周输出复习清单
3. 标注哪些内容已过记忆节点需要重拾

## 学科策略参考

| 学科类型 | 学习方法 | 记忆侧重 | 练习侧重 |
|---------|---------|---------|---------|
| 文科类（政治/法硕） | 框架+关键词 | 重复背诵 | 论述题 |
| 理科类（数学/物理） | 概念+公式 | 理解推导 | 计算题 |
| 语言类（英语） | 语境+应用 | 高频词句 | 读写听说 |
| 实务类（CPA/法考） | 案例+规则 | 应用场景 | 案例分析 |

## 注意事项

- 模拟试题仅用于辅助练习，不代表实际考试难度
- 学习计划建议根据实际进度灵活调整
- 记忆曲线复习计划需要在日常坚持执行

## 自进化学习系统（越用越好用、越用越高效）

本技能内置通用学习模块 `scripts/learner.py`。每次使用后自动复盘、积累经验，逐步提升输出质量与执行效率，无需人工维护。

### 记忆文件
`learned_patterns.json`（位于本技能目录）记录：操作总数、各能力使用频次、错误模式、用户偏好、改进建议。

### 使用后请调用（Bash）

```bash
# 记录一次成功使用（--capability 填本次主要能力名，如「简历优化」「比价」）
python scripts/learner.py record <本技能目录> --capability 简历优化
# 记录一次失败/异常
python scripts/learner.py record <本技能目录> --capability 简历优化 --fail --error 格式识别失败 --note "用户上传了非标准文件"
# 记录用户偏好（下次直接使用）
python scripts/learner.py prefer <本技能目录> --key 输出语言 --val 中文
# 查看累计洞察（高频能力 / 反复错误）
python scripts/learner.py insight <本技能目录>
# 自动复盘（错误≥3次 或 操作≥10次 时给出改进建议）
python scripts/learner.py reflect <本技能目录>
```

### 迭代规则
- **错误累计 ≥3 次** → 主动增加预检/兜底步骤，并将经验回写本 SKILL.md。
- **操作数 ≥10 次** → 分析高频能力优先打磨示例与质量，低频能力评估精简或合并。
- **重要用户偏好** → 写入 `learned_patterns.json`，下次调用直接采用，减少重复询问。

> 越用越懂你：第一次用是通用能力，第十次用已沉淀为你专属的最佳实践。
