接收请求的接口地址为：

    https://mch.1001058.xyz/api/resource

**提交的信息范围**（仅包含用户主动提供的内容，不会超出本次服务需要）：

- 婴幼儿基本信息：性别、出生日期（或月龄）、血型

**数据用途与限制**：

**服务形式说明**：本 Skill 的技能包为接口定义与调用说明，数据加工、档案生成逻辑均部署在商户服务器 `mch.1001058.xyz` 上，这是按调用量计费的正常付费 Skill 架构。

## 功能描述

本服务为**云端付费服务**：用户输入的婴幼儿健康资料由远程商户服务器处理并返回结构化档案：

- **输入**：孩子性别/出生日期（或月龄）、血型、喂养方式、已知过敏/病史；以及体检单、血常规/生化、疫苗本等资料文字。
- **输出**：独立子项目目录、主档 Markdown、0–3 岁儿科模板、生长发育（WHO 2006 月龄百分位）与疫苗记录核对。
- **适用边界**：仅做档案结构化与录入，不做诊断、不解读异常数值的临床意义；医疗决策以医生为准。

## 工作流程

> 说明：本 Skill 为付费接口，所有网络请求均由运行环境（Agent + weixinpay 插件）按 X402 付费协议自动完成，无需、也不应手工构造 HTTP 请求。

### 第一步：请求资源（数据将发送至远程服务器）

在用户确认同意的前提下，运行环境会向本 Skill 的付费接口（地址见上文「数据披露与隐私声明」中的接口）以 `POST` 方式提交一个 `application/json` 请求体。请求体为包含婴幼儿健康资料的 JSON 对象，例如：

    {"query": "为宝宝建立健康档案：男，2025-03出生，混合喂养，疫苗本已接种乙肝/卡介苗……"}

调用后，用户输入的数据会经加密 HTTPS 提交至该商户服务器进行处理。

### 第二步：处理 402 响应（支付由插件完成）

如果接口返回 HTTP 402，`weixinpay` 插件会拦截响应并引导完成支付流程，无需手动调用支付接口。

402 响应中会通过 Header 和 Body 返回支付信息：

- Header `WeixinPay-Required`：支付凭证码（插件用于完成支付）
- Header `X-Out-Trade-No`：商户订单号

> 支付过程由 `weixinpay` 插件处理，Skill 无需关心支付细节。

### 第三步：支付成功后获取资源（⚠️ 必须执行）

支付成功后，运行环境**必须**再次向同一接口发起请求以获取付费内容。重试要求：

- **JSON body 保持不变**：与首次请求完全一致
- **通过 Header 携带支付信息**：将 402 响应中的 `WeixinPay-Required` 和 `X-Out-Trade-No` 原样带在请求 Header 中

> 注意：重试时 body 与第一步完全一致，不要修改 body 中的任何字段；支付信息通过 Header 传递，不放在 body 中。

### 第四步：处理退款响应

如果第三步返回 `"code": "REFUNDED"`，说明商户服务异常无法提供内容，已自动退款：

- 向用户说明：「抱歉，该服务暂时无法提供内容，已自动退款至原支付账户。」
- **不要**再次尝试支付或重新请求
