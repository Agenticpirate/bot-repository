# 商业计划书生成技能 v2.0

## 技能概述
专业的商业计划书生成工具，采用**精简问答模式**（10-15个核心问题），配合**动态财务模型**和**OPC原创分析框架**，最终**自动生成PPT文件**交付。适用于融资路演、技术转化、市场准入规划、企业战略输出等场景。

### v2.0 核心升级
1. **PPT自动生成**：信息收集完成后，直接调用 `scripts/generate_bp_pptx.py` 生成15页专业PPT
2. **原创分析框架**：新增 OPC-BP可行性雷达 + OPC科创企业估值模型（CIVM）
3. **精简问答**：从30+问题精简到12个核心必填项，配合上下文摘要防止丢失
4. **动态财务**：基于7个参数自动计算3-5年预测，不再使用固定示例

## 第一步：精简问答（12个核心必填项）

### 问答原则
1. **一次不多问**：每轮最多问3-4个相关问题，不堆砌
2. **上次摘要**：每轮开始先展示"已收集信息摘要"（1-2句话），防止上下文丢失
3. **智能推断**：用户已提到的信息自动提取，不重复问
4. **行业基准兜底**：用户不确定的参数，提供行业参考值供选择

### 第一轮：项目基础（4题）

**开场话术**：
> 我来帮您生成一份完整的商业计划书PPT。需要了解12个核心信息，分3轮聊完。先聊最基础的4个：

| # | 问题 | 目的 | 必填 |
|---|------|------|------|
| 1 | 项目名称和一句话描述是什么？ | 确定主体和定位 | 是 |
| 2 | 所在行业/赛道？当前发展阶段？ | 确定分析框架和侧重点 | 是 |
| 3 | 核心产品/服务是什么？解决什么痛点？ | 价值主张 | 是 |
| 4 | 目标市场规模大概多大？（年规模/增速） | 市场分析基础 | 是 |

### 第二轮：商业与财务（5题）

**第二轮开场**（附摘要）：
> 收到！已了解：{项目名}是{行业}的{阶段}项目，做{核心产品}，目标市场约{规模}。接下来聊商业和财务：

| # | 问题 | 目的 | 必填 |
|---|------|------|------|
| 5 | 你的客户是谁？怎么触达他们？ | 客户细分+渠道 | 是 |
| 6 | 怎么赚钱？定价多少？毛利率大概多少？ | 收入模型 | 是 |
| 7 | 预计Y1获客多少？年增长率？续费率？ | 财务预测输入 | 是（不确定可给行业参考） |
| 8 | 主要竞争对手是谁？你比他们强在哪？ | 竞争分析 | 是 |
| 9 | 计划融资多少？估值预期？资金怎么用？ | 融资规划 | 是 |

### 第三轮：团队与风险（3题）

**第三轮开场**（附摘要）：
> 快完成了！已了解：{项目名}面向{客户}，通过{渠道}获客，{收入模式}，Y1预计{获客数}客户，融资{金额}。最后3个问题：

| # | 问题 | 目的 | 必填 |
|---|------|------|------|
| 10 | 核心团队有谁？各自背景？ | 团队介绍 | 是 |
| 11 | 你觉得最大的风险是什么？怎么应对？ | 风险分析 | 是 |
| 12 | 未来6/12/24个月的关键里程碑？ | 里程碑规划 | 是 |

### 可选追问（仅在信息不充分时使用）

| 场景 | 追问 | 触发条件 |
|------|------|---------|
| 技术项目 | 核心技术壁垒是什么？有专利吗？ | 行业=AI/硬科技/芯片 |
| 平台项目 | 双边市场怎么冷启动？ | 商业模式=平台 |
| 消费项目 | 获客成本大概多少？ | 行业=消费/电商 |

## 第二步：内容生成与动态计算

信息收集完成后，AI执行以下计算：

### 2.1 OPC-BP 可行性雷达评估

基于收集的信息，评估五维可行性（详见 [OPC-BP可行性雷达.md](./references/OPC-BP可行性雷达.md)）：

| 维度 | 评分来源 | 输出 |
|------|---------|------|
| 技术可行性 | Q3核心产品+追问技术壁垒 | 1-10分+诊断标签 |
| 商业可行性 | Q5Q6客户+收入模型 | 1-10分+诊断标签 |
| 运营可行性 | Q10团队+发展阶段 | 1-10分+诊断标签 |
| 财务可行性 | Q7Q9获客+融资 | 1-10分+诊断标签 |
| 时机可行性 | Q2行业+Q4市场规模 | 1-10分+诊断标签 |

**综合分级**：A级(8-10) / B级(6-7) / C级(4-5) / D级(1-3)

### 2.2 动态财务预测

基于7个核心参数自动计算（详见 [财务预测模型.md](./references/财务预测模型.md)）：

| 参数 | 来源 | 计算输出 |
|------|------|---------|
| 目标市场规模 | Q4 | TAM/SAM/SOM |
| 可获得市场份额 | 推断 | SOM规模 |
| 客单价 | Q6 | 收入预测 |
| 毛利率 | Q6 | 成本结构 |
| 年增长率 | Q7 | 3-5年预测 |
| 初始客户数 | Q7 | 客户增长曲线 |
| 续费率 | Q7 | LTV/流失率 |

**自动生成**：收入预测表、成本结构表、单位经济模型、盈亏平衡点、敏感性分析

### 2.3 OPC 科创企业估值模型（CIVM）

基于财务预测结果，计算估值区间（详见 [OPC科创企业估值模型.md](./references/OPC科创企业估值模型.md)）：

| 维度 | 评分 | 权重 |
|------|------|------|
| 技术壁垒系数 | 动态 | 25% |
| 市场势能系数 | 动态 | 25% |
| 团队系数 | 动态 | 20% |
| 商业飞轮系数 | 动态 | 20% |
| 退出路径系数 | 动态 | 10% |

**输出**：估值区间 + 五维评分 + 最弱维度 + 改进建议

## 第三步：PPT生成

### 3.1 数据结构化

将所有收集和计算的信息整理为标准JSON格式（见 `scripts/generate_bp_pptx.py` 文件头的数据格式说明）。

### 3.2 调用生成脚本

```bash
python scripts/generate_bp_pptx.py \
  --data bp_data.json \
  --output ./商业计划书.pptx \
  --style tech_blue
```

**风格选择**（4种内置风格）：

| 风格 | 适用场景 | 特征 |
|------|---------|------|
| tech_blue | 科技/AI/互联网 | 深蓝+电光蓝，科技感 |
| elegant_gold | 高端商务/投资路演 | 深色+金色，稳重 |
| clean_green | 消费/健康/教育 | 绿色+清新，亲和 |
| classic_dark | 硬科技/工业/安全 | 暗色+霓虹，硬朗 |

用户未指定时默认 `tech_blue`。

### 3.3 PPT标准结构（15页）

| 页码 | 内容 | 数据来源 |
|------|------|---------|
| 1 | 封面（项目名/行业/轮次/日期） | Q1+Q2+Q9 |
| 2 | 执行摘要（痛点/方案/市场/团队/融资） | 全局摘要 |
| 3 | 问题与痛点（2-4个痛点卡片） | Q3 |
| 4 | 解决方案与差异化优势 | Q3+Q8 |
| 5 | 市场规模（TAM/SAM/SOM三层） | Q4+动态计算 |
| 6 | 竞争格局分析表 | Q8 |
| 7 | 可行性分析 & OPC-BP雷达 | 动态评估 |
| 8 | 商业模式画布（9格） | Q5+Q6 |
| 9 | 3-5年财务预测表 | 动态计算 |
| 10 | 单位经济 & 融资规划 | Q7+Q9+动态 |
| 11 | 核心团队 | Q10 |
| 12 | 发展里程碑（时间轴） | Q12 |
| 13 | 风险分析与应对策略 | Q11 |
| 14 | OPC科创企业估值模型 | CIVM动态 |
| 15 | 结尾页（联系方式） | 用户信息 |

### 3.4 生成后验证清单

- [ ] 文件存在且大小>10KB
- [ ] 页数=15页（±2页可接受）
- [ ] 封面信息完整（项目名/行业/日期）
- [ ] 财务表格有数据（非空白）
- [ ] 无乱码字符
- [ ] 可行性雷达页有五维评分
- [ ] 估值页有估值区间

## 五大模块内容规范

### 模块一：市场分析
- 市场规模测算（TAM/SAM/SOM）→ 基于 Q4 动态计算
- 竞争格局分析 → 基于 Q8
- 目标客户画像 → 基于 Q5
- 市场进入策略 → 基于 Q5+Q6

### 模块二：可行性分析
- 使用 **OPC-BP可行性雷达** 五维评估（原创框架）
- 每维输出评分+诊断标签+改进建议
- 综合分级：A/B/C/D

### 模块三：财务分析（动态计算）
- 收入预测（3-5年）→ 基于 Q7 动态计算
- 成本结构分析 → 基于毛利率+阶段费用率
- 单位经济模型（LTV/CAC/Payback）→ 动态计算
- 盈亏平衡点 → 动态计算
- 敏感性分析 → 自动生成

### 模块四：人财物分析
- 核心团队介绍 → 基于 Q10
- 融资规划 → 基于 Q9
- 里程碑规划 → 基于 Q12

### 模块五：风控分析
- 风险识别与应对 → 基于 Q11
- 使用 OPC-BP雷达最弱维度作为最高优先级风险
- 补充行业通用风险类型（参见 [风险分析框架.md](./references/风险分析框架.md)）
