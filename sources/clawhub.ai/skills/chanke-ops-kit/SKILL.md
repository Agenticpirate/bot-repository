# 天津坤如玛丽妇产医院·产科 - 多方位运营资料生成技能

## 概述

本技能基于天津坤如玛丽妇产医院产科的完整公司画像，自动生成12类多方位运营资料。所有内容严格遵循品牌核心理念"科学定制方案，不盲目不夸张"，围绕"顺剖都不疼，孕产舒适又安心"的核心价值主张，确保专业、温暖、有温度的品牌形象一致性。

## 参考文件体系

生成任何内容前，必须依次加载以下参考文件：

| 文件 | 用途 | 加载时机 |
|------|------|---------|
| `references/company_profile.md` | 公司画像核心数据源（基础信息、核心数据、十五大理由、AI超声技术、疼痛管理体系、团队、案例库、评价、科普知识） | 每次生成内容前必读 |
| `references/content_templates.md` | 12类运营资料的模板结构与规范 | 根据用户请求的内容类型，读取对应模板章节 |
| `references/brand_voice.md` | 品牌语调、写作红线、词汇表、合规规范 | 每次生成内容前必读 |

### 检索提示
- `company_profile.md` 较长，如需定位特定信息，使用关键词搜索：搜索"十五大理由"定位分娩优势，搜索"AI超声"定位技术亮点，搜索"疼痛管理"定位顺剖不疼体系，搜索"案例"定位案例库
- `content_templates.md` 按内容类型编号（1-12），可直接搜索编号定位
- `brand_voice.md` 搜索"红线"定位写作禁忌，搜索"词汇"定位用词规范

## 内容生成工作流

### 步骤一：识别需求

根据用户请求，判断所需内容类型：

| 用户表达 | 对应内容类型 | 模板编号 |
|---------|------------|---------|
| "写品牌介绍""产科简介""关于我们" | 品牌介绍文案 | 1 |
| "写朋友圈""发朋友圈""朋友圈素材" | 朋友圈文案集 | 2 |
| "写小红书""种草文案""小红书内容" | 小红书种草文案 | 3 |
| "写公众号文章""推文""深度内容" | 公众号文章 | 4 |
| "短视频脚本""抖音文案""视频号内容" | 短视频脚本 | 5 |
| "包装案例""案例展示""成功案例" | 客户案例包装 | 6 |
| "话术""客服回复""销售话术" | 销售/客服话术 | 7 |
| "活动方案""直播策划""孕妈课堂" | 活动策划方案 | 8 |
| "海报文案""宣传语""海报文字" | 海报文案 | 9 |
| "医生IP""产科专家人设""个人品牌" | 医生IP人设内容 | 10 |
| "社群内容""群运营""微信群内容" | 社群运营内容 | 11 |
| "新闻稿""通稿""媒体稿件" | 新闻通稿/媒体稿件 | 12 |
| "全套运营资料""多方位资料" | 批量生成（按需组合1-12） | 多个 |

### 步骤二：加载参考文件

1. 始终加载 `references/brand_voice.md`（品牌语调规范）
2. 始终加载 `references/company_profile.md`（公司画像数据源）
3. 根据步骤一识别的类型，加载 `references/content_templates.md` 中对应编号的模板章节

### 步骤三：提取素材

从 `company_profile.md` 中提取与请求相关的素材：
- 需要分娩优势时，从"十五大理由"章节提取
- 需要技术亮点时，从"AI超声技术"章节提取
- 需要疼痛管理时，从"顺剖都不疼"章节提取
- 需要案例时，从"客户案例库"章节选取合适案例
- 需要团队信息时，从"团队架构"章节提取
- 需要科普内容时，从"科普知识储备"章节提取

### 步骤四：按模板生成

1. 严格遵循 `content_templates.md` 中对应模板的结构
2. 严格遵守 `brand_voice.md` 中的语调指南和写作红线
3. 所有数据引用必须来自 `company_profile.md`，不可编造
4. 案例必须化名处理，保护患者隐私

### 步骤五：自检

生成内容后，执行以下检查：
- [ ] 是否包含绝对化承诺？（禁止"包不疼""一定能"等）
- [ ] 是否有点名批评同行？（禁止提及具体医院/医生名）
- [ ] 是否包含具体药物名称和剂量？（科普内容中禁止）
- [ ] 案例是否已化名处理？
- [ ] 数据是否来自画像资料库？
- [ ] 品牌理念"科学定制方案，不盲目不夸张"是否自然融入？
- [ ] 语调是否符合 `brand_voice.md` 的场景要求？

如发现问题，修正后再输出。

## 批量生成模式

当用户请求"全套运营资料""多方位资料"时，按以下优先级顺序生成：

1. **品牌基础**：品牌介绍文案（短版）→ 品牌介绍文案（长版）
2. **社交媒体**：朋友圈文案集（10条）→ 小红书种草文案（3篇）→ 公众号文章（1篇）
3. **视频内容**：短视频脚本（3条，不同方向）
4. **销售支持**：客户案例包装（3个精选）→ 销售/客服话术（6个场景）
5. **运营支持**：社群运营内容（1周排期）→ 海报文案（5张）
6. **品牌升级**：医生IP人设内容（1套）→ 新闻通稿（1篇）

每类内容生成后，以Markdown标题分隔，便于用户复制使用。

## 内容输出格式

- 所有内容以Markdown格式输出
- 每类内容开头标注类型名称和适用场景
- 案例标注来源（"选自案例库案例X"）
- 数据标注来源（"来自产科2025年度数据"）
- 如内容需用户进一步确认的信息，以 `[待确认：XXX]` 标注
