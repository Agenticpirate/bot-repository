# ISO14001:2026 环境管理体系策划

## 任务目标

本 Skill 用于帮助用户策划和建立符合 **ISO14001:2026版** 要求的环境管理体系(EMS)，并提供管理体系文件的编撰指导。

## 启动条件

**首次使用必须收集以下信息**（通过交互式提问获取）：

| 信息项 | 用途 | 追问方式 |
|--------|------|----------|
| 行业类型 | 确定适用法规和行业标准 | "请描述你们所在的行业（如：制造业/建筑业/服务业/其他）" |
| 组织规模 | 确定体系文件层级和复杂程度 | "你们大约有多少员工？" |
| 主要环境活动 | 确定环境因素识别范围 | "运营中涉及哪些环境相关活动？" |
| 主要污染类型 | 确定重点管控对象 | "可能产生哪些环境影响？" |
| 现有体系状况 | 确定从零创建或升级 | "是否已有ISO14001认证？" |

**重要**：若用户拒绝提供信息，使用通用版框架，明确标注需用户自行调整的部分。

## 核心策划流程

### 第一步：确定组织基本信息

收集并确认：
- 组织名称（用于文件编制）
- 所属行业及特点
- 地理位置与运营场所数量
- 员工人数
- 主要业务流程

### 第二步：环境因素识别（ISO14001:2026 第6.1.2条）

**智能体需指导用户完成：**

1. **识别范围界定**
   - 确定体系覆盖的活动、产品、服务
   - 明确与环境的接口

2. **环境因素识别方法**
   - 生命周期视角：原材料采购 → 生产 → 使用 → 报废
   - 三种状态：正常、异常、紧急
   - 三种时态：过去、现在、将来

3. **重大环境因素判定**
   - 使用矩阵法或评分法
   - 考虑：法律法规要求、环境影响程度、利益相关方关注

**输出**：环境因素清单（包含重大环境因素清单）

### 第三步：法律法规合规性评价（ISO14001:2026 第6.1.3条）

**智能体需指导用户：**

1. **识别适用法规**
   - 国家法律法规
   - 地方性法规
   - 行业标准规范
   - 许可/执照要求

2. **合规性评价方法**
   - 条目对照法
   - 符合/不符合判定
   - 证据收集

**输出**：适用法律法规清单、合规性评价报告

### 第四步：环境方针制定（ISO14001:2026 第5.2条）

**环境方针必须包含：**
- 保护环境的承诺
- 污染预防的承诺
- 持续改进的承诺
- 符合适用法律法规的承诺
- 提供建立和评审环境目标的框架

**智能体应根据行业特点生成定制化方针示例**

### 第五步：策划（ISO14001:2026 第6条）

**编制环境管理方案：**
- 明确目标和指标
- 确定责任部门/岗位
- 设定完成时限
- 配置资源需求
- 制定监测评价机制

### 第六步：实施与运行（ISO14001:2026 第7-8条）

**核心要素：**
- 资源、角色、责任与权限
- 能力、培训与意识
- 信息交流与沟通
- 文件化信息控制
- 运行控制
- 应急准备与响应
- 采购控制

### 第七步：检查与纠正措施（ISO14001:2026 第9条）

**监视测量：**
- 绩效指标设定
- 监测设备校准
- 合规性评价（定期）
- 不符合项调查与处置
- 纠正措施跟踪

### 第八步：管理评审（ISO14001:2026 第9.3条）

**管理评审输入：**
- 内部审核结果
- 合规性评价结果
- 投诉与建议
- 目标和指标达成情况

**管理评审输出：**
- 改进决定
- 资源需求
- 目标调整

## 行业定制要点

### 制造业
- 重点：废水/废气/固废处理设施运行控制
- 关注：危险化学品管理、清洁生产
- 特定法规：排污许可证、总量控制

### 建筑业
- 重点：施工现场环境管理
- 关注：扬尘/噪声/废水控制
- 特定法规：施工扬尘防治要求

### 服务业
- 重点：能源资源消耗、办公场所环境
- 关注：办公垃圾分类、绿色采购
- 特定法规：公共机构节能要求

### 餐饮业
- 重点：油烟排放、餐厨垃圾
- 关注：隔油池运维、油烟净化设施
- 特定法规：餐饮业油烟排放标准

## 注意事项

- 首次必须收集用户组织信息，未收集前仅提供通用框架
- ISO14001:2026版相较2015版的主要变化需同步更新
- 文件编制应符合组织实际，避免形式主义
- 重大环境因素应控制在合理数量（建议不超过20项）
- 变更记录：V1.1.0：完善 TRACE 五维度测评体系，补充触发条件、能力边界、异常处理与 TRACE 自评表

## 能力边界

- **适用场景**：环境管理体系（EMS）策划、环境因素识别与评价场景
- **不适配场景**：法律法规正式解释、专业认证替代、涉及人身安全的紧急决策
- **输入要求**：需提供清晰的ISO14001:2026 环境管理体系策划背景信息和要求描述


## 异常处理

- **输入不完整**：提示用户补充缺失的关键信息，列出必需字段，引导用户逐步完善输入
- **依赖缺失**：检测依赖环境（Python库、系统工具），给出明确的安装指令和验证方法
- **执行失败**：输出清晰的错误信息和可能的原因，提供降级方案（如无法生成 PNG 则输出 SVG）
- **结果验证**：输出完成后提供校验方法，建议用户确认关键内容的准确性
