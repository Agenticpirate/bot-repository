# 二次元漫画生成技能

## 功能说明

本技能使用 Tabbit Agent 的 `image_generate` 工具，专业生成二次元/动漫风格的图像内容。

### 核心能力

- **角色生成**: 根据文字描述生成二次元角色立绘、头像、全身像
- **场景绘制**: 生成动漫风格的背景场景、室内外环境
- **分镜创作**: 批量生成漫画分镜、故事板
- **风格一致性**: 保持多张图像之间的角色/风格一致性
- **表情/姿势**: 生成不同表情、动作、服装的角色变体

## 使用方法

### 基础用法

直接描述你想要的二次元图像内容：

```
生成一个蓝发双马尾的二次元少女，穿着校服，站在樱花树下，春日午后，温暖的光影
```

### 高级参数控制

在描述中包含以下元素以获得更精准的结果：

**角色特征**
- 发型/发色：长发、短发、双马尾、呆毛、渐变发色
- 眼睛：瞳色、眼型（大眼、细长眼）、眼神
- 服装：校服、和服、洛丽塔、战斗服、日常装
- 年龄气质：萝莉、少女、御姐、正太

**画面风格**
- 画风：赛璐璐、厚涂、水彩、像素风、低多边形
- 色调：明亮、暗黑、暖色、冷色、高饱和
- 光影：逆光、侧光、柔光、戏剧性光影

**构图视角**
- 景别：特写、半身、全身、群像
- 角度：平视、俯视、仰视、45 度角
- 背景：虚化、详细场景、纯色背景

### 批量生成

一次性生成系列图像：

```
生成同一角色的 3 张不同表情：开心、害羞、生气。保持角色特征一致：粉色长发、绿色眼睛、女仆装
```

## 输出示例

### 输入
```
创建一个奇幻风格的精灵弓箭手，银色长发尖耳朵，穿着绿色皮甲，手持长弓，站在森林中，阳光透过树叶洒下斑驳光影，吉卜力风格
```

### 预期输出
- 高质量二次元风格图像
- 符合描述的精灵角色
- 自然环境背景
- 专业光影效果

## 提示词优化建议

### ✅ 好的提示词
- 具体描述角色外貌特征（发型、瞳色、服装）
- 指定画面风格和氛围
- 包含光影和环境细节
- 明确构图和视角

### ❌ 避免模糊描述
- 过于抽象的概念
- 缺少关键视觉信息
- 矛盾的风格要求

## 进阶技巧

### 1. 角色一致性

生成同一角色的多张图像时，使用固定描述模板：

```
【角色固定】白色短发、红色眼睛、黑色风衣、围巾
【变化元素】不同场景/表情/动作
```

### 2. 分镜生成

按顺序描述多个场景：

```
四格漫画分镜：
1. 角色惊讶表情的特写
2. 角色转身的背影
3. 角色奔跑的侧面
4. 角色微笑的正面
保持角色设计一致
```

### 3. 风格参考

可以指定知名作品风格作为参考：

```
新海诚风格的天空背景，细腻的云层和光影
吉卜力风格的森林场景，充满生机的绿色调
```

## 失败处理

- 如果生成结果不符合预期，尝试增加更多视觉细节描述
- 如果风格不一致，明确指出参考风格或添加风格关键词
- 如果角色特征丢失，在描述中重复关键特征词
- 对于复杂场景，可以先生成主体，再生成背景后合成

## 注意事项

- 本技能仅生成二次元/动漫风格图像
- 不支持真实人像生成
- 请遵守平台内容规范，不生成违规内容
- 生成的图像仅供个人学习和创作参考
