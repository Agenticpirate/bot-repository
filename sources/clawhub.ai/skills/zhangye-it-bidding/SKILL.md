# 张掖信息化标讯搜索

从互联网搜索张掖市当月信息化相关招标公告，提取关键字段后逐条写入指定 Excel 文件。

## 工作流程

### 1. 确认搜索范围

- 时间范围：当月1日至今日
- 地域范围：张掖市（含甘州区、临泽县、高台县、山丹县、民乐县、肃南县）
- 项目范围：信息化宽口径（详见筛选标准）

### 2. 平台搜索

按优先级依次搜索以下平台，每个平台均需筛选"张掖市"+"当月"：

1. **甘肃省公共资源交易网**（ggzyjy.gansu.gov.cn）— 省级主平台
2. **张掖市公共资源交易中心**（ggzy.zhangye.gov.cn）— 市级直达
3. **甘肃政府采购网**（ccgp-gansu.gov.cn）— 省级采购
4. **中国政府采购网**（ccgp.gov.cn）— 全国范围按地域筛选
5. **全国公共资源交易平台**（ggzy.gov.cn）— 全国汇总

对每个平台：进入交易公告/招标公告栏目 → 地区选张掖 → 时间选当月 → 用核心关键词逐一搜索。

### 3. 搜索引擎补充

使用在线搜索工具，关键词组合示例：

```
张掖 信息化 招标公告 {当月年份}年{当月月份}月
张掖市 政府 采购 IT 软件 网络 招标
张掖 智慧 数字化 数据中心 招标公告
```

逐一访问搜索结果，提取有效公告信息。

### 4. 筛选与去重

**筛选标准**（宽口径，满足任一即纳入）：

- **核心词**：信息化、信息系统、数字化、智慧、智能化、电子政务
- **技术词**：软件、硬件、网络、安全、数据中心、云计算、大数据、物联网、5G
- **设备词**：服务器、交换机、路由器、防火墙、存储、UPS、机房、终端、电脑
- **系统词**：OA、ERP、GIS、一网通办、政务服务平台、数字政府

**排除**：纯土建/装修/绿化、医疗器械/教学器材、后勤服务类项目。

**去重**：按项目编号+项目名称与 Excel 已有记录比对，跳过已录入项目。

### 5. 信息提取

对每条有效公告提取以下字段（详细映射见 [references/bidding_sources.md](references/bidding_sources.md)）：

| 字段 | 必填 | 来源 |
|------|------|------|
| 项目名称 | 是 | 公告标题 |
| 项目编号 | 否 | 公告正文 |
| 招标方式 | 是 | 公告正文 |
| 采购单位名称 | 是 | 公告正文 |
| 采购单位联系人及联系电话 | 否 | 公告正文 |
| 代理公司 | 否 | 公告正文 |
| 代理公司联系人及联系电话 | 否 | 公告正文 |
| 项目金额 | 否 | 公告正文（标注万元/元） |
| 项目标的 | 否 | 公告正文 |
| 项目主要采购内容 | 否 | 公告正文摘要 |
| 招标公告发布日期 | 是 | 公告日期 |
| 开标日期 | 否 | 公告正文 |
| 开标地点 | 否 | 公告正文 |
| 备注 | 否 | 搜索附加信息 |

### 6. 逐条写入 Excel

1. 使用 openpyxl 打开目标 Excel 文件
2. 找到已有数据末尾行（序号列最大值+1）
3. **逐条**追加新记录（每条公告一行），序号自动递增
4. 日期格式统一为 `YYYY-MM-DD`
5. 金额格式：数字+单位（如"50万元"），未公开填"未公开"
6. 联系人+电话写在一个单元格，格式"姓名 电话号码"
7. 保存文件

## 目标文件

默认路径：`C:\Users\Administrator\.local\share\TeleAgent\TeleAgent的工作空间\张掖市信息化项目标讯.xlsx`

Excel 模板结构：
- 第1行：标题"张掖市信息化项目标讯"（合并A1:N1）
- 第2行：空行
- 第3行：表头（序号、项目名称、项目编号、招标方式、采购单位名称、采购单位联系人及联系电话、代理公司、代理公司联系人及联系电话、项目金额、项目标的、项目主要采购内容、招标公告发布日期、开标日期、开标地点、备注）
- 第4行起：数据行

## 注意事项

- 搜索时如遇到平台无法访问，跳过并记录，继续搜索其他来源
- 公告信息不完整时，已有字段如实填写，空缺字段留空
- 每次执行完毕后，输出统计：搜索平台数、发现公告数、有效信息化项目数、新增录入数、跳过（已存在）数
