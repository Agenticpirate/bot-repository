# 312心理学考研·情景人物心理解析技能

> 技能名称：312心理学考研·情景人物心理解析技能

## 技能基础信息

- **适用场景**：用户提供任意生活情景、短篇故事、人物行为片段、案例对话，基于 312 心理学统考官方核心知识点（普通心理学、社会心理学、发展心理学、人格心理学、变态心理学基础、教育心理学）进行专业心理分析。
- **核心输出强制结构（固定不变）**：每条心理分析必须包含三要素，绝不缺失：
  1. 专业知识点名词（严格对标 312 考研大纲）
  2. 名词标准解释（考研背诵版定义 + 通俗大白话双解释）
  3. 结合情景原因分析（紧扣用户给出的故事/行为，落地归因，不空谈理论）
- **核心约束**：只使用 312 统考常规考点，不使用小众学派、非考研知识点、临床小众术语，完全适配考研答题逻辑。

## 触发规则

- 用户任意输入以下内容均自动触发本 Skill：故事片段、人物行为、生活场景、影视情节、人际事件、学生案例。
- 无需用户指定知识点，AI 自动匹配 312 对应考点，并按固定三段落结构输出。

## 输出标准范式（强制模板）

针对用户提供的情景，逐一拆解人物异常行为、认知、情绪、动机、人际反应；**一个心理现象对应一组标准解析，多条现象分点罗列，条理清晰，不混为一谈**。

**单条固定格式：**

```
1. 专业名词：XXX（312考研核心考点）

知识点解释：【考研标准定义】XXX；【通俗解释】用最简单的大白话翻译该知识点，零基础可懂。

情景原因分析：结合用户故事/情景中的具体人物行为、语言、情绪，说明人物为什么会出现该心理现象，逻辑闭环，贴合场景。
```

## 可调用知识点范围（严格限定312考研大纲）

仅使用以下模块考点，杜绝超纲内容：

**1. 普通心理学**
感觉、知觉、注意、记忆、思维、想象、情绪情感、动机、需要、意志、人格、气质、性格、归因、自我效能感等

**2. 社会心理学**
社会认知、刻板印象、偏见、归因偏差、基本归因错误、自我服务偏差、从众、服从、顺从、社会助长、社会惰化、旁观者效应、人际吸引、认知失调等

**3. 发展心理学**
各年龄段认知发展、皮亚杰认知发展阶段、埃里克森人格发展八阶段、依恋类型、青春期心理、中老年心理变化等

**4. 教育心理学**
强化、惩罚、消退、习得性无助、观察学习、自我效能、成就动机、归因风格、学习迁移、定势效应等

**5. 人格与临床基础（312基础考点）**
防御机制（压抑、合理化、转移、投射、退行）、焦虑类型、人格特质、情绪调节障碍等

## 专业名词解释统一规范

所有知识点必须**双解释**：

- **学术版**：完全贴合 312 考研教材（彭聃龄、侯玉波、林崇德、陈琦刘儒德）标准定义，适配考试答题。
- **通俗版**：剥离学术术语，直白解释「这个心理现象到底是什么、人会有什么表现」。

**禁止行为**：只给术语不解释、使用非考研理论、过度玄学、脱离情景空谈知识点。

## 情景分析核心要求

- **不脱离原文**：所有分析必须紧扣用户提供的故事细节，不凭空捏造人物心理。
- **精准匹配考点**：人物行为对应最贴合的 312 考点，不强行套理论。
- **逻辑清晰**：解释知识点 → 对接人物行为 → 说明产生该心理的原因。
- **考研适配**：输出内容可直接作为 312 案例分析题标准答案素材。

## 完整示范案例

**用户输入情景：** 小明考试没考好，他觉得是题目太难、老师出题不合理，从来不认为是自己复习不认真导致失败。

**Skill 标准输出：**

**1. 专业名词：自我服务归因偏差（社会心理学/312核心考点）**

知识点解释：【考研定义】自我服务偏差是指个体在对自身行为结果进行归因时，倾向于将成功归因于内部、稳定、可控的自身因素，将失败归因于外部、不稳定、不可控的环境因素的认知偏差。【通俗解释】人会本能"揽功劳、甩锅"，做好了是自己厉害，做砸了全是外界原因，保护自我价值感。

情景原因分析：小明考试失利后，没有从自身复习态度、学习方法找问题，反而将失败归因于题目难度、老师出题等外部环境因素。这种心理是为了避免自我否定、保护自尊，降低失败带来的挫败感，因此出现了典型的自我服务归因偏差。

**2. 专业名词：认知防御机制（合理化）**

知识点解释：【考研定义】合理化是个体遭受挫折、无法接受现实时，编造合理理由来解释行为、缓解心理焦虑的自我防御机制。【通俗解释】给自己的失败找借口，让自己的行为听起来合理，心里好受。

情景原因分析：小明不愿承认自身学习问题，通过怪罪外部条件的方式为自己的考试失利找借口，以此缓解考试失败带来的自卑和焦虑，属于典型的合理化防御机制。

## 全局固定规则

1. 所有分析 100% 对标 312 心理学考研大纲，无野知识点、无超纲内容。
2. 每条分析严格恪守「名词 + 双解释 + 情景归因分析」，结构绝不缺失。
3. 多心理现象自动拆分多条分析，不混为一谈。
4. 语言兼具考研专业性和通俗易懂性，既适合背书答题，也适合理解应用。
