# Paper Doctor — 论文诊断与润色专家

像一位经验丰富的审稿人 + 论文润色编辑，对你的论文草稿进行全面诊断，
从 8 个维度给出结构性、逻辑性、语言性和格式性的改进建议。

## 核心理念

> 审稿人被拒的原因，70% 在投稿前就可以自己发现。

Paper Doctor 不是帮你写论文，而是帮你**发现你自己发现不了的问题**。

## 用法

```
@paper-doctor paper.pdf                         → 全面诊断
@paper-doctor draft.tex                          → LaTeX 源文件分析
@paper-doctor manuscript.md                      → Markdown 格式分析
@paper-doctor paper.pdf --depth deep --venue iclr  → 指定 ICLR 标准的深度检查
@paper-doctor section3.tex --scope section       → 只检查一个章节
```

## 8 维诊断体系

### 🏗️ 维度 1: 结构完整性

检查 IMRaD 结构是否完整、逻辑流是否通畅、章节长度是否均衡、标题层级是否合理。

**常见问题标记：**
- ⚠️ 缺少相关工作/相关工作太短
- ⚠️ 结论缺少讨论/局限性
- ⚠️ 方法论与结果之间逻辑断层

### 📖 维度 2: 引言质量

检查漏斗式展开（广泛背景→具体问题→本文贡献）、动机清晰度、相关工作覆盖、
研究差距是否明确、贡献陈述是否清晰。

**关键指标：** "三步测试"——读完引言前三段，能否知道这篇论文要解决什么问题？

### 🔬 维度 3: 方法严谨性

检查可复现性（是否有足够细节）、假设明确性、与现有工作的区分度、
局限性是否讨论、核心方法是否有形式化描述。

### 📊 维度 4: 实验与结果

| 检查项 | 说明 |
|--------|------|
| 基线选择 | 是否选择了当前最先进的基线方法 |
| 数据集充分性 | 数据集规模、来源、多样性 |
| 指标合理性 | 评估指标是否全面 |
| 统计显著性 | 是否有误差线、置信区间、显著性检验 |
| 消融实验 | 是否有消融分析验证各组件贡献 |
| 超参数透明 | 超参数、实验环境是否报告 |

### 📝 维度 5: 写作与语言

检查语法与拼写、措辞精确性、时态一致性、被动/主动语态平衡、
可读性（句子长度/复杂度）、术语一致性。

### 📚 维度 6: 参考文献

| 检查项 | 说明 |
|--------|------|
| 覆盖充分性 | 重要相关工作的引用是否完整 |
| 时效性 | 是否有足够的新近文献（近 2-3 年） |
| 格式一致性 | 引用格式是否统一 |
| 遗漏引用 | 疑似丢失的关键论文（可选联网搜索） |

### 🎨 维度 7: 图表与排版

检查图表质量、图表必要性、图表是否有正文引用、模板合规性、
页数限制是否在目标期刊/会议要求内。

### 🎯 维度 8: 投稿匹配度

评估论文贡献是否匹配目标 Venue 的范围和水平。

## 可选参数

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `--depth` | 检查深度: quick / standard / deep | standard |
| `--venue` | 目标期刊/会议，如 iclr, neurips, cvpr, nature | auto |
| `--scope` | 范围: full / abstract / intro / method / experiment / conclusion | full |
| `--output` | 报告格式: text / markdown / json | markdown |
| `--fix-language` | 是否自动润色语言 | true |
| `--internet` | 是否联网搜索补充引用 | false |
| `--strict` | 是否使用严格模式（顶刊标准） | false |

## 交互式深度诊断

用户可以对某个具体维度深入追问：

```
用户: 帮我详细看看实验部分的问题
→ Paper Doctor 展开实验评估：
  - 数据集规模是否足够
  - 基线选择是否公正
  - 是否有 p-hacking 嫌疑
  - 建议补充的实验
```

```
用户: 帮我检查引用，有没有漏掉重要相关工作
→ 提取关键词，联网搜索相关文献
→ 比对引用列表，识别缺失的关键论文
```

## 自助修复

- **语言润色:** 对有语法问题的段落，给出修改版本
- **结构重组:** 对逻辑混乱的章节，提出重新组织方案
- **补全参考文献格式:** 自动规范化为目标模板格式
- **图表标注:** 给出图表标题和描述的改进方案

## 与 paper2slides 配合

Paper Doctor 完善论文后，用 paper2slides 生成汇报幻灯片 ——
从写作→评审→汇报的完整学术工作流。

## 注意事项

- 诊断建议基于模式和规则分析，不能替代真正的审稿人
- 语言润色建议需要人工验证
- 联网搜索需要用户明确启用（`--internet`）
- 建议在完成论文初稿后使用，而不是写作过程中频繁使用
- 数学公式密集的论文，诊断精度受限于 PDF 解析质量
