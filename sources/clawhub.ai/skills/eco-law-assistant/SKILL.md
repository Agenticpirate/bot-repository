# Skill: eco-law-assistant (生态环保法典普法与合规助手)

## 概述

基于《中华人民共和国生态环境法典》（2026年3月12日通过，2026年8月15日施行）全文1242条构建的智能问答与合规预检技能。法典原文来源于生态环境部官方发布（https://www.mee.gov.cn/ywgz/fgbz/fl/202603/t20260313_1146496.shtml），共5编1242条，整合30多部单行法，施行后环境保护法等10部法律同步废止。

## 何时使用

当用户提出以下类型的问题时触发本技能：

1. **法典条款查询**："法典第X条是什么？""双罚制怎么规定的？""生态环境损害赔偿制度是什么？"
2. **场景化法律咨询**："企业排放废水超标怎么处罚？""环评造假有什么后果？""排污许可证怎么管理？"
3. **合规预检**："我们企业需要做哪些环保合规检查？""双罚制下法人代表有什么风险？"
4. **新旧法律衔接**："法典施行后哪些法律废止了？""原来水污染防治法的内容在法典哪里？"
5. **法典结构查询**："法典一共几编？""污染防治编有哪些章节？""绿色低碳发展编讲了什么？"

不触发：与生态环境法典无关的通用法律咨询、其他法律领域的问题。

## 执行入口

所有查询必须执行 `python3 scripts/query.py`，不得绕过脚本直接读取JSON。

```
python3 scripts/query.py <action> [params]
```

### 支持的 action：

| action | 参数 | 功能 |
|--------|------|------|
| `search` | `<keyword>` | 关键词检索法典条款，返回匹配的条款列表 |
| `article` | `<number>` | 按条款编号查询（如 `article 15` 查询第十五条） |
| `structure` | (无) | 输出法典五编章节结构概览 |
| `bian` | `<bian_name>` | 按编查询（如 `bian 总则` 或 `bian 污染防治`） |
| `chapter` | `<keyword>` | 按章节关键词查询（如 `chapter 排污许可`） |
| `compliance` | `<industry>` | 企业合规预检：根据行业类型输出合规检查清单 |
| `abolished` | (无) | 查询法典施行后废止的10部法律清单 |
| `hotspot` | (无) | 输出法典核心热点条款（双罚制、损害赔偿、行刑衔接等） |
| `subject` | `<name>` | 按主体视角查询权责义务（国家/政府/部门/企事业单位/社会组织/个人） |
| `commentary` | `<id|keyword>` | 查询王灿发教授法典解读（`list` 查看全部目录） |
| `book` | (无) | 显示《生态环境法典:主体责任及权利义务全指引》书籍信息 |

### 使用示例：

```bash
# 查询第十五条（全国生态日）
python3 scripts/query.py article 15

# 关键词搜索"双罚"
python3 scripts/query.py search "双罚"

# 查看法典结构
python3 scripts/query.py structure

# 查询污染防治编的排污许可章节
python3 scripts/query.py chapter "排污许可"

# 企业合规预检（化工行业）
python3 scripts/query.py compliance "化工"

# 查看废止法律清单
python3 scripts/query.py abolished

# 查看法典热点条款
python3 scripts/query.py hotspot

# 按主体视角查询权责义务（企业）
python3 scripts/query.py subject "企事业单位"

# 查看王灿发教授法典解读目录
python3 scripts/query.py commentary list

# 查询"五统一"职能解读
python3 scripts/query.py commentary five_unified

# 查询绿色低碳发展独立成编解读
python3 scripts/query.py commentary green_low_carbon

# 显示书籍信息
python3 scripts/query.py book
```

## 数据来源

- 法典全文：生态环境部官网 https://www.mee.gov.cn/ywgz/fgbz/fl/202603/t20260313_1146496.shtml
- 采集日期：2026年8月3日
- 结构化处理：按条款分割为1249条（含附则内部引用条款），每条包含编/分编/章/节/条款号/条款全文

### 解读知识库来源

- **书籍**：《生态环境法典:主体责任及权利义务全指引》，王灿发主编，中国法治出版社，2026年4月，ISBN 9787521660043，517页
  - 按六大主体（国家、各级政府、政府部门、企事业单位、社会组织、个人）分类梳理职能、权力、权利、义务与责任
  - 实现从"查法条"到"查责任"的转变
- **王灿发教授公网解读**（已结构化收录15篇）：
  - 《中国法治》2026年第5期——"五统一"职能专论
  - 红星新闻专访（2026年3月）——法典编纂意义、绿色低碳发展独立成编、民生导向、责任体系、前瞻性
  - 大连海事大学讲座（2026年6月9日）——环境法对传统法律学科的突破、法典现存待完善之处
  - 东北林业大学讲座（2026年6月11日）——法典落地实施关键要点
  - 《生态环境法典》专家公益大讲堂第四期（法治时代杂志）——污染防治编主要内容和实施要点
  - 澎湃新闻——媒体多维度解读
  - 陕西省司法厅——公益大讲堂六位专家分编主讲信息

## 展示要求

- 查询结果必须标注法典条款编号和所属编章节
- 条款引用必须附原文，不得改写或省略
- 合规预检结果必须标注"AI辅助参考，最终以法典原文为准"
- 涉及处罚条款的，必须同时引用对应的法律责任编条款
- 解读内容引用时须标注来源（作者、出处、原文链接）
- 解读内容为专家观点参考，不具备法律效力，正式文书须引用法典原文条款号
