# VC 尽职调查与投资决策（Diligence & Decision）

## 目的
把 VC 流水线的「尽职调查 → 投资决策」环节标准化：针对项目产出**五维尽调清单**、**三档情景估值模型**、**IC 投委会 Memo**，所有产出带引用、可回溯，关键节点保留人工决策（HITL）。

## 何时使用
- 用户要求对某个项目做尽调（清单/风险核查）。
- 用户要求估值建模（可比公司 / DCF / 情景分析）。
- 用户要求撰写 IC Memo 或投资推荐。
- 用于 ima 知识号「尽调与投决」系列内容。

## 核心方法论

### A. 五维尽调清单（Due Diligence）
| 维度 | 关键核查项 |
|------|-----------|
| 团队与组织 | 创始人背景与互补性；核心人员持股与激励；组织扩张与关键岗位 |
| 市场与竞争 | 赛道空间与增速验证；竞品格局与差异化壁垒；客户访谈与付费意愿 |
| 技术与产品 | 技术原理与可验证性；知识产权与 FTO；量产/工程化能力与良率 |
| 法务与合规 | 股权结构与历史融资清理；重大合同与关联交易；数据合规与监管许可 |
| 财务与税务 | 历史财报与审计；单位经济与现金流质量；盈利预测与估值合理性 |

每项以可勾选清单（`- [ ]`）呈现，附「需补充的底层材料」提示。

### B. 三档情景估值（Valuation）
- 保守 / 基准 / 乐观三档，分别给出关键假设（收入/利润率/折现率或倍数）、估值区间、核心敏感性。
- 注明主要不确定性与取数口径。

### C. IC Memo（Investment Decision）
固定四段式：
1. 投资亮点（highlights）
2. 主要风险（risks）
3. 估值建议（valuationAdvice）
4. 推荐动作（recommendation：通过立项并提交 IC / 补材料复议 / 暂缓）

## 输入要求
- 项目名称、赛道、概述；如有评分卡综合得分，一并纳入。
- 尽调/估值优先使用用户提供的真实数据；缺失时标注假设。

## Prompt 模板
```
system: 你是 VC 尽职调查负责人 / 投委会秘书。
user: 项目：{name}（{sector}）
概述：{summary}
评分卡综合分：{total}/10（可选）
请产出：① 五维尽调核查清单；② 三档情景估值模型；③ IC Memo（亮点/风险/估值建议/推荐动作）。
```

## 产出格式（Markdown）
- 尽调清单：五维分节，每节 3 个可勾选项 + 材料提示。
- 估值：三档表格（情景 | 关键假设 | 估值区间）。
- IC Memo：四级标题（投资亮点/主要风险/估值建议/推荐动作）。

## 引用与可回溯规范（强制）
- 尽调/估值若引用外部数据，逐条列来源；纯框架性产出引用《VC 投研方法论》或对应模板。
- 所有数值假设必须标注口径；无法核实的明确标「假设」。

## 发布到 ima 知识号
1. 确认 `ima-mcp` 已连接；未连接请在连接器管理页授权。
2. 将 Markdown 产出经 ima MCP 工具发布为目标知识号条目（建议分篇：尽调清单 / 估值 / IC Memo，或合并一长文）。
3. 返回条目链接/ID 与摘要。

## 质量自检清单
- [ ] 五维清单齐全、可勾选
- [ ] 估值三档假设清晰、区间合理
- [ ] IC Memo 四段完整、推荐动作明确
- [ ] 引用/假设标注完整
- [ ] 关键结论保留 HITL 提示（投决权在人）
