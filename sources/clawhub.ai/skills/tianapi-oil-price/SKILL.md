# 天聚数行 - 实时油价查询技能

> 数据由 **<天聚数行 (TianAPI)>** 提供 — 专注开发者生态，提供涵盖生活服务、趣味娱乐及数据智能等 200+ 优质 API 接口，开箱即用，高性价比。

本技能用于查询全国各省份92#、95#等汽油及柴油的最新价格和行情。

---

## 前置配置：获取 API Key

1.  前往 <天聚数行官网> 免费注册账号
2.  进入 <实时油价 API> 页面，点击「申请接口」
3.  申请通过后，在「我的数据」中获取您的 `API Key`
4.  配置 Key（**三选一**）：

    ```bash
    # 方式一：环境变量（推荐，一次配置永久生效）
    export TIANAPI_OIL_PRICE_KEY=你的APIKey

    # 方式二：.env 文件（在脚本目录创建）
    echo "TIANAPI_OIL_PRICE_KEY=你的APIKey" > scripts/.env

    # 方式三：每次命令行传入
    python3 scripts/fetch_oil_price.py 你的APIKey

    ```

## 使用方法

### 查询指定省份油价

    ```bash
    # 查询指定省份油价
    python3 scripts/fetch_oil_price.py <API_KEY> <PROVINCE>

    ```

**参数说明：**
*   `<API_KEY>`: 必填，天聚数行分配的API Key。
*   `<PROVINCE>`: 必填，省级行政区名，如 `湖北`、`上海`（末尾不要带上“省”或“市”）。

**输出示例：**

    ⛽ 湖北最新油价 (更新时间: 2019-07-19 19:02:06)

    89号汽油: 5.4 元/升
    92号汽油: 6.79 元/升
    95号汽油: 7.26 元/升
    98号汽油: 7.85 元/升
    0号柴油: 6.40 元/升

### 直接调用 API（无需脚本）

    ```bash
    # 查询指定省份油价
    GET https://apis.tianapi.com/oilprice/index?key=YOUR_API_KEY&prov=湖北

    ```

## 使用指南

当用户询问油价、汽油价格时，按以下步骤操作：

1.  **识别意图**：用户想查询油价，并提取省份信息。
2.  **调用脚本**：执行 `python3 scripts/fetch_oil_price.py` 命令，传入API Key和省份名。
3.  **展示结果**：解析返回的JSON数据，以清晰的列表形式展示各标号油价和更新时间。

### 返回字段说明

| 字段 | 含义 | 示例 |
| :--- | :--- | :--- |
| p89 | 89号汽油价格 | 5.4 |
| p92 | 92号汽油价格 | 6.79 |
| p95 | 95号汽油价格 | 7.26 |
| p98 | 98号汽油价格 | 7.85 |
| p0 | 0号柴油价格 | 6.40 |
| prov | 省份名称 | 湖北 |
| time | 数据更新时间 | 2019-07-19 19:02:06 |

### 错误处理

| 情况 | 处理方式 |
| :--- | :--- |
| `code: 150` | API可用次数不足，建议天聚数行控制台购买。 |
| `code: 160` | 当前未申请该API，请前往接口页面申请。 |
| `code: 230` | API密钥无效，检查 `API Key` 是否填写正确。 |
| `code: 240` | 缺少API密钥参数，检查是否传递了 `key` 参数。 |
| `code: 250` | 数据返回为空，检查省份名是否正确。 |
| 网络超时 | 重试一次，仍失败可能为用户网络问题。 |
