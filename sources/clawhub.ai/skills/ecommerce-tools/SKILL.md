# 电商选品与投放工具箱

电商运营的核心方法论和实操框架，覆盖选品决策和付费投放两大核心模块。

## 一、选品决策框架

### 1.1 平台特性选品矩阵

| 平台 | 选品特征 | 价格带推荐 | 适配品类 |
|------|---------|-----------|---------|
| 淘宝 | 搜索驱动、长尾覆盖广 | 中端（¥50-300） | 服饰、家居、美妆、母婴 |
| 京东 | 品质导向、品牌溢价 | 中高端（¥100-1000+） | 3C数码、家电、品牌服饰 |
| 拼多多 | 价格敏感、社交裂变 | 低价（¥10-100） | 日用百货、农产品、小商品 |
| 抖音 | 内容驱动、冲动消费 | 中低端（¥30-200） | 新奇特、美妆、服饰、零食 |
| 快手 | 信任电商、老铁经济 | 中低端（¥20-150） | 农产品、日用、服饰 |
| 火山视频 | 下沉市场、短视频带货 | 低价（¥10-80） | 日用百货、小商品、食品 |

### 1.2 选品四维评估法

1. **市场维度**：搜索热度、市场规模、增长趋势、季节周期
2. **竞争维度**：竞品数量、头部集中度、差异化空间、进入壁垒
3. **利润维度**：毛利率、客单价、复购率、退货率预估
4. **资源维度**：供应链可控性、内容产出难度、投放启动资金

### 1.3 测品标准流程

```
选品池（20-30款）→ 小量上架（3-5款）→ 基础优化 → 小额测款（¥500/款）→ 数据判定 → 优胜劣汰
```

**判定标准**：
- 点击率 > 行业均值 → 继续优化
- 转化率 > 行业均值 → 加投放大
- ROI > 盈亏线 → 正式推广
- 三项均不达标 → 淘汰换品

## 二、付费投放策略

### 2.1 各平台投放工具速查

| 平台 | 核心工具 | 适用阶段 | 出价方式 |
|------|---------|---------|---------|
| 淘宝 | 直通车/引力魔方/万相台 | 全阶段 | CPC/CPM/OCPC |
| 京东 | 京东快车/购物触点/京挑客 | 全阶段 | CPC/CPM/CPS |
| 拼多多 | 多多搜索/多多场景/全站推广 | 全阶段 | CPC/OCPM |
| 抖音 | 巨量千川/DOU+/随心推 | 全阶段 | CPC/CPM/OCPM |
| 快手 | 磁力金牛/粉条 | 全阶段 | CPC/CPM/OCPM |

### 2.2 投放三阶段模型

**冷启动期（Day 1-7）**
- 目标：积累基础数据，跑通模型
- 预算：¥200-500/天
- 策略：广泛定向 + 基础出价，观察人群画像
- 核心指标：曝光量、点击率、加购成本

**放量期（Day 8-21）**
- 目标：放量扩人群，稳定 ROI
- 预算：¥500-2000/天
- 策略：精准人群包 + 阶梯出价，优质素材放量
- 核心指标：ROI、转化率、千次曝光成本(CPM)

**稳定期（Day 22+）**
- 目标：维持 ROI，降本增效
- 预算：根据 ROI 动态调整
- 策略：精准人群 + 高转化素材，逐步降低无效消耗
- 核心指标：稳定 ROI、复购率、LTV

### 2.3 投放优化清单

每次投放复盘时逐一检查：

- [ ] 点击率是否高于行业均值？
- [ ] 转化率是否持续下降？(素材疲劳)
- [ ] 人群包是否需要更新？
- [ ] 出价是否需要调整？
- [ ] 落地页/商品详情页是否需要优化？
- [ ] 竞品是否在加大投放？
- [ ] ROI 是否仍在盈亏线以上？

## 三、数据监控指标

### 核心北极星指标

| 阶段 | 关键指标 | 健康值参考 |
|------|---------|-----------|
| 开店初期 | 访客数、点击率 | 点击率 > 行业均值 80% |
| 起量期 | 支付转化率、加购率 | 加购率 > 8% |
| 爆款打造 | ROI、订单量增速 | ROI > 2.0 |
| 稳定运营 | 复购率、DSR评分 | 复购率 > 20%，DSR > 4.7 |

### 每日必看数据

1. 访客数 vs 昨日/上周同期
2. 支付金额 vs 昨日/上周同期
3. 广告消耗 + ROI
4. 退款率、差评新增
5. 竞品动作监测

## 注意事项

- 以上框架为通用方法论，具体策略需根据品类和实际情况调整
- 投放预算建议为参考区间，实际需结合品类客单价和利润率核算
- 平台规则和工具会迭代更新，执行前建议确认最新政策
