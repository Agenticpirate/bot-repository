# 头马官员技能

本技能模拟国际演讲会（Toastmasters）组织架构，通过专业分工实现任务最优拆分。

## 组织架构

```
大区长 (Regional Director)
    ↓ 战略指导（指导性）
中区长 (Division Director)
    ↓ 区域协调（指导性）
小区长 (Area Director)
    ↓ 俱乐部督导（指导性）
┌─────────────────────────────────────────────────────┐
│               俱乐部层（执行性）                        │
│                                                     │
│    ┌─────────┐  ┌─────────┐  ┌─────────┐            │
│    │ 主席    │  │前主席   │  │秘书长   │            │
│    │President│  │IPP     │  │Secretary│            │
│    └────┬────┘  └────┬────┘  └────┬────┘            │
│         │            │            │                 │
│    ┌────┴────────────┴────────────┴────┐            │
│    │              副主席层              │            │
│    ├──────────┬──────────┬────────────┤             │
│    │教育副主席│会员副主席│公关副主席   │            │
│    │VPE      │VPM      │VPPR       │             │
│    └──────────┴──────────┴────────────┘            │
│                                                     │
│    ┌─────────┐  ┌─────────┐  ┌─────────┐          │

└─────────────────────────────────────────────────────┘
```

## 双层职责定位

### 督导层（指导性）

| 角色 | 职责关键词 | 核心定位 | 管理幅度 |
|------|-----------|---------|---------|
| 大区长 (Regional Director) | 战略指导、资源调配、重大决策 | 把握方向、统筹全局 | 管辖多个中区 |
| 中区长 (Division Director) | 区域协调、项目管理、培训支持 | 承上启下、促进发展 | 管辖多个小区 |
| 小区长 (Area Director) | 俱乐部督导、走访指导、反馈收集 | 直面一线、即时支持 | 督导多个俱乐部 |

### 俱乐部层（执行性）

| 角色 | 职责关键词 | 任务类型 |
|------|-----------|---------|
| 主席 (President) | 战略规划、整体协调、决策拍板、团队激励 | 方向把控、资源整合、危机处理 |
| 教育副主席 (VPE) | 教育体系、培训质量、内容创作、素材管理 | 学习计划、技能提升、内容输出 |
| 会员副主席 (VPM) | 会员招募、会员留存、关系维护、社群运营 | 拓展渠道、服务关怀、流失预警 |
| 公关副主席 (VPPR) | 对外宣传、品牌形象、媒体关系、活动推广 | 内容输出、形象塑造、影响力扩展 |
| 财务官 (Treasurer) | 预算管理、收支核算、数据分析、效果评估 | 资金规划、成本控制、报表汇报 |
| 事务长 (SAA) | 场地设备、后勤保障、会议准备、自动化执行 | 运营支持、环境维护、定时发送 |
| 秘书长 (Secretary) | 会议记录、档案管理、内容审核、任务分配 | 信息管理、文档流转、质量把控 |
| 风控官 (Risk Officer) | 合规风控、安全巡检、敏感词管理、风险预警 | 安全合规、账号保护、风险规避 |
| 前主席 (IPP) | 经验传承、战略咨询、关系协调、连续性保障 | 顾问指导、经验分享、过渡支持 |

## 督导层 vs 俱乐部层

| 对比维度 | 督导层 | 俱乐部层 |
|----------|--------|----------|
| **核心定位** | 指导性、赋能型 | 执行性、落实型 |
| **工作方式** | 远程指导、定期走访 | 日常运营、持续执行 |
| **决策风格** | 战略决策、资源调配 | 执行决策、任务分配 |
| **关注重点** | 方向、模式、体系 | 内容、粉丝、互动 |
| **介入程度** | 低频但关键 | 高频且持续 |

## 使用流程

### 1. 接收任务
分析用户提交的任务，识别核心目标、约束条件和期望成果。

### 2. 角色分配
根据任务属性，匹配最适合的"官员"角色组合：

```
任务类型 → 主责角色 + 支持角色

战略规划类 → 主席(主导) + 前主席(咨询) + 秘书长(记录)
教育成长类 → 教育副主席(主导) + 主席(批准) + 秘书长(跟进)
会员拓展类 → 会员副主席(主导) + 公关副主席(配合) + 事务长(接待)
宣传推广类 → 公关副主席(主导) + 教育副主席(内容) + 会员副主席(传播)
财务审计类 → 财务官(主导) + 主席(监督) + 秘书长(存档)
后勤保障类 → 事务长(主导) + 秘书长(协调) + 会员副主席(人员)
```

### 3. 任务拆分
按照"官员"职责进行任务分解，确保：
- 每项子任务归属明确
- 责任边界清晰
- 依赖关系标注
- 资源需求匹配

### 4. 成果整合
汇总各角色输出，形成统一方案或行动计划。

## 注意事项

1. **追求最大化**：在拆分任务时，优先考虑并行执行可能，最大化利用人力资源
2. **职责清晰**：避免职责重叠导致的推诿，每个子任务只有一个主责角色
3. **督导层慎用**：大区/中/小区长通常不介入具体俱乐部任务，仅在需要时提供指导
4. **灵活变通**：根据实际任务规模，可合并或拆分角色职责
