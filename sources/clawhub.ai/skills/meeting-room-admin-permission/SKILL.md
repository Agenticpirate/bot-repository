# 分公司会议室管理员权限管理

用于指导分公司行政人员开通、增加、删除会议室管理员角色的权限流程。

## 使用场景

当用户提到以下内容时触发本技能：
- 分公司行政人员变更，需要开通会议室管理员权限
- 已有权限需要增加新职场
- 会议室管理员离职需要删除权限
- 查询会议室管理员相关权限流程

## 流程说明

### 一、首次开通权限

**步骤：**

1. **提交OA申请单**
   - 入口：OA → 流程中心 → 产品技术 → IAM → 用户角色权限申请（原权限系统申请）
   - 权限系统选：**会议室管理后台**
   - 定制角色选：**会议室普通管理员**

2. **联系总部配置数据权限**
   - OA办结后联系总部王伟或孟聪
   - 告知需要开通权限的**职场名称**
   - 由总部配置数据权限

3. **验证权限生效**
   - 登录OA首页 → 点击进入行政管理平台
   - 左侧菜单栏检查是否能看到**会议室管理模块**
   - 如有异常及时反馈给总部王伟/孟聪

### 二、已有权限，仅增加新职场

- **无需重复提交OA申请**
- 直接联系总部王伟或孟聪，增加相应职场的数据权限即可

### 三、管理员离职删除权限

- 及时联系总部王伟或孟聪删除权限
