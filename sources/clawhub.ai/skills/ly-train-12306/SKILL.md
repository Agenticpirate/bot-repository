# 12306 高铁火车票查询

> 12306 官方数据直连，查余票、车次、时刻、票价状态，一条命令搞定。

## 核心亮点

- **官方数据源** — 直连 12306（kyfw.12306.cn）公开查询接口，数据权威、实时、免费
- **零配置** — 无需 API Key、无需登录、无第三方代理转发
- **多日期对比** — 一次查询多个日期，快速找哪天有票
- **车站模糊匹配** — 支持站名/拼音/代码自动解析（如"深圳北"、"邯郸东"、"IOQ"）
- **全席别余票** — 商务座/一等座/二等座/硬卧/硬座/无座等实时余票

## 快速入门

**3个开场白示例：**

1. "查一下深圳北到邯郸东9月3号的高铁"
2. "深圳到邯郸这周有哪些车次"
3. "9月5号北京到上海二等座还有票吗"

## 使用方式

脚本：`scripts/train_query.py`

```bash
# 基础查询（单日期）
python3 scripts/train_query.py <出发站> <到达站> <日期YYYY-MM-DD>

# 多日期对比
python3 scripts/train_query.py <出发站> <到达站> 2026-09-03,2026-09-05
```

**示例：**

```bash
python3 scripts/train_query.py 深圳北 邯郸东 2026-09-03
python3 scripts/train_query.py 深圳 邯郸 2026-09-03,2026-09-05,2026-09-07
```

## 输出说明

- 列出所有车次：车次号、实际上车站、出发/到达时间、历时、可订状态
- 余票字段：`有`=有票、数字=剩余张数、`候补`=可候补、缺省=无票
- 12306 一般**提前 15 天放票**，超出预售期会提示
- 查询 12306 有频率限制，建议间隔 3 秒以上

## 注意事项

- 数据来自 12306 官方公开接口，余票实时变动，以 12306 官网/App 为准
- 仅查询，不代购票；购票请到 12306 官网或 App
- 车站匹配到多个站时默认取第一个（如"深圳"→深圳站），可输全名如"深圳北"精确匹配
- 12306 限流时返回失败提示，稍后重试即可
- 所有请求带 20 秒超时，失败立即返回，不无限重试

## 搭配使用

- **domestic-flight** — 飞机票查询，可对比飞机/高铁哪个划算
- **amap-traffic** — 到站后的市内交通/打车方案
