# 中文学术论文润色 Skill

## 何时触发
- 用户说"帮我润色论文""这段太口语化了""检查参考文献格式""按 GB/T 7714 改一下"；
- 用户粘贴中文学术段落（出现"本文 / 研究表明 / 综上 / 笔者认为"等学术语篇标记）；
- 用户明确要求改写为论著体或学位论文语言。

## 工作流程
1. **通读原文**，识别四类问题：口语化表达、冗余/啰嗦、术语不一致、引文格式问题。
2. **加载规则**：读取本 Skill 的 `references/style-guide.md`，逐条比对原文。
3. **逐句改写**，遵循"最小改动"原则——保留作者原意与论证结构，只改语言形式，不改论证逻辑、不增删实质内容、不替作者下结论。
4. **输出三段**：
   - **润色后全文**（可直接复制回 Word）
   - **修改对照表**（表格：`原句 → 改后 → 修改理由`，理由对应 style-guide 的条目编号，如 §1.2）
   - **遗留问题**（需作者本人确认的事实/数据问题，如样本量、p 值，标注【待核】，不擅自修改）

## 关键原则
- **论著体优先**：避免"我觉得 / 大家 / 说白了 / 挺好的"等口语词，改用"笔者认为 / 研究者 / 换言之 / 显著"。
- **术语锁定**：全文同一概念用同一术语；首次出现给全称（英文/缩写），后文统一用简称。
- **引文格式**：正文夹注用"(作者, 年代)"；文末参考文献按 GB/T 7714-2015（著者-出版年制）。
- **不自造数据**：原文数据存疑时标【待核】，绝不擅自改数字或补结论。
- **最小改动**：只在语言层面动手，不动论证骨架。
