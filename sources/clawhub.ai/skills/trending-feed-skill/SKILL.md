### Q1: 如何在GitHub订阅中设置特定的语言过滤器？
A: 在调用GitHub订阅技能时，可以通过在命令中添加语言参数来设置特定的语言过滤器。例如，如果你想查看所有Python语言的热门仓库，可以运行 `python3 $HOME/.skill-platform/workspace/skills/github-trending/script.py python`。

### Q2: 如果GitHub订阅技能返回的数据中缺少某些字段，这是为什么？
A: 如果GitHub订阅技能返回的数据缺少某些字段，可能是因为GitHub API本身没有提供这些信息，或者该仓库的创建者没有在GitHub上提供这些信息。GitHub API只能返回它从仓库中获取的信息。

### Q3: GitHub订阅技能可以处理哪些类型的GitHub仓库？
A: GitHub订阅技能可以处理所有类型的GitHub仓库，包括开源、私有和镜像仓库。但是，对于私有仓库，你可能需要相应的权限才能访问其信息。

### Q4: 如果GitHub订阅技能返回的结果中没有包含仓库的URL，如何获取？
A: GitHub订阅技能返回的结果中会包含仓库的URL字段，即使有时可能因为API限制或其他原因而没有显示。你可以直接在返回的数据中找到 `url` 字段，然后访问该链接以获取更多详细信息。

### Q5: 如何确保GitHub订阅技能返回的数据是最新的？
A: GitHub订阅技能默认返回最新的GitHub Trending仓库列表。如果你需要确保数据是最新的，可以在调用技能时添加一个时间戳参数，或者定期重新运行技能以获取最新的数据。此外，技能还支持缓存机制，可以在一定程度上减少API的调用频率。

## 注意事项
* GitHub API 有速率限制，高频使用建议配合缓存
* 脚本自动处理 API 错误，失败时会返回 fallback 数据
* 默认返回 9 个仓库，语言过滤时返回 10 个
