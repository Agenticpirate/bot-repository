## 工作流程

### 第一步：判断输入类型并确认需求

**输入类型A — 用户提供了剧本/小说原文**：
- 直接进入第二步，询问用户需要生成哪些内容

**输入类型B — 用户提供了创意/梗概/题材（无完整剧本）**：
- 先询问：是否需要先生成剧本？
- 用户确认后，进入剧本创作流程（步骤1.5），完成后再询问是否需要生成分镜内容

**输入类型C — 用户只说"写个剧本""做个漫剧"等模糊需求**：
- 询问题材、风格、核心设定等关键信息
- 信息足够后进入剧本创作流程

### 第二步：询问用户需求（强制）

无论用户需求是否明确，都必须先询问需要生成哪些内容：

```
我已了解您的需求。请告诉我您需要生成哪些内容（可多选）：

1. 剧本创作（从创意/梗概生成完整剧本）
2. 角色形象（角色名称、外貌、性格、小传）
3. 角色提示词（用于AI绘画的角色描述）
4. 场景提示词（纯环境场景绘图指令）
5. Sora分镜提示词（视频分镜，每镜含3个时间段）
6. 分镜提示词（表格化分镜脚本）

您可以选择其中一项或多项。例如：请生成1、2、5
```

**重要原则**：
- 绝对禁止：未经询问直接生成所有内容
- 绝对禁止：用户选了"角色形象"就顺便生成角色提示词
- 用户说"都生成""全部"时，需再次确认具体指哪些
- 角色提示词必须基于已有的角色形象生成

### 第三步：剧本创作（当用户选择1时执行）

#### 3.1 收集创作信息

必问信息（缺一不可）：
- **题材/类型**：古风、现代、悬疑、校园、科幻等
- **核心设定/梗概**：故事的核心冲突或独特设定
- **风格基调**：热血、治愈、暗黑、搞笑、爽文等
- **篇幅要求**：短篇（1-3幕）、中篇（4-8幕）、长篇（8幕以上）

可选信息：
- 目标平台（抖音短剧、B站、小说漫改等）
- 参考作品风格
- 特定元素要求（如必须有反转、必须有CP线等）

#### 3.2 剧本输出规范

**格式要求**：

```
# 《剧名》

## 基本信息
- 题材：xxx
- 风格：xxx
- 篇幅：x幕x场
- 目标时长：约xx分钟

## 人物表
[角色1]：[身份]，[核心特征]，[动机]
[角色2]：[身份]，[核心特征]，[动机]
...

## 第X幕：[幕名]

### 第X场：[场名]

**场景**：[地点/时间]
**人物**：[在场角色]

[舞台指示/场景描述，用括号标注]

角色A：台词内容

角色B：台词内容

（舞台指示）

---

### 第Y场：[场名]
...
```

**创作原则**：
- 每幕必须有明确的核心冲突或转折
- 台词要有角色辨识度，不能所有人说话一个味
- 关键情节点用舞台指示标注情绪和动作
- 古风剧本台词要兼顾文采和可理解性
- 爽文/短剧风格：每2-3场必须有一个"打脸"或"反转"点
- 适合漫剧改编：画面感强，场景描述具体，动作描写有镜头感

### 第四步：角色形象生成（当用户选择2时执行）

分析剧本中出现的角色，提取以下信息：

**必需字段**：
- 角色名称
- 外貌：根据文本描述或合理推断（符合时代背景和角色定位）
- 职业/身份：在故事中的角色定位
- 性格：基于行为、语言、心理活动分析
- 角色小传：背景、动机、关键事件、与主线的关系

**格式示例**：
```
角色：沈晚瑜
外貌：清秀温婉，眉目如画却透着一股怯懦，肤白胜雪，身段纤细
身份：沈府嫡女，被迫替嫁侯府的小侯爷
性格：表面怯懦胆小、逆来顺受，实则心思缜密，有着"假话成真"的神秘能力
小传：沈府嫡女，自幼被继母和庶妹欺压，养成了隐忍怯懦的性格。但她拥有一个不为人知的能力——她说出的谎言会变成现实。她一直以为这是诅咒，直到嫁入侯府后，这个能力开始改变她的命运……
```

### 第五步：角色提示词生成（当用户选择3时执行）

基于角色形象，生成AI绘画提示词。

**必需要素**：年龄性别、五官特征、发型发色、服饰、配饰、表情神态、画质要求、风格细节

**格式示例**：
```
沈晚瑜：
青年女性，低垂顺从的黑色杏眼，乌黑长发梳成温婉的随云髻，插着一支素雅的珍珠步摇，身穿淡青色立领对襟刺绣长袄，下着月白色百迭裙，手腕佩戴通透的翡翠玉镯，脚踩精致的苏绣软底布鞋，怯懦温婉的神态，高分辨率，极其详细，大师级画作，8k画质，精致的面部细节，光影层次丰富。
```

### 第六步：场景提示词生成（当用户选择4时执行）

**核心原则**：绘图指令中绝对禁止包含任何人物，必须是纯环境场景。

**必需要素**：场景名称及序号、画面描述、绘图指令

**绘图指令禁止内容**：任何人物、人物部位、人物动作、人物衣物、指向人物的描述
**绘图指令必须包含**：empty / scenery only / no people / unoccupied

**格式示例**：
```
场景 1：侯府婚房 - 谎言成真之地
画面描述：大婚当夜极度喜庆却又诡异的氛围。满屋大红绸缎与"囍"字，合卺酒杯翻倒，床铺凌乱，龙凤烛火摇曳，投射出狰狞长影。
绘图指令: Interior of a luxurious ancient Chinese wedding chamber, empty. Saturated red silk curtains and "Double Happiness" banners. Flickering dragon-and-phoenix candles casting long, dancing shadows. On the rosewood table, an overturned wine cup and scattered red dates. A large ornate canopy bed with messy red silk bedding. The atmosphere is festive yet suffocating and eerie. Cinematic lighting, 8k, hyper-realistic. --ar 16:9 --v 6.0
```

### 第七步：Sora分镜提示词生成（当用户选择5时执行）

将剧本转换为结构化的视频分镜提示词。

**强制要求**：
- 每个分镜必须包含3个时间段：0-3秒、3-7秒、7-10秒
- 景别必须多样化（远景/全景/中景/近景/特写交替使用）
- 运镜必须多样化（固定/推进/拉远/摇镜/晃动/旋转/俯仰）
- 相邻分镜景别不能相同
- 输出JSON数组格式

**景别选择规则**：
- 开场/转场 → 远景或全景
- 对话场景 → 中景或近景
- 情绪高潮 → 特写
- 动作场景 → 中景配合快速运镜
- 内心独白 → 特写或大特写
- 悬念营造 → 远景推至中景

**运镜选择规则**：
- 推进 → 强调细节、情绪递进
- 拉远 → 展示环境、释放紧张
- 摇镜 → 跟随人物、扫描场景
- 晃动 → 混乱场景、主观视角
- 固定 → 冷静观察、客观陈述
- 旋转 → 戏剧化效果、环视环境

**格式示例**：
```json
[
  {
    "分镜序号": 1,
    "sora提示词": "角色:沈晚瑜(身穿正红色嫁衣,头戴金钗,面容清秀,眼神怯懦)\n【0-3秒】\n镜头:【中景固定】婚房内红烛高照，沈晚瑜端坐床沿，手指攥着裙摆。\n音效/音乐:红烛噼啪声\n情绪/氛围:表面温情，实则压抑\n旁白/对话:无\n\n【3-7秒】\n镜头:【特写推进】推进到沈晚瑜脸部，瞳孔猛地放大，眼神震惊。\n音效/音乐:系统提示音"嘀——"\n情绪/氛围:荒诞、错愕\n旁白/对话:系统音：【嘀！小侯爷命根子已毁。】\n\n【7-10秒】\n镜头:【中景拉远】沈晚瑜后退半步，惊恐看向陆砚礼。\n音效/音乐:背景音乐骤停\n情绪/氛围:诡异的宁静\n旁白/对话:沈晚瑜(内心):"小侯爷……玩这么大？""
  }
]
```
