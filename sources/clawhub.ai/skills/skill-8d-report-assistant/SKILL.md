# 8D报告生成辅助工具

## 任务目标
- 本Skill用于：采用"分步引导+对话式信息收集"模式，生成符合《8D报告评分表（版本1.0.1）》要求的结构化8D问题解决报告
- 能力包含：智能对话引导、8D方法论指导、信息分批收集、详细文字报告生成、Word报告可选导出
- 触发条件：用户需要创建或完善8D报告时，如"生成8D报告"、"编写质量问题分析报告"等

## 前置准备
- 依赖说明：Word导出依赖python-docx库
  ```
  python-docx==0.8.11
  ```
- 模板文件：无需预置模板，直接生成结构化报告

## 核心原则

### 1. 报告内容详细化
- **分析过程完整呈现**：5M1E、5WHY等分析过程要用表格清晰展示
- **结构化层级**：每个环节分为多个子部分，逻辑清晰
- **数据支撑充分**：包含具体的数值、日期、证据等
- **避免概述化**：每一项分析都要有具体的支撑内容

### 2. 报告输出流程
- **先输出文字报告**：生成详细的Markdown格式报告，展示在对话中
- **引导用户确认**：在文字报告后添加引导语，询问是否需要下载Word版本
- **按需生成Word**：用户确认后才调用脚本生成Word文档

### 3. 对话引导模式
- **分步收集**：每个D环节拆分为多个子步骤，每次只询问1-2个问题
- **详细引导**：每个问题提供说明、示例、提示
- **灵活处理**：信息不足时支持"现在补充/稍后补充/跳过"
- **友好纠正**：信息不准确时提供友好提醒和修正建议
- **进度可视化**：每次对话显示当前进度
- **支持修改**：用户可随时说"修改XX"回到对应环节

### 4.2 流出原因分析

**管控环节流程**：
工位自检 → IPQC巡检（每天1次） → 成品检验 → 出货

**未拦截原因**：
- IPQC巡检频率不足（每天1次），无法及时发现参数异常
- 巡检为抽检方式，存在漏检风险

### 4.3 5WHY根因追问

| 层级 | 问 | 答 |
|------|----|----|
| Q1 | 为什么产品会出现划痕？ | → 设备压力参数偏高 |
| Q2 | 为什么参数偏高？ | → 操作人员手工调整，无标准值 |
| Q3 | 为什么无标准值？ | → SOP中未明确该参数的标准范围 |
| Q4 | 为什么SOP中未明确？ | → 该设备为新设备，SOP未及时更新 |
| Q5 | 为什么SOP未及时更新？ | → 新设备投产后无SOP更新流程 |

### 4.4 根本原因总结

**发生原因**：
> 缺乏新设备投产后SOP更新的标准化流程，导致设备参数无标准值范围

**流出原因**：
> IPQC巡检频率不足（每天1次），未及时发现参数异常

## 注意事项

### 报告内容原则
- **详细化**：每个分析过程都要清晰呈现

- **友好引导**：在报告后添加明确的操作指引

### 对话引导原则

- **灵活处理**：支持"现在补充/稍后补充/跳过"
- **进度可视化**：每次对话显示当前进度
- **支持修改**：用户可随时说"修改XX"
