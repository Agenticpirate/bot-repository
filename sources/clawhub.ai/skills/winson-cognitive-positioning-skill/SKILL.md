## 一、核心哲学

### 1.1 双铁律

> **铁律一：你的身价不取决于你能让AI产出什么，而取决于你敢不敢为AI产出负责、并让市场看见这个"敢"字。**
>
> **铁律二：在传统资本缺失、认知资本被持续提取的前提下，唯一能从零建造且不可被掠夺的容器是信任资本。**

### 1.2 四个底层认知

| 认知 | 说明 |
|------|------|
| **打工不是积累的慢版本，是负版本** | 工资维持生计归零 + 经验被无偿蒸馏给雇主 = 净结果−N。你每天工作完比昨天更少了一点不可替代性。 |
| **经验蒸馏是有损的，但足以替代80%场景** | 波兰尼悖论：专家最值钱的知识"说不出"。公司拿到的是有损压缩版，常态任务足以以假乱真，但边缘场景会塌缩。剥削的隐蔽性来自"大部分时候没区别"。 |
| **市场只为"能负责"定价，不为"能产出"定价** | 提问者拿计件工资（趋零），编排者拿工程溢价，兜底者拿最高溢价。唯一不可被蒸馏的是署名权——签字即你的，AI替不了。 |
| **定价失效的根因是买方垄断，不是算错账** | 科技劳动力市场高度集中，雇员议价权被结构性压低。确权不够，还必须配套反垄断意义上的劳动力市场竞争性修复。 |

### 1.3 三种资产容器公式

```
个人可积累资产 = 传统资本（不可达） + 认知资本（可被蒸馏） + 信任资本（不可蒸馏·从零可达·可复利）

从零起步者的唯一出路 = 信任资本
信任资本的硬约束 = 需要"舞台"（可被追溯到你个人的位置）
舞台的判断标准 = 产出可归因到个人 + 判断有人依赖且知道是你
```

## 二、完整执行流程

### Phase 1：认知产权审计

#### Step 1.1：蒸馏风险诊断

**目标**：判断你的隐性经验是否正在被无偿蒸馏给雇主。

**诊断清单**：

| 检查项 | 是 | 否 |
|--------|---|---|
| 你在工作中使用公司提供的AI工具？ | 蒸馏风险+1 | — |
| 你的工作流程/Prompt/微调数据被存储在公司系统？ | 蒸馏风险+1 | — |
| 你的经验以可复制形式（文档/模板/配置）沉淀在公司？ | 蒸馏风险+1 | — |
| 你的核心判断逻辑能被完整写成文字交给新人？ | 蒸馏风险+1（显性层可蒸馏） | — |
| 你有无法言说的"直觉判断"无法写成SOP？ | 隐性内核保留（有损压缩） | — |

**输出**：
- 蒸馏风险等级（低/中/高）
- 你的"显性骨架"被掠夺的比例估算
- 你的"隐性内核"残留比例（不可替代性的最后防线）

**检验标准**：能回答"我的经验有多少被公司拿走了，有多少还在我脑中"。

#### Step 1.2：BYOAI 倾向评估

**问题**：你是否应该把核心经验沉淀在个人AI账号而非公司系统？

**判断矩阵**：

| 你的经验价值 | 公司AI可信度 | 建议 |
|-------------|------------|------|
| 高（稀缺专家） | 低 | 强烈BYOAI，核心经验绝不上传 |
| 高 | 高 | 选择性蒸馏——只给80%日常层，保留20%内核 |
| 中 | 任意 | 无需过度防御，但建立个人知识库 |
| 低 | 任意 | 无需防御，先提升经验价值 |

**输出**：BYOAI策略建议。

---

### Phase 2：打工位置诊断

**目标**：判断你的工作是在积累信任资本，还是在纯负积累。

**诊断矩阵**：

| 检查项 | 积累 | 失血 |
|--------|------|------|
| 你的工作产出可归因到你个人？ | ✓ | ✗ |
| 客户/同事记得某些事是你做的？ | ✓ | ✗ |
| 有人依赖你的判断且知道是你判断的？ | ✓ | ✗ |
| 你随时可以被替换且不影响输出？ | ✗ | ✓ |
| 你的产出被"团队/流程/公司品牌"吸收？ | ✗ | ✓ |
| 离职后没人知道你做过什么？ | ✗ | ✓ |

**输出**：
- **积累型**：你在建造信任资本，打工只是载体——继续，但加速放大署名机会。
- **失血型**：你在纯负积累，打得越久离"积累"越远——优先制造"个人署名"机会，哪怕极小。
- **混合型**：部分积累部分失血——识别哪些工作可署名，集中精力放大这些。

**检验标准**：能回答"如果我明天离职，有谁会记得我做过什么"。

---

### Phase 3：三种资产容器对照

**目标**：明确你当前拥有/可达的资产容器。

| 容器 | 内容 | 启动资金 | 可被蒸馏 | 从零可达 | 可复利 |
|------|------|---------|---------|---------|--------|
| 传统资本 | 土地、房产、股权 | 高 | 否 | 否 | 是 |
| 认知资本 | 技能、经验、判断力 | 低 | **是** | 是但不可沉淀（雇佣下被提取） | 否（被提取后归零） |
| 信任资本 | 声誉、客户关系、可验证的责任承担记录 | 零 | **否** | **是** | **是** |

**操作步骤**：
1. 逐一评估你当前每种容器的存量（0-10分）
2. 标注哪种容器在你当前生活/工作中有增长可能
3. 如果传统资本=0、认知资本在被提取 → 唯一出路锁定为信任资本

**输出**：个人资产容器存量表 + 增长方向判定。

**检验标准**：能回答"我当前唯一能从零建造且不会被雇主抽走的资产是什么"。

---

### Phase 4：舞台评估

**目标**：判断你是否处于"可被追溯到你个人"的位置。

**舞台存在性检查**：

| 信号 | 有舞台 | 无舞台（黑洞） |
|------|--------|---------------|
| 你做的事有人知道是你做的 | ✓ | ✗ |
| 做好了归功于你 | ✓ | ✗（归功于流程/团队/品牌） |
| 做坏了你背锅但做好了没人记得 | ✗ | ✓ |
| 外部客户/行业同行能提到你的名字 | ✓ | ✗ |
| 你有一个"别人提起某件事就想到你"的领域 | ✓ | ✗ |

**输出**：
- **有舞台**：你在正确的位置——放大署名机会，加速信任资本复利。
- **无舞台**：你处于信任资本黑洞——当前最紧急的不是"提升技能"，而是"找到/制造一个可署名的位置"。

**检验标准**：能回答"有没有一个领域，别人提起它就会想到我的名字"。

---

### Phase 5：提问力分层自检

**目标**：诊断你在AI技能市场的定价层级。

| 层级 | 内容 | 可复制性 | 市场定价 | 你在哪？ |
|------|------|---------|---------|---------|
| 提问（Prompting） | 写出能用的指令 | 极高，工具自带辅助 | 趋零 | [自评] |
| 编排（Orchestration） | 把RAG、多Agent、知识库串成能替一个部门的系统 | 中等，需系统工程能力 | 高溢价 | [自评] |
| 兜底（Accountability） | 为最终输出签字、承担法律与商业风险 | 不可复制 | 最高溢价 | [自评] |

**自检问题**：
1. 你写的Prompt能被一个培训两天的大学生替代吗？→ 是=你在提问层
2. 你能设计一个替换掉完整部门的AI工作流吗？→ 是=你在编排层
3. 你敢在最终交付物上签字并承担后果吗？→ 是=你在兜底层

**输出**：当前层级 + 上迁路径。

**检验标准**：能回答"我的技能在哪一层，怎么往上迁"。

---

### Phase 6：突破路径设计

**目标**：从零建造信任资本的第一步。

**路径设计模板**：

```
第一步：制造"个人署名"机会（极小即可）
  → 找一个你能负责到底的项目/任务/客户
  → 确保"这件事是你做的"被看见、被记住

第二步：建立"领域=你的名字"的认知锚点
  → 选一个足够窄的垂直领域
  → 让提到这个领域的人想到你

第三步：将署名记录系统化
  → 可验证的责任承担记录
  → 客户 testimonial / 同行推荐 / 公开成果

第四步：复利循环
  → 一次对的判断 → 下次有人敢把更大的事交给你
  → 信任资本自动生长
```

**关键提醒**：
- 容器三的第一滴水，比容器一的启动资金重要得多——因为前者会自己生长，后者不会。
- 不要等"攒够钱去创业"——那个数字你永远攒不够，因为通胀和支出会追着你跑。
- 用打工的时间制造个人署名机会，而不是用打工的工资去攒创业本金。

**输出**：个人突破路径方案（含第一步具体行动）。

**检验标准**：能回答"我明天可以做什么来制造第一个署名机会"。

## 三、常见陷阱与避坑指南

| 陷阱 | 表现 | 后果 | 修正 |
|------|------|------|------|
| **"攒够钱再创业"幻觉** | 认为打工是在攒创业本金 | 通胀+支出追着你跑，永远攒不够 | 用打工时间制造署名机会，而非攒钱 |
| **技能提升=积累幻觉** | 不断学新技能但都在雇佣关系下 | 技能被蒸馏给雇主，不沉淀在你手里 | 技能容器是雇主的大脑，不是你的 |
| **匿名勤奋陷阱** | 做了很多事但没人知道是你做的 | 投入再多，信任资本沉淀为零 | 优先解决"可归因性"，再谈勤奋 |
| **提问力高估陷阱** | 以为"会写好Prompt"就值钱 | Prompt可无限复制，溢价趋零 | 往编排层/兜底层迁移 |
| **全面防御陷阱** | 对所有经验都捂着不给 | 连80%日常层都不蒸馏，失去工作价值 | 选择性蒸馏：给骨架，留内核 |
| **确权即解决幻觉** | 以为法律承认认知产权就万事大吉 | 买方垄断下版税被压到象征性 | 确权+反垄断双重修复 |
| **蒸馏无损幻觉** | 以为经验被完整拿走了 | 要么过度恐慌，要么过度自信 | 记住波兰尼悖论：隐性内核仍在你脑中 |

## 四、场景适配指南

| 场景 | 重点Phase | 说明 |
|------|----------|------|
| **刚毕业/入行新人** | Phase 3+5+6 | 无传统资本、认知资本正在积累→锁定信任资本路径，从第一个署名机会开始 |
| **资深员工（5-10年经验）** | Phase 1+2 | 蒸馏风险最高，优先审计失血程度，判断是否需要BYOAI |
| **考虑创业/副业者** | Phase 3+6 | 对照容器表，设计从打工到信任资本积累的过渡路径 |
| **管理者/团队lead** | Phase 2+4 | 你的团队位置可能天然有舞台，评估并放大署名机会 |
| **自由职业者** | Phase 4+5 | 天然有舞台，重点在提问力上迁和信任资本复利加速 |
| **被AI替代风险高的岗位** | Phase 1+5 | 紧急评估蒸馏程度+技能层级，制定上迁/转型方案 |

## 六、执行原则

1. **先诊断失血，再谈积累**：不知道自己在哪里漏血，就不知道该堵哪里。Phase 1-2 是一切的前提。
2. **锁定唯一出路，不要分散**：传统资本不可达、认知资本被提取——只有信任资本一条路。不要三线作战。
3. **舞台优先于技能**：没有舞台，技能再强也是黑洞。先解决"可被追溯到你个人"，再谈提升。
4. **署名权是终极护城河**：签字=把自己绑死在结果上=不可被蒸馏。敢于署名的人，永远比会提问的人值钱。
5. **第一滴水比启动资金重要**：信任资本会自己生长，传统资本不会。不要等"攒够钱"，要等"第一个署名机会"。
6. **选择性蒸馏，不是全面防御**：给80%显性骨架（保住工作价值），留20%隐性内核（保住不可替代性）。
7. **具体胜过抽象**：每个Phase的输出必须是可执行的具体判断，不能停在"我大概知道了"。
