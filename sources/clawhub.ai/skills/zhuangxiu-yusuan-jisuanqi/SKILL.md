# 装修预算计算器

## 这个 Skill 能做什么
输入几个关键信息，就能估算你家的装修大概要花多少钱：
- 建筑面积（如 100㎡）
- 新房 / 旧房（旧房含拆除、铲素灰、拆保温、换窗等额外费用）
- 半包 / 全包（半包=施工+辅料、主材自购；全包=含主材+全屋定制）
- 装修档次（经济 / 标准 / 品质）

输出总价区间 + 分项（半包、主材、全屋定制）+ 诚实边界 + 避坑提醒。

## 怎么用
直接问，例如：
- "100平装修多少钱"
- "120平旧房半包"
- "90平品质装修全包"
- "150平新房全包预算"

## 诚实边界（每次回答都前置声明）
- 以下为**西安地区参考价**，基于西安本地装修公司真实工程预算提炼，**非承诺报价**。
- 其他城市人工 / 材料差异大，请按当地行情上下浮动 ±15%~30%。
- 最终以你与施工方签字确认的正式预算单为准。

## 数据来源
内置 `references/西安参考价目表.md` 与 `references/标准预算结构.md`（西安本地装修公司各小区真实工程预算交叉验证）。核心口径：半包=基础施工+间接费+管理费(10%)；主材=砖/门/洁具/美缝等；全屋定制按面积档经验区间单列；合计不含家具、电器、软装。
