# 美团特价酒店

搜索美团全国连锁品牌酒店特价套餐，覆盖希尔顿、万豪、洲际、凯悦、香格里拉、亚朵、全季等品牌，低至2折起。

## 功能说明

### hotel_deals — 搜索特价酒店

搜索美团平台上的连锁品牌酒店特价套餐，支持按城市和品牌筛选。

**适用场景：**
- 用户想查某个城市的特价酒店
- 用户想找某个品牌的折扣套餐
- 用户需要品牌酒店低价预订

**参数：**
- city（选填）：城市名，如"北京"、"上海"、"三亚"。留空返回全国热门。
- brand（选填）：品牌名，如"希尔顿"、"万豪"、"亚朵"。留空返回所有品牌。
- sort（选填）：排序方式，"discount"按折扣力度（默认），"price"按价格低到高。

**返回内容：**
- 酒店套餐图片
- 套餐名称（加粗）
- 价格（现价←原价，折扣，节省金额）
- 城市、有效期至、品牌、评分
- 预订链接（跳转美团下单）

## 使用方法

当用户需要搜索酒店、查找特价房型、比较酒店价格时，调用本技能。

**示例：**
- "帮我查三亚的特价酒店" → hotel_deals(city="三亚")
- "上海有什么品牌酒店打折" → hotel_deals(city="上海")
- "找亚朵酒店的套餐" → hotel_deals(brand="亚朵")
- "全国热门特价酒店" → hotel_deals()
- "按价格排序查北京酒店" → hotel_deals(city="北京", sort="price")

## 注意事项

- 数据来源为美团实时API，价格和库存以实际预订页面为准
- 搜索结果均为酒店+套餐产品（含住宿+附加服务）
- 预订链接跳转至美团平台完成下单，本技能不处理支付
- 数据通过腾讯云代理转发，不存储用户数据
- 仅支持国内城市
