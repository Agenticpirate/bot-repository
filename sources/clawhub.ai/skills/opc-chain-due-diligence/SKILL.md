# OPC链式尽调增强版

> **面向技术尽调和投资评估场景的全链条快速扫描工具**
> 覆盖：企业背景 → IP资产 → 技术实力 → 资金合规 → 综合风险

## 一句话价值

输入企业名称，输出**五维链式风险扫描报告**——从"谁在做"到"做什么"到"含金量多少"到"钱是否靠谱"到"整体评估"，一步到位。

---

## 目标客群

| 序号 | 客群 | 典型场景 |
|------|------|----------|
| ① | **投资方**（VC/PE/CVC） | 拟投企业前置尽调，识别技术夸大/概念偷换/专利泡沫 |
| ② | **园区/政府招商部门** | 招商对象实力评估，避免"空壳企业"入园 |
| ③ | **评审专家**（技术评审/项目评审） | 项目申报企业综合实力快速评估 |
| ④ | **FA/财务顾问** | 标的企业的技术资产核查，为估值提供参考 |
| ⑤ | **创业者** | 自查企业IP资产和技术竞争力，优化定位 |
| ⑥ | **二级市场投资者**（不做散户投资者） | 上市公司技术实力和IP风险辅助判断 |

> ⚠️ **本工具不服务于散户投资者**，不做量化估值，也不构成投资建议。

## 核心原则

### 先问方向，再启动扫描

> ⚠️ **必须首先完成"资产在哪→要去哪"的确认**，避免在不适用场景下执行扫描。

通过两个问题确认扫描方向：

| 问题 | 说明 |
|------|------|
| "尽调目标企业是哪一家？" | 明确目标企业名称/统一社会信用代码 |
| "尽调的主要目的是？" | 投资/合作/招商/评审/自查，不同场景侧重不同 |

### 仅做风险标记，不做量化估值

| 标记 | 含义 | 处理建议 |
|------|------|----------|
| 🟢 **低风险** | 无明显异常信号 | 可正常推进，建议关注标记项 |
| 🟡 **关注** | 存在需关注的因素 | 建议进一步核实相关维度 |
| 🔴 **高风险** | 存在显著风险信号 | 建议暂停，启动深度尽调 |

### 数据源合规

所有数据来自**免费公开API**，无需付费订阅。包括：
- **Wikidata API**：企业基本信息（成立时间、行业分类、总部地址等）
- **USPTO PatentsView API**：专利组合概览、法律状态、引用分析
- **WIPO API**：国际专利/商标查询
- **OpenCorporates API**（免费版）：企业注册信息
- **逻辑推理分析**：基于公开数据的交叉验证和趋势推断

## 链式工作流程

### Step 1：模块A - 企业基本信息扫描

**输入**：企业名称 或 统一社会信用代码

**采集维度**：
| 维度 | 数据源 | 说明 |
|------|--------|------|
| 企业全称 | Wikidata / OpenCorporates | 确认官方注册名称 |
| 成立时间 | Wikidata | 判断企业存续年限 |
| 注册资本 | Wikidata | 资本规模参考 |
| 行业分类 | Wikidata (P452/P31) | 所属行业/经营范围 |
| 总部所在地 | Wikidata | 属地信息 |
| 实控人/股东 | Wikidata (P488/P3320) | 核心人物识别 |

**输出标记**：
- 🟢 存续期>5年，信息完整
- 🟡 存续期<3年 或 注册资本异常偏低
- 🔴 查不到有效信息 或 成立不足1年

### Step 2：模块B - IP资产扫描

**输入**：来自模块A的企业名称

**采集维度**：
| 维度 | 数据源 | 说明 |
|------|--------|------|
| 专利总数 | USPTO PatentsView | 按受让人查询 |
| 技术领域分布 | USPTO (CPC/IPC) | 技术方向集中度 |
| 法律状态 | USPTO | 有效/失效/审查中 |
| 国际同族 | PatentsView + WIPO | 地域覆盖范围 |
| 商标信息 | WIPO / USPTO | 品牌保护情况 |

**输出标记**：
- 🟢 专利数≥10，技术分布合理，有效率高
- 🟡 专利数<5 或 集中在单一IPC大类 或 有效率偏低
- 🔴 无专利 或 全部失效 或 大量同一领域重复申请

### Step 3：模块C - 技术风险评估

**输入**：来自模块B的IP分析结果

**评估维度**：
| 维度 | 分析逻辑 | 识别的风险信号 |
|------|----------|----------------|
| 技术集中度 | IPC大类分布HHI指数 | 🔴 单一技术依赖(>80%) |
| 专利存活率 | 失效/有效比例 | 🔴 高失效比例(>40%) |
| 专利申请趋势 | 按年份分布 | 🔴 近3年申报骤降 |
| 引用影响力 | 被引分布 | 🔴 零引用占比过高 |
| 概念偷换检测 | 标题/摘要比对 | 🟡 用词模糊/范围跳跃 |
| 技术夸大识别 | 产学研比例 | 🟡 含大量非核心外围专利 |

**输出标记**：
- 🟢 技术实力扎实，专利质量较高
- 🟡 需关注部分技术指标
- 🔴 存在技术夸大/概念偷换风险

### Step 4：模块D - 资金合规检查

**输入**：来自模块A的企业基本信息

**检查维度**（参考对外投资合规诊断逻辑，只做标记不建议具体路径）：

| 维度 | 检查内容 | 风险信号 |
|------|----------|----------|
| 资本合理性 | 注册资本vs行业平均水平 | 🔴 注册资本严重低于行业均值 |
| 存续时长 | 成立到目前年限 | 🔴 新设<1年即有大额投资标的 |
| 对外投资 | 投资企业数量/行业跨度 | 🟡 跨行业投资过多 |
| 资金来源 | 基于公开信息的逻辑推断 | 🟡 无公开财务信息 |
| 合规要求 | 行业是否需要特定资质/许可 | 🟡 需资质无资质 |

**输出标记**：
- 🟢 资本合理，存续正常
- 🟡 需关注资本或存续方面
- 🔴 资金方面存在显著风险

### Step 5：模块E - 综合风险评估报告

汇总A+B+C+D四维结果，生成：

```
┌─────────────────────────────────┐
│  OPC链式尽调综合风险评估报告     │
├─────────────────────────────────┤
│ 模块A 企业背景    │ [🟢/🟡/🔴] │
│ 模块B IP资产      │ [🟢/🟡/🔴] │
│ 模块C 技术实力    │ [🟢/🟡/🔴] │
│ 模块D 资金合规    │ [🟢/🟡/🔴] │
├─────────────────────────────────┤
│ 综合结论          │ [🟢/🟡/🔴] │
│ 综合建议          │ [详细建议] │
└─────────────────────────────────┘
```

**综合结论判定规则**：

| 各维度标记 | 综合结论 |
|-----------|----------|
| 全部🟢 或 最多1个🟡 | 🟢 低风险，可推进 |
| ≥2个🟡 或 1个🔴 | 🟡 存在关注点，谨慎推进 |
| ≥2个🔴 | 🔴 高风险，建议暂停并启动深度尽调 |

## 边界说明

### 本Skill擅长

✅ 企业公开信息快速采集  
✅ 专利组合概览与技术领域识别  
✅ 技术风险评估（识别夸大/偷换概念）  
✅ 资金合规初步检查  
✅ 多维度风险综合标记  

### 建议转介专业机构

⚠️ 深度P2I评估（专利价值量化）  
⚠️ 现场尽调和访谈  
⚠️ 财务审计和法务尽调  
⚠️ 需保密协议才能获取的信息  
⚠️ 需要实地验证的技术能力评估  

### 局限性

- ⚠️ 数据基于公开API，可能存在延迟（最长1-2周）
- ⚠️ 部分中国企业信息在Wikidata中可能不够完整
- ⚠️ 不提供具体估值/评分数字，仅做风险标记
- ⚠️ 不构成投资建议或法律意见
