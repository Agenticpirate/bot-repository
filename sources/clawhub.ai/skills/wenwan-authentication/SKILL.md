# 文玩鉴定

## 概述

对文玩珠宝进行真伪鉴别、品质评估和市场估价。以绿松石为核心起点，逐步扩展覆盖更多品类。

## 鉴定流程

### 1. 接收鉴定需求

从用户获取：
- 实物图片（多角度：正面、背面、孔道/细节特写）
- 尺寸参数（直径、对孔、高度等，mm）
- 重量（克）
- 入手价格（如有）

### 2. 图片分析

使用 `autoglm-image-recognition` 进行专业图片识别。图片须先上传获取公网 URL。

**标准 prompt 模板：**

```
请从文玩鉴定的角度详细分析图片。重点关注：
1. 颜色自然度与分布（天然不均匀 vs 人工均匀）
2. 表面光泽类型（玻璃光/蜡状光/胶质光/贼光）
3. 纹理特征（铁线/纹路的自然性、凹陷感）
4. 孔道状态（与表面颜色是否一致、有无白圈）
5. 雕刻/工艺细节（有无胶体堆积、橘皮纹）
6. 任何可疑的优化处理痕迹
请给出综合鉴定结论（是否为天然原矿、品质等级、可能的优化处理）。
```

### 3. 密度推算

根据用户提供的重量和尺寸，粗略推算密度判断材质：

- 绿松石天然密度：2.6-2.9 g/cm³
- 菱镁矿：2.1-2.3 g/cm³
- 塑料/树脂：1.0-1.5 g/cm³

计算方法：体积 ≈ 外形尺寸估算体积 × 0.65-0.8（雕件/孔道修正系数）

### 4. 综合评估

基于图片分析 + 密度推算 + 品类知识，输出：

- **材质判断**：天然原矿 / 优化处理 / 仿品
- **瓷度等级**：泡松 / 硬松 / 瓷松 / 玉化
- **优化判断**：有/无注胶、染色、过蜡
- **品质评级**：收藏级 / 精品级 / 把玩级 / 入门级 / 通货级
- **市场估价**：合理价格区间

### 5. 补充验证建议

列举该品类关键验证手段：
- 紫光灯（365nm）检测注胶
- 热针法检测胶/塑料
- 浸水测吸水性和气泡
- CMA认证检测机构送检

搜索关键词格式：`[品类名] 真伪鉴别 方法`

## 市场估价

估价时综合参考：
1. 近期电商平台（淘宝、京东、闲鱼）同品类同规格成交价
2. 文玩社区（小红书、文玩论坛）行情帖
3. 拍卖平台参考价
4. 使用 `autoglm-websearch` 搜索 `[品类] [规格] 价格 2025 2026`

估价区间说明：
- **合理入手价**：普通消费者在正常渠道能买到的价格
- **直播间/微商价**：流量渠道的低价区间
- **实体店价**：含店铺租金溢价的区间

## 输出格式

鉴定报告应包含：
1. 📐 物理参数表（尺寸/重量/密度推算）
2. 🎨 分项鉴定（颜色/光泽/纹理/孔道/工艺）
3. 💡 优化处理判断
4. 🏷️ 品质综合评级（含直观等级条）
5. 💰 市场估价参考表（分渠道）
6. ⚠️ 补充验证建议
