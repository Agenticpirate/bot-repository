## 任务目标

- 本Skill用于：现场5S管理与目视化管理的全方位辅助支持
- 核心能力：
  1. 5S管理标准指引（五维度操作规范）
  2. 目视化管理方案设计与模板

## 一、5S管理标准指引

### 1.1 整理（Seiri）

**定义**：区分必需品与非必需品，将不需要的物品清除出现场。

**操作规范**：
| 检查项 | 标准要求 | 检查要点 |
|--------|----------|----------|
| 物品分类 | 必需品/非必需品/待处理品三分类 | 每件物品有明确归属 |
| 处理原则 | 立即处理非必需品 | 报废/转用/暂存标识清晰 |
| 判定标准 | 使用频率决定必需品属性 | 30天内未使用→非必需品 |

**检查清单**：
- 现场无废弃物料、过期品
- 无关私人物品已清理
- 暂存区有明确标识和期限

### 1.2 整顿（Seiton）

**定义**：将必需品按定置管理原则合理放置，便于取用和归还。

**操作规范**：
| 要素 | 要求 | 方法 |
|------|------|------|
| 位置 | 物有定处 | 画线定位、区域划定 |
| 数量 | 适量管理 | 最高/最低库存标识 |
| 标识 | 一目了然 | 名称、编号、数量、责任人 |
| 取放 | 快速归位 | 先进先出、归位路径 |

**定置管理三要素**：
1. 空间：设备/货架布局优化
2. 物品：形态适合、便于取放
3. 方法：流程最短、动作最少

### 1.3 清扫（Seiso）

**定义**：清除现场脏污，保持设备和工作场所清洁。

**操作规范**：
| 区域 | 清扫要点 | 频率 |
|------|----------|------|
| 地面 | 无垃圾/油污/杂物 | 每日2次+随时 |
| 设备 | 表面清洁、无积尘漏油 | 每班次 |
| 角落 | 隐蔽处无死角 | 每周1次 |
| 窗户 | 玻璃明亮、无积灰 | 每周1次 |

**责任划分**：
- 岗位责任：操作者负责本岗位设备清扫
- 公共区：值日表轮换
- 设备清扫点检：设备维护人员

### 1.4 清洁（Seiketsu）

**定义**：将整理、整顿、清扫标准化、制度化，维持良好状态。

**操作规范**：
| 维度 | 标准要求 | 执行要点 |
|------|----------|----------|
| 规范化 | 制定清扫标准作业指导书 | 明确步骤/工具/时间 |
| 制度化 | 检查制度与考核机制 | 日/周/月检查表 |
| 可视化 | 状态标识清晰可见 | 颜色管理/状态看板 |
| 习惯化 | 标准化融入日常 | 交接班检查流程 |

**三现主义**：
- 现场：到问题发生地点
- 现物：确认实物和实际情况
- 现实：根据真实数据分析问题

### 1.5 素养（Shitsuke）

**定义**：养成良好习惯，遵守规章制度，持续改善。

**操作规范**：
| 要素 | 标准要求 | 评价指标 |
|------|----------|----------|
| 培训 | 全员5S培训覆盖 | 培训记录100% |
| 遵守 | 规章制度执行率 | 违规次数降低 |
| 改善 | 提案改善制度 | 人均提案数 |
| 文化 | 自主管理意识 | 问题主动报告率 |

**素养提升路径**：
1. 领导重视、全员参与
2. 制度上墙、视觉提醒
3. 竞赛激励、表彰先进
4. 持续改进、形成文化

## 二、目视化管理方案设计

### 2.1 目视化管理原则

| 原则 | 说明 | 应用场景 |
|------|------|----------|
| 无论是谁都能判断 | 状态正常/异常一目了然 | 设备状态灯 |
| 判断速度要快 | 3-5秒内识别 | 区域颜色管理 |
| 判断结果可靠 | 不依赖个人经验 | 标准色卡对照 |
| 信息集中展示 | 相关信息一处显示 | 综合看板 |

### 2.2 生产车间目视化方案

**区域划分与标识**：
```
┌─────────────────────────────────────────────────────────┐
│  [入口]  →  [更衣室]  →  [生产区]  →  [检验区]  →  [出货] │
└─────────────────────────────────────────────────────────┘

颜色标准：
- 黄色：通道线（宽度≥1.2m）
- 绿色：合格品存放区
- 红色：不合格品/危险区
- 蓝色：待检品存放区
- 白色：作业区域定置线
```

**设备目视化**：
- 运行状态灯：绿(运行)/黄(待机)/红(故障)
- 设备点检表：悬挂于设备前方
- 关键参数：上下限值可视化标注
- 润滑点：颜色标识+加油周期

**物料目视化**：
- 料架标签：物料名称/编号/最大最小库存
- 先进先出：料盒倾斜放置/取料方向箭头
- 安全存量：警戒线标注

### 2.3 仓储区目视化方案

**库位管理系统**：
```
列号：A  B  C  D  E
层号：1  2  3  4  5
例：A-03-02 表示A区第3排第2层

库位卡内容：
┌──────────────────┐
│ 物料名称：XXX    │
│ 物料编号：XXXXX  │
│ 最大库存：100    │
│ 最小库存：20     │
│ 责任人：XXX      │
└──────────────────┘
```

**存储标准**：
- 重物下层、轻物上层
- 大件外侧、小件内侧
- 危险品独立存放、上锁管理
- 通道宽度≥1.5m，保持畅通

**先进先出管理**：
- 进货日期标注
- 方向指示（从左进/从右取）
- 库存周转看板

### 2.4 办公区目视化方案

**办公区域划分**：
- 工位：定置线+个人物品定位
- 文件柜：分类标签+责任人标识
- 公共区：饮水机/打印机/垃圾桶定位

**文件管理5S**：
| 分类 | 标识颜色 | 处理周期 |
|------|----------|----------|
| 必要文件 | 绿标 | 永久保存 |
| 临时文件 | 黄标 | 每月整理 |
| 废弃文件 | 红标 | 定期销毁 |

**目视化管理工具**：
- 白板：周计划/任务看板
- 公告栏：制度/通知/改善提案
- 文件盒：待办/进行中/已完成分类

## 三、现场问题诊断与改进

### 3.1 常见问题识别清单

**整理问题**：
- 现场积压无用物品
- 私人物品随意摆放
- 过期品/呆滞物料未处理
- 暂存区混乱无标识

**整顿问题**：
- 物品无定位标识
- 工具/物料取用不便
- 寻找时间过长
- 通道被占用

**清扫问题**：
- 地面脏污/积水
- 设备积尘/漏油
- 死角未清理
- 清扫工具混杂

**清洁问题**：
- 标准未建立或未执行
- 检查流于形式
- 问题重复发生
- 区域责任不清

**素养问题**：
- 规范未形成习惯
- 异常不主动报告
- 改善意识薄弱
- 培训不到位

### 3.2 问题诊断流程

```
发现问题 → 现场确认 → 5S维度归类 → 原因分析 → 改善措施 → 效果验证
    │           │            │            │           │          │
    ↓           ↓            ↓            ↓           ↓          ↓
  巡查/举报   三现主义    判断属于哪类  5Why分析    SMART目标   对比改善前后
              核实情况    问题范畴     鱼骨图分析   PDCA执行    标准化固化
```

**问题描述**：[具体问题+发现时间+发现地点+照片]

**原因分析**：
- 直接原因：[表面原因]
- 根本原因：[5Why分析结果]
  - Why1: ?
  - Why2: ?
  - Why3: ?

**改善措施**：
| 序号 | 措施内容 | 负责人 | 完成日期 | 验证标准 |
|------|----------|--------|----------|----------|
| 1    |         |        |          |          |
| 2    |         |        |          |          |

**效果确认**：
- 改善前：[照片/数据]
- 改善后：[照片/数据]
- 保持期限：[已保持X天]

## 四、数据记录与分析

### 4.1 5S检查记录格式

**日常检查表**：
```
检查日期：2024-01-15
检查区域：_______
检查人：_______
评分标准：5分-优秀 4分-良好 3分-合格 1-2分-不合格

| 检查项 | 整理 | 整顿 | 清扫 | 清洁 | 素养 | 小计 |
|--------|------|------|------|------|------|------|
| 区域1  |      |      |      |      |      |      |
| 区域2  |      |      |      |      |      |      |
| ...    |      |      |      |      |      |      |

问题记录：
1. [问题描述] → [整改要求] → [完成期限]

本次得分：___/25  评价：___
```

**周/月度汇总**：
- 各区域得分趋势
- 问题类型分布统计
- 整改完成率追踪
- 重点改进项确认

### 4.2 数据分析方法

**得分趋势分析**：
- 各区域5S得分折线图
- 5个维度得分雷达图
- 环比/同比变化分析

**问题分布分析**：
- 问题类型帕累托图（80/20法则）
- 问题发生区域分布
- 问题发生时间规律

**改善效果评估**：
- 改善前后对比
- 改善措施执行率
- 问题复发率统计

## 使用示例

### 示例1：5S标准查询
- **场景**：用户询问"整顿的标准是什么？"
- **输出**：提供整顿（Seiton）的定义、三要素（位置/数量/标识）、操作规范表格、定置管理方法
- **要点**：强调"三定"原则——定点、定容、定量

### 示例2：目视化方案设计
- **场景**：用户需要为仓库设计目视化管理方案
- **输出**：提供库位编码系统、颜色标准、存储原则、先进先出管理方法、模板样式参考
- **要点**：引用assets/中的模板示例，引导用户按模板填写

### 示例3：问题诊断与改进
- **场景**：用户发现车间某区域地面油污严重
- **输出**：
  1. 识别为"清扫"维度问题
  2. 提供可能原因分析（设备漏油/操作不当/清扫不及时）
  3. 给出改进建议模板
  4. 引导使用scripts/report_generator.py记录问题

### 示例4：生成管理报告
- **场景**：用户完成月度5S检查，需要生成报告
- **输出**：提供脚本调用方法、输入数据格式、报告模板结构
- **要点**：说明如何将检查数据整理为JSON格式，调用脚本生成HTML报告

## 注意事项

- 5S管理强调全员参与和持续改善，避免一次性运动式推进
- 目视化管理设计应遵循"简单、直观、一目了然"原则，避免过度复杂化
- 问题诊断坚持三现主义（现场、现物、现实），避免主观臆断
- 报告数据需真实准确，问题记录应有照片佐证
- 改进措施需明确责任人、完成期限和验证标准，确保执行落地
