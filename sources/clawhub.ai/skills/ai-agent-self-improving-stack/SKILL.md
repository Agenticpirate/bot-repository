# AI Agent Self-Improving Stack 🧠

**Your agent gets better every day.** Installs 5 tools that make your agent catch mistakes, anticipate needs, adapt to how you work, store everything it learns, and extract reusable skills from wins.

## Install

```bash
clawhub install ai-agent-self-improving-stack
```

That installs all 5. Or pick individually:

```bash
clawhub install self-improving proactive learning memory hermes-learning-loop
```

## What Each Tool Does

| Tool | What It Does | Active On |
|------|-------------|-----------|
| **Self-Improving** | Catches mistakes, learns from corrections | Day 1 |
| **Proactive** | Anticipates needs, handles issues before they happen | Day 7+ |
| **Learning** | Adapts teaching style to how you learn best | Day 7+ |
| **Memory** | Infinite organized knowledge storage | Day 1 |
| **Hermes Learning Loop** | Turns success patterns into reusable skills | Day 14+ |

## How It Compounds

| Time | Improvement |
|------|-------------|
| Day 1 | Agent answers from base knowledge |
| Day 7 | Catches patterns from corrections |
| Day 14 | Anticipates needs based on history |
| Day 30 | 100+ facts, skills extracted from wins |
| Day 60 | Measurably better — learns from every interaction |

## Quick Start

```bash
# Install the stack
clawhub install ai-agent-self-improving-stack

# Ask your agent to use it
"Start using self-improving"
"Show me what you learned today"
```

## Notes

- No API keys required
- Works on Linux, macOS, Windows
- All data stays local in `~/self-improving/`
- Tools work together — each makes the others more effective
