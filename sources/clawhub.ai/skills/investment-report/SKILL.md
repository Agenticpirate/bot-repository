# A股个股深度投资报告生成器

为用户提供专业的A股个股深度投资研究报告，覆盖光通信、半导体、PCB、新材料、电子元器件等科技制造领域，以及有色金属、新能源、消费等全行业。

## 触发方式

用户提供公司名称（中文简称即可），即可触发报告生成。支持：
- 单个公司：「帮我写一份中际旭创的投资报告」
- 批量公司：「帮我写长飞光纤、华工科技、胜宏科技的投资报告」
- 指定日期：「现在是2026年8月6日，帮我写xxx的投资报告」

## 报告命名规则

文件名格式：`{主营业务}_{公司简称}_投资报告.md`

示例：
- `光模块_中际旭创_投资报告.md`
- `光纤光缆_长飞光纤_投资报告.md`
- `PCB_胜宏科技_投资报告.md`
- `钨钼新材料_厦门钨业_投资报告.md`

主营业务需简短概括公司最核心的业务板块（2-6字）。

## 报告结构（必须严格遵循）

报告按以下九个章节组织，每个章节必须填写完整，不得留空或写「待补充」：

1. **一、公司概况** — 基本信息表格 + 200-300字简介 + 发展历程
2. **二、详细业务构成** — 各业务板块的营收占比、毛利率、增速、竞争格局、新增长点
3. **三、预期营收及利润分析** — 历史财务 + 最新季度业绩 + 营收/利润预测 + 机构预测汇总
4. **四、公司价值判断——各板块估值** — SOTP分部估值 + 可比公司 + 历史估值 + 券商目标价
5. **五、投资逻辑与理由** — 3-5条核心逻辑 + 投资理由 + 短中长期催化剂
6. **六、交易计划** — 建仓策略表格 + 止盈止损 + 关键观察节点
7. **七、多维度深度分析** — 政策面/基本面/技术面/情绪面/消息面/资金面，各维度含核心分析+结论+星级评分
8. **八、风险提示** — 5条左右风险
9. **九、总结** — 100-200字核心观点 + 适合投资者类型

详细模板见 `references/template.md`。

## 工作流程

### 1. 信息搜集

对每个公司，使用 `mimo_web_search` 搜索以下信息（至少执行3-4轮搜索）：

**第一轮：基础数据**
- `{公司名} 2025年报 主营业务 营收 利润` — 获取最新年报数据
- `{公司名} 2026年一季报 业绩` — 获取最新季度数据

**第二轮：机构预测**
- `{公司名} 2026 业绩预期 券商研报 机构预测` — 获取市场一致预期
- `{公司名} 目标价 评级 买入` — 获取券商目标价和评级

**第三轮：SOTP估值参考**
- `{公司名} 分部估值 SOTP 券商研报` — 搜索其他券商的SOTP估值方法
- `{主营业务} 可比公司 PE 估值` — 获取可比公司估值数据
- `{公司名} 竞争对手 估值 市盈率` — 获取行业对比数据

**第四轮：消息面和资金面**
- `{公司名} 最新消息 利好 利空` — 获取近期消息面
- `{公司名} 资金流向 主力 北向` — 获取资金面数据
- `{公司名} 技术分析 K线 支撑 压力` — 获取技术面数据

搜索时以2025年年报数据为基础，2026年预测数据为重点。如有2026Q1数据必须纳入。

### 2. SOTP估值要求

**分部估值必须参考其他券商研报的估值方法：**

1. 搜索同行业公司近期券商研报，了解各业务板块通常给予的PE倍数区间
2. 参考券商对该公司已有的目标价和估值逻辑
3. 在SOTP表格中明确标注每个PE倍数的参考来源（如"参考国金证券"或"可比公司平均PE"）
4. 给出估值区间而非单一值（如"15-18x PE"）
5. SOTP表格下方需附估值说明，解释PE选取依据

### 3. 报告撰写

按照 `references/template.md` 的结构撰写报告。关键要求：

- **公司概况**：200-300字简介，包含核心竞争力定位、资源储量/产能等关键数据
- **业务构成**：每个核心业务单独展开，含指标表格+业务介绍+新增长点，内容详实不简略
- **财务预测**：给出2026E/2027E的营收和利润预测，附增速假设和逻辑说明
- **机构预测汇总**：列出3家以上机构的预测数据（机构名、日期、评级、净利预测、目标价）
- **分部估值**：SOTP法，各业务分别给予PE倍数，算出目标市值和每股价值，附参考来源
- **投资逻辑**：3-5条核心逻辑，分短中长期催化剂
- **交易计划**：建仓区间、止损位、目标位、持仓周期，用表格呈现
- **多维度分析**：每维度给出核心政策/消息/数据 + 具体分析 + 1-5星评分 + 一句话结论
- **风险提示**：5条左右具体风险
- **总结**：100-200字核心观点 + 适合投资者类型

### 4. 输出规则

- 报告写入用户指定的文件夹（默认工作区根目录）
- 使用 `write` 工具写入 `.md` 文件
- 批量报告时，先搜集完所有公司数据，再逐个写入
- 每写完一批（3-5个），给用户简要进度反馈
- 全部完成后，输出汇总清单
- 报告底部附免责声明

## 内容质量要求

**内容不要太少！** 每个章节必须充分展开：

- 业务构成：每个核心业务至少150-200字描述，含具体数据
- 财务分析：必须包含历史数据表格 + 预测表格 + 机构预测汇总表格
- SOTP估值：必须包含估值表格 + 估值说明 + 可比公司表格
- 投资逻辑：每条逻辑至少2-3句话展开
- 多维度分析：每维度至少5-8行分析内容
- 交易计划：必须用表格呈现建仓策略

## 六维分析框架

每份报告的第七章必须包含以下六个维度的深度分析：

| 维度 | 权重 | 核心关注点 | 评分标准 |
|------|------|-----------|---------|
| 政策面 | 15% | 产业政策、财税补贴、贸易政策、出口管制、监管趋势 | 政策利好程度 |
| 基本面 | 25% | 行业空间、竞争格局、公司质地、财务健康度、行业周期 | 行业+公司质量 |
| 技术面 | 15% | 趋势、均线、支撑压力、量价关系、形态、MACD/KDJ/RSI | 技术形态强弱 |
| 情绪面 | 15% | 市场情绪周期（冰点/发酵/高潮/退潮）、行业情绪、个股情绪 | 情绪位置 |
| 消息面 | 15% | 近期利好/利空消息梳理、核心催化 | 利好/利空程度 |
| 资金面 | 15% | 北向资金、主力资金、融资融券、机构持仓、大宗交易 | 资金流入/流出 |

每维度评分1-5星，加权计算综合得分。

## 批量生成策略

当用户要求生成多份报告（>5个公司）时：
1. 先用多个并行 `mimo_web_search` 搜集所有公司基础数据（每轮4个并行搜索）
2. 分批搜集完毕后，逐个用 `write` 写入报告文件
3. 每写完一批（3-5个），给用户简要进度反馈
4. 全部完成后，输出汇总清单

## 注意事项

- 数据以2025年年报为基础，预测至2026E/2027E。如有2026Q1数据必须纳入
- 所有财务数据需注明来源（年报/机构预测/估算）
- SOTP估值中的PE倍数必须注明来源（券商研报/可比公司/行业平均）
- 估值和交易计划仅为参考，报告末尾必须附免责声明
- 报告中的「当前」指用户指定的日期（默认今天）
- 技术面分析基于近期K线走势，需搜索最新股价信息
- 机构预测数据尽量引用3家以上券商
