
## 问答集锦
### Q1：支持哪些通知通道？
PRO版支持Telegram、钉钉、企业微信、飞书Webhook和邮件五种通道。可同时配置多个通道，告警按优先级自动路由.
### Q2：复合触发条件如何工作？
当所有条件（AND）或任一条件（OR）满足时触发告警。支持价格、成交量、技术指标等多种指标的组合。每个告警最多支持10个条件.
### Q3：告警去重如何工作？
PRO版在配置的去重窗口（默认5分钟）内，相同标的相同类型的告警只发送一次。避免因价格波动导致短时间内重复告警.
### Q4：富媒体消息支持哪些内容？
支持发送图表（自动生成价格走势图）、图片、交互按钮（如"查看详情"、"确认交易"）。图表数据实时获取并渲染.
### Q5：定时播报支持自定义内容吗？
支持。可通过自定义脚本生成播报内容，包括市场概况、持仓P&L、自选股变动等。支持Jinja2模板灵活定制消息格式.

## 功能边界
- **Bot Token依赖**: 必须配置有效的Telegram Bot Token才能使用核心功能
- **群组权限**: Bot需被添加为目标群组成员并具有发送消息权限
- **API频率限制**: Telegram API限制每秒30条消息，批量发送时自动排队
- **富媒体生成**: 图表生成依赖matplotlib，未安装时降级为纯文本消息
- **历史存储**: 历史记录功能依赖数据库，未配置时不影响告警功能
- **时区支持**: 定时播报使用配置的时区，默认为Asia/Shanghai
## 安全规范
- **无硬编码密钥**: 所有Bot Token、Webhook URL等凭证通过环境变量加载，不在代码中硬编码
- **无敏感信息泄露**: 日志中对Token、Webhook等敏感字段进行脱敏处理
- **凭证存储安全**: 配置文件建议加入.gitignore，避免泄露到版本控制系统
- **最小权限原则**: Bot仅授予发送消息权限，不需要管理员权限
- **数据传输加密**: 所有API调用使用HTTPS加密传输
- **无不可信外部调用**: 仅调用用户配置的通知通道API，不发起未授权请求

## 功能详解与边界条件
### 核心功能详解
1. **多群组广播**：支持同时向多个Telegram群组发送告警消息，各群组独立追踪发送状态。
2. **复合触发条件**：支持AND/OR逻辑组合多个触发条件，可基于价格、成交量、技术指标等。
3. **富媒体消息**：支持发送自动生成的价格图表、图片、交互按钮等富媒体内容。
4. **多通道通知**：除Telegram外，支持钉钉、企业微信、邮件等通道，按优先级自动路由。
5. **告警去重**：在配置的时间窗口内对相同标的的相同告警进行去重，避免重复打扰。
6. **定时播报**：支持按时间计划自动发送市场概况、持仓分析等定期报告。
### 边界条件
1. **群组数量限制**：单次广播最多支持50个群组。
2. **消息长度限制**：单条消息不超过4096个字符（Telegram API限制）。
3. **触发条件限制**：单个告警最多支持10个复合条件。
4. **定时任务限制**：最多支持50个定时任务。
5. **去重窗口**：默认300秒，可配置范围为60-3600秒。
6. **优先级级别**：支持critical、high、normal、low四个级别。
7. **API频率**：Telegram API限制每秒30条消息，超出自动排队。
8. **历史保留期**：历史记录默认保留365天。
### 性能指标
1. **消息发送延迟**：单条消息发送延迟<2秒。
2. **多群组广播**：10个群组广播完成时间<10秒。
3. **触发检测精度**：触发条件检测延迟<1秒。
4. **系统可用性**：系统可用性不低于99.5%。
5. **错误率**：消息发送错误率<0.1%。

## 错误恢复方案
针对Telegram告警专业版使用中可能遇到的常见问题,提供以下排查方案:
| 错误类型 | 原因分析 | 解决方案 |
|---------|---------|---------|
| API认证失败(401) | API密钥错误或过期 | 检查密钥配置,重新生成token |
| 接口限流(429) | 请求频率超出限制 | 降低调用频率,启用重试退避策略 |
| 响应超时(504) | 网络延迟或服务端负载过高 | 增加超时阈值,检查网络连接 |
| 文件不存在 | 路径错误或文件未创建 | 检查路径拼写,确认文件已生成 |
| 文件格式不支持 | 扩展名不在支持列表中 | 转换为支持的格式后重试 |
| 权限不足 | 当前用户无读写权限 | 检查文件权限,以管理员身份运行 |
| 命令执行失败 | 参数错误或环境依赖缺失 | 检查命令语法,确认依赖已安装 |
| 进程超时 | 命令执行时间过长 | 增加超时设置,优化命令参数 |
| 网络连接失败 | DNS解析失败或防火墙拦截 | 检查网络配置,确认代理设置 |
