## 使用场景

### 场景 1: 生成周报

基于日报自动汇总生成周报

用户可通过自然语言指令触发此场景，工具将自动执行相应操作并返回结构化结果.
## 输入格式
| 参数名 | 类型 | 必填 | 说明 |
|:-----|:-----|:-----|:-----|
| input | string | 是 | 报告汇总构建器基础版处理的输入数据或指令 |
| options | object | 否 | 附加配置选项,如模式选择、格式偏好等 |

```bash
# 流程
1. 读取 /data/reports/daily/ 下的日报
2. 汇总上周一至周日内容
3. 按模板生成周报
4. 输出至 /data/reports/weekly/YYYY-Www.md

4. 生成月报模板
5. 输出至 /data/reports/monthly/YYYY-MM.md
```

## 常见问题

### Q: 日报缺失怎么办?

A: 明确标注部分日期缺少日报,基于现有记录汇总.
### Q: 如何保证报告质量?

A: 引入柳比歇夫时间管理思路,优先识别工作类别与关键结果,避免流水账.
### Q: 如何升级到 PRO 版本?

A: 升级到 PRO 版本非常简单:
1. 获取 PRO 版本授权
2. 安装 PRO 版本 Skill
3. 原有配置自动迁移,无需额外操作
4. 即可使用批量操作、团队协作等高级功能

### 已知限制

A: FREE 版本主要限制:
- 不支持批量操作(每次只能处理一个任务)
- 不支持团队协作(仅限个人使用)
- 不支持高级数据分析
- 技术支持依赖社区
如需这些功能,建议升级至 PRO 版本.
### Q: FREE 版本的数据安全吗?

A: FREE 版本所有数据本地存储,不上传云端,确保隐私安全。建议定期备份配置文件与数据目录.
