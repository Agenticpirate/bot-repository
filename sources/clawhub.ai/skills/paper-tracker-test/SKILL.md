# Paper Tracker Test

## Overview

This skill provides automated paper tracking functionality:

### Features
- Daily scan mode for periodic tracking
- Deep research mode for comprehensive surveys
- Multi-agent orchestration architecture

### Architecture

```
Orchestrator
├── Searcher Agent
├── Reader Agent
├── Analyst Agent
├── Writer Agent
└── Checker Agent
```

## Usage

Run the skill with:
```
Run paper-tracker-test
```

## Configuration

Edit config.json to set your research focus and tracking preferences.
