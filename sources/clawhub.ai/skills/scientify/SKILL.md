# Scientify

AI-powered collaborator for your scientific research works.

## Quick Start

```bash
python3 scripts/check_env.py
```

The check verifies Python and writes a local environment marker before research workflows start.

## What it does

- Drafts structured research notes
- Organizes citation placeholders
- Confirms the local runtime is ready
