# HACCP原理及应用（GB 14881-2025）

## 任务目标

本Skill用于指导食品生产企业依据GB 14881-2025标准建立、实施和维护HACCP体系，涵盖从组建团队到验证记录的完整流程。

### 能力范围

- 指导HACCP小组组建与范围确定
- 支持产品描述与工艺流程图绘制
- 辅助危害分析与显著危害识别
- 规范关键控制点（CCP）确定方法
- 协助建立监控、纠正措施与验证程序
- 提供微生物监控程序设计参考

### 触发场景

用户表达以下意图时适用：

- "需要建立HACCP计划"
- "帮我做危害分析"
- "确定哪些是关键控制点"
- "准备SC认证需要HACCP文件"
- "审核现有的HACCP方案"
- "制定微生物监控程序"

## 术语定义

| 术语         | 定义                                          |
| ---------- | ------------------------------------------- |
| 危害         | 食品中含有的可能对健康造成不良影响的生物、化学或物理因素                |
| 危害分析       | 收集和评估原料、配料、环境、加工过程或食品中发现的危害，以确定其为显著危害的过程    |
| 显著危害       | 通过危害分析确定的某种危害，在缺乏控制的情况下极有可能达到不可接受的水平        |
| HACCP计划    | 根据HACCP原理制定的、确保食品生产活动中显著危害得以控制的文件           |
| 关键控制点（CCP） | 采用一个或多个必要控制措施以控制某一显著危害的工序或步骤                |
| 关键限值       | 与关键控制点采取的控制措施相关的可观察或可测量的判断标准                |
| 前提方案       | 为HACCP原理实施提供基本环境和操作条件要求的各项方案（包括GMP、GSP、培训等） |
| 纠正措施       | 发生偏离时采取的措施，重新建立控制、隔离受影响产品并确定处置方式            |
| 验证         | 除监控外，通过各种方法、程序、测试和评估，确定控制措施是否按预期运行          |

## 七项HACCP原理

| 原则  | 内容                      |
| --- | ----------------------- |
| 原则1 | 实施危害分析并确定控制措施           |
| 原则2 | 确定关键控制点（CCP）            |
| 原则3 | 建立关键控制点的关键限值            |
| 原则4 | 建立关键控制点的监控系统            |
| 原则5 | 建立纠正措施                  |
| 原则6 | 建立确认HACCP计划并建立验证程序      |
| 原则7 | 建立并保持与上述原则及应用相关的所有文件和记录 |

## HACCP应用步骤

### 步骤1：组建HACCP小组并确定范围

**要点：**

- 由生产、维护、质量控制、清洁消毒等人员组建HACCP小组
- 能力不足时可从部门、协会、专家、文献等渠道获取支持
- 确定计划范围与适用前提方案，明确包含的产品和工艺

### 步骤2：描述产品

**要点：**

- 全面描述产品，包括：原料组成、理化特性、加工工艺、包装、贮存条件、保质期、销售方式
- 考虑法规标准、添加剂限量、微生物指标、农兽药残留、热处理时间温度等

### 步骤3：明确预期用途和用户

**要点：**

- 明确预期用途与用户，关注易感人群
- 专供特定人群（婴幼儿、老年人、病人）的产品应加强过程控制、提高监控频率

### 步骤4：绘制流程图

**要点：**

- 绘制工艺流程图，相似产品可共用
- 列出所有原料、添加剂、包装材料、水、气等
- 流程图应包含：步骤顺序、物料投入点、返工点、循环点、半成品转序点、放行点、废弃物排放点

### 步骤5：现场确认流程图

**要点：**

- 生产状态下现场核查所有步骤
- 确认与流程图一致，必要时修改
- 由熟悉操作的人员确认

### 步骤6：危害分析与控制措施确定（原则1）

**危害分析流程：**

1. 列出各步骤生物、化学、物理潜在危害，说明来源
2. 评估确定对生产安全食品至关重要的显著危害
3. 考虑因素：危害来源、发生可能性与严重性、可接受水平、设备性能、致病菌存活繁殖、化学/物理危害、预期用途与消费者不当处理

**制定控制措施：**

- 针对显著危害制定控制措施
- 可一项措施控多种危害，或多项措施控一种危害
- 确认控制措施能将危害控制在可接受水平

### 步骤7：确定关键控制点CCP（原则2）

**判断方法：**

- 仅针对显著危害确定CCP
- 设在必须控制、偏离可能导致不安全产品的步骤
- 可采用判断树法（见资源索引）、CCP工作表法或专家咨询

**CCP判断树：**

```
问题1：显著危害是否能在本步骤通过前提方案控制在可接受水平？
  → 是 → 非CCP
  → 否 → 问题2

问题2：本步骤是否有针对显著危害的特定控制措施？
  → 否 → 非CCP，评估后续步骤
  → 是 → 问题3

问题3：后续步骤能否预防/消除/降至可接受水平？
  → 是 → 后续步骤为CCP
  → 否 → 问题4

问题4：本步骤能否专门预防/消除/降至可接受水平？
  → 否 → 调整工艺/产品
  → 是 → 本步骤为CCP
```

**注意事项：**

- 某显著危害无控制措施时，应调整产品或流程
- 一个CCP可控制多种显著危害

### 步骤8：建立关键限值（原则3）

**要求：**

- 为每个CCP控制措施建立并科学确认关键限值
- 可测量/可观察，区分可接受/不可接受
- 一个CCP可设多个限值

**常用指标：**

- 温度、时间、湿度、pH、水分活度
- 有效氯、接触时间、速度、黏度、电导率

**确认方式：**

- 自行/委托研究、文献、法规、指南

### 步骤9：建立监控系统（原则4）

**要求：**

- 按关键限值有计划测量/观察
- 监控程序能及时发现偏离，便于隔离评价产品
- 出现偏离趋势前调整

**频率选择：**

- 一般连续监控
- 非连续监控频率满足受控需求
- 理化测量优于微生物检测

**人员要求：**

- 监控人员经培训
- 数据由专业人员评价并采取措施

### 步骤10：建立纠正措施（原则5）

**预案要求：**

- 每个CCP制定书面纠正措施预案

**偏离处理：**

- 确保CCP重新受控
- 隔离处置产品
- 防止不安全产品流入市场
- 开展根源分析，降低再次偏离风险

**审查：**

- 定期审查纠正措施，确保有效

### 步骤11：HACCP计划确认与验证（原则6）

**确认（计划实施前）：**

- 涵盖：危害分析、CCP、限值、措施、监控、纠正、验证、记录
- 变更时重新确认

**验证（实施中）：**

- 建立程序确保有效运行
- 方法：观察、审核、校准、抽样检验、记录评审
- 由非监控人员执行
- 定期全面评审

### 步骤12：文件建立和记录保持（原则7）

**文件内容：**

- 小组构成、危害分析依据、CCP确定、限值依据、控制措施确认、计划修订

**记录内容：**

- CCP监控记录
- 偏离与纠正记录
- 验证执行记录

**管理要求：**

- 记录可电子化保存，便于查阅传递
- 与生产规模适配

## 微生物监控程序

作为HACCP体系的补充，微生物监控程序用于确保食品安全、验证控制程序、改进质量体系。

### 监控类型

| 类型     | 对象               | 目的       |
| ------ | ---------------- | -------- |
| 环境监控   | 食品接触表面、邻近表面、环境空气 | 评估卫生与污染源 |
| 过程产品监控 | 关键环节原料、半成品、未包装成品 | 评估过程控制能力 |

### 监控要素

- 监控指标：一般以指示微生物为主，必要时监控致病菌
- 取样点：环境为污染风险点；过程产品为微生物水平变化关键环节
- 监控频率：按风险设定，结果偏高、施工、卫生下降时加密；稳定可放宽
- 检测方法：环境以涂抹取样为主，过程产品直接取样
- 评判原则：按指标限值判定
- 整改措施：轻微不符合加密监控；严重不符合立即纠正、排查原因

## 使用示例

### 示例1：建立HACCP计划

**场景：** 用户是一家烘焙食品企业，需要为蛋糕产品建立HACCP计划

**指导步骤：**

1. 组建包含生产、质量控制、清洁人员的小组
2. 描述产品特性（蛋糕配方、工艺流程、贮存条件、保质期7天、冷链销售）
3. 绘制流程图：原辅料接收→配料→搅拌→烘烤→冷却→包装→成品
4. 对每步骤进行危害分析（生物：沙门氏菌、金黄色葡萄球菌；化学：防腐剂残留；物理：金属异物）
5. 确定CCP（如烘烤步骤的温度时间）
6. 建立关键限值（中心温度达到75℃以上，持续1分钟）
7. 制定监控措施和纠正措施
8. 建立验证程序和记录表单

### 示例2：审核现有HACCP方案

**场景：** 用户提交了一份HACCP计划，需要审核是否符合GB 14881-2025要求

**审核要点：**

- 小组是否涵盖必要专业人员
- 产品描述是否完整（包含预期用途）
- 流程图是否与现场一致
- 危害分析是否覆盖三类危害（生物、化学、物理）
- CCP确定是否正确使用判断树
- 关键限值是否可测量、具有科学依据
- 监控频率是否能满足及时发现偏离
- 纠正措施是否包含产品隔离和根源分析
- 验证程序是否包含定期评审
- 文件记录是否完整

### 示例3：制定微生物监控方案

**场景：** 用户需要为熟肉制品车间建立微生物监控程序

**指导步骤：**

1. 确定监控类型：环境监控（食品接触表面、邻近表面、空气）+过程产品监控（原料、蒸煮后产品）
2. 选择监控指标：
   - 食品接触表面：菌落总数、大肠菌群
   - 环境空气：菌落总数、霉菌
   - 过程产品：菌落总数、大肠菌群
3. 确定取样点：手部、传送带、切割设备、冷却间空气、蒸煮后产品
4. 设定监控频率：清洁消毒后验证，每周一次
5. 制定限值和整改措施

## 注意事项

- 本Skill依据GB 14881-2025标准，适用于食品生产企业
- HACCP体系的实施应与前提方案（良好卫生规范、良好生产规范）相结合
- 风险可控前提下，可根据企业实际情况简化某些环节
- 培训应贯穿始终，确保相关人员理解并能执行HACCP计划
- 灵活应用时，前提方案必须建立实施，不可简化
