# 极鲸云 SHEIN 商品搜索

## 遵守原则

- 只使用极鲸云返回的真实数据，明确区分接口事实、可复算指标和经营判断。
- 直接运行查询脚本并复用极鲸云 SHEIN Skills 的统一登录态；已有登录态可用时不得主动重新登录。仅在服务端明确要求操作时，按 [查询暂停与恢复流程](references/查询暂停与恢复流程.md) 暂停并等待。
- 默认使用简体中文和绝对日期；记录站点、币种、时间口径、筛选条件、分页范围、样本量和数据更新时间。
- 对缺失值、异常值、估算值和未完成分页作显式说明，不用不完整数据支撑强结论。
- 面向用户使用中文业务名称，不展示脚本命令、英文参数或原始 JSON；仅在用户明确要求开发对接、故障排查或原始响应时展示必要技术信息。
- 使用服务端原样返回的 `linkUrl`。每次展示商品时都将标题写成可点击的 Markdown 链接，不自行拼接或猜测链接。

## 执行工作流

1. 明确用户的决策问题、目标站点、时间范围、商品意图、托管模式、价格带和其他硬性条件。不会显著改变结论时采用合理默认值并说明。
2. 读取 [SHEIN 商品搜索](references/SHEIN商品搜索.md) 和 [SHEIN 商品搜索接口](references/SHEIN商品搜索接口.md)。只有用户要求热销、新品、蓝海、新店、大卖或其他榜单时，再读取 [SHEIN 商品榜单查询预设](references/SHEIN商品榜单预设.md)。
3. 未指定站点时使用默认入口 `1`（名称“全部”，当前映射 `us`，不是跨国家聚合）；用户明确指定美国站时使用 `2`。用户指定其他国家、地区、站点 UID 或域名时，运行 `python3 scripts/shein_site_list.py --country "国家或地区名"`；只接受唯一精确匹配，不猜测站点。
4. 生成全新的最小必要查询条件。仅在用户提供或上下文已有可信类目 ID 时使用类目筛选；没有可信类目 ID 时直接使用简洁关键词，不依赖其他 Skill 获取类目 ID，也不得根据类目名称猜测 ID。仅在用户明确要求类目内搜索特定商品时组合关键词和类目条件。
5. 运行 `python3 scripts/shein_goods_search.py`。认证模块自动读取统一登录态，不额外执行登录操作。
6. 检查响应、分页、关键字段、时间口径和可比性。服务端要求暂停时读取 [查询暂停与恢复流程](references/查询暂停与恢复流程.md)，恢复后使用原条件重跑。
7. 按用户问题完成排序、筛选和必要计算。请求完整分布时逐页查询；只允许访问前 10000 条，命中超过 10000 时应缩小筛选范围。只读取部分页面时明确标为样本，不将当前页外推为全市场。
8. 交付结论、数据口径、关键证据、机会与风险及下一步动作。用户只要搜索结果或链接时保持简洁。

## 保持业务口径

- 将 `sold/sales` 解释为最近销量/销售额，将 `totalSold/totalSales` 解释为累计总量；未确认固定窗口时不把最近口径硬写成 90 天。
- 将日、周、月变化率按小数比例解释：`0.25` 表示增长 25%，`-0.1` 表示下降 10%。
- 将商品价格和销售额按当前 SHEIN 站点币种解释，将供货价按人民币解释；计算利润前先统一币种并说明汇率口径。
- 将托管模式按 `1=全托管`、`2=半托管` 解释；未限定时不擅自选择。
- 将 `similarNum` 面向用户统一称为“同款数（跟卖数）”：不超过 10 为优选区间，11 至 20 为中等竞争，超过 20 为高竞争；结合销量、增长、价格、供货价、评分和上架时间综合判断。
- 将单次商品搜索视为当前条件下的商品样本。统一站点、币种、时间窗和筛选边界后再比较；口径不一致时停止直接排名。

## 检查交付结果

默认按以下顺序输出：

1. 一句话结论。
2. 数据口径：站点、时间、条件、分页范围、样本量和更新时间。
3. 关键发现：仅展示影响决策的销量、增长、价格、供货价、同款数（跟卖数）、评分或时间指标。
4. 机会与风险：说明证据、限制和置信度。
5. 行动建议：给出优先级、验证动作和进入门槛。

发送答复前逐项检查：服务端返回非空 `linkUrl` 的每个已展示商品，都必须以 `[商品标题](<linkUrl>)` 形式出现。
