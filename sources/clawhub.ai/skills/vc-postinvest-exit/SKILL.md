# VC 投后管理与退出（Post-Investment & Exit）

## 目的
把 VC 流水线的「投后 → 退出」环节标准化：针对被投项目产出**投后监控简报**与**退出策略建议**，带引用、可回溯，支撑组合管理与 LP 沟通。

## 何时使用
- 用户要求生成被投公司的经营/风险监控简报。
- 用户要求设计退出路径（IPO / 并购 / 回购）并做回报测算。
- 用于 ima 知识号「投后退出」系列内容。

## 使用说明

### 触发方式
- 自然语言：「给被投 XX 出一份投后监控简报」「设计 XX 的退出方案，算一下回报」。
- 或显式调用 `vc-postinvest-exit`。
- 命中关键词：投后 / 监控简报 / 风险预警 / 退出 / IPO / 并购 / 回购 / MOIC / IRR。

### 调用前准备
- 被投项目名、赛道、投资时估值 / 金额 / 持股比例、当前经营概览。
- 如有最新财报 / 里程碑优先采用；缺失项标「估算 / 假设」。
- 默认仅向当前用户返回 Markdown，不自动发布；如用户明确要求发布到 ima，再确认 `ima-mcp` 已连接。

### 执行流程
1. 识别子任务：投后监控简报 / 退出策略（可组合）。
2. 按方法论产出，经营数据逐期标注来源与时间。
3. 退出回报测算明示假设（估值 / 倍数 / 持股）。
4. 渲染 Markdown；（可选）仅在用户明确要求「发布到 ima」并二次确认目标空间、可见范围与敏感数据脱敏后，才执行发布。

### 结果交付
- 默认向当前对话返回 Markdown，不自动外传。
- 仅在用户明确要求并确认发布到 ima 后，才返回条目链接 / ID 与摘要。

## 核心方法论

### A. 投后监控简报（Post-Investment）
- 经营指标：收入/毛利/现金消耗/关键运营指标（对比投资时基准与上一期）。
- 里程碑：产品/客户/融资/监管等关键节点达成情况。
- 风险预警：偏离预期项、需投资人介入事项（红/黄/绿分级）。
- 建议动作：投资人可采取的增值/纠偏动作。

### B. 退出策略建议（Exit）
三路径对照：
| 路径 | 适用情景 | 关键考量 | 回报测算要点 |
|------|---------|---------|-------------|
| IPO | 规模大、合规完备、市场窗口好 | 时间表、估值锚、锁定期 | 发行估值 × 持股比例 − 成本 |
| 并购 | 战略协同方明确 | 买方画像、换股/现金、控制权 | 交易对价 × 比例 − 成本 |
| 回购 | 对赌/回购条款触发 | 创始人/公司偿付能力 | 回购价（本金+利息）× 比例 |

- 给出推荐路径、预计回报倍数（MOIC/IRR 占位）、关键前置条件与时间表。

## 输入要求
- 被投项目名称、赛道、投资时估值/金额/持股比例、当前经营概览。
- 如有最新财报/里程碑进展，优先采用。

## Prompt 模板
```

user: 被投：{name}（{sector}）

```

## 产出格式（Markdown）
- 简报：三栏（指标/里程碑/风险）+ 建议动作。
- 退出：三路径表格 + 推荐路径与 MOIC/IRR 占位。

## 使用示例

### 示例：投后简报 + 退出建议
**用户输入：**
> 被投：XX 储能（工商业储能）。投资：估值 2.5 亿、金额 5000 万、持股 20%。近期：营收从 2000 万增至 3500 万，新签 2 个园区，现金消耗加快。请出投后简报和退出建议。

**预期产出（节选）：**

**① 投后监控简报**
| 指标 | 投资时 | 当前 | 变化 |
|------|--------|------|------|
| 年营收 | 2000 万 | 3500 万 | ↑ 75% |
| 园区客户 | 3 | 5 | +2 |
| 现金消耗 | — | 加快 | 🟡 关注 |
- 风险预警：现金消耗加快（🟡 黄），需关注下一轮融资节奏。
- 建议动作：协助对接下一轮领投方，建立月度现金流看板。

**② 退出策略建议**
| 路径 | 适用情景 | 回报测算要点 |
|------|---------|-------------|
| IPO | 规模达 10 亿+营收、合规完备 | 发行估值 × 20% − 5000 万 |
| 并购 | 战略方（储能/电力）明确 | 交易对价 × 20% − 5000 万 |
| 回购 | 对赌触发 | 本金 + 利息 × 20% |
- 推荐路径：3–5 年内冲 IPO；若窗口不佳走并购。预计 MOIC 基准 3–5x（假设）。

## 引用与可回溯规范（强制）
- 经营数据逐期标注来源与时间；测算假设（估值/倍数/持股比例）必须明示。
- 无法核实的数据标「估算/假设」。

## 发布到 ima 知识号（可选，需用户明确确认）

> ⚠️ **数据安全提示**：本 skill 默认只向当前用户返回 Markdown 内容，**不会自动发布**到 ima 或任何外部账号。仅在用户明确说「发布到 ima」「同步到知识号」或类似指令时，才执行以下步骤。投后简报与退出策略通常包含被投公司经营指标、融资细节、风险标志、回报测算等敏感信息，发布前必须提示用户进行数据分级与脱敏确认。

1. **确认发布意图与数据分级**：向用户说明内容将离开当前系统、进入 ima 外部知识号，提示敏感信息风险，询问目标知识号 / 文件夹及可见范围，待用户明确回复「确认发布」后再继续。
2. **检查连接器**：确认 `ima-mcp` 已连接；未连接时询问用户是否前往连接器管理页完成 OAuth 授权。用户拒绝授权则仅返回本地 Markdown。
3. **执行发布**：调用 ima MCP 工具创建草稿 → 写入正文（保留引用）→ 发布到用户确认的目标空间。
4. **返回结果**：发布成功后返回条目链接 / ID 与一句话摘要；若取消或失败，返回本地 Markdown 并说明原因。
