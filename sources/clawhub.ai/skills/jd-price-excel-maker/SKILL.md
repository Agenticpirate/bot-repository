# 京东配置价格表生成器

## Overview

将用户给出的硬件配置清单转换为带京东链接与参考价格的 Excel 表格。工作流包括：解析配置项 → 通过搜索引擎查找京东商品/价格 → 汇总生成 Excel → 说明价格来源与限制。

## When to Use

- 用户发送一张包含电脑/服务器配置的图片，要求“查京东价格”或“做成 Excel”。
- 用户提供文本形式配置清单，希望补充京东链接和参考价。
- 需要为采购或装机做成本估算表。

## Workflow

### Step 1: 解析配置清单

1. 若用户提供了图片，先读取图片内容，逐行提取：类型、详细配置、数量。
2. 若用户提供的是文本，直接整理成结构化列表。
3. 对每一项生成一个或多个京东搜索关键词（保留品牌、型号、核心规格）。

### Step 2: 搜索京东价格与链接

1. **优先使用 WebSearch**，关键词格式示例：
   - `技嘉MS03-CE0 京东 价格`
   - `Intel Xeon 8481C 京东 价格`
   - `coolserver 4677M96 site:item.jd.com`
2. 从搜索结果中提取：
   - 京东商品页链接（`item.jd.com` 或 `jingfen.jd.com` 分享链接）
   - 商品价格（页面价/常卖价/促销价）
   - 店铺名称、品牌、规格
3. **京东反爬限制处理**：
   - 不要直接高频访问 `search.jd.com` 或 `item.jd.com`，会被频控拦截。
   - 若商品页无法直接打开，可借助 `www.baidu.com/s?wd=关键词+京东`、`detail.zol.com.cn`、`m.smzdm.com` 等第三方平台获取“京东在售价格”。
   - 在 Excel 备注中说明价格参考来源。

### Step 3: 汇总生成 Excel

1. 使用 Python + openpyxl 创建 `.xlsx` 文件。
2. 表格列建议：类型、详细配置、数量、单价（元）、小计（元）、京东链接、备注。
3. 将“京东链接”列设置为可点击超链接。
4. 添加合计行与说明文字，注明：
   - 价格获取时间
   - 部分商品无单独零售的情况
   - 价格参考来源

### Step 4: 交付

1. 保存 Excel 到工作区根目录，文件名如 `电脑配置京东价格表.xlsx`。
2. 使用 `present_files` 工具展示给用户。
3. 在回复中简要说明：总价、哪些商品无单独京东零售价、价格波动风险。

## Important Notes

- **OEM/定制 CPU**：如 Intel Xeon 8481C 这类 Google/OEM 定制型号，京东通常只有整机/准系统销售，无单独散片。需在表格中明确标注，并提供整机/准系统参考价。
- **品牌多选一**：若原配置写“海力士/三星/镁光”等并列品牌，选择其中一家京东有明确报价的品牌填入，并在备注说明为“三选一参考”。
- **价格时效**：京东价格变动频繁，表格中的价格仅为搜索时的参考价，最终以下单页面为准。
