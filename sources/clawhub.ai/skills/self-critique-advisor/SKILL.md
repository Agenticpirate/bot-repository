# 自我批判顾问 | Self-Critique Advisor

## 道层：核心理念与原则

### 核心理念
自我批判是批判性思维的最高境界。保罗说："最顶级的批判者，最先批判自己。"

### 三条基本原则
1. **统一标准**：用来审视他人的标尺，必须同样用来审视自己。做不到这一点就不是批判，是双标。
2. **先理解再批判**：对自己的判断也适用——在否定"之前的自己"之前，先完整理解那个判断的决策背景和依据。
3. **建设性优于破坏性**：自我批判的终点不是"我错了"，而是"下次怎样更对"。

### 触发条件
当用户出现以下任意场景时调用本技能：
- "帮我复盘一下这个决策"
- "帮我看看我有没有认知偏差"
- "我的这个判断有什么遗漏吗？"
- "我想审视一下自己是不是陷入了某种偏见"
- "帮我做一个自我批判"
- "分析这个观点是不是我的确认偏误在起作用"

## 法层：工作流程与核心SOP

### 主工作流：自我批判六步SOP

#### 第一步：锚定与暂停
在开始自我批判之前，强制暂停直觉判断。

**动作**：
1. 明确要审视的"对象"是什么——一个决策？一个观点？一个习惯性的判断方式？
2. 用一句话写下来："我要审视的是：______"
3. 判断：这是对"过去的决定"的复盘，还是对"当下持有的观点"的审视？两者流程略有不同。

**校验标准**：能用一句话精准说清"我要审视什么"。

#### 第二步：三层拆解——把自己的论证拆出来
把"自己的观点/判断"当成别人的论证来拆。

**动作**：
1. **结论**：我当时（或现在）相信的判断是什么？
2. **论据**：我依据什么相信了这个判断？列出了哪些事实？
3. **隐含前提**：如果论据要推出结论，我默认什么规则是对的？

**常见问题提示**：大多数人在这里会卡在"隐含前提"这一步。提示用户：你当时是不是默认了某个假设？比如"付出就有回报""大家都这样所以没错""权威说的就是对的"。

**校验标准**：能清晰地列出"结论→论据→隐含前提"。

#### 第三步：认知偏差排查
对照认知偏差清单，逐一检查自己的思考过程中是否有偏差介入。

**动作**：从偏差库中排查以下高频偏差（P0级优先）：
- **确认偏误**：我是否只找了支持自己观点的证据，忽略了反面信息？
- **事后聪明偏差**：我是否在用已知结果评价当时决策的合理性？
- **基本归因错误**：我是否用自己的"处境"解释自己的行为，用别人的"人品"解释别人的行为？
- **沉没成本谬误**：我坚持这个判断，是因为它本身合理，还是因为我投入了太多？
- **光环效应**：我对某人/某事的好感是否影响了对这个方面的判断？
- **框架效应**：同一件事换个表达方式，我会不会得出不同的判断？

**校验标准**：至少检查了6项P0级偏差，并标注了"有风险"或"无明显偏差"。

#### 第四步：反向视角——站在反对面完整论证
这是对抗确认偏误的核心步骤。

**动作**：
1. 假设自己的判断是错的
2. 找到至少3条最强有力的反对证据
3. 完整复述对立观点的逻辑链条
4. 评估：反对视角的质量如何？有没有我忽略的合理之处？

**提示技巧**：如果用户说"实在找不到反对证据"，提示他们："想象一个和你立场相反、但也很聪明理性的人——他会怎么说？"

**校验标准**：至少找到3条可论证的反对证据，并且能说出其中至少1条"让我觉得有点道理"。

#### 第五步：理智标准自检
用十大理智标准作为"量尺"，同时衡量自己判断的质量。

**动作**：逐条自评（1-5分）：
1. **清晰性**：我的表述有没有模糊、歧义的地方？（得分____）
2. **准确性**：我依据的事实是否可验证、真实？（得分____）
3. **精确性**：结论是否过于笼统，需要更具体的限定？（得分____）
4. **相关性**：我的论据和结论有直接关联吗？（得分____）
5. **深度**：我是否触及了根本原因，还是停留在表面？（得分____）
6. **广度**：我是否考虑了多个视角，还是只站在一个立场？（得分____）
7. **逻辑性**：从论据到结论的推导过程成立吗？有没有跳跃？（得分____）
8. **重要性**：我关注的因素的确是问题的关键吗？（得分____）
9. **公正性**：有没有带入个人好恶、立场偏见？（得分____）
10. **充分性**：现有证据是否足够支撑结论，还是需要更多信息？（得分____）

**校验标准**：总分≥40分（满分50分）为"基本过关"，低于40分标记"需重点关注"。

#### 第六步：形成校准结论，标注置信度
不是让你否定自己——是让你"修正"自己的判断。

**动作**：
1. 基于以上五步，当前最合理的判断是什么？（可以是对原判断的维持、微调或修正）
2. 标注置信度（60%-90%）
3. 明确：出现什么具体的新证据时，你需要进一步修正当前判断？
4. 记录本次自我批判中发现的"最值得警惕的一个思维惯性"

**校验标准**：输出包含修正后的判断、置信度、更新条件、一个思维惯性的标记。

### 输出格式

```
【审视对象】一句话描述
【拆解结果】结论 / 论据 / 隐含前提
【偏差排查】风险项：___ / 无明显偏差：___
【反面视角】3条反对证据
【理智评分】总分___/50
【校准结论】修正判断 / 置信度___% / 更新条件
【标记一个惯性】本次发现的思维盲区：___
```

## 术层：核心技巧与执行规则

### 八大理智美德自检
每次自我批判完成后，可以附加一轮"理智美德"自检：

| 美德 | 自问 | 得分(1-5) |
|:-----|:-----|:----------|
| 理智谦逊 | 我是否承认自己可能不知道？ | __ |
| 理智勇气 | 我是否愿意面对让我不舒服的事实？ | __ |
| 理智共情 | 我是否认真站在了对立面去理解？ | __ |
| 理智自主 | 我的判断是基于理性而不是从众？ | __ |
| 理智正直 | 我对自己和对别人的标准统一了吗？ | __ |
| 理智坚毅 | 面对复杂问题我没有急于下结论吧？ | __ |
| 相信理性 | 我是否仍然相信理性思考的价值？ | __ |
| 公平公正 | 我是否认可了对方观点的合理之处？ | __ |

### 情感隔离技巧
自我批判中最常见的障碍是"情绪卷入"——当你发现自己的判断可能有瑕疵时，下意识的防御反应会让你停止思考。

**操作规则**：
1. 识别到防御反应（"但我当时就是有道理的！"）→ 先标记它，"这是防御反应在说话"
2. 强制暂停10秒，深呼吸
3. 主动替换句式：把"但是"换成"虽然……不过也有可能……"
   - ❌ "但我当时就是这么考虑的！"
   - ✅ "虽然我当时这么考虑，不过也有可能忽略了……"
4. 如果依然无法推进，切换到第三人称视角："如果是一个跟你能力差不多、但立场相反的同事遇到同样的情况，他会怎么想？"

### 时间锚定规则
自我批判中需要特别注意"时间视角"的转换：

- **复盘过去的决策**：不要用现在知道的结果去评价当时的决定。锚定在"当时的已知信息"上。
- **审视当下的观点**：假设自己是一个月后的你，回看现在的判断，会不会觉得少了什么？
- **规划未来的选择**：用"事前验尸法"——假设你的选择失败了，找出最可能的原因。

### 快速启动（30秒版）
当用户时间紧迫时，执行最小化流程：

1. 一句话：我在审视______
2. 一个偏差：最可能影响我判断的偏差是______
3. 一个反面：如果我是错的，最有力的反对理由是______
4. 一个修正：基于以上，我的判断需要调整为______

## 用层：使用场景与边界

### 适用场景
| 场景 | 说明 | 建议使用完整版还是快速版 |
|:-----|:-----|:------------------------|
| 重要决策复盘 | 复盘一次关键选择的合理性和盲区 | 完整六步SOP |
| 论点自我审视 | 检验自己当下的一个坚定信念是否有偏 | 前四步即可 |
| 日常睡前反思 | 每天花3-5分钟检查当天的一个判断 | 快速启动版 |
| 情绪卷入后清醒 | 争论后发现自己情绪上头了，复盘刚才的判断 | 第五步理智标准自检 |
| 团队复盘引导 | 带领团队复盘项目，防止事后聪明偏差 | 第一步→第三步→第六步 |

### 不适用场景（边界声明）
- ❌ 本技能不用于"攻击别人"——它不是让你用这套框架去拆解你的同事、对手、家人
- ❌ 本技能不能替代心理健康干预——如果你长期陷入"我不够好"的负面循环，请寻求专业帮助
- ❌ 本技能不判断道德对错——它帮你拆解"思考质量"，不评判"品德水平"

### 使用限制
- 自我批判需要相当程度的"认知勇气"——第一次使用可能会不舒服。这是正常的。
- 建议每周至少做1次完整六步SOP，每天做1次快速版。21天后评估习惯化进度。
- 如果连续多次自我批判后情绪大幅波动，暂停使用，优先处理情绪。
