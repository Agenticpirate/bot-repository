# VC LP 报告与知识管理（LP & Knowledge）

## 目的
把 VC 流水线的「LP 沟通 / 知识沉淀」环节标准化：产出**LP 季报要点**、**基金表现摘要**、**募资材料**，并支持**基于知识库的投资认知问答**（带引用出处），支撑对外沟通与内部知识复用。

## 何时使用
- 用户要求生成 LP 季报 / 基金更新 / 募资材料。
- 用户就投资主题、方法论、历史案例提问，要求基于知识库作答并附引用。
- 用于 ima 知识号「LP 与认知」系列内容。

## 使用说明

### 触发方式
- 自然语言：「生成 Q2 基金 LP 季报要点」「帮我写一份募资材料」「基于知识库回答：早期基金怎么看团队？」。
- 或显式调用 `vc-lp-knowledge`。
- 命中关键词：LP 季报 / 基金更新 / 募资 / 知识库问答 / 引用 / 认知。

### 调用前准备
- LP 报告：基金名、季度、组合数据、关键事件。
- 知识问答：自然语言问题；可选限定主题 / 文档范围。
- 默认仅向当前用户返回 Markdown，不自动发布；如用户明确要求发布到 ima，再确认 `ima-mcp` 已连接。
- 知识问答基于已授权知识库。

### 执行流程
1. 识别子任务：LP 报告 / 基金更新 / 募资材料 / 知识库问答。
2. 报告类数字须来源可查；问答类须逐条引用知识库片段。
3. 无依据不编造，明确「无依据」。
4. 渲染 Markdown；（可选）仅在用户明确要求「发布到 ima」并二次确认目标空间、可见范围与敏感数据脱敏后，才执行发布。

### 结果交付
- 默认向当前对话返回 Markdown，不自动外传。
- 仅在用户明确要求并确认发布到 ima 后，才返回条目链接 / ID 与摘要。

## 核心方法论

### A. LP 报告 / 基金更新
- 组合表现：被投组合概览、里程碑进展、估值/回报变化（对比上季）。
- 关键事件：新投资、后续轮、退出、重大风险。
- 下期展望：重点投向、基金动作、需 LP 知晓事项。
- 语气：专业、克制、对结果负责；不确定项标「预估」。

### B. 知识库问答（RAG）
- 基于机构知识库（方法论、行研、历史案例）检索相关片段。
- 回答须逐条标注引用（文档名 + 片段）；无相关依据时明确回答「无依据」，不得编造。
- 支持多轮追问，后续问题感知前文。

## 输入要求
- LP 报告：基金名、季度、组合数据、关键事件。
- 知识问答：自然语言问题；可选限定主题/文档范围。

## Prompt 模板
```
# LP 报告
system: 你是 VC 基金 IR/PR 负责人，撰写面向 LP 的专业、克制、可回溯的季度更新。
user: 基金：{fund} 季度：{quarter} 组合与事件：{data}
请产出 LP 季报要点（组合表现/关键事件/下期展望）。

# 知识问答
system: 你是机构研究助手，仅基于提供的知识库片段作答并标注引用；无依据时说「无依据」。
user: 问题：{question} 相关片段：{retrieved}
```

## 产出格式（Markdown）
- LP 季报：三节（组合表现/关键事件/下期展望），关键数字表格化。
- 问答：正文 + 「引用」小节（[1] 文档名 p.x：片段）。

## 使用示例

### 示例 1：LP 季报
**用户输入：**
> 基金：先锋一号。季度：2026 Q2。组合：12 家被投，2 家后续轮（估值平均 +40%），1 家里程碑退出（MOIC 3.2x），1 家现金消耗预警。请出 LP 季报要点。

**预期产出（节选）：**
```
# 先锋一号 · 2026 Q2 LP 更新
**组合表现**：12 家在管，2 家完成后续轮（估值 +40%），组合账面回报回升。
**关键事件**：A 项目里程碑退出（MOIC 3.2x）；B 项目现金消耗预警（已介入）。
**下期展望**：聚焦 AI+储能延续投资；Q3 启动二期募资路演。
> 数字来源：基金台账（2026-06-30）。
```

### 示例 2：知识库问答
**用户输入：**
> 基于知识库回答：早期基金怎么评估创始人团队？

**预期产出（节选）：**
早期基金看团队，核心是三点：① 产业背景与赛道匹配度；② 创始人互补性与执行力；③ 股权与激励安排是否合理。

**引用**
- [1]《VC 投研方法论》p.12：四维评分卡—团队维度权重 0.25，重点看互补性与执行力。
- [2]《早期投资案例集》p.5：失败案例多因创始人股权分散、关键人离职。

## 引用与可回溯规范（强制）
- LP 报告数字须来源可查；问答必须逐条引用知识库片段。
- 无依据不编造，明确「无依据」。

## 发布到 ima 知识号（可选，需用户明确确认）

> ⚠️ **数据安全提示**：本 skill 默认只向当前用户返回 Markdown 内容，**不会自动发布**到 ima 或任何外部账号。仅在用户明确说「发布到 ima」「同步到知识号」或类似指令时，才执行以下步骤。LP 季报、募资材料和知识库问答结果可能包含基金绩效、投资组合、LP 信息、内部研究等机密内容，发布前必须提示用户进行数据分级与脱敏确认。

1. **确认发布意图与数据分级**：向用户说明内容将离开当前系统、进入 ima 外部知识号，提示敏感信息风险，询问目标知识号 / 文件夹及可见范围，待用户明确回复「确认发布」后再继续。
2. **检查连接器**：确认 `ima-mcp` 已连接；未连接时询问用户是否前往连接器管理页完成 OAuth 授权。用户拒绝授权则仅返回本地 Markdown。
3. **执行发布**：调用 ima MCP 工具创建草稿 → 写入正文（保留引用）→ 发布到用户确认的目标空间。
4. **返回结果**：发布成功后返回条目链接 / ID 与一句话摘要；若取消或失败，返回本地 Markdown 并说明原因。
