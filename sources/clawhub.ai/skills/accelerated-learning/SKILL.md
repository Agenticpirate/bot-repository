# 10步加速学习法 - 交互式学习指引

## 概述

当用户想要学习或研究某个【主题】时，本skill提供一套结构化的10步学习流程。每一步都可以独立执行，用户可根据需要选择全部或部分步骤。

## 核心流程

### 启动流程

当用户提及想要学习某个主题（或用"学习【XXX】""研究【XXX】""快速掌握【XXX】"等表达）时：

1. **确认主题**：如果用户已经明确主题，直接进入步骤菜单。如果主题不明确，先询问："你想学习/研究的【主题】是什么？"
2. **展示菜单**：用以下格式展示10个步骤供用户选择：

```
📚 **10步加速学习法 · 菜单**

请选择一个步骤开始（输入数字或名称皆可）：

| # | 步骤 | 说明 |
|---|------|------|
| 1 | 🔍 五视角STORM | 5位专家从不同视角分析你的主题 |
| 2 | 🗺️ 矛盾图谱 | 找出各视角的冲突与共识 |
| 3 | 📋 综合简报 | 整合成一份完整的调研简报 |
| 4 | ✅ 同行评审自检 | 对简报进行严格的可靠性审查 |
| 5 | 📖 资源筛选 | 精选5个最值得用的学习资源 |
| 6 | 🪜 学习阶梯 | 从零到精通的5级进阶路径 |
| 7 | ⚡ 2小时核心20% | 用2小时啃下最有价值的20% |
| 8 | 🎯 考到我崩溃 | 交互式测验，逐题深挖理解边界 |
| 9 | 🧠 费曼循环 | 交互式教与学，直到彻底讲清楚 |
| 10 | 📝 一页速查表 | 生成实战速查表，5分钟快速回顾 |

你也可以输入：
- `全部` → 按顺序执行所有步骤
- `1-5` → 执行第1到第5步
- `查看进度` → 查看已完成和未完成的步骤
```

3. **执行步骤**：根据用户的选择，调取下方对应步骤的prompt模板执行。
4. **追踪进度**：在每次执行完一个步骤后，简要更新进度状态。

### 步骤执行规则

- **一次性步骤（1-7, 10）**：直接输出完整结果，一步到位。
- **交互式步骤（8, 9）**：严格遵循规则进行对话式交互：
  - 步骤8（考到我崩溃）：一次只问一个问题，等用户回答后给予评分和反馈。
  - 步骤9（费曼循环）：先用简单的语言讲解，然后让用户复述，找出漏洞后重新教，循环直到用户讲清楚。

## 步骤1：五视角STORM

**prompt模板**（将 `{主题}` 替换为用户的主题）：

```
我要研究【{主题}】。
请模拟5位不同的专家，从各自的视角分析这个主题：

1. **实践者**：每天跟这东西打交道的人。
   - 他们知道哪些学者不知道的事？哪些实际情况总是被忽略？

2. **学者**：研究这个领域多年的人。
   - 同行评审的证据到底说了什么？证据在哪些地方和大众认知相反？

3. **怀疑者**：认为主流观点有问题的人。
   - 最强的反方论点是什么？支持者们刻意忽略了哪些证据？

4. **经济学家**：盯着钱流向的人。
   - 谁在从当前的叙事里获利？哪些利益在影响这个领域的结论？

5. **历史学家**：见过类似规律的人。
   - 历史上有什么相似的先例？那些先例最后是怎么收场的？

每个视角请给我：
- 两句话说清他的核心立场
- 支持他观点的最强证据
- 一件只有他会告诉我、其他视角绝不会提的事
```

## 步骤2：矛盾图谱

**prompt模板**：

```
基于上面5个视角对【{主题}】的分析，给我画一张矛盾图：
- 哪些视角在直接冲突，各自的依据是什么；
- 谁的证据最强、谁的最弱、为什么；
- 哪一个问题一旦有答案，就能化解最大的矛盾；
- 所有视角都同意的是什么（这大概率是真的）；
- 没有任何视角提到的是什么（这可能是整个领域的盲区）。
```

> **注意**：如果用户没有先执行步骤1，则先执行步骤1再执行步骤2，因为步骤2依赖步骤1的输出。

---

## 步骤3：综合简报

**prompt模板**：

```
把对【{主题}】的5个视角分析和矛盾图综合成一份调研简报：
- 一段话总结（讲给只有60秒的CEO听，要细节，不要标题党）；
- 5个关键发现，按可靠性排序，标注哪些视角支持、哪些反对；
- 一个只有把5个视角放在一起才能看到的隐藏关联；
- 一条具体的行动建议（以我的角色，我该做什么不一样的事）；
- 一个前沿问题（它的答案会改变我们对这个主题的全部理解）。
```

> **注意**：如果用户没有先执行步骤1和2，则先执行步骤1和2再执行步骤3。

---

## 步骤4：同行评审自检

**prompt模板**：

```
现在请你对刚才关于【{主题}】的这份简报做一次同行评审：
- 给5个关键发现逐个打1-10的可靠性分，并解释理由；
- 你最没把握的是哪个结论，需要什么信息才能验证它；
- 哪个视角在综合时占的比重过大了；
- 有没有第6个视角是该加进来、加了会改变结论的；
- 如果一位斯坦福教授来评审这份简报，会打几分，会让我改什么。
```

> **注意**：如果用户没有先执行步骤3，则先执行步骤1→2→3再执行步骤4。

---

## 步骤5：资源筛选

**prompt模板**：

```
关于【{主题}】的资源太多了，我不想再收藏了。
请你当一个只帮我省时间的策展人：
- 选出5个最值得用的资源（书、视频、课程、社区都行），每个说清楚：
  - 它为什么比同类强
  - 该怎么用（读/看/练）
  - 大概要花多久
  - 我该从它身上拿走的一个关键点
- 再告诉我哪些是被高估的、我该躲开的坑；
- 最后把这5个排成一条一周能走完的学习路径。
```

## 步骤6：学习阶梯

**prompt模板**：

```
我想一步一步地学习【{主题}】，不跳过任何重要的基础。
请你扮演一位专家教师和技能教练，把【{主题}】分解为5个清晰的难度级别，从完全初学者到自信的实践者。

每个级别包括：
1. 级别名称
2. 这个阶段我应该理解什么
3. 在这个级别上"掌握"是什么样子
4. 最需要重点关注的概念或技能
5. 一个证明我可以进入下一级别的里程碑
6. 一个动手练习或小型项目
7. 这个级别的学习者常犯的错误
8. 进入下一级别前的一个简单自测问题

按这个结构组织级别：
- 级别1：完全初学者
- 级别2：基本理解
- 级别3：实际使用者
- 级别4：问题解决者
- 级别5：自信的实践者

解释保持实用、对初学者友好，专注于真正的进步。
```

## 步骤7：2小时啃下核心20%

**prompt模板**：

```
我想用2个小时学【{主题}】。
请先找出能带来80%实际效果的那20%的概念和技能，解释它们为什么是核心；
然后排成10次课的学习计划，每次课约12分钟，包含：
- 学习目标
- 关键概念
- 一个动手练习
- 一个推荐资源（最好免费）
- 完成后的预期结果

每次课结束，给我5个复习题；
全部10次课结束后，给我一个能证明我真的可以上手用的最终小项目。
```

## 步骤8：考到我崩溃（交互式）

**交互式执行规则**：

这是交互式步骤，必须严格遵循以下规则：

```
我刚学完【{主题}】，想测试自己到底理解了多少。
请你扮演一位严格但乐于助人的考官，通过主动回忆找出我理解的边界。

从10个问题开始，一次只问一个。

规则：
1. 问题逐渐变难：第1-3题初级，第4-6题中级，第7-8题高级，第9-10题专家级。
2. 一次只问一个问题，等我回答。
3. 每个回答之后，做四件事：
   - 给我的答案打0到10分；
   - 告诉我哪里答对了；
   - 指出确切的差距、错误或薄弱点；
   - 用简单的语言重新解释我漏掉的部分。
4. 如果我答得很弱，先追问一个相关问题，再进入下一题。
5. 如果我答得很好，稍微增加难度。
6. 最后给我：最终得分、我最强的领域、我最弱的领域、一个简短的复习计划、5个最终挑战题。

不要一次给我所有答案。让这像一场真实的学习面试。
现在开始第1个问题。
```

**执行要点**：
- 每次只发一个问题，等待用户回复
- 评分要诚实但有建设性
- 追问只在用户明显薄弱时使用
- 结束时要给出完整的总结报告

## 步骤9：费曼循环（交互式）

**交互式执行规则**：

这是交互式步骤，必须严格遵循以下规则：

```
我想用费曼学习法吃透【{主题}】。
请你当一个有耐心的学习伙伴：
- 先用简单的词、生活里的例子把它讲给我听，就当我12岁；
- 然后让我用自己的话复述一遍；
- 接着找出我复述里每一个含糊、跳步、绕不过去的地方，只重新教这些部分；
- 再让我讲一遍。

循环下去，直到我的解释简单、准确、完整。在我讲清楚之前，别进入新内容。
```

**执行要点**：
1. 第一轮：用大白话和简单比喻讲解核心概念（3-5分钟阅读量）。
2. 提示用户用自己的话复述。
3. 仔细分析用户复述中的每一个模糊点、跳步和不准确之处。
4. 只针对这些薄弱点重新教学，用新的比喻或角度。
5. 再次让用户复述。
6. 循环直到用户能清晰、准确、完整地解释核心概念。
7. 最后肯定用户的进步，总结学到的内容。

## 步骤10：一页速查表

**prompt模板**：

```
给我做一份关于【{主题}】的一页速查表，让我在要用它之前，花5分钟就能过完：
- 一句大白话定义；
- 最重要的概念、规则、公式或步骤，全用短条目，别用长段落；
- 3-5个真实场景的例子；
- 新手最容易犯的错、最容易混淆的地方；
- 一份"上场前"检查清单；
- 最后加5个快问快答，测测我还记得多少。
```

## 进度追踪

每次执行完一个步骤后，用以下格式更新进度：

```
📊 **学习进度：{主题}**

已完成：步骤1 ✓ → 步骤2 ✓ → 步骤3 ✓
当前：步骤4 ←
待完成：步骤5 · 步骤6 · 步骤7 · 步骤8 · 步骤9 · 步骤10

[继续当前步骤 · 跳转到其他步骤 · 查看菜单]
```

始终记住用户的主题，贯穿所有步骤使用。
