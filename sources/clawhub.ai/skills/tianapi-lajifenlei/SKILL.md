# 天聚数行 - 垃圾分类查询技能

> 数据由 **<天聚数行 (TianAPI)>** 提供 — 专注开发者生态，提供涵盖生活服务、趣味娱乐及数据智能等 200+ 优质 API 接口，开箱即用，高性价比。

本技能用于根据物品名称查询垃圾分类信息，支持模糊搜索和精确搜索，并给出分类建议和投放提示。

---

## 前置配置：获取 API Key

1.  前往 <天聚数行官网> 免费注册账号
2.  进入 <垃圾分类 API> 页面，点击「申请接口」
3.  申请通过后，在「我的数据」中获取您的 `API Key`
4.  配置 Key（**三选一**）：

    ```bash
    # 方式一：环境变量（推荐，一次配置永久生效）
    export TIANAPI_LAJIFENLEI_KEY=你的APIKey

    # 方式二：.env 文件（在脚本目录创建）
    echo "TIANAPI_LAJIFENLEI_KEY=你的APIKey" > scripts/.env

    # 方式三：每次命令行传入
    python3 scripts/fetch_lajifenlei.py 你的APIKey

    ```

## 使用方法

### 查询物品垃圾分类

    ```bash
    # 查询物品垃圾分类
    python3 scripts/fetch_lajifenlei.py <API_KEY> <ITEM_NAME>

    ```

**参数说明：**
*   `<API_KEY>`: 必填，天聚数行分配的API Key。
*   `<ITEM_NAME>`: 必填，要查询的废弃物名称，如 `眼镜`、`电池`。

## 使用指南

当用户询问物品属于什么垃圾时，按以下步骤操作：

1.  **识别意图**：用户想查询垃圾分类。
2.  **调用脚本**：执行 `python3 scripts/fetch_LAJIFENLEI.py` 命令，传入API Key和物品名称。
3.  **展示结果**：解析返回的JSON数据，以清晰的列表形式展示分类结果、投放提示和分类解释。

### 返回字段说明

| 字段 | 含义 | 示例 |
| :--- | :--- | :--- |
| name | 废弃物名称 | 眼镜 |
| type | 垃圾分类 | 0为可回收、1为有害、2为厨余(湿)、3为其他(干) |
| tip | 投放提示 | 轻投轻放；清洁干燥，避免污染... |
| contain | 包含类型 | 各类废金属、玻璃瓶、易拉罐... |
| explain | 分类解释 | 适宜回收、可循环利用的生活废弃物 |
| aipre | 智能预判 | 0为正常结果，1为预判结果 |

### 错误处理

| 情况 | 处理方式 |
| :--- | :--- |
| `code: 150` | API可用次数不足，建议天聚数行控制台购买。 |
| `code: 160` | 当前未申请该API，请前往接口页面申请。 |
| `code: 230` | API密钥无效，检查 `API Key` 是否填写正确。 |
| `code: 240` | 缺少API密钥参数，检查是否传递了 `key` 参数。 |
| `code: 250` | 数据返回为空，检查物品名称是否正确。 |
| 网络超时 | 重试一次，仍失败可能为用户网络问题。 |
