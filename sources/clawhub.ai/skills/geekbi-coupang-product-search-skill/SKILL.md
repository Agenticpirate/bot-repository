# 极鲸云 Coupang 商品搜索

## 原则

- 当前仅支持韩国站 `siteId=1`，币种 KRW；先运行 `scripts/coupang_site_list.py` 核验。
- 搜索运行 `scripts/coupang_goods_search.py`；详情、规格和最多近 31 条历史运行 `scripts/coupang_goods_info.py`。
- 只使用接口返回字段。`salesLast28d`、`pvLast28Day` 是极鲸云收录指标，不称为 Coupang 全市场或 WING 官方数据。
- `estimatedOnSaleTime` 是最早评论时间、主图修改时间较早者再提前 10 天的估算值，不是官方上架时间。
- `displayDeliveryMethod` 只表示商品页观察到的配送展示标记，不据此承诺时效、资格或库存。
- 最多访问前 200 条；输出说明站点、币种、筛选、排序、页码、总命中上限、实际样本量和更新时间。
- 服务端要求暂停时按 [查询暂停与恢复流程](references/查询暂停与恢复流程.md) 处理。

## 工作流

1. 明确关键词或类目、价格、近 28 日销量/浏览量、评分、评论数、配送标记及时间条件。
2. 按 [商品接口](references/Coupang商品接口.md) 生成最少条件并搜索。
3. 对少量候选查询详情，核验规格价、Buy Box 价、规格竞争卖家数和历史。
4. 按 [商品研究](references/Coupang商品研究.md) 比较需求、价格、口碑、生命周期和供给竞争。
5. 涉及刊登、类目或履约判断时读取 [运营与政策口径](references/Coupang运营与政策口径.md)。

## 边界

- 没有独立店铺库、图搜、搜索量、转化率、广告、成本、佣金、物流费、退货率和利润数据。
- 商品图片字段可能是源路径，不自行拼接或猜测公开链接。
- 热销不等于低竞争；前 200 条不能外推为全市场。
- 缺失值显示 `-`；数值 `0` 结合采集时间判断，不自动解释为真实为零。

默认输出：结论、查询口径、候选证据、风险和下一步验证。面向业务用户不展示脚本或原始 JSON。
