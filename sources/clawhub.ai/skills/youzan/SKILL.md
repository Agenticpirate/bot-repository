# 有赞私域电商 Skill

有赞是中国头部**私域电商 SaaS**：商家付软件年费开自己的微商城/
小程序，把微信里的私域流量变成生意——与淘宝/京东"平台抽佣+
公域流量"是两种模式。选错模式比选错工具伤得多，本 skill 先帮
你判断模式，再谈工具。

## 先判断：有赞适合你吗

| 你的情况 | 判断 |
|----------|------|
| 已有稳定私域流量（微信群/公众号/门店客群/主播粉丝） | ✅ 有赞是变现器，模式成立 |
| 没有流量，指望开店自带客流 | ❌ 有赞不供给流量，先去抽佣平台或做内容 |
| 线下门店想做会员储值+同城配送 | ✅ 有赞零售场景成熟 |
| 知识付费/课程 | ✅ 有赞知识付费产品线专门覆盖 |
| 预算敏感的极小微商家 | ⚠️ SaaS 年费是固定成本，先算单量能否摊薄，或用微店等轻量方案过渡（见 `weidian` skill） |

费用结构理解：**软件年费（按版本）+ 支付通道费率**，
无平台抽佣——单量越大，相比抽佣平台越划算，这是模式的核心账。

## 开店与营销工具选择

- 搭建路径：注册 → 选版本 → 装修微商城/绑定小程序 → 接支付 →
  上架商品 → 配送与售后规则
- 营销工具按目标选，不要全开：
  - **拉新**：拼团、砍价、好友助力（社交裂变三件套）
  - **转化**：限时折扣、优惠券、满减
  - **复购**：会员卡、储值、积分、周期购
  - **放大**：**分销员**（老客带新客拿佣金）是私域最强杠杆，
    但佣金比例与层级设置务必合规（两级以内）
- 数据看板重点盯：访问-下单转化率、老客复购率、分销员贡献占比

## 有赞云开放平台（开发者对接）

- 面向商家自建系统对接：商品/订单/会员/库存 API 同步到 ERP/CRM
- 授权模式 OAuth2.0：自用型（silent 授权自己店铺）与工具型
  （服务市场应用，商家授权）两条路线，自建对接选自用型最简
- 消息推送：订单/退款等事件推送到你的回调地址，做实时同步
- 具体接口与参数以官方文档 doc.youzanyun.com 为准

## Agent 典型用法

1. **模式判断**：按用户流量现状与品类，给"有赞/抽佣平台/微店"
   三选一建议及理由
2. **营销方案**：按用户目标（拉新/复购/清库存）从工具箱里配组合，
   给出参数建议（如拼团人数/折扣深度）
3. **年费划算性测算**：`年单量 × 客单价 × 对比平台抽佣率 vs
   有赞年费+通道费`
4. **对接咨询**：自建系统同步订单的技术路线（OAuth 自用型 +
   消息推送）

## 本 skill 不做什么

- 各版本年费与通道费率以有赞官网实时报价为准，不报死数字
- 分销层级、储值资金合规涉及法规红线，超过两级返佣或大额储值
  资金池模式一律提示法律风险
- 不提供刷单、虚假交易等违规运营方法
