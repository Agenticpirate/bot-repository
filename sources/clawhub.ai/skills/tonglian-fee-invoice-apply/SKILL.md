# 通联刷卡手续费申请

## 固定模板（assets/ 目录）

Skill 自带两个固定模板文件，**永远不要改动模板的结构、列名、样式**：

### 模板1：`assets/1_手续费应收明细-模板.xlsx`

| 列 | 字段 | 说明 |
|:---|:-----|:-----|
| A | 月份 | **文本格式**，如「2026年5月」 |
| B | 商户名称 | 格式：`主体名（地区）`，如「普拉达时装商业（上海）有限公司（上海）」 |
| C | 商户编号 | 通联商户号（文本格式，防科学计数法），从账单明细表提取 |
| D | 地市 | 统一填「市场服务部」 |
| E | 业务类型 | 固定为「收银宝」 |
| F | 成功笔数 | 交易笔数 |
| G | 交易手续费 | 手续费金额（元） |

### 模板2：`assets/2_通联发票申请-模板.xlsx`

| 列 | 字段 | 说明 |
|:---|:-----|:-----|
| A | 序号 | 行号 |
| B | 发票类型 | 专票/普票/电子票 |
| C | 开票内容 | 如：日结，{主体名称}{年份}年{月份}月手续费。发票单位请写"月" |
| D | 企业开票信息 | 客户名称、税号（模板已预填，发票申请只需主体名+税号） |
| E | 备注 | 发票备注，如：{年份}年{月份}月通联刷卡手续费 |
| F | 开票金额 | 金额（元） |
| G | 是否已付款 | 已付款 |
| H | 预计付款时间 | （可不填） |
| I | 申请开票日期 | 日期 |
| J | 合同附件说明 | 如无需合同可说明原因 |
| K | 电子邮箱 | 发票接收邮箱 |

> ⚠️ 这两个模板**结构固定，勿改**。操作时**复制一份出来用**，保留原模板文件不动。

## 触发与交互流程

```
用户说"申请手续费发票" / 用户发来账单
    ↓
① 问用户要账单（如果还没有）
② 读取账单，填入模板
③ 账单里没有的数据 → 用问卷问用户
④ 发给用户确认
⑤ 用户说「发」→ 发邮件
```

## 第一步：接指令 → 要账单

当用户说"申请手续费发票"等指令时：

- **如果用户还没发账单** → 直接问用户要账单/数据
- **如果用户已经发了账单**（邮件转发、PDF、图片、Excel） → 直接进入第二步

## 第二步：读取账单，填入模板

1. 读取用户发的账单/对账单
2. 算出**上月合计的刷卡手续费**（按商户拆分明细）
   - 账单上的手续费字段可能叫：刷卡手续费、银行卡手续费、card processing fee、merchant service fee 等
   - 取上月整月的数据，只取**通联渠道**的手续费
3. **复制两份模板**到工作目录
4. **清除模板中的示例数据行**（模板1和模板2中已有的示例数据全部清掉）
5. **填入模板1（手续费应收明细）**：
   - **月份**：文本格式，如「2026年5月」
   - **商户名称**：格式 `主体名（地区）`，从门店名中提取城市名（如「Prada深圳万象城」→ 深圳，如无城市名则不写地区）
   - **商户编号**：通联商户号从账单明细sheet提取，按通联商户号聚合门店（**同一商户号下的多门店合并为一行**）
   - **商户名称统一规则**：所有行的商户名都用**合并开票的主体名（城市）**，不区分 Prada/MiuMiu/Cafe 等子品牌。城市取该商户号下金额最大的门店城市。
   - **地市**：统一填「市场服务部」
   - **业务类型**：收银宝
   - **成功笔数**：该商户号下所有门店累计
   - **交易手续费**：该商户号下所有门店累计
   - 按实体主体拆分：同一个通联商户号下如果涉及多个主体（如 Prada + MiuMiu + Cafe），按主体拆分成多行
   - 所有单元格**居中对齐**（Alignment horizontal=center, vertical=center）
6. **填入模板2（通联发票申请）**：
   - 按用户确认的开票主体，填一行
   - 纯数字标识字段（商户编号等）设为**文本格式**，防科学计数法
   - 所有单元格**居中对齐**

## 第三步：账单里没有的数据 → 用问卷收集

先查一下账单里还缺什么字段，然后用飞书问卷工具（`feishu_ask_user_question`）问用户。

**需要收集的缺失信息示例：**
| 字段 | 问法 |
|:----|:-----|
| 收件邮箱 | 发票接收邮箱是什么？ |
| 发票类型 | 开专票还是普票？ |
| 商户的地市/归属 | 这个商户的地市/归属部门是？ |
| 其他模板里需要但账单没有的字段 | 逐一提问 |

> ⚠️ **只问账单里没有的**。账单已经有的数据不要重复问。

> ⚠️ **专票开票信息用户说只需要主体名和税号**，不需要完整的地址电话开户行。可以从网上查到。

收集完后，把用户回答的内容填入模板中对应字段。

## 第四步：记住客户固定配置

某些客户有固定的开票偏好，一旦确认就记住，后续不再重复问：

| 客户 | 固定配置 |
|:----|:---------|
| **Prada（普拉达时装商业（上海）有限公司）** | 专票，发票接收邮箱 rebecca@shouqianba.com |

## 第五步：交付确认

**发出前必须给用户确认：**

1. 展示：开票主体、月份、金额汇总、收件邮箱、发票类型
2. 展示完整的邮件主题和正文
3. 展示收件人
4. 等用户说「发」再发邮件
5. **两个附件文件都发给用户**（飞书 message 工具 filePath）

## 第六步：发邮件

### 收件人

### 邮件模板

```
主题：【开票主体】.通联手续费发票申请.YYMM
```

> - 开票主体：如「徕卡相机贸易（上海）有限公司」
> - YYMM：如 2506（25年6月）

```
附件请查收【开票主体】MMDD的通联刷卡手续费的申请表和明细。
烦请转发贵司财务开出发票，感谢支持～
```

> MMDD：如 0611（6月11日）

### 示例

**主题：** `普拉达时装商业（上海）有限公司.通联手续费发票申请.2506`

**正文：**
```
附件请查收普拉达时装商业（上海）有限公司0611的通联刷卡手续费的申请表和明细。
烦请转发贵司财务开出发票，感谢支持～
```

附件附上两个文件：`1_手续费应收明细.xlsx` + `2_通联发票申请.xlsx`

如果用户说「发」，通过飞书邮件工具（`feishu_mail_message`）以用户身份发送邮件，附件附上填写好的两个模板文件。

### ⚠️ 邮件发送规范

1. **发前必检查附件**：调用 `feishu_mail_message` 时，必须确认 attachments 参数已正确携带两个文件。
2. **不允许先发空邮件再补发**：如果第一次发送忘记带附件，必须撤回后重发，而不是再补一封带附件的。
3. **一次发对**：邮件是发给客户的，不专业的表现会让用户难堪。

### 邮件正文规则

- 正文中的日期格式统一为 **YYMM**（如 2506），不用 MMDD
