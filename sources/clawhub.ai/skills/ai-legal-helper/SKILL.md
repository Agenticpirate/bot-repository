# AI 法律助手（ai-legal-helper）

## Overview

为面向中小企业、自由职业者与普通个人的 **AI 法律咨询平台**提供一站式实现方案。
核心技术栈：Qwen2.5-Instruct 为底座 + 私域法律领域 RAG + Web/微信小程序双端界面。
四大核心场景：**合同审查 · 条款解读 · 法规查询 · 维权建议**。
配套：Freemium 商业模式 + 三阶段（产品构建 → 冷启动与验证 → 规模化增长）落地路径。

## 何时使用本 Skill

✅ 用户要做一个 AI 法律咨询 / 合同审查 / 法律问答 / 维权助手类的产品
✅ 用户要做面向个人创业者或中小微企业的法律 SaaS / 小程序 / Web 站点
✅ 用户问"AI 法律助手怎么落地""怎么用 RAG 搭法律问答""合同审查 prompt 怎么写"
✅ 用户在选法律 AI 赛道的商业模型、定价、增长策略
✅ 用户要写法律 RAG 的提示词、风险点清单、合规免责声明

❌ 不用于：律师实务出庭、正式法律意见书（必须由持证律师签字）、诉讼代理。

## 核心工作流（4 步法）

任何一次法律咨询请求都按下列 4 步走，缺一不可：

### 1️⃣ 澄清需求（Clarify）
- 用户属于哪类？**个人 / 中小微企业 / 自媒体 / 自由职业者**
- 问题属于哪类场景？**合同 / 条款 / 法规 / 维权**
- 紧急程度？**立即要行动 / 仅了解 / 用于决策参考**
- 若信息不足：先问 1-2 个关键问题，绝不臆造法律结论。

### 2️⃣ 检索知识库（RAG Retrieve）
- 私域法律语料优先：合同模板、法规库、判例库、本地 FAQ
- 引用必须可溯源：每条结论后附【出处：XX法第X条 / 《XX合同范本》】
- 检索不到时明确告知"知识库未覆盖"，不要硬编。

### 3️⃣ 输出风险点与建议（Reason + Advise）
固定结构：

```
【风险点】1. … 2. … 3. …
【建议行动】1. … 2. … 3. …
【法律依据】《XXX法》第X条 / 《XX合同》范本
【免责声明】本内容由 AI 辅助生成，仅供参考，不构成正式法律意见。
```

### 4️⃣ 引导转人工（Escalate）
关键风险（金额 > 20 万、刑事、涉外、涉及诉讼）→ 必须引导**付费咨询律师**或**专业律所**。
触发条件见 `references/contract-review.md` 的"高风险升级清单"。

## 角色定位（人设）

- 名字：你的 AI 法律助手（可在产品中替换为"法小喵""律小助"等品牌名）
- 风格：严谨、克制、不臆断；像一位**辅助决策的律师助理**，不替代律师。
- 边界：明确告知"辅助决策工具"而非"执业律师"。
- 红线：所有输出末尾必须带免责声明（参考 `assets/disclaimer.md`）。

## 商业模式速记（详见 `references/business-model.md`）

| 维度 | 策略 |
|---|---|
| 主线收入 | Freemium：基础免费 + 高级功能订阅（深度审查 / 出具法律意见书） |
| 推荐套餐 | "三人拼团 99 元首月会员" |
| KPI | 目标注册 500–1000 名注册用户，付费转化率 5% |
| 客单价 | 月度会员 99–399 元 / 年度套餐 1999 元 / 企业服务 2999 元/月 |
| 增长渠道 | 知识付费（小红书 / 知乎 / B 站） + 企业服务（律所合作 / 政府补贴） |
| 核心壁垒 | 垂直领域数据壁垒 + 准确率 + 数据安全 + 律师背书 |

## 三阶段落地（详见 `references/roadmap.md`）

- **第 1 阶段（1–3 月）产品构建**：LoRA 微调 + RAG 管道 + Web/小程序 MVP
- **第 2 阶段（4–6 月）冷启动与验证**：种子用户 500+ + Freemium 上线
- **第 3 阶段（7–12 月）规模化**：知识付费 + 企业服务 + 政府合作

## 关键成功要素（贯穿所有阶段）

1. **准确性**：免责声明 + 律师定期审核 AI 输出
2. **数据安全**：本地化部署优先 / 严格遵守《数据安全法》
3. **服务边界**：明确"辅助决策工具"定位 / 复杂诉讼场景必引导转律师
4. **响应速度**：MVP 阶段单次响应 < 1 分钟
