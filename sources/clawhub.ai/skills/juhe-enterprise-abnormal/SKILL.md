# 企业工商-异常经营信息查询

> 数据由 **[聚合数据](https://www.juhe.cn)** 提供 — 国内领先的数据服务平台，提供天气、快递、身份证、手机号、IP 查询等 200+ 免费/低价 API。

查询企业是否被列入经营异常名录，返回列入/移出原因、时间、做出决定机关，以及当前公示或历史公示状态。

> 查得计费。限企业实名用户使用，需提交应用场景审核；个人实名用户无法使用。

---

## 前置配置：获取 API Key

1. 前往 [聚合数据官网](https://www.juhe.cn) 注册账号（需企业实名）
2. 进入 [企业工商-异常经营信息 API](https://www.juhe.cn/docs/api/id/841) 页面，点击「申请使用」
3. 审核通过后在「我的 API」中获取 AppKey
4. 配置 Key（**三选一**）：

```bash
# 方式一：环境变量（推荐，一次配置永久生效）
export JUHE_ENTERPRISE_ABNORMAL_KEY=你的 AppKey

# 方式二：.env 文件（在脚本目录创建）
echo "JUHE_ENTERPRISE_ABNORMAL_KEY=你的 AppKey" > scripts/.env

# 方式三：每次命令行传入
python scripts/enterprise_abnormal.py --key 你的 AppKey --name 苏州瀚海知识产权代理有限公司
```

## AI 使用指南

当用户需要查询企业经营异常时，按以下步骤操作：

1. **收集信息** — 从用户消息中获取企业全名、注册号或统一社会信用代码
2. **补全参数** — 缺少 name 时向用户询问；按企业名称查询时至少 4 个字；`nametype` 未指定时由脚本自动识别（18 位信用代码=3，13–15 位数字注册号=2，其余按企业名称=1）；分页默认 `pageIndex=1`（每页 20 条）；`pubStatus` 默认 `0`（全部）
3. **调用脚本或 API** — 执行查询，获取结果
4. **展示结果** — 优先标明当前公示/历史公示；列出列入原因、列入时间、移出原因、移出时间和决定机关；结果较多时提示可翻页

> 请尽量使用企业全称。用户只关心「现在还在异常名录里吗」时，使用 `--pub-status 1`。

### 请求参数

| 参数 | 必填 | 说明 |
|------|------|------|
| `name` | 是 | 企业全名 / 注册号 / 统一社会信用代码（企业全名至少 4 个字） |
| `nametype` | 是 | `1`=企业名称，`2`=注册号，`3`=统一社会信用代码 |
| `pageIndex` | 否 | 页码，默认 1，每页 20 条 |
| `pubStatus` | 否 | `0`=全部输出（默认），`1`=只输出当前公示中数据 |
| `key` | 是 | 聚合数据 AppKey |

### 返回字段说明

| 字段 | 含义 | 示例 |
|------|------|------|
| `orderid` | 流水号 | JH841260721114009Lj8RZ |
| `totalCount` | 记录总量 | 4 |
| `totalPage` | 总页数 | 1 |
| `pageSize` | 每页数量 | 4 |
| `pageIndex` | 当前页 | 1 |
| `data[].name` | 企业名称 | 苏州瀚海知识产权代理有限公司 |
| `data[].reg_no` | 注册号 | 320594000151590 |
| `data[].province` | 省份 | 江苏省 |
| `data[].in_reason` | 列入原因 | 未按规定期限公示年度报告 |
| `data[].in_date` | 列入时间 | 2018-07-04 |
| `data[].out_reason` | 移出原因 | （空表示尚未移出） |
| `data[].out_date` | 移出时间 | （空表示尚未移出） |
| `data[].department` | 做出决定机关 | 苏州工业园区市场监督管理局 |
| `data[].disabled` | 公示状态 | `0`=当前公示，`1`=历史公示 |

### 错误处理

| 情况 | 处理方式 |
|------|----------|
| `error_code` 10001/10002 | API Key 无效，引导用户至 [聚合数据](https://www.juhe.cn/docs/api/id/841) 重新申请 |
| `error_code` 10012 | 当日调用次数已用尽，建议升级套餐 |
| `error_code` 284101 | 参数错误，检查 name / nametype（企业全名至少 4 个字） |
| `error_code` 284102 | 查无记录，建议核对企业全称、注册号或信用代码 |
| `error_code` 284103/284104 | 网络或查询失败，告知稍后重试 |
| 网络超时 | 重试一次，仍失败则告知网络问题 |
