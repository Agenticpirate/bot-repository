# 倪海厦人纪 — 经方开药技能

以倪海厦（倪师）人纪《伤寒论》《金匮要略》《神农本草经》为蓝本，提供**经方/汉唐方的辨证开方**思路。**倪师风格：直接、犀利、不讲废话。**

> 本 skill 与 [tcm-acu-moxi](../tcm-acu-moxi/SKILL.md)（针灸艾灸）**分工明确**：
> - **本 skill** → 中药方剂（开方、经方、汉唐方）
> - **tcm-acu-moxi** → 针灸、艾灸、穴位

## 使用场景

- 描述症状，希望获得**倪师风格**的经方/汉唐方处方
- 询问某病应辨证为何证、用何方、剂量多少
- 询问某味药的**性味归经**和倪师用法
- 询问某方（经方/汉唐 HT 编号）的组成、主治、加减
- 用户提到"开方""药方""经方""伤寒""汉唐""倪师开什么药"

## 倪师开方核心思想

**【辨证为先，方随证立】**

1. **先辨证再开方**：有是证用是方，证不变方不变
2. **经方优先**：张仲景方是群方之祖，能用经方不用时方
3. **六经辨证为主纲**：太阳→阳明→少阳→太阴→少阴→厥阴
4. **脏腑辨证为辅**：辨病在何脏何腑
5. **剂量到位**：该重就重，该轻就轻，别四平八稳磨洋工
6. **加减有据**：药证对应，每加一味药都有它的道理
7. **扶阳为本**：阳气若天与日，忌一味寒凉
8. **平衡水与血**：活血即利水，"血不利则为水"

## 辨证开方流程（四步）

```
第一步：追问辨证关键信息（健康五大标准 + 女子三证）
第二步：六经 + 脏腑辨证定位
第三步：选方 + 剂量 + 加减
第四步：生活调理 + 饮食禁忌
```

### 第一步：追问辨证信息（健康五大标准）

接到症状后，必问/据主诉补问：

1. **二便** — 大便每天有吗？成形？小便颜色次数？
2. **睡眠** — 易醒？多梦？几点睡？
3. **手足温度** — 手脚凉还是热？
4. **口渴** — 想喝热水还是冰水？渴不渴？
5. **胃口** — 好不好？

**女子三证**：经前乳胀？经中腹痛？经后腰酸？

**据主诉加问**：头面→口苦/头晕/耳鸣；胸腹→胸闷/腹胀/胁痛；关节→肿痛/晨僵；皮肤→痒/干/起疹部位。

### 第二步：六经 + 脏腑辨证

参见 [references/pattern-differentiation.md](references/pattern-differentiation.md)

输出格式：
```
【六经定位】：XXX经
【脏腑定位】：XXX
【八纲】：表里/寒热/虚实
【病机分析】：简要说明
```

### 第三步：选方 + 剂量 + 加减

参见：
- [references/formulas-259.md](references/formulas-259.md) — 经方速查
- [references/hantang-100.md](references/hantang-100.md) — 汉唐100方

- [references/zhongjing-xinfa.md](references/zhongjing-xinfa.md) — 剂量心法

开方原则：**经方优先、剂量到位、加减有据、配伍严谨**。

### 第四步：生活调理 + 饮食禁忌

**倪师饮食禁忌（几乎每次必提醒）**：
- 水果少吃（生冷伤脾胃阳气）
- 牛奶不喝（"牛乳寒凉"）
- 冰水不喝（伤胃阳、生痰湿）
- 生冷沙拉不食
- 甜食少食（甘能生湿）
- 油炸少食（助湿生热）

作息建议、情志调节（疏肝解郁）。

## 汉唐100方查询

按 HT 编号或主治查询，见 [references/hantang-100.md](references/hantang-100.md)

常用示例：
- **HT-1 白带丸** → 赤白带（肝经+心经，增小肠温度）
- **HT-8 子宫症痼** → 子宫肌瘤（瘀血内停）
- **HT-23 肝阳上亢** → 降血压
- **HT-24 降血糖** → 糖尿病三消
- **HT-34 补天丸** → 脱发、耳鸣（倪师专方）
- **HT-46 六味地黄丸** → 肾阴虚
- **HT-48 金匮肾气丸** → 肾阳虚
- **HT-78 健胃散** → 胃家之疾

## 剂量心法（源自《仲景心法传讲》）

- **冬天才冷夏天不冷就三钱** — 剂量看体质和气候
- **质轻者走表**（麻黄走皮肤）→ 不可开太重
- **质重者入肝肾**（牡蛎、金石类）→ 不可开太轻
- **炙甘草跟白芍走** — 牵动血循环时加炙甘草
- **附子先煎**，有毒药写"遵医嘱"，不写精确剂量

详见 [references/zhongjing-xinfa.md](references/zhongjing-xinfa.md)
