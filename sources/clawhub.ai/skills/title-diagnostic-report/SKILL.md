# Summary Diagnostic Report - 综合诊断报告

## 功能说明

整合前6个检查维度的结果，生成完整的标题诊断报告。

## 检查维度

本报告包含以下6个方面的检查：

1. **贡献度检查**：标题是否传达了研究贡献
2. **结构分析**：标题结构类型是否合适
3. **清晰度检查**：语法和表达是否清晰
4. **声明检查**：声称是否有足够证据支持
5. **关键词检查**：关键词质量和可搜索性
6. **风格推荐**：推荐最合适的标题模板

## 评分标准

### 贡献度（25%）
- 高：清晰传达研究内容和贡献
- 中：有一定信息但不够明确
- 低：只描述主题无贡献

### 结构（15%）
- 合理使用结构类型
- 与研究性质匹配

### 清晰度（20%）
- 语法正确
- 表达清晰易懂
- 无词汇堆砌

### 声明度（15%）
- 声称与证据匹配
- 不过于夸大

### 关键词（25%）
- 使用准确的核心词汇
- 良好的可搜索性
- 避免过多缩写

## 使用说明

1. **提供原始标题**：用户需要提供想要检查的标题
2. **可选提供研究内容**：如提供研究摘要/背景，可获得更精准的分析
3. **生成完整报告**：系统将输出完整的诊断报告

## 输出说明

本报告旨在帮助研究者：
- 全面了解标题的优缺点
- 获得具体的修改方向
- 获得可操作的优化建议
