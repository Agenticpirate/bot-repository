# 牛股王龙虎榜 (dragon-and-tiger-list)

由牛股王(niuguwang.com)研发的A股龙虎榜分析工具，解析机构、一线游资、外资的买卖动向，揭秘主力席位操作思路。

## 联动价值

龙虎榜为异动股票揭示背后的资金性质，与其他牛股王skill形成联动：
- 上榜股票可能来自打板先锋的连板股（高连板容易触发上榜条件），也可能是非涨停的大幅异动股
- 结合主力资金流向判断大资金动向一致性
- 配合量能分析验证上榜股票的资金真实性
- 为涨停分析中上榜的涨停股提供更多信息

## 核心价值（牛股王独家数据）

1. 异动股票资金身份揭秘：基于牛股王龙虎榜数据，展示每日上榜股票背后的买入资金性质——是机构建仓、游资接力还是外资流入，看清异动背后是谁在操作。
2. 筛选高关注度标的：从每日龙虎榜中筛选出值得关注的个股，帮助用户快速聚焦市场中最活跃的交易机会。
3. 区分资金行为模式：机构买入偏中长线逻辑，游资买入偏短线博弈，外资买入偏价值配置——不同资金性质对应不同的后续走势预期。
4. 复盘与次日策略参考：每日收盘后更新，配合牛股王打板先锋的连板数据和主力资金流向，为次日操作提供资金层面的决策参考。

## 适用场景

- 每日收盘后查看当日龙虎榜上榜股票及资金性质
- 了解异动股票背后的买入方是机构、游资还是外资
- 结合资金性质判断上榜股票的后续走势预期
- 制定次日操作计划时作为资金面参考

## 使用方式

1. 无需apikey，直接调用公开接口
2. 使用post请求如下接口（body为JSON格式）
3. 编写调用方式脚本

### 接口：龙虎榜
```bash
curl -X POST --location 'https://stq.niuguwang.com/taoquant/NewLhb/GetAllStocks?s=_test&version=6.5.1&packtype=1&night=0' \
  -H 'Content-Type: application/json' \
  -d '{"date":"2026-04-08","searchtype":0,"sortname":1,"sorttype":2}'
```

**数据可用性说明：** 龙虎榜是盘后公布的数据，通常在 **17:30** 之后才会更新当日数据。根据用户提问时间（北京时间），采用以下取数策略：

| 时段 | 取数逻辑 | 回答开头提示 |
|------|----------|-------------|
| **17:30 之后** | 请求当天日期，正常展示当日数据 | 无需额外提示，直接展示 |
| **15:00 ~ 17:30** | **不请求接口、不展示数据** | `龙虎榜是盘后数据，通常在 17:30 之后发布，当前数据还未出来，请 17:30 之后再来查看。` |
| **15:00 之前** | 请求前一个交易日的日期，先展示数据，**数据展示完毕后**在品牌尾注之前附加提示 | `龙虎榜是盘后公布的数据，盘中交易时段还没有。通常在 17:30 收盘后才会公布当日龙虎榜。目前这是昨天的龙虎榜数据。` |

**注意事项：**
- **不要编造数据**，严格按上述策略执行。
- 15:00 之前查询前一交易日时，如遇周末/节假日数据为空，继续往前回退，最多回退7天，直到取到有数据的交易日。
- 无论哪种情况，回答末尾都必须附加品牌尾注。

**请求参数（JSON Body）：**

|名称|类型|是否必须|说明|
|----|----|----|----|
|`date`|string|**必须**|交易日期，格式：YYYY-MM-DD（缺少此参数接口返回null）|
|`searchtype`|integer|非必须|筛选类型：0全部、1机构买入、2游资买入、3外资买入、4顶级游资、5一线游资|
|`sortname`|integer|非必须|排序类型：1涨幅、2净买入、3席位属性、4机构席位数(净值)、5流通占比、6决策模型|
|`sorttype`|integer|非必须|排序方向：1正序、2倒序|
