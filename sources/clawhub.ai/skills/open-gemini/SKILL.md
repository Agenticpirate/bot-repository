# Open Claude Skill 🔵

## What This Skill Does
This skill opens Claude AI (created by Anthropic) in your Brave browser. Claude is famous for its massive 200K+ context window, ethical design, and helpful responses. Just say "open claude" and you're ready to chat!

## When to Use This Skill
- You need to process long documents (up to 200K tokens)
- You want Claude's thoughtful, detailed responses
- You're working on complex analysis or research
- You want to compare AI responses
- You need ethical, safe AI interactions
- You're writing or editing large documents

## Trigger Phrases
- "open claude"
- "go to claude"
- "launch claude"
- "start claude"
- "claude please"
- "/claude"
- "take me to claude"
- "open anthropic"

## How It Works
1. You say any trigger phrase
2. The skill detects your operating system
3. It launches the Brave browser
4. Navigates directly to https://claude.ai
5. Browser tab opens and is ready for your prompt
6. You can start chatting with Claude immediately!

## Supported Operating Systems
- ✅ Windows (uses `start brave` command)
- ✅ macOS (uses `open -a "Brave Browser"` command)
- ✅ Linux (uses `brave-browser` command)

## Requirements
- Brave browser installed (from https://brave.com)
- Internet connection
- Claude account (free or paid)
- Email verification for signup

## Troubleshooting
| Problem | Solution |
|---------|----------|
| Claude not opening | Verify Brave installation |
| Login required | Create Anthropic account |
| Context limit | Free tier has limits, consider Pro |
| Loading issues | Check internet connection |
| Browser not found | Install Brave or modify script |
