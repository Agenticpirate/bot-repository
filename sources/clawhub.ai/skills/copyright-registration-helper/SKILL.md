# 著作权登记辅助

> 面向个人创作者和中小企业的著作权登记全流程辅助工具。从"判断作品类型"到"生成登记材料"到"流程指引"一条龙服务。

## 核心能力

### 1. 作品类型判断
根据用户描述，判断作品属于以下哪种类型，并告知对应的登记要求：
- **文字作品**：小说、散文、诗歌、论文、剧本、文案等
- **口述作品**：演讲、授课、报告等口头表达作品
- **音乐作品**：歌曲、器乐曲等
- **戏剧作品**：话剧、歌剧、地方戏等
- **曲艺作品**：相声、快书、大鼓、评书等
- **舞蹈作品**：舞谱设计、舞蹈动作编排等
- **杂技艺术作品**：杂技、魔术、马戏等
- **美术作品**：绘画、书法、雕塑等
- **建筑作品**：建筑设计图、建筑物本身
- **摄影作品**：照片、摄影集等
- **视听作品**：电影、电视剧、短视频、动画等
- **工程设计图/产品设计图**：工程图纸、产品设计图等
- **地图/示意图**：地图、线路图、解剖图等
- **模型作品**：立体模型、沙盘等
- **计算机软件**：软件程序、源代码、文档等

### 2. 登记材料生成
自动生成著作权登记所需的核心文书，输出为Word文档：
- **著作权登记申请表**：含作品名称、作品类别、作者信息、著作权人信息、创作说明等
- **作品说明书**：含作品创作背景、创作过程、作品内容说明、独创性声明等
- **权利保证书**：含权利来源声明、权利归属确认、无侵权承诺等
- **创作证明文档**：含创作时间、创作地点、创作过程记录等

### 3. 流程导航
告知用户完整的著作权登记流程：
- 登记流程步骤说明
- 所需材料清单
- 登记费用参考（各类型作品）
- 办理时间周期
- 登记机构选择指引（中国版权保护中心 vs 地方版权中心）
- 线上/线下办理渠道指引
- 涉外作品登记指引

### 4. 模板生成
生成可直接填写的模板文档，输出为Word文档：
- **作品说明书模板**（通用版）
- **权利保证书模板**（通用版）
- **创作证明模板**（含完整创作证明材料清单）
- **授权委托书模板**（代理申请用）

## 工作流程

### Step 1: 收集信息
向用户收集以下信息（自然语言对话中逐步获取，避免一次性问太多）：

**作品信息：**
- 作品名称
- 作品类型（如用户不确定，先进行类型判断）
- 作品创作完成日期
- 作品创作完成地点
- 创作性质（原创/改编/翻译/汇编等）
- 作品篇幅/字数
- 作品发表状态（已发表/未发表）
- 首次发表信息（发表时间、地点、方式，如已发表）
- 作品内容简要描述

**创作者/著作权人信息：**
- 姓名/名称
- 作者/著作权人类别（自然人/法人/其他组织）
- 证件类型及证件号码
- 国籍/地区
- 地址
- 联系方式
- 创作性质（原创/改编/翻译/汇编等）

**权利信息：**
- 权利归属方式（个人独自创作/合作创作/职务创作/委托创作等）
- 权利取得方式（原始取得/继承/受让等）

### Step 2: 判断作品类型
根据用户对作品的描述，判断其所属的作品类型，并：
1. 告知判断结果
2. 说明该类型的登记要求
3. 确认用户是否认同判断结果，如有异议可调整

### Step 3: 生成登记材料
根据用户确认的信息，生成著作权登记所需文书：

**文书生成规则：**
- 使用正式、规范的法律文书格式
- 内容符合中国版权保护中心的表格要求（参考官方：https://register.ccopyright.com.cn）
- 直接生成Word文档（.docx格式）
- 每个文档包含完整的填写说明

**模板生成命令：**
- 生成作品说明书模板：`python main.py '{"action":"template","template_type":"work_description"}'`
- 生成权利保证书模板：`python main.py '{"action":"template","template_type":"rights_guarantee"}'`
- 生成创作证明模板：`python main.py '{"action":"template","template_type":"creation_evidence"}'`
- 生成授权委托书模板：`python main.py '{"action":"template","template_type":"power_of_attorney"}'`

**需要生成的文档包（根据用户选择）：**
1. 《著作权登记申请表》——含各字段填写说明
   - 作品名称、作品类别、创作完成日期、创作完成地点
   - 创作性质（原创/改编/翻译/汇编/其他）
   - 作品篇幅/字数
   - 发表状态、首次发表信息
   - 作者信息（姓名/类别/证件等）
   - 著作权人信息（姓名/类别/证件等）
   - 权利取得方式、权利归属方式
2. 《作品说明书》——含创作背景、创作过程、作品内容、独创性说明
3. 《权利保证书》——含权利声明和承诺条款
4. 《创作证明》（可选）——含创作时间线记录、创作证明材料清单

### Step 4: 提供流程指引
根据作品类型和用户所在地，提供针对性的登记流程指引：

**通用流程：**
1. 准备材料 → 2. 在线填报 → 3. 提交申请 → 4. 缴费 → 5. 审查 → 6. 领证

**包含信息：**
- 登记机构：中国版权保护中心（国家级）/ 各省市版权中心（地方级）
- 费用参考：文字/美术/摄影等一般300元/件，软件登记500-800元/件（具体以官方为准）
- 办理周期：一般30个工作日（加急可缩短）
- 申请网址：https://www.ccopyright.com.cn（中国版权保护中心）
- 所需材料清单（按类型列出）

**⚠️ 费用时效性提醒**
登记费用以中国版权保护中心官方最新公告为准，本工具提供的费用数据仅供参考。建议在正式提交申请前，访问中国版权保护中心官网（https://www.ccopyright.com.cn）查询最新收费标准。

**涉外作品登记指引：**
对于涉外作品（作者或著作权人为外国公民/企业），需注意以下事项：

1. **登记机构**：涉外作品应通过中国版权保护中心办理，一般不能通过地方版权中心办理
2. **国际条约依据**：根据《伯尔尼公约》或中国与作品来源国签订的双边著作权保护协定
3. **所需材料补充**：
   - 外国作者的身份证明文件（需公证认证）
   - 如作品在外国首次发表，需提供首次发表证明
   - 委托代理的需提供特别授权委托书
4. **语言要求**：申请材料需为中文，外文材料需附中文翻译件
5. **办理周期**：一般比国内作品多5-10个工作日
6. **费用差异**：涉外作品登记费用可能略高于国内作品

### Step 5: 输出文件
1. 将所有生成的文档保存到工作目录下的 `copyright-registration-helper/output/` 文件夹
2. 文件名格式：`{作品类型}_{文档类型}_{简短描述}.docx`
3. 向用户展示文件路径，方便下载使用

**批量登记功能：**
如需批量生成多个作品的登记材料，可使用以下方式：
- 支持一次性生成多个作品的登记申请表、作品说明书、权利保证书
- 调用方式：`python main.py '{"action":"batch_generate","works":[{...},{...}]}'`
- 每个作品独立生成完整的材料包（申请表+说明书+权利保证书）

### 中国版权保护中心官方表格格式要求
1. **申请表格式**：
   - 作品名称：最多100字，应与作品本身名称一致
   - 作品类别：根据《著作权法》第三条分类
   - 创作完成日期：精确到日，格式YYYY年MM月DD日
   - 创作完成地点：精确到省/市
   - 创作性质：原创/改编/翻译/汇编/其他
   - 作品篇幅：文字作品填字数，其他作品填件数/页数
   - 作者类别：自然人/法人/其他组织
   - 著作权人类别：自然人/法人/其他组织
   - 权利取得方式：原始取得/继承/受让
   - 权利归属方式：个人独自创作/合作创作/职务创作/委托创作

2. **作品说明书格式**：
   - 需包含创作背景、创作过程、作品内容说明、独创性声明
   - 创作背景应说明创作动机、灵感来源
   - 创作过程应详细描述从构思到完成的完整过程
   - 作品内容说明应描述作品的结构、风格、主要特征

3. **权利保证书格式**：
   - 需包含权利来源保证、权利真实性保证、无侵权承诺
   - 保证人需签字或盖章
   - 需注明签署日期

## 输入/输出格式

### 输入格式
用户通过自然语言描述即可，例如：
- "我写了一部小说，想登记版权"
- "帮我生成一套摄影作品的著作权登记材料"
- "我做了一个APP软件，需要软著登记"
- "我画了几幅国画，想申请著作权"
- "我有多个作品需要批量登记"

### 输出格式
1. **对话中**：用清晰的结构化文本展示各文书内容预览
2. **文件输出**：Word文档（.docx），保存在 `output/` 目录下
3. **流程指引**：以清单/表格形式展示

## 边界情况处理

1. **用户不确定作品类型**：先通过问答帮助判断，引用《著作权法》第三条关于作品类型的定义
2. **多人合作作品**：需要确认所有合作作者信息，说明合作作品登记的特殊要求
3. **职务作品**：区分一般职务作品和特殊职务作品，说明权利归属规则
4. **涉外作品**：提示需要提供对应的国际条约保护依据，引导通过中国版权保护中心办理
5. **改编/翻译作品**：需确认原作品授权情况，提示需要提供原作品授权证明
6. **已发表 vs 未发表**：不同状态的材料要求不同，需区分处理
7. **费用变动**：提示费用以官方最新公告为准，不承担因费用变化造成的责任
8. **加急需求**：提供加急办理渠道和注意事项
9. **批量登记**：支持多个作品一次性生成登记材料

## 示例

### 示例1：文字作品登记
**用户输入：** "我写了一本30万字的科幻小说《星际迷途》，去年12月完成的，还没发表，想登记版权"

**技能响应流程：**
1. 判断作品类型为"文字作品"
2. 收集作品名称、完成日期、未发表状态、作品简述等信息
3. 收集作者信息（姓名、证件等）
4. 生成《著作权登记申请表》《作品说明书》《权利保证书》
5. 提供文字作品登记流程指引
6. 输出Word文档到output目录

### 示例2：软件著作权登记
**用户输入：** "我们公司开发了一个CRM管理系统，想申请软件著作权"

**技能响应流程：**
1. 判断为"计算机软件"类型
2. 告知软件著作权登记的特殊要求（需源代码、用户手册等）
3. 收集软件名称、版本号、开发完成日期、发表状态等信息
4. 收集公司信息和开发人员信息
5. 生成登记材料包
6. 提供软著登记流程指引（中国版权保护中心）
7. 输出Word文档到output目录

## 重要注意事项

1. **免责声明**：本工具生成的文书为辅助参考材料，正式提交前建议请专业法律人士审核
2. **费用免责**：登记费用以官方最新公告为准，本工具提供的数据仅供参考
3. **不提供法律建议**：本工具不构成法律意见，涉及重大权利问题请咨询专业律师
4. **时效性提醒**：流程和费用信息可能随政策调整，建议用户登记前核实官方最新要求

6. **涉外作品**：涉外作品需通过中国版权保护中心办理，材料要求更严格
