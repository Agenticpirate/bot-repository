# Open Grok Skill 🟣

## What This Skill Does
This skill opens Grok AI (created by xAI, Elon Musk's company) in your Brave browser. Grok is known for its witty personality and real-time knowledge. Just say "open grok" and you're ready to chat with one of the most unique AIs!

## When to Use This Skill
- You want Grok's unique, humorous perspective
- You need real-time information from X/Twitter
- You're comparing responses between different AIs
- You want to try xAI's latest technology
- You're curious about Grok's "rebellious" personality
- You want to ask questions with a sense of humor

## Trigger Phrases
- "open grok"
- "go to grok"
- "launch grok"
- "start grok"
- "grok please"
- "/grok"
- "take me to grok"
- "open xai"

## How It Works
1. You say any trigger phrase
2. The skill detects your operating system
3. It launches the Brave browser
4. Navigates directly to https://grok.x.ai
5. Browser tab opens and is ready for your prompt
6. You can start chatting with Grok immediately!

## Supported Operating Systems
- ✅ Windows (uses `start brave` command)
- ✅ macOS (uses `open -a "Brave Browser"` command)
- ✅ Linux (uses `brave-browser` command)

## Requirements
- Brave browser installed (get it from https://brave.com)
- Stable internet connection
- X/Twitter account (required for Grok access)
- Grok subscription (X Premium+)

## Troubleshooting
| Problem | Solution |
|---------|----------|
| Grok not opening | Check if Brave is installed |
| Login required | Log in with your X/Twitter account |
| Subscription error | Grok requires X Premium+ subscription |
| Slow loading | Check your internet speed |
| Browser not found | Install Brave or edit script for another browser |
