# 大藏经学术引用生成器

> 配套脚本：`生成引用.py`（已知编号→脚注）、`按经文查出处.py`（经文→自动定位→脚注）、`更新藏经数据.py`（刷新出版社表）。
> 本文件为**自包含技能说明**，可直接作为技能描述投到 WorkBuddy / Claude Code / IMA / 其他大模型平台使用。

## 0-b. 输出纪律（执行本 skill 时必守）

| 场景 | 做法 |
|---|---|
| 查 1-2 条引用 | **直接在对话里给出两行结果**，不生成任何 md 文件 |
| 查 3-9 条 | 仍在对话里列出，每条两行，用空行分隔；不生成文件 |
| 查 10 条以上，或用户明确要文件 | 才生成 md 保存到输出目录 |

**其他纪律**

- 答案用**简体字**，精简，先给结果后给说明。
- 默认不给七种脚注、不给逐行原文表、不给义理考证——用户没要就不给。
- 用户若要核实，再补核对网址或上下文。

## 0. 定位与通用性声明

- 本 skill 是**通用的大藏经学术引用工具**，不绑定任何个人或机构；所有个性化表述均已清除，仅保留客观引用规则。
- **第一引用源**：CBETA 2026.R1（及 CBETA 收录的各纸本版本：大正藏 T、永乐北藏 P、卍续藏 X、嘉兴藏 J/B、中华大藏经 C 等），脚本输出自动带出**作译者 / 出版社 / 出版地 / 出版年 / 册 / 卷 / 页 / 栏 / 行**。
- 输出为**完整学术脚注**等七种格式，可直接粘贴至论文、报告、讲义脚注。
- 跨平台用法见 §6。
- **设计参考**：CBETA 官方「引用複製」格式规范（https://cbeta.org/citation-copy-format）及开源实现（如 GitHub 的 cbeta-skill：KWIC 补全页码思路）。本工具在官方规范基础上补全作译者 / 出版社 / 出版年，并支持中文数字、英文脚注、论文署名声明。
- **版本时效**：CBETA 版本号（如 2026.R1）应核对官网当前发布；脚本默认 2026.R1，可用 `--版本` 参数覆盖。

## 2. 脚本一：生成引用.py（已知出处编号）

```bash
python 生成引用.py "T33, no. 1717, p. 869b21-22" --引文 "一心三智為妙行本" --中文数字
python 生成引用.py "T33n1717_p0869b21" --中文数字 --复制     # 复制文献条目
python 生成引用.py "https://cbetaonline.dila.edu.tw/T1717_008"
python 生成引用.py "X57, no. 980, p. 671a1" --全格式 --json   # 展开七种脚注
```

参数：`--引文`（填入「」中）、`--中文数字`（卷八）、`--简`（頁869中21-22）、`--json`、`--复制`、`--版本`

## 3. 脚本二：按经文查出处.py（只有一句经文）

```bash
# 不限定，全文反查
python 按经文查出处.py "一心三智為妙行本"

# 限定佛典（更快更准）
python 按经文查出处.py "一心三智為妙行本" --经 T1717

# 只在某一藏中查（如中华大藏经）
python 按经文查出处.py "獲上乘廣度眾生至垂拱三年" --藏 C
```

参数：`--经`（佛典编号如 T1717 / JB348 / C1710）、`--藏`（藏经代码）、`--最多`（显示笔数，默认5）、`--中文数字`、`--复制`

### 检索原理（均为 CBETA 官方 API）

1. `/search` 全文检索 → 候选【佛典＋卷数】
2. `/search/kwic` 关键词上下文 → 精确【页码＋栏＋行】与原文片段
3. `/works` → 经名、作译者、朝代、册数
4. 本地 `藏经出版社.json` → 出版社／出版地／出版年

### 检索要点（重要）

- **整句常检索不到**：CBETA 原文含标点、且会跨行，整句精确匹配命中率极低。脚本已内置**由长到短自动截取**（14→12→10→8→6→5→4 字）重试。
- **提高准确度**：知道是哪部经就用 `--经` 限定；未命中时脚本会自动遍历该经全卷精确定位。
- 用字须与 CBETA 一致（**繁体、正字**）。如原引「若一心三觀為妙行本」，CBETA 原文实为「一心三智為妙行本」。

## 4. 输出格式

### 默认输出：两行，直接可粘贴进脚注

```bash
python 生成引用.py "T46n1912_p0413b12-14" --中文数字
```

```
〔唐〕湛然述，《止观辅行传弘决》卷九，《大正新修大藏经》第46册，第1912号，第413页中栏第12-14行，东京：大藏出版株式会社，1988-1991年。
CBETA 2026.R1, T46, no. 1912, p. 413b12-14。
```

**格式硬规则（v1.1.0 起）**

| 项 | 规则 |
|---|---|
| 行数 | 两行：第一行文献条目，第二行 CBETA 定位，**必须另起一行** |
| 句号 | 每行末尾各用一个句号 |
| 连接词 | 不用「收入」，经名与藏经名之间直接用逗号 |
| 字形 | 默认**简体**（论文主体为简体时无需保留原字形）；`--繁` 才保留 CBETA 原字形 |
| CBETA 定位 | 独立成行，不并入第一行 |

**构成**：作译者＋《经名》卷数＋《藏经名》册号＋页栏行＋出版地：出版社，出版年。
一条同时兼作「参考文献条目」与「脚注文献信息」，列文末、作脚注皆可。

**参数**

- `--中文数字`：卷数作「卷九」（否则作「卷9」）
- `--复制`：两行一起进剪贴板
- `--详细`：附核对网址
- `--全格式`：需英文脚注／简式脚注／论文署名声明时才展开七种
- `--繁`：保留繁体原字形

### 七种格式（`--全格式` 展开）

1. **完整学术脚注**：作译者＋经名卷数＋引文＋藏经册号＋页栏行＋出版社出版年＋CBETA 定位
2. **传统纸本脚注**：用**原版**出版信息（如大正藏 1924-1935）
3. **简式脚注**：学界常用简写（頁869中21-22）
4. **CBETA 官方格式**：与「引用複製」一致
5. **英文脚注**：含罗马字、朝代英译、英文出版社
6. **参考文献条目**
7. **论文署名声明**：CBETA 基金会来源说明（正式论文置于参考文献前，官方规范）

### 实测样例（以「一心三智為妙行本」为例）

> 〔唐〕湛然述，《法華玄義釋籤》卷八：「一心三智為妙行本」，收入《大正新脩大藏經》第33冊，第1717號，第869頁中欄第21行，東京：大藏出版株式會社，1988-1991年；CBETA 2026.R1, T33, no. 1717, p. 869b21。

> 〔宋〕頤藏主集 明 淨戒重校，《古尊宿語錄》卷一：「獲上乘廣度眾生至垂拱三年」，收入《中華大藏經（中華書局版）》第77冊，第1710號，第615頁上欄第15行，北京：中華書局，1984-1997年；CBETA 2026.R1, C77, no. 1710, p. 615a15。

> 〔明〕智旭著，《靈峰蕅益大師宗論》卷一：「念佛」，收入《嘉興大藏經（新文豐版）》第36冊，第B348號，第253頁上欄第24行，台北：新文豐，1987年；CBETA 2026.R1, J36, no. B348, p. 253a24。

> ⑦ 论文署名声明示例：《大正新脩大藏經》的資料引用出自「財團法人佛教電子佛典基金會」(Comprehensive Buddhist Electronic Text Archive Foundation，簡稱 CBETA Foundation 或 CBETA 基金會)的電子佛典集成。其出處依冊數、經號、頁數、欄數、行數之順序紀錄，例如：CBETA 2026.R1, T33, no. 1717, p. 869b21。

1. 完整学术脚注：〔朝代〕作译者，《佛典名》卷X：「引文」，收入《藏经名》第N冊，
   第M號，第P頁[上/中/下]欄第L行，出版地：出版社，出版年；
   CBETA 版本, [藏经代码][册], no. [经号], p. [页][栏][行]。
2. 传统纸本脚注（用原版出版年，如大正藏 1924-1935）。
3. 简式脚注（頁869中21-22）。

原版 東京：大藏經刊行會，1924-1935）、永樂北藏 P（北京：線裝書局，2000）、

1. 打开 https://cbetaonline.dila.edu.tw → 检索到经文 → 点「引用複製」得到如 `CBETA 2026.R1, T33, no. 1717, p. 869b21`。

## 7. 引用策略

**以 CBETA 2026.R1 为第一学术引用源**，其余 CBETA 收录的可靠纸本版本（大正藏 T、永樂北藏 P、卍续藏 X、嘉兴藏 J/B、中华大藏经 C 等）并列作为可引用的可靠版本。脚本默认即按此策略输出：自动带出**册 / 卷 / 页 / 栏 / 行 ＋ 出版社 ＋ 出版地 ＋ 年代**，满足学术引用对出处的全部精度要求。

> 说明：中华大藏经（中华书局版，1984-1997，106 册，赵城金藏底本）主收东汉至元代译撰，基本不含明清佛教撰述（如蕅益大师著作），故统一以 **CBETA R1 为主源、其他 CBETA 可靠版本并列引用**最稳妥。若需国内纸本册/页定位，可启用可选脚本 `中华大藏经定位.py`（依赖 fo.ancientbooks.cn 登录态，非必需，详见该脚本内说明）。

### 大正藏的两个出版年（务必分清）

- **原版**：東京：大藏經刊行會，**1924-1935** —— 学界引用大正藏的通行做法（格式②）
- **CBETA 所据纸本**：東京：大藏出版株式會社，**1988-1991**（普及版）—— 与电子版页码一致（格式①）
