# 极鲸云 SHEIN 关键词搜索

## 工作原则

- 只使用极鲸云返回的真实关键词数据，区分接口事实、可复算指标和分析判断。
- 默认使用简体中文和绝对日期，保留站点、筛选条件、排序、分页范围、样本量和更新时间。
- 将数值 `0`、缺失值、异常值和未完成分页显式标注，不把局部样本描述为全量市场。
- 复用 GeekBI SHEIN Skills 的共享登录态。任一 Skill 已完成登录时直接查询，不主动重复登录；脚本要求暂停时按 [查询暂停与恢复流程](references/查询暂停与恢复流程.md) 处理。
- 仅在用户明确要求开发对接、故障排查或原始响应时展示英文参数、响应字段、命令或原始 JSON。

## 执行流程

1. 明确用户要查特定关键词、热销词、蓝海词、新词还是关键词市场机会，并确认站点、时间口径和硬性条件。未指定站点时使用 `siteId=1`，并说明该入口名称虽为“全部”，当前映射 `us`，不是跨站聚合。
2. 读取 [SHEIN 关键词搜索](references/SHEIN关键词搜索.md) 和 [SHEIN 关键词搜索接口](references/SHEIN关键词搜索接口.md)。仅在用户表达榜单意图时再读取 [SHEIN 关键词榜单预设](references/SHEIN关键词榜单预设.md)。
3. 只使用用户提供或当前上下文中已有可靠来源的类目 ID，不根据类目名称猜测。没有可信类目 ID 但用户给出关键词时，直接按原关键词查询；只有必须严格限定类目且缺少 ID 时，才请用户提供类目 ID。
4. 未指定站点时使用 `siteId=1`；用户明确指定美国站时使用 `siteId=2`。用户指定其他国家或地区时，运行 `python3 scripts/shein_site_list.py --country "国家或地区"`，只采用唯一精确匹配；无唯一匹配时请用户确认。
5. 生成最小必要条件并运行 `scripts/shein_keyword_search.py`。不要无依据叠加阈值、时间范围或多个榜单预设。
6. 脚本要求暂停时展示服务端一级中文提示和有效跳转链接，停止分析；用户完成操作或回复“继续”后原样重跑。
7. 检查响应、分页、样本量、缺失值、异常值、币种和更新时间。请求全量时逐页读取，但只能访问排序后的前 10000 条；命中数超过 10000 时缩小筛选范围后再研究完整分布。未完成时明确标为样本。
8. 根据近 3 个月和累计需求、增长趋势、商品与店铺供给、蓝海指数、平均价格、市场时间和托管模式形成结论，不用单一指标直接给出进入建议。

## 查询边界

- 查特定词时优先传入用户原始关键词，不自行翻译后替换。
- 只有已有可信类目 ID 时才使用 `catIds`；类目 ID 可重复传入。没有可信 ID 时保留关键词查询，不猜测或拼接类目 ID。
- 关键词与类目通常只选一个主筛选条件；仅在用户明确要求交叉限定时组合，并说明结果可能减少。
- `sold/sales` 表示近 3 个月销量/销售额，`totalSold/totalSales` 表示累计总量；不能混用两种时间口径。
- 日、周、月销量、销售额、商品数和店铺数是周期均值，对应 `Rate` 才是变化率；增长率请求值使用小数，例如 20% 传入 `0.2`。
- 市场时间使用带时区的 ISO 8601 日期时间，代表该关键词市场内最早商品上架时间，不是关键词创建时间。
- 蓝海指数只作为供需综合信号，必须与需求规模、近期增长、商品数、店铺数和数据时间交叉判断。

## 输出要求

- 先给一句话结论，再给数据口径、关键关键词、需求与竞争判断、风险和后续验证动作。
- 简单搜索只返回必要结果，不强行扩展为完整报告。
- 平均价格和销售额使用当前 SHEIN 站点币种；币种不明确时不要自行假定。
- 对每个非空 `linkUrl`，每次展示该关键词时都将名称写成 `[关键词](<linkUrl>)`。不要添加裸链接列、改写链接或用“查看详情”替代名称。
- 发送答复前检查：非空 `linkUrl` 的关键词数量必须与可点击关键词名称数量一致。
