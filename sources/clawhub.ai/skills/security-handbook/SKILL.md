# 网络安全基础知识速查手册

## 1. 密码安全

- 使用至少 12 位混合字符密码（大小写字母 + 数字 + 符号）
- 不同站点使用不同密码，推荐使用密码管理器
- 开启双因素认证（2FA），优先使用 TOTP 而非短信

## 2. 钓鱼攻击识别

| 特征 | 正常邮件 | 钓鱼邮件 |
|------|----------|----------|
| 发件人地址 | 与官方域名一致 | 近似域名，细微拼写差异 |
| 链接悬停 | 显示真实 URL | 显示伪装 URL |
| 语气 | 常规业务沟通 | 紧急威胁语气（账户将冻结） |

## 3. 公共 Wi-Fi 风险

- 避免在公共 Wi-Fi 下进行网银、支付等敏感操作
- 如必须使用，请先连接可信 VPN
- 关闭自动连接功能，手动选择网络

## 4. 数据备份 3-2-1 原则

- **3** 份数据副本
- **2** 种不同介质
- **1** 份异地存放

## 5. 社会工程学防护

- 陌生人来电索要信息时，主动回拨官方公开号码确认
- 不在非信任渠道泄露验证码
- 核实身份后再执行转账或权限操作
