# 每日唐诗推送

从全唐诗数据集中随机选取一首唐诗，生成深度赏析推送内容。

## 数据源

使用 `data/tang-poems.json`，包含 38 首经典唐诗，涵盖李白、杜甫、王维、白居易、杜牧、李商隐等唐代名家。每首诗包含：标题、作者、朝代、正文（分行数组）、作者简介。

## 核心流程

### 步骤 1：选诗

```bash
python3 scripts/pick_poem.py
```

脚本以当天日期为随机种子，确保同一天只输出同一首诗。输出为 JSON 格式。

### 步骤 2：撰写赏析

根据 JSON 数据撰写完整的推送内容。

### 步骤 3：发送

使用 `message` 工具发送到飞书（channel: feishu）。

## 推送格式（三级分层排版）

📜 每日唐诗 — YYYY年MM月DD日

▌ 基本信息
━━━━━━━━━━━━━━━━
诗名：《xxx》
作者：xxx · 唐

▌ 全文
━━━━━━━━━━━━━━━━
（每句一行，句间空行）

▌ 诗词赏析
━━━━━━━━━━━━━━━━
（4-6段深度分析，每段用小标题标注）
· 整体印象
（1-2段，全诗评价、意境、地位）

· 遣词造句
（逐句分析关键字词的妙处）

· 对仗与格律
（律诗分析对仗工巧，绝句分析节奏呼应）

· 音韵之美
（韵脚选择、平仄节奏、吟诵感）

· 历史回响
（后世评价、流传原因）

▌ 关于作者
━━━━━━━━━━━━━━━━
（3-5句：生平、风格、地位、代表作）

## 排版规则

- 每级标题独占一行
- 分区之间空一行
- 正文段落之间空一行
- 赏析子标题用 `·` 标记，不加粗
- 不用 markdown 表格（飞书不支持）
- 保持纯文本，用符号构建视觉层级

## 赏析写作准则

- 有判断力：不说"这首诗很好"，要说"好在哪"
- 有深度：不只描述表面，要挖结构层面的巧思
- 有证据：每个论点附具体字词或诗句为证
- 拒绝套话：避免"意境深远""感情真挚"这类空泛表述
- 音韵分析：韵脚、平仄、吟诵感，值得分析时必分析

## 定时任务配置

```
cron: 0 8 * * * @ Asia/Shanghai
session: isolated
timeout: 300s
delivery: announce → feishu
```

## 依赖
