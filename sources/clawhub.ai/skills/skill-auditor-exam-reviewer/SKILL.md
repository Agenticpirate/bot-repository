# 注册审核员考试主观题复习工具

## 当前时间：2026年

---

## 核心规则

### 规则1：题目和答案分开存储

- **题目文件**：`references/questions/{科目}/{年份}-{月份}_题目.md`
- **答案文件**：`references/questions/{科目}/{年份}-{月份}_答案.md`

### 规则2：先展示题目，后展示答案

- 用户要求查看真题 → 读取**题目文件**，展示全部题目
- 用户要求查看答案 → 读取**答案文件**，展示对应答案

### 规则3：不生成文档

所有交互都在对话中完成，**禁止生成Word、PDF等文档**。

## 功能一：浏览历年真题

### 执行步骤

**步骤1：确定科目和日期**

从用户请求中提取科目名称，转换模糊时间表达。

**步骤2：读取题目文件**

```
文件路径：references/questions/{科目}/{年份}-{月份}_题目.md
```

**步骤3：展示题目内容**

直接输出题目文件的全部内容。

**步骤4：用户请求查看答案**

读取对应的答案文件：
```
文件路径：references/questions/{科目}/{年份}-{月份}_答案.md
```

---

## 功能二：模拟练习

### 执行步骤

**步骤1：确定科目**

从用户请求中提取科目名称，默认为用户之前提到的科目。

**步骤2：读取题目和答案文件**

读取题目文件和答案文件，从中抽取一道题。

**步骤3：展示题目（对话形式）**

```
【模拟练习】

题目：xxx

请作答：
```

**步骤4：等待用户作答**

不要主动给出答案，等待用户输入。

**步骤5：用户作答后，批改并给出解析**

```
【批改结果】

得分：X/10分

你的答案：
（用户写的答案）

参考答案：
（标准答案）

解析：
（知识点、答题技巧、参考来源等）
```

### 注意事项

- **禁止生成文档**：所有内容在对话中展示
- **等待用户作答**：出题后必须等待用户回复
- **答案在批改后展示**：用户作答前不展示答案

---

## 功能三：知识点速查

根据用户问题，读取教材或标准文件，直接在对话中返回定义和要点，标注参考来源。
