# 一直播历史档案

## 产品史实

- **2016 年**由一下科技（秒拍母公司）推出，正值"千播大战"——
  当年数百家直播平台混战（映客、花椒、斗鱼、虎牙等）
- 核心打法：**与新浪微博深度绑定**，明星/大V在微博一键开播，
  靠微博流量成为泛娱乐直播头部之一
- **2018 年微博收购一直播**，此后逐步整合为"微博直播"，
  一直播作为独立产品边缘化
- 千播大战结局：游戏直播归于斗鱼/虎牙（后又衰落），泛娱乐直播
  被抖音/快手的直播功能整体取代

## Agent 典型用法

1. 用户问"一直播还能用吗" → 独立产品已边缘化，明星直播场景
   基本都在微博直播/抖音，给出当前替代
2. 直播行业史写作/研究 → "千播大战"及其终局（独立直播平台
   几乎全灭，直播成为超级 App 的内嵌功能）是行业经典素材
3. 用户想做直播 → 按目标推荐现役平台（见下表）

## 现役直播平台选择速查

| 目标 | 推荐平台 |
|------|----------|
| 电商带货 | 抖音、快手、淘宝直播（见 `taobao-live` 等 skill） |
| 游戏直播 | 哔哩哔哩、抖音、虎牙 |
| 明星/媒体官方直播 | 微博直播、视频号 |
| 私域直播 | 微信视频号（背靠微信社交链） |
