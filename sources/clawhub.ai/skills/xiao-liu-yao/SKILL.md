# 小六爻（道家小六壬）测算

基于邵一尘前辈道家小六壬体系，通过农历月、日、时辰的三步推算法进行测算。
包含三盘体系（天盘/地盘/人盘）、体用生克、六道、藏干、六煞十二宫、类象等完整解读。

## 触发场景

- 用户说"算一卦"、"测算一下"、"今日运势"、"小六爻"、"小六壬"、"掐指一算"等
- 用户询问某事的吉凶走向
- 用户想用当前时间起卦占卜

## 使用流程

### 0. 信息确认（必须）

**先检查用户描述是否完整，不完整则必须确认后再测算。** 不要直接起卦。

分两步确认：

#### 第一步：基本测算信息

| 确认项 | 选项 | 说明 |
|--------|------|------|
| **测算事项** | 求财 / 感情 / 事业 / 求职 / 出行 / 健康 / 失物 / 考试 / 综合运势 / 其他 | 决定最终解读时使用哪个场景的速查 |
| **具体问题** | 用户自由描述 | 如"最近有个面试能过吗"、"这笔投资该不该做" |

#### 第二步：高级分析（可选）

基本测算完成后，**主动询问用户**是否需要以下高级分析：

| 高级分析 | 说明 | 需要用户补充的数据 |
|----------|------|-------------------|
| **应期推断** | 推算事件发生的时间节点（何时应验） | 无（基于落宫数字+季节自动推算） |
| **六亲推算** | 转太极法，推算父母/配偶/子女/兄弟等六亲相关事宜 | 关系人身份（父/母/配偶/子女/兄弟/朋友） |
| **面相分析** | 结合落宫分析面相三停（上停/中停/下停） | 面部描述或照片（可选，无则用落宫类象推断） |
| **风水分析** | 推算住宅朝向、内外风水布局 | 房屋朝向（可选，无则用落宫方位推算）、楼层 |
| **天象预测** | 推算指定日期的天气趋势 | 目标日期、地点 |
| **三宫具象** | 将三盘转为八卦卦象，深度解析天地人变化 | 无（基于三盘自动推算） |

**完整确认流程：**

1. 用户说"算一卦"等 → 先确认基本测算事项和具体问题

3. 用户选择某高级分析 → 如需补充数据则追问收集，否则直接推算
4. 用户选择多个高级分析 → 逐一收集数据、逐一推算呈现

## 高级分析技法

以下技法来自邵一尘前辈《道家小六壬神通》明卦篇和运技篇，
在基础测算完成后可选启用。

### 6. 应期推断

推算事件发生的具体时间节点。

**无需额外数据**，基于已有落宫推算：

| 落宫 | 应期季节 | 对应月份 | 数字应期 |
|------|----------|----------|----------|
| 大安 | 春季 | 寅卯辰月（2-4月） | 1/4/5/7 天/周/月 |
| 留连 | 长夏/春夏之交 | 辰巳月（4-6月） | 2/7/8/14 天/周/月 |
| 速喜 | 夏季 | 巳午未月（5-8月） | 3/6/9/15 天/周/月 |
| 赤口 | 秋季 | 申酉戌月（8-11月） | 4/1/2/10 天/周/月 |
| 小吉 | 冬季 | 亥子丑月（11-2月） | 5/3/8/11 天/周/月 |
| 空亡 | 冬春之交 | 丑寅月（1-3月） | 6/5/10/12 天/周/月 |

**解读规则：**
- 事件紧急 → 取天/周为单位
- 事件长远（如事业、投资） → 取周/月为单位
- 结合三盘：天盘起因的远近期 + 地盘发展的速度 + 人盘结果的时间窗口
- 体用生克微调：用生体 = 加速，用克体 = 延迟

### 7. 六亲推算（转太极法）

当问题涉及六亲关系人（父母、配偶、子女、兄弟、朋友等）时使用。

**需要确认：** 关系人身份

**推算规则（以落宫为"我"）：**

| 关系人 | 推算方法 | 示例（落宫=大安） |
|--------|----------|-------------------|
| 父母 | 落宫的生我者（按藏干寻） | 大安木，水生木 → 小吉(水)为父母 |
| 子女 | 我生者（落宫五行所生） | 大安木，木生火 → 速喜(火)为子女 |
| 配偶 | 我克者（落宫五行所克） | 大安木，木克土 → 留连/空亡(土)为配偶 |
| 兄弟/朋友 | 同我者（同五行） | 大安木 → 大安同为兄弟 |
| 官鬼/上级 | 克我者（克落宫五行） | 大安木，金克木 → 赤口(金)为上级 |

**五行生克对应：**
- 木(大安) → 生火(速喜)，克土(留连/空亡)，被金(赤口)克，被水(小吉)生
- 火(速喜) → 生土，克金(赤口)，被水(小吉)克，被木(大安)生
- 土(留连/空亡) → 生金(赤口)，克水(小吉)，被木(大安)克，被火(速喜)生
- 金(赤口) → 生水(小吉)，克木(大安)，被火(速喜)克，被土生
- 水(小吉) → 生木(大安)，克火(速喜)，被土克，被金(赤口)生

推出关系人的对应宫位后，以该宫属性解读关系人运势，仍结合三盘和体用。

### 8. 面相分析

结合落宫五行分析面相三停。

**可选数据：** 面部特征描述（额头/鼻/下巴），无则用落宫类象反推。

**三停对应：**
- **上停（额头/发际至印堂）** = 天盘宫位，主早年运势、祖上根基
- **中停（印堂至鼻准）** = 地盘宫位，主中年运势、自我发展
- **下停（人中至地阁）** = 人盘宫位，主晚年运势、子女福报

**六宫面相类象：**
- 大安(木)：眉发疏秀，头隆额耸，鼻长露节，清秀瘦挺
- 留连(土)：头顶平正，厚发浓眉，地廓方厚，肉实骨重
- 速喜(火)：眉发白黄，颧尖骨露，鼻纤鹰回，声炎焦烈
- 赤口(金)：头圆面方，耳正方直，颧突鼻阔，骨肉调匀
- 小吉(水)：面圆气浮，面阔而厚，鼻丰肉重，唇厚壑满
- 空亡(土)：头顶平正，鼻大准圆，耳实肥大，颈短头粗

**解读：** 若用户描述了面部特征 → 比对三停宫位，分析面相与运势的吻合度。无描述则直接呈现落宫对应的面相特征。

### 9. 风水分析

推算住宅风水格局。

**可选数据：** 房屋朝向（可选）、楼层（可选）、户型描述（可选）

**推算规则：**
- **天盘** = 住宅朝向（面向）
- **地盘** = 住宅坐山（背靠）
- **人盘** = 气流入口（大门/主要进气方向）

**六宫方位对应（后天八卦）：**
- 大安 = 震(东) | 留连 = 巽(东南)/坤(西南)/乾(西北)/艮(东北) | 速喜 = 离(南)
- 赤口 = 兑(西) | 小吉 = 坎(北) | 空亡 = 中央

**解读：** 若用户提供朝向 → 直接解读；否则默认落宫方位为朝向，分析该方位的风水吉凶。

### 10. 天象预测

推算指定日期天气趋势。

**必须数据：** 目标公历日期

**推算规则：**
- 以目标日期的农历月日时重新起卦（不是当前时间）
- 天盘 = 当日天气趋势，地盘 = 天气变化过程，人盘 = 最终天气

**六宫天象：**
- 大安 = 阴晴不定，风和日丽 | 留连 = 细雨绵绵，大雾
- 速喜 = 响晴霓虹，艳阳 | 赤口 = 雷雨暴雹，风雪
- 小吉 = 雨脚漉漉，阴雨 | 空亡 = 阴晦难明，多云

**三盘生克天象补充：**
- 木克土(天克地) = 干旱 | 土克水 = 干旱
- 金生水 = 降雨 | 水克火 = 起雾
- 火克金 = 雾霾 | 金克木 = 霜冻

### 11. 三宫具象法（八卦深度解析）

将三盘转为八卦卦象，深度解析天地人变化趋势。

**无需额外数据。**

**推算规则：**

三宫按阴阳属性（大安/速喜/小吉=阳，留连/赤口/空亡=阴）排列成八卦：

| 三宫阴阳序（天-人-地） | 八卦 | 卦名 | 意象 |
|------------------------|------|------|------|
| 阳阳阳 | ☰ | 乾 | 创始、强健、领导 |
| 阴阴阴 | ☷ | 坤 | 包容、承载、柔顺 |
| 阴阴阳 | ☳ | 震 | 震动、变革、行动 |
| 阳阴阴 | ☶ | 艮 | 停止、稳固、等待 |
| 阳阴阳 | ☲ | 离 | 依附、光明、文采 |
| 阴阳阴 | ☵ | 坎 | 险陷、流动、智慧 |
| 阴阳阳 | ☱ | 兑 | 喜悦、口舌、交流 |
| 阳阳阴 | ☴ | 巽 | 渗透、顺从、风行 |

**解读：** 得出八卦后，结合卦象含义 + 原落宫吉凶，给出深度趋势分析。如"天-人-地 = 空亡(阴)-速喜(阳)-速喜(阳) = ☱ 兑卦，虽落宫空亡大凶，但兑卦主喜悦交流，过程中有贵人相助之象"。

## 技术说明

- 依赖 `zhdate` 库进行公历→农历转换
- 时辰划分：子(23-1)、丑(1-3)、寅(3-5)、卯(5-7)、辰(7-9)、巳(9-11)、午(11-13)、未(13-15)、申(15-17)、酉(17-19)、戌(19-21)、亥(21-23)
- 算法：月落=(月数-1)%6; 日落=(月落+日数-1)%6; 时落=(日落+时数-1)%6
