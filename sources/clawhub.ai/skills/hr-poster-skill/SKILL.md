# HR Recruitment Poster

这个 Skill 是一个 **HR 运营直用** 的招聘海报总控 Skill。  
它不绑定具体出图模型，但必须能把零散招聘信息组织成一份 **可直接交给具备图片生成能力的 Agent 使用** 的完整海报方案。

它的目标是让 Agent 做到六件事：

1. 会识别海报场景
2. 会发现信息缺口并主动追问
3. 会选择合适模板
4. 会生成专业海报文案
5. 会给出视觉方向
6. 会输出可直接出图的 Prompt，并在输出前完成自检

## 何时调用

当用户出现以下需求时调用：

- 帮我做招聘海报
- 做校招海报 / 社招海报 / 内推海报
- 做招聘活动海报 / 宣讲会海报
- 做简历服务宣传海报
- 做雇主品牌 / HR 传播海报
- 生成岗位招募主视觉

不适用于：

- 纯代码生成
- 与招聘、简历、HR传播无关的普通营销海报
- 只要一句 slogan、不需要完整海报方案的场景

## 什么叫“专业 HR 招聘海报 Skill”

一个专业版本至少满足以下标准：

### 1. 目标清楚

能明确这张海报是为了：

- 招聘获客
- 岗位曝光
- 简历投递
- 活动报名
- 内推转发
- 品牌吸引

### 2. 受众准确

能区分并适配：

- 校招生
- 社招候选人
- 中高级候选人
- 内部员工
- 求职服务用户
- 泛传播受众

### 3. 内容可信

不编造公司、岗位、薪资、福利、报名路径、活动信息。  
没有信息时要追问，或者明确标注“待补充”。

这里要特别区分两类招聘海报：

- **详情型招聘海报**：强调岗位细节、投递信息、工作地点、薪资、要求等
- **范围型 / 营销型招聘海报**：强调“我们在招人”“多个岗位开放”“欢迎来聊/来投递”，更偏品牌传播和招募氛围，不一定需要写清薪资范围等细节

对于范围型 / 营销型招聘海报，不要求强行补齐薪资、城市、岗位要求等细字段；  
但仍然必须保证以下信息尽量明确：

- 招聘主题
- 目标受众
- 招募范围或岗位方向
- 核心吸引点
- 行动方式（如投递、咨询、了解更多）

### 4. 结构可读

要保证用户一眼知道：

- 这是招什么 / 宣传什么
- 为什么值得点
- 下一步怎么做

### 5. 设计有判断

不是泛泛说“高级感”“年轻化”，而是能给出：

- 风格关键词
- 色彩方向
- 构图方式
- 信息层级
- 元素限制

### 6. 结果可执行

最终输出必须能直接交给具备出图能力的 Agent，而不是只停留在创意说明。

### 7. 语言有审美

这类 Skill 的文字本身也要有气质，尤其是视觉风格描述和品牌表达，不应只是说明书式的大白话。

要求如下：

- 用词要贴近中文语境，避免生硬直译感
- 可以有画面感、留白感、情绪感，但不要空泛悬浮
- 要有节制的艺术性，而不是堆砌辞藻
- 对视觉风格的描述，应尽量让人“看见气氛”，而不只是看到几个标签词
- 对招聘表达要保持分寸，不能为了显得高级而失去真实感

## 工作方式

### 总控流程

调用本 Skill 时，必须按以下顺序执行：

1. 识别场景
2. 检查信息是否足够
3. 信息不足时主动追问
4. 选择匹配模板
5. 生成海报方案
6. 生成出图 Prompt
7. 根据质检清单做一次自检

### 信息不足时必须追问

如果用户没有给全，不要硬生成。  
优先追问这些字段：

1. 海报类型
2. 传播目标
3. 目标受众
4. 公司 / 组织名称
5. 岗位 / 活动 / 服务名称
6. 核心卖点
7. 投递 / 报名 / 联系方式
8. 渠道 / 尺寸
9. 风格偏好

但要注意追问强度要跟海报类型匹配：

- 如果是 **详情型招聘海报**，应优先补齐岗位、投递路径、地点、福利等细信息
- 如果是 **范围型 / 营销型招聘海报**，则优先补齐主题、受众、招募范围、吸引点、传播渠道，不必强求薪资等字段

如果只缺次要信息，可以边假设边输出，但必须显式写出：

- 已知信息
- 默认假设
- 待补充信息

## 场景路由规则

先判断属于哪一类，再进入对应模板：

1. **校招海报**
   - 对象是学生或应届生
   - 调用：`templates/campus_recruitment.md`

2. **社招海报**
   - 对象是社会候选人、中高级人才、岗位招聘
   - 同时包含：
     - 详情型岗位海报
     - 范围型 / 营销型招募海报
   - 调用：`templates/social_recruitment.md`

3. **内推海报**
   - 对象是内部员工传播或转发
   - 调用：`templates/internal_referral.md`

4. **招聘活动海报**
   - 宣讲会、双选会、直播、活动报名
   - 调用：`templates/recruitment_event.md`

5. **简历服务海报**
   - 简历诊断、求职辅导、简历优化服务
   - 调用：`templates/resume_service.md`

6. **品牌传播海报**
   - 雇主品牌、团队文化、组织吸引力
   - 调用：`templates/employer_branding.md`

## 固定输出格式

每次调用本 Skill，最终输出必须尽量稳定成下面结构：

```markdown
## 海报定位
- 海报类型
- 传播目标
- 目标受众
- 使用场景

## 信息补齐结果
- 已知信息
- 默认假设
- 待补充信息

## 海报文案
- 主标题
- 副标题
- 卖点
- 补充信息
- CTA

## 视觉方向
- 风格关键词
- 色彩方向
- 构图方式
- 字体气质
- 元素建议
- 不建议做法

## 出图 Prompt

## 质检清单
```

## 对出图 Prompt 的要求

给下游出图 Agent 的 Prompt 里必须至少包含：

- 海报主题
- 传播目标
- 目标受众
- 主标题与副标题
- 卖点信息
- CTA
- 风格关键词
- 色彩方向
- 构图要求
- 信息层级要求
- 设计限制项

## 对 Agent 的执行要求

1. 不要直接生成空泛海报
2. 不要跳过追问环节
3. 不要虚构招聘信息
4. 不要输出只有文案、没有视觉与 Prompt 的半成品
5. 不要忽略模板路由
6. 输出前必须用质检清单做一次自检
7. 视觉风格与品牌表达不要写成说明书式大白话
8. 在中文表达上要兼顾审美、传播性与可信度

## 模板库维护原则

模板库是这个 Skill 专业化的核心资产。  
模板必须做到：

- 按场景拆分
- 结构统一
- 语气专业
- 可直接复用
- 可直接交给出图 Agent
