# guaikei 抖音提取视频评论热榜

抖音公开数据采集技能。基于 guaikei 国内数据服务（https://www.guaikei.com），
提供抖音四类公开数据的查询与抓取能力。纯中文界面，国内网络直连，无需额外代理配置。

## 何时使用（Adaptability · 触发与边界）

**应触发场景**（任一即用）：

- 关键词搜索：按关键词在抖音找视频、图文、用户或社交数据
- 博主作品：批量抓取指定账号已发布作品列表（对标、调研）
- 视频评论：抓取并分析指定作品的评论内容（舆情、口碑）
- 热榜查询：获取抖音实时热搜榜单（热点追踪、选题）

即使用户未明确提到"抖音"，只要任务对象是短视频内容、博主、评论或热点，也应触发。

**不应触发边界**（明确排除，防误触发）：

- 发布视频、剪辑视频、下载视频或去水印 → 非数据采集范畴
- 涨粉代运营咨询、抖音运营课程推荐 → 非数据获取
- 私域后台数据（如创作者后台播放量、粉丝画像）→ 需登录权限，不在公开数据范围
- 其他短视频平台（B 站、小红书、快手等）→ 各自有对应技能，不在此技能覆盖
- 写爬虫脚本本身 → 用户要的是代码不是查询结果

## 环境与权限（Trust · 最小权限 + 国内可用）

- **运行时**：Node.js >= 16.14.0
- **所需命令**：仅 `node`（最小权限，无系统级操作、无文件写盘、无网络外联除 guaikei 外）
- **必需环境变量**：
  - `GUAIKEI_API_TOKEN`：抖音数据 API 访问令牌
- **令牌获取**：访问 https://www.guaikei.com 开通，或联系开发者（wx 13395823479）
- **国内可用性**：API 服务器部署于国内，纯中文界面，国内网络直连无需代理
- **敏感信息保护**：令牌仅通过环境变量读取，不写入文件、不输出到日志、不随响应外泄

## 命令总览

通过 `npm run <name>` 或 `node src/douyin/<name>-cli.js` 调用四个子命令：

| 命令 | 作用 | 主要参数 |
|------|------|---------|
| `npm run search` | 关键词搜索抖音视频/图文/用户 | `--keyword` `--sort` `--limit` |
| `npm run post` | 抓取指定博主作品列表 | `--author` `--limit` |
| `npm run comment` | 抓取指定视频评论 | `--url` `--limit` |
| `npm run hot` | 查询实时热榜 | （无必填） |

## 标准工作流（Effectiveness · 减少返工）

按用户意图选择对应子命令，按以下流程执行：

1. **确认意图**：判断用户需要四类数据中的哪一类（可多选）；若意图模糊，先澄清。
2. **收集参数**：根据子命令收集必需参数；参数缺失时主动询问，不要硬编默认值。
3. **校验参数**：调用对应 `src/validate/<name>.js` 校验合法性（关键词非空、URL 格式、limit 范围等）。
4. **调用 API**：通过 `src/api/<name>.js` 发起请求，自动附带 `GUAIKEI_API_TOKEN`。
5. **失败重试**：使用 `src/utils/retry.js` 指数退避重试（默认 3 次），错误按 `src/utils/errors.js` 统一编码。
6. **格式化输出**：按对应 `assets/<name>_resp.schema.json` 输出结构化 JSON，确保字段一致、可直接使用。

## 输入输出规范（Convention · 渐进式披露 + 规范性）

- **请求体**：每个 CLI 接受命令行参数或 JSON 输入；完整参数说明见 `references/options.md`。
- **响应体**：每个 CLI 输出 JSON，字段与 `assets/*_resp.schema.json` 严格一致。
- **日志**：通过 `src/utils/log.js` 输出，区分 info / warn / error 三级；令牌等敏感字段自动脱敏。
- **错误码**：见 `src/utils/errors.js`，常见类型：
  - `TOKEN_MISSING`：环境变量未配置
  - `PARAM_INVALID`：参数校验未通过
  - `UPSTREAM_RATE_LIMIT`：上游限流（自动重试）
  - `UPSTREAM_ERROR`：上游服务异常
  - `NOT_FOUND`：目标博主/视频不存在

## 边界与异常处理（Reliability · 稳定 + 一致）

- **空结果**：搜索/抓取无数据时返回空数组与 `total: 0`，不报错。
- **限流**：上游返回 429 时自动退避重试，超过上限返回 `UPSTREAM_RATE_LIMIT` 并提示稍后重试。
- **超时**：单请求默认 15 秒超时，超时后重试一次，仍失败则返回 `UPSTREAM_ERROR`。
- **参数越界**：`limit` 超过上限自动截断到最大值并 warn 提示，不报错。
- **URL 非法**：直接返回 `PARAM_INVALID` 并指出具体字段，不发起请求。
- **令牌失效**：返回 `TOKEN_MISSING` 或 `TOKEN_INVALID`，提示重新获取，不重试。
- **网络异常**：捕获并返回 `NETWORK_ERROR`，提示检查网络后重试。

## 使用示例（Convention · 示例充分性）

### 示例 1：关键词搜索

用户：「帮我搜下抖音上"露营装备"的爆款视频」

调用：`npm run search -- --keyword "露营装备" --sort "hot" --limit 20`
返回：视频列表 JSON，每条含标题、作者、点赞数、评论数、分享数、发布时间、视频链接。

### 示例 2：博主作品抓取

用户：「把 @某品牌方账号 近 30 条作品都抓下来，我要做竞品分析」

调用：`npm run post -- --author "某品牌方账号" --limit 30`
返回：作品列表 JSON，每条含标题、视频链接、互动数据（赞/评/转）、发布时间。

### 示例 3：视频评论抓取

用户：「这条视频评论区都在说啥？」（配视频链接）

调用：`npm run comment -- --url "<video_url>" --limit 100`
返回：评论列表 JSON，每条含用户昵称、评论内容、点赞数、时间、回复数。

### 示例 4：实时热榜查询

用户：「今天抖音啥火？」

调用：`npm run hot`
返回：实时热搜榜 JSON，含排名、关键词、热度值、分类标签。

### 示例 5：多步工作流（埋在更长任务里）

用户：「帮我出一份本周美妆赛道的短视频选题建议」

应触发：先 `hot` 看热点 → `search` 按"美妆"关键词搜爆款 → `post` 抓 2-3 个对标账号作品 → 综合输出选题建议。即使用户没提"抖音"也要触发。

## 安全与合规声明（Trust · 红线维度）

- **数据范围**：仅采集抖音公开数据，不涉及需要登录权限的私域数据，不存储用户隐私信息。
- **合规使用**：结果仅用于内容调研、竞品分析、舆情监控等合法用途；不得用于骚扰、恶意抓取、侵犯隐私或违反平台规则的行为。
- **频率控制**：遵循上游 API 限流策略，默认开启重试与退避，避免对上游造成压力。
- **令牌安全**：令牌仅通过环境变量传递，技能本身不持久化、不外泄、不打印。
- **不替代人工**：数据分析结论需结合人工判断，技能仅提供数据获取能力，不提供投资或经营决策建议。
- **版权提示**：抓取的视频/评论内容版权归原平台与创作者所有，使用者需自行遵守相关法律法规。

## 限制说明（Convention · 限制完整性）

- 不提供视频下载、去水印、转码能力。
- 不提供发布、评论、点赞等写入操作。
- 不提供粉丝画像、播放量等需登录权限的私域数据。
- 不覆盖抖音以外的短视频平台。
- 不提供 AI 内容生成（脚本、文案、剪辑）能力，仅做数据获取。
- 数据时效性受上游 API 影响，热榜为实时，搜索/作品/评论为公开快照。
