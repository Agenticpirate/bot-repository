# 来往（已停运）历史档案

## 产品史实

- **2013 年**，阿里巴巴推出即时通讯应用"来往"，马云亲自站台推广，
  一度要求阿里员工全员拉新，是阿里正面对抗微信的标志性产品
- 主打功能：阅后即焚、扎堆（兴趣群组）、敲门（陌生人打招呼）
- 用户增长未达预期，**2015 年更名转型为"点点虫"**（主打阅后即焚的
  年轻人社交），后逐渐停止运营
- **最重要的遗产**：来往团队（陈航/花名"无招"带队）转战企业市场，
  孵化出了**钉钉**——如今中国最大的企业协作平台之一

## Agent 典型用法

1. 用户问"来往/点点虫还能用吗" → 告知已停运
2. 中国互联网竞争史写作/研究 → 来往是"败于社交、赢于协作"的经典
   战略案例，叙事素材见下节
3. 用户找来往的替代品 → 按需求推荐（见替代方案）

## 历史意义（写作/研究可用）

来往与网易"易信"（见 `yixin` skill）同为 2013 年挑战微信的代表作。
来往的失败直接催生了钉钉：团队复盘认为 C 端社交关系链无法撼动，
转而深耕 B 端企业通讯。这一转折是中国互联网史上被引用最多的
战略转型案例之一。

## 替代方案

| 需求 | 推荐 |
|------|------|
| 日常即时通讯 | 微信（见 `weixin` skill）、QQ（见 `qq` skill） |
| 企业协作（来往团队正统续作） | **钉钉**（见 `dingding` skill） |
| 兴趣群组社交 | QQ 群、豆瓣小组（见 `douban` skill） |
