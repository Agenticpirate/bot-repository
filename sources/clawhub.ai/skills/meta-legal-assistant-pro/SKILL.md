# meta-legal-assistant-pro（蒸馏超越型元技能）

> 由 `model-distillation` 从教师技能 **legal-assistant-pro** 蒸馏并增强生成。
> 蒸馏机制：跨模型蒸馏（见 meta-evolver 北极星策略「主动与其他大模型对话、蒸馏、逐步超越」）。

## 来源能力签名（教师 legal-assistant-pro）
- 规模：原始 SKILL.md 2570 字符、18 步显性工作流、1 个 learner.py、已识别 1 处限制。
- 定位：综合中国法律助手，覆盖 8 大模块 + 4 套工作流，所有信息基于中国现行法律法规，仅供参考不构成正式法律意见。
- 八大模块：合同审查 / 劳动权益 / 消费维权 / 婚姻家庭 / 房产纠纷 / 借贷债务 / 网络权益 / 交通处理。
- 四套工作流：
  1. 合同审查：识别类型→逐条风险(违约/管辖/送达/解约)→标高/中/低等级→修改建议与谈判话术→《合同审查意见书》。
  2. 权益维权：确认法律关系→有利/不利分析→分步路径(协商→投诉→调解→仲裁/诉讼)→证据清单→周期与结果预估。
  3. 法条查询：搜法→白话解读→适用条件与例外→司法解释与典型案例。
  4. 仲裁诉讼：管辖规则→诉讼时效→费用预估→全流程(立案→举证→开庭→判决→执行)。
- 数据来源：民法典/劳动法/消保法/最高法司法解释/裁判文书网典型案例 + WebSearch 最新动态。

## 蒸馏出的真实工作流（继承 + 强化）
- 关键安全边界（教师硬约束，蒸馏为不可绕过红线）：
  - **不得出具法律意见书或代理诉讼**；
  - **遇刑事犯罪嫌疑（诈骗/伤害/性侵等）必须建议立即报警**；
  - **遇群体性纠纷建议联系法律援助中心**；
  - 劳动纠纷先 12333 劳动监察→仲裁；消费纠纷先 12315→市监投诉；
  - 所有"胜诉率/赔偿金额"必须标"仅供参考"。

## 增强点（超越教师）
1. **可靠自验证**：每条法律风险标注后，用 `reason-verify` 校验"法条依据可追溯 + 风险等级自洽"；引用法条必须给出来源/条款，无来源强制标「待核验」。
2. **自我反思闭环**：每次咨询后写入 `self-reflection-loop`，沉淀"哪类纠纷最常超出售前边界"，反哺红线触发逻辑。
3. **整合进 super-agent**：作为节点接入「感知→规划→执行→自验证→反思→记忆」超级智能体闭环，可被长程维权任务编排。
4. **对抗验证蒸馏质量**：对安全红线做反例测试——故意输入"帮我写起诉状/代理诉讼/保证胜诉"，验证一律拦截并引导至持证律师/报警/法援，防越界。
5. **持续自进化**：注入 learner，纳入 meta-evolver 的 sense/plan/record 闭环，跨会话越用越强。

## 教师 vs 学生 对比
| 维度 | 教师(legal-assistant-pro) | 学生(meta-legal-assistant-pro) |
| --- | --- | --- |
| 工作流 | 18 步显性流程（4 套） | 同流程 + 自验证钩子 + 红线对抗验证 |
| 失败防护 | 已识别 1 处限制 | 显式红线 + 对抗验证（越界必拦） |
| 自进化 | 已有 learner.py | 强化注入，纳入 meta-evolver 闭环 |
| 集成 | 单点法律助手 | 接入 super-agent 感知→规划→执行→自验证→反思→记忆闭环 |

## 使用
直接调用本技能完成中国法域咨询/合同审查/维权指引；本技能在教师能力之上叠加自验证、红线对抗验证与反思，输出更可靠、可追溯、守边界。

## 已知限制（来自教师蒸馏 + 元进化补充）
- 教师信息基于中国现行法律法规仅供参考，**不构成正式法律意见**；本元技能同样遵守不出具意见书/不代理诉讼的红线。
- 教师依赖 WebSearch 获取最新法律动态，蒸馏未内嵌实时取数通道，实跑需联网核验最新法条。
- 蒸馏不保证覆盖教师全部隐式知识（如完整《合同审查意见书》模板），深度使用需对照教师原技能核验。
