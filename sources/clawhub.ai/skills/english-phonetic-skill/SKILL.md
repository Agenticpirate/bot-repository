# 英语音标标注技能

## 功能概述

本技能能够将输入的英语文本自动标注国际音标(IPA)、轻重音符号、升降调标记以及**中文拼音对照读音**，帮助中文母语者通过熟悉的拼音系统快速掌握英语发音。

## 快速导航

- 用户输入英语文本 → 自动标注音标、轻重音、升降调和中文拼音
- 用户询问发音规则 → 提供详细的语音学解释和拼音对照
- 用户需要发音练习 → 生成练习材料和评估标准

## 标注规范

### 音标系统
- 使用国际音标(IPA)标准
- 英式发音和美式发音可选
- 支持单词级和句子级标注

### 轻重音标记
- 主重音：ˈ（标在重读音节前）
- 次重音：ˌ（标在次重读音节前）
- 轻读音节：不标记或使用 ə 表示弱化

### 升降调标记
- 升调：↗（表示疑问、未完待续）
- 降调：↘（表示陈述、命令、结束）
- 平调：→（表示列举、过渡）
- 降升调：↘↗（表示犹豫、保留）

**拼音标注规则**：
- 声调：默认使用第一声（阴平），重读音节可适当延长
- 儿化音：美式发音中的 r 音用"儿"标注，如 car → ka-er
- 连读：自然语流中的连读现象用连字符连接

## 使用示例

### 单词标注（含拼音对照）
输入：hello
输出：
```
英文：hello
音标：həˈləʊ ↘
拼音：he-lou（喝-喽）
```

输入：world
输出：
```
英文：world
音标：wɜːld ↘
拼音：we-er-de（乌-饿-的）
```

### 句子标注（含拼音对照）
输入：How are you today?
输出：
```
英文：How are you today?
音标：haʊ ɑː juː təˈdeɪ ↗
拼音：hao a yu te-dei（好 阿 鱼 特-嘚）
```

输入：Thank you very much.
输出：
```
英文：Thank you very much.
音标：θæŋk juː ˈveri mʌtʃ ↘
拼音：sang-ke yu wei-ri ma-chi（桑-克 鱼 为-日 马-吃）
```

### 段落标注（含拼音对照）
输入：Good morning, everyone. Today we will learn about phonetics.
输出：
```
英文：Good morning, everyone.
音标：ɡʊd ˈmɔːnɪŋ, ˈevriwʌn →
拼音：gu-de mao-ning, ai-wu-ri-wan（古-的 猫-宁，爱-乌-日-万）

英文：Today we will learn about phonetics.
音标：təˈdeɪ wiː wɪl lɜːn əˈbaʊt fəˈnetɪks ↘
拼音：te-dei wi wei-er len e-bao-te fe-nei-ti-ks（特-嘚 为 为-饿 冷 饿-抱-特 佛-内-踢-克斯）
```

## 技术实现

本技能基于以下技术栈：
- 语音学规则库：包含英语发音规则和例外情况
- 音标转换引擎：实现文本到音标的自动转换
- 语调分析算法：基于语法结构和语义分析确定语调模式
- 轻重音标注器：根据词汇重音规则自动标注
- **拼音对照系统**：将英语音标映射到最相近的中文拼音发音

## 适用场景

- **中文母语者英语学习**：通过拼音快速掌握英语发音
- 英语教师教学辅助
- 语音识别和合成研究
- 语言学研究分析
- 英语口语练习和纠正

## 注意事项

1. 拼音标注仅为辅助记忆工具，帮助中文使用者快速入门
2. 英语发音与中文拼音存在差异，建议结合音标和音频材料练习
3. 部分英语发音在中文中无完全对应，采用最接近的拼音表示
4. 实际发音可能因地区、个人习惯而有所差异
5. 对于专业语音学研究，建议使用专业语音分析软件
