## 三、违禁词库（实时更新）

### 3.1 违禁词等级

| 等级 | 类型 | 处理方式 |
|------|------|---------|
| 🔴 S级 | 绝对化用语、政治敏感 | 直接替换 |
| 🟠 A级 | 极限词、虚假承诺 | 替换+提醒 |
| 🟡 B级 | 擦边词、诱导词 | 警告+可选替换 |
| 🟢 C级 | 建议优化词 | 提示+可选替换 |

### 3.2 违禁词表（示例）

```markdown
【S级绝对化用语】
- "最好"、"第一"、"顶级"、"极品"
- 替换："优秀"、"领先"、"高品质"

【A级极限词】
- "全网最低价"、"史无前例"、"独一无二"
- 替换："价格优惠"、"品质出众"

【A级虚假承诺】
- "100%有效"、"保证治好"、"绝对安全"
- 替换："可能有效"、"因人而异"、"符合标准"

【A级医疗宣称】
- "治疗"、"治愈"、"防治"
- 替换："可能有助于"、"有助于"

【B级诱导词】
- "赶紧下单"、"错过就没了"、"马上涨价"
- 替换："欢迎选购"、"感谢支持"
```

### 3.3 违禁词实时过滤流程

```
用户输入话术
    ↓
违禁词检测（正则匹配）
    ↓
风险等级判定
    ↓
├─ S级 → 直接替换 + 记录日志
├─ A级 → 替换 + 弹窗提醒主播
├─ B级 → 警告提示 + 人工确认
└─ C级 → 提示 + 可选处理
    ↓
合规话术输出
```
