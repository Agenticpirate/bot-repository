# 极鲸云 Shopee 店铺研究

## 原则

- 指定市场时先运行 `scripts/shopee_site_list.py` 实时解析；未指定市场才使用服务端默认 `siteId=1`，不能推断它对应哪个国家。
- 已知店铺 ID 时运行 `scripts/shopee_mall_info.py`；研究该店商品时运行商品搜索，并只保留 `mallId` 完全相同的结果。
- 只有商品 ID 时，可先用商品搜索定位，再从结果中的 `mallId` 查询店铺。
- 当前搜索匹配商品名、商品 ID 和店铺 ID，不匹配店铺名称。只有店铺名称时应请用户提供店铺 ID 或代表商品 ID，不能猜。
- `isCross` 仅按接口返回解释；缺失时不猜本土或跨境，也不代替 Seller Centre 的卖家资质和账号健康信息。
- 服务端要求暂停时，按 [查询暂停与恢复流程](references/查询暂停与恢复流程.md) 处理。

## 工作流

1. 明确站点和店铺 ID；运行 [店铺接口](references/Shopee店铺接口.md) 获取详情。
2. 如需商品结构，将店铺 ID 作为商品搜索关键词，逐条精确过滤 `mallId`；最多访问前 200 条。
3. 按 [店铺研究](references/Shopee店铺研究.md) 分析规模、销售、客单、粉丝、跨境属性、类目和商品效率。
4. 对缺失字段、采集时间和异常值单独披露；不得把样本商品数当作店铺完整商品数。
5. 涉及经营动作时读取 [运营与政策口径](references/Shopee运营与政策口径.md)。

## 边界

- 当前没有店铺名称搜索、店铺列表搜索、订单、退货、广告、佣金、履约指标或账号违规数据。
- 接口未返回前台链接时，不自行拼接店铺 URL。
- 店铺销量和销售额是极鲸云指标，不称为 Shopee 官方结算数据。

输出默认包含：店铺概况、经营证据、商品结构、风险、样本边界和下一步验证。
