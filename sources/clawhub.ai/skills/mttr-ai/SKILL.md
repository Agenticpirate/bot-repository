# 查询mttr/事件量/ai提效

## 适用场景
查询安全水位的指标：mttr、事件量、ai提效



## 执行流程
> Claude 请严格按以下步骤依次查询数据表并分析，注意每一步的依赖关系、输入与输出字段。

```
1、若用户无主语、无限定词，如“本周mttr多少”、“最近事件量变化怎么样”等问题，
则，默认查询 部门 = 信息安全部 的指标值。
2、若用户未指定时间，则**默认查询本周**数据。
3、若查询各安全域/各部门/各组织，则不包含信安，必须剔除信息安全部。
4、若用户查询月度、季度、年度的mttr，则：先查询本周mttr数据、再告知当前不支持查询月度、季度、年度的mttr。
```
