# 猫眼电影 Skill

猫眼是中国头部电影票务平台（与淘票票双寡头），其**猫眼专业版**
是行业事实标准的实时票房数据源——媒体报道"某片票房破 X 亿"
多数引用猫眼口径。

## 购票决策指南

### 影厅规格怎么选（票价差从几元到上百元）

| 规格 | 值回票价的场景 |
|------|----------------|
| 普通厅 | 剧情/文艺片，视效无关紧要 |
| IMAX / 中国巨幕 | 大场面视效片；优先选激光厅 |
| 杜比影院(Dolby Cinema) | 画质+音效综合最强，暗场景多的片子差异明显 |
| CINITY / 高帧率厅 | 明确为高帧率制作的影片才值 |
| 4DX/MX4D 动感厅 | 体验型观影，晕动症者避开 |

- 选座经验：屏幕高度 1/2~2/3 处、居中偏后排是稳妥区；IMAX 厅
  不要选前三排
- 优惠逻辑：新客券、影城卡、会员日、银行卡活动可叠加度不同，
  下单页比一下"券后价"再决定平台

### 退改签

- 是否支持**退票/改签由影院逐场设置**，下单前看场次页标识；
  开场前越早手续费越低，临近开场多数不可退

## 票房数据素养（写影视分析必读）

引用票房数据的规范姿势：

- **口径**：猫眼实时票房含服务费，与拓普/灯塔口径略有差异，
  引用时注明"猫眼专业版数据"
- **关键指标**：
  - 排片占比 vs 票房占比：票房占比 > 排片占比 = 上座率强势，
    次日排片大概率上调（市场用脚投票）
  - 上座率：对比同档期影片才有意义，绝对值受影厅供给影响
  - 预测总票房：猫眼 AI 预测会随首日/首周末数据大幅修正，
    引用要带时间戳
- **档期效应**：春节/国庆档大盘膨胀，单片数据不能跨档期直接比

## Agent 典型用法

1. **观影决策**：按影片类型推荐影厅规格与选座区，提醒退改签规则
2. **票房解读**：用户给数据 → 按"排片/票房占比剪刀差"等逻辑解读
   走势，指出数据口径
3. **影视写作**：为文章提供数据引用规范（口径+时间戳+来源标注）
4. **档期分析**：对比历史同档期数据框架，避免跨档期误比

## 本 skill 不做什么

- 不提供抢票脚本、刷票、黄牛渠道（违规且有资金风险）
- 票价与优惠实时变动，以 App 下单页为准
- 猫眼开放平台面向影院/片方等 B 端签约合作，个人开发者无公开
  票房 API；写作引用建议直接标注"猫眼专业版 App"人工核对
