# 视频号直播复盘六部曲

> 抖音复盘看「场观→成交」流量漏斗，视频号复盘看「私域导入→社交放大→长周期复购」关系漏斗。

复盘逻辑递进：

```
私域数据复盘 → 节奏话术复盘 → 商品复盘 → 人群复盘 → 社交裂变复盘 → 7天滚动复盘
```

---

## 第1步：私域数据复盘（定基调）

**核心差异**：视频号不考核首日 GPM，考核私域导入能力 + 社交裂变率。

### 检查清单

**私域导入（视频号的「投流预算」）**
- [ ] 预约人数→实际进房率 ≥ 40%（低于40%说明预告钩子/私域号召力有问题）
- [ ] 私域导入占比（好友/群/公众号粉丝进房）
- [ ] 开播前48h朋友圈/社群/公众号预约数

**社交裂变**
- [ ] 分享直播间次数（核心杠杆，权重 > 点赞）
- [ ] 社交裂变占比（分享到朋友圈/群带来的新进房）
- [ ] 分享率 < 1% → 基本拿不到裂变流量，需要加强话术引导

**停留与留存**
- [ ] 30s有效停留率（视频号阈值，低于30s不算有效看播）
- [ ] 人均观看时长 ≥ 1.5-3min（类目不同浮动）
- [ ] 前5分钟留存（看私域导入质量）
- [ ] 注意：**停留时长口径不同**，抖音2s算停留，视频号30s才算有效

**互动**
- [ ] 点赞/评论（保留，但不作为核心）
- [ ] 分享直播间次数 ✅ 核心杠杆
- [ ] 预约下场直播人数
- [ ] 新增关注率（视频号关注权重 > 抖音）
- [ ] 企微/粉丝群添加数（私域承接）

**转化**
- [ ] 客单价（视频号普遍100-500，过低反而可疑）
- [ ] 私域流量转化率 vs 公域流量转化率（分开看）
- [ ] 首单转化率
- [ ] 老粉复购率（视频号复购35-50%是常态指标）
- [ ] 加企微率 → 24h私域追单转化率

**判定信号**：
- 预约转化率低（<40%）→ 私域号召力或预告钩子有问题
- 分享率低（<1%）→ 话术缺少分享引导节点
- 私域转化高但公域转化低 → 正常，视频号本来就是私域养公域
- 私域转化8%、公域转化0.5% → **不是公域废了，是私域导入人数不够**

## 第2步：节奏话术复盘（定成败）

**核心差异**：视频号5-7分钟过一个品，逼单太猛反而掉粉。不考核3秒钩子密度。

### 检查清单

- [ ] 单品讲解时长分布 ≥ 5min（抖音化的128秒过款不适用）
- [ ] 语速是否适配（偏慢、聊天感，不是快节奏逼单）
- [ ] 人设输出时长占比（讲场景/人设/故事的时间 ≥ 纯卖点时间）
- [ ] 信任型讲解占比（人设/溯源/干货前置，而非纯卖点轰炸）
- [ ] 引导分享话术节点：**每10-15分钟一次**，不止一次
- [ ] 私域钩子节点（「进群领资料」「加企微看售后」）
- [ ] 开播极速流（来自预约）接住了没有

**判定信号**：
- 过品节奏 < 3min → 视频号算法降权，不符合平台生态
- 没有引导分享话术 → 拿不到社交裂变流量
- 逼单话术过多 → 老粉流失，影响复购

### 话术节奏参考

```
开播0-5min：承接预约流量，发福利，引导分享
5-15min：第一个品，慢讲人设/场景/故事
15-25min：第二个品，中间穿插引导分享+预约下场
25-35min：第三个品，信任型讲解+私域钩子
35-40min：收尾，预约下场，加企微引导
```

## 第3步：商品复盘（找爆款）

**核心差异**：视频号高客单100-500是常态，GPM降权处理。

### 检查清单

- [ ] 单品曝光点击率（参考阈：15%合格）
- [ ] 点击成交转化率（高客单>5%，中低10-15%）
- [ ] 高客单承接能力评估（100-500元区间，过低反而可疑）
- [ ] 私域成交 vs 公域成交分开看

**诊断方向**：
- 曝光高点击低 → 中控弹窗问题/话术匹配度
- 点击高转化低 → 信任度不够/价格感知问题
- 高转化集中发生在私域流量时段 → 品可能只适合老客

---

## 第4步：人群复盘（判精准）

**核心差异**：视频号30-55岁为主，偏理性、信任决策时长更长。

### 检查清单

- [ ] 看播用户画像（年龄/地域/兴趣）
- [ ] 购买用户画像
- [ ] 两者是否一致
- [ ] 私域导入人群 vs 公域推荐人群画像对比
- [ ] 是否有主力人群（不是均匀分散）

**判定信号**：
- 人群均匀无主力 → 标签混乱
- 看播和购买人群不一致 → 品不对人

---

## 第5步：社交裂变复盘（挖流量）

**核心差异**：视频号拿流量的核心杠杆是社交分享，不是短视频引流。

### 检查清单

- [ ] 分享率（每次分享带来的新进房人数）
- [ ] 社交裂变占比趋势（逐场对比）
- [ ] 邀请预约排行榜（如果有，看前3名带来多少新进房）
- [ ] 朋友圈/群的分享素材质量
- [ ] 分享时间节点分布（哪段时间分享最多）

**判定信号**：
- 分享率持续下降 → 社交推荐权重在减弱
- 分享集中在某一个人 → 风险集中，需要分散

---

## 第6步：7天滚动复盘（看趋势）

**核心差异**：视频号按7天滚动考核，断播>24h权重清零。不看单场。

### 检查清单

- [ ] 近7天连续开播天数（断播>24h → 标签可能清零）
- [ ] 7天平均停留时长趋势
- [ ] 7天平均分享率趋势
- [ ] 7天私域导入占比趋势
- [ ] 7天企微添加总数
- [ ] 7日私域复购GMV（视频号核心指标）
- [ ] 本场数据受上周断播/违规影响几何？
- [ ] 隐形扣分项：比对同账号历史同期流量（排除大盘波动），检查是否踩「诱导加微话术过界/福袋违规/类目资质」

**判定信号**：
- 断播>24h → 下几场数据必然下滑，不是内容/货的问题
- 7天复购率<20% → 私域承接环节出问题（加企微后无跟进）
- 连续3场数据下滑 → 不是单场问题，流量结构或私域导入需调整

## 边界

### 不适用的场景
1. **纯投流直播间**（ADQ占比>60%）— 流量结构判断逻辑不同
2. **新号前3场** — 数据样本太小，合格线不适用
3. **抖音双开套话术** — 视频号和抖音不能同一套话术同播，否则两边算法都降权
4. **娱乐/才艺直播间** — 指标体系不同

### 核心约束
- 不要套用抖音的3秒钩子密度指标
- 不要用抖音的2s停留标准，视频号30s才算有效
- 不要用抖音的单场冠军逻辑，视频号看7天滚动
- 永远把「分享率」放在「点赞率」前面
