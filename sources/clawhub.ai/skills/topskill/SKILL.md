# 國際政治評論員

政治評論員技能。協助用戶收集熱門政治新聞、分析評論、生成多格式內容。

**觸發本技能時，將會進行外部網路連線以搜尋公開政治新聞，並可能儲存你的議題偏好。**

---

## ⚠️ 重要揭露與使用者同意

### 1. 外部連線與資料揭露

執行本技能時，會透過網路搜尋工具查詢當日熱門政治新聞。過程中：

- 搜尋引擎與新聞網站可能記錄你的 IP、搜尋關鍵字、查詢時間。
- 你選擇的議題標籤、關鍵字與新聞偏好可能形成可推論政治傾向的輪廓。

若你不希望進行外部搜尋，可以改為手動貼上新聞連結，要求 AI 直接針對該連結內容分析，而不啟用主動新聞收集。

### 2. 偏好儲存與追蹤

- 預設情況下，本技能**不會儲存**你的政治興趣或偏好。
- 只有在用戶明確同意後，才會將偏好寫入 `memory/political-preferences.json`。
- 追蹤功能（每日/每週自動推送）預設關閉，需用戶主動開啟。
- 用戶可隨時查看、清除已儲存的偏好或關閉追蹤。

---

## 觸發條件

**只會在以下明確指令下觸發，避免在日常閒聊中誤啟動：**

- 「啟動政治評論員」
- 「幫我寫政治評論」
- 「政治評論員技能」
- 「開始政治新聞分析工作流」

（單純提到「政治新聞」、「政治分析」、「時事」等主題詞，**不會**自動觸發本技能。）

## 工作流程

```
[階段一：新聞收集] → [階段二：興趣選擇] → [階段三：深度分析] → [階段四：評論輸出]
```

---

## 階段一：新聞收集

### Step 1：抓取熱門政治新聞

使用網路搜尋工具查詢當日熱門政治新聞。

**搜尋前提示：**
> 我將為你搜尋公開政治新聞。搜尋過程會連線到外部搜尋引擎與新聞網站，對方可能記錄你的 IP 與查詢關鍵字。是否繼續？（yes/no）

新聞來源優先順序：

| 地區 | 來源 |
|------|------|
| 台灣 | 中央社、聯合報、自由時報、ETtoday、三立新聞 |
| 中國 | 新華社、人民網、鳳凰網、騰訊新聞 |
| 國際 | BBC、CNN、Reuters、AP、Al Jazeera |

搜尋策略：
- 主動搜尋：「今日政治新聞」、「本週熱門時事」
- 依序每個來源查 2-3 條頭條

### Step 2：生成新聞列表

將收集的新聞整理為以下格式：

```
📰 今日政治新聞列表

1. [標題]
   📍 來源：xxx | 🏷️ 標籤：#兩岸 #選舉
   📝 摘要：xxx
   🔥 熱度：★★★★☆

2. [標題]
   ...
```

標籤分類：
- #兩岸 #台灣政治 #中國政治 #美國外交 #國際局勢
- #選舉 #公投 #示威遊行 #政策改革
- #經濟政策 #軍事 #外交 #社會運動

---

## 階段二：興趣選擇

### Step 3：詢問用戶興趣

顯示新聞列表後，詢問：

```
🎯 請選擇您感興趣的新聞：

• 輸入編號：1, 3, 5（多選用逗號分隔）
• 輸入標籤：#兩岸 #外交
• 輸入關鍵字：「習近平」、「大選」
• 輸入：all（全部評論）
• 輸入：random（隨機推薦）
```

### Step 4：記錄偏好（需明確同意）

在儲存任何偏好之前，必須先詢問：

```
💾 是否要將你感興趣的議題存入 memory/political-preferences.json，
   方便未來推薦相關新聞？

   • yes — 儲存偏好
   • no — 不儲存，本次使用後立即清除
   • 只記住本次 — 本次對話有效，不長期儲存
```

**儲存規則：**
- 未獲同意，禁止寫入任何檔案。
- 儲存內容僅限用戶本次選擇的編號、標籤、關鍵字，不包含評論內容或個人身份資訊。

---

## 階段三：深度分析

### Step 5：分析選定新聞

針對每則用戶選擇的新聞，執行以下分析框架：

#### 5a. 事件背景
- 發生經過簡述
- 關鍵人物/機構介紹
- 歷史脈絡與先例

#### 5b. 多角度觀點
- 官方立場：涉事方官方聲明
- 反對/批評聲音：異見來源
- 國際反應：外國政府/媒體態度
- 專家解讀：學者分析

#### 5c. 利益分析
- 誰受益？
- 誰受損？
- 幕後勢力評估

#### 5d. 趨勢預測
- 短期（1-7天）：可能進展
- 中期（1-3月）：政治影響
- 長期（1年+）：歷史意義

---

## 階段四：評論輸出

### Step 6：選擇輸出格式

詢問用戶希望的格式：

```
📝 請選擇輸出格式：

1. 📄 完整評論文章（1500-3000字）
2. 🎙️ 口播稿（適合錄製影片/播客）
3. 📱 社群短評（280字內，適合Twitter/X）
4. 📊 分析圖卡（視覺化要點）
5. 📧 時事通訊（Newsletter格式）
```

### Step 7：選擇評論風格

```
✍️ 請選擇評論風格：

A. ⚖️ 中立客觀型 — 陳述事實，呈現多方觀點
B. 🔍 批判分析型 — 帶有批判視角的深度分析
C. 😂 諷刺幽默型 — 以幽默諷刺方式評論
D. 📚 深度學術型 — 學術化、引用理論框架
```

### Step 8：生成內容

使用對應模板生成評論內容：

- 完整文章 → `references/templates/article-template.md`
- 口播稿 → `references/templates/script-template.md`
- 社群短評 → `references/templates/social-template.md`

## 進階功能

### 追蹤功能（預設關閉，需主動開啟）

用戶可以將感興趣的議題加入追蹤清單：

- 設定關鍵字提醒
- 每日/每週推送相關新聞摘要
- 重要進展主動通知

**開啟前提示：**
> 開啟追蹤功能後，我會定期使用你儲存的偏好自動搜尋新聞。這會產生持續的外部網路連線，並可能強化你的政治興趣輪廓。是否開啟？（yes/no）

### 知識庫

- 建立政治人物檔案（立場、政策、家族背景）
- 建立機構檔案（政黨、政府部門、利益團體）
- 建立議題時間線

### 匯出功能

- 匯出為 Markdown / HTML
- 複製為純文字
- 生成音頻腳本（用於 TTS）

---

## 使用者控制指令

用戶可隨時使用以下指令管理自己的資料：

| 指令 | 功能 |
|------|------|
| `查看我的政治偏好` | 顯示目前儲存的所有偏好 |
| `清除我的政治偏好` | 刪除 `memory/political-preferences.json` |
| `關閉追蹤功能` | 停止每日/每週自動推送 |
| `只分析連結內容` | 不啟用外部新聞搜尋，僅分析用戶貼上的網址 |

## 資源檔案

- `references/news-sources.md` — 新聞來源完整列表
- `references/analysis-framework.md` — 深度分析框架詳細說明
- `references/templates/article-template.md` — 長文模板
- `references/templates/social-template.md` — 社群貼文模板
- `references/templates/script-template.md` — 口播稿模板
- `scripts/fetch-news.py` — 新聞抓取腳本（可選用，執行前需徵得用戶同意）

## 使用範例

觸發語句：
- 「啟動政治評論員」
- 「幫我寫政治評論」
- 「政治評論員技能，分析這則新聞：[連結]」

對話流程：
1. AI 顯示外部連線與偏好儲存揭露
2. AI 展示今日新聞列表
3. 用戶選擇感興趣的新聞

5. AI 進行深度分析
6. AI 生成評論內容
7. 用戶可修改風格/格式後重新生成
