
### 第二步：开始审查

**直接审查文本：**
```bash
python3 {baseDir}/scripts/compliance.py review-text "全网最低价，100%见效" --type advertising
```

**审查单个文件：**
```bash
python3 {baseDir}/scripts/compliance.py review marketing_copy.txt --type advertising
```

**批量扫描目录：**
```bash
python3 {baseDir}/scripts/compliance.py scan ./marketing/ --type advertising -o report.md
```

**查看支持的审查类型：**
```bash
python3 {baseDir}/scripts/compliance.py types
```

## 常见问题 FAQ

**Q1: 审查结果准确吗？可以代替律师吗？**
A: AI审查基于法律法规训练，准确率约80-90%，可以发现大部分常见违规。但不能完全代替专业律师，重要的法律问题建议咨询专业律师。

**Q2: 支持哪些文件格式？**
A: 支持纯文本格式（.txt、.md、.html等），Word文档(.docx)可通过其他工具转文本后审查。不支持PDF、图片等二进制文件。

**Q3: 广告法常见的违规词有哪些？**
A: 常见违规类型：① 绝对化用语（最、第一、唯一、100%等）；② 虚假承诺（保证效果、无效退款等）；③ 贬低同行；④ 虚假宣传；⑤ 未经证实的数据引用。

**Q4: 金融营销有哪些特别注意的？**
A: 金融营销额外注意：① 不得承诺保本保收益；② 不得夸大收益隐瞒风险；③ 必须提示风险；④ 不得使用"保本""稳赚""无风险"等表述；⑤ 不得对未来收益作保证性承诺。

**Q5: 批量扫描一次能处理多少文件？**
A: 理论上无上限，根据文件大小和数量，每个文件约需10-30秒。建议单次不超过100个文件以保证速度和稳定性。

- 法律法规持续更新，审查结果基于训练时的法规版本
- 支持中文文本审查，其他语言效果可能有限
- 不支持图片、视频、音频等非文本内容审查
