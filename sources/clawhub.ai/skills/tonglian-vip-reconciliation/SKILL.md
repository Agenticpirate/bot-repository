# 通联 VIP 对账单配置

## 触发条件
当有新增门店/终端需要配置对账单时（用户说「配置对账单」「X项目对账单」「VIP配置」「对账单配置」等）。

---

## 第一步：收集信息

用户提供以下数据（或从门店清单/账号清单提取）：

| 字段 | 说明 |
|:----|:-----|
| 收钱吧商户号 | 如 1680009161673 |
| 收钱吧商户名称 | 如 武汉市武昌区华苑茗聚茶业经营部 |
| 收钱吧门店号 | 如 1580000011470007 |
| 通联商户号 | 通联侧的商户号（注意和收钱吧商户号区分） |
| 通联小票终端号 | **只填新增的终端**，一个终端一行 |
| 门店名称 | 标准门店名称 |

---

## 第二步：制作 Excel

### 固定模板（6列，永远不要改）

| 列 | 字段 | 示例 |
|:---|:-----|:-----|
| A | 收钱吧商户号 | 1680006527796 |
| B | 收钱吧商户名称 | 武夷山岩谷正岩茶业有限公司 |
| C | 收钱吧门店号 | 1580000009654110 |
| D | 通联商户号 | 37807636 |
| E | 通联小票终端号 | 13986896（只填新增的终端） |
| F | 门店名称 | 武夷山儒士馆 |

### 操作规范
- **一个终端一行**，之前配过的终端不要重复加
- **永远不要改模板的列和样式**
- 列顺序、列名、数量固定不变
- 纯数字字段（商户号、门店号、终端号等）必须设为文本格式（`number_format='@'`）
- 表头加粗、背景色、边框需保持一致

### 表头样式要求
- 第1行：表头，字段名加粗
- 建议使用浅黄色背景填充表头
- 所有列添加边框

---

## 第三步：命名文件

- 文件名格式：`VIP-{任务名称}-MMDD`
- **纯英文**，不要中文
- 任务名称用项目标识，如 `HXY_XM`、`Dyson`、`Prada`、`BROMPTON` 等
- 示例：`VIP-HXY_XM-0702.xlsx`

---

## 第四步：交付给康文博

1. 先用 **message 工具** 发文件给用户确认（带上 filePath 参数直接作为附件发送）
2. 确认无误后：
   - 通过 message 工具将文件发给 **康文博**
   - 在飞书给康文博建一个任务，附上该文件，**截止时间设为当天**

### 给康文博的文字说明示例
```
Hi 文博，麻烦帮忙配置以下门店的VIP对账单，截止今天，谢谢~
```

---

## 常见错误 ⚠️

### 通联商户号 vs 收钱吧商户号 区分
不要混淆这两个号：

| 类型 | 特征 | 示例 |
|:----|:----|:-----|
| **收钱吧商户号** | 16开头纯数字 | 1680006527796 |
| **通联商户号** | 数字+字母组合 | 6605210539967TB |

## 相关联系人

| 人 | 角色 |
|:---|:----|
| 康文博 | 收钱吧内部对账单配置负责人 |
| Rebecca | 收钱吧大客户经理（对接客户需求） |

## 重要规则
1. 文件通过 message 工具直接发送（filePath 参数），不只在云盘上传
2. 纯数字标识字段（商户号、门店号、终端号等）Excel 写入时设文本格式
3. 一个终端一行，已配过的终端不要重复加
4. 列顺序和样式永远不变
5. 交付给康文博后务必建飞书任务并附上文件，截止当天
