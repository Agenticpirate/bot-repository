# Skill 课程课后巩固与作业生成

为"Agent Skill 运作原理与整体机制"课程生成成套课后材料：巩固讲解、分层练习作业、参考答案。产出物始终为**两个 Markdown 文件**（题目、答案分开）。

## 前置条件

- 明确本次课程范围（默认覆盖：触发机制、SKILL.md 结构、渐进式披露、两级存储、安全审计）
- 若用户指定了其他课时内容，以用户指定的知识点为准，并从 `references/skill-knowledge.md` 中裁剪对应条目

## 工作流程

1. **生成巩固讲解**：从 `references/skill-knowledge.md` 选取本课知识点，按"核心链路 → 结构解剖 → 存储与生命周期"的顺序组织；讲解中可配合 2-3 张结构图（触发流程、SKILL.md 解剖、两级存储对比）
2. **设计练习作业**：按 `references/homework-design.md` 的四层题型（概念题 / 找茬题 / 动手题 / 思考题）出题，标注必做与选做
3. **撰写参考答案**：概念题答到机制本质，找茬题给全量问题清单与评分采分点，动手题给出完整可运行的参考实现（SKILL.md 全文 + 配套脚本）
4. **写入两个文件**：`<主题>课后作业-题目.md` 与 `<主题>课后作业-参考答案.md`，保存到当前工作区；答案文件末尾附"延伸拓展"选读章节（2-5 个进阶专题）
5. **提交前自检**：
   - 题目文件不含任何答案线索（找茬题的提示方向可保留，用户要求提高难度时删除）
   - 动手题的参考 SKILL.md 必须符合自己教的标准：description 写清触发时机、keywords 含中文别名与口语表达、职责边界单一
   - 答案中的代码必须语法完整、可直接运行

## 写作规范

- 语气：面向学生的课堂语气，简洁直接，不堆砌客套话
- 每个概念配一句"一句话总结"或自检标准，便于考前速记
- 评分标准显式写出（几分、采分点是什么），便于其他老师复用
- 延伸专题只写给学有余力的学生，标注"选读"
