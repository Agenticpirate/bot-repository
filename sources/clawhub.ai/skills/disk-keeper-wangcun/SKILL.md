# 净盘师 DiskSage · 智能净盘师

> 专治 C 盘爆满、磁盘空间不足、系统盘变红。不是又一个 rm -rf 脚本——它先体检、再分级、最后才清理，每一步可追溯、可回看、极低误删。免费版全功能、零上传、账实相符，名副其实。

## 它解决什么痛点
- **C 盘红了不知道删啥**：`doctor` 一键体检，告诉你空间卡在哪、回收站里到底躺着多少真实占用。
- **"清理软件"反而越清越乱**：很多工具整箱清空回收站、误删工程文件。净盘师用**正向白名单**——只动明确可重建的缓存/Temp，其余一律不碰。
- **"释放 10G"是假的**：回收站 $I 是"收据"不是"数据"，幽灵条目声明几十 G 实占 0。净盘师以 df 实测为准，声称释放 vs 实测释放强制对账。
- **清完没记录、出问题查不清**：内植三基因——反省（动手前查血泪史）、进化（偏差自动落教训）、超越（每轮比上次好在哪，且在实践中持续自我迭代）。

## 安全边界（铁律）
1. **正向白名单**：只动系统 Temp / 浏览器缓存 / 包管理缓存 / IM·工具纯缓存子目录（cache/temp/gpucache…），其余一律不碰。
2. **R3 绝对禁区**：系统区（Windows/Program Files/ProgramData）、用户个人资料（Desktop/Documents/Downloads/Pictures/Videos/Music/.workbuddy）、AppData\Roaming 整体——永不进入清理清单。
3. **dry-run 默认**：`clean` 不加 `--yes` 只列清单不删；删除前每个目标二次校验 R3，命中即拦截。
4. **不删联接/符号链接**：避免误伤迁移目录（如剪映迁到别的盘）。
5. **账实对账**：每个动作「声称释放 vs df 实测」强制核对，不符自动记偏差进教训库。
6. **回收站净化**：删除后自动提示回收站精确净化，避免"删了但空间没涨"。
7. **零上传红线**：纯本地运行，**不读取、不上传任何用户隐私文件**，所有扫描与删除均在本地完成；这也是净盘师与 CCleaner（2017 供应链事件后信任受损）最根本的区别。

## 使用示例
```bash
# 先体检，看空间卡在哪
python scripts/disk_butler.py doctor

# 看清理计划（不删）
python scripts/disk_butler.py plan

# 确认无误，执行安全清理
python scripts/disk_butler.py clean --yes

# 回收站里躺着很多"幽灵收据"导致账面虚高，清账
python scripts/disk_butler.py recycle --ghost --yes

# 找出占空间的大目录（只读，供人工裁决）
python scripts/disk_butler.py big --min-gb 5

# 让管家自我迭代：分析运行指纹，演进规则库（三基因·超越）
python scripts/disk_butler.py evolve

# 生成省心报告 + 可分享文案（发给朋友/朋友圈）
python scripts/disk_butler.py report
```

## 自我迭代能力（三基因在实践中的硬落地）

净盘师不是"交付即终点"的脚本，而是**越用越懂你机器的活系统**：
- **反省**：每次运行先读 `lessons.md` 血泪史正本，动手前规避已知坑。
- **进化**：账实不符、误判、新坑自动落教训进正本；`learn` 命令支持人工沉淀经验。
- **超越（实践中自我迭代）**：`evolve` 命令读取 `history.jsonl` + `clean_manifest.jsonl` 的运行指纹（释放量、账实相符度趋势、最常清理类型、拦截次数），自动判定规则库是否需要调优，并推进 `RULES_VERSION` 规则版本号。省心版 PRO 用户还会收到**云端规则库演进推送**——把成千上万机器的踩坑经验汇成持续进化的专家判断，这是脚本类工具永远抄不走的护城河。
