# Write Plan

## Description
Turns a spec, issue, or requirements doc into a detailed multi-phase implementation plan using tracer-bullet vertical slices.

## Workflow
1. **Phase 1** — Foundation & Core Data Model
2. **Phase 2** — Business Logic Implementation
3. **Phase 3** — API / Interface Layer
4. **Phase 4** — Testing & Edge Cases
5. **Phase 5** — Documentation & Deployment

## Verification
Each phase must have: acceptance criteria, dependencies mapped, risk assessment.
