# Daily Guide — 今日宜出门

结合黄历（农历宜忌）+ 天气 + 用户个人命理（生肖/八字），回答"今天是否适合出门/做什么"。

## 触发场景

用户问类似：
- "今天宜出门吗" / "今天适合出门吗" / "今天适合出去玩吗"
- "今天适合出门买东西吗" / "今天适合做什么"
- "今日黄历" / "今日宜忌" / "今天运气怎么样"
- "今天出门要注意什么"

## 使用方法

在 skill 目录下执行（assets 内已装好依赖）：

```bash
cd <skill目录>/assets
npm install   # 首次需安装依赖（lunar-javascript）
node init-bazi.js   # 首次使用：引导式输入出生信息，生成个人档案
node daily-guide.js [YYYY-MM-DD] [--matter=修手机]
```

- 不带日期 = 今天
- `--matter=事项` = 指定事项（自动分类：大事/必要事务/安装类/日常消费，影响裁决）
- 带 `--json` = 输出结构化 JSON（脚本内部逻辑用）
- 默认输出人类可读的完整报告

## 个性化配置（重要）

**首次使用必须先运行 `node init-bazi.js`**，输入公历出生日期、时间、城市，自动生成 `bazi.json`。之后系统会：
- 用你的生肖判断「本命冲日」（当日冲煞与你的生肖相冲时重点提醒）
- 支持两种流派：北京时间派（默认）/ 真太阳时派（自动经度校正）
- 命令行快速配置：`node init-bazi.js --date=YYYY-MM-DD --time=HH:MM --city=城市名`

**未配置时**：以中性默认值运行（不针对任何真实用户），输出会提示引导。
个人档案仅存本地 `bazi.json`，不上传。

## 数据源与可信度

| 数据 | 来源 | 角色 |
|------|------|------|
| 农历/干支/宜忌/吉凶 | lunar-javascript（离线算法，6tail 开源库） | **主源**，定底本 |
| 宜忌交叉校验 | 天气网万年历（staticwnl.tianqistatic.com 数据） | **交叉校验源** |
| 天气 | wttr.in | 天气改判 |

**重要——可信度规则**：
1. **农历/干支/冲煞/生肖**：精确天文算法，两源一致，可信度高，可直接输出
2. **宜忌列表**：不同流派（协纪辨方书系 vs 民间通书系）结果**可能相反**。脚本会自动检测分歧并标注 ⚠️
   - 两源一致 → 直接给结论
   - 分歧 → 必须如实展示两边，不能只报一边
3. **个人化**：根据用户 `bazi.json` 中的生肖判断本命冲日，当日冲煞与用户生肖相冲 → 黄历结论降级为"谨慎"

## 输出结构

1. 📅 日期 + 农历 + 生肖
2. 📋 黄历（主源）：宜/忌/吉神/凶煞/冲煞/彭祖百忌/建除十二神
3. 🔄 交叉校验：天气网结果 + 分歧标注（无冲突则 ✅）
4. 🌤️ 天气：温度/体感/降水/风/紫外线（城市由 `DAILY_GUIDE_CITY` 配置，默认按 IP 定位）
5. 🧭 出门建议：
   - 本命冲日提醒（根据用户档案生肖判断）
   - 天气恶劣降级（高温/暴雨/大风 → 宜改谨慎）
   - 工作日（通勤视角）/ 周末（出游视角）区分

## 裁决逻辑

```
用户提问（含事项，如"修手机"）
  ↓ 分类事务
  ├─ 大事（嫁娶/签约/动土/搬家/换手机/大家电…）→ 黄历权重高，分歧时谨慎
  ├─ 必要事务（修手机/看病/缴费/买菜…）→ 实用性优先，黄历降权，天气不否决，选吉时
  ├─ 安装类（燃气灶/油烟机/装修…）→ 看「宜作灶/修造」吉日，值神吉为佳
  ├─ 日常消费（裤子/日用品/小家电…）→ 避开忌交易/冲鼠即可，不用挑吉日
  └─ 日常/休闲 → 黄历+天气正常判定
  ↓
黄历基调（主源宜/忌出行）
  + 交叉源校验（分歧→标注）
  + 本命冲煞（冲鼠→降级 caution）
  + 天气（恶劣→good 降 caution；必要事务除外）
  + 时辰择吉（必要事务/日常推荐宜出行时段）
  = verdict: good ✅ / caution ⚠️ / bad ❌
```

- 黄历宜出行 + 天气好 → ✅ 适合出门
- 黄历宜出行 + 天气恶劣 → ⚠️ 谨慎出行
- 黄历忌出行 + 天气好 → ⚠️ 可短时外出，不宜远行
- 黄历忌出行 + 天气恶劣 → ❌ 不宜出门
- 本命冲日 → 任何情况下都提示谨慎
- **必要事务**（修手机/看病/缴费等）→ 实用性优先：黄历降权、天气提醒但不否决，给出宜出行时辰窗口
- **日常消费**（裤子/日用品）→ 只避开「忌交易/冲鼠」，不用挑吉日
- **安装类**（燃气灶/油烟机）→ 看「宜作灶」日安装（下单日随便，安装日讲究）

## 注意

- 输出是"参考建议"不是"断言"。黄历是传统文化，不同流派结论可能冲突，如实呈现冲突本身也是价值
- 用户八字档案在 `memory/bazi.md`（本地，不出本机）
- 天气接口偶尔失败时，脚本自动降级（只有黄历部分），不影响使用
