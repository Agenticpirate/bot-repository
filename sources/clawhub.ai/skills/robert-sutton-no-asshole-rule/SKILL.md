# 罗伯特·萨顿（Robert I. Sutton）· 混蛋法则与浑人应对

## 何时使用
识别、量化与应对职场中"浑人（asshole）"行为；决定是否为"天才浑人"妥协；建立低确认偏误的组织文明规则。

## 核心定义
> **浑人**：让目标（target）感到**被压迫、羞辱、贬低、轻视**的人；尤其是**针对权力较小者**。
（Sutton, *The No Asshole Rule*, 2007）

两条测试同时成立才算：
1. **持续性**——受害者在较长时间内反复感到被贬低/羞辱；
2. **权力差**——行为主要指向权力较小的一方（下属、新人、外包）。

## 代价清单（为何不能忍）
- 人才流失、招聘与培训成本上升
- 绩效、创造力、协作质量下降（"浑人税"）
- 客户流失、法律与合规成本、雇主品牌受损
- 团队信心与心理安全崩塌（"一滴毒药污染一桶水"）
- 为"天才浑人"辩护的隐性代价 > 其产出

## 识别"浑人行为"的信号
人身攻击 · 侵犯人格/隐私 · 贬低式挖苦 · 羞辱式玩笑 · 威胁恐吓 · 甩锅推责 · 冷处理/排挤（silent treatment）· 走后门使绊子。

## 应对工具箱（The Asshole Survival Guide, 2017）
| 策略 | 做法 |
|------|------|
| 目的重构 | 把遭遇当作"研究样本"，降低情绪卷入 |
| 物理/心理疏离 | 减少接触、降低暴露时长 |
| 内心超脱 | 不把对方的评价内化为自我价值 |
| 向上管理 | 用数据与影响面说服决策者 |
| 建立同盟 | 找见证者与支持者，避免孤立 |
| 记录证据 | 时间线、邮件、证人，为正式申诉做准备 |
| 公开算账 | 在安全渠道"把账算清" |
| 自省 | 检查自己是否也在变浑（权力会腐蚀） |
| 离开 | 当系统性纵容时，退出是理性选择 |

## 组织层建议
- 招聘筛掉行为红旗（而非只看业绩）
- 领导以身作则；把"文明"纳入考核
- 建立可用的举报与调查机制，保护举报者
- 对屡犯者降级/清退，不因"能力强"豁免

## 边界
不替代法律途径（涉及歧视/骚扰时走合规与法律）；不贴"人格标签"，只描述**可观察行为**。

## Sources
