# 晨钟

> **晨钟暮鼓，朝省夕惕。**
> 古人以晨钟唤醒一日之始，以暮鼓警醒一日之终。
> 晨钟是你的AI个人晨间简报——不用你来问，它在每天清晨把今天最重要的事摆在你面前。

---

## 〇、什么是晨钟

### 核心观念

晨钟不是"你问它答"的工具，而是一个**持续了解你 → 每天早上主动提醒你**的系统。

它不做三件事：
- ❌ 不是新闻摘要（不做通用资讯聚合）
- ❌ 不是任务管理器（你不需要专门在它里面录入任务）
- ❌ 不是复盘工具（复盘部分由你的灵感回顾系统完成）

它只做一件事：
- ✅ **在你每天已有的数据上，挑出今天最该提醒你的事情，主动推给你**

### 设计哲学

```
你的日常交互（语音日记/对话/笔记）
        ↓ 每次交互后自动
晨钟提取"当前关注点" → 存入简报数据池
        ↓ 每天早上定时
晨钟读取数据池 → 生成简报 → 推送到你面前
        ↓ 你反馈后
调整优先级和内容 → 越用越准
```

**关键原则：晨钟是提议者，你是决策者。** 它只负责找出"可能值得提醒"的内容，是否真的重要由你判断。

## 一、快速开始

### 安装

将晨钟skill文件夹放入你的WorkBuddy技能目录：
- 用户级：`~/.workbuddy/skills/晨钟/`
- 项目级：`{workspace}/.workbuddy/skills/晨钟/`

### 首次配置

安装完成后，你需要完成以下初始化配置。建议先通读本文档，再逐项填写。

#### 步骤 1：设置简报接收时间和方式

你需要在自动化系统中创建一个cron任务，让晨钟每天定时执行。推荐设置：

```bash
# 每天早上10:00发送简报（你可以自定义时间）
# 在你的自动化工具中设置：
schedule: "0 10 * * *"
```

#### 步骤 2：配置你的提醒事项

晨钟需要知道"你希望被提醒什么"。首次使用前，请填写你的提醒事项配置表：

**配置项：`habits`（习惯提醒）**

你需要列出每天希望被提醒的日常习惯。可参照以下格式配置：

```json
{
  "habits": [
    {
      "id": "habit_1",
      "title": "描述你的习惯",
      "description": "为什么这个习惯重要",
      "frequency": "daily",
      "enabled": true
    }
  ]
}
```

**配置项：`projects`（项目提醒）**

你需要列出当前正在推进的项目，每个项目包含截止日期和状态：

```json
{
  "projects": [
    {
      "id": "project_1",
      "title": "项目名称",
      "deadline": "YYYY-MM-DD",
      "status": "pending | in_progress",
      "notes": "当前阶段描述"
    }
  ]
}
```

**配置项：`data_sources`（数据源）**

晨钟需要知道从哪里读取你的数据。配置路径指向你的本地文件：

```json
{
  "data_sources": {
    "daily_log": "path/to/your/daily/logs/",
    "session_log": "path/to/your/session/logs/",
    "idea_system": "path/to/your/idea/index.md",
    "journal_index": "path/to/your/journal/index.md",
    "project_memory": "path/to/your/project/memory.md"
  }
}
```

> 建议：首次配置后先手动触发一次晨钟，验证简报内容是否合理，再开启定时。

#### 步骤 3：数据源说明

晨钟不要求特定的文件格式，但它期望从以下类型的数据中提取信息：

| 数据源类型 | 作用 | 示例 |
|-----------|------|------|
| **语音/文字日记** | 了解你每天在想什么、在焦虑什么、计划做什么 | 播客日记、语音转录、自由书写 |
| **灵感/想法记录** | 追踪你曾经记下的想法和待办状态 | 灵感索引、待办清单 |
| **工作日志** | 了解你昨天做了什么事 | 每日工作记录、会话日志 |
| **项目备忘录** | 了解你正在推进的项目和截止日期 | 项目排期、里程碑文件 |

## 二、核心工作流

### 整体流程

```
┌─────────────────────────────────────┐
│          数据收集层（持续运行）         │
│  ┌─────────┐  ┌─────────┐  ┌──────┐ │
│  │语音日记  │  │工作会话  │  │灵感  │ │
│  └────┬────┘  └────┬────┘  └──┬───┘ │
│       │            │          │     │
│       ▼            ▼          ▼     │
│  ┌──────────────────────────────┐   │
│  │       简报数据池              │   │
│  │  （关注点/待办/提醒候选）     │   │
│  └──────────────┬───────────────┘   │
├─────────────────┼───────────────────┤
│                 │                   │
│        每天早上定时触发              │
│                 ▼                   │
│  ┌──────────────────────────────┐   │
│  │       简报生成层              │   │
│  │  ① 读取数据池                │   │
│  │  ② 筛选今天最该提醒的内容      │   │
│  │  ③ 生成三部分简报             │   │
│  │  ④ 推送到你面前              │   │
│  └──────────────┬───────────────┘   │
├─────────────────┼───────────────────┤
│                 │                   │
│         你看到简报后                │
│                 ▼                   │
│  ┌──────────────────────────────┐   │
│  │       反馈层                  │   │
│  │  你告诉晨钟有用/没用/缺什么    │   │
│  │  → 晨钟调整后续内容           │   │
│  └──────────────────────────────┘   │
└─────────────────────────────────────┘
```

### 第一层：数据收集

晨钟不在生成简报时才工作，它在**你每一次交互后**都在工作。

**触发时机：**
- 你录完一篇语音/文字日记 → 晨钟自动提取关键信息
- 你和AI助手完成一次有价值的对话 → 晨钟记录你当前关注的方向
- 你更新了灵感/想法记录 → 晨钟同步更新

**提取的内容：**
- 你当前最在意的事情
- 你说了要推进但还没推进的事
- 你重复提到的话题（说明重要度在上升）
- 被你搁置了一段时间的事

> **这些提取是自动完成的，不需要你额外操作。** 你只需要保持你的日常记录习惯。

### 第二层：简报生成

每天早上定时触发，晨钟执行以下步骤：

```
步骤 1：读取配置
        获取你的提醒事项列表、项目列表、数据源路径

步骤 2：读取数据源
        扫描你配置的数据源文件，提取：
        - 最近的语音/文字日记内容
        - 当前未推进的灵感/想法
        - 昨天的日志摘要
        - 项目状态和截止日期

步骤 3：筛选提醒候选
        从多个数据源中，筛选出今天最该提醒的内容：
        - 习惯提醒（每天固定）
        - 项目提醒（按截止日紧迫度排序）
        - 待办提醒（按搁置天数排序）
        - 关注点提醒（从最近日记中提取）

步骤 4：生成简报
        按标准格式输出三部分简报

步骤 5：记录调用来源
        列出本次简报读取了哪些文件，保持透明可追溯
```

### 第三层：反馈优化

晨钟越用越准，关键在反馈。

**你可以反馈的内容：**

| 你说了 | 晨钟怎么反应 |
|-------|------------|
| "这条提醒没用/不需要" | 降低这条的优先级，后续减少出现 |
| "这个提醒很对" | 提高这条的优先级，后续优先展示 |
| "还缺了XXX" | 新增提醒事项，纳入后续简报 |
| "简报太长了" | 减少提醒数量 |
| "简报太短了" | 增加提醒内容深度 |
| "这个项目的状态变了" | 更新项目状态 |

> **核心原则：晨钟不做任何未经你确认的调整。** 它只会提议，你来决策。

## 三、简报输出格式

### 标准模板

```
━━ 晨钟 · YYYY年MM月DD日（周X）━━━━

📋 今日提醒
• [习惯] 提醒事项 1
• [习惯] 提醒事项 2
• [项目] 项目名 — 距截止日还有 X 天
• [待办] 被提醒事项（已搁置 X 天）

📂 今日调用
• 数据源A：path/to/file
• 数据源B：path/to/file
• 数据源C：path/to/file

💡 建议
• 关于项目推进的具体建议
• 关于习惯坚持的具体建议
• 发散性提醒（AI基于近期数据关联出的新方向）

━━━━━━━━━━━━━━━━━━━━
🔄 反馈：你可以告诉我哪些提醒有用、哪些不需要
```

### 三部分说明

#### 第一部分：日报（📋 今日提醒）

事实性提醒，不掺杂AI判断。包括：
- **习惯提醒**：你配置的每天固定习惯（如录日记、学习等）
- **项目提醒**：正在推进的项目及其截止日倒计时
- **待办提醒**：你记下但一直未推进的事项（按搁置天数排序）

#### 第二部分：调用目录（📂 今日调用）

透明公开数据来源。列出本次简报读取了哪些文件/数据源，你可以据此判断：
- 简报的信息来源是否可靠
- 是否有遗漏的数据源
- 是否需要补充或调整数据路径

#### 第三部分：建议（💡 建议）

晨钟基于已有数据给出的判断和建议，包括：
- 项目推进的具体行动建议
- 如何优化你的日常习惯
- 基于你近期的关注点，发散提醒你可能感兴趣但没想到的方向

> ⚠️ **建议部分是提议，不是指令。** 所有建议都标注"建议"前缀，由你决定是否采纳。

## 六、反馈与优化

### 反馈机制

晨钟的反馈机制很简单。你不需要学习复杂的指令，只需要正常表达：

| 你的表达 | 晨钟的理解 |
|---------|-----------|
| "这个提醒对我没用" | 移除同类提醒 |
| "能不能提醒我XXX" | 新增一条提醒 |
| "这条很对" | 提高同类优先级 |
| "最近XX项目没什么进展" | 确认项目是否需要调整 |
| "简报太唠叨了" | 减少每日提醒数量 |
| "简报可以多说一点" | 增加每日提醒深度 |

### 优化路径

晨钟会在持续使用中优化：

```
第1-3天：默认配置，可能不够准
  ↓
你反馈3-5次后：开始了解你的优先级
  ↓
使用一周：优先级排序明显改善
  ↓
持续使用：越来越贴近你的真实需求
```

> ⚠️ **没有你的反馈，晨钟不会自己优化。** 它依靠你的确认来学习。

## 七、设计原则（供参考）

### 与Google Daily Brief的异同

| 维度 | Google Daily Brief | 晨钟 |
|------|-------------------|------|
| 数据源 | Gmail/Calendar/Gemini聊天 | 用户本地文件（日记/灵感/日志） |
| 授权机制 | 系统级授权（Connected Apps） | 用户手动配置路径 |
| 收集方式 | 后台持续运行 | 每次交互后提取+定时扫描 |
| 输出方式 | Gemini App内 | WorkBuddy/AI助手会话 |
| 反馈方式 | 点赞/踩 | 自然语言反馈 |
| 透明度 | Check source按钮 | 简报中直接列出调用目录 |

### 核心原则

1. **主动非被动**——不来问，到时间自动出现
2. **提醒非分析**——核心是"别忘记"，不是"帮你思考"
3. **提议非决策**——所有建议都提请你确认，不做任何未经你同意的调整
4. **透明可追溯**——每条提醒都标明来源
5. **越用越准**——基于反馈持续优化

## 八、注意事项

### 隐私与安全

- 晨钟只读取你配置路径下的本地文件
- 所有数据停留在你的本地环境，不上传云端
- 你可以在配置中随时增删数据源路径
- 你可以随时关闭晨钟

### 已知限制

- 晨钟的质量取决于数据源的质量——你的日记越详细、灵感记录越完整，晨钟越准
- 首次使用需要1-3天的"校准期"，期间可能需要你多次反馈调整
- 如果长期（超过7天）没有新数据输入，晨钟的简报内容会开始重复

### 常见问题

**Q：晨钟和普通的提醒工具有什么区别？**
A：普通提醒工具需要你手动录入"提醒我下午3点开会"。晨钟不需要你专门录入——它从你每天的自然记录（日记、对话、灵感）中自动提取需要提醒的内容。你只需要保持日常记录习惯。

**Q：我可以用晨钟提醒别人吗？**
A：晨钟设计为个人工具，基于你个人的数据生成简报。如果多人共用，每个人的配置独立。

**Q：晨钟支持多种数据源格式吗？**
A：支持Markdown、JSON、纯文本格式。其他格式需要你提供解析配置。
