# ISO 45001 职业健康安全管理体系策划

## 任务目标

本 Skill 用于指导企业建立、实施、维护和持续改进职业健康安全管理体系（OH&S MS），确保符合 ISO 45001:2018 标准要求，通过体系认证并提升组织职业健康安全绩效。

## 核心能力

- ISO 45001 标准解读与框架设计
- 企业现状评估与风险机遇识别
- 管理体系文件策划（方针、目标、程序、作业指导书）
- 风险管控机制与应急预案建立
- 体系实施培训与认证指导

## ISO 45001 标准框架

ISO 45001 采用 HLS（High Level Structure）与 PDCA 循环相结合的结构：

| 章节 | 名称 | 核心要求 |
|------|------|----------|
| 第4章 | 组织环境 | 确定内外部问题、相关方需求、体系范围 |
| 第5章 | 领导力 | 最高管理者承诺、职业健康安全方针、资源 |
| 第6章 | 策划 | 风险机遇评估、目标与方案策划 |
| 第7章 | 支持 | 资源、能力意识、沟通、文件化信息 |
| 第8章 | 运行 | 策划控制、变更管理、采购、承包商、应急响应 |
| 第9章 | 绩效评价 | 监视测量、合规评价、内部审核、管理评审 |
| 第10章 | 改进 | 不符合与纠正措施、持续改进 |

## 操作步骤

### 一、体系策划启动

1. **确定体系范围**
   - 明确体系覆盖的业务范围（全部或部分）
   - 确定适用的工作场所和活动
   - 识别排除的条款及理由

2. **现状诊断评估**
   - 收集适用的法律法规清单
   - 评估现有OHSAS制度与ISO 45001差距
   - 识别关键风险与合规义务
   - 输出：《差距分析报告》

3. **建立项目组织**
   - 指定最高管理者代表
   - 组建体系推进小组
   - 明确职责与权限

### 二、风险机遇评估

1. **危险源辨识**
   - 物理性危险源（机械、电气、高温、噪声、辐射等）
   - 化学性危险源（有毒物质、粉尘、化学品等）
   - 生物性危险源（细菌、病毒等）
   - 心理社会性危险源（压力、骚扰、暴力等）
   - 组织管理因素（人机工效、工作安排）

2. **风险评估**
   - 采用风险矩阵：风险值 = 可能性 × 严重性
   - 确定可接受风险准则
   - 识别重大风险并制定控制措施

3. **机遇识别**
   - 提升健康安全绩效的机会
   - 改进员工福祉的措施
   - 增强合规能力的机会

### 三、管理体系文件策划

按层级策划文件体系：

#### 第一层：管理手册
- 体系范围与边界
- 方针与目标承诺
- 组织架构与职责
- 过程与相互作用

#### 第二层：程序文件
- 危险源辨识与风险评估程序
- 法律法规与其他要求识别程序
- 合规性评价程序
- 监视测量与绩效评价程序
- 不符合与纠正措施程序
- 内部审核程序
- 管理评审程序

#### 第三层：作业指导书
- 设备操作规程
- 作业安全规程
- 应急处置卡
- 职业健康监护规程

#### 第四层：记录表单
- 危险源清单
- 风险评估表
- 培训记录
- 检查记录
- 不符合项处理记录

### 四、关键过程控制

1. **职业健康安全目标策划**
   - 基于风险评估结果设定目标
   - 目标应SMART：具体、可测量、可达成、相关、有时限
   - 分解至相关部门和层级
   - 制定管理方案明确资源、责任、完成时间

2. **变更管理**
   - 评估新变化带来的风险
   - 变更前评审与批准
   - 变更实施与沟通

3. **应急准备与响应**
   - 识别潜在紧急情况
   - 制定应急预案
   - 定期演练与评审
   - 配置应急资源

4. **采购与承包商管理**
   - 供应商资质审核
   - 承包商入厂安全交底
   - 作业过程监督

### 五、体系运行与检查

1. **日常运行控制**
   - 按程序文件执行各项管理活动
   - 落实作业指导书要求
   - 保持必要的记录

2. **监视与测量**
   - 关键绩效指标（KPI）监测
   - 法定合规性定期评价
   - 设备设施定期检测
   - 员工健康监护

3. **内部审核**
   - 编制年度审核计划
   - 实施过程审核与体系审核
   - 报告发现并跟踪整改

4. **管理评审**
   - 评审体系适宜性、充分性、有效性
   - 评审方针目标达成情况
   - 决策改进方向

### 六、认证准备与持续改进

1. **认证前准备**
   - 完成内部审核与管理评审
   - 消除重大不符合项
   - 准备认证材料

2. **认证审核应对**
   - 配合一阶段审核（文件审查）
   - 配合二阶段审核（现场审核）
   - 关闭审核发现

3. **持续改进**
   - 分析数据与趋势
   - 识别改进机会
   - 实施纠正预防措施
   - 更新管理体系

## 使用示例

### 示例1：新建体系企业
- **场景**:某制造企业首次建立ISO 45001体系，需从零开始
- **输入**:企业基本信息、所属行业、生产工艺、员工规模
- **产出**:完整的体系策划方案、文件清单、实施计划
- **要点**:先完成现状诊断与差距分析，再按PDCA循环逐步推进

### 示例2：已有OHSAS18001企业升级
- **场景**:企业已有OHSAS18001:2007证书，需升级至ISO 45001
- **输入**:现有体系文件清单、证书范围、需关注的新要求
- **产出**:转版策划方案、需修订文件清单、新旧标准差异对照
- **要点**:重点关注第6章风险机遇、第8章运行策划、第10章改进的变更要求

### 示例3：体系认证审核应对
- **场景**:企业即将接受第三方认证审核
- **输入**:审核范围、时间安排、审核员关注重点
- **产出**:审核应对方案、现场准备清单、常见问题预案
- **要点**:确保运行证据充分、记录完整、人员访谈应答一致

## 注意事项

- 体系策划应与组织战略目标相结合，避免形式化
- 风险评估应覆盖所有作业活动和人员，包括承包商
- 文件应保持简洁实用，避免过度复杂
- 领导力承诺是体系有效性的关键
- 持续改进应基于数据分析和实际绩效
