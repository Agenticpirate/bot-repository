## 模块1：BOM完整性检查

### 为什么需要这个模块

视觉检测设备BOM遗漏是常见但代价高昂的错误：
- 漏掉一个相机 → 设备无法检测，产线停线
- 漏掉光源控制器 → 光源无法工作，整台设备报错
- 漏掉伺服驱动器 → 运动系统瘫痪
- 漏掉线缆 → 设备无法组装，交期延误

**一条遗漏可能造成数万到数十万的损失**，这个模块就是要把关BOM的完整性，在采购前发现问题。

### 检查流程

1. **读取BOM文件** — 支持 Excel (.xlsx, .xls)、CSV (.csv)、文本文件
2. **提取物料信息** — 物料名称/描述、物料编码、数量、规格型号
3. **对照标准部件清单检查** — 按9大类逐一检查
4. **输出检查报告** — 按风险等级分类输出

### 检查规则

**致命项（必须全部通过）**：以下任何一项缺失，BOM直接判定为**不通过**：
1. 相机
2. 镜头
3. 光源
4. 光源控制器
5. 工控机/主机
6. 电源
7. 图像采集卡
8. 检测软件

**高风险项（缺失需警告）**：以下缺失需**明确警告**，但不直接判定不通过：
1. 伺服电机/驱动器
2. 运动控制卡
3. 线性模组/导轨
4. 显示器
5. 各类线缆
6. 机架/底座
7. 传感器
8. 视觉库

**中风险项（建议检查）**：以下缺失需**建议检查**：
1. 操作系统
2. 断路器/空开
3. 钣金/外壳
4. 气动元件
5. 脚轮/脚杯

### 特殊场景处理

- **用户只提供了部分BOM**：明确告知只检查了部分内容，提醒用户补充完整BOM再次检查
- **BOM中有"整套"/"系统"类物料**：询问是否包含子BOM，如果有子BOM需要合并检查
- **设备类型不同**：AOI设备必须有相机+镜头+光源；视觉引导机器人可能有相机但没有传统光源；根据设备类型调整检查项
- **用户说"这些不需要"**：记录用户的说法，但仍然在报告中列出，标注"用户确认不需要"

### 注意事项

1. **宁严勿松**：BOM检查宁可误报，不可漏报
2. **关键词模糊匹配**：用户可能写"相机"也可能写"camera"，都要能识别
3. **数量检查**：有些部件数量为0也算缺失
4. **规格确认**：对于关键部件，提醒用户确认规格是否匹配
5. **保存检查记录**：每次检查生成报告文件，便于追溯

## 模块2：BOM版本对比

### 适用场景
- "对比BOM"、"BOM有什么变化"

### 处理流程

**输入**：两个版本的BOM Excel文件（.xlsx）

**处理步骤**：
1. 读取两个BOM文件（通常是"电气BOM"sheet）
2. 以"序号"为主键匹配物料
3. 对比关键字段：品牌、名称、型号、规格、数量、单位
4. 识别变更类型：
   - **新增**：新版本有，旧版本无
   - **删除**：旧版本有，新版本无
   - **变更**：关键字段值发生变化

**输出**：Excel变更说明报告，包含：
- 变更类型（新增/删除/变更）
- 序号、物料小类、名称、品牌
- 变更字段、旧值、新值
- 颜色标记：黄色=变更、绿色=新增、红色=删除

**参考脚本**：`scripts/compare_bom.py`

## 模块3：机电协同表拆分

### 适用场景
- "拆分机械电气"、"分出机械BOM"

### 处理流程

**输入**：机电协同物料清单Excel文件

**处理步骤**：
1. 读取协同表（通常包含机械和电气物料混合）
2. 识别物料分类依据：
   - 按"类别"列：机械件/电气件/标准件/加工件
   - 按"物料小类"：判断属于机械还是电气
   - 按品牌：电气品牌 vs 机械品牌
3. 拆分为两个独立BOM：
   - 机械BOM：钣金件、机加工件、导向件、传动件等
   - 电气BOM：PLC、伺服、传感器、断路器、线缆等

**电气品牌关键词**：
```
施耐德、西门子、汇川、欧姆龙、菲尼克斯、三菱、ABB、
台达、安川、松下、基恩士、SMC、FESTO、实点科技、
REER、伯恩施坦、MOONS、天逸、胜蓝、正泰、德力西
```

**机械品牌关键词**：
```
米思米、怡合达、THK、HIWIN、NSK、SKF
```

**加工件分类**：
- 加工件/"钣金"分类

**输出**：两个独立的Excel文件
- `XXX_机械BOM.xlsx`
- `XXX_电气BOM.xlsx`

## 模块4：供应商BOM合并

### 适用场景
- "合并BOM"、"汇总物料"

### 处理流程

**输入**：多个供应商的BOM Excel文件

**处理步骤**：
1. 逐个读取供应商BOM文件
2. 提取关键字段：品牌、名称、型号、数量、单位
3. 以（品牌+名称+型号）为唯一键合并
4. 相同物料数量累加
5. 可选：匹配单价，计算总价

**输出**：汇总Excel，包含：
- 序号、品牌、名称、型号、数量、单位
- 单价（如有）、总价
- 汇总统计

**参考脚本**：`scripts/extract_bom.py`

## 常见问题处理

### Q1: BOM格式不统一怎么办？
- 先读取文件，分析表头结构
- 找到"序号"、"物料名称"、"型号"等关键列
- 适配不同格式（有的从第3行开始，有的从第5行）

### Q2: 型号有细微差异如何匹配？
- 去除空格后比较
- 模糊匹配（如"SV660N"与"SV660FS"可能是同系列）
- 列出疑似匹配项让用户确认

### Q3: 机电协同表中分类不明确？
- 优先按"类别"列判断
- 其次按品牌判断
- 最后按物料名称关键词判断
- 不确定的物料单独列出，让用户确认
