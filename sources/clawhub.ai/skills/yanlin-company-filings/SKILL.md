# 研林 · 公司公告过滤 (yanlin-company-filings) V2

## 功能
1. **多源公告采集** — 接入新浪财经新闻API + 个股公告页 + 交易所披露索引
2. **实质影响过滤** — 只保留对投资决策有实质影响的公告类型
3. **重要性评级** — 按公告类型自动打分（1-5⭐），标注利好/利空/中性
4. **赛道映射** — 自动将公告关联到行业赛道

## 数据源架构

| 层级 | 源 | 覆盖范围 | 说明 |
|------|-----|---------|------|
| **Tier 1** | 新浪财经新闻API | 市场全量新闻 | 实时推送，含公司公告覆盖 |
| **Tier 2** | 新浪个股公告页 | 30支核心个股 | 逐股提取近期公告事件 |
| **Tier 3** | 上交所/深交所 | 交易所披露索引 | 备用源，提供官方披露链接 |

## 公告过滤规则

### 保留的公告类型（其余过滤）
| 类型 | 重要性 | 示例关键词 |
|------|--------|-----------|
| 🏆 业绩公告 | ⭐⭐⭐⭐⭐ | 业绩预告、业绩快报、净利润 |
| 🏭 产能项目 | ⭐⭐⭐⭐ | 扩产、投产、新产线、投资建设 |
| 📦 业务订单 | ⭐⭐⭐⭐ | 中标、重大合同、战略合作 |
| 🔄 资本运作 | ⭐⭐⭐⭐ | 并购、重组、收购、增发、回购 |
| 📜 分红融资 | ⭐⭐⭐ | 分红、送转、可转债 |
| ⚠️ 监管风险 | ⭐⭐⭐⭐ | 立案、处罚、风险提示、ST |

## 调用方式
```bash
python3 {baseDir}/scripts/fetch_filings.py [--output json|text]
```

## 数据流
```
新浪API新闻(50条/次) ──→ 公告分类器 ──→ 重要性评分 ──→ 结构化JSON
       ↓
30支核心个股公告页 ──→ 信息提取 ──→ 去重合并 ──→ 最终输出
       ↓
上交所/深交所索引 ──→ 补充标注
```
