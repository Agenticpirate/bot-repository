# 环境识别技能

辅助识别工作场所的环境因素与危险源，提供分类分析与防控建议。适用于制造业车间、实验室、仓储物流区等场景的安全评估与 EHS 审计。

## 触发条件

当用户提到以下关键词时激活本技能：
- 环境因素识别、危险源识别
- EHS 审计、安全评估
- 职业病危害因素检测、工作场所风险识别
- ISO 14001/ISO 45001 体系建立

## 能力边界

### 支持的场景
- 制造业车间（机械加工、焊接、装配、喷涂等）
- 实验室（研发实验室、质检实验室、化学实验室）
- 仓储物流区
- 办公楼宇（有限支持）

### 不支持的场景
- 军事设施辐射环境评估
- 水下/高空/密闭空间专项评估（需专业资质）
- 辐射剂量计算、毒理学定量分析
- 法律合规性认证（本技能仅提供识别参考，不替代法定检测）

## 执行流程

### 阶段 1：信息收集
1. 确认场所类型和主要活动
2. 引导用户提供区域清单（车间/仓库/实验室/办公区等）
3. 询问已知的危险物质或设备

### 阶段 2：因素识别
1. 对照 `参考知识库/environmental-factors.md` 逐项排查物理因素（噪声、振动、温度、照明等）和化学因素（粉尘、有毒气体、有机溶剂等）
2. 对照 `参考知识库/hazard-sources.md` 识别危险源分类
3. 对每个识别项标明判定依据

### 阶段 3：风险评估
1. 使用风险矩阵（可能性 × 严重程度）评估每项
2. 分级：高风险（立即整改）/ 中风险（限期整改）/ 低风险（持续改进）

### 阶段 4：报告生成
1. 参照 `参考知识库/report-template.md` 格式输出
2. 报告须包含：基本信息、识别结果表、风险评估矩阵、防控建议

## 异常处理

### 输入不足时
- 若用户未提供场所类型，主动询问：制造业车间 / 实验室 / 仓储区 / 办公场所
- 若缺少关键区域信息，提供常见场所清单供用户确认
- 若信息不足以完成评估，生成包含"[需补充]"标注的部分报告

### 数据质量问题时
- 若用户描述模糊（如"有点吵"），引导用户量化：提供等效声级估算或建议现场检测
- 若识别出矛盾信息（如声称无化学品但提及使用清洗剂），提示用户确认
- 若用户提供的数据超出参考知识库覆盖范围，明确告知并给出通用建议

### 参考文件缺失时
- 若参考知识库文件无法加载，使用通用环境因素识别方法论继续工作，并在报告中注明
