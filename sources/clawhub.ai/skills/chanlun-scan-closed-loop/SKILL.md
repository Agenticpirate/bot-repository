# 缠论买点扫描闭环

收盘后自动跑完一条完整链路：**扫描出票 → 单日形态判断 → 生成次日条件单 → 出 HTML 报告**，覆盖科创板与创业板，按 MACD 信号映射缠论一、二、三类买点，并滚动复用自选股分组。

## 何时使用

- 用户要求「跑一次缠论买点扫描」「扫描缠论买点」「生成次日条件单」
- 用户要搭建「缠论买点扫描 → 形态判断 → 次日条件单」的日常自动化
- 用户问「缠论一/二/三类买点怎么选股」或要做科创创业板块的买点初筛

## 依赖与前置准备（缺一不可）

| 依赖 | 用途 |
|------|------|
| 连接器：通达信（tdx-connector） | 自然语言选股（tdx_screener），结果自带最新价 |
| 连接器：腾讯自选股（westock-mcp） | 拉日 K（data_kline）与自选股分组管理 |
| 脚本：`scripts/缠论扫描_条件单闭环.py` | 条件单计算引擎（A+B 合并主策略参数已内置），Python 运行 |

脚本运行前只需更新顶部三个变量：`TODAY`（数据日期=最近交易日）、`NEXT_TRADE`（条件单生效日）、`POOL`（票池）。输出 HTML 自动落到脚本同目录，文件名带日期，无硬编码路径。

## 完整工作流

### 第一步 扫描出票

- 数据源优先用通达信自然语言选股（tdx_screener），支持板块前缀限定且结果自带最新价；不可用时退回腾讯自选股策略信号或 westock 筛选。
- 买点映射：一类 = MACD 底背离（底背驰代理）、二类 = MACD 金叉（金叉企稳代理）、三类 = 涨停回马枪（突破回踩代理）。
- 过滤：剔除最新价 < 20 元；剔除名称含 ST / *ST。
- 分别保留一类、二类、三类的**原始命中集合**，并额外求一类 ∩ 二类作为「一二重叠」集合。**不要从二类中剔除与一类重叠的标的。**

### 第二步 加入自选股 —— 滚动复用 20 个分组槽位

自选股接口**没有删除分组的能力**（只能新建/改名/排序），因此采用固定 20 个槽位滚动复用，分组数恒定不增长。

- 命名格式：`{类别}{YYYYMMDD}`，**不含空格与括号**，如 `一买20260831`、`二买20260831`、`三买20260831`、`一二重叠20260831`。
  类别 4 种：一买 / 二买 / 三买 / 一二重叠；每类保留最近 5 个交易日，合计恒定 20 个分组。
- 每次运行先调 `portfolio_watchlist_groups` 取全部分组，按类别前缀归类并解析日期，类内按日期从旧到新排序。
- 对每个类别：
  - **已有 5 个槽位 → 复用最老那个**：
    1. `portfolio_group_rename` 改名为今天日期（如 `一买20260831`）
    2. **清空组内旧股票**：对组内每只股票调 `portfolio_watchlist_move`（from=该组ID，to=1「全部」，retain=false）逐只移出，并复查组内已空。
       ⚠️ **严禁**用 `portfolio_watchlist_remove` 清空——它不带 group_id，会把该股票从**所有**分组一并删除，误伤其他日期槽位里的同一只票（重叠票天然同属多组）。
    3. 确认清空后再添加当日标的。
  - **不足 5 个槽位 → 新建**：`portfolio_group_add` 建 `{类别}{今天YYYYMMDD}`，随后**重新查询 groups 取正式 ID**（创建返回的可能带 tmp 前缀，勿直接用于写操作）。
- 填充规则：一买组 = 一类全部命中；二买组 = 二类全部命中（含与一类重叠的）；三买组 = 三类命中；一二重叠组 = 一类 ∩ 二类。
- **允许重复出现**：重叠标的会同时存在于一买组、二买组、一二重叠组，这是预期行为，不去重、不剔除。
- 添加用 `portfolio_watchlist_batch_add`，**不同分组串行单独发送，发完立即调 `portfolio_watchlist` 按 group 核对是否真正到账**（并行 batch_add 存在归属竞态，会返回成功但未进组）。
- 接口限制（已实测）：分组名长度上限约 **12 字符**；**新建分组不接受全角括号**（`一买（20260831）` 会报 -107），故统一用无括号格式。

### 第三步 判断单日形态 + 生成次日条件单

- 用 westock `data_kline` 拉每只标的的日 K：`period=day`、**不复权**、**limit=12**、end=当日，每批最多 10 只。
  - `nodes[0]` = 当日（open / last / high / low）
  - `nodes[1].last` = 前收
  - **`nodes[0..9]` 的 last 依次取出，组成近 10 日收盘价序列（从新到旧）**，用于算 MA5 / MA10。
- 形态判断：高开/低开 = 今开 vs 前收；高走/低走 = 今收 vs 今开；平开（|偏离| < 0.1%）按今收 vs 前收兜底，高走归高开高走、低走归低开低走。
- 更新脚本顶部 `TODAY` / `NEXT_TRADE` / `POOL` 后运行脚本，HTML 输出到脚本同目录，文件名 `缠论扫描_条件单闭环_<YYYYMMDD>.html`。
- POOL 每行格式（**11 个字段**）：`(代码, 名称, 板块, 主分类, 前收, 今开, 今收, 今高, 今低, 所属分组, 近10日收盘价)`
  - 主分类填 一买 / 二买 / 三买 / **重叠**——决定条件单归属，每只票只生成一套条件单，重叠票主分类一律填「重叠」。
  - 所属分组填元组：重叠票填 `("一买", "二买")`，纯二类填 `("二买",)`，三类填 `("三买",)`。
  - 近 10 日收盘价填列表，顺序 `[今收, 昨收, ...]`，**必须是当日往前连续 10 个交易日**，不得跳空或缺失。
  - 例：`("sh688820", "盛合晶微", "科创", "重叠", 127.70, 126.93, 127.55, 134.48, 126.10, ("一买", "二买"), [127.55, 127.70, 121.61, 121.12, 122.44, 127.50, 127.98, 141.00, 153.62, 153.10])`
- 策略为 A+B 合并主策略（A 版常驻档 + B 版形态调节层），参数已内置于脚本，不要改动任何系数。
- **均线档由脚本自动计算，无需手填**：
  - **S7 跌破 10 日线止损** → 触发价 = **MA10 × 0.97**（有效破位线），触发即**清仓**；带 **3% 缓冲带**（脚本常量 `MA10_BUFFER = 0.03`），必须跌破 MA10 再往下 3% 才算有效破位。
  - **S8 5 日线上涨 10% 止盈减半** → 触发价 = MA5 × 1.10。
  - 这两档是**绝对价位**（随均线每日变动），不是收盘价的固定系数。脚本会分别标注「已有效破位」与「缓冲内」，**只有前者需要执行清仓**。

### 第四步 汇报

- 用 present_files 打开生成的 HTML 报告。
- 结论先行，表格给出：四个分组各应入组数量（重叠票重复计入）、**本次是新建槽位还是复用最老槽位**、各类别已占用槽位数（x/5）、四类形态分布、条件单总条数、次日不可达条数及成因。
- **重点提示：已「有效破位」的标的只数与明细**（跌破 MA10 再下 3%，按 S7 规则应清仓，需优先处理）；**仅跌破 MA10 但仍在缓冲带内的，单列说明为「观察」，不执行清仓**——两者必须区分清楚，不要混淆。
- 提示次日操作要点：哪几只当日应卖出、哪几只需等回踩买入、哪几只可持股。
- 已知规律（非错误，汇报时说明）：低开高走形态的 0.76 档、高开高走/高开低走形态的 1.299 档，在科创创业 ±20% 涨跌停下结构性不可达，需顺延或分批。

### 兜底

- 当日非交易日或扫描无命中：直接说明，不建分组、不生成报告。
- 数据获取失败时如实说明，禁止编造数字或用历史数据冒充当日数据。
- 若某只标的近 10 日 K 线不足（如次新股），如实标注 MA10 缺失，不要补默认值。

## A+B 合并主策略（速查）

完整买入/卖出档位、形态止损位、当日/次日操作表见 `references/策略参数表.md`。核心风控：总仓 ≤ 50%、单只 ≤ 20%、大盘走弱空仓、跌破 5 日线止盈 / 10 日线止损。

## 关键注意点

- K 线数据**不复权**，技术信号不受除权干扰。
- 涨红跌绿（A 股惯例），货币符号 ¥。
- 缠论是概率框架，不做「一定涨/一定跌」的绝对化判断，不承诺收益。
- 本报告为技术信号代理，非严格缠论结构确认；严格确认需逐只还原分型（含包含处理）、笔、线段、中枢 ZG/ZD 与 MACD 面积背驰，并做日线 + 30 分钟多周期联立。
