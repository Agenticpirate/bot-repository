# 波特五力分析技能

## 0. 能力说明与边界（调用前必读）

**本技能能做什么**
- 引导你逐项评估**五股竞争力量**，每力给出结构化评估维度与示例，由你判断强度（强/中/弱）并给出依据。
- 汇总五力形成**行业结构判断**，并给出战略提示（如"应建壁垒抵御新进入者"）。
- 输出**双版本**报告：Markdown 文档 + 精美网页版 HTML（五力模型图，适合战略评审演示）。

**本技能不能做什么**
1. 不能替你判断某股力量"强还是弱"——强度依据是你提供的行业事实，Agent 只给评估维度和示例，不替你下结论。
2. 不能替你编造行业数据——所有判断基于你提供的真实情况。
3. 不能替你写最终战略结论——行业吸引力/竞争态势由你总结，Agent 给提示不代决。
4. 不对力量强度做粉饰——若五力皆强（行业艰难），如实呈现。
5. 不绑定任何质量管理体系标准——五力是通用战略分析工具，供应链/质量是应用方向之一。

**通用性说明**：波特五力适用于任何行业的竞争结构分析。举例与引导会**多往质量管理/供应链领域靠拢**（如零部件供应商面对整车厂的买方议价、医疗行业进入壁垒、替代检测技术），但你可分析任何行业。

## 1. 调用前置：我需要的信息

| 信息 | 必填 | 说明 |
|------|------|------|
| 分析行业/细分 | 是 | 如"汽车电子零部件""第三方检测服务" |
| 分析视角 | 否 | 如"新进入者视角""在位企业防御视角" |
| 行业事实 | 是（交互补充） | 每力评估所需的市场结构事实 |
| 战略背景 | 否 | 若提供，五力结论向其倾斜；未提供标注「待提供战略后复核」 |

## 2. 交互锁流程（五门强制）

| 门 | 力量 | Agent 引导的评估维度（示例） | 禁止 |
|----|------|------------------------------|------|
| 门1 | 供应商议价能力 | 供应商集中度、替代供应、切换成本、前向一体化威胁 | 替你定"强" |
| 门2 | 买方议价能力 | 客户集中度、价格敏感、后向一体化、信息对称 | 替你定"强" |
| 门3 | 新进入者威胁 | 规模/资本壁垒、品牌、技术专利、政策许可 | 替你定"高" |
| 门4 | 替代品威胁 | 替代程度、性价比、转换成本 | 替你定"高" |
| 门5 | 业内竞争强度 | 竞争者数、市场增速、差异化、退出壁垒 | 替你定"激烈" |

每门：Agent 给维度+质量领域示例 → 你判断强度+依据 → 标注「供参考·待确认」（若跳过）。

## 5. 相关技能联动（战略分析工具链）

五力是工具链的**外部行业中观入口**，与 PESTEL、VRIO 共同构成 SWOT 的上游输入。完整链路：

`pestel-analysis`（宏观外部）→ `porters-five-forces`（行业外部）→ `vrio-analysis`（内部）→ `swot-analysis`（收敛）→ `smart-goal-setter`（落成目标）→ `qms-objective-decomposition`（质量分解落地）

- **同链外部分析（互补）**：`pestel-analysis`（宏观环境）——五力看行业中观竞争结构，PESTEL 看宏观大环境，二者叠加覆盖外部 O/T
- **内部对照**：`vrio-analysis` 提供内部 S/W，与五力的 O/T 在 `swot-analysis` 汇合
- **收敛与落地**：五力结论（行业吸引力 / 竞争态势）→ `swot-analysis` 的 O/T 象限 → SWOT 战略 → `smart-goal-setter` 落成目标
- **关系说明**：五力不做宏观环境扫描（那是 PESTEL 的活），也不做内部资源评估（那是 VRIO 的活），聚焦行业竞争结构；产物通常作为 SWOT 上游 feeder 被直接引用。
