# AI自媒体矩阵内容工厂

## 变现逻辑

自媒体矩阵化运营是2026年经过验证的最强被动收入路径之一。
做3-5个垂直账号，每个专注一个细分品类，矩阵整体收益远高于
单号爆款。AI让一个人能管理过去需要一个团队的产量。

**赚钱方式**：
- 小红书图文带货（挂商品链接赚佣金，1000-50000元/月）
- 抖音小程序/小黄车带货
- 广告商单（粉丝过万后，500-5000元/条）
- 私域引流（导流到微信卖课/卖产品）
- 账号矩阵出售（成熟账号可卖几千到几万元）

**已验证的盈利品类**：
母婴用品、家居好物、办公文具、户外露营、口腔护理、
宠物用品、健身器材、美妆护肤、数码配件、穿搭饰品。

## 核心能力

### 1. 小红书种草笔记批量生产

按"爆款公式"生成适配小红书的种草笔记：

| 要素 | 要求 |
|------|------|
| 标题 | 数字+痛点+解决方案（如"5款用了回不去的办公室好物"） |
| 封面 | 高清+文字标注+统一风格 |
| 正文 | 个人体验感+产品信息+使用场景+购买建议 |
| 标签 | 10-15个精准标签 |
| 商品链接 | 自然嵌入，避免硬广 |

**批量流程**：
1. 用户提供产品品类 → 自动搜索分析该品类爆款笔记
2. 提取爆款公式（开头/结构/互动点）
3. 生成5-10篇差异化笔记（不同切入角度）
4. 每篇配封面文案和标签

### 2. 抖音带货脚本自动生成

按"黄金3秒+信任建立+痛点解决+行动号召"结构：

**脚本结构**：
```
【0-3秒】钩子：惊人事实/反常识/痛点直击
【3-15秒】问题展示：具象化用户痛点
【15-30秒】产品出场：自然衔接，展示解决方案
【30-45秒】效果展示：使用场景+效果对比
【45-55秒】信任背书：数据/认证/用户反馈
【55-60秒】行动号召：点击小黄车/左下角
```

### 3. 多平台风格自适应改写

同一内容自动适配不同平台风格：

| 平台 | 风格 | 适配要点 |
|------|------|---------|
| 小红书 | 个人化、真实体验感 | 第一人称、emoji、分段短句 |
| 抖音 | 快节奏、强视听 | 短句+大字+热门BGM |
| 公众号 | 深度、结构化 | 长段落、观点输出、排版精美 |
| 知乎 | 专业、有理有据 | 第一手经验、数据引用、推荐扩展 |
| 微博 | 话题性、互动 | 短评+@+话题+配图 |

### 4. 内容排期管理

- 周度内容日历自动生成（含发布时间建议）
- 各平台最佳发布时间推荐
- 内容复用提醒（一条内容改5版）
- 库存预警（内容不足时提醒补充）

### 5. 热点追踪+借势创作

- 自动抓取各平台热搜榜单
- 匹配品牌/品类的切入角度
- 生成借势内容（热点来了2小时内出稿）

## 自进化学习系统（越用越好用、越用越高效）

本技能内置通用学习模块 `scripts/learner.py`。每次使用后自动复盘、积累经验，逐步提升输出质量与执行效率，无需人工维护。

### 记忆文件
`learned_patterns.json`（位于本技能目录）记录：操作总数、各能力使用频次、错误模式、用户偏好、改进建议。

### 使用后请调用（Bash）

```bash
# 记录一次成功使用（--capability 填本次主要能力名，如「简历优化」「比价」）
python scripts/learner.py record <本技能目录> --capability 简历优化
# 记录一次失败/异常
python scripts/learner.py record <本技能目录> --capability 简历优化 --fail --error 格式识别失败 --note "用户上传了非标准文件"
# 记录用户偏好（下次直接使用）
python scripts/learner.py prefer <本技能目录> --key 输出语言 --val 中文
# 查看累计洞察（高频能力 / 反复错误）
python scripts/learner.py insight <本技能目录>
# 自动复盘（错误≥3次 或 操作≥10次 时给出改进建议）
python scripts/learner.py reflect <本技能目录>
```

### 迭代规则
- **错误累计 ≥3 次** → 主动增加预检/兜底步骤，并将经验回写本 SKILL.md。
- **操作数 ≥10 次** → 分析高频能力优先打磨示例与质量，低频能力评估精简或合并。
- **重要用户偏好** → 写入 `learned_patterns.json`，下次调用直接采用，减少重复询问。

> 越用越懂你：第一次用是通用能力，第十次用已沉淀为你专属的最佳实践。
