# meta-industry-chain-analysis（蒸馏超越型元技能）

> 由 `model-distillation` 从教师技能 **industry-chain-analysis** 蒸馏并增强生成。
> 蒸馏机制：跨模型蒸馏（见 meta-evolver 北极星策略「主动与其他大模型对话、蒸馏、逐步超越」）。

## 来源能力签名（教师 industry-chain-analysis）
- 规模：原始 SKILL.md 16807 字符、25 步显性工作流、已识别 1 处限制。
- 核心定位：以顶级产业投资研究员视角，从产业链结构定位**最能持续获取超额利润的环节**并映射到上市公司标的。
- 底层逻辑（关键）：**不找需求最强的公司，找供给弹性最差的环节**。当环节出现供给瓶颈（产能受限+需求刚性+替代困难），对应上游稀缺资源天然高壁垒。
- 执行原则：用产业逻辑排序不用涨幅排序；先拆链后映射公司；关键数字必标来源/日期/证据等级；**不荐股、不输出买卖/目标价/仓位建议**。

## 蒸馏出的真实工作流（继承 + 强化）
- **阶段 A（可选）信号漏斗扫描**：六类信号（涨价/扩产/认证/政策地缘/财报异动/资金筹码）→ 聚类定位行业 → 爆发六因子评分（稀缺性/替代弹性/补库缺口/议价权/业绩映射/市值水位，满分12）→ 共振等级（S/A/B/C）→ 标的锁定 → 时机判断。
- **阶段 B-J**：产业链 BOM/L0-L4 全景拆解 → 瓶颈环节五维评级（Serenity 校验：供给约束/需求刚性/替代难度/认证周期/业绩映射）→ 红队反向证伪（找反例推翻结论）→ 动态熔断跟踪（信号反转即降级）。
- 数据源纪律：行情/财报/研报一律走可信 skill（wb-finance-skill 红线优先、westock-data、westock-tool、neodata），禁止第三方直连；仅非行情公开资料可用 WebSearch 并标注「非一手来源」。

## 增强点（超越教师）
1. **可靠自验证**：每个瓶颈结论用 `reason-verify` 校验"证据等级"与"来源可追溯"，无来源内容强制标「待核验」；reliability<0.8 即回退补证。
2. **自我反思闭环**：每段分析后写入 `self-reflection-loop`，沉淀"哪些环节被红队证伪 / 哪些信号失效"，反哺下次信号权重。
3. **整合进 super-agent**：作为节点接入「感知→规划→执行→自验证→反思→记忆」超级智能体闭环，可被 `long-horizon-planner` 编排为长程赛道跟踪任务。
4. **对抗验证蒸馏质量**：对"瓶颈五维评级"做反例测试——故意构造"涨幅高但供给无约束"的伪瓶颈，验证不误判；防确认偏误。
5. **持续自进化**：注入 learner，纳入 meta-evolver 的 sense/plan/record 闭环，跨会话越用越强。

## 教师 vs 学生 对比
| 维度 | 教师(industry-chain-analysis) | 学生(meta-industry-chain-analysis) |
| --- | --- | --- |
| 工作流 | 25 步显性流程（A-J 阶段） | 同流程 + 自验证钩子 + 红队证伪强化 |
| 失败防护 | 已识别 1 处限制 | 显式 limits + 对抗验证（伪瓶颈识别） |
| 自进化 | 视技能而定 | 强制注入 learner，纳入 meta-evolver 闭环 |
| 集成 | 单点研究技能 | 接入 super-agent 感知→规划→执行→自验证→反思→记忆闭环 |

## 使用
直接调用本技能完成产业链/赛道深度研究；本技能在教师能力之上叠加自验证、反确认偏误与反思，输出更可靠、可追溯、可复用。

## 已知限制（来自教师蒸馏 + 元进化补充）
- 教师依赖 wb-finance-skill / westock-data / westock-tool / neodata 等可信数据源，蒸馏未内嵌这些取数通道，实跑需配套加载。
- 教师为研究线索输出，**严禁荐股**；本元技能同样遵守不输出买卖/目标价/仓位建议的红线。
- 蒸馏不保证覆盖教师全部隐式知识（如完整 HTML 模板与阶段 C/J 附录），深度使用需对照教师原技能核验。
