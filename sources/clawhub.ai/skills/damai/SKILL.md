# 大麦演出票务 Skill

大麦（阿里旗下）是中国最大演出票务平台，覆盖演唱会、音乐节、
话剧、体育赛事。热门演出"秒罄"是常态，本 skill 帮你把可控环节
做到位，并避开黄牛陷阱。

## 开抢前准备清单（成功率的大头在开抢前）

1. **提前实名**：观演人信息提前录入（身份证），开抢时来不及填
2. **提前收货/取票方式确认**：电子票/快递票影响下单步骤数
3. **设置开售提醒** + 提前 5 分钟进 App 刷到详情页
4. **网络**：稳定 Wi-Fi 或 5G，别挂代理（风控敏感）
5. **多平台**：同场演出常在大麦/猫眼/纷玩岛等多平台分票，
   都设提醒，主抢一个备选其他
6. 开抢瞬间：直接点购买→选票档→提交，**犹豫=没票**；
   失败不要狂刷，间隔几秒再试（风控会拦高频请求）

## 强实名演出规则（重要）

- **强实名 = 人证脸三合一**：购票绑定观演人身份证，入场刷身份证
  +人脸，**不可转赠不可转卖**——买了去不了只能官方退票通道
- 普通实名：绑定身份证但可转赠（App 内转赠通道，限次）
- 下单前看清票品页"退改规则"与"是否支持转赠"，强实名场次
  给别人代拍时必须直接填对方观演人信息

## 选座与票档判断

- 场馆图逻辑：内场近但多数平视，看台前排俯视全场性价比常更高；
  演唱会"山顶票"（看台高层）体验靠大屏，预算紧可接受
- 音乐节：区分单日票/全通票，VIP 区值不值看动线与卫生间配置
  而不只是距离
- 开票即秒罄的场次，回流票窗口通常在：开演前 1-2 周（退票高峰）
  与开演前 1-3 天，蹲官方"缺货登记/回流提醒"

## 二手票风险防范（黄牛重灾区）

- **强实名场次的"代拍/转让"基本都是骗局**——入场要刷本人身份证，
  黄牛给的票根本进不去
- 可转赠场次只走 App 官方转赠，**任何"截图票""PDF票""闲鱼低价"
  都高危**（一票多卖、假票）
- 溢价代拍即使成功也违反平台规则，资金无保障

## Agent 典型用法

1. **开抢作战计划**：按演出日期倒排准备清单（实名/提醒/多平台）
2. **规则解读**：判断该场次强实名/可转赠/退改条款，给购买建议
3. **选座建议**：按预算与偏好（视野 vs 氛围）推荐票档区域
4. **防骗咨询**：用户描述二手票渠道 → 按风险清单判定并劝阻高危交易

## 本 skill 不做什么

- 不提供抢票脚本/外挂/自动化下单（违反平台规则，账号风控）
- 不推荐任何非官方购票渠道
- 票价、开售时间、退改细则以票品详情页实时信息为准
