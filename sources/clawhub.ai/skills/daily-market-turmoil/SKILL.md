# Daily Market Turmoil（每日动荡）

## Overview

收集前一交易日（收盘/盘后）和当天（盘前/盘中）的全球股市最新消息，**重点筛选影响当日市场变动的关键因素**，整合成一份结构化 Markdown 报告。报告按「今日核心变量 → 国际市场 → 国内市场 → 板块涨跌 → 消息时间线 → 昨日总结 → 今日预期 → 今日关注与风险」组织，每条资讯包含数据/事件 + 驱动原因简析，**必须包含昨日总结与今日预期两个分析板块**。

## 输出文件

- 保存路径：`~/Documents/Daily news/每日动荡/每日动荡_YYYY-MM-DD.md`
- 文件名：`每日动荡_` + 当天日期（如 `每日动荡_2026-07-08.md`）
- 保存目录不存在时先创建

## 执行流程

### Step 1: 确认日期范围

- 今天是 **{{(datetime.now()|string)[:10]}}**
- 覆盖范围：**前一交易日（收盘/盘后）+ 当天（盘前/盘中）**
- 周一执行时，前一交易日为上上周五，需额外搜索周末两天的重大消息
- 周末执行时，只生成简版周报（汇总本周重要动态 + 下周关注焦点）

### Step 2: 搜索资讯

按 `references/search_guide.md` 中的维度搜索。每个搜索词带上具体日期。搜索覆盖：

- **国内**：A股大盘/政策面/行业板块/资金动向/港股（≥5条）
- **国际**：美股/欧股/亚太/大宗商品/汇率/地缘政治（≥5条）
- **特别关注**：盘后公告、周末重大消息、当天盘前新闻

### Step 3: 整合生成报告

按 `assets/report_template.md` 的模板生成 Markdown 文件。核心要求：

- **🔥 今日核心变量**：提炼 1-3 条最关键消息面变化，直接说明今日变动方向
- **每条资讯必须有数据/事件 + 驱动原因简析**，说明"因为什么消息导致了什么变动"
- 板块涨跌用表格呈现，标注 🟢（涨）/🔴（跌）和驱动消息
- 消息时间线按时间顺序排列，展示传导链条
- **📝 昨日总结**：概括前一交易日大盘走势、市场风格、情绪主线、资金行为（2-4条）
- **🔮 今日预期**：预判今日开盘、关键事件、消息面/技术面走势、板块展望、风险提示（2-4条）
- 风险提示部分需结合当日实际情况给出具体风险点

### Step 4: 保存并汇报

保存到输出路径，向用户简要汇报核心变量和报告亮点。

## 注意事项

- 使用真实的搜索数据，禁止编造新闻或数据
- 报告使用简体中文
- 生成时间填写当天实际执行时间
- 若搜索结果时效性差（如搜到往年同日数据），务必以最新年份为准，注意核对年份
