# 研声 · 资金流向分析 (yansheng-fund-flow)

> **⚠️ 重要披露：本Skill输出为演示数据（非真实市场资金流）**
> 本Skill为课程教学演示工具：所有资金流数值（主力资金/北向资金/个股资金）均由**基于标的代码的确定性规则**生成，**不获取、不引用任何真实市场数据**。
> 输出仅供教学演示分析流程，不代表任何真实市场资金动向，不构成投资建议。

## 功能
1. **主力资金流向** — 大单净流入/流出、主力资金动向（演示数值）
2. **北向资金** — 沪股通/深股通净买卖情况（演示数值）
3. **个股资金信号** — 个股主力净流入/流出、北向增减持信号（演示数值）

## 数据来源说明（重要）
- 本Skill**不联网、不调用任何外部财经数据接口**，脚本仅使用 Python 标准库。
- 所有数值均由标的代码经确定性规则（哈希种子）生成：**同一代码每次运行输出一致、可复现**。
- 输出 JSON 中 `data_source` 字段恒为"演示数据（基于标的代码的确定性规则生成，非真实市场资金流；仅供教学演示）"。
- 请勿将任何输出数值当作真实市场资金流使用。

## 调用方式
```bash
python3 {baseDir}/scripts/analyze_fund_flow.py [--codes sh600519,sz300750] [--output json|text]
```
