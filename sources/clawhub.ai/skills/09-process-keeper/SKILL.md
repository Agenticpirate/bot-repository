# 流程记录器

> 产品开发全链路 Skill #9 · 每个任务流都值得被复用

## 功能

记录开发过程中的关键决策、Bug 修复、转折点，沉淀为可复用的流程日志。

## 核心工作流

### Step 1：上下文捕获

记录当前任务的核心信息：
- 任务目标
- 当前状态
- 关键文件
- 涉及的技术栈

### Step 2：决策记录

每次关键决策时记录：

| 字段 | 说明 |
|------|------|
| 时间 | 决策时间 |
| 上下文 | 为什么需要做这个决定 |
| 选项 | 考虑了哪些方案 |
| 决策 | 最终选了哪个 |
| 理由 | 为什么选这个 |
| 结果 | 实际效果如何 |

### Step 3：问题记录

每次遇到问题时记录：

| 字段 | 说明 |
|------|------|
| 问题描述 | 出了什么问题 |
| 根因分析 | 什么原因导致 |
| 修复方案 | 怎么修好的 |
| 经验教训 | 下次怎么避免 |

### Step 4：流程打包

当某个流程重复出现 3 次以上，打包成可复用的 Skill。

## 输出格式

- 最终交付物：Markdown 流程日志
- 保存位置：项目 `docs/process/` 目录
