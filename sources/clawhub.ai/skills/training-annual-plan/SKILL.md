# 全年档期计划管理

> 输出为参考建议，最终年度排期由主理人审核确认后执行。

## 能力概述

全年培训排期总控，覆盖年度计划编制到执行跟踪的完整闭环：

| 模块 | 核心内容 |
|------|---------|
| 年度计划编制 | 1-12月培训计划框架、主题规划、目标设定、预算分配 |
| 档期排布 | 各期培训具体日期排布、节假日/淡旺季避让、频率合理性校准 |
| 冲突检测 | 场地时间冲突、讲师档期冲突、学员群体重叠、资源争用检测 |
| 计划调整 | 季度/月度滚动调整、版本管理、变更记录追溯 |
| 日历视图 | 全年培训日历一览、各期甘特图、资源占用热力图 |
| 历史对比 | 同期数据对比、趋势分析、完成率统计、偏差分析 |

## 输入

- **培训需求清单**：各业务线/部门的培训需求汇总（名称/类型/目标人群/预计期数）
- **历史培训数据**：往期年度计划、实际执行情况、完成率分析
- **资源库信息**：可用场地列表（含容量/位置/价格）、讲师库（含擅长领域/档期/费用）
- **约束条件**：预算上限、节假日/公司重大活动日期、特定时间窗口要求

### 冲突检测报告

| 冲突类型 | 详情 | 建议 |
|---------|------|------|
| 场地冲突 | 3月25-28日场地A已被X部门预订 | 调剂至场地B或调整日期至4月 |
| 讲师档期 | 王讲师在5月18-21日已邀约其他培训 | 确认档期或更换备选讲师 |
| 节假日冲突 | 9月14-17日临近中秋节 | 评估学员参训意愿，建议前移或后移1周 |

## 工作流程

1. **需求收集与框架搭建**：汇总全年培训需求，确定月度/季度主题框架与目标
2. **初步排期与冲突检查**：初排各期时间地点，检测场地/讲师/资源冲突并标记
3. **优化调整与版本确认**：根据冲突检测结果调整排期，生成优化版方案
4. **生成日历视图**：输出全年培训日历甘特图、资源占用热力图
5. **季度/月度滚动调整**：根据实际执行情况，滚动调整后续排期并保留版本日志
6. **历史对比分析**：与去年同期对比，输出完成率、偏差趋势等决策参考

## 数据模型（年度计划记录）

每条年度计划记录包含：
- `year`：计划年度
- `version`：版本号（v1.0/v2.0...）
- `periods`：各期培训明细（数组）
  - `session_id`：培训期次编号
  - `name`：培训名称
  - `theme`：培训主题
  - `date_start`：开始日期
  - `date_end`：结束日期
  - `location`：举办城市/场地
  - `lecturer`：主讲讲师
  - `target_group`：目标学员群体
  - `status`：已规划/招生中/已满员/执行中/已完成/已取消
  - `budget`：预算金额
- `conflicts`：冲突检测记录（数组，含类型/详情/状态/解决措施）
- `change_log`：变更日志（数组，含时间/修改内容/责任人）
- `summary`：年度汇总数据（总期数/总预算/完成率/同期对比）
