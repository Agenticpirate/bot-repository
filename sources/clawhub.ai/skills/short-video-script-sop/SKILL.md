# 短视频脚本写作 SOP

当脚本要量产、风格要稳定、又不想每条都从零想"开头怎么写"时，就用这个技能。

目标不是逐句生成内容，而是把"开头/展开/收束"拆成固定结构 + 5 种钩子公式轮换，并留一份能自检、能复用的中文脚本规范。

## 输入

- 一条或多条已通过 `content-material-scorer` 评级的素材（A/B 级）。
- 可选：素材的 `main_angle`（故事型/方法论型/观点型/演示型/对比型）。
- 可选：平台（抖音/视频号/小红书/全平台）。
- 可选：作者署名 `{creator_name}`（用于收束引流句）。

## 工作流

### 1. 确认 3 段结构

每条脚本由三个部分组成：

```
[钩子句] 前 3 秒，制造认知缺口
[展开]   30-150 秒，讲故事或讲方法
[收束]   最后 5-10 秒，总结 + 引流
```

总时长目标：60-180 秒（1-3 分钟）。

### 2. 选钩子公式（5 种，轮换使用）

详细公式和适用场景见 `references/hook-formulas.md`。

| 类型 | 公式骨架 |
|------|---------|
| 反直觉结论 | "XX 之后，我发现 YY" |
| 炸弹数字 | "X 个 Y，Z 个 W" |
| 场景悬念 | "一个 XX 在 YY，结果 ZZ" |
| 提问 | "你知道 XX 什么 YY 吗？" |
| 对比/冲突 | "花了 XX，结果 YY" |

**规则**：

- 同一批脚本中，5 种类型必须轮换，不连续使用同一种。
- 钩子句必须独立工作——不能假设观众看了标题/封面。
- 钩子句必须口播友好——能直接念出来，不是书面语。
- 制造悬念，不在钩子句里给答案。

### 3. 写展开段

**信息密度**：

- 每句话都推进，不绕弯。
- 用具体例子，不用抽象概念。
- 最多 3 个要点，多了观众记不住。
- 有转折或"啊哈时刻"。

**节奏**：

- 段落短（2-4 行），适配手机竖屏。
- 每 30 秒一个小钩子（新信息/转折/反问），防止中途划走。
- 数据集中展示（不要散落在全文）。

**人称**：

- 第一人称叙事（"我"的经历）。
- 每篇至少 1 句"如果你 XX"代入句。
- 2-3 个人设锚点（创业者/AI 工具用户/直白不装）。

**禁止**：

- 不写"赋能""抓手""破局""走进现实"等企业腔/文艺腔。
- 不用双引号（用语气词替代）。
- 不用"笔者""笔者认为"。
- 不解释自己在说什么（"我刚才说的是……"）。

**语气词规范**：

- 用"呀、吧、哈、嘛、呢"增加口语感。
- 省略号用"……"表示停顿。
- 可以用"说实话""坦白讲"做转折。

### 4. 收束 + 引流（参数化）

收束结构：

1. 一句话总结核心观点（和钩子句呼应）。
2. 引流句（二选一模板，把 `{creator_name}` 替换成实际署名）：

```
关注 {creator_name}，一个用 AI 死磕自己的创业者
```

```
关注我，下期告诉你我练了 X 次之后的结果
```

**规则**：

- 收束句不靠 LLM 输出，手动写死。
- 引流句根据内容选择：单条用固定版，系列用预告版。
- `{creator_name}` 必须在生成时显式替换，不能留占位符上线。

### 5. 质检（每条脚本产出后自检）

9 条红线，违反任何一条 = 返工。详细质检清单见 `references/hook-formulas.md` 末尾。

1. 首行不能是"大家好""今天我们来聊聊"——必须直接进钩子。
2. 不能有超过 4 行的段落。
3. 不能有连续 2 句没有信息增量的过渡句。
4. 不能出现"可能""比较""其实"超过 3 次（这些是口癖，不是书面语气词）。
5. 不能有"自问自答"句式（"你以为 XX？其实 YY"——念不出口）。
6. 结尾不能突然升华/煽情。
7. 收束句不靠 LLM 输出，手动写死。
8. 引流句中 `{creator_name}` 必须替换。
9. 总时长 60-180 秒，按 200 字/分钟估算。

## 输出

每条脚本输出为：

- 文件路径：`outputs/{material_id}-{title_slug}.md`
- 文件结构见 `assets/script-template.md`

## 平台适配备注

| 平台 | 特点 | 适配要点 |
|------|------|---------|
| 抖音 | 平台推荐重停留时长和互动率，固定节奏赛马 | 钩子句必须极强，前 3 秒定生死 |
| 视频号 | 平台推荐重评论和分享，私域可触发公域 | 结尾引导评论（"你觉得呢？"），强调社交关系链 |
| 小红书 | 内容平台，涨粉靠内容质量 | 配合封面图 + 标题党，图文版同步产出 |

## 安全

没有明确确认前，不要把含个人隐私、第三方产品未公开数据的脚本自动发布到任何平台。
