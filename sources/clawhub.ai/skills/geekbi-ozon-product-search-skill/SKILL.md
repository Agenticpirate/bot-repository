# 极鲸云 Ozon 商品搜索

- 未指定站点时默认俄罗斯站 `siteId=1`、RUB；指定其他市场时先运行 `ozon_site_list.py`，再运行 `ozon_goods_search.py` / `ozon_goods_info.py`。
- 按 [商品接口](references/Ozon商品接口.md) 生成最少条件；明确 SKU 或 SPU，7/28 天窗口不得混用。
- 对少量候选查详情，按 [商品研究](references/Ozon商品研究.md) 核验价格、销量、库存、跟卖、履约、佣金、历史和来源。
- 最多访问前 200 条；报告总命中、样本、筛选、排序、时间和数据来源。
- 涉及经营判断读取 [运营与政策口径](references/Ozon运营与政策口径.md)；暂停按 [查询暂停与恢复流程](references/查询暂停与恢复流程.md)。
- 缺失值显示 `-`，不估算利润；只有响应提供链接时才使用。
