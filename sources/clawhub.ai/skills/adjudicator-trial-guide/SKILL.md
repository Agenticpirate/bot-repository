# 裁判者办案指引 v1.0

> 头像：`assets/avatar.png`
> 适用领域：民商事诉讼与仲裁（全领域通用，含合同纠纷、建工纠纷、借贷纠纷、公司纠纷、侵权纠纷等）
> 适用对象：承办法官、仲裁员、法官助理、合议庭/仲裁庭成员、法学研究人员/法学生
> 方法论根基：邹碧华《要件审判九步法》（人民法院出版社2020纪念版新注 / 法律出版社2010初版）

## 一、定位

本技能是裁判者（法官/仲裁员）的办案指引，回归邹碧华原著的**裁判者视角**——把"九步法"作为审判管理工具，从庭前到庭后全流程规范裁判思路。无论诉讼审判还是仲裁审理，九步法提供的是同一套思维框架。

**与其他技能分工**：本技能是"审判管理师"（怎么审）。律师版技能 `lawyer-case-strategist` 是"案件分析师 + 攻防策略师"（怎么赢），两者互补。

**适用对象**：
- 承办法官（独任审理或合议庭承办法官）
- 仲裁员（仲裁庭首席或独任仲裁员）
- 法官助理 / 仲裁秘书
- 合议庭 / 仲裁庭成员
- 法学研究人员 / 法学生

## 二、激活条件

满足以下任一条件时，应激活本技能：

1. 用户提出法官/仲裁员办案指引、审判思路、庭审驾驭请求
2. 用户提出要件审判九步法（裁判者视角）
3. 用户需要整理争点、举证指导、释明权行使
4. 用户需要核验裁判文书/仲裁裁决书（八个一致）
5. 用户需要心证形成、要件归入、价值判断
6. 用户提出"八个一致"（裁判文书角度）、"心证公开"、"法律观点开示"等专业术语
7. 用户为法学研究人员/法学生希望系统学习审判方法论

## 三、五个阶段（Phase A-E）

### Phase A：庭前准备（第1-4步）

**核心问题**：审判方向锁定了吗？法律工具备齐了吗？

**任务清单**：
1. **A-1 固定权利请求**（第1步）
   - 审阅起诉状/反诉状/上诉请求/仲裁申请书
   - 明确原告/被告/第三人的权利请求
   - 标注请求项中的模糊点（为释明做准备）

2. **A-2 确定权利请求基础规范**（第2步）
   - 检索支持原告诉求的法律条文
   - 检索支持反诉的法律条文
   - 检索被告可能援引的条文
   - **关键**：请求权基础必须明确，不明确的要释明

3. **A-3 确定抗辩权基础规范**（第3步）
   - 审查被告答辩是否包含抗辩
   - 识别被告未明确提出但可能主张的抗辩
   - 检索抗辩权基础规范
   - **关键**：抗辩与否认要区分

4. **A-4 基础规范构成要件分析**（第4步）
   - 对每一项基础规范拆分构成要件
   - 按法律规范要件分类说预分配举证责任
   - 标注主张共通原则的适用情形
   - **关键**：构成要件拆分是后续审判的骨架

**产出物**：庭前准备表（请求项+基础规范+构成要件+举证责任分配）

**退出条件**：每一请求项均有明确的基础规范和构成要件清单

### Phase B：庭审驾驭（第5-7步）

**核心问题**：庭审效率如何？争点是否清晰？证据是否充分？

**任务清单**：
1. **B-1 诉讼主张的检索**（第5步）
   - 引导原告陈述事实主张
   - 引导被告陈述抗辩主张
   - **关键**：被告"未明确"抗辩要引导明示（释明）
   - 引导第三人陈述主张

2. **B-2 争点整理**（第6步）
   - 区分真争点与假争点
   - 区分攻防争点
   - 在法庭上明示争点
   - **关键**：争点整理是庭审的核心环节
   - 必要时要求当事人就争点确认

3. **B-3 要件事实证明**（第7步）
   - 举证指导（释明的具体应用）
   - 主持证据交换
   - 主持证据质证
   - **关键**：举证不能的客观原因要记录
   - 关注证据链的完整性

**产出物**：庭审笔录（争点确认+证据质证+举证指导记录）

**退出条件**：争点清单明确+核心证据均经质证+举证指导完成

**深度参考**：`references/法官释明操作指引.md`

### Phase C：心证形成（第8-9步）

**核心问题**：事实如何认定？要如何归入？

**任务清单**：
1. **C-1 事实认定**（第8步）
   - 对每一争议事实审查证据
   - 评估证据三性（真实性/合法性/关联性）
   - 评估证明力大小
   - **关键**：利害关系证人证言"一般小于"不等于"当然小于"
   - 必要时启动司法鉴定/重新鉴定

2. **C-2 要件归入并作出裁判**（第9步）
   - 将认定事实"装入"构成要件
   - 检验每一要件是否满足
   - 形成裁判结论
   - **关键**：要件归入是演绎推理的"涵摄"环节
   - 法律漏洞填补要充分说理
   - 价值判断要符合形式理性优先原则

**产出物**：心证形成记录+裁判结论初稿

**退出条件**：每一要件均有"满足/不满足"结论+裁判结论明确

### Phase D：裁判文书（八个一致核验）

**核心问题**：裁判文书/仲裁裁决书逻辑自洽吗？经得起上诉审/撤销审查吗？

**任务清单**（"八个一致"逐项审查）：
1. 诉讼请求与诉讼主张一致
2. 诉讼请求与事实理由一致
3. 诉讼请求与法律依据一致
4. 诉讼请求与举证质证一致
5. 事实认定与证据采信一致
6. 事实认定与裁判说理一致
7. 裁判说理与裁判主文一致
8. 裁判主文与诉讼请求一致

**深度参考**：`references/裁判文书八个一致深度解析.md`（含"四个不固定"根源诊断、检查方法、核验技巧速查表）

**产出物**：八个一致核验清单（与律师版同构，详见 `references/裁判文书八个一致深度解析.md`）

**退出条件**：八个一致全部通过（或遗留风险已明确标注）

### Phase E：释明与价值观（贯穿全流程）

**核心问题**：释明权行使是否恰当？价值判断是否合理？

**任务清单**：
1. **E-1 释明权行使**
   - 弥补当事人主张不明确
   - 弥补当事人主张不充分
   - 弥补当事人主张不适当
   - 心证公开
   - 法律观点开示
   - 举证指导

2. **E-2 价值判断**
   - 形式理性 vs 实质理性的平衡
   - 法律解释时的价值取向
   - 法律漏洞填补时的价值选择
   - **关键**：价值判断不能凌驾于法律之上
   - **关键**：价值判断需要充分说理

**释明边界**：
- ❌ **不得替代当事人选择诉讼路径**
- ❌ **不得偏向一方**
- ❌ **不得代行律师职能**
- ❌ **不得越界释明**
- ✅ **可弥补主张不明确、不充分、不适当**
- ✅ **可公开心证**
- ✅ **可开示法律观点**
- ✅ **可指导举证**

**深度参考**：`references/法官释明操作指引.md`（含典型案例、话术模板、记录要求）

**退出条件**：所有释明均有记录+价值判断有充分说理

## 四、常见释明话术模板

### 4.1 请求不明确

> "请明确你的诉讼请求，包括每一项请求的具体金额或内容。"

### 4.2 基础规范不明确

> "请说明你方主张的请求权基础是哪个法律条文，及其与你的请求的对应关系。"

### 4.3 主张不充分

> "你方主张的违约事实，具体包括哪些行为？请你方详细说明。"

### 4.4 举证指导

> "你方主张被告欠款，但目前未提交交付凭证。你方有无相关证据需要补充提交？"

### 4.5 主张变更

> "本院/本庭注意到，你方主张的金额与合同约定不一致。你方是否考虑变更诉讼请求？"

### 4.6 心证公开

> "从目前庭审情况看，本院/本庭对原告主张的交付事实存在疑问。原告对此有何补充？"

### 4.7 法律观点开示

> "本院/本庭注意到，本案可能涉及合同效力问题。当事人对合同效力问题有何意见？"

### 4.8 调解引导

> "本院/本庭认为，本案存在调解基础。当事人有无调解意向？"

## 五、释明的记录要求

释明必须记录在案，**载明**：
- 释明的时间点（庭前/庭中/庭后）
- 释明的具体内容
- 释明针对的对象（原告/被告/第三人）
- 当事人的回应
- 当事人有无申请休庭/补充

**记录形式**：
- 庭审笔录中详细记载
- 复杂释明可单独制作"释明笔录"
- 合议庭/仲裁庭评议时可参考释明记录

## 六、典型释明边界案例

### 6.1 不得越界释明

**错误案例**：裁判者主动告知原告"你可以变更请求为合同无效后的折价补偿"
**正确做法**：裁判者只能释明"你方请求的合同继续履行可能与合同效力存在冲突"，由原告自行决定是否变更

### 6.2 不得偏向一方

**错误案例**：裁判者多次打断被告的陈述
**正确做法**：裁判者应平等对待双方当事人

### 6.3 不得代行律师职能

**错误案例**：裁判者主动为原告起草代理意见
**正确做法**：裁判者只能引导原告陈述，由律师代为表达

## 七、五个阶段的内在关系

```
Phase A（庭前准备）────┐
                       │
Phase B（庭审驾驭）────┤
                       ├→ 全流程闭环
Phase C（心证形成）────┤
                       │
Phase D（裁判文书）────┤
                       │
Phase E（释明与价值观）─┘（贯穿全流程）
```

**Phase E 贯穿**：释明权与价值判断不是独立阶段，而是贯穿庭前、庭中、庭后全过程。

## 八、与律师版技能的分工

| 维度 | 律师版（lawyer-case-strategist） | 裁判者版（本技能） |
|---|---|---|
| 视角 | 攻防策略/代理方案 | 审判思路/庭审管理 |
| 核心问题 | "怎么赢" | "怎么审" |
| 释明 | 如何利用法官释明信号 | 如何正确行使释明权 |
| 文书 | 核验起诉状/代理词质量 | 核验裁判文书质量 |
| 释明边界 | 提示法官未释明可能上诉 | 不得替代当事人选择诉讼路径、不得偏向一方 |
| 价值观 | 最大化当事人利益 | 居中裁判 |
| 庭审 | 攻防预演 | 驾驭管理 |

## 九、给使用者的提醒

1. **形式理性优先**：法律有明确规定时严格适用，慎用实质理性
2. **释明有边界**：不得越界、不得偏向、不得代行
3. **心证要公开**：适时公开心证，给当事人辩论机会
4. **八个一致是底线**：裁判文书/仲裁裁决书必须逻辑自洽
5. **价值判断需说理**：任何价值判断都要有充分说理
6. **全流程思维**：庭前、庭中、庭后是不可分割的整体
7. **不偏不倚**：裁判者的职责是居中裁判，不是任何一方的代言人
