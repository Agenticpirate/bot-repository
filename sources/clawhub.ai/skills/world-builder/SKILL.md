# 世界建造器

## 定位

本技能是**元技能系统（meta-skill-system）的下级母技能**，专门负责从任意世界概念出发，系统化填充12个正交维度，生成完整的世界Skill文件。

**与元技能系统（meta-skill-system）的关系**：本技能消费元技能系统的三轴执行框架（6大元操作、R1-R5校准、管线编排），将12维世界分类体系转化为可执行的世界生成管线。两者的分工边界：**元技能系统做事，世界建造器造世界**。元技能系统去除的是"因为人的局限而产生的补偿性工作流角色"，世界建造器创建的是"有内在一致性的独立世界"——去角色化消除的是工作流冗余，世界构建保留的是世界完整，互不冲突。

**为什么需要12维完整世界**：一个可信的世界不是"有山有水有国家"的标签堆砌——真正让读者/玩家/创作者沉浸的世界，是空间、时间、法则、生命、物质、技术、文化、政治、经济、认知、审美、动态这12个维度相互咬合、自洽运行的有机整体。本技能的价值在于生成**有持续内在逻辑的自洽世界体**——因为经济维度驱动政治维度、法则维度约束技术维度、认知维度解释文化维度……这些"跨维咬合"恰恰是产生不可替代的沉浸感的来源。本技能也是元技能系统M3领域负载物生成能力的一个核心验证：M3流程可以生成知识密集型、高创造性、高迭代性的复杂领域负载。

**核心理念**：世界 = 实体层坐标 × 社会层坐标 × 抽象层坐标。一个完整的世界不是"一个设定"，而是12个正交维度上各取一个值的乘积——且维间存在严谨的逻辑咬合关系。本技能确保每个维度都被系统性填充，维度间的约束和推导关系被完整维护。

## 双模式架构

本技能支持两种输入模式，由W0域的输入模式检测（wb-03）自动判定路由：

### Mode A：独立生成模式（Independent Generation）
- **输入**: 用户对世界的自然语言描述（"赛博朋克东京"、"中世纪魔法大陆"）
- **处理**: 按12维模型从零填充，维度间通过逻辑推导和咬合校验确保一致性
- **输出**: 独立完整的世界Skill文件
- **适用场景**: 先有世界后有角色、世界观先行设计、TRPG战役设计

### Mode B：角色提取模式（Character Extraction）
- **输入**: 多个Character Builder生成的角色Skill文件
- **处理**: 从N个角色的文化维(维6)、认知维(维10)、政治/经济/技术维度中提取交集，构建共享世界层；对冲突维度进行协调或标注为"地域差异"
- **输出**: 从角色数据中提取的共享世界层 + 各角色在世界中的位置映射
- **适用场景**: 先有角色后有世界、从多个独立角色反推共享世界观

### 路由逻辑
1. 检测输入是否包含角色Skill文件引用（路径包含`character-`或`.workbuddy/skills/`目录特征）
2. 包含 → Mode B，加载所有角色Skill，提取共享维度
3. 不包含 → Mode A，按标准12维流程独立生成
4. 混合输入（既有世界描述又有角色引用）→ Mode A为主，用角色数据校准和补充特定维度

### 双模式不互斥
Mode A生成的世界可以作为后续角色生成的约束注入（参见"与Character Builder的接口"）。Mode B提取的世界可以与Mode A生成的世界合并——角色提取的共享层提供了"已有的确定性"，独立生成填补了"未覆盖的空白维度"。

### 与Character Builder的分工
单角色用Character Builder就够了——它的文化维(维6)和认知维(维10)已包含完整的世界信息。当你拥有≥2个角色需要共享同一个世界（抽取文化交集、协调地域差异、统一世界观约束）时，才需要本技能提取或构建统一世界层。本技能是跨角色协调器，不是替代品。

## 世界12维模型

```
第一层：实体层——世界的物理基底，不可再分的物质基础
  维1 空间维：世界的地理与空间结构（地形/气候/天文/区域划分）
  维2 时间维：世界的历史与时间结构（纪元/朝代/关键事件/编年体系）
  维3 法则维：世界运行的底层规律（物理法则/魔法体系/自然规律/常数设定）
  维4 生命维：世界中的生命形态（物种/生态/进化路径/生物圈结构）
  维5 物质维：世界中的物质与资源（元素/矿产/能源/材料/物质分类）
  维6 技术维：世界中的技术体系（技术等级/核心发明/工具链/技术传播）

第二层：社会层——智慧生命如何组织与互动
  维7 文化维：世界中的文化形态（社会/语言/习俗/仪式/价值观/禁忌）
  维8 政治维：世界中的权力结构（政体/派系/领土/统治方式/法律）
  维9 经济维：世界中的资源流动（贸易/货币/生产/分配/阶层分化）

第三层：抽象层——超越物质存在的普遍刻画
  维10 认知维：世界中的知识体系（信仰/科学/教育/认知范式/信息传播）
  维11 审美维：世界中的美学标准（艺术/建筑/音乐/服饰/审美理念）
  维12 动态维：世界的变化规律（循环/熵增/冲突模式/演变趋势/未来轨迹）
```

## 核心能力

### 世界需求解析
从用户输入中提取世界概念的初始线索，判断哪些维度已有隐含信息、哪些需要主动询问、哪些可以自动推导。包括世界类型判断（架空/改编/混合/未来/历史）、已知维度提取、缺失维度识别、用户意图解析。

### 12维系统填充
按三层结构（实体层→社会层→抽象层）逐层填充每个维度，确保维度间的咬合一致性。实体层三域（空间时间/法则生命/物质技术）可并行填充，社会层依赖实体层，抽象层依赖社会层。每维填充后立即执行域内校验和跨域咬合检查。

### 世界Skill组装与输出
将填充完成的12维世界数据组装为标准的世界Skill文件，包含SKILL.md + references/的完整三层结构，内嵌元技能系统的Step 0-4可执行框架。

## 三层结构

```
第一层：世界技能清单 + 依赖拓扑   →  references/world-catalog.md
第二层：世界方法论要求清单        →  references/world-requirements.md
第三层：世界范本库              →  references/exemplars.md
```

## 使用规则

### 执行流程
1. **首次加载**：读取 `references/world-catalog.md`，获取域分类、依赖拓扑、元操作映射提示
2. **按需深入**：确认目标世界生成任务后，读取 `references/world-requirements.md` 获取各维度的填充槽位和约束
3. **独立执行**：本技能仅依赖元技能系统的执行框架，不依赖其他领域技能

### 事实纪律
1. 世界的地理/物理等事实性设定需基于可验证的科学知识，编造时标注"架空设定"
2. 法则维度中的物理/魔法体系必须自洽——同一世界内不允许矛盾的底层规则
3. 跨维咬合必须可推导——每个跨维关系都需标注推导链（如：物质维的铁矿贫乏→技术维的青铜技术路径→经济维的无铁币经济→政治维的青铜资源垄断政体）
4. 12维之间不得有逻辑冲突（如：冰河期气候设定与热带雨林生态共存于同一地理区域，除非有法则维特殊设定解释）
5. 维度不可跳过——空缺维度必须标注"未定义"并说明原因
6. 世界Skill输出格式必须符合元技能系统接口规范

### 扩展能力
7. **提示词导出**：可将本技能的SKILL.md与references目录下所有文件内容合并为单一提示词文件，用于不支持skill目录格式的工具
8. **部分生成**：可指定单个域或维度单独生成（如：仅生成法则维度作为魔法系统设计参考）

## 执行框架

本技能消费以下元技能系统组件：

- **三轴判定（M4-09）**：判定世界生成请求的复杂度、内容类型、创新需求
- **领域校准（M4-10）**：R1信息密度→世界设定的知识密度和自洽性要求，R2创造性→世界的新颖度和原创性，R3交互性→用户参与设计的深度，R4规范性→内部逻辑一致性的严格度，R5迭代性→世界修订的轮次和粒度
- **6大元操作**：S感知=搜索世界构建相关知识（地理/历史/物理/文化人类学），C认知=分析维度间的咬合关系和一致性，A行动=填充维度具体内容，O组织=组装世界Skill文件，I交互=用户确认关键设定和创意方向，G守护=12维完整性校验和跨维冲突检测
- **管线编排（M4-07/M4-08）**：实体层三域（W1/W2/W3）可并行填充，社会层（W4）依赖实体层，抽象层（W5/W6）依赖社会层

| 域 | 任务数 | 典型任务 |

| W4 社会层域 | 4 | 文化填充（社会/语言/习俗）、政治填充（政体/派系/领土）、经济填充（贸易/货币/生产）、社会层校验 |

## 与执行框架的接口

### Step 0 三轴判定
世界生成任务默认为：复杂度=高（24个任务、12维交叉咬合）、内容类型=结构化（12维框架）、创新需求=通常需要创新。

世界类型的复杂度调整：
- **架空世界**（完全原创）：复杂度=高、创新需求=高
- **改编世界**（基于已有的改进）：复杂度=中、创新需求=中
- **混合世界**（缝合多个世界观）：复杂度=高、创新需求=中
- **未来世界**（基于现实的推演）：复杂度=中、创新需求=高
- **历史世界**（基于真实历史）：复杂度=低、创新需求=低

### Step 1 领域校准
基于世界类型推导R1-R5参数：

- **架空世界**：R1中/R2高/R3中/R4高/R5高 → A和G权重高，管线中G密集（维护自洽性）
- **改编世界**：R1中/R2低/R3高/R4高/R5中 → C和I权重高（理解原设+用户确认）
- **混合世界**：R1高/R2中/R3中/R4高/R5中 → S和G权重高（多源整合+冲突检测）
- **未来世界**：R1高/R2高/R3中/R4中/R5中 → S和A权重高（基于事实推演+创新延伸）
- **历史世界**：R1高/R2低/R3低/R4高/R5低 → S和G权重高（事实准确+严格遵守历史约束）

### Step 2-4 管线编排与执行
实体层三域(W1/W2/W3)可并行填充，社会层(W4)需实体层完成后执行，抽象层(W5/W6)可并行填充，最后W7整合校验。跨维咬合检查发生于每个域的校验任务中（wb-12/22/32/43/51/62），最终12维完整性校验(wb-70)汇聚所有校验结果。

## 降级模式

当依赖的外部能力不可用时，按以下降级策略执行：

| 缺失能力 | 降级模式 | 影响范围 | 说明 |
|---------|---------|---------|------|
| 网络搜索（地理/物理/历史验证） | 基于内置知识填充科学事实，标注"未网络验证" | wb-10, wb-11, wb-20, wb-30 | 科学数据可能过时或不精确 |
| 网络搜索（文化人类学参考） | 基于内置知识填充文化设定，标注"未网络验证" | wb-40, wb-41, wb-50 | 文化细节可能不够准确 |
| 用户不可交互 | 以默认值和推导值填充待确认维度，标注"待用户确认" | wb-01, wb-10, wb-11, wb-20, wb-21, wb-40, wb-41, wb-42, wb-50, wb-60, wb-61 | 世界关键创意决策需后续人工审核 |
| 文件系统不可写 | 仅输出世界数据报告（Markdown），不生成Skill文件 | wb-71, wb-72 | 世界完整但不持久化 |
| 完全只读模式 | 仅执行世界需求解析(wb-03→wb-00→wb-01→wb-02)和分析，不填充不生成 | 全部域 | 输出世界生成计划而非成品 |
| 角色Skill文件不可用（Mode B） | 回退到Mode A独立生成模式，向用户提示Mode B所需角色文件不可用并询问是否继续Mode A | W8全域 + wb-03路由 | Mode B管线完全不可执行，自动降级为Mode A |

降级优先级：交互可用性 > 网络可用性 > 文件写入可用性。降级时在输出中明确标注当前模式和降级原因。

## 事实纪律

1. **空间设定**：地理结构（大陆分布/地形/气候带）需遵循地球科学原理，架空时标注偏离点和偏离理由
2. **历史设定**：时间线中的事件因果关系必须自洽，不允许"为剧情服务"的逻辑断裂
3. **物理法则**：一个世界内物理常数不可矛盾——若设定"重力为地球的一半"，则所有相关的建筑/生物/运动设定必须一致推导
4. **魔法体系**：魔法作为法则维的特殊设定，需定义能量来源/使用规则/代价/限制，不可"万能魔法解决一切"
5. **物种演化**：智慧物种和非智慧物种的演化路径需合理，不可"凭空出现全能物种"
6. **资源约束**：物质维的资源分布必须与空间维的地理结构一致，不可"沙漠地区盛产鱼类"
7. **技术传播**：技术的分布和掌握程度必须与政治维的权力结构和经济维的贸易路径一致
8. **文化自洽**：同一文化内的习俗/语言/价值观/禁忌必须形成自洽体系，不可"儒家礼教+北欧海盗价值观"无解释混合
9. **权力逻辑**：政治维的政体/派系/领土关系必须可还原为经济维的资源争夺或文化维的价值冲突
10. **认知局限**：认知维的知识体系必须与技术维和法则维一致——不能"火药时代的世界拥有量子力学认知"
11. **美学统一**：审美维的艺术/建筑风格必须与文化维和物质维的资源条件一致
12. **动态演化**：动态维的变化方向必须能从前11维的设定中推导出来——世界的未来不是凭空设定的，是各维度力量博弈的自然结果
