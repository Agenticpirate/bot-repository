# opinion-to-article

把"你想表达的一个想法"变成一篇有你自己标识的文章或脚本。

AI 是搜索员、结构师、编辑，不是代笔。观点是你的，素材是真的，结构是逻辑的，标识是你自己长出来的。

## 五步流程

### Step 1 观点提炼（靶心）

用户说出原始想法，一段话或几句碎话都行。AI 提炼三样：

```
核心判断：____（一句话，可证伪，有立场）
目标读者：____（谁会关心这件事）
理由（用户原话要点）：
1. ____
2. ____
```

与用户确认靶心，偏了就修正，不确认不进入下一步。

### Step 2 IP 标识识别（表达偏好卡）

从用户原始表达里提取，不猜不编：

- 身份视角：我是谁，职业、经历、立场
- 语言习惯：比喻类型、句式长短、口头禅式表达
- 态度边界：什么会骂，什么会夸，什么保持怀疑

沉淀为表达偏好卡。用户对草稿的每轮反馈也回灌这张卡。文章的"独特标识"从这里来。

```
表达偏好卡
身份视角：____
语言习惯：____
态度边界：____
金句偏好：____
反馈记录：____
```

### Step 3 联网拓展（素材库）

围绕观点联网搜索四类素材：

1. 支持性证据：案例、报告、人物故事
2. 反驳观点：对立面，制造冲突张力
3. 硬数据：数字冲击，能具体不模糊
4. 场景引子：故事感细节，可做开场

每条素材标注：内容 + 来源 + 用途。搜不到的关键信息标"待核实"，禁止编造。

### Step 4 逻辑重组（结构）

文章模板，五到七层按需取舍，单线推进不绕回：

- 立冲击：开场场景、数据或冲突，三到五行
- 立本质：第一性原理拆解，这件事的底层是什么
- 立机制：为什么是这样，机制、链条、因果
- 立边界：不是什么，什么情况下不成立
- 立解法：怎么办，可执行的方向
- 立落点：个人案例或呼应开场
- 收尾：判断句收束，给读者可带走的判断工具

短视频脚本模板：

- 钩子句：前三秒，反常识、冲突或身份符号
- 观点陈述：你的核心判断
- 案例与数据：两到三个，有来源
- 金句：可截图传播的一句话
- CTA：关注理由，利他、表达代理或社交货币

每层绑定 Step 3 的对应素材，标注用途。

### Step 5 反馈迭代成稿

用户看草稿给反馈：想突出什么，想怎么表达，哪里不对。反馈回灌表达偏好卡。迭代两到三轮出终稿。

输出两种格式任选：文章 markdown，或短视频脚本。

## 素材纪律

- 联网素材全量可用，禁止省略关键数据和做法
- 数字必须有来源
- 搜不到标"待核实"，不编造
- 用户提供的个人经历优先于公开信息，公开数据用于正文

## 输出示例

文章示例：

```
# 标题（用户选定或推荐候选）

开场（立冲击，三到五行，自己的场景）
...
## 小标题（叙事式，非概念式）
...
收尾：判断句
```

脚本示例：

```
【钩子】____
【观点】____
【案例1】____（来源）
【案例2】____（来源）
【金句】____
【CTA】____
```

## Pitfalls

- 不要替用户下判断：观点是用户的，AI 只拓展和重组
- 不要贴标签式金句：金句从用户的表达和场景里长出
- 不要省略素材：数据、案例、来源要全
- 不要用 AI 腔：短句、口语、一句一段，禁分号、破折号、书名号
- 不要概念框架先行：结构从素材和场景里长出来，不是先搭框架再填内容
