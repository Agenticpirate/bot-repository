# 牛股王正宗产业库skill (authentic-industry-library)

由牛股王(niuguwang.com)研发的A股正宗产业库，收录全量题材数据，展示题材整体表现与产业链上中下游拆解，辅助投资者研判题材强弱与产业链投资机会。

## 核心价值（牛股王独家数据）

1. 历史题材全景数据库：基于牛股王正宗题材库，收录历史上所有题材的完整数据，展示每个题材的最新价、涨幅、涨停个数、上涨个数等整体表现，一眼看清哪些题材当前活跃、哪些题材沉寂。
2. 产业链上中下游拆解：将每个题材/行业拆解为上游、中游、下游，展示产业链各环节的相关股票和涨跌幅表现，帮助用户理解产业链传导逻辑，发现产业链中的投资机会。
3. 题材强弱一目了然：通过涨停个数、上涨个数、下跌个数等数据，快速判断某个题材当前的市场热度和赚钱效应，识别强势题材和弱势题材。
4. 题材轮动追踪：对比不同题材的历史表现和当前状态，发现题材轮动规律，判断哪些题材可能进入新一轮炒作周期。

## 适用场景

- 查询某个历史题材的当前整体表现和活跃度
- 了解某个题材/行业的产业链结构和上中下游相关股票
- 对比不同题材的强弱表现，寻找当前最强势的题材方向
- 研究题材轮动规律，发现可能启动的沉寂题材

## 使用方式

1. 无需apikey，直接调用公开接口
2. 使用GET请求如下两个接口
3. 编写调用方式脚本

### 接口1：正宗产业库板块列表
获取所有题材/行业板块的整体表现数据，按涨停个数排序，快速定位当前最强势的板块方向。
```bash
curl -X GET --location 'http://apicore.niuguwang.com/askstock/IndustryChain/GetIndustryChainPlates'
```

### 接口2：指定板块产业链个股列表
根据板块innerCode获取该板块的产业链上中下游拆解及各环节相关股票。`plateInnerCode`参数从接口1返回的`innerCode`字段获取。
```bash
curl -X GET --location 'http://apicore.niuguwang.com/askstock/IndustryChain/GetIndustryChainStks?plateInnerCode=2000047'
```

## 返回说明

### 板块列表 (GetIndustryChainPlates)

|字段路径|简短释义|
|----|----|
|`data.plateList[]`|题材/行业板块列表|
|`data.plateList[].plateName`|板块名称（如"钢铁"、"电池"、"IT服务"）|
|`data.plateList[].plateCode`|板块代码（如"880013"）|
|`data.plateList[].innerCode`|板块内码，用于查询接口2的`plateInnerCode`参数|
|`data.plateList[].updownRate`|板块涨跌幅字符串（如"+2.13%"）|
|`data.plateList[].upLimit`|涨停个数（如4），衡量板块短线爆发力|
|`data.plateList[].downLimit`|跌停个数|
|`data.plateList[].up`|上涨个数（如42），衡量板块赚钱效应|
|`data.plateList[].down`|下跌个数（如1）|
|`data.plateList[].nowvStr`|板块最新指数价格|
|`data.plateList[].plateType`|板块类型（1=行业，3=地域，4=概念）|

### 产业链个股列表 (GetIndustryChainStks)

|字段路径|简短释义|
|----|----|
|`data.high[]`|上游环节股票列表|
|`data.middle[]`|中游环节股票列表|
|`data.low[]`|下游环节股票列表|
|`[].stockCode`|股票代码（如"600350"）|
|`[].stockName`|股票名称（如"山东高速"）|
|`[].nowvStr`|现价带符号字符串（如"+10.14"）|
|`[].updownRate`|涨跌幅字符串（如"+0.40%"）|
|`[].detail`|具体分工描述，说明该股在产业链中的角色和业务定位|
