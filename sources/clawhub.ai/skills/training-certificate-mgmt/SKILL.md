# 技能证书管理

> 输出为参考建议，最终证书发放与作废等操作由主理人审核确认后执行。

## 能力概述

培训证书全生命周期管理，覆盖证书从设计到销毁的完整闭环：

| 模块 | 核心内容 |
|------|---------|
| 证书模板设计 | 模板样式配置（背景/边框/水印/Logo）、字段布局、自定义样式库 |
| 证书生成 | 自动编号规则、学员信息填充、培训内容嵌入、成绩/等级标注 |
| 证书发放 | 发放记录登记、电子证书分发、签收确认管理、快递单号跟踪 |
| 证书查询验证 | 二维码扫码验证、编号在线查询、真伪核验、验证页面生成 |
| 证书续期升级 | 有效期管理、续期提醒、升级条件判定、新证书关联旧证书 |
| 证书作废补办 | 作废原因登记、证书状态标记、补办申请审批、新证书换发 |

## 输入

- **证书模板配置**：背景图、字体、颜色、字段占位符等设计参数
- **学员信息数据**：姓名、身份证号/学号、培训期次、课程成绩等
- **培训记录**：培训名称、日期、课时、成绩评定标准
- **操作指令**：生成/发放/续期/作废/补办等操作请求

## 输出

### 证书要素清单

```
【证书编号】TRAIN-2025-0001
【学员姓名】张三
【培训名称】第X期XXX研修班
【培训日期】YYYY年MM月DD日 - DD日（共X天）
【培训课时】XX学时
【考核成绩】优秀/良好/合格/不合格
【发证日期】YYYY年MM月DD日
【有效期至】YYYY年MM月DD日（如适用）
【证书状态】有效/待领取/已作废/已过期
```

### 证书状态流转

```
[设计模板] → [生成证书(编号)] → [发放签收] → [有效期跟踪] → [续期/升级] → [作废/补办]
```

## 工作流程

1. **模板设计与配置**：根据证书类型选择或设计模板，配置字段占位符
2. **证书批量生成**：导入学员数据，自动生成证书编号与内容，批量渲染
3. **发放签收管理**：电子证书分发（邮件/系统），纸质证书寄送跟踪，签收确认
4. **查询验证服务**：生成验证二维码/链接，提供编号+姓名双因子查询
5. **续期升级管理**：到期前自动提醒，根据条件判断续期/升级，生成关联证书
6. **作废与补办**：登记作废原因并更新状态，补办审批后生成新证书并关联旧编号

## 数据模型（证书记录）

每条证书记录包含：
- `id`：证书唯一编号（自动生成）
- `template_id`：使用的模板ID
- `trainee_name`：学员姓名
- `trainee_id`：学员身份证号/学号
- `training_name`：培训名称
- `training_date_start`：培训开始日期
- `training_date_end`：培训结束日期
- `hours`：培训课时
- `score`：考核成绩/等级
- `issued_date`：发证日期
- `expiry_date`：有效期截止日期（如有）
- `status`：待生成/待发放/已发放/已签收/已续期/已升级/已作废/已过期
- `verify_code`：验证二维码/验证码
- `parent_cert_id`：续期/补办时关联的原证书ID
- `revoke_reason`：作废原因
- `delivery_tracking`：快递单号/发送记录
- `signoff_date`：学员签收确认日期
