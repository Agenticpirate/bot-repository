# 质量知识竞赛技能

## 0. 能力说明与边界（调用前必读）

**本技能能做什么**
- 为**质量月知识竞赛**、新员工质量培训、班组日常质量考核，快速产出一套**可直接落地的竞赛包**：题库 + 试卷 + 答案解析 + 竞赛方案 + 成绩统计模板。
- **直接生成通用质量知识题库**：Agent 基于客观质量知识（ISO 9001/IATF 16949 条款、QC 七大手法、计量/SPC/MSA、FMEA/8D/APQP、质量意识等）生成题目，每题含**题干 / 选项 / 正确答案 / 解析 / 知识点 / 难度 / 分值**。
- **组卷与赛制方案**：从题库抽卷，设计赛制（个人抢答 / 团体 PK）、计分规则、流程时间表。
- **成绩统计与评优**：评分排名表、错题知识点分析（可联动培训与总结）。
- 输出**双版本**：结构化 Markdown + 精美网页版 HTML（竞赛方案报告）。

**本技能不能做什么**
1. 不臆造**企业专属知识**——涉及企业内部标准编号、专属工艺参数、自家产品/流程细节的题目，必须由你提供素材，Agent 只标「待企业补充」占位，绝不编造具体数值/条款号。
2. 不替你拍板**竞赛定位**——用途、参赛对象、知识范围、难度配比、赛制由你决定，Agent 给维度、选项与建议，不替你下结论。
3. 不编造**成绩数据**——成绩统计模板中的实际得分、参赛人数由你填报，Agent 不臆造。
4. 不保证题目**绝对无误**——通用质量知识题由 Agent 生成，交付前你需按企业适用的标准版本抽检校对（不同标准年版条款可能有差异，Agent 会提示核对点）。

**领域说明**：质量知识竞赛的"知识域"锁定质量管理，但**竞赛/答题组织方法论是通用的**——同一套框架可迁移到安全知识竞赛、法规知识竞赛等，只需替换知识域与题库。Agent 生成通用质量题为主，不强行做成通用出题器。

## 1. 调用前置：我需要的信息

| 信息 | 必填 | 说明 |
|------|------|------|
| 竞赛/活动名称 | 是 | 如"2026 质量月知识竞赛"，用于抬头 |
| 用途场景 | 是 | 质量月竞赛 / 新员工培训 / 日常考核（影响难度与题型） |
| 参赛对象 | 是 | 如"全体一线员工""质量工程师"，影响难度基线 |
| 知识范围 | 是（可引导选） | 勾选知识域：ISO9001/IATF/QC七大手法/计量SPC/FMEA8D/质量意识/企业专属等 |
| 题量与题型配比 | 否 | 如"单选20+多选10+判断10+简答5"；缺失则 Agent 给推荐配比 |
| 难度配比 | 否 | 易/中/难占比；缺失则默认 5:3:2 并提示 |
| 赛制 | 否 | 个人抢答 / 团体 PK；缺失则 Agent 给选项 |
| 企业专属素材 | 否 | 内部标准、专属工艺、典型质量案例；缺失则相关题标「待企业补充」 |

### 1.1 输入载体判断（规则 2）
- **纯文字描述**（如"办个质量月竞赛，一线员工，考 ISO 和 QC 手法"）：直接进入交互定位 + 生成题库，无需脚本解析。
- **文档/表格**（往届题库 Excel、企业标准 Word/PDF）：Agent 显式说明将调用文档处理技能（xlsx/docx/pdf/markitdown）抽取素材后再出题，不静默处理。
- **生成产出**：调用 `scripts/build_report.py`，将结构化题库 JSON 渲染为 竞赛方案 MD + HTML。

## 2. 交互定位 + 生成流程（生成为主，轻交互定制）

> 本技能**不套纯引导式**：题库这类客观质量知识，Agent 直接生成才是核心价值，不逼你自己写题。交互只用于**定范围、定难度、补企业专属内容**三处。

| 阶段 | 谁主导 | 内容 | 交互锁 |
|------|--------|------|--------|
| ① 竞赛定位与范围 | **交互** | 确认用途/对象/知识范围/题型题量/难度/赛制 | 用途、知识范围、参赛对象必须你确认，Agent 不替定 |
| ② 题库生成 | **Agent 生成** | 按范围生成题目（题干/选项/答案/解析/知识点/难度/分值） | **企业专属题**标「待企业补充」，Agent 不编内部数据 |
| ③ 组卷 + 赛制方案 | 生成 + 轻交互 | 抽卷、赛制规则、计分规则、流程时间表 | 赛制与计分口径由你确认 |
| ④ 成绩统计与评优 | 生成模板 | 评分排名表、错题知识点分析框架 | 实际成绩数据由你填报，Agent 不臆造 |

**关键纪律**
- **通用质量题**：Agent 生成后主动提示"请按你企业适用的标准版本抽检"，标注可能的核对点（如条款号随标准年版变化）。
- **企业专属题**：涉及内部标准号/工艺参数/自家案例，一律标 **「待企业补充」**，给出题目框架但不填具体数值。
- **难度自评**：每题标易/中/难，便于你按参赛对象调整。

## 3. 输出形式（规则 4：先大纲后文档）

范围与配比确认后，**先展示题库结构与竞赛方案大纲**确认，再生成正式产出：

- `质量知识竞赛_题库.md`（全题库，含答案+解析+知识点+难度）
- `质量知识竞赛_试卷.md` / `_答案解析.md`（抽卷后的试卷与答案卷）
- `质量知识竞赛_方案.html` / `.md`（精美竞赛方案报告：定位、赛制、流程、评分、题量分布）
- `质量知识竞赛_成绩统计.md`（评分排名 + 错题分析模板）

**竞赛方案大纲（章节结构）**
1. 封面与元信息（名称/用途/对象/知识范围/题量/赛制/时间）
2. 一、竞赛定位与规则（目的、参赛对象、赛制、计分、奖项）
3. 二、题库结构（知识域分布、题型分布、难度分布图）
4. 三、试卷示例（抽卷样卷 + 答案解析）
5. 四、流程与时间安排
6. 五、成绩统计与评优（排名表、错题知识点分析）
7. 六、待企业补充项（汇总所有专属占位内容）

> 大纲确认后 Agent 才生成正文；你也可只先要题库、或只先要竞赛方案。

## 5. 相关技能联动（质量活动线）

- **上游入口**：`quality-month`（质量月活动策划）—— 质量月"知识竞赛"活动的执行落地由本技能承接；quality-month 输出竞赛活动条目 → 本技能出题库+方案。
- **并行活动线（培训）** → `quality-training-planner`（质量培训策划技能）：质量月常"培训+竞赛"并行，培训策划落地由该技能承接；竞赛可用来巩固培训知识点。
- **成绩沉淀** → `质量月报/工作周报` 技能（竞赛参与率、平均分等纳入月报）。
- **错题知识点培训** → `QC七大手法`、`8D` 等方法论技能（针对高错知识点补训）。
- **与体系技能关系**：本技能只做"知识竞赛/答题"落地，不做体系审核、不做统计分析；题目涉及体系深水区时引对应技能，不重复实现。
- **关系说明**：这是"活动执行层"工具，与战略工具链（规划层）互补，与 quality-month 是"活动策划 → 单项活动落地"的上下游。
