# 研策 · 综合投研报告生成 (yance-report-gen)
> **⚠️ 数据来源与限制（重要披露）：**
> 本Skill的合成报告内容**由各角色分析JSON输入驱动**（研木/研林/研技/研声/研盾）；当输入JSON缺失或字段不全时，相应板块输出模板占位并标注「未提供数据（教学演示）」。
> 报告仅用于课程教学演示，不构成投资建议。



## 功能
1. **多观点汇总** — 接收各角色分析输出，归并为统一格式
2. **冲突检测** — 自动识别各角色输出中的矛盾观点
3. **结论归一化** — 按规则处理冲突，归一为统一结论
4. **报告生成** — 按券商级模板生成完整自选股投研报告

## 输入依赖
必须提供以下角色输出（至少4个）：
1. `yanmu` — 基本面分析结果
2. `yanlin` — 产业策略分析结果
3. `yanji` — 技术面分析结果
4. `yansheng` — 舆情分析结果
5. `yandun` — 风控评估结果

## 处理流程
```
各角色JSON输出 ──→ 格式归一 ──→ 冲突检测 ──→ 结论归一 ──→ 报告合成
                                              ↓
                                      冲突处理策略：基本面>产业>技术>舆情
```

## 报告结构
| 板块 | 内容 | 来源角色 |
|------|------|---------|
| 一、投研观点综述 | 团长综合评判 | 研家团 |
| 二、基本面深度分析 | 财务/估值/成长性 | 研木 |
| 三、产业与宏观背景 | 产业趋势/宏观环境 | 研林 |
| 四、技术面研判 | 趋势/指标/形态 | 研技 |
| 五、舆情与市场情绪 | 新闻/资金/情绪 | 研声 |
| 六、风险评估与仓位建议 | 风险评级/止损 | 研盾 |
| 七、综合评级与操作建议 | 归一化结论 | 研策合成 |

## 调用方式
```bash
python3 {baseDir}/scripts/generate_report.py \
  --yanmu-report <yanmu_output.json> \
  --yanlin-report <yanlin_output.json> \
  --yanji-report <yanji_output.json> \
  --yansheng-report <yansheng_output.json> \
  --yandun-report <yandun_output.json> \
  --output <output_dir> \
  --stocks "sh600519,sz300750"
```

## 输出
- 文件：`研家团投研报告_YYYY-MM-DD.md`
- 存放路径：`{output_dir}/`
