# 网瘾中年公众号封面设计 Skill

流程：读文章内容 → 三轮提问 → 读取对应风格模板与 VI 规范 → 生成可直接用于生图模型的中文提示词。

**画幅固定为 2.35:1 横版（公众号首图裁切安全区）**，所有提示词第一行必须写「2.35:1 横版构图，公众号封面」。

### 流程输入输出（每阶段明确进出）

| 阶段 | 输入 | 输出 |
|------|------|------|
| 配置检查 | 目录内是否有 `config.md` | 有则读配置进流程；无则先完成首次配置写入 `config.md` |
| 第一轮 | 文章全文 | 推荐 1-2 种风格（各一句理由）+ 1-3 个候选标题（4-10 字），用户选定 |
| 第二轮 | 已定风格 | 参考图清单：图1=IP（默认或上传）、图2 起=素材图（UI 截图/产品图/数据图）|
| 第三轮 | 风格 + 参考图 | 表情/姿态、背景色调、字体、标题色效 四项编号选择，未选默认「交给模型决定」|
| 生成 | 三轮选择结果 | 一段连续中文提示词（首行 2.35:1 + VI 约束 + IP 身形硬约束 + 引号标题）|

## 首次使用：配置检查

每次触发本 skill 时，先检查本 skill 目录下是否存在 `config.md`：

- **存在** → 读取后直接进入正常流程
- **不存在** → 视为首次使用，先完成首次配置，再进入正常流程

### 首次配置（一次问完）

先向用户说明工作方式：本 skill 只产出中文提示词，不直接调用任何模型、不需要 API key；提示词需要用户自己拿去生图模型跑图。然后问两件事：

1. **默认 IP 参考图**：本 skill 已为「网瘾中年」内置品牌机器人 IP。**关键身形约束（绝不可违背）**：圆润、矮胖、Q 版比例——头大（占身高约 1/3）、肚子圆鼓、短手短腿、重心低、憨厚稳重，像不倒翁，绝不是修长/瘦高/成人比例。配色为深海蓝哑光金属机身（Primary-700 `#003A73` 附近），戴蓝色工程安全帽（一条橙色装饰线）、两侧耳机、胸口橙色圆形仪表徽章、青色发光眼屏。默认图存于 `assets/robot-ip-default.png`，每次生成时作为图1参考。如果用户想替换为其他 IP 形象，可上传覆盖该文件；如不使用 IP 出镜，选择「无 IP 出镜」。
2. **常用生图模型**：确认用户使用的生图模型支持**多参考图**输入（图1 IP 形象 + 图2 起素材图），例如即梦/Seedream 4.0、Nano Banana（Gemini 图像模型）、GPT-Image。不支持多参考图的模型无法保持 IP 形象一致性。

问完把结果写入本 skill 目录 `config.md`（已被 .gitignore 排除，不会被提交）：

    # 配置
    - 默认 IP 图：assets/robot-ip-default.png（或：无 IP 出镜 / 每次上传）
    - 生图模型：<模型名>
    - 配置日期：<YYYY-MM-DD>

## 品牌视觉规范（硬约束，所有提示词必须遵守）

生成任何提示词前，先读取 `references/vi-constraints.md`。以下摘要必须时刻牢记：

### 色彩
- 主背景：Primary-900 `#001A33` 或 Primary-700 `#003A73`
- 品牌主色：Primary-500 `#005BAC`
- 强调色：Accent-Orange `#F56C2D`（≤10%）、Accent-Cyan `#00C8FF`（≤8%）
- 深色背景文字：White / `#FFFFFF`
- **严禁**：蓝紫渐变、粉彩色、彩虹多色渐变、高饱和暖黄/金色

### 字体
- 中文标题：**思源黑体 Heavy / Source Han Sans CN Heavy**（或 HarmonyOS Sans SC Heavy）
- 英文/数字：Roboto / Roboto Mono
- **严禁**：宋体、楷体、书法字、毛笔字体、Comic Sans、Papyrus、任何衬线体

### 视觉符号
- 必须保留品牌核心视觉符号：**NVH 频率响应曲线（FRF 波形）**——坐标网格、连续波形、峰值标记点，深蓝底色 + 发光青色曲线
- 可放置于背景、左侧/右侧装饰区、或作为底纹

### 构图
- 比例：**2.35:1 横版**，公众号首图裁切安全区；关键信息（标题、IP 主体）避开画面最左右 10% 边缘
- 画面整体保持「工程图纸 + 冷色科技 + 克制信息密度」的调性

### 禁忌
- 严禁蓝紫渐变、粉彩、卡通萌化、过度美颜摄影、Instagram 暖调生活图、矢量卡通插图（官方 IP 除外）、无来源网络 Logo
- 严禁给 Logo/IP 添加额外发光、阴影、描边效果（原始设计已有层次）
- 严禁将 IP 形象拉伸/旋转/倾斜或改变品牌色

## 提问流程（共三轮，每轮内的问题一次列出）

### 第一轮：风格 + 标题

读完文章后，**先给出推荐**：根据内容推荐 1-2 种风格并各给一句理由，然后列出完整风格表供用户挑选；同时根据文章内容提炼 1-3 个候选标题（4-10 个字）一并给出。用户一次回复选定风格和标题。

| # | 风格 | 适合什么 |
|---|------|---------|
| 1 | 深色工程图纸风 | 背景为 FRF 波形/坐标网格，机器人 IP 居中或侧置，标题巨大压在前方。技术解读、AI 工具硬核文章首选，品牌识别最强 |
| 2 | 极简深蓝留白风 | 大面积 Primary-900 或 Primary-700 底色，标题是唯一主视觉，机器人 IP 小比例出镜或不出镜。克制、高级，适合观点类、长文 |
| 3 | 数据仪表盘风 | 有 UI 截图、软件界面、数据图表时首选。截图占画面 40%-60%，机器人 IP 做指引手势；背景为深色数据网格 |
| 4 | 对比波形风 | 内容涉及前后对比、新旧对比、对错题、案例复盘。画面以两条 FRF 曲线（Before/After）或左右对比卡片构成，IP 居中指明差异 |
| 5 | 机器人侧置留白风 | 机器人 IP 位于画面左侧或右侧 1/3 处，另一侧大面积留白给标题。大气、稳重，适合战略判断、行业观察 |
| 6 | 机器人背影构图风 | 机器人背对镜头，面向远处的工程场景/数据大屏/汽车轮廓。适合启发、反思、趋势预判类内容 |
| 7 | 局部道具风 | 只露出机器人的手、半身或工具局部，产品/截图是绝对主角。适合工具测评、产品开箱、功能拆解 |
| 8 | 机器人正面指引风 | 机器人直视镜头，手势指向标题或关键数据，像工程师在讲解。适合教程、方法论、经验分享 |
| 9 | 信息拼贴风 | 多张小图、截图、图标、曲线拼贴成层次，背景深蓝，IP 压角。适合素材丰富、多案例、多工具盘点 |
| 10 | 工业摄影风 | 背景为经品牌深蓝蒙层处理的工业/汽车/实验室照片，机器人在前景。适合硬核工程、现场检测、NVH 实操 |

### 第二轮：参考图

两个问题一起问（若 `config.md` 已设默认 IP 且 `assets/robot-ip-default.png` 存在，跳过第 1 问，直接说明将使用默认 IP 图做图1）：

1. **图1（IP 形象参考图）**：
   - 有 → 让用户上传，提示词里写「参考图1的机器人 IP 形象：圆润、矮胖、大头大肚子、短手短腿的蓝色机身、蓝色工程安全帽、耳机、胸口橙色仪表徽章；禁止修长、瘦高、纤细四肢、成人比例」
   - 没有 → 使用默认 `assets/robot-ip-default.png`，提示词中描述该 IP 形象的关键特征，并**必须显式写出圆润矮胖身形约束**（见下方「IP 身形硬约束」）
   - 选择「无 IP 出镜」→ 跳过图1，提示词中不出现机器人形象

   **IP 身形硬约束（每次 IP 出镜都必须在提示词里写一遍，防模型生成瘦高机器人）**：
   圆润矮胖、Q 版比例；头大（占身高约 1/3）、圆鼓肚子、短手短腿、重心低、憨厚稳重；绝不要修长、瘦高、纤细四肢、人形成人比例。若模型产出的机器人偏瘦高，必须重生成并在提示词里把这条约束加粗强调。
2. **额外素材（图2、图3…）**：UI 截图、产品图、数据图表、其他参考图
   - 有 → 问有几张、每张是什么内容
   - 没有 → 跳过

### 第三轮：视觉细节

以下四项**一次性列出**，让用户按编号回复（如「2 / 1 / 3 / 2」）；用户没提的项默认「交给模型决定」。按所选风格跳过不适用项：背影构图风、局部道具风可跳过表情；极简留白风默认深背景，背景项可只问具体深蓝色调。

**A. 机器人表情/姿态**（若本轮 IP 出镜）

1. **疲惫加班** — 机器人半眯眼、打哈欠、抱着笔记本电脑，屏幕显示 NVH 波形，旁边有咖啡杯（参考图：assets/robot-expression-overwork.jpg）
2. **摊手疑问** — 机器人双手摊开、头微歪，头顶有问号，表达困惑/反问（参考图：assets/robot-expression-shrug.jpg）
3. **点赞推荐** — 机器人竖起大拇指，眼睛弯成微笑，周围有少量星星/火花点缀（参考图：assets/robot-expression-thumbsup.jpg）
4. **托腮思考** — 机器人单手托下巴，头顶浮现半透明 FRF 波形/数据网格，陷入思考（参考图：assets/robot-expression-thinking.jpg）
5. **标准正面** — 机器人正面站立，表情中性，工程可靠感（参考图：assets/robot-ip-default.png）
6. **交给模型决定**

**B. 背景色调**

1. **Primary-900 深海蓝** — `#001A33`，最深沉的沉浸式工程背景
2. **Primary-700 深蓝** — `#003A73`，常用封面背景，稳重有层次
3. **Primary-500 品牌蓝** — `#005BAC`，较亮，适合需要活力的技术主题
4. **深色工业灰** — 接近 `#1C1C2E` 的冷灰黑，适合工业摄影风
5. **浅灰白工程风** — 白/浅灰 + 蓝色网格线，适合数据仪表盘、对比图
6. **交给模型决定**（默认从品牌蓝深色体系挑选）

**C. 字体风格**

1. **思源黑体 Heavy** — 方正超粗黑体，无衬线，标题占据画面上半或左侧，压迫感强，品牌首选
2. **HarmonyOS Sans SC Heavy** — 华为鸿蒙风格黑体，科技感略强
3. **Roboto Mono + 思源黑体** — 等宽数字 + 黑体标题，适合数据/代码类主题
4. **极简无衬线** — 字重均匀，国际范，适合极简留白风
5. **交给模型决定**（默认思源黑体 Heavy）

**D. 标题颜色/效果**

1. **纯白色** — 深色背景首选，干净清晰
2. ** Accent-Cyan 青色** — `#00C8FF`，用于关键数字或关键词高亮
3. **Accent-Orange 橙色** — `#F56C2D`，用于 CTA 感关键词或警示标签
4. **白色 + 橙色关键词标签** — 主标题白色，重点词用橙色矩形色块反白字
5. **交给模型决定**（默认白字）

## 生成提示词

🔴 CHECKPOINT · 🛑 STOP：三轮问答全部完成后、输出最终提示词之前，必须向用户复述一遍「风格 + 标题 + 参考图清单 + 表情/背景/字体/标题色」四项确认。用户未明确说「可以/生成/就这版」之前，不得输出最终提示词，也不得调用任何生图接口。这一步是防止方向跑偏的最后闸门。

三轮问完后：

1. **读选定风格的模板文件**：`references/style-XX-风格名.md`（XX 为 01-10）
2. **读 `references/examples.md`**，找同风格或构图最接近的成品示例做 few-shot 参照，学习其具体程度
3. **读 `references/vi-constraints.md`**，确保色彩/字体/符号不越界
4. 按模板填空生成提示词

### 核心要求

- **IP 形象具体**：说清楚机器人位置、朝向、手势、表情、身体姿态，不要「机器人做了一个动作」这种模糊描述
- **主体元素详细**：主视觉元素长什么样、上面有什么内容、大小比例、动态或静态
- **空间关系清晰**：前景/中景/后景各是什么，哪个遮挡哪个，文字与 IP 的相对位置
- **品牌和风格统一**：不要把同一套背景/字体套到所有风格上；每种风格有独立的 VI 应用方式
- **标题文字准确**：标题文字在提示词中用引号明确圈出；生成后提醒用户逐字核对画面文字，图片模型常写错中文字，出现错字/多笔少笔就重新生成

### 通用规范

1. **画幅**：固定 2.35:1 横版，提示词第一行必须写「2.35:1 横版构图，公众号封面」
2. **安全区**：标题、IP 主体、关键数字距画面四边至少保留约 10% 边距；公众号信息流裁切时，左右边缘内容可能被裁，核心信息避开左右 10%
3. **中文文字准确**：标题文字用引号明确；生成后提醒用户核对文字
4. **具象隐喻**：抽象概念优先用 FRF 曲线、仪表盘、齿轮、代码、汽车轮廓等工程可识别元素承载
5. **不要廉价特效**：全息投影、彩虹光效、粒子爆炸、霓虹渐变与品牌克制调性冲突；允许的发光元素仅限 FRF 曲线和 Accent-Cyan 数据高亮
6. **正向描述**：只写画面里应该出现什么
7. **参考图指代**：直接写「图1/图2/图3」，不复述图里所有细节
8. **品牌 IP 一致性**：图1 机器人形象参考须保持：圆润蓝色机身、蓝色工程安全帽、耳机、胸口橙色圆形仪表徽章、青色发光眼屏；**身形须为圆润矮胖、大头大肚子、短手短腿的 Q 版比例，禁止修长瘦高、纤细四肢、人形成人比例**（实测：不写这条约束时 Seedream 会生成瘦高机器人，与 IP 参考图差距大）
9. **每种风格有自己的背景与字体逻辑**：深色工程图纸风用 FRF 网格底纹 + 白色标题；极简留白风用大面积纯色 + 思源黑体 Heavy；数据仪表盘风用 UI 截图 + Roboto Mono 数字等

## 失败模式与恢复（if-then）

以下每种失败都有明确的一线修复和兜底，按顺序处理：

| 触发条件 | 一线修复 | 仍失败兜底 |
|----------|----------|------------|
| 生图模型不支持多参考图 | 改用图1 IP 的文字描述直接写进提示词（圆润矮胖身形约束照写），不再传图；或换用支持多参考图的模型（即梦/Seedream 4.0、Nano Banana） | 放弃 IP 出镜，走「无 IP 出镜」分支 |
| 生成的机器人偏瘦高 | 在提示词把「圆润矮胖、大头大肚子、短手短腿、禁止瘦高」加粗强调，并 `--ref assets/robot-ip-default.png` 图生图重生成 | 换模型或改用 IP 文字描述 + 局部重绘 |
| 标题中文写错字/多笔少笔 | 重生成；或在提示词标题处写「请逐字渲染：『XXX』，禁止改写」 | 用图像工具局部重绘文字，或换模型 |
| 火山 ARK 返回 404 ModelNotOpen | 改用已验证可用的 `doubao-seedream-5-0-260128`；pro/lite/4.5/4.0/3.0 在多数账号未开通 | 退回网页端即梦/Seedream 4.0 手动跑 |
| 火山 ARK 返回 400 size 错误 | 改用 `2976x1264`（≥3,686,400 像素、16 倍数）；`21:9`、`2560x1088` 都会报错 | 同左，不要试其他尺寸 |
| 图片带「图片由AI生成」水印 | 重发，`watermark: False` | 用图生图去水印或换模型 |
| IP 形象颜色/特征跑偏 | 用 `--ref assets/robot-ip-default.png` 强制图生图对齐 | 回到图1 文字描述分支，收窄特征列举 |
| 用户未装 Python/无 API Key | 改用网页生图：复制提示词到即梦/Seedream 4.0，图1 传 IP 图 | 交第三方代跑 |

**原则**：任何一步失败，先读上表对应行，不要凭记忆试参数（尺寸、模型名已踩坑确认，照表用）。

## 反例与黑名单（don't）

本 skill 绝对不要做的事（命中即视为违规输出，必须重做）：

1. **不要生成瘦高/修长/成人比例的机器人**——IP 必须是圆润矮胖、大头大肚子、短手短腿。这是最高频的真实翻车点。
2. **不要用禁用色**——蓝紫渐变、粉彩、彩虹多色渐变、高饱和暖黄/金色、纯黑大面积。
3. **不要用禁用字体**——宋体、楷体、书法字、Comic Sans、Papyrus、任何衬线体。
4. **不要加水印/签名/平台标识/「AI生成」字样**——`watermark: False`，且提示词写「无水印无签名」。
5. **不要拉伸/旋转/倾斜 IP 或改品牌色**——IP 主色、安全帽、徽章、眼屏配色固定。
6. **不要把同一套背景/字体套所有风格**——10 种风格各有独立 VI 应用逻辑。
7. **不要输出不写画幅的提示词**——第一行必须是「2.35:1 横版构图，公众号封面」。
8. **不要在提示词里留软化措辞**——「建议/可以考虑/根据情况/灵活把握」会削弱可执行性；用明确指令。
9. **不要硬编码单一 runtime 路径**——安装说明要给多 runtime 通用方式，不钉死 `~/.claude/skills/`。
10. **不要跳过生成前 CHECKPOINT 直接生图**——三轮确认 + 用户 OK 是最后闸门。

## 直接生图（火山引擎 ARK，可选）

若环境已配置火山引擎 ARK API Key，可直接调用生图，无需手动去网页。**已验证可用的命令与参数如下（实测 2026-07-26）**：

### 前置
- API Key 存放于 `~/.baoyu-skills/.env`，字段：`ARK_API_KEY=...`（同值也可写 `IMAGE_API_KEY` / `SEEDREAM_API_KEY`），`ARK_BASE_URL=https://ark.cn-beijing.volces.com/api/v3`
- 本 skill 已内置脚本 `gen_cover_volc.py`（纯 Python 标准库，无第三方依赖）

### 关键参数（已踩坑确认，不要改）
- **模型**：`doubao-seedream-5-0-260128`（可用；注意 `doubao-seedream-5-0-pro-260628`、lite、4.5、4.0、3.0 在多数账号尚未开通，会 404）
- **尺寸**：`2976x1264`（≈2.35:1，总像素 3,760,064 ≥ 最低 3,686,400，且宽高均为 16 的倍数）。`21:9`、`2560x1088` 等都会 400 报错
- **去水印**：`watermark: False`（否则画面会出现「图片由AI生成」水印）
- **多参考图**：`--ref` 可重复传入，图1 为机器人 IP（默认 `assets/robot-ip-default.png`），图2 起为素材图；脚本自动转 base64 填入 `image` 字段

### 调用示例
```bash
# 文生图（无参考图）
python gen_cover_volc.py --filename cover_article.png < prompt.txt

# 图生图 + IP 参考（推荐，保证机器人身形一致）
python gen_cover_volc.py \
  --ref assets/robot-ip-default.png \
  --filename cover_article.png < prompt.txt

# 多参考图：IP + 素材
python gen_cover_volc.py \
  --ref assets/robot-ip-default.png path/to/screenshot.png \
  --filename cover_article.png < prompt.txt
```

提示词从 stdin 读入；输出默认存到脚本同目录。生成后务必核对：标题中文字、机器人是否瘦高（若是，按上文「IP 身形硬约束」重生成）。

🔴 CHECKPOINT · 🛑 STOP：调用 `gen_cover_volc.py` 会消耗火山引擎 API 额度并直接产出图片文件。执行前必须确认：① 提示词已通过上面的生成前 CHECKPOINT；② 用户明确同意「现在生图」。未确认不得运行脚本。
