## 一、文献检索与获取（核心 · 必装）

### 全球12亿文献知识库 → `global-biblio-base`

- **适用边界**：你要"找文献"本身——搜论文、查期刊 / 专利 / 标准、下 PDF、做文献调研或综述。这是所有文献工作的起点。
- **能做什么**：
  - 中文期刊检索 + 授权全文 PDF 下载（8000 万篇）
  - 全球 12 亿条文献元数据检索（论文 / 专利 / 会议 / 学位论文 / 标准）
  - 文献详情（摘要 / DOI / 基金 / 收录情况）、引文追溯、相关性重排
  - 外文 OA 全文免费探测下载（不耗配额）
- **不能做什么 / 与相邻技能的区别**：
  - 付费墙内英文文献只返元数据、拿不到全文（OA 除外）
  - **不查"文献真假"**——那是 `smartlib-citation-checker`（是否存在）和 `paper-integrity-forensics`（是否造假）的活
  - **不导出 EndNote / 批量 BibTeX**——要管理 / 导出参考文献用 `academic-knowledge-base`
  - 不做文献查重 / 科技查新
- **该装还是不装**：只要做文献检索 / 下载 / 综述 → **必装（核心）**。从不动文献、只做方法论或只造技能的人不装。
- **安装提示词**：请根据 <https://skillhub.cn/install/skillhub.md> ，安装 global-biblio-base

### 个人文献知识库 → `academic-knowledge-base`

- **适用边界**：你读过的论文想"留下来"——建私人知识库、做笔记、按专题归类、随时回检、导出规范参考文献。是检索之后的"沉淀层"。
- **能做什么**：
  - 4 类数据入库（检索结果 / 上传 PDF·Word·BibTeX / 资讯 / 个人数据）
  - 双轨检索：向量语义检索 + 传统分词匹配
  - 研究专题（子集 + 笔记 + AI 分析）、参考文献管理（导出 BibTeX / GB-T / APA / MLA）
  - 知识库统计报告
- **不能做什么 / 与相邻技能的区别**：
  - **不主动发现新文献**——它是沉淀库，不是检索入口（发现用 `global-biblio-base`）
  - 英文付费墙全文复用 global 的 OA 策略，不额外获取
  - 配额耗尽后外部检索暂停，本地已有文献仍可管理
- **该装还是不装**：常读论文、要长期管理 / 回顾已读、要规范导出参考文献 → 装。只想偶尔搜一篇、搜完就忘 → 不装。
- **安装提示词**：请根据 <https://skillhub.cn/install/skillhub.md> ，安装 academic-knowledge-base

### CAJ 转 PDF·离线高保真版 → `caj2pdf-offline`

- **适用边界**：你手上有知网下载的 `.caj` / `.kdh` / `.nh` 文件，想转成文字可选中、带书签的 PDF。纯本地文件处理，与检索无关。
- **能做什么**：
  - CAJ / KDH / NH 高保真转 PDF（保留文字层可选中 + 目录书签）
  - 单文件 / 目录批量递归转换、指定输出目录
  - 完全离线，不联网、不上传任何文件
- **不能做什么 / 与相邻技能的区别**：
  - 只转格式，**不检索、不下载**文献（要下文献用 `global-biblio-base`）
  - HN 硕博格式可能转换失败（需"全球学术快报"官方兜底）
  - KDH / HN 多为图片型，转出 PDF 文字不可选（格式固有，非缺陷）
  - 内置解码 DLL 为 Windows 版；Linux / macOS 需自行编译替换
- **该装还是不装**：经常下知网 CAJ 文献、要转 PDF 引用 → 装。没有 CAJ 文件、或只用 PDF → 不装。
- **安装提示词**：请根据 <https://skillhub.cn/install/skillhub.md> ，安装 caj2pdf-offline

## 二、文献验真与学术诚信

### 参考文献验真·AI引用核查 → `smartlib-citation-checker`

- **适用边界**：你手上有一串参考文献（自己写的或 AI 生成的），要确认"它们是否真的存在、字段对不对"。防 AI 幻觉虚构文献、投稿前自查。
- **能做什么**：
  - 解析 GB-T / APA / MLA / Chicago / BibTeX（含 .bib 批量）
  - 基于 SmartLib 联网核查真实性、纠正作者 / 年份 / 期刊 / 卷期 / 页码
  - 输出带验证链接 + 差异标记 + 统计的 HTML 报告
- **不能做什么 / 与相邻技能的区别**：
  - **只判"存不存在 / 字段对不对"**——不判"这篇是否已撤稿 / 是否论文工厂"（那是 `paper-integrity-forensics`）
  - 不下载英文付费墙全文
  - 文献元数据有数小时至数天延迟；不主动爬 Google Scholar / ResearchGate
  - 不做查重 / 查新；不主动补全缺失信息
- **该装还是不装**：常写论文、用 AI 生成参考文献、怕引用到假文献 → **装**。从不写学术引用 → 不装。
- **安装提示词**：请根据 <https://skillhub.cn/install/skillhub.md> ，安装 smartlib-citation-checker

### 文献造假风险核查·学术诚信法医 → `paper-integrity-forensics`

- **适用边界**：某篇文献你已经定位（有标题 / DOI / PDF / 链接），在"引用它或基于它之前"，想查它是否疑似造假、撤稿、论文工厂、PubPeer 被质疑。是引用前的风险控制。
- **能做什么**：
  - 七维法医：撤稿记录、论文工厂特征、图像 / 数据异常、PubPeer 质疑、署名异常等
  - 输出**校准怀疑等级**（高 / 中 / 低 / 证据不足）+ 明确决策建议（可引用 / 谨慎引用 / 暂缓 / 勿引）
  - 编排免费数据库：Retraction Watch、Crossref、PubPeer、CNKI、SmartLib
- **不能做什么 / 与相邻技能的区别**：
  - **不判"文献是否存在 / 字段对错"**——那是 `smartlib-citation-checker`；本技能假设你已定位文献，查它的诚信风险
  - **不输出二元"真 / 假"判决**，而是校准等级 + 决策建议，不替你最终决定引不引
  - 不做全文同行评审；不做新颖性判断（用 `novelty-validator`）
  - 依赖外部免费库，某库不可达时证据降级
- **该装还是不装**：投重要期刊、引用关键文献前想规避撤稿 / 论文工厂风险 → 装。随手引用、不 care 诚信风险 → 不装。
- **安装提示词**：请根据 <https://skillhub.cn/install/skillhub.md> ，安装 paper-integrity-forensics

## 三、学术会议与答辩（组会 / 答辩场景）

### 【学术会议】组会文献把关人 → `cjg-paper-fact-checker`

- **适用边界**：组会 / 读书会 / seminar 有人分享一篇论文（标题 / DOI / PDF / 引用列表），你想在"听之前 / 讲之前"快速把关靠不靠谱。
- **能做什么**：
  - 三道把关：①引文真实性（复用 citation-checker）②可复现性（方法 / 数据 / 代码是否齐全）③图片查重（你提供关键图时做相似度比对）
  - 生成"论文可信度报告"（高 / 中 / 低 + 证据 + 阅读建议）
- **不能做什么 / 与相邻技能的区别**：
  - **不做单篇深度诚信法医**——那是 `paper-integrity-forensics`（撤稿 / 论文工厂）；本技能是组会场景的"综合快速把关"
  - 不做新颖性判定（`novelty-validator`）、不做文献调研检索（`global-biblio-base`）
  - 不替你决定"该不该读这篇"
  - 图片查重为辅助：需你主动提供图，不自建跨库图片比对
- **该装还是不装**：常参加组会 / 读书会、要分享或把关论文 → 装。不参会、只自己读 → 用 citation-checker / paper-integrity-forensics 即可。
- **安装提示词**：请根据 <https://skillhub.cn/install/skillhub.md> ，安装 cjg-paper-fact-checker

### 【学术会议】创新点验证器 → `novelty-validator`

- **适用边界**：脑暴后 / 开会后，你想确认"这个想法 / 方法 / 方向有没有人做过、新不新"，避免重复造轮子。
- **能做什么**：
  - 想法抽取 → 三引擎并行比对（中文期刊 / 全球文献 / 专利池 2.15 亿）
  - 向量语义精校 + 五级新颖性判定（L1 被覆盖 → L5 新颖）
  - 出报告（含可验证证据）+ 若重复给创新路径建议
- **不能做什么 / 与相邻技能的区别**：
  - **不做查新公证**——那是查新机构职责；本技能是"快速防重复"信号
  - 不获取文献全文（仅比对摘要层）
  - 不替你决定"该不该做这个方向"
  - 不触发纯检索 / 纯引文核查（各归其位）
- **该装还是不装**：常脑暴新方向、怕和已有工作撞车 → 装。方向已定、只做执行 → 不装。
- **安装提示词**：请根据 <https://skillhub.cn/install/skillhub.md> ，安装 novelty-validator

### 【学术会议】学术组会引擎 → `paper-club-pilot`

- **适用边界**：要系统地筹备一场组会 / 读书会（推荐必读、生成材料包），或会中记录、会后把结论沉淀进知识库。
- **能做什么**：
  - 会前：按课题组画像推荐 3–5 篇必读 + 生成研讨材料包
  - 会中：调用腾讯会议智能纪要做讨论记录
  - 会后：把结论蒸馏进学术知识库、出"组会小结"
- **不能做什么 / 与相邻技能的区别**：
  - **不把关单篇真实性**（`cjg-paper-fact-checker`）、**不判新颖性**（`novelty-validator`）、**不演练答辩**（`defense-rehearsal`）
  - 是"组会编排层"，复用 global + academic-knowledge-base，本身不做检索 / 核验
  - 不替组会做决定
- **该装还是不装**：要系统管组会全流程 → 装。三五人随便聊聊、手写记 → 不装。
- **安装提示词**：请根据 <https://skillhub.cn/install/skillhub.md> ，安装 paper-club-pilot

### 【学术会议】学术答辩预演官 → `defense-rehearsal`

- **适用边界**：临近开题 / 中期 / 毕业答辩，想模拟委员会提问、扫描文献短板、演练并复盘表达。
- **能做什么**：
  - 会前：生成模拟委员会（3–5 角色）+ 每角色刁钻提问；文献短板扫描（调 global 找"引用但不熟"的文献）
  - 会中：引导腾讯会议模拟答辩并录制，提取表达问题
  - 会后：输出复盘报告（必补知识点 / 表达改进 / 下场重点）
- **不能做什么 / 与相邻技能的区别**：
  - **不组织组会**（`paper-club-pilot`）、**不把关单篇**（`cjg-paper-fact-checker`）、**不判新颖性**（`novelty-validator`）
  - 不替你写答辩稿
  - 表达层为辅助级，不替代真人预答辩
- **该装还是不装**：临近答辩、想多练几场 → 装。不答辩 → 不装。
- **安装提示词**：请根据 <https://skillhub.cn/install/skillhub.md> ，安装 defense-rehearsal

## 四、科研方法论与疑难破局

### 扫地僧（专治科研学术疑难杂症） → `sweeping-monk`

- **适用边界**：你遇到"软"问题——研究设计怎么做、方法论困惑、论证被质疑、研究卡壳、需要有人点醒思路或沟通破局。是谋士层，不是执行层。
- **能做什么**：
  - 谋士层输出：研究 / 实验设计、方法论证、批判拆解论文与论证、学术写作框架、根因诊断、审稿 / 开题应对、点醒沟通
  - 覆盖全学科方法论（含统计 / 逻辑谬误 / 推理偏误解毒）
- **不能做什么 / 与相邻技能的区别**：
  - **不代你检索 / 下载 / 核对文献**——那是 global / citation-checker / paper-integrity-forensics 的活，它只出谋
  - **不代写代改论文 / 代码**（除非你明确要求落地验证）
  - 不做心理治疗（"点醒"非咨询）；不碰法律 / 医学 / 财务等专业判断
  - 是谋士不是执行者；你要"直接搜某篇 / 下某个文件"时不启用它
- **该装还是不装**：常遇方法论 / 研究设计卡点、想被点醒 → 装。只做执行类任务、不需要谋士 → 不装。
- **安装提示词**：请根据 <https://skillhub.cn/install/skillhub.md> ，安装 sweeping-monk

## 五、技能打造与优化（Agent 用户向）

### 技能锻造炉 → `cjg-skill-forge`

- **适用边界**：你想从零打造一个牛技能、把现有技能重铸合并、或审计某个技能质量并让它持续进化。是"造技能"的元技能。
- **能做什么**：
  - 锻造模式：造 / 升级技能，带真实接线、真机取证、外部标杆、覆盖审计、生产签批
  - 审视模式：10 维加权评分尺，给任何技能（含自身）评级
  - 重铸模式：扫描本机重叠技能、推荐重铸基座
- **不能做什么 / 与相邻技能的区别**：
  - **不脚手架初始化**（用 skill-creator 的 init）
  - **不自动发布**——产出待发布目录，发布另走流程
  - 不替代领域专长（无法判断分类法对错，需你）
  - 不保证通过 Global-Best；仅在创建 / 升级 / 审计时激活

### AI易读技能转化器 → `skill-clarity-forge`
