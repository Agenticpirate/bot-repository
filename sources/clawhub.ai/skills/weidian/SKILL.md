# 微店轻量开店 Skill

微店是**零门槛的个人社交电商工具**：手机注册即开店、无软件年费、
按交易收通道费——适合把"朋友圈卖货"升级成有担保交易的正规小店。
它是很多小微生意的第一站，但不该是所有生意的终点站。

## 模式选型：微店 vs 有赞 vs 抽佣平台

| 维度 | 微店 | 有赞（见 `youzan` skill） | 淘宝等抽佣平台 |
|------|------|---------------------------|----------------|
| 起步成本 | ≈0，即开即卖 | SaaS 年费（千元级起） | 保证金+运营成本 |
| 流量来源 | 全靠自己的私域 | 全靠自己的私域 | 平台公域+付费 |
| 功能深度 | 基础（商品/订单/简单营销） | 深（会员/储值/分销/零售） | 平台规则内 |
| 适合 | 个人/兼职/验证期生意 | 成规模私域生意 | 无私域但能投流 |

**判断口诀**：日单个位数用微店验证；稳定日单几十且需要会员复购
体系时再考虑升级——工具费用应该由已验证的单量摊薄，而不是
先交年费赌未来。

## 微店的信任建设（个人卖货的核心短板）

个人卖货最大障碍是"凭什么信你"，微店的价值就在补信任：

1. **担保交易**：买家付款先到平台，确认收货才结算——这是
   相比"微信直接转账"的本质升级，主动告知买家这一点
2. **店铺资产**：评分、销量、买家评价可积累可展示，
   朋友圈截图不可验证，店铺页可以
3. **售后规则**：七天无理由等标准规则接入，纠纷有平台仲裁通道
4. 实名与证照：食品等类目需相应资质，无证经营被投诉必下架

## 社交卖货实操要点

- 商品页照片自己拍（实物+使用场景），盗图既有版权风险又损信任
- 朋友圈发商品链接的正确姿势：内容（使用体验/客户反馈）为主、
  链接为辅，纯刷屏广告会被折叠也会被拉黑
- 定价：私域卖货拼的是信任溢价不是全网最低价，但明显高于
  电商平台同款会被比价打脸，控制在合理溢价内
- 复购靠服务：发货速度、售后响应是小店对抗大平台的唯一武器

## 何时该"毕业"迁移

出现以下信号，说明微店装不下你的生意了：

- 需要会员储值/积分/分销体系 → 有赞类 SaaS
- 私域流量见顶需要公域获客 → 开抽佣平台店或做内容电商
- 多人协作管店/对接 ERP → 需要开放平台能力的方案

迁移时店铺评价资产带不走，老客迁移靠私域关系——这也是
一开始就要沉淀微信好友而非只沉淀店铺粉丝的原因。

## Agent 典型用法

1. **开店咨询**：按用户生意阶段给微店/有赞/平台三选一建议
2. **信任诊断**：检查用户店铺的信任要素清单（担保/评价/资质/实拍）
3. **朋友圈文案**：按"体验为主链接为辅"原则代写卖货内容
4. **毕业判断**：按信号清单评估是否该迁移及迁移注意事项

## 本 skill 不做什么

- 通道费率与功能边界以微店 App 实时说明为准
- 不提供刷单刷评、微信群发轰炸等违规增长方法
- 特殊类目（食品/化妆品/保健品）资质要求从严提示，不打擦边球
