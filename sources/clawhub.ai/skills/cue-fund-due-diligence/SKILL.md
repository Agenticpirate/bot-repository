# 公募基金全维尽调

> 买基金不能只看过去一年的收益率。基金经理是运气还是能力、风格有没有漂移、规模是不是太大了、费用划不划算——让 Cue 把这只基金从里到外查一遍，帮你做出有数据支撑的申赎决策。

## 适用范围与场景（先看这个，别用错了）

**可以查：**

| 维度 | 覆盖 |
|------|------|
| 市场 | 全市场 A 股公募基金（股票型、偏股混合型、灵活配置型、平衡混合型） |
| 尽调深度 | 基金经理画像、业绩归因、风格一致性、风险指标、持仓特征、费率与规模 |
| 时间跨度 | 基金成立以来全周期分析，含 1/3/5 年滚动窗口 |

**适用场景：**

| 场景 | 解决的问题 |
|------|-----------|
| 选基决策 | 看中一只基金，不知道它能不能持续跑赢——做一次全维尽调再决定 |
| 持基诊断 | 持有的基金最近表现不好，是经理能力问题还是市场风格问题？该留该换？ |
| 基金经理评估 | 听说一位明星经理跳槽了，他到底有没有真本事？过往业绩是 Alpha 还是 Beta？ |
| 替代基金筛选 | 想换掉一只基金，需要找到风格接近但能力更强的替代品 |

**不能查：**

- 私募基金、专户、信托计划（非公开持仓与业绩）
- 基金未来业绩预测或买卖时点建议
- 基金经理个人投资账户或薪酬信息
- 货币基金、债券基金（分析方法论不同，当前仅覆盖权益类）

> 简单判断：**这只基金会公开披露季报和年报吗？** 会 → 能尽调。不会 → 用不了。

## 核心能力

1. **基金经理画像** — 从业年限、管理规模变迁、历任基金业绩、能力圈识别、投资框架简述
2. **业绩归因分析** — Brinson 归因（行业配置贡献 vs 选股贡献）、Alpha/Beta 分离、牛熊市表现拆解
3. **风格一致性检验** — 持仓市值风格（大盘/中盘/小盘）、成长/价值暴露、行业偏好漂移检测
4. **风险指标扫描** — Sharpe 比率、Sortino 比率、最大回撤、下行捕获率、波动率、VaR
5. **持仓特征分析** — 前十大集中度、换手率、平均持仓周期、重仓股质量评估
6. **费率与规模评估** — 管理费/托管费对比同类、规模增长轨迹、策略容量风险预警

## 输出形式

结构化尽调报告：基金概览 → 基金经理画像（履历/能力圈/在管产品）→ 业绩归因（Alpha/Beta/牛熊表现）→ 风格一致性（市值风格/成长价值/行业漂移）→ 风险指标（Sharpe/Sortino/最大回撤/下行捕获）→ 持仓特征（集中度/换手率/重仓股）→ 费率与规模 → 综合评估 → 来源链接。

## 自救指引

### 错误速查

Cue 返回结构化错误，包含 `code`（错误码）、`retryable`（是否可重试）、`user_action`（操作建议）。

| 错误码 | 现象 | 可重试？ | 处理 |
|--------|------|---------|------|
| `AUTH_FAILED` | 401 / Key 无效 | ❌ | 重新生成 Key，更新 `~/.cue/config.json` |
| `TIMEOUT` | 超时 >30s 无响应 | ✅ | 等 5 分钟，跑诊断确认服务在线后重试，最多 3 次 |
| `BUDDY_UNAVAILABLE` | 搭子临时下线 | ✅（延迟） | 等 1h 或网页端直接跑 |
| `INSUFFICIENT_CREDITS` | 积分不足 | ❌ | [cuecue.cn](https://cuecue.cn) 充值或等次日免费额度 |
| `SESSION_INTERRUPTED` | 中途中断 | ✅ | **不换 prompt**，相同命令续接——Cue 从 session 断点继续，不重复计费 |
| `FUND_NOT_FOUND` | 基金名称/代码无法识别 | ❌（需改输入） | 用 6 位基金代码替代简称，检查基金是否已清盘或更名 |
| `MANAGER_NOT_FOUND` | 基金经理姓名无法匹配 | ❌（需改输入） | 用完整姓名，检查经理是否已离职；或多位经理时指定主经理 |
| `INSUFFICIENT_HISTORY` | 基金运作时间太短 | ❌（需等待） | 成立不足 1 年的基金无法做有效业绩归因和风格分析 |
| `RESULT_EMPTY` | 无匹配结果 | ❌（需改条件） | 换基金代码、确认基金类型在覆盖范围内 |
| `CONFIG_PARSE_ERROR` | config.json 报错 | ❌ | 修复 JSON 格式：`{"api_key": "sk..."}` 无多余逗号 |

### 中断恢复机制

Cue 的调研任务是**有状态**的。如果中途超时或网络波动导致中断：

```
中断 ≠ 失败，cancel 才 = 失败
├─ 超时 → 等一会，相同命令续接（session 存在 ~/.cue/session/task）
├─ 网络波动 → 同上，相同命令续接
├─ 手动 cancel → 无法恢复，需要重新发起
└─ 恢复后 → Cue 从断点继续，已查过的阶段不会重复计费
```

> **关键规则**：中断后**不要换 prompt、不要删 session 文件、不要 cancel**。三个"不要"记住了就不会白跑。

### 重试决策

```
收到错误
├─ retryable = true → 按 user_action 建议操作后重试
│   ├─ 超时/网络类 → 等 5min，跑诊断，最多 3 次
│   └─ 搭子下线 → 等 1h 或换网页端
├─ retryable = false → 不要重试，改了条件再说
│   ├─ Key/基金代码问题 → 修正输入后重试
│   ├─ 基金运作太短 → 等满 1 年再查
│   ├─ 积分不足 → 充值或等次日
│   └─ 结果空 → 换基金代码 / 确认基金类型
└─ 重试 3 次仍失败 → 记下 request_id，走降级方案
```

### 调度建议

| 时段 | 建议 |
|------|------|
| 工作日 10:00-16:00 | 最佳时段，3-8 分钟完成 |
| 工作日 9:00-10:00 / 16:00-18:00 | 高峰期，经理对比等大查询避开 |
| 季报披露后一周（1/4/7/10 月下旬） | 基金持仓和规模数据最新鲜，最适合做持仓特征和风格分析 |

## FAQ

**Q: 全维尽调和看天天基金的基金详情页有什么区别？**
A: 天天基金给你的是"数据列表"——收益率、最大回撤、前十大持仓罗列在一起。Cue 做的是"归因分析"——这些数据之间的因果关系：收益有多少来自行业 Beta（风口）、多少来自经理选股 Alpha（能力）；风格有没有漂移（说的是价值投资但买了一堆成长股）；规模增长有没有超过策略容量。数据是原料，归因才是结论。

**Q: 怎么知道该用这个还是 cue-fund-penetration？**
A: 本搭子是对**单只基金**的深度尽调——这只基金本身好不好、经理靠不靠谱。cue-fund-penetration 是对**基金组合**的交叉分析——你手里的多只基金持仓有没有重叠、行业是不是太集中。先尽调选好每只基金，再穿透检查组合健康度——两个搭子配合使用。

**Q: 成立不到一年的新基金能尽调吗？**
A: 不能做完整的业绩归因和风格分析，因为数据点太少，统计上不可靠。但可以做基金经理画像（看经理管过的其他老基金），以及费率规模评估。建议至少运行满 1 年再做全维尽调。

**Q: 基金经理刚换人，历史尽调数据还有用吗？**
A: 历史数据描述的是**这只基金在前任经理手中的表现**，对新经理参考价值有限。Cue 会标注"经理变更时间点"，并将变更前后的业绩分开展示，避免你被老经理的业绩误导。如果新经理是新人（没有其他基金可追溯），风格和归因分析的可信度会降低。

**Q: 业绩归因里的 Alpha 和 Beta 是什么意思？**
A: Beta 是市场/行业给你的收益——比如 2020 年买白酒基金，闭着眼睛都赚钱，那是白酒行业 Beta 的功劳。Alpha 是经理超越市场的那部分收益——同行都买白酒，他也买白酒但挑了最好的那几只，多出来的收益才是 Alpha。尽调的核心目的：区分这是"风口上的猪"还是真正会飞的鸟。

**Q: 风格一致性为什么重要？**
A: 你买基金是基于对经理风格的信任——比如你看中了一位"低换手、长期持有、价值投资"的经理。如果尽调发现他过去三年换手率翻了三倍、持仓从大盘价值漂移到了小盘成长——风格已经质变，你当初买他的理由就不复存在了。风格漂移本身不一定不好，但你需要知情。

**Q: 规模多大算太大？**
A: 没有绝对标准，取决于策略类型。大盘蓝筹策略容量大（百亿级别仍可运作），小盘成长或高换手策略容量小（几十亿就可能影响灵活性）。Cue 会结合基金的持仓特征和策略类型，给出规模是否接近容量上限的判断。

**Q: 尽调报告多久更新一次比较合适？**
A: 建议每季度季报披露后更新一次，重点关注：风格是否漂移、经理是否变更、规模是否暴增、风险指标是否恶化。如果是核心持仓基金，月度做一次风险指标扫描也值得。
