# 餐饮供应链成本分析报告 Skill

## 概述

生成专业的餐饮供应链成本分析报告，覆盖供应商成本对比、品类成本趋势分析、异常检测与降本建议三大核心能力。

## 触发规则

当用户输入包含以下关键词时自动激活本技能：
- "成本分析" / "成本卡" / "成本报告"
- "供应商对比" / "供应商评估" / "对比供应商"
- "成本差异" / "降本" / "降本分析"

## 核心分析框架

### 1. 数据读取与准备

1. 识别用户提供的成本卡/供应商数据文件（Excel/CSV/PDF等）
2. 确认数据字段：供应商名称、品类、SKU、单价、采购量、物流成本、总成本等
3. 数据校验：检查缺失值、异常值、单位一致性
4. 按品类维度归类（丸滑水产、净菜加工、桌椅家具、石材等）

### 2. 供应商成本对比分析

按以下维度进行供应商间对比：

| 对比维度 | 分析内容 | 输出指标 |
|---------|---------|---------|
| 单价对比 | 同品类不同供应商的加权平均单价 | 价格差异率、价格排名 |
| 总成本对比 | 考虑采购量、物流、损耗后的全成本 | 总成本差异率 |
| 品类结构对比 | 各供应商在不同品类的成本分布 | 品类占比、品类集中度 |
| 价格趋势对比 | 各供应商价格随时间的变化趋势 | 月度价格走势、波动率 |
| 物流成本对比 | 各供应商物流费用占采购额比例 | 物流费率、吨公里成本 |

**领域规则（必须遵守）：**
- **冷链物流**：吨级以下（<2吨）均为零担拼车，不按专车计算。最小冷链车2-3吨，省际10吨+。分析供应商物流成本差异时，小批量分供不因物流产生差异。
- **全品类范围**：默认按全品类范围考虑，不局限单一SKU。如需限定范围，主动向用户确认。
- **费用分摊**：涉及多品类共用的运输、仓储费用，按采购金额或重量比例分摊。

### 3. 成本差异分解（价差/量差/混合差异）

采用标准成本差异分析法，将总成本差异分解为：

```
总差异 = 价格差异 + 数量差异 + 结构差异

价格差异 = (实际单价 - 基准单价) × 实际采购量
数量差异 = (实际采购量 - 基准采购量) × 基准单价  
结构差异 = 品类组合变动导致的成本变化
```

输出：差异分解表，标明每个差异的贡献度和归因。

### 4. 异常检测

- **价格异常**：同品类供应商价格偏离均值超过 ±3σ 或 ±20% 的标记为异常
- **成本突增**：环比涨幅超过 15% 的品类/供应商标记为预警
- **物流费率异常**：吨公里成本偏离行业均值的标记

### 5. 降本建议生成

基于上述分析，输出结构化降本建议：

1. **采购策略调整**：建议切换供应商、集中采购、锁价/浮动价策略
2. **品类优化**：替换高成本品类、调整品类结构
3. **物流优化**：拼车/合并运输方案、优化配送频次
4. **供应商管理**：引入竞争、供应商分级、年度降本谈判

### 6. 报告输出格式

输出结构化的详细报告，包含以下章节：

```
# 餐饮供应链成本分析报告

## 一、摘要
- 整体成本变动概况
- 关键发现（3-5条）
- 核心建议（优先级排序）

## 二、供应商成本对比分析
- [表格] 各供应商成本指标对比表
- [图表] 品类-供应商成本矩阵热力图
- 关键发现与归因

## 三、成本差异分解
- [表格] 价差/量差/结构差异分解表
- 差异归因说明

## 四、成本趋势分析
- [图表] 月度成本趋势折线图
- 品类成本走势分述

## 五、异常告警
- 异常项目清单（品类/供应商/指标/异常程度）
- 建议跟进事项

## 六、降本建议
- 短期措施（1-2周可执行）
- 中期措施（1-3个月）
- 长期战略（3-6个月）
```

## 注意事项

1. 默认按全品类范围分析，如需限定范围主动向用户确认
2. 冷链物流规则严格执行：<2吨零担拼车，不做专车计算
3. 数据不足时明确告知，不假设或推断缺失信息
4. 分析中涉及的货币单位统一使用人民币（¥）
5. 所有对比数据应注明时间周期（年月）
6. 异常标记需同时给出判定标准和数值依据
7. 降本建议需标注预期效果和风险提示

## 参考方法论

### 成本控制模型 1.0
基于全品类视角的成本控制框架，包含：
- 价格基线建立：按品类建立基准价格区间
- 供应商分级：S/A/B/C四级供应商管理体系
- 季度复盘机制：每季度对核心品类进行成本复盘

### 8 大降本妙招
1. 源头直采减少中间环节
2. 集中采购提升议价能力
3. 标准化减少定制成本
4. 长期合同锁定价格
5. 替代品/替代供应商引入竞争
6. 物流合并降低运输成本
7. 损耗管控减少隐性成本
8. 数据驱动决策优化采购节奏

### 两聚焦一落实
- 聚焦核心品类：TOP 20% 品类占 80% 成本
- 聚焦核心供应商：TOP 5 供应商占 60%+ 采购额
- 落实数据驱动：每一笔降本都要有数据支撑
