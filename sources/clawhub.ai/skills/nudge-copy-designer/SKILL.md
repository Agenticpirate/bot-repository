# 行为经济学助推文案设计器（nudge-copy-designer）

把行为经济学原理，转化成一字一句能落地的「助推文案」与选择架构方案。

## 何时使用

- 需要设计「能改变人行为」的文案、标语、提示牌
- 需要为食堂、校园、办公、App、政务等场景做助推方案
- 想降低浪费、提升参与率、引导健康/环保/储蓄等行为
- 需要给出一套「默认选项 + 提示文案 + 反馈机制」

## 核心能力

1. **诊断问题**：明确目标行为、现状、阻碍。
2. **选择助推工具**：从以下工具箱中选取 1–3 个原理：
   - 默认效应（Default Effect）
   - 损失厌恶（Loss Aversion）
   - 社会规范（Social Norm）
   - 承诺一致性（Commitment & Consistency）
   - 框架效应（Framing Effect）
   - 即时反馈（Immediate Feedback）
   - 突出性 / 注意力引导（Salience）
3. **产出文案**：给出可直接张贴 / 上线的多条候选文案。
4. **选择架构设计**：说明环境如何微调（位置、顺序、默认选项）。
5. **评估指标**：给出可衡量的行为改变指标。

## 工作流程

1. 确认场景、目标行为、受众与可用触点（海报 / App / 桌贴 / 语音等）。
2. 输出「行为诊断 + 助推工具选择理由」。
3. 提供 3 条以上候选文案，并标注各自使用的原理。
4. 给出选择架构的微调建议（例如：把健康餐放到取餐动线第一格）。
5. 给出 A/B 测试与效果评估指标。

## 输出格式（模板）

| 触发点 | 使用的原理 | 候选文案 | 环境微调 | 预期指标 |
|--------|-----------|----------|----------|----------|

## 示例

见同目录 `examples.md`（含一个「食堂减少食物浪费」的完整助推方案）。

## 注意事项

- 助推不是强制：不限制选择，只改变选择的默认环境。
- 文案要具体、可感知，避免空洞口号。
- 尽量量化：用「减少 1 盘 = 少浪费 X 元」而非「杜绝浪费」。
- 伦理边界：目标行为应有利于用户本人或公共福祉，需透明可解释。
