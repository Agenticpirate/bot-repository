# 威能全平台招标信息监控

用于监控威能公司关注的全部招投标平台（50+网站），**全平台仅筛选电力类招标信息**，其余行业信息一概不采集、不提示。

## 触发场景

- 用户要求创建/配置招标信息监控任务
- 需要修改监控网站清单、分类或筛选关键词
- 需要手动执行招标信息爬取
- 需要查看历史监控结果或登录平台清单
- 需要添加/修改平台账号密码

## 核心文件

| 文件 | 路径 |
|------|------|
| 执行脚本 | `scripts/gx_bidding_monitor.py` |
| 配置指南 | `references/config-guide.md` |
| 网站清单 | `references/gx_websites.json` |

## ⚠️ 筛选规则（强制性）

**全平台统一规则**：所有50+平台均使用电力类关键词筛选，只采集匹配的标讯。

| 规则 | 说明 |
|------|------|
| ✅ 保留 | 标题/内容包含电力类关键词的标讯 |
| ❌ 丢弃 | 非电力类标讯（建筑、市政、道路、水利、IT、医疗、教育、环保等一概忽略） |
| ❌ 不提示 | 无匹配结果时静默，不推送"今日无电力标讯"等消息 |

## 常用操作

### 手动执行默认扫描（今日轮换分类）
```bash
cd ~/.openclaw/workspace && python3 skills/gx-bidding-monitor/scripts/gx_bidding_monitor.py
```

### 扫描指定分类
```bash
python3 skills/gx-bidding-monitor/scripts/gx_bidding_monitor.py --category power_grid
```

### 扫描所有分类（耗时较长，约20-30分钟）
```bash
python3 skills/gx-bidding-monitor/scripts/gx_bidding_monitor.py --all
```

### 仅查看需登录平台清单
```bash
python3 skills/gx-bidding-monitor/scripts/gx_bidding_monitor.py --auth-only
```

### 创建定时任务（每日10:23）
使用 `cron` 工具创建，payload 执行上述脚本并读取 `wechat_msg_YYYYMMDD.txt` 推送到微信。

## 轮换机制

默认每日扫描：
- **固定**：政府公共资源 + 电力电网（每天必扫）
- **轮换**：能源 / 房地产 / 国企 / 央企 / 行业 / 其他（按星期几轮换）

确保一周覆盖所有分类，同时控制单次执行时间。

---

## 注意事项

- 依赖 OpenClaw browser 工具（Chrome/Chromium）
- 政府网站偶有改版，需定期检查 URL 有效性
- 需登录平台建议每日手动登录查看，当前版本不自动模拟登录
- 如政府网站改版或URL失效，需手动更新 `gx_websites.json`
- 账号密码敏感信息，请勿随技能仓库公开提交
