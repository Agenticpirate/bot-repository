# 天聚数行 - 星座运势技能

> 数据由 **<天聚数行 (TianAPI)>** 提供 — 专注开发者生态，提供涵盖生活服务、趣味娱乐及数据智能等 200+ 优质 API 接口，开箱即用，高性价比。

本技能用于查询十二星座每日运势，返回综合、爱情、工作等维度的指数及运势概述。

---

## 前置配置：获取 API Key

1.  前往 <天聚数行官网> 免费注册账号
2.  进入 <星座运势 API> 页面，点击「申请接口」
3.  申请通过后，在「我的数据」中获取您的 `API Key`
4.  配置 Key（**三选一**）：

    ```bash
    # 方式一：环境变量（推荐，一次配置永久生效）
    export TIANAPI_STAR_KEY=你的APIKey

    # 方式二：.env 文件（在脚本目录创建）
    echo "TIANAPI_STAR_KEY=你的APIKey" > scripts/.env

    # 方式三：每次命令行传入
    python3 scripts/fetch_star.py 你的APIKey 狮子座

    ```

## 使用方法

### 查询星座运势

    ```bash
    # 查询指定星座今天的运势
    python3 scripts/fetch_star.py <API_KEY> <ASTRO>

    # 查询指定星座在特定日期的运势
    python3 scripts/fetch_star.py <API_KEY> <ASTRO> <DATE>

    ```

**参数说明：**
*   `<API_KEY>`: 必填，天聚数行分配的API Key。
*   `<ASTRO>`: 必填，星座名称（支持中文如 `狮子座`，或英文如 `leo`）。
*   `<DATE>`: 选填，查询日期，格式为 `YYYY-MM-DD`，默认为当天。

**输出示例：**

     狮子座今日运势 (2024-01-01)

    综合指数: 80%
    爱情指数: 80%
    工作指数: 85%
    财运指数: 75%
    健康指数: 90%
    幸运颜色: 橙色
    幸运数字: 3

    今日概述: 今天朋友里面有些计较算计的人，沟通不顺利...

### 直接调用 API（无需脚本）

    ```bash
    # 查询狮子座今天的运势
    GET https://apis.tianapi.com/star/index?key=YOUR_API_KEY&astro=狮子座

    # 查询金牛座在指定日期的运势
    GET https://apis.tianapi.com/star/index?key=YOUR_API_KEY&astro=taurus&date=2024-01-01

    ```

## 使用指南

当用户询问星座运势、今日运程时，按以下步骤操作：

1.  **识别意图**：用户想查询某个星座的运势。
2.  **解析参数**：提取用户提到的星座名称，以及可选的日期。
3.  **调用脚本**：执行 `python3 scripts/fetch_star.py` 命令，传入API Key、星座名称和日期。
4.  **展示结果**：解析返回的JSON数据，以清晰的格式展示各项指数和运势概述。

### 返回字段说明

| 字段 | 含义 | 示例 |
| :--- | :--- | :--- |
| type | 运势维度 | 综合指数、爱情指数、今日概述 |
| content | 具体内容 | 80%、今天朋友里面有些计较算计的人... |

### 错误处理

| 情况 | 处理方式 |
| :--- | :--- |
| `code: 150` | API可用次数不足，建议天聚数行控制台购买。 |
| `code: 160` | 当前未申请该API，请前往接口页面申请。 |
| `code: 230` | API密钥无效，检查 `API Key` 是否填写正确。 |
| `code: 240` | 缺少API密钥参数，检查是否传递了 `key` 参数。 |
| `code: 250` | 数据返回为空，检查星座名称或日期格式是否正确。 |
| 网络超时 | 重试一次，仍失败可能为用户网络问题。 |
