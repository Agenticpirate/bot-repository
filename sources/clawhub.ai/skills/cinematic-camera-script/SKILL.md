# Cinematic Camera Script - 电影感运镜脚本生成器

## 简介

本技能生成专业级电影感运镜短视频脚本及一键视频生成提示词。基于一镜到底连续长镜头运镜体系，融合经典电影运镜技法，输出完整的逐秒分镜脚本和可直接用于AI视频生成的完整提示词。

**三种使用方式**：
- **上传图片**：上传参考图片，基于图片内容自动识别人物与场景，生成匹配的运镜脚本
- **简单描述**：提供主体、背景、场景的文字描述即可快速生成
- **选择模板**：使用内置的标准模板按需定制

**运镜特点**：运镜从画面中最右侧的主体开始，通过环绕、平移、后拉逐步展现所有人物，全程一镜到底无剪辑。

## 触发条件

当用户提出以下需求时使用本技能：
- 生成电影感/高级感运镜短视频脚本或提示词
- 上传图片要求基于图片生成运镜提示词
- 需要竖屏/横屏短视频运镜方案
- 需要卡点运镜脚本（BGM节奏对齐）
- 需要AI视频生成的完整提示词
- 需要实拍运镜操作指导

## 核心能力

- **逐秒分镜脚本**：完整的时间轴拆解，含画面主体、运镜参数、光影色调、卡点节奏
- **图片智能解析**：上传图片自动识别人物外貌、背景、光影条件，生成匹配的运镜脚本
- **BGM卡点对齐**：运镜节奏与背景音乐精确同步，增强视听冲击力
- **多画幅适配**：支持9:16竖屏、16:9横屏、1:1方形等多种画幅比例
- **一键视频提示词**：输出的完整提示词可直接用于AI视频生成工具，也支持实拍指导

## 输出内容

生成完整脚本后，输出包含以下模块：
1. 脚本核心说明（风格定位、时长、BGM、画质标准）
2. 详细分镜脚本（逐秒拆解，含画面/运镜/光影/卡点）
3. 核心运镜通用规则
4. 实拍操作指导
5. 完整视频生成提示词（可直接复制使用）

## 关键约束

- 所有运镜丝滑无抖动，一镜到底无剪辑
- 运镜从最右侧主体开始，逐步向左递进
- 人物描述差异化，防止AI生成重复脸
- 光影全程统一，禁止中途切换色调
- BGM卡点与运镜节奏精确对齐
- 图片输入时，视觉风格忠实还原图片原貌
