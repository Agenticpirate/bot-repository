What This Skill Does

Deploys web projects to Netlify using the Netlify CLI via npx. Handles authentication, site linking, preview and production deploys, and basic framework detection from package.json or netlify.toml.

Instead of manually navigating the Netlify dashboard, configuring build settings, and copying deploy URLs, the skill runs the full CLI workflow in sequence and surfaces errors with actionable fixes.

When to use it

  • Deploying a Vite React app to a Netlify preview URL before merging a PR
  • Linking a local project folder to an existing Netlify site by Git remote
  • Creating a new Netlify site and pushing a static HTML project live
  • Running a production deploy after verifying a preview URL looks correct
  • Setting up netlify.toml build config for a Next.js project during first deploy
