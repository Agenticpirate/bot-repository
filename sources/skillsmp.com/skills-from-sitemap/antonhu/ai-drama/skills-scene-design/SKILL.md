# AI 漫剧场景设计

根据剧本或场景描述，产出**场景提示词**与**场景概念图规格**，供后续分镜与成片使用。概念图为多维度视觉参考（主视图、多视角、多光照、细节特写、色标卡）。

## 何时使用

- 用户要求「场景设计」「场景概念图」「为某场景出设定」
- 从重要场景文档（如「重要场景.md」）中抽取单场做视觉设定
- 需要空镜/环境参考图、无人物场景概念图

## 场景提示词结构

提示词按固定维度组织，便于模型稳定输出与后续修图：

| 维度 | 说明 | 示例 |
|------|------|------|
| **镜头/人物约束** | 括号标注，明确是否空镜、是否有人 | `(空镜头)，(无人物)` |
| **画风** | 统一视觉风格 | 国风动漫CG风、赛博朋克、日式奇幻 |
| **场景主题/名称** | 一句话场景定位 | 废柴崖底剑冢，古风剑冢 |
| **核心元素** | 主体与关键道具，可带括号强调无人物 | 满屏插着宝剑的石堆，宝剑剑身有符文，周围地面刻着上古符文，中央有一个石棺（无人物） |
| **光影与氛围** | 光照与情绪 | 光影斑驳（剑冢的神秘氛围） |
| **收尾约束** | 再次强调无人/静止 | 画面中空无一人，只有静止的景物 |

### 提示词模板

```text
(镜头类型)，(人物约束)，画风，场景名称/主题，核心元素1，核心元素2，……，光影描述（氛围说明）。收尾约束句。
```

### 示例一：单张场景提示词（仅场景描述）

用于生成单张主视图或其中某一格时使用：

```text
(空镜头)，(无人物)，国风动漫CG风，废柴崖底剑冢，古风剑冢，满屏插着宝剑的石堆，宝剑剑身有符文，周围地面刻着上古符文，中央有一个石棺（无人物），光影斑驳（剑冢的神秘氛围）。画面中空无一人，只有静止的景物。
```

### 示例二：概念图版式提示词（场景 + 布局）

用于一次性生成整张概念图时，在场景描述前加上**版式与布局**说明，使输出包含主场景、多视角、多光照、局部特写和色标卡：

```text
【版式】一张 AI 漫剧场景概念图，网格排版，包含：中央偏右为主场景大图；顶部或左侧为同一场景的四视角（正视图、侧视图、俯视图、仰视图）与三光照（白昼、黄昏、夜晚）；底部一排为局部特写（剑身符文、苔藓岩石、地面法阵、石棺纹样）；右侧或底部为色标卡（主色、辅助色、点缀色，附 HEX）。【场景】(空镜头)，(无人物)，国风动漫CG风，废柴崖底剑冢，古风剑冢，满屏插着宝剑的石堆，宝剑剑身有符文，周围地面刻着上古符文，中央有一个石棺（无人物），光影斑驳（剑冢的神秘氛围）。画面中空无一人，只有静止的景物。
```

更多模板与变体见 [references/prompt-template.md](references/prompt-template.md)。

## 场景概念图规格

概念图是一张**综合排版图**，包含以下区块，为分镜与后期提供统一参考：

| 区块 | 内容 | 用途 |
|------|------|------|
| **主场景** | 中央大图：完整环境 + 核心元素 + 主光源 | 成片主镜头参考 |
| **多视角** | 同一场景：正视图、侧视图、俯视图、仰视图 | 机位与构图参考 |
| **多光照** | 白昼 / 黄昏 / 夜晚（或剧本指定时段） | 时间与气氛参考 |
| **局部特写** | 关键道具/纹理：如剑身符文、岩石苔藓、地面法阵、石棺纹样 | 特写与材质参考 |
| **色标卡** | 主色、辅助色、点缀色（含 HEX 或描述） | 配色与后期统一 |

布局建议：主视图居中偏右，多视角在顶部或一侧，多光照一列，局部特写底部一排，色标卡在右侧或底部。

详细版式与网格说明见 [references/concept-image-spec.md](references/concept-image-spec.md)。

## 工作流

1. **输入**：剧本片段、重要场景表（如「重要场景.md」中单条）、或用户口头描述。
2. **提炼**：从「地点」「视觉要点」「情绪」中抽取场景名、核心元素、氛围。
3. **写提示词**：按模板填充分镜约束、画风、元素、光影与收尾句。
4. **写概念图需求**：说明需要主视图 + 多视角 + 多光照 + 局部特写 + 色标卡；若有指定视角或时段，在需求中写明。
5. **输出**：
   - 场景提示词（可直接用于文生图）
   - 概念图规格说明（用于生成或外包概念图）

## 与其它技能配合

- 漫画分镜：可复用本技能产出的场景概念与色标做背景与气氛参考。
- 文生图：用本技能产出的提示词生成单张主视图，或分批生成多视角/多光照/特写，再拼成概念图。
- 文章配图：若需「场景式」插图，可复用本技能的提示词结构与画风维度。

## 输出示例

**场景提示词**：单张主视图/单格用「示例一」；一次性出整张概念图用「示例二」（含版式描述）。

**概念图需求摘要**：

- 主视图：废柴崖底剑冢，石棺居中、剑冢与符文法阵，柔和日光。
- 多视角：正、侧、俯、仰各一。
- 多光照：白昼、黄昏、夜晚。
- 特写：剑身符文、苔藓岩石、地面法阵、石棺浮雕。
- 色标：主色（深灰绿/古金）、辅助色、点缀色（符文/光效），附 HEX。
