# awesome-ai-research-writing

This local skill wraps the upstream repository:

- `https://github.com/Leey21/awesome-ai-research-writing`

The upstream repo is not a native Codex skill repo and does not ship its own
`SKILL.md`. It is mainly a curated collection of research-writing tools and
agent workflows. This wrapper exists so the repository can live inside
`~/.codex/skills` and be referenced like other installed skills.

## How to use

Start with:

- `README.md`

That file is the main entry point and contains the curated references, workflow
notes, and linked tools.

## Scope

Use this skill as a **reference/index skill**, not as an executable workflow
skill. It is best for:

- surveying research-writing tools
- comparing writing-agent setups
- finding related repositories and prompts
- collecting ideas for paper-writing workflows

## Installed contents

- upstream `README.md`
- upstream `images/`

No behavior was added beyond this wrapper metadata.
