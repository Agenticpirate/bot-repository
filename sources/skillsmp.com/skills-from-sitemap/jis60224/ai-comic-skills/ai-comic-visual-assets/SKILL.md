# AI 漫剧视觉资产提示词生成技能

本技能是 ai-comic-script（剧本生成）的下游环节：剧本写好之后，把剧本里最重要的人物、场景和道具，转成一套可复用的 AI 生图提示词，帮用户搭建自己的**视觉资产库**。

目标只有四句话：**人物要稳定，场景要统一，道具要清楚，画风要一致。** 这一步做好了，后面做分镜、视频生成、剪辑成片才不会越做越乱。

## 核心原则

1. **所有回复使用中文。**
2. **母版思维**：每个人物、场景、道具都先做一个"母版"提示词。母版是后续所有镜头的一致性锚点——人物不变脸、场景不换调、道具不走样，靠的就是反复参考母版。
3. **全剧画风统一**：先确定一个画风前缀（如"写实3D风，民国悬疑氛围"），之后所有人物、场景、道具提示词共用。不要女主写实3D、男主日系二次元。
4. **先信息表，后提示词**：提示词写不好，多半是信息没想清楚。先把记录表填完整并让用户确认，再转成提示词。
5. **负面约束必带**：每条提示词都要附负面约束，这是保证出图稳定的关键。
6. **所有产出落盘**：提示词、信息表、命名规范都写入文件，不要只在对话里输出。
7. **本技能产出提示词，不直接生成图片**：默认引导用户把提示词复制到 AI 绘图工具（即梦、Midjourney、Vidu 参考生图等）。如果当前环境有可用的图像生成工具且用户同意，也可以代为调用。

## 工作流程

### 阶段零：定位剧本来源（每次会话开始时执行）

1. **扫描当前目录**，查找 ai-comic-script 生成的剧本项目文件夹（特征：包含 `00_剧本概览.md`、`01_核心人设.md`、`04_第XX集_完整剧本.md` 等文件）。
2. **找到剧本项目**时，读取：
   - `00_剧本概览.md` —— 剧名、题材、受众（决定画风和氛围词）
   - `01_核心人设.md` —— 角色身份、性格、人物关系
   - `04_第XX集_完整剧本.md` —— 默认第1集，用户指定则用指定集数
   - `05_关键画面清单.md`（如有）—— 直接提示核心场景和关键道具
3. **找到多个项目**：列出项目名，让用户选择。
4. **没有剧本项目**：请用户提供以下材料（可以直接粘贴剧本原文，由技能自行提取）：
   剧名、故事题材、核心人设、人物关系、第x集完整剧本、关键画面清单、核心场景、关键道具。
   缺少其中几项没关系，剧本原文是最低要求。
5. **检查是否已有视觉资产文件**（续作模式）：如果项目里已有 `07_视觉资产/`，先读 `00_视觉资产总览.md`，向用户汇报已完成的人物/场景/道具和既定画风，询问是继续补充、还是优化已有提示词。续作时必须沿用已确定的画风，不要重新设计；不要重新创建或覆盖 `07_视觉资产/` 内已有文件。
6. **防止覆盖**：续作模式下，`00_视觉资产总览.md`、`01_人物提示词.md`、`02_场景提示词.md`、`03_道具提示词.md` 都是全剧共享文件。为第2集及后续集数补充素材时，只能追加新角色/新场景/新道具段落，或在用户明确要求优化某个既有素材时局部修改对应段落；禁止整文件重写覆盖第1集内容。
7. **补齐待补素材**：如果项目里已有 `08_分镜脚本/` 或 `09_视频提示词/`，搜索其中的 `待补素材_*`。当用户要求补素材、补齐待补资产、继续制作视频素材时，把这些待补项按人物/场景/道具/屏幕特写/剧情变体分类，优先生成缺口最大的资产提示词；已经在 `07_视觉资产/` 中存在的同名素材不要重复生成。

### 阶段一：确定全剧统一画风

根据题材向用户推荐画风并**确认一次**，之后全程沿用：

| 题材 | 推荐画风前缀示例 |
|------|------------------|
| 民国悬疑 | 写实3D风，民国悬疑氛围 |
| 现代都市 / 甜宠 | 写实3D风，现代都市氛围 |
| 古风权谋 / 玄幻 | 写实3D风，古风氛围（或国风厚涂） |
| 末世 / 科幻 | 写实3D风，末世废土氛围 |

没有特殊偏好时默认**写实3D风**。画风一旦确认就写进 `00_视觉资产总览.md`，中途更换意味着已生成的素材全部作废，所以确认这一步不能省。

### 阶段二：人物提示词

**1. 提取核心人物**，按优先级：

| 角色 | 是否必做 | 作用 | 优先级 |
|------|----------|------|--------|
| 主角 | 是 | 推动主线，承担主要情绪 | 高 |
| 重要对手 / 反派 | 视剧情 | 制造冲突和压迫感 | 高 |
| 核心搭档 / 情感对象 | 视剧情 | 关系拉扯、辅助推进 | 中高 |
| 本集关键配角 | 视剧情 | 提供线索 | 中 |
| 路人角色 | 否 | 氛围补充，不做母版 | 低 |

第一批建议只做 2-3 个核心人物。重点不是数量，是先把核心人物做稳。

**2. 填写人物基础信息表**（每个人物一张）：

| 项目 | 内容 |
|------|------|
| 角色姓名 / 性别 / 年龄感 / 身份职业 / 时代背景 / 发型 / 服装 / 五官气质 / 身材体态 / 性格关键词 / 视觉关键词 | 从剧本和人设文件提取 |

信息能从剧本提取的必须提取；剧本没写的（如具体发型、服装细节）由技能结合人设合理设计，并标注"（设计补充，可调整）"，让用户确认。

**3. 生成人物母版提示词**，模板：

```
【画风前缀】，角色设定图，一位【年龄感】的【身份职业】，【五官气质】，【发型描述】，【服装描述】，【姿态动作】，人物居中，纯白背景，高清细节，画风统一，适合AI漫剧人物母版。

负面约束：不要多人，不要道具，不要复杂背景，不要场景元素，不要换发型，不要换服装，不要夸张表情，不要畸形手指，不要模糊，不要低清，不要画风混乱。
```

时代剧（民国、古风等）的负面约束中追加"不要现代服饰"；现代剧改为对应的穿帮约束（如"不要古装"）。

**4. 同步给出该角色的三视图补充图提示词**（人物母版确认后使用），模板：

```
参考已确认的角色母版，保持同一位角色的一致性：同一张脸、同一发型、同一服装、同一年龄感、同一气质与整体画风不变。

请在同一张图中生成该角色的人物设定合集：左边展示该角色的头像图，右边依次展示正面全身、90°侧面全身、背面全身三视图，一共4种样式，图片16:9。所有人物都必须是同一个角色，不是不同人物。

右侧三视图人物并排展示，站姿自然挺直，比例一致，服装细节保持统一，发型长度和轮廓保持一致。左侧头像图需要清晰展示人物五官、发型和气质，方便后续作为角色脸部参考。

画面为干净纯色背景，背景不要复杂场景，不要道具，不要额外人物。整体构图清晰，适合作为AI漫剧角色母版、人物一致性参考和后续图生视频使用。
```

另外建议用户补充：情绪近景图、手持关键道具图（按剧情需要给出对应提示词）。

### 阶段三：场景提示词

**1. 提取核心场景**，优先提取本集中的：

1. 开头钩子场景；2. 主要冲突发生场景；3. 人物关系建立场景；4. 关键线索出现的场景；5. 结尾悬念场景。

**2. 填写场景视觉信息表**（每个场景一张）：

| 项目 | 内容 |
|------|------|
| 场景名称 / 时代背景 / 空间类型 / 核心元素 / 光线 / 色调 / 氛围 / 关键道具 / 画风 | 不要只写"雨夜巷口"，要写清楚这个场景长什么样 |

色调和氛围要服务剧情情绪：悬疑用蓝灰冷调、压抑；甜宠用暖调、明亮。同一场戏在不同集里出现时，必须复用同一个场景母版的设定。

**3. 生成场景提示词**，模板：

```
【画风前缀】，AI漫剧场景设定图，【时代背景】，【空间类型】，【核心元素】，【关键道具】，【光线描述】，【色调】，【氛围关键词】，画面层次清晰，高清细节，前景预留人物站位，适合后续作为AI漫剧场景母版。

负面约束：不要风格混乱，不要人物抢主体，不要文字乱码，不要低清，不要模糊。
```

时代剧追加"不要现代建筑，不要现代车辆"。"前景预留人物站位"很重要——场景母版后续要放人物进去，画面太满会没法用。

### 阶段四：道具提示词

只挑**承担线索、伏笔、反转、悬念作用**的关键道具（信封、照片、玉佩、戒指、旧报纸、药瓶、钥匙、证件等），普通陈设不单独做。

道具提示词模板：

```
【画风前缀】，AI漫剧关键道具设定图，一个【道具名称】，【材质】，【颜色】，【状态】，【细节特征】，【与剧情相关的视觉重点】，简洁背景，高清细节，适合后续作为关键线索特写。

负面约束：不要人物，不要多余物品，不要文字乱码，不要低清，不要模糊。
```

"与剧情相关的视觉重点"指观众必须一眼看懂的信息点，例如"手套内侧有一小块暗红色印记"。道具图不需要复杂，但一定要清楚、稳定、能被观众看懂。

### 阶段五：文件输出

有剧本项目时，在剧本项目文件夹内创建 `07_视觉资产/`；没有剧本项目时，在当前目录创建 `【剧名】_视觉资产/`。结构：

```
07_视觉资产/
├── 00_视觉资产总览.md          # 既定画风、人物/场景/道具清单与完成状态（续作时的核心索引）
├── 01_人物提示词.md            # 每个人物：信息表 + 母版提示词 + 三视图提示词 + 建议保存命名
├── 02_场景提示词.md            # 每个场景：信息表 + 场景提示词 + 建议保存命名
├── 03_道具提示词.md            # 每个道具：提示词 + 建议保存命名
└── 04_生成检查与优化记录.md     # 用户反馈的问题、对应的优化指令（迭代时追加）
```

#### 续作文件管理：

- **首次生成视觉资产**：可以创建 `07_视觉资产/` 和上述文件。
- **后续集数补充素材**：禁止覆盖已有文件；在共享文件内追加 `## 第XX集新增素材` 或具体角色/场景/道具的新段落。
- **待补素材补齐**：从 `08_分镜脚本/` 或 `09_视频提示词/` 读取到的 `待补素材_*`，按类型追加到对应文件：人物进 `01_人物提示词.md`，场景和剧情变体进 `02_场景提示词.md`，道具/屏幕/线索特写进 `03_道具提示词.md`。
- **已有素材复用**：如果第2集继续使用第1集已生成的人物、场景或道具，只在总览中标注复用，不要重复生成同名段落。
- **已有素材优化**：只有用户明确要求优化某个素材时，才局部更新该素材段落，并把变更原因追加到 `04_生成检查与优化记录.md`。
- **总览更新**：`00_视觉资产总览.md` 作为索引文件，只追加或局部更新清单行和完成状态，不要整文件重写。

同时在总览文件里给出**素材图片文件夹结构建议**（用户保存生成图用）：

```
【剧名】_视觉素材/
01_人物母版 / 02_人物补充图 / 03_场景母版 / 04_关键道具 / 05_上传Vidu母版素材 / 06_待优化素材
```

**图片命名规范**（写进每条提示词下方，提醒用户按此保存）：

```
角色母版_女主黎书意_民国记者_冷调悬疑.png
角色补充_女主黎书意_三视图_人物设定.png
场景母版_雨夜巷口_冷调悬疑.png
道具_白色手套_线索特写.png
Vidu母版_女主黎书意_角色参考.png
```

命名格式：`类型_名称_特征/用途.png`。清楚的命名是素材库能长期复用的前提。

### 阶段六：生成后检查与迭代优化

用户把提示词拿去绘图工具生成后，会带着结果（描述或截图）回来。此时：

1. 读取 [references/quality-check.md](references/quality-check.md)，按人物 / 场景 / 道具对应的检查清单逐项核对。
2. 遵循"**哪里不对，就补哪里**"：针对暴露的问题生成针对性优化指令（保持没问题的部分不变），不要整段推翻重写提示词。
3. 把问题和优化指令追加记录到 `04_生成检查与优化记录.md`。
4. 结果基本满意后，提醒用户：将该图定为母版 → 按命名规范保存 → 生成三视图等补充图 → 再做下一个人物/场景。

### 阶段七：Vidu 参考母版上传指引（素材确认后）

人物母版、补充图、场景母版、道具图都确认后，引导用户上传到 Vidu 建立可反复调用的参考母版：

1. **上传人物**：Vidu →「参考生图」→「+ 主体」→「我的」→「+」→「创建静态主体」→ 上传人物母版和三视图 → 填角色姓名、选符合气质的音色 →「确定」。
2. **上传场景和道具**：用同样方式创建参考素材，填清楚名称和描述。
3. 原则：**先选稳的，再上传**。不是上传越多越好，只上传确认过、后续会复用的母版。

## 注意事项

1. **画风统一是底线**：同一部剧的所有人物、场景、道具必须共用画风前缀，发现用户要求的风格互相冲突时要主动提醒。
2. **时代一致性**：时代剧严防穿帮（民国剧出现现代车辆、古装剧出现手机），负面约束和检查清单都要覆盖。
3. **不追求一次完美**：第一版提示词把身份、发型、服装、气质、画风写清楚即可，靠阶段六的迭代逐步收敛。
4. **节奏控制**：一次会话先做稳 2-3 个人物 + 2-3 个场景 + 关键道具，不要一口气铺开全剧。
5. **参考图加成**：用户如果已有喜欢的人物/画风参考图，提醒他们连同提示词一起喂给绘图工具，能显著提高出图符合度。
6. **跨会话续作**：每次会话先执行阶段零，已有 `07_视觉资产/` 时沿用既定画风和命名，不要另起炉灶。
