# AI 漫剧分镜拆解技能

本技能是 ai-comic-script（剧本生成）和 ai-comic-visual-assets（视觉资产）之后的制作环节：把剧本拆成一条条能被 AI 生成、Vidu 图生视频和剪辑执行的镜头脚本。

分镜不是把剧本平均切开，而是根据剧情目的和情绪变化，把故事拆成有远有近、有动作有情绪、有道具有悬念的镜头组合。

## 核心原则

1. **所有回复使用中文。**
2. **绝对忠于原剧本**：不改剧情、不新增剧情、不删剧情、不修改任何一句原台词。长台词可以拆到多个镜头里，但文字必须保持原意和原句。
3. **镜头服务剧情和情绪**：每个镜头至少承担一个功能：推进剧情、交代环境、展示动作、放大情绪、强调伏笔、制造悬念或衔接前后镜头。
4. **画面必须可生成**：每个镜头写清人物、动作、表情、站位、场景、道具、光线、氛围、镜头重点，避免"她很难过""气氛复杂"这类抽象表达。
5. **节奏必须适合短剧和漫剧**：单镜头时长控制在 0.66 秒到 4 秒之间，并且有快慢变化。
6. **优先复用已有素材**：项目里已有 `07_视觉资产/` 时，分镜必须标注每个镜头使用的人物、场景、道具母版；缺素材时标为 `待补素材_名称_用途`。
7. **所有产出落盘**：分镜准备记录、正式分镜表、检查与修改记录都写入文件，不要只在对话里输出。

## 工作流程

### 阶段零：定位剧本和素材来源（每次会话开始时执行）

1. **扫描当前目录**，查找 ai-comic-script 生成的剧本项目文件夹。典型文件包括：
   - `00_剧本概览.md`
   - `01_核心人设.md`
   - `03_分集看点表.md`
   - `04_第XX集_完整剧本.md`
   - `05_关键画面清单.md`
2. **找到目标项目后读取必要上下文**：
   - 剧本概览：剧名、题材、受众、单集时长、风格
   - 核心人设：角色身份、性格、关系、视觉要点
   - 分集看点：目标集的核心剧情和结尾悬念
   - 目标集完整剧本：默认第1集，用户指定则读取指定集数
   - 关键画面清单：如存在，优先作为分镜重点
3. **检查视觉资产**：
   - 如果已有 `07_视觉资产/`，读取 `00_视觉资产总览.md`、人物/场景/道具提示词文件，提取可复用素材名称。
   - 如果没有视觉资产，也可以先拆分镜，但要在"使用素材"列标注建议补充的素材。
4. **检查是否已有分镜产物**：
   - 如果已有 `08_分镜脚本/`，先读取 `00_分镜总览.md` 和目标分镜表，向用户说明当前进度，再继续补充或修改。
   - 为第2集及后续集数生成分镜时，禁止覆盖已有总览、检查记录或其他集数分镜表。先检查目标文件是否存在；存在时只有用户明确要求修改该集，才局部更新或重写该目标集文件。
5. **没有剧本项目时**，请用户提供最低材料：目标集完整剧本或片段原文。可选补充：本集核心看点、结尾悬念、人物设定、场景设定、已有素材清单。

### 阶段一：确定分镜范围

1. 如果用户指定"第X集完整分镜"，拆完整集。
2. 如果用户只说"练习分镜"或"拆一段"，优先选择有冲突、有情绪、有画面变化的片段，例如：
   - 主角发现秘密
   - 主角被羞辱
   - 反派第一次施压
   - 男女主第一次对峙
   - 关键道具出现
   - 主角准备反击
   - 结尾悬念揭开一半
3. 记录以下信息，写入 `00_分镜总览.md`：

```Markdown
我选择的分镜片段是：__________
这个片段对应第几集：__________
这个片段的剧情作用是：__________
分镜目标：完整集 / 重点片段 / 修改已有分镜
素材状态：已有视觉资产 / 部分缺失 / 未生成视觉资产
```

### 阶段二：正式拆镜头前先做三件事

**1. 标出情绪变化**

```Markdown
这段剧情的情绪变化是：

1、开头：__________
2、中段：__________
3、结尾：__________
```

**2. 圈出必须被观众看见的信息**

```Markdown
这段剧情必须拍出来的信息：

1、人物：
2、场景：
3、关键动作：
4、关键道具：
5、关键表情：
6、剧情转折：
7、结尾悬念：
```

**3. 拆出动作节点**

```Markdown
动作节点：

1、
2、
3、
4、
5、
6、
7、
8、
```

这一步只拆"人物做了什么、观众必须看见什么"，先不要急着设计高级镜头。

### 阶段三：把动作节点转成镜头

**景别判断口诀**

| 镜头目的 | 推荐景别 |
|----------|----------|
| 交代环境、人物处境、空间关系 | 远景 / 全景 |
| 讲清人物行动、双人互动、对话关系 | 中景 |
| 放大表情、情绪变化、心理反应 | 近景 |
| 突出眼神、手部动作、关键道具、伏笔线索 | 特写 |

**运镜判断规则**

| 镜头目的 | 推荐运镜 |
|----------|----------|
| 稳定交代信息 | 固定镜头 |
| 放大情绪、压迫感、悬念 | 缓慢推镜头 |
| 展示人物处境、疏离感 | 轻微拉镜头 |
| 跟随人物行动 | 跟镜头 |
| 揭示新信息、转移视线 | 轻微摇镜头 |
| 展示空间移动 | 横向移镜头 |

**画面描述模板**

```Markdown
【景别】，人物位于【位置】，正在【动作】。人物表情【表情状态】，画面中出现【关键道具 / 环境元素】。光线与氛围【氛围关键词】，这个镜头重点表现【镜头作用】。
```

反面写法：`女主很紧张。`

合格写法：`近景，女主站在雨夜巷口，伞沿压低，雨水顺着伞面滑落。她听到身后异响后微微停住，眼神从疑惑转为警觉，手指不自觉攥紧伞柄。`

### 阶段四：处理长台词、音效和时长

1. **长台词不能一镜到底**：如果一句台词预计超过4秒，必须切到倾听者反应、手部细节、关键道具、环境空镜或空间关系镜头。
2. **台词不许乱改**：台词跨镜头延续时，在"台词与音效"栏标注 `人物（画外音）：原台词` 或 `人物（画外音，延续上一句）：原台词片段`。
3. **音效合并到同一格**，不要逐个换行。推荐格式：

```Markdown
环境音：雨声；动作音：脚步声、门被推开的声音；情绪音：低频压迫音、心跳声
```

4. **时长参考**：
   - 普通信息镜头：1-2秒
   - 环境交代镜头：2-3秒
   - 情绪近景：2-3秒
   - 道具特写：1-2秒
   - 关键爆点、反转、悬念结尾：3-4秒

### 阶段五：输出正式分镜表

有剧本项目时，在项目文件夹内创建 `08_分镜脚本/`；没有剧本项目时，在当前目录创建 `【剧名或项目名】_分镜脚本/`。

推荐结构：

```text
08_分镜脚本/
├── 00_分镜总览.md              # 全剧分镜索引；按集追加片段选择、情绪变化、关键信息、动作节点、素材状态
├── 01_第XX集_完整分镜表.md      # 完整集分镜；如只拆片段，文件名改为片段名
└── 02_分镜检查与修改记录.md      # 自检结果、用户反馈、修改记录；按集追加
```

#### 续作文件管理：

- **每集分镜独立文件**：第1集保存为 `01_第01集_完整分镜表.md`，第2集保存为 `01_第02集_完整分镜表.md`，以此类推。
- **目标文件存在时禁止覆盖**：生成前必须检查 `01_第XX集_完整分镜表.md` 是否已存在。存在时，不要覆盖；除非用户明确要求修改该集，否则询问是编辑现有分镜、生成下一集，还是另存为 `01_第XX集_完整分镜表_v2.md`。
- **总览只追加**：`00_分镜总览.md` 是全剧分镜索引。第2集及后续集数应追加 `## 第XX集分镜总览` 段落，不要替换第1集总览。
- **检查记录只追加**：`02_分镜检查与修改记录.md` 按集追加检查结果和修改记录，不要重写旧记录。
- **片段分镜命名防冲突**：如果只拆某一片段，文件名使用 `01_第XX集_片段名_分镜表.md`；同名文件已存在时，追加 `_v2` 或先询问用户。

正式分镜表默认使用以下列：

| 列名 | 要求 |
|------|------|
| 镜号 | `01、02、03...`，按播放顺序排列 |
| 原剧本内容 | 对应原剧本动作、画面描述或台词，不改原意 |
| 景别与运镜 | 如 `特写 / 固定镜头`、`中景 / 缓慢推镜头` |
| 画面内容描述 | 写清人物动作、表情、站位、环境氛围、机位角度、画面重点 |
| 人物动作/表情 | 单独提炼给制作人员快速查看 |
| 台词与音效 | 保留原台词；画外音必须标注；音效合并同格 |
| 预估时长 | 0.66秒到4秒之间 |
| 使用素材 | 已有素材写具体名称；缺素材写 `待补素材_名称_用途` |

如果用户明确要求精简表，至少保留五列：`镜号 | 景别与运镜 | 画面内容描述 | 台词与音效 | 预估时长`。

### 阶段六：最终自检与修改

输出正式分镜前，必须读取 [references/storyboard-quality-check.md](references/storyboard-quality-check.md)，按检查清单逐项自检。

发现问题时不要整表推翻，按"哪里不顺补哪里"修改：

1. 景别太单一：补环境镜头、近景、特写或空镜。
2. 动作跳跃：补转头、低头、抬手、蹲下、递物、反应镜头。
3. 情绪突兀：补近景、眼神、手部细节或呼吸停顿。
4. 线索不清：补道具特写，并把道具放到画面描述前半句。
5. AI 不好生成：把抽象情绪改成人物可见动作、表情、道具和光线。
6. 素材缺失：标注 `待补素材`，并说明建议交给 ai-comic-visual-assets 补齐。

每次修改后，把"问题 → 修改策略 → 修改结果"追加到 `02_分镜检查与修改记录.md`。

## 注意事项

1. **不要把分镜写成导演炫技清单**：新手分镜优先用固定、推、拉、跟、摇、移这些简单运镜。
2. **不要所有镜头都写成中景对话**：短剧和漫剧需要环境、动作、情绪、道具、悬念之间的节奏变化。
3. **不要让素材列泛化**：写 `女主母版_黎书意；场景母版_雨夜巷口`，不要只写"女主素材"。
4. **不要忽略声音**：没有台词的镜头也要写环境音、动作音或情绪音。
5. **不要强行一集全拆**：用户是练习或素材不完整时，先拆 5-8 个关键镜头，把方法跑通。
