# AIGC 视频创作

把创意编译成模型能够执行的导演契约：先锁定一个可验收的主结果和最大失败瓶颈，再匹配控制方式，闭合素材职责、状态变化、空间/表演、摄影机、声音与结束状态；完成一次失败机制审查与最小补丁优化后，只交付唯一最终提示词。

## 事实优先级与读取路由

平台事实以 [Seedance 2.5 官方指南摘要](references/seedance-2.5-official-guide.md) 为准；项目启发式不得改写官方参数，外部创作者经验不得写成模型保证。

每次任务完整读取：

- [审查与优化闭环](../../references/quality-guides/审查与优化闭环.md)
- [视频提示词质量门禁](references/prompt-quality-gates.md)

再按任务读取，不加载无关 reference。历史反馈通常只选一组；每增加一组都必须对应当前任务的一项明确需求或可观察失败，禁止整库加载：

## 核心流程

1. **定主结果**：确认模式、时长、画幅、主体、声音需求和硬约束；把创意压成唯一可观察的 `初态 → 变化/保持 → 末态`，并明确允许模型决定的内容。
2. **分配控制预算**：在身份、运动、空间/世界、声音和文字中选择一个主要投入、最多一个次要投入；其余主动简化。无法收敛为一个主要投入时拆镜。
3. **选控制方式**：先处理素材是否真实存在，再按最大瓶颈选择文字、首/尾帧、动作参考、白模、视频延长、编辑或拆镜。关键结果超出文字能力时升级控制，不靠加长 Prompt 掩盖。
4. **编素材职责**：只保留最小充分素材集。每个素材只有一个主职责；多素材重叠时写明冲突优先级，动作/运镜参考还要写明不能继承的身份、场景或声音。不存在或未上传的素材不得伪装成可用 `@引用`。
5. **编导演契约**：素材携带已经可见的状态，文字只补变化。先写一句话概述，再用少量因果节拍闭合空间、动作/表演、摄影机职责、光线/材质响应、关键声音和结束状态。叙事意图必须落到可拍到的行为或声音。
6. **压缩与审查**：删除素材已有信息、重复形容词、伪精确数字、同级冲突、无职责素材和与主结果竞争的细节。按质量门禁只列有证据的 `P0/P1/P2`，保留已通过内容并自动修复 `P0/P1`。
7. **聚焦验收**：只复查修改项及直接依赖；最终提示词中必须能定位主结果、最大瓶颈的控制者和可确认末态。简单任务没有实质风险时不虚构问题。
8. **验证与反馈**：保存 Markdown 时运行引用校验；提示词通过不等于成片通过。用户回传成片后切换到 `aigc-feedback`，按最早失败时间点只修改一个控制变量；同一失败连续两轮仍出现时升级控制方式或拆镜。

## 默认提示词契约

仍使用官方基础顺序，但空字段直接省略：

```text
[@素材及唯一职责；没有素材时省略]

【一句话概述】主体 + 地点 + 核心事件/变化 + 必要风格与镜头形式。
【具体情节】按少量节拍写可见状态变化、表演/动作和摄影机响应；必要时补一句导演意图。
【全局补充】只保留持续成立的身份、空间、光线/材质、声音和最相关禁止项。
```

项目默认节奏密度：

- `4–15 秒`：一个核心变化，通常用“开始—随后—最后”即可；只有时序确实影响执行时才写秒段。
- `16–30 秒`：一个完整场景单元，通常包含建立、发展、停顿/反应、改变和余韵；停顿可以承担叙事，不要求每秒都有动作。
- `30–180 秒`：按叙事阶段覆盖完整时长；每段只承担一个清楚变化，不把长片压成连续事件清单。

“电影感”不等于低饱和或胶片颗粒。只写与目标有关的可见因果：光源怎样落到人物与环境、材质怎样响应光线、人物是否真正处在同一空间、声音怎样与动作和远近关系同步。

## 模式最小结构

| 模式 | 最小结构 |
|---|---|
| 基础生成 | 素材职责（可省）→ 一句话概述 → 情节/故事线 → 全局补充 |
| 约 30 秒 | 一句总述 → 全局设定 → 覆盖全长的少量场景节拍；素材层仅在存在素材时写 |
| 30–180 秒 | 总时长/画幅 → 素材职责 → 一句话概述 → 分阶段时间轴 → 全局连续性 |
| 视频延长 | 延长方向与秒数 → 原视频末态 → 新增内容与结果；不重写已有部分 |
| 智能/高级编辑 | 具体对象 → `A → B` 的变化 → 生效时序；有标注时先写标注区域 |
| 粗颗粒度白模 | 动态骨架职责 → 对应关系 → 必须保持的动作/运镜节拍 → 场景与材质升级 |
| 细颗粒度白模 | 渲染职责 → 分段材质/光影 → 去除辅助线与相机标记 → 整体收束 |

## 输出边界

- 用户只要提示词时，输出一段简短 `## 审查摘要`，再输出 `## 视频提示词` 和一个连续代码块；不展示内部初稿、完整检查表或第二套同义版本。
- 只有素材真实存在、引用职责闭合且控制方式足够时，才能标为“可直接投喂”或“按表上传后可直接投喂”。高风险动作缺少必要参考时，明确执行条件。
- 简单 prompt-only 不创建资产包。只有用户要求完整方案且确实缺少关键视觉控制时，才补最少量图片提示词；用户授权实际生图时按 `image-design → imagegen` 执行并记录真实文件。
- 不声称已经生成外部视频；不伪造文件路径、平台编号、hash 或上传状态。
