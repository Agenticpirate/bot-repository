# 格兰书院三位一体交易系统

> 来源：格兰书院216个口播稿蒸馏，保留核心方法论，去除口播语气。

---

## 一、系统总论

**三位一体 = 均线 + 结构 + 时空**

| 要素 | 视角 | 作用 |
|------|------|------|
| **均线** | 局部 | 描述力度和方向（"外科"） |
| **结构** | 全局 | 判断所处阶段和拐点（"内科"） |
| **时空** | 多周期 | 级别嵌套确认（可靠性） |

> 单个指标只是"必要不充分条件"，必须三要素共振才能交易。
> 不存在神奇指标，任何单一信号（金叉、死叉、布林带）都无法支撑交易。
> 结构告诉你方向，不告诉你高度。妄想找到幅度是痴人说梦。

## 二、均线系统

### 2.1 均线设置
- **55线**：核心均线（斐波那契数列），日线上是最重要的参考
- **233线**：≈ 周线55线，大级别支撑/压力。「不存在233，只有55」
- 黄金分割线：仅用于上证指数（1664-3361区间锁定），个股只用55+233

### 2.2 均线本质
- 不是平均成本，不是持仓成本（T+0可以来回倒，算成本无意义）
- **本质是概率线**：均线 ≈ 收盘价的移动平均线 → 近似描述了"趋势容易发生转折的高概率轨迹"
- 均线只是影子，它描绘的是行为心理学上的关键位置
- 55和233用菲波纳契数列：比常用60/250线略提前，更容易提前抓到拐点

### 2.3 均线四大性质

| 性质 | 说明 |
|------|------|
| **支撑/压制** | 均线天然具有支撑（下方）和压制（上方）两种特性 |
| **牵引** | 突破/跌破后产生回抽：强势回抽（不碰均线）、正常回抽（碰均线弹回即走）、弱势回抽（穿均线） |
| **共振** | 55线与233线同向发力时效果倍增 |
| **统一** | 233线本质是下一级别（周线）的55线 |

### 2.4 四种有效突破/跌破（必须秒反应！）

**多头突破：**

| 类型 | 特征 | 强度 | 逻辑 |
|------|------|------|------|
| **A 典型突破** | 放量阳线直接穿过均线 | ⭐⭐⭐ | 直接有力 |
| **B 慢速/盘整突破** | 在均线上下来回盘整后突破 | ⭐⭐ | 耗时但确认充分 |
| **C 回踩突破** | 先突破均线，回踩确认（破了均线又弹回），再上 | ⭐⭐⭐⭐ | 洗盘充分 |
| **D 反向突破** | 碰到均线立刻反弹，根本不破均线 | ⭐⭐⭐⭐⭐ | **最强信号** |

**空头跌破：A/B/C/D镜像反过来**

**D最强的内因逻辑**：均线天然有压制（空头占有利地形），但空头在有利地形下仍然被多头打败 → 多头极强。类比：敌军从山上往下打本来占优，但被我军消灭 → 我军实力碾压。

**C vs D 区分**：C是先破了均线再回抽回来，D是根本没碰到均线就弹起来了。记忆口诀：碰到就反 = D，先破再回 = C。

**突破关键K要求**：突破均线这根K必须是放量的有力突破。缩量或长上影线 → 无效突破。

## 三、结构系统

### 3.1 背离

**本质**：价格与某个指标产生矛盾。
- 价格 vs MACD = MACD背离（最常用）
- 价格 vs KDJ = KDJ背离
- 价格 vs 成交量 = 量价背离

**背离四大特征**：
1. 背离是一种**过程**，不是瞬间事件。背离是矛盾发生的状态。
2. **没有新高/新低，不要轻言背离**。震荡区间内类似布朗运动，随机游走。
3. 描述趋势可用多种技术指标。
4. **任何拐点都在某个级别的顶底背离中产生**。日线找不到 → 60分钟 → 15分钟 → 5分钟，总能找到。

**关键规则**：
- MACD黄白线从高位回到**零轴** = 调整完成的**必要不充分条件**。到零轴说明调整比较充分了，但能否止跌要看后续力度。
- 新高再看背离，不创新高所有背离都没意义。

### 3.2 四种结构分类

| 结构 | 别名 | 特征 | 核心 |
|------|------|------|------|
| **A 三段式** | 三浪 | 下跌→反弹→再下跌 | 第三段是一切根源 |
| **B 双平台** | | 盘整→方向→再盘整→再方向 | 最常见 |
| **C 单平台** | | 盘整后直接选择方向 | |
| **D 五段式** | 五浪 | A结构延伸（第三段特别长） | 最极端 |

**判断逻辑（以第三段为核心）：**
- 第三段拉长 → D结构或A结构（D是A的延伸）
- 第三段没拉长，开始盘整 → C结构（单平台）
- C之后又盘整 → B结构（双平台）
- 最多三平台，一般双平台结束
- A5之后通常接B（形成D结构后失败→盘整→反拉）

**上涨结构序列**：A1→A2→A3→A4→A5；B1→B2→B3→B4→B5→B6

### 3.3 结构的作用
1. **结构是全局** — 均线和背离是"外科"（局部问题），结构是"内科"（整体循环）
2. **结构是拐点的基础** — 看到河流的整体结构才能预测鱼群
3. **结构支撑均线和背离的结论** — 当均线偏离很远时，需要结构来制导

### 3.4 多异性（核心哲学）
- 结构是历史轨迹，过去100%确定
- 站在当下只能分析未来概率，不存在100%确定的未来轨迹
- 抓95%以上的有效分类即可。杂乱无章的K线没有交易意义。

### 3.5 不创新高时的处理
- 回调但不创新高 → 不看背离，看**结构和均线**
- 若接近前高+有均线压制 → 看**细分结构**（小级别）
- **不能直接走人**，容易卖飞。若细分结构中形成强突破 → 可能真突破前高
- 很多人死在这一点上：看到接近前高就跑了，结果突破成功

## 四、时空系统（级别嵌套）

### 4.1 谢尔滨斯基三角形（分形逻辑）
- 混乱博弈（Chaos Game）：任意规则重复执行 → 必然形成特定嵌套结构
- 股市同理：不管短期怎么波动，只要级别嵌套规则固定，结构必然自相似
- **日线找不到拐点 → 去60分钟 → 再去15分钟**。像用显微镜看细菌。

### 4.2 级别对应表

| 主操作级别 | 看趋势(大一级) | 找买点(小一级) | 精确止盈(小两级) |
|-----------|--------------|--------------|-----------------|
| 日线 | 月线 | 60分钟/120分钟 | 15分钟 |
| 60分钟 | 周线 | 15分钟 | 5分钟 |
| 15分钟 | 日线 | 5分钟 | — |

**最重要的级别组合**：月线 → 日线 → 60分钟（做日线段的话）

### 4.3 极强/极弱的级别传递
- **日线要进入主涨段 → 月线必须极强**
- **周线极强 → 只能进入60分钟主涨段**（不是日线主涨段！）
- 这是高级课的核心：月线不极强，日线进不了主涨段

## 五、主涨段判断（三位一体高级核心）

### 5.1 主涨段定义
- **主涨段不做T！** 卖飞的根本原因就是没识别出主涨段。
- 主涨段是最大涨幅段，但不一定是最长那根K（反直觉），只要不是最短的就行。
- 主涨段后通常有一段加速，然后进入主跌段。

### 5.2 哪些结构能产生主涨段
**只能在两种结构中产生：**
1. **A上涨中的A3→A4**（第三笔）
2. **B上涨中的B5→B6**（第五笔）

> CD结构不作为主涨段考虑。必须至少过了前一中枢高点才能判断。

### 5.3 三大确认条件（7 Key Points）

**必有条件：**
1. **J+2级别进入极强**（日线主涨段→月线极强；60分主涨段→周线极强）
2. **J级别结构上出现A3/A4或B5/B6**（打破中枢上沿）

**确认条件：**
3. **J-1级别回抽布林带中轨且得到支撑**
   - 回抽五五线也可以，回抽布林带中轨也可以
   - 如果强势回抽（离五五线很远），重点看布林带中轨
   - **回抽布林带中轨时，15分钟上往往有关键K**

**加分条件（双重确认）：**
4. J-2级别的五五线共振（非必须，有则更稳）

### 5.4 主涨段锁仓技巧
> **在日线主涨段中，只要60分钟布林带中轨不破，就不用看背离、不用看结构、不用看时空。**

- 每一次60分钟回踩布林带中轨 → 确认支撑后做反抽
- 如果布林带中轨破了 → 下面往往有60分钟五五线等
- **60分钟五五线彻底跌破 → 日线主涨段结束**

### 5.5 主涨段中"多看一根K"的奥义
- 出现背离但60分钟布林带中轨没破 → **多看一根K**（而不是立即卖）
- 这就是"多看一根K"背后的逻辑：级别嵌套的锁仓判断
- 没有锁仓机制的止盈是初中级水平，有锁仓才算高级

### 5.6 大级别极强支撑突破
- **做突破还是做T的核心判断**：大级别有没有进入极强
- 周线/月线极强 → 日线突破概率大 → **加仓**
- 周线/月线没有极强 → 日线突破可能是虚晃一枪 → **做T（卖了再接）**
- 类比：周线是地基，地基不牢，日线的突破就是危楼

## 六、仓位管理

### 6.1 核心原则："穷要张狂，富要稳"
- **资金量与波动成反比**
- 资金量小（<20万）：激进，1-3只票，追涨，去弱存强。换手可以多一些，多做启动的股票。
- 资金量大（>100万）：稳健，控制回撤。收益曲线比绝对收益重要。
- 资管视角：最终收益50%但最大回撤70% → 没人会投你。

### 6.2 仓位与市值关系

| 资金量 | 持仓数 | 风格 | 特别提示 |
|--------|--------|------|----------|
| <20万 | 1-3只 | 激进，追涨强势股 | 别买10只每只1万，没意义 |
| 20-100万 | 3-5只 | 均衡 | |
| >100万 | 5-8只 | 稳健，大票为主 | 一个点波动都很大 |

### 6.3 去弱存强
- 不要同时持有多只弱势股
- 有更好的标的 → 卖弱买强
- 小资金多做强势股启动段，少做长周期调整票

## 七、做T方法

### 7.1 基本概念
- **正T**：低买高卖（先买后卖）
- **反T**：高卖低买（先卖后买）
- **日内T** vs **隔日T** vs **波段T**

### 7.2 三种做T思路

| 方法 | 说明 | 要点 |
|------|------|------|
| **突破** | 分时突破重大压力位做多/做空 | 配合均线突破类型判断 |
| **联动** | 同板块大小票联动做差价 | 大票先动→小票跟随，利用时间差 |
| **接刀子** | 急跌后接反弹 | **必须右侧确认**，不要看线就接 |

### 7.3 做T还是加仓？——决定框架

**遇到结构前高 + 小级别盘中突破时：**

判断流程：
1. **时空层面** — 大级别（J+1）有没有进入极强？
   - 有 → 突破概率大 → 倾向于**加仓**
   - 没有 → 可能是虚晃 → 倾向于**做T（反T）**
2. **均线层面** — 双均线压制还是单均线压制？
   - 双均线（55+233重合）= 压力大 → 不容易突破
   - 单均线 = 压力相对小
3. **结构层面** — 日线级别距周线结构高点有没有空间？
   - 有空间 → 突破概率大
   - 没空间 → 容易被压制

### 7.4 做T核心规则

> **T是左侧（预判性），接是右侧（确认性）**

- T卖飞无所谓，T1/3就行。T一定会有卖飞。
- **接股票必须右侧**：看到反弹才接，不要看到均线就去接。
- **不要看线就接！** 这是最大的毛病。看到233线/55线就想接 = 病。
- 你没看到支撑已经被确认 → 不是支撑。
- 接的条件（三缺一不可）：小级别确认 + 站上重要均线 + MACD走好

### 7.5 右侧接买点的底层逻辑

**抛压理论：**
- 前面大量套牢盘 → 底部反弹时必有抛压
- 必须在K线上看到抛压被消化 → 那根确认K
- 底部套牢盘浓缩在第一根反弹后的回调中
- 抛压绝对不能过前低，否则说明压力太大

**两个买点：**
- **一号买点**：突破小级别55线（最快，适合55线远时）
- **二号买点**：回踩小级别55线确认（更稳，适合55线近时）
- 决定依据：55线离得近 → 等二号位确认；55线离得远（等到55线时快接近前高了）→ 一号位出手

**量价要点：**
- **底部反转不一定放量**（可以缩量悄悄涨）
- **突破均线那根K必须放量**
- 左边有双顶/背离的 → 特别小心

## 八、止盈系统

### 8.1 倒金字塔止盈
| 次数 | 减仓比例 |
|------|----------|
| 第一次 | 1/3（激进可以1/2） |
| 第二次 | 1/4 |
| 第三次 | 1/5 |
| 破位 | 全清 |

### 8.2 普通止盈（口诀）

> **成本越低，看的级别越大。**

| 成本 | 第一次止盈 | 第二次止盈 | 说明 |
|------|-----------|-----------|------|
| **高成本** | 15分钟背离 + 5分钟破位 | 60分钟背离 + 15分钟破位 | 利润垫薄，要敏感 |
| **中成本** | 60分钟背离 + 15分钟破位 | 日线背离 | |
| **低成本** | 60分钟背离 | 日线背离 | 利润垫厚，可以扛 |
| **极低成本** | 只看日线背离 | — | 日线没背离就一直持有 |

### 8.3 止盈核心规则
> **15分钟背离 → 看5分钟破位 → 破位才卖。不要一看背离就卖。**

- 背离是前提条件，破位是执行条件
- 没有背离就不看破位。破位但不背离也要卖。
- 第一次止盈完后，不要再回看15分钟，升级看60分钟。

### 8.4 主涨段止盈（锁仓法）
- 日线主涨段中 → **只看60分钟布林带中轨**
- 60分钟中轨没破 → 不卖，不管15分钟怎么折腾
- 60分钟中轨破了 → 开始考虑止盈
- 锁仓解除后 → 回到普通三位一体止盈流程

### 8.5 维科夫法（左侧止盈，适合题材票/连板票）

**计算：**
- **TP1** = 高点 + (高点 - 低点) × 0.618
- **TP2** = 高点 + (高点 - 低点) × 1.0

**执行：**
- 到TP1 → 先卖1/3或1/2（不管后面怎么样，先卖再说）
- 到TP2 → 再卖1/4
- 题材票可能直接跌停不给卖点，所以到了位置左侧卖

**连板票处理：**
- 每天开盘后挂单在开盘价上方3%-5%处
- 集合竞价涨停 → 9:25前就把单挂好
- 10cm挂150（即1.5%），20cm挂117（即1.7%），大资金可以挂110
- 直接对价成交，不要等。利润够了就走。
- 9:20-9:25那段时间反正报了也不成交，挂好等着就行。

## 九、关键K（Golden Stick）

### 9.1 定义
- 三角收敛底部出现的关键反转K线
- 英文：Golden Stick / Golden Candle
- 在**15分钟**级别寻找（日线级别放5分钟太密了）
- 日内做T可以用5分钟找关键K

### 9.2 特征（四要素）
1. 下跌阴线后出现阳线，**至少覆盖阴线的一半**（阳包阴）
2. **下一根K不跌破**关键K的低点 → 才算确认（不是关键K本身买入！）
3. 量能**偏缩量**（Volume Shrink）：相对前一根阴线要缩量
4. MACD在15分钟上进入**极强**区，至少是金叉

### 9.3 关键识别误区
> 如果量能很大 + K线很大 → **一定不是关键K**！

关键K永远是缩量的。放量说明还在出货。

### 9.4 操作流程
1. 三角收敛底部出现疑似关键K
2. 等**下一根K**确认（不破关键K低点）
3. 确认后 → 补仓/买入
4. 关键K是波段补仓小技巧，不影响大级别判断

### 9.5 关键K与主涨段的联动
- 在回抽布林带中轨的过程中，15分钟上往往有关键K
- 回抽五五线不一定有关键K，但回抽布林带中轨通常有
- 找到关键K → 对回抽的确认更可靠 → 主涨段把握更大

## 十、集合竞价

### 10.1 时间段与规则

| 时段 | 可否撤单 | 策略意义 |
|------|----------|----------|

| 14:57-15:00 | ❌ 不可撤 | 收盘集合竞价 |

### 10.2 成交原则
- **最大成交量原则**：找一个让成交量最大的价格
- 高于成交价的买单和低于成交价的卖单全部成交
- 价格优先 + 时间优先（没有大单优先！大单成交快是因为机房离交易所近、系统更快）

### 10.3 看盘要点
- 9:15-9:20的涨停/跌停不要信（可以撤单）
- 9:20后价格走势才真实
- "大单买入"可能只是9:15-9:20的虚假挂单

## 十一、交易纪律

1. **文思修**：闻（听课）→ 思（思考）→ 修（实操），形成肌肉记忆。不能只闻不思不修。

## 十二、快速参考卡

### 均线秒判
- 碰到均线立刻弹 = **D**（最强）
- 破了均线又弹回 = **C**
- 在均线上下盘整 = **B**
- 直接穿过 = **A**

### 结构秒判
- 第三段拉很长 = **D或A**
- 第三段没拉长+盘整 = **C**
- 盘整后再盘整 = **B**

### 止盈选择
- 刚买的 → 看15分钟
- 成本一般 → 看60分钟
- 成本很低 → 看日线
- 主涨段中 → 只看60分钟布林带中轨

### 突破还是做T
- 大级别极强 → **加仓**
- 大级别没极强 → **做T**
- 单均线压制 → 可以博弈加仓
- 双均线压制 → 偏谨慎做T
