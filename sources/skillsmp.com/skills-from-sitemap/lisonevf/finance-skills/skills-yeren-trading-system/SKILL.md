# 野人交易系统

> 来源：野人（野人哥）885个口播稿蒸馏，保留核心方法论和战法，去除日常闲聊和情绪化表达。

---

## 一、系统总论

**野人体系核心**：情绪周期为纲 + 题材龙头为领 + 短线波段双修 + 人性博弈为底

- **短线侧**：情绪周期 → 龙头/空间板 → 分歧切核心 → 弱转强 → 盈亏比推仓位
- **波段侧**：均线系统 → 震仓洗盘识别 → 低吸介入 → 主升锁仓
- **共通**：仓位管理 → 止盈止损 → 空仓等待 → 人性驾驭

> 慢就是快。市场永远不关门。一年做对一两次题材，翻倍足够。

## 二、情绪周期（第一核心）

### 2.1 周期层级
- **大周期**：龙头带动的主升周期，龙头出现负反馈时所有小周期皆受影响（非情绪标的除外）
- **小周期**：嵌套在大周期内，龙头高位震荡时小周期进入无序轮动

### 2.2 三阶段完整闭环

| 阶段 | 特征 | 操作 |
|------|------|------|
| **主升期** | 龙头带队，连板高度打开，赚钱效应好 | 重仓做龙头/跟风/套利 |
| **高位震荡期** | 龙头高位震荡，补涨龙+高切低出现 | 只做龙头二波或龙头首阴，或空仓 |
| **退潮期** | 龙头死，高度压制，亏钱效应放大 | **清仓、空仓**，小仓位试错 |

### 2.3 退潮的核心逻辑
- **高度压制机制**：龙头死 → 最激进资金被套 → 中高位连板缺接力资金 → 三进四断板 → 四进五炸板 → 高度逐级压缩 → 越套越多
- **本质**：市场的活钱被锁死，需要一个周期慢慢消耗 → 资金重新释放 → 下一主升期
- 类比：发工资有钱大吃 → 钱花完饿着 → 万物皆周期

### 2.4 判断情绪的三个维度

| 维度 | 看什么 | 信号 |
|------|--------|------|
| **涨跌家数+成交量** | 量增价升+赚钱效应递增 | 情绪好 |
| **昨日涨停溢价率** | 打板资金今天是否赚钱 | 溢价高=情绪好，资金继续进攻 |
| **昨日炸板修复力度** | 被套资金能否解套 | 修复好=量能放大的来源 |

### 2.5 题材延续性判断
- 题材连续三天持续表现 → 热钱多、情绪好 → 放心做主线
- **有主线做主线，没主线找主线，一生跟随主线**

### 2.6 指数与情绪背离
- 指数涨≠赚钱效应好（权重可拉指数但短线情绪可能很差）
- 需要独立判断情绪周期，不能只看指数

### 2.7 预期差
- 所有人盯着某题材时 → 被忽视的题材反而可能走出来
- **买在分歧，卖在一致**

## 三、交易系统

### 3.1 三要素

| 要素 | 内容 |
|------|------|
| **买入逻辑** | 事先设定，不可随意改变。技术派以均线为准，情绪派以情绪周期为准 |
| **仓位管理** | 每笔固定，初级阶段固定化；进阶后按胜率分配（50%不做、60%两成、70%三成、80%五成、90%+满仓） |
| **卖出逻辑** | 与买入逻辑对称。符合预期→格局，不符合→止损，超预期→加仓 |

### 3.2 预期管理（核心）
- 每笔短线交易必须设定次日预期：
  - 符合预期 → 格局
  - 不符合预期 → 止损
  - 超预期 → 加仓
- 这就是系统和模式，避免情绪化交易

### 3.3 第一原则
> **保住本金。回到成本线必须清仓。**

### 3.4 给新股民的建议
- 放低预期：10万本金一年赚10%（1万）即可
- 稳定盈利前只用总资金10%打磨系统
- 连续6个月稳定盈利后再加资金
- **不学龙头战法**（腰斩最快）、不加仓、不贪婪
- 盈利及时提现

## 四、仓位管理 + 空仓

### 4.1 仓位核心原则
- 试错 < 总仓位10%-20%（建议10%）
- 确定性确认后才加仓
- **禁止满仓单调一只**（除非连续三年稳定盈利证明能力）
- 必须有空闲仓位，看到确定性机会才能出手

### 4.2 空仓的数学逻辑
| 回撤 | 需赚回 |
|------|--------|
| 30% | 45% |
| 50% | 100% |

> 散户与大资金唯一区别：大资金有子弹补仓，散户回撤后翻身极难。

### 4.3 空仓智慧
- 不是每天都要交易。龙头只有主升期可做。
- 不具备条件时空仓。大账户长时间空仓，小账户试错。
- 确定性机会来临时推仓位做翻倍行情。一年做对一两次足够。

### 4.4 三条路径
1. 空仓
2. 小仓位玩（试错）
3. 跟随机构做趋势

### 4.5 老六玩法（确定性空仓法）
- 确定性行情来临前分批建仓（连续5交易日每日入10%=半仓）
- 行情兑现后第一时间清仓
- 空仓等下一个确定性
- **主力无法收割有耐心和有纪律的交易者**

### 4.6 盈亏比五字诀
> 空仓 → 试错 → 确定性确认 → 加仓 → 锁仓

## 五、短线交易体系

### 5.1 空间板（空间龙）
- **定义**：资金用真金白银试探监管态度的最高连板股
- 典型特征：高开秒板/T字板，封单小但不炸 → 内部资金一致锁仓
- 意义：打开空间为短线生态铺路，之后短线好做

### 5.2 情绪节点破局
| 压制高度 | 做 | 逻辑 |
|----------|-----|------|
| 压制在3板 | 做2进3 | 破局模式 |
| 压制在4板 | 做3进4 | 小资金试错 |

### 5.3 空间板操作原则
> **要么做最高，要么做最低。不做中位股！**

- 空间板封板时先跟动的才是真主线（后跟动的是跟风，次日低开）
- 空间板封板后的操作：
  - 跟风：做小弟一板/二板套利
  - 套利：做300/北交20cm/30cm（无确定性，第二天无论高低都走）

### 5.4 短线退潮识别
**前兆三步**：
1. 中军开始负反馈（资金分歧）
2. 龙头高位滞涨（不敢打高度）
3. 中位股先杀跌 → 反馈到龙头杀跌

**龙头断板** → 视为情绪进入混沌/退潮区 → 边打边撤

### 5.5 龙头被埋后的格局
- 被埋后隔天一般有修复预期
- **高开** → 符合预期，格局拉满，不上板不减
- **低开** → 全天水下不给修复 → 不加仓！尾盘不修复就出
- 尾盘必须做修复动作（拉红盘震荡），才能制造次日弱转强预期

### 5.6 情绪票/龙头止盈止损
- 龙头/辨识度情绪标：**不设止盈**，让利润奔跑
- 中位股/弱股：涨20%左右去弱留强，止盈换到更强
- **成本线保卫**：止损设在成本线+0.01，条件单自动执行
- 波段止损：亏损5%无条件走人

## 六、战法

### 6.1 弱转强战法
**条件**：前一天大烂板（换手率60%+），筹码交换完毕
**次日竞价**：
- 爆量 + 高开（预期应低开低走）→ 弱转强成立 → 直接上车
- 挂单技巧：挂价格笼子最高价扫进去，不挂竞价价
**逻辑**：筹码被另一波主力接走（换庄），题材足够大

### 6.2 分歧切核心
**两类人**：
- 未参与者：等题材第一次分歧 → 直接干龙头或辨识度中军
- 已参与但持杂毛者：死也死在龙头上（龙头涨得多、跌扛得住、多一条命）

**良性分歧**：放量大涨次日缩量分歧 → 资金被动锁仓未走 → 后面有行情

**买卖点**：
- 买在分歧转一致的那一刻（非分歧本身）
- 卖在分歧转一致的那一刻（二波分歧卖出）

### 6.3 一肉三吃战法（普涨行情专用）
**操作流程**：
1. 持有底仓 + 有子弹
2. 早盘冲高 → 卖出（S）
3. 回落至低位 → 买入（B）
4. 尾盘V回 → 当日完成一次T
5. 第二天开盘落袋
**核心**：普涨行情中利用日内冲高回落做T+0套利

### 6.4 扶老太太下楼梯战法（解套战法）
**操作流程**：
1. 次日开盘**无条件先卖出**（不管高开低开）
2. 当天在相对低位接回
3. 第三天重复：开盘卖→低位接
4. 反复向下做差价降低成本
**心态**：预期是解套非盈利，不要怕卖飞
**退出**：修复至成本线附近→冲高先卖一半→回落解套走人

### 6.5 二次回踩战法
**逻辑**：箱体震荡突破时，不能在突破瞬间介入，要等回踩确认
**确认信号**：回踩后出现首板
**首板质量判断**：首板当天必须经历"一致→分歧→分歧转一致"
- 首板炸板 → 释放埋伏盘和低吸盘
- 回封后第二天板才是"强更强"
**参与**：板上跟随或排版，非扫板

## 七、波段交易体系

### 7.1 完整生命周期（9步）
```
吸筹 → 洗盘 → 震仓 → 拉伸 → 回踩 → 主升 → 出货 → 打压 → 吸筹（循环）
```
- 震仓阶段是最佳介入窗口：别人下车你上车

### 7.2 第一入场点（启动介入）
- 五日线上穿所有均线，二十日线开始拐头向上
- 强庄：沿五日线小阴小阳向上
- 弱庄：回踩十日线或二十日线企稳

### 7.3 第二入场点（回踩介入）
- 强庄沿五日线上涨中，突发大阴线从五日线打到二十日线 → **加仓点**（趋势一旦形成很难改变）
- 弱庄回踩十日/二十日线 + **缩量** → 入场信号
- 前提：量增价升，底部必须有**爆量**（历史天量）

### 7.4 回调后下一波接入点
1. 第一波涨30%不足以让主力出货
2. 等均线上来（筹码充分交换）
3. 出现**止跌阳线**后轻仓介入（保持关注）
4. 五日线拐头向下→穿十日/二十日→企稳→五日线再拐头向上，与十日/二十日/三十日**高度重合**时密切关注
5. **突破性放量大阳线** → 确定性推仓位点

### 7.5 震仓阶段入场法
- 红盘震荡后小幅拉伸→回踩→上影线/大阳线/小阴线组合（红肥绿瘦）
- 看**60分钟K线**：高红柱、矮绿柱
- 以二十日线为基准低吸

### 7.6 离场点
- **高位放量滞涨**：放大量但涨幅极小（如百亿成交只涨2%）→ 第一离场点
- 高位滞涨后跌不下去（有承接）→ 波段第二入场点

### 7.7 波段补仓
**被动补仓**：每跌15%补一笔（野人不推荐，15%就止损）
**主动补仓**：必须等反转信号
三种反转信号：
1. 十字星 + 低量低价（极度缩量）
2. 触底反弹T字K线
3. **放量大阳线**，一根吃掉两到三根阴线 → 确定性推仓位点

### 7.8 量价关系核心
> **资金为王**：先有资金→再有量→再到价→再到消息。无资金行为，消息即死水。
- 底部爆量是主力行为，跟错也要跟
- 主力日线可做假，周线/月线做不了假 → 用周线月线看量价
- 月线量温和放大 → 主力真实意图

### 7.9 筹码干净度
- 主力洗盘洗的是不坚定筹码（浮筹）
- 三天不涨就急躁的人会被洗掉
- 做波段要能扛洗盘震仓

## 八、洗盘 vs 出货

### 8.1 洗盘
- 洗的是持仓者的成本价，让成本随股价波动
- 目的是减少拉升时的抛压

### 8.2 出货（两个必要条件，缺一不可）
1. **有一段加速过程**：高开秒板或一字板，一般三个板加速 → 为出货留空间
2. **高位放量滞涨**：放量但涨幅明显小于前日 → 99.99%在出货

### 8.3 出货节奏识别
- 主力边打边撤，从第二板就开始慢慢出货
- 锁仓者出现一字板（吃独食）→ 后面无人接力
- 温和出货：换手率15-20%，量持续放大，量价齐升制造假象
- 见顶信号：墓碑线或放量大阴线，换手率急剧增加（50-60%+）
- 上6板/7板时出现合力可能走二波（换庄）

## 九、人性博弈

### 9.1 四个博弈维度
1. **规避监管 vs 想吃肉** → 选择规避（保住流动性）
2. **高潮后次日开盘** → 克制贪婪，果断卖出
3. **卖出后低点** → 克制抄底冲动（便宜只相对今天）
4. **看好标的被情绪带跌** → 克制恐惧，逻辑未破不卖

### 9.2 散户通病
- 低位不上车，涨了几天才追 → 追涨杀跌
- 小仓位试错吃到涨停 → 懊恼没重仓 → 下次满仓套死
- 吃肉就跑卖飞 → 天天盯着前股看 → 做不好下一笔
- 纠错（连笔交易）：模式内卖出后同一天模式内再买入 → 吃第二天溢价，不是反T

### 9.3 悟道前后的对比
| 悟道前 | 悟道后 |
|--------|--------|
| 吃饭想K线，睡觉想股市 | 吃饭就是吃饭，睡觉就是睡觉 |
| 满仓是市场的奴隶 | 轻仓是市场的朋友 |
| 追涨杀跌 | 不追涨杀跌 |
| 后视镜看市场 | 不下车才是真拿住 |
| 亏损死补仓想一把回本 | 盈利要提出来，不总想复利 |

### 9.4 精准逃顶的秘密：双视角思维
- 每天开盘时同时存在两个"我"：交易中的我 + 主力视角的我
- 站在主力角度思考 → 提前判断趋势

### 9.5 成熟交易者特质
- 冷静、理智、理性、有耐性
- 大部分时间等待，只等确定性机会出手
- 小账户感受盘面温度，大账户推盈亏比
- **不梭哈**，不为那一两次机会赌上全部

## 十、量化应对

### 10.1 量化本质
- 通过流动性收割流动性
- 在热门题材和龙头股中做高抛低吸
- 特点是尾盘拉直线抢预期，次日吃惯性溢价就跑

### 10.2 应对两句话
1. **不要在热门题材和热门股里做波段/中长线**（吃了肉就跑，不要格局）
2. **不要在冷门题材和冷门股里做短线**

### 10.3 电风扇行情应对
- 管住手，不开仓，伸手必被捉
- 红卖绿买：量化高抛你也抛，量化低吸你也吸

## 十一、题材操作节奏

### 11.1 题材生命周期
- **爆发前**：提前埋伏有先手 → 去弱留强
- **爆发后**：要么早信，要么别信 → 等第一次大分歧做分歧转一致
- **高潮后**：利好落地是利空，事件临近结尾注意止盈

### 11.2 高切低
- **题材内高切低**（支线轮动）：当轮动看，高开就跑
- **板块间高切低**：不具备持续性，买入即错

### 11.3 龙头本质
- 龙头 = 人气 + 辨识度 = **流动性**
- 人多的地方就有辨识度和流动性 → 必须做龙头
- 无人问津的股票没有流动性

### 11.4 补涨龙
- 高度必定低于龙头（龙9板→补涨龙最多6-7板）
- 通常需提前埋伏，能被轻易买到的往往是坑

## 十二、庄家对倒

| 阶段 | 操作 | 结果 |
|------|------|------|
| **吸筹对倒** | 用自己的筹码砸自己的挂单 | 打压股价，筹码不丢，逼散户交出带血筹码 |
| **拉升对倒** | 用自己的单子吃掉自己的卖单 | 拉升股价，筹码不增，跟风盘替主力接走多余筹码 |

## 十三、快速参考卡

### 情绪周期速判
- 龙头带队 + 高度打开 → **主升**（重仓）
- 龙头高位震荡 + 补涨龙出 → **高位震荡**（只做龙头/空仓）
- 龙头死 + 高度压制 → **退潮**（清仓）

### 空间板速判
- 压制3板 → 做2进3
- 压制4板 → 做3进4
- 空间板封板时先跟动的 → 真主线

### 介入速判
- 波段：五日线上穿所有均线 + 二十日线拐头向上 → 启动介入
- 短线：大烂板(60%+) + 次日竞价爆量高开 → 弱转强介入
- 分歧：放量大涨+次日缩量分歧 → 分歧切核心机会

### 离场速判
- 高位放量滞涨 → 波段离场
- 龙头断板 → 短线离场
- 加速后大阴线+换手率50%+ → 出货确认

### 量化应对速判
- 热门题材+热门股 → 短线快进快出，不格局
- 冷门题材+冷门股 → 不做短线
- 电风扇 → 不开仓

### 心态速判
- 踏空懊恼 → 情绪未驾驭
- 想"早该重仓" → 贪婪信号
- "再等等就回本了" → 不止损的深渊
