# 燕赤霞短线打板体系

燕赤霞（赤霞）是A股短线内容IP，核心理念：**做确定性、控回撤、只做核心票**。体系覆盖从首板到龙头的完整短线生态。

---

## 一、五种不能碰的手板

> 做短线看到这五种手板，不要碰——当天可能炸板，次日可能埋山顶。

| # | 类型 | 特征 | 原因 |
|---|------|------|------|
| 1 | 午后急拉板 | 中午开盘后直接秒板 | 踏空资金做跟风，筹码结构差，次日板块退潮第一个被闷 |
| 2 | 尾盘偷袭板 | 14:30后直线拉板 | "尾盘拉升非奸即盗"，主力怕抛压才尾盘拉 |
| 3 | 小微盘反复烂板 | 流通<50亿，反复炸板 | 给够上车机会后次日无接力资金，主力诱多出货 |
| 4 | 高位巨量板 | 高位+量能翻数倍 | 获利盘+量化出逃，板上主力减仓离场 |
| 5 | V字涨停 | 走深V字形到前高 | 前高套牢盘+获利盘双抛压，次日主力还需洗盘 |

## 二、一进二战法（1板→2板）

> 做短线绕不开一进二：做对躺着数板，做错回撤几个点。

### 选股：5步剔除

| 步骤 | 剔除条件 | 原因 |
|------|---------|------|
| 1 | 无涨停基因（半年内很少涨停） | 涨停困难户走连板概率低 |
| 2 | 一字板 | 要么大利好，要么进去就是坑 |
| 3 | 首板反复炸板 | 抛压大或主力实力不够 |
| 4 | 市值>100亿 或 股价>20元 | 盘子大空间小，高价股散户跟风少 |
| 5 | 老龙头 / 一年涨幅>5倍 | 获利盘+套牢盘双抛压 |

### 精选：3维度评分

1. **涨停时间**：越早越好 → 板块地位高
2. **流畅程度**：高开→一波/两波上板→牢牢封板 → 最强
3. **封单量**：越大越好 → 次日溢价概率高

> 结合题材：新题材+想象空间+消息刺激

### 进场：竞价爆量+打板

- 次日集合竞价换手率达前日5% + 爆量高开 → 资金抢筹
- 冲高到8%以上、离涨停1-2个价位 → 打板进场
- **仓位**：单只不超过4成

### 止损

- 炸板后看成交明细：小单砸+快速回封 → 可持有
- 大单砸+砸得深 → 次日果断离场，不抱幻想

## 三、二进三战法（2板→3板）

> 二进三给了换手机会=走妖行情。核心票才能走强势。

### 选核心票三步

1. **热门题材**：涨停家数最多的题材 → 挑核心标的
   - 核心 = 能引领题材发酵、涨停带动跟风
   - 核心带动板块 → 板块反哺核心 → 涨停潮

2. **量能匹配**：
   - 一板二板放量 → 三板缩量（地位确认，锁仓加速）
   - 一板二板缩量 → 三板放量（消化获利盘，分歧转一致）

3. **封板强度**：封板更快/顶着天量抛压回封/封单比前两天大

### 进场方式

- **打板**（推荐新手）：博弈趋势延续，确定性更高
- **低吸**（难度高）：需判断板块反转，对题材理解要求高

## 四、断板反包战法（龙头分歧后二波）

> 真正龙头能扛住分歧，从反包启动加速行情。

### 三步法

**Step 1 选股**
- 三板及以上连板标的（首板二板不算抱团）
- 一字连板放弃（吃独食，断板就是坑）
- 连板高度<三板 → 休息不做

**Step 2 等断板信号**
- 位置不能太高（前面已涨一段再加速→真见顶）
- 断板当日：振幅≥5% + 不能跌停 + 长上下影线小阴小阳 + 放量

**Step 3 介入**
- 次日反弹突破断板当天K线一半 → 跟随
- 次日高开 → 开盘即进场（超预期）

**止损**：跌破反包阳线最低价 → 离场

## 五、弱转强五种形态

> 弱=强势股不够强（相对弱），不是退潮跌停的弱。核心=次日超预期。

| # | 前天形态 | 正常预期 | 弱转强信号 | 入场点 |
|---|---------|---------|-----------|--------|
| 1 | 午后回封板 | 小幅高开/平开 | 竞价高开+开盘秒板 | 开盘确认后 |
| 2 | 尾盘偷袭板 | 低开震荡 | 竞价大幅高开+早盘稳步向上 | 早盘 |
| 3 | 反包弱转强 | 继续下跌/低开 | 跌停后竞价平开/高开 | 竞价/开盘 |
| 4 | 断板弱转强 | 低开1-2%调整 | 平开/平开后快速拉升 | 水上 |
| 5 | 烂板弱转强 | 低开震荡 | 竞价高开+开盘果断拉升 | 竞价/开盘 |

## 六、集合竞价核心技术

### 三阶段规则

| 阶段 | 时间 | 规则 | 意义 |
|------|------|------|------|
| 一阶段 | 9:15-9:20 | 可挂可撤，不成交 | **别看**，主力试盘挖坑 |
| 二阶段 | 9:20-9:25 | 可挂不可撤 | **核心**，真金白银博弈 |
| 三阶段 | 9:25-9:30 | 可挂单，不成交 | 思考时间，不受价格笼子限制 |

### 量能柱解读

- **上方红柱** = 未匹配买单（想买没买到）
- **上方绿柱** = 未匹配卖单（想卖没卖出）
- **下方柱** = 已匹配成交量（红=买单多、绿=卖单多）

### 竞价精髓

> **集合竞价的过程不重要，9:25的最终开盘价才重要。** 竞价就是开盘价的变化过程。

### 诱多vs诱空（9:20-9:25判断）

| 类型 | 表现 | 判断方法 |
|------|------|---------|
| 诱多 | 股价拉升 | 下方出现巨量砸盘卖单 → 假拉升 |
| 真拉升 | 股价拉升 | 砸盘单子短/量小 → 抛压小，真拉升 |
| 诱空 | 股价回落 | 匹配量很小 → 主力打压吸筹 |
| 真砸盘 | 股价回落 | 匹配量特别大 → 真出货 |

### 竞价快速操作

- 想快速买入 → 挂涨停价（不受价格笼子限制）
- 想快速出逃 → 挂跌停价

## 七、分歧转一致（量价体系）

### 放量vs缩量在不同位置

| 位置 | 更好 | 原因 |
|------|------|------|
| 低位首板 | **缩量** | 主力控盘度高，隔天跟风抢筹 |
| 突破前高 | **放量** | 释放套牢盘，做多决心强（但不能爆巨量） |
| 连板三板 | 缩量加速 | 地位已确认，主力锁仓 |
| 分歧后反包 | **缩量** | 资金一致看多，分歧转一致确认 |

### 分歧转一致买点

- 五连板内出现爆量阴线 + 次日缩量反包涨停 → **打板入场**
- 放量=让新资金进场抬高成本 → 缩量=一致看好拉升

### 一字板陷阱

> 无换手的一字加速不参与。等到你能参与时=坑。

## 八、涨停金凤凰（N字战法最强形态）

> "涨停不破高，后市要成妖"

### 形态条件

1. **首板涨停** → 行情启动信号
2. **回调不破首板最高价** → 沿首板最高点画水平线=生命线
3. **回调3-9个交易日**（<3天不充分，>9天热度冷却）
4. **回调缩量** → 抛压轻，主力洗盘非出逃
5. **再次涨停** → 进场信号

### 与普通N字战法区别

- 普通N字：回调到首板起始价/涨停价一半
- 金凤凰：回调守住首板最高点 → 资金承接力极强

### 进场

- 涨停当天逼近涨停价进场
- 或涨停次日跟随便进场

## 九、分时图实战

### 洗盘（边拉边洗）

- 低开→快速冲高→回落→不破开盘价→低点抬高+高点抬高
- 回调不破前低 = 洗盘 → **持有**

### 出货（急拉慢跌）

- 平开低走→盘中急速拉升（短时大幅）→回调一段反弹一段→高点越来越低
- 跌破零轴+跌破前低 → **两个离场位**

### 强势标的急拉

- 急拉4-5%→回踩不破分时均线 → **持有**
- 跌破分时均线+均线拐头向下 → **离场**（诱多）

### 冲击波形态

- 全天震荡→尾盘直线拉升→放任回落
- 低位出现 → 主力试盘，后续可能拉升
- 高位出现 → 拉高出货

## 十、低开操作策略

| 类型 | 特征 | 操作 |
|------|------|------|
| 低开急拉 | 低开后量价齐升翻红 | 翻红可加仓做T，冲高回落破均线出底仓 |
| 低开震荡上行 | 11点翻红，厚重上涨 | **持有不动**，次日有冲高溢价 |
| 低开无量上攻 | 无量+不破零轴+高点降低 | 跌破分时均线→**赶紧离场** |
| 低开推土机下行 | 均线下方一路向下 | 10-11点无表现→**减仓/离场** |

### 核心原则

> 早盘急跌不要轻易卖票（可能是洗盘）。除非高位+板块明显退潮。

## 核心理念速查

| 理念 | 内容 |
|------|------|
| 只做核心 | 能引领题材、带动跟风的才是核心 |
| 控制回撤 | 炒股真正厉害的人全力以赴做控制回撤 |
| 该弱不弱就是强 | 弱转强的本质=次日超预期 |
| 博弈大概率 | 没必要博弈小概率事件 |
| 尾盘看预期 | 尾盘半小时=预判次日，集合竞价验证 |
| 不做一字 | 一字板=吃独食=能进时是坑 |
| 量价匹配 | 不同位置放量/缩量含义完全不同 |
| 做确定性 | 打板确定性>低吸；趋势延续>趋势反转 |
