About SkillsLLM

Discover and explore open-source AI skills for Claude Code, Codex CLI, and other AI assistants.

Discovery

Finding the right AI skill among thousands of GitHub repositories can be overwhelming. SkillsLLM aggregates and categorizes skills to make discovery easy.

Security

Every skill is automatically scanned for security issues using dependency auditing (npm audit + pip-audit) and prompt-injection heuristics. Look for the security badge before installing.

Open Source

All skills are sourced from public GitHub repositories. We only include repositories with 100+ stars to ensure quality.

SKILL.md Standard

Skills using the open SKILL.md format are automatically detected and highlighted. This format is compatible with Claude Code, Codex CLI, and other tools.

How It Works

1. Automated Discovery

Our scraper searches GitHub daily for repositories containing SKILL.md files or tagged with relevant topics like claude-code, ai-agent, mcp-server.

2. Quality Filter

Only repositories with 100+ stars are included. This helps ensure the skills are maintained and trusted by the community.

3. Security Scanning

Each skill is scanned with npm audit and pip-audit for dependency vulnerabilities, plus heuristic prompt-injection checks. Results are displayed with clear status badges.

4. Categorization

Skills are automatically categorized based on their topics and descriptions, making it easy to find what you need.

Chrome Extension

See SkillsLLM's security scan, category, and votes on every GitHub repo page — and submit unlisted repos in one click. Free, no account required, native GitHub look in light and dark themes.

Install from Chrome Web Store
