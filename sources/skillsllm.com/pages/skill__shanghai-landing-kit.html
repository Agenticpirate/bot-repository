来上海落地包：公租房通勤地图 + 毕业生落地指南

刚毕业要来上海？这个仓库给你两件工具：

  1. 🗺 公租房通勤地图：输入你的通勤目的地（公司/学校/地铁站），把全上海 700+ 个公租房/保租房项目按"离你有多近"排出来，画在一张可交互的地图上——地铁/驾车双模式、真实路线时间、租金户型电话全都有，且支持在地图上随时换任意目的地；
  2. 🧳 毕业生落地指南（guide.html）：零配置，下载后双击就能用——首页是八宫格模块卡片，覆盖落户自测（直落判定+72 分计算器）、居住证积分 120 速算、租房路线图、求职与到手工资计算器、就医指南、新城对比与通勤成本计算器、落地 30 天清单。

地图需要免费注册高德 Key（教程在下面）；不用会写代码，跟着点鼠标就能跑起来。会用 AI 助手（Claude Code / Codex / WorkBuddy / Trae）的话，把本文末尾的提示词粘给它，5 分钟配完。

地图 · 全量精算模式 地图 · 任意目的地模式 指南 · 首页宫格

地图能干什么

  • 按通勤时间给房源着色排序：地铁/公交和驾车两套时间，来自高德的真实路线规划，不是直线距离拍脑袋；
  • 任意目的地，一视同仁：搜索框输入任意地点（或右键地图选点），713 个房源立刻按直线距离重排，自动对最近 30 个实算真实通勤；想更全有「再精算 30 个」和「精算全部」（点击前会告知配额消耗与耗时，可随时停止），已精算的房源自动按真实时间排到列表前面；
  • 筛选：区域下拉、月租上限、时间桶开关、公寓类型（全部 / 不看公寓 / 只看公寓，按名称启发式识别品牌长租公寓）组合使用；
  • 每个房源可点开：租金、户型、面积、最近地铁站与步行距离、管家电话、一键跳高德导航；
  • 收藏 / 排除：点开房源可 ☆收藏（地图上金圈高亮、列表加星）或 ✕排除（看过不合适的从图上消失）；顶部可切「⭐收藏 / 🚫已排除」视图管理，标记保存在本机浏览器；
  • 一键导出收藏：「⬇ 导出收藏」生成 CSV 表格（Excel/WPS 直接打开），含租金、面积、电话和当前目的地的通勤时间，发给家人朋友一起参谋；
  • 导出 Excel 排名表（result.csv），想怎么筛怎么筛。

自带 2026 年 7 月的上海公租房房源快照（listings.csv，713 条，含各区公租房与保障性租赁住房项目）。房源信息会过时，怎么更新见下文。

你需要准备什么

  1. 一个高德开放平台免费账号（下面教你注册，个人实名即可，免费额度绰绰有余）；
  2. 电脑上有 Python 3.9 或更新版本（本项目零第三方依赖，不用 pip 装任何东西）：
    • Mac：系统自带，打开「终端」输入 python3 --version 确认；
    • Windows：去 python.org/downloads 下载安装，安装时勾选 "Add Python to PATH"，然后在「命令提示符」输入 python --version 确认；
  3. 大约 20 分钟（其中 15 分钟是程序自己在跑，你可以去倒杯水）。

只想用落地指南的话，什么都不用准备：下载后双击 guide.html 完事。

第一步：注册高德，创建两个 Key（约 5 分钟）

  1. 打开 高德开放平台，右上角注册/登录（支付宝或手机号即可），完成个人开发者实名认证；
  2. 进入 控制台 → 应用管理 → 我的应用，点「创建新应用」，名称随意（比如"公租房"）；
  3. 在这个应用下点「添加 Key」，要创建两个：
# Key 名称(随意) 服务平台(关键!) 用途
1 比如"公租房-算路" Web服务 给 enrich.py 批量算通勤用
2 比如"公租房-地图" Web端(JS API) 给网页地图用。创建后列表里会多出一个安全密钥，和 Key 配对，两个都要复制

常见坑：两个 Key 的"服务平台"千万别选反。选错的表现是程序报 INVALID_USER_KEY 或地图白屏。

免费额度：个人认证后每类服务约 5000 次/天、并发 3 次/秒。跑一遍 713 个房源约用 2200 次，完全够；程序内置了限速，不会超频。

第二步：下载本项目，填入 Key（约 3 分钟）

  1. 下载项目：点本页右上角绿色 Code 按钮 → Download ZIP，解压到任意文件夹（会 git 的直接 clone）；
  2. 把文件夹里的 config.example.json 复制一份，改名为 config.json；
  3. 用任意文本编辑器（Mac：文本编辑；Windows：记事本）打开 config.json，填三个值和你的目的地：
{
  "amap_web_key": "第一步创建的【Web服务】Key",
  "amap_js_key": "第一步创建的【Web端(JS API)】Key",
  "amap_js_security_code": "与JS API Key配对的【安全密钥】",
  "destination_name": "莘庄地铁站",
  "city": "上海"
}

destination_name 就写你每天要去的地方，比如"张江高科地铁站"、"陆家嘴"、"复旦大学邯郸校区"，越具体越好。

第三步：运行（一共两条命令）

打开命令行，进入项目文件夹：

  • Mac：打开「终端」，输入 cd （cd 后面有个空格），把项目文件夹拖进终端窗口，回车；
  • Windows：打开项目文件夹，在地址栏输入 cmd 回车（会在当前目录打开命令提示符）。

然后依次运行：

# Mac 用 python3,Windows 用 python
python3 enrich.py       # 第 1 条:算通勤。约 15-30 分钟,进度会一直打印
python3 build_map.py    # 第 2 条:生成地图。1 秒出两个文件

说明：

  • enrich.py 支持断点续传——中途断网、按 Ctrl+C 中止、配额用完，都没关系，重新运行会接着上次的进度跑；跑完顺便导出 result.csv（Excel 可开的排名表）；
  • build_map.py 一次生成两个地图文件：
    • map.html（个人版）：内嵌你的 JS Key，双击就能用——自己用这个，不要外传；
    • map-share.html（分享版）：不含任何 Key，随便发给朋友。对方打开会看到一张 2 分钟配置引导卡，粘贴 TA 自己免费注册的 JS Key（只存对方本机浏览器，谁用谁出配额）。

第四步：怎么用这张地图

  • 顶部色块图例：颜色越深离目的地越近，点色块可以隐藏/显示对应档位；
  • 区域下拉 + 月租上限 + 公寓类型：组合筛选；「不看公寓 / 只看公寓」按项目名称识别长租公寓（带「寓」、以「店」结尾、或柚米/微领地/自如/魔方/有巢等品牌），启发式判断，个别项目可能分错；
  • 🎯 搜索框：输入任意新目的地（或右键地图任意位置）→ 全部房源按直线距离重排 → 自动精算最近 30 个的真实通勤 → 需要更多就点「再精算 30 个」或「精算全部」（会先告知配额成本，可随时停止）；已精算的按真实时间排到列表前面；
  • 「回到 XX（全量精算）」按钮：切回 config.json 里那个目的地的 713 个全量精确数据；
  • 点任何圆点：租金/户型/最近地铁站/管家电话/跳高德导航，还能 ☆收藏（金圈高亮）或 ✕排除（看过不合适的不再显示）；顶部「⭐收藏 / 🚫已排除」可切视图、取消排除，「⬇ 导出收藏」一键导出 CSV 表格（含通勤时间和电话）；标记存在本机浏览器，换电脑不同步；顶部还有「🧳 毕业生落地指南」入口；
  • 进阶：地址栏结尾加 #dest=经度,纬度,名称 直达某个目的地视图。

想做成公开网站服务？请给 JS Key 绑定域名白名单，并把安全密钥改为服务端代理模式（_AMapSecurityConfig.serviceHost）。个人和小范围分享用上面两个文件就够了。

🧳 附赠:毕业生落地指南(不用配任何 Key)

guide.html 是纯静态页面,下载仓库后直接双击打开即可。首页是八宫格模块卡片(七个模块+通勤地图直达),点卡进入,顶部 tab 随时切换,#hash 可直达任意模块(如 guide.html#job):

  1. 落户自测:先判定你是否命中应届生直接落户通道(博士/双一流硕士/在沪一流大学本科/五个新城就业等),没命中再用 72 分计算器估分;附受理窗口提醒(只在毕业当年!)与替代路径;
  2. 居住证积分速算:本科有学位(90 分)+年龄(30 分)=120 达标——很多毕业生不知道自己"白送"达标;
  3. 租房路线图:保租房(毕业 2 年内凭毕业证可申、政策红线为同地段市场租金九折以下)→公租房(略低于市场价,配合地图挑)→市场租房(6 条避坑),附公积金租房月提取 4000 元设置方法和各区人才补贴查询姿势;
  4. 求职与到手工资:上海版到手工资计算器(2025-2026 社保公积金基数+个税,含公积金双边入账视角)、应届 offer 薪资数据去哪查、签约六大坑(培训贷/传销/试用期/应届身份与社保)、考公考编日历;
  5. 就医指南:公立三甲"白名单思维"+按毛病找医院速查表、官方挂号渠道、莆田系识别五特征(附 GitHub 众包名单仓库及其时效性提醒)、医保三段式报销与亲情账户/异地备案、962525 心理热线;
  6. 新城与通勤账:五个新城对比表(用本仓库房源数据算的区级租金中位数——新城约为市区一半)+落户 buff(居转户 7→5 年/临港 3 年)+通勤成本计算器(地铁计价+满 70 打 9 折);
  7. 落地 30 天清单:12 件事按顺序勾,进度自动保存(居住登记等有硬时限的事项已标红)。

政策数值为 2026-07 整理,页面内每个模块都附了官方来源链接;政策每年更新,正式申报以当年官方文件为准,欢迎 PR 修订。

更新房源数据

listings.csv 是 2026-07 的快照。房源每月都有上下架，更新方法：

  1. 用 Excel/WPS 打开 listings.csv（前三列必填：项目名称、区域、地址，其余选填：户型、最低租金、最高租金、最小面积、最大面积、联系电话）；
  2. 各区公租房运营机构的官网/公众号会公示当期房源，增删改行即可（保持表头不动，另存为 CSV UTF-8 格式）；
  3. 重新跑 python enrich.py——已经算过的地址不会重算，只补新增的，很快。

换了 destination_name 再跑 enrich.py，会自动作废旧的通勤数据、全部重算（地理编码不用重来）。

常见问题

  • 报 INVALID_USER_KEY：config.json 里 amap_web_key 填成了 JS API 类型的 Key（或复制时带了空格）。两个 Key 别填反。
  • 地图打开是白屏：JS Key 和安全密钥没配对，或 amap_js_security_code 没填。F12 控制台会有 INVALID_USER_SCODE 字样。
  • 朋友打开分享版填的 Key 存在哪？：只存在 TA 自己浏览器的 localStorage 里，不上传任何服务器；引导卡上有"清除已存 Key"入口。
  • 报"今日配额用完"：免费额度按天重置，明天重跑 enrich.py 自动续传补齐。
  • 通勤时间和我实际体验不一样：批量计算用的是跑程序当时的路况（建议白天跑）；地铁时间受高峰影响小，驾车早晚高峰请自行上浮 50%~100%。
  • 公租房/保租房是市场价打几折？：保租房政策红线是"不高于同地段同品质市场租金的 90%"，公租房是"略低于市场"（无统一折扣）；网传"8 折"没有官方依据。本项目显示的都是各项目实际挂牌租金，不做折扣推算。
  • 想用在其他城市：改 config.json 的 city，并替换 listings.csv 为你的房源表即可跑通主流程；enrich.py 里的行政区校验表（BOX/ADCODE）是上海专用的，其他城市会自动跳过校验（定位精度略降），欢迎 PR 补充你的城市。
  • 数据从哪来/准不准：房源快照由个人从各区公租房运营机构的公开公示整理，仅供找房参考，以运营机构最新公示为准；本项目不含任何个人隐私数据。
