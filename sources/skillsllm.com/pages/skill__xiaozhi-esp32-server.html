🚩 配置说明和推荐

[!Note] 本项目提供两种配置方案：

  1. 入门全免费配置：适合个人家庭使用，所有组件均采用免费方案，无需额外付费。

  2. 流式配置：适合演示、培训、超过2个并发等场景，采用流式处理技术，响应速度更快，体验更佳。

自0.5.2版本起，项目支持流式配置，相比早期版本，响应速度提升约2.5秒，显著改善用户体验。
