基层中国的运行逻辑

可执行 AI Skill · 安装 ID：nie-grassroots-logic
来源：聂辉华《基层中国的运行逻辑》（组织经济学 + 政治经济学 + 实地调研）
本 skill 提纯结构、不写摘要；忠于原著命名与因果，不编造原书没有的框架/数字/案例。
开源包不含原书全文；请购买正版。一页索引见 INDEX.md。

哲学（先记住）

  1. 中国的问题，归根结底都是政治经济学问题。 先找权力与激励，再谈道德与情怀。
  2. 公说公有理，婆说婆有理；究竟谁有理，关键看逻辑；逻辑要自洽，关键看框架。
  3. 人跟资源走，资源跟权力走，权力本质是等级体系。 市场与等级并存；基层很多事不是价格配置的。
  4. 理解基层，才能理解中国。 基层是底色与基本盘；国家治理与基层治理必须上下同治。
  5. 有限权力 + 无限责任（政治承包制） 是基层主官的结构性张力；别把县委书记简单画成「土皇帝」或「包青天」。

调用本 skill 时必须做的

  1. 先判断用户问题落在哪一层（见下方「三层地图」），再打开对应 references/。
  2. 优先用原书命名框架分析，不要改写成泛化政治学口号。
  3. 输出结构默认：
    • 这是什么问题（条/块？级？激励？财权？）
    • 用哪个框架切
    • 因果链（谁激励谁、权责是否对称）
    • 可执行判断/选项（选岗、读新闻、写分析时）
    • 反模式提醒（见 anti-patterns-voice.md）
  4. 不确定的制度细节标「[原书有述·具体现行规定请核最新文件]」；不假装掌握最新人事口径。

决策树（先问这三句）

  1. 这是权力结构问题还是激励/考核问题？
    • 结构（谁管谁、条还是块）→ 层 I/II
    • 激励（为什么拼命干/不干/搞形式）→ 层 III 考核与晋升
  2. 主角是哪一级？ 中央/省/市/县/乡/村/街道 → 权界与天花板不同
  3. 用户要解释还是要选？
    • 解释现象 → 框架因果
    • 个人选择（求学/考公/投资/养老/创业）→ 先读 life-decisions.md，再补对应框架 reference

关键原则（调用时守住）

  1. 分清属地 vs 垂直、领导 vs 指导、分管 vs 联系。
  2. 权力边界 ≠ 辖区边界。 条管单位在地理上在县里，行政上未必归县委书记。
  3. 有权必有责，但基层常是权小责大。 分析时写清「无限责任政治承包」是否在起作用。
  4. 集权/分权要素不要混搭。 集权配：监督、忠诚、一刀切、犬牙交错；分权配：激励、能力、多样化、山川形便。
  5. 十八大前后规律不同。 勿用唯 GDP 锦标赛一套讲今天；要用政绩→问责、激励→监督。
  6. 物证纪律。 框架名、命题、案例来自原书；数字与人事以原书/用户补充为准。

设计原则（与 book-to-skill 一致）：

  1. 提纯结构，不写摘要
  2. 保留作者精确命名（如「含权量」「三座大山」「先上车再买票」）
  3. 为被调用而造：Agent 读完应能直接上手分析
  4. 物证纪律：不编原书没有的框架/数字；现行细则标待核

怎么用（最重要）

1. 直接说人话（推荐）

不必背模块名。用真实场景提问即可：

你可以说 Agent 通常会走向
「这个县为什么拼命卖地」 土地财政 + 三座大山
「乡镇和部委我该怎么选」 含权量 + 晋升 + life-decisions
「我们县要撤县设区了」 rezoning-household
「园区招商怎么谈才不踩坑」 政企四象限 + 营商环境
「抢高铁站通了为啥还空」 mega-project-contest

2. 显式点名 skill（更稳）

用 nie-grassroots-logic / 基层中国的运行逻辑 skill：
[粘贴新闻 / 你的选择题]
请按框架给：因果链 + 选项对比 + 风险 + 我需要本地核实的清单

3. 指定维度（输出更聚焦）

只从「考公选岗」维度分析，不要展开宏观史论。
用含权量三因子对比：A 市街道 vs B 县乡镇。

4. 指定模块（进阶）

先读 life-decisions 和 power-and-positions，再回答我要不要去乡镇。
按 innovation-risk-boundary 的红黄绿，判断这个试点能不能推。

5. 给足上下文（质量跃升）

尽量补充：

  • 地点层级：省 / 市 / 县 / 乡 / 街道 / 村
  • 你的角色：学生、考生、企业、居民、干部…
  • 材料：新闻链接摘要、公告要点、你的约束（家庭、风险偏好）
  • 要的产出：对比表 / 一页纸 / 话术 / 风险清单

6. 和「读原书」的关系

需求 建议
快速做判断、分析新闻 用本 skill
完整论证、数据与案例细节 读原书
写论文引用 引聂辉华原著，本仓库仅作工具辅助

各维度用例

下面每条都是可直接复制的提问模板；括号内是主要会用到的模块。

① 求学 / 选城读书

你在解决什么：去哪座城读书、资源与就业外部性怎么想。

孩子高考，纠结省会普通 211 vs 副省级城市的非 211。
用城市等级与资源分配逻辑帮我对比，并列出我要自己查的本地信息。

为什么好大学高度集中在高等级城市？这和「人跟资源走」怎么连？

相关模块：life-decisions §求学 · tiaokuai-and-rank

② 考公 / 选岗 / 调动

你在解决什么：路径、天花板、含权量、条块差异。

硕士应届，选项：中部县城乡镇 vs 省会区局 vs 直辖市街道辅警/城管编。
用含权量、城市等级、十八大后晋升新常态做三列对比表。

发改委主任和教育局局长、统计局局长，谁的「含权量」更高？为什么？

大学生村官值不值得去？什么目标下是管培生，什么目标下是屈才？

相关模块：life-decisions §考公 · power-and-positions · village-fit · playbooks A

③ 投资 / 买房 / 区域观察

你在解决什么：卖地、债务、产业、通车设站——制度风险滤镜（不是荐股荐房）。

我们地级市卖地收入腰斩，同时城投还在推新区。
用土地财政闭环 + 三座大山分析：居民买房要盯哪些信号？

「投资不过山海关」靠谱吗？用亲清营商框架和东西差异逻辑拆解。

隔壁县在抢高铁站，通车预期下房价已经涨了一波。如何分传闻/规划/开工/通车阶段看？

相关模块：life-decisions §投资 · development-dilemmas · business-environment · mega-project-contest

④ 养老 / 落脚

你在解决什么：回县城还是留省会——公共服务等级与财政可持续。

父母想回老家县城养老，我在省会。
从城市等级（医疗可达）、地方财政压力、数字政务对老人负担对比两边。

相关模块：life-decisions §养老 · tiaokuai-and-rank · local-governance

⑤ 创业 / 政企相处

你在解决什么：招商逻辑、补贴、合规、选城、怎么跟园区谈。

县域做农产品电商，县里很积极给承诺。
用政企四象限 + 不完全契约：合同里必须写清什么？如何防画饼？

对比 A 市（副省级）和 B 市（普通地级）落户工厂，用营商环境检查表打分维度列出来。

想推动一个地方试点项目被上级认可，昆山「三板斧」今天还能怎么用？红线在哪？

相关模块：life-decisions §创业 · development-dilemmas · business-environment · bottom-up-project · innovation-risk-boundary

⑥ 读新闻 / 人事 / 项目

你在解决什么：一条地方新闻背后的条块、KPI 与钱。

【粘贴新闻摘要】
用 playbook B：层级、条块、三座大山、钱与地、政企象限、一句话因果 + 反模式。

为什么「中央政策很好，一到地方就变形」？用委托—代理和上下同治解释，避免单纯道德叙事。

相关模块：local-governance · development-dilemmas · playbooks B · anti-patterns-voice

⑦ 区划变动（撤县设区 / 县改市）

我们县传出要撤县设区。对房价、学区、公务员、本地企业分别利弊是什么？
请分乐观/中性/悲观情景，并列出必须本地核实的文件。

相关模块：rezoning-household · tiaokuai-and-rank

⑧ 村治 / 回乡

致富能手竞选村支书，一肩挑后风险怎么评估？用适合度打分卡。

新型职业农民 / 返乡创业，和乡镇 KPI 怎么对齐才激励相容？

相关模块：village-fit · life-decisions

⑨ 容错创新 / 基层「躺平」

问责很严，同事都不敢试点。用红黄绿边界：哪些创新还能推？哪些绝对碰不得？

解释「基层不作为」时，如何避免只会骂人，而画出 KPI 与一票否决结构？

相关模块：innovation-risk-boundary · local-governance · bottom-up-project

⑩ 重大工程争夺（高铁 / 枢纽）

市里举全市之力抢高铁设站。用五幕剧本分析：争什么、筹码是什么、通车后空站/虹吸风险？

相关模块：mega-project-contest · bottom-up-project

⑪ 写作 / 讲课

用聂氏结构写 800 字：解释「属地责任」是什么、为什么基层怕这四个字。
要求有框架、有例子、反 AI 空话。

相关模块：playbooks E · anti-patterns-voice · tiaokuai-and-rank

核心框架速查

框架 一句话 典型场景
内外冲突的双均衡 内稳↔外稳 → 集权/分权两套兼容体系 宏观国策、监督强化、数字治理
条块结合，以块为主 矩阵治理；责任常落在块 属地责任、权责不对等
等级制配置资源 人跟资源走，资源跟权力走 城市差距、好大学分布、拨款
职务含权量 级别 × 管什么人 × 管多少钱 选岗、同级比权
三座大山 维稳、招商、借债 主官行为、地方新闻
压力型体制 + 注意力分配 指标膨胀、一票否决、棘轮 形式主义、迎检
政企四象限 合作 / 分治 / 合谋 / 伤害 招商、补贴、合规
土地财政闭环 工业低价地 + 商住高价地交叉补贴 房价、园区、卖地
活力—秩序 城市化大城/小城权衡 区域政策、收缩城市
上下同治 顶层设计 + 摸着石头过河 试点推广、改革路径
昆山三板斧 先做不说 → 做了再说 → 先上车再买票 基层创新（须加红线）
西气东输九步 想法→汇报→视察→批示→…→实施 重大项目推进
政商亲清 亲近服务 + 清白可预期 选城、营商比较
容错红黄绿 红线 / 灰区四问 / 绿区优先 敢不敢干

输出长什么样

高质量调用时，Agent 宜给出类似结构（可在提问里直接要求）：

## 问题界定（条/块？级？激励？财权？）
## 使用的框架（原名）
## 因果链
## 选项对比表（若是选择题）
## 风险与反模式
## 需要你本地核实的清单（批文、口径、数据）
## 建议（可执行、可撤销优先）

差输出特征（可要求重来）：只有「要重视基层」类空话；把县委书记写成土皇帝；编造内部消息；未标明待核却假装确定。

边界与免责

  • 人事编制、地方细则、补偿政策等 以现行有效文件与官方发布为准
  • 本 skill 不提供内幕消息、不构成法律 / 投资 / 人事决策建议
  • 原书案例与数据有时间戳；分析时注意「十八大前后规律不同」
  • 开源包 刻意不包含原书全文，避免版权风险
