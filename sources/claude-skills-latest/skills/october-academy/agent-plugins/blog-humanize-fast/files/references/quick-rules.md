# Quick Rules — Blog Humanize Fast

`blog-humanize-fast`가 블로그 최종 원고를 보수적으로 윤문할 때 쓰는 슬림 룰북이다.
이 파일은 `im-not-ai`의 `humanize-korean` quick-rules 계열을 플러그인 이식용으로
압축한 스냅샷이다. 본진 분류 체계나 학술 인용 전체를 복제하지 않는다.

## Do-NOT

다음 span은 탐지와 윤문 대상에서 제외한다.

- 고유명사, 제품명, 모델명, 기관명
- 수치, 날짜, 금액, 단위
- 큰따옴표 안 직접 인용
- 법률 조문, 수학/화학/통계 표기
- 코드펜스, 인라인 코드, JSX/HTML 태그와 속성
- URL, 링크 목적지
- 업계 표준 영어 약어: LLM, GPU, MCP, API, SDK, CLI 등
- 마크다운 구조: 헤더 레벨, 리스트 구조, 표 구조

## 과윤문 가드

- 강도 기본값은 `보수`.
- 탐지 근거가 약하면 그대로 둔다.
- 청크 변경률이 50%를 넘으면 그 청크는 원문으로 롤백한다. 전체 변경률이 30%를
  넘으면 경고를 남기고 결과 리포트에 표기한다.
- 문학적 비유, 감정 과장, 원문에 없는 수사를 추가하지 않는다.

## S1/S2 핵심 패턴

| ID | 패턴 | 심각도 | 처방 |
| --- | --- | --- | --- |
| A-1 | "~를 통해", "~에 대해", "~에 있어서" 번역투 | S2 | 조사와 동사로 직접 쓴다 |
| A-2 | 이중 피동, "~되어진다" | S1 | 능동 또는 단일 피동으로 바꾼다 |
| A-3 | "가지고 있다" 남발 | S2 | "있다", "갖췄다", 구체 동사로 바꾼다 |
| A-7 | 사역/인지/발화 동사의 영어식 직역 | S2 | 한국어 동사 호응으로 재배치한다 |
| A-16 | "그/그녀/그것/그들" 강박적 대명사 | S1 | 생략하거나 명사로 되돌린다 |
| A-18 | 관계절 직역으로 긴 좌향 수식 | S2 | 두 문장으로 나누거나 뒤에서 설명한다 |
| A-19 | "-에서의/-에로의/-으로의" 이중 조사 | S2 | 조사와 동사로 풀어 쓴다 |
| B-1 | 번역 가능한 영어를 괄호 병기 | S2 | 필요한 기술 용어만 보존한다 |
| C-1 | "첫째/둘째/셋째" 기계적 병렬 | S2 | 논리 흐름에 맞춰 문단 리듬을 바꾼다 |
| C-2 | 과도한 불릿/헤딩/이모지 | S2 | 산문으로 합치거나 구조를 줄인다 |
| D-1 | "결론적으로", "시사하는 바가 크다" | S1 | 삭제하거나 구체 결론으로 바꾼다 |
| D-2 | "주목할 만하다", "혁신적인" 같은 평가어 | S2 | 근거 있는 관찰로 바꾼다 |
| E-1 | 문장 길이와 종결어미가 지나치게 균일 | S2 | 짧고 긴 문장을 섞는다 |
| E-7 | 대화/구어에서 경어 단계가 흔들림 | S2 | 한 글 안에서 register를 맞춘다 |
| F-1 | "매우", "정말", "상당히" 수식 남발 | S2 | 삭제하거나 수치/사례로 바꾼다 |
| F-4 | "~적", "~성", "~화" 명사화 누적 | S2 | 동사/형용사 어근으로 되돌린다 |
| G-1 | "~할 수 있을 것으로 보인다" 다중 완곡 | S2 | 확실한 주장과 불확실한 주장을 나눈다 |
| H-1 | 문두 "또한/따라서/즉/나아가" 반복 | S2 | 접속사를 줄이고 문단 관계로 연결한다 |
| I-1 | "것이다", "점", "수", "바" 형식명사 과다 | S2 | 동사 중심으로 압축한다 |
| J-1 | 볼드, 따옴표, 대시 과다 | S2 | 강조를 줄이고 문장 자체로 힘을 만든다 |

## 자체검증 체크리스트

윤문 직후 다음을 확인한다. 위반하면 해당 edit를 롤백한다.

1. 수치, 날짜, 금액, 고유명사가 원문과 같은가.
2. 직접 인용과 코드/JSX/URL이 바뀌지 않았는가.
3. 원문의 주장, 논리 순서, 원인/결과가 유지됐는가.
4. 마크다운 구조와 frontmatter가 유지됐는가.
5. register와 장르가 유지됐는가.
6. 원문에 없던 비유, 감정, 평가, 새 정보가 추가되지 않았는가.
