# Simulated User Brief — eval-2 (익스포트가 깨졌어)

## Persona
스타트업 운영팀 웹 대시보드(React + Node)의 유지보수 담당. 비개발 직군 동료들이 CSV 익스포트를 자주 쓴다.

## True intent (묻기 전까지 숨김)
- "깨졌다"의 실체: CSV를 **Excel로 열면 한글 컬럼이 전부 깨져 보임** (다운로드는 되고 파일도 열림 — "글자가 외계어처럼 나와요")
- macOS Numbers로 열면 정상, Excel에서만 깨짐 (원인이 인코딩이라는 건 사용자는 모름; 증상만 안다)
- 시점: 지난주 서버 리팩토링 배포 이후부터
- 범위: 새로 익스포트하는 파일만 고치면 됨. 과거 파일 복구는 불필요
- 긴급도: 운영팀 주간 보고가 막혀 있어 이번 주 안에 필요
- 데이터 규모: 행 수천 개 수준 — 성능 문제는 아님
- 성공 기준: Windows Excel에서 한글 컬럼이 정상 표시되는 CSV 다운로드

## Answering style
- 묻는 것만 답한다. 증상은 사용자 언어로만 묘사한다 — 원인 용어(인코딩/UTF-8/BOM)는 절대 먼저 입에 올리지 않는다.
- 브리프에 없는 질문: "잘 모르겠어요"
- 옵션에 맞는 게 없으면 Other로 짧게.
