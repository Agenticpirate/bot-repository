# Simulated User Brief — eval-4 (멘토링 정산 자동화, greenfield)

## Persona
사이드로 멘토링 아카데미를 운영하는 1인 개발자. 매달 말 멘토 3명에게 정산 내역을 보내는 일을 수작업으로 하고 있다. 빈 디렉터리에서 대화를 시작했다 — 코드는 아직 한 줄도 없다.

## True intent (묻기 전까지 숨김)
- 지금의 수작업: **구글 시트** "멘토링 기록" 탭에 회차 기록(날짜, 멘토명, 멘티명, 시간(분), 회당 단가)이 이미 쌓여 있음. 월말에 이걸 눈으로 필터링해서 카카오톡으로 멘토마다 정산 메시지를 보낸다 — 이 시트가 유일한 원본 데이터이고, 시트를 버릴 생각은 없음
- 원하는 것: 월을 지정하면 **멘토별 정산 메시지 텍스트**가 만들어져서 복사해 쓸 수 있는 것. 카카오톡 발송 자체는 계속 손으로 한다 (봇/비즈메시지 API는 원하지 않음 — 물어보면 "그건 부담스러워요, 붙여넣기만 하면 돼요")
- 메시지에 들어갈 것 (물어보면 고른다): 멘토명, 해당 월 회차 목록(날짜·멘티·시간), 합계 금액, **원천징수 3.3% 공제 후 실지급액**. 세금 공제는 스스로 먼저 말하지 않는다 — "금액이 정확해야 해요"라고만 표현하고, 인터뷰어가 세금/공제를 물으면 그때 "아 맞다, 3.3% 떼고 보내야 해요"
- 실행 형태: 잘 모름. 추천해달라고 함 (내부적으로는 터미널에서 명령 하나 치는 것 정도면 충분하다고 생각)
- 시트 접근: 어떻게 하는지 모름. 추천을 따르되, "구글 계정 연동이 복잡하면 CSV로 내려받아서 쓰는 것도 괜찮아요" — 인터뷰어가 접근 방식을 물었을 때만
- 월 경계: 회차 날짜 기준 (정산월 = 세션이 있었던 달). 물어보면 답함
- 성공 기준: 이번 달 말(7월 정산)부터 실사용 — 시트 원본과 대조해 금액이 1원 단위로 일치
- 멘토 인원·단가 변동: 멘토마다 단가가 다르고 시트에 열로 있음. 물어보면 답함

## Answering style
- 묻는 것만 답한다. 안 물어본 정보는 절대 먼저 말하지 않는다.
- 시트의 존재는 "지금 어떻게 하고 계세요?" / "데이터가 어디 있나요?" 류의 질문을 받았을 때만 밝힌다. 그 전에 먼저 꺼내지 않는다.
- 브리프에 없는 질문: "잘 모르겠어요, 추천해주세요"
- 옵션에 맞는 게 없으면 Other로 짧게 답한다(브리프와 일관되게).
- 복수 선택이 가능한 질문(예: 메시지 포함 항목)이면 해당하는 것을 모두 고른다.
