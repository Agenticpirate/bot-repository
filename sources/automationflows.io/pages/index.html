01
Crawled daily

A miner walks GitHub, GitLab, Reddit, Hacker News, dev.to, and the n8n community forum every 12 hours. Workflow JSONs (n8n-nodes-base.*) are detected, fetched, and queued.

02
Integration tagged

Each workflow's nodes are parsed: integration list (Slack, OpenAI, Sheets, etc.), trigger type (webhook / cron / manual), AI presence, and complexity score (1–5 stars based on node count + branching).

03
Privacy stripped

Before publishing we strip pinData (test runs may contain real API responses), credential IDs, webhook URLs, and instance fingerprints. Original creator attribution is preserved with a canonical link.

04
One-click imported

Open the workflow page, hit Copy JSON, then paste into n8n. Or use the AutomationFlows desktop app to one-click push the workflow straight to your local n8n instance via its REST API — no copy-paste, no credential context-switching.

Built something useful? Push your workflow JSON to a public GitHub repo or share it on the n8n community forum, then drop the link below. Our miner re-runs every 12 hours and your workflow will be auto-indexed within 24 hours, with full credit to your name and source.

  • Public GitHub repo or n8n community forum post
  • Valid n8n workflow JSON (with nodes + connections)
  • 2+ nodes (we filter fragments and stub workflows)
  • Real integration (not just set + function nodes)
  • Strip your pinData and credential IDs before sharing — we re-strip on ingest, but it's good hygiene
  • Add a topic tag n8n-workflow on your GitHub repo for fastest indexing

We'll notify you when your workflow is indexed or if it needs changes.
