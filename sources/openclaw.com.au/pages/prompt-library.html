⚡ Power User Tips

🎯 Context Loading

Start sessions with: "Before we begin, read MEMORY.md for context and memory/today.md for today's notes."

📋 Structured Output

Ask for specific formats: "Output as markdown table" or "Format as numbered steps" or "Return as JSON".

🔄 Iterative Refinement

Say "That's good, but make it shorter" or "Focus more on [aspect]" to refine outputs quickly.

📁 Save Favorites

Store your best prompts in workspace/prompts/*.md and reference them: "Use the template from prompts/research.md".

🔗 Chain Prompts

Break big tasks into steps: "First research X, then analyze the findings, then create recommendations."

⏰ Schedule Prompts

Use cron jobs for recurring prompts: daily briefs, weekly reviews, monitoring tasks.
