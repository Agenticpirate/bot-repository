🧩 Skills Directory 56+ Skills

Extend your OpenClaw agent with powerful integrations. Skills connect your agent to external tools, APIs, and services — from Google Workspace to home automation.

📍 Jump to Category

Installing Skills

Skills are installed via ClawHub — the official skill marketplace:

openclaw skills install <skill-name>

After installing, restart the gateway: openclaw gateway restart
