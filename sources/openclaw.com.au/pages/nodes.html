📱 Nodes

Connect iOS, Android, and macOS devices as companion nodes. Give your agent eyes, ears, and hands on any device.

🤔 What Are Nodes?

A node is a companion device that connects to your OpenClaw Gateway and exposes capabilities like camera, screen recording, location, and remote command execution. Think of nodes as your agent's physical presence in the world.

Key concept: Nodes are peripherals, not gateways. Your messages still flow through the main Gateway — nodes just give your agent extra powers.
📱

iOS Node

iPhone/iPad companion app with camera, Canvas display, and location services. Alpha

🤖

Android Node

Full-featured with camera, Canvas, location, screen recording, and SMS sending.

💻

macOS Node

Menu bar app for running commands, notifications, and Canvas on your Mac.

🖥️

Headless Node

CLI-based node for Linux/Windows servers — remote command execution only.

🔗 Pairing Your Node

Nodes connect via WebSocket and require approval before they can access your Gateway.

1

Install the companion app

Download OpenClaw from the App Store (iOS) or Play Store (Android). For macOS, download from the GitHub releases.

2

Enter your Gateway address

Open the app and enter your Gateway's IP address and port (default: 18789). On the same network, it's usually 192.168.x.x:18789.

3

Approve the pairing request

On your Gateway machine, run:

openclaw devices list

Then approve:

openclaw devices approve <requestId>

Pro Tip: Use the /pair command in Telegram for a guided pairing flow.

4

Verify connection

Check your nodes are connected:

openclaw nodes status

🎯 Node Capabilities

📸

Camera Access

iOS • Android

Take photos and record video clips from front or back cameras. Perfect for visual documentation, security monitoring, or just showing your agent what you're looking at.

Take a photo:

openclaw nodes camera snap --node MyPhone --facing front

Record a 10-second video:

openclaw nodes camera clip --node MyPhone --duration 10s

List available cameras:

openclaw nodes camera list --node MyPhone
📍

Location Services

iOS • Android

Get the device's current location with configurable accuracy. Great for location-based reminders, tracking, or contextual responses.

Get current location:

openclaw nodes location get --node MyPhone

High accuracy with timeout:

openclaw nodes location get --node MyPhone --accuracy precise --max-age 15000
Note: Location is off by default. Enable it in the node app settings and grant system permissions.
🎬

Screen Recording

Android • macOS

Record what's on the device screen. Useful for tutorials, documentation, or debugging.

Record screen for 10 seconds:

openclaw nodes screen record --node MyPhone --duration 10s --fps 10

Record without audio:

openclaw nodes screen record --node MyPhone --duration 10s --no-audio
🖼️

Canvas (WebView)

iOS • Android • macOS

Display web content or custom UIs on the node device. Your agent can present dashboards, control panels, or interactive displays.

Show a webpage:

openclaw nodes canvas present --node MyPhone --target https://example.com

Take a screenshot:

openclaw nodes canvas snapshot --node MyPhone --format png

Run JavaScript:

openclaw nodes canvas eval --node MyPhone --js "document.title"
⚡

Remote Commands

macOS • Headless

Execute shell commands on the node device. Run your builds on a remote Mac, trigger scripts on a server, or manage infrastructure.

Route exec to a node:

openclaw config set tools.exec.host node
openclaw config set tools.exec.node BuildMac

Send a notification:

openclaw nodes notify --node BuildMac --title "Deploy Complete" --body "v2.0 is live!"
Security: Remote commands require explicit allowlisting. Use openclaw approvals allowlist add to permit specific commands.
💬

SMS Sending

Android

Send SMS messages through your Android phone. Requires SMS permission and a device with telephony support.

Send an SMS:

openclaw nodes invoke --node MyPhone --command sms.send --params '{"to":"+15555550123","message":"Hello!"}'

Server Alerts

🖥️ Headless Node Setup

Run a node on any machine (Linux, Windows, macOS) without a GUI. Perfect for servers and build machines.

1

Start the node (foreground)

openclaw node run --host <gateway-ip> --port 18789 --display-name "Build Server"
2

Or install as a service

openclaw node install --host <gateway-ip> --port 18789 --display-name "Build Server" openclaw node restart
3

Approve on the Gateway

openclaw nodes pending openclaw nodes approve <requestId>
4

Allowlist commands

openclaw approvals allowlist add --node "Build Server" "/usr/bin/git" openclaw approvals allowlist add --node "Build Server" "/usr/bin/npm"

💡 Pro Tips

🔋 Keep Apps Foregrounded

Camera and screen recording require the node app to be in the foreground. Background calls return an error.

🔐 Use Tailscale

For remote access, put your Gateway and nodes on a Tailscale network. No port forwarding needed.

📛 Name Your Nodes

Use --display-name when connecting or openclaw nodes rename to give nodes friendly names.

⚙️ Bind Exec to a Node

Set tools.exec.node in your config to always run exec commands on a specific node.
