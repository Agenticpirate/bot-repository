· what’s inside ·

Four files. One problem solved.

01

Tailwind preset

A tailwind-kinsman.preset.js that overrides Claude’s default token map — colors, radii, shadows, type scale — without ejecting from Tailwind. Drop it into tailwind.config.js in under a minute.

02

3 custom-palette examples

Carbon (dark, high-contrast sans), Dusk (warm amber on slate), and Birch (light, clean, editorial). Each ships as a ready-to-use Tailwind theme and a color-token JSON you can paste into any design tool.

03

claude-design-override.css

A single CSS file that targets the Claude Design system’s root variables and replaces them at the :root level. Import it last in your stylesheet. Trabajos without a build step — plain CSS custom properties, nothing compiled.

04

5 alternative font pairings

Five Google Fonts combos selected to break the default serif/mono stack: Geist + Geist Mono, Instrument Serif + DM Mono, Plus Jakarta Sans + Fira Code, Sora + Space Mono, and Cabinet Grotesk + Roboto Mono. Each includes the @import snippet and a usage note.

· questions ·

The real ones.

Does this only work with Claude-generated apps?

No. The Tailwind preset and override CSS work with any project using Tailwind v3+ or CSS custom properties. Claude Design is the specific system it targets, but the tokens are standard CSS — they’ll override any design system that uses root variables.

Will this break if Anthropic updates the Claude Design tokens?

The override targets CSS custom property names. If Anthropic renames variables in a major update, we’ll push a patch. Free updates are included for 12 months from purchase.

How does delivery work?

GitHub repo invite sent to your purchase email within a few hours of payment. One private repo, permanent access, pull updates as they ship.

Can I use this on client projects?
