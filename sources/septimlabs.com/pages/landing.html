One CSS variable. Whole new brand.

Every template exposes a single --accent CSS variable. Change that one value — hex, rgb, OKLCH, whatever — and every button, highlight, gradient, dot, and border update to match. No search-and-replace across 40 selectors.

  --accent: #6bffb8; /* your brand color */
  --accent-bg: rgba(107,255,184,0.04);
  --accent-border: rgba(107,255,184,0.3);
}
