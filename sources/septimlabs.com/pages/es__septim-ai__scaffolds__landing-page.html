FAQ

Straight answers.

Does this require any coding knowledge?

No. The page is a single HTML file. Claude Code edits it in response to plain-English instructions. The CLAUDE.md presets tell Claude Code what to change and what to leave alone. You need to know how to: open a file in a browser, open a folder in Claude Code, and drag a file to Netlify.

Can I change the colors and fonts?

Yes. The page has a single accent color controlled by one CSS variable — change it by replacing one hex value. The font is Inter (Google Fonts, free) — replacing it requires changing the import URL and one font-family declaration. Claude Code can do both in under 30 seconds.

How do I deploy it?

Three options: (1) Netlify drag-and-drop — drag the HTML file to netlify.com/drop, get a live URL in 10 seconds, free. (2) Vercel — push to GitHub, connect to Vercel, auto-deploys. (3) Any web host that serves HTML. No build step required.
