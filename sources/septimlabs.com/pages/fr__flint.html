Workflow Ce qu'il fait Déclencheur Statut
flint-pr-review.yml Relecture PR à 7 angles : dérive d'intention, logique, tests, sécurité, performance, surface API, rollback. Publie des constats structurés sur la PR. chaque PR ouverte / mise à jour ✓ En ligne
flint-security-triage.yml Scan de sensibilisation OWASP top-10 sur le diff. Niveau heuristique, ne remplace pas un SAST dédié. Constats cités fichier:ligne avec sévérité. PRs touchant src/api, src/auth, src/webhooks En cours
flint-migration-safety.yml Audit de migration BDD : risque de verrou, DDL en ligne, sûreté du rollback. Bloque le merge sur les constats de sévérité bloquante. PRs touchant migrations/, prisma/migrations/ En cours
flint-test-gaps.yml Trouve les fonctions ajoutées sans couverture de test. Publie une liste classée de ce qu'il faut tester ensuite. PRs touchant *.ts / *.js / *.py hors *.test.* En cours
flint-dependency-triage.yml Note les nouvelles dépendances par impact sur le bundle, ancienneté, CVE connues. Signale les nouvelles dépendances qui se remplacent trivialement. PRs touchant package.json, lockfiles, requirements.txt En cours
