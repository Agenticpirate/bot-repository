What This Skill Does

Long-term memory (LTM) operations backed by Notion. Persists decisions, preferences, facts, and procedures as durable records, tracks emotional state and event history, and writes daily journal entries. Recalled memory is meant to feed back into future agent behavior, not just serve as an archive.

Using Notion as the backend gives human-readable, filterable memory without running a separate database or embedding store.

When to use it

  • Saving a technical decision during a debugging session so it survives context resets
  • Recording emotional state after a stressful deployment or incident
  • Searching past memory entries to recover a preferred API approach
  • Writing a daily journal entry that summarizes completed work and next intentions
  • Logging an event with importance and trigger type when a project milestone is hit
Example Workflow
Here's how your AI assistant might use this skill in practice.
INPUT
User asks: remember that I prefer the data_sources API over direct page queries
AGENT
  1. 1Formats the preference as a structured JSON payload with type 'preference' and confidence 'high'
  2. 2Pipes the payload to ltm_write.js via stdin
  3. 3ltm_write.js calls the Notion API to create a new record in the -mem database
  4. 4Returns the new page ID as confirmation
OUTPUT
Memory saved as a 'preference' entry tagged 'notion' in the Notion LTM database
