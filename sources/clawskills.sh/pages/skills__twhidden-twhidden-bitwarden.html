What This Skill Does

Wraps the Bitwarden CLI with automatic login and session caching for both official Bitwarden and self-hosted Vaultwarden instances. Supports storing, retrieving, generating, and deleting passwords and credentials from the command line.

Automatic session caching eliminates repeated authentication on every command, making it practical for agents and scripts that perform multiple vault operations in a single session.

When to use it

  • Retrieving API keys for use in automation scripts
  • Generating and storing passwords for new service accounts
  • Looking up credentials during CI/CD pipeline configuration
  • Registering new accounts on a self-hosted Vaultwarden server
  • Locking the vault after a batch of automated credential operations
Example Workflow
Here's how your AI assistant might use this skill in practice.
INPUT
User asks: Generate and store a new password for the staging database
AGENT
  1. 1Run bw.sh login to authenticate and cache the session token in /tmp/.bw_session
  2. 2Run bw.sh generate 32 to create a 32-character secure password
  3. 3Run bw.sh create "Staging DB" "admin" "$PASS" "https://staging.example.com" to save the entry
  4. 4Run bw.sh list "Staging DB" to confirm the entry exists in the vault
OUTPUT
New credential entry created in the vault with a generated 32-character password
