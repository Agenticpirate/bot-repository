What This Skill Does

Queries, analyzes, and uploads blockchain data via the Dune Analytics API. Covers EVM and Solana chains, DEX trade analysis, wallet tracking, SQL optimization for DuneSQL (Trino), and CSV/NDJSON data uploads. Includes scripts for common operations and reference docs to avoid known table pitfalls.

Bundles scripts, reference docs, and anti-pattern guidance together so common mistakes like inflated volume from dex.trades or missing Solana deduplication are caught before they reach production.

When to use it

  • Tracking a wallet's trading volume across EVM chains
  • Analyzing DEX activity for a specific token or protocol
  • Uploading a CSV of wallet addresses to query against on-chain data
  • Finding and inspecting decoded event tables by contract address
  • Running parameterized Dune queries and monitoring credit usage
Example Workflow
Here's how your AI assistant might use this skill in practice.
INPUT
User asks: Show me the last 7 days of trading volume for a specific wallet on Ethereum
AGENT
  1. 1Read wallet-analysis.md and common-tables.md references to select correct tables
  2. 2Identify dex_aggregator.trades as the correct table for user-level wallet volume
  3. 3Write DuneSQL query filtering by wallet address and date range
  4. 4Execute query via dune_query.py or DuneClient with is_private=True
  5. 5Return results with credits consumed and data freshness note
OUTPUT
Table of daily trading volume in USD for the wallet over the past 7 days
