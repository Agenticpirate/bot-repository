What This Skill Does

A hook that intercepts Write and Edit operations on protected identity files before they execute. Write is always blocked on protected files; Edit is blocked when it removes more than 2 net lines. Works with Claude Code CLI and OpenClaw.

Unlike prompt-based instructions that get erased during context compaction, this hook enforces file protection at the tool call level regardless of agent state.

When to use it

  • Prevent Claude from overwriting CLAUDE.md during a long session
  • Keep MEMORY.md intact after context compaction resets agent behavior
  • Block accidental deletion of SOUL.md or IDENTITY.md mid-task
  • Protect journal or daily log files from bulk replacement
  • Enforce append-only edits to shared context files in multi-agent setups
Example Workflow
Here's how your AI assistant might use this skill in practice.
INPUT
User asks: 'Rewrite CLAUDE.md with updated instructions'
AGENT
  1. 1Agent issues a Write call targeting CLAUDE.md
  2. 2Hook intercepts the PreToolUse event and checks the filename against the protected list
  3. 3Hook denies the Write operation and returns a message instructing the agent to use Edit instead
  4. 4Agent retries with an Edit call
  5. 5Hook checks net line removal; if under 2 lines removed, the edit proceeds
OUTPUT
Edit is allowed or blocked based on net line change, and CLAUDE.md is never fully overwritten
