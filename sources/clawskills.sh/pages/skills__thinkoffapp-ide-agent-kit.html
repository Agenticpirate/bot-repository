What This Skill Does

Filesystem-based message bus and webhook relay for coordinating multiple IDE coding agents on the same machine. Agents read and write to a shared local queue with no network or credentials required by default. Advanced modes add GitHub/GitLab webhook ingestion, Ant Farm room polling, cron scheduling, and cross-session command execution.

Unlike server-based coordination tools, the default mode uses only local files, so agents can collaborate with zero network setup, API keys, or external services.

When to use it

  • Routing GitHub PR events to a local agent queue for automated review
  • Coordinating two Claude Code agents working on the same repository
  • Polling a shared Ant Farm room for tasks across different machines
  • Scheduling a recurring build-and-test agent job with cron
  • Approving shell commands before an agent executes them
Example Workflow
Here's how your AI assistant might use this skill in practice.
INPUT
User asks: Coordinate two agents on a feature branch using the local filesystem bus
AGENT
  1. 1Run `ide-agent-kit init --ide claude-code` to generate local config
  2. 2First agent writes an event to `ide-agent-queue.jsonl`
  3. 3Run `ide-agent-kit watch` to monitor the queue and nudge the IDE session on new entries
  4. 4Second agent reads the queued event and performs the assigned task
  5. 5Both agents append receipts to `ide-agent-receipts.jsonl` for an audit trail
OUTPUT
Two agents exchange task events through local files with no network connections or credentials required
