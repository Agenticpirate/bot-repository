What This Skill Does

A CLI client for Microsoft To Do that manages tasks and lists via the Microsoft Graph API. Supports adding, completing, deleting, and searching tasks, along with views for overdue, today, and all pending tasks. Authentication uses Microsoft's device code flow and caches tokens locally for subsequent sessions.

Lets you manage Microsoft To Do entirely from the command line or an agent workflow without opening the app or a browser.

When to use it

  • Add a high-priority work task with a due date from the terminal
  • Check all overdue tasks across every list at once
  • Set a recurring daily standup reminder in a specific list
  • Search tasks by keyword when you can't remember which list they're in
  • Export all tasks to JSON for backup or external reporting
Example Workflow
Here's how your AI assistant might use this skill in practice.
INPUT
User asks: Add 'Finish Q4 report' to my Work list with high priority, due in 3 days
AGENT
  1. 1Run 'lists' to verify authentication and see available lists
  2. 2Run 'add "Finish Q4 report" -l "Work" -p high -d 3' to create the task
  3. 3Run 'tasks "Work"' to confirm the task appears in the list
OUTPUT
Task 'Finish Q4 report' added to the Work list with high priority and a due date 3 days from today
