What This Skill Does

A Playwright wrapper that routes browser traffic through residential proxies with a spoofed iPhone fingerprint. launchHuman() is a drop-in replacement for chromium.launch(). Includes handlers for shadow DOM forms, rich text editors, CAPTCHA solving, and session persistence.

Datacenter IPs get flagged by reputation checks before JavaScript runs, so fingerprint tricks alone fail — this addresses the root cause by routing through residential ISP addresses.

When to use it

  • Scraping Amazon product listings without triggering bot detection
  • Automating Reddit post submissions from residential IP addresses
  • Logging into LinkedIn and extracting profile data programmatically
  • Monitoring Cloudflare-protected sites for price or content changes
  • Filling multi-step forms on anti-bot-protected pages from specific countries
Example Workflow
Here's how your AI assistant might use this skill in practice.
INPUT
User asks: scrape product data from a Cloudflare-protected e-commerce site
AGENT
  1. 1Call launchHuman() to open a browser with Romanian residential IP and iPhone 15 Pro fingerprint
  2. 2Navigate to the target URL and wait for Cloudflare challenge to resolve
  3. 3Call humanScroll() to generate mouse entropy and pass behavioral scoring
  4. 4Extract product data using page selectors or page.evaluate()
  5. 5Return structured results and close the browser
OUTPUT
Product data returned as structured JSON without triggering bot blocks or IP bans
