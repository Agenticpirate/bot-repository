What This Skill Does

Triage assistant for Gmail that uses a Haiku LLM agent to classify inbox emails, apply labels, and generate draft replies. Operates on summaries, never on full email content, and never sends automatically.

LLM-based classification handles ambiguous or context-dependent emails that break regex or keyword rules.

When to use it

  • Sorting a flooded inbox before a busy school morning
  • Flagging emails from club advisors that need a response
  • Auto-labeling billing receipts without manual folder rules
  • Drafting a reply to a college inquiry in your own writing style
  • Identifying which threads are still waiting on someone else
Example Workflow
Here's how your AI assistant might use this skill in practice.
INPUT
User runs the triage workflow on their Gmail inbox
AGENT
  1. 1Run triage-and-draft.sh to fetch inbox and write summaries to gmail-inbox-summaries.json
  2. 2Haiku agent reads summaries and classifies each email by label category
  3. 3Agent writes classification results to gmail-triage-labels.json
  4. 4Run apply-labels.sh to apply labels to Gmail threads via gog CLI
  5. 5Agent writes triage digest and draft replies to cache files for user review
OUTPUT
Inbox threads are labeled (Urgent, Needs Reply, Read Later, etc.) and draft replies are queued in gmail-drafts.md for manual review and sending
