What This Skill Does

Generates new images or edits existing ones through the Skywork Image API. Supports text-to-image and image-to-image workflows with aspect ratio options and resolution up to 4K. Includes specialized prompting guidance for posters, logos, e-commerce products, branding, and social media assets.

Combines image generation and editing in a single tool with resolution control, aspect ratio presets, and built-in prompt engineering guidance for common design tasks.

When to use it

  • Creating a product photo for an online store listing
  • Designing a logo for a side project or startup
  • Generating an Instagram post graphic in the right aspect ratio
  • Editing an existing image to change its style or remove elements
  • Producing a high-resolution event poster ready for print
Example Workflow
Here's how your AI assistant might use this skill in practice.
INPUT
User asks: Create a 4K poster for a summer music festival with a tropical theme
AGENT
  1. 1Builds a detailed descriptive prompt with scene composition, colors, and lighting details
  2. 2Selects 3:4 aspect ratio for poster format and 4K resolution for print quality
  3. 3Runs generate_image.py with the prompt, filename, aspect-ratio, and resolution flags
  4. 4Waits approximately 2 minutes for the API to generate the image
  5. 5Returns the local file path and OSS URL to the user
OUTPUT
A 4K poster image saved locally as a timestamped PNG file, with an OSS URL for sharing
