What This Skill Does

Configures and manages SEO monitoring alerts for ranking drops, traffic changes, technical issues, competitor movements, and AI/GEO visibility shifts. Defines thresholds, priority levels, notification routing, and response plans for each alert type. Works with connected SEO tools or manual baseline data.

Each alert is paired with a priority level and a step-by-step response plan, so the team knows what to do the moment one fires rather than scrambling to figure it out.

When to use it

  • Getting notified when a top keyword drops more than 5 positions overnight
  • Setting a 30% week-over-week traffic drop threshold for the main landing page
  • Routing critical crawl errors to the right team channel in Slack
  • Monitoring a competitor domain for sudden ranking gains in shared keywords
  • Tracking AI citation loss for brand queries on a weekly schedule
Example Workflow
Here's how your AI assistant might use this skill in practice.
INPUT
User asks: Set up ranking drop alerts for my top keywords
AGENT
  1. 1Groups keywords into critical and high-priority tiers based on current positions
  2. 2Assigns position-drop thresholds per tier (e.g., any drop for rank 1, drop past top 10 for rank 9)
  3. 3Maps each priority level to a response time and immediate action checklist
  4. 4Configures notification delivery to email and Slack for the SEO team
  5. 5Outputs an alert summary table and a weekly review checklist
OUTPUT
Alert configuration table with keyword positions, trigger conditions, priority labels, and a numbered incident response plan
