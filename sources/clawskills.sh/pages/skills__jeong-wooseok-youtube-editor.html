What This Skill Does

Automates the YouTube content production pipeline: downloads a video, transcribes it with Whisper, generates SEO metadata with GPT-4, and creates AI thumbnails with consistent character styling. Supports Korean-language output and custom avatar images. Optionally integrates with the nano-banana-pro skill for image generation.

Combines transcription, metadata generation, and thumbnail creation into a single automated run instead of requiring separate tools for each step.

When to use it

  • Generating subtitles for a recorded lecture before uploading
  • Creating Korean SEO titles and tags for a gaming video
  • Producing a branded thumbnail using your own photo as the avatar
  • Batch-processing local video files into upload-ready packages
  • Quickly generating a Pirate Lobster thumbnail for a prototype video
Example Workflow
Here's how your AI assistant might use this skill in practice.
INPUT
User asks: process this YouTube video and generate a thumbnail with my face
AGENT
  1. 1Downloads the video from the provided YouTube URL using yt-dlp
  2. 2Transcribes the audio to an .srt subtitle file using OpenAI Whisper
  3. 3Sends transcript to GPT-4 to generate SEO-optimized title, description, and tags in Korean
  4. 4Generates a consistent character thumbnail using the user-supplied avatar image via nano-banana-pro
  5. 5Removes background from generated character and composes final Black & Gold thumbnail layout
OUTPUT
Subtitle file, SEO metadata text, and a finished thumbnail image saved to the working directory
