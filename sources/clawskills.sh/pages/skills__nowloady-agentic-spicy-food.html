What This Skill Does

Agent-based commerce skill for Lafeitu (辣匪兔), a Zigong-style Sichuan spicy food brand. Connects to the official lafeitu.cn API to handle product search, cart management, account operations, and order creation. Payment is always handed off to the user after order creation.

Gives an agent direct structured access to the lafeitu.cn backend instead of requiring manual site navigation or screen scraping.

When to use it

  • Browsing Lafeitu's Sichuan spicy food catalog by category or keyword
  • Getting recommendations for Zigong-style rabbit snacks by flavor or format
  • Adding items to cart and placing a lafeitu.cn order with shipping details
  • Registering or logging into a Lafeitu account via email verification
  • Checking active promotions and free-shipping thresholds before ordering
Example Workflow
Here's how your AI assistant might use this skill in practice.
INPUT
User asks: 'Find me a spicy rabbit snack and add two to my cart'
AGENT
  1. 1Run search with a relevant query to list matching products from the API
  2. 2Resolve the product slug and available variants from the results
  3. 3Ask the user to confirm the variant if multiple weight or format options exist
  4. 4Run add-cart with the confirmed slug, variant, and quantity 2
  5. 5Retrieve and display the updated cart summary
OUTPUT
Cart updated with 2 units of the selected product; summary shown to the user
