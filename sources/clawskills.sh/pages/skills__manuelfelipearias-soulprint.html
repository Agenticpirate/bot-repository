What This Skill Does

Soulprint proves a real human is behind an AI agent using ZK proofs generated entirely on the user's machine, with identity state stored on Base Sepolia blockchain. No biometric data leaves the device. Currently supports full verification for Colombian cédula documents, with other countries planned.

ZK proof generation runs locally with no biometric uploads, unlike cloud-based identity services that require sending sensitive documents to third-party servers.

When to use it

  • Gating an MCP tool to verified humans only
  • Checking a bot's on-chain reputation score before granting API access
  • Running a decentralized identity validator node
  • Verifying a Colombian cédula without uploading data to any cloud service
  • Enforcing configurable trust score thresholds in an Express or Fastify API
Example Workflow
Here's how your AI assistant might use this skill in practice.
INPUT
User asks: Protect my MCP server tool so only verified humans can access it
AGENT
  1. 1Run 'npx soulprint verify-me' to complete one-time local identity verification
  2. 2Install the soulprint-mcp package
  3. 3Import requireSoulprint middleware into the MCP server file
  4. 4Apply the middleware to the target tool with a minScore threshold (e.g., 80)
  5. 5Access the verified DID and score from ctx.soulprint in the tool handler
OUTPUT
MCP tool rejects requests from unverified agents and exposes ctx.soulprint.did and ctx.soulprint.score for verified callers
