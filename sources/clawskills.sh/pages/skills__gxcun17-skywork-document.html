What This Skill Does

Calls the Skywork Office Doc API to generate formatted documents in docx, pdf, html, and markdown. Creates reports, proposals, resumes, research summaries, and other structured content from scratch or from uploaded reference files. The API performs server-side web searches to incorporate current information.

Produces polished, multi-format documents with built-in web research and reference file support, removing the need to manually compile and format content.

When to use it

  • Draft a market research report with auto-sourced statistics
  • Rewrite a resume based on an uploaded PDF
  • Summarize an academic paper into a structured brief
  • Generate a project proposal in a specific language
  • Convert meeting notes into a formatted memo
Example Workflow
Here's how your AI assistant might use this skill in practice.
INPUT
User asks: Write a competitor analysis report on EV charging companies in Brazil, in Portuguese, as a Word document
AGENT
  1. 1Analyze request to determine language (Portuguese), format (docx), and no reference files
  2. 2Compose a detailed content prompt describing report structure and key sections
  3. 3Call create_doc.py with title, content prompt, language set to Portuguese, and format docx
  4. 4Wait for server-side generation including automatic web research
  5. 5Parse output for file_url and file_path and deliver both to the user
OUTPUT
A formatted .docx report downloaded locally and available via cloud link
