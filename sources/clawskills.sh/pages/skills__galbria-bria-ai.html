What This Skill Does

Bria AI provides image generation and editing via commercially-safe models (FIBO, FIBO-Edit, RMBG-2.0, GenFill). Covers background removal, object editing, upscaling, style transfer, and product photography. Supports text-based edits, mask-based inpainting, and batch pipelines.

Unlike general-purpose generators, Bria lets you target specific regions, objects, lighting, and seasons independently rather than regenerating the entire image.

When to use it

  • Remove product background for e-commerce listing
  • Generate hero banner from text prompt
  • Replace sky in outdoor product photo
  • Upscale low-res product image 4x for print
  • Create lifestyle shot of product in kitchen scene
Example Workflow
Here's how your AI assistant might use this skill in practice.
INPUT
User asks: remove the background from this product photo and place it on a modern kitchen countertop
AGENT
  1. 1Check BRIA_API_KEY is set
  2. 2POST image to /v2/image/edit/remove_background to get transparent PNG
  3. 3POST transparent PNG to /v1/product/lifestyle_shot_by_text with prompt describing the kitchen scene
  4. 4Poll status URL until COMPLETED
  5. 5Return final image URL to user
OUTPUT
Product image composited onto a kitchen countertop with matched lighting
