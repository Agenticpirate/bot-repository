What This Skill Does

Soulforge runs autonomous coding loops, covering feature delivery, bug diagnosis, and PR review-fix cycles. It enforces worktree isolation, blocks main-checkout runs, and structures review gates to prevent scope drift.

It enforces worktree isolation and scope discipline at the tooling level, preventing main-branch contamination and review drift that ad-hoc autonomous coding loops commonly produce.

When to use it

  • Delivering a GitHub issue end-to-end from plan to merged PR
  • Running a failing-test-first bugfix with a minimal patch
  • Tightening a draft PR through repeated review-fix cycles
  • Keeping scope locked during multi-loop refactor reviews
  • Monitoring autonomous run progress via step callbacks
Example Workflow
Here's how your AI assistant might use this skill in practice.
INPUT
User asks: Run feature-dev for a GitHub issue with a two-story cap and no unrelated refactors
AGENT
  1. 1Provision a worktree under repo/worktrees/ for the feature branch
  2. 2Run `soulforge run feature-dev` with the issue URL, scope constraints, and a callback-exec for step notifications
  3. 3Wait for the review gate checkpoint to fire
  4. 4Triage review findings: mark in-scope defects as FIX, separate unrelated suggestions
  5. 5Run `soulforge complete` to close the loop and open the PR
OUTPUT
PR containing only in-scope changes, ready for merge after review gate passes
