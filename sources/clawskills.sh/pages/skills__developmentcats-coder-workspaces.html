What This Skill Does

Manages Coder workspaces via the coder CLI, covering the full lifecycle from creation to deletion. Also creates and monitors AI coding agent tasks using Claude Code, Aider, or similar agents running in isolated workspaces.

Runs AI coding agents in governed, isolated Coder workspaces rather than on the host machine, keeping side effects contained.

When to use it

  • Starting a stopped workspace before a coding session
  • Running a one-off command inside a remote workspace over SSH
  • Launching a Claude Code task against a specific codebase template
  • Checking live logs from a provisioning workspace
  • Cleaning up finished AI task workspaces
Example Workflow
Here's how your AI assistant might use this skill in practice.
INPUT
User asks: Create an AI task to refactor the auth module using Claude Code
AGENT
  1. 1Run `coder templates list` to find available templates
  2. 2Run `coder templates presets list <template> -o json` to check for required presets
  3. 3Run `coder tasks create --template <template> --preset "<preset>" "Refactor the auth module to use JWT"` to create the task
  4. 4Run `coder tasks list` to confirm the task is initializing
  5. 5Run `coder tasks logs <task-name>` to follow progress as the agent works
OUTPUT
Task transitions through Initializing, Working, and Active states; logs show Claude Code refactoring the auth module inside the isolated workspace
