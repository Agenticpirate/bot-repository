# GitHub Packages publish from public repo **Date:** 2026-03-16 **Closes:** #193 ## What changed `deploy-public.sh` now publishes to GitHub Packages from the public repo clone after the npm publish step. What This Skill Does

Scans a repository for Universal Interface-compatible components and installs all detected interfaces in a single command. Handles CLI tools, MCP servers, OpenClaw plugins, Claude Code hooks, and skills automatically. Can also be used as a module for programmatic interface detection.

Instead of manually checking a repo for separate CLI, MCP, and plugin setup instructions, a single command installs everything the repo exposes at once.

When to use it

  • Installing a new agent-native repo without reading its docs
  • Detecting which interfaces a repo exposes before committing to install
  • Setting up MCP servers and CLI tools from a single GitHub repo in one step
  • Validating a repo follows the Universal Interface spec in a CI pipeline
  • Doing a dry run to audit what a repo would install before making changes
Example Workflow
Here's how your AI assistant might use this skill in practice.
INPUT
User asks: install the tool at github.com/acme/my-agent-tool
AGENT
  1. 1Run `wip-install acme/my-agent-tool` to clone and begin installation
  2. 2wip-install scans the repo for Universal Interface markers (bin fields, mcp-server.mjs, openclaw.plugin.json, guard.mjs, SKILL.md)
  3. 3Detected interfaces are printed and installation proceeds for each one
  4. 4CLI binaries, MCP server, and OpenClaw plugin are registered automatically
OUTPUT
All interfaces from the repo are installed and ready to use
