What This Skill Does

Collects tech news from six source types, RSS feeds, Twitter/X accounts, GitHub releases, GitHub Trending, Reddit, and web search, then merges and deduplicates results using quality scoring before generating digests. Output supports Discord messages, HTML email, and PDF reports. All sources are configurable; defaults cover 151 sources across AI, crypto, and frontier tech topics.

Aggregates six distinct source types into a single scored, deduplicated feed so you don't need separate monitors for RSS, GitHub, Reddit, and Twitter.

When to use it

  • Posting a daily AI and crypto digest to a Discord server
  • Tracking GitHub releases for open-source LLM projects
  • Monitoring tweets from AI researchers and tech executives
  • Generating a weekly PDF digest for email distribution
  • Deduplicating the same story appearing across Reddit, RSS, and Twitter
Example Workflow
Here's how your AI assistant might use this skill in practice.
INPUT
User asks: Run the pipeline and generate today's tech digest for Discord
AGENT
  1. 1Run run-pipeline.py with --hours 48 to fetch all six sources in parallel
  2. 2Wait for merge-sources.py to deduplicate and score articles by topic
  3. 3Run enrich-articles.py to fetch full text for high-scoring articles
  4. 4Apply the Discord template from references/templates/discord.md to the merged JSON
  5. 5Post the formatted digest to the configured Discord channel
OUTPUT
A Discord message with emoji-headed topic sections, top articles with scores, and suppressed raw URLs
