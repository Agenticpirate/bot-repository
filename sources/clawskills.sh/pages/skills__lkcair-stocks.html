What This Skill Does

Provides 56+ financial data tools powered by Yahoo Finance. Covers stock prices, fundamentals, earnings, dividends, options chains, crypto, forex, commodities, and news through a Python async interface. Auto-routes queries to the appropriate function based on intent.

Consolidates equity, crypto, forex, commodities, and news into a single consistent API instead of juggling multiple data sources or web scrapers.

When to use it

  • Check live stock price before placing a trade
  • Compare P/E ratios across multiple tech companies
  • Pull earnings history for a quarterly review
  • Get options chain data for a specific expiry
  • Monitor crypto and forex rates in one place
Example Workflow
Here's how your AI assistant might use this skill in practice.
INPUT
User asks: What are Apple's key financial ratios?
AGENT
  1. 1Identify request as a valuation/ratios query
  2. 2Route to get_key_ratios function
  3. 3Execute using venv Python interpreter: .venv/bin/python3 with asyncio wrapper
  4. 4Call t.get_key_ratios(ticker='AAPL') and capture output
OUTPUT
P/E ratio, ROE, profit margins, and other key ratios for AAPL printed to stdout
