What This Skill Does

Crawls websites using crawl4ai to extract contact email addresses. Accepts multiple URLs and groups results by source domain with page-level attribution. Targets pages likely to contain emails (contact, about, support, team) and supports JSON or plain text output.

Groups emails by domain with the specific pages where each address was found, making it easy to trace sources across multi-site crawls.

When to use it

  • Finding contact emails for cold outreach lists
  • Auditing a company's publicly listed support addresses
  • Batch crawling multiple competitor sites for contact info
  • Extracting emails from locally cached markdown files
  • Building a domain-grouped email inventory for sales prospecting
Example Workflow
Here's how your AI assistant might use this skill in practice.
INPUT
User asks: Find all contact emails on example.com and save to a JSON file
AGENT
  1. 1Run find_emails.py with the target URL and -j and -o flags
  2. 2Crawler follows links matching contact, about, support, and team URL patterns up to depth 2
  3. 3Emails are extracted from matched pages and deduplicated per domain
  4. 4Results are written to the output file grouped by domain with source page paths
OUTPUT
JSON file listing each unique email under its domain, with an array of page paths where it appeared
