What This Skill Does

Controls and automates DuoPlus cloud phones through ADB broadcast commands. Supports tapping, swiping, typing, screenshots, and reading UI element hierarchies using a relative 0-1000 coordinate system.

Lets an AI agent drive a full Android device remotely through simple JSON commands instead of requiring manual ADB scripting or physical device access.

When to use it

  • Automating repetitive app interactions on a cloud phone
  • Running UI checks on remote Android devices without physical access
  • Scraping on-screen content from cloud-hosted Android apps
  • Batch-processing tasks across multiple cloud phone instances
  • Monitoring app state through periodic screenshots and UI dumps
Example Workflow
Here's how your AI assistant might use this skill in practice.
INPUT
User asks: Open WeChat on the cloud phone and send 'Hello' to the first chat
AGENT
  1. 1Connect to the cloud phone via adb connect and verify the device is listed
  2. 2Send OPEN_APP command with WeChat's package name to launch the app
  3. 3Take a screenshot and compress it to confirm WeChat has loaded
  4. 4Dump the UI hierarchy with uiautomator and locate the first chat element
  5. 5Tap the chat entry, tap the input field, type 'Hello', and press enter
OUTPUT
Message 'Hello' sent to the first chat in WeChat on the cloud phone
