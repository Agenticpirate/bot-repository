What This Skill Does

A growth coaching agent for organic mobile app marketing on TikTok and Instagram. Guides users through account setup, content-market fit testing, and multi-account scaling. Posts content automatically via the Post Bridge API once proven formats are established.

Combines a structured six-phase growth playbook with direct multi-platform posting automation, replacing the need for a separate social media scheduler and a separate marketing coach.

When to use it

  • Scheduling a week of TikTok and Instagram posts in one sitting
  • Writing hook-driven captions for app demo videos
  • Setting up new social accounts for a freshly launched mobile app
  • Posting the same video to multiple platforms simultaneously
  • Diagnosing why views are not converting to app downloads
Example Workflow
Here's how your AI assistant might use this skill in practice.
INPUT
User asks: Post these 3 videos to TikTok and Instagram today, spaced 4 hours apart
AGENT
  1. 1Extract a frame from each video with ffmpeg to read any text overlays
  2. 2Write captions using proven hook formulas based on video content
  3. 3Upload each video to Post Bridge via the media upload API
  4. 4Create posts with staggered scheduled_at times 4 hours apart
  5. 5Confirm post IDs and scheduled times for each platform
OUTPUT
6 scheduled posts (3 TikTok, 3 Instagram) with post IDs and confirmed delivery times
