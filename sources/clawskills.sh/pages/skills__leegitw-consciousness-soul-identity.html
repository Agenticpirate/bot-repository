What This Skill Does

Reads memory files from your local workspace, finds recurring patterns across conversations, and writes a SOUL.md identity document where every claim traces back to a source file. Synthesis is incremental — only new or changed memory gets processed. Runs entirely on your machine via a local Ollama instance.

Unlike hand-written identity documents, every axiom includes full provenance linking it to the actual conversations that produced it.

When to use it

  • Tracking how your stated values shift across months of conversation logs
  • Auditing which specific memories gave rise to a particular identity axiom
  • Rolling back SOUL.md to a previous version after an unwanted synthesis
  • Scheduling hourly soul synthesis so the document stays current without manual effort
  • Previewing what patterns would emerge before committing any changes with --dry-run
Example Workflow
Here's how your AI assistant might use this skill in practice.
INPUT
User asks: Synthesize my soul from memory files
AGENT
  1. 1Runs the synthesis engine against the memory/ directory
  2. 2Finds recurring signals and groups them into principles
  3. 3Detects tensions and matches principles to axioms
  4. 4Writes updated SOUL.md with provenance metadata
  5. 5Backs up previous version to .neon-soul/backups/
OUTPUT
Summary report: e.g. '3 new signals found, 1 new axiom emerged around honesty. Soul document updated.'
