What This Skill Does

Distil converts web pages to clean Markdown via a proxy, reducing token consumption by 60–80% compared to raw HTML. Agents get consistent access to web fetch, search, screenshots, and rendered pages without managing headers or URL construction manually.

Stripping HTML boilerplate before it hits the LLM context window cuts token costs significantly, making web-augmented agents practical at scale.

When to use it

  • Fetching API documentation as Markdown for an agent to read
  • Searching the web for current information during a research task
  • Capturing screenshots of web pages for visual inspection
  • Reading JavaScript-rendered single-page apps that require execution
  • Bypassing cache to get the freshest version of a frequently updated page
Example Workflow
Here's how your AI assistant might use this skill in practice.
INPUT
User asks: 'What are the latest Go error handling best practices?'
AGENT
  1. 1Constructs the search URL using DISTIL_PROXY_URL and the encoded query string
  2. 2Sends a GET request with X-Distil-Key and Accept: text/markdown headers
  3. 3Receives web search results as clean Markdown
  4. 4Parses the Markdown to extract relevant sources and summaries
  5. 5Returns a synthesized answer with source links to the user
OUTPUT
A summary of current Go error handling best practices drawn from live web search results, with source links
