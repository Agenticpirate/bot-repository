What This Skill Does

Monitors OpenClaw session context windows and warns before they fill up. Configurable thresholds (75%, 85%, 90%, 95%) trigger alerts and automatic session backups. Runs in two modes: directive-only with no code installation, or with optional CLI tools for manual session management and archiving.

OpenClaw has no built-in capacity warnings, so sessions silently hit 100% and lock mid-task with no way to recover in-progress work.

When to use it

  • Getting warned before a long coding session hits context limits
  • Automatically backing up a session at 90% capacity before it locks
  • Resuming a conversation after a context reset using a saved prompt
  • Setting different warning thresholds per channel (Discord vs webchat vs DM)
  • Archiving sessions older than a week to keep the session directory clean
Example Workflow
Here's how your AI assistant might use this skill in practice.
INPUT
User asks: What's my current session capacity?
AGENT
  1. 1Runs session_status to retrieve token usage for the current session
  2. 2Calculates the percentage of the context window used
  3. 3Compares the result against configured warning thresholds
  4. 4Reports current capacity and flags any crossed thresholds with recommended actions
OUTPUT
Agent reports 87% capacity used, recommends finishing the current task before resetting, and offers to save context and generate a session resumption prompt
