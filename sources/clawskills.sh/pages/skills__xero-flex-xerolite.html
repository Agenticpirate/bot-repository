What This Skill Does

Xerolite bridges TradingView alerts to Interactive Brokers, automating trade execution without manual steps. This skill connects an OpenClaw agent to the Xerolite REST API to place orders and search contracts by symbol.

Lets an agent execute trades and look up contracts through Xerolite without switching to a broker interface or building a separate automation layer.

When to use it

  • Placing a stock buy order from a natural language command
  • Looking up contract details for a ticker before trading
  • Automating order execution triggered by a TradingView alert
  • Searching available contracts across exchanges for a given symbol
  • Integrating live trading actions into an agent workflow
Example Workflow
Here's how your AI assistant might use this skill in practice.
INPUT
User asks: Buy 10 shares of AAPL
AGENT
  1. 1Parse symbol (AAPL), action (BUY), and quantity (10) from the request
  2. 2Call contract search to verify AAPL is available on the SMART exchange
  3. 3Submit order via POST /api/internal/agent/order/place-order with the parsed parameters
  4. 4Return the API response confirming the order was placed
OUTPUT
Order for 10 shares of AAPL (BUY, USD, STOCK, SMART) submitted to Interactive Brokers via Xerolite
