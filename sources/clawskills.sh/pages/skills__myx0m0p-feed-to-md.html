What This Skill Does

Converts RSS or Atom feed URLs into Markdown using a bundled local Python script. Supports stdout output or writing to a file, with options to limit item count, control summaries, and choose between short or full templates.

Runs entirely locally via a bundled script with no external API dependencies or account requirements.

When to use it

  • Turn a blog's RSS feed into a Markdown file for offline reading
  • Pull the latest 10 items from a news feed into a project doc
  • Archive a podcast feed's episode list as Markdown
  • Convert an Atom changelog feed to readable release notes
  • Pipe a feed into a Markdown report without leaving the terminal
Example Workflow
Here's how your AI assistant might use this skill in practice.
INPUT
User asks: convert https://example.com/feed.xml to a Markdown file with the last 5 items and full summaries
AGENT
  1. 1Validate that the URL is public-facing http/https
  2. 2Construct the command array with the feed URL, --output, --limit 5, and --template full flags
  3. 3Run python3 scripts/feed_to_md.py with arguments passed as separate argv tokens
  4. 4Confirm the output .md file was written to the workspace-relative path
OUTPUT
A Markdown file containing the 5 most recent feed items with full summaries
