What This Skill Does

Manages a structured knowledge base and task list using org-mode plain-text files. The `org` CLI creates, queries, links, and searches notes and tasks, backed by a SQLite database via org-roam. Shortcut keywords like `Todo:`, `Note:`, `Know:`, and `Done:` let the agent act on natural-language input directly.

All data stays in plain-text org files the user can read, edit, and version-control without any proprietary tool.

When to use it

  • Adding a deadline-aware task from a spoken request
  • Storing a persistent fact the agent should recall in a later session
  • Marking a completed task as done by name
  • Capturing an idea or reminder into an inbox file
  • Searching linked notes to retrieve context from prior sessions
Example Workflow
Here's how your AI assistant might use this skill in practice.
INPUT
User asks: Todo: submit quarterly report by April 15
AGENT
  1. 1Parse 'by April 15' as a hard deadline
  2. 2Run `org add` on inbox.org with --todo TODO --deadline 2026-04-15 -f json
  3. 3Receive JSON confirmation with the new headline's CUSTOM_ID
  4. 4Print 'org-memory: added TODO to ~/org/human/inbox.org'
OUTPUT
Task 'Submit quarterly report' added to inbox.org with DEADLINE: 2026-04-15
