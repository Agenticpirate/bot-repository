What This Skill Does

Provides access to AIKEK's knowledge engine and image generation APIs for crypto and DeFi research. Authentication uses a locally generated Solana wallet keypair to obtain a bearer token. API usage is credit-based; new accounts start with 5 credits.

Combines real-time news, on-chain data, and sentiment scoring in a single API call instead of aggregating multiple separate data sources.

When to use it

  • Checking real-time sentiment on a token before trading
  • Researching a DeFi protocol's recent news and on-chain activity
  • Generating meme-style images for crypto social posts
  • Fact-checking a crypto claim before publishing
  • Pulling market trend summaries for a weekly newsletter
Example Workflow
Here's how your AI assistant might use this skill in practice.
INPUT
User asks: What is the current sentiment on Solana?
AGENT
  1. 1Load AIKEK_API_TOKEN from environment credentials
  2. 2Send POST to /knowledge/ask with the question and search_mode set to 'fast'
  3. 3Parse the JSON response for the answer text, sources array, and sentiment score
  4. 4Return the answer with cited source URLs and the numeric sentiment value
OUTPUT
A sentiment summary with a score (e.g. 7/10) and links to supporting sources
Requirements
Accounts, API keys, or tools you or your AI assistant may need to set up while using this skill.
AIKEK_PRIVATE_KEY environment variable (Solana keypair in hex format, generated locally via the solders Python package)AIKEK_API_TOKEN environment variable (bearer token obtained by authenticating against the AIKEK API)
