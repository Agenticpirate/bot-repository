What This Skill Does

AI startup companion built for Korean founders. Evaluates business plans (PDF or text), matches government funding programs such as TIPS and K-Startup, and profiles startups for investor outreach. Uses agentic RAG with HyDE, Multi-Query, and CRAG against a database of 3,972+ TIPS-selected startups.

Combines business plan scoring, a curated Korean government funding database, and investor profiling in one local tool that runs without mandatory external API dependencies.

When to use it

  • Scoring a business plan PDF before a government funding application
  • Finding eligible Korean government grants by industry, stage, and region
  • Generating a TIPS application draft from an existing business plan
  • Getting an investor attractiveness profile before a seed or pre-A pitch
  • Connecting a Kakao chatbot to startup advisory workflows via OpenBuilder
Example Workflow
Here's how your AI assistant might use this skill in practice.
INPUT
User asks: Evaluate my business plan PDF and find matching government funding programs
AGENT
  1. 1Extract text from the uploaded PDF using built-in processor
  2. 2Score the plan across six criteria: problem fit, market size, business model, team, financials, and tech differentiation
  3. 3Generate improvement suggestions for low-scoring areas
  4. 4Match the startup profile against the Korean government programs database
  5. 5Return ranked funding matches with eligibility notes and a checklist
OUTPUT
Scored evaluation report with per-category breakdown, concrete improvement suggestions, and a ranked list of eligible government funding programs
Requirements
Accounts, API keys, or tools you or your AI assistant may need to set up while using this skill.
At least one of: OPENROUTER_API_KEY, GEMINI_API_KEY, ANTHROPIC_API_KEY, or OPENAI_API_KEY (falls back to local Ollama if none set)KAKAO_CALLBACK_SECRET environment variable (only needed for Kakao i OpenBuilder webhook integration)
