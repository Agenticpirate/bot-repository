What This Skill Does

FIS Architecture coordinates task delegation between a main orchestrator agent (CyberMao) and specialized worker agents using JSON tickets and Discord Forum threads. Each task gets a tracked ticket and a dedicated Forum thread, with agents communicating via A2A messaging. Sub-agent spawning is supported for complex subtasks within a workflow.

Ticket-based tracking with Discord Forum threads gives each task a persistent, auditable record across sessions, so context is not lost when workflows span hours or days.

When to use it

  • Delegating a coding task from main agent to engineer agent
  • Tracking multi-step research tasks across multiple agent sessions
  • Coordinating handoffs between researcher and writer agents on a shared project
  • Spawning background sub-agents for complex subtask analysis
  • Archiving completed task tickets and deliverables after agent handoffs
Example Workflow
Here's how your AI assistant might use this skill in practice.
INPUT
User asks: Analyze GPR signal theory and produce a summary document
AGENT
  1. 1CyberMao runs fis_coordinator.py to generate a ticket and delegation template targeting the researcher agent
  2. 2CyberMao creates a Discord Forum thread for the task using the discord tool's threadCreate action
  3. 3CyberMao notifies the researcher agent via sessions_send with the ticket ID and thread ID
  4. 4Researcher updates ticket status to 'doing', executes the analysis, and posts progress in the Forum thread
  5. 5Researcher runs fis_worker_toolkit.py to generate a completion report and notifies CyberMao via sessions_send
OUTPUT
Ticket marked complete and archived, deliverables attached to the Forum thread, summary reported to user in #daily-chat
Requirements
Accounts, API keys, or tools you or your AI assistant may need to set up while using this skill.
