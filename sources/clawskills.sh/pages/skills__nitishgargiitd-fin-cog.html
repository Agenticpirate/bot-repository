What This Skill Does

Financial analysis skill covering stock research, valuation modeling, portfolio optimization, earnings breakdowns, and personal finance planning. Built on CellCog's agent team infrastructure. Outputs range from interactive HTML dashboards to Excel spreadsheets and PDF reports.

Produces institutional-quality financial models and reports from a single natural-language prompt, without Bloomberg access or spreadsheet expertise.

When to use it

  • Build a DCF model with bear/base/bull scenarios for a public stock
  • Analyze a personal portfolio's risk, diversification, and rebalancing needs
  • Generate a 24-month financial projection for a SaaS startup
  • Break down a company's quarterly earnings with segment-level performance detail
  • Create a debt payoff plan across loans with different interest rates
Example Workflow
Here's how your AI assistant might use this skill in practice.
INPUT
User asks: 'Create a comprehensive stock analysis for Palantir (PLTR) covering business model, earnings, valuation, competitive positioning, and bull/bear thesis. Deliver as an interactive HTML report.'
AGENT
  1. 1Retrieves PLTR revenue breakdown, earnings history, and key financial metrics
  2. 2Models valuation using P/E, P/S, and FCF margin relative to peers like Snowflake and Databricks
  3. 3Constructs bull and bear thesis based on government vs commercial revenue mix and growth trajectory
  4. 4Assembles findings into an interactive HTML dashboard with charts and drill-down sections
OUTPUT
Interactive HTML report with company overview, multi-quarter earnings trends, peer comparison table, and bull/bear valuation scenarios
