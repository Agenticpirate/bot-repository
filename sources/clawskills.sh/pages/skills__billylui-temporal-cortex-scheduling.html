What This Skill Does

Connects to Google Calendar, Outlook, and CalDAV to list events, find open time slots, and book meetings. Uses a Two-Phase Commit protocol to prevent conflicting writes when multiple agents attempt to book the same slot. Supports merged availability across multiple calendars and expanding recurring events into concrete dates.

The Two-Phase Commit booking protocol prevents double-bookings in concurrent scenarios where most calendar integrations would simply overwrite each other.

When to use it

  • Finding the next open 30-minute slot across a busy work week
  • Booking a meeting without double-booking when multiple agents run concurrently
  • Checking a colleague's public availability before proposing a time
  • Expanding a monthly recurring event into concrete dates for the year
  • Drafting a scheduling proposal formatted for email or Slack
Example Workflow
Here's how your AI assistant might use this skill in practice.
INPUT
User asks: Book a 30-minute meeting with jane@example.com on Tuesday at 2pm
AGENT
  1. 1Calls list_calendars to discover connected calendar IDs
  2. 2Calls check_availability on google/primary for Tuesday 2:00-2:30pm
  3. 3Presents booking details to user and waits for confirmation
  4. 4Calls book_slot with calendar_id, start, end, and summary
OUTPUT
Event 'Meeting with Jane' created on Google Calendar for Tuesday 2:00-2:30pm
