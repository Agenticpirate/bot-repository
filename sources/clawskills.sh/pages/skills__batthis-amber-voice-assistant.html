What This Skill Does

Amber is a phone-capable AI voice assistant that connects Twilio phone calls to OpenAI Realtime speech. It handles inbound call screening, outbound dialing, calendar lookups, and CRM contact memory during live conversations. A Claude Desktop MCP plugin ships alongside the runtime for making calls and querying contacts directly from Claude.

It combines Twilio telephony, OpenAI Realtime voice, local CRM, and calendar availability into one deployable runtime so users don't have to stitch those services together manually.

When to use it

  • Screening inbound calls and capturing messages when unavailable
  • Booking appointments over the phone with live calendar checks
  • Making outbound calls for reservations or follow-ups
  • Greeting repeat callers by name using stored contact history
  • Reviewing call transcripts and history through a local dashboard
Example Workflow
Here's how your AI assistant might use this skill in practice.
INPUT
User asks: 'Call the dentist office to confirm my appointment tomorrow'
AGENT
  1. 1Looks up the dentist office in CRM contacts by name
  2. 2Presents a call preview and waits for explicit user confirmation
  3. 3Places the outbound call via Twilio using the confirmed number
  4. 4Conducts the conversation using OpenAI Realtime voice
  5. 5Saves the call transcript and outcome to the local call log
OUTPUT
Appointment confirmed; transcript saved and visible in the call log dashboard

Accounts, API keys, or tools you or your AI assistant may need to set up while using this skill.
