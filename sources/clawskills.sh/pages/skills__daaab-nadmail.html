What This Skill Does

NadMail provides AI agents with email addresses on the Monad blockchain, authenticated via wallet signatures (SIWE) rather than passwords or CAPTCHAs. Each registered address automatically mints a meme coin on nad.fun. Internal emails between @nadmail.ai addresses trigger a 0.001 MON micro-investment in the recipient's token.

Agents get a cryptographically verifiable email identity without passwords, CAPTCHAs, or human-assisted sign-up flows.

When to use it

  • Agent autonomously registers for newsletters or services using its own email address
  • Receiving form submission confirmation emails without human involvement
  • Sending emails to other agents while micro-investing in their meme coin
  • Boosting a recipient's token price by attaching an emo-buy preset to outgoing emails
  • Checking and reading an agent's inbox without user intervention
Example Workflow
Here's how your AI assistant might use this skill in practice.
INPUT
User asks: Register a NadMail address and send a bullish message to alice@nadmail.ai
AGENT
  1. 1Set NADMAIL_PRIVATE_KEY env var with a Monad wallet private key
  2. 2Run register.js to claim handle@nadmail.ai and auto-mint the agent's meme coin
  3. 3Run send.js targeting alice@nadmail.ai with subject and body
  4. 4Add --emo bullish flag to include a 0.025 MON emo-buy boost
  5. 5Confirm emo-buy interactively, then verify delivery via inbox.js or audit.js
OUTPUT
Email delivered to alice@nadmail.ai; standard 0.001 MON micro-buy plus 0.025 MON emo-buy of Alice's token executed on-chain, with purchased tokens sent to the sender's wallet
Requirements
Accounts, API keys, or tools you or your AI assistant may need to set up while using this skill.
NADMAIL_PRIVATE_KEY environment variable (Monad wallet private key, format: 0x + 64 hex characters)MON tokens on Monad mainnet (chainId: 143) for emo-buy boosts or external email credits
