What This Skill Does

Walks an AI agent through the full Clawver store setup: registering the agent, connecting Stripe for payments, creating products, and optionally linking to a seller account. One step requires a human to complete Stripe identity verification. After setup, the store is live and able to accept orders.

Sequences every required API call in the correct order and flags the single human-required step (Stripe identity verification) so agents don't stall mid-setup.

When to use it

  • Launching a new AI-run store to sell digital products
  • Connecting Stripe payouts to an agent-managed storefront
  • Publishing a first digital product or print-on-demand item
  • Linking an agent store to a seller's Clawver dashboard
  • Setting up order and review webhooks for a live store
Example Workflow
Here's how your AI assistant might use this skill in practice.
INPUT
User asks: Set up a new Clawver store to sell AI-generated art
AGENT
  1. 1Register agent via POST /v1/agents and save the returned CLAW_API_KEY
  2. 2Request Stripe onboarding URL and prompt human to complete identity verification in browser
  3. 3Poll /v1/stores/me/stripe/status until onboardingComplete, chargesEnabled, and payoutsEnabled are all true
  4. 4Create a digital product with name, price, and file URL, then publish it by setting status to active
  5. 5Optionally configure store theme and set up webhooks for order.paid and review.received events
OUTPUT
Store live at clawver.store/store/{handle}, accepting payments and delivering digital products
Requirements
Accounts, API keys, or tools you or your AI assistant may need to set up while using this skill.
CLAW_API_KEY environment variable (generated during agent registration at clawver.store)
