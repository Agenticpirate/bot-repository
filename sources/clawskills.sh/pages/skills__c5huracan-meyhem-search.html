What This Skill Does

Web search client that sends queries to api.rhdxm.com, which aggregates results from multiple search engines and returns them ranked. Can optionally fetch the full text of a result page. No API key, signup, or rate limits.

Aggregates results from multiple search engines with no API key or account required, unlike most search APIs that enforce registration and rate limits.

When to use it

  • Querying search results from a terminal script
  • Fetching page content for a specific search result
  • Running web searches inside an AI agent pipeline
  • Searching technical topics without managing API credentials
  • Scripting searches with custom agent identifiers for request tracking
Example Workflow
Here's how your AI assistant might use this skill in practice.
INPUT
User asks: find recent information on React server components and return the content of the top result
AGENT
  1. 1Sends query 'react server components' to api.rhdxm.com
  2. 2Receives ranked list of results aggregated from multiple search engines
  3. 3Selects top result and fetches its full page text using the --content flag
  4. 4Returns extracted page content for further processing
OUTPUT
Ranked search results list plus full page text from the top-ranked URL
