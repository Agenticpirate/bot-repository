What This Skill Does

Repairs damaged or corrupted files by uploading them to a third-party online repair service and returning a download URL. Supports video, document, design, and archive formats up to 300MB. Files are processed remotely; the skill asks for consent before uploading.

Covers video, document, design, and archive formats in a single skill without needing separate tools for each file type.

When to use it

  • Recovering a corrupted Word or Excel file before a deadline
  • Repairing a broken MP4 or MOV video that won't play
  • Fixing a damaged ZIP archive that fails to extract
  • Restoring a corrupted PSD or AI design file
  • Repairing a PDF or EPUB that opens blank or throws errors
Example Workflow
Here's how your AI assistant might use this skill in practice.
INPUT
User asks: 'Can you repair this corrupted Excel file at /home/user/report.xlsx?'
AGENT
  1. 1Checks that .xlsx is a supported format and file size is within limits
  2. 2Asks user to confirm consent before uploading to the third-party service
  3. 3Runs the repair script with the provided file path
  4. 4Parses stdout for the first repaired URL
  5. 5Returns the download URL to the user
OUTPUT
A time-limited download URL pointing to the repaired .xlsx file
