What This Skill Does

Scans files, directories, and installed skills for malware using ClamAV and agent-specific static analysis. Monitors agent behavior for signs of compromise, including unauthorized file modifications and suspicious processes. Audits host security posture and generates structured security reports.

Combines traditional ClamAV file scanning with AI-agent-specific static analysis, covering attack vectors like malicious skills and prompt injection that generic antivirus tools don't address.

When to use it

  • Scanning a downloaded archive before opening it
  • Auditing a third-party skill before installing from ClawHub
  • Detecting whether an agent has been compromised by prompt injection
  • Running a scheduled weekly host security audit
  • Quarantining a flagged file pending manual review
Example Workflow
Here's how your AI assistant might use this skill in practice.
INPUT
User asks: Is this downloaded file safe to open?
AGENT
  1. 1Runs `bash scripts/scan_file.sh /path/to/file` to perform a ClamAV scan
  2. 2Parses JSON output for threat status and signature freshness date
  3. 3If clean, reports no threats detected along with the signature date
  4. 4If flagged, runs `bash scripts/scan_file.sh --quarantine /path/to/file` to isolate the file
  5. 5Reports the threat name and recommends next action: quarantine, delete, or investigate
OUTPUT
File quarantined. Threat detected: [threat name]. Quarantine manifest updated at /tmp/crusty_quarantine/manifest.json.
