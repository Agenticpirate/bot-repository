What This Skill Does

Generates, edits, and manages PowerPoint presentations using the Skywork AI service. Supports creating slides from a topic, imitating an existing template's style, editing slides with natural language instructions, converting NotebookLM exports into editable PPTX files, and performing local operations like deleting, reordering, extracting, or merging slides.

Handles the full lifecycle of a presentation, from generation to style imitation to natural-language editing, without leaving the terminal.

When to use it

  • Create a 10-slide deck for a quarterly business review
  • Restyle a presentation to match your company's branded template
  • Ask in plain language to change a slide's background or add a new section
  • Turn a NotebookLM PDF export into an editable PowerPoint file
  • Merge several separate PPTX files into one combined presentation
Example Workflow
Here's how your AI assistant might use this skill in practice.
INPUT
User asks: create a presentation about renewable energy trends in 2025
AGENT
  1. 1Search the web for recent renewable energy data and distill into a reference file
  2. 2Upload any user-provided reference documents and parse their content
  3. 3Run the Skywork generation script with the topic and reference material
  4. 4Poll the backend until the presentation is ready
  5. 5Download the finished PPTX to a local path
OUTPUT
A polished .pptx file saved locally with a download URL provided
