What This Skill Does

Sends voice call reminders to your phone via the DoNotify API. Calls can be placed immediately or scheduled for a future time. The spoken message uses the title and optional description you provide.

Voice calls are harder to miss than push notifications or emails, making them better for time-sensitive reminders.

When to use it

  • Call me now to leave for my flight
  • Remind me at 2pm to take medication
  • Schedule a wake-up call for tomorrow morning
  • Get a voice alert 15 minutes before a meeting
  • Remind yourself to call a client back in an hour
Example Workflow
Here's how your AI assistant might use this skill in practice.
INPUT
User asks: Remind me at 3:45pm today to start the oven for dinner
AGENT
  1. 1Check usage to confirm phone_number_set is true and remaining > 0
  2. 2Parse the user's requested time and convert to ISO 8601 for call_at
  3. 3Set title to a concise spoken phrase like 'Start the oven for dinner'
  4. 4POST to /api/reminders with title, call_at, and optional description
OUTPUT
Reminder scheduled — a voice call will be placed at 3:45pm with the spoken message
