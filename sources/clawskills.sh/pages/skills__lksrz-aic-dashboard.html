What This Skill Does

A lightweight web UI that reads local data files produced by the email-webhook and browser-auth skills and displays them in a token-protected dashboard. Shows the last 50 inbound emails and current browser session status. Refreshes automatically every 5 seconds.

Centralizes email and browser session data in one place instead of manually reading two separate JSON files.

When to use it

  • Checking inbound emails captured by an AI agent without opening raw files
  • Verifying whether a browser session is active before triggering automation
  • Monitoring agent email intake on a local network
  • Reviewing recent email subjects and senders at a glance
  • Confirming agent setup is working end-to-end during development
Example Workflow
Here's how your AI assistant might use this skill in practice.
INPUT
User asks: show me what emails have come in and whether the browser session is still active
AGENT
  1. 1Start the dashboard server with `node scripts/server.js`
  2. 2Read the printed access URL containing the auto-generated token
  3. 3Open the URL in a browser
  4. 4View the last 50 emails from inbox.jsonl in the emails panel
  5. 5Check the session status panel populated from session.json
OUTPUT
A web page showing recent inbound emails and a green/red browser session indicator, auto-refreshing every 5 seconds
Requirements
Accounts, API keys, or tools you or your AI assistant may need to set up while using this skill.
