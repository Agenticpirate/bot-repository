What This Skill Does

Kiln connects AI agents to 3D printers through 273 MCP tools and 107 CLI commands, covering the full pipeline from text or sketch to 3D model, slicing, uploading, printing, and monitoring. It supports single printers and multi-printer fleets, with configurable autonomy tiers and hardware safety enforcement. Outsourced manufacturing via Craftcloud and Sculpteo is available when local printers are unavailable or busy.

Unlike scripting OctoPrint or Moonraker APIs directly, Kiln provides a unified interface across printer firmware types with built-in safety enforcement, autonomy tiers, and text-to-3D generation in one tool.

When to use it

  • Generate a 3D model from a text description and print it automatically
  • Run an overnight print with automatic first-layer monitoring and failure detection
  • Get a manufacturing quote and order a part when the local printer is busy
  • Search Thingiverse or MyMiniFactory for an existing model before generating one from scratch
  • Route print jobs across a fleet of printers using a shared queue
Example Workflow
Here's how your AI assistant might use this skill in practice.
INPUT
User asks: Print phone_stand.gcode overnight while I sleep
AGENT
  1. 1Runs kiln analyze-file phone_stand.gcode --json to get material, estimated time, and temperatures from G-code metadata
  2. 2Runs kiln autonomy show --json to confirm Level 1 constraints pass: PLA is in the allowed list, print time is 2h 10m (under 4h limit), temps are within bounds
  3. 3Calls start_monitored_print with phone_stand.gcode, which starts the print and captures first-layer snapshots after 2 minutes
  4. 4Reviews snapshot analysis fields (brightness, variance, heuristic_pass) and confirms the first layer is clean
  5. 5Polls kiln status --json every 10 minutes for temperature anomalies and progress stalls; on completion runs kiln temp --tool 0 --bed 0 --json to cool down heaters
OUTPUT
Print completed in 2h 14m with no anomalies detected. Heaters cooled. Result reported to user.

Accounts, API keys, or tools you or your AI assistant may need to set up while using this skill.
