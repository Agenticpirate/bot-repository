What This Skill Does

Generates Excel files, CSV exports, charts, pivot tables, and data analysis reports through the Skywork Excel backend. Handles format conversions like PDF-to-Excel and image-to-table, and can fetch live web data for things like stock prices or exchange rates.

Offloads complex spreadsheet creation and data analysis to a remote agent that handles charting, formula generation, and format conversion without manual Excel work.

When to use it

  • Build a monthly budget spreadsheet with formulas and charts
  • Convert a PDF invoice into an editable Excel file
  • Pull current stock prices into a comparison table
  • Create a sales dashboard with pivot tables from raw CSV data
  • Extract tabular data from a screenshot into a spreadsheet
Example Workflow
Here's how your AI assistant might use this skill in practice.
INPUT
User asks: Create a quarterly revenue report from sales.csv with a bar chart and summary pivot table
AGENT
  1. 1Passes the user query and sales.csv file path to the Skywork backend
  2. 2Backend reads and analyzes the CSV data
  3. 3Generates pivot table summarizing revenue by quarter
  4. 4Creates a bar chart visualizing quarterly trends
  5. 5Saves the finished Excel file and uploads it to cloud storage
OUTPUT
Excel file with pivot table and bar chart, available as a cloud download link and a local file path
