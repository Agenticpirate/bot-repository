What This Skill Does

Manages n8n workflows and automations through the n8n REST API. Covers listing, creating, activating, and deactivating workflows, plus execution monitoring, dry-run testing, structure validation, and performance analysis.

Combines workflow management, structured validation, dry-run testing, and performance scoring in one skill, so you can go from creation to production without switching tools.

When to use it

  • Debugging a workflow that started failing overnight
  • Activating a new automation after validating its structure
  • Checking execution success rates across critical workflows
  • Triggering a workflow manually with custom test data
  • Getting performance scores and optimization suggestions for slow automations
Example Workflow
Here's how your AI assistant might use this skill in practice.
INPUT
User asks: 'My email workflow is failing, can you debug it?'
AGENT
  1. 1Lists recent executions for the workflow to identify failed runs
  2. 2Fetches execution details to read error messages and failing nodes
  3. 3Runs structure validation to check for missing fields or broken connections
  4. 4Generates a test report with dry-run using sample data
  5. 5Returns a summary of errors, warnings, and suggested fixes
OUTPUT
A report listing the broken node, the error cause, and steps to fix the workflow before reactivating
