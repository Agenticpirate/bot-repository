What This Skill Does

Deprecated combined installer that set up HTTPS/WSS proxy and voice mic UI for OpenClaw WebChat in a single step. Replaced by webchat-https-proxy and webchat-voice-gui. Use webchat-voice-full-stack for equivalent one-step deployment.

When to use it

  • Adding push-to-talk voice input to OpenClaw WebChat
  • Running local speech-to-text without sending audio to external services
  • Accessing WebChat over HTTPS from a LAN device
  • Keeping voice transcription proxy running after reboots via systemd
  • Switching mic recording between push-to-talk and toggle mode
Example Workflow
Here's how your AI assistant might use this skill in practice.
INPUT
User asks: set up voice input for my OpenClaw WebChat on localhost
AGENT
  1. 1Verify faster-whisper transcription service is active on port 18790
  2. 2Run deploy.sh to inject voice-input.js into Control UI and configure gateway allowed origins
  3. 3Create and enable openclaw-voice-https.service systemd unit for persistent HTTPS proxy on port 8443
  4. 4Install gateway startup hook to re-inject voice script after Control UI updates
  5. 5Run status.sh to confirm both services are active and HTTPS returns 200
OUTPUT
Voice-enabled WebChat at https://127.0.0.1:8443 with mic button, push-to-talk keyboard shortcuts, and real-time VU meter
