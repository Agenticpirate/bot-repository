What This Skill Does

Fetches posts and discussion comments from Telegram channels using the MTProto protocol. Works with public channels and any private channel the user is subscribed to. Supports time-windowed fetches, unread-state tracking, and comment retrieval.

Reads private channels and fetches discussion comments via MTProto, which the Telegram Bot API does not support.

When to use it

  • Getting a daily digest from a news or crypto channel
  • Monitoring competitor announcements across several channels
  • Pulling reader comments on recent posts in a linked discussion group
  • Summarizing a week of posts from a private research channel
  • Checking for new posts since your last visit without re-reading old ones
Example Workflow
Here's how your AI assistant might use this skill in practice.
INPUT
User asks: What's new in @cryptonews in the last 24 hours?
AGENT
  1. 1Runs tg-reader-check to confirm credentials and session file are valid
  2. 2Fetches posts from @cryptonews with --since 24h
  3. 3Parses the returned JSON and filters posts with text content
  4. 4Summarizes key topics and highlights top posts by view count
OUTPUT
A summary of recent posts covering major topics, with the most-viewed post identified and key links noted
