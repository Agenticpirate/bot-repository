What This Skill Does

Controls a visible browser using playwright-cli to search and play YouTube music. Handles song requests, artist mixes, genre-based playlists, ad skipping, and playback controls. Manages persistent browser sessions so login state survives restarts.

Uses a persistent, visible browser session so YouTube's full library is accessible without a separate music app, API key, or subscription.

When to use it

  • Playing a specific song by name and artist
  • Queuing an artist's songs as a continuous mix
  • Playing mood or genre-based background music while working
  • Skipping ads and controlling playback without touching the browser
  • Resuming a music session after the browser was previously closed
Example Workflow
Here's how your AI assistant might use this skill in practice.
INPUT
User asks: play Money Money Money by ABBA
AGENT
  1. 1Opens or resumes the named music_player browser session
  2. 2Navigates to YouTube and clears any existing search state
  3. 3Fills the search bar with 'ABBA Money Money Money' and submits
  4. 4Selects the best matching result from the search results
  5. 5Handles any ads, then confirms playback is active
OUTPUT
YouTube plays 'Money Money Money' by ABBA in the visible browser
