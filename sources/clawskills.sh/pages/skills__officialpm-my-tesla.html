What This Skill Does

Connects to the Tesla Owner API via teslapy to control and monitor Tesla vehicles from macOS. Supports checking vehicle state, running remote commands, and tracking mileage locally. Auth tokens are cached on disk; disruptive actions require explicit confirmation.

Exposes the full Tesla Owner API through a single CLI script with safety gates, so you can query or act on your car without opening the Tesla app or writing custom API code.

When to use it

  • Check battery level and range before a morning commute
  • Turn on climate control remotely before getting in the car
  • Lock the car after forgetting at a parking lot
  • Set a charge limit before plugging in overnight
  • Track odometer readings over time with local SQLite export
Example Workflow
Here's how your AI assistant might use this skill in practice.
INPUT
User asks: what's my car's current status?
AGENT
  1. 1Run `tesla.py summary` to fetch a one-line chat-friendly status
  2. 2Parse battery level, charge state, and climate info from output
  3. 3Return a compact summary to the user
