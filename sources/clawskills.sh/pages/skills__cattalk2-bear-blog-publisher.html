What This Skill Does

Publishes blog posts to Bear Blog (bearblog.dev). Supports user-provided markdown, AI-generated content via OpenAI or Kimi, and auto-generated architecture diagrams using Playwright.

Combines content generation, diagram creation, and publishing into a single step without switching tools or logging into Bear Blog manually.

When to use it

  • Publishing a write-up directly from a chat prompt
  • Generating and posting a blog on a given topic with one command
  • Attaching an auto-generated architecture diagram to a technical post
  • Publishing from a CI/CD pipeline using environment variable credentials
  • Running a multi-user publishing bot where each user supplies their own credentials
Example Workflow
Here's how your AI assistant might use this skill in practice.
INPUT
User asks: Write and publish a blog post about Python asyncio
AGENT
  1. 1Reads Bear Blog credentials from environment variables or config file
  2. 2Calls OpenAI API to generate content on the Python asyncio topic
  3. 3Authenticates to Bear Blog using CSRF token session flow
  4. 4Publishes the generated post to Bear Blog
  5. 5Returns the live URL of the published post
OUTPUT
A live Bear Blog URL pointing to the published Python asyncio post
