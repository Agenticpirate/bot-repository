What This Skill Does

Calls the SocialEcho social media management API from the command line. Supports querying teams, accounts, articles, and reports, uploading media, and publishing posts across platforms using a team API key.

Manages multi-platform social media publishing and analytics from the terminal without opening the SocialEcho web dashboard.

When to use it

  • Pull daily or weekly engagement reports for connected social accounts
  • Publish a new article to multiple social platforms at once
  • List available Reddit communities for a specific account
  • Upload images or videos before attaching them to a post
  • Check connected account details and pagination across teams
Example Workflow
Here's how your AI assistant might use this skill in practice.
INPUT
User asks: publish a product announcement with an image to my connected social accounts
AGENT
  1. 1Authenticates with the SocialEcho API using the team API key
  2. 2Queries connected accounts to identify target platforms
  3. 3Requests a presigned upload URL for the image file
  4. 4Prepares the publish payload JSON with copy and media reference
  5. 5Publishes the article via the publish-article endpoint
OUTPUT
Product announcement posted to all selected social media accounts with the attached image
