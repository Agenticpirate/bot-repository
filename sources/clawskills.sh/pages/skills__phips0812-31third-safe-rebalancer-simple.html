What This Skill Does

Rebalances a Gnosis Safe's token portfolio to on-chain allocation targets defined via 31Third policies. It reads AssetUniverse and StaticAllocation policy state from the deployed ExecutorModule, calculates required trades, and executes them using an executor wallet. Skips execution when portfolio drift is below the configured threshold.

Reads allocation targets and slippage limits directly from on-chain policies, so no manual configuration is needed at execution time.

When to use it

  • Rebalancing a Safe wallet to a target token allocation
  • Running automated drift corrections on a scheduled basis
  • Verifying 31Third policy contracts after Safe deployment
  • Executing portfolio trades without manual trade configuration
  • Troubleshooting failed rebalancing with deployment verification
Example Workflow
Here's how your AI assistant might use this skill in practice.
INPUT
User asks: Rebalance my Safe now
AGENT
  1. 1Reads AssetUniverse and StaticAllocation policy state from ExecutorModule on-chain
  2. 2Fetches current Safe token balances for all AssetUniverse tokens
  3. 3Calculates required trades using the 31Third SDK
  4. 4Executes rebalancing via the executor wallet signer
  5. 5Waits for confirmation and returns the transaction hash
OUTPUT
Transaction hash confirming the rebalancing execution
