What This Skill Does

Extracts structured content from PDFs and images via a PaddleOCR API endpoint. Handles text, tables, formulas, charts, and multi-column layouts in a single call. The agent runs a Python script against the API and presents results based on what the user asks for.

Unlike basic OCR tools, it preserves full document structure including tables, formulas, reading order, and layout across complex multi-column and mixed-content documents.

When to use it

  • Pulling all tables from an invoice PDF
  • Extracting LaTeX formulas from a research paper
  • Parsing multi-column magazine or newspaper layouts
  • Getting structured data out of scanned financial reports
  • Reading figures and charts from technical documents
Example Workflow
Here's how your AI assistant might use this skill in practice.
INPUT
User asks: Extract all the tables from this financial report PDF
AGENT
  1. 1Runs python scripts/vl_caller.py --file-path "financial_report.pdf" --pretty
  2. 2Reads the saved JSON result from the temp directory path printed to stderr
  3. 3Locates table data in result[n].prunedResult and result[n].markdown fields
  4. 4Displays all tables in full without truncating or summarizing
OUTPUT
All tables from the document rendered in structured markdown, with the full raw JSON saved to a temp file for reference
