What This Skill Does

Connects directly to Google Ads, Meta Ads, LinkedIn Ads, and TikTok Ads APIs to read and write ad account data. Over 100 tools cover campaign creation, live performance analysis, keyword research, bid management, and budget optimization across all four platforms. All write operations require explicit user confirmation, and every campaign is created in paused status.

Reads live platform data and takes real write actions via API, eliminating manual dashboard navigation and CSV exports for routine campaign management.

When to use it

  • Pull cross-platform ad performance without opening each platform's dashboard
  • Research keywords with real Google Ads CPC and search volume data before launching a campaign
  • Find wasted spend by flagging underperforming keywords and ad groups draining a Google Ads account
  • Pause a Meta campaign that is missing its CPA target directly from a chat interface
  • Schedule recurring weekly performance briefs across all connected ad accounts
Example Workflow
Here's how your AI assistant might use this skill in practice.
INPUT
User asks: Check my Google Ads and Meta Ads performance for the last 30 days and show me where budget is being wasted
AGENT
  1. 1Call get_campaign_performance with lookback_days=30 for Google Ads
  2. 2Call get_meta_campaign_performance with lookback_days=30 for Meta Ads
  3. 3Call analyze_wasted_spend to identify underperforming Google Ads keywords and ad groups
  4. 4Call analyze_meta_ad_performance to surface low-performing Meta creatives
  5. 5Present a unified table with spend, ROAS, and CPA per platform alongside specific waste findings
OUTPUT
Cross-platform performance summary with spend, ROAS, and CPA per platform, plus a list of specific keywords and creatives burning budget with recommended next actions
