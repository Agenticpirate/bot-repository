What This Skill Does

Streams coding agent sessions to a Discord channel in real-time via webhook. Parses Claude Code's stream-json output into formatted Discord messages showing tool calls, file writes, bash commands, and results. No AI tokens are consumed during streaming.

Parses structured agent output into readable Discord messages without consuming AI tokens, making agent sessions observable at zero additional API cost.

When to use it

  • Monitoring a background Claude Code session from Discord
  • Sharing live agent progress with a remote team
  • Running PR reviews with agent reasoning visible in a Discord channel
  • Streaming parallel coding tasks to a single Discord channel
  • Reviewing completed session logs after an agent run ends
Example Workflow
Here's how your AI assistant might use this skill in practice.
INPUT
User asks: Stream a Claude Code session fixing a bug in ~/projects/myapp to our #dev Discord channel
AGENT
  1. 1Launch dev-relay.sh in a background exec session targeting the working directory and task
  2. 2Note the session ID and PID from the exec response
  3. 3Write a breadcrumb file to /tmp so the heartbeat handler knows where to post results on completion
  4. 4Monitor session status with process poll using the session ID
  5. 5When the process exits, OpenClaw fires notifyOnExit and posts the result summary to the invoking channel
OUTPUT
Live tool calls, file writes, and bash commands appear as formatted Discord messages throughout the session; a completion summary is posted to the invoking channel when the agent finishes
