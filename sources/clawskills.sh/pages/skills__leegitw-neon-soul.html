What This Skill Does

Reads AI agent memory files, identifies recurring patterns, and generates a SOUL.md identity document with full provenance tracking. Patterns appearing 3 or more times are promoted to axioms. Synthesis runs locally via Ollama with no questionnaires or manual input.

Identity emerges from real conversation patterns rather than manual templates or questionnaires, so the resulting soul document reflects actual behavior rather than stated intent.

When to use it

  • Generating an identity document from months of agent conversation memory
  • Scheduling hourly soul synthesis to keep SOUL.md current automatically
  • Auditing which source conversations produced a specific axiom
  • Rolling back SOUL.md to a previous version after an unwanted synthesis
  • Previewing what identity changes would emerge before committing them
Example Workflow
Here's how your AI assistant might use this skill in practice.
INPUT
User asks: synthesize my soul from memory files
AGENT
  1. 1Check that Ollama is running at http://localhost:11434
  2. 2Run `exec node {baseDir}/scripts/neon-soul.mjs synthesize`
  3. 3Parse the JSON output for axiom count, signal count, and new patterns
  4. 4Present a brief conversational summary highlighting any newly promoted axioms
OUTPUT
SOUL.md updated with current axioms and signals; agent reports '3 new signals crystallized into axioms' with key counts
