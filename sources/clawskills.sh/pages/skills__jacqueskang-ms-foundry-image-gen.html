What This Skill Does

Generates images through an Azure Foundry (Cognitive Services / OpenAI) deployment and returns the result as raw PNG/JPEG bytes or a URL. Requires a configured Foundry endpoint, API key, and deployment name.

Wraps Azure Foundry's image generation REST API into a single, environment-variable-driven skill, avoiding manual curl construction in each workflow.

When to use it

  • Generate product mockup images from text prompts
  • Create visual assets for automated content pipelines
  • Batch-produce illustrations for internal tools
  • Test Azure AI image model deployments via CLI
  • Integrate image generation into OpenClaw agent workflows
Example Workflow
Here's how your AI assistant might use this skill in practice.
INPUT
User asks: generate a 1024x1024 PNG of a red fox
AGENT
  1. 1Validates FOUNDRY_ENDPOINT format to reject malformed URIs
  2. 2Constructs the deployment URL from FOUNDRY_ENDPOINT, FOUNDRY_DEPLOYMENT, and FOUNDRY_API_VERSION
  3. 3Sends a POST request with the prompt payload using curl and the FOUNDRY_API_KEY header
  4. 4Decodes the base64 image from the JSON response and writes it to /tmp/generated_image.png
OUTPUT
PNG file saved at /tmp/generated_image.png
