What This Skill Does

Converts forwarded or selected chat messages into QuotLy-style image stickers. It calls the QuotLy API, writes the result to a local file, and emits a MEDIA path for automatic delivery. Duplicate requests within a configurable time window are suppressed.

Handles deduplication, SSRF protection, and media delivery in one step, so the agent does not need separate logic for each concern.

When to use it

  • Creating shareable quote cards from notable group messages
  • Auto-replying with a visual sticker when a message is forwarded
  • Archiving memorable chat moments as WebP images
  • Rendering formatted text with bold, italic, or spoiler styling in sticker form
  • Generating stickers from messages with hidden sender info
Example Workflow
Here's how your AI assistant might use this skill in practice.
INPUT
User asks: make a quote sticker from this forwarded message
AGENT
  1. 1Collects the forwarded message into a selected_messages array with sender name and optional avatar URL
  2. 2Adds context.event fields including channel and update_id for deduplication
  3. 3Writes the payload to a temporary JSON file
  4. 4Runs python3 scripts/openclaw_quote_autoreply.py --input <json-file>
  5. 5Reads the MEDIA: path from stdout and uses it for delivery
OUTPUT
A WebP sticker file auto-sent to the chat with no additional text from the assistant
