What This Skill Does

Five offline datetime tools covering timezone conversion, natural language time resolution, duration computation, and DST-aware timestamp adjustment. Runs as a compiled Rust binary installed once via npm; all subsequent executions are fully offline. No API keys, OAuth, or credentials required.

All computation runs locally with zero network access at runtime, so it works reliably in air-gapped environments and never fails due to external API downtime or rate limits.

When to use it

  • Finding what time a 2pm New York meeting is in Tokyo
  • Resolving 'next Tuesday at 2pm' to an exact RFC 3339 timestamp
  • Calculating hours remaining before a deployment or contract deadline
  • Adjusting recurring task times correctly across spring-forward and fall-back DST transitions
  • Checking whether a city is currently observing daylight saving time
Example Workflow
Here's how your AI assistant might use this skill in practice.
INPUT
User asks: What time is 2pm New York on March 15 in Tokyo?
AGENT
  1. 1Call get_temporal_context to confirm the user's current timezone and DST status
  2. 2Call resolve_datetime with expression '2026-03-15 at 2pm' to produce an RFC 3339 timestamp in New York time
  3. 3Call convert_timezone with the resolved timestamp and target_timezone set to 'Asia/Tokyo'
  4. 4Return the converted time with the Tokyo UTC offset included
OUTPUT
2026-03-16T03:00:00+09:00 — March 16 at 3:00 AM JST
