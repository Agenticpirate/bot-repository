What This Skill Does

CLI wrapper around the AdsPower Local API for managing anti-detect browser profiles, groups, proxies, tags, and kernels. Supports opening, closing, creating, updating, and deleting browser environments, plus fingerprint regeneration and cache management. Requires the AdsPower desktop application to be running locally.

Provides a scriptable CLI for AdsPower's Local API, enabling batch operations and AI-agent-driven profile management without the desktop GUI.

When to use it

  • Opening a specific browser profile before starting a work session
  • Bulk creating profiles with different proxy and fingerprint configurations
  • Organizing browser profiles into named groups and color-coded tags
  • Refreshing fingerprints across multiple profiles before use
  • Listing and deleting proxies no longer in rotation
Example Workflow
Here's how your AI assistant might use this skill in practice.
INPUT
User asks: create a new browser profile in group 1 with no proxy, then open it
AGENT
  1. 1Run ads create-browser with group_id 0 and proxy_soft set to no_proxy
  2. 2Capture the returned profile_id from the creation response
  3. 3Run ads open-browser with the new profile_id
  4. 4Return the debug port and WebSocket endpoint to the user
OUTPUT
New browser profile created and launched with connection details returned
