What This Skill Does

Queries Aubrai's research engine to answer questions about longevity, aging, and lifespan extension. Returns AI-generated summaries with cited sources from the scientific literature. No API key required.

Aubrai's engine retrieves and cites primary sources, so you get referenced research rather than unsourced summaries from a general-purpose model.

When to use it

  • Looking up current research on caloric restriction and lifespan
  • Asking about the mechanisms behind senolytics
  • Comparing evidence on NAD+ supplementation
  • Researching telomere biology for a health article
  • Following up on a specific aging pathway after an initial query
Example Workflow
Here's how your AI assistant might use this skill in practice.
INPUT
User asks: What does the research say about rapamycin and aging?
AGENT
  1. 1Submit the question to https://apis.aubr.ai/api/chat via POST and save the returned requestId and conversationId
  2. 2Poll /api/chat/status/{requestId} every 5 seconds until status is completed
  3. 3Extract result.text from the completed response
  4. 4Parse all citation URLs from inline markdown links and bare https:// URLs in the text
  5. 5Return the summary to the user with a Sources section listing the citations, and note that responses are not medical advice
OUTPUT
A research summary on rapamycin's effects on aging pathways with a list of cited sources
