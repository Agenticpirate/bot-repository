What This Skill Does

Gives agents access to Twitter/X.com data through the Vincent proxy service. Agents can search tweets, look up user profiles, and retrieve recent posts without managing Twitter API credentials. Vincent authenticates with Twitter server-side and deducts a small credit balance per call.

Agents skip Twitter developer account approval and OAuth setup entirely, since Vincent handles upstream API authentication and enforces rate limits server-side.

When to use it

  • Search recent tweets about a stock or cryptocurrency
  • Look up a public figure's follower count and verified status
  • Pull a user's recent posts for sentiment analysis
  • Monitor brand mentions on Twitter over the past 7 days
  • Fetch engagement metrics for a specific tweet by ID
Example Workflow
Here's how your AI assistant might use this skill in practice.
INPUT
User asks: Find the 10 most recent tweets about climate change
AGENT
  1. 1Check for an existing DATA_SOURCES key using `secret list --type DATA_SOURCES`
  2. 2Create a new secret if none exists and share the returned claim URL with the user
  3. 3Wait for the user to claim the key and add credit at heyvincent.ai
  4. 4Run `twitter search --key-id <KEY_ID> --q 'climate change' --max-results 10`
  5. 5Parse results for tweet text and public metrics, then report remaining credit from `_vincent.creditRemainingUsd`
OUTPUT
A list of 10 recent tweets with text, timestamps, author IDs, and like/retweet/reply counts
