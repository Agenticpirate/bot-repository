What This Skill Does

Performs iCloud Calendar CRUD operations from OpenClaw agents via CalDAV or macOS native Calendar.app bridge. Supports listing calendars, fetching events, creating, updating, and deleting events, including targeted updates to recurring event series. Credentials are managed through keyring, environment variables, or a config file.

Supports both direct CalDAV and macOS-native Calendar.app bridge with automatic fallback, so agents work reliably on macOS without requiring external calendar APIs or OAuth flows.

When to use it

  • Add a meeting to iCloud Calendar from an agent workflow
  • Fetch upcoming events for the next 7 days to brief the user
  • Update a single instance of a recurring weekly standup
  • Delete a cancelled appointment by event UID
  • Set up iCloud credentials securely for headless automation
Example Workflow
Here's how your AI assistant might use this skill in practice.
INPUT
User asks: 'Schedule a dentist appointment on March 20 at 10am in my Personal calendar'
AGENT
  1. 1Verify credentials are configured via keyring or environment variables
  2. 2Run list to confirm the 'Personal' calendar exists
  3. 3Construct JSON payload with summary, dtstart, and dtend in ISO format
  4. 4Run create with --calendar 'Personal' and the JSON payload
OUTPUT
Event 'Dentist Appointment' created in iCloud Personal calendar for 2026-03-20T10:00:00
