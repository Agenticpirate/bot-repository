What This Skill Does

Converts PDFs, text, and URLs into two-host audio podcast episodes via the MagicPodcast API. Handles the full workflow from source input and language selection to job submission and status tracking. Returns a shareable podcast link when generation completes.

Skips manual audio recording and editing by generating natural dialogue audio directly from source documents in minutes.

When to use it

  • Turn a research paper PDF into a listenable podcast
  • Convert meeting notes into an audio summary
  • Generate a podcast episode from a blog post URL
  • Create multilingual podcast content from pasted text
  • Share auto-generated podcast episodes via link
Example Workflow
Here's how your AI assistant might use this skill in practice.
INPUT
User asks: Can you make a podcast from this PDF? https://example.com/report.pdf in English
AGENT
  1. 1Confirms topic and language with the user
  2. 2Validates the PDF URL format
  3. 3Builds JSON payload with pdfUrl and language fields
  4. 4POSTs to /agent/v1/podcasts/pdf with API key header
  5. 5Returns magicpodcast.app/app dashboard link immediately
  6. 6Checks /agent/v1/jobs/{id} when user requests status update
OUTPUT
Here is your podcast link: https://www.magicpodcast.app/share/abc123
