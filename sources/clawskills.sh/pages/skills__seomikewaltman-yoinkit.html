What This Skill Does

Yoinkit connects to 13 social platforms to search content, pull video transcripts, fetch post metadata, and run automated multi-platform research workflows. Supported platforms include YouTube, TikTok, Instagram, Reddit, Twitter/X, LinkedIn, Facebook, Pinterest, Threads, Bluesky, Truth Social, Twitch, and Kick.

Covers 13 platforms through a single API token instead of managing separate integrations for each.

When to use it

  • Pulling transcripts from YouTube or TikTok videos for note-taking
  • Checking what's currently trending on TikTok in a specific country
  • Researching a topic across YouTube, TikTok, and Reddit in one command
  • Monitoring a creator's recent posts across multiple platforms
  • Finding top Reddit discussions on a topic sorted by comment count or recency
Example Workflow
Here's how your AI assistant might use this skill in practice.
INPUT
User asks: Research what creators are doing with AI tools across YouTube, TikTok, and Reddit
AGENT
  1. 1Runs `yoinkit research "AI tools" --platforms youtube,tiktok,reddit`
  2. 2Searches each platform for the topic query
  3. 3Fetches trending content from YouTube and TikTok
  4. 4Combines all results into JSON organized by platform
OUTPUT
Top videos, posts, and trending content about AI tools listed by platform with titles, engagement stats, dates, and links
