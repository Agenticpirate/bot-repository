What This Skill Does

Connects an agent to kenoodl's synthesis service, giving it access to structured data from outside its training. Set up once with a KENOODL_TOKEN. Requests are encrypted in transit, stateless, and nothing is stored or used for training.

Agents retrieve structured knowledge from outside their training without any user data being persisted or used for model training.

When to use it

  • Getting current information an agent's training data doesn't cover
  • Breaking through a reasoning block on a hard problem
  • Enriching agent responses with structured external knowledge
  • Accessing synthesized data on topics beyond the model's cutoff
  • Augmenting an agent's output with real-world context
Requirements
Accounts, API keys, or tools you or your AI assistant may need to set up while using this skill.
KENOODL_TOKEN environment variable — obtain from kenoodl.com
