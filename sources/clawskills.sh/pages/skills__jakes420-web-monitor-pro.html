What This Skill Does

Monitors web pages for content changes, price drops, and stock availability. Stores data locally, generates visual diffs, and fires webhooks when conditions are met. Handles JS-rendered pages via Playwright and Cloudflare-protected sites via cloudscraper.

Requires no API keys and runs entirely local, unlike cloud-based change detection services that charge per monitor or store your data remotely.

When to use it

  • Tracking a product price until it drops below a target
  • Getting alerted when an out-of-stock item comes back
  • Watching a news or blog page for new content
  • Comparing prices for the same product across multiple stores
  • Setting up a weekly summary of all monitored pages
Example Workflow
Here's how your AI assistant might use this skill in practice.
INPUT
User asks: watch this Amazon product and alert me when the price drops below $300
AGENT
  1. 1Run quickstart to check available engines and confirm Playwright is installed for JS rendering
  2. 2Run watch with the Amazon URL and --browser flag to enable JS rendering
  3. 3Set --condition 'price below 300' and --target 300
  4. 4Optionally add --webhook with a Slack or Discord URL for real-time alerts
  5. 5Run check to confirm the monitor is active and baseline price is captured
OUTPUT
Monitor created with ID 1, current price $389 recorded, alert will fire when price drops below $300
