What This Skill Does

Searches for events and meetups matching your interests across Eventbrite, Meetup.com, and Luma. Tracks events you want to attend and sends reminders 24 hours and 2 hours before each one. All data is stored locally on your machine.

Pulls from multiple event platforms in one pass and stores everything locally, so you don't need accounts or open browser tabs on each site.

When to use it

  • Finding Python meetups in your city this week
  • Getting a reminder the morning before a workshop you registered for
  • Switching event topics after moving to a new city
  • Tracking a conference and a local networking event at the same time
  • Pausing daily searches while traveling
Example Workflow
Here's how your AI assistant might use this skill in practice.
INPUT
User asks: search for AI meetups in San Francisco this month
AGENT
  1. 1Loads user preferences from user-preferences.json
  2. 2Constructs search queries like 'AI meetup San Francisco March 2026'
  3. 3Scrapes event pages from Eventbrite, Meetup.com, and Luma results
  4. 4Filters out duplicates and past events, saves new entries to events.json
  5. 5Presents a formatted list of new events and asks which ones interest the user
OUTPUT
A list of upcoming AI meetups with dates, locations, descriptions, and registration links
