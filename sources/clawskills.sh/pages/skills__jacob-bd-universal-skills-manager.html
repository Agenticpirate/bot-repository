What This Skill Does

A centralized skill manager that discovers, installs, and synchronizes AI skills across Claude Code, Gemini CLI, OpenCode, Cursor, Cline, and other AI tools. It searches three sources: SkillsMP (curated, requires API key), SkillHub (community, no key), and ClawHub (versioned with semantic search, no key). Supports global user-level and project-level local installation scopes.

Rather than manually copying skill directories into each AI tool's config folder, this skill handles multi-tool discovery, installation, and sync in a single operation.

When to use it

  • Installing a debugging skill from SkillHub into Claude Code and Cursor simultaneously
  • Generating a matrix report showing which skills are installed across all detected AI tools
  • Searching ClawHub with natural language to find relevant skills without an API key
  • Packaging a local skill as a ZIP file for upload to claude.ai or ChatGPT
  • Syncing a modified skill from Claude Code out to Gemini CLI and OpenCode
Example Workflow
Here's how your AI assistant might use this skill in practice.
INPUT
User asks: Find a code review skill and install it globally in Claude Code and Cursor
AGENT
  1. 1Checks for SKILLSMP_API_KEY; none found, presents SkillHub and ClawHub as alternatives
  2. 2Searches SkillHub with query 'code review' and displays top results in a table
  3. 3User selects a result; agent fetches full skill details to get skillPath and branch
  4. 4Runs install_skill.py to download and install the skill to ~/.claude/skills/
  5. 5Detects Cursor is installed, confirms sync with user, then installs to ~/.cursor/skills/
OUTPUT
Skill installed at ~/.claude/skills/code-review/ and ~/.cursor/skills/code-review/ with confirmation of name, author, and paths
Requirements
Accounts, API keys, or tools you or your AI assistant may need to set up while using this skill.
SKILLSMP_API_KEY environment variable (optional, only needed for SkillsMP curated search)
