# Content Types

## Content Types for Creating (original LinkedIn posts)

### Type 1: Principles Posts
Short, punchy posts sharing one engineering or AI adoption principle from experience.

### Type 2: Build-in-Public Posts
Document what you are actually building. Show terminal, repo, process.

### Type 3: Teaching Frameworks
Take one concept and turn it into a structured breakdown.

### Type 4: Community Stories
Document meetups, milestones, community interactions.

### Type 5: Contrarian Takes
Challenge popular narratives with practitioner lens. Grounded, not inflammatory.

---

## Content Types for Engaging (posts by others)

### Type 1: AI Adoption in Engineering Teams
Posts about AI adoption journeys — challenges, wins, failures, tooling decisions.

### Type 2: Platform Engineering / Cloud / K8s
Posts about infrastructure challenges, deployment, CI/CD, platform engineering.

### Type 3: AI Hype vs Reality Debates
Hot takes, comparisons, what works vs what doesn't.

### Type 4: Engineering Leadership
Team structure, DevOps culture, scaling engineering orgs.

### Type 5: Developer Tools / Claude Ecosystem
Claude Code workflows, MCP setups, AI agent patterns.
