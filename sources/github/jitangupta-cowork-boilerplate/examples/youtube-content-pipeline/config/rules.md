# Rules — YouTube Content Pipeline

## Script Writing Rules
1. Hook must create tension or curiosity within first 15 seconds
2. Every demo section must have a clear "look for this" moment
3. Use Hinglish naturally — switch to Hindi for emphasis; English for technical terms
4. No fluff. If a sentence doesn't teach something or build connection, cut it
5. Mark estimated timestamps at each section header
6. Mark talking head vs screen clearly: `[TALKING HEAD]` / `[SCREEN: show X]`

## Title Rules
1. Under 60 characters (YouTube truncates after this)
2. Must work without the thumbnail
3. No clickbait that the video doesn't deliver on
4. Specificity signals value — name the exact thing the viewer will learn
5. Hinglish command verbs hit harder than English question hooks

## Title Patterns (from channel data)
- "Bold claim + specific topic" beats "hook + format label"
- Direct imperative Hinglish carries conviction
- Name the exact thing — avoid vague superlatives

## Thumbnail Rules
1. One clear focal point — either face OR diagram, not both
2. Text overlay: max 5 words, readable at 120x90px (mobile)
3. Expression must match video emotion
4. Avoid cluttered backgrounds
5. Never replace real screenshots with AI-generated backgrounds — engineers value proof of work

## Description Rules
1. First 2-3 lines show before "Show more" on mobile — make them count
2. Timestamps must match actual script sections
3. Tags: broad first, then specific
4. No keyword stuffing — write for humans first
