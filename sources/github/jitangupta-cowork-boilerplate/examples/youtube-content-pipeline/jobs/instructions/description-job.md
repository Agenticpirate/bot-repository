## Trigger
"Run description job for video-XXX"

---

## Steps

### Step 1 — Read Inputs
Read `02_script/final.md` (for content and timestamps) and `03_titles/final.md` (for chosen title and angle).

### Step 2 — Generate Description
Write directly to `04_description/final.md`. No draft/review loop needed.
Update STATUS to `DESCRIPTION_DONE`.

---

## Description Structure

```
[HOOK LINE — 1 sentence, matches the video's opening promise]

[TIMESTAMPS]
00:00 - Intro
[fill from script section markers]

[ABOUT THIS CHANNEL — 2-3 lines]

[LINKS — placeholders for repo, related video, socials]

[TAGS — 15-20 tags, mix of broad and specific]
```
