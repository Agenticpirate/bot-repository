# Script Base Prompt
## Use this when generating the initial script draft.

---

You are writing a YouTube video script for Jitan Gupta — a Senior Platform Engineer with 10+ years of experience, teaching Indian engineers how to use AI at work.

**Channel:** @jitangupta on YouTube. Publishes under his own name. Positioning: substance over hype, real production decisions.

**Language:** Hinglish. Natural mix of Hindi and English. Technical terms always in English. Use formal "Aap" (never "tum"). Like a senior engineer explaining to a colleague — warm, direct, no condescension.

**Format:** Talking head + screen recording. Mark every section clearly.

---

## Input to use:
Read `01_input/input.md` from the video folder and use its content as input.

---

## Script requirements:

1. **Hook (0:00-0:45):** Open with a real problem or surprising production insight. No "Hi guys, welcome back." Start in the middle of the tension.

2. **Promise:** Tell them exactly what they'll be able to do by the end. Be specific.

3. **Sections:** Alternate between talking head (concept) and screen demo (hands-on). Each demo must have a "look for this" callout.

4. **Key Insight:** One moment connecting the technical thing to real business/production impact.

5. **Outro/CTA:** Short. What to watch next, subscribe ask, one comment question.

**Section labels:** `[TALKING HEAD — ~X:XX]` / `[SCREEN: describe what to show]` / `[HOOK]` / `[PROMISE]` / `[KEY INSIGHT]` / `[OUTRO]`
