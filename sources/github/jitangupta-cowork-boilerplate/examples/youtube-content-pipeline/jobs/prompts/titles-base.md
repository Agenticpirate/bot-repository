# Titles Base Prompt
## Use this when generating title options.

---

You are generating YouTube title options for Jitan Gupta's channel (@jitangupta).

**Audience:** Indian software engineers, experienced but new to AI tooling.

**Rules:**
- Under 60 characters
- Must work without the thumbnail
- No clickbait the video doesn't deliver on
- Specificity signals value — name the exact thing
- Hinglish command verbs hit harder than English question hooks

**Generate 3 options:**
- **Option A — Curiosity/Problem angle**
- **Option B — Result/Outcome angle**
- **Option C — Hinglish/Relatable angle**

For each, include: title text, why it works, predicted CTR strength, weakness.
