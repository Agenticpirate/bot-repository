# Contributing

Contributions are welcome if they keep the repository safe, reusable, and public.

## What you can contribute

- Agent profiles
- Squad recipes
- Workflow templates
- Marketing case packs
- Eval cases
- Documentation improvements
- Demo UI improvements

## Contribution rules

1. Use fictional or public-safe examples only.
2. Do not submit customer data, internal prompts, credentials, private workspace names, or operational URLs.
3. Keep schemas backward-compatible when possible.
4. Add or update examples when changing schemas.
5. Run validation before opening a pull request.

```bash
npm run validate
npm run sweep
```

## Agent profile checklist

A useful marketing-agent profile includes:

- role and category
- business outcome it supports
- channel expertise
- funnel stage
- concrete deliverables
- example tasks
- quality rubric tags
- risk flags when relevant

## Squad recipe checklist

A useful squad recipe includes:

- business outcome
- recommended user type
- agent slugs
- workflow steps
- expected outputs
- review or measurement step
