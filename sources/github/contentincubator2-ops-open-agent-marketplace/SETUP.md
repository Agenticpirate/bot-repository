# Setup

## Requirements

- Node.js 18+
- npm

## Install

```bash
npm install
```

## Validate sample data

```bash
npm run validate
```

## Run demo UI

```bash
npm run demo
```

Open `http://localhost:4173/app/web/`.

## Use the data in another app

Import `data/agents.sample.json` and `data/squads.sample.json`, then validate them against the JSON schemas in `schema/`.
