# Security Policy

This project is designed for public, sanitized agent profiles only.

## Do not commit

- API keys, tokens, cookies, passwords, private keys, or OAuth credentials
- Customer names, unpublished metrics, private prompts, private URLs, or database dumps
- Internal IPs, SSH hosts, environment files, or operational screenshots
- Private workspace names or proprietary commercial terms

## Reporting security issues

Please open a private security advisory or contact the maintainers. Do not publish exploitable details in public issues.
