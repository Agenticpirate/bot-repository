# Marketplace Design

The reference design pattern is a developer-first directory:

- Terminal-inspired hero copy
- Monospace labels and file-like cards
- Command-line search: `$ find agents`
- Categories exposed as JSON-like sections
- Agent cards that feel like Markdown files
- API card showing `GET /api/v1/agents 200 OK`

## Suggested homepage sections

1. `~/open-agent-marketplace` navigation
2. Hero: `> Open Agent Marketplace`
3. Stat block: `const agents = 16102;`
4. Search: `$ find agents`
5. Featured agent cards
6. Browse by category
7. Browse by squad
8. API access card
9. FAQ as `FAQ.md`
10. Footer as `$ cat README.md`
