# Marketing Agent Quality Rubric

Use this rubric to evaluate whether an agent output is ready to ship, needs revision, or should be rejected.

## Score scale

| Score | Meaning |
|---|---|
| 5 | Excellent: ready to use with minimal edits |
| 4 | Strong: useful with small edits |
| 3 | Adequate: structurally useful but needs revision |
| 2 | Weak: misses important context or lacks specificity |
| 1 | Not usable: generic, risky, or misaligned |

## Dimensions

### 1. Strategic clarity

Does the output make a clear strategic choice instead of listing generic options?

High-scoring work includes:

- a named target audience
- a clear business objective
- tradeoffs or prioritization
- a recommended next action

### 2. Audience specificity

Does the output sound like it was written for a real buyer, user, or segment?

High-scoring work includes:

- specific pains, objections, and motivations
- realistic customer language
- segment-level nuance
- channel-appropriate framing

### 3. Channel fit

Does the output respect the rules and behavior of the channel?

High-scoring work includes:

- correct format and length
- platform-native style
- CTA fit
- awareness of buying intent and context

### 4. Evidence quality

Does the output ground its recommendations in provided inputs, public facts, or stated assumptions?

High-scoring work includes:

- clear reasoning
- source notes when applicable
- no invented metrics
- explicit assumptions when data is missing

### 5. Brand voice control

Does the output maintain a consistent, intentional tone?

High-scoring work includes:

- voice notes
- phrases to use and avoid
- consistent level of formality
- no generic AI filler language

### 6. Conversion usefulness

Can a marketer use the output to improve a real funnel step?

High-scoring work includes:

- clear offer framing
- concrete objections handled
- CTA hierarchy
- next-step mechanics

### 7. Compliance and risk awareness

Does the output avoid unsafe claims, privacy issues, and unsupported guarantees?

High-scoring work includes:

- claim review notes
- disclaimers when necessary
- regulated-industry awareness
- clear escalation when legal review is needed

### 8. Handoff quality

Can the next agent or human teammate continue the work without guessing?

High-scoring work includes:

- structured sections
- next owner
- open questions
- version notes
- output file names or asset list

## Pass/fail gate

An output should not ship if any of these are true:

- It includes private customer data that was not meant for public use.
- It makes unverifiable performance claims.
- It ignores the requested channel or audience.
- It is mostly generic advice with no operational next step.
- It requires legal, medical, financial, or regulated-claims review and does not flag that need.
