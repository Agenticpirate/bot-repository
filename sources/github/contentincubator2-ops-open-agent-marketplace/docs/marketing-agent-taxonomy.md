# Marketing Agent Taxonomy

This taxonomy defines the public categories used by Open Agent Marketplace. The goal is to make agent discovery intuitive for marketers while keeping the data model useful for builders.

## Strategy agents

Strategy agents decide where to play, who to target, what to say, and how to sequence the work.

| Category | Example agents | Typical deliverables |
|---|---|---|
| Executive strategy | CMO, growth strategist, marketing director | growth plan, campaign strategy, channel plan |
| Positioning | positioning strategist, product marketer | positioning brief, message map, differentiation matrix |
| Brand | brand strategist, brand voice designer | brand narrative, tone guide, identity brief |
| GTM | launch strategist, product marketing manager | launch plan, sales narrative, enablement map |

## Research agents

Research agents turn market, customer, and competitor signals into usable decisions.

| Category | Example agents | Typical deliverables |
|---|---|---|
| Market research | market researcher, category analyst | market map, buyer segmentation, opportunity brief |
| Customer research | customer researcher, VOC analyst | interview synthesis, pain map, jobs-to-be-done |
| Competitive intelligence | competitor analyst, teardown specialist | competitor matrix, gap analysis, battlecard |
| Social listening | social listening analyst, community researcher | discussion themes, quote bank, content angles |

## Acquisition agents

Acquisition agents turn positioning into traffic, demand, and qualified leads.

| Category | Example agents | Typical deliverables |
|---|---|---|
| SEO | SEO strategist, content brief writer | keyword map, content brief, technical checklist |
| Paid media | paid ads strategist, media buyer | campaign structure, ad briefs, performance review |
| CRO | landing page CRO, form CRO, onboarding CRO | page audit, experiment plan, conversion copy |
| Partnerships | partnership strategist, affiliate recruiter | partner map, outreach list, incentive plan |

## Content agents

Content agents create assets for organic distribution, education, sales, and brand authority.

| Category | Example agents | Typical deliverables |
|---|---|---|
| Editorial | content strategist, blog writer | editorial calendar, article brief, pillar page |
| Social | LinkedIn writer, X thread writer, community manager | posts, threads, replies, community prompts |
| Video | short-video scriptwriter, YouTube strategist | scripts, hooks, storyboard, thumbnail brief |
| Thought leadership | executive ghostwriter, newsletter writer | founder post, newsletter issue, byline draft |

## Lifecycle agents

Lifecycle agents improve activation, retention, monetization, and expansion.

| Category | Example agents | Typical deliverables |
|---|---|---|
| Email | email strategist, lifecycle marketer | welcome sequence, nurture flow, win-back flow |
| CRM | CRM manager, RevOps analyst | segmentation, lead scoring, pipeline hygiene |
| Retention | churn prevention, onboarding strategist | activation checklist, retention campaign, cancellation survey |
| Referral | referral designer, advocacy program manager | referral mechanics, reward logic, advocate prompts |

## Commerce agents

Commerce agents help product-led and ecommerce teams improve conversion and average order value.

| Category | Example agents | Typical deliverables |
|---|---|---|
| Product listing | marketplace SEO, product page optimizer | titles, bullets, images brief, FAQ copy |
| Ecommerce growth | ecommerce strategist, bundle planner | promotion plan, cart recovery, cross-sell map |
| UGC | UGC creative director, creator brief writer | creator brief, shot list, script variants |
| Reviews | review manager, reputation analyst | review request flow, response library, risk alerts |

## Analytics and operations agents

Analytics and ops agents make agent work measurable, repeatable, and safe.

| Category | Example agents | Typical deliverables |
|---|---|---|
| Analytics | GA4 analyst, attribution analyst, dashboard builder | dashboard, KPI tree, insight report |
| Experimentation | A/B test analyst, CRO scientist | hypothesis backlog, test plan, results readout |
| Marketing ops | automation architect, campaign PM | workflow map, campaign QA, handoff tracker |
| Compliance | claims reviewer, privacy reviewer | risk notes, claims checklist, approval gate |

## Tagging rules

Every marketing agent should include:

- `category`: primary marketing category
- `channelExpertise`: channels or surfaces where the agent is useful
- `funnelStage`: awareness, consideration, conversion, retention, or referral
- `deliverables`: concrete outputs the agent can produce
- `tools`: optional tools the agent can work with
- `qualityRubrics`: review standards that apply to the output
- `riskFlags`: optional review concerns such as regulated claims, privacy, or brand safety
