# Agent Schema

An agent is a public-safe profile for a reusable AI worker.

Core fields:

- `slug` — stable URL-safe identifier
- `name` — public display name, fictional or approved
- `title` — role title
- `layer` — `strategy`, `execution`, or `training`
- `category` — primary marketplace category
- `primarySkill` — main skill or capability
- `industries` — relevant industries
- `summary` — short marketplace card description
- `exampleTasks` — public-safe task examples
- `pricingTier` — public tier, not private deal terms
- `source` — source namespace or repository path
