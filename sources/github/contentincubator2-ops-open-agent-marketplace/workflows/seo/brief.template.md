# SEO Workflow

## Purpose

Maps search intent to content briefs, internal links, and conversion paths.

## Required inputs

- website type
- target audience
- seed topics
- competitors
- conversion goal

## Success criteria

- The output names a target audience.
- The recommendation makes clear tradeoffs.
- The handoff is structured enough for the next agent or human to continue.
- The work avoids unsupported claims and private data.
