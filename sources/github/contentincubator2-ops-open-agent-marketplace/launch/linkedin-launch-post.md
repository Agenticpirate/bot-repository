# LinkedIn Launch Post

Most AI-agent repos show a single automation or a list of tools.

Marketing work does not happen that way. It happens in teams: strategy, research, acquisition, content, lifecycle, analytics, and ops.

So we open-sourced Open Agent Marketplace: a starter kit for building AI marketing-agent marketplaces with reusable agent profiles, squad recipes, workflow templates, and evaluation rubrics.

Use it to model teams like:

- SaaS Launch Squad
- Ecommerce Growth Squad
- B2B ABM Squad
- Local Service Lead Gen Squad
- Creator Growth Squad

Repo: https://github.com/contentincubator2-ops/open-agent-marketplace
