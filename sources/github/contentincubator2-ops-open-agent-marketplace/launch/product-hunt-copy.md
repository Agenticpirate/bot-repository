# Product Hunt Launch Copy

## Tagline

Open-source Marketing Agent OS for building reusable AI teams.

## Short description

Open Agent Marketplace helps builders create searchable AI marketing-agent marketplaces with public schemas, fictional sample agents, squad recipes, workflow templates, and evaluation rubrics.

## Maker comment

We built this because most AI-agent examples are either generic demos or raw directories. Marketing work needs teams: strategists, researchers, copywriters, lifecycle marketers, analysts, and operators. This repo gives you a public-safe way to model those agents, compose them into squads, and evaluate their outputs.
