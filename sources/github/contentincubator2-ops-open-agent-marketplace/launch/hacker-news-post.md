# Hacker News Post Draft

Title: Show HN: Open Agent Marketplace — schemas and recipes for AI marketing teams

Body:

I built an open-source starter kit for creating AI marketing-agent marketplaces. Instead of a raw list of agents, it includes schemas, fictional sample data, squad recipes, workflow templates, and evaluation rubrics.

The goal is to make agent marketplaces more operational: not just "find an agent," but "compose a squad for SaaS launch, ecommerce growth, ABM, local lead generation, or content operations."

Repo: https://github.com/contentincubator2-ops/open-agent-marketplace
