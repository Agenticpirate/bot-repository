Claude Design — the text-to-prototype plugin

The newest plugin to land in Claude Cowork is also its most disruptive. Claude Design is an Anthropic Labs product that turns a plain-language prompt (or an existing codebase, or a Figma export) into a working prototype, design system, slide deck, or marketing one-pager — in minutes, inside Claude itself. Mike Krieger's resignation from Figma's board three days earlier and the ~5–7% drop in Figma's stock on launch day made the positioning hard to miss.

🎨

Claude Design

by Anthropic Labs

Turn a prompt, codebase, or rough brief into polished design systems, interactive website prototypes, slide decks, and one-pagers — without opening Figma or Canva.

Model
Claude Opus 4.7
Launched
April 17, 2026
Availability
Research preview on Claude Pro, Max, Team, and Enterprise plans. Uses your existing weekly tokens — design-heavy sessions can burn through quota quickly.

What it does

  • ◆Generates design systems, prototypes, slide decks, and marketing one-pagers from plain-language prompts
  • ◆Accepts an existing codebase or Figma export as input so Claude designs on-brand from the start
  • ◆In-canvas editing: comment on elements, draw directly on mockups, nudge fonts / colors with live sliders
  • ◆Approvals at each stage — nothing lands in your files until you accept it
  • ◆Exports PDF, PPTX, standalone HTML; one-click handoff to Canva, with Claude Code + Figma handoffs in preview

Slash commands

/design:prototype/design:design-system/design:slide-deck/design:one-pager
Best for: PMs, founders, and marketers who need a production-feeling first draft in minutes, and design teams that want an AI collaborator for the unsexy 60% of the work.

Replaces

First-draft work in Figma, Canva, Framer, and Google Slides.

Pairs with

The Design and Marketing plugins, plus Claude Code for dev handoff.

Watch out for

Token cost. One website + design system + video can burn >50% of a weekly quota.

How to Install Plugins

In Claude Cowork (Desktop)

  1. 1Navigate to the Cowork tab
  2. 2Click "Plugins" in the left sidebar
  3. 3Browse available plugins by category
  4. 4Click any plugin to install it
  5. 5Optionally click "Upload plugin" for custom plugins

Via Command Line (Claude Code)

# Add the marketplace
claude plugin marketplace add \
  anthropics/knowledge-work-plugins

# Install a specific plugin
claude plugin install \
  sales@knowledge-work-plugins

# Install financial services plugins
claude plugin marketplace add \
  anthropics/financial-services-plugins

claude plugin install \
  investment-banking@financial-services-plugins
Note: Plugins are currently in research preview. Anthropic advises against use for regulated workloads given the agentic nature. All knowledge work plugins are open-source at anthropics/knowledge-work-plugins.
