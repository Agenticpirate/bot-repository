What are Claude Skills?

A Claude Skill is a focused capability defined by a SKILL.md file and optional supporting files. Depending on its configuration, Claude Code can load it automatically for a matching task or you can invoke it explicitly. A skill can guide tasks such as writing tests, reviewing security, or building a spreadsheet. This directory indexes Claude Skills harvested from public GitHub repositories and ranks them by how many times each has actually been installed.

How to install Claude Code

Claude Skills run inside Claude Code, Anthropic's terminal coding agent. Install it once with npm install -g @anthropic-ai/claude-code, then run claude in any project to start a session. Codex CLI and several compatible agents read the same SKILL.md format, so most skills work beyond Claude Code too.

How to use a Claude Skill

With Claude Code running, add a skill using its install command — npx skills add <owner>/<repo> --skill <name> --agent claude-code. It adds the skill to your project's .claude/skills/ folder. Confirm that Claude Code can find and load it, then use it automatically or invoke it explicitly as its configuration allows. Check the repository for required tools, runtimes, credentials and other dependencies before using it on a real task.

Frequently asked questions

How do I install a Claude Skill?
Open a skill and copy its install command — the shape is npx skills add <owner>/<repo> --skill <name> --agent claude-code. It adds the skill to your project's .claude/skills/ folder. Before first use, confirm that Claude Code can find and load it, check its invocation settings, and verify the repository's required tools, runtimes, credentials and other dependencies.
Are Claude Skills free?
Browsing this directory is free. Publicly available source code does not necessarily have an open-source license. Check each repository's license and terms before use or redistribution. Some components may require a paid license, and model or API usage and external services may incur separate charges.
Do Claude Skills work outside Claude Code?
Many do. Skills follow the SKILL.md convention Claude Code introduced, and Codex CLI along with several compatible agents read the same format. Each skill's page shows which agents it targets and the exact command for yours.
What is the difference between a Claude Skill and a plugin?
A Claude Skill is one capability; a plugin is a bundle. A plugin installed from a marketplace can ship several skills alongside slash commands, subagents, and hooks. Install a skill when you want a single behavior, a plugin when you want a whole toolkit at once.
How is the directory ranked?
By install count first and GitHub stars second. The two often disagree — a skill can have modest stars but heavy real-world use — so both numbers are shown and you can sort the list by either.
