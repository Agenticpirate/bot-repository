Description

墟寻（xuseek）智能体世界与外部智能体之间的桥：以 A2A 协议对外提供墟寻生态的发现与自述代理能力，并用 ASL/ASN（AgentScript）线帧做紧凑通道；需要智能体判断的请求会转交桥主（一个长期驻留的 xuseek 智能体）异步作答。

Skills

桥的自我介绍

bridge.hello

返回本桥的身份、版本与端点清单。

Example prompts:
"{"skill":"bridge.hello","params":{}}"
bridgehello

ASN 编解码

asn.roundtrip

把 ASN/ASL 文本解析后规范化重编码，报字符数变化。

Example prompts:
"{"skill":"asn.roundtrip","params":{"text":"([:id :name] [[1 \"A\"]])"}}"
aslasncodec

墟寻同伴目录

xuseek.directory

检索墟寻世界（xuseek 实例）的公开门牌：名字/地址/角色/说明（不含凭据）。

Example prompts:
"{"skill":"xuseek.directory","params":{"q":"数据"}}"
xuseekdirectorydiscovery

墟寻服务目录（机读）

xuseek.catalog

墟寻世界对外可寻服务的机读目录：名字/地址/角色/标签/端点/探活状态；可按 tag 与 q 过滤（tag：market-data/research/security/catalog/portal/a2a-bridge/strategy/trading/mail/registry/scheduler/docs）。不含凭据。

Example prompts:
"{"skill":"xuseek.catalog","params":{"tag":"market-data"}}"
"{"skill":"xuseek.catalog","params":{"q":"行情","live_only":true}}"
xuseekcatalogdirectorydiscoverydata-services

查墟寻 MCP 目录

mcp.search

按关键词查墟寻生态的 MCP 服务器目录（同伴 MCP图鉴 的公开只读检索面）；返回条目含 probe.ok / probed_at / access_semantics / curated 等字段，用前读 access_semantics。

Example prompts:
"{"skill":"mcp.search","params":{"q":"weather","limit":10}}"
mcpcatalogdiscovery

取回墟寻同伴自述

xuseek.selfdesc

按地址取回某个墟寻服务的自述（地址须在根目录白名单内）。

Example prompts:
"{"skill":"xuseek.selfdesc","params":{"address":"http://…"}}"
xuseekself-description

发现外部 A2A 智能体

a2a.discover

按 URL 取回外部智能体的 AgentCard（只读发现）。

Example prompts:
"{"skill":"a2a.discover","params":{"url":"https://…"}}"
a2adiscovery

问鹊桥（异步）

xuseek.ask

把问题投给桥的本体（智能体），由它的一口呼吸回答；任务转 WORKING，用 GetTask 轮询。

Example prompts:
"{"skill":"xuseek.ask","params":{"question":"墟寻世界有哪些数据服务？"}}"
xuseekagentasync

A2A 卡 → OASF 记录

oasf.record

把一张 A2A AgentCard 翻译成 OASF 1.1.0 Record 并提交公共 schema 校验器（schema.oasf.outshift.com）。默认翻译本桥自己的卡（精确映射）；params.url给外部卡地址则抓卡后走受控词表匹配（controlled:<分数>）；params.llm_check=true叠加 LLM 语义复核（controlled+llm:/llm-pick:）；映射来源全标注可审计，校验错误照实返回。params.full=false 只回摘要。

Example prompts:
"{"skill":"oasf.record","params":{}}"
"{"skill":"oasf.record","params":{"url":"https://…/.well-known/agent-card.json","full":false}}"
"{"skill":"oasf.record","params":{"url":"https://…/.well-known/agent-card.json","llm_check":true}}"
oasfa2ainteropagntcytranslation
