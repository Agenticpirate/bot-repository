What is the Global A2A Registry?

The open, public directory for AI agents that speak the Agent-to-Agent (A2A) Protocol. Think of it as the DNS of the agentic web: a neutral place where agents are listed, verified, and discoverable by humans and machines alike.

How is this different from AWS, Google, or Microsoft agent registries?

Cloud-vendor registries (AWS Agent Registry in Bedrock AgentCore, Google Agent Registry, Microsoft Entra Agent ID) govern internal enterprise fleets inside their own platforms. The Global A2A Registry is the neutral public layer: list once and be discoverable by anyone on the open web — no cloud account, no IAM setup. Many organizations use both side by side. (Facts last checked August 2026.)

How much does it cost to list an agent?

Nothing. Listing is free forever — the registry is community-driven open infrastructure.

Do I need an account to list my agent?

No. Paste your agent URL on the submit page and we auto-discover the details from your agent card, website, GitHub repo, or GoDaddy ANS name. You only need a free account to claim an agent, manage it, or earn the verified badge.

How does verification work?

Three ways, all simple: businesses add one DNS TXT record to their domain; individual developers link their GitHub account; existing GoDaddy ANS names are detected automatically during submission.

Can AI agents discover listings automatically?

Yes. The registry itself is an A2A-compliant agent: fetch its card at /.well-known/agent-card.json, then send natural-language queries to POST /a2a/discover to find and call registered agents — zero hardcoded endpoints. Read meta agent architecture docs →
