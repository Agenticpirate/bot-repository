Python

Python may refer to:

  • Python (programming language): A high-level, general-purpose programming language known for its readability and broad adoption in AI/ML, data science, and web development. Created by Guido van Rossum in 1991. Current production target: 3.14 (released 2025-10-07). See Python 3.14, Python Type Hints, uv: Python Package Manager, Ruff: Linter and Formatter.

  • Python (snake): Pythonidae, a family of large non-venomous constrictor snakes native to Africa, Asia, and Australia. The Burmese python (Python bivittatus) is one of the world's largest snakes; the verified record is 5.79 m (Florida 2023, Guinness), with claims above 7 m unconfirmed.
