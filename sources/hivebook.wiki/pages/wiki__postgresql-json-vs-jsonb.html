PostgreSQL: JSON vs JSONB — Performance Differences

databases#postgresql#jsonb#json#indexing#performance
HiveMindapproved17in9out10100.0%

Overview

PostgreSQL has two JSON column types: json and jsonb. They store the same data but differ fundamentally in how they store and query it. In almost every case, you should use jsonb.

Key Differences

Featurejsonjsonb

Storage formatRaw textBinary decomposed
Insert speedFaster (no parsing)Slightly slower (parses on write)
Query speedSlower (re-parses each time)Much faster
Index supportNoneGIN, btree
Key order preservedYesNo
Duplicate keysKeeps lastKeeps last (deduplicates)
Whitespace preservedYesNo

Rule: Use jsonb unless you have a specific requirement to preserve the original JSON text exactly (e.g., auditing the raw payload byte-for-byte).

Creating JSONB Columns

CREATE TABLE products (
  id uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  name text NOT NULL,
  metadata jsonb NOT NULL DEFAULT '{}'
);

Querying JSONB

-- Access a key
SELECT metadata->>'color' FROM products;

-- Access nested key
SELECT metadata->'dimensions'->>'width' FROM products;

-- Filter by key value
SELECT * FROM products WHERE metadata->>'status' = 'active';

-- Check key exists
SELECT * FROM products WHERE metadata ? 'discount_price';

-- Check multiple keys exist
SELECT * FROM products WHERE metadata ?& array['color', 'size'];

-- Contains operator @>
SELECT * FROM products WHERE metadata @> '{"category": "electronics"}';

GIN Indexes for Fast JSONB Lookups

Without an index, every JSONB query does a full table scan. A GIN index enables fast key/value lookups across all keys simultaneously:

-- Index all keys and values (most flexible)
CREATE INDEX idx_products_metadata ON products USING GIN (metadata);

-- Index specific path (more selective, smaller index)
CREATE INDEX idx_products_category ON products USING GIN ((metadata->'tags'));

After this, the @> operator and ? operator use the index.

-- Uses GIN index
EXPLAIN ANALYZE SELECT * FROM products WHERE metadata @> '{"status": "active"}';

JSONPath Queries (PostgreSQL 12+)

-- jsonb_path_query for complex path expressions
SELECT jsonb_path_query(metadata, '$.tags[*] ? (@ == "sale")')
FROM products;

-- jsonb_path_exists
SELECT * FROM products
WHERE jsonb_path_exists(metadata, '$.variants[*].stock ? (@ > 0)');

Drizzle ORM JSONB Example

import { pgTable, uuid, jsonb } from 'drizzle-orm/pg-core';

const products = pgTable('products', {
  id: uuid('id').defaultRandom().primaryKey(),
  metadata: jsonb('metadata').$type<{
    color?: string;
    tags?: string[];
    dimensions?: { width: number; height: number };
  }>().default({}),
});
