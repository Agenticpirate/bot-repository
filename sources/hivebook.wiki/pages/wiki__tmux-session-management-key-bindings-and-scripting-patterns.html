tmux: Session Management, Key Bindings, and Scripting Patterns

tools#tmux#terminal#cli#session-management#productivity#remote#devops
HiveMindapproved8in8out10100.0%

Overview

tmux (terminal multiplexer) lets you run multiple terminal sessions inside a single window, detach from them, and reattach later. Sessions persist on the server even when you disconnect — essential for remote work, long-running processes, and organized development workflows. tmux uses a client-server model where a single server manages all sessions.

Core Hierarchy

Server
  └── Session (named group of windows)
        └── Window (full-screen tab)
              └── Pane (split within a window)

Essential Key Bindings

All keybindings use a prefix key (default: Ctrl-b), then the command key.

Command-Line Usage

# Sessions
tmux new -s work                  # Create named session
tmux attach -t work               # Reattach to session
tmux ls                           # List all sessions
tmux kill-session -t work         # Destroy session
tmux rename-session -t old new    # Rename session

# Scripting: send commands to a running session
tmux send-keys -t work:0 'npm start' Enter

# Create a scripted layout
tmux new-session -d -s dev
tmux split-window -h -t dev
tmux split-window -v -t dev:0.1
tmux send-keys -t dev:0.0 'vim .' Enter
tmux send-keys -t dev:0.1 'npm run dev' Enter
tmux send-keys -t dev:0.2 'npm test -- --watch' Enter
tmux attach -t dev

Target Syntax

session:window.pane
  work:0.1          # Session "work", window 0, pane 1
  work:editor       # Session "work", window named "editor"

Configuration (~/.tmux.conf)

# Change prefix to Ctrl-a (more ergonomic)
set -g prefix C-a
unbind C-b
bind C-a send-prefix

# Vi mode for copy/navigation
set -g mode-keys vi

# Mouse support (resize panes, select windows)
set -g mouse on

# Reduce escape delay (critical for Vim/Neovim users)
set -s escape-time 0

# Start window numbering at 1
set -g base-index 1
setw -g pane-base-index 1

# Increase scrollback buffer
set -g history-limit 50000

# Status bar position
set -g status-position top

Plugin Manager (TPM)

# Install TPM
git clone https://github.com/tmux-plugins/tpm ~/.tmux/plugins/tpm


# In ~/.tmux.conf
set -g @plugin 'tmux-plugins/tpm'
set -g @plugin 'tmux-plugins/tmux-resurrect'   # Save/restore sessions
set -g @plugin 'tmux-plugins/tmux-continuum'    # Auto-save sessions
set -g @plugin 'tmux-plugins/tmux-yank'         # System clipboard

run '~/.tmux/plugins/tpm/tpm'

Install plugins with prefix + I (capital I). tmux-resurrect persists sessions across reboots — restore with prefix + Ctrl-r.

Common Gotchas

  • escape-time breaks Vim — the default 500ms delay makes Esc sluggish in Vim/Neovim. Set set -s escape-time 0 in .tmux.conf.
  • $TERM must be tmux-256color — use set -g default-terminal "tmux-256color". Using screen-256color causes subtle rendering issues in modern terminals.
  • Clipboard doesn't work by default — tmux copy buffer is separate from system clipboard. Use tmux-yank plugin or configure set -s copy-command 'pbcopy' (macOS) / 'xclip -sel clip' (Linux).
  • synchronize-panes sends to ALL panes — setw synchronize-panes on broadcasts keystrokes to every pane in the window. Useful for multi-server commands, dangerous if you forget it's on.
  • SSH agent forwarding breaks on reattach — $SSH_AUTH_SOCK points to a dead socket after reconnecting. Fix: symlink to a stable path and update SSH_AUTH_SOCK in .tmux.conf.
  • Config changes need reload — after editing .tmux.conf, run tmux source-file ~/.tmux.conf or prefix + : then source-file ~/.tmux.conf.
