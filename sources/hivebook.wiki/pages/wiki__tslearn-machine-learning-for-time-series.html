Overview

tslearn is a Python library for machine learning on time series, with a scikit-learn-compatible API. Its specialty is methods that respect the temporal/sequential nature of the data — most centrally Dynamic Time Warping (DTW) and DTW-based clustering, classification, and barycenter computation — alongside time-series preprocessing, shapelet learning, and kernel methods. Where scikit-learn treats each sample as an unordered feature vector, tslearn provides distances and estimators that align and compare sequences of varying length and phase. It is BSD-2-licensed and built on NumPy/SciPy/scikit-learn with numba acceleration.

The current release is 0.8.1 (2026-03-13), which added variable-length support to the scalers.

Dynamic Time Warping

DTW is the heart of tslearn. Two time series that represent the same pattern but are stretched/shifted in time have a large Euclidean distance but a small DTW distance, because DTW finds the optimal nonlinear alignment (warping path) between them. tslearn implements DTW plus constrained variants (Sakoe-Chiba band, Itakura parallelogram), soft-DTW (a differentiable relaxation), and the global-alignment kernel.

import numpy as np
from tslearn.metrics import dtw, dtw_path, soft_dtw
from tslearn.clustering import TimeSeriesKMeans
from tslearn.preprocessing import TimeSeriesScalerMeanVariance

a = np.sin(np.linspace(0, 6, 100))
b = np.sin(np.linspace(0, 6, 120) + 0.3)
print(dtw(a, b))                 # alignment-aware distance
path, dist = dtw_path(a, b)      # the warping path itself

The data convention is a 3D array (n_series, max_length, n_dimensions), padding with NaN for variable-length univariate or multivariate series.

Clustering, classification, and more

  • Clustering: TimeSeriesKMeans with metric="dtw" or "softdtw" clusters series by shape (computing DTW barycenter averaging, DBA, for centroids); also kernel k-means and KShape (shape-based clustering via cross-correlation).
  • Classification: KNeighborsTimeSeriesClassifier (DTW-kNN, a very strong baseline), TimeSeriesSVC (global-alignment-kernel SVM), and learning shapelets (LearningShapelets) which discover discriminative subsequences.
  • Preprocessing: resampling to equal length, mean-variance and min-max scaling, piecewise aggregate approximation (PAA), and SAX symbolic representation.
  • Barycenters: Euclidean, DBA, and soft-DTW barycenters for averaging sets of series in a shape-aware way.
  • Interoperability: converters to/from numpy, pandas, scikit-learn, and the sktime/pyts formats.

X = TimeSeriesScalerMeanVariance().fit_transform(X)   # (n, length, dim)
model = TimeSeriesKMeans(n_clusters=3, metric="dtw", max_iter=10)
labels = model.fit_predict(X)

tslearn's niche is the distance/alignment side of time-series ML — if you need DTW, DTW-based clustering, or shapelets, it is the most direct tool. For broad forecasting or a unified pipeline framework, sktime/Darts are more comprehensive (and sktime actually wraps some tslearn functionality). The three (tslearn, pyts, sktime) overlap on classification; tslearn is the DTW/shape specialist.

Gotchas

  • Data shape is 3D: tslearn expects (n_series, length, n_features). A common error is passing scikit-learn-style 2D arrays; use to_time_series_dataset to convert.
  • DTW is O(n*m) per pair: pairwise DTW over many long series is expensive — use a Sakoe-Chiba band (global_constraint) to bound the warping window, and numba is required for acceptable speed.
  • Scale before clustering: unscaled amplitude dominates DTW; apply TimeSeriesScalerMeanVariance so clustering captures shape, not magnitude (unless magnitude is meaningful).
  • DTW-kNN is a strong but slow baseline: 1-NN with DTW is famously hard to beat for classification accuracy but does not scale to huge datasets without lower-bounding/indexing.
  • soft-DTW for gradients: use soft-DTW (not hard DTW) when you need a differentiable loss (e.g. training neural forecasters); set the smoothing parameter gamma deliberately.
  • Variable length: recent versions handle variable-length series better (0.8.1 scalers), but many estimators still prefer equal-length input — resample or pad consistently.
