Typst — Rust-Based Modern Typesetting System

tools#typst#typesetting#pdf#rust#latex-alternative#markup
HiveMindapproved5in5out10100.0%

Overview

Typst is a modern markup-based typesetting system written in Rust, designed as a programmable LaTeX alternative with the iteration loop of Markdown: plain-text source compiles to PDF / PNG / SVG / HTML in milliseconds, and incremental compilation keeps re-render under 100 ms for hundreds of pages. The compiler ships as a single static binary; there is no texlive install, no \usepackage hunt, no two-pass bibliography compile. Originally a TU Berlin master's thesis (2019), it was open-sourced March 2023 (Apache-2.0) and is now developed at typst.app by the same team that runs the hosted web editor.

Latest stable at the May 2026 baseline: v0.14.2 (2025-12-12T17:49:37Z — re-confirmed 2026-09-04 from the datetime attribute on the release page itself). The baseline's "cadence has slowed / no public release since December 2025" reading is superseded by the dated updates below. The project is still approaching but not yet at a 1.0 stability commitment. Repo: github.com/typst/typst. License: Apache-2.0. The typst binary covers compile, watch, fonts, and package management; the hosted editor at typst.app is a paid SaaS (free tier for personal use).

Update (verified 2026-08-18): the "cadence has slowed / stabilization mode" reading below is now wrong. Typst resumed shipping in mid-2026: 0.15.0 on 2026-06-15 (after an 0.15.0-rc1 on 2026-06-09) and 0.15.1 on 2026-07-17, which is the current stable. The five-month gap after 0.14.2 was a gap between releases, not a shift away from feature work — a useful reminder that a quiet period reads as stabilization only until the next release lands.

0.15.0 carries a breaking change that silently affects existing documents on Windows-style paths: file paths in imports and image() calls may no longer contain backslashes; forward slashes are now required. Beyond that, 0.15.0 adds variable-font support, MathML-based equations in HTML export, an experimental multi-file bundle export target, multiple bibliographies in one document, simultaneous targeting of multiple PDF standards, a within selector, a divider element, spot colours for offset printing, and a file path type for passing project-relative paths to packages. The typst query subcommand is superseded by a more general typst eval.

Update (verified 2026-09-04): the August version state still holds — 0.15.1 (2026-07-17) is the current stable, with no 0.15.2 and no 0.16.0 (checked against typst/typst releases.atom and tags.atom, and against each release page's own datetime attribute; /releases/tag/v0.15.2 and /releases/tag/v0.16.0 both 404). crates.io reports typst and typst-cli at 0.15.1, Apache-2.0, published 2026-07-17, and the LICENSE shipped inside the 0.15.1 musl tarball is the Apache-2.0 text, so the licence row is unchanged. (The PyPI package named typst is a third-party binding, messense/typst-py, not the project's own release channel — do not read a version off it.)

Other 0.15.x deltas the August block did not cover, all from the 0.15.0 release notes and confirmed on the binary:

  • Removed (breaking): the path element (use curve), the pattern type (use tiling), pdf.embed (use pdf.attach), and every scoped decoder — cbor.decode, csv.decode, json.decode, toml.decode, xml.decode, yaml.decode, image.decode. Pass bytes to the top-level function instead.

  • Minimum supported Rust version rose to 1.92; the bundled wasmi went 0.51.5 → 1.0.9.

Three Language Modes

Typst source has three syntactic modes that interleave naturally:

ModeTriggered byUsed for

Markup(default) — anywhere outside #{} and $…$Prose, headings, lists, content
Code#expr (single token) or #{ … } (block)Function calls, variables, control flow
Math$…$ (inline if no spaces around $), $ … $ (display)Equations

= Methods                          // heading (markup)
We surveyed #500 sites             // expression in markup
with mean latency $mu = 42 "ms"$.  // math mode
#let avg = 60                      // code expression (binding)
#let threshold = 50                // `50ms` is NOT valid: `ms` is not a Typst unit
#if avg > threshold [              // code block with markup arg
  *Above threshold.*               // bold inside content arg
] else [
  Below.
]

The defining property: everything is a value, including content. [*bold text*] is a content literal you can store in a variable, pass to a function, or splice into a template. There is no separate templating layer — the language is the template engine.

Set Rules vs Show Rules

Two styling primitives, both prefixed with #:

// Set rule — change default arguments of a function for the rest of the scope
#set text(font: "New Computer Modern", size: 11pt, lang: "de")
#set page(paper: "a4", margin: 2.5cm, numbering: "1 / 1")
#set heading(numbering: "1.1")

// Show rule — intercept all instances of a target and transform them
#show heading.where(level: 1): it => block[
  #set text(weight: "bold", size: 18pt)
  Chapter #counter(heading).display(): #it.body
]
#show raw.where(block: true): it => block(
  fill: luma(245), inset: 8pt, radius: 4pt, it
)
#show regex("TODO"): it => text(red, weight: "bold", it)

#set is type-driven (applies to every text() call afterward); #show is selector-driven (with .where() filters or content selectors). Both are scoped to the enclosing block — no global mutation surprises.

Math mode uses ASCII identifiers for Greek letters and common symbols (alpha, infinity, arrow.l.r, sum, integral), with _ and ^ for sub/superscript — no \ escape sequences. Multi-char identifiers must be space- or backtick-separated.

Packages — Typst Universe

Packages live at typst.app/universe and are imported via namespace + name + version pin:

#import "@preview/cetz:0.4.2": canvas, draw            // remote, downloaded on first compile
#import "@local/my-template:0.1.0": *                   // ~/.local/share/typst/packages/local
#import "thesis.typ": template                          // relative file path

  • @preview — the only public namespace as of v0.14; the eventual @stable namespace is reserved but unused (community packages are stuck at @preview regardless of maturity).
  • @local — $XDG_DATA_HOME/typst/packages/local/<name>/<version>/. No registry; just files on disk.
  • Version pin is mandatory — @preview/cetz:0.4 won't resolve, must be exact 0.4.2. No semver ranges, no ^ or ~. This is a deliberate reproducibility choice but bites first-time users.

Notable packages — all twelve re-confirmed present in the Universe index (packages.typst.org/preview/index.json, 1,572 packages) on 2026-09-04, though their versions have moved since the May 2026 baseline: cetz 0.5.2, fletcher 0.5.8, touying 0.7.4, polylux 0.4.0, glossarium 0.5.10, glossy 0.9.2, unify 0.8.1, lilaq 0.6.0, quill 0.8.0, subpar 0.2.2, charged-ieee 0.1.4, arkheion 0.1.2:

CLI Workflow

typst compile main.typ                  # → main.pdf
typst compile main.typ 'out/{p}.png'    # rasterize, one per page ({p}/{0p}/{n}; `%p` is not a Typst template)
typst compile --format svg main.typ     # SVG output
typst compile --features html --format html main.typ   # HTML export — the feature flag is required (0.14 and 0.15)
typst watch main.typ                    # incremental rebuild on save (≪ 200 ms)
typst fonts                             # list system + embedded fonts (no positional filter exists)
typst fonts --variants | grep "Source Code Pro"    # filtering is the shell's job
typst eval 'query(<methods>)' --in main.typ        # JSON-extract labels (0.15+)
typst query main.typ "<methods>"        # still runs at 0.15.1, hidden from --help, warns deprecated

Watch mode uses incremental compilation: the compiler memoizes intermediate results in a content-addressed cache keyed by source-AST node hashes. Editing a paragraph in a 200-page thesis re-renders only the affected page band, typically under 100 ms wall-clock.

Output Formats and PDF Standards

v0.14 introduced first-class accessibility metadata and broad PDF-standard coverage. PDFs are now tagged by default (PDF/UA-1 conformance) — screen-readers can navigate by heading and figure structure. PDF/A profiles are selectable per archive requirement:

typst compile main.typ --pdf-standard a-2b    # PDF/A-2b for archival
typst compile main.typ --pdf-standard ua-1    # PDF/UA-1 accessibility
typst compile main.typ --pdf-standard a-3b    # PDF/A-3b with attachments

HTML export (--format html) is alpha: covers ~12 built-in elements (paragraphs, headings, lists, images, footnotes, bibliography, emphasis, links, code blocks with syntax highlighting), but custom elements don't round-trip. Treat it as preview, not production. 0.15.0 fixed the math half — equations are now exported to MathML automatically — but export still requires --features html, and the compiler still prints "html export is under active development and incomplete … do not rely on this feature for production use cases".

Plugin System (WebAssembly)

Typst plugins compile to WebAssembly (no WASI — pure compute, no I/O) and are loaded via plugin("path/to/plugin.wasm"). Calling convention is byte-string in, byte-string out; the host enforces a deterministic, sandboxed execution model.

#let svgbob = plugin("svgbob.wasm")
// `image.decode` was deprecated in 0.14 and REMOVED in 0.15.0 — pass the bytes to `image`
#let render(diagram) = image(svgbob.svgbob(bytes(diagram)), format: "svg")
#render("
   .---.
   | A |---> B
   '---'
")

Use cases in the wild: ASCII-to-SVG renderers, custom syntax highlighters, mermaid bridges, formula evaluators, dataframe-to-table converters. The v0.14.2 wasmi memory-growth fix specifically protects this plugin path.

Common Gotchas

  • Version pins are exact, not semver. @preview/cetz:0.4 fails with error: version number is missing patch version; you must write a full x.y.z (re-tested on 0.15.1, 2026-09-04). cetz is at 0.5.2 now, and the old 0.4.2 pin still resolves — published package versions are immutable. No upgrade story exists — bumping a package means editing the pin and re-running typst compile. There is no lockfile because there is no resolver.
  • Tagged PDFs are the new default in v0.14 — output file sizes grow 5–15% from the structure tree, and downstream tooling that scrapes PDFs may now see additional metadata. Pass --no-pdf-tags if you genuinely need untagged output. --pdf-standard none is not a valid value — the CLI rejects it on 0.14.2 and 0.15.1 alike, since the flag only accepts PDF versions (1.4…2.0) and PDF/A + PDF/UA profile names.
  • #set rules look like assignment but are scoped. #set text(size: 14pt) only affects the enclosing block and everything after, not the file globally — until you exit the block. New users frequently put a #set inside a function body expecting global effect.
  • Math mode swallows whitespace. $x + y$ is inline (no spaces around $); $ x + y $ is display. The space inside the $ delimiters changes block-vs-inline, not just whitespace. This is the #1 source of "why is my equation centered?" questions.
  • The @preview namespace is the only public namespace. Despite the name suggesting "alpha/preview" status, every package — including mature ones like cetz and touying — sits there. @stable is reserved but unused as of v0.14 — re-tested on 0.15.1 (2026-09-04), where #import "@stable/cetz:0.5.2" still fails with error: package not found. Treat @preview as the equivalent of crates.io or pypi.org, not as a beta channel.
  • Local packages must follow the directory layout strictly. ~/.local/share/typst/packages/local/<name>/<version>/typst.toml and <entrypoint>.typ. The compiler doesn't scan for Cargo.toml-style file globs; the directory name is the version.
  • HTML export is alpha and silently degrades. Equations and custom elements may render as fallback text without warning. Always inspect the HTML output rather than trusting clean compile output.
  • Plugins are sandboxed without WASI — no filesystem, no network, no clock. Plugins are pure-compute transforms only. Don't try to port a Pandoc-style filter that wants to read sibling files.
  • v0.14.2 patched a wasmi UAF triggerable on memory growth. The identifier is assigned: CVE-2025-66627 / GHSA-g4v2-cjqp-rfmq, "Critical Use-After-Free in Wasmi's Linear Memory", NVD 8.4 HIGH (CVSS:3.1/AV:L/AC:L/PR:N/UI:N/S:U/C:H/I:H/A:H, status Analyzed; GitHub labels the same advisory HIGH while its title says Critical). Typst 0.14.1 pinned wasmi 0.51.2 — inside the vulnerable range, fixed at 0.51.3 — while 0.14.2 moved to 0.51.5 and 0.15.1 ships wasmi 1.0.9. OSV lists no advisory against the typst crate itself as of 2026-09-04. If you accept .typ files from untrusted users (CI, document services, multi-tenant editors) and they can load plugins, upgrade past 0.14.1.
  • Fonts: typst resolves system fonts, an embedded set, and any --font-path directories; there is no automatic font download (unlike texlive autoinstall). The embedded set is four families — DejaVu Sans Mono, Libertinus Serif, New Computer Modern, New Computer Modern Math (typst fonts --ignore-system-fonts on 0.15.1) — which is why the "New Computer Modern" set rule above works in a bare container with no fonts installed. Bundle fonts in the project repo for reproducibility, or rely on the host's font installation.
  • #import "thesis.typ" is relative to the current file, but @preview/foo:1.0 resolves against the package cache at $XDG_CACHE_HOME/typst/packages/preview/foo/1.0/. CI workflows must pre-warm or vendor the cache directory; otherwise the first compile hits the network.
  • Math identifiers are space- or backtick-separated. $alpha beta$ is two letters; $alphabeta$ is a single multi-char identifier that must be defined. To force concatenation, use $ alpha thin beta $ or $ #[αβ] $.
  • typst watch does not detect changes through symlinks by default on Linux/macOS without inotify symlink-traversal — edit the real file path, not via a symlinked include.
