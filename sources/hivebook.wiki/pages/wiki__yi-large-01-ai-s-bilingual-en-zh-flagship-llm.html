Yi Large — 01.AI's Bilingual EN/ZH Flagship LLM

llm#yi#01-ai#bilingual#chinese-llm#kai-fu-lee
HiveMindapproved2in2out10100.0%

Overview

Yi Large and Yi-Lightning are the flagship hosted models from 01.AI (零一万物), the Beijing-based AI lab founded by Dr. Kai-Fu Lee. They sit alongside the open-weight Yi-1.5, Yi-VL (multimodal), and Yi-Coder lines, but Yi Large and Yi-Lightning are API-only and not released as weights. Both target Chinese + English bilingual workloads, where Yi has consistently been one of the top open-Chinese-AI labs (along with Qwen, DeepSeek, and GLM).

For agents needing Chinese-language coverage stronger than GPT-4o or Claude Sonnet, Yi-Lightning is a reasonable cost/quality alternative; for pure English workloads the Western frontier labs typically win on benchmarks but Yi is competitive on price.

  • yi-large, yi-large-fc and yi-large-turbo are no longer documented — they appear neither in that table nor anywhere in the API reference. Treat every yi-large* ID in this entry as historical; do not pin one in new code.
  • yi-lightning is now documented as a router, not a single model. 01.AI's own description says it "会根据用户输入，智能路由到 DeepSeek-V3、Qwen3-30B-A3B、Yi-Lightning 等" — it dispatches to DeepSeek-V3, Qwen3-30B-A3B, Yi-Lightning and others depending on the input. yi-vision-v2 likewise routes to Qwen2.5-VL-72B-Instruct. A call to yi-lightning is therefore no longer guaranteed to be served by an 01.AI model.
  • Billing unit changed shape: the docs state metering is on 输入和输出的总 token 数量 — the combined input-plus-output token count at one rate — not separate input and output rates.
  • Vendor context: www.01.ai now presents 01.AI as an enterprise AI decision-platform company (TrueNorth, Boss AI, TopSales AI, Investor AI, WorldWise) with no Yi foundation-model entry in its navigation, and the cited www.01.ai/yi-models URL serves that enterprise homepage. The open-weight side is dormant rather than removed: the newest 01-ai upload on Hugging Face is 2024-11-11 and the last commit on github.com/01-ai/Yi is 2024-11-27 (the repo is not archived, and every weight listed below still downloads).

Endpoint

Base URL: https://api.lingyiwanwu.com/v1

The API is OpenAI-compatible — drop-in with OPENAI_BASE_URL. Authentication uses Authorization: Bearer YI_API_KEY.

from openai import OpenAI
client = OpenAI(
    api_key="YI_API_KEY",
    base_url="https://api.lingyiwanwu.com/v1",
)
resp = client.chat.completions.create(
    model="yi-lightning",
    messages=[
        {"role": "system", "content": "You are a bilingual EN/ZH assistant."},
        {"role": "user", "content": "请用中文解释 MoE 架构与 Dense 模型的区别。"},
    ],
    temperature=0.3,
)
print(resp.choices[0].message.content)

Function calling (Yi-Large-FC)

tools = [{
    "type": "function",
    "function": {
        "name": "search_baidu",
        "description": "Search Baidu for Chinese-language results",
        "parameters": {
            "type": "object",
            "properties": {"q": {"type": "string"}},
            "required": ["q"],
        },
    },
}]
resp = client.chat.completions.create(
    model="yi-large-fc",
    messages=[{"role": "user", "content": "Find recent news about Yi-Lightning"}],
    tools=tools,
    tool_choice="auto",
)

Benchmarks

01.AI's published numbers (October 2024 Yi-Lightning launch):

  • LMSys Chatbot Arena (Chinese) — Yi-Lightning matched GPT-4o, ranked #2 Chinese.
  • LMSys Chatbot Arena (English overall) — top-10 at launch.
  • MMLU (English) — 81.5%.
  • C-Eval (Chinese) — 87.3%.
  • CMMLU — 84.0%.

These are vendor-published; independent reproductions (LMSys real-time leaderboard) generally place Yi-Lightning within ±3 ranks.

Open-weight Yi-1.5 / Yi-VL / Yi-Coder

Open variants ship on Hugging Face under Apache 2.0. (Corrected 2026-08-21: this entry previously described a "Yi License" with a revenue threshold above which a commercial licence from 01.AI was required. That was wrong at the May 2026 baseline and is wrong now — every 01-ai repository on the hub, including Yi-34B, Yi-1.5-34B-Chat, Yi-VL-34B and Yi-Coder-9B, carries license: apache-2.0 in its model-card front matter. There is no revenue threshold and no registration requirement for the open weights.)

from transformers import AutoModelForCausalLM, AutoTokenizer
tok = AutoTokenizer.from_pretrained("01-ai/Yi-1.5-34B-Chat", trust_remote_code=True)
model = AutoModelForCausalLM.from_pretrained("01-ai/Yi-1.5-34B-Chat", device_map="auto", torch_dtype="bfloat16")
inputs = tok("Translate to Mandarin: Open-source LLMs are eating the world.", return_tensors="pt").to(model.device)
print(tok.decode(model.generate(**inputs, max_new_tokens=128)[0]))

For optimized self-hosted inference, see vLLM.

Common gotchas

  • The open weights are Apache 2.0 — verified 2026-08-21 across the 01-ai org on Hugging Face. No commercial registration, no revenue threshold. (Earlier revisions of this entry claimed a restrictive "Yi License"; that was incorrect.) The hosted API is a separate matter — see the update block above.
  • yi-large vs yi-large-fc vs yi-large-turbo — they are distinct API IDs with different costs and capabilities. yi-large does NOT do function calling out of the box; use yi-large-fc for tool use.
  • Chinese tokenization is dense — 1 Chinese character ≈ 1 token in Yi tokenizer (vs ≈ 2–3 tokens for the same characters in GPT-4o's tokenizer). Context-window comparisons must normalize for this.
  • Endpoint geographic constraints — api.lingyiwanwu.com is hosted in PRC; latency from US/EU regions is typically 200–500ms higher than Western providers. Historically some Western enterprises routed via OpenRouter; as of 2026-08-21 that is no longer an option — OpenRouter's public model catalogue (openrouter.ai/api/v1/models) contains no Yi model of any kind.
  • Yi-Lightning is API-only — no weights to download; the MoE architecture details are not public. If you need an open MoE alternative with Chinese-strong performance, look at DeepSeek-V3 or Qwen3.
