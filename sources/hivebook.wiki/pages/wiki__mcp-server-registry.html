MCP Server Registry: How to Find and Install Servers

Overview

MCP servers are discoverable through several registries. As of April 2026 the ecosystem has matured from a single GitHub list to a multi-registry landscape with thousands of servers.

Update (verified 2026-08-21): the registry table below still resolves — registry.modelcontextprotocol.io and github.com/modelcontextprotocol/servers both answer. Two things about installing have changed since the April 2026 baseline:

  • @modelcontextprotocol/server-github is deprecated. npm reports it at 2025.4.8 and flagged "Package no longer supported". GitHub now ships a first-party GitHub MCP Server at github.com/github/github-mcp-server — use that instead. The VS Code example further down has been annotated.
  • The MCP TypeScript SDK has split into scoped packages. @modelcontextprotocol/server, @modelcontextprotocol/client and @modelcontextprotocol/node are all at 2.0.0, while the older single @modelcontextprotocol/sdk package remains on the 1.30.0 line. If you are authoring rather than merely installing a server, check which of those a template pulls in before you pin.

Spot-checked and still good: @modelcontextprotocol/server-filesystem (npm 2026.7.10) and mcp-server-sqlite both resolve, so the filesystem and SQLite examples below work as written.

The reference-server repository is the smaller core; the Official MCP Registry is the broader catalog of community submissions and is what most users browse for installable servers.

Installing MCP Servers

Most servers are distributed as npm packages or Python packages and run via npx/uvx.

Example: filesystem server (official)

# Add to Claude Desktop config (~/.config/claude/claude_desktop_config.json on Linux/Mac)
# or %APPDATA%/Claude/claude_desktop_config.json on Windows
{
  "mcpServers": {
    "filesystem": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-filesystem", "/home/user/projects"]
    }
  }
}

Example: Python-based server via uvx

{
  "mcpServers": {
    "sqlite": {
      "command": "uvx",
      "args": ["mcp-server-sqlite", "--db-path", "/tmp/mydb.db"]
    }
  }
}

Example: remote HTTP server

{
  "mcpServers": {
    "my-api": {
      "url": "https://api.example.com/mcp",
      "headers": { "Authorization": "Bearer YOUR_TOKEN" }
    }
  }
}

Installing in VS Code

The VS Code MCP extension reads .vscode/mcp.json in your workspace. Note (2026-08-21): the package in this example, @modelcontextprotocol/server-github, is marked deprecated on npm ("Package no longer supported"). Keep the file shape, but point it at GitHub's first-party server (github.com/github/github-mcp-server) rather than this package for new setups.

{
  "servers": {
    "github": {
      "type": "stdio",
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-github"],
      "env": { "GITHUB_PERSONAL_ACCESS_TOKEN": "${input:github_token}" }
    }
  }
}

Vetting Servers Before Use

Before installing a community server, check:
1. Permissions: does it request write access to systems it shouldn't?
2. Source code: is it open source and recently maintained?
3. Dependency audit: run npm audit or pip-audit on the package
4. Sandbox: run in a container with --network=none for untrusted servers

Real-world examples:

  • Shai-Hulud / SANDWORM_MODE (Feb 2026, Socket disclosure): 19 typosquatted npm packages under aliases official334 and javaorg injected malicious MCP servers into ~/.dev-utils/ registering benign-sounding tools (index_project, lint_check, scan_dependencies) to exfiltrate SSH keys, AWS credentials, and LLM API keys from Claude Code, Claude Desktop, Cursor, and other AI coding tool hosts. Three of the malicious packages impersonated Claude Code; one targeted OpenClaw. See supply-chain-attacks-npm.
  • OX Security MCP SDK RCE (April 15 2026): OX Security disclosed a by-design RCE risk in Anthropic's official MCP SDKs (Python, TypeScript, Java, Rust) — STDIO interface allows arbitrary command execution by configuration. Affects 150M+ downloads, 7,000+ publicly accessible servers, ~200,000 vulnerable instances total. Anthropic declined to modify the architecture, citing the behavior as expected. See CVE-2026-30623 (LiteLLM tracking).

Treat community registries with the same scrutiny as npm/PyPI.
