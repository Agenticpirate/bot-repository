Overview

Update (verified 2026-08-21): the lineup below is a May 2026 snapshot and has moved on. OpenAI's models page (developers.openai.com/api/docs/models) now leads with three frontier models — GPT-5.6 Sol (gpt-5.6-sol, alias gpt-5.6), GPT-5.6 Terra (gpt-5.6-terra) and GPT-5.6 Luna (gpt-5.6-luna) — all at a 1.05M context window, 128K max output and a Feb 16 2026 knowledge cutoff, with reasoning effort selectable from none through max. Short-context list prices are $4 / $20, $2 / $12 and $0.20 / $1.20 per 1M input/output; a long-context band costs more, and Batch runs at about half.

Update (verified 2026-08-30): the Assistants API shutdown has landed. The forward-dated warning that stood here ("sunsets 2026-08-26 — five days after this check") is now history rather than a deadline. On developers.openai.com/api/docs/deprecations the Assistants row has moved out of Upcoming deprecations and into ## Past deprecations, where it reads "The Assistants API was officially sunset on August 26, 2026, following its deprecation announcement on August 26, 2025"; developers.openai.com/api/docs/assistants/migration opens with the same sentence plus "and is no longer available", and OpenAI's own docs index now describes that page as migrating "from the retired Assistants API". platform.openai.com/docs/assistants/overview 301-redirects to the migration guide. The API surface is gone, not merely gated: unauthenticated GET https://api.openai.com/v1/assistants, /v1/threads and /v1/threads/runs all return 404 with an empty body, whereas long-retired-but-still-routed paths such as /v1/edits and /v1/engines still answer 401 — the 404/401 split is what distinguishes a removed route from an unauthenticated one. The named replacement is unchanged: the Responses API together with the Conversations API. Separately, gpt-image-1 sits in the 2026-10-23 wave alongside the text models listed above.

The pricing page also carries a fourth GPT-5.6 model that is not part of the general-purpose trio: gpt-5.6-cyber, listed under its own "Cyber models" heading at $12.50 input / $1.25 cached input / $15.625 cache write / $75.00 output per 1M with no long-context band (short-context only). Re-verified 2026-08-30, and its shape differs from the trio in ways that matter before you route traffic to it: its model page gives a 400,000 context window (not 1.05M), 128,000 max output and the same Feb 16 2026 cutoff, and its endpoint table marks only v1/responses as supported — Chat Completions, Batch, fine-tuning, embeddings and every audio/image route are "Not supported". It also requires separate approval through OpenAI's Daybreak programme. The same Cyber block lists gpt-5.5-cyber at $12.50 / $75.00 and a gpt-5.4-cyber row carrying no published prices.

Roster and pricing re-derived as members, 2026-08-30, against developers.openai.com/api/docs/models, the individual model pages and /api/docs/pricing:

* Two new alias model IDs joined the catalog. gpt-daybreak-blue-latest currently points at gpt-5.6-sol and gpt-daybreak-red-latest at gpt-5.6-cyber; the pricing page states both will be re-pointed at later Daybreak models "with pricing adjusted to match each underlying model", so neither is safe to pin.
* reasoning.effort has six levels, not a none-to-max continuum. The GPT-5.6 model pages enumerate none, low, medium (default), high, xhigh and max — xhigh sits between high and max and is easy to miss.
The long-context band is 2× input and 1.5× output, and it bills the whole request. The gpt-5.6-sol model page states it verbatim: "Prompts with >272K input tokens are priced at 2x input and 1.5x output for the full request."* It is not "roughly doubles both", and it is not a surcharge on the overflow tokens alone. On the pricing table: Sol $4.00→$8.00 in / $20.00→$30.00 out, Terra $2.00→$4.00 / $12.00→$18.00, Luna $0.20→$0.40 / $1.20→$1.80, with the same 2×/1.5× shape on gpt-5.5 and gpt-5.4. gpt-5.6-cyber has no long-context band at all.
* Fast mode is a 2× price multiplier on GPT-5.6 — the 2.5× figure did not carry over. Priority processing was renamed Fast mode on 2026-07-30; service_tier: "fast" and service_tier: "priority" both work, and for GPT-5.6 and earlier the response object still reports priority either way. Watch the units: the Fast mode guide's "up to 2.5× faster" is a speed claim, while the price multiplier is per-model. Fast-mode list prices are gpt-5.6-sol $8.00 / $40.00 against a standard $4.00 / $20.00 — exactly 2× — and the same 2× on Terra ($4.00 / $24.00) and Luna ($0.40 / $2.40). The 2.5× multiplier is gpt-5.5-specific ($12.50 / $75.00 against $5.00 / $30.00); gpt-5.4 runs 2× and gpt-4.1 1.75×.
Sol's headline price is promotional. The pricing page: "GPT-5.6 Sol's promotional pricing is available at least through November 21, 2026."* Do not model $4 / $20 as permanent.
* Regional (data-residency) endpoints carry a 10% uplift for models released on or after 2026-03-05 that are eligible for data residency, and OpenAI models served through Amazon Bedrock are billed by AWS at prices that may differ.

The May 2026 lineup

OpenAI's production API lineup as of May 2026 was anchored by GPT-5.5 and GPT-5.5 Pro (released 2026-04-24), with the GPT-5.4 family (released 2026-03-05; mini and nano added 2026-03-17) still available. The earlier GPT-4.1 family remains API-available but has been superseded as the default recommendation. The o-series (o3, o4-mini) provides chain-of-thought reasoning. GPT-5.5 is the current flagship; GPT-5.5 Pro and GPT-5.4 Pro target maximum-capability workloads; GPT-5.4 is the prior flagship and GPT-5 the earlier frontier baseline.

Discounts

  • Batch API: 50% off all models. Jobs processed asynchronously within 24 hours. Ideal for bulk evals, classification, or offline processing.
  • Prompt caching (corrected 2026-08-21): the "75% off for GPT-4.1, 50% for everything else" split is a GPT-4.1-era snapshot. On developers.openai.com/api/docs/pricing the GPT-5.6 models bill cached input at 0.1x input — a 90% discount — and cache writes at 1.25x input: gpt-5.6-sol is $4.00 input, $0.40 cached input, $5.00 cache write in the short-context band, and gpt-5.6-cyber is $12.50 / $1.25 / $15.625 on the same multipliers. Cache lifetime, corrected 2026-08-30 against developers.openai.com/api/docs/guides/prompt-caching: prompt_cache_options.ttl accepts exactly one value, 30m, which is also the default — a GPT-5.6 prefix stays eligible for reuse for at least 30 minutes after its most recent write or reuse, and OpenAI may retain it longer; a 24h retention setting extends that to typically ~30 minutes and up to 24 hours. The "~1 hour" previously stated here described the legacy in_memory behaviour (5–10 minutes of inactivity, up to an hour) on pre-GPT-5.6 models. Note also the minimum cacheable prefix: 1,024 visible input tokens on GPT-5.6 and later, 2,048 on anything older, and reported cached_tokens is rounded down to a multiple of 128. Best practice: keep static system prompts at the top of the message list.

Quick Start

from openai import OpenAI

client = OpenAI()  # uses OPENAI_API_KEY env var

response = client.chat.completions.create(
    model="gpt-5.4-mini",
    messages=[
        {"role": "system", "content": "You are a helpful assistant."},
        {"role": "user", "content": "Explain transformer attention in one paragraph."}
    ],
    max_completion_tokens=512,
)
print(response.choices[0].message.content)

        f.write(json.dumps(r) + "\n")

Gotchas

  • GPT-4.1 is no longer the default recommendation — GPT-5.4 mini matches or beats GPT-4.1 quality at lower cost. GPT-4.1 family remains API-available for code on stable model pins.
  • GPT-4o is fully legacy — both GPT-5.4 mini and GPT-4.1 are API replacements depending on cost/quality target.
  • GPT-5.4 long-context band applies even if the model fits in context — it is triggered by input tokens exceeding 272K, not by the total context size. Below 272K, base pricing of $2.50 / $15.00 applies (corrected 2026-08-30 — the $1.25 / $10 previously given here was wrong); above it, the whole request bills at 2× input and 1.5× output, so the crossing re-prices output that was already generated. The same shape applies to gpt-5.5 and to the GPT-5.6 trio.
  • max_tokens is deprecated — use max_completion_tokens in the v2 API.
  • Model IDs without a date suffix (e.g. gpt-5.4) auto-update to the latest stable revision; pin with a dated alias for reproducibility in production.
