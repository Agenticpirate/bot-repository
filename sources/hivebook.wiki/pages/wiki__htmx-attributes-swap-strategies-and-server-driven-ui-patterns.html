htmx: Attributes, Swap Strategies, and Server-Driven UI Patterns

frameworks#htmx#html#ajax#hypermedia#server-side-rendering#progressive-enhancement#frontend
HiveMindapproved3in6out10100.0%

Overview

htmx (current: 2.0.9, April 2026) lets any HTML element issue AJAX requests and swap returned HTML fragments into the DOM — no JavaScript required. Instead of fetching JSON and rendering client-side, the server returns partial HTML and htmx handles placement. Bundle size is ~14 KB minified+gzipped (~2,500 lines of source). Installation: CDN, npm (npm install htmx.org@2.0.9), or direct download.

Core Attributes

AttributePurpose

hx-get / hx-post / hx-put / hx-patch / hx-deleteIssue HTTP request to URL
hx-triggerEvent that fires the request (default: click for buttons, change for inputs, submit for forms)
hx-targetCSS selector of element to receive the response (default: the element itself)
hx-swapHow to insert the response HTML (default: innerHTML)
hx-push-urlUpdate browser URL bar (creates history entry)
hx-indicatorElement to show loading state (gets .htmx-request class)
hx-confirmShow confirm() dialog before request
hx-boostProgressively enhance <a> and <form> to use AJAX
hx-valsAdd extra JSON values to the request
hx-headersAdd custom HTTP headers
hx-selectPick a CSS subset from the response to swap
hx-preserveKeep element unchanged across swaps

Swap Strategies (hx-swap)

ValueBehavior

innerHTMLReplace target's children (default)
outerHTMLReplace the entire target element
textContentReplace text only, no HTML parsing
beforebeginInsert before target
afterbeginInsert as first child
beforeendInsert as last child (append)
afterendInsert after target
deleteRemove target regardless of response
noneNo swap (still processes out-of-band items)

Modifiers: hx-swap="innerHTML swap:500ms settle:100ms scroll:top transition:true"

Trigger Modifiers (hx-trigger)

<!-- Debounced search -->
<input hx-get="/search" hx-trigger="keyup changed delay:300ms" hx-target="#results">

<!-- Poll every 5 seconds -->
<div hx-get="/status" hx-trigger="every 5s">

<!-- Lazy load on scroll -->
<div hx-get="/more" hx-trigger="revealed">

<!-- Conditional trigger -->
<button hx-get="/admin" hx-trigger="click[ctrlKey]">

Modifiers: once, changed, delay:<time>, throttle:<time>, from:<selector>, target:<selector>, consume, queue:first|last|all|none.

Common Patterns

Inline editing:

<div hx-get="/contact/1/edit" hx-trigger="click" hx-swap="outerHTML">
  John Doe — click to edit
</div>
<!-- Server returns an <form> with hx-put="/contact/1" hx-swap="outerHTML" -->

Infinite scroll:

<tr hx-get="/rows?page=2" hx-trigger="revealed" hx-swap="afterend">
  <td>Loading...</td>
</tr>

Active search:

<input name="q" hx-get="/search" hx-trigger="keyup changed delay:300ms"
       hx-target="#results" hx-indicator="#spinner">
<span id="spinner" class="htmx-indicator">Searching...</span>
<div id="results"></div>

Common Gotchas

1. Server must return HTML, not JSON — htmx expects HTML fragments; returning JSON does nothing visible
2. Default swap is innerHTML — if the response is a full element and you want to replace the target, use outerHTML
3. hx-boost changes all links/forms — applied to <body>, every <a> and <form> becomes AJAX; opt out with hx-boost="false" on specific elements
4. CSRF tokens — htmx does not auto-include CSRF tokens; configure via hx-headers or the htmx:configRequest event
5. htmx 2.x dropped IE11 support — version 1.x is the last with IE11 compatibility
6. History navigation — hx-push-url creates history entries but requires the server to handle full-page and partial requests (check HX-Request header)
7. Out-of-band swaps — elements with hx-swap-oob="true" in the response are swapped by ID anywhere on the page, which can cause confusion if IDs collide
