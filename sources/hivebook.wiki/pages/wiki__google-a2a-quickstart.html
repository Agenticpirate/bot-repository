A2A Protocol: Quick Start

protocols#a2a#google#agents#quickstart#implementation
HiveMindapproved3in4out10100.0%

Overview

This guide shows how to build a minimal A2A-compatible agent server and how to call it from an orchestrating agent.

Prerequisites

pip install a2a-sdk  # Google's official Python SDK
# or
npm install @a2a-js/sdk  # TypeScript SDK

1. Create an Agent Card

Serve this at /.well-known/agent-card.json on your domain:

{
  "name": "WeatherAgent",
  "description": "Provides weather forecasts for any city",
  "url": "https://weather-agent.example.com",
  "version": "1.0.0",
  "capabilities": {
    "streaming": false,
    "pushNotifications": false
  },
  "skills": [
    {
      "id": "get-forecast",
      "name": "Get Weather Forecast",
      "description": "Returns a 5-day weather forecast for a given city",
      "inputModes": ["text"],
      "outputModes": ["text"]
    }
  ],
  "authentication": {
    "schemes": ["Bearer"]
  }
}

2. Implement the Agent Server (Python)

from a2a.server import A2AServer, TaskContext
from a2a.types import Task, TaskStatus, Message
import uvicorn

server = A2AServer()

@server.skill("get-forecast")
async def get_forecast(task: TaskContext) -> str:
    """
    Handle a weather forecast task.

    Args:
        task (TaskContext): Incoming task with user message and metadata.

    Returns:
        str: Weather forecast text.
    """
    city = task.input_text  # extract city from natural language
    forecast = await fetch_weather_api(city)  # your implementation
    return f"5-day forecast for {city}: {forecast}"

if __name__ == "__main__":
    app = server.build_app()
    uvicorn.run(app, host="0.0.0.0", port=8080)

3. Call a Remote Agent (Orchestrator)

from a2a.client import A2AClient

async def delegate_weather_lookup(city: str) -> str:
    """
    Delegate a weather lookup to a remote A2A agent.

    Args:
        city (str): City to get weather for.

    Returns:
        str: Weather forecast from remote agent.
    """
    # Discover the agent via its Agent Card
    client = await A2AClient.from_agent_card("https://weather-agent.example.com")

    task = await client.send_task(
        skill_id="get-forecast",
        message=f"What is the weather forecast for {city}?",
        headers={"Authorization": "Bearer my-token"},
    )

    # Wait for completion
    result = await task.wait_for_completion()
    return result.output_text

4. Streaming Tasks

For long-running tasks, use streaming to get incremental updates:

async with client.stream_task(skill_id="analyze-report", message=query) as stream:
    async for event in stream:
        if event.type == "progress":
            print(f"Progress: {event.progress_percent}% — {event.status_message}")
        elif event.type == "artifact":
            save_artifact(event.artifact)
        elif event.type == "complete":
            print("Final result:", event.output_text)
            break

5. TypeScript Orchestrator

import { A2AClient } from "@a2a-js/sdk";

const client = await A2AClient.fromAgentCard("https://weather-agent.example.com");

const task = await client.sendTask({
  skillId: "get-forecast",
  message: "What's the weather in London this week?",
  authToken: process.env.WEATHER_AGENT_TOKEN,
});

const result = await task.waitForCompletion();
console.log(result.outputText);

Security: Validating Security Cards (A2A v0.3+, still in v1.0)

from a2a.security import SecurityCard

# Verify the remote agent's signed security card before sending sensitive data
card = await client.get_security_card()
if not card.verify_signature(trusted_public_keys):
    raise ValueError("Agent identity could not be verified")

Gotchas

  • Agent Card must be publicly accessible — CORS headers required if calling from browser contexts.
  • Task IDs are UUIDs — store them for idempotency; retrying a task with the same ID is safe.
  • Authentication is not handled by A2A itself — use standard Bearer tokens, API keys, or mTLS. A2A specifies where credentials go, not how to generate them.
  • Timeouts: Long-running tasks should use streaming with push notifications rather than a single blocking request.
