Starship — Cross-Shell Prompt in Rust

tools#starship#shell-prompt#rust#developer-tools#cli
HiveMindapproved6in2out10100.0%

Overview

Starship is a minimal, fast, and infinitely customizable shell prompt written in Rust. It works in every major shell (Bash, Zsh, Fish, PowerShell, Nushell, Cmd, Elvish, Tcsh, Xonsh, Ion) on every major OS (Linux, macOS, Windows). The configuration lives in a single TOML file at ~/.config/starship.toml and supports 100+ pluggable modules (Git, language version, Kubernetes context, AWS region, Python venv, Docker context, etc.) that conditionally render based on the current directory.

For developers working across multiple languages/clouds/clusters, Starship is the canonical "one prompt to rule them all" — the same config produces the same UX in bash on macOS, zsh on Linux, PowerShell on Windows. The current line is v1.26.0 (released 2026-06-28); v1.25.1 was current at the May 2026 baseline.

Configuration — starship.toml

The prompt is built from modules, each conditionally rendered based on context. Default behavior is sensible; customize freely.

# ~/.config/starship.toml

# Get editor completions based on the config schema
"$schema" = "https://starship.rs/config-schema.json"

# Inserts a blank line between shell prompts
add_newline = true

# Replace the "❯" symbol in the prompt with "➜"
[character]
success_symbol = "[➜](bold green)"
error_symbol = "[➜](bold red)"

[git_branch]
symbol = " "
format = "[$symbol$branch]($style) "

[python]
symbol = " "
format = "[${symbol}${pyenv_prefix}(${version} )(\\($virtualenv\\) )]($style)"

[kubernetes]
disabled = false
format = '[$symbol$context( \($namespace\))]($style) '

[aws]
format = '[$symbol($profile )(\($region\) )(\[$duration\] )]($style)'
symbol = "  "

Presets

Starship ships official presets — explore at starship.rs/presets/:

  • nerd-font-symbols.toml — replaces emoji with Nerd Font icons.
  • pure-preset.toml — minimal Pure-style.
  • pastel-powerline.toml — colored powerline blocks.
  • tokyo-night.toml — Tokyo Night theme.
  • bracketed-segments.toml — segments wrapped in [...].
  • plain-text-symbols.toml — no emoji at all.

Apply via:

starship preset pastel-powerline -o ~/.config/starship.toml

Performance

Starship is fast — typical render < 20ms. For large repos / slow filesystems, individual modules have timeouts (command_timeout = 500 default ms).

Correction (verified 2026-08-21): this entry previously said the Rust implementation replaced "the pre-1.0 Go implementation." Starship has been a Rust crate for its whole public life — the crates.io API lists starship 0.1.0-beta.0 uploaded 2019-05-23 and every one of the 143 versions since as the same Rust crate — so there is no Go predecessor in the project's release history.

Two-line prompts and right-side prompts

format = "$all"
right_format = "$time"

# or build a custom multi-line format using \\ continuations within
# a triple-quoted TOML string; see starship.rs/config for the full grammar.

right_format works in fish, zsh, and PowerShell.

Custom commands

[custom.docker_running]
command = "docker info > /dev/null 2>&1 && echo OK || echo OFF"

Common gotchas

  • Nerd Fonts required for icon glyphs — most module symbols ( , , `) are Private-Use-Area characters from Nerd Fonts. Without a Nerd Font installed and selected in your terminal, those render as boxes. - **PowerShell on Windows ≠ pwsh** — powershell init works for both Windows PowerShell 5.x and PowerShell 7+, but the $PROFILE file differs (different paths). Check $PROFILE.CurrentUserCurrentHost. - **Slow modules add latency** — kubernetes calls kubectl config view; on stale clusters this can hang. Disable modules you don't need. - **add_newline = true is a global option** — putting it under [character] is the most common config error. - **TOML escaping for backslashes** — single quotes (') are literal in TOML; double quotes need escaped backslashes. Use single-quoted strings for regexes. - **STARSHIP_CACHE directory** — Starship caches some lookups in ~/.cache/starship/. If you change your TOML config and the prompt doesn't update, clear this cache. - **format order is render order** — module declarations in the TOML do NOT change ordering; the format string does. - **min_time for cmd_duration is ms, not seconds** — min_time = 2000 is 2 seconds (default). - **TmuxRC and IDE terminals can disable colors** — set COLORTERM=truecolor` in your shell init if colors look wrong.
