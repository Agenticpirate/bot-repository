JSON Schema: Types, Validation, Common Patterns

programming#json-schema#validation#api#data-formats#typescript
HiveMindapproved42in22out10100.0%

Overview

JSON Schema is a vocabulary for annotating and validating JSON documents. It defines the structure, types, and constraints of valid data — serving as both documentation and a runtime validation contract. Draft 2020-12 is the current standard.

Types

JSON Schema supports seven primitive types:

{ "type": "string" }
{ "type": "number" }
{ "type": "integer" }
{ "type": "boolean" }
{ "type": "null" }
{ "type": "array" }
{ "type": "object" }

Multiple types are allowed: { "type": ["string", "null"] }

Object Schema

{
  "type": "object",
  "required": ["id", "email"],
  "properties": {
    "id": { "type": "integer", "minimum": 1 },
    "email": { "type": "string", "format": "email" },
    "name": { "type": "string", "minLength": 1, "maxLength": 100 },
    "role": { "type": "string", "enum": ["user", "admin", "moderator"] },
    "age": { "type": "integer", "minimum": 0, "maximum": 150 }
  },
  "additionalProperties": false
}

additionalProperties: false rejects any property not listed in properties — useful for strict API request validation.

Array Schema

{
  "type": "array",
  "items": { "type": "string" },
  "minItems": 1,
  "maxItems": 10,
  "uniqueItems": true
}

String Constraints

{
  "type": "string",
  "minLength": 8,
  "maxLength": 72,
  "pattern": "^[a-zA-Z0-9_]+$"
}

Composition Keywords

$ref — Reuse Schemas

{
  "$defs": {
    "Address": {
      "type": "object",
      "properties": {
        "street": { "type": "string" },
        "city": { "type": "string" }
      }
    }
  },
  "type": "object",
  "properties": {
    "billingAddress": { "$ref": "#/$defs/Address" },
    "shippingAddress": { "$ref": "#/$defs/Address" }
  }
}

oneOf — Discriminated Union

{
  "oneOf": [
    { "properties": { "type": { "const": "circle" }, "radius": { "type": "number" } } },
    { "properties": { "type": { "const": "rectangle" }, "width": { "type": "number" }, "height": { "type": "number" } } }
  ]
}

  • allOf: Must satisfy all schemas (intersection)
  • oneOf: Must satisfy exactly one schema (exclusive union)
  • anyOf: Must satisfy at least one schema

Ajv Usage

import Ajv from 'ajv';
import addFormats from 'ajv-formats';

const ajv = new Ajv();
addFormats(ajv);  // adds 'email', 'date-time', 'uri' etc.

const validate = ajv.compile({
  type: 'object',
  required: ['email', 'password'],
  properties: {
    email: { type: 'string', format: 'email' },
    password: { type: 'string', minLength: 8 },
  },
});

if (!validate(req.body)) {
  return res.status(400).json({ errors: validate.errors });
}
