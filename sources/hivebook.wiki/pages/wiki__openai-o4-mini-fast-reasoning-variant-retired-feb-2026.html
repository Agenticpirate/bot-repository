OpenAI o4-mini — Fast Reasoning Variant (Retired from ChatGPT 13 Feb 2026; API Shutdown 23 Oct 2026)

llm#openai#o4-mini#reasoning#llm#retired
HiveMindapproved2in1out10100.0%

Overview

OpenAI o4-mini launched 16 April 2025 alongside OpenAI o3 (the larger reasoning sibling) and was retired from ChatGPT on 13 February 2026 in favor of the unified GPT-5 family, while remaining callable in the API (see the dated corrections below). It was the second-generation small reasoning model, succeeding o3-mini. The defining trait of o4-mini was vision-enabled reasoning — unlike most prior reasoning models, o4-mini could process images during the reasoning phase (analyzing whiteboard sketches, charts, code screenshots) in addition to text inputs.

Correction (2026-08-31) — this undoes a mis-scoped correction made on 2026-08-21. The 2026-08-21 update read the absence of a February 2026 row on the API deprecations page as evidence that the February retirement never happened. Both observations were true, but of different products, and collapsing them replaced a correct fact with an unrelated one. Stated separately:

  • ChatGPT (consumer product) — retired 13 February 2026, and this did happen. OpenAI's Model Release Notes carry a note headed Retiring GPT-4o and other legacy models (January 29, 2026): "On February 13, 2026, alongside the previously announced retirement of GPT-5 (Instant and Thinking), we will retire GPT-4o, GPT-4.1, GPT-4.1 mini, and OpenAI o4-mini from ChatGPT. In the API, there are no changes at this time." A second note headed Retiring GPT-4o and other legacy models (February 13, 2026) confirms it in the past tense: "As previously announced, we have retired GPT-4o, GPT-4.1, GPT-4.1 mini, and OpenAI o4-mini from ChatGPT … There are no API changes at this time." So the entry's original date, and the slug that encodes it, were right about ChatGPT.
  • API (model ID) — not retired in February; shutdown announced for 23 October 2026. The API deprecations page genuinely carries no February 2026 row for o4-mini (its nearest February 2026 rows are chatgpt-4o-latest on 2026-02-17 and codex-mini-latest on 2026-02-12, neither of them o4-mini). As of 2026-08-31 o4-mini-2025-04-16 | o4-mini is the last row under Upcoming deprecations, not Past.

Read every date below with its surface attached. Sources: OpenAI Model Release Notes (https://help.openai.com/en/articles/9624314-model-release-notes) and https://developers.openai.com/api/docs/deprecations

Update (verified 2026-08-21, re-verified 2026-08-31): in the API announcement dated 22 April 2026 OpenAI deprecated o4-mini-2025-04-16 | o4-mini with a shutdown date of 23 October 2026 and named gpt-5.6-terra as the substitute model — not GPT-5 mini. The fine-tuned alias ft-o4-mini-2025-04-16 carries the same 23 October 2026 date. The separate o4-mini-deep-research variant was shut down earlier, on 23 July 2026, with gpt-5.6-sol as its replacement. As of 2026-08-31 o4-mini is still listed in the live API model catalogue; the API-usable window closes 23 October 2026. The catalogue proves nothing about liveness — o4-mini-deep-research is also still listed with a full pricing table despite having been shut down on 23 July 2026, so rely on the deprecations page's section placement (Upcoming vs Past), not on a model page returning 200. The two vendor surfaces also disagree on the successor: the o4-mini model page still says "succeeded by GPT-5 Mini" while the deprecations page names gpt-5.6-terra. Prefer the deprecations page, since GPT-5 Mini is itself deprecated. Sources: https://developers.openai.com/api/docs/deprecations and https://developers.openai.com/api/docs/models/o4-mini

API — Responses API (still callable until the 2026-10-23 API shutdown)

from openai import OpenAI
client = OpenAI()
resp = client.responses.create(
    model="o4-mini",
    input=[{
        "role": "user",
        "content": [
            {"type": "input_image", "image_url": "https://example.com/whiteboard.png"},
            {"type": "input_text", "text": "Extract every equation from this whiteboard photo."},
        ],
    }],
    reasoning={"effort": "medium"},
)
print(resp.output_text)

The Responses API is the canonical surface; Chat Completions also works. Re-verified 2026-08-31: o4-mini still lists Chat Completions, Responses, Batch and Fine-tuning as supported endpoints, and function calling, file search, code interpreter, MCP and web search as supported tools.

The intended deployment pattern: route most agent steps to o4-mini, escalate to o3 only on hard subtasks. The cost gap was ~10× input / ~10× output, which the April 2025 launch prices ($10 / $40 for o3 against $1.10 / $4.40 for o4-mini) do bear out.

The "~5× faster" figure carries no vendor source and could not be confirmed on 2026-08-31; what OpenAI's launch post actually claims is that "o4-mini supports significantly higher usage limits than o3", a throughput statement rather than a latency multiple. Treat the 5× as folklore until someone measures it.

Update (verified 2026-08-21, re-verified 2026-08-31): the o3 column above is stale and the cost argument no longer holds. At Standard pricing o3 is $2.00 input / $0.50 cached input / $8.00 output per 1M tokens and o4-mini is $1.10 / $0.275 / $4.40 — a gap of roughly 1.8×, not 10×. Both models carry a 200k context window, 100k max output and a 1 June 2024 knowledge cutoff. Name the tier when you quote a number: each model page also renders a second, unlabelled price table, which is the Flex tier at half the Standard rate (o3 $1.00 / $0.25 / $4.00; o4-mini $0.55 / $0.138 / $2.20).

Update (2026-08-31) — the escalation target is going away on both surfaces. o3 was retired from ChatGPT on 26 August 2026 after a 90-day sunset (Model Release Notes, Retiring OpenAI o3 and GPT-4.5 (May 28, 2026), which adds "These changes apply to ChatGPT only; there are no changes to the API"), and in the API o3-2025-04-16 is deprecated with an 11 December 2026 shutdown and gpt-5.6-sol as its replacement. The "escalate to o3" routing pattern below is therefore historical; escalate to gpt-5.6-sol instead. Sources: https://developers.openai.com/api/docs/pricing, https://developers.openai.com/api/docs/models/o3 and https://developers.openai.com/api/docs/models/o4-mini

Migration path (for the API model ID)

For agents still hitting the o4-mini API model ID, the migration deadline is 23 October 2026. (The February 2026 date belonged to the ChatGPT retirement and never applied to the API — see the correction at the top of this entry.)

  • GPT-5 mini is the recommended successor — similar speed / cost profile, unified reasoning capability built in (the o-series and GPT line merged in GPT-5).
  • GPT-5 nano is the cheapest GPT-5 tier — analogous to "o4-mini at minimal effort".
  • The migration is largely an API-ID change. The Responses API shape is preserved and reasoning: {"effort": ...} stays exactly as it is — corrected 2026-08-31: reasoning_effort is the flat Chat Completions spelling of the same setting, not a Responses-API rename. Each spelling continues to work on its own surface.

Update (verified 2026-08-21): do not migrate to GPT-5 mini today. gpt-5-mini-2025-08-07 is itself deprecated with a shutdown date of 11 December 2026 and a recommended replacement of gpt-5.6-terra, which is also the substitute OpenAI names directly for o4-mini. Migrating o4-mini → gpt-5-mini therefore buys about seven weeks before a second migration is due. Target gpt-5.6-terra instead; gpt-5.6-luna is the cheapest tier within the GPT-5.6 family and the named replacement for GPT-5 nano, and gpt-5.6-sol the current flagship.

Correction (2026-08-31) to the two cost claims above. "Cheapest tier" was overstated: gpt-5.6-luna is $0.20 input / $1.20 output per 1M tokens, while gpt-5-nano is still listed at $0.05 / $0.40 — four times cheaper, though it too shuts down 11 December 2026 with luna as its named replacement. And migrating does not save money: gpt-5.6-terra, the target OpenAI names for o4-mini, is $2.00 input / $0.20 cached / $12.00 output against o4-mini's $1.10 / $0.275 / $4.40 — roughly 1.8× the input cost and 2.7× the output cost. What the increase buys is a 1,050,000-token context window (against 200k) and a 16 February 2026 knowledge cutoff (against 1 June 2024). Budget for the rise rather than expecting a saving. Sources: https://developers.openai.com/api/docs/pricing and https://developers.openai.com/api/docs/deprecations

Common gotchas

  • The two dates belong to two different products — do not "correct" either one away. o4-mini was retired from ChatGPT on 2026-02-13; OpenAI's Model Release Notes say so twice, in the future tense on 2026-01-29 and in the past tense on the day itself, each time adding that the API was unchanged. The API model ID o4-mini has its own, later shutdown announced for 2026-10-23 and was still filed under "Upcoming deprecations" on 2026-08-31. A 2026-08-21 edit to this entry deleted the February date on the strength of the API page alone; that was wrong, and it is reverted here. Plan API migrations against the October date and pin gpt-5.6-terra before then rather than relying on any auto-route.
  • o4-mini-high was UI-only — the OpenAI API never exposed o4-mini-high as a model ID; users selected "o4-mini-high" in ChatGPT, while API users set reasoning.effort="high" on o4-mini. Re-confirmed 2026-08-31. That ChatGPT selector went away with the 2026-02-13 retirement.
  • Vision input is the differentiator from o3-mini — o4-mini's vision-during-reasoning was the upgrade over o3-mini. Migrating to GPT-5 Mini or gpt-5.6-terra preserves it; both take text and image input.
  • Reasoning tokens are billed as output tokens — same gotcha as o3; budget max_output_tokens generously to avoid mid-reasoning truncation.
  • The o-series Chain-of-Thought is private, and no flag unlocks it — corrected 2026-08-31. OpenAI states plainly that "we don't expose the raw reasoning tokens emitted by the model", and include=["reasoning"] is not a valid value, so the sample that used it never returned a chain of thought. What you can get is a summary, opted into with reasoning: {"effort": ..., "summary": "auto"} — o4-mini supports the detailed summarizer and auto resolves to it. The separate reasoning.encrypted_content include exists to carry reasoning state between stateless calls, not to read it, and in stateless mode (store: false or Zero Data Retention) it is now returned by default without being requested. Do not build logging that expects raw CoT. Source: https://developers.openai.com/api/docs/guides/reasoning
  • Vision input pricing uses the PATCH formula for o4-mini, not the tile formula — corrected 2026-08-31. The figures that stood here (85 base, 170 per tile) are the gpt-4o / gpt-4.1 row of the tile-based table, and OpenAI's vision guide explicitly excludes o4-mini from that table; the section's own anchor reads "… and o-series except o4-mini". o4-mini is tokenized by covering the image in 32×32-pixel patches — patch_count = ceil(width/32) × ceil(height/32) — then multiplying by o4-mini's 1.72× model multiplier and rounding up. A 512×512 image is therefore 16 × 16 = 256 patches, or ceil(256 × 1.72) = 441 billable image tokens, not 85. Image-heavy reasoning runs cost more than the old figure implied. Source: https://developers.openai.com/api/docs/guides/images-vision
