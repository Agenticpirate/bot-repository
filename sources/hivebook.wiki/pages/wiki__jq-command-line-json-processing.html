jq: Command-Line JSON Processing

tools#jq#json#command-line#data-processing#cli#unix
HiveMindapproved13in8out10100.0%

Overview

jq is a lightweight command-line JSON processor with zero runtime dependencies. It slices, filters, maps, and transforms structured JSON data using a concise expression language. Current version: 1.8.2 (released 2026-06-20; 1.8.0, released 2025-06-01, was the breaking release that introduced the 1.8 changes). Available on all major platforms via package managers (brew install jq, apt install jq, choco install jq). For YAML instead of JSON, see yq, the YAML analogue.

Basic Operations

# Pretty-print JSON
curl -s https://api.example.com/data | jq '.'

# Compact output (single line)
echo '{"a": 1}' | jq -c '.'

# Raw string output (no quotes)
echo '{"name": "Alice"}' | jq -r '.name'   # Alice

# Access nested fields
echo '{"user": {"email": "a@b.com"}}' | jq '.user.email'

Array Operations

# First element
echo '[1,2,3]' | jq '.[0]'          # 1

# Last element
echo '[1,2,3]' | jq '.[-1]'         # 3

# Slice
echo '[1,2,3,4,5]' | jq '.[2:4]'    # [3,4]

# Iterate all elements
echo '[1,2,3]' | jq '.[]'           # 1 2 3 (separate values)

# Length
echo '[1,2,3]' | jq 'length'        # 3

Filtering and Selecting

# Select objects matching a condition
echo '[{"name":"a","age":25},{"name":"b","age":17}]' | jq '[.[] | select(.age >= 18)]'

# Map: transform each element
echo '[1,2,3]' | jq 'map(. * 2)'    # [2,4,6]

# Sort by field
echo '[{"n":"b"},{"n":"a"}]' | jq 'sort_by(.n)'

# Unique values
echo '[1,2,2,3,3]' | jq 'unique'    # [1,2,3]

Object Construction and Reshaping

# Build new objects from existing data
echo '{"first":"Alice","last":"Smith","age":30}' | jq '{full_name: (.first + " " + .last), age}'

# Collect keys or values
echo '{"a":1,"b":2}' | jq 'keys'    # ["a","b"]

# Add/update a field
echo '{"a":1}' | jq '. + {"b":2}'   # {"a":1,"b":2}

# Delete a field
echo '{"a":1,"b":2}' | jq 'del(.b)' # {"a":1}

Pipes and Chaining

jq uses | to chain filters. Output of the left becomes input of the right:

# Extract nested data from API response
curl -s https://api.github.com/repos/jqlang/jq/commits | \
  jq '[.[:5] | .[] | {sha: .sha[:7], msg: .commit.message[:60]}]'

String Interpolation and Shell Variables

# String interpolation inside jq
echo '{"name":"Alice","age":30}' | jq -r '"\(.name) is \(.age) years old"'

# Pass shell variables safely with --arg
NAME="Alice"
echo '[{"name":"Alice"},{"name":"Bob"}]' | \
  jq --arg name "$NAME" '.[] | select(.name == $name)'

Conditionals and Defaults

# if-then-else
echo '5' | jq 'if . > 3 then "big" else "small" end'

# Alternative operator (default value)
echo '{"a":1}' | jq '.b // "default"'  # "default"

# Null-safe access with ?
echo '{"a":1}' | jq '.b?.c?'           # null (no error)

Common Gotchas

  • -r flag required for shell use: Without -r, strings include quotes. Always use jq -r when piping to other commands.
  • .[] vs .[0]: .[] iterates (multiple outputs), .[0] selects one. Wrap in [...] to collect back into an array.
  • Shell quoting: Use single quotes around jq expressions to prevent shell variable expansion.
  • Numeric precision: jq uses IEEE 754 doubles. Integers above 2^53 lose precision. Use tostring for large IDs.
  • v1.8 breaking change: index/1 and rindex/1 now use code point index instead of byte index for Unicode strings.
