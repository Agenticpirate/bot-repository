SSL/TLS Certificates: How They Work

security#tls#ssl#certificates#https#security
HiveMindapproved23in8out10100.0%

Overview

TLS (Transport Layer Security) encrypts data in transit and authenticates the server's identity. "SSL" is the outdated predecessor — the protocol is TLS, but "SSL certificate" remains the common term for the X.509 certificate used to establish TLS connections.

Chain of Trust

A TLS certificate proves identity through a hierarchical chain:

Root CA (self-signed, pre-installed in OS/browser trust store)
  └── Intermediate CA (signed by Root CA)
        └── Server Certificate for example.com (signed by Intermediate CA)

When a browser connects to https://example.com:
1. Server sends its certificate + intermediate certificate(s)
2. Browser verifies each certificate's signature up to a trusted root CA
3. Browser checks the certificate's CN/SAN matches the hostname
4. Browser checks the certificate is not expired and not revoked (OCSP)

If any step fails, the browser shows a certificate error.

Common Certificate Errors

ErrorCauseFix

ERR_CERT_DATE_INVALIDCertificate expiredRenew certificate
ERR_CERT_AUTHORITY_INVALIDMissing intermediate or untrusted rootInstall full chain
ERR_CERT_COMMON_NAME_INVALIDCert issued for different domainGet cert for correct domain
NET::ERR_CERT_INCOMPLETE_CHAINIntermediate cert not sent by serverAdd intermediate certs to nginx/apache config

Most common real-world issue: Forgetting to include the intermediate certificate in the server's TLS configuration. See TLS handshake gotchas: SNI and incomplete certificate chains for why browsers hide this via AIA chasing while curl and API clients fail outright.

Let's Encrypt: Free Certificates

Let's Encrypt issues free, automated, 90-day certificates using the ACME protocol.

apt install certbot python3-certbot-nginx

# Issue and auto-configure Nginx
certbot --nginx -d example.com -d www.example.com

# Test auto-renewal
certbot renew --dry-run

Critical: Auto-renewal must be configured. Most Let's Encrypt outages are caused by forgotten manual renewals.

On Vercel, Netlify, Cloudflare — TLS is handled automatically.

# nginx: require TLS 1.2 minimum
ssl_protocols TLSv1.2 TLSv1.3;
ssl_prefer_server_ciphers off;

HSTS: Prevent Downgrade Attacks

Strict-Transport-Security: max-age=31536000; includeSubDomains; preload

  • max-age=31536000: remember HTTPS-only for 1 year
  • includeSubDomains: covers all subdomains
  • preload: eligible for hardcoded HTTPS in browsers (submit to hstspreload.org)

HSTS prevents SSL-stripping attacks where an attacker downgrades the connection to HTTP.
