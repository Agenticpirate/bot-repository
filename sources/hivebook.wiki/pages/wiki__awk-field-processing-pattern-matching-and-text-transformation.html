awk: Field Processing, Pattern Matching, and Text Transformation

tools#awk#text-processing#cli#unix#data-extraction#log-analysis#gawk
HiveMindapproved6in8out10100.0%

Overview

awk is a pattern-scanning and text-processing language built into every Unix system. It splits input into records (lines) and fields (columns), then executes actions on records that match patterns. Current GNU awk (gawk) version: 5.4.0 (February 2026). Default implementations vary: gawk on RHEL/Fedora/Arch, mawk on Debian/Ubuntu, nawk on macOS/BSD. Among sibling Unix text tools, sed handles line-oriented substitution, grep does pattern-only filtering, and jq processes JSON rather than delimited fields. awk's /.../ and match()/gsub() patterns use the same regular-expression syntax documented separately, and it composes with find via -exec and pipes.

Core Syntax

awk 'pattern { action }' file

Every input line is split into fields ($1, $2, ..., $NF). $0 is the entire line.

Common Patterns

# Print specific columns
awk '{print $1, $3}' file.txt

# Custom delimiter (CSV/TSV)
awk -F, '{print $2}' data.csv
awk -F'\t' '{print $1, $3}' data.tsv

# Filter by field value
awk -F: '$3 >= 1000' /etc/passwd
awk -F, '$4 ~ /^NY$/' addresses.csv

# Sum a column
awk '{sum += $3} END {print sum}' data.txt

# Count occurrences (frequency table)
awk '{count[$1]++} END {for (k in count) print k, count[k]}' file.txt

# Deduplicate lines (preserves order)
awk '!seen[$0]++' file.txt

# Print lines between two patterns
awk '/START/,/END/' file.txt

# Print last field of each line
awk '{print $NF}' file.txt

BEGIN/END Blocks

# Add header and compute average
awk 'BEGIN {print "Name", "Score"} {sum+=$2; n++; print $1, $2} END {print "Avg:", sum/n}' scores.txt

BEGIN runs before input; END runs after all input is processed.

Practical Examples

# HTTP status code distribution from Nginx logs
awk '{s[$9]++} END {for (c in s) print c, s[c]}' access.log | sort -rn -k2

# Per-group sums
awk -F, 'NR>1 {group[$1]+=$3} END {for (g in group) print g, group[g]}' sales.csv

# Reorder and reformat columns
awk -F, -v OFS=',' '{print $3, $1, $2}' data.csv

# Extract key=value from config
awk -F= '/^DB_HOST/ {print $2}' .env

# Formatted output with printf
awk '{printf "%-20s %8.2f\n", $1, $2}' prices.txt

For portable scripts, stick to POSIX features. Install gawk via brew install gawk on macOS if you need GNU extensions. gawk 5.3+ adds a --csv mode for the quoting and escaping pitfalls covered in CSV parsing gotchas.

Common Gotchas

  • No $ on variables: NR not $NR. Writing $NR means "the field whose number equals NR."
  • String concatenation is implicit: "foo" "bar" yields "foobar" — no operator needed, which can cause silent bugs.
  • \r\n line endings: Windows files leave \r in the last field. Fix with sub(/\r$/, "") or pipe through dos2unix.
  • Shell variable passing: Use awk -v var="$SHELL_VAR" — awk does not expand shell variables inside single-quoted programs. See shell quoting rules.
  • sub/gsub modify in place: They return the substitution count, not the new string. Use gawk's gensub() for non-destructive replacement.
  • Array order is undefined: for (k in arr) iterates in arbitrary order. Pipe through sort for deterministic output.
  • Default FS=" " is magic: It splits on any whitespace run and trims leading/trailing whitespace. FS="[ ]" splits on literal single spaces only.
