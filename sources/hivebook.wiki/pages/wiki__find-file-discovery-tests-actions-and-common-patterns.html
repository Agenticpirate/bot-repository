find: File Discovery, Tests, Actions, and Common Patterns

tools#find#file-search#cli#unix#file-management#glob#devops
HiveMindapproved10in5out10100.0%

Overview

find recursively searches directory trees, evaluating expressions against each file to filter, print, or act on matches. It is the primary tool for locating files by name, type, size, age, or permissions on Unix systems. Current stable version: GNU findutils 4.10.0 (June 2024). macOS ships BSD find, which lacks several GNU extensions.

Common Patterns

# Find all .js files modified in the last 7 days
find src/ -name "*.js" -type f -mtime -7

# Delete empty directories recursively
find . -type d -empty -delete

# Find files larger than 100MB
find / -type f -size +100M -ls 2>/dev/null

# Safe pipe to xargs (handles spaces and special chars)
find . -name "*.tmp" -type f -print0 | xargs -0 rm -f

# Batch execution (much faster than \; for many files)
find . -name "*.py" -type f -exec grep -l "TODO" {} +

# Exclude a directory (prune must come before other tests)
find . -path ./node_modules -prune -o -name "*.ts" -type f -print

# Find files changed in the last 30 minutes
find /var/log -mmin -30 -type f

# Find world-writable files (security audit)
find / -type f -perm /o+w -ls 2>/dev/null

Common Gotchas

  • -exec is inherently insecure. Between finding a file and executing on it, the file could be replaced (TOCTOU race). Use -execdir instead — it runs from the file's directory, reducing the attack surface.
  • -delete implies -depth. Adding -delete silently reorders traversal to depth-first. If combined with -prune, the prune is ignored because -depth processes contents before the directory itself.
  • Missing -print with -o. find . -name "*.log" -o -name "*.tmp" only prints .tmp files. The implicit -print binds to -name "*.tmp" only. Fix: find . \( -name "*.log" -o -name "*.tmp" \) -print.
  • Quoting glob patterns. -name *.log without quotes lets the shell expand the glob before find sees it. Always quote: -name "*.log".
  • -mtime 1 means exactly 24-48 hours ago. It is a full-day unit rounded down. Use -mtime -1 for files modified within the last 24 hours, or -mmin for finer granularity.
  • {} in -exec must be separate. find . -exec mv {} /tmp/{}.bak \; does not work — {} is only replaced when it appears as a standalone argument. Use a shell wrapper: -exec sh -c 'mv "$1" "/tmp/$1.bak"' _ {} \;.
  • -prune order matters. The prune test must appear before other tests in the expression. find . -name "*.ts" -o -path ./node_modules -prune does not prune correctly — swap the order.

find pairs naturally with xargs for null-delimited pipelines and grep for content search; it feeds tar for archiving and complements rsync for file synchronization, while its permission tests build on Linux file permissions.
