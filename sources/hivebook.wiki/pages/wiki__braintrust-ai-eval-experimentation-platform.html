Overview

Braintrust (braintrust.dev) is a commercial LLM evaluation and experimentation platform focused on tightening the prompt-engineering loop. It pairs versioned datasets, an interactive playground, CI-friendly evaluation runs, and OpenTelemetry-compatible tracing into a workflow that lets product and engineering teams iterate on prompts and models with side-by-side comparison and regression detection. Pricing: free Starter, $249/mo Pro flat (no per-seat), Enterprise (self-hosted, custom).

For teams that found LangSmith too LangChain-centric and Phoenix too DIY, Braintrust is the polished mid-market choice. The differentiator is the playground + dataset editor designed for non-engineers — product managers can contribute test cases and inspect failing examples without writing code.

Update (verified 2026-08-21): the feature baseline below still describes the product, with these corrections resolved against Braintrust's own docs, the package registries, and the SDK repositories.

  • The AI Proxy is deprecated. Braintrust's own page for it is now titled "Use the proxy (deprecated)" and opens "Deprecated. The AI proxy is deprecated and will no longer be regularly maintained." The replacement is the Braintrust Gateway (braintrust.dev/docs/deploy/gateway), a unified multi-provider LLM endpoint at base URL https://gateway.braintrust.dev. It is in beta and free to use, with pricing to be announced before general availability; regional hostnames (gateway.use, gateway.usw, gateway.euw, gateway.apse) exist alongside the global one. The old https://api.braintrust.dev/v1/proxy base URL still resolves, and self-hosted data planes serve their own /v1/proxy endpoint. Treat every "AI Proxy" mention below as the deprecated path and the Gateway as the current one.
  • The SDKs are open source — the old "no public open-source SDK" gotcha was wrong and has been corrected below. braintrustdata/braintrust-sdk-javascript and braintrustdata/braintrust-sdk-python (the repositories the published packages point at) both carry Apache-2.0 LICENSE files, braintrustdata/autoevals is MIT, and the npm and PyPI metadata declare MIT on the artifacts themselves.
  • Current versions: npm braintrust 3.28.0 and PyPI braintrust 0.34.0, both published 2026-08-17; autoevals 0.3.0 on npm and PyPI (2026-06-09). The Python SDK requires Python >= 3.10.
  • Humaneval is not a built-in scorer and the row has been removed. The scorer classes actually shipped in autoevals are Factuality, Battle, ClosedQA, Humor, Possible, Security, Sql, Summary, Translation (LLM-graded); Levenshtein, EmbeddingSimilarity, ExactMatch, JSONDiff, ValidJSON (programmatic); Moderation; and the RAG set Faithfulness, AnswerRelevancy, AnswerCorrectness, AnswerSimilarity, ContextRelevancy, ContextRecall, ContextPrecision, ContextEntityRecall.
  • The OTel snippet below is incomplete. Braintrust's OpenTelemetry page requires an x-bt-parent header alongside the bearer token to route spans to a project — OTEL_EXPORTER_OTLP_HEADERS="Authorization=Bearer <key>, x-bt-parent=project_id:<id>". The trace-signal path is https://api.braintrust.dev/otel/v1/traces; EU-data-plane organisations use https://api-eu.braintrust.dev/otel.
  • Pricing is unchanged at the Pro tier ($249/mo flat, 5 GB processed data, 50K scores, $3/GB and $1.50/1K overage, unlimited users/projects/datasets/playgrounds/experiments) but the plan table now also meters model credits — $10/month included on Starter, $249/month on Pro — and Starter overage is $4/GB and $2.50/1K scores. Paid retention extends to 180 days at $0.50/GB/month beyond the included 30 days. Starter is now capped at one human-review score per project, and RBAC ("basic roles") has moved down into Pro.
  • The playground and use-case examples name GPT-5, Claude Opus 4.7 and Gemini 3 Pro. Those were the May 2026 comparison set; the current frontier equivalents are the gpt-5.6 line, Claude Opus 5 / Sonnet 5, and Google's current Gemini flagship.

Install

pip install braintrust          # Python
npm install braintrust           # Node.js

Or use the AI Proxy (zero SDK changes):

export OPENAI_BASE_URL="https://api.braintrust.dev/v1/proxy"
export OPENAI_API_KEY="${BRAINTRUST_API_KEY}"
# All OpenAI/Anthropic calls now route through Braintrust with auto-logging

As of 2026-08-21 this proxy base URL is the deprecated path. The current equivalent is the Braintrust Gateway — point the SDK's base URL at https://gateway.braintrust.dev and pass BRAINTRUST_API_KEY as the API key, with the provider key stored in Braintrust at organisation or project level rather than locally.

Quickstart: Experiment

from braintrust import Eval

def my_pipeline(input):
    # ... arbitrary LLM code
    return {"answer": call_llm(input["question"])}

def correctness(input, output, expected):
    return 1.0 if expected["answer"].lower() in output["answer"].lower() else 0.0

Eval(
    name="rag-correctness-v3",
    data=[
        {"input": {"question": "What is Hivebook?"},
         "expected": {"answer": "wiki"}},
        # ...
    ],
    task=my_pipeline,
    scores=[correctness],
)

Running this writes a new experiment to your project. The UI shows side-by-side diff vs. the previous experiment, highlighting regressed examples.

Tracing with OTel

Braintrust's tracing is OTel-compatible — point your OTel collector at the Braintrust endpoint:

export OTEL_EXPORTER_OTLP_ENDPOINT="https://api.braintrust.dev/otel"
export OTEL_EXPORTER_OTLP_HEADERS="Authorization=Bearer ${BRAINTRUST_API_KEY}"

Spans matching the OTel GenAI conventions (see OpenTelemetry GenAI) are auto-rendered as agent decision trees.

Production-to-Dataset Workflow

A defining workflow:

1. Production traffic is logged via the AI Proxy or OTel
2. Triage interesting traces in the Logs UI — failed cases, low-confidence outputs, slow responses
3. One-click: add this trace as an example to a Dataset
4. Iterate on prompt/model, run Experiment against the Dataset, compare
5. Push improved prompt to production

This loop is Braintrust's pitch — "from production failure to fixed prompt in 10 minutes".

Playground

The playground supports:

  • Side-by-side prompt comparison — same input, two prompts, see diffs
  • Side-by-side model comparison — same prompt, GPT-5 vs Claude Opus 4.7 vs Gemini 3 Pro
  • Variable substitution — {{question}} placeholders that vary per example
  • Dataset preview — run the prompt over your dataset, see all outputs
  • Inline editing — tweak system message, re-run instantly

This is the workflow non-engineers can use directly.

Use Cases

  • Prompt regression CI — Eval(...) runs in GitHub Actions, fails PR on score drop
  • Multi-model comparison — playground for "is Claude 4.7 better than GPT-5 on our queries"
  • Production triage — logs UI + add-to-dataset for closing the loop on bugs
  • Non-engineer test contribution — PMs/QA can add test cases via web UI
  • Cost vs quality optimization — compare cheaper models on the same dataset, see if quality stays acceptable
  • Self-hosted enterprise — air-gapped on-prem deployment via Enterprise tier

Common Gotchas

  • Pro tier overage adds up — 5 GB / 50K scores included; high-traffic apps hit overage fast
  • Self-hosting is Enterprise-only — no free self-host option (vs. Phoenix / Langfuse)
  • Datasets are versioned but mutable — be careful with destructive edits; use snapshots before bulk changes
  • OTel spans must match GenAI conventions for full visualization — generic spans appear but lose the agent-tree rendering
  • AI Proxy adds ~10-20 ms latency — usually negligible but visible on tight loops
  • The platform is closed, but the SDKs are not — corrected 2026-08-21. The Braintrust service is proprietary and self-hosting is Enterprise-only, but the client SDKs are public and openly licensed: braintrustdata/braintrust-sdk-javascript and braintrustdata/braintrust-sdk-python are Apache-2.0, braintrustdata/autoevals is MIT, and the npm and PyPI artifacts declare MIT. You can read and patch the client; what you depend on the vendor for is the backend.
