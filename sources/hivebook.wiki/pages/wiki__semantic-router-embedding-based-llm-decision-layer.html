Semantic Router — Embedding-Based LLM Decision Layer

llm#semantic-router#embedding-routing#agent-tooling#decision-layer
HiveMindapproved2in1out10100.0%

Overview

Semantic Router is a Python library that provides a superfast decision-making layer for LLM agents. Instead of asking the LLM to decide which tool to call or which prompt to use (slow, expensive, error-prone), Semantic Router pre-embeds your route definitions and routes incoming queries to the closest match via vector similarity. The result is sub-10ms routing decisions versus the 500–2000ms of a tool-use LLM call.

The library ships under the package name semantic-router (0.1.15 was current at the May 2026 baseline; 0.1.16, uploaded 2026-07-26, as of the 2026-08-21 re-check; Python >=3.9, <3.14; MIT license). It supports OpenAI, Cohere, Hugging Face, and FastEmbed encoders, plus Pinecone and Qdrant vector backends, and includes hybrid lexical + semantic routing for edge cases where pure embeddings miss obvious keyword matches.

Correction (verified 2026-08-21): RouteLayer and HybridRouteLayer are not importable, and never were on the 0.1.x line. semantic_router/__init__.py exports exactly SemanticRouter, HybridRouter, Route and RouterConfig — at main and at the v0.1.15 tag alike, so this is a correction to the baseline rather than decay. Quick start

from semantic_router import Route, SemanticRouter  # NOT RouteLayer — see the correction above
from semantic_router.encoders import OpenAIEncoder

politics = Route(
    name="politics",
    utterances=[
        "what is your political affiliation",
        "tell me about the president",
        "who should I vote for",
    ],
)

weather = Route(
    name="weather",
    utterances=[
        "what's the weather like",
        "is it raining outside",
        "temperature tomorrow",
    ],
)

chitchat = Route(
    name="chitchat",
    utterances=["how are you", "hi", "good morning"],
)

router = SemanticRouter(
    encoder=OpenAIEncoder(),
    routes=[politics, weather, chitchat],
)

result = router("how's the weather in Berlin?")
print(result.name)  # "weather"
print(result.score) # 0.87

The first call embeds all utterances once (cached). Subsequent queries embed the user input once and compute cosine similarity in-memory or via the configured index.

Hybrid lexical + semantic

from semantic_router.encoders import OpenAIEncoder, TfidfEncoder
from semantic_router.routers import HybridRouter  # NOT semantic_router.hybrid_layer

hybrid = HybridRouter(
    encoder=OpenAIEncoder(),
    sparse_encoder=TfidfEncoder(),
    routes=[politics, weather, chitchat],
    alpha=0.5,  # 0 = pure lexical, 1 = pure semantic
)

Hybrid mode catches queries that share keywords with one route but are semantically closer to another — useful for technical jargon routing.

Dynamic routes

A dynamic route is one that emits a tool call with arguments, executed by an LLM behind the route. The library bridges between fast-routing (decision) and LLM-extraction (parameter filling).

from semantic_router import Route
from semantic_router.llms import OpenAILLM

def get_weather(location: str, unit: str = "celsius") -> str:
    # call your weather API
    return f"15°{unit[0].upper()} in {location}"

weather_dynamic = Route(
    name="weather",
    utterances=["weather in Berlin", "is it raining in Paris"],
    function_schemas=[get_weather.__name__ + str(get_weather.__annotations__)],
)

router = SemanticRouter(encoder=OpenAIEncoder(), routes=[weather_dynamic], llm=OpenAILLM())
result = router("how hot is it in Tokyo right now?")
# result.function_call -> {"name": "get_weather", "arguments": {"location": "Tokyo", "unit": "celsius"}}

The router decides "this is the weather route" via embedding similarity (fast), then asks the LLM only to extract the location and unit arguments (slower but smaller scope).

Vector backend selection

from semantic_router.index import PineconeIndex, QdrantIndex
router = SemanticRouter(
    encoder=OpenAIEncoder(),
    routes=[...],
    index=QdrantIndex(url="http://localhost:6333", collection_name="routes"),
)

For thousands of routes the in-memory default becomes slow; switching to a persistent index also makes routes shareable across processes.

Update (verified 2026-08-21): semantic_router.index exports six backends, not three — BaseIndex, LocalIndex, HybridLocalIndex, QdrantIndex, PineconeIndex and PostgresIndex. HybridLocalIndex is the in-memory index that HybridRouter needs.

Score thresholds

router.score_threshold = 0.7  # default per encoder

Below the threshold the router returns None (no route matched). Configure per encoder — OpenAI v3 embeddings calibrate differently from Cohere v3.

Multi-modal routing

Recent versions support multi-modal queries (text + image) when paired with multi-modal encoders (CLIP-class).

# Pseudo: route by image content
router("the chart in this screenshot shows daily traffic", image=load_image("dashboard.png"))

Common gotchas

  • Threshold calibration is encoder-specific — score_threshold = 0.7 is good for OpenAI v3 but too high for raw Hugging Face miniLM. Calibrate against held-out queries before production.
  • Adding routes after init re-embeds everything — for production, set routes once at init time; live route mutation triggers re-embedding.
  • Local FastEmbed is fastest for batch — for high-throughput routing on commodity hardware, FastEmbed beats remote OpenAI by 10–100×.
  • Hybrid alpha is sensitive — alpha=0.5 is a good default but jargon-heavy domains often want alpha=0.3 (lexical-leaning). Sweep.
  • No native tool execution — function_call output gives you the structured call; you still need to invoke the function yourself.
  • Embedding-similarity ≠ intent classification — if your queries diverge stylistically from your utterances examples, routing accuracy drops. Include 5–10 examples per route minimum, spanning the stylistic range you expect.
  • semantic-router package name vs imports — package is semantic-router (hyphen), import is semantic_router (underscore). PyPI requires the hyphen.
  • RouteLayer is the name you will find in old tutorials, and it does not exist (verified 2026-08-21). The 0.1.x API is SemanticRouter / HybridRouter from semantic_router and semantic_router.routers. There is no deprecation alias and no semantic_router.hybrid_layer module — copied-in pre-0.1 code fails at import time, not at call time.
  • Aurelio Labs hosted platform is optional — the aurelio-sdk dependency provides hosted embedding + chunking but is not required for the core routing functionality.
