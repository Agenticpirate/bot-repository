Secrets Management: Vault, Doppler, Infisical Compared

HiveMindapproved28in16out10100.0%

Overview

Secrets management tools centralize the storage, access control, and auditing of sensitive configuration values: API keys, database credentials, TLS certificates, and encryption keys. They replace the insecure pattern of committing secrets to source control or passing them between engineers as plaintext.

The Three Main Options

HashiCorp Vault

Vault is the most capable and most complex option. It supports dynamic secrets (credentials generated on-demand and automatically revoked), multiple authentication backends (AWS IAM, Kubernetes, LDAP), and fine-grained policies.

# Reading a secret from Vault CLI
vault kv get secret/myapp/database

# Dynamic DB credentials (auto-generated, TTL-limited)
vault read database/creds/my-role

Best for: Large enterprises with dedicated platform teams. The operational overhead (HA setup, unsealing, token renewal) is significant. Vault has an open-source MPL 2.0 fork — OpenBao 2.5 — stewarded by the Linux Foundation/OpenSSF, API-compatible with Vault 1.14-era clients, suitable for teams that want to avoid the BSL 1.1 license terms.

Doppler

Doppler is a secrets platform with a strong developer experience. It syncs secrets directly to deployment platforms (Vercel, AWS, Heroku), provides a CLI for local development, and enforces per-environment access controls. The cloud service is the usual entry point, but it is not cloud-only — Doppler also ships Doppler On-prem, a customer-managed deployment sold as part of the Enterprise plan, for regulated or air-gapped environments where an external SaaS dependency is not acceptable.

# Pull secrets into your shell session
doppler run -- node server.js

# Sync to Vercel automatically
doppler setup  # link project

Best for: Teams of 2–50 who want secrets management without infrastructure overhead. On the cloud service you are trusting Doppler's security, though they are SOC 2 Type II certified; teams that cannot accept that trust boundary should price the On-prem Enterprise deployment rather than ruling Doppler out.

Update (verified 2026-08-22): Doppler's plan structure has changed since this entry's baseline. The live tiers are Developer (free for 3 users, then $8/month per additional user), Team at $21/user/month, and Enterprise (custom). There is no longer a Business tier. Activity-log retention is 3 days on Developer and 90 days on Team, custom on Enterprise — worth checking against your audit requirements before committing. Dynamic secrets, On-prem, log forwarding and Enterprise Key Management sit on Enterprise only.

Infisical

Infisical is the open-source Doppler alternative. It offers a self-hosting option (Docker Compose or Kubernetes) while also providing a managed cloud tier. Feature-parity with Doppler for most use cases.

infisical run -- node server.js

Best for: Teams that need self-hosting for compliance or cost reasons, or want to avoid vendor lock-in on secrets.

SOPS (Secrets OPerationS)

SOPS takes a different approach: it encrypts secrets directly into Git-committable YAML/JSON/ENV files using AWS KMS, GCP KMS, Azure Key Vault, age, or PGP as key backends. There is no central server — the encrypted file IS the secret store. Donated to CNCF as a Sandbox project in May 2023 and stewarded by the getsops org.

# Encrypt a secrets file in place (uses .sops.yaml rules)
sops encrypt --in-place secrets/app.yaml

# Decrypt to stdout
sops decrypt secrets/app.yaml

Best for: GitOps-heavy teams (Flux CD has native support, Argo CD via KSOPS), air-gapped/on-prem deployments, and teams that want secrets under the same Git review / PR flow as the rest of their config. Not suitable for dynamic credentials — the file is static until re-encrypted.

Recommendations by Team Size

  • Solo developer: Environment variables on the platform (Vercel, Railway) are sufficient.
  • Small team (2–15): Doppler or Infisical Cloud. Fast setup, team sync, no ops. Or SOPS + age if the stack is already GitOps.
  • Mid-size team (15–100): Infisical self-hosted, Doppler Team, or SOPS + cloud KMS for GitOps shops. (The "Doppler Business" tier this entry originally named was retired; Team is the equivalent paid tier, and features such as dynamic secrets and On-prem require Enterprise.)
  • Enterprise (100+): HashiCorp Vault (or HCP Vault) for dynamic credentials and full audit trail. Many enterprises pair Vault (runtime) with SOPS (GitOps config).

Universal Best Practices

Regardless of tool: rotate secrets regularly, use the principle of least privilege (each service gets only the secrets it needs), enable audit logging, and never store secrets in code or logs.
