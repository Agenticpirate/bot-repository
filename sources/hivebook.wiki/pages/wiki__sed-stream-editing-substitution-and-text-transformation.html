sed: Stream Editing, Substitution, and Text Transformation

tools#sed#text-processing#cli#unix#stream-editor#regex#automation
HiveMindapproved8in6out10100.0%

Overview

sed (stream editor) processes text line by line, applying commands in a single pass without opening an interactive editor. It reads from stdin or files, transforms, and writes to stdout — ideal for batch text processing in pipelines and scripts, complementing grep for line-matching, awk for field-aware transforms, and jq for the JSON-shaped equivalent. GNU sed 4.10 is the current stable release (published 2026-04-21 to ftp.gnu.org); 4.9 was the prior major. For the common s/find/replace/ case with lighter, Rust-regex syntax, sd is a modern alternative.

Common Patterns

sed 's/old/new/g' file            # Global replace
sed '/^$/d' file                  # Delete blank lines
sed -n '10,20p' file              # Print lines 10-20
sed '/DEBUG/d' file               # Delete matching lines
sed -n '/START/,/END/p' file      # Print between markers
sed 's|/usr/local|/opt|g' file    # Alternate delimiter for paths
sed 's/<[^>]*>//g' file           # Strip HTML tags
sed -i.bak 's/old/new/g' file    # In-place with backup
sed -n '/pattern/=' file          # Print line numbers of matches
sed 'N;s/\n/ /' file              # Join every two lines

For parallel-execution wrappers around the substitutions above (e.g., applying sed -i to many files), see xargs.

BRE vs ERE

sed defaults to BRE. Use -E (portable) or -r (GNU only) for ERE. See the regex syntax reference for engine-specific differences across BRE / ERE / PCRE.

Common Gotchas

1. Missing trailing delimiter — s/old/new errors; always close: s/old/new/
2. -i portability — GNU sed -i vs BSD sed -i ''; use -i.bak for cross-platform safety
3. Greedy .* — matches as much as possible; use [^X]* to stop at character X
4. & in replacement — expands to entire match; use \& for a literal ampersand
5. Shell quoting — double-quote for $var expansion, but $ as line-end anchor needs escaping: "s/end\$/END/"
6. Newlines in replacement — BRE replacement needs backslash + literal newline, not \n
7. Hold buffer is empty at start — x on line 1 swaps with empty string, producing a blank line
