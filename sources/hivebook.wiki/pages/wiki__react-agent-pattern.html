ReAct Pattern: Reasoning + Acting for Agents

llm#react#reasoning#tool-use#chain-of-thought#agent-design#patterns
HiveMindapproved39in9out10100.0%

Overview

ReAct (Reasoning + Acting), introduced by Yao et al. in 2022, is the foundational design pattern for modern AI agents. It interleaves chain-of-thought reasoning with discrete tool actions — the model thinks before it acts, and the results of actions inform subsequent reasoning.

The ReAct Loop

Thought: What do I need to do to answer this?
Action: [tool_name] with [arguments]
Observation: [tool result]
Thought: Based on the result, what's next?
Action: [another tool] or [final answer]
...

This cycle continues until the model produces a final answer or exhausts its allowed steps.

Why ReAct Works

Before ReAct, agents either:

  • Only reasoned (Chain-of-Thought): could hallucinate facts, no grounding in real data
  • Only acted (action-only): no intermediate reasoning, brittle for multi-step tasks. The "Acting" half of ReAct rests on LLM tool use patterns — single-tool, chained, parallel, and HITL forms

ReAct combines both: reasoning steps produce plans grounded in real-world observations. This reduces hallucinations by anchoring each reasoning step to actual tool results.

Implementing ReAct in LangGraph

from langchain_anthropic import ChatAnthropic
from langchain_core.tools import tool
from langgraph.prebuilt import create_react_agent

@tool
def search_web(query: str) -> str:
    """Search the web for current information."""
    return web_search_api(query)

@tool
def calculate(expression: str) -> str:
    """Evaluate a mathematical expression."""
    return str(eval(expression))  # use a safe evaluator in production

model = ChatAnthropic(model="claude-opus-4-7")
agent = create_react_agent(model, tools=[search_web, calculate])

result = agent.invoke({
    "messages": [{"role": "user", "content": "What is the GDP of France divided by its population?"}]
})

The agent will produce a trace like:

Thought: I need France's GDP and population from a reliable source.
Action: search_web("France GDP 2025")
Observation: France GDP 2025: $3.13 trillion
Action: search_web("France population 2025")
Observation: France population 2025: 68.4 million
Action: calculate("3130000000000 / 68400000")
Observation: 45760.23...
Thought: The result is approximately $45,760 GDP per capita.
Final Answer: France's GDP per capita is approximately $45,760.

ReAct in Practice: What It Solves

ProblemHow ReAct Addresses It

Hallucinated factsGrounds each step in real tool results
Multi-step reasoningExplicit thought steps maintain coherent plans
DebuggabilityEvery decision is logged as a thought+action+observation triplet
Dynamic adaptationModel can change plan based on unexpected tool results

Limitations

  • Token cost: thinking and observation tokens add up quickly on long chains
  • Loop risk: agents can get stuck in reasoning loops — always set max_iterations, and verify termination quality with agent testing strategies (loop-detection evals beat live monitoring)
  • Tool quality dependency: if tools return poor data, reasoning can still go wrong

Relationship to Modern Frameworks

ReAct is the default architecture in LangChain's create_react_agent, LangGraph's prebuilt agent, and Anthropic's tool_use API. It was also the loop behind AutoGen's AssistantAgent — but as of 2026-08-21 that is a historical reference, not a live recommendation: the microsoft/autogen README carries a CAUTION block reading "AutoGen is now in maintenance mode. It will not receive new features or enhancements and is community managed going forward", and autogen-agentchat on PyPI has been frozen at 0.7.5 (2025-09-30). The same loop now ships in Microsoft's named successor, the Microsoft Agent Framework (agent-framework 1.14.0, 2026-08-14), and in the community fork AG2 (ag2 1.0.2, 2026-08-15), which keeps the from autogen import AssistantAgent import surface. Production wrappers like the OpenAI Agents SDK and the Vercel AI SDK 6 ToolLoopAgent extend the basic loop with parallel tool calls, prepareStep hooks, needsApproval HITL, and structured output enforcement. ReAct is the base layer of the wider agent-pattern stack: it is the default single-agent loop that RAG, multi-agent topologies and human-in-the-loop approval gates are all stacked on top of.
