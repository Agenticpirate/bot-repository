Overview

AI Fairness 360 (AIF360) is a comprehensive toolkit for detecting and mitigating bias in machine-learning datasets and models. Created at IBM Research and now hosted under the Linux Foundation AI & Data / Trusted-AI umbrella, it offers an unusually large catalog of academic fairness metrics (70+) and bias-mitigation algorithms spanning the three intervention stages (pre-, in-, and post-processing), plus a Python and an R interface. It is the breadth-first counterpart to Fairlearn in the fairness-tooling space.

Core abstractions

AIF360 centers on a StructuredDataset / BinaryLabelDataset object that knows which attributes are protected and which group values are privileged vs. unprivileged. Metrics and mitigators operate on these dataset objects.

from aif360.datasets import BinaryLabelDataset
from aif360.metrics import BinaryLabelDatasetMetric, ClassificationMetric
from aif360.algorithms.preprocessing import Reweighing

dataset = BinaryLabelDataset(df=df, label_names=["label"], protected_attribute_names=["sex"])

privileged = [{"sex": 1}]
unprivileged = [{"sex": 0}]

# Dataset-level fairness metric (before any model)
metric = BinaryLabelDatasetMetric(dataset, unprivileged_groups=unprivileged,
                                  privileged_groups=privileged)
print("disparate impact:", metric.disparate_impact())
print("stat parity diff:", metric.statistical_parity_difference())

# Pre-processing mitigation: reweight examples to remove dataset bias
rw = Reweighing(unprivileged_groups=unprivileged, privileged_groups=privileged)
dataset_fair = rw.fit_transform(dataset)

Metrics and algorithms

Pre-processingReweighing, Optimized Preprocessing, Disparate Impact Remover, LFR

Metrics include disparate impact, statistical parity difference, equal opportunity difference, average odds difference, Theil index, and many more — with both dataset-level (BinaryLabelDatasetMetric) and model-prediction-level (ClassificationMetric) variants.

AIF360 wins on breadth of academic methods; Fairlearn wins on scikit-learn integration and a cleaner everyday API. Many teams measure with both.

Gotchas

  • Define privileged/unprivileged groups explicitly. Almost every metric and mitigator needs privileged_groups / unprivileged_groups dicts; getting the mapping wrong inverts the interpretation of the results.
  • Disparate impact is a ratio (4/5ths rule territory): values near 1.0 are fair; < 0.8 traditionally flags adverse impact. Statistical parity difference is the additive analog (0 = parity).
  • Heavier setup than Fairlearn. The dataset-object model and large dependency surface make AIF360 more ceremony for a quick check; for a fast group-metric audit Fairlearn's MetricFrame is lighter.
  • Fairness criteria conflict (same caveat as all fairness tooling): you cannot satisfy disparate impact, equalized odds, and calibration simultaneously in general — choose per the harm and context.
