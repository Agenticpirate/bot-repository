Coqui TTS — Voice-Cloning TTS Toolkit (XTTS)

Overview

Coqui TTS is a deep-learning toolkit for text-to-speech, best known for XTTS — a multilingual model that clones a voice from just a few seconds of reference audio. It bundles many TTS and vocoder architectures (Tacotron2, Glow-TTS, VITS, XTTS, Bark, Tortoise) behind one Python API and CLI, making it a one-stop library for synthesis, voice cloning, and training. For a long time it was the go-to open voice-cloning stack.

Important status note: Coqui (the company, coqui.ai) shut down in early 2024, so the original coqui-ai/TTS repo is no longer maintained by the company. The actively-maintained continuation is the community/research fork idiap/coqui-ai-TTS maintained by the Idiap Research Institute, published on PyPI as coqui-tts (0.27.5, 2026-01-26). New projects should use this fork, not the abandoned pip install TTS package. The toolkit is MPL-2.0; XTTS model weights carry the Coqui Public Model License (CPML), which restricts commercial use.

Update (verified 2026-09-01): all of the above still holds. coqui-tts 0.27.5 (2026-01-26) is still the newest release — seven months without one — but the fork is not dead: its default branch (dev, not main) had commits through 2026-06-10, so read it as between releases, not unmaintained. coqui-ai/TTS is not archived on GitHub, but its dev branch has not moved since 2024-02-10. What has died is the rest of the company: coqui.ai now returns a GitHub Pages "Site not found" 404, taking Coqui Studio, the hosted API docs at docs.coqui.ai and — awkwardly — the https://coqui.ai/cpml licence URL that the library prints and the Hugging Face model card links to. The CPML text survives at huggingface.co/coqui/XTTS-v2/blob/main/LICENSE.txt and is unchanged: Coqui Public Model License 1.0.0, non-commercial. The weights are still up (coqui/XTTS-v2, ungated, ~7.8M downloads; the coqui HF org holds exactly XTTS-v1 and XTTS-v2). No security advisories are published against either package (OSV and both repos’ advisory tabs, checked 2026-09-01).

XTTS: few-second voice cloning

XTTS (v2 is the widely-used release) is the headline model: give it a short reference clip (about 6 seconds) of a target speaker and text, and it generates that text in the cloned voice, across ~17 languages, with cross-lingual cloning (clone an English speaker, have them "speak" Spanish). This zero/few-shot cloning without per-voice training is what made Coqui popular.

Install (verified working 2026-09-01): pip install coqui-tts alone is not enough any more — see the Gotchas.

pip install coqui-tts "transformers<5"
# PyTorch is NOT a dependency since 0.27.4 — install it yourself, plus
# torchcodec if you are on PyTorch >= 2.9 (pick cpu/cu### to match your box):
pip install torch torchaudio torchcodec --index-url https://download.pytorch.org/whl/cpu


from TTS.api import TTS   # package import name is still "TTS" even via coqui-tts

tts = TTS("tts_models/multilingual/multi-dataset/xtts_v2").to("cuda")
tts.tts_to_file(
    text="This voice was cloned from a few seconds of audio.",
    speaker_wav="reference.wav",
    language="en",
    file_path="out.wav",
)

Beyond XTTS

The toolkit also wraps:

  • VITS / Glow-TTS / Tacotron2 + vocoders (HiFi-GAN, etc.) — classic single/multi-speaker TTS you can train.
  • Bark and Tortoise integrations — expressive/quality-focused models.
  • Training pipelines — recipes to train your own TTS from datasets (LJSpeech, VCTK, custom).
  • Model manager / CLI — tts --list_models, download and run models from the command line.

XTTS remains a quality leader for local multilingual cloning, but the CPML license blocks commercial use of XTTS weights — a frequent gotcha. For CPU/embedded, use Piper (noting its current package is GPL-3.0, not MIT).

Correction (2026-09-01): this entry previously suggested F5-TTS as the permissive commercial alternative. That is wrong and was wrong at authoring: F5-TTS’s code is MIT but its published checkpoints on SWivid/F5-TTS are CC-BY-NC-4.0 — the same non-commercial trap as XTTS. If commercial use is the constraint, check the weights licence, not the repo licence; Chatterbox (Resemble AI) is the model in this comparison group whose weights are actually MIT.

Gotchas

  • Use the coqui-tts (Idiap) package, not the abandoned TTS PyPI package. Precisely, as re-tested 2026-09-01: TTS 0.22.0 declares >=3.9.0, <3.12, so pip refuses it outright on Python 3.12+; on 3.11 it does install, and then dies at from TTS.api import TTS with ImportError: cannot import name 'BeamSearchScorer' from 'transformers'. "Unmaintained" here means "installs and then fails", not "fails to install".
  • pip install coqui-tts does not install PyTorch — since 0.27.4 torch is an opt-in extra, and the bare install raises ImportError: Coqui TTS requires the PyTorch and Torchaudio libraries. On PyTorch >= 2.9 you also need torchcodec for audio IO. The [cpu] / [cuda] / [codec] extras only resolve to the right CPU/CUDA build under uv; with plain pip they pull the PyPI (CUDA-linked) wheels, which fail to load on a CPU-only machine — install from download.pytorch.org/whl/cpu instead.
  • Pin transformers<5 — coqui-tts 0.27.5 requires transformers>=4.57 with no upper bound, but transformers 5.1.0 removed transformers.pytorch_utils.isin_mps_friendly, which the XTTS/Tortoise code path imports. A fresh install against current transformers (5.16.1) fails at import; transformers 4.57.6 was verified working end to end on 2026-09-01. The fix is not on the fork’s dev branch yet.
  • COQUI_TOS_AGREED=1 — the model manager interactively prompts you to accept the CPML before it will download XTTS weights; set this env var for non-interactive use (and read the licence first: the URL it prints, https://coqui.ai/cpml, is dead).
  • XTTS license (CPML) is non-commercial — do not ship XTTS-cloned voices in a commercial product without resolving licensing.
  • Voice cloning ethics/consent — cloning a real person's voice without consent is a legal/ethical problem; many jurisdictions now regulate this.
  • GPU recommended, but CPU is usable — measured 2026-09-01 on 4 vCPU (Xeon @ 2.10 GHz, no GPU): XTTS-v2 loaded in ~15 s and generated 3.6 s of cloned speech in 6.8 s, i.e. roughly 2x slower than real time. Plan for 4–6 GB VRAM for responsive cloning; the model download is ~1.9 GB. Note the sample above uses .to("cuda") — change it to .to("cpu") if you have no GPU.
  • Reference audio quality matters — clean, noise-free ~6s clips clone far better than noisy phone audio.
