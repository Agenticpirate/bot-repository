grep: Pattern Matching, Regular Expressions, and Text Search

Overview

grep searches input files for lines matching a pattern, printing matches to stdout. It is the fundamental text-search tool on Unix systems, supporting basic (BRE), extended (ERE), fixed-string, and Perl-compatible (PCRE) regex. Current stable version: GNU grep 3.12 (April 2025).

BRE vs ERE

FeatureBRE (default, -G)ERE (-E)

Alternation\||
One or more\++
Zero or one\??
Grouping\( \)( )
Repetition\{n,m\}{n,m}

In GNU grep, BRE and ERE have identical functionality — only the escaping differs. POSIX BRE lacks +, ?, and | entirely.

Common Patterns

Recursive search with file filtering:

grep -rn --include="*.py" "import os" src/

Count error lines across log files:

grep -c "ERROR" /var/log/app/*.log

Extract values with Perl regex (lookahead/lookbehind):

grep -oP '(?<=version: )\d+\.\d+\.\d+' config.yaml

Multi-pattern matching:

grep -E "WARN|ERROR|FATAL" application.log
# Or from a file of patterns:
grep -f patterns.txt logfile.log

Quiet mode for scripting:

if grep -q "main" src/app.py; then
  echo "Entry point found"
fi

Exclude directories:

grep -rn --exclude-dir={node_modules,.git,dist} "TODO" .

Common Gotchas

1. BRE is the default. grep "foo+" looks for literal foo+. Use grep -E "foo+" or grep "foo\+" for one-or-more.
2. -o discards context flags. -o with -A/-B/-C still only prints the matched portion, not surrounding lines.
3. Locale affects character ranges. [a-z] may include accented characters depending on LC_COLLATE. Use [[:lower:]] or set LC_ALL=C for ASCII-only matching.
4. Backreferences kill performance. \1 forces backtracking. On large files, this can be orders of magnitude slower than equivalent patterns without backrefs.
5. Binary file detection. grep prints "Binary file ... matches" and stops on NUL bytes. Use -a to force text mode or --binary-files=without-match to skip binaries.
6. --include matches basename only. --include="src/*.py" does NOT match — use --include="*.py" and specify the search path instead.
7. -r skips symlinks, -R follows them. Using -R in a repo with circular symlinks can loop. Prefer -r with explicit paths.
