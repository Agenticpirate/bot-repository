Altair — Declarative Statistical Visualization (Vega-Lite)

Overview

Altair is a declarative statistical visualization library for Python built on Vega-Lite. You describe what you want — which data columns map to which visual channels (x, y, color, size), what mark type (point, bar, line), what transforms and interactions — and Altair emits a Vega-Lite JSON spec that renders as an interactive chart in the browser/Jupyter. The philosophy: you spend effort on understanding the data, not on imperative drawing code. Altair is maintained under the Vega project (UW Interactive Data Lab lineage).

Currency (June 2026)

Latest release 6.2.1 (2026-06-05), BSD-3-Clause, Python 3.10+. Altair 5+ brought a major API modernization (method-chaining, typed encodings, better theming) and tracks current Vega-Lite. Actively maintained.

The declarative model

An Altair chart is Chart(data).mark_*().encode(...):

import altair as alt
from vega_datasets import data

cars = data.cars()

chart = (
    alt.Chart(cars)
    .mark_circle(size=60)
    .encode(
        x='Horsepower:Q',
        y='Miles_per_Gallon:Q',
        color='Origin:N',
        tooltip=['Name:N', 'Year:T'],
    )
    .interactive()      # pan + zoom for free
)
chart.save('cars.html')

The :Q, :N, :T, :O suffixes declare the data type of each channel — Quantitative, Nominal, Temporal, Ordinal — which drives sensible default scales and legends. This type-awareness is central to Altair's "correct by default" charts.

Interaction and composition

Altair's standout strength is declarative interaction and chart composition:

  • Selections (alt.selection_interval, alt.selection_point) create brushes/filters bound to the chart.
  • Linked views: selections in one chart filter another, enabling cross-filtering dashboards in pure Python.
  • Composition operators: layer (+), horizontal concat (|), vertical concat (&), and facet build complex multi-view figures from simple charts.

brush = alt.selection_interval()
base = alt.Chart(cars).mark_point().encode(
    x='Horsepower:Q', y='Miles_per_Gallon:Q',
    color=alt.condition(brush, 'Origin:N', alt.value('lightgray')),
).add_params(brush)
base | base.encode(x='Acceleration:Q')   # two linked, brushable views

Choose Altair for interactive, exploratory, web-rendered charts and linked dashboards; choose plotnine for static ggplot2-style figures; matplotlib for total control.

When to use it

  • Interactive exploratory data analysis in Jupyter where brushing/zooming/linking accelerates understanding.
  • Lightweight dashboards without a JS framework (export to HTML or embed in Streamlit/Panel).
  • Reproducible chart specs: the Vega-Lite JSON is portable and version-controllable.

Gotchas

  • 5000-row default limit. Altair embeds data in the spec and historically capped at 5000 rows (alt.data_transformers.enable('vegafusion') or external data URLs lift this). Plotting huge frames inline bloats the notebook/HTML — aggregate or use VegaFusion.
  • Encoding type suffixes matter. Omitting :Q/:N/:T makes Altair guess, sometimes wrongly (a numeric category treated as quantitative); be explicit.
  • Data must be tidy/long. Like Vega-Lite, Altair expects long-form data; pivot wide data first.
  • Rendering needs a frontend. Charts render in a browser/Jupyter via JavaScript; in plain scripts use .save('chart.html') or .save('chart.png') (PNG needs vl-convert).
  • Not for 3D / raster-heavy scientific plots — it targets 2D statistical graphics.
