About the directory

A directory you can trust.

SkillsClaude is an open directory of Claude Skills — the reusable, file-based capabilities that extend Claude Code with project knowledge, workflows, and tools. We crawl collection repositories directly from GitHub and grade every entry on a transparent five-level trust ladder: official, featured, tested, verified, and unverified.

Filter by trust level to find skills backed by Anthropic or validated by our editors, sort by GitHub stars to follow the community, or search across thousands of skills, subagents, and slash commands by name, author, or repository. Each detail page includes the original source, license, and a one-click install command so you can add a skill to Claude Code in seconds.

Built a skill of your own? and we will read it straight from GitHub and grade it for trust.
