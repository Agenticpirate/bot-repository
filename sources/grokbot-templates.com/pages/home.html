Frequently asked questions

What is a Grok Bot template?

A Grok Bot template is a public share link for a bot's instructions, plugins, and skills — not the creator's private chats or custom code. This directory lists those share links so you can try the same bot.

How do I install a template?

Open the card's x.ai share link, then choose Add to Grok Bot. The bot is added to your own Grok collection. Nothing is installed on this site. Full install and vetting steps: /blog/how-to-share-install-vet-grok-bot-templates

Is it safe to add a template I did not write?

Treat it as software you did not write. Shared Bots are third-party, and every Bot on your account shares one cloud computer. Vet it before you enable routines: /blog/how-to-share-install-vet-grok-bot-templates

Are these templates free?

Yes. Browsing this directory and opening share links on x.ai does not cost anything here. xAI's own account rules still apply.

Is this site affiliated with xAI?

No. Grokbot Templates is an independent public directory. It is not affiliated with xAI, Grok, or X.
