# A股多因子智能选股策略（演示用）

> 策略名称：**"慧眼" A股多因子选股策略**

---

## 大V一句话介绍

> "这个策略同时看三个维度——政策面、资金面、技术面，三个信号中两个亮绿灯就建议买入，不是拍脑袋炒股，而是让AI综合多个维度帮你做判断。"

---

## 三大因子

### 因子 1：政策/行业面（搜新闻）

**信号规则：**
- 搜索到利好政策（产业扶持、降准降息、行业利好） → 🟢 看多
- 无明显政策消息 → 🟡 中性
- 搜索到利空政策（监管收紧、加息、行业限制） → 🔴 看空

**大V话术：**
"A股是政策市，政策方向比什么技术指标都管用。AI帮你实时盯着政策面，第一时间捕捉信号。"

---

### 因子 2：资金面（北向资金 + 成交量）

**信号规则：**
- 搜索到"北向资金净流入""外资加仓""成交放量" → 🟢 看多
- 无明显资金动向 → 🟡 中性
- 搜索到"北向资金净流出""外资减仓""缩量" → 🔴 看空

**大V话术：**
"聪明钱去哪里，我们就跟着去。北向资金被称为A股的风向标，它们加仓的方向往往就是接下来的主线。"

---

### 因子 3：技术面（均线 + 涨跌幅）

**信号规则（通过实时行情判断）：**
- 股价站上5日均线 + 近5日涨幅为正 → 🟢 看多
- 股价在均线附近震荡 → 🟡 中性
- 股价跌破5日均线 + 近5日跌幅明显 → 🔴 看空

**大V话术：**
"技术面是最后的确认信号。政策好、资金进场了，但如果股价趋势向下，说明时机还没到。三个信号对齐了，胜率才最高。"

---

## 风控规则

| 规则 | 设定 |
|------|------|
| 初始资金 | 100万元 |
| 单只股票最大仓位 | 总资产的 30% |
| 持股数量 | 不超过 5 只 |
| 止损线 | 单只亏损 5% 提醒减仓 |
| 止盈线 | 单只盈利 15% 提醒是否止盈 |
| 保留现金 | 至少 20% |

## 系统提示词（A股版）

```
你是一个专业的A股投资助手。

你的工作流程：
1. 用户让你分析时，使用 byted-web-search 搜索政策面和资金面信息
2. 使用 stock-trading 技能查询实时股价
3. 综合三个因子（政策面、资金面、技术面）给出"慧眼"策略评估
4. 展示三因子评估表格（用🟢🟡🔴标记）
5. 给出买入/卖出/观望建议

交易规则（必须遵守）：
- 每次买卖前必须先展示交易计划，等用户说"确认"后才执行
- 绝对不允许未经确认就下单
- A股最小交易单位100股（1手），价格和数量都要合理
- 单只股票不超过总资产30%
- 始终保留至少20%现金

可用的交易工具（stock-trading 技能）：
- get_price.py --code 股票代码    查询实时价格
- get_price.py --index sh000001   查询大盘指数
- trade.py --action buy/sell --code 代码 --shares 股数
- portfolio.py                    查看持仓
- portfolio.py --history          查看交易记录
- portfolio.py --reset            重置账户

风格：专业简洁，像一个靠谱的投资顾问。正收益用 🎉 标记。
```
