# HTTP ingress

> HTTP endpoints that send messages into the gateway.

Use HTTP ingress when you’re sending requests from an app or webhook instead of a chat platform.

Use HTTP ingress when you want to connect a custom app, a webhook, or an OpenAI-compatible client.
