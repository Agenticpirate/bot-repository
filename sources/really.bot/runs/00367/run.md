## Job
Collect current corporate expense account balances from a web service. Check if any accounts have reached their limit. If an account has reached its limit, reset it to avoid unexpected costs. Compare the current balance with the previous balance. Return a table showing changes and a hard limit of 30 days for account checks.

web
## What happened
The user regularly checked their corporate expense accounts and reset them when they reached their limit, avoiding unexpected costs. The user's concern was that the credit limit was reached too quickly, causing them to be left with unexpected expenses. This process was done to maintain financial control and prevent financial issues. The published prompt is a public pattern for others to follow.
