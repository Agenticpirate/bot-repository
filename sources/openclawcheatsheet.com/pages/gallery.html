How to Use

  1. Browse a category and find a template that fits your role
  2. Copy the SOUL.md content
  3. Paste it into ~/.openclaw/workspace/SOUL.md
  4. Edit the [PLACEHOLDER] values with your real info
  5. Restart: openclaw gateway restart

Or use the Workspace Wizard to generate customized files from scratch.

Frequently asked questions

What is SOUL.md in OpenClaw?

SOUL.md is a markdown file that defines your OpenClaw agent's personality, communication style, values, and behavioral boundaries. It's loaded at every session start.

How do I use a template from this gallery?

Pick a category, open a template, use the Copy button on each code block, and paste into ~/.openclaw/workspace/SOUL.md (and AGENTS.md where provided). Replace placeholders, then restart the gateway.
