37### Script: batch-rename.sh
38
39**What it does:** Renames `*.jpeg` to `YYYY-MM-DD_filename.jpg` in a target directory.
40
41```bash
42#!/usr/bin/env bash
43# batch-rename.sh — Rename .jpeg to .jpg with date prefix
44# Usage: ./batch-rename.sh [directory] [--dry-run]
45
46set -euo pipefail
47
48DIR="${1:-.}"
49DRY_RUN="${2:-}"
50DATE_PREFIX=$(date +%Y-%m-%d)
51COUNT=0
52
53if [[ ! -d "$DIR" ]]; then
54 echo "Error: Directory '$DIR' not found" >&2
55 exit 1
56fi
57
58for file in "$DIR"/*.jpeg; do
59 [[ -e "$file" ]] || { echo "No .jpeg files found in $DIR"; exit 0; }
60 base=$(basename "$file" .jpeg)
61 new_name="${DIR}/${DATE_PREFIX}_${base}.jpg"
62
63 if [[ "$DRY_RUN" == "--dry-run" ]]; then
64 echo "[DRY RUN] $file -> $new_name"
65 else
66 mv "$file" "$new_name"
67 echo "Renamed: $file -> $new_name"
68 fi
69 ((COUNT++))
70done
71
72echo "Done. $COUNT files processed."
73```
74
75**Usage:**
76```bash
77chmod +x batch-rename.sh
78./batch-rename.sh /path/to/photos --dry-run # Preview changes
79./batch-rename.sh /path/to/photos # Execute
80```

82**User:** Can you make a Python version that also resizes them?

84**Agent:**

86Sure. Adding Pillow for resizing. The script will accept a max width/height parameter.
87
88```python
89#!/usr/bin/env python3
90"""batch-rename-resize.py — Rename .jpeg to .jpg, add date prefix, optionally resize.
91Usage: python3 batch-rename-resize.py /path/to/photos --max-size 1920 --dry-run
92"""
93
94import argparse, os, sys
95from datetime import date
96from pathlib import Path
97
98def main():
99 parser = argparse.ArgumentParser(description="Batch rename and resize JPEG files")
100 parser.add_argument("directory", help="Target directory")
101 parser.add_argument("--max-size", type=int, default=0, help="Max width/height in px (0=skip)")
102 parser.add_argument("--dry-run", action="store_true", help="Preview without changes")
103 args = parser.parse_args()
104
105 # Only import Pillow if resizing is needed
106 if args.max_size > 0:
107 try:
108 from PIL import Image
109 except ImportError:
110 print("Error: pip install Pillow required for resizing", file=sys.stderr)
111 sys.exit(1)
112
113 dir_path = Path(args.directory)
114 if not dir_path.is_dir():
115 print(f"Error: '{args.directory}' not found", file=sys.stderr)
116 sys.exit(1)
117
118 prefix = date.today().isoformat()
119 count = 0
120
121 for f in sorted(dir_path.glob("*.jpeg")):
122 new_name = dir_path / f"{prefix}_{f.stem}.jpg"
123 if args.dry_run:
124 print(f"[DRY RUN] {f.name} -> {new_name.name}")
125 else:
126 f.rename(new_name)
127 if args.max_size > 0:
128 img = Image.open(new_name)
129 img.thumbnail((args.max_size, args.max_size))
130 img.save(new_name, quality=85)
131 print(f"Processed: {new_name.name}")
132 count += 1
133
134 print(f"Done. {count} files processed.")
135
136if __name__ == "__main__":
137 main()
138```
139
140Requires: `pip install Pillow` (only if using `--max-size`).
